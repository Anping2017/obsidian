# 沟通协调

## 🎯 核心概念

### 沟通协调定义
**沟通协调**是指领导者通过有效的信息传递、情感交流和利益协调，建立良好的人际关系，促进团队协作，实现组织目标的核心领导能力。

### 核心特征
- **双向性**：信息双向流动
- **目的性**：有明确的沟通目标
- **情境性**：根据情境调整方式
- **效果性**：注重沟通效果

## 📚 沟通理论框架

### 沟通模型

```mermaid
    G --> A
    
    A --> A1[想法]
    A --> A2[意图]
    A --> A3[情感]
    
    B --> B1[语言]
    B --> B2[非语言]
    B --> B3[符号]
    
    C --> C1[内容]
    C --> C2[形式]
    C --> C3[风格]
    
    D --> D1[口头]
    D --> D2[书面]
    D --> D3[电子]
    
    E --> E1[理解]
    E --> E2[解释]
    E --> E3[反应]

```

### 沟通类型分类
| 分类维度 | 类型 | 特征 | 适用场景 |
|----------|------|------|----------|
| **按方向** | 上行沟通 | 下级向上级 | 汇报工作、请示问题 |
| | 下行沟通 | 上级向下级 | 传达指令、指导工作 |
| | 平行沟通 | 同级之间 | 协调配合、信息共享 |
| **按方式** | 正式沟通 | 正式渠道 | 重要信息、正式场合 |
| | 非正式沟通 | 非正式渠道 | 日常交流、情感沟通 |
| **按媒介** | 口头沟通 | 语言交流 | 即时反馈、情感表达 |
| | 书面沟通 | 文字交流 | 准确记录、正式传达 |
| | 电子沟通 | 电子媒介 | 快速便捷、跨地域 |
