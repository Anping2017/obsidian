# 贝索斯思维框架详解

## 一、12 大核心思维模式

### 1. 客户偏执(Customer Obsession)⭐
"We are not competitor-obsessed, we are customer-obsessed."
- 从客户反推所有决策
- Divinely discontent(神性不满)的客户
- 高管会议留客户空椅子
- 盯客户 = 领跑,盯对手 = 追随

### 2. 长期主义(Long-term Thinking)⭐
Amazon 20 年不赚钱。"Willing to be misunderstood for long periods."
- 10-year outlook > 季度报表
- 长期主义 = 愿意在别人不理解时坚持

### 3. Day 1 Mindset ⭐
"Day 2 is stasis. Followed by irrelevance. Followed by decline. Followed by death."
- 抵抗代理(用流程代替思考)
- 拥抱外部趋势
- 高速决策反官僚
- Day 2 症状:会议多决策少 / 用流程代脑子 / KPI 代替客户满意

### 4. Working Backwards(从结果反推)⭐
Amazon 独有:做新产品前先写:
1. Press Release(发布新闻稿)
2. FAQ
3. 视觉稿
4. User Manual

**写不出来 = 想不清楚,别做**。

### 5. Type 1 vs Type 2 决策 ⭐⭐
Bezos 最原创方法论。
- **Type 1(单向门)**:不可逆,慢决,90% 信息才决
- **Type 2(双向门)**:可逆,快决,70% 信息就决

大多数决策是 Type 2,但被当 Type 1 处理 → 决策慢 → 组织变 Day 2。

### 6. 6-Page Memo(反 PPT)
会议前静读 6 页备忘录 30 分钟,禁用 PPT。
- PPT 让作者藏在 bullet points 后
- 6 页 memo 强迫完整思考
- 写不清楚的东西 PPT 帮不了

### 7. Two-Pizza Team
6-10 人。沟通成本 O(n²)。小团队=快决+主人翁。

### 8. Regret Minimization Framework
Bezos 离开 D.E. Shaw 创办 Amazon 的决策法。
"80 岁我会后悔哪个?"
- 财务是短期账,后悔是终生账
- 尤其对 Type 1 极好用

### 9. High Standards(可教)
"High standards are teachable"(与 Munger 认为天赋不同)
- 见过好东西(才有标准)
- 明确 scope(不是所有都极致)
- 有正向反例

### 10. Frugality + Ownership
门板办公桌传统。"绝不说 that's not my job"。

### 11. Focus on What Doesn't Change(押不变的东西)
"10 年后什么不变" > "10 年后什么改变"
- 客户想要低价 / 快送达 / 多选择 — 10 年后仍然
- 押不变 = 稳定复利
- 追热点 = 高风险

### 12. Fail Big, Fail Often
"If failures aren't growing, you're not inventing at meaningful size."
- Fire Phone / Auctions / Wallet 都失败
- AWS / Prime / Kindle / Alexa 大成
- 失败是 discovery cost
- **但失败必须是 Type 2(可回收)**

## 二、Type 1 vs Type 2 深度展开

### 判定问题
- 决策错了能回滚吗?
- 回滚成本?回滚时间?
- 影响核心资产还是边缘资产?

### Type 1(慢决)典型
- 辞主业创业 / 招合伙人 / 公开战略 / 发布伤信任产品 / 分手 / 大贷款

### Type 2(快决)典型
- 试新功能 / 招初级员工 / 定价调整 / 广告文案 / 试新市场 / 换 AI 工具

### 最大陷阱
**把 Type 2 当 Type 1 处理**:
- "发不发这条视频"想 3 天(应 3 分钟)
- "用哪个订阅工具"研究 2 周(应 1 小时)
- "招不招 freelancer"纠结一月(应试 1 周)

**Amazon 90% 决策是 Type 2**。你的也是。

### 用户 vault 应用
- ✅ Type 1(慢决):全职 vs 副业 / 用真名 vs 品牌名 / 招合伙人
- ✅ Type 2(快决,别再纠结):
  - 手机 vs 露营先做哪个 → 试 90 天
  - 中英文哪个主 → 试 30 天
  - AIGC vs 故障诊断 wedge → 试 6 周
  - Trade Me 要不要接入 → 试 60 天

## 三、黑暗面 / 局限

1. **仓库工人待遇差** — 长期争议,替代率高
2. **强硬反工会**
3. **公开离婚 + 隐私争议**
4. **与 Musk 太空竞赛的 insecurity**
5. **对小卖家挤压**(Amazon Basics 用第三方数据)
6. **税务优化极致**
7. **华盛顿邮报干预争议**(2024)
8. **政治游说 + 反反垄断游说**

## 四、可复用 vs 不可复用

### 可复用
| 模式 | 具体做法 |
|---|---|
| Type 1 vs Type 2 | 每决策先分类 |
| Working Backwards | 先写 PR + FAQ |
| Regret Minimization | 大决策问 80 岁 |
| Day 1 Mindset | 每天问"如果今天是第一天" |
| 客户偏执 | 留客户空椅子 |
| 押不变 | 问"10 年后什么不变" |
| 6-Page Memo | 重要沟通 1-2 页 |
| Two-Pizza Team | 保 6-10 人 |
| Fail Big Type 2 | 大失败但可回收 |

### 不可复用
| 模式 | 为什么 |
|---|---|
| 20 年不赚钱 | 你没华尔街融资 |
| Amazon 规模效应 | 独一无二 |
| 资本市场地位 | 需要 30+ 年积累 |

## 五、Musk vs Jobs vs Munger vs Bezos 四方对比

| 维度 | Musk | Jobs | Munger | Bezos |
|---|---|---|---|---|
| 核心 | 物理突破 | 品味完美 | 谦逊避错 | 客户+长期 |
| 时间尺度 | 100 年 | 10 年 | 30-70 年 | 20-50 年 |
| 决策速度 | 快 | 慢 | 极慢 | Type 1 慢/Type 2 快 |
| 风险容忍 | 极高 | 中高 | 极低 | 中(可控) |
| 失败态度 | 拥抱 | 完美 | 避免 | 大失败但 Type 2 |
| 组织哲学 | 反官僚 | A players | 少而精 | Two-Pizza+Day 1 |
| 沟通 | Twitter | 精心 | 书面 | 6-page memo |
| 想解决 | 物种存续 | 体验尊严 | 判断质量 | 客户不满意 |

### 4 人根本差异
- **Musk**:如何造出以前造不出的东西
- **Jobs**:如何造出让人爱的东西
- **Munger**:如何不被自己愚蠢干掉
- **Bezos**:如何长期为客户创造价值,同时不押身家

### 谁最适合谁?
- 深科技创业者 → Musk 主导
- 消费产品/设计驱动 → Jobs 主导
- 投资人/长期决策者 → Munger 主导
- **平台/服务/生态创业者 → Bezos 主导**

**对用户**(手机 AI 营销 / 露营变现):**Bezos 方法最匹配** — 因为都是"客户长期价值 + 慢慢积累的资产"型生意。

## 七、给普通人的 8 条 Lessons

1. **每决策先问 Type 1/2** — 80% Type 2,立刻做
2. **Working Backwards** — 做新产品前先写发布新闻稿
3. **Regret Minimization** — 大决策问 80 岁
4. **Day 1 Mindset** — 每天问"如果今天是第一天"
5. **押不变** — 10 年后什么不变?押那些
6. **6-Page Memo** — 重要沟通写 1-2 页,不用 PPT
7. **Two-Pizza Team** — 6-10 人
8. **大失败但 Type 2** — 大胆失败,确保可回收

## 八、结合用户路径的应用

### 1. Working Backwards 写 press release
手机 AI 内容工厂发布新闻稿 → 写不出来别做

### 2. Type 1/2 分类现有纠结
- 手机 vs 露营先做 = Type 2 → 立刻试
- 用真名 vs 品牌名 = Type 1 → 慢想
- 中英文优先 = Type 2 → 试 30 天
- 辞主业 = Type 1 → 慢决
- 用 Claude 还是 OpenAI = Type 2 → 别研究一周

### 3. Regret Minimization for Type 1
辞主业问 80 岁的你:
- 试了失败 vs 从没试
- 答案永远是"从没试更后悔"

### 4. 押 10 年不变的东西
NZ 露营 10 年后不变:
- 中国游客想来 NZ
- 中英信息差
- 客户想省时间 + 有把握
**押不变,不押平台**。

### 5. Day 1 审视 vault
每季度问:"如果今天是我 vault 的第一天,我会怎么建?"防陷 Day 2 惯性。

## 九、一句话总结

**Bezos 最独特的不是"客户偏执"或"长期主义",是"把决策系统化,把组织长寿化"。**

- Musk 用天赋赢
- Jobs 用品味赢
- Munger 用谦逊赢
- **Bezos 用系统赢**

**四人中,Bezos + Munger 是"最可教"的一对**——都靠可复制的系统,不靠不可复制的天赋。**给普通人**,这两位比 Musk/Jobs 更该学。
