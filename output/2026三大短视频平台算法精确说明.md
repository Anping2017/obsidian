# 三大短视频平台算法精确说明(2026 版)

> 基于 2026 公开信息 + 官方文档 + 第三方研究综合。各平台算法不完全公开,以下为主流估算与实证观察。

## 一、通用底层原理

所有短视频推荐算法核心目标:**最大化用户停留时长 + 长期留存**。

**3 层管道**:
- **召回**(Recall):千万→万级候选,协同过滤+内容标签+关注+地理
- **粗排**(Coarse):万→百级,简单模型
- **精排**(Fine):百→10 级,深度模型 + 实时行为 + 多模态特征

## 二、TikTok / 抖音算法

### 2.1 核心
FYP 主导,推荐 vs 关注权重约 **8:2**(全平台最激进)。

### 2.2 排名信号(相对权重,2026)

| 信号 | 权重 | 说明 |
|---|---|---|
| 完播率 | ⭐⭐⭐⭐⭐ | 2026 最重要 |
| 重播率(2 次+) | ⭐⭐⭐⭐⭐ | "好内容"最强指示 |
| 观看时长 | ⭐⭐⭐⭐⭐ | 总时长 + 平均时长 |
| 完播 → 主页访问 | ⭐⭐⭐⭐ | 强兴趣信号 |
| 分享(私信+公开) | ⭐⭐⭐⭐ | 私信 > 公开 |
| 评论(质量>数量) | ⭐⭐⭐⭐ | 回复链条加权 |
| 收藏 | ⭐⭐⭐⭐ | 强意图 |
| 点赞 | ⭐⭐⭐ | 已贬值 |
| 关注(看完后) | ⭐⭐⭐⭐⭐ | 稀缺,权重最高 |
| 视频信息(OCR/CV/音频/hashtag) | ⭐⭐⭐ | 分类召回 |
| 设备/账号信息 | ⭐⭐ | |

### 2.3 流量池阶梯

```
初始池   200-500 曝光    (前 1-3h)
  ↓ 完播 > 30%
小池     1K-5K
  ↓ 完播 > 45% + 互动 > 5%
中池     10K-100K
  ↓ 完播 > 55% + 分享 > 1%
大池     100K-1M
  ↓ 完播 > 60% + 关注 > 0.5%
FYP 爆款  1M+
```

**长尾机制**:好内容可在数周/数月后被重新推爆。

### 2.4 2026 关键变化

- STEM/兴趣子 Feed 分化
- 搜索权重上升(TikTok Search 成第二流量入口)
- TikTok Shop 挂车信号并入
- 较长视频(1-10 分钟)加权
- Creativity Program(> 1min 才有分账)
- AI 内容识别与降权(未披露)
- Originality Score(搬运/水印严打)

## 三、Instagram Reels 算法

### 3.1 核心
分发在 Reels Tab / Feed / Explore 三处,共用信号。关注权重 **约 5:5**。

### 3.2 排名信号(相对权重,2026)

| 信号 | 权重 | 备注 |
|---|---|---|
| **DM 分享** | ⭐⭐⭐⭐⭐ | Meta 2024 官方第一信号 |
| 观看时长 / 完播 | ⭐⭐⭐⭐⭐ | |
| 保存(Save) | ⭐⭐⭐⭐ | 强意图 |
| 评论 | ⭐⭐⭐⭐ | |
| 点赞 | ⭐⭐ | 大幅贬值 |
| 主页访问 + 关注 | ⭐⭐⭐⭐ | |
| 音频使用(热门音频加权) | ⭐⭐⭐ | |
| 原创性分数 | ⭐⭐⭐⭐ | TikTok 水印严重降权 |
| Original Reel 标签 | ⭐⭐⭐ | Meta 加权 |
| 发送到 Story / Broadcast | ⭐⭐⭐ | |

### 3.3 特殊机制
- Meta AI 统一驱动 Reels + Feed + Explore
- 关注权重比 TikTok 大
- 前 24h 最重要(比 TikTok 长尾弱)
- "Not interested" 影响强

### 3.4 2026 关键变化
- Threads / Broadcast Channel 跨产品信号
- AI 内容标签(未披露账号限流)
- **"Sends per Reach" 成核心 KPI**
- 原创性 boost 加大
- Reels 长度 up to 3 分钟

## 四、YouTube Shorts 算法

### 4.1 核心
Shorts 独立算法,**但与长视频跨格式互通**(YouTube 独有)。关注/订阅权重 **约 4:6**。

### 4.2 排名信号(相对权重,2026)

| 信号 | 权重 | 备注 |
|---|---|---|
| 观看 vs 跳过(3 秒) | ⭐⭐⭐⭐⭐ | Shorts 核心信号 |
| 完播率 | ⭐⭐⭐⭐⭐ | |
| 重播 | ⭐⭐⭐⭐ | |
| 点赞 / 讨厌 | ⭐⭐⭐ | Dislike 隐藏但仍算 |
| 评论 | ⭐⭐⭐ | |
| 分享 | ⭐⭐⭐⭐ | |
| 订阅(看完后) | ⭐⭐⭐⭐⭐ | 长期关系 |
| **看完 → 观看长视频** | ⭐⭐⭐⭐⭐ | 跨格式独有,加权极高 |
| 返回观众(Return Viewers) | ⭐⭐⭐⭐ | |
| 频道整体健康度 | ⭐⭐⭐⭐ | 与 TikTok 差异最大 |

### 4.3 特殊机制
- **频道健康度权重最高**:老账号 / 长期活跃 起步更快
- 跨格式漏斗:Shorts 引流 → 长视频建立信任
- 搜索权重高
- AI Overview 引用(GEO 效应)

### 4.4 2026 关键变化
- Shorts 长度扩至 3 分钟
- 跨格式 signals 权重加大
- Community Tab 整合
- YouTube Shopping affiliate
- AI 内容披露要求

## 五、三大平台差异对照

| 维度 | TikTok/抖音 | Instagram Reels | YouTube Shorts |
|---|---|---|---|
| 推荐 vs 关注 | 8:2 | 5:5 | 4:6 |
| 第一信号 | 完播 + 重播 | DM 分享 | 3 秒不滑走 + 完播 |
| 发布时机 | 长尾强 | 前 24h 最重要 | 长尾中 |
| 原创性 | 严打搬运 | 极严打 TikTok 水印 | 中等严 |
| 跨格式 | Live / Shop | Story / Feed / DM | 长视频(独有) |
| 变现门槛 | Creativity Program | Reels Play Bonus | YPP + Shorts Fund |
| 搜索权重 | 上升 | 中 | 高 |
| AI 内容 | 需披露 | 需披露 | 需披露 |
| 地域 | TikTok vs 抖音有差 | 全球统一 | 全球统一 |

## 六、通用 anti-signals

1. 前 3 秒被滑走
2. "Not Interested" / "Less Like This"
3. 举报 / 屏蔽
4. 看到一半退出 + 不关注
5. 发布 → 无人观看 24h
6. 搬运 / TikTok 水印
7. 重复度高(疲劳)
8. 未披露 AI 生成
9. 诱导互动但无真诚回应
10. 疑似刷量

## 七、实操建议

### 7.1 通用
- 第 1-3 秒钩子必强
- 完播率 > 点赞
- **鼓励私信分享 > 公开点赞**
- 多模态一致(视觉/OCR/音频/hashtag 同主题)
- 发布节奏稳定
- AI 内容主动披露

### 7.2 TikTok 特有
- 关键词密度(标题 + on-screen + 首评)
- 21-34 秒是完播甜蜜点
- 长视频(1-3 分钟)Creativity Program 分账
- 追热门音频/挑战早期

### 7.3 Reels 特有
- "值得分享给一个朋友"是核心自问
- 避免 TikTok 水印
- Original Reel 标签有 boost
- Story 交叉分发加权

### 7.4 Shorts 特有
- 频道健康度是底层
- 结尾引导"看完整版"
- Shorts 是预告片,不是终点
- 老账号做 Shorts 更轻

## 八、2026 十大共同趋势

1. 完播率的绝对主导
2. 私域分享 >> 公开互动
3. AI 内容检测(未披露=降权,人+AI 混合=加权)
4. 原创性分数化
5. Fatigue 检测(相似内容降权)
6. 跨模态搜索(视觉/音频/OCR 组合)
7. 搜索 SEO 化
8. 短视频 → 商业闭环
9. 多语言原生优待
10. 多账号协作信号

## 九、一句话总结

**2026 短视频算法的共同真理**:

- 不是"讨好点赞",是"讨好完播"
- 不是"追求曝光",是"追求被分享给一个朋友"
- 不是"AI 量产",是"AI 加速的人味内容"
- 不是"单条爆款",是"账号复利"

**给创作者**:每一条内容 = 一次"能否让人看完 + 想告诉一个朋友"的测试。其他都是二阶效应。
