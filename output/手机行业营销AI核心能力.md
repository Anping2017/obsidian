# 手机行业营销 AI 核心能力(营销视角)

> 平行于 `output/手机行业垂直AI核心能力.md`(产品视角全流程)。本文聚焦"营销 customer journey"。

## 一、营销 customer journey

```
认知 → 考虑 → 转化 → 售后 → 倡导/复购
内容+广告/IP / 测评+咨询 / 报价+成交 / 售后+评价 / 口碑+推荐
```

## 三、5 项核心能力(MVP 必须有)

1. **手机行业 AIGC 内容工厂**(店主不会做内容,垂直模板壁垒最厚)
2. **AI 销售客服 + 产品比对**(多语言+行业话术,通用客服替代不了)
3. **多平台 AI 投放调度**(Google/Meta/TikTok/Trade Me 统一,平台割裂痛点)
4. **AI 售后跟进+复购自动化**(私域 bot+换机周期预测,数据资产驱动)
5. **AI 多平台数据整合+归因**(跨平台 ROI 一站看)

## 四、3 项差异化护城河

| # | 护城河 | 描述 |
|---|---|---|
| 1 | 手机行业垂直内容语料 | 2,000+ 机型 × 配件 × 维修话术 × 营销话术 |
| 2 | NZ 本地化营销栈 | Trade Me + 多元文化(英中印韩越)+ NZ Privacy Act |
| 3 | 销售-售后-复购全链路 | 通用工具是单点,垂直 AI 是闭环 |

## 五、3 项长期能力

| # | 能力 | 何时引入 |
|---|---|---|
| 1 | 跨店营销数据网络 | 50+ 店之后 |
| 2 | 创始人/店主 IP 矩阵 | 18-24 月 |
| 3 | 2C 信任品牌(消费者找你) | 24+ 月 |

## 六、设计原则 7 条(营销专属)

1. 垂直话术 > 通用文案
2. 全漏斗闭环 > 单点工具
3. 多平台原生 > 套用模板
4. 多语言原生 > 翻译
5. 店主在前 > AI 在后(让店主"看起来在亲自做")
6. 数据透明 > 黑盒效果(给可解释的归因)
7. 私域 > 公域(NZ 客户重信任)

## 七、与现有营销工具对比

| 类型      | 代表                         | 缺什么                  |
| ------- | -------------------------- | -------------------- |
| 通用 AIGC | Jasper / Copy.ai / 创可贴     | 无手机话术语料              |
| 多平台调度   | Hootsuite / Buffer / Later | 无 AI 优化 + 无 Trade Me |
| 通用 CRM  | HubSpot / Mailchimp        | 无手机行业工作流             |
| 通用客服    | Intercom / Drift           | 无产品知识库               |
| 营销分析    | GA / Triple Whale          | 无 Trade Me 数据源       |
| 短视频剪辑   | 剪映 / CapCut AI             | 无垂直模板库               |

**缝隙**:手机行业 + 全漏斗 + NZ 平台栈 + 多语言整合营销 AI——市场无。

## 八、1 人 MVP wedge(营销版)

**推荐起点:手机行业 AIGC 内容工厂(店主 IP 版)**

### 候选对比

| 候选 | 启动门槛 | 1 人可行 | 粘性 | 垂直壁垒 |
|---|---|---|---|---|
| ⭐ AIGC 内容工厂 | 低 | ✅ | 高 | 高 |
| AI 销售客服 | 低 | ✅ | 中 | 中 |
| 多平台投放调度 | 高 | ❌ | 高 | 中 |
| 售后复购自动化 | 中 | △ | 极高 | 中 |
| 数据整合归因 | 高 | ❌ | 极高 | 高 |

### MVP 形态

- **输入**:手机型号 / 维修类型 / 配件类型 / 店主人设照片
- **输出**:
  - 抖音/TikTok 短视频脚本(中英双语)
  - 测评长文(小红书/微信公众号)
  - Trade Me/Facebook Marketplace 商品描述
  - 维修教学视频脚本+分镜
  - 店主 IP 短视频(以"AI 营销手机人"人设)

### 为什么是好 wedge

- 1 人可做(Claude/GPT API + 模板库 + 简单 UI)
- 店主天天用(高频)
- 替代"不会做内容"最大痛点
- 垂直壁垒明显
- 自然延展到其他 4 项核心(客服/投放/复购/归因)

## 九、一句话

**手机行业营销 AI 的核心,是把"店主不会做的营销动作"做成"3 分钟产出"的工具。**

通用 AI 营销卖的是"我帮你写文案",
垂直 AI 营销卖的是"我替你做手机生意的营销"——
**主语不同,价值不同。**

## 十、与产品版的分工

| 维度        | 产品版(`手机行业垂直AI核心能力.md`)        | 营销版(本文)                            |
| --------- | ----------------------------- | ---------------------------------- |
| 视角        | 全流程(进货-销售-维修-二手)              | 营销漏斗(认知-考虑-转化-售后-倡导)               |
| 核心 5 项    | 故障诊断 / 估价 / AIGC 工厂 / 客服 / 投放 | AIGC 工厂 / 客服+比对 / 投放 / 售后复购 / 数据归因 |
| MVP wedge | AI 故障诊断+报价                    | AIGC 内容工厂(店主 IP 版)                 |
| 适合场景      | 想做"店主全闭环工具"                   | 想做"店主营销外包/服务公司"                    |

→ **两个 wedge 不冲突,可以并行**:
- 如果走"工具产品"路线 → 先做故障诊断
- 如果走"服务公司+工具"路线 → 先做内容工厂
