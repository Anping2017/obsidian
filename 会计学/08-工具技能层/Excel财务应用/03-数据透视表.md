# 数据透视表

## 数据透视表概述

### 📖 基本定义
**数据透视表**是Excel中一种强大的数据分析工具，能够快速汇总、分析和展示大量数据。

### 🔍 功能特点
- **汇总功能**：快速汇总数据
- **分析功能**：多维度分析数据
- **展示功能**：直观展示数据
- **交互功能**：交互式数据操作

### 🎯 应用作用
1. **数据分析**：分析财务数据
2. **报表制作**：制作财务报表
3. **趋势分析**：分析数据趋势
4. **决策支持**：支持管理决策

## 数据透视表创建

### 📊 创建步骤

#### 准备数据
- **要求**：准备源数据
- **内容**：
  - 数据完整
  - 格式统一
  - 标题清晰
  - 无空行空列
- **技巧**：
  - 使用表格格式
  - 避免合并单元格
  - 确保数据连续性
  - 检查数据质量

#### 创建透视表
- **步骤**：创建数据透视表
- **方法**：
  1. 选择数据区域
  2. 插入数据透视表
  3. 选择放置位置
  4. 点击确定
- **技巧**：
  - 使用Ctrl+A全选
  - 选择新工作表
  - 使用现有位置
  - 设置数据源

#### 设计布局
- **步骤**：设计透视表布局
- **方法**：
  1. 拖拽字段到行区域
  2. 拖拽字段到列区域
  3. 拖拽字段到值区域
  4. 拖拽字段到筛选区域
- **技巧**：
  - 合理布局字段
  - 调整字段顺序
  - 设置字段属性
  - 优化显示效果

### 📈 高级操作

#### 计算字段
- **功能**：创建计算字段
- **步骤**：
  1. 选择字段
  2. 右键计算字段
  3. 输入公式
  4. 点击确定
- **示例**：
  ```
  利润率 = 利润/收入
  增长率 = (本期-上期)/上期
  ```

#### 计算项
- **功能**：创建计算项
- **步骤**：
  1. 选择项
  2. 右键计算项
  3. 输入公式
  4. 点击确定
- **示例**：
  ```
  总计 = 项目A + 项目B
  差额 = 实际 - 预算
  ```
