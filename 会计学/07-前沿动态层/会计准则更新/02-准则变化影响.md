# 准则变化影响

## 准则变化影响概述

### 📖 基本定义
**准则变化影响**是指会计准则的修订或更新对企业财务状况、经营成果和现金流量等方面产生的影响。

### 🔍 影响特点
- **全面性**：影响企业各个方面
- **持续性**：影响具有持续性
- **复杂性**：影响具有复杂性
- **差异性**：不同企业影响不同

### 🎯 影响作用
1. **财务影响**：影响企业财务状况
2. **经营影响**：影响企业经营决策
3. **管理影响**：影响企业管理方式
4. **合规影响**：影响企业合规要求
