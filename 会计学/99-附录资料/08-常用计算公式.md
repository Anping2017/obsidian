## 财务比率计算公式

### 💰 偿债能力比率

#### 流动比率
- **公式**：流动比率 = 流动资产 ÷ 流动负债
- **说明**：反映企业短期偿债能力
- **标准**：一般认为2:1较为合适
- **计算示例**：
  ```
  流动资产 = 1,000,000元
  流动负债 = 500,000元
  流动比率 = 1,000,000 ÷ 500,000 = 2.0
  ```

#### 速动比率
- **公式**：速动比率 = (流动资产 - 存货) ÷ 流动负债
- **说明**：反映企业立即偿债能力
- **标准**：一般认为1:1较为合适
- **计算示例**：
  ```
  流动资产 = 1,000,000元
  存货 = 300,000元
  流动负债 = 500,000元
  速动比率 = (1,000,000 - 300,000) ÷ 500,000 = 1.4
  ```

#### 现金比率
- **公式**：现金比率 = (货币资金 + 交易性金融资产) ÷ 流动负债
- **说明**：反映企业最直接的偿债能力
- **标准**：一般认为0.2-0.3较为合适
- **计算示例**：
  ```
  货币资金 = 100,000元
  交易性金融资产 = 50,000元
  流动负债 = 500,000元
  现金比率 = (100,000 + 50,000) ÷ 500,000 = 0.3
  ```

#### 资产负债率
- **公式**：资产负债率 = 负债总额 ÷ 资产总额 × 100%
- **说明**：反映企业长期偿债能力
- **标准**：一般认为50%以下较为合适
- **计算示例**：
  ```
  负债总额 = 2,000,000元
  资产总额 = 5,000,000元
  资产负债率 = 2,000,000 ÷ 5,000,000 × 100% = 40%
  ```

#### 产权比率
- **公式**：产权比率 = 负债总额 ÷ 所有者权益总额
- **说明**：反映企业财务结构
- **标准**：一般认为1:1较为合适
- **计算示例**：
  ```
  负债总额 = 2,000,000元
  所有者权益总额 = 3,000,000元
  产权比率 = 2,000,000 ÷ 3,000,000 = 0.67
  ```

#### 利息保障倍数
- **公式**：利息保障倍数 = (利润总额 + 利息费用) ÷ 利息费用
- **说明**：反映企业支付利息能力
- **标准**：一般认为3倍以上较为合适
- **计算示例**：
  ```
  利润总额 = 500,000元
  利息费用 = 100,000元
  利息保障倍数 = (500,000 + 100,000) ÷ 100,000 = 6.0
  ```

### 🔄 营运能力比率

#### 应收账款周转率
- **公式**：应收账款周转率 = 营业收入 ÷ 平均应收账款余额
- **说明**：反映应收账款周转速度
- **计算示例**：
  ```
  营业收入 = 10,000,000元
  期初应收账款 = 800,000元
  期末应收账款 = 1,200,000元
  平均应收账款 = (800,000 + 1,200,000) ÷ 2 = 1,000,000元
  应收账款周转率 = 10,000,000 ÷ 1,000,000 = 10次
  ```

#### 存货周转率
- **公式**：存货周转率 = 营业成本 ÷ 平均存货余额
- **说明**：反映存货周转速度
- **计算示例**：
  ```
  营业成本 = 6,000,000元
  期初存货 = 1,000,000元
  期末存货 = 1,500,000元
  平均存货 = (1,000,000 + 1,500,000) ÷ 2 = 1,250,000元
  存货周转率 = 6,000,000 ÷ 1,250,000 = 4.8次
  ```

#### 流动资产周转率
- **公式**：流动资产周转率 = 营业收入 ÷ 平均流动资产余额
- **说明**：反映流动资产周转速度
- **计算示例**：
  ```
  营业收入 = 10,000,000元
  期初流动资产 = 2,000,000元
  期末流动资产 = 2,500,000元
  平均流动资产 = (2,000,000 + 2,500,000) ÷ 2 = 2,250,000元
  流动资产周转率 = 10,000,000 ÷ 2,250,000 = 4.44次
  ```

#### 总资产周转率
- **公式**：总资产周转率 = 营业收入 ÷ 平均总资产余额
- **说明**：反映总资产周转速度
- **计算示例**：
  ```
  营业收入 = 10,000,000元
  期初总资产 = 5,000,000元
  期末总资产 = 6,000,000元
  平均总资产 = (5,000,000 + 6,000,000) ÷ 2 = 5,500,000元
  总资产周转率 = 10,000,000 ÷ 5,500,000 = 1.82次
  ```

#### 固定资产周转率
- **公式**：固定资产周转率 = 营业收入 ÷ 平均固定资产余额
- **说明**：反映固定资产周转速度
- **计算示例**：
  ```
  营业收入 = 10,000,000元
  期初固定资产 = 3,000,000元
  期末固定资产 = 3,500,000元
  平均固定资产 = (3,000,000 + 3,500,000) ÷ 2 = 3,250,000元
  固定资产周转率 = 10,000,000 ÷ 3,250,000 = 3.08次
  ```

### 💰 盈利能力比率

#### 营业利润率
- **公式**：营业利润率 = 营业利润 ÷ 营业收入 × 100%
- **说明**：反映企业营业盈利能力
- **计算示例**：
  ```
  营业利润 = 1,500,000元
  营业收入 = 10,000,000元
  营业利润率 = 1,500,000 ÷ 10,000,000 × 100% = 15%
  ```

#### 销售净利率
- **公式**：销售净利率 = 净利润 ÷ 营业收入 × 100%
- **说明**：反映企业销售盈利能力
- **计算示例**：
  ```
  净利润 = 1,200,000元
  营业收入 = 10,000,000元
  销售净利率 = 1,200,000 ÷ 10,000,000 × 100% = 12%
  ```

#### 毛利率
- **公式**：毛利率 = (营业收入 - 营业成本) ÷ 营业收入 × 100%
- **说明**：反映企业产品盈利能力
- **计算示例**：
  ```
  营业收入 = 10,000,000元
  营业成本 = 6,000,000元
  毛利率 = (10,000,000 - 6,000,000) ÷ 10,000,000 × 100% = 40%
  ```

#### 总资产收益率
- **公式**：总资产收益率 = 净利润 ÷ 平均总资产 × 100%
- **说明**：反映企业资产盈利能力
- **计算示例**：
  ```
  净利润 = 1,200,000元
  平均总资产 = 5,500,000元
  总资产收益率 = 1,200,000 ÷ 5,500,000 × 100% = 21.82%
  ```

#### 净资产收益率
- **公式**：净资产收益率 = 净利润 ÷ 平均净资产 × 100%
- **说明**：反映企业净资产盈利能力

  ```
  净利润 = 1,200,000元
  ```

## 成本计算公式

### 🏭 产品成本计算

#### 单位产品成本
- **公式**：单位产品成本 = 总成本 ÷ 产品数量
- **说明**：计算单个产品的成本
- **计算示例**：
  ```
  总成本 = 500,000元
  产品数量 = 1,000件
  单位产品成本 = 500,000 ÷ 1,000 = 500元/件
  ```

#### 直接材料成本
- **公式**：直接材料成本 = 材料消耗量 × 材料单价
- **说明**：计算直接材料成本
- **计算示例**：
  ```
  材料消耗量 = 100公斤
  材料单价 = 50元/公斤
  直接材料成本 = 100 × 50 = 5,000元
  ```

#### 直接人工成本
- **公式**：直接人工成本 = 工时 × 小时工资率
- **说明**：计算直接人工成本
- **计算示例**：
  ```
  工时 = 200小时
  小时工资率 = 30元/小时
  直接人工成本 = 200 × 30 = 6,000元
  ```

#### 制造费用分配率
- **公式**：制造费用分配率 = 制造费用总额 ÷ 分配标准总额
- **说明**：计算制造费用分配率
- **计算示例**：
  ```
  制造费用总额 = 100,000元
  分配标准总额 = 10,000小时
  制造费用分配率 = 100,000 ÷ 10,000 = 10元/小时
  ```

### 📊 成本分析方法

#### 成本降低率
- **公式**：成本降低率 = (基期成本 - 报告期成本) ÷ 基期成本 × 100%
- **说明**：计算成本降低幅度
- **计算示例**：
  ```
  基期成本 = 1,000,000元
  报告期成本 = 900,000元
  成本降低率 = (1,000,000 - 900,000) ÷ 1,000,000 × 100% = 10%
  ```

#### 成本利润率
- **公式**：成本利润率 = 利润 ÷ 成本 × 100%
- **说明**：计算成本利润率
- **计算示例**：
  ```
  利润 = 200,000元
  成本 = 800,000元
  成本利润率 = 200,000 ÷ 800,000 × 100% = 25%
  ```

## 预算计算公式

### 📈 预算编制

#### 销售预算
- **公式**：销售预算 = 预计销售量 × 预计销售单价
- **说明**：计算销售预算
- **计算示例**：
  ```
  预计销售量 = 10,000件
  预计销售单价 = 100元/件
  销售预算 = 10,000 × 100 = 1,000,000元
  ```

#### 生产预算
- **公式**：生产预算 = 预计销售量 + 预计期末存货 - 预计期初存货
- **说明**：计算生产预算
- **计算示例**：
  ```
  预计销售量 = 10,000件
  预计期末存货 = 1,000件
  预计期初存货 = 500件
  生产预算 = 10,000 + 1,000 - 500 = 10,500件
  ```

#### 材料采购预算
- **公式**：材料采购预算 = 预计生产量 × 单位产品材料消耗量 × 材料单价
- **说明**：计算材料采购预算
- **计算示例**：
  ```
  预计生产量 = 10,500件
  单位产品材料消耗量 = 2公斤/件
  材料单价 = 50元/公斤
  材料采购预算 = 10,500 × 2 × 50 = 1,050,000元
  ```

### 📊 预算分析

#### 预算完成率
- **公式**：预算完成率 = 实际完成数 ÷ 预算数 × 100%
- **说明**：计算预算完成情况
- **计算示例**：
  ```
  实际完成数 = 1,100,000元
  预算数 = 1,000,000元
  预算完成率 = 1,100,000 ÷ 1,000,000 × 100% = 110%
  ```

#### 预算差异率
- **公式**：预算差异率 = (实际数 - 预算数) ÷ 预算数 × 100%
- **说明**：计算预算差异
- **计算示例**：
  ```
  实际数 = 1,100,000元
  预算数 = 1,000,000元
  预算差异率 = (1,100,000 - 1,000,000) ÷ 1,000,000 × 100% = 10%
  ```

## 投资决策计算公式

### 💰 投资回收期

#### 静态投资回收期
- **公式**：静态投资回收期 = 原始投资额 ÷ 年现金净流量
- **说明**：计算静态投资回收期
- **计算示例**：
  ```
  原始投资额 = 1,000,000元
  年现金净流量 = 200,000元
  静态投资回收期 = 1,000,000 ÷ 200,000 = 5年
  ```

#### 动态投资回收期
- **公式**：动态投资回收期 = 累计净现金流量现值出现正值的年数 - 1 + 上年累计净现金流量现值的绝对值 ÷ 当年净现金流量现值
- **说明**：计算动态投资回收期
- **计算示例**：
  ```
  累计净现金流量现值出现正值的年数 = 6年
  上年累计净现金流量现值 = -50,000元
  当年净现金流量现值 = 100,000元
  动态投资回收期 = 6 - 1 + 50,000 ÷ 100,000 = 5.5年
  ```

### 📊 净现值

#### 净现值
- **公式**：NPV = Σ(CFt ÷ (1 + r)^t) - I0
- **说明**：计算净现值
- **其中**：
  - CFt：第t年的现金净流量
  - r：折现率
  - t：年份
  - I0：初始投资额
- **计算示例**：
  ```
  初始投资额 = 1,000,000元
  第1年现金净流量 = 300,000元
  第2年现金净流量 = 400,000元
  第3年现金净流量 = 500,000元
  折现率 = 10%
  NPV = 300,000÷(1+0.1)^1 + 400,000÷(1+0.1)^2 + 500,000÷(1+0.1)^3 - 1,000,000
  NPV = 272,727 + 330,579 + 375,657 - 1,000,000 = -21,037元
  ```

### 📈 内部收益率

#### 内部收益率
- **公式**：IRR = r1 + (NPV1 × (r2 - r1)) ÷ (NPV1 - NPV2)
- **说明**：计算内部收益率
- **其中**：
  - r1：较低的折现率
  - r2：较高的折现率
  - NPV1：r1对应的净现值
  - NPV2：r2对应的净现值
- **计算示例**：
  ```
  r1 = 8%, NPV1 = 50,000元
  r2 = 12%, NPV2 = -30,000元
  IRR = 8% + (50,000 × (12% - 8%)) ÷ (50,000 - (-30,000))
  IRR = 8% + (50,000 × 4%) ÷ 80,000 = 8% + 2.5% = 10.5%
  ```

## 税务计算公式

### 🏛️ 增值税计算

#### 销项税额
- **公式**：销项税额 = 销售额 × 适用税率
- **说明**：计算销项税额
- **计算示例**：
  ```
  销售额 = 1,000,000元
  适用税率 = 13%
  销项税额 = 1,000,000 × 13% = 130,000元
  ```

#### 进项税额
- **公式**：进项税额 = 购进货物金额 × 适用税率
- **说明**：计算进项税额
- **计算示例**：
  ```
  购进货物金额 = 500,000元
  适用税率 = 13%
  进项税额 = 500,000 × 13% = 65,000元
  ```

#### 应纳增值税
- **公式**：应纳增值税 = 销项税额 - 进项税额
- **说明**：计算应纳增值税
- **计算示例**：
  ```
  销项税额 = 130,000元
  进项税额 = 65,000元
  应纳增值税 = 130,000 - 65,000 = 65,000元
  ```

### 💼 企业所得税计算

#### 应纳税所得额
- **公式**：应纳税所得额 = 收入总额 - 不征税收入 - 免税收入 - 各项扣除 - 以前年度亏损
- **说明**：计算应纳税所得额
- **计算示例**：
  ```
  收入总额 = 10,000,000元
  不征税收入 = 0元
  免税收入 = 0元
  各项扣除 = 7,000,000元
  以前年度亏损 = 0元
  应纳税所得额 = 10,000,000 - 0 - 0 - 7,000,000 - 0 = 3,000,000元
  ```

#### 应纳企业所得税
- **公式**：应纳企业所得税 = 应纳税所得额 × 适用税率
- **说明**：计算应纳企业所得税
- **计算示例**：
  ```
  应纳税所得额 = 3,000,000元
  适用税率 = 25%
  应纳企业所得税 = 3,000,000 × 25% = 750,000元
  ```

## 折旧计算公式

### 🏢 直线法折旧

#### 年折旧额
- **公式**：年折旧额 = (固定资产原值 - 预计净残值) ÷ 预计使用年限
- **说明**：计算年折旧额
- **计算示例**：
  ```
  固定资产原值 = 1,000,000元
  预计净残值 = 100,000元
  预计使用年限 = 10年
  年折旧额 = (1,000,000 - 100,000) ÷ 10 = 90,000元
  ```

#### 月折旧额
- **公式**：月折旧额 = 年折旧额 ÷ 12
- **说明**：计算月折旧额
- **计算示例**：
  ```
  年折旧额 = 90,000元
  月折旧额 = 90,000 ÷ 12 = 7,500元
  ```

### 📊 工作量法折旧

#### 单位工作量折旧额
- **公式**：单位工作量折旧额 = (固定资产原值 - 预计净残值) ÷ 预计总工作量
- **说明**：计算单位工作量折旧额
- **计算示例**：
  ```
  固定资产原值 = 1,000,000元
  预计净残值 = 100,000元
  预计总工作量 = 100,000小时
  单位工作量折旧额 = (1,000,000 - 100,000) ÷ 100,000 = 9元/小时
  ```

#### 月折旧额
- **公式**：月折旧额 = 单位工作量折旧额 × 月实际工作量
- **说明**：计算月折旧额
- **计算示例**：
  ```
  单位工作量折旧额 = 9元/小时
  月实际工作量 = 800小时
  月折旧额 = 9 × 800 = 7,200元
  ```

### 📈 双倍余额递减法折旧

#### 年折旧率
- **公式**：年折旧率 = 2 ÷ 预计使用年限 × 100%
- **说明**：计算年折旧率
- **计算示例**：
  ```
  预计使用年限 = 10年
  年折旧率 = 2 ÷ 10 × 100% = 20%
  ```

#### 年折旧额
- **公式**：年折旧额 = 固定资产账面净值 × 年折旧率
- **说明**：计算年折旧额
- **计算示例**：
  ```
  固定资产账面净值 = 800,000元
  年折旧率 = 20%
  年折旧额 = 800,000 × 20% = 160,000元
  ```
