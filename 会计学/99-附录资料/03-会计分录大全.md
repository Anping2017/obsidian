# 会计分录大全

## 会计分录概述

### 📖 基本定义
**会计分录**是按照复式记账的要求，对每项经济业务标明其应借应贷账户及其金额的记录。

### 🔍 分录特点
- **复式记账**：有借必有贷，借贷必相等
- **账户对应**：账户之间相互对应
- **金额相等**：借方金额等于贷方金额
- **方向明确**：借贷方向明确

### 🎯 分录作用
1. **记录基础**：会计核算的记录基础
2. **分析工具**：经济业务分析工具
3. **控制手段**：内部控制的重要手段
4. **信息载体**：会计信息的载体

## 资金筹集业务分录

### 💰 接受投资

#### 接受货币资金投资
```
借：银行存款
    贷：实收资本
```

#### 接受实物投资
```
借：固定资产（或原材料）
    贷：实收资本
```

#### 接受无形资产投资
```
借：无形资产
    贷：实收资本
```

### 🏦 借入资金

#### 借入短期借款
```
借：银行存款
    贷：短期借款
```

#### 借入长期借款
```
借：银行存款
    贷：长期借款
```

#### 计提借款利息
```
借：财务费用
    贷：应付利息
```

#### 支付借款利息
```
借：应付利息
    贷：银行存款
```

#### 偿还借款本金
```
借：短期借款（或长期借款）
    贷：银行存款
```

## 供应过程业务分录

### 🛒 材料采购

#### 购入材料，货款已付
```
借：材料采购
    应交税费——应交增值税（进项税额）
    贷：银行存款
```

#### 购入材料，货款未付
```
借：材料采购
    应交税费——应交增值税（进项税额）
    贷：应付账款
```

#### 购入材料，开出商业汇票
```
借：材料采购
    应交税费——应交增值税（进项税额）
    贷：应付票据
```

#### 预付材料款
```
借：预付账款
    贷：银行存款
```

#### 材料验收入库
```
借：原材料
    贷：材料采购
```

#### 支付材料采购费用
```
借：材料采购
    贷：银行存款
```

### 🚚 固定资产购置

#### 购入不需要安装的固定资产
```
借：固定资产
    应交税费——应交增值税（进项税额）
    贷：银行存款
```

#### 购入需要安装的固定资产
```
借：在建工程
    应交税费——应交增值税（进项税额）
    贷：银行存款
```

#### 支付安装费用
```
借：在建工程
    贷：银行存款
```

#### 安装完毕，交付使用
```
借：固定资产
    贷：在建工程
```

## 销售过程业务分录

### 💰 销售商品

#### 销售商品，货款已收
```
借：银行存款
    贷：主营业务收入
        应交税费——应交增值税（销项税额）
```

#### 销售商品，货款未收
```
借：应收账款
    贷：主营业务收入
        应交税费——应交增值税（销项税额）
```

#### 销售商品，收到商业汇票
```
借：应收票据
    贷：主营业务收入
        应交税费——应交增值税（销项税额）
```

#### 预收货款
```
借：银行存款
    贷：预收账款
```

#### 发出商品，确认收入
```
借：预收账款
    贷：主营业务收入
        应交税费——应交增值税（销项税额）
```

### 📤 结转销售成本

#### 结转已销商品成本
```
借：主营业务成本
    贷：库存商品
```

### 🚚 销售费用

#### 支付销售费用
```
借：销售费用
    贷：银行存款
```

#### 计提销售费用
```
借：销售费用
    贷：应付职工薪酬
        累计折旧
```

## 利润形成与分配分录

### 💰 收入结转

#### 结转各项收入
```
借：主营业务收入
    其他业务收入
    投资收益
    营业外收入
    贷：本年利润
```

### 💸 费用结转

#### 结转各项费用
```
借：本年利润
    贷：主营业务成本
        其他业务成本
        税金及附加
        销售费用
        管理费用
        财务费用
        资产减值损失
        营业外支出
        所得税费用
```

### 📊 利润分配

#### 提取盈余公积
```
借：利润分配——提取法定盈余公积
    利润分配——提取任意盈余公积
    贷：盈余公积——法定盈余公积
        盈余公积——任意盈余公积
```

#### 向投资者分配利润
```
借：利润分配——应付现金股利
    贷：应付股利
```

#### 支付现金股利
```
借：应付股利
    贷：银行存款
```

#### 结转利润分配
```
借：利润分配——未分配利润
    贷：利润分配——提取法定盈余公积
        利润分配——提取任意盈余公积
        利润分配——应付现金股利
```

## 错账更正分录

### ✏️ 划线更正法
- 适用于记账凭证正确，账簿记录错误
- 在错误的文字或数字上划红线，在上方写正确内容

### 📝 红字更正法
- 适用于记账凭证错误导致账簿错误

#### 科目错误
```
借：管理费用（红字）
    贷：银行存款（红字）
借：销售费用
    贷：银行存款
```

#### 金额多记
```
借：管理费用（红字）
    贷：银行存款（红字）
```

### 🔄 补充登记法
- 适用于记账凭证金额少记

```
借：管理费用
    贷：银行存款
```

## 分录编制技巧

### 📋 编制步骤
1. **分析业务**：分析经济业务内容
2. **确定科目**：确定涉及的会计科目
3. **判断方向**：判断借贷方向
4. **计算金额**：计算借贷金额
5. **检查平衡**：检查借贷是否平衡

### 🎯 编制原则
1. **有借必有贷**：每笔分录必须有借有贷
2. **借贷必相等**：借方金额等于贷方金额
3. **科目正确**：使用正确的会计科目
4. **金额准确**：金额计算准确无误

### 💡 注意事项
1. **科目选择**：选择正确的会计科目
2. **方向判断**：正确判断借贷方向
3. **金额计算**：准确计算金额
4. **格式规范**：分录格式规范
