# 财务比率分析

## 财务比率分析概述

### 📖 基本定义
**财务比率分析**是通过计算和分析财务报表中相关项目之间的比率，来评价企业财务状况和经营成果的一种分析方法。

### 🔍 分析特点
- **相对分析**：通过比率进行相对分析
- **比较分析**：便于不同期间、不同企业比较
- **综合分析**：综合反映企业财务状况
- **决策支持**：为决策提供支持

### 🎯 分析作用
1. **财务状况**：评价企业财务状况
2. **经营成果**：评价企业经营成果
3. **发展趋势**：分析企业发展趋势
4. **决策支持**：为决策提供支持

## 财务比率的分类

### 📊 按分析目的分类

#### 1. 偿债能力比率
- **短期偿债能力**：流动比率、速动比率、现金比率
- **长期偿债能力**：资产负债率、权益比率、利息保障倍数

#### 2. 营运能力比率
- **资产周转率**：总资产周转率、流动资产周转率、固定资产周转率
- **存货周转率**：存货周转率、存货周转天数
- **应收账款周转率**：应收账款周转率、应收账款周转天数

#### 3. 盈利能力比率
- **销售利润率**：销售毛利率、销售净利率
- **资产收益率**：总资产收益率、净资产收益率
- **每股收益**：基本每股收益、稀释每股收益

#### 4. 发展能力比率
- **增长率**：营业收入增长率、净利润增长率
- **资本积累率**：资本积累率、总资产增长率
- **技术投入比率**：技术投入比率、研发投入比率

### 🔄 按计算方法分类

#### 1. 结构比率
- **资产结构比率**：各项资产占总资产的比例
- **负债结构比率**：各项负债占总负债的比例
- **收入结构比率**：各项收入占总收入的比例
- **费用结构比率**：各项费用占总费用的比例

#### 2. 效率比率
- **资产周转率**：资产使用效率
- **存货周转率**：存货管理效率
- **应收账款周转率**：应收账款管理效率
- **总资产周转率**：总资产使用效率

#### 3. 相关比率
- **流动比率**：流动资产与流动负债的比率
- **速动比率**：速动资产与流动负债的比率
- **资产负债率**：负债总额与资产总额的比率
- **权益比率**：所有者权益与资产总额的比率

## 偿债能力比率分析

### 💰 短期偿债能力比率

#### 1. 流动比率
- **计算公式**：流动比率 = 流动资产 / 流动负债
- **分析意义**：反映企业短期偿债能力
- **标准值**：一般认为2:1较为合适
- **影响因素**：流动资产结构、流动负债结构

#### 2. 速动比率
- **计算公式**：速动比率 = (流动资产 - 存货) / 流动负债
- **分析意义**：反映企业立即偿债能力
- **标准值**：一般认为1:1较为合适
- **影响因素**：速动资产结构、流动负债结构

#### 3. 现金比率
- **计算公式**：现金比率 = (货币资金 + 交易性金融资产) / 流动负债
- **分析意义**：反映企业现金偿债能力
- **标准值**：一般认为0.2:1较为合适
- **影响因素**：现金持有量、流动负债结构

### 🏦 长期偿债能力比率

#### 1. 资产负债率
- **计算公式**：资产负债率 = 负债总额 / 资产总额
- **分析意义**：反映企业长期偿债能力
- **标准值**：一般认为50%以下较为合适
- **影响因素**：资产结构、负债结构

#### 2. 权益比率
- **计算公式**：权益比率 = 所有者权益 / 资产总额
- **分析意义**：反映企业财务稳定性
- **标准值**：一般认为50%以上较为合适
- **影响因素**：所有者权益结构、资产结构

#### 3. 利息保障倍数
- **计算公式**：利息保障倍数 = (利润总额 + 利息费用) / 利息费用
- **分析意义**：反映企业支付利息能力
- **标准值**：一般认为3倍以上较为合适
- **影响因素**：利润水平、利息费用

## 营运能力比率分析

### 🔄 资产周转率

#### 1. 总资产周转率
- **计算公式**：总资产周转率 = 营业收入 / 总资产平均余额
- **分析意义**：反映企业总资产使用效率
- **标准值**：因行业而异，一般越高越好
- **影响因素**：资产结构、营业收入水平

#### 2. 流动资产周转率
- **计算公式**：流动资产周转率 = 营业收入 / 流动资产平均余额
- **分析意义**：反映企业流动资产使用效率
- **标准值**：因行业而异，一般越高越好
- **影响因素**：流动资产结构、营业收入水平

#### 3. 固定资产周转率
- **计算公式**：固定资产周转率 = 营业收入 / 固定资产平均余额
- **分析意义**：反映企业固定资产使用效率
- **标准值**：因行业而异，一般越高越好
- **影响因素**：固定资产结构、营业收入水平

### 📦 存货周转率

#### 1. 存货周转率
- **计算公式**：存货周转率 = 营业成本 / 存货平均余额
- **分析意义**：反映企业存货管理效率
- **标准值**：因行业而异，一般越高越好
- **影响因素**：存货结构、营业成本水平

#### 2. 存货周转天数
- **计算公式**：存货周转天数 = 365 / 存货周转率
- **分析意义**：反映企业存货周转速度
- **标准值**：因行业而异，一般越短越好
- **影响因素**：存货周转率、营业成本水平

### 💳 应收账款周转率

#### 1. 应收账款周转率
- **计算公式**：应收账款周转率 = 营业收入 / 应收账款平均余额
- **分析意义**：反映企业应收账款管理效率
- **标准值**：因行业而异，一般越高越好
- **影响因素**：应收账款结构、营业收入水平

#### 2. 应收账款周转天数
- **计算公式**：应收账款周转天数 = 365 / 应收账款周转率
- **分析意义**：反映企业应收账款回收速度
- **标准值**：因行业而异，一般越短越好
- **影响因素**：应收账款周转率、营业收入水平

## 盈利能力比率分析

### 💵 销售利润率

#### 1. 销售毛利率
- **计算公式**：销售毛利率 = (营业收入 - 营业成本) / 营业收入
- **分析意义**：反映企业销售毛利率水平
- **标准值**：因行业而异，一般越高越好
- **影响因素**：销售价格、成本水平

#### 2. 销售净利率
- **计算公式**：销售净利率 = 净利润 / 营业收入
- **分析意义**：反映企业销售净利率水平
- **标准值**：因行业而异，一般越高越好
- **影响因素**：销售价格、成本水平、费用水平

### 🏢 资产收益率

#### 1. 总资产收益率
- **计算公式**：总资产收益率 = 净利润 / 总资产平均余额
- **分析意义**：反映企业总资产盈利能力
- **标准值**：因行业而异，一般越高越好
- **影响因素**：资产结构、利润水平

#### 2. 净资产收益率
- **计算公式**：净资产收益率 = 净利润 / 所有者权益平均余额
- **分析意义**：反映企业净资产盈利能力
- **标准值**：因行业而异，一般越高越好
- **影响因素**：所有者权益结构、利润水平

### 📈 每股收益

#### 1. 基本每股收益
- **计算公式**：基本每股收益 = 净利润 / 发行在外普通股加权平均数
- **分析意义**：反映企业每股盈利能力
- **标准值**：因行业而异，一般越高越好
- **影响因素**：净利润水平、股本结构

#### 2. 稀释每股收益
- **计算公式**：稀释每股收益 = 调整后净利润 / 调整后发行在外普通股加权平均数
- **分析意义**：反映企业稀释后每股盈利能力
- **标准值**：因行业而异，一般越高越好
- **影响因素**：净利润水平、股本结构、潜在稀释因素

## 发展能力比率分析

### 📊 增长率

#### 1. 营业收入增长率
- **计算公式**：营业收入增长率 = (本期营业收入 - 上期营业收入) / 上期营业收入
- **分析意义**：反映企业营业收入增长能力
- **标准值**：因行业而异，一般越高越好
- **影响因素**：市场环境、竞争能力、产品结构

#### 2. 净利润增长率
- **计算公式**：净利润增长率 = (本期净利润 - 上期净利润) / 上期净利润
- **分析意义**：反映企业净利润增长能力
- **标准值**：因行业而异，一般越高越好
- **影响因素**：营业收入水平、成本控制、费用管理

#### 3. 总资产增长率
- **计算公式**：总资产增长率 = (本期总资产 - 上期总资产) / 上期总资产
- **分析意义**：反映企业资产增长能力
- **标准值**：因行业而异，一般适中为好
- **影响因素**：投资决策、融资决策、经营决策

### 💰 资本积累率

#### 1. 资本积累率
- **计算公式**：资本积累率 = (本期所有者权益 - 上期所有者权益) / 上期所有者权益
- **分析意义**：反映企业资本积累能力
- **标准值**：因行业而异，一般越高越好
- **影响因素**：利润水平、分配政策、融资决策

#### 2. 技术投入比率
- **计算公式**：技术投入比率 = 技术投入 / 营业收入
- **分析意义**：反映企业技术投入水平
- **标准值**：因行业而异，一般越高越好
- **影响因素**：技术投入水平、营业收入水平

## 财务比率分析的应用

### 📊 综合分析

#### 1. 杜邦分析体系
- **核心公式**：净资产收益率 = 销售净利率 × 总资产周转率 × 权益乘数
- **分析意义**：综合分析企业盈利能力
- **应用方法**：分解分析、因素分析
- **改进方向**：提高销售净利率、加快资产周转、优化资本结构

#### 2. 沃尔评分法
- **评分方法**：选择财务比率、确定权重、计算得分
- **分析意义**：综合评价企业财务状况
- **应用方法**：加权平均、综合评分
- **改进方向**：提高各项比率水平

#### 3. 雷达图分析
- **图形方法**：绘制雷达图、分析各项比率
- **分析意义**：直观反映企业财务状况
- **应用方法**：图形分析、比较分析
- **改进方向**：平衡发展各项能力

- **改进方向**：保持优势、改进劣势
