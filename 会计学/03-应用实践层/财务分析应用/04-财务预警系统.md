# 财务预警系统

## 财务预警系统概述

### 📖 基本定义
**财务预警系统**是指通过建立财务指标监控体系，及时发现企业财务风险，提前预警财务危机的系统。

### 🔍 系统特点
- **预警性**：提前发现财务风险
- **系统性**：系统监控财务状况
- **及时性**：及时发出预警信号
- **准确性**：准确识别财务风险

### 🎯 重要作用
1. **风险识别**：识别财务风险
2. **危机预警**：预警财务危机
3. **决策支持**：支持管理决策
4. **风险控制**：控制财务风险

## 财务预警系统的应用

### 📈 Z-score模型

#### 1. Z-score模型概述
**基本概念**：
- Z-score模型是由Altman提出的财务预警模型
- 使用5个财务指标
- 计算Z-score值
- 判断企业财务风险

**基本公式**：
- Z = 1.2X1 + 1.4X2 + 3.3X3 + 0.6X4 + 1.0X5
- X1 = 营运资本/总资产
- X2 = 留存收益/总资产
- X3 = 息税前利润/总资产
- X4 = 股东权益市值/负债总额
- X5 = 营业收入/总资产

#### 2. Z-score模型应用
**某企业Z-score计算**：
- 营运资本：200,000元
- 留存收益：300,000元
- 息税前利润：150,000元
- 股东权益市值：1,000,000元
- 负债总额：500,000元
- 营业收入：1,000,000元
- 总资产：1,500,000元

**计算过程**：
- X1 = 200,000 / 1,500,000 = 0.133
- X2 = 300,000 / 1,500,000 = 0.200
- X3 = 150,000 / 1,500,000 = 0.100
- X4 = 1,000,000 / 500,000 = 2.000
- X5 = 1,000,000 / 1,500,000 = 0.667

**Z-score计算**：
- Z = 1.2×0.133 + 1.4×0.200 + 3.3×0.100 + 0.6×2.000 + 1.0×0.667
- Z = 0.160 + 0.280 + 0.330 + 1.200 + 0.667 = 2.637

**预警判断**：
- Z > 2.99：安全区域
- 1.81 < Z < 2.99：灰色区域
- Z < 1.81：危险区域
- 该企业Z-score为2.637，处于灰色区域

- 应用模型分析
- 得出预警结果

#### 2. 多变量模型实例
**某企业多变量预警**：
- 流动比率：1.5
- 资产负债率：60%
- 净利润率：8%
- 总资产周转率：1.2
- 营业收入增长率：5%

**模型计算**：
- 预警得分 = 0.3×流动比率 + 0.2×资产负债率 + 0.2×净利润率 + 0.2×总资产周转率 + 0.1×营业收入增长率
- 预警得分 = 0.3×1.5 + 0.2×60 + 0.2×8 + 0.2×1.2 + 0.1×5
- 预警得分 = 0.45 + 12 + 1.6 + 0.24 + 0.5 = 14.79

**预警判断**：
- 得分 > 15：安全区域
- 10 < 得分 < 15：关注区域
- 得分 < 10：危险区域
- 该企业得分为14.79，处于关注区域
