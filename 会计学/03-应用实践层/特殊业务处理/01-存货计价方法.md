# 存货计价方法

## 存货计价方法概述

### 📖 基本定义
**存货计价方法**是指企业确定存货发出成本和期末存货成本的方法。

### 🔍 方法特点
- **多样性**：有多种计价方法
- **重要性**：影响企业财务状况
- **选择性**：企业可以选择方法
- **一致性**：需要保持一致性

### 🎯 重要作用
1. **成本计算**：计算存货成本
2. **利润影响**：影响企业利润
3. **税务影响**：影响税务处理
4. **决策支持**：支持管理决策

## 存货计价方法的类型

### 📊 先进先出法（FIFO）

#### 1. 先进先出法概述
**基本概念**：
- 先进先出法是指先购入的存货先发出
- 假设先购入的存货先使用或销售
- 期末存货成本为最近购入的成本
- 发出存货成本为较早购入的成本

**基本特点**：
- 符合存货流转规律
- 期末存货成本接近市价
- 发出存货成本较低
- 利润相对较高

**适用条件**：
- 存货流转较快
- 存货不易变质
- 存货价格波动较大
- 需要反映真实成本

#### 2. 先进先出法计算
**计算步骤**：
1. 按购入时间顺序排列存货
2. 发出时按先进先出原则计算成本
3. 期末存货按最近购入成本计算
4. 计算发出存货总成本

**计算实例**：
**某企业存货数据**：
- 1月1日：期初存货100件，单价10元
- 1月5日：购入200件，单价12元
- 1月10日：发出150件
- 1月15日：购入300件，单价15元
- 1月20日：发出200件

**计算过程**：
- 1月10日发出150件成本：
  - 100件×10元 = 1,000元
  - 50件×12元 = 600元
  - 合计：1,600元
- 1月20日发出200件成本：
  - 150件×12元 = 1,800元
  - 50件×15元 = 750元
  - 合计：2,550元
- 期末存货成本：
  - 250件×15元 = 3,750元

### 📈 后进先出法（LIFO）

#### 1. 后进先出法概述
**基本概念**：
- 后进先出法是指后购入的存货先发出
- 假设后购入的存货先使用或销售
- 期末存货成本为较早购入的成本
- 发出存货成本为最近购入的成本

**基本特点**：
- 发出存货成本接近市价
- 期末存货成本较低
- 利润相对较低
- 税务优势明显

**适用条件**：
- 存货价格持续上涨
- 需要降低税负
- 存货流转较慢
- 存货不易变质

#### 2. 后进先出法计算
**计算步骤**：
1. 按购入时间顺序排列存货
2. 发出时按后进先出原则计算成本
3. 期末存货按较早购入成本计算
4. 计算发出存货总成本

**计算实例**：
**某企业存货数据**：
- 1月1日：期初存货100件，单价10元
- 1月5日：购入200件，单价12元
- 1月10日：发出150件
- 1月15日：购入300件，单价15元
- 1月20日：发出200件

**计算过程**：
- 1月10日发出150件成本：
  - 150件×12元 = 1,800元
- 1月20日发出200件成本：
  - 200件×15元 = 3,000元
- 期末存货成本：
  - 100件×10元 = 1,000元
  - 50件×12元 = 600元
  - 合计：1,600元

### ⚖️ 加权平均法

#### 1. 加权平均法概述
**基本概念**：
- 加权平均法是指按加权平均单价计算存货成本
- 加权平均单价 = 总成本 / 总数量
- 发出存货成本 = 发出数量 × 加权平均单价
- 期末存货成本 = 期末数量 × 加权平均单价

**基本特点**：
- 计算简单
- 成本平滑
- 价格波动影响小
- 符合成本原则

**适用条件**：
- 存货品种较多
- 价格波动频繁
- 计算要求简单
- 成本控制需要

#### 2. 加权平均法计算
**计算步骤**：
1. 计算加权平均单价
2. 计算发出存货成本
3. 计算期末存货成本
4. 验证计算结果

**计算实例**：
**某企业存货数据**：
- 1月1日：期初存货100件，单价10元
- 1月5日：购入200件，单价12元
- 1月10日：发出150件
- 1月15日：购入300件，单价15元
- 1月20日：发出200件

**计算过程**：
- 加权平均单价 = (100×10 + 200×12 + 300×15) / (100 + 200 + 300)
- 加权平均单价 = (1,000 + 2,400 + 4,500) / 600 = 13.17元
- 发出存货成本 = 350 × 13.17 = 4,609.5元
- 期末存货成本 = 250 × 13.17 = 3,292.5元

### 🎯 个别计价法

#### 1. 个别计价法概述
**基本概念**：
- 个别计价法是指按每批存货的实际成本计价
- 每批存货都有明确的成本
- 发出时按实际成本计算
- 期末存货按实际成本计算

**基本特点**：
- 成本最准确
- 计算最复杂
- 适用性有限
- 管理要求高

**适用条件**：
- 存货品种少
- 存货价值高
- 存货可识别
- 管理精细

#### 2. 个别计价法计算
**计算步骤**：
1. 记录每批存货的实际成本
2. 发出时按实际成本计算
3. 期末存货按实际成本计算
4. 验证计算结果

**计算实例**：
**某企业存货数据**：
- 批次1：100件，单价10元
- 批次2：200件，单价12元
- 批次3：300件，单价15元
- 发出：批次1的100件，批次2的150件

**计算过程**：
- 发出存货成本 = 100×10 + 150×12 = 1,000 + 1,800 = 2,800元
- 期末存货成本 = 50×12 + 300×15 = 600 + 4,500 = 5,100元

## 存货计价方法的选择

### 🤔 选择原则

#### 1. 会计准则要求
**会计准则规定**：
- 企业可以选择存货计价方法
- 选择后需要保持一致性
- 变更需要说明原因
- 需要披露计价方法

**选择要求**：
- 符合会计准则
- 保持一致性
- 便于管理
- 提高效率

#### 2. 企业实际情况
**企业特点**：
- 存货特点
- 经营特点
- 管理特点
- 技术特点

**选择考虑**：
- 存货流转特点
- 价格波动情况
- 管理能力
- 计算能力

### 💡 选择建议

#### 1. 不同情况的选择
**价格持续上涨**：
- 选择后进先出法
- 降低税负
- 减少利润
- 提高竞争力

**价格波动较大**：
- 选择加权平均法
- 平滑成本
- 减少波动
- 便于管理

**存货价值较高**：
- 选择个别计价法
- 准确计算成本
- 精细管理
- 提高效率

**存货流转较快**：
- 选择先进先出法
- 符合流转规律
- 反映真实成本
- 便于管理

#### 2. 选择注意事项
**一致性要求**：
- 选择后保持一致性
- 不能随意变更
- 变更需要说明
- 需要披露原因

**管理要求**：
- 建立管理制度
- 规范操作流程
- 加强监督检查
- 提高管理水平

## 存货计价方法的会计处理

### 📋 会计处理

#### 1. 购入存货的会计处理
**购入原材料**：
- 借：原材料
- 借：应交税费——应交增值税（进项税额）
- 贷：银行存款/应付账款

**购入商品**：
- 借：库存商品
- 借：应交税费——应交增值税（进项税额）
- 贷：银行存款/应付账款

#### 2. 发出存货的会计处理
**发出原材料**：
- 借：生产成本
- 贷：原材料

**发出商品**：
- 借：主营业务成本
- 贷：库存商品

#### 3. 期末存货的会计处理
**存货盘点**：
- 盘盈时：
  - 借：原材料/库存商品
  - 贷：待处理财产损溢
- 盘亏时：
  - 借：待处理财产损溢
  - 贷：原材料/库存商品

**存货减值**：
- 借：资产减值损失
- 贷：存货跌价准备

## 存货计价方法的影响

### 📊 对财务报表的影响

#### 1. 对资产负债表的影响
**存货项目**：
- 不同方法下存货金额不同
- 影响资产总额
- 影响流动比率
- 影响资产负债率

**影响分析**：
- 先进先出法：存货金额较高
- 后进先出法：存货金额较低
- 加权平均法：存货金额中等
- 个别计价法：存货金额准确

#### 2. 对利润表的影响
**营业成本**：
- 不同方法下营业成本不同
- 影响毛利润
- 影响净利润
- 影响利润率

**影响分析**：
- 先进先出法：营业成本较低，利润较高
- 后进先出法：营业成本较高，利润较低
- 加权平均法：营业成本中等，利润中等
- 个别计价法：营业成本准确，利润准确

#### 3. 对现金流量表的影响
**经营活动现金流量**：
- 存货计价方法不影响现金流量
- 但影响利润
- 间接影响现金流量
- 影响现金流量质量

### 💰 对税务的影响

#### 1. 对所得税的影响
**所得税计算**：
- 不同方法下利润不同
- 影响所得税费用
- 影响税后利润
- 影响税务负担

**影响分析**：
- 先进先出法：利润较高，税负较重
- 后进先出法：利润较低，税负较轻
- 加权平均法：利润中等，税负中等
- 个别计价法：利润准确，税负准确

#### 2. 对增值税的影响
**增值税计算**：
- 存货计价方法不影响增值税
- 但影响成本
- 间接影响增值税
- 影响增值税负担
