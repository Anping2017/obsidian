# 会计假设与基础

## 会计假设

### 🏗️ 会计假设的定义
**会计假设**是会计工作的基本前提条件，是对会计核算所处的时间、空间环境等所作的合理设定，是会计理论体系的基础。

### 📋 四大会计假设

#### 1. 会计主体假设（Accounting Entity Assumption）
**定义**：会计工作为之服务的特定单位或组织

**要点**：
- 明确会计核算的空间范围
- 区分企业与其他主体的经济活动
- 区分企业与企业所有者的经济活动

**作用**：
- 确定会计核算范围
- 明确会计责任主体
- 保证会计信息的相关性

**举例**：
- 企业A与企业B是不同会计主体
- 企业与其所有者是不同会计主体
- 企业内部各部门不是独立会计主体

#### 2. 持续经营假设（Going Concern Assumption）
**定义**：企业将按照当前的规模和状态继续经营下去

**要点**：
- 企业不会在可预见的将来破产清算
- 企业将正常经营，不会停业
- 企业的资产将按预定用途使用

**作用**：
- 为会计方法选择提供基础
- 支持历史成本计量
- 支持权责发生制

**举例**：
- 固定资产按使用年限折旧
- 长期负债按到期时间分类
- 存货按正常经营需要储备

#### 3. 会计分期假设（Accounting Period Assumption）
**定义**：将企业持续经营的生产经营活动划分为一个个连续的、长短相同的期间

**要点**：
- 人为划分会计期间
- 通常按年度、半年度、季度、月度分期
- 便于及时提供会计信息

**作用**：
- 及时提供会计信息
- 便于比较分析
- 支持权责发生制

**举例**：
- 年度财务报表
- 月度成本核算
- 季度财务分析

#### 4. 货币计量假设（Monetary Unit Assumption）
**定义**：会计主体在会计核算过程中采用货币作为计量单位

**要点**：
- 以货币为主要计量单位
- 假设币值稳定
- 辅以实物量度

**作用**：
- 统一计量单位
- 便于汇总比较
- 支持会计记录

**举例**：
- 资产以人民币计量
- 收入以货币金额记录
- 成本以货币单位核算

## 会计基础

### ⚖️ 会计基础的定义
**会计基础**是确定收入和费用归属期间的标准，是会计核算的基础。

### 🔄 两种会计基础

#### 1. 权责发生制（Accrual Basis）
**定义**：以权利和责任的发生与否作为确认收入和费用的标准

**特点**：
- 收入在实现时确认
- 费用在发生时确认
- 不考虑款项是否收付

**优点**：
- 准确反映经营成果
- 符合配比原则
- 提供完整信息

**缺点**：
- 计算复杂
- 需要估计判断
- 可能存在误差

**举例**：
- 销售商品，收入在商品交付时确认
- 购买原材料，费用在材料使用时确认
- 计提折旧，费用在资产使用时确认

#### 2. 收付实现制（Cash Basis）
**定义**：以款项的实际收付作为确认收入和费用的标准

**特点**：
- 收入在实际收到时确认
- 费用在实际支付时确认
- 以现金流动为准

**优点**：
- 计算简单
- 反映现金流动
- 易于理解

**缺点**：
- 不能准确反映经营成果
- 不符合配比原则
- 信息不完整

**举例**：
- 销售商品，收入在收到货款时确认
- 购买原材料，费用在支付货款时确认
- 支付工资，费用在支付时确认

### 📊 权责发生制与收付实现制对比

| 项目 | 权责发生制 | 收付实现制 |
|------|------------|------------|
| 确认标准 | 权利责任发生 | 款项收付 |
| 收入确认 | 实现时确认 | 收到时确认 |
| 费用确认 | 发生时确认 | 支付时确认 |
| 准确性 | 高 | 低 |
| 复杂性 | 高 | 低 |
| 适用性 | 企业会计 | 预算会计 |

## 会计假设的作用

### 🎯 理论作用
1. **构建理论体系**：为会计理论提供基础
2. **指导实务操作**：指导会计实务工作
3. **规范会计行为**：规范会计人员行为
4. **支持准则制定**：支持会计准则制定

### 💼 实务作用
1. **确定核算范围**：明确会计核算范围
2. **选择会计方法**：指导会计方法选择
3. **处理会计事项**：指导会计事项处理
4. **编制财务报表**：支持财务报表编制

## 会计假设的局限性

### ⚠️ 主要局限性
1. **环境变化**：经济环境变化可能影响假设
2. **技术进步**：技术进步可能改变假设
3. **国际差异**：不同国家可能有不同假设
4. **实务需要**：实务需要可能突破假设

### 🔄 适应性调整
1. **环境适应**：根据环境变化调整假设
2. **技术进步**：利用技术进步改进假设
3. **国际协调**：与国际会计准则协调
4. **实务指导**：根据实务需要完善假设

## 费曼学习法应用

### 🎯 学习目标
**能够准确理解会计假设和会计基础的含义和作用**

### 📝 学习步骤
1. **选择概念**：会计假设和会计基础
2. **简化解释**：用简单语言解释概念
3. **识别盲区**：发现不理解的地方
4. **重新学习**：回到源头重新理解

### 💡 记忆技巧
- **四大假设**：主体、持续、分期、货币
- **两种基础**：权责发生制、收付实现制
- **假设作用**：理论指导、实务规范

## 刻意练习要点

### 🎯 练习重点
1. **假设理解**：准确理解四大会计假设
2. **基础区分**：区分权责发生制和收付实现制
3. **作用分析**：分析会计假设的作用
4. **应用判断**：判断在具体情况下适用哪种基础

### 📊 练习方法
1. **概念解释**：用自己的话解释会计假设
2. **案例分析**：分析具体案例中的会计假设
3. **对比分析**：对比两种会计基础的差异
4. **综合应用**：综合运用所学知识分析问题
