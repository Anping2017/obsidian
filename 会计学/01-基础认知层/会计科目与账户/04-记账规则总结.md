# 记账规则总结

## 记账规则概述

### 📖 基本定义
**记账规则**是指在会计核算过程中，对经济业务进行记录和处理时必须遵循的基本规范和原则。

### 🔍 规则特点
- **规范性**：具有规范性和约束性
- **科学性**：基于科学的会计理论
- **实用性**：具有实用性和可操作性
- **统一性**：统一的标准和要求

### 🎯 规则作用
1. **规范行为**：规范会计人员的行为
2. **保证质量**：保证会计信息质量
3. **提高效率**：提高会计核算效率
4. **便于管理**：便于会计管理

## 借贷记账规则

### ⚖️ 基本规则
**有借必有贷，借贷必相等**

### 🔍 规则解析

#### 1. 有借必有贷
- **含义**：每笔经济业务至少涉及一个借方账户和一个贷方账户
- **原因**：复式记账的基本要求
- **作用**：保证记录的完整性
- **应用**：适用于所有经济业务

#### 2. 借贷必相等
- **含义**：每笔经济业务的借方金额合计等于贷方金额合计
- **原因**：会计等式平衡的要求
- **作用**：保证记录的准确性
- **应用**：适用于所有经济业务

### 📊 规则应用

#### 1. 简单分录（一借一贷）
```
借：账户A    金额
贷：账户B    金额
```

#### 2. 复合分录（一借多贷）
```
借：账户A    金额
贷：账户B    金额
贷：账户C    金额
```

#### 3. 复合分录（多借一贷）
```
借：账户A    金额
借：账户B    金额
贷：账户C    金额
```

#### 4. 复杂分录（多借多贷）
```
借：账户A    金额
借：账户B    金额
贷：账户C    金额
贷：账户D    金额
```

## 各类账户记账规则

### 💰 资产类账户

#### 记账规则
- **增加**：记借方
- **减少**：记贷方
- **余额**：在借方

#### 余额计算
```
期末余额 = 期初余额 + 本期借方发生额 - 本期贷方发生额
```

#### 应用示例
**库存现金账户**
```
库存现金
┌─────────────────┐
│  借方（增加）    │  贷方（减少）
├─────────────────┤
│ 期初余额 1,000  │
│ 收到现金 5,000  │ 支付现金 3,000
│ 销售收款 2,000  │ 购买材料 1,500
├─────────────────┤
│ 本期发生 7,000  │ 本期发生 4,500

└─────────────────┘
```

- **时效错误**：时效性错误

### 🔧 错误纠正方法

#### 1. 划线更正法
- **适用情况**：记账凭证正确，账簿记录错误
- **更正方法**：用红线划掉错误记录，在上方写上正确记录
- **注意事项**：保持原有记录清晰可见

#### 2. 红字更正法
- **适用情况**：记账凭证错误，导致账簿记录错误
- **更正方法**：用红字编制相同分录，再用蓝字编制正确分录
- **注意事项**：红字金额用负数表示

#### 3. 补充登记法
- **适用情况**：记账凭证金额小于应记金额
- **更正方法**：用蓝字编制补充分录
- **注意事项**：补充金额为差额部分
