# 战略管理概论

## 🎯 学习目标
理解战略管理的本质，掌握战略管理过程，建立战略思维框架。

## 📊 战略管理定义

### 核心定义
**战略管理**是企业确定使命、愿景和目标，制定和实施战略，评估和控制战略执行的管理过程。

### 战略层次
```mermaid

    A[战略管理] --> B[公司战略]
    A --> C[业务战略]
    A --> D[职能战略]
    
    B --> B1[业务组合]
    B --> B2[资源配置]
    B --> B3[协同效应]
    B --> B4[价值创造]
    
    C --> C1[竞争定位]
    C --> C2[竞争优势]

    C --> C4[运营策略]
    
    D --> D1[营销战略]
    D --> D2[运营战略]
    D --> D3[财务战略]
    D --> D4[人力资源战略]
```
