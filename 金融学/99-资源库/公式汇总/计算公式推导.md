# 计算公式推导

## 🎯 核心概念

### 公式推导的重要性
**公式推导**是理解金融学公式本质的关键过程，通过推导可以深入理解公式的数学逻辑、经济含义和应用条件，为正确使用公式奠定理论基础。

> **费曼解释**：公式推导就像"数学公式的制造过程"一样。就像了解汽车需要知道制造过程，了解公式需要知道推导过程。就像"公式的工厂"，推导过程就是"生产"公式的工艺流程。

### 公式推导的基本特征
- **逻辑性**：严格的数学逻辑
- **系统性**：系统化的推导过程
- **严谨性**：严谨的推导步骤
- **可验证性**：结果可验证

## 📊 基础公式推导

### 1. 货币乘数推导
**推导过程**：
1. **基础货币**：B = C + R
   - C：流通中现金
   - R：银行准备金

2. **货币供应量**：M = C + D
   - D：银行存款

3. **现金漏损率**：c = C/D
   - 现金与存款的比率

4. **准备金率**：r = R/D
   - 准备金与存款的比率

5. **货币乘数**：m = M/B = (C+D)/(C+R)
   - 分子分母同除以D
   - m = (c+1)/(c+r)

**经济含义**：
- 货币乘数反映货币创造能力
- 准备金率越高，乘数越小
- 现金漏损率越高，乘数越小

**关联学习**：[[01-基础理论/货币与信用/货币供求理论|货币供求理论]]

### 2. 利率公式推导
**名义利率与实际利率**：
1. **定义**：
   - 名义利率：i
   - 实际利率：r
   - 通货膨胀率：π

2. **推导**：
   - 1元投资1年后：1+i
   - 实际购买力：(1+i)/(1+π)
   - 实际利率：r = (1+i)/(1+π) - 1
   - 近似公式：r ≈ i - π

**连续复利推导**：
1. **离散复利**：FV = PV(1+r/n)^(nt)
2. **连续复利**：n→∞
3. **极限**：lim(n→∞)(1+r/n)^(nt) = e^(rt)
4. **结果**：FV = PV × e^(rt)

### 3. 其他基础推导
**年金现值推导**：
1. **普通年金**：PMT每期支付
2. **现值计算**：PVA = PMT/(1+r) + PMT/(1+r)² + ... + PMT/(1+r)^n
3. **等比数列求和**：PVA = PMT[1-(1+r)^(-n)]/r

**永续年金推导**：
1. **永续年金**：n→∞
2. **极限**：lim(n→∞)[1-(1+r)^(-n)]/r = 1/r
3. **结果**：PVA = PMT/r

## 🔄 投资学公式推导

### 1. CAPM推导
**推导假设**：
1. **市场均衡**：所有投资者持有市场组合
2. **同质预期**：所有投资者预期相同
3. **无摩擦市场**：无交易成本、无税收
4. **风险厌恶**：投资者风险厌恶

**推导过程**：
1. **市场组合**：所有风险资产的组合
2. **有效前沿**：风险-收益最优组合
3. **资本市场线**：CML = Rf + σp × [(E(Rm)-Rf)/σm]
4. **证券市场线**：SML = Rf + βi[E(Rm)-Rf]

**Beta系数推导**：
1. **定义**：βi = Cov(Ri,Rm)/Var(Rm)
2. **回归系数**：Ri = αi + βiRm + εi
3. **最小二乘法**：βi = Cov(Ri,Rm)/Var(Rm)

**关联学习**：[[03-投资学/投资基础/资产定价模型|资产定价模型]]

### 2. 期权定价推导
**Black-Scholes推导**：
1. **假设条件**：
   - 股票价格遵循几何布朗运动
   - 无风险利率恒定
   - 无股息支付
   - 无套利机会

2. **随机过程**：dS = μSdt + σSdW
3. **伊藤引理**：dC = (∂C/∂t + μS∂C/∂S + 0.5σ²S²∂²C/∂S²)dt + σS∂C/∂S dW
4. **无风险组合**：构造无风险组合
5. **偏微分方程**：∂C/∂t + rS∂C/∂S + 0.5σ²S²∂²C/∂S² = rC
6. **边界条件**：C(T) = max(S-K,0)
7. **解析解**：C = S₀N(d₁) - Ke^(-rT)N(d₂)

**d₁和d₂推导**：
1. **d₁**：d₁ = [ln(S₀/K) + (r+σ²/2)T]/(σ√T)
2. **d₂**：d₂ = d₁ - σ√T

### 3. 其他投资推导
**投资组合方差推导**：
1. **两资产组合**：Rp = w1R1 + w2R2
2. **方差**：Var(Rp) = w1²Var(R1) + w2²Var(R2) + 2w1w2Cov(R1,R2)
3. **协方差**：Cov(R1,R2) = ρ12σ1σ2
4. **结果**：σp² = w1²σ1² + w2²σ2² + 2w1w2ρ12σ1σ2

**有效前沿推导**：
1. **目标函数**：最小化σp²，约束条件E(Rp) = 目标收益
2. **拉格朗日乘数法**：L = σp² - λ[E(Rp) - 目标收益]
3. **一阶条件**：∂L/∂wi = 0
4. **求解**：得到最优权重

## 📈 公司金融公式推导

### 1. DCF推导
**推导过程**：
1. **企业价值**：V = Σ[CFt/(1+r)^t] + TV/(1+r)^n
2. **现金流**：CFt = EBIT(1-T) + Dep - CapEx - ΔWC
3. **终值**：TV = CFn+1/(r-g)
4. **永续增长**：g为永续增长率

**WACC推导**：
1. **加权平均**：WACC = (E/V)Re + (D/V)Rd(1-T)
2. **股权成本**：Re = Rf + β[E(Rm)-Rf]
3. **债务成本**：Rd = 市场利率
4. **权重**：E/V + D/V = 1

**关联学习**：[[04-公司金融/价值评估/现金流折现模型|现金流折现模型]]

### 2. 资本成本推导
**股权成本推导**：
1. **CAPM方法**：Re = Rf + β[E(Rm)-Rf]
2. **DDM方法**：Re = D1/P0 + g
3. **债券收益率加风险溢价**：Re = Rd + RP

**债务成本推导**：
1. **税前成本**：Rd = 市场利率
2. **税后成本**：Rd(1-T)
3. **税盾效应**：利息费用可抵税

### 3. 其他公司金融推导
**MM理论推导**：
1. **无税情况**：VL = VU
2. **有税情况**：VL = VU + TD
3. **税盾价值**：PV(税盾) = TD

**最优资本结构推导**：
1. **目标函数**：最小化WACC
2. **约束条件**：E + D = V
3. **一阶条件**：∂WACC/∂(D/V) = 0
4. **求解**：得到最优债务比率

## 🔒 高级公式推导

### 1. 随机过程推导
**几何布朗运动推导**：
1. **假设**：股票价格遵循随机游走
2. **随机微分方程**：dS = μSdt + σSdW
3. **解**：S(t) = S(0)exp[(μ-σ²/2)t + σW(t)]
4. **对数正态分布**：ln(S(t)) ~ N(ln(S(0)) + (μ-σ²/2)t, σ²t)

**伊藤引理推导**：
1. **泰勒展开**：f(S+ΔS) = f(S) + f'(S)ΔS + 0.5f''(S)(ΔS)² + ...
2. **随机项**：(ΔS)² ≈ σ²S²(ΔW)² ≈ σ²S²Δt
3. **结果**：df = f'(S)dS + 0.5f''(S)σ²S²dt

### 2. 偏微分方程推导
**热传导方程推导**：
1. **期权价格**：C(S,t)
2. **无风险组合**：Π = C - ΔS
3. **组合收益**：dΠ = dC - ΔdS
4. **无风险条件**：dΠ = rΠdt
5. **偏微分方程**：∂C/∂t + rS∂C/∂S + 0.5σ²S²∂²C/∂S² = rC

**边界条件推导**：
1. **到期条件**：C(S,T) = max(S-K,0)
2. **边界条件**：C(0,t) = 0, C(S→∞,t) = S
3. **初始条件**：C(S,0) = max(S-K,0)

### 3. 其他高级推导
**蒙特卡洛模拟推导**：
1. **随机数生成**：生成标准正态分布随机数
2. **路径模拟**：模拟股票价格路径
3. **期权价值**：计算期权到期价值
4. **期望值**：计算期望期权价值

**数值方法推导**：
1. **有限差分法**：将偏微分方程离散化
2. **二叉树模型**：将连续过程离散化
3. **蒙特卡洛方法**：随机模拟方法
