# 外汇市场

## 🎯 核心概念

### 外汇市场的定义
**外汇市场**是不同货币之间进行兑换和交易的场所，是全球最大的金融市场，为国际贸易、投资和风险管理提供货币兑换服务。

> **费曼解释**：外汇市场就像"货币兑换的超市"一样。就像超市卖各种商品，外汇市场卖各种货币。就像"货币兑换的交易所"，你可以在这里把一种货币换成另一种货币。

### 外汇市场的基本特征
- **全球性**：24小时全球交易
- **流动性**：流动性极高
- **波动性**：价格波动较大
- **杠杆性**：高杠杆交易

## 🔄 汇率决定理论

### 1. 购买力平价理论
**绝对购买力平价**：
- **定义**：汇率等于两国价格水平之比
- **公式**：S = P/P*
- **假设**：商品同质、无交易成本
- **应用**：长期汇率预测

**相对购买力平价**：
- **定义**：汇率变化等于两国通胀率之差
- **公式**：ΔS = π - π*
- **假设**：商品同质、无交易成本
- **应用**：长期汇率预测

**购买力平价局限性**：
- **商品同质假设**：商品不完全同质
- **无交易成本假设**：存在交易成本
- **价格指数问题**：价格指数不完善
- **非贸易品问题**：非贸易品影响

### 2. 利率平价理论
**无抛补利率平价**：
- **定义**：预期汇率变化等于两国利率差
- **公式**：E(ΔS) = i - i*
- **假设**：资本自由流动、无风险
- **应用**：短期汇率预测

**抛补利率平价**：
- **定义**：远期汇率等于即期汇率加利率差
- **公式**：F = S(1+i)/(1+i*)
- **假设**：资本自由流动、无风险
- **应用**：套利交易

**利率平价局限性**：
- **资本流动假设**：资本不完全自由流动
- **无风险假设**：存在汇率风险
- **交易成本问题**：存在交易成本
- **政策干预问题**：存在政策干预

### 3. 国际收支理论
**国际收支平衡**：
- **定义**：国际收支平衡
- **构成**：经常账户、资本账户
- **平衡条件**：国际收支平衡
- **汇率影响**：汇率影响国际收支

**汇率调节机制**：
