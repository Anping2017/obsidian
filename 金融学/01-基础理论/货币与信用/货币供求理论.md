# 货币供求理论

## 🎯 核心概念

### 货币供求理论的定义
**货币供求理论**是研究货币供给和货币需求的决定因素、变动规律及其对经济影响的理论体系，是货币金融学的核心理论。

> **费曼解释**：货币供求理论就像"货币市场的供求关系"一样。就像商品市场有供求关系，货币市场也有供求关系。就像"货币的价格决定"，告诉你货币的价值是怎么决定的。

### 货币供求理论的基本特征
- **理论性**：具有完整的理论体系
- **实践性**：指导实际货币政策
- **动态性**：货币供求动态变化
- **综合性**：涉及多个经济因素

## 📊 货币供给理论

### 1. 货币供给的定义
**货币供给**：
- **定义**：一定时点上社会货币总量
- **构成**：M0、M1、M2、M3
- **特点**：存量概念、时点概念
- **意义**：货币政策目标

**货币层次**：
- **M0**：流通中现金
- **M1**：M0 + 活期存款
- **M2**：M1 + 定期存款 + 储蓄存款
- **M3**：M2 + 其他存款

**货币创造**：
- **基础货币**：央行创造的货币
- **货币乘数**：银行体系创造的货币
- **货币总量**：基础货币 × 货币乘数
- **创造过程**：存款创造过程

**关联学习**：[[01-基础理论/货币与信用/货币本质与职能|货币本质与职能]]

### 2. 货币供给的决定因素
**基础货币**：
- **央行资产**：央行资产变化
- **外汇占款**：外汇占款变化
- **对政府债权**：对政府债权变化
- **对银行债权**：对银行债权变化

**货币乘数**：
- **法定准备金率**：法定准备金率
- **超额准备金率**：超额准备金率
- **现金比率**：现金比率
- **定期存款比率**：定期存款比率

**货币乘数公式**：
```
货币乘数 = 1 / (rd + re + c + t)
其中：
rd = 法定准备金率
re = 超额准备金率
c = 现金比率
t = 定期存款比率
```

## 🔄 货币需求理论

### 1. 古典货币需求理论
**费雪方程式**：
- **公式**：MV = PT
- **M**：货币数量
- **V**：货币流通速度
- **P**：价格水平
- **T**：交易量

**剑桥方程式**：
- **公式**：M = kPY
- **M**：货币数量
- **k**：货币持有比例
- **P**：价格水平
- **Y**：实际收入

**现金余额说**：
- **定义**：货币需求是现金余额需求
- **决定因素**：收入、价格、利率
- **特点**：强调货币储藏功能
- **意义**：货币需求理论

### 2. 凯恩斯货币需求理论
**流动性偏好理论**：
- **定义**：货币需求是流动性偏好
- **决定因素**：收入、利率
- **特点**：强调货币流动性
- **意义**：货币需求理论

**货币需求动机**：
- **交易动机**：日常交易需求
- **预防动机**：预防意外需求
- **投机动机**：投机获利需求
- **财富动机**：财富保值需求

**货币需求函数**：
```
L = L1(Y) + L2(r)
其中：
L1(Y) = 交易动机和预防动机需求
L2(r) = 投机动机需求
Y = 收入
r = 利率
```

### 3. 现代货币需求理论
**弗里德曼货币需求理论**：
- **定义**：货币需求是资产需求
- **决定因素**：财富、利率、通胀率
- **特点**：强调货币资产功能
- **意义**：现代货币需求理论

**货币需求函数**：
```
M/P = f(Y, r, π, W)
其中：
M/P = 实际货币需求
Y = 永久收入
r = 利率
π = 通胀率
W = 财富
```

**货币需求稳定性**：
- **稳定性**：货币需求稳定
- **可预测性**：货币需求可预测
- **政策含义**：货币政策有效
- **实证支持**：实证研究支持

## 📈 货币供求均衡

### 1. 货币市场均衡

- **需求减少**：利率下降

**均衡稳定性**：
- **稳定性**：均衡稳定性
- **调整机制**：调整机制
- **收敛性**：收敛性
- **唯一性**：唯一性

### 2. 货币供求失衡
**供给过剩**：
- **表现**：货币供给过多
- **影响**：利率下降、通胀上升
- **调整**：减少货币供给
- **政策**：紧缩货币政策

**供给不足**：
- **表现**：货币供给不足
- **影响**：利率上升、通缩风险
- **调整**：增加货币供给
- **政策**：宽松货币政策

**需求过剩**：
- **表现**：货币需求过多
- **影响**：利率上升、流动性紧张
- **调整**：增加货币供给
- **政策**：宽松货币政策

**需求不足**：
- **表现**：货币需求不足
- **影响**：利率下降、流动性过剩
- **调整**：减少货币供给
- **政策**：紧缩货币政策
