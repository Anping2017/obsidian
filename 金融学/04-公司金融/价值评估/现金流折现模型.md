# 现金流折现模型

## 🎯 核心概念

### DCF模型的定义
**现金流折现模型（DCF）**是通过预测企业未来现金流并将其折现到现值来评估企业价值的方法。

> **费曼解释**：DCF模型就像预测一个人的未来收入，然后计算现在值多少钱。就像买房子要看未来租金收入一样，买股票要看未来分红和增值。

### 基本原理
- **时间价值**：今天的钱比明天的钱值钱
- **现金流**：企业创造的实际价值
- **折现率**：反映投资风险和要求回报

## 📊 DCF模型基础

### 1. 基本公式
**企业价值** = Σ[CFt / (1+r)^t] + TV / (1+r)^n

**参数解释**：
- **CFt**：第t年的现金流
- **r**：折现率
- **TV**：终值（Terminal Value）
- **n**：预测期年数

### 2. 现金流类型
**自由现金流（FCF）**：
- **FCF to Firm**：企业自由现金流
- **FCF to Equity**：股权自由现金流

**计算公式**：
```
FCF to Firm = EBIT(1-T) + 折旧 - 资本支出 - 营运资本变化
FCF to Equity = 净利润 + 折旧 - 资本支出 - 营运资本变化 - 债务变化
```

**关联学习**：[[04-公司金融/价值评估/企业价值评估|企业价值评估]]

### 3. 折现率确定
**加权平均资本成本（WACC）**：
```
WACC = (E/V) × Re + (D/V) × Rd × (1-T)
```
- **E**：股权价值
- **D**：债务价值
- **V**：企业总价值
- **Re**：股权成本
- **Rd**：债务成本
- **T**：税率

**关联学习**：[[04-公司金融/资本结构/资本成本|资本成本]]

## 🔮 现金流预测

### 1. 预测方法
**自上而下法**：
1. **宏观经济分析**：GDP、通胀、利率
2. **行业分析**：市场规模、竞争格局
3. **企业分析**：市场份额、盈利能力

**自下而上法**：
1. **历史数据**：过去3-5年表现
2. **管理层指引**：企业发展规划
3. **财务模型**：收入、成本、资本支出

### 2. 预测期选择
**一般原则**：
- **5-10年**：详细预测期
- **10年以上**：终值计算
- **行业特点**：根据行业周期调整

**考虑因素**：
- **企业生命周期**
- **行业成熟度**
- **预测准确性**

### 3. 预测假设
**收入增长**：
- **历史增长率**
- **行业增长率**
- **市场份额变化**

**利润率**：
- **历史利润率**
- **行业平均水平**
- **竞争压力**

**资本支出**：
- **维持性资本支出**
- **扩张性资本支出**
- **折旧政策**

## 📈 终值计算

### 1. 永续增长法
**公式**：TV = CFn+1 / (r - g)

**参数**：
- **CFn+1**：预测期后第一年现金流
- **r**：折现率
- **g**：永续增长率

**永续增长率**：
- **通常2-3%**：长期通胀率
- **不超过GDP增长率**
- **考虑行业特点**

### 2. 退出倍数法
**公式**：TV = CFn × 倍数

**常用倍数**：
- **EV/EBITDA**：企业价值倍数
- **P/E**：市盈率
- **P/B**：市净率

**倍数选择**：
- **历史倍数**
- **行业平均倍数**
- **可比公司倍数**

## 📊 DCF模型优缺点

### 优点
1. **理论基础强**：基于现金流和折现理论
2. **灵活性高**：可以调整各种假设
3. **适用性广**：适用于各种企业
4. **透明度高**：假设和计算过程清晰

### 缺点
1. **预测困难**：未来现金流难以准确预测
2. **假设敏感**：结果对假设变化敏感
3. **计算复杂**：需要大量数据和计算
4. **主观性强**：折现率和增长率选择主观

| **美国** | 5-10年 | WACC | 永续增长 | 成熟市场 |
| **欧洲** | 5-8年 | WACC | 退出倍数 | 保守估计 |
| **中国** | 3-5年 | 股权成本 | 永续增长 | 高增长 |
| **日本** | 5-7年 | WACC | 退出倍数 | 低增长 |

| 行业 | 现金流特点 | 折现率 | 预测难度 | 主要挑战 |
