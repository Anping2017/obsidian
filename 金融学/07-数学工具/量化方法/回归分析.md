# 回归分析

## 🎯 核心概念

### 回归分析的定义
**回归分析**是一种统计分析方法，用于研究因变量与一个或多个自变量之间的数量关系，建立数学模型进行预测和控制。

> **费曼解释**：回归分析就像"找规律的工具"一样。就像看天气变化找规律，回归分析看数据变化找规律。就像"数据的天气预报"，告诉你数据会怎么变化。

### 回归分析的基本特征
- **关系性**：研究变量间关系
- **预测性**：用于预测分析
- **统计性**：基于统计理论
- **应用性**：广泛实际应用

## 📊 回归分析基础

### 1. 回归概念
**回归定义**：
- **定义**：回归分析定义
- **目的**：建立变量关系
- **方法**：数学建模
- **应用**：预测控制

**回归类型**：
- **简单回归**：一个自变量
- **多元回归**：多个自变量
- **线性回归**：线性关系
- **非线性回归**：非线性关系

**回归假设**：
- **线性假设**：线性关系
- **独立性假设**：观测独立
- **正态性假设**：误差正态
- **同方差假设**：误差方差相等

**关联学习**：[[07-数学工具/金融数学基础/概率论与统计学|概率论与统计学]]

### 2. 回归模型
**线性回归模型**：
- **定义**：Y = β₀ + β₁X + ε
- **参数**：β₀截距、β₁斜率
- **误差**：ε随机误差
- **假设**：误差项假设

**多元回归模型**：
- **定义**：Y = β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ + ε
- **参数**：多个回归系数
- **变量**：多个自变量
- **应用**：复杂关系分析

**非线性回归模型**：
- **定义**：非线性函数关系
- **类型**：多项式、指数、对数
- **方法**：非线性估计
- **应用**：复杂关系建模

### 3. 参数估计
**最小二乘法**：
- **定义**：最小二乘估计
- **原理**：最小化残差平方和
- **公式**：β̂ = (X'X)⁻¹X'Y
- **性质**：无偏性、有效性

**最大似然法**：
- **定义**：最大似然估计
- **原理**：最大化似然函数
- **方法**：数值优化
- **应用**：非线性模型

**贝叶斯估计**：
- **定义**：贝叶斯估计
- **原理**：贝叶斯定理
- **方法**：后验分布
- **应用**：不确定性建模

## 🔄 线性回归

### 1. 简单线性回归
**模型设定**：
- **定义**：Y = β₀ + β₁X + ε
- **假设**：线性、独立、正态、同方差
- **参数**：β₀、β₁
- **估计**：最小二乘法

**参数估计**：
- **截距**：β̂₀ = Ȳ - β̂₁X̄
- **斜率**：β̂₁ = Σ(Xᵢ-X̄)(Yᵢ-Ȳ)/Σ(Xᵢ-X̄)²
- **标准误**：SE(β̂₁) = σ/√Σ(Xᵢ-X̄)²
- **t统计量**：t = β̂₁/SE(β̂₁)

**模型检验**：
- **F检验**：整体显著性
- **t检验**：参数显著性
- **R²**：拟合优度
- **调整R²**：调整拟合优度

### 2. 多元线性回归
**模型设定**：
- **定义**：Y = β₀ + β₁X₁ + β₂X₂ + ... + βₙXₙ + ε
- **矩阵形式**：Y = Xβ + ε
- **假设**：线性、独立、正态、同方差
- **估计**：最小二乘法

**参数估计**：
- **矩阵形式**：β̂ = (X'X)⁻¹X'Y
- **协方差矩阵**：Var(β̂) = σ²(X'X)⁻¹
- **标准误**：SE(β̂ᵢ) = √σ²(X'X)⁻¹ᵢᵢ
- **t统计量**：tᵢ = β̂ᵢ/SE(β̂ᵢ)

**模型诊断**：
- **多重共线性**：VIF检验
- **异方差性**：White检验
- **自相关性**：Durbin-Watson检验
- **正态性**：Jarque-Bera检验

### 3. 回归诊断
**残差分析**：
- **定义**：残差 = 观测值 - 拟合值
- **图形**：残差图、Q-Q图
- **检验**：正态性检验
- **诊断**：模型假设检验

**影响点分析**：
- **定义**：影响点分析
- **方法**：Cook距离、杠杆值
- **识别**：异常值识别
- **处理**：异常值处理

**模型改进**：
- **定义**：模型改进
- **方法**：变量选择、变换
- **工具**：逐步回归、AIC
- **验证**：交叉验证

## 📈 非线性回归

### 1. 非线性模型
**多项式回归**：
- **定义**：Y = β₀ + β₁X + β₂X² + ... + βₙXⁿ + ε
- **特点**：非线性关系
- **应用**：曲线拟合
- **估计**：最小二乘法

**指数回归**：
- **定义**：Y = β₀e^(β₁X) + ε
- **特点**：指数增长
- **应用**：增长模型
- **估计**：非线性最小二乘

**对数回归**：
- **定义**：Y = β₀ + β₁ln(X) + ε
- **特点**：对数关系
- **应用**：弹性分析
- **估计**：最小二乘法

### 2. 参数估计
**非线性最小二乘**：
- **定义**：非线性最小二乘
- **方法**：数值优化
- **算法**：牛顿法、拟牛顿法
- **收敛**：收敛性检验

**最大似然估计**：
- **定义**：最大似然估计
- **方法**：似然函数最大化
- **算法**：EM算法、梯度法
- **应用**：复杂模型

### 3. 模型选择
**信息准则**：
- **AIC**：Akaike信息准则
- **BIC**：贝叶斯信息准则
- **HQ**：Hannan-Quinn准则
- **选择**：最小准则值

**交叉验证**：
- **定义**：交叉验证
- **方法**：k折交叉验证
- **应用**：模型选择
- **评估**：预测性能

## 🌍 金融应用

### 1. 资产定价
**CAPM模型**：
- **定义**：E(R) = Rf + β[E(Rm) - Rf]
- **回归**：R - Rf = α + β(Rm - Rf) + ε
- **参数**：α、β
- **应用**：资产定价

**多因子模型**：
- **定义**：多因子定价模型
- **回归**：R = α + β₁F₁ + β₂F₂ + ... + βₙFₙ + ε
- **因子**：市场、规模、价值
- **应用**：风险分析

### 2. 风险模型
**VaR模型**：
- **定义**：风险价值模型
- **回归**：VaR = α + βX + ε
- **变量**：市场变量
- **应用**：风险管理

**信用风险模型**：
- **定义**：信用风险模型
- **回归**：违约概率 = f(财务指标)
- **变量**：财务比率
- **应用**：信用评估

### 3. 投资组合
**投资组合回归**：
- **定义**：投资组合回归
- **回归**：组合收益 = α + β市场收益 + ε
- **参数**：α、β
- **应用**：绩效评估

**风格分析**：
- **定义**：投资风格分析
- **回归**：基金收益 = Σβᵢ风格因子 + ε
- **因子**：价值、成长、小盘
- **应用**：风格识别

### 4. 市场分析
**市场预测**：
- **定义**：市场预测模型
- **回归**：未来收益 = f(历史数据)
- **变量**：技术指标、基本面
- **应用**：投资决策

**波动率预测**：
- **定义**：波动率预测模型
- **回归**：波动率 = f(历史波动率)
- **模型**：GARCH模型
- **应用**：风险管理
