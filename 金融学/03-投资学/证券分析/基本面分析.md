# 基本面分析

## 🎯 核心概念

### 基本面分析的定义
**基本面分析**是通过分析公司的财务状况、经营状况、行业地位和宏观经济环境来评估证券内在价值的分析方法。

> **费曼解释**：基本面分析就像给公司做"体检"，通过检查公司的财务状况、经营能力、行业地位等，来判断这家公司是否健康，股票是否值得投资。就像医生通过检查身体各项指标来判断健康状况一样。

### 基本面分析的基本特征
- **价值导向**：以内在价值为核心
- **长期视角**：关注长期投资价值
- **全面分析**：多维度综合分析
- **数据驱动**：基于客观数据进行分析

### 2. 财务比率分析
**盈利能力比率**：
- **ROE**：净资产收益率 = 净利润/净资产
- **ROA**：总资产收益率 = 净利润/总资产
- **ROIC**：投入资本回报率 = 税后经营利润/投入资本
- **毛利率**：毛利率 = 毛利润/营业收入

**偿债能力比率**：
- **流动比率**：流动比率 = 流动资产/流动负债
- **速动比率**：速动比率 = (流动资产-存货)/流动负债
- **资产负债率**：资产负债率 = 总负债/总资产
- **利息保障倍数**：利息保障倍数 = 息税前利润/利息费用

**运营能力比率**：
- **存货周转率**：存货周转率 = 营业成本/平均存货
- **应收账款周转率**：应收账款周转率 = 营业收入/平均应收账款
- **总资产周转率**：总资产周转率 = 营业收入/平均总资产
- **固定资产周转率**：固定资产周转率 = 营业收入/平均固定资产

**成长能力比率**：
- **营业收入增长率**：营业收入增长率 = (本期营业收入-上期营业收入)/上期营业收入
- **净利润增长率**：净利润增长率 = (本期净利润-上期净利润)/上期净利润
- **总资产增长率**：总资产增长率 = (本期总资产-上期总资产)/上期总资产
- **净资产增长率**：净资产增长率 = (本期净资产-上期净资产)/上期净资产

### 3. 财务分析框架
**杜邦分析**：
- **ROE分解**：ROE = 净利润率 × 总资产周转率 × 权益乘数
- **盈利能力**：分析净利润率变化
- **运营效率**：分析总资产周转率变化
- **财务杠杆**：分析权益乘数变化

**财务健康度评估**：
- **盈利能力**：评估盈利能力水平
- **偿债能力**：评估偿债能力水平
- **运营能力**：评估运营能力水平
- **成长能力**：评估成长能力水平

## 🔄 行业分析

### 1. 行业生命周期分析
**行业生命周期阶段**：
- **导入期**：技术不成熟，市场小，风险高
- **成长期**：技术成熟，市场扩大，增长快
- **成熟期**：技术稳定，市场饱和，增长慢
- **衰退期**：技术落后，市场萎缩，负增长

**各阶段特征**：
- **导入期**：高投入、高风险、低回报
- **成长期**：高增长、高回报、竞争激烈
- **成熟期**：稳定增长、稳定回报、寡头垄断
- **衰退期**：负增长、低回报、退出市场

**投资策略**：
- **导入期**：高风险投资，关注技术突破
- **成长期**：成长投资，关注市场份额
- **成熟期**：价值投资，关注分红回报
- **衰退期**：避免投资，关注转型机会
