# 期权定价

## 🎯 核心概念

### 期权定价的定义
**期权定价**是确定期权合理价格的过程，通过数学模型和理论分析来评估期权的内在价值和时间价值。

> **费曼解释**：期权定价就像"给保险定价"一样。就像保险公司根据风险给保险定价，期权定价根据标的资产价格波动给期权定价。就像"未来的权利价格"，告诉你这个权利值多少钱。

### 期权定价的基本特征
- **理论性**：基于数学理论
- **复杂性**：涉及多个变量
- **实用性**：指导实际交易
- **动态性**：价格动态变化

## 📊 期权定价理论

### 1. 期权价值构成
**内在价值**：
- **看涨期权**：max(S-K, 0)
- **看跌期权**：max(K-S, 0)
- **实值期权**：内在价值>0
- **虚值期权**：内在价值=0
- **平值期权**：内在价值=0

**时间价值**：
- **定义**：期权价格超过内在价值的部分
- **影响因素**：到期时间、波动率、利率
- **衰减**：随时间衰减
- **最大**：平值期权时间价值最大

**期权价格**：
```
期权价格 = 内在价值 + 时间价值
```

**关联学习**：[[03-投资学/衍生品/期权基础|期权基础]]

### 2. 影响期权价格的因素
**标的资产价格（S）**：
- **看涨期权**：S上升，期权价格上升
- **看跌期权**：S上升，期权价格下降
- **Delta**：价格敏感性
- **影响程度**：影响程度最大

**执行价格（K）**：
- **看涨期权**：K上升，期权价格下降
- **看跌期权**：K上升，期权价格上升
- **影响程度**：影响程度较大
- **关系**：反向关系

**到期时间（T）**：
- **时间价值**：时间越长，时间价值越大
- **衰减**：随时间衰减
- **Theta**：时间衰减率
- **影响程度**：影响程度中等

**波动率（σ）**：
- **波动率**：波动率越高，期权价格越高
- **Vega**：波动率敏感性
- **影响程度**：影响程度较大
- **关系**：正相关关系

**无风险利率（r）**：
- **看涨期权**：r上升，期权价格上升
- **看跌期权**：r上升，期权价格下降
- **Rho**：利率敏感性
- **影响程度**：影响程度较小

**关联学习**：[[03-投资学/衍生品/期权希腊字母|期权希腊字母]]

### 3. 期权定价模型
**Black-Scholes模型**：
- **假设**：标的资产价格服从几何布朗运动
- **公式**：复杂的数学公式
- **应用**：欧式期权定价
- **局限**：假设过于理想化

**二项式模型**：
- **假设**：标的资产价格只有两种可能
- **方法**：逐步向后推导
- **应用**：美式期权定价
- **优势**：直观易懂

**蒙特卡洛模拟**：
- **方法**：随机模拟
- **应用**：复杂期权定价
- **优势**：灵活性高
- **劣势**：计算量大

## 🔄 期权定价模型详解

### 1. Black-Scholes模型
**模型假设**：
- **标的资产**：价格服从几何布朗运动
- **无风险利率**：常数
- **波动率**：常数
- **无分红**：标的资产无分红
- **无交易成本**：无交易成本
- **连续交易**：可以连续交易

**看涨期权公式**：
```
C = S × N(d1) - K × e^(-rT) × N(d2)
其中：
d1 = [ln(S/K) + (r + σ²/2)T] / (σ√T)
d2 = d1 - σ√T
N(x) = 标准正态分布累积分布函数
```

**看跌期权公式**：
```
P = K × e^(-rT) × N(-d2) - S × N(-d1)
```

**参数解释**：
- **C**：看涨期权价格
- **P**：看跌期权价格
- **S**：标的资产当前价格
- **K**：执行价格
- **r**：无风险利率
- **T**：到期时间
- **σ**：波动率

### 2. 二项式模型
**模型原理**：
- **价格变动**：标的资产价格只有两种可能
- **向上概率**：p = (e^(rΔt) - d) / (u - d)
- **向下概率**：1-p
- **价格倍数**：u = e^(σ√Δt), d = e^(-σ√Δt)

**计算步骤**：
1. **构建价格树**：构建价格变动树
2. **计算期权价值**：从到期日向前计算
3. **美式期权**：考虑提前执行
4. **最终价格**：得到期权价格

**模型优势**：
- **直观**：直观易懂
- **灵活**：可以处理美式期权
- **准确**：可以处理复杂情况
- **实用**：实际应用广泛

### 3. 蒙特卡洛模拟
**模拟方法**：
- **随机路径**：生成随机价格路径
- **多次模拟**：进行大量模拟
- **期权价值**：计算每条路径的期权价值
- **平均价值**：计算平均期权价值

**应用场景**：
- **复杂期权**：路径依赖期权
- **多资产期权**：多资产期权
- **奇异期权**：奇异期权
- **风险中性**：风险中性定价
