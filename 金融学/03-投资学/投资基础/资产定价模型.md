# 资产定价模型

## 🎯 核心概念

### 资产定价模型的定义
**资产定价模型**是用于确定金融资产合理价格的理论模型，通过分析资产的风险和收益关系来评估资产的内在价值。

> **费曼解释**：资产定价模型就像"商品定价的规则"一样。就像商品价格由供求关系决定，资产价格由风险和收益决定。就像"资产的价格标签"，告诉你这个资产值多少钱。

### 资产定价模型的基本特征
- **理论性**：基于金融理论
- **科学性**：科学的方法论
- **实用性**：指导实际应用
- **动态性**：动态调整模型

## 📊 经典资产定价模型

### 1. 资本资产定价模型（CAPM）
**模型假设**：
- **市场有效**：市场是有效的
- **投资者理性**：投资者是理性的
- **风险厌恶**：投资者风险厌恶
- **同质预期**：投资者有相同预期

**CAPM公式**：
```
E(Ri) = Rf + βi[E(Rm) - Rf]
其中：
E(Ri) = 资产i的预期收益
Rf = 无风险利率
βi = 资产i的Beta系数
E(Rm) = 市场组合的预期收益
```

**Beta系数**：
- **定义**：衡量资产相对于市场的系统性风险
- **计算**：βi = Cov(Ri, Rm) / Var(Rm)
- **含义**：β = 1表示与市场同步
- **应用**：风险度量和资产定价

**证券市场线（SML）**：
- **定义**：描述资产预期收益与Beta关系的直线
- **截距**：无风险利率
- **斜率**：市场风险溢价
- **应用**：资产定价和投资决策

**关联学习**：[[03-投资学/投资基础/投资组合理论|投资组合理论]]

### 2. 套利定价理论（APT）
**模型假设**：
- **无套利**：市场无套利机会
- **多因子**：多个影响因子
- **线性关系**：线性关系假设
- **风险中性**：风险中性定价

**APT公式**：
```
E(Ri) = Rf + βi1F1 + βi2F2 + ... + βikFk
其中：
βij = 资产i对因子j的敏感度
Fj = 因子j的风险溢价
```

**常见因子**：
- **市场因子**：市场整体表现
- **规模因子**：小盘股效应
- **价值因子**：价值股效应
- **动量因子**：价格动量

**模型优势**：
- **灵活性**：比CAPM更灵活
- **现实性**：更接近现实
- **多因子**：考虑多个因子
- **无套利**：基于套利原理

### 3. 多因子模型
**Fama-French三因子模型**：
- **市场因子**：市场超额收益
- **规模因子**：小盘股减大盘股
- **价值因子**：高账面市值比减低账面市值比
- **公式**：E(Ri) = Rf + βi[E(Rm) - Rf] + siSMB + hiHML

**Fama-French五因子模型**：
- **市场因子**：市场超额收益
- **规模因子**：小盘股减大盘股
- **价值因子**：高账面市值比减低账面市值比
- **盈利因子**：高盈利减低盈利
- **投资因子**：保守投资减激进投资

**Carhart四因子模型**：
- **市场因子**：市场超额收益
- **规模因子**：小盘股减大盘股
- **价值因子**：高账面市值比减低账面市值比
- **动量因子**：赢家组合减输家组合

## 🔄 现代资产定价模型

### 1. 消费资本资产定价模型（CCAPM）
**模型假设**：
- **消费效用**：基于消费效用
- **跨期选择**：跨期消费选择
- **风险厌恶**：相对风险厌恶
- **消费增长**：消费增长率

**CCAPM公式**：
```
E(Ri) = Rf + βi[E(Rm) - Rf]
其中：
βi = Cov(Ri, ΔC/C) / Var(ΔC/C)
ΔC/C = 消费增长率
```

**模型特点**：
- **消费导向**：基于消费
- **跨期分析**：跨期分析
- **效用函数**：效用函数
- **消费风险**：消费风险

### 2. 跨期资本资产定价模型（ICAPM）
**模型假设**：
- **多期投资**：多期投资决策
- **状态变量**：状态变量影响
- **风险溢价**：风险溢价
- **投资机会**：投资机会变化

**ICAPM公式**：
```
E(Ri) = Rf + βi[E(Rm) - Rf] + Σγij[E(Rj) - Rf]
其中：
γij = 资产i对状态变量j的敏感度
Rj = 状态变量j的收益率
```

**模型特点**：
- **跨期分析**：跨期分析
- **状态变量**：状态变量
- **投资机会**：投资机会
- **风险溢价**：风险溢价

### 3. 行为资产定价模型
**模型假设**：
- **非理性**：投资者非理性
- **认知偏差**：认知偏差
- **情绪影响**：情绪影响
- **市场异常**：市场异常

**行为因子**：
- **过度自信**：过度自信
- **代表性偏差**：代表性偏差
- **锚定偏差**：锚定偏差
- **损失厌恶**：损失厌恶

**模型特点**：
- **行为导向**：基于行为
- **心理因素**：心理因素
- **市场异常**：市场异常
- **非理性**：非理性
