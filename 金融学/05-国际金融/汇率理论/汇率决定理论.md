# 汇率决定理论

## 🎯 核心概念

### 汇率的定义
**汇率**是两种货币之间的兑换比率，表示一种货币用另一种货币表示的价格。

> **费曼解释**：汇率就像不同国家货币之间的"兑换比例"。就像1美元可以换7元人民币一样，汇率告诉我们不同货币之间的价值关系。

### 汇率的基本特征
- **相对性**：汇率是两种货币的相对价格
- **波动性**：汇率会不断变化
- **双向性**：汇率有买入价和卖出价
- **实时性**：汇率实时更新

## 📊 汇率决定理论

### 1. 购买力平价理论（PPP）
**基本观点**：汇率由两国货币的购买力决定

**绝对购买力平价**：
- **公式**：S = P/P*
- **S**：汇率（直接标价法）
- **P**：本国价格水平
- **P***：外国价格水平
- **含义**：汇率等于两国价格水平之比

**相对购买力平价**：
- **公式**：ΔS/S = π - π*
- **ΔS/S**：汇率变化率
- **π**：本国通胀率
- **π***：外国通胀率
- **含义**：汇率变化率等于两国通胀率之差

**理论假设**：
- 商品完全可贸易
- 无交易成本
- 无贸易壁垒
- 商品同质

**理论局限**：
- 忽略非贸易商品
- 忽略资本流动
- 忽略市场结构差异

### 2. 利率平价理论（IRP）
**基本观点**：汇率由两国利率差异决定

**无抛补利率平价**：
- **公式**：E(S) = S × (1 + i)/(1 + i*)
- **E(S)**：预期汇率
- **S**：即期汇率
- **i**：本国利率
- **i***：外国利率
- **含义**：预期汇率变化等于利率差异

**抛补利率平价**：
- **公式**：F = S × (1 + i)/(1 + i*)
- **F**：远期汇率
- **S**：即期汇率
- **i**：本国利率
- **i***：外国利率
- **含义**：远期汇率等于利率差异调整后的即期汇率

**理论假设**：
- 资本完全流动
- 无交易成本
- 无风险溢价
- 市场完全竞争

**理论局限**：
- 忽略风险因素
- 忽略资本管制
- 忽略市场摩擦

### 3. 国际收支理论
**基本观点**：汇率由国际收支状况决定

**国际收支平衡**：
- **经常账户**：贸易收支、服务收支、转移收支
- **资本账户**：直接投资、证券投资、其他投资
- **金融账户**：储备资产变化
- **平衡条件**：经常账户 + 资本账户 + 金融账户 = 0

**汇率调节机制**：
- **贸易收支**：汇率影响进出口
- **资本流动**：汇率影响资本流动
- **价格调节**：汇率影响价格水平
- **收入调节**：汇率影响收入水平

**理论假设**：
- 市场完全竞争
- 价格弹性充分
- 无资本管制
- 无贸易壁垒

**理论局限**：
- 忽略资本流动
- 忽略预期因素
- 忽略政策因素

### 4. 资产市场理论
**基本观点**：汇率由资产市场供求决定

**货币分析法**：
- **基本模型**：M/P = L(Y, i)
- **M**：货币供应量
- **P**：价格水平
- **L**：货币需求函数
- **Y**：收入水平
- **i**：利率水平

**资产组合分析法**：
- **基本模型**：W = M + B + B*
- **W**：总财富
- **M**：货币资产
- **B**：本国债券
- **B***：外国债券

**理论假设**：
- 资产完全替代
- 资本完全流动
- 市场完全竞争
- 无交易成本

**理论局限**：
- 忽略商品市场
- 忽略贸易因素
- 忽略政策因素
