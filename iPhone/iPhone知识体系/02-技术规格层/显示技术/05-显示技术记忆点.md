# iPhone显示技术记忆点

## 显示技术记忆概述

掌握iPhone显示技术的记忆技巧，能够快速识别产品特征，提高销售效率和客户服务质量。

## 屏幕尺寸记忆法

### 尺寸发展记忆
```
3.5英寸 → 4.7英寸 → 5.5英寸 → 5.8英寸 → 6.1英寸 → 6.7英寸 → 6.9英寸
```

### 尺寸选择记忆
- **6.1英寸**: 标准尺寸，平衡便携性和视觉体验
- **6.7英寸**: 大屏体验，视觉体验更佳
- **6.3英寸**: 专业尺寸，专业功能
- **6.9英寸**: 超大屏，极致体验

### 尺寸特点记忆
- **小屏**: 便携性好，单手操作
- **大屏**: 视觉体验好，双手操作
- **超大屏**: 极致体验，专业需求

## 分辨率记忆法

### 分辨率发展记忆
```
320×480 → 960×640 → 1334×750 → 1920×1080 → 2436×1125 → 2556×1179 → 2796×1290
```

### 像素密度记忆
- **163ppi**: 基础显示
- **326ppi**: Retina标准
- **401ppi**: 高像素密度
- **460ppi**: Super Retina XDR标准

### 显示技术记忆
- **Retina**: 326ppi，显示清晰
- **Super Retina**: 458ppi，显示更细腻
- **Super Retina XDR**: 460ppi，显示效果最佳

## 刷新率记忆法

### 刷新率发展记忆
```
60Hz → 120Hz (ProMotion)
```

### 刷新率特点记忆
- **60Hz**: 标准刷新率，日常使用
- **120Hz**: 高刷新率，专业使用
- **ProMotion**: 自适应刷新率，10Hz-120Hz

### 刷新率影响记忆
- **流畅度**: 120Hz > 60Hz
- **功耗**: 120Hz > 60Hz
- **体验**: 120Hz > 60Hz

## 显示材质记忆法

### 材质发展记忆
```
LCD → OLED
```

### 材质特点记忆
- **LCD**: 色彩准确，成本低
- **OLED**: 色彩鲜艳，对比度高
- **Super Retina XDR**: OLED技术，显示效果最佳

### 材质对比记忆
- **色彩**: OLED > LCD
- **对比度**: OLED > LCD
- **成本**: LCD > OLED
- **寿命**: LCD > OLED

## 综合记忆技巧

### 产品线记忆
- **iPhone 7-8**: LCD，60Hz，标准尺寸
- **iPhone X-13**: OLED，60Hz，全面屏
- **iPhone 14-16**: OLED，120Hz，灵动岛

### 技术特点记忆
- **标准版**: 60Hz，基础显示
- **Plus版**: 60Hz，大屏显示
- **Pro版**: 120Hz，专业显示
- **Pro Max版**: 120Hz，超大屏显示

### 销售要点记忆
- **尺寸**: 6.9英寸 > 6.7英寸 > 6.1英寸
- **分辨率**: 2796×1290 > 2556×1179
- **刷新率**: 120Hz > 60Hz
- **材质**: OLED > LCD
