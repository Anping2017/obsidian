# 基础测试

## 🎯 测试目标
- 检验基础语法知识掌握情况
- 提高基础语法应用能力
- 发现基础语法学习中的不足

## 📚 测试内容

### 1. 词性测试 (25分)

#### 1.1 名词测试 (5分)
**题目1: 名词分类**
请将下列名词分类：
```
apple, water, book, music, happiness, team, family, information, advice, news
```

**题目2: 名词单复数**
请写出下列名词的复数形式：
```
1. child → 
2. mouse → 
3. tooth → 
4. foot → 
5. man → 
```

**题目3: 名词所有格**
请将下列短语改为所有格形式：
```
1. the book of Tom → 
2. the car of my father → 
3. the house of the Smiths → 
```

#### 1.2 代词测试 (5分)
**题目1: 人称代词**
请选择正确的人称代词：
```
1. ___ am a student. (I/Me)
2. ___ is my friend. (He/Him)
3. ___ are teachers. (They/Them)
4. ___ is a book. (It/They)
5. ___ are students. (We/Us)
```

**题目2: 物主代词**
请选择正确的物主代词：
```
1. This is ___ book. (my/mine)
2. That book is ___. (your/yours)
3. ___ car is red. (His/Him)
```

#### 1.3 动词测试 (5分)
**题目1: 动词基本形式**
请写出下列动词的过去式和过去分词：
```
1. go → 
2. come → 
3. see → 
4. do → 
5. have → 
```

**题目2: 情态动词**
请选择正确的情态动词：
```
1. You ___ study hard. (can/must)
2. I ___ swim. (can/must)
3. He ___ come tomorrow. (may/must)
```

#### 1.4 形容词副词测试 (5分)
**题目1: 形容词比较级**
请写出下列形容词的比较级和最高级：
```
1. big → 
2. good → 
3. many → 
4. little → 
5. far → 
```

**题目2: 副词分类**
请将下列副词分类：
```
quickly, very, here, now, always, never, well, badly, yesterday, tomorrow
```

#### 1.5 介词连词冠词测试 (5分)
**题目1: 介词填空**
请选择正确的介词：
```
1. The book is ___ the table. (on/in/at)
2. I go to school ___ bus. (by/with/in)
3. She is good ___ English. (at/in/on)
```

**题目2: 连词选择**
请选择正确的连词：
```
1. Tom ___ Jerry are friends. (and/but/or)
2. I like apples ___ not oranges. (and/but/or)
3. You can have tea ___ coffee. (and/but/or)
```

**题目3: 冠词填空**
请选择正确的冠词：
```
1. ___ apple is red. (a/an/the)
2. ___ sun is bright. (a/an/the)
3. I have ___ book. (a/an/the)
```

### 2. 句子成分测试 (25分)

#### 2.1 基本成分识别 (15分)
**题目1: 句子成分识别**

```
1. Tom is a student.
   主语: 
   谓语: 
   表语: 

2. She reads books.
   主语: 
   谓语: 
   宾语: 

3. I gave him a book.
   主语: 
   谓语: 
   间接宾语: 
   直接宾语: 

4. The weather is very nice.
   主语: 
   谓语: 
   表语: 

5. The book is on the table.
   主语: 
   谓语: 
   表语: 
```

#### 2.2 句子结构类型 (10分)
**题目1: 句子结构识别**
请识别下列句子的结构类型：
```
1. Tom is a student. → 
2. She reads books. → 
3. I gave him a book. → 
4. The book is on the table. →
```

### 3. 时态测试 (25分)

#### 3.1 现在时态测试 (8分)
**题目1: 一般现在时**
请将下列动词改为一般现在时的正确形式：
```
1. I (go) to school every day. → 
2. She (like) apples. → 
3. They (play) football. → 
4. Tom (study) English. → 
```

**题目2: 现在进行时**
请将下列动词改为现在进行时的正确形式：
```
1. I (read) a book now. → 
2. She (write) a letter. → 
3. They (play) football. → 
```

#### 3.2 过去时态测试 (8分)
**题目1: 一般过去时**
请将下列动词改为一般过去时的正确形式：
```
1. I (go) to school yesterday. → 
2. She (like) apples. → 
3. They (play) football. → 
4. Tom (study) English. → 
```

**题目2: 过去进行时**
请将下列动词改为过去进行时的正确形式：
```
1. I (read) a book at 3 PM yesterday. → 
2. She (write) a letter when I called. → 
3. They (play) football at that time. → 
```

#### 3.3 将来时态测试 (9分)
**题目1: 一般将来时**

```

```

### 4. 语态测试 (25分)

#### 4.1 主动语态测试 (12分)

## 📊 测试评分标准

### 5. 评分标准
| 测试项目 | 满分 | 评分标准 |
|----------|------|----------|
| **词性测试** | 25分 | 名词5分 + 代词5分 + 动词5分 + 形容词副词5分 + 介词连词冠词5分 |
| **句子成分测试** | 25分 | 基本成分识别15分 + 句子结构类型10分 |
| **时态测试** | 25分 | 现在时态8分 + 过去时态8分 + 将来时态9分 |
| **语态测试** | 25分 | 主动语态12分 + 被动语态13分 |
| **总分** | 100分 | 优秀: 90分以上, 良好: 80-89分, 及格: 60-79分, 不及格: 60分以下 |

### 6. 测试要求
1. **时间限制**: 60分钟
2. **答题要求**: 答案要准确、完整
3. **评分标准**: 按评分标准严格评分
4. **成绩评定**: 按总分评定等级
