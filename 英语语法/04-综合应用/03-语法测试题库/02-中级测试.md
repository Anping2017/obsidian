# 中级测试

## 🎯 测试目标
- 检验中级语法知识掌握情况
- 提高中级语法应用能力
- 发现中级语法学习中的不足

## 📚 测试内容

### 1. 时态综合测试 (30分)

#### 1.1 现在时态群测试 (10分)

3. They (visit) the museum. →

5. We (complete) the project. → 
```

3. They (play) football for three hours. → 
4. Tom (study) English for five years. → 
5. We (wait) for the bus since 8 AM. → 
```

## 📊 测试评分标准

### 5. 评分标准
| 测试项目 | 满分 | 评分标准 |
|----------|------|----------|
| **时态综合测试** | 30分 | 现在时态群10分 + 过去时态群10分 + 将来时态群10分 |
| **语气测试** | 20分 | 陈述语气5分 + 疑问语气5分 + 祈使语气5分 + 虚拟语气5分 |
| **从句测试** | 30分 | 名词性从句15分 + 定语从句15分 |
| **状语从句测试** | 20分 | 时间状语从句5分 + 条件状语从句5分 + 原因状语从句5分 + 目的状语从句5分 |
| **总分** | 100分 | 优秀: 90分以上, 良好: 80-89分, 及格: 60-79分, 不及格: 60分以下 |

### 6. 测试要求
1. **时间限制**: 90分钟
2. **答题要求**: 答案要准确、完整
3. **评分标准**: 按评分标准严格评分
4. **成绩评定**: 按总分评定等级
