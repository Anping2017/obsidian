### 1. 高级提示词技巧
#### 练习1.1：链式提示词
**目标**：掌握链式提示词的设计和应用

**任务**：设计内容创作链式提示词

**场景**：技术博客创作流程

**链式设计**：
```
第一步：主题分析
你是一个技术专家，请分析以下主题的技术要点：
主题：{主题}
请输出：技术要点、目标受众、核心价值

第二步：大纲生成
基于第一步的分析结果，生成详细的文章大纲：
技术要点：{技术要点}
目标受众：{目标受众}
核心价值：{核心价值}
请输出：文章大纲（包含标题、章节、要点）

第三步：内容创作
基于大纲创作文章内容：
大纲：{大纲}
要求：专业但易懂，包含代码示例
请输出：完整文章内容

第四步：质量检查
检查文章质量并优化：
文章：{文章内容}
检查要点：逻辑性、准确性、可读性
请输出：优化建议和修改后的文章
```

**练习要求**：
1. 设计3个不同的链式提示词
2. 测试链式效果
3. 优化链式结构

#### 练习1.2：动态提示词
**目标**：掌握动态提示词的设计

**任务**：设计自适应提示词

**场景**：智能客服系统

**动态设计**：
```
你是一个智能客服助手，请根据用户问题类型提供相应服务。

问题类型判断：
- 如果问题包含"价格"、"费用"、"收费"，则类型为"价格咨询"
- 如果问题包含"功能"、"特性"、"介绍"，则类型为"产品介绍"
- 如果问题包含"问题"、"错误"、"故障"，则类型为"技术支持"
- 如果问题包含"退款"、"退货"、"取消"，则类型为"售后服务"
- 其他情况为"一般咨询"

根据问题类型，使用相应的回答模板：

价格咨询模板：
你是一个销售顾问，请回答价格相关问题。
提供：价格信息、优惠政策、购买建议

产品介绍模板：
你是一个产品专家，请介绍产品功能。
提供：功能特性、使用场景、优势对比

技术支持模板：
你是一个技术专家，请解决技术问题。
提供：问题分析、解决方案、预防措施

售后服务模板：
你是一个客服代表，请处理售后问题。
提供：处理流程、时间安排、联系方式

一般咨询模板：
你是一个客服助手，请回答一般问题。
提供：基本信息、相关链接、联系方式

用户问题：{用户问题}
```

**练习要求**：
1. 设计动态判断逻辑
2. 创建多个回答模板
3. 测试动态效果

```python
class PerformanceMonitor:
    def __init__(self):
        self.metrics = {}
    
    def start_timer(self, operation):
        """开始计时"""
        self.metrics[operation] = {
            'start_time': time.time(),
            'end_time': None,
            'duration': None
        }
    
    def end_timer(self, operation):
        """结束计时"""
        if operation in self.metrics:
            self.metrics[operation]['end_time'] = time.time()
            self.metrics[operation]['duration'] = \
                self.metrics[operation]['end_time'] - \
                self.metrics[operation]['start_time']
    
    def get_metrics(self):
        """获取性能指标"""
        return self.metrics
```
