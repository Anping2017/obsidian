# SEO审计模板

## 📋 概述

### 什么是SEO审计模板
SEO审计模板是一套系统化的SEO审计工具和模板，用于全面评估网站的SEO状况，识别问题并提供改进建议。

### 审计框架
```mermaid
graph TD
    A[SEO审计模板] --> B[技术SEO审计"]
    A --> C[内容SEO审计"]
    A --> D[用户体验审计"]
    A --> E[竞争分析审计"]
    A --> F[性能审计"]
    
    B --> B1[网站结构"]
    B --> B2[页面优化"]
    B --> B3[移动端优化"]
    B --> B4[安全优化"]
    
    C --> C1[内容质量"]
    C --> C2[关键词优化"]
    C --> C3[内容结构"]
    C --> C4[内容更新"]
    
    D --> D1[页面体验"]
    D --> D2[导航体验"]
    D --> D3[交互体验"]
    D --> D4[加载体验"]
    
    E --> E1[竞争对手分析"]
    E --> E2[关键词差距"]
    E --> E3[内容差距"]
    E --> E4[技术差距"]
    
    F --> F1[页面速度"]
    F --> F2[Core Web Vitals"]
    F --> F3[服务器性能"]
    F --> F4[资源优化"]
```
