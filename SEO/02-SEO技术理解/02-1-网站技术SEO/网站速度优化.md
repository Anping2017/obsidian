# 网站速度优化

> **核心理念**：网站速度是SEO和用户体验的关键因素，直接影响排名和转化率

## 🚀 网站速度概述

### 为什么网站速度重要
```mermaid
graph LR
    A[网站速度] --> B[用户体验]
    A --> C[SEO排名]
    A --> D[转化率]
    A --> E[业务收入]
    
    B --> B1[用户满意度]
    B --> B2[跳出率]
    
    C --> C1[搜索引擎排名]
    C --> C2[爬虫效率]
    
    D --> D1[购买转化]
    D --> D2[注册转化]
    
    E --> E1[收入增长]
    E --> E2[成本降低]
```

**速度影响数据**：
- **加载时间每增加1秒**：转化率下降7%
- **移动端加载时间超过3秒**：53%用户会离开
- **页面速度是Google排名因素**：直接影响SEO效果

### 速度优化目标
| 指标 | 目标值 | 重要性 | 影响 |
|------|--------|--------|------|
| **LCP（最大内容绘制）** | < 2.5秒 | 极高 | 用户感知的加载速度 |
| **FID（首次输入延迟）** | < 100ms | 极高 | 页面交互响应速度 |
| **CLS（累积布局偏移）** | < 0.1 | 极高 | 页面稳定性 |
| **TTFB（首字节时间）** | < 600ms | 高 | 服务器响应速度 |
| **FCP（首次内容绘制）** | < 1.8秒 | 高 | 内容可见时间 |

## 📊 Core Web Vitals详解

### LCP（Largest Contentful Paint）
#### 什么是LCP
**LCP = 最大内容绘制时间**

```mermaid
graph TD
    A[页面加载] --> B[最大内容元素]
    B --> C[LCP时间]
    
    B --> B1[大图片]
    B --> B2[视频]
    B --> B3[文本块]
    B --> B4[背景图片]
```

#### LCP优化策略
| 优化方法 | 具体措施 | 预期效果 | 实施难度 |
|---------|---------|---------|----------|
| **图片优化** | 压缩图片、使用WebP格式 | 减少50-80%图片大小 | 中等 |
| **CDN使用** | 部署CDN加速静态资源 | 提升30-50%加载速度 | 低 |
| **服务器优化** | 优化服务器配置 | 提升20-30%响应速度 | 中等 |
| **资源优先级** | 优先加载关键资源 | 提升用户体验 | 中等 |

### FID（First Input Delay）
#### 什么是FID
**FID = 首次输入延迟**

```mermaid
graph LR
    A[用户点击] --> B[浏览器处理]
    B --> C[页面响应]
    C --> D[FID时间]
    
    B --> B1[JavaScript执行]
    B --> B2[主线程阻塞]
    B --> B3[事件处理]
```

#### FID优化策略
| 优化方法 | 具体措施 | 预期效果 | 实施难度 |
|---------|---------|---------|----------|
| **JavaScript优化** | 代码分割、延迟加载 | 减少主线程阻塞 | 中等 |
| **第三方脚本** | 异步加载、延迟执行 | 提升交互响应 | 低 |
| **事件处理** | 优化事件监听器 | 提升响应速度 | 中等 |
| **内存管理** | 避免内存泄漏 | 提升长期性能 | 高 |

### CLS（Cumulative Layout Shift）
#### 什么是CLS
**CLS = 累积布局偏移**

```mermaid
graph TD
    A[页面加载] --> B[元素渲染]
    B --> C[布局变化]
    C --> D[CLS分数]
    
    C --> C1[图片加载]
    C --> C2[字体加载]
    C --> C3[动态内容]
    C --> C4[广告加载]
```

#### CLS优化策略
| 优化方法 | 具体措施 | 预期效果 | 实施难度 |
|---------|---------|---------|----------|
| **图片尺寸** | 设置明确的宽高 | 避免布局偏移 | 低 |
| **字体优化** | 使用font-display | 减少文字跳动 | 中等 |
| **动态内容** | 预留空间 | 避免内容跳动 | 中等 |
| **广告优化** | 固定广告位 | 减少布局影响 | 低 |

## 🖼️ 图片优化

### 图片格式选择
#### 现代图片格式
```mermaid
pie title 图片格式选择
    "WebP" : 40
    "AVIF" : 20
    "JPEG" : 25
    "PNG" : 10
    "SVG" : 5
```

| 格式 | 优势 | 劣势 | 适用场景 | 浏览器支持 |
|------|------|------|----------|-----------|
| **WebP** | 压缩率高、质量好 | 兼容性一般 | 照片、复杂图像 | 95%+ |
| **AVIF** | 压缩率最高 | 兼容性差 | 高质量图片 | 85%+ |
| **JPEG** | 兼容性好 | 压缩率一般 | 照片、复杂图像 | 100% |
| **PNG** | 支持透明 | 文件较大 | 图标、简单图像 | 100% |
| **SVG** | 矢量、可缩放 | 不适合照片 | 图标、简单图形 | 100% |
