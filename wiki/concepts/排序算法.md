# 排序算法 Sorting Algorithms

## 定义

**排序(Sorting)**是把无序序列按某一比较关系(通常是大小)重排为有序序列的过程。它是几乎所有数据处理流水线的基础步骤,也是评估[[算法]]设计能力的标准考题。

按设计思想分:
- **比较排序**:仅依赖元素间比较,理论下界 Ω(n log n)
- **非比较排序**:利用元素值范围或结构,可达 O(n)

按性能分:O(n²) 一族(教学/小数据)与 O(n log n) 一族(工程主力)。

## 核心要点

### 性能对比

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 思想 |
|---|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 | 相邻交换 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 | 找最小放前 |
| 插入 | O(n²) | O(n²) | O(1) | 稳定 | 牌式插入 |
| 希尔 | O(n^1.3) | O(n²) | O(1) | 不稳定 | 分组插入 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 | [[分治算法]] |
| 快排 | O(n log n) | O(n²) | O(log n) | 不稳定 | 分治+原地 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 不稳定 | 堆 |
| 计数 | O(n+k) | O(n+k) | O(k) | 稳定 | 桶+计数 |
| 基数 | O(d(n+k)) | - | O(n+k) | 稳定 | 按位 |
| 桶 | O(n+k) | O(n²) | O(n+k) | 稳定 | 分桶+组内排序 |

### 快速排序(Quicksort)

[[分治算法]]的代表:选 pivot → 分区(< pivot 在左,> pivot 在右)→ 递归两边。
- 平均 O(n log n),最坏 O(n²)(退化:已排序数组用首元素 pivot)
- **优化**:三路快排(处理重复元素)、随机化 pivot、小区间转插入排序
- C++ `std::sort` 用 introsort(快排+堆排+插排混合)

### 归并排序(Merge Sort)

分治:递归排两半 → 合并(双指针)。
- 严格 O(n log n)、稳定、需 O(n) 辅助空间
- 适合**链表**(无需随机访问)、**外排序**(磁盘大文件)、**并行计算**

### 堆排序(Heap Sort)

见[[堆]]。原地、不稳定,最坏 O(n log n)。但缓存不友好,工程很少用作主排序。

### 非比较排序

突破 Ω(n log n) 下界:
- **计数排序**:键范围小且为整数,O(n+k)
- **基数排序**:按位多次计数排序,适合定长字符串、整数
- **桶排序**:均匀分布数据分到 k 个桶分别排序

### 稳定性的意义

稳定排序保留相同键元素的相对顺序。多关键字排序需稳定排序(先按次要键排,再稳定地按主要键排)。SQL `ORDER BY a, b` 实现常依赖稳定性。

### 工程现实

- C++ `std::sort` = introsort(quicksort + heapsort fallback)
- C++ `std::stable_sort` = 归并 + 插入
- Java `Arrays.sort(int[])` = 双轴快排;`Arrays.sort(Object[])` = TimSort
- Python `sorted` / `list.sort()` = TimSort(归并 + 插入,利用已有有序段)

## 和其他概念的关系

排序是众多[[算法]]的预处理步骤:[[二分查找]]要求有序、[[贪心算法]]很多需先排序、滑动窗口和双指针多在有序数据上。

[[数据结构]]的排序行为不同:数组适合快排/堆排;[[链表]]适合归并;[[树]]的中序遍历自然有序。[[Hash表]]无序、[[B+树]]有序,选索引时这是关键差异。

[[数据库]]的 ORDER BY、索引构建、外部排序(归并大量小排序文件)都是排序应用。MapReduce/Spark 的 shuffle 阶段本质是分布式排序。
