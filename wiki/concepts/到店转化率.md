# 到店转化率

## 定义

到店转化率(In-store Conversion Rate)指走进店铺的客户中最终完成购买的比例,公式 **到店转化率 = 当日成交客户数 / 当日到店客户数**。它是实体零售的"漏斗下半截"——上游是客流量(选址决定),下游是客单价。同样客流的两家店,转化率差 5pt(从 15% 到 20%)就是销售额差 33%。手机店等高客单实体业,到店转化率优化空间大,是日常运营最高 ROI 的工作之一。

## 核心要点

**漏斗结构**:

```
路过门口的人(Walk-by Traffic)
    ↓ 进店率 (Entry Rate)
进店浏览(Walk-in)
    ↓ 接待率(Engagement Rate)
被店员主动接待
    ↓ 试用率(Try-out Rate)
试用 / 体验产品
    ↓ 转化率
成交
    ↓ 连带率
连带销售
```

**各层影响因素与优化**:

### 1. 进店率(Entry Rate)— 0.5-3%

- **门面设计**:橱窗陈列、招牌、灯光。
- **进入摩擦**:门是否敞开?有无台阶?玻璃门距离感?
- **店内热度**:看起来"有人"vs "空店"差距巨大。家庭式饭店原理:5-7 桌客人聚集才能不断带新客。
- **优惠展示**:门口立牌"今日限时 X 元"、"以旧换新 1500 抵扣"。
- **季节 / 时段**:雨天进店率高(避雨同时进店)、午餐前后高、晚间下降。

### 2. 接待率(Engagement Rate)— 30-70%

- **黄金 30 秒规则**:客户进店后 30 秒内必须有人主动打招呼,否则 70% 客户会在 1 分钟内离开。
- **接待话术**:不是"您好,请问需要什么"(关闭式),而是"您好,在看哪一款?"(开放式)。
- **不强势贴身**:让客户先看 1-2 分钟,再温和进入。
- **店员主动观察**:客户对哪台机器停留 > 30 秒 → 主动介绍。

### 3. 试用率(Try-out Rate)— 30-50%

- 客户摸到 / 体验过产品的成交率比仅看的高 3-5 倍(具身认知)。
- 鼓励试机、试戴、试穿——"先体验再决定"。
- 提供 demo 流程:展示拍照 / 流畅度 / 续航 / 系统差异。
- 让客户主动操作而非店员演示。

### 4. 转化率(Conversion Rate)— 10-30%

- **价值清晰**:客户已理解为什么这款适合他。
- **价格信任**:不觉得贵 / 不觉得被宰。
- **决策推动**:[[价格谈判技巧]] + 限时优惠 + [[损失厌恶]] 刺激。
- **支付便利**:多支付方式、信用分期、立刻发货。

### 5. 连带率(Attach Rate)

- 见 [[连带销售]]。

**进店转化率国际基准**:

| 业态 | 健康转化率 |
|---|---|
| **手机零售** | 15-25% |
| **奢侈品** | 5-15% |
| **快时尚服装** | 25-40% |
| **超市** | 80%+(一般进入即购买) |
| **汽车展厅** | 8-15%(决策周期长,首次到店难成交) |

**测量方法**:

- **传统**:进店登记 + 销售记录手动比对。
- **科技**:门口摄像头 + AI 计数(海康威视、商汤、旷视都有解决方案)。
- **POS 系统**:每个收银对应一个客户(但只统计成交,不知没成交人数)。
- **WiFi 探针**:经过店铺 WiFi 信号识别手机数(隐私争议下退潮)。

**优化战术 6 法**:

### 1. 门面活化

- 橱窗陈列每 2 周换一次,保持新鲜感。
- 门口"今日推荐"小黑板 / 立牌。
- 灯光设计:暖光让人放松,冷光显得专业。

### 2. 店员训练

- 每周角色扮演 / 销售剧本演练。
- 录音抽样回听,逐句打磨话术。
- 设"接待响应秒数"KPI:客户进店 30 秒内响应。

### 3. 商品陈列

- 高单价 + 视觉吸引点放在主动线。
- "卖最好"区单独标识,客户跟随大众选择(从众效应)。
- 高 Attach 配件放在结账动线。

### 4. 试机区设计

- 真机能开机 / 联网 / 用户登录测试。
- 椅子让客户能坐下试机 30+ 分钟,加深决策。
- 配 Wi-Fi 让客户测试网速。

### 5. 决策辅助

- "对比表"挂墙:不同型号差异一目了然。
- 限时活动倒计时屏(显得真实紧迫)。
- 免费咨询 / 不买也可以先看 → 降低戒备。

### 6. 离店挽留

- 客户准备走了:"不买也可以,留个微信下次活动通知"——加 [[私域流量运营]] 池。
- 出门前最后一句:"这台手机我帮您留 24 小时,您回去想想再来"——锚定与时间承诺。

**反模式**:

- 店员都站收银台聊天,客户进店没人理。
- 强势推销让客户"不进来"。
- 试机区机器没电 / 没联网 → 体验崩溃。
- 价格不公开,人人都以为很贵。
- 不主动跟进未成交客户 → 一锤子买卖。

## 和其他概念的关系

到店转化率是 [[零售门店运营]] 的核心 KPI,与 [[门店选址]](决定客流量上限)、[[销售技巧]] / [[价格谈判技巧]](决定单客户转化)、[[连带销售]](决定客单价)三位一体。

它本质上是 [[转化漏斗]] 在线下场景的实例化,与 [[漏斗优化]] 的方法论同源。优化逻辑也对应 [[转化率优化]] 的 LIFT 模型(价值 / 相关 / 清晰 / 焦虑 / 干扰 / 紧迫)。

[[O2O 全渠道营销]] 时代,到店转化率与"到店即被识别"的会员体系结合(GBP / 线下打卡)能更精细——实现"线上引流 → 到店识别 → 个性化服务 → 成交闭环"。它直接驱动 [[客户终身价值]] 提升 + [[CAC获客成本]] 摊薄(CAC 较高时必须用高转化率分摊)。
