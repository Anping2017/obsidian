# 价值链分析

## 定义

**价值链分析**(Value Chain Analysis)是 [[迈克尔·波特]] 在 1985 年《竞争优势》一书中提出的内部能力分析框架,把企业的价值创造活动拆解为**主要活动**与**支持活动**,通过逐项识别**成本驱动因素**和**差异化机会**来定位竞争优势的来源。

它的核心命题是:**竞争优势不是源自整体,而是源自价值链中具体环节的卓越运营**。

## 核心要点

### 价值链结构

**主要活动 (Primary Activities)**:产品价值的直接创造与传递

| 活动 | 内容 |
|---|---|
| 内部物流 | 原料接收、仓储、库存管理 |
| 生产运营 | 加工、装配、质量控制 |
| 外部物流 | 成品仓储、订单处理、配送 |
| 市场销售 | 营销、广告、渠道、销售队伍 |
| 服务 | 安装、培训、维修、售后 |

**支持活动 (Support Activities)**:为主要活动提供基础

| 活动 | 内容 |
|---|---|
| 企业基础设施 | 战略、财务、法务、IT |
| 人力资源管理 | 招聘、培训、薪酬、绩效 |
| 技术开发 | 研发、产品设计、流程改进 |
| 采购 | 供应商管理、原料/设备采购 |

### 竞争优势的两条路径

通过价值链分析识别两类机会:

- **成本优势**:某些活动相对竞争对手成本更低 → 支持 [[波特三种竞争战略]] 中的**成本领先**
- **差异化优势**:某些活动创造独特价值 → 支持**差异化战略**

例如:

- 沃尔玛在外部物流(交叉转运)上效率领先 → 成本优势
- Apple 在产品设计与零售体验上独特 → 差异化优势

### 链接(Linkages)与协调

价值链各活动之间存在**链接**,优化单一环节可能损害整体:

- **内部链接**:研发与生产的协同,营销与服务的反馈
- **外部链接**:与供应商、渠道商、客户的价值链整合
- **垂直链接**:[[供应链管理]] 视角下的上下游协同

### 价值系统(Value System)

把视角从单个企业扩展到产业链:**供应商价值链 → 企业价值链 → 渠道价值链 → 客户价值链**。竞争优势可来自任意环节的链接优化,这是"**价值网络**"和[[平台商业模式]]的理论起点。

### 现代发展

- **数字化价值链**:数据流贯穿所有活动,信息系统从支持活动跃升为核心
- **全球价值链 (GVC)**:活动跨国分布,中国制造 + 美国研发 + 欧洲设计是典型形态
- **服务价值链**:服务业主活动重新定义(如运营变为"服务交付"、物流变为"接触点")
- **可持续价值链**:把环境与社会责任纳入(参见 [[ESG]] 视角)

### 实施步骤

1. **识别活动**:把企业经营拆为可分析的活动单元
2. **分配成本与价值**:识别每项活动的成本占比和价值贡献
3. **基准比较**:与竞争对手价值链对比,寻找差距
4. **识别链接**:发现活动间协同机会
5. **战略决策**:决定外包、合作、自营,以及投资重点

## 和其他概念的关系

- 是 [[战略管理]] 内部能力分析的核心工具
- 输入对接 [[SWOT分析]] 的内部维度(S/W)
- 输出对接 [[波特三种竞争战略]] 的实施落地
- 与 [[波特五力模型]] 互补:五力看行业,价值链看自身
- [[供应链管理]] 是价值链思维在采购到交付环节的延伸
- [[商业模式画布]] 中"关键业务"和"核心资源"对应价值链的活动与资源
- [[运营管理]]、[[精益生产]] 围绕价值链中的生产运营环节展开
- 是 [[核心竞争力]] 理论(普拉哈拉德)的方法论补充
- [[平台商业模式]] 通过重组价值链颠覆传统线性模式
