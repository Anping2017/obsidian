# 后现代主义

## 定义

**后现代主义**(Postmodernism)既是 20 世纪 60 年代后兴起的**思想潮流**,也是覆盖**哲学、文学、艺术、建筑、电影、社会理论**的文化运动。

利奥塔(Jean-François Lyotard)1979 年《后现代状况》给出了著名定义:

> 后现代是对**宏大叙事**(grand narratives)的怀疑。

其他常见特征:
- 反对启蒙以来的"理性—进步—普遍人性"叙事
- 强调差异、碎片、地方性、身体、权力
- 解构主体、作者、原创性、客观真理的稳固性

## 核心要点

### 历史与背景

- **二战与大屠杀**:对启蒙理性能保证善行的根本动摇
- **结构主义之后**:从 Saussure 语言学到 Levi-Strauss 人类学,索绪尔的能指/所指关系被推到极致
- **冷战与去殖民化**:大叙事(自由主义 vs 共产主义)双重失效
- **大众媒体与消费社会**:鲍德里亚的"超真实"
- **数字技术**:身份、空间、文本的边界崩解

### 主要思想家与立场

| 思想家 | 核心贡献 |
|---|---|
| [[福柯]] | 权力—知识、规训、生命政治、谱系学 |
| [[德里达]] | [[解构主义]]、延异、文本无外部 |
| 利奥塔(Lyotard) | 反对宏大叙事、语言游戏的多元 |
| 鲍德里亚(Baudrillard) | 拟像与超真实、消费社会 |
| Deleuze & Guattari | 块茎、欲望机器、千高原 |
| Lyotard、Vattimo | 弱思想、信仰之解构 |
| Rorty | 美国实用主义版后现代 |
| [[巴特勒]] | 性别表演、酷儿理论 |
| Jameson | 晚期资本主义文化逻辑 |

### 几个核心命题

#### 1. 宏大叙事的瓦解
- 启蒙理性、马克思主义历史目的论、自由主义进步观、技术救赎都被怀疑
- 替代:小叙事、地方性知识、多元化

#### 2. 主体的去中心化
- 笛卡尔"我思"主体被语言、社会、欲望、权力构造
- 主体是文化效应而非本源

#### 3. 真理与权力
- 福柯:真理体制是权力关系的产物
- 没有"中立的"知识——所有知识都是权力的形态

#### 4. 文本与解构
- 德里达:"文本之外别无他物"
- 解构暴露二元对立的内在矛盾

#### 5. 差异与多元
- 拒绝"差异 = 偏离"的等级化
- 性别、种族、阶级、地理、性向等多重差异并置

#### 6. 表征的危机
- 语言不是透明的世界镜像,而是构造世界的力量

### 后现代主义的领域分支

- **哲学**:解构、反基础主义、语言转向之后的转向
- **文学**:Pynchon、Borges、卡尔维诺、村上春树
- **建筑**:Charles Jencks 命名,强调风格混搭、装饰回归
- **艺术**:挪用、互文、波普、装置
- **电影**:Tarantino、王家卫、Lynch
- **社会学**:Bauman 流动现代性
- **女性主义**:第三波女性主义、酷儿理论
- **后殖民**:Said、Bhabha、Spivak

### 与现代主义的对比

| 维度 | 现代主义 | 后现代主义 |
|---|---|---|
| 真理 | 客观、可达 | 多元、视角 |
| 主体 | 自主理性 | 去中心、被构造 |
| 历史 | 进步 | 断裂、循环 |
| 风格 | 高低分明 | 混搭、戏仿 |
| 美学 | 形式纯粹 | 装饰、引用 |
| 政治 | 解放叙事 | 微观政治 |
| 知识 | 体系化 | 碎片化 |

### 主要批评

| 批评者 | 核心质疑 |
|---|---|
| **Habermas** | 后现代放弃启蒙的解放潜能 |
| **Sokal** | 物理学家 Sokal 1996 用胡言乱语论文嘲讽后现代滥用科学术语 |
| **Chomsky** | 文风晦涩、内容稀薄 |
| **Nussbaum** | 否认普遍人性会损害弱者保护 |
| **新唯物主义** | 仅停留语言层,忽视物质 |
| **政治批评** | 过度相对主义削弱进步政治 |

## 应用场景

- **文化批评**:广告、电视、流行文化研究
- **媒体研究**:超真实、模拟、虚拟身份
- **设计**:后现代建筑、平面、UX
- **教育**:多元文化教育、批判教育学
- **管理学**:对"科学管理"普适性的质疑
- **AI 时代**:LLM 输出与"超真实"、版权与原创、合成媒体

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **相对主义滑坡** | "一切都是建构"导致无法批判 |
| **晦涩** | 文风与术语门槛过高 |
| **政治模糊** | 解构传统的解放叙事却乏建设性方案 |
| **学院化** | 与社会运动的有效对接有限 |
| **滥用** | 在科学领域错位套用 |
| **过度去中心** | 主体彻底瓦解后责任难以安置 |

## 与其他概念的关系

- 代表人物:[[福柯]]、[[德里达]]、[[巴特勒]],与 [[海德格尔]]、[[尼采]] 是思想前史
- 核心方法:[[解构主义]]
- 与 [[现象学]]、[[存在主义]]、[[实用主义]] 同期发展
- 与 [[批判理论]]、法兰克福学派形成欧陆双线
- 与 [[女性主义哲学]]、酷儿理论协同
- 反对 [[西方哲学]] 中的 [[理性主义]] 与启蒙叙事
- 与 [[科学哲学]] 中的 Feyerabend 思想呼应
- [[语言哲学]]、[[认识论]] 中"语言转向之后的转向"
- [[东方哲学]] 中的非二元思想被部分后现代论者借用
