# 成本理论

## 定义

**成本理论(Cost Theory)**:研究企业在不同产量水平下的最小总成本及其结构,分析成本变化规律以及成本与利润的关系。它由 [[生产函数]] 通过要素价格对偶导出,是企业供给决策与 [[市场结构]] 分析的直接基础。

## 核心要点

### 成本分类

| 维度 | 类型 | 含义 |
|---|---|---|
| 时间 | 短期 vs. 长期 | 是否所有要素均可变 |
| 来源 | 显性 vs. 隐性 | 是否涉及货币支付 |
| 与产量 | 固定 vs. 可变 | 是否随产量变化 |
| 性质 | 会计成本 vs. 经济成本 | 是否包含 [[稀缺性与选择#机会成本]] |

**关键区分**:经济成本 = 会计成本 + 隐性机会成本;经济利润 = 总收入 − 经济成本(可为零或负而企业仍存活,因为正常利润已计入隐性成本)。

### 短期成本曲线

```
TC = FC + VC
ATC = TC/Q = AFC + AVC
MC = dTC/dQ
```

**形态规律**:由于边际产量递减规律(见 [[生产函数]]),
- MC 曲线先减后增,呈 U 形
- AVC、ATC 也呈 U 形(因为 AVC 部分先减后增,AFC 单调递减)
- **MC 必然穿过 AVC 与 ATC 的最低点**(平均-边际关系)

### 长期成本曲线

**长期总成本(LTC)** 是所有可能短期总成本曲线的下包络。**长期平均成本(LAC)** 反映规模经济的存在:

- LAC 递减段:**规模经济**(规模报酬递增、专业化、批量折扣、技术不可分)
- LAC 平稳段:**规模中性**
- LAC 递增段:**规模不经济**(管理跨度、协调成本、官僚化)

LAC 最小处定义企业的**最小有效规模(MES)**,是产业组织分析的关键变量,决定了行业内最优企业数。

### 成本最小化

给定要素价格 (w, r) 和目标产出 Q̄,选择 (L, K) 使总成本 wL + rK 最小化。最优条件:

```
MPL/MPK = w/r  ⟺  MPL/w = MPK/r
```

直观:每元钱购买的边际产量在所有要素上相等。这与 [[消费者选择理论]] 中的最优条件结构对偶 —— 一个是消费者侧,一个是生产者侧。

### 利润最大化

```
π(Q) = TR(Q) − TC(Q)
一阶条件:MR = MC
二阶条件:dMR/dQ < dMC/dQ(MC 斜率大于 MR 斜率)
```

不同 [[市场结构]] 下 MR 不同:
- [[完全竞争市场]]:MR = P,故 P = MC
- [[垄断市场]]:MR = P(1 − 1/|Ed|) < P,故 P > MC
- [[寡头垄断]]:MR 取决于其他企业策略反应
- [[垄断竞争]]:类似垄断但长期 P = ATC

### 停产决策

短期:P ≥ AVC 时继续生产(覆盖可变成本即可,因为 FC 已沉没)。
长期:P ≥ LAC 时继续经营。
**沉没成本不应影响决策** —— 这是经济学最常被违反的常识。

## 和其他概念的关系

成本理论是 [[生产函数]] 的对偶,是 [[供给与需求]] 中供给曲线的直接来源。MC 曲线即完全竞争企业的供给曲线(P ≥ AVC 部分)。

它驱动 [[市场结构]] 的全部分析:不同结构下利润最大化条件 MR = MC 仍成立,但 MR 形式不同导致价格-产量结果差异。规模经济也直接催生自然 [[垄断市场]] 与产业政策。

跨域:[[企业价值评估]] 与 [[现金流折现模型]] 用现金流而非会计利润为估值基础,正是为了贴近经济成本概念;[[资本成本]] 中 WACC 是企业资金的机会成本,与经济成本同源;[[绩效评估]] 中经济增加值(EVA)= 营业利润 − 资本机会成本,直接体现经济成本观。

机会成本概念在 [[投资决策框架]] 中表现为折现率;在 [[资产配置]] 中表现为不同资产的 trade-off。
