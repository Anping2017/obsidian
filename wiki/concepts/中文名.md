# 中文名

## 定义

**中文名**(Chinese Name)在两个层面被使用:

1. **文化层**:中文文化语境下的人名,通常由"姓 + 名"构成,姓在前,体现宗族认同与个人寄托
2. **PKM 层**:在中文为主的知识库中作为笔记标题与文件名,直接被 [[Obsidian双向链接]] 解析

本 vault 在 [[CLAUDE]] 与 SCHEMA 约定:wiki 条目以中文为基础名,概念走 `wiki/concepts/<中文名>.md`,实体走 `wiki/entities/<中文名>.md`,主题走 `wiki/topics/<中文名>.md`。

## 核心要点

### 中文姓名的文化层

| 维度 | 内容 |
|---|---|
| **结构** | 姓 + 名(常见 1–2 字名,少数复姓) |
| **姓的来源** | 古代分封、地名、官职、避讳、改姓 |
| **名的寄托** | 美德、自然、典故、家族字辈 |
| **避讳** | 历史上对长辈/帝王名字的避用 |
| **谦称** | "鄙人""在下"等自我贬抑式表达 |
| **字号** | 古代"字""号""谥号"复合体系 |
| **现代变化** | 单字名增多、双字组合多元、汉字简化 |

### 罗马化系统

| 系统 | 用途 | 例 |
|---|---|---|
| **汉语拼音** | 中国大陆官方,1958 年起 | Mao Zedong |
| **威妥玛** | 19 世纪英美主流 | Mao Tse-tung |
| **邮政式** | 历史地名 | Peking、Tsingtao |
| **粤拼 / Jyutping** | 香港 | Wong Kar-wai |
| **注音二式** | 台湾(部分) | — |
| **通用拼音** | 台湾 2002–2008 主导 | — |

### PKM 中的中文文件名:技术议题

#### 1. 跨平台编码
- **macOS APFS**:NFD(分解形式)
- **Windows NTFS**:NFC(组合形式)
- **Linux ext4**:UTF-8 字节流,不规范化
- 同步到 Dropbox/iCloud/git 时需注意 normalization

#### 2. git 与中文文件名
- 默认 `core.quotePath=true`,中文显示为 `\xxx` 转义
- 设置 `git config core.quotePath false` 恢复 UTF-8 显示
- 大小写问题:macOS 默认不区分,需配 `core.ignorecase`

#### 3. URL 共享
- 浏览器中显示中文,实际 percent-encoding(`%E5%A5%A5%E5%8D%A1...`)
- 部分老旧 CMS 在中文 URL 下出现 404
- Obsidian Publish 与 Quartz 等都支持中文路径

#### 4. CLI 操作
- 通过 bash 脚本处理中文文件名时建议引号包裹
- 部分工具(grep/awk)需设置 LANG/LC_ALL=zh_CN.UTF-8

### vault 命名约定

本 vault 规则(见 [[CLAUDE]]):
- **概念页**:`wiki/concepts/<中文名>.md`
- **实体页**:`wiki/entities/<中文名>.md`
- **主题页**:`wiki/topics/<中文名>.md`
- **wikilink**:`[[中文名]]`,无 alias、无 path
- **唯一性**:同名歧义时加学科前缀或 disambiguator
- **罗马字保留**:专业术语(如 RAG、LLM、SOX)保留英文缩写

详见 [[文件名]] 通用议题。

### 中英混合命名

vault 中部分页面用中英混合(如 `[[Aaker品牌资产模型]]`、`[[NPS净推荐值]]`、`[[GDPR]]`):
- 当英文术语本身已是国际标准且被广泛识别 → 保留英文
- 当中文译名稳定 → 中文为主
- 当二者并行 → 用混合命名包含两层信息
- 避免:多个版本(如 [[ABC作业成本法]] 而不是同时存在 ABC、作业成本法、Activity-Based Costing)

### 中文名与全球化

- 海外华人姓名:多样化(简称、英文名、本名并用)
- 跨文化交流:在英文环境中常用 "中文名 (English Name)" 双轨
- AI 时代:LLM 普遍能正确处理中文姓名,但仍偶发音译误差

## 应用场景

- **PKM**:中文知识库的命名一致性
- **学术发表**:中文姓名罗马化的标准化(避免文献检索缺失)
- **法律文档**:身份证、护照、签证统一
- **跨文化沟通**:商务、教育、移民
- **个人品牌**:作家笔名、艺人艺名

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **罗马化不一致** | 同一人多种拼写导致检索困难 |
| **生僻字** | OCR、输入法、字库难处理 |
| **重名极多** | "张伟""王芳"千万级重复 |
| **正字法歧义** | 简繁体差异、异体字 |
| **日韩越姓名混淆** | 共享汉字但读音和文化大不同 |
| **平台兼容性** | 部分老系统对中文文件名不友好 |
