# 自我决定论

## 定义

自我决定论(Self-Determination Theory, SDT)由 Edward Deci 与 Richard Ryan 1985 年在《内在动机与人类行为的自我决定》一书中正式提出,是当代最重要的动机理论之一。SDT 主张人天生具有成长倾向,需要满足三大基本心理需求才能实现繁盛。

## 核心要点

### 1. 三大基本心理需求

| 需求 | 内涵 |
|---|---|
| **自主**(Autonomy) | 行为出于自己的选择,而非被迫 |
| **胜任**(Competence) | 感到能掌握环境、产生影响 |
| **关联**(Relatedness) | 与他人有连接、归属感 |

三需求像维生素,任一缺乏都损害动机与心理健康。

### 2. 内在动机 vs 外在动机连续体

SDT 不是简单二分,而是**自主性连续体**:

| 类型 | 调节方式 | 例子 |
|---|---|---|
| 无动机 | 不做 | 不在乎 |
| 外部调节 | 奖惩 | "我做这是为了不被罚" |
| 内摄调节 | 内化压力 | "我应该做" |
| 认同调节 | 认同价值 | "这对我重要" |
| 整合调节 | 融入自我 | "这就是我" |
| **内在动机** | 兴趣/愉悦 | "我喜欢做" |

越往右,自主性越高,质量越好。

### 3. 因果定向(Causality Orientations)
- 自主定向:倾向选择内在动机
- 控制定向:倾向回应奖惩
- 非个人定向:被动、习得性无助

## 关键发现

- **过度奖励效应**(Overjustification Effect):外在奖励削弱内在动机
- 1971 年 Deci 拼图实验:为完成拼图付钱反而降低自由时间继续玩
- 但奖励信息(认可)>奖励控制(贿赂),效果不同
- **内化**:外在动机可被内化为整合调节
- 自主支持环境促进内化,控制环境阻碍

## 主要分支理论

### 1. 认知评估理论(CET)
- 解释外在事件如何影响内在动机
- 关键:控制 vs 信息成分

### 2. 有机整合理论(OIT)
- 描述外在动机内化过程

### 3. 因果定向理论(COT)
- 个体差异

### 4. 基本心理需求理论(BPNT)
- 三需求是普遍的、跨文化的

### 5. 目标内容理论(GCT)
- 内在目标(成长、关系、贡献)>外在目标(财富、名声、外表)

### 6. 关系动机理论(RMT)
- 关系中的自主支持

## 应用领域

| 领域 | 应用 |
|---|---|
| **教育** | 自主支持型教学,学习动机最大化 |
| **组织** | 工作设计、内在激励、高绩效团队 |
| **健康** | 戒烟、运动、慢病管理依从性 |
| **运动** | 教练沟通、青少年体育 |
| **临床** | 抑郁、焦虑、行为改变 |
| **育儿** | 自主支持 vs 控制型养育 |
| **环境** | 可持续行为养成 |
| **心理治疗** | 动机访谈(MI)整合 SDT |

## 经验证据

- 涉及上千实证研究,横跨 60+ 国家
- 元分析显示三需求的预测力跨文化稳健
- 在中国、日本、印度等集体主义文化也成立(自主 = 自主选择,不是个人主义)
- 神经科学:VTA 多巴胺系统响应自主行为
- 经济学:与"软家长制"、 [[助推]] 设计互补

## 实务建议

### 工作设计
- 提供选择机会
- 解释规则的原因
- 听取反馈
- 减少不必要监控
- 任务有适度挑战
- 团队心理安全

### 教育
- 让学生选择学习路径
- 提供有意义任务
- 用信息性反馈
- 减少表扬控制
- 培养任务兴趣
