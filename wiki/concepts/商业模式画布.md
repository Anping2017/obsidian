# 商业模式画布

## 定义

**商业模式画布**(Business Model Canvas, BMC)是瑞士学者 [[亚历山大·奥斯特瓦德]](Alexander Osterwalder)2010 年在博士论文与畅销书《商业模式新生代》(*Business Model Generation*)中提出的可视化战略工具。它把任何商业模式抽象为**九个相互关联的模块**,在一张画布上完整描述企业**如何创造、传递、获取价值**。

它的核心贡献是把抽象的"商业模式"概念变成可设计、可讨论、可迭代的具象工具,广泛应用于创业、战略、咨询、教学。

## 核心要点

### 九大模块

按画布布局分为**右侧价值-客户端**与**左侧效率-资源端**:

**价值核心**(中央):

1. **价值主张 (Value Propositions)**:为何客户选择你?解决什么痛点?

**客户端**(右侧):

2. **客户细分 (Customer Segments)**:为谁创造价值?
3. **渠道通路 (Channels)**:如何接触客户?(沟通、销售、配送)
4. **客户关系 (Customer Relationships)**:如何获取、留存、扩大?

**资源端**(左侧):

5. **关键业务 (Key Activities)**:必须做哪些核心事?
6. **核心资源 (Key Resources)**:必须拥有哪些资源?(实物、知识、人力、财务)
7. **重要伙伴 (Key Partnerships)**:谁是关键合作方?

**底部财务**:

8. **收入来源 (Revenue Streams)**:如何变现?
9. **成本结构 (Cost Structure)**:主要成本是什么?

### 价值主张的四类驱动

- **功能价值**:解决问题、提供功能(如导航 App 节省时间)
- **情感价值**:身份认同、社交、自我表达(奢侈品)
- **经济价值**:省钱、增收、降低风险
- **社会价值**:环保、公益、文化

### 收入模式分类

| 类型 | 例子 |
|---|---|
| 一次性销售 | 产品销售、项目费 |
| 订阅 | SaaS、流媒体、Costco 会员 |
| 授权许可 | 专利、品牌、IP 授权 |
| 佣金抽成 | 平台、中介(参见 [[平台商业模式]]) |
| 广告 | 媒体、搜索引擎 |
| 租赁 | 房产、设备、共享经济 |
| 增值服务 | 免费增值(Freemium)模式 |

### 应用步骤

1. **现状画布**:描绘当前模式
2. **客户洞察**:基于客户档案与价值主张画布(VPC)深入理解需求
3. **要素诊断**:每模块识别强弱点
4. **创新设计**:重新组合模块,生成新模式选项
5. **可行性评估**:商业、技术、市场三方面验证
6. **实验迭代**:精益创业法快速验证

### 经典案例分析

| 公司 | 价值主张 | 关键创新 |
|---|---|---|
| Uber | 即时按需出行 | 司机网络作为核心资源 + 平台模式 |
| Spotify | 海量音乐随听 | 订阅制 + 版权伙伴 |
| Apple | 一体化体验 | 软硬件 + 生态服务 |
| 拼多多 | 极致低价 | 社交拼团 + 农产品产地直采 |
| Airbnb | 独特住宿体验 | 闲置房屋平台化 |

### 与其他工具的关系

- **价值主张画布**(VPC):商业模式画布的"放大版",把价值主张+客户细分进一步拆解为客户工作/痛点/收益与价值主张/产品服务/痛点解决方案/收益创造
- **精益画布**(Lean Canvas):由 Ash Maurya 改造,用问题/解决方案替换关键业务/合作伙伴,更适合早期创业

### 局限性

- 静态视角,缺乏竞争与生态维度
- 对"为何能赢"的回答较弱,需配合 [[波特五力模型]]、[[VRIO分析]]
- 不强调动态演化(参见动态商业模式理论)
- 易流于格式化填空,缺乏深入洞察

## 和其他概念的关系

- 是 [[战略管理]] 在战略制定层的实操工具
- 价值主张直接关联 [[STP战略]] 中的"定位"
- 客户关系与渠道与 [[市场营销]] 4P 中的渠道(Place)、促销(Promotion)对应
- 关键业务与核心资源是 [[价值链分析]] 的精炼表达
- 重要伙伴对应 [[供应链管理]] 与战略联盟视角
- 成本结构对接 [[成本会计]] 与 [[管理会计]]
- 收入来源对接 [[利润表]] 中的收入项
- 平台模式拓展形成 [[平台商业模式]]
- 与 [[商业模式创新]]、[[蓝海战略]] 共同构成创新方法论
- 财务可行性需通过 [[企业价值评估]]、[[现金流折现模型]] 验证
