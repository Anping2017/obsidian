# 小红书笔记结构

## 定义

小红书笔记结构(Xiaohongshu Note Structure)是创作者在小红书平台发布图文 / 视频笔记时遵循的优化型组成模板,目标是符合小红书推荐算法对"完播率、互动率、收藏率、转发率"的偏好,从而在初始流量池(0-500 曝光)穿越到下一级(500-5000 / 5K-50K / 50K+)。一篇笔记的传播潜力,80% 在发布前就被结构决定。

## 核心要点

**笔记五要素**:

### 1. 封面(Cover)— 决定"被点开率"

- 占用户决策权重 60%+。
- **首图必含 4 种元素中的至少 2 种**:
  - 强人物 / 自拍(亲近感)。
  - 大字标题(蓝紫黄高对比色,30+ 号粗体)。
  - 数字 / 价格 / 时间(具体性)。
  - 强对比(Before/After、列表、表情)。
- **避免**:模糊低质、纯产品图、纯文字、过白过素。
- **图文笔记**:9:16 竖屏 1080×1440;视频:9:16 竖屏 1080×1920。

### 2. 标题(Title)— 与封面双引擎

- 标题 ≤ 20 字,前 12 字尤其关键(预览只显前 12)。
- **公式**:
  - **数字 + 关键词 + 价值**:"3 天教你 X / 5 个 X 必看"。
  - **痛点 + 反转**:"以为是 X,结果是 Y"。
  - **疑问钩**:"为什么 X 都在做 Y?"。
  - **限定 + 痛点**:"30 岁前必看的 X"。
- **避免**:平铺直叙、不痛不痒、信息密度低。
- **关键词埋设**:目标搜索词放标题前部,让搜索流量也进入。

### 3. 正文(Body)

**图文笔记**:

- **黄金钩子(前 30 字)**:开场即说出"我要给你解决什么问题 / 你为什么应该看完"。
- **结构化排版**:每段 1-3 句、emoji 标记、序号 / 项目符号。
- **价值密度**:每段必须有信息量(数据 / 步骤 / 对比 / 真实经历)。
- **故事化**:主观叙述比说教更易共情(我尝试了 30 天发现...)。
- **行动指令(CTA)**:结尾引导互动("有疑问评论区告诉我"、"收藏不迷路")。

**视频笔记(34 秒黄金结构)**:

| 时段 | 任务 | 要求 |
|---|---|---|
| **0-3 秒** | 致命钩子 | 静音能看懂、5 年级能理解、强视觉冲击 |
| **3-5 秒** | 悬念铺垫 | 立即告诉观众结尾会发生什么 |
| **5-25 秒** | 核心内容 | 丝滑过渡、不说废话、每秒都重要 |
| **25-30 秒** | 反转 / 高潮 | 故事 + 反转结构 |
| **30-34 秒** | 引导互动 | "评论区聊聊"、"关注 + 收藏" |

完播率 90%+ 是最低门槛,平台算法以此判断内容是否值得推到更大流量池。

### 4. 标签(Hashtag)— 引导算法分类

- 总量 5-15 个最优,过少无暴露增量、过多权重稀释。
- **三类标签组合**:
  - **大词**(数百万笔记):#美食 #穿搭 #母婴 → 涨曝光天花板。
  - **中词**(数十万笔记):#新中式穿搭 #早 C 晚 A → 中等竞争。
  - **长尾词**(数万笔记):#上海西餐厅 #女鞋种草 → 精准流量。
- 加个性化 / 情绪 / 场景标签:#日常分享 #治愈 #好物推荐。

### 5. 评论区运营

- **置顶引导**:笔记发布即置顶一条引导评论(如自答提问)。
- **30 分钟黄金回复**:发布后第一小时所有评论必回 → 算法识别为高互动笔记。
- **引导讨论**:发起小话题让用户主动评论。

**6 大爆款笔记类型**:

1. **测评对比型**:A vs B,客观实验。
2. **教程攻略型**:N 步完成 X。
3. **避坑指南型**:你以为对其实错的。
4. **反差/反转型**:Before/After、试错-纠正。
5. **真情实感型**:故事 / 经历 / 情感共鸣。
6. **资料整理型**:N 个 X 资源汇总。

**算法对结构的偏好**:

小红书推荐机制核心 4 指标(权重递减):

1. **完播率(视频)/ 阅读完成率(图文)**
2. **互动率**(点赞 + 评论 + 收藏 + 分享 / 曝光)
3. **收藏率**(强信号,代表用户认为有用)
4. **转发率**(社交破圈)

结构的所有优化都服务于推高这 4 个指标。

**反模式**:

- **首图随便选 / 没设计**:被算法判为低质,初始流量池 0 + 流量。
- **标题平铺直叙**:CTR 低,曝光快速衰减。
- **正文废话开场**:用户 5 秒内退出,完播率崩。
- **过度营销**:笔记前几句即推销,违反平台调性。
- **滥用违禁词**:"最便宜""第一""绝对" → 限流。
- **导流外站(微信 / 二维码)**:严重违规,封号。

## 和其他概念的关系

小红书笔记结构是 [[小红书种草]] 的工程化执行——结构是"种草"的载体,内容质量是"种草"的灵魂。它与 [[内容营销]] 中的"3秒钩子原则"、[[视频营销]] 的"完播率优化"、[[文案心理学]] 的"价值前置"深度同源。

笔记结构与 [[小红书推荐机制]] 形成因果链:结构合格 → 算法识别 → 推到更大流量池 → 数据反馈 → 算法学习 → 个人账号权重提升。它依赖 [[关键词研究]] 决定标题词、[[搜索意图]] 匹配选题。

[[直播营销]] 与 [[短视频营销]] 共享"3 秒钩子"原理。在 [[全渠道营销]] 中,小红书笔记是种草环节的关键内容资产——一个爆款笔记能持续带来流量数月,远超信息流广告生命周期。在 [[KOL营销]] 与 [[KOC]] 投放中,笔记结构是检验内容质量的硬指标。
