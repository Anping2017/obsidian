# 数据分析提示模式

## 定义

数据分析提示模式是为提升[[大语言模型]]在数据探索、统计计算、图表生成、商业洞察等数据分析任务表现而设计的一套提示工程模式。它综合考虑了数据私密性、计算可靠性、结论可解释性等要求。

## 核心结构(CASE 模式)

- **C - Context**:数据来源、字段含义、样本规模、业务背景
- **A - Ask**:具体要回答的业务问题(避免开放式)
- **S - Steps**:让模型逐步思考(EDA → 统计 → 可视化 → 解释)
- **E - Evaluate**:要求模型自评结论可信度,标注假设

## 经典提示模板

```
[CONTEXT]
我有一份销售数据:
- 字段:date(YYYY-MM-DD)、product、region、revenue、quantity
- 样本量:10000 行,2024 年全年
- 业务:电商平台,大促日为 6.18 与 11.11

[ASK]
回答:哪些产品在大促日比平日转化率上升最多?

[STEPS]
1. 列出 EDA 计划
2. 给出 Pandas 代码计算
3. 解释结果(因果 vs 相关)
4. 标注潜在偏差与假设

[EVALUATE]
最后给出三档置信度(高/中/低)与理由。
```

## 关键技巧

### 强制使用 [[思维链]]

数据题要逐步推导,先 EDA 再统计,避免直接给结论。

### Code Interpreter 集成

让 LLM 写代码而非心算,准确度从 60% 升到 95%+。

### 结构化输出

要求结果以 Markdown 表格或 JSON 返回,便于下游消费。

### 私密数据处理

不上传原始数据,改为传 schema + 抽样 + 统计摘要。

## 反模式

- 让 LLM 心算大量乘除(用 Code Interpreter 替代)
- 不给字段含义直接问"分析这份数据"
- 接受第一个看起来合理的结论(应让模型质疑)
- 忽略缺失值与异常值

## 与其他概念的关系

- 与 [[思维链]]、[[Few-shot提示]] 结合提升准确性
- 与 [[工具调用提示]](Code Interpreter)是天作之合
- 与 [[反思提示]] 共同构成"先做后查"模式
- 与 [[提示词反模式]] 形成正反对照
- 是 [[AI编码助手]] 在数据科学领域的延展
