# 承诺与一致

## 定义

**承诺与一致**(Commitment and Consistency)是西奥迪尼《影响力》六大原则之一,**人一旦做出某种承诺(尤其是公开、自主、费力的承诺),会倾向以一致的行为延续之**。这一倾向源于深层的"**保持自我一致**"心理需要,是销售、政治动员、习惯设计的核心机制。

## 心理基础

### [[认知失调]] 理论

- 费斯廷格(Festinger,1957):自我矛盾产生不适
- 缓解失调的方法之一:**调整后续行为以匹配先前承诺**
- 详见 [[认知失调]]

### 自我知觉

- 人通过观察自己的行为推断自己是谁
- "**我做了 X → 我大概是支持 X 的人**"
- 持续行为强化自我定位

### 社会评价

- 一致的人被认为可信、可预测
- 反复无常的人被排斥
- 因此社会化压力培育一致性

## 关键技术

### 1. 登门槛技术(Foot-in-the-Door)

> 先小请求,再大请求

- 经典实验(Freedman & Fraser,1966):
  - 直接问家庭主妇能否在前院立"安全驾驶"大牌:接受率 17%
  - 先让她们贴一张小贴纸,两周后再问大牌:接受率 76%
- 机制:小承诺后,自我看作"**支持安全的公民**",大请求一致

### 2. 抛低球(Low-Ball)

> 先以较优条件让对方承诺,再"发现问题"提高代价

- 汽车销售经典:报低价让客户决定→签字阶段"经理说不行"→提高条件
- 客户已**心理承诺**,多倾向接受
- 即使新条件本来不会接受

### 3. 先付小定金

- 一旦付出**任何代价**,就会强化承诺
- 健身房先收年费,使用率与续约率反而上升(沉没成本+承诺)

### 4. 公开承诺

- **写下来比说出来强,公开说比私下强**
- 公众号"我要在 30 天内瘦 5 公斤" → 完成率高
- 婚礼仪式的公开宣誓
- 营销中的"宣言""倡议"

### 5. 自由选择的幻觉

- 关键:承诺要是**自主选择**的
- 强迫的承诺无效
- 这就是为何销售给"**多个选项让你选**"——选择本身是承诺

## 应用领域

### 销售

- 销售员先问"小问题"让客户说"是"
- 一系列"是" → 关键问题更难拒绝
- "**5 yes 法则**"

### 营销

- "**注册抢免费样品**" → 承诺路径
- 邮件订阅 → 内容互动 → 购买
- 详见 [[转化漏斗]]、 [[转化率优化]]、 [[消费者行为]]

### 政治动员

- 签名 → 张贴海报 → 捐款 → 做志愿者 → 入党
- 每一步加深承诺
- 极端组织招募也用此模式(警示)

### 习惯设计

- "**两分钟法则**":先做 2 分钟版本
- 写一行 → 写一段 → 写一篇
- 与 [[操作性条件反射]] 中**塑造**(shaping)结合
- 詹姆斯·克利尔《原子习惯》核心机制之一

### 心理治疗

- 来访者**写**改变计划比**说**有效
- 公开宣告(治疗师见证)增加坚持率
- 详见 [[认知行为疗法]]

### 团队管理

- 让员工**自己**说出目标 vs 上级布置
- 自主承诺的目标完成率显著高
- 详见 [[激励理论]]、 [[变革型领导]]、 [[组织行为学]]

### 谈判

- 让对方**自己说出**最低条件
- 一旦说出,他们更难退后
- 反向:警惕被诱导承诺

## 增强承诺力度的因素

| 因素 | 强化承诺 |
|---|---|
| **公开性** | 公开 > 私下 |
| **自主性** | 自由选择 > 被迫 |
| **付出代价** | 越费力越强 |
| **书面** | 写下 > 口头 |
| **重复** | 多次重申 > 一次 |

## 反向利用:撤回承诺

- 如何让人改变立场?
- 让 ta 公开做出"**新承诺**" → 转变方向
- 治疗中常用:让来访者承诺"**这周尝试新方法**"

## 与其他影响力原则的协同

### 与 [[互惠原则]]

- 互惠制造**当下**回报压力
- 承诺一致制造**长期**延续压力
- 二者结合更强

### 与 [[社会证明]]

- 公开承诺利用了社会证明
- "我都说了 yes,周围人都看到"

### 与 [[损失厌恶]]

- 撤回承诺感觉是损失
- 双倍约束力

## 抵抗策略

### 觉察

- 警觉销售员的"小请求"
- "为什么对方让我先做这个?"

### "**初始决策的检验**"

- 西奥迪尼建议:**回到最初决策时**问自己,如果当时知道现在条件,是否还会同意
- 如果不会,就"**重新校准**"

### 撤回承诺的勇气

- "**我改变主意了**"是健康
- 反对沉没成本谬误(详见 [[沉没成本]])
- 与 [[第一性原理]] 思维结合

### 文化:错误反复的代价

- 集体主义文化把"反复"看作**不值得信**
- 个人主义文化更宽容
- 但都需"**审慎初始承诺**"

## 在 [[多元思维模型|芒格多元思维模型]] 中

- 芒格"**误判心理学清单**"中重要倾向
- 称为"**坚持—一致性倾向**"(Consistency Tendency)
- 投资警示:
  - 公开看好某股 → 难以止损
  - "**避免做出公开承诺,除非你已仔细思考**"
- 详见 [[芒格]]、 [[芒格误判心理学清单]]、 [[多元思维模型]]

## 黑暗面:邪教与极端组织

- 渐进式承诺的极端应用
- 从小义务 → 中等行为 → 极端行为
- 离开成本不断累积
- 这是邪教控制的核心机制
