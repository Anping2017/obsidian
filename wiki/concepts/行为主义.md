# 行为主义

## 定义

**行为主义**(Behaviorism)是 20 世纪上半叶占据美国心理学主流地位的流派。其核心主张:**心理学应以可观察、可测量的行为为唯一研究对象**,排斥意识、潜意识等不可直接观察的内在心理状态。代表人物有**华生、巴甫洛夫、斯金纳、桑代克**。它把心理学塑造成"硬科学",同时也因其极端化招致批评。

## 核心要点

### 方法论原则

- **只研究可观察的行为**:输入(刺激 S)→ 输出(反应 R)
- 排斥内省法、意识研究
- 强调**实验、测量、控制**
- 跨物种研究:动物行为可推及人(老鼠、鸽子、狗)

### 三大里程碑研究

#### 1. 经典条件反射(巴甫洛夫,1903)

- **狗实验**:铃声(中性刺激)+ 食物(无条件刺激)→ 唾液(无条件反应)
- 多次配对后,铃声单独出现就引起唾液(条件反应)
- 关键概念:**习得、消退、自发恢复、泛化、辨别**

#### 2. 行为主义宣言(华生,1913)

- "**给我十二个健康婴儿,我可以训练他们成为任何一种我所选择的专家**"
- 著名的**小阿尔伯特实验**(1920):制造婴儿对白鼠的恐惧
- 将巴甫洛夫框架推广到情感与人格

#### 3. 操作条件反射(斯金纳,1938)

- **斯金纳箱**:鸽子按键得食 → 行为被强化
- **强化(reinforcement)**:正强化、负强化
- **惩罚(punishment)**:正惩罚、负惩罚
- **强化时间表**:连续、固定间隔、可变间隔等
- 反对自由意志,主张"行为是塑造的产物"

### 学习的核心机制

| 机制 | 说明 | 代表 |
|---|---|---|
| 经典条件反射 | 刺激—刺激联结 | 巴甫洛夫 |
| 操作条件反射 | 行为—结果联结 | 斯金纳 |
| 试错学习 | 通过失败学到 | 桑代克 |
| 模仿学习 | 后期班杜拉社会学习,跨越行为主义 | 班杜拉 |

### 关键概念

- **强化**:增加行为概率
- **消退**:不强化导致行为减少
- **泛化**:相似刺激引起相同反应
- **辨别**:区分相似刺激
- **塑造(shaping)**:逐步逼近目标行为

### 与精神分析的对立

| 议题 | 行为主义 | [[精神分析]] |
|---|---|---|
| 研究对象 | 可观察行为 | 潜意识 |
| 方法 | 实验、控制 | 自由联想、梦 |
| 治疗 | 行为疗法 | 解释、移情 |
| 人性观 | 白板/被塑造 | 内驱力冲突 |
| 核心人物 | 华生、斯金纳 | 弗洛伊德、荣格 |

详见 [[精神分析]]、 [[弗洛伊德]]。

### 行为治疗

- **系统脱敏**:逐步暴露+放松,治焦虑
- **厌恶疗法**:把不良行为与不愉快刺激配对
- **代币法**(token economy):正强化代币,可兑换
- **应用行为分析(ABA)**:用于自闭症儿童干预

### 极端行为主义的衰落

- 50-60 年代认知革命兴起,**乔姆斯基对斯金纳《语言行为》的著名批判**(1959):语言不能单靠强化习得
- **班杜拉**的社会学习理论:认知中介、观察学习
- **认知主义**逐渐取代极端行为主义

### 现代影响

- 学术上转化为**认知行为疗法(CBT)**(详见 [[认知行为疗法]])
- 应用领域仍广泛:教育(行为管理)、临床(暴露疗法)、组织(强化设计)、动物训练
- **应用行为分析**在自闭症、ADHD 等仍是主流干预
- 强化理论在 [[激励理论]]、 [[组织行为学]] 中持续
- 详见 [[激励理论]]

### 行为主义与 [[人工智能]]

- 早期 AI 与行为主义共享"输入—输出"模型
- 强化学习(详见 [[强化学习]])直接源自斯金纳框架
- 现代 [[RLHF]] 是把人类反馈当强化信号

## 和其他概念的关系

- 创始人:华生、巴甫洛夫、斯金纳、桑代克
- 与 [[精神分析]] 是 20 世纪心理学两大对立流派
- 与 [[认知主义]] 在 60 年代后形成竞争(并发展为认知行为疗法)
- 与 [[人本主义心理学]] 形成"第三势力"对立
- 与 [[激励理论]] 直接相承
- 与 [[强化学习]]、 [[人工智能]] 早期模型血缘
- 与 [[认知行为疗法]] 现代延伸
- 与 [[消费者行为]]、 [[营销心理学]] 中"刺激—反应"模型
- 与 [[操作性条件反射]]、 [[经典条件反射]] 是其支柱概念
- 与 [[班杜拉]]、 [[斯金纳]]、 [[巴甫洛夫]] 的工作直接相关
- 历史定位:[[心理学]] 流派之第二大势力(在精神分析之后)
