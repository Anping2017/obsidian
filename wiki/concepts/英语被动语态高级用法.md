# 英语被动语态高级用法

## 定义

**被动语态**(Passive Voice)由 **be + 过去分词**构成,核心功能是把"动作的承受者"提到主语位置,而把"动作的发出者"省略或后置。被动语态在英语写作中的频率远高于汉语,是英语**信息焦点重组**的核心工具。本词条聚焦于其**高级用法与微妙之处**——基本概念详见 [[英语语态系统]]。

## 核心要点

### 各时态的被动形式

| 时态 | 主动 | 被动 |
|---|---|---|
| 一般现在 | does / do | is / are done |
| 一般过去 | did | was / were done |
| 一般将来 | will do | will be done |
| 现在进行 | is doing | is being done |
| 过去进行 | was doing | was being done |
| 现在完成 | has done | has been done |
| 过去完成 | had done | had been done |
| 完成进行 | has been doing | (罕用,常改主动) |
| 情态 + 不定式 | must do | must be done |
| 情态 + 完成 | must have done | must have been done |

注意:**不存在完成进行被动**(*has been being done* 太繁琐,通常重写)。

### 双宾语动词的被动

主动:S + V + IO + DO(He gave me a book)

可变两种被动:
- *I was given a book*(IO 作主语,更常见)
- *A book was given to me*(DO 作主语,正式)

类似动词:give, send, show, tell, offer, lend, teach, pay, promise...

### 含介词的动词整体被动化

把"动词 + 介词"视为整体动词被动化:

- *The boy laughed at the clown* → *The clown was laughed at by the boy*.
- *They listened to the music* → *The music was listened to*.
- *The plan must be carried out* / *The matter is being looked into*.

不能丢掉介词:
- ✗ The clown was laughed by the boy.

### 含名词的动词短语整体被动化

某些动词 + 名词 + 介词组合:

- *take care of* → *be taken care of*
- *make use of* → *be made use of*
- *put an end to* → *be put an end to*

例:*The patient was well taken care of by the nurses.*

### get-passive(动态被动)

**get + 过去分词** 替代 be + 过去分词:

- *He got promoted last year.*(获得提升)
- *They got married in 2020.*(结婚)
- *My phone got stolen.*(被偷,带"事件 / 不幸"语气)

**get-passive 特点**:
- 更口语化、随意
- 强调结果或事件性
- 常含"突然 / 意外 / 抱怨"语气
- 不能直接接 by 短语(get-passive 重在动作发生)

### 不及物动词的"伪被动"

某些不及物动词无被动语态,但相似形式可表"被...":

- *The book sells well*(畅销——主动形式被动义)
- *The cake tastes good*
- *Eggs cook quickly.*

这是"中动语态(middle voice)",虽形主动,意义带被动。常与 well, easily, quickly 等副词搭配。

### 状态被动 vs 动作被动

**动作被动(动作发生)**:被动语态本身
- *The window was broken by the boy.*(动作:有人打破)

**状态被动(描述结果)**:形态相同,但 was/were 后是表语形容词
- *The window was broken*(状态:窗子坏了,不强调谁打破)

英语中两者形式相同,需根据语境判断。

### 隐含主体(Agentless Passive)

省略 by + 主体的被动,用于:

1. **主体未知**:*The car has been stolen.*
2. **主体不重要**:*Coffee is grown in Brazil.*
3. **主体明显**:*She was arrested.*(警察,不必说)
4. **泛指**:*English is spoken worldwide.*
5. **回避责任**:*Mistakes were made.*(经典官腔)

学术写作中**主动 vs 被动选择**:
- 描述方法:*Samples were collected*(被动,作者不重要)
- 提出主张:*We argue that...*(主动,强调贡献)

### 情态动词的被动

**情态 + be + 过去分词**:
- *This must be done immediately.*
- *The work can be finished today.*
- *You should be told the truth.*

**情态 + have been + 过去分词**(过去推测):
- *He must have been informed yesterday.*(他过去一定被告知)
- *The decision should have been made earlier.*

### 非谓语动词的被动

#### 不定式被动

- *to be done*(一般)/ *to have been done*(完成)
- *I want to be informed*(想被告知)
- *He is said to have been wronged*(据说他被冤枉了)

#### 动名词被动

- *being done* / *having been done*
- *I dislike being criticized.*
- *I appreciate having been invited.*

#### 分词被动

- 现在分词被动:*being done*
- 过去分词:本身就是被动 / 完成 → *the broken vase*

### 双重被动(罕见但可)

**get + sb + done**:让某事被做(causative)
- *I got my car repaired.*(让人修了)
- *She had her hair cut.*(去理发)

注意:这是 have / get + 名词 + 过去分词,虽然形态像被动,功能更像"使役 + 被动"。

### 主动 vs 被动的选择原则

**用被动的情况**:
- 强调动作承受者
- 主体未知 / 不重要 / 想隐藏
- 学术 / 正式风格
- 信息流"旧→新"重排

**用主动的情况**:
- 强调动作发出者
- 风格直接、简洁、有力
- 一般口语、新闻
- 强调责任归属

**避免过度被动**:写作经典建议(Strunk & White)是**多用主动**,被动用于特定目的。

### 中文学习者常见问题

#### 1. 主动形式被动义未识别

- ✓ The book reads well.(中动语态)
- 学生易写为 The book is read well(错或不自然)

#### 2. 不及物动词误用被动

- ✗ The accident was happened. → ✓ The accident happened.
- happen, occur, take place, exist, appear, disappear 是不及物动词,无被动。

#### 3. 短语动词漏介词

- ✗ The plan was carried. → ✓ The plan was carried out.

#### 4. by 在不同语境的差别

by + 人(动作发出者)vs by + 时间(时间到... before):
- *The book was written by Tom.*
- *The book will be finished by Monday.*(到周一前完成)

#### 5. 双宾语主动 vs 被动

- *He gave me a book*(主动)
- *I was given a book*(被动,中国学生易混)
- ✗ *Me was given*(语法错)

### 英汉差异

汉语少用形式被动,常用主动表被动义:
- *书被我看完了*(可,但少)
- *我把书看完了*(常)
- *书我看完了*(常)

英语必须用形式被动来精准表达:
- *The book was finished by me.*

## 和其他概念的关系
