# Odoo PoS 销售点

## 定义

Odoo PoS(Point of Sale)是 Odoo 的销售点(收银)模块,把传统 POS 收银机的功能搬到浏览器中——服务员/收银员在门店触屏设备上录单、结算、打印小票,数据实时(或离线后批量)同步到 Odoo ERP。

它的核心差异化在 **ERP 原生集成**:每笔门店销售即时反映在库存(扣减)、会计(收入入账)、CRM(客户消费记录)中,无需第三方对账,这是独立 POS 系统(Square、美团美味不见、有赞)需通过 API 才能做到的。

## 核心功能

**收银界面**

- 触屏友好的网格商品布局(图片 + 名称 + 价格)
- 分类切换、搜索
- 多种支付:现金、卡、电子钱包、礼品卡、代金券
- 折扣、促销自动应用
- 退货、修改、暂存订单

**多支付方式**

- 现金:钱箱开关、找零计算
- 银行卡:接 Stripe Terminal、Adyen Terminal、Verifone
- 电子钱包:微信支付、支付宝(中国本地)、Apple Pay、Google Pay
- 礼品卡、积分抵扣
- 多种货币

**离线模式**

网络断开后:
- POS 仍可正常收银(本地浏览器存储)
- 网络恢复后自动同步订单到服务器
- 关键设计,门店稳定性必须

**库存联动**

- 销售即时扣减库存
- 缺货提示、备选品推荐
- 多仓位(柜台库存、后仓)

**会计联动**

- 自动生成会计分录(收入 / 增值税 / 现金)
- 日终结账(Close Session)汇总
- 现金对账、银行存款

**CRM 联动**

- 顾客查询(电话、邮箱、积分卡)
- 历史消费、首选品
- 积分累计、生日提醒

## 行业场景适配

**零售门店**

- 服装、珠宝、超市、便利店
- 条码扫描、商品信息查询
- 会员系统、积分

**餐饮(Restaurant 子模块)**

- 桌台管理(Floor Plan)
- 菜单、备注、加料
- 厨房打印(Kitchen Printer 或 Display)
- 拼桌、合并账单、分摊
- 服务员账户、佣金

**服务行业**

- 美容、美发、按摩
- 预约管理、技师选择
- 套餐、储值卡、次卡

**移动 / 弹出店**

- 临时活动、市集摊位
- 平板 POS 全离线运转

## 硬件支持

**官方支持的 PoS Box**

Odoo PoS Box(基于 Raspberry Pi)桥接以下硬件:
- 收据打印机(EPSON、Star、Citizen)
- 钱箱
- 条码扫描器
- 标签秤

**iOS / Android Tablet**

可作为 PoS 终端,蓝牙连打印机和钱箱。

**自建 IoT**

Odoo 提供 IoT Box 接驳工业打印机、扫码枪、秤,统一管理。

## 多店与连锁

**多店架构**

每个门店:
- 独立 PoS Session(每天开关账)
- 独立现金账户
- 独立库存仓库
- 共享商品、价格表、客户

总部可:
- 跨店看销售报表
- 跨店调拨
- 统一活动促销
- 统一会员体系

## 离线模式架构

**前端浏览器**

- IndexedDB 存离线订单
- 本地持有商品、价格、客户副本(启动时下载)
- 网络断开后所有操作本地完成

**冲突解决**

网络恢复后:
- 顺序同步离线订单到服务器
- 冲突(库存不足)在服务端处理为问题订单(human review)
- 价格变化:以下单时价格为准

**与服务器实时同步**

- 在线时,POS 与 Odoo 服务器 WebSocket 长连接
- 服务器更新(价格变更)实时推送到 POS
- 多 POS 终端共享 Session 时,订单实时可见

## 与同类系统对比

| 维度 | Odoo PoS | Square | Shopify POS | 美团美味不见 |
|---|---|---|---|---|
| ERP 集成 | 原生 | API | API | 仅餐饮 |
| 离线 | 支持 | 部分 | 部分 | 限 |
| 自部署 | 是 | 否 | 否 | 否 |
| 月费 | Odoo 订阅内 | $0 + 交易费 | $0-$50 + 交易费 | 月费/分润 |
| 行业 | 通用 | 零售/餐饮 | 零售为主 | 餐饮 |

## 局限

- 触屏 UX 不如原生 POS App(部分操作需多次点击)
- 大型连锁(数百店)需高性能 Odoo 部署 + IoT 中心
- 中国本地特色(发票、税务集成)需第三方模块
- 报表实时性受 Odoo Workers 限制
- 现金管理在多人轮班下需额外流程
