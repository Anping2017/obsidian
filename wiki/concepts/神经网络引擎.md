# 神经网络引擎 Neural Engine

## 定义

神经网络引擎(Apple Neural Engine, ANE)是 Apple 自研芯片中专门用于加速**机器学习推理**的硬件单元,首发于 2017 年的 [[A系列芯片|A11 Bionic]]。它与 CPU、GPU 并列为芯片三大计算单元,通过定制化的矩阵乘加电路(MAC)在功耗极低的前提下完成神经网络推理。

ANE 是「[[端侧AI]]」战略的核心——把 AI 推理放在设备本地而非云端,既保护用户隐私,又降低延迟与流量成本。

## 核心要点

### 性能演进

| 芯片 | 年份 | TOPS(每秒万亿次操作) |
|---|---|---|
| A11 | 2017 | 0.6 |
| A12 | 2018 | 5 |
| A13 | 2019 | 6 |
| A14 / M1 | 2020 | 11 |
| A15 / M1 Pro/Max | 2021 | 15.8 |
| A16 / M2 | 2022 | 17 |
| A17 Pro / M3 | 2023 | 35 |
| A18 Pro / M4 | 2024 | 38 |

ANE 用极低的功耗(典型 1~2W)实现这些算力,是 GPU 推理同等任务功耗的 1/10。

### 设计原理

ANE 是**专用加速器(ASIC)**,牺牲通用性换取效率:

- 大量并行的乘加单元(MAC)阵列
- 针对常见层(卷积、全连接、注意力)优化数据流
- 8 位/16 位整型量化以提升吞吐
- 与 CPU/GPU 共享统一内存,减少数据搬运

开发者通过 **Core ML** 框架使用 ANE,系统会自动决定将操作分发到 CPU/GPU/ANE,开发者无需手动调度。

### 支撑的关键功能

| 功能 | 用途 |
|---|---|
| Face ID | 3D 点阵 → 深度图 → 神经网络识别 |
| 相机智能 HDR、夜景 | 多帧合成、降噪、人像分割 |
| Live Text | 图像 OCR + 翻译 |
| Visual Look Up | 物体识别 |
| Siri 语音识别(本地) | A12 起本地化部分语音指令 |
| 图像/视频分析 | Photos 应用的人脸聚类、场景搜索 |
| Apple Intelligence(2024+) | 端侧 30 亿参数 LLM 推理 |

### 与 GPU 的分工

- **GPU**:适合训练、批量并行、灵活算子,显存与算力大但功耗高
- **ANE**:适合推理、固定算子、低功耗,峰值算力高但灵活性低
- **CPU**:适合控制流、串行依赖、小量数据

## 和其他概念的关系

神经网络引擎是 [[端侧AI]] 的硬件基础,与 [[Siri与Apple Intelligence|Apple Intelligence]]、[[Siri与Apple Intelligence|Core ML]] 一同支撑 Apple 的「私有 AI」战略。它代表了 [[AI 加速器]] 的一类思路——专用 ASIC,与 NVIDIA 通用 GPU、Google TPU、Cerebras Wafer-Scale 等形成并行路线。

ANE 的存在塑造了 iOS 生态的 AI 能力上限:[[Face ID]]、[[相机系统]]、[[Photos]]、[[Live Text]] 等功能都构建于其之上。第三方 App 通过 [[Siri与Apple Intelligence|Core ML]] 利用 ANE,出现了大量端侧 OCR、图像增强、语音处理 App。

理解 ANE 也是理解 [[Apple Silicon]] 哲学的一把钥匙:与 Intel/AMD 通用 CPU + 独立 GPU 不同,Apple 把 CPU、GPU、ANE、ISP 集成在同一硅片,共享内存,以系统级协同换取效率。这与 [[NVIDIA Jetson]]、[[Qualcomm Hexagon]] 等竞争对手有相似的设计哲学。

[[隐私计算]] 与 [[联邦学习]] 是 ANE 价值的延伸——本地推理与可选的差分隐私同步使得「学习而不上传数据」成为可能。
