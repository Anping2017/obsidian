# 期权定价

## 定义

**期权**(Option)是一种合约,买方支付权利金后获得"以约定价格买/卖标的资产"的权利(无义务)。**期权定价**研究在无套利前提下,合理的权利金应该是多少。

## 核心要点

### 期权类型

- **看涨期权(Call)**:买入权
- **看跌期权(Put)**:卖出权
- **欧式**:仅到期日可执行
- **美式**:任何时点可执行

### Black-Scholes 模型(1973)

最具影响力的连续时间期权定价公式,五个输入:
- **S**:标的当前价格
- **K**:行权价
- **T**:到期时间
- **σ**:波动率
- **r**:无风险利率

```
C = S·N(d₁) − K·e^(-rT)·N(d₂)
```

核心思想:**用标的资产 + 无风险债构造复制组合**,期权价格必须等于复制成本(否则有套利机会)。模型假设包括股价对数正态、波动率恒定、无套利、无交易成本等。

### 二叉树模型

离散版本,通过逐步向后归纳定价。可处理美式期权、复杂结构。

### Greeks(希腊字母)

衡量期权价格对输入参数的敏感度,是风险管理核心工具:

| 字母 | 含义 |
|---|---|
| **Δ Delta** | 对标的价格的敏感度 |
| **Γ Gamma** | Delta 对标的价格的敏感度(凸性) |
| **ν Vega** | 对波动率的敏感度 |
| **Θ Theta** | 时间衰减(每天损失多少价值) |
| **ρ Rho** | 对利率的敏感度 |

### 隐含波动率

由市场期权价格反推的 σ —— 反映市场对未来波动的预期。"波动率微笑"是实证观察:深度价内/价外的隐含波动率高于平值,违反 BS 的恒定 σ 假设。
