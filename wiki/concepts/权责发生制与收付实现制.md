# 权责发生制与收付实现制

## 定义

**权责发生制**(Accrual Basis)与**收付实现制**(Cash Basis)是会计确认收入与费用的两种基本方法,核心区别在于**确认时点的标准**:

- **权责发生制**:按经济实质——权利产生 / 义务发生时确认,不论现金是否流动
- **收付实现制**:按现金流动——实际收钱时确认收入,实际付钱时确认费用

权责发生制是现代财务会计的主流;收付实现制仅适用于政府部分预算会计、小型个体经营。

## 核心要点

### 核心差异图示

```
                    现金流入 / 流出
                       ↓                  
权责发生制:    经济权利产生 → 收入确认(可能比现金早或晚)
收付实现制:    现金实际收付 → 收入费用确认(总是与现金同步)
```

### 简明对比

| 维度 | 权责发生制 | 收付实现制 |
|---|---|---|
| 确认依据 | 经济权利与义务 | 现金收付 |
| 收入确认 | 提供商品 / 服务时 | 收到现金时 |
| 费用确认 | 资源耗用时 | 支付现金时 |
| 应计项目 | 应收应付存在 | 不存在应收应付 |
| 折旧摊销 | 按使用期间分摊 | 不分摊或按现金支出确认 |
| 信息质量 | 反映经济实质 | 反映现金状况 |
| 法定要求 | 企业准则要求 | 政府预算会计、小微纳税人 |

### 同一交易的不同处理

**例**:9 月 1 日提供咨询服务,合同价 100,000,客户 12 月 1 日付款。

```
权责发生制:
9月1日:
  借:应收账款           100,000
     贷:主营业务收入    100,000

12月1日:
  借:银行存款           100,000
     贷:应收账款        100,000

→ 9月利润表已确认收入 100,000

收付实现制:
9月1日:不做账(无现金流动)
12月1日:
  借:库存现金           100,000
     贷:咨询收入        100,000

→ 12月才确认收入
```

### 权责发生制的四大原则

#### 1. 配比原则(Matching Principle)

成本应与其所产生的收入在同一会计期间确认:
- 销货成本与销售收入配比
- 折旧与设备产生的收益配比

#### 2. 收入实现原则(Realization Principle)

收入在"商品所有权转移、服务履行完成"时确认,不必等收钱。
现已演化为 IFRS 15 / ASC 606 的[[收入确认五步法]]。

#### 3. 谨慎性原则

预计可能损失提前确认(坏账准备、跌价准备),预计收益不提前确认。

#### 4. 期间配比

通过期末调整把跨期项目分配到正确会计期间。

### 期末调整(权责发生制特有)

| 调整类型 | 含义 | 例 |
|---|---|---|
| **应计收入** | 已实现但未收钱 | 应收利息、应收租金 |
| **应计费用** | 已发生但未付钱 | 应付利息、应付工资 |
| **递延收入** | 已收钱但未实现 | 预收账款 |
| **递延费用** | 已付钱但未发生 | 预付保险费 |

收付实现制不需要这些调整,这是其简单性的来源,也是信息质量低的代价。

### 现金流量表的协调

权责发生制下编制 [[现金流量表]] 需要从净利润倒推现金流(间接法):

```
净利润                  100,000
+ 折旧摊销               20,000(非现金)
- 应收账款增加          -15,000(收入未收)
+ 应付账款增加           10,000(费用未付)
+/- 其他营运资本变化
= 经营活动现金流        115,000
```

这就是为什么权责发生制的"利润"不等于现金流。

### 为什么权责发生制成为主流

- **经济实质优于现金时点**:反映企业真实经营成果
- **跨期匹配**:决策更准确(投资人、股东、债权人)
- **可比性**:同一会计期间业务可对比
- **趋势可识别**:连续期间真实业绩可比

收付实现制虽简单,但:
- 利润可被提前/延后付款操纵
- 不反映赊销与赊购实质
- 长期资产支出无法分摊到受益期间

### 适用情形

| 主体 | 用法 |
|---|---|
| 上市公司、企业 | 权责发生制(强制) |
| 政府(预算会计) | 收付实现制为主,逐步引入权责发生制(政府会计准则改革) |
| 小型个体户 | 收付实现制(简便) |
| 个税申报 | 多数情况下收付实现制 |
| 公益基金 | 因捐赠不可预测,常用收付实现制 |

### 现代修正版

#### 修正的权责发生制

部分政府引入"修正的权责发生制":对长期资产用权责发生制(摊销),对短期项目用收付实现制,折中简化。

#### 修正的收付实现制

把"近期内将收/付"的款项提前确认,弥补纯现金制的滞后性。

### 与税法的差异

很多税法采用"修正的权责发生制":
- 收入按合同履行确认(类似权责发生制)
- 部分费用税前扣除按实际支付(类似收付实现制)

会计与税法差异 → [[递延所得税]] 的来源之一。

## 和其他概念的关系

- 是 [[会计假设]] 中的重要假设之一
- 是 [[会计循环]] 期末调整的根本依据
- 决定 [[利润表]] 与 [[现金流量表]] 数据差异的主因
- 与 [[收入确认五步法]](IFRS 15)在确认时点判断上一致
- 影响 [[财务报表分析]] 中"利润 vs 现金流"质量评估
- 与 [[递延所得税]] 来源的"暂时性差异"密切相关
- [[审计]] 风险评估时,不当的应计项目是常见舞弊手段
- 与 [[国际财务报告准则]] 概念框架一致
