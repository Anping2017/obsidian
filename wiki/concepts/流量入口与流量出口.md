# 流量入口与流量出口

## 定义

**流量入口(Traffic Source / Inlet)** 与 **流量出口(Traffic Sink / Outlet)** 是分析数字业态(网站、APP、直播间、电商店铺)的 **流量生态完整视角**:

- **流量入口**:用户从哪里进来(SEO、Ads、社交、邮件、直接访问、推荐)
- **流量出口**:用户离开后去了哪里(内部跳转到下游页、外链、关闭、跨平台)

只看入口忽略出口会错失整个用户旅程的视角。

## 核心要点

### 1. 主要流量入口分类

#### a) 自然入口(Organic)
- **自然搜索(Organic Search)**:Google/百度/Bing 等搜索引擎
- **直接访问(Direct)**:输入网址或书签
- **自然推荐(Referral)**:其他网站链接

#### b) 付费入口(Paid)
- **搜索广告(Paid Search / SEM)**
- **展示广告(Display)**
- **社交广告**
- **联盟营销(Affiliate)**
- **再营销(Retargeting)**

#### c) 社交入口(Social)
- **微博、Twitter、LinkedIn**
- **抖音 / TikTok**
- **YouTube / Bilibili**
- **小红书 / Instagram**

#### d) 自有渠道(Owned)
- **邮件营销**
- **APP 推送**
- **微信公众号 / 视频号**
- **会员体系**

#### e) 线下导流
- **二维码**
- **包装卡片**
- **门店触达**

### 2. 主要流量出口分类

#### a) 内部跳转(Internal)
- 站内点击下一页
- 加入购物车 → 结算 → 完成
- 内容深度浏览

这是最理想的"出口" — 实质上是 [[漏斗分析]] 的下游。

#### b) 外部跳转(External Outbound)
- 联盟外链
- 引导到 APP 下载页
- 引到客服微信
- 跨域跳转其他业务

#### c) 离开(Exit)
- 关闭浏览器/App
- 后退按钮
- 长时间不操作

这是 [[跳出率]] 与 Exit Rate 的来源。

#### d) 转化退出(Conversion Exit)
- 完成购买后离开
- 完成填表后离开

这是健康的"出口"——任务完成。

### 3. 流量入口的关键指标

| 指标 | 含义 |
|---|---|
| **流量量级** | 该来源带来多少访客 |
| **质量(转化率)** | 该来源访客的转化比例 |
| **成本(CPC/CPA)** | 单位获客成本 |
| **LTV** | 该来源用户长期价值 |
| **跳出率** | 该来源用户的跳出率 |
| **平均停留** | 用户平均停留时长 |
| **回访率** | 用户多久后再访问 |

不能只看流量量级——某渠道流量大但质量差,LTV 低,实际价值不如小流量优质渠道。

### 4. 不同入口的特性对比

| 入口 | 量 | 质量 | 成本 | 可控性 |
|---|---|---|---|---|
| **直接访问** | 中 | 极高 | 0 | 长期品牌建设 |
| **自然搜索** | 大 | 高 | 0(SEO 投入) | 中等(算法变化) |
| **付费搜索** | 中 | 高 | 高 | 高(广告预算) |
| **付费社交** | 大 | 中 | 中-高 | 高 |
| **自然社交** | 中 | 中 | 0 | 低(算法决定) |
| **邮件** | 小 | 高 | 低 | 高 |
| **联盟** | 中 | 中 | 中 | 中 |
| **再营销** | 小 | 高 | 低-中 | 高 |

### 5. 流量入口诊断框架

#### a) 渠道贡献分析
每个入口的:
- 流量占比
- 转化贡献占比
- 成本占比
- 净利润占比(扣除获客成本)

#### b) 渠道质量梯度
按 LTV/CAC 比从高到低排序,投入应集中在比 ≥ 3 的渠道。

#### c) 渠道协同
单一渠道归因可能误判。用 [[多触点归因]] 看跨渠道协同——如自然搜索看似无成本,但用户可能是先看到付费广告才搜索品牌词。

#### d) 渠道增量
[[A/B测试]] 或地理实验测每个渠道的真实增量(暂停渠道一段时间看转化变化)。

### 6. 流量出口的诊断价值

#### a) 跳出率定位问题页
高跳出率 = 用户进来即走 = 内容/价值/技术问题。要分流量来源细分(从 SEO 来的跳出率低不奇怪,从付费广告来的跳出率高就有问题)。

#### b) Exit Pages 揭示流失节点
看用户从哪些页面离开率最高,这些是漏斗瓶颈。

#### c) Click-out 看用户兴趣
点出到外部链接的高频页面,反映用户真实兴趣。

#### d) 跨平台跳转
小红书笔记 → 淘宝商品页的跳转链路,是种草到转化的关键。

### 7. 直播间的流量入口与出口

直播间是"流量地"的极致案例:

#### 入口
- 关注页推荐
- 推荐流刷出
- 千川投流
- 直播广场
- 主播分享

#### 出口
- 商品成交(理想)
- 跨平台引流(私信、群)
- 直接划走
- 看完离开

[[直播脚本结构]] 的核心目的:延长入口转化,引导高价值出口(成交)。

## 实战诊断

### 第 1 步:画流量地图
从所有入口到所有出口的桑基图(Sankey),一眼看清流量结构。

### 第 2 步:计算每条路径价值
每条 入口 → 关键页 → 出口 的转化与价值。

### 第 3 步:找浪费
某些入口贡献流量但 0 转化 = 选错关键词或受众。
某些出口大量离开 = 关键流失点。

### 第 4 步:渠道再分配
高 LTV/CAC 渠道 → 加大投入
低 LTV/CAC 渠道 → 减少或暂停
新渠道 → 小预算测试

### 第 5 步:出口优化
关键流失点 → 加站内引导 / 优化内容 / 提供 CTA
内部下游路径 → 加内链 / 推荐 / 相关内容

## 当代演进

### 隐私时代的流量分析挑战
- ITP/ATT 让来源识别精度降低
- "Direct" 来源占比上升(实际是其他来源被遮蔽)
- Server-side 与 First-Party Data 重要性上升

### 多平台 / 多入口分裂
- 单一品牌可能在抖音、小红书、视频号、微信、官网各有入口
- [[CDP客户数据平台]] 统一身份必要性增强

### AI 流量
- 来自 ChatGPT、Perplexity、Bing Copilot 引荐的流量增长
- 部分被识别为 Direct(无 referrer)
- GEO 优化是新流量入口战略

### "无浏览器"流量
- AI Agent 代表用户访问与购买
- 不再有传统"浏览器流量入口"概念
