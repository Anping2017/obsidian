# IS-LM模型

## 定义

**IS-LM 模型**:由约翰·希克斯(John Hicks, 1937)对 [[凯恩斯]]《通论》进行形式化的宏观经济模型,通过两条曲线刻画商品市场(IS)与货币市场(LM)的同时均衡,在收入 Y 与利率 r 的二维平面上确定均衡点 (Y*, r*)。

模型基本假设:
- **价格刚性(短期)**:价格水平 P 给定
- 封闭经济
- 完全信息

虽简单,但 IS-LM 是几乎所有 [[财政政策]] 与 [[货币政策]] 的入门分析框架,直至今日仍是教学与政策讨论的核心工具。

## 核心要点

### IS 曲线:商品市场均衡

商品市场均衡条件:总产出 = 总需求

```
Y = C(Y − T) + I(r) + G + NX
```

或等价的"投资 = 储蓄":I(r) = S(Y) + (T − G)。

**IS 曲线**:在 (Y, r) 平面上,商品市场均衡的所有 (Y, r) 组合。**向下倾斜**:r 下降 → I 增加 → 通过乘数 Y 增加。

**斜率**取决于:
- 投资对利率敏感性(I 对 r 弹性):敏感则 IS 平缓
- 边际消费倾向 c:c 大则乘数大,IS 平缓

**位置移动**:
- G 增加、T 减少:IS 右移(扩张性财政政策)
- 自主消费/投资增加:IS 右移
- 净出口增加:IS 右移

### LM 曲线:货币市场均衡

货币市场均衡条件:实际货币需求 = 实际货币供给

```
M/P = L(Y, r) = L₁(Y) + L₂(r)
```

其中 L₁ 为交易需求(随 Y 上升),L₂ 为投机需求(随 r 上升而下降)。

**LM 曲线**:在 (Y, r) 平面上,货币市场均衡的所有 (Y, r) 组合。**向上倾斜**:Y 上升 → 交易需求增加 → 投机需求腾出空间 → r 上升。

**斜率**取决于货币需求对利率的敏感性:敏感则 LM 平缓。**流动性陷阱**情形:LM 在低利率处近水平,货币政策失效。

**位置移动**:
- 货币供给 M 增加:LM 右移(扩张性货币政策)
- 价格水平 P 上升:LM 左移
- 货币需求增加:LM 左移

### 双重均衡与政策分析

IS 与 LM 交点 (Y*, r*) 是双市场同时均衡。

**财政政策(G↑ 或 T↓)**:
- IS 右移 → Y↑、r↑
- 利率上升导致投资减少 →**挤出效应(crowding out)**
- 财政政策有效但部分被挤出抵消;LM 越陡(货币需求对 r 不敏感),挤出越大

**货币政策(M↑)**:
- LM 右移 → Y↑、r↓
- 投资增加进一步推高 Y(无挤出)
- IS 越陡(投资对 r 不敏感),货币政策越无力
- 流动性陷阱下完全失效

**政策协调**:
- 财政紧缩 + 货币扩张 → r↓、Y 不变(常见于发达国家)
- 财政扩张 + 货币紧缩 → r 大幅↑、Y 不变(滞胀应对)

### 经典情形

**流动性陷阱**(Liquidity Trap):
- 利率 r 极低(接近零下限),公众宁愿持币不愿持债
- LM 水平,货币政策失效
- 财政政策最有效(挤出效应消失)
- 1990s 日本、2008 后美欧、2020 全球疫情后均接近此情形

**古典情形**:
- 货币需求对 r 完全不敏感,LM 垂直
- 货币政策最有效,财政政策完全被挤出
- 货币主义(米尔顿·弗里德曼)倾向此假设

### 模型局限

- **价格刚性假设**:仅短期适用
- **封闭经济**:开放经济需扩展为蒙代尔-弗莱明模型(IS-LM-BP)
- **静态分析**:无法处理预期、动态调整
- **预期忽视**:卢卡斯批判指出,政策效果取决于预期形成方式
- **微观基础不足**:新凯恩斯与新古典都对 IS-LM 进行微观重构

## 和其他概念的关系

IS-LM 把 [[GDP核算]] 中的恒等式与 [[利率理论]] 中的货币市场结合,在短期框架下分析 [[财政政策]] 与 [[货币政策]] 的相对有效性,是 [[凯恩斯]] 思想最广为流传的呈现形式。

它与 [[AD-AS模型]] 紧密相关:固定 IS-LM 推导价格-产出关系即得 AD 曲线;放松价格刚性即过渡到 AD-AS 框架。[[菲利普斯曲线]] 把 IS-LM 的产出 Y 与失业 U(通过奥肯定律)以及通胀 π 关联起来,扩展为通胀-产出权衡。

挤出效应是 [[财政政策]] 局限性的核心解释;流动性陷阱是 [[货币政策]] 失效的核心情形;政策协调是宏观调控的实战核心。

跨域:[[利率理论]] 中三大利率决定理论(古典、凯恩斯、可贷资金)在 IS-LM 中得到统合;[[货币政策传导机制]] 的"利率渠道"对应 LM 移动;[[汇率决定理论]] 中蒙代尔-弗莱明模型将 IS-LM 扩展到开放经济;[[投资决策框架]] 与 [[基本面分析]] 中宏观周期判断离不开 IS-LM 直觉(利率、产出走势)。
