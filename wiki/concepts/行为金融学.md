# 行为金融学

## 定义

**行为金融学**(Behavioral Finance)结合心理学与金融学,研究**非理性行为**对投资决策与市场价格的影响,挑战经典金融学的"理性人 + 有效市场"假设。代表人物:Kahneman、Tversky、Thaler、Shiller。

## 核心要点

### 与传统金融学的对立

| 维度 | 传统金融学 | 行为金融学 |
|---|---|---|
| 投资者 | 理性、效用最大化 | 有限理性、心理偏差 |
| 市场 | 有效(EMH) | 部分有效,可被错误定价 |
| 风险态度 | 一致风险厌恶 | 损失厌恶,前景依赖 |
| 决策 | 贝叶斯更新 | 启发式、锚定、易受影响 |

### 前景理论(Prospect Theory)

Kahneman & Tversky 的核心贡献,描述实际决策行为:
- **价值函数**在收益区凹(风险厌恶)、损失区凸(风险偏好);损失的痛苦 ≈ 同等收益快乐的 2-2.5 倍
- **概率权重**:小概率被高估(乐透情结),大概率被低估
- **参考点依赖**:决策围绕参考点的相对变化,而非绝对水平

### 常见认知偏差

| 偏差 | 表现 |
|---|---|
| **过度自信** | 高估自己能力 → 过度交易,跑输被动指数 |
| **锚定效应** | 对初始信息(如成本价)过度依赖 |
| **代表性启发** | 把短期模式当成长期规律 |
| **可得性启发** | 易回忆的事件被高估概率(空难) |
| **损失厌恶** | 持有亏损股不愿割肉,过早卖出盈利股 |
| **确认偏差** | 选择性接收支持自己观点的信息 |
| **羊群效应** | 跟风买卖,放大市场波动 |

### 市场异象(Market Anomalies)

- **动量效应**:近期上涨的股票继续跑赢
- **反转效应**:长期跑输的股票后续跑赢
- **小盘股效应**、**价值股效应**(Fama-French 因子的行为解释)
- **过度反应/反应不足**:市场对新信息处理不充分
- **日历效应**:1 月效应、周一效应

### 实践应用

- **行为投资策略**:利用市场偏差获利(反向投资、动量、价值)
- **行为公司金融**:管理层非理性、并购溢价
- **政策设计**:Thaler 的"助推"(Nudge),用违约选项引导更好的决策
