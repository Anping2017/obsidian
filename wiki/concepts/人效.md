# 人效

## 定义

**人效**(Sales per Employee, SPE)是单位员工在单位时间(月/年)创造的销售额或毛利,是实体零售衡量 **人力资源效率** 的核心指标。它与 [[坪效]] 并称"双效",共同诊断实体业态健康度。

公式:

```
人效 = 营业额 / 员工人数(月)
人效 = 毛利 / 员工人数
小时人效 = 单日营业额 / 单日工时总和
```

## 核心要点

### 1. 不同业态的人效基准(中国,月人均)

| 业态 | 人效(万元/人/月) |
|---|---|
| **手机店(品牌专卖)** | 8-25 |
| **手机店(综合)** | 5-15 |
| **便利店(711/全家)** | 5-12 |
| **奶茶店** | 8-20 |
| **餐饮(快餐)** | 4-10 |
| **服饰(中端品牌)** | 3-8 |
| **奢侈品店** | 30-100 |
| **3C 数码连锁** | 6-18 |

注:数字仅供参考,因城市、商圈、品牌差异巨大。

### 2. 人效的核心影响因素

#### a) 销售技能
- 接待礼仪
- 需求挖掘
- 产品讲解
- 异议处理
- 关单技巧
- 加配件能力

#### b) 排班合理性
- 与客流匹配(早晚高峰加人)
- 工时利用率(无客流时做整理/学习)
- 多岗轮替减少疲劳

#### c) 商品熟悉度
- 培训完整度
- 老员工带新员工
- 标准话术库

#### d) 客流质量
人多但都不买没用,人效要看的是"能成交的客流"。

#### e) 工具支持
- POS 系统效率
- CRM 客户档案
- 数字化展示道具
- AI 推荐辅助

### 3. 人效 vs 坪效

| 维度 | 坪效 | 人效 |
|---|---|---|
| **关注** | 空间效率 | 人力效率 |
| **可控** | 选址后较固定 | 培训、激励可调 |
| **优化** | 陈列、品类 | 销售技能、排班 |
| **悖论** | 增员可能拖低人效但提升坪效 | 减员提升人效但降坪效 |

二者协同优化才是健康。

### 4. 人效提升路径

#### a) 销售技能体系化
- 需求漏斗(问、听、推)
- 异议处理八大套路
- 加配件话术
- 二手回收引导
- 客户档案建立

#### b) 数字化辅助
- 客户进店即识别(熟客系统)
- 平板辅助选品
- 直播打通线上线下

#### c) 激励机制
- 单店冠军、加配件冠军、新客冠军
- 双轨制提成(底薪 + 销售提成 + 毛利提成)
- 月度 PK + 即时奖励

#### d) 培训体系
- 新员工 7 天通关
- 老员工每月技能升级
- 暗访测评 + 回访改进

#### e) 减少非销售工时
- 库房集中管理减少员工跑动
- 自助点单 / 收银
- 简化报表流程

### 5. 人效与人均薪酬的合理关系

健康人效应满足:

```
人均月人效 ≥ 人均月薪 × 5(基础生存)
人均月人效 ≥ 人均月薪 × 8(健康)
人均月人效 ≥ 人均月薪 × 12(优秀)
```

例:员工月薪 6000,健康人效应 ≥ 4.8 万,优秀 ≥ 7.2 万。

### 6. AI 与自动化对人效的冲击

- **自助收银**:便利店减少 30% 人力但坪效不降
- **AI 推荐**:手机店让新员工接近老员工的成交率
- **直播 + 私域**:1 个店员可服务百倍客户群
- **客服机器人**:售后简单问题自动化

人效的"分子"在保持,"分母"在缩小,提升空间巨大。

## 实战诊断:人效低的常见原因

1. **销售技能不达标**:培训缺失或激励不足
2. **排班不合理**:高峰人不够,平峰人闲置
3. **客流不足**:本是营销问题,误诊为人效问题
4. **商品组合差**:缺爆款或客单提升空间小
5. **激励无关联**:固定工资 + 不挂钩绩效,员工无动力
6. **管理跨度过大**:1 个店长管 30 人无法精细辅导

## 跨业态启示

### 海底捞模式(高人效)
- 极致服务文化
- 师徒制传承
- 双轨晋升
- 高激励高门槛

### 优衣库模式(标准化人效)
- SOP 极致标准化
- 数字化补货减负
- 训练有素的兼职生

### 苹果零售店(高客单人效)
- 不催签单的文化
- 销售即体验师
- 高薪 + 高门槛

## 当代演进

- **远程值守**:1 个员工通过摄像头管多店
- **AI 销售助手**:实时建议话术与产品组合
- **数字陈列墙**:1 米屏幕展示全 SKU
- **自动售货化**:简单 SKU 不用人(零食、饮料)
- **私域人效**:线下员工兼线上社群运营
