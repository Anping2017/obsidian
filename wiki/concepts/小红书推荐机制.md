# 小红书推荐机制

## 定义

小红书推荐机制(Xiaohongshu Recommendation Algorithm)是平台决定一篇笔记应展示给多少用户、什么用户的算法体系。其核心结构是**梯度流量池(Tiered Traffic Pool)**——笔记发布后先进入小流量池(初始 200-500 人),依据用户行为表现决定是否推入下一级流量池(500 → 5K → 50K → 500K → 百万级)。每一级的"通行证"由四大互动指标决定:完播率、点赞率、收藏率、评论 / 转发率。理解这套机制是 [[小红书种草]] 与 [[KOL营销]] 投放的前提。

## 核心要点

**流量池层级(典型梯度)**:

| 层级 | 流量范围 | 关键考核 |
|---|---|---|
| 冷启动 | 0-500 | 完播 / 阅读完成率 |
| 初级 | 500-5K | 点赞率 + 完播 |
| 中级 | 5K-50K | 收藏率 + 评论质量 |
| 高级 | 50K-500K | 转发率 + 长尾点击 |
| 顶级 | 500K+ | 持续互动 + 用户留存 |

**CES(Community Engagement Score)评分模型**:

CES = 点赞 × 1 + 评论 × 4 + 收藏 × 4 + 转发 × 4 + 关注 × 8

**互动权重**(粗略):

- **点赞**:基础信号,易获得,权重 1。
- **评论**:深度互动,权重 4。
- **收藏**:用户对内容"有用性"的投票,权重 4。
- **转发**:超出本平台扩散,权重 4。
- **关注**:作者价值的认可,权重 8。

CES 越高的笔记被推上更大流量池的概率越大。

**核心算法因素**:

### 1. 内容质量信号

- **完播率 / 阅读完成率**:30 秒视频要求 90%+ 完播。
- **停留时长**:图文笔记的页面停留 ≥ 平均水平。
- **跳出率**:打开 < 3 秒就关闭算"无效曝光"。

### 2. 互动质量信号

- 互动率 = 总互动 / 曝光,健康线 ≥ 8%。
- 评论字数 / 复杂度,长评论比短"赞"权重高。
- 收藏率比点赞率更被算法看重(收藏 = "我觉得有用要保存")。

### 3. 用户匹配信号

- **兴趣匹配**:用户的历史浏览 / 搜索 / 互动 → 兴趣画像 → 该笔记是否在其兴趣范围。
- **关注关系**:被关注用户的笔记优先推送。
- **同城 / 地理位置**:本地化内容优先推同城用户。

### 4. 账号权重信号

- **粉丝量级**:不是越大越好,1-10W 粉中腰部账号反而有流量倾斜。
- **历史发文质量**:连续发布优质笔记的账号权重高。
- **垂直度**:专一垂类比杂烩账号权重高。
- **互动率**:粉丝活跃度高的账号被偏好。

### 5. 时效性

- 新发布笔记有"冷启动加权"。
- 24 小时内未起量的笔记很难再破圈。
- 时效内容(节日 / 热点)有额外加权。

**搜索流量(Search) vs 发现流量(Discovery)**:

- **发现流量**:首页推荐、"发现"页,占 70-80%,依赖算法推荐。
- **搜索流量**:用户主动搜索,占 20-30%,依赖关键词埋设与 SEO。
- 优秀笔记应同时优化两类流量入口。

**降权 / 限流的常见雷区**:

- **导流外平台**:微信号、二维码、外站链接 → 严重限流。
- **违禁词**:"最便宜""第一""绝对"等极端词 → 限流。
- **诱导互动**:"必赞""点赞才告诉" → 算法识别。
- **搬运抄袭**:与其他笔记重复度高 → 不进流量池。
- **频繁删除 / 修改**:发布后短期内反复操作 → 算法降权。
- **小号矩阵互赞**:被识别后封号。
- **广告未报备**:商业合作不备案 → 处罚。

**爆款的反向工程**:

- 用第三方工具(蝉妈妈、新红、千瓜数据)看垂类爆款 30 天 Top 100。
- 拆解爆款共性:封面风格 / 标题套路 / 正文结构 / 标签组合。
- 模仿迭代而非抄袭:相同结构、不同内容。

**搜索 SEO 优化**:

- 标题 + 正文埋目标关键词 2-3 次。
- 标签覆盖大中小词。
- 评论区埋长尾关键词。
- 持续发同主题笔记建立"垂直权重"。

**实操运营节奏**:

- **发布时间**:工作日 12-13 点、19-22 点;周末全天。垂类不同最优时段(母婴 8-10 点、健身 6-8 点)。
- **发布频次**:1-2 篇/天最优,过密(> 3 篇)互相分流。
- **互动维护**:发布后 1 小时内回复全部评论 + 主动私聊 / 跟评。

## 和其他概念的关系

小红书推荐机制是 [[小红书种草]] 与 [[小红书笔记结构]] 的算法基座——前者决定"种草后能否被看见",后者是被算法识别的"语言"。它与 [[抖音算法]]、[[微信视频号算法]] 同属"内容推荐 + 兴趣电商"流派,但小红书更重收藏与决策、抖音更重情绪与娱乐。

平台机制深度影响 [[KOL营销]] 投放策略——KOC(数千-数万粉)在小红书的 ROI 常优于头部 KOL,因为算法对中腰部账号有结构性倾斜。这也是 [[矩阵账号]] 战术兴起的根本原因。

它与 [[搜索引擎优化]] 共享"用户搜索词 + 内容质量信号 + 站内权重"的三因子模型,只是平台权重略不同。在 [[内容营销]] 战略中,小红书是种草中坚,与 [[抖音]] 的爆品引流、[[淘宝]] / [[天猫]] 的成交闭环形成"种草 → 爆品 → 成交"的全域链路。
