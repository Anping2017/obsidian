# 格式塔心理学

## 定义

格式塔心理学(Gestalt Psychology)是 1912 年由 Max Wertheimer 在德国创立、Wolfgang Köhler 与 Kurt Koffka 共同发展的心理学流派。"Gestalt"(形态)原意为"整体形状或结构"。核心命题:**整体不是部分之和,而是大于部分之和**(The whole is other than the sum of its parts)。

它反对当时心理学的"原子论"——把意识还原为基本元素;反对 [[行为主义]] 仅看刺激-反应。

## 历史背景

| 年 | 事件 |
|---|---|
| 1890 | 埃伦费尔斯首次使用"格式塔品质"一词 |
| 1912 | 韦特海默 phi 现象论文,正式起点 |
| 1921 | 创办《心理研究》(Psychologische Forschung) |
| 1933 | 纳粹上台,主要人物逃往美国 |
| 1934 | 考夫卡《格式塔心理学原理》英文版 |
| 1947 | 苛勒《格式塔心理学》(Gestalt Psychology) |
| 1960s | 主流地位被认知革命继承 |

## 核心要点

### 1. Phi 现象(似动现象)
- 韦特海默 1912 年实验:两个相邻光点交替闪烁产生"运动"知觉
- 没有真实运动,但意识感知运动
- 整体经验 ≠ 单个静止刺激的相加
- 这是格式塔心理学诞生的标志性实验

### 2. 知觉组织原则(图形—背景与七大法则)

| 法则 | 内容 |
|---|---|
| **图形—背景** | 视觉自动分出主体与背景 |
| **接近性** | 空间近的元素被组织在一起 |
| **相似性** | 形状/颜色相似的归一组 |
| **闭合性** | 倾向把不完整图形看成完整 |
| **连续性** | 倾向沿连续路径感知 |
| **共同命运** | 一起运动的物体被视为一组 |
| **简单性**(Prägnanz) | 倾向感知最简单结构 |
| **对称性** | 对称图形被视为一体 |

### 3. 同型论(Isomorphism)
- 苛勒主张大脑场动力学与意识经验同构
- 后被神经科学修正,但启发了"涌现"思想

### 4. 顿悟学习
- 苛勒在 Tenerife 岛(一战囚禁地)研究黑猩猩"苏丹"
- 与 [[行为主义]] 渐进试错对立
- 突然重组问题表征——"啊哈"时刻

### 5. 思维的格式塔
- 韦特海默《富有成效的思维》(1945,遗作)
- 区分"再生性思维"(套用旧解法)与"生产性思维"(重组结构)
- 影响创造力研究

## 主要代表人物

- **Max Wertheimer**(1880-1943):创立者,《富有成效的思维》
- **Wolfgang Köhler**(1887-1967):《动物的智慧》《格式塔心理学》
- **Kurt Koffka**(1886-1941):《格式塔心理学原理》系统化
- **Kurt Lewin**(1890-1947):场论,后被吸收入社会心理学,父亲是拓扑心理学
- **Fritz Heider**:归因理论(后述)
- **Solomon Asch**:从众实验、印象形成

## 与其他流派关系

- 反对 [[行为主义]] 还原刺激-反应
- 反对结构主义内省的元素分析
- 与 [[现象学]](胡塞尔)有共同欧洲哲学根
- 影响 [[认知主义]] 与认知科学
- 影响 [[积极心理学]]、[[人本主义心理学]]
- Lewin 继承格式塔传统创立 [[组织变革]] 三阶段模型(解冻—变革—再冻结)
- 影响"完形治疗"(Gestalt Therapy, Perls)虽其实理论上偏离原意

## 应用领域

- **设计与 UI/UX**:格式塔法则是设计教科书必修
- **平面设计**:Logo、海报借助闭合、相似
- **电影**:Phi 现象是动画基础
- **广告**:利用图形—背景突出品牌
- **音乐**:旋律是音符的格式塔
- **教育**:整体教学法 vs 部分练习
- **AI/计算机视觉**:深度学习边界检测仍受格式塔启发
- **管理**:Lewin 力场分析、变革理论

## 与其他概念关系

- 是 [[认知主义]] 的先驱
- 影响 [[皮亚杰认知发展]] 整体结构观
- 在 [[领导行为理论]] Lewin 民主/专制/放任研究中应用
- 在 [[组织变革]] 中,Lewin 三步法是经典
- 与 [[第一性原理]] 形成对比:整体 vs 还原
- 与 [[系统思维]] 共享"涌现"洞察
- 与 [[多元思维模型]] 交叉

## 当代评价

- 作为独立流派被吸收,但原则仍活跃
- 神经科学复兴整体性研究(global workspace)
- 涌现性、整合信息理论(IIT)是格式塔精神延续
- 设计与 HCI 领域永恒相关
- "全脑"营销与品牌建设仍引用
