# 演绎与归纳

## 定义

**演绎(Deduction)** 与 **归纳(Induction)** 是两类基本推理方式:
- **演绎**:从一般到特殊,前提为真则结论必然为真
- **归纳**:从特殊到一般,前提支持但不保证结论

二者构成 [[逻辑]] 与科学的双引擎,各有所长,互为补足。

## 核心要点

### 演绎推理

#### 特征

- **必然性**:前提真 → 结论必然真
- **形式有效**:正确推理形式独立于内容
- **不增加新信息**:结论已隐含在前提中

#### 经典例子

```
所有人都会死(大前提)
苏格拉底是人(小前提)
∴ 苏格拉底会死(结论)
```

#### 经典推理规则

- **肯定前件**:A → B,A,故 B
- **否定后件**:A → B,¬B,故 ¬A
- **三段论**:大前提 + 小前提 → 结论
- **数学证明**:从公理演绎所有定理

#### 优势与局限

- 优势:结论必然,逻辑严密
- 局限:前提必须真;不能产生超出前提的新知识

### 归纳推理

#### 特征

- **或然性**:前提支持但不必然导出结论
- **从经验出发**:观察 → 模式 → 普遍规律
- **可证伪**:一个反例就推翻

#### 经典例子

```
观察到的天鹅都是白的(经验)
∴ 所有天鹅都是白的(归纳结论)
```

直到澳大利亚发现黑天鹅 → 推翻

#### 类型

- **简单枚举**:从多个例子归纳
- **类比归纳**:从一相似例归纳到另一例
- **统计归纳**:从样本推断总体
- **因果归纳**:从相关推断因果

#### 优势与局限

- 优势:能产生新知识,科学发现的主要工具
- 局限:不能保证必然;归纳问题(休谟)无解

### 休谟的归纳问题

- 我们如何证成"过去 X 总伴随 Y → 未来仍如此"?
- 用演绎不行(逻辑上未来不必复制过去)
- 用归纳证成归纳是循环论证
- 结论:**归纳无法被纯逻辑证成**
- 仅是"心理习惯"而非"理性必然"

### 波普尔的回应

- 科学不是从归纳累积真理,而是**猜想 + 反驳**
- 提出大胆假设,通过观察试图反驳(可证伪)
- 经受住证伪检验的理论是"暂时被接受",而非"被证实"
- 这绕开了归纳问题的核心难点

### 溯因推理(Abduction)

- 第三类推理:从现象到最佳解释
- "草地湿了 → 推断下过雨"
- 是科学假设生成的主要方式
- 由皮尔斯系统提出

### 在科学方法中的协同

```
观察(归纳) → 假设 → 演绎出可检验后果 → 实验验证
```

科学既需归纳生成假设,也需演绎推出可观察后果。

### 在日常决策中

- **演绎**:已有规则 → 应用到具体案例(法律审判、棋类策略)
- **归纳**:从经验积累 → 形成通用判断(医生靠案例、投资靠历史数据)
- **溯因**:听到嘈杂 → 推断车祸了

## 和其他概念的关系

- 是 [[逻辑]] 的两种基本推理方式
- 演绎是 [[第一性原理]] 思维的核心
- 归纳问题由 [[休谟]] 提出,引发 [[康德]] 回应
- 与 [[科学方法]]、波普尔可证伪精神紧密相关
- 在 [[认识论]] 中是经典议题
- [[亚里士多德]] 系统化演绎(三段论);培根强调归纳
- 与 [[贝叶斯]] 推理形成现代版本
- 在 [[认知偏差]] 中:确认偏差让归纳被滥用("看到三个支持就当真理")
