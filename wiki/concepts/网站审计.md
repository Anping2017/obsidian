# 网站审计

## 定义

**网站审计(SEO Audit / Website Audit)** 是通过技术工具与人工分析,对网站的 SEO 表现进行全面、系统、深度的诊断,识别问题、机会与风险,输出可执行的优化建议清单的过程。

SEO 审计是任何严肃 SEO 项目的起点——没有诊断就开药方的优化往往南辕北辙。成熟企业每季度或半年做一次完整审计,实时监控关键指标的异常波动。

## 核心要点

- **审计的覆盖维度**:
  - **技术 SEO**:爬取、索引、渲染、速度、移动、安全
  - **页面 SEO**:Title、Description、H 标签、内容、内链、结构化数据
  - **内容 SEO**:质量、深度、原创性、E-E-A-T、覆盖完整度
  - **链接审计**:外链质量、内链结构、垃圾链接
  - **用户体验**:Core Web Vitals、跳出、停留、转化
  - **本地 SEO**(如适用):GBP、NAP、本地引用
  - **竞品对标**:对手在做什么我们没做
- **技术审计核心检查项**:
  - **可爬取性**:robots.txt 配置、sitemap.xml、可访问性
  - **可索引性**:GSC 索引覆盖报告、noindex 误用、规范化标签
  - **速度**:LCP、INP、CLS([[Core Web Vitals]])
  - **移动友好**:响应式、触控目标、视口
  - **安全**:HTTPS、混合内容、安全头
  - **渲染**:JS 渲染问题、SSR/CSR 选择
  - **状态码**:404、5xx、重定向链
  - **国际化**(如适用):hreflang 配置
  - **结构化数据**:Schema 错误、Rich Result 触发
- **页面审计核心检查项**:
  - **Title 唯一性与长度**
  - **Meta Description 唯一性与吸引力**
  - **H1 唯一与关键词覆盖**
  - **URL 结构清晰**
  - **图片 alt 属性**
  - **关键词密度与分布**(避免堆砌)
  - **内链结构与锚文本**
  - **页面深度**(到首页距离)
  - **重复内容**(站内同样内容多页)
  - **稀薄内容**(内容过短)
- **内容审计**:
  - **内容质量评分**:基于深度、原创性、价值、E-E-A-T
  - **内容更新时间**:陈旧内容标记
  - **流量页面分析**:哪些页面有流量、哪些没有
  - **意图错配**:页面类型与查询意图是否匹配
  - **内容自我竞争(Cannibalization)**:多页竞争同关键词
  - **内容缺口(Content Gap)**:对手有但我们没有的主题
- **链接审计**:
  - **反向链接质量**:DR、相关性、垃圾比例
  - **锚文本分布**:精准匹配过多易触发 Penguin
  - **链接来源多样性**
  - **新增/丢失链接监控**
  - **垃圾链接清理**(disavow)
  - **内链结构**:Hub & Spoke、深度
- **用户行为审计**:
  - **跳出率**:着陆页 vs 全站
  - **停留时间**
  - **滚动深度**
  - **搜索内点击**(Site Search)
  - **转化漏斗各阶段流失**
- **审计工具**:
  - **Google 工具**:GSC(Search Console)、GA4(Analytics)、PageSpeed Insights、Mobile-Friendly Test、Rich Results Test、Lighthouse
  - **爬虫工具**:Screaming Frog、Sitebulb、JetOctopus、OnCrawl、DeepCrawl
  - **链接工具**:Ahrefs、SEMrush、Majestic、Moz
  - **内容工具**:Surfer、Clearscope、MarketMuse
  - **日志分析**:用 Splunk、ELK、SolarWinds 解析服务器日志看 Googlebot 行为
  - **AI 辅助**:GPT/Claude 用于审计报告生成与诊断假设
- **审计输出**:
  - **诊断报告**:发现的所有问题
  - **优先级矩阵**:基于影响×难度排序
  - **行动清单**:具体优化任务,分配到人到期
  - **路线图**:短期(1-3 个月)+ 中期(3-12 个月)+ 长期(1 年+)优化
  - **基线指标**:当前关键指标,用于跟踪改进
- **审计的不同形态**:
  - **快速审计(Quick Audit)**:1-2 天,聚焦最大问题
  - **深度审计(Deep Audit)**:2-4 周,全维度
  - **季度健康检查(Health Check)**:常规监控
  - **专项审计**:针对特定问题(流量下降、移动迁移)
  - **新站上线前审计**:确保上线前没有重大技术问题
- **审计后的常见高优先级行动**:
  - 修复重大索引问题(成千上万页未被索引)
  - 改善 Core Web Vitals
  - 修复重复内容
  - 重写薄内容/低质内容
  - 改进 Title/Description 提升 CTR
  - 增加结构化数据
  - 内链优化
  - 清理垃圾外链

## 和其他概念的关系

网站审计是 [[搜索引擎优化]] 项目的起点与定期实践,直接对应 [[技术SEO]]、[[页面SEO]]、[[链接建设]]、[[内容营销]] 的诊断与改进。

网站审计的输出是 [[Google算法更新]] 影响诊断的标准工具——大幅流量波动后第一件事就是审计。

审计中的"内容缺口分析"是 [[关键词研究]] 的高级应用——基于对手的关键词排名找到自己的内容机会。

链接审计与 [[E-E-A-T]] 的"权威性"维度紧密相关——好的链接画像即权威信号。

[[Core Web Vitals]] 与速度审计直接对应用户体验类排名信号。

网站审计的工程化实施是 [[数据驱动营销]] 在 SEO 场景的具体形态——基于数据诊断而非凭感觉决策。
