# 函数式编程 Functional Programming

## 定义

**函数式编程(Functional Programming, FP)**是一种以**纯函数为核心**的[[编程范式]]:把程序视为数学函数的求值,而非状态机的转换。它源自 λ 演算(Church 1930),代表语言 Haskell、Lisp、Erlang、OCaml,主流语言 JS、Python、Java、C# 也大量吸收 FP 特性。

四大核心特征:
- **函数是一等公民**:可作为参数、返回值、赋值给变量
- **纯函数**:相同输入相同输出,无副作用
- **不可变数据**:不修改原始数据,而是创建新数据
- **声明式**:描述"做什么",而非"怎么做"

## 核心要点

### 纯函数(Pure Function)

满足两个条件:
- **确定性**:相同输入恒产生相同输出
- **无副作用**:不修改外部状态、不做 I/O、不依赖隐式上下文(系统时间、随机数)

优点:
- **可测试**:无需 mock 外部依赖
- **可缓存(memoization)**:结果与输入一一对应
- **可并行**:无共享状态,无竞态
- **可推理**:等式替换(referential transparency)

### 高阶函数(Higher-Order Function)

接受函数为参数或返回函数。经典:`map`、`filter`、`reduce`。
```js
[1,2,3].map(x => x*2).filter(x => x > 2).reduce((a,b) => a+b, 0)
```
这种**链式管道**风格,用最少代码描述复杂数据变换 —— 命令式版本会有多层 for 循环。

### 函数组合(Composition)

`compose(f, g)(x) = f(g(x))`。把小函数像乐高积木拼成大函数。
- 数学上是单子(category)的态射组合
- 代码上等价于 Unix 管道 `cmd1 | cmd2 | cmd3`

### 不可变数据(Immutability)

数据一旦创建不可修改,变更通过返回新数据实现。
- 优势:历史可追溯(用于撤销/重做、时间旅行调试)、并发免锁
- 工程实现:持久化数据结构(structural sharing)避免每次复制全部数据,如 Clojure 的 PersistentVector(O(log32 n)实际近 O(1))
- React 的 Redux、Immer 库本质都是不可变性

### 闭包(Closure)与柯里化(Currying)

- **闭包**:函数捕获定义环境的变量,即使外部环境结束仍存活。是 FP 实现状态、模块、回调的基础
- **柯里化**:`f(a,b,c)` 转为 `f(a)(b)(c)`,部分应用化函数

### 惰性求值(Lazy Evaluation)

只在需要时计算,Haskell 默认惰性。Python 的 generator、Java 的 Stream 是有限的惰性。
优势:可处理"无限序列",自然实现 memoization。

### Monad 与代数效应

把"包装计算"(Optional/Maybe、Either、Future、IO)统一抽象。Haskell 用 Monad 隔离副作用 —— "纯"语言能做 IO 是因为 IO Monad 把副作用变为"被调度"的纯描述。
对入门者门槛较高,但是是高级 FP 抽象的关键。

### FP 与 [[面向对象编程]] 的对比

| 维度 | OOP | FP |
|---|---|---|
| 核心 | 对象 + 消息 | 函数 + 数据 |
| 状态 | 封装在对象 | 不可变 |
| 复用 | 继承 / 组合 | 函数组合 / 高阶函数 |
| 多态 | 子类型 | 参数化(泛型)、Type Class |
| 并发 | 锁、Actor | 无锁(纯)、CSP、STM |
| 学习曲线 | 平缓 | 较陡(monad 等) |

### 工程现实

- React/Redux/RxJS 大量 FP 思想:不可变状态、纯函数 reducer、流
- 大数据(Spark、Flink):map/reduce/filter 是核心
- Java Stream API、C# LINQ、Kotlin Sequence 把 FP 注入工业语言
- 类型系统(TS、Rust、Scala)借鉴 Haskell 的代数数据类型(ADT)

## 和其他概念的关系

FP 与[[面向对象编程]]构成主流编程的两大范式,现代语言多数是混合范式。FP 思想直接驱动了响应式编程(Reactive)、数据流编程、声明式 UI(React)、ML 框架(PyTorch 的函数式 API、JAX)。

[[递归]]在 FP 中替代循环;不可变性与[[并发与并行]]安全紧密相关 —— Erlang 用纯 + Actor 模型支撑电信级高并发。Map/Reduce 大数据范式直接来自 FP 的 map/reduce。

[[数据库]]查询语言 SQL 本身是声明式的,与 FP 哲学相通。GraphQL 的 schema + resolver 也是函数式风格。
