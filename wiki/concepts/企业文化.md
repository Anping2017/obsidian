# 企业文化 Corporate Culture

## 定义

企业文化(Corporate Culture / Organizational Culture)是**组织成员共同持有的价值观、信念、规范、行为模式与符号体系**,它在没有明文规定时仍能潜移默化地塑造决策、协作方式、问题处理、人际关系。

Edgar Schein 经典定义:「群体在解决外部适应与内部整合问题过程中习得、被验证有效、被新成员视为正确认知方式的基本假设模式」。

## 核心要点

### Schein 三层模型

```
┌──────────────────────────────────┐
│ 1. 表象层(Artifacts)            │  能看到、听到、感觉到
│    办公环境、着装、仪式、口号     │
├──────────────────────────────────┤
│ 2. 价值观层(Espoused Values)    │  组织声称的信念与目标
│    使命、愿景、价值观、行为准则   │
├──────────────────────────────────┤
│ 3. 基本假设层(Basic Assumptions)│  无意识、被视为理所当然
│    人性观、时间观、关系观         │
└──────────────────────────────────┘
```

文化变革之难,恰因第三层不易察觉、更难改变。

### 经典文化类型框架

**Cameron & Quinn 竞争价值观框架(CVF)**:

| 类型 | 特征 | 代表 |
|---|---|---|
| 家庭(Clan) | 内部 + 灵活,亲情、协作、师徒 | 家族企业、研发实验室 |
| 创新(Adhocracy) | 外部 + 灵活,创业、试错、敏捷 | Tech 公司早期、初创 |
| 市场(Market) | 外部 + 控制,业绩、竞争、客户 | 销售导向公司 |
| 层级(Hierarchy) | 内部 + 控制,流程、稳定、规范 | 政府、银行、大型工业 |

健康企业通常以一种为主,其他兼顾。

### 强文化 vs 弱文化

- **强文化**:成员对核心价值观有高度共识,行为高度一致
  - 优势:高凝聚、低协调成本、品牌一致性
  - 风险:同质化、不容异见、难以变革
- **弱文化**:价值观分散,行为依赖明文规则
  - 优势:多样性高、变革阻力小
  - 风险:协调成本高、缺乏认同

### 塑造与传播

- **创始人效应**:早期决策与言行刻入公司 DNA(Steve Jobs vs Tim Cook)
- **招聘**:寻找文化匹配,而非仅技能
- **入职社会化**:讲故事、师徒、新员工训练营
- **奖惩机制**:奖励什么就能强化什么文化
- **领导者示范**:高管行为是最强文化信号
- **空间与仪式**:工位布局、月会、年会、季度复盘

### 文化与战略的关系

「文化把战略当早餐」(Peter Drucker)——再好的战略也会被不匹配的文化消解。

成功公司的文化-战略一致案例:

- 苹果:产品至上、极致细节 → 设计驱动战略
- 谷歌:工程师文化 + 数据决策 → 技术创新战略
- 亚马逊:Day 1、客户痴迷 → 长期投资战略
- 海底捞:服务为家 → 极致体验战略

### 文化变革

变革文化通常需 3-5 年,关键步骤:

1. 诊断现有文化(员工调研、行为观察)
2. 明确目标文化(与战略匹配)
3. 高层强烈承诺与示范
4. 招聘与考核体系联动调整
5. 短期赢得 quick wins 增信
6. 长期持续故事化与仪式化

## 和其他概念的关系

企业文化与 [[战略管理]]、[[领导力]]、[[组织设计]]、[[变革管理]] 互为支撑——文化是战略的土壤,领导是文化的园丁。

[[变革型领导]]、[[价值观领导]]、[[仆人式领导]] 等领导风格深刻影响文化形成;[[团队动力学]]、[[团队建设]] 是文化在小单位的具体表现。

[[人力资源管理]] 中的招聘、绩效、培训、薪酬体系都是文化的具体载体;[[企业生命周期]] 不同阶段(创业、成长、成熟、衰退)有不同的文化挑战。

[[赫兹伯格双因素理论]]、[[马斯洛需求层次]]、[[内在驱动力]] 在心理学层面解释了文化为何能激发员工。[[OKR]]、[[平衡计分卡]] 把抽象文化指标化,是落地关键工具。
