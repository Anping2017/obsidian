# 二阶思维

## 定义

**二阶思维**(Second-Order Thinking)由 Oaktree Capital 联合创始人**霍华德·马克斯**(Howard Marks)在《投资最重要的事》(2011)中系统化:**不仅考虑行动的直接后果(一阶),还要考虑后果的后果(二阶)、再之后(三阶)**。它是 [[芒格]]、巴菲特等大投资者超越平均水平的思维利器,也是 [[多元思维模型|芒格多元思维模型]] 的应用形态。

## 一阶 vs 二阶

### 一阶思维

- "**我喜欢这家公司,我要买股票。**"
- 只看到第一层结果
- 简单、快速、被多数人采用
- 因此**只能赚平均收益**(甚至更少)

### 二阶思维

- "**这家公司很好,但所有人都知道,股价已反映 → 收益不会超额。**"
- 考虑**别人的反应、市场的反应、政策的反应**
- 预想链:**A → B → C → D → ...**
- 复杂、慢、被少数人采用
- 是**超额回报**的源头

## 经典案例

### 投资:好公司不等于好投资

- 一阶:这家公司利润高、护城河深 → 买
- 二阶:大家都看好 → 价格已高 → 收益空间小 → **可能不买**

### 政策:善意的副作用

- 一阶:租金管制保护租户 → 推
- 二阶:房东减少投资 → 房屋质量下降 → 长期反伤租户
- 这是经济学反复强调的**意外后果**

### 营销:短期高峰的反作用

- 一阶:大力打折促销 → 销量爆涨
- 二阶:消费者期待打折 → 不打折就不买 → **品牌价值受损**
- 详见 [[品牌权益]]、 [[品牌定位]]

### 产品:功能的隐性代价

- 一阶:加这个功能 → 用户更喜欢
- 二阶:产品复杂度增加 → 维护成本上升 → 性能下降 → 用户体验更差
- 与 [[奥卡姆剃刀]] 相承

### 招聘:一时的捷径

- 一阶:这个候选人能力很强 → 雇佣
- 二阶:此人价值观与团队不合 → 制造矛盾 → 团队凝聚力崩溃 → **得不偿失**

## 训练二阶思维的提问

> 马克斯建议在每个决策时问自己:

1. **我预期会发生什么?**
2. **会发生什么的概率多大?**
3. **市场已经预期了什么?**
4. **我的预期与市场预期差多少?**
5. **如果我对了,谁亏了?如果我错了,我亏多少?**
6. **这一切发生后,接下来会怎样?**(链式)

## 与其他思维模型的关系

### [[逆向思维]](Inversion)

- 二阶:**之后会发生什么?**
- 逆向:**反过来想,什么会让事情变糟?**
- 二者结合:思考反向二阶后果
- 详见 [[逆向思维]]、 [[芒格]]

### [[系统思维]]

- 二阶思维是系统思维的简化形式
- 系统思维:多变量、反馈环、动态平衡
- 详见 [[系统思维]]

### [[第一性原理]]

- 第一性原理:**回到基本规律**
- 二阶思维:**沿规律向后推**
- 二者互补
- 详见 [[第一性原理]]

### [[复利效应]]

- 复利是**正向二阶**:今天的收益作为明天的本金
- 详见 [[复利效应]]

### **决策树分析**

- 形式化的多阶思维
- 详见 [[决策树分析]] 之 stub
- 蒙特卡洛、博弈论扩展

## 应用领域

### 投资

- 巴菲特:"**我们试图避免一阶决定,做二阶决定**"
- 选股、估值、宏观预测中的关键思维
- 详见 [[投资决策框架]]、 [[投资组合理论]]、 [[基本面分析]]

### 战略管理

- 竞争对手的反应
- 客户的二阶行为(用了 6 个月后……)
- 政策的非预期后果
- 详见 [[战略管理]]、 [[波特五力模型]]、 [[竞争优势]]

### 政策制定

- "**意图—结果差距**"问题
- 一阶善意可能产生二阶恶果
- 行为经济学帮助预测真实反应

### 产品设计

- "**新功能的隐性成本**"
- 用户行为变化的链式后果
- 推荐系统的二阶后果(回音室、极化)
- 详见 [[人工智能]] 推荐系统

### 个人决策

- 职业:这份工作 5 年后让我变成什么样的人?
- 关系:这次让步对方学到什么?
- 健康:这个习惯 10 年后是什么状态?

### 数字与社交

- "**点赞按钮的二阶后果**":社交媒体的攀比、焦虑
- 抖音算法的二阶后果:注意力碎片化
- 详见 [[HOOK模型]]、 [[消费者行为]]、 [[积极心理学]] 中相关讨论

## 局限与陷阱

### 1. 过度推演

- 沿链推得太远 → 不确定性失控
- 实际作用有限的远期后果 → 不应主导当下

### 2. 麻痹

- 看到太多可能后果 → 不敢决策
- 与 [[认知失调]]、过度分析瘫痪

### 3. 自信的误差累积

- 每一阶有 80% 把握 → 到第 5 阶只有 32%
- 多阶推演的整体不确定

### 4. 错失简单解

- 有时一阶答案就对
- 不要"二阶"过度复杂化

## 良好实践

### 关键决策才用

- 不必每个决策都二阶
- 高风险、长期、可逆性低的决策用

### 写下来

- 把推演过程写下,事后回看
- 校准自己的预测能力

### 多视角

- 不同角色的反应:用户、对手、监管、股东、员工
- 详见 [[博弈论]]

### 与他人辩论

- 自己想容易被自我确认
- 对方质疑帮助看到盲点
- 与 [[确认偏差]] 抵抗
- "**红队**"(Red Team)演练

## 在 [[多元思维模型|芒格多元思维模型]] 中

- 芒格强调:**反复想后续后果**
- 经典芒格语:"**告诉我我会死在哪里,我就不去那里**"——这是二阶思维 + [[逆向思维]]
- "**Lollapalooza 效应**":多重二阶力量协同
- 详见 [[芒格]]、 [[多元思维模型]]、 [[逆向思维]]
