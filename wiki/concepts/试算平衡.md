# 试算平衡

## 定义

**试算平衡**(Trial Balance)是会计期末,在编制财务报表前,**列示全部账户借方与贷方金额并核对其是否相等**的程序。它是 [[复式记账法]] 内在数学逻辑的检查工具——若每笔分录都"借贷相等",则全部分录加总后必然"借方合计 = 贷方合计"。试算不平衡说明肯定有错;但试算平衡也不保证完全无错。

## 核心要点

### 基本原理

复式记账法的核心要求:**每一笔交易,借方金额 = 贷方金额**。
- 推论:全部分录的借方合计 = 全部分录的贷方合计
- 等价于:全部账户的借方期末余额合计 = 全部账户的贷方期末余额合计
- 这是 [[会计等式]](资产 = 负债 + 所有者权益)的必然结果

### 程序步骤

1. 期末把全部明细账与总分类账过完
2. 列出每个账户的期末余额(按性质放在借方或贷方)
3. 分别加总借方与贷方
4. 核对总和是否相等

### 主要类型

- **总额式试算平衡**:所有账户借方发生额合计 = 贷方发生额合计
- **余额式试算平衡**:所有账户期末借方余额合计 = 贷方余额合计
- **综合式**:发生额平衡 + 余额平衡同时编制

### 能发现的错误

- **借贷不平衡**:漏记一方、金额不一致
- **数字录入错误**:转抄错误、加总错误
- **科目方向错误**:借贷方向写反

### 不能发现的错误

试算平衡平衡 ≠ 记账正确,以下错误它不报警:
- **整笔漏记**:没记的不影响平衡
- **整笔重记**:借贷都重一次,仍平衡
- **借贷方向都错**(借方错记到 A,贷方错记到 B,但金额对)
- **科目用错但金额对**:把"主营业务收入"记到"其他业务收入"
- **多记或少记同等借贷**

### 改进:平衡 + 其他控制

为弥补试算平衡的局限,会计系统配合使用:
- 银行余额调节表
- 应收应付明细对账
- 存货盘点
- [[内部控制]] 中的职责分离与复核
- ERP 系统的实时双重校验

### 现代信息化下的角色

在手工记账时代,试算平衡是会计循环必不可少的环节;在 ERP 系统下,系统自动维护借贷一致,试算平衡更多是**对账与汇总报表**的形式,而非"防错工具"。但其揭示的"会计内在数学一致性"原则仍是理解复式簿记的核心。

## 和其他概念的关系

- 是 [[复式记账法]] 内在逻辑的实现工具
- 直接基于 [[会计等式]] 与 [[会计要素]] 的分类
