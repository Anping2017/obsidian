# 工作倦怠

## 定义

工作倦怠(Burnout)是长期工作压力得不到有效缓解所产生的特定综合征。Christina Maslach 与 Susan Jackson 1981 年通过 Maslach Burnout Inventory(MBI)系统化为三维度构念。WHO 在 2019 年 ICD-11 中将其确认为"职业现象"(非疾病诊断),指"未成功管理的慢性工作场所压力综合征"。

## 三维度模型

### 1. 情绪耗竭(Emotional Exhaustion)
- 核心维度,情感资源被耗尽
- 早晨起床即疲惫
- 一想到工作就累
- 与 [[压力与应对]] HPA 轴失调相关

### 2. 去人格化/犬儒(Depersonalization / Cynicism)
- 对工作、客户、同事冷漠、疏离
- 把人物化、用消极态度
- 在医护、教师、社工最严重

### 3. 个人成就感低落(Reduced Personal Accomplishment)
- 觉得自己在工作中没价值
- 自我效能感下降
- 与抑郁症状重叠但概念区分

## JD-R 工作要求—资源模型

Bakker & Demerouti 等当代主流框架:

### 工作要求(Job Demands)
- 工作量、时间压力
- 情绪劳动
- 角色冲突
- 工作—家庭冲突
- 物理环境差

### 工作资源(Job Resources)
- 自主性
- 反馈
- 社会支持
- 工作意义
- 发展机会

### 双路径
- **健康损害路径**:高要求 + 低资源 → 倦怠 → 健康问题
- **激励路径**:充足资源 → 投入(engagement) → 高绩效

## 倦怠对立面:工作投入

Schaufeli 提出工作投入(Work Engagement):
- **活力**(Vigor):精力充沛
- **奉献**(Dedication):投入意义感
- **专注**(Absorption):沉浸([[心流]])

## 测量

| 量表 | 维度 |
|---|---|
| **MBI**(Maslach) | 三维度,行业版多个 |
| **OLBI**(Demerouti) | 双维度:耗竭、脱离 |
| **CBI**(Copenhagen) | 个人、工作、客户三维 |
| **BAT**(Burnout Assessment Tool) | 新一代,核心 + 次级症状 |
| **UWES**(Schaufeli) | 工作投入 |

## 主要风险因素

### 个人层面
- 完美主义、神经质([[大五人格]])
- 自我效能低
- 工作—家庭边界模糊
- 缺乏边界

### 工作层面
- 工作超载
- 控制感缺乏
- 奖励不足
- 不公平
- 价值冲突
- 缺乏归属

### 组织层面
- 文化不健康
- 沟通失败
- 领导风格差
- 长期改革震荡

### 社会层面
- 经济不稳
- 行业危机(如医护疫情后)
- 职业污名

## 高风险职业

- 医护人员(尤其 ICU、急诊)
- 教师(尤其特殊教育)
- 社工、心理咨询师
- 客服、客户成功
- 律师
- 创业者、CEO
- 远程工作"永远在线"

## 干预策略

### 个人
- 时间管理、边界设定
- [[正念]] 减压(MBSR)
- [[认知行为疗法]] 思维重构
- 体能管理(睡眠、运动、营养)
- [[心流]] 体验恢复
- 社交支持

### 工作设计
- 任务自主、技能多样
- 工作—资源平衡
- 角色澄清
- 反馈机制

### 组织
- 心理安全文化
- 弹性工作制
- 公平薪酬
- 领导力训练
- EAP 员工援助计划

### 系统
- 法定休息权(欧盟"断联权")
- 行业规范
- 工作时间法规

## 与其他概念关系

- 与 [[压力与应对]] 直接关联,是慢性应激的特定形态
- 与 [[抑郁症]] 重叠但概念区分(倦怠是工作特定的)
- 与 [[心流]] 相反极
- 与 [[自我效能]] 反向相关
- 与 [[自我决定论]] 三需求(自主、胜任、关联)缺失关联
- 与 [[赫兹伯格双因素理论]] 不满情境呼应
- 与 [[团队建设]] 心理安全感互补
- 与 [[领导力]] 真诚领导可降低
- [[人力资源管理]] 关键议题
- [[组织文化]] 健康文化议题
- 影响 [[卫生经济学]] 医生短缺、医疗质量

## 当代议题

### 大流行后
- 医护职业倦怠空前
- 远程工作模糊边界
- "Quiet Quitting"是倦怠表征

### 数字化
- 信息过载
- 算法管理(平台劳动)
- 屏幕疲劳

### 职业代际差异
- Z 世代倦怠率最高
- 与意义感寻求相关

### 系统视角
- 不只修复个人,要改变工作设计
- "Burnout is an organizational problem, not personal"
