# 共情

## 定义

**共情**(Empathy,又译"同理心")是**理解和分享他人情感、视角与处境的能力**。它不只是"同情"(sympathy,为他人难过)而是"进入他人的心灵世界,如同自己一样体验"。它是人际关系、领导力、临床实践、道德判断的核心能力。

## 核心要点

### 三种成分

| 类型 | 内容 | 神经基础 |
|---|---|---|
| **认知共情** | 理解他人想法、感受、视角 | 心智化网络(mPFC、TPJ) |
| **情绪共情** | 自动感同身受他人情绪 | 镜像神经元、岛叶、扣带回 |
| **同情关切** | 对他人福祉的关怀和帮助意愿 | 涉及奖赏与照顾系统 |

三者相互独立,可单独存在或缺失。

### 与相关概念的区分

- **同情**(Sympathy):为他人感到难过,不必准确理解
- **怜悯**(Pity):带有上下不对等
- **共情**(Empathy):理解 + 感受,平等
- **同理心反应**(Compassion):理解 + 想要帮助,但不被淹没

### 镜像神经元与共情神经科学

- 1990 年代意大利神经科学家发现:猴子看他人做动作时,自己运动皮层也激活
- 人类有更广泛的"心智化网络"
- 共情有部分自动、部分受调节
- 自闭症谱系常涉及认知共情困难

### 共情的发展

- 婴儿期:情绪传染(看别人哭自己也哭)
- 幼儿期:开始识别他人情绪
- 学龄期:能从他人视角思考
- 青春期:更复杂的道德共情
- 成年:认知与情绪共情的精细整合

### 共情与道德

- 休谟、亚当·斯密(《道德情操论》):共情是道德判断的基础
- 现代研究:共情驱动利他行为,但有"共情偏差"(对内群更共情)
- 与 [[儒家]] 仁爱、孟子"恻隐之心"概念相通

### 共情的副作用

**共情疲劳(Empathy Fatigue)**
- 长期暴露于他人痛苦 → 情绪枯竭
- 临床、护理、社工常见
- 对治:专业边界、自我照顾、慈悲冥想

**共情偏差(Empathy Bias)**
- 对相似者(同族、同性别、同阶层)更共情
- 可能导致道德判断不公正
- Paul Bloom《反对共情》主张用"理性同情"替代

**镜像情绪溢出(Emotional Contagion)**
- 不加边界的共情 = 被他人情绪淹没
- 分清"我的"与"对方的"情绪是关键

### 共情可训练

- **正念训练**:对自身情绪的觉察是共情前提
- **慈悲冥想**:培养对他人福祉的关切
- **角色扮演**:体验他人立场
- **倾听练习**:全神贯注、不打断、不评判
- 临床领域有专门的共情训练课程

### 在领导力与商业中

- **变革型领导**:共情是核心能力
- **谈判**:理解对方真实诉求 → 创造价值
- **客户体验**:从用户角度设计产品
- **冲突解决**:被理解 = 一半的解决

### 在治疗中

- 罗杰斯人本主义疗法:无条件积极关注 + 共情理解 + 真诚 = 三大条件
- 现代心理治疗共识:治疗联盟比技术更重要,共情是核心

### 局限与争议

- 过度共情 → 决策被情绪左右
- 共情不是万能道德指南(对受害者共情可能让人更暴力)
- 平衡:**共情 + 理性 + 系统思考**

## 和其他概念的关系

- 是人际心理学核心,与 [[依恋理论]] 紧密相关
- 与 [[防御机制]]:过度防御阻碍共情
- 与 [[社会心理学]] 中"基本归因错误"对照 —— 共情减少归因错误
- 与 [[儒家]] 仁、孟子"恻隐之心"概念相通
- 与 [[佛家]] "慈悲"传统衔接
- 在 [[积极心理学]] 中是关系幸福的关键
- 与 [[领导力]]、变革型领导核心能力重叠
- 在 [[现象学]] 中"主体间性"研究有交集
- [[变革型领导]]:个性化关怀维度的心理学根基
- [[组织文化]]:塑造高心理安全感、高互信文化的关键能力
- [[人力资源管理]]:招聘、绩效面谈、员工关系的底层素养
