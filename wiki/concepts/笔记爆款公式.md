# 笔记爆款公式

## 定义

**笔记爆款公式** 是把小红书等内容平台的"爆款笔记"反向工程为可复制结构的方法论。爆款不是偶然——它符合两套机制:

1. **算法侧**:[[小红书推荐机制]] 的 CES 评分(完播率、点赞率、收藏率、评论率、分享率)
2. **心理侧**:[[营销心理学]] 的 [[注意力经济]]、[[损失厌恶]]、[[社会证明]]、[[互惠原则]]

爆款公式的核心是 **"五重钩子"** + **"高价值密度"** + **"互动设计"**。

## 核心要点

### 1. 五重钩子结构

#### a) 封面钩子(决定是否点击,3 秒)
- **大字标题**:封面图直接显示问题/利益/数字
- **强对比**:Before/After、错/对、便宜/贵
- **强情绪**:震惊脸、喜悦、痛苦
- **数字诱惑**:"省 5 万"、"亲测 10 款"
- **冲突感**:"95% 人不知道"、"被坑了"

#### b) 标题钩子(决定是否点击,2 秒)
- 数字开头:"5 个"、"3 步"、"100 元"
- 痛点提问:"是不是你也…"
- 对立反差:"穷人用 vs 富人用"
- 时效紧迫:"2025 必看"、"本月最后一次"
- 身份共鸣:"30 岁油痘肌"、"二胎妈妈"

#### c) 开篇钩子(决定是否完整读,前 3 行)
- 反直觉断言:"减肥别只吃水煮蛋!"
- 强承诺:"看完省 3 个月工资"
- 故事开场:"上周差点被销售坑…"
- 对话感:"姐妹们,我真的劝退…"

#### d) 中段钩子(决定是否看完)
- 每 3-5 行小标题/分点
- 数字编号让人想看完
- 反转/惊喜在中段抛出
- 最干货放在中后段(吊读者下滑)

#### e) 结尾钩子(决定是否互动)
- 提问式 CTA:"你们用过哪个?评论区告诉我"
- 福利预告:"双 11 攻略下篇见"
- 引发讨论:"我觉得 A 更好,你呢?"

### 2. 价值密度公式

爆款不是篇幅长,是 **每秒/每屏价值密度高**。

```
价值密度 = (实用信息 + 情绪触达 + 共鸣体验) / 阅读时长
```

#### 实用类
- 测评对比:5 款产品具体维度对比
- 攻略型:具体步骤 + 价格 + 注意事项
- 避坑型:"我踩过的 N 个坑,看这一篇就够"

#### 情绪类
- 共鸣:"30 岁单身的下午"
- 治愈:"这家店让我重新爱上下班"
- 反讽:"职场新人的迷惑行为"

#### 知识类
- 揭秘:"医美机构不会告诉你的"
- 科普:"为什么 XX 比 YY 贵 10 倍"

### 3. 互动设计

CES 评分中互动权重最高,主动设计互动机会:

| 互动类型 | 设计技巧 |
|---|---|
| **点赞** | 内容引发"对啊!"瞬间 |
| **收藏** | 干货 / 列表 / 攻略型 |
| **评论** | 提问 / 投票 / 求建议 |
| **分享** | 攻略 / 揭秘 / 强烈观点 |
| **关注** | 系列内容预告 |

### 4. 爆款类型矩阵

| 类型 | 特征 | 适合品类 |
|---|---|---|
| **测评对比型** | 多产品深度对比 | 美妆、家电、母婴、3C |
| **攻略干货型** | 步骤 + 工具 | 学习、健身、旅行、做饭 |
| **种草分享型** | 自用安利 | 服饰、家居、零食 |
| **避坑揭秘型** | 反向案例 | 装修、医美、家电 |
| **故事情感型** | 个人经历 | 生活、感情、职场 |
| **争议观点型** | 对抗主流 | 育儿、消费、职业选择 |
| **变美变好型** | Before/After | 减肥、护肤、穿搭 |

### 5. 标题模板(经过验证的 20 个)

1. **数字 + 痛点**:5 个让你看起来贵 10 倍的细节
2. **反差**:月薪 8k vs 月薪 80k 的早晨日常
3. **避坑**:被 X 坑了 3 万,这些雷千万别踩
4. **测评**:亲测 10 款,只有这 3 款值得买
5. **攻略**:0 基础也能学会的 5 步…
6. **身份**:25 岁不再迷茫的 7 个习惯
7. **时效**:2025 一定要打卡的 8 家小店
8. **揭秘**:XX 行业不会告诉你的潜规则
9. **省钱**:每月省 2000 的 5 个方法
10. **改变**:30 天减脂打卡,真实记录
11. **赞叹**:绝绝子!XX 真的太好用了
12. **请教**:在线求助,姐妹们怎么选?
13. **决断**:别再买 X 了,真的不值
14. **对比**:1000 vs 10000 的护肤品差距
15. **极简**:3 件单品搭出 10 套通勤
16. **自检**:如果你符合这 5 条,赶紧改
17. **致谢**:谢谢这个产品救了我的肌肤
18. **问答**:为什么 X 越来越贵?
19. **打脸**:那些被骗了的常识
20. **总结**:用了 100 款后的终极推荐

## 反爆款误区

- **关键词堆砌**:CES 互动跟不上,曝光大但流量来了就走
- **标题党**:一时点击高但跳出率高,长期账号权重下降
- **过度营销**:用户敏感度高,显见广告即败
- **同质化**:跟风同类爆款只能拿小流量
- **忽略时效**:节日/季节内容必须提前 2-4 周

## 当代演进

- **AI 辅助创作**:用 GPT/Claude 生成 20 个标题候选 → 真人筛选 → A/B 测试
- **数据工具**:千瓜、新红、灰豚等爆款分析工具
- **AI 推荐时代**:更精准的人群分发让"局部爆款"门槛降低
- **品牌专业号**:有官方流量池倾斜,公式略不同
