# 品牌专业号

## 定义

品牌专业号(Branded Professional Account)是小红书为认证品牌商家提供的官方账号产品,2022 年由原"企业号"升级而来,经认证后获得专属功能权限——**专业号工具箱、商品橱窗、群聊、私信助手、活动管理、企业头像蓝标、专业号数据后台**。它是品牌在小红书做"内容种草+电商承接+用户管理"全链路运营的官方载体,也是小红书逐步从"种草平台"演进为"种草+成交闭环平台"的核心基础设施。

## 与个人号的核心区别

| 维度 | 个人号 | 品牌专业号 |
|---|---|---|
| 认证 | 无 | 营业执照 + 商标证书 |
| 蓝标 | 无 | 有(认证标识) |
| 商品橱窗 | 无 | 支持(店铺商品挂载) |
| 私信功能 | 基础 | 私信助手 + 自动回复 |
| 群聊 | 个人群 | 品牌群,可设欢迎语、规则、机器人 |
| 数据后台 | 基础 | 专业版数据(粉丝画像、笔记效果、客户管理) |
| 流量加权 | 无 | 部分功能加权(商品笔记、活动) |
| 蒲公英 | 不可作为品牌方 | 可发布投放需求 |
| 聚光投放 | 无 | 主投放主体 |
| 客户管理 | 无 | 客户标签、分群、生命周期管理 |

## 核心功能模块

### 1. 内容运营

- **专业号笔记**:可挂商品、可挂活动、可挂群聊
- **直播带货**:开通后直播售货,接小红书电商或外站
- **品牌账号矩阵**:主账号 + 子账号(产品线、市场、客服),内部互链

### 2. 商品与店铺

- **商品橱窗**:笔记内挂商品卡片,点击直达店铺
- **店铺装修**:首页头图、分类、商品陈列
- **小红书电商闭环**:不出站交易,佣金抽成
- **千帆**(原"小红书直播服务平台"):直播相关数据与运营工具

### 3. 私信与客服

- **私信助手**:关键词自动回复、转人工策略
- **常用语库**:客服话术库,提升回复效率
- **客户标签**:自动+手动标签,分群运营
- **私信卡片**:商品卡、活动卡、群聊卡,引导转化

### 4. 群聊运营

- **品牌群**:粉丝、新客、老客、SVIP 分层
- **群欢迎语 + 关键词机器人**:24 小时基础应答
- **群活动**:打卡、抽奖、新品试用、专属优惠
- **群定向引流**:从笔记导粉、私信进群

### 5. 数据后台

- **粉丝画像**:年龄、性别、地域、兴趣
- **笔记效果**:阅读、互动、转化漏斗
- **客户来源**:笔记 / 搜索 / 推荐 / 私信
- **GMV 与 ROI**:电商闭环数据

## 申请与认证

1. **资质要求**:营业执照 + 商标注册证(R 标或 TM 标)
2. **认证费**:600 元/年(部分类目特殊价格)
3. **行业类目**:目前覆盖大多数行业,但医疗、金融、教育等需特殊审批
4. **审核周期**:1-7 个工作日

## 运营策略框架

### 阶段一:冷启动(0-3 月)

- 内容人设确立(品牌人格化)
- 30-50 篇基础笔记(产品介绍 + 用户教育 + 场景应用)
- 私信引导加群,沉淀首批种子用户
- 蒲公英少量 KOC 配合扩散

### 阶段二:增长期(3-12 月)

- 内容矩阵化:主号 + 子账号差异化定位
- 聚光效果广告投放
- 蒲公英中腰部 KOL 持续合作
- 群聊裂变,搭建私域

### 阶段三:成熟期(12 月+)

- 直播带货常态化
- SVIP 群层级运营
- 大型营销节点策划
- 跨平台导流(微信、淘宝)

## 与品牌私域的关系

- 小红书私域 ≠ 微信私域,但可形成"小红书引流 → 微信沉淀"双层结构
- 高客单类目(美妆、母婴、奢侈品)倾向引导加微信细致服务
- 小红书内闭环类目(快消、新消费)直接群+橱窗成交

## 与其他概念的关系

- 与 [[小红书种草]]:专业号是种草后承接转化的官方载体
- 与 [[小红书广告体系]]:专业号是聚光、蒲公英的主投主体
- 与 [[小红书笔记SEO]]、[[笔记SEO]]:专业号笔记同样需 SEO 优化
- 与 [[私域流量运营]]:专业号 + 群聊 + 私信构成站内私域
- 与 [[私信引流]]:私信助手是关键工具
- 与 [[KOL营销]]、[[达人投放与品牌合作人]]:品牌方主要载体
- 与 [[CRM客户关系管理]]:客户标签与分群是 mini-CRM
