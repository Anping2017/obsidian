# 漏斗优化

## 定义

漏斗优化(Funnel Optimization)是 [[转化漏斗]] 分析的执行篇:在已建立的漏斗上识别哪一层转化率最低或潜力最大,通过假设、实验、迭代,系统性提升整个漏斗的端到端转化率。它是 [[转化率优化]] 与 [[增长黑客]] 的日常工作。漏斗优化的复利效应惊人——每层提升 10%,五层漏斗整体提升 1.61 倍。

## 核心要点

**完整流程(LIFT 模型 / ICE 评分)**:

1. **量化漏斗**:每层留下绝对人数与转化率。
2. **识别瓶颈**:三种判断方法
   - 绝对低:某层 CR 远低于行业基准。
   - 相对低:相比同漏斗其他层显著低。
   - 高潜力低:用户流量大且离行业最佳差距大。
3. **生成假设**:用户为什么在这一层流失?(摩擦?不信任?价值不清?)
4. **设计实验**:[[AB测试]] 一个具体改动。
5. **执行验证**:跑足样本,达到统计显著。
6. **结论与扩散**:成功的改动推广,失败的复盘。

**ICE 优先级评分**:

- **Impact(影响)**:成功后能提升多少 CR(1-10 分)。
- **Confidence(置信)**:基于数据 / 经验,有多确信会成功(1-10 分)。
- **Ease(难度)**:实施成本(1-10 分,简单 = 高分)。
- **ICE = (I + C + E) / 3**,排序优先级。

**漏斗各层典型瓶颈与对策**:

| 漏斗层 | 常见瓶颈 | 优化战术 |
|---|---|---|
| 流量获取 | CTR 低 | 重写广告创意、优化关键词、AB 标题 |
| 着陆页访问 | 跳出率高 | 价值主张前置、首屏速度、FOMO 元素 |
| 注册 | 表单太长 | 字段减少、SSO、社交账号登录 |
| 激活 | 未达 [[Aha Moment]] | 新手引导、空状态优化、激励 |
| 付费 | 价格冲击 | 锚定定价、阶梯套餐、试用 |
| 复购 | 价值未持续 | 内容触达、个性化推荐、会员体系 |

**关键工具**:

- **GA4 / 神策 / 友盟**:行为埋点 + 漏斗可视化。
- **Hotjar / Microsoft Clarity**:热图 + 录屏,发现交互摩擦。
- **Mixpanel / Amplitude**:产品分析,Cohort + 漏斗联动。
- **Optimizely / VWO / Google Optimize(已停)**:AB 测试。
- **GrowthBook / Statsig**:开源 AB 测试。

**LIFT 模型(着陆页优化六维度)**:

- **Value Proposition(价值主张)**:核心价值是否清晰?
- **Relevance(相关性)**:广告→落地页的承诺一致?
- **Clarity(清晰度)**:文案视觉信息层次?
- **Anxiety(焦虑感)**:支付 / 隐私 / 退货焦虑是否被解除?
- **Distraction(干扰)**:是否有不必要的离开按钮?
- **Urgency(紧迫感)**:限时 / 库存稀缺?

**反模式**:

- 同时改多个变量 → AB 结果归因不到具体改动。
- 样本不足就停止实验 → 假阳性。
- 只看 CR 不看 LTV → 优化出大量"白嫖"用户。
- 只关注末端漏斗 → 忽略上游流量质量决定一切下游。
- 优化某层 CR 把流量挤到下一层却没承接能力 → 整体崩盘。

## 和其他概念的关系

漏斗优化是 [[转化漏斗]] 与 [[转化率优化]] 的执行交集,直接服务 [[增长黑客]] 与 [[北极星指标]]。它依赖 [[AB测试]] 验证因果、[[同期群分析]] 验证长期价值、[[归因模型]] 量化各步贡献。

漏斗优化的实验文化与 [[精益创业]] 的 Build-Measure-Learn 循环同源,与 [[精益管理]] 中的 PDCA 形态相通。它是 [[CRO 转化率优化]] 团队的核心工作,与 [[用户画像]]、[[用户旅程地图]] 共享分析视角。

漏斗的"宽口"(流量)与"细管"(转化)是 [[投放]] 与 CRO 的协作主题——投放团队负责把更多人塞进漏斗,CRO 负责让进来的人不流失。错误划分两者职责会导致互相甩锅。
