# Constitutional AI 提示

## 定义

Constitutional AI(CAI)提示是一种应用层的提示工程模式,在 [[System Prompt]] 中明确写出一组"宪法原则"(Constitution),让模型在生成回答前对照这些原则进行自检与修正。该方法借鉴 [[Anthropic]] 训练 [[Claude系列模型]] 时使用的 [[Constitutional AI]] 思想,但运行于应用层而非训练层。

## 与训练层 CAI 的对比

| 维度 | 训练层 CAI | 应用层 CAI 提示 |
|---|---|---|
| 时机 | 模型预训练 | 推理时 |
| 实施方 | 模型厂 | 开发者 |
| 强度 | 改变权重 | 改变输出分布 |
| 灵活性 | 难修改 | 即时调整 |

## 提示模板

```
你必须遵循以下宪法原则:
1. 诚实:不能编造事实,不知道就说"不知道"。
2. 无害:拒绝协助任何违法或致命危险行为。
3. 有用:在前两条之上尽可能提供完整答案。
4. 透明:在不确定时明确标注。

每次生成前先在内部检查:这个回答违反任一原则吗?如违反,请重新生成或拒绝。
```

## 关键技术细节

- **逐条原则**:5-10 条具体可操作,而非抽象口号
- **冲突优先级**:明确诚实/无害/有用的优先级
- **自检指令**:让模型显式输出"我已检查"
- **示例锚定**:配 1-2 个边界示例帮助理解

## 应用场景

- 客服机器人(防止承诺无法兑现)
- 教育产品(避免提供学术不端帮助)
- 医疗咨询(必须建议就医)
- 法律 AI(避免出具具体法律建议)
- 企业内部 AI(信息保密、合规)

## 与其他概念的关系

- 与 [[Constitutional AI]] 同名,源自训练层概念
- 与 [[反思提示]] 类似但更系统化
- 与 [[多智能体提示]] 中的"评判者"角色互补
- 是 [[提示词反模式]] 的对立——主动设计而非临时打补丁
- 与 [[超级对齐]] 目标方向一致,在应用层实现局部对齐

## 局限

- 长 System Prompt 占用 token 预算
- 模型可能"嘴上承认但实际违反"(口惠而实不至)
- 复杂规则间冲突难穷尽
- 多轮对话中宪法可能被遗忘,需周期性强调
