# 端侧AI

## 定义

**端侧 AI**(On-Device AI / Edge AI)是指 AI 模型的推理(乃至轻量训练)直接在用户设备本地完成,而非通过网络发送到云端服务器执行。设备包括手机、PC、可穿戴、汽车、IoT 摄像头、智能家居中枢、机器人等。

它与"云端 AI"是互补关系:
- **云端**:大模型、长上下文、最强能力,但有延迟、成本、隐私顾虑
- **端侧**:小模型、低延迟、隐私优先、离线可用,但能力受限于内存与算力

主流厂商已推出 Apple Intelligence(3B 模型)、Google Gemini Nano、Qwen 1.5B、Phi-3.5、Llama 3.2 1B/3B 等专为端侧优化的版本。

## 核心要点

### 关键技术栈

| 技术 | 作用 |
|---|---|
| **[[模型量化]]** | INT8/INT4/2bit 压缩,显存内存大幅降低 |
| **[[模型剪枝]]** | 移除冗余权重 |
| **[[模型蒸馏]]** | 大模型→小模型知识迁移 |
| **稀疏化 / MoE** | 只激活部分专家 |
| **NPU / Neural Engine** | 专用 AI 加速器,见 [[神经网络引擎]] |
| **优化推理引擎** | Core ML、ML Compute、ONNX Runtime、llama.cpp、MLX |
| **AOT 编译** | 提前编译减少运行时开销 |

### 主流端侧模型(2025)

| 厂商 | 模型 | 参数 | 用途 |
|---|---|---|---|
| Apple | AFM-on-device | ~3B | Apple Intelligence 摘要、改写 |
| Google | Gemini Nano | 1.8B/3.25B | Pixel 录音摘要、智能回复 |
| Microsoft | Phi-3.5 mini | 3.8B | Copilot+ PC |
| Meta | Llama 3.2 | 1B/3B | 移动开源 |
| Qwen | Qwen 0.5B/1.5B/3B | <3B | 阿里端云协同 |
| Mistral | Ministral | 3B | 端侧多语言 |

### 端侧 AI 的优势

| 优势 | 描述 |
|---|---|
| **低延迟** | 无网络往返,毫秒级响应 |
| **隐私** | 数据不出设备,不传云,见 [[iOS隐私机制]]、[[ATT隐私框架]] |
| **离线可用** | 无网络也能用 |
| **成本** | 单次推理零云端费用 |
| **个性化** | 在设备本地用本人数据微调 |
| **能耗** | 较云端整体能耗更低(免去传输) |

### 端云协同(Hybrid)

主流方案不是非此即彼:
- **端侧**:意图识别、轻量摘要、语音唤醒、隐私敏感任务
- **云端**:复杂推理、长上下文、最新知识查询
- **路由器**:任务/意图自动选择端 vs 云,Apple Private Cloud Compute 是代表
- **私有云中间层**:介于端和公有云之间,保护隐私同时获得算力

### 关键挑战

- **内存墙**:手机一般 6-12GB,严格上限
- **散热与电池**:持续推理发热掉电
- **模型小则能力弱**:与云端大模型差距持续存在
- **生态碎片化**:不同设备/系统/框架兼容性
- **更新机制**:端侧模型如何 OTA 升级
- **冷启动**:首次加载延迟

### 商业格局

- **苹果**:Apple Intelligence + Private Cloud Compute,隐私差异化
- **Google**:Gemini Nano + Pixel 深度集成
- **高通**:Snapdragon X Elite + AI Hub
- **联发科**:天玑 NPU + 端侧 LLM
- **PC 阵营**:Copilot+ PC 标志 NPU 进入主流 PC
- **国内**:OPPO/vivo/小米端侧大模型生态

## 应用场景

- **手机助手**:实时翻译、视觉问答、智能回复
- **拍照与影像**:[[计算摄影]]、Live Text、人脸识别
- **生产力**:邮件摘要、文档改写、会议转写
- **可穿戴**:Apple Watch 健康分析、Whisper 端侧字幕
- **汽车**:车机语音、ADAS 视觉
- **IoT**:智能门铃人脸、安防异常检测
- **企业**:终端 DLP、本地 RAG、敏感数据分析

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **能力幻想** | 端侧 ≠ 云端 GPT-4,功能要量入为出 |
| **隐私营销过度** | 不是所有"本地处理"都真的私密 |
| **碎片化** | 不同设备性能差距大,需多版本 |
| **续航与发热** | 持续推理影响用户体验 |
| **越大越好误解** | 设备上 7B 不如优化好的 1B |

## 与其他概念的关系

- 与 [[模型量化]]、[[模型剪枝]]、[[模型蒸馏]]、[[推测解码]] 是核心技术族
- 与 [[大语言模型]] 反向方向——同样是 LLM,优化目标不同
- 是 [[移动营销]]、[[多模态AI]] 在端的落地通路
- 苹果实现:[[神经网络引擎]]、[[A系列芯片]]、[[Secure Enclave]]、[[iOS隐私机制]]
- 与 [[Apple生态系统]]、[[iOS系统架构]] 紧密协同
- [[ATT隐私框架]]、[[隐私优先时代]] 是商业驱动力
- 与 [[AI Agent]] 协同,移动 Agent 大量端侧化
- [[计算摄影]] 是端侧 AI 最早大规模落地的代表
