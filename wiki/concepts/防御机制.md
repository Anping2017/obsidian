# 防御机制

## 定义

**防御机制**(Defense Mechanisms)是 [[弗洛伊德]] 精神分析理论中的核心概念,指**自我(Ego)为减轻焦虑、化解本我与超我的冲突,而采用的无意识心理策略**。它们扭曲、否认或转换现实,使个体免于难以承受的情绪痛苦。后由弗洛伊德的女儿**安娜·弗洛伊德**(1936)系统化为列表。

## 核心要点

### 弗洛伊德人格三结构(背景)

- **本我(Id)**:潜意识的原始冲动,遵循快乐原则
- **自我(Ego)**:意识的现实应对,遵循现实原则
- **超我(Superego)**:内化的道德标准,遵循理想原则
- 三者冲突 → 焦虑 → 自我启动防御机制

### 主要防御机制

| 机制 | 描述 | 示例 |
|---|---|---|
| **压抑(Repression)** | 把不可接受的想法推入潜意识 | 童年创伤被遗忘 |
| **否认(Denial)** | 拒绝承认现实 | 病人不接受患癌事实 |
| **投射(Projection)** | 把自己的想法归于他人 | 自己出轨却怀疑伴侣 |
| **合理化(Rationalization)** | 用看似合理的理由解释行为 | 没考上"那专业不适合我" |
| **置换(Displacement)** | 把情绪转移到次要对象 | 工作受气回家骂孩子 |
| **升华(Sublimation)** | 把冲动转化为社会接受的活动 | 把攻击性转为运动 |
| **反向形成(Reaction Formation)** | 表现与真实感受相反 | 内心讨厌却过分热情 |
| **退行(Regression)** | 回到早期发展阶段的行为 | 成年人在压力下哭闹 |
| **理智化(Intellectualization)** | 用抽象思考避开情绪 | 谈论亲人去世只用医学术语 |
| **认同(Identification)** | 把自己融入他人或群体 | 模仿偶像、加入团体 |
| **隔离(Isolation)** | 把情绪与事件分离 | 描述创伤毫无情绪 |

### 成熟度等级(Vaillant 的分类)

1. **病理性**:否认、扭曲(精神病性)
2. **不成熟**:投射、退行、被动攻击(青少年常见)
3. **神经症性**:压抑、合理化、置换(常人日常)
4. **成熟**:升华、利他、幽默、预期(适应良好)

### 实证地位

- 防御机制概念虽源于精神分析,但部分(压抑、合理化)在认知心理学和神经科学中找到对应
- 现代研究将其视为**情绪调节策略(emotion regulation)**:有适应性的也有适应不良的
- 完全否定与完全接受都不准确,部分机制(尤其升华、幽默)被广泛证实有益

### 在临床与日常

- 心理治疗中识别来访者主导防御机制是重要工作
- 自我觉察自己的防御模式有助于成长
- 不同情境需不同防御:危机时否认可保护功能,长期否认则有害

## 和其他概念的关系

- [[弗洛伊德]] 的精神分析框架的核心组件
- 与人格三结构(本我—自我—超我)直接关联
- 与 [[认知偏差]] 部分重叠 —— 合理化、否认即心智简化
- [[荣格]] 的"阴影"概念延伸了对压抑内容的处理
- 与现代情绪调节(emotion regulation)研究衔接
- [[共情]] 训练中识别他人防御机制是重要技能
- [[正念]] 与冥想被视为对抗过度防御的练习
