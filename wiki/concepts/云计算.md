# 云计算 Cloud Computing

## 定义

云计算(Cloud Computing)是**通过互联网按需提供计算、存储、网络、数据库、应用等 IT 资源,以按使用量付费的方式交付**的计算范式。

NIST 定义五大特征:

1. **按需自助服务**:用户随时申请,无需人工干预
2. **广泛网络接入**:通过标准网络从任何设备访问
3. **资源池化**:多租户共享,动态分配
4. **快速弹性**:近乎无限地扩展或收缩
5. **可计量服务**:按使用量精确计费

## 核心要点

### 三层服务模型

| 层级 | 抽象内容 | 用户负责 | 代表 |
|---|---|---|---|
| IaaS(基础设施即服务) | VM、存储、网络 | OS、运行时、应用、数据 | EC2、Compute Engine、阿里云 ECS |
| PaaS(平台即服务) | 运行时、数据库、消息 | 应用、数据 | App Engine、Heroku、Azure App Service |
| SaaS(软件即服务) | 完整应用 | 仅数据 | Salesforce、Office 365、Notion |
| FaaS(函数即服务) | 单函数 | 函数代码 | AWS Lambda、Cloud Functions |
| BaaS(后端即服务) | 后端组件 | 前端 | Firebase、Supabase |

### 四种部署模式

| 模式 | 定义 | 适用 |
|---|---|---|
| 公有云 | 多租户共享,云厂商运营 | 大多数应用,弹性需求高 |
| 私有云 | 单租户专属,自有或托管 | 强合规、高安全场景 |
| 混合云 | 公有 + 私有,工作负载流动 | 大企业过渡、灾备 |
| 多云 | 跨多个公有云 | 避免锁定、地理覆盖 |

### 三大公有云

| 云 | 优势 |
|---|---|
| AWS | 服务最全、生态最大、市场份额最高 |
| Azure | 企业 Office/AD 集成、Hybrid 友好 |
| Google Cloud | 数据 + AI、K8s 起源 |

中国市场:阿里云、腾讯云、华为云、火山引擎。

### 关键技术与服务

- 计算:VM、容器、[[Kubernetes]]、[[Serverless]]
- 存储:对象存储(S3 类)、块存储、文件存储
- 数据库:RDS、托管 NoSQL、托管数仓
- 网络:VPC、Load Balancer、CDN、DNS
- 消息:Kafka、SQS、Pub/Sub
- AI:模型托管、训练平台、向量数据库
- 可观测性:CloudWatch、Stackdriver、Datadog

### 核心收益

1. **资本支出 → 运营支出**:无需提前买硬件
2. **弹性扩缩**:应对突发流量、季节高峰
3. **全球覆盖**:几次点击部署到全球区域
4. **降低运维负担**:云厂商接管硬件、网络、安全补丁
5. **创新加速**:AI、大数据、IoT 等高级服务即开即用
6. **聚焦业务**:把非差异化重活外包给云

### 风险与挑战

- 厂商锁定(Vendor Lock-in)
- 成本失控(俗称「云账单恐惧症」)
- 数据主权与合规
- 安全责任共担模型理解偏差
- 网络延迟与可用区故障
- 复杂度转移而非消除

## 和其他概念的关系

云计算是过去 15 年最重要的 IT 范式转变,与 [[微服务]]、[[容器化]]、[[Kubernetes]]、[[DevOps]]、[[Serverless]]、[[现代云原生架构|云原生]] 形成完整生态。

[[边缘计算]] 是云计算的边缘延伸,共同构成「云-边-端」体系。[[CDN]] 是云存储与边缘加速的早期形态。

[[大数据]]、[[人工智能]]、[[数据库]] 在云时代实现了「按需弹性」——Snowflake、BigQuery、Databricks、OpenAI API 都是云原生范式的代表。

[[Serverless]] 是云计算抽象层级的极致形态,把基础设施完全隐藏。[[Serverless|FaaS]]、[[Serverless|BaaS]]、[[Jamstack]] 是其衍生模式。

[[安全]] 与合规在云时代有责任共担模型(AWS/客户分别负责的安全责任不同),理解这一模型是上云第一课。
