# 泰勒规则

## 定义

**泰勒规则**(Taylor Rule)由 Stanford 经济学家 **John Taylor** 在 **1993 年** 提出,是描述**央行政策利率应如何回应通胀偏离目标与产出缺口**的简单线性反应函数。它最初是对美联储 1987-92 年实际行为的拟合,后来成为现代央行政策框架的事实标杆——既是研究工具,也是政策评估基准。

## 核心要点

### 经典公式

$$i_t = r^* + \pi_t + \alpha (\pi_t - \pi^*) + \beta (y_t - y^*)$$

其中:
- i_t = 名义政策利率
- r* = 实际均衡利率(自然实际利率)
- π_t = 当前通胀率
- π* = 通胀目标(美联储隐含 2%)
- y_t - y* = 产出缺口(实际 GDP 偏离潜在 GDP 的百分比)
- α = 通胀缺口反应系数(Taylor 1993 取 0.5)
- β = 产出缺口反应系数(Taylor 1993 取 0.5)

### Taylor 原始版本(1993)

$$i_t = 2\% + \pi_t + 0.5(\pi_t - 2\%) + 0.5(y_t - y^*)$$

含义:
- 通胀每超目标 1%,利率提高 1.5%(1% 自动 + 0.5% 反应)
- 产出超潜在 1%,利率提高 0.5%
- 实际利率 r* 假设为 2%

### "泰勒原则"(Taylor Principle)

α + 1 > 1,即名义利率对通胀的反应系数 > 1,等价于**实际利率随通胀同向变动**。

- 满足泰勒原则:通胀上升时实际利率上升,抑制总需求 → 通胀稳定
- 违背泰勒原则:通胀上升时实际利率下降,刺激更多需求 → 通胀脱锚

这是货币政策"决定性反应"的关键属性,是 1980 年代美国通胀稳定的核心。

### 实证拟合

Taylor 1993 发现该规则**精确拟合 Greenspan 时代美联储行为**:
- 通胀偏高时,FFR 偏高
- 衰退时,FFR 偏低
- 是描述性工具,而非美联储声明的规则

### 各国变体

- **欧央行**:重通胀目标(2% 上限),产出缺口反应较弱
- **英央行**:类似欧央行
- **日央行**:长期处于零利率下限,泰勒规则失效
- **新兴市场**:有时加入汇率项,变成"扩展泰勒规则"

### 改进与扩展

**前瞻性版本**(用预期通胀替代当期):

$$i_t = r^* + E_t \pi_{t+k} + \alpha (E_t \pi_{t+k} - \pi^*) + \beta (y_t - y^*)$$

更符合理性预期理论与央行实际操作。

**利率平滑(Inertial Rule)**:

$$i_t = \rho i_{t-1} + (1-\rho) i^*_t$$

加入滞后项,反映央行渐进调整偏好。

**含金融条件**:加入信贷利差、房价等,2008 后讨论较多。

### 与货币主义的对比

| 维度 | 货币主义(Friedman) | 泰勒规则 |
|---|---|---|
| 工具 | 货币供应增长率 | 政策利率 |
| 反馈 | 不反应,固定 m% 增长 | 反应通胀与产出 |
| 目标 | 长期通胀稳定 | 短期 + 长期稳定 |
| 优势 | 透明、可信 | 灵活、抗冲击 |
| 现实 | 1970 年代失败 | 1990 年代起主流 |

### 零利率下限(ZLB)的挑战

2008 后,泰勒规则建议的利率多次低于零,但名义利率有零下限。这导致:
- 货币政策"失能"
- 转向 [[量化宽松|量化宽松(QE)]]、负利率(欧、日)、前瞻指引等非常规工具
- 学界讨论"影子利率"修正泰勒规则

### 泰勒规则的争议

- **r\* 估计困难**:实际均衡利率不可观测,2008 后估计大幅下行
- **产出缺口估计不稳**:潜在产出本身是估计值
- **金融周期未纳入**:2008 前泰勒规则可能"过松",未应对资产泡沫
- **预期形成**:理性 vs 适应性预期下结果不同
- **规则 vs 相机抉择**:Taylor 主张规则,Bernanke 主张约束相机抉择

### 现代政策实践

- 大多央行不公开承诺遵守某个版本,但泰勒规则是关键参考
- 美联储多个版本并行计算,作为决策对照
- 学界 DSGE 模型常用泰勒规则作为政策方程
- "泰勒诊断"用于评估央行行为是否过松/过紧

## 和其他概念的关系

泰勒规则是现代 [[货币政策]] 的核心反应函数,与 [[菲利普斯曲线]] 与 [[奥肯定律]] 共同构成宏观稳定三角。它依赖 [[GDP核算]] 中产出缺口与 [[价格指数与通胀]] 的测度。在 [[凯恩斯主义]]-货币主义之争后,泰勒规则代表"约束的相机抉择"中间立场。它与 [[弗里德曼]] 货币增长规则形成方法对照。在零利率下,它直接关联 [[量化宽松|量化宽松(QE)]] 等非常规工具。它在 [[计量经济学]] 中是著名的"政策反应函数"案例,在 DSGE 模型中是标准方程之一。
