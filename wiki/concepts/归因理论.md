# 归因理论

## 定义

归因理论(Attribution Theory)是社会心理学研究人如何对自己与他人行为做出原因解释的理论体系。基本问题:面对一个行为(成功/失败、亲切/冷漠),人们如何决定它源于人本身、情境还是其他因素?

## 历史发展

### 1. 海德的奠基(1958)
- Fritz Heider《人际关系心理学》
- "朴素心理学家":普通人也是因果分析者
- 核心二分:**内部归因**(personal/dispositional)vs **外部归因**(situational)
- 朴素人倾向把行为归于人(个人化偏差)

### 2. 琼斯与戴维斯的对应推论(1965)
- Edward Jones & Keith Davis
- 对应推论(Correspondent Inference)
- 行为何时直接对应内部特质?
- 关键:选择自由、低社会期望、独特结果、不利结果(揭示真态度)

### 3. 凯利的协变模型(1967)
- Harold Kelley 立方体模型
- 三大信息维度:
  - **共识性**(Consensus):他人在同情境是否相同
  - **特殊性**(Distinctiveness):此人对其他对象是否相同
  - **一致性**(Consistency):此人不同时间是否相同
- **HHL 模式**(高共识、高特殊、低一致)→ 外部归因
- **LLH 模式**(低共识、低特殊、高一致)→ 内部归因

### 4. 韦纳的成就归因(1972)
- Bernard Weiner 三维度:
  - **位置**(locus):内 vs 外
  - **稳定性**(stability):稳定 vs 可变
  - **可控性**(controllability):可控 vs 不可控
- 具体类型:
  - 能力(内、稳、不可控)
  - 努力(内、可变、可控)
  - 任务难度(外、稳、不可控)
  - 运气(外、可变、不可控)
- 不同归因引发不同情绪与未来动机

### 5. 罗特的内外控人格(1966)
- Julian Rotter 控制点(Locus of Control)
- 内控者(internals):相信自己控制结果
- 外控者(externals):相信运气、命运
- 个体差异化的归因倾向

## 主要归因偏差

### 1. 基本归因错误(FAE)
- Lee Ross 1977 命名
- 解释他人行为时低估情境、高估个性
- "他迟到 = 不负责"(忽视交通)

### 2. 行动者—观察者偏差
- 解释自己:更多归因情境
- 解释他人:更多归因个性
- "我迟到是因为堵车;他迟到是因为不负责"

### 3. 自利归因偏差(Self-Serving Bias)
- 成功 → 归因自己(能力、努力)
- 失败 → 归因外部(运气、他人)
- 维护自尊心
- 跨文化:东亚"谦虚归因"较弱但仍存在

### 4. 群体归因偏差
- 内群体好行为 → 内部;坏行为 → 外部
- 外群体反之
- 是 [[偏见]] 的认知基础

### 5. 防御性归因
- 看到不幸事件 → 归因受害者(降低自己受害焦虑)
- "公正世界假设"(Lerner)

## 应用领域

| 领域 | 应用 |
|---|---|
| **教育** | 教师如何归因学生表现影响动机(韦纳) |
| **临床** | 抑郁与负向归因风格(塞利格曼习得性无助) |
| **组织管理** | 绩效评估的归因偏差 |
| **婚姻** | 配偶行为归因模式预测离婚 |
| **健康** | 疾病归因影响应对 |
| **法律** | 陪审团对被告归因 |
| **跨文化** | 东西方归因模式差异 |
| **AI 解释** | 算法决策可解释性 |

## 与其他概念关系

- 是 [[认知主义]] 在社会认知的应用
- 与 [[认知偏差]] 紧密关联(基本归因错误是核心偏差)
- 与 [[首因效应与近因效应]] 都是社会认知现象
- 韦纳三维度与 [[自我效能]]、[[习得性无助]] 紧密联系
- [[认知行为疗法]] 直接修正抑郁性归因
- 影响 [[绩效反馈与改进]] 设计
- 与 [[培训与发展体系]] 学习动机理论结合
- 是 [[领导力]] 公正知觉、信任建立基础
- [[确认偏差]]、[[过度自信]] 与归因偏差相互强化
- [[文化差异]] 中归因模式跨文化变化

## 跨文化研究

- 西方:更倾向个性归因(FAE 强)
- 东亚(中、日、韩):更注重情境归因(FAE 弱)
- 中国农村 vs 城市差异
- 集体主义文化"关系归因"独特模式
- 全球化下归因风格混合演变

## 现代延伸

- 神经科学:mPFC 与 TPJ 在心智化(mentalizing)中的角色
- 大语言模型如何归因?
- 算法决策:让 AI 给出可信"理由"
- 推荐系统中的归因(为何看到这条)
- 归因建模在因果推断中的应用
