# 精益创业

## 定义

**精益创业(Lean Startup)** 由 **Eric Ries** 在 2011 年的同名著作中系统提出,把 [[精益生产]] 的浪费消除思想 + 客户开发(CustDev,Steve Blank)+ 敏捷开发整合为创业方法论。

核心命题:**初创企业是在极度不确定性下设计和运营的临时组织,目标不是执行计划,而是快速学习。** 浪费 = "构建客户不要的东西的所有努力"。

## 核心要点

### Build-Measure-Learn 循环

精益创业的核心引擎,与 [[丰田生产方式]] 中持续改善异曲同工:

```
        想法(Ideas)
            ↓
        Build 构建
            ↓
        产品(Product)
            ↓
        Measure 测量
            ↓
        数据(Data)
            ↓
        Learn 学习
            ↓
       (回到想法,更新假设)
```

关键不是构建快慢,而是**整个循环的速度** —— 学得快比建得快更重要。

### 最小可行产品(MVP)

用最少资源构建,**目的是测试核心假设而非提供完整价值**。MVP 类型:

| 类型 | 描述 | 例子 |
|---|---|---|
| **登陆页 MVP** | 简单网页测概念 | "假设大家关心 X" |
| **解释视频 MVP** | 视频展示未实现的产品 | Dropbox 早期视频 |
| **奥兹国巫师 MVP** | 用户以为是软件,后台人工 | Aardvark 问答 |
| **协调者 MVP** | 极简产品 + 人工运营 | Zappos 早期 |
| **单一功能 MVP** | 实现 1 个核心功能 | Foursquare 早期签到 |

MVP 不是"质量低",而是"功能少 + 学习多"。

### 验证型学习(Validated Learning)

不是问"用户喜欢吗?",而是问"什么假设被验证?":

- **价值假设**:用户真的想要吗?(愿意付钱/留存/推荐)
- **增长假设**:能规模化获客吗?(获客渠道、成本)

每次循环验证或证伪具体假设,推动决策。

### 创新会计(Innovation Accounting)

传统会计衡量历史利润,精益创业需要"过程指标"衡量学习速度:

- **基线指标**:当前转化率、留存率、增长率
- **改进指标**:每次实验的影响
- **决策指标**:坚持(Persevere)还是转型(Pivot)?

避免"虚荣指标"(Vanity Metrics):看起来漂亮但无法指导决策(累计用户、PV 总量)。健康指标是"可执行的"(actionable):**队列分析、漏斗、A/B 测试**。

### 转型(Pivot)的类型

当数据证明假设错误,需要 Pivot —— 不是放弃,而是有方向地调整:

| 类型 | 描述 |
|---|---|
| **放大 Pivot** | 把一个功能变成整个产品 |
| **缩小 Pivot** | 把整个产品变成一个功能 |
| **客户细分 Pivot** | 同样产品换目标客户 |
| **客户需求 Pivot** | 同样客户换需求 |
| **平台 Pivot** | 应用 → 平台 或 反之 |
| **商业架构 Pivot** | B2B ↔ B2C |
| **价值获取 Pivot** | 货币化模式改变 |
| **增长引擎 Pivot** | 病毒/付费/粘性切换 |
| **渠道 Pivot** | 直营/分销/SaaS 切换 |
| **技术 Pivot** | 用新技术解决同问题 |

### 三大增长引擎

精益创业识别三种自我维持增长方式:

| 引擎 | 机制 | 关键指标 |
|---|---|---|
| **粘性引擎** | 留存为王 | 流失率 < 增长率 |
| **病毒引擎** | 用户带来用户 | K 值 > 1 |
| **付费引擎** | LTV > CAC,投入广告 | LTV/CAC > 3 |

不要混合,聚焦一种。

### 与传统创业的对比

| 维度 | 传统(瀑布式) | 精益创业 |
|---|---|---|
| 商业计划 | 5 年详细计划 | 假设清单 + 实验 |
| 产品 | 完整发布 | MVP 快速迭代 |
| 客户 | 上市后了解 | 早期介入 |
| 失败 | 终极失败 | 学习信号 |
| 速度 | 长周期 | 周/月级 |

### 适用边界

精益创业最适合**软件、互联网、轻资产** 创业;在以下领域需调整:

- 医药/航空(安全监管)
- 重资产制造(MVP 难)
- 平台型业务(网络效应需冷启动)
- 深科技(基础研究为主)

## 和其他概念的关系

- 是 [[创业机会识别]] 之后的方法论,与商业模式画布配套使用
- 思想源于 [[精益生产]] 与 [[丰田生产方式]] 的浪费消除哲学
- 与 [[商业模式画布]] 是配套工具:画布表达假设,精益验证假设
- 衍生工具:精益画布(Lean Canvas, Ash Maurya)更聚焦初创
- 与 Customer Development(客户开发)Steve Blank 方法论紧密结合
- 在硅谷文化中与敏捷开发、Scrum 互相强化
- 改变了 [[风险投资]](本 vault 待立)对早期 startup 的评估方式
- 体现 [[管理决策]] 中"假设-实验-学习"的科学方法论
- 在大公司内部演化为"内部创业"(Intrapreneurship)与精益创新
- 概念上回应 [[商业模式创新]] 的实操方法
