# 吠陀

## 定义

**吠陀**(Veda,意为"知识")是 [[印度哲学]] 与印度教的最古老圣典,起源于约**公元前 1500-前 600 年**的雅利安时代。被视为"**天启**"(Shruti),非人作。包括四部本集(Samhitas)与三类附属文献(梵书、森林书、奥义书),奠定了印度此后 3000 年的宗教—哲学—社会基础。

## 四部吠陀

| 名称 | 内容 |
|---|---|
| **梨俱吠陀**(Rigveda) | 1028 首颂神诗,最古老,印欧语系最古文本之一 |
| **娑摩吠陀**(Samaveda) | 祭祀时唱诵的曲调与歌词 |
| **耶柔吠陀**(Yajurveda) | 祭祀仪式的散文公式 |
| **阿闼婆吠陀**(Atharvaveda) | 咒语、巫术、医方 |

## 核心概念

### 1. 祭祀(Yajna)

- 吠陀核心是**祭祀仪式**
- 通过祭祀维护宇宙秩序
- 早期印度社会的核心活动
- 与 [[儒家]] "礼"在仪式与宇宙秩序结构上有可比之处

### 2. 梨陀(Rita)

- **宇宙秩序、真理、规律**
- 涵盖自然、道德、社会
- 是后来"**法**"(Dharma)的远祖
- 与希腊"逻各斯"、中国"道"在功能上类似

### 3. 神祇

- **因陀罗**(Indra):雷神之王
- **阿耆尼**(Agni):火神
- **苏摩**(Soma):祭祀植物—神
- **伐楼那**(Varuna):宇宙秩序之主
- 多神,但不否定一神倾向("**他们用许多名字称呼那一**"——《梨俱吠陀》)

### 4. 哲学萌芽

- "**创世颂**"(Nasadiya Sukta)展现哲学反思
- "**那时既无有也无无**"——质问宇宙起源
- 这是世界文明中最早的形而上学之一

## 吠陀文献的层次

```
吠陀(Shruti)
├── 本集(Samhita):颂诗与公式
├── 梵书(Brahmana):祭祀仪轨与解释
├── 森林书(Aranyaka):隐居者沉思
└── 奥义书(Upanishad):哲学对话
```

各层次反映**从仪式到内省**的演变,从外在祭祀转向内在自我的探索。

## 奥义书的转折

- **奥义书**(约公元前 800-前 500)
- 哲学化的吠陀终篇,故又称"**吠檀多**"(Veda 的尽头)
- 提出**梵我合一**(详见 [[印度哲学]])
- "**Tat tvam asi**"(你即是那)
- 业(karma)、轮回(samsara)、解脱(moksha)三大概念在此成型

## 吠陀的权威性

- "**Shruti**"(天启):权威源自直接听到神
- 与"**Smriti**"(传统记忆,人作)区别
- **婆罗门**(祭司)阶层垄断诵读权
- 这一权威结构维系印度教 3000 年

## 历史影响

### 印度内部

- 印度教所有派别尊吠陀为根
- **吠檀多派**(Vedanta):奥义书的系统化
- **弥曼差派**(Mimamsa):祭祀诠释
- 详见 [[印度哲学]] 正统六派

### 异端传统

- **[[佛家|佛教]]**与**耆那教****反对吠陀权威**
- 但仍在概念上(业、轮回、解脱)继承
- 这是印度宗教最大分裂

### 西方接触

- **18-19 世纪**:东印度公司学者翻译
- **威廉·琼斯**确立印欧语系——梵语与拉丁、希腊同源
- 影响**比较语言学、宗教学**诞生
- **叔本华**深受奥义书影响:称吠陀为"**最高人类智慧**"
- **爱默生**美国超验主义引用

### 现代复兴

- **罗摩克里希纳—辨喜**(Vivekananda):把吠檀多带到西方
- 1893 年芝加哥宗教大会
- 对全球瑜伽、冥想运动的源头

## 与其他古代文明

| 文明 | 圣典 | 时代 |
|---|---|---|
| 印度 | 吠陀 | 前 1500-前 600 |
| 希伯来 | 旧约 | 前 1200-前 200 |
| 希腊 | 荷马 | 前 800 |
| 中国 | 五经 | 前 1000-前 500 |
| 波斯 | 阿维斯陀 | 前 1000 |

吠陀是**印欧文化**最古老连续传统的代表。

## 仪式与冥想

- **火祭**(homa):至今仍在印度举行
- **唱颂**:反复诵读吠陀诗篇,**精确传承几千年**
- **三摩地**(samadhi):后期发展的禅定状态
- 是印度宗教**实践传统**的根

## 现代影响

### 瑜伽

- 现代瑜伽源自吠陀冥想传统
- 全球数亿人练习

### 冥想

- 与 [[正念]] 等现代心理实践有共同源头

### 哲学—心理学交叉

- 提供"自我"的非西方理解框架
- 与 [[心灵哲学]]、 [[积极心理学]] 之"自我超越"对话

## 和其他概念的关系

- 是 [[印度哲学]] 的核心源头
- 与 [[佛家]] 有"反吠陀但承业、轮回"的复杂关系
- 与 [[儒家]] 五经在"圣典—社会"结构上类似
- 与 [[道家]] 在自然秩序观上有可比
- 与 [[西方哲学]] 古希腊神话与早期哲学并列文明萌芽
- 与 [[本体论]]、 [[认识论]] 在"梵我合一"问题上有印度特色
- 与 [[现象学]]、 [[心灵哲学]] 之"自我"问题在印度智慧中的版本
- 与 [[正念]] 现代实践的远祖
- 与 [[积极心理学]] 中"自我超越"主题
- 与 [[语言哲学]] 中梵语与神圣语言议题
- 影响叔本华、爱默生、爱因斯坦(部分)、容格
- 历史定位:与中国五经、希伯来圣经、希腊荷马并列文明源头
