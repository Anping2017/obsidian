# 回归分析

## 定义

**回归分析**(Regression Analysis)是统计学中用一组自变量解释/预测因变量的方法。在金融中无处不在 —— 估计 Beta、检验因子、归因业绩、宏观预测,都离不开它。

## 核心要点

### 线性回归

**形式**:Y = β₀ + β₁X₁ + ... + β_kX_k + ε

**估计方法**:**普通最小二乘(OLS)**,使残差平方和最小。

**关键统计量**:
- **R²**:解释方差占比,衡量拟合程度
- **t 统计量**:单个系数显著性
- **F 统计量**:整体模型显著性
- **残差**:实际值 − 预测值

### 高斯-马尔可夫假设

OLS 估计为 BLUE(最佳线性无偏)需要:
1. 线性
2. 无完全多重共线性
3. 误差零均值
4. 同方差(homoskedasticity)
5. 误差不相关

实际数据常违反同方差与不相关 —— 需要修正(异方差稳健标准误、HAC 标准误)。

### 金融经典应用

**1. 估计 Beta(单因子模型)**
```
R_i,t − R_f = α + β(R_m,t − R_f) + ε
```
β 即资产对市场的敏感度,是 [[资产定价模型|CAPM]] 核心。

**2. 多因子模型**
```
R_i,t = α + β₁·MKT + β₂·SMB + β₃·HML + ... + ε
```
Fama-French 三/五因子模型用回归同时检验多个系统性风险来源。

**3. 业绩归因**
把基金超额收益分解为因子暴露 + α(选股能力)。

**4. 事件研究**
公告前后超额收益是否显著异于零,用回归剔除市场效应。

**5. 宏观预测**
GDP、通胀、利率的多元回归预测。

### 进阶方法

| 方法 | 用途 |
|---|---|
| 加权最小二乘(WLS) | 异方差修正 |
| 广义最小二乘(GLS) | 序列相关修正 |
| 工具变量(IV) | 内生性问题 |
| Probit / Logit | 二元因变量(违约预测) |
| 分位数回归 | 关注尾部而非均值 |
| 面板数据回归 | 同时利用时间和截面信息 |
| Lasso / Ridge / 弹性网 | 高维变量选择,机器学习类 |

### 典型陷阱

- **过拟合**:样本内 R² 高不代表样本外好
- **多重共线性**:自变量高度相关,系数估计不稳定
- **遗漏变量偏差**:重要解释变量缺失,系数估计有偏
- **数据挖掘**:测试足够多模型必然有"显著"结果(谨慎对待 p-hacking)
- **非平稳数据回归**:时间序列上回归非平稳变量易得"伪回归"

## 和其他概念的关系

- 数学基础来自 [[概率论与统计学]]
- 用于估计 [[资产定价模型|CAPM/APT]] 的因子暴露
- 是 [[基本面分析]] 中实证检验的标准工具
- 与 [[绩效评估]] 中的业绩归因紧密相关
