# 心灵哲学

## 定义

**心灵哲学**(Philosophy of Mind)是 [[西方哲学]] 重要分支,研究**心灵的本质、意识的性质、思维的过程、心物关系**等问题。20 世纪以来成为 [[分析哲学]] 最活跃的分支之一,与认知科学、神经科学、 [[人工智能]] 紧密交织。

## 核心问题

### 心物问题(Mind-Body Problem)

- 心灵和身体是同一种实体还是两种不同实体?
- 它们如何相互作用?
- 这是从笛卡尔以来的根本问题

### 意识难题(Hard Problem of Consciousness)

- 大卫·查默斯(Chalmers)提出
- "**为何信息处理伴随主观体验?**"
- 物理过程为何能产生**质感**(qualia,如红色看起来的样子)
- 这是当代心灵哲学最具挑战性的问题

### 意向性(Intentionality)

- 心灵状态指向**对象**(关于…)
- 思想总是关于某事的、信念是关于某事为真的
- 这是布伦塔诺指出心灵的标志
- 与 [[现象学]] 直接相关

### 人工智能能否拥有心灵

- 强人工智能 vs 弱人工智能(Searle 区分)
- **中文房间**思想实验:句法可以模拟,但语义/理解不能
- 与 [[人工智能]]、 [[大语言模型]] 时代的伦理紧迫相关

## 主要立场

### [[二元论]](Dualism)

- 心灵和身体是两种实体(笛卡尔)
- **属性二元论**:一种实体两种属性(查默斯倾向)
- 难题:如何相互作用?

### [[物理主义]](Physicalism)

- 心灵就是物理(神经)状态
- **同一论**:心灵状态 = 大脑状态(Smart、Place)
- 难题:无法解释主观体验

### 功能主义(Functionalism)

- 心灵 = **功能角色**(Putnam、Fodor)
- 心灵状态由其因果作用定义,与具体物质载体无关
- 类比:程序 vs 硬件
- **多重可实现性**(multiple realizability):同一心灵状态可由不同物质实现
- 这是 [[人工智能]] 能否拥有心灵的理论基础

### 取消主义(Eliminativism)

- 民俗心理学(beliefs、desires)是错误的伪理论
- 应被神经科学取代(Churchland 夫妇)
- 极端立场,争议巨大

### 现象主义/性质二元论

- 接受意识的根本独立性
- 但不否认物理是基础
- 查默斯、Strawson 当代代表

### 高阶理论

- 意识 = 对心灵状态的高阶意识(HOT、HOP)
- 解释了反思性的意识层次

## 关键议题

### 自由意志与心灵

- 心灵的因果效力问题
- 决定论 vs 自由意志(详见 [[决定论]]、 [[自由意志]])
- Libet 实验:大脑信号先于意识决定

### 个人同一性

- 时间中的"我"靠什么连续?
- **身体连续论 vs 心理连续论**
- 帕菲特、洛克的经典讨论

### 他心问题

- 我如何知道他人有心灵?
- 类比论证、推论模型
- 与 [[共情]] 的心理学研究互通

### 私人语言论证

- [[维特根斯坦]] 后期重要论题
- 私人(只我能懂)的语言是不可能的
- 削弱主体优先传统

### 嵌入式认知

- 4E 认知:Embodied、Embedded、Enacted、Extended
- 心灵不只在大脑里,延伸到身体、环境、工具
- Clark、Chalmers《扩展心灵》

## 与认知科学的关系

- 20 世纪后期心灵哲学与**认知科学**深度合作
- 心灵哲学提供概念分析、思想实验
- 认知科学提供经验数据、计算模型
- 神经科学:意识神经相关物(NCC)研究
- AI:从符号主义到深度学习,各自心灵哲学预设不同

## 与人工智能的现代张力

- [[大语言模型]] 是否有"理解"?
- 涌现能力是否预示意识?
- 详见 [[幻觉]]、 [[涌现能力]]、 [[人工智能]]
- 这是当代心灵哲学最热议题

## 和其他概念的关系

- 起源:[[笛卡尔]] [[二元论]]
- 与 [[认识论]]、 [[本体论]] 紧密交织
- 与 [[现象学]]、 [[海德格尔]]、 [[萨特]] 主体哲学传统对话
- 与 [[维特根斯坦]] 后期私人语言论证
- 与 [[弗洛伊德]] 潜意识理论形成"意识 vs 潜意识"维度
- 与 [[心理学]]、 [[认知偏差]]、 [[意识与潜意识]] 互通
- 与 [[人工智能]]、 [[大语言模型]]、 [[神经网络]] 紧密相关
- 与 [[佛家]] "心识"理论可作比较
- 与 [[科学方法]] 在意识研究方法上相关
