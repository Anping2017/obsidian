# Odoo Project Forecasting

## 定义

**Odoo Project Forecasting**(项目预测)是 Odoo 项目管理模块的延伸,把**项目任务、阶段、截止日期、人员可用时间、技能、预算**综合规划,生成**甘特图、负荷视图、时间线**,识别资源冲突、人员过载、项目延期风险。它是项目型企业(咨询、广告、IT 服务、建筑设计)的资源调度引擎,把"项目管理 + 人力规划 + 预算控制"合并为一体。

## 核心要点

**预测的核心数据**

1. **任务工时估算**:每个任务计划工时
2. **任务依赖**:前置 / 后置关系决定排序
3. **人员日历**:每员工的可工作日 / 时长 / 假期
4. **人员技能**:任务匹配能完成的人选
5. **项目里程碑**:阶段截止日期
6. **预算限额**:项目人天 / 金额上限

**核心视图**

1. **甘特图(Gantt View)**:横轴时间、纵轴人员或任务,直观看时间冲突
2. **负荷视图(Workload)**:每人每周工时百分比,识别过载(>100%)或闲置
3. **时间线(Timeline)**:跨项目的高层视图

**预测算法**

系统不"自动安排",而是**辅助分析**:
- 输入:任务列表 + 工时 + 截止日 + 资源池
- 输出:每人时间线、潜在冲突警报
- 经理手动调整,系统重算

某些高级版本加入"自动平衡":在不超截止日的前提下重新分配任务给空闲资源。

**与时间表(Timesheet)的整合**

- 预测 = 计划工时
- 时间表 = 实际工时
- 两者对比生成"计划 vs 实际"差异报告
- 长期数据训练估算模型(下次估算更准)

**项目盈利分析**

每个项目实时计算:
- 已发生工时 × 内部成本 = 实际人力成本
- 已开发票 - 实际成本 = 项目利润
- 预测剩余成本 = 剩余工时 × 内部成本
- 预测项目最终利润率

**典型应用场景**

1. **咨询公司**:多顾问分摊到多客户项目,负荷视图防过载
2. **广告创意**:设计师 / 文案 / 客户经理在多 campaign 中切换
3. **IT 服务**:开发者 / 测试 / 项目经理在多迭代中分配
4. **建筑设计**:建筑师 / 工程师 / 制图员按阶段交付

**整合 HR**

- 人员请假在 HR 模块录入后,预测视图自动反映
- 招聘新人后,预测可立即把任务分给候选人("此人入职后可完成 X")
- 离职后任务自动标红"无人执行"

## 与其他概念的关系

Project Forecasting 与 [[Odoo HR与招聘]] 的人员日历、时间表数据互通,是 [[项目管理]] 在 ERP 内的具体落地。预算分析关联 [[Odoo报表引擎]] 的项目盈利报告,工作流关联 [[Odoo工作流]] 的任务状态机。

## 高频陷阱

- 预测仅基于"计划",实际工时不够时项目会延期但预测视图不实时报警
- 人员日历未维护(请假 / 培训未录)→ 负荷分析失真
- 任务工时估算不准是最大问题,需历史数据校准
- 多时区团队的"工作日"定义需谨慎(印度 / 美国 / 中国时区错位)
- 子任务未分配工时则不会出现在负荷视图
