# 斯多葛主义

## 定义

斯多葛主义(Stoicism)是公元前 300 年塞浦路斯的芝诺(Zeno of Citium)在雅典彩绘柱廊(Stoa Poikile)创立的哲学学派,因此得名。它是希腊化—罗马世界 500 年最具影响力的哲学之一,被誉为西方"实践哲学"传统的源头。

## 三大支柱

### 1. 物理学(自然学)
- 宇宙是一个有理性的有机整体
- **逻各斯**(Logos):贯穿宇宙的理性原则
- **决定论**:一切由原因链决定,但人内心可自由
- 周期性宇宙大火与重生(Ekpyrosis)

### 2. 逻辑学
- 语义学、命题逻辑(克律西波斯创立现代命题逻辑前身)
- 强调"清晰印象"作为知识标准
- 真知与意见的区分

### 3. 伦理学(核心)
- **德性是唯一的善**:智慧、正义、勇气、节制
- **激情是错误判断**:愤怒、恐惧、欲望来自错误的价值赋予
- **无关紧要之物**(adiaphora):健康、财富、地位本身既非善亦非恶
- **无激情**(apatheia)与"良好情感"(eupatheia)
- 顺应自然(理性)而生活

## 核心实践工具

| 工具 | 内容 |
|---|---|
| 控制二分法 | 分清"我能控制"(判断、意图)与"我不能控制"(他人、外物、过去) |
| 晨思与夜思 | 早起规划、晚上回顾 |
| 否定可视化 | 想象失去所拥有的(praemeditatio malorum) |
| 自上俯瞰 | 从宇宙视角看渺小烦恼 |
| 普同视角 | 把自己看作世界公民 |
| 态度选择 | "重要的不是发生什么,而是你如何回应" |

## 三大代表人物

### 早期(希腊)
- **芝诺**(前 334-262):创始人
- **克律西波斯**(前 280-207):系统化,被誉为"第二位创始人"

### 罗马时期(著作传世)
- **塞涅卡**(前 4-65):《道德书简》,尼禄老师
- **爱比克泰德**(50-135):前奴隶哲学家,《手册》
- **马可·奥勒留**(121-180):罗马皇帝,《沉思录》

## 与其他学派对比

| 学派 | 核心立场 |
|---|---|
| 斯多葛 | 德性为善,接受命运 |
| [[伊壁鸠鲁主义]] | 快乐为善,远离公共生活 |
| 怀疑主义 | 悬置判断,达到 ataraxia |
| [[柏拉图]]学派 | 理念世界优先 |
| 犬儒主义 | 拒绝习俗,极端简朴 |

## 与其他概念关系

- 影响 [[基督教]] 神学(逻各斯、内省、原谅)
- 经文艺复兴重新发现,成为现代美德伦理基础
- 启蒙时期影响 [[斯宾诺莎]]、[[康德]] 自由观念
- 与 [[儒家]] 修身养性、[[佛家]] 接受苦难有跨文化共鸣
- 现代复兴:Tim Ferriss、Ryan Holiday、CBT 认知行为疗法
- [[认知行为疗法]] 直接借鉴爱比克泰德"困扰我们的不是事物本身,而是我们对它们的看法"
- 与 [[马斯洛]] 自我实现、[[弗兰克尔]] 意义疗法精神同源
- 与 [[决定论]]、[[自由意志]] 经典张力的早期回应

## 当代影响

- 硅谷创业者文化(Holiday《障碍即道路》)
- 军人与运动员心理训练
- "现代斯多葛主义"运动(Modern Stoicism Conference)
- 与 [[正念]] 冥想合流
- 抗逆力(resilience)研究的哲学源头
