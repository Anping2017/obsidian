# 客户生命周期价值

## 定义

**客户生命周期价值**(Customer Lifetime Value, CLV / LTV)是指**单个客户在与企业关系存续期间,为企业贡献的全部现金流的现值**。它把营销视角从"单次交易"扩展到"客户终身关系",是衡量客户长期经济贡献的核心指标。

CLV 与**客户获取成本**(Customer Acquisition Cost, CAC)的比值是评估商业模式可持续性的黄金指标:**CLV/CAC > 3** 通常被视为健康的 SaaS 或互联网公司基线,< 1 则表示客户每多一个就亏损。

## 核心要点

### 基本计算公式

最简版本:

```
CLV = 平均订单价值 × 购买频次 × 客户毛利率 × 客户保留年限
```

考虑货币时间价值的版本:

```
CLV = Σ (年度毛利) / (1 + 折现率)^t   (t 从 1 到客户预期生命)
```

SaaS 简化模型(订阅制):

```
CLV = ARPU × 毛利率 / 月度流失率
```

其中 ARPU = 每用户月均收入。

### 关键变量

- **平均消费金额**(Average Order Value, AOV)
- **购买频次**(Purchase Frequency)
- **客户毛利率**:服务客户的成本扣除后利润率
- **客户保留率**(Retention Rate)与流失率(Churn Rate)
- **客户生命周期长度**:1/流失率 的近似公式
- **折现率**:[[资本成本]],通常用 WACC

### CLV/CAC 比率的解释

| CLV/CAC | 含义 |
|---|---|
| < 1 | 失血,模式不可持续 |
| 1-3 | 偏低,可能投入不足或客户质量差 |
| 3-5 | 健康水平 |
| > 5 | 优秀,但可能投入获客不足,错失增长 |

回本周期(CAC Payback Period)是另一关键指标:CAC ÷ 月度毛利,12 个月内回本通常视为良好。

### 应用场景

**1. 营销预算分配**:不同渠道的 CAC 不同,把预算导向 LTV/CAC 比率最高的渠道。

**2. 客户分层管理**:

- **高 CLV 客户**:VIP 服务、专属经理(参见 [[客户关系管理]])
- **中 CLV 客户**:精准营销提升复购
- **低 CLV 客户**:自动化服务降低成本,或评估退出

**3. 投资决策**:VC 估值 SaaS 公司时,LTV 直接进入 [[企业价值评估]] 模型。

**4. 产品设计**:提升 LTV 的两条路径——
- 增加 ARPU(向上销售、交叉销售)
- 降低流失(产品改进、客户成功)

### 群组分析(Cohort Analysis)

按获客时间分群追踪:

- 不同月份获客的客户保留曲线
- 评估产品迭代是否提升保留
- 识别什么使早期客户更忠诚

### 局限性

- **预测困难**:未来保留率与购买行为存在不确定性
- **隐性价值**:口碑推荐、推荐其他客户等价值难以纳入
- **行业差异巨大**:订阅制 vs 一次性购买、B2B vs B2C
- **可能错失增长**:过度优化 CLV/CAC 可能压抑获客投入,错过窗口期
- **不应单一衡量**:与品牌价值、市场份额等指标综合使用

### 现代发展

- **AI 预测 CLV**:基于行为数据的机器学习模型替代静态公式
- **嵌入式 CLV**:实时仪表板让运营、产品、客服共同关注
- **NPS 与 CLV 联结**:净推荐值高的客户 CLV 显著高
- **生态视角**:客户带来的网络效应(参见 [[平台商业模式]])

## 和其他概念的关系

- 是 [[市场营销]] 数据驱动决策的核心指标
- 与 [[STP战略]] 中"目标市场选择"对接(选择高 CLV 细分)
- 是 [[商业模式画布]] 中"收入来源""客户关系"模块的量化衡量
- 在 [[企业价值评估]] DCF 模型中,可作为收入预测的微观基础
- 与 [[客户关系管理]](CRM)系统数据深度结合
- 折现率使用 [[资本成本]] (WACC)
- 流失率分析涉及 [[行为金融学]] 中的客户决策心理
- [[平衡计分卡]] 客户维度的关键 KPI 之一
- 是 [[平台商业模式]] 中网络效应价值的量化工具
- 数据科学方法(参见 [[回归分析]])是 CLV 预测的基础工具
