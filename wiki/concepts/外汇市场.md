# 外汇市场

## 定义

**外汇市场**(FX / Forex)是不同货币之间兑换的市场。它是**全球规模最大**的金融市场(日均交易量 ≈ 7 万亿美元),全天 24 小时运转,以场外银行间(interbank)为主导。

## 核心要点

### 市场层级

1. **银行间批发市场**:核心,大型银行做市
2. **零售市场**:企业、个人通过经纪商接入
3. **跨市场连接**:东京 → 伦敦 → 纽约,首尾相接形成 24 小时交易

### 主要参与者

商业银行(做市)、[[中央银行]](干预)、跨国公司(贸易/投资)、对冲基金、个人交易者。

### 主要工具

| 工具 | 用途 |
|---|---|
| 即期(Spot) | T+2 交割 |
| 远期(Forward) | 锁定未来汇率,对冲汇率风险 |
| 外汇期货 / 期权 | 标准化衍生工具 |
| 货币互换 | 跨币种利率/本金交换 |

### 报价规则

- **直接报价**:1 单位外币 = X 单位本币(中国大陆采用)
- **间接报价**:1 单位本币 = X 单位外币
- **基础货币**(base) / **报价货币**(quote):EUR/USD 中 EUR 是 base
- **买价(bid) / 卖价(ask)**:做市商的双边报价

### 影响汇率的因素

- 利差(影响套利资金流动)
- 通胀(购买力平价)
- 经济基本面(经常账户、增长)
- 央行政策与市场预期
- 详见 [[汇率决定理论]]
