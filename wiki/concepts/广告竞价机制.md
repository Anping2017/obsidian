# 广告竞价机制

## 定义

广告竞价机制(Ad Auction Mechanism)是搜索广告、信息流广告、程序化广告平台决定"哪个广告中标 + 中标后扣多少钱"的算法规则总称。理解竞价机制是 [[Google Ads]]、Meta Ads、TikTok Ads、[[DSP需求方平台]]、[[RTB实时竞价]] 实战的底层基础,直接决定广告主出价策略与预算消耗效率。

## 三大主流竞价机制

### 1. 第二价格密封拍卖(Vickrey Auction)

- **规则**:出价最高者中标,但只支付第二高出价 + 最小加价(典型 0.01)
- **激励效应**:让广告主真实出价(Truth-Telling)成为最优策略
- **历史**:William Vickrey 1961 年提出,1996 年获诺贝尔经济学奖
- **应用**:eBay 等拍卖平台、Google AdSense 早期模式

### 2. 广义二价拍卖(Generalized Second-Price, GSP)

- **规则**:多位置同时拍卖,第 N 位中标者支付第 N+1 位的报价
- **应用**:Google Ads 搜索结果(2002-2018 年期间)、Yahoo!、百度搜索
- **特点**:
  - 兼顾广告主激励与平台收入
  - 但允许策略性出价(非完全 Truth-Telling)
  - 平台收入与一价拍卖相比通常稍低

### 3. 一价拍卖(First-Price Auction, FPA)

- **规则**:中标者支付自己的出价
- **激励效应**:广告主必须"算"对手会出多少,出价博弈复杂
- **当前应用**:
  - Google Display Network(2019 年从 GSP 切换至 FPA)
  - Meta Ads Auction(广告评级最高者中标,扣费按其报价)
  - 大多数 Header Bidding 实现
  - DSP 程序化购买
- **趋势**:行业逐步从 GSP 转向 FPA,因 FPA 更透明、平台收入更高

## 综合广告评级公式

实际广告平台不只看出价,还融合多维信号:

### Google Ads 公式
```
广告评级(Ad Rank) = CPC 出价 × 质量得分 + 广告附加信息影响 + 上下文相关性
```

### Meta Ads 公式
```
Total Value = 广告主出价 × 估算行动率(eCTR + eCVR)+ 广告质量与相关性
```

### 关键概念

1. **质量得分**(Quality Score, Google Ads):
   - 1-10 分制
   - 三因素:预期 CTR、广告相关性、落地页体验
   - 高质量得分 → 同样出价,排名更高、CPC 更低

2. **预估行动率**(Meta):
   - 平台 ML 预测的点击率与转化率
   - 高预估率 → 出价乘子大,实际扣费低

3. **底价**(Floor Price):
   - 平台设定的最低中标价
   - 保护媒体方收入,防止恶性低价

4. **广告评级阈值**:
   - 排名足够高才能展示
   - 即便最高出价,评级低于阈值也不展示

## 竞价方式选择

| 出价类型 | 适合场景 | 风险 |
|---|---|---|
| 手动 CPC | 控制力高,数据少 | 工作量大 |
| 增强 CPC(eCPC) | 自动按转化概率调整 ±30% | 较温和 |
| 最大化点击 | 流量为目标 | 易消耗预算无效流量 |
| 最大化转化 | 平台 ML 全自动出价 | 黑盒,需信任平台 |
| 目标 CPA | 控制单次转化成本 | 学习期慢 |
| 目标 ROAS | 控制广告 ROI | 数据要求高 |

## 与其他概念的关系

- 与 [[Google Ads]]、[[KOL营销]]、[[搜索引擎营销]]:实施层载体
- 与 [[RTB实时竞价]]:程序化展示广告的实时拍卖
- 与 [[DSP需求方平台]]、[[SSP供应方平台]]、[[Ad Exchange广告交易市场]]:基础设施
- 与 [[展示广告]]、[[搜索广告]]、[[信息流广告]]:不同形态的拍卖应用
- 与 [[博弈论]]([[纳什均衡]]):理论基础
- 与 [[ATT隐私框架]]、[[Cookie退役]]:隐私限制改变信号丰富度,影响竞价精度

## 实战要点

1. **看广告评级而非单一出价**:质量得分提升 1 分往往等同出价提升 30%
2. **创意 A/B 测试**是低成本提升评级的最有效杠杆
3. **落地页体验**是 Google Ads Quality Score 中常被忽视的因素
4. **目标转化与目标 ROAS** 在数据量充足后通常优于人工出价
5. **关注实际 CPC 趋势**,而非单纯报价——竞价机制会"奖励"高质量广告主

## 经济学根源

竞价机制设计是机制设计(Mechanism Design)的应用,核心目标是:
- 帕累托效率(分配给最高估值者)
- 激励相容(激励真实出价)
- 个体理性(不会让人后悔参与)
- 平台收入最大化

不同机制在四目标间权衡。Google 等平台的演化反映了商业目标的变迁——从 truth-telling 优先(GSP)到平台收入优先(FPA)。
