# 销售漏斗 Sales Funnel

## 定义

销售漏斗(Sales Funnel),又称营销漏斗(Marketing Funnel)、转化漏斗(Conversion Funnel),是**把客户从初次接触品牌到最终成交的完整旅程划分为多个递进阶段、并以漏斗形可视化每阶段筛减比例**的分析框架。

「漏斗」的形象意味着每一步都有人流失,顶部最广(认知人数多),底部最窄(成交人数少)。

## 核心要点

### 经典模型

**AIDA 模型**(1898 Lewis 提出,最早的漏斗):

- Attention 注意
- Interest 兴趣
- Desire 欲望
- Action 行动

**现代 SaaS / 数字营销漏斗**:

- TOFU(Top of Funnel)— 认知层:博客、社媒、广告曝光
- MOFU(Middle of Funnel)— 兴趣层:邮件订阅、白皮书下载、试用
- BOFU(Bottom of Funnel)— 决策层:咨询、报价、成单
- 后端:留存、复购、推荐(已超越漏斗,成为飞轮)

### 标准阶段与转化率

| 阶段 | 行为 | 典型转化率 |
|---|---|---|
| 曝光(Impressions) | 看见广告/内容 | 100% |
| 点击(Clicks / Visits) | 进入网站 | 1-5%(广告 CTR) |
| 浏览(Browsing) | 多页面浏览 | 30-60% |
| 兴趣(Lead) | 留资料、试用、订阅 | 2-10% |
| 商机(Opportunity) | 与销售对话 | 20-40%(B2B) |
| 成交(Conversion) | 付款 / 签约 | 10-30% |
| 复购(Retention) | 再次购买 | 视行业 |

### 漏斗分析的价值

1. **定位瓶颈**:转化率最低的环节就是优化重点
2. **分配预算**:数据驱动决定渠道投入
3. **预测流量**:已知最终转化率,反推顶部所需流量
4. **A/B 测试**:针对单一环节做对照实验
5. **跨部门协作**:营销-销售-客户成功有共同语言

### 经典漏斗的局限

- 假设线性流程,但实际客户会跳跃、回流、对比
- 忽略口碑、推荐等横向影响
- 单次成交导向,忽略长期价值
- 无法描述高复杂度 B2B(多角色、多决策点)

### 替代/演化模型

| 模型 | 特征 |
|---|---|
| Flywheel(飞轮) | HubSpot 提出,客户体验驱动循环增长 |
| Customer Journey Map | 描述实际触点与情绪曲线 |
| Bowtie 模型 | 漏斗 + 留存 + 推荐对称形 |
| Pirate Metrics(AARRR) | Acquisition / Activation / Retention / Referral / Revenue |

### 全渠道时代的复杂化

数字时代客户旅程:

- 多设备(手机、PC、电视、智能音箱)
- 多渠道(搜索、社媒、邮件、线下、客服)
- 多触点(平均 7-9 次接触才成交)
- 长决策周期(B2B 可达数月至数年)

[[归因模型]]、[[Marketing Mix Modeling]]、[[转化API]] 是应对这种复杂性的工具。

## 和其他概念的关系

销售漏斗是 [[营销定义与本质|营销]] 与 [[销售管理]] 共享的核心分析框架,与 [[CRM客户关系管理]]、[[转化率优化]]、[[漏斗分析]] 紧密相关。

[[CAC获客成本]]、[[LTV]]、[[ROAS]] 等核心 KPI 都基于漏斗各环节计算;[[AB测试|AB测试]] 是优化单一漏斗节点的标准方法。

[[内容营销]] 中,不同漏斗阶段需要不同内容:TOFU 教育型博客、MOFU 案例研究、BOFU 产品演示;[[搜索引擎优化]] 与 [[搜索引擎营销]] 也按漏斗位匹配关键词意图(信息型 / 商业型 / 交易型)。

[[精准营销]]、[[再营销]]、[[Lookalike人群]] 都是基于漏斗位置定向用户的具体战术;[[消费者行为]] 理论(认知-情感-意动)在漏斗中找到了量化的对照。

[[私域流量运营]]、[[品牌定位]]、[[网络效应]] 改变了传统漏斗的形状——好的产品体验让用户既是终点也是起点(推荐 → 新用户)。
