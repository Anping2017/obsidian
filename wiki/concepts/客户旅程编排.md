# 客户旅程编排

## 定义

客户旅程编排(Customer Journey Orchestration, CJO)是把静态的 [[客户旅程地图实操]] 升级为实时、个性化、跨触点的自动化执行引擎的实践。区别于早期 [[营销自动化]] 的"线性 if-then-then 触发流",CJO 通过事件采集、行为打分、AI 决策实时计算"下一个最佳行动"(Next Best Action, NBA),把客户旅程从可视化模型变成可执行系统。该概念由 Forrester 在 2018 年正式提出,代表厂商包括 Adobe Journey Optimizer、Salesforce Journey Builder、Braze、Insider 等。

## 与传统营销自动化的核心区别

| 维度 | 传统营销自动化 | 客户旅程编排 |
|---|---|---|
| 流程结构 | 线性 if-then-then | 网状状态机 |
| 决策方式 | 规则触发 | 实时 AI 决策(NBA) |
| 客户视角 | Campaign 中心 | 单一客户视角 |
| 跨触点 | 邮件为主 | 邮件+Push+SMS+广告+客服+网站 |
| 数据基础 | CRM 静态字段 | CDP 实时事件流 |
| 个性化粒度 | 规则分群 | 1:1 实时 |

## 核心组件

### 1. 事件采集层

- 网站、App、邮件、广告、CRM、客服等所有触点的事件
- 实时上传到 [[CDP客户数据平台]]
- 关键能力:跨设备/跨渠道身份解析

### 2. 决策引擎

- **规则引擎**:if-then 业务规则
- **预测模型**:流失概率、购买概率、LTV 预测
- **AI 推荐**:基于协同过滤/向量召回的个性化推荐
- **NBA 决策**:综合规则+模型+优先级,选择"此时此刻这个客户应该收到什么"

### 3. 多触点执行

- 邮件、Push、SMS、In-App、网站个性化、广告人群上传、客服建议
- 跨触点频次控制(避免单一客户被过度打扰)
- 失败兜底:首选触点失败,自动切到次选

### 4. 反馈闭环

- 触达后客户反应回流到决策引擎
- 强化学习/Multi-armed Bandit 持续优化策略
- 不同变体的 A/B 测试自动化

## 典型应用场景

### 1. 新客 Onboarding(首次)

```
注册 → 立即欢迎邮件
24h 未登录 → 提醒邮件 + Push
3 日活跃 → 引导核心功能
7 日仍未达成 Aha Moment → 客服主动接触
14 日未召回 → 流失人群广告
```

### 2. 流失预警与召回

```
活跃度突降 → 召回模型预测流失概率
高概率 → 个性化优惠券 + 邮件
召回成功 → 标记并退回主流程
召回失败 → 沉默,3 个月后再激活
```

### 3. 跨品类交叉销售

```
首单 A 品类 → 7 日后推荐 B 品类(基于协同过滤)
B 品类未点 → 14 日后推荐 C 品类
持续无响应 → 进入"低频客户"流程
```

### 4. VIP 客户深度服务

```
LTV 进入 Top 10% → 自动升级 VIP
触发专属客服分配
线下活动邀请
个性化新品首发
```

## 关键技术能力

### 1. 实时性

- 事件 → 决策 → 执行,SLA 通常 <1 秒
- 适合"购物车放弃"、"页面行为"等实时场景

### 2. 全渠道一致性

- 同一客户在邮件、Push、广告中收到协调一致的信息
- 避免某个客户被反复推同一个营销内容

### 3. 频次治理

- 全局频次上限:每客户每天最多 N 条触达
- 跨渠道频次:邮件 + Push 综合不超 X
- 退订/拒绝规则:用户拒绝某类后,所有渠道暂停

### 4. AI 与机器学习

- 流失预测、购买预测、LTV 预测
- 个性化内容生成(标题、正文、商品推荐)
- 自动化创意优化(MAB)

### 5. 实验与优化

- 持续 A/B 测试 + Multi-Variate Testing
- Holdout 测试组验证整体增益

## 实施挑战

### 1. 数据基础

- 没有 CDP 与统一身份解析,CJO 不可能
- 数据碎片化是大多数公司的现实

### 2. 组织协同

- 渠道分属不同部门(EDM 一组、Push 一组、广告一组)
- CJO 需要跨部门统一治理

### 3. 内容生产

- 个性化要求大量内容变体
- AI 内容生产是协同的关键

### 4. 测量复杂

- 多触点协同,归因困难
- 必须用 Holdout 实验法验证整体增益

### 5. 隐私合规

- GDPR/CCPA/PIPL 限制
- 用户授权管理与数据保留期

## 衡量指标

- **NBA 接受率**:客户响应建议的比例
- **跨渠道引导率**:首选渠道到次选渠道的连贯
- **触达频次合理度**:用户疲劳的退订率
- **整体 LTV 提升**:相对 Holdout 组的对照
- **客户满意度 NPS**:CJO 不应损害客户体验
