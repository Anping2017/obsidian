# NLP 自然语言处理

## 定义

**NLP(Natural Language Processing,自然语言处理)** 是 [[人工智能]] 的核心子领域,研究计算机如何理解、生成、操作人类自然语言(中、英、阿等)。它处于语言学、计算机科学、统计学、机器学习的交叉点,目标是让机器在文本和语音两种模态上"读得懂、写得出、答得对"。

NLP 经历四代范式演进:**规则系统(1950—1990)→ 统计方法(1990—2010)→ 深度学习(2010—2018)→ 预训练大模型(2018—至今)**。当前的 [[大语言模型]] 时代,NLP 与生成式 AI 高度融合,但作为基础学科仍涵盖更广的语言任务和理论。

## 核心要点

### 经典任务谱系

- **理解类**:分词、词性标注、命名实体识别(NER)、句法分析、语义角色标注、指代消解。
- **抽取类**:关系抽取、事件抽取、知识图谱构建、信息抽取(IE)。
- **分类类**:情感分析、意图识别、文本分类、垃圾邮件检测。
- **生成类**:机器翻译、摘要、问答、对话、代码生成。
- **检索类**:语义搜索、相似度匹配、文档排序。

### 范式演进

| 时代 | 代表方法 | 特点 |
|---|---|---|
| 规则 | 词典 + 文法 + 正则 | 可解释,难扩展 |
| 统计 | HMM、CRF、SVM、n-gram | 数据驱动,但浅层 |
| 深度学习 | RNN、LSTM、Word2Vec、Transformer | 端到端,语义表示 |
| 预训练 | BERT、GPT、T5、Llama | 通用基座 + 微调 / 提示 |

[[大语言模型]] 把"任务定义"从"训特定模型"变成"prompt 工程",大幅降低 NLP 应用门槛。

### 关键技术基石

- **[[词嵌入]] / [[Embedding]]**:把词或句映射为稠密向量,使语义可计算。
- **Transformer 架构**:自注意力机制取代 RNN,并行化训练,成为现代 NLP 主干。
- **预训练 + 微调**:大规模无监督预训练学语言知识,小数据微调适配下游任务。
- **Tokenization**:BPE / WordPiece / SentencePiece 把字符流切成子词单元。

### 评估体系

- **任务专有**:BLEU(翻译)、ROUGE(摘要)、F1(NER/分类)、Exact Match(QA)。
- **基准合集**:GLUE、SuperGLUE(理解)、[[MMLU基准]](知识)、[[HumanEval基准]](代码)、[[MT-Bench]](对话)。
- **人评 + LLM-as-Judge**:复杂生成任务越来越依赖人评和强模型自动裁判。

## 典型应用 / 主要工具

- **搜索引擎**:Query 理解、语义检索、答案生成,Google、Bing 全栈 NLP。
- **机器翻译**:Google Translate、DeepL、模型翻译已超越统计 MT。
- **客服与对话**:智能客服、Siri/Alexa、ChatGPT 类助手。
- **企业文档**:合同审阅、金融研报抽取、医学病例分析。
- **主流框架**:Hugging Face Transformers、spaCy、NLTK、LangChain、PyTorch、TensorFlow。
- **企业平台**:Azure AI Language、AWS Comprehend、Google Cloud Natural Language。

## 局限与陷阱

- **歧义难解**:语言天然多义、歧义、隐喻,边界场景仍易错。
- **少资源语言**:中英外的小语种数据稀缺,模型质量参差。
- **常识缺乏**:LLM 看似流畅但缺乏世界模型,易"一本正经编造"。
- **偏见传递**:训练语料反映社会偏见,模型放大性别、种族、地域刻板印象。
- **隐私合规**:涉及个人文本(邮件、医疗、聊天),需脱敏与合规体系支撑。
- **计算成本**:大模型推理 + 训练耗费巨大,对中小团队不友好。

## 与其他概念的关系

- 学科归属:[[人工智能]] 三大主分支(NLP、CV、语音/强化学习)之一。
- 现代主力:[[大语言模型]] 是 NLP 当前最强大的统一范式。
- 核心组件:[[Embedding]]、[[词嵌入]]、[[BERT语义搜索算法]] 提供语义表示与检索基础。
- 工程落地:[[RAG]] 把 NLP 检索与生成结合,解决知识时效与幻觉。
- 评估生态:[[MMLU基准]]、[[HumanEval基准]]、[[MT-Bench]] 等共同度量 NLP 模型能力。
- 历史延续:与 [[自然语言处理]] 主条目内容呼应,本页聚焦缩写视角与速览。
