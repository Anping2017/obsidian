# 怀疑主义

## 定义

**怀疑主义**(Skepticism,源自希腊语 skepsis = 探究)是一种**质疑获取确定知识可能性**的哲学立场。它从古希腊皮浪学派"悬置判断",到 [[笛卡尔]] 把怀疑作为方法,再到 [[休谟]] 对因果与归纳的根本质疑,持续推动哲学审视自身根基。

## 核心要点

### 三种主要类型

| 类型 | 主张 | 代表 |
|---|---|---|
| **古典怀疑论** | 知识不可能,应悬置判断(epoché) | 皮浪、塞克斯都·恩披里柯 |
| **方法怀疑** | 怀疑作为寻找确定真理的方法 | 笛卡尔 |
| **温和怀疑论** | 知识可能但有限度 | 休谟 |
| **当代怀疑论** | 通过虚拟假设挑战确定性 | 缸中之脑、诺奇克 |

### 古典怀疑论(皮浪主义)

- **皮浪**(前 360-前 270):随亚历山大东征,接触印度思想
- 核心:任何议题都有同等强度的支持论证 → 应**悬置判断**(epoché)
- 目的:**心灵宁静(ataraxia)** —— 不卷入无解争辩
- 与 [[佛家]] 的"无执"有相似精神

### 笛卡尔的方法怀疑

- 不是为了否定知识,而是为了**找到不可怀疑的基础**
- 三步怀疑:
  1. 感官可错 → 不可信
  2. 我可能在做梦 → 物理世界可疑
  3. 可能有恶魔欺骗我 → 数学也可疑
- 但**"我在怀疑"本身不可怀疑** → "我思故我在"(cogito ergo sum)
- 然后从此重建知识体系
- 详见 [[笛卡尔]]

### 休谟的因果怀疑

- 因果关系不能从经验**演绎**出来
- 我们看到 A 后总有 B,推出"A 引起 B" —— 但这只是**习惯**联想
- 归纳推理无法被证成("归纳问题")
- 也质疑外部世界、自我同一性的根据
- 但休谟仍生活在"自然信念"之下,不真正悬置一切

### 现代版本

- **缸中之脑**:你怎么知道你不是被刺激的脑子?
- **僵尸论证**:可设想物理一致但无意识的存在
- **诺奇克的可能性论证**:在反事实情境中你的信念是否仍真

### 反怀疑论的回应

- **常识哲学**(摩尔):"这是我的手" → 怀疑论否认这比相信它需要更多论证
- **实用主义**:在实践中我们已默认外物存在
- **可错主义**:接受可错性,不要求绝对确定就能有知识
- **可靠论**:信念由可靠过程产生即算知识,不需主观确定

### 怀疑主义的健康功能

- **批判精神**:对权威、迷信、教条的天然解药
- **科学方法**:可证伪精神中的怀疑成分
- **认知谦逊**:不过度自信,留有修订空间
- **与 [[批判性思维]] 同源**

### 极端怀疑的瘫痪风险

- 完全怀疑导致**行动瘫痪**:连"我现在饿了"都不能确定
- 实践需要"够用的真" —— 而非"绝对的真"
- 健康怀疑 = 高度怀疑 + 暂定相信(provisional belief)

## 和其他概念的关系

- 古典怀疑论与 [[佛家]]"无执"有平行
- [[笛卡尔]] 用怀疑作方法,发现 [[二元论]]
- [[休谟]] 的怀疑论挑战归纳,引发 [[康德]] 回应
- 与 [[批判性思维]] 同源
- 与 [[科学方法]] 中可证伪原则相关
- 与 [[认识论]] 中"知识标准"问题直接关联
- 极端怀疑反对 [[第一性原理]] 假设的"基础"
- 在 [[认知偏差]] 对治中:健康怀疑帮助识别过度自信
