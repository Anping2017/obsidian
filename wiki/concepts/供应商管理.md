# 供应商管理

## 定义

**供应商管理(Supplier Management 或 Supplier Relationship Management, SRM)** 指企业从战略到运营层面管理外部供应方关系的系统性活动,涵盖筛选、合同、绩效、发展、退出的全生命周期。

它既是采购职能的核心,也是 [[供应链管理]] 战略的关键支柱;在外包和全球化时代,供应商管理水平直接决定企业成本、质量、灵活性、韧性。

## 核心要点

### Kraljic 矩阵(战略采购分类)

经典工具,按"利润影响"与"供应风险"两维度分类:

|   | **供应风险低** | **供应风险高** |
|---|---|---|
| **利润影响低** | **常规品(Routine)**<br>办公文具、五金 | **瓶颈品(Bottleneck)**<br>专用化学品、少数供应商 |
| **利润影响高** | **杠杆品(Leverage)**<br>大宗采购、议价空间大 | **战略品(Strategic)**<br>核心元件、定制开发 |

| 类别 | 推荐策略 |
|---|---|
| 常规 | 自动化、目录采购、电子招标 |
| 杠杆 | 多供应商竞争、聚合议价 |
| 瓶颈 | 长期合同、风险对冲、寻找替代 |
| 战略 | 战略合作、深度协同、可能合资 |

### 供应商关系谱系

按合作深度从低到高:

```
现货采购 → 优选供应商 → 长期合同 → 战略合作 → 战略联盟 → 合资/并购
```

| 关系类型 | 特征 | 适用 |
|---|---|---|
| 现货采购 | 一次性、价格驱动 | 大宗、低差异化 |
| 优选供应商 | 准入资格、定期评审 | 常规品 |
| 长期合同 | 多年协议、价格条款 | 稳定需求 |
| 战略合作 | 联合开发、共担研发 | 核心组件 |
| 战略联盟 | 股权或深度承诺 | 关键技术 |

### 供应商评估的多维体系(QCDS+)

- **Quality(质量)**:不良率、退货、认证
- **Cost(成本)**:价格、TCO、隐性成本
- **Delivery(交付)**:准时率、提前期、灵活性
- **Service(服务)**:响应速度、技术支持
- **+**:可持续性(ESG)、创新能力、财务健康、风险

### 供应商生命周期管理

```
战略 → 寻源 → 评审 → 合同 → 上线 → 绩效 → 发展 → 退出
```

- **寻源(Sourcing)**:RFI/RFP/RFQ 三阶段
- **绩效记分卡(Scorecard)**:QCDS+ 量化追踪
- **供应商发展(SD)**:协助改善质量、产能、流程
- **退出**:平稳替换、知识转移

### 供应商关系的张力管理

- **价格 vs 关系**:压价过狠破坏长期合作
- **多源 vs 集中**:多源降风险但失规模优势
- **审计 vs 信任**:控制成本与关系成本权衡
- **本地 vs 全球**:成本、税务、政治风险

### 现代趋势

- **供应链可视化**:实时跟踪、数字孪生
- **供应商韧性(Resilience)**:疫情后从效率回归冗余
- **ESG 供应链合规**:碳足迹、人权、反贿赂
- **战略库存(JIC)**:对关键品建立 2-6 个月库存
- **近岸/友岸外包**:地缘政治考量

## 和其他概念的关系

- 是 [[供应链管理]] 的核心子领域
- 战略层面与 [[垂直整合与水平整合]] 决策互补——供应商管理是"不整合"的替代
- 与 [[战略联盟]] 中的纵向联盟重叠
- 关系深度对应 [[价值链分析]] 中"采购"环节的战略地位
- 受 [[Porter五力模型|波特五力模型]] 中"供应商议价权"分析驱动
- 在 [[精益生产]] 与 [[JIT准时制]] 中要求供应商深度协同
- 全球化背景下交叉 [[国际化战略]] 与跨文化管理
- 谈判与关系建立涉及谈判心理学与博弈论
- 数字化采购体系是 [[数字化转型]] 的重要场景
