# 徒步露营

## 定义

徒步露营(Backpacking)是把**全部装备(帐篷 / 睡袋 / 食物 / 水 / 衣物)装入一个背包**,徒步到自然营地过夜的露营方式。区别于汽车营地(可带任何重量)、车露(车作"基地"),徒步露营的核心约束是**负重**——总重通常需控制在体重 20-30% 内,这一约束催生了 **UL(Ultra-Light,超轻量化)** 装备体系与"一物多用"打包哲学。

## 核心要点

**重量分级**

| 级别 | 基础装备总重 | 风格 |
|---|---|---|
| 传统(Traditional) | 12-18 kg | 经典装备,舒适度高 |
| 轻量化(Lightweight) | 7-12 kg | 主流徒步,平衡舒适与重量 |
| 超轻量化 UL(Ultra-Light) | 3-7 kg | 资深玩家,DCF / 钛合金 / 多用途 |
| 极轻量 SUL(Super UL) | 2-3 kg | 极端追求,牺牲舒适 |
| 极限(XUL) | < 2 kg | 比赛级别,夏季短途 |

基础装备 = 不含食物、水、燃料的"永久装备"。

**Big 3 + 1 — 占重最大的四件**

1. **背包(Backpack)**:25-65 L,200g-2kg
2. **帐篷 / 庇护所(Shelter)**:300g-2.5kg
3. **睡袋 / 被(Sleep)**:300g-1.5kg
4. **地垫(Mat)**:200g-700g

这四件占基础装备 60-80% 重量,优化它们效率最高。

**UL 哲学三原则**

1. **多用途(Multi-use)**:一物多用,不带"也许有用"
   - 雨披 = 防雨 + 营地坐垫
   - 餐勺 = 锅铲 + 量勺
   - 头巾 = 帽子 + 围巾 + 毛巾
2. **无奢侈品(No Luxury)**:剃掉"非必需"
   - 不带椅子、桌子、备用衣物
   - 一双鞋通用全程
3. **DIY 与定制**:剪掉背包多余带子、改换轻地钉、自切食物分量

**典型 UL 装备升级链**

| 物品 | 传统 | UL 替代 | 减重 |
|---|---|---|---|
| 帐篷 | 自立 4 杆双层 2.5kg | DCF 单杆金字塔 600g | 1.9 kg |
| 睡袋 | 化纤 1.5kg | 800FP 羽绒 600g | 0.9 kg |
| 地垫 | 充气 R3 600g | 蛋槽泡沫 200g | 0.4 kg |
| 背包 | 80L 内框 2.2kg | 50L 无框 600g | 1.6 kg |
| 炊具 | 气罐炉 + 不锈钢锅 800g | 酒精炉 + 钛锅 100g | 0.7 kg |

**食物与水**

- **食物重量公式**:0.7-1.0 kg/天/人(脱水食品占主流)
- **水**:重(1L = 1kg),携带最少够"到下个水源"即可,沿途取水净化
- **能量密度**:坚果、奶酪、巧克力、即食米面优先

**路线规划**

- **每日里程**:UL 玩家 20-30 km;新手 10-15 km
- **海拔变化**:每升 100 米相当于多走 1 公里(精力消耗)
- **水源点**:必须事先标记,长无水段需多带
- **营地点**:傍晚到达,留时间扎营做饭
- **撤退路线**:每日规划应急下撤路径

**长距离徒步(Long Distance)**

- AT(美国阿巴拉契亚山径,3500 km,5-7 月完成)
- PCT(太平洋山脊,4300 km)
- TMB(勃朗峰环线,170 km,11 天)
- 大五朝(Five Sacred Mountains,中国)
- 这些"thru-hike"对装备 / 体能 / 心智都是极限考验

## 与其他概念的关系

徒步露营是 [[Bushcraft]]、[[Glamping精致露营]] 之外的另一极,装备需求严苛,涉及 [[帐篷类型]] 中 UL 金字塔 / 单杆帐选择、[[睡袋温标系统]] 与重量平衡、[[防潮垫R值]] 与重量平衡、[[户外炊具系统]] 中酒精炉 / 钛炊具优势、[[Leave No Trace原则]] 严格执行。

## 高频陷阱

- "称完发现重 20 kg" → 必有不必要装备,逐件称重砍掉
- 鞋子选错(高帮 / 太硬) → 长距离脚部毁掉行程
- 食物带过多 → 末日吃不完背回去
- 不试装备就上长线 → 帐篷漏 / 睡袋短 / 鞋磨脚
- 忽视"行走时不舒服"——背包重心 / 腰带松紧调不好等于背两倍重
