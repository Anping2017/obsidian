# 个性化推荐系统

## 定义

个性化推荐系统(Personalized Recommendation System)是用机器学习算法,基于用户的历史行为、画像属性、上下文场景,预测每个用户最可能感兴趣的内容、商品、广告、视频,并按预测概率排序展示的系统。它是抖音、小红书、淘宝、Netflix、YouTube、亚马逊、Spotify 的核心算法基础设施。在营销视角下,推荐系统决定了用户看到什么,直接影响 [[转化漏斗]] 顶部触达效率。一句话:推荐系统的好坏决定了内容平台与电商平台的天花板。

## 核心要点

**经典推荐算法演化**:

### 1. 基于规则(Rule-based)

- 编辑推荐 / 运营选品 / 同品类相关。
- 优:简单可控。缺:无法规模化,千人一面。

### 2. 协同过滤(Collaborative Filtering, CF)

- **用户协同(User-based)**:与你相似的用户喜欢什么 → 推给你。
- **物品协同(Item-based)**:你喜欢的商品类似的商品 → 推给你。
- 优:不需要内容理解,纯行为驱动。缺:冷启动问题(新用户 / 新内容无数据)。
- 经典:亚马逊"买了又买"。

### 3. 矩阵分解(Matrix Factorization)

- 把用户-物品评分矩阵分解为用户向量 × 物品向量。
- SVD、ALS 是常用算法。
- Netflix Prize 时代主流。

### 4. 内容召回(Content-based)

- 提取内容特征(关键词、类目、标签),匹配用户偏好。
- 解决冷启动:新内容靠特征推给可能感兴趣的用户。
- 与 CF 互补,通常融合使用。

### 5. 深度学习推荐(Deep Learning)

- DNN(深度神经网络)、Wide & Deep、DeepFM、DIN(深度兴趣网络)、DIEN、SIM(超长行为序列)。
- 字节跳动、腾讯、阿里都已规模化部署。
- 能捕捉复杂非线性关系,但需海量数据 + 强算力。

### 6. 向量召回(Vector Retrieval)

- 用 [[Embedding]] 把用户与物品都嵌入同一向量空间。
- 用 ANN(Approximate Nearest Neighbor)算法在百万级商品中毫秒级找近邻。
- FAISS、Milvus、Pinecone 是流行的 [[向量数据库]]。
- 与 LLM / RAG 同源技术,2023 后成为推荐工业标准。

### 7. 大模型增强推荐(LLM-Enhanced)

- 用 LLM 理解用户长尾意图、生成个性化推荐解释、跨领域迁移。
- 2024-2026 起,字节、阿里、Meta 等都在探索。

**推荐系统典型架构**:

```
用户行为日志 → 特征工程 → 召回(从百万选千)→ 排序(从千选百)→ 重排(业务规则)→ 展示
                ↓
              用户画像 + 物品画像 + 上下文
```

- **召回(Recall)**:从百万级物品快速召回数千候选,要求快(< 50ms)且覆盖广。
- **排序(Ranking)**:对召回的候选用复杂模型预测点击 / 转化概率,精排。
- **重排(Re-rank)**:加入业务规则(多样性、新颖性、商业目标、合规)。
- **展示**:最终用户看到的推荐结果。

**核心目标函数**:

- **CTR**(点击率):基础。
- **CVR**(转化率):电商关键。
- **多目标融合**(GMV = CTR × CVR × Price)。
- **长期价值**(LTV、留存、生态健康)。
- **多样性 / 公平性 / 探索**:避免回声室效应。

**冷启动问题**:

- **用户冷启动**:新用户无历史 → 用注册问卷 / 设备 / 地理位置 / 入口来源做初始画像。
- **物品冷启动**:新内容无数据 → 用内容特征预估 + 强制曝光 → 收集真实数据后切换。
- **系统冷启动**:新平台 / 新场景从零搭建。

**评估指标**:

- **离线**:AUC、NDCG、Recall@K、HR@K。
- **在线 [[AB测试]]**:CTR、CVR、人均点击、人均消费时长、留存。
- **业务**:GMV、ARPU、用户满意度。

**营销视角的推荐系统应用**:

- **首页 Feed 个性化**:每个用户首页内容由其画像决定,极大提升留存与转化。
- **搜索意图扩展**:搜"耳机"也展示"耳机收纳袋"等关联(典型场景的推荐式补充)。
- **个性化邮件 / Push**:每封邮件内容根据用户画像生成 → 见 [[营销自动化]]。
- **再营销人群构建**:推荐系统识别"高购买概率"用户作为 [[再营销]] 种子。
- **定价个性化**:对价格敏感用户给折扣,不敏感用户全价。
- **广告推荐**:程序化广告平台核心,oCPM 出价就是推荐排序模型。

**反模式**:

- **回声室效应**:推荐过度个性化 → 用户内容窄化 → 失去发现新事物的机会。
- **CTR 单目标**:推标题党 → 短期 CTR 高但长期满意度差。
- **冷启动失败**:新用户首页千篇一律 → 流失。
- **公平性问题**:推荐对某类内容 / 某类创作者系统性偏低。
- **黑箱不可解释**:用户不知道为什么被推这个,信任降低。

## 和其他概念的关系

个性化推荐系统是 [[精准营销]]、[[数据驱动营销]]、[[营销自动化]] 的算法基础设施,与 [[CDP客户数据平台]]、[[CRM]] 提供数据上游,与 [[再营销]]、[[Lookalike人群]] 共享底层 ML 模型。

它的算法栈与 [[搜索引擎优化]]、[[搜索广告]] 的排名系统同源——本质都是"在大量候选中按用户预测概率排序"。在 [[小红书推荐机制]]、[[抖音推荐机制]] 等内容平台,推荐系统直接决定流量分发。

[[向量召回]] 与 [[Embedding]]、[[向量数据库]]、[[RAG]] 同属 [[机器学习]] / [[深度学习]] 领域,2023 后大模型时代让推荐与 NLP / RAG 越来越融合。在 [[隐私优先时代]],推荐系统正从"个人级数据"向"群体级建模"转型,Differential Privacy 与 Federated Learning 是技术应对方向。
