# 历史成本

## 定义

**历史成本**(Historical Cost)是会计计量的基础属性之一,指**资产按购置或建造时实际支付的对价(包括税金、运费、安装费等达到可使用状态前的必要支出)入账并保留账面价值**。它是现代财务会计最长期、最广泛使用的计量基础,与**公允价值**并列为两种最重要的计量属性,各有适用领域。

## 核心要点

### 主要特征

- **客观性**:基于真实交易,有发票、合同、付款凭证可核
- **可靠性**:不易被人为操纵
- **可验证性**:外部审计师可独立确认
- **稳定性**:不随市场波动调整
- **简便性**:计量与记账成本低

### 主要缺陷

- **忽视价值变动**:房产几十年不变账面价值,与市值严重脱节
- **通胀失真**:在高通胀环境,历史成本严重低估实物资产
- **不反映现行经营成果**:用历史成本计算的折旧无法反映当期重置压力
- **行业适用性差**:对金融工具、生物资产、农业资产等市价波动大的资产,历史成本意义有限

### 应用领域

历史成本主要用于:
- **固定资产**:厂房、机器、土地(初始入账,后续视情况减值)
- **存货**:多用 [[存货计价方法]] 中的先进先出、加权平均
- **无形资产**:专利、商标、商誉(后续减值测试)
- **长期股权投资**:成本法核算

### 与公允价值的对照

| 维度 | 历史成本 | 公允价值 |
|---|---|---|
| 基础 | 过去交易 | 当前市场 |
| 客观性 | 高 | 中(尤其无活跃市场时) |
| 时效性 | 低 | 高 |
| 易操纵 | 低 | 高(有判断空间) |
| 适用 | 长期持有的实物资产 | 频繁交易、市价可得的金融资产 |

### 计量层次混合的现实

现代会计准则(IFRS / US GAAP / CAS)采用**混合计量**:
- 多数实物资产:历史成本 + 减值
- 多数金融资产:公允价值
- 投资性房地产:可选择历史成本或公允价值
- 生物资产:多用公允价值减处置费用

### 修正历史成本

为缓解长期失真,有几种修正:
- **重估价**:特定资产定期按公允价值重估(如投资性房地产、IFRS 选项)
- **减值测试**:可收回金额低于账面值则减计
- **通胀调整会计**:在恶性通胀经济体强制使用(IAS 29)

### 历史成本原则的哲学根基

历史成本被批评为"过时",但其支持者认为:
- 财务报表是过去的记录,不是估值预测
- 基于交易的客观性是会计公信力的基石
- 估值预测应交给分析师,不是会计师

## 和其他概念的关系

- 是 [[复式记账法]] 框架下的默认计量基础
- 与 [[存货计价方法]]、[[固定资产折旧]] 等具体处理紧密相关
- 与 [[权责发生制]] 共同构成传统会计两大支柱
- 影响 [[资产负债表]] 与 [[利润表]] 的全部金额
- 与 [[财务比率分析]] 中的 ROA、ROE 等指标的解读相关
