# 垄断竞争

## 定义

**垄断竞争(Monopolistic Competition)**:由 Edward Chamberlin 与 Joan Robinson 在 1930s 独立提出的市场结构,具有以下特征:

1. **大量企业** —— 单一企业份额小
2. **产品差异化** —— 通过质量、品牌、地点、服务、设计等区分(给企业有限定价权)
3. **自由进出** —— 长期经济利润趋零

零售、餐饮、出版、消费品、个人服务多属此类。是 [[完全竞争市场]] 与 [[垄断市场]] 间的中间形态,但与 [[寡头垄断]] 区别在于企业数量多、单一企业行为不影响他者。

## 核心要点

### 企业行为

由于产品差异化,企业面临**向下倾斜但弹性较高**的需求曲线:

- 价格上升,部分顾客流向同类竞品(但不全部),需求量下降但不为零
- MR < P,但 MR 比纯垄断更接近 P(弹性更高)

利润最大化条件仍是 **MR = MC**,得到 Q_mc 与 P_mc。

### 短期均衡

可能出现:
- 经济利润 > 0(P > ATC)
- 经济利润 = 0
- 经济损失(P < ATC,但 P > AVC 仍生产)

### 长期均衡

自由进出导致经济利润趋零:

- 短期超额利润 → 新企业带差异化产品进入 → 各企业需求曲线左移并变陡 → 利润减少
- 短期亏损 → 企业退出 → 留存企业需求增加 → 亏损消除

最终长期均衡:

```
MR = MC, P = ATC, P > MC
```

几何上,需求曲线与 ATC 曲线相切于 ATC 下降段(因为 P 仍 > MC)。

### 与完全竞争的差异

| 指标 | 完全竞争 | 垄断竞争 |
|---|---|---|
| 长期 P | = MC | > MC |
| 长期产量 | LAC 最低点 | 低于 LAC 最低点 |
| 经济利润 | 0 | 0 |
| 配置效率 | 满足 | 不满足 |
| 生产效率 | 满足 | 不满足(过剩产能) |
| 产品多样性 | 无 | 丰富 |

**关键权衡**:产品多样性的福利收益 vs. 过剩产能的福利成本。Spence 模型和 Dixit-Stiglitz 模型证明,垄断竞争下品种数与社会最优品种数的关系并不简单 —— 多样性可能不足也可能过度。

### 广告与品牌

广告是垄断竞争的核心策略变量:

- **信息广告**:降低搜索成本,有福利收益
- **说服广告**:改变偏好,福利效应有争议
- **提示广告**:维持品牌存在感

广告增加固定成本(进入壁垒),但可能扩大整个市场需求。是产业组织实证研究的重要主题。

### 产品差异化的类型

- **水平差异化**:不同消费者偏好不同变体(口味、颜色、款式) —— Hotelling 模型
- **垂直差异化**:质量分层,所有人都偏好高质量(但价格不同)
- **服务差异化**:售后、配送、地理位置

地点选择(spatial competition)是垄断竞争的重要变体,Hotelling 海滩模型展示了"位置同质化"倾向。

### 福利分析

垄断竞争产生 [[消费者剩余与生产者剩余#无谓损失]],但比纯垄断小。多样性带来的消费者价值难以纳入传统福利分析。

[[国际贸易理论]] 中新贸易理论(克鲁格曼)以垄断竞争 + 规模经济 + 产品差异化为基础,解释了同类产品的双向贸易现象(如各国互相进出口汽车),是 1980s 经济学重要进展。

## 和其他概念的关系

垄断竞争是 [[市场结构]] 谱系中现实中最常见的形态(占消费品零售大多数),也是 [[完全竞争市场]] 与 [[垄断市场]] 之间的桥梁。它整合了 [[供给与需求]]、[[弹性理论]]、[[成本理论]] 的工具,加入产品差异化要素。

[[市场均衡]] 在垄断竞争下不再 [[帕累托最优]],但增加了产品多样性,是非常态福利分析的经典案例。

[[行为经济学]] 在垄断竞争中作用突出 —— 品牌忠诚、转换成本、参考价格、损失厌恶都是企业差异化定价权的心理基础。

跨域:[[金融市场概述]] 中投资基金行业、保险产品、信用卡、银行零售业务呈典型垄断竞争形态 —— 大量提供商,产品差异化(品牌、收费、服务、附加权益),长期利润压缩至接近经济利润为零;[[商业银行]] 零售存贷款业务在多数发达国家具垄断竞争特征。理财产品、私募基金、ETF 也是经典案例。

新贸易理论与 [[国际贸易理论]] 革命的核心是把垄断竞争作为理论框架,解释了二战后产业内贸易激增现象。
