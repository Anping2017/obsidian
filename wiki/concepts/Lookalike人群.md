# Lookalike人群

## 定义

Lookalike 人群(相似受众,LAL)是广告平台基于"种子人群"(Seed Audience)的特征数据,通过机器学习模型扩散出的画像与种子相似但还未与品牌接触过的用户群体。它是规模化拉新的核心工具——把"小而精的优质客户"批量复制到"大而似的潜在客户",平衡精准度与覆盖量,通常是 [[再营销]] 之外最高 ROI 的拉新方式。

## 核心要点

**种子选择(决定 LAL 质量的第一性原理)**:

- 种子越精,LAL 越准。常见种子:
  - **高 LTV 客户**:Top 20% 付费用户,扩散结果最好。
  - **高活跃用户**:DAU/MAU 高,适合订阅模式。
  - **高复购客户**:适合电商。
  - **完成深度行为的用户**:如完成 Aha 动作、订阅付费。
  - **NPS 高分用户**:态度上高满意。
- **种子人数建议**:Meta 1000+ 起步、最佳 10000-50000;Google Ads 5000+;巨量 200+。
- 种子过小 → 算法无法学到稳定特征。
- 种子过大且杂 → 特征模糊,扩散精度下降。

**扩散比例 — 1% / 3% / 5% / 10%**:

- 1%(最相似 1%):精度最高但量最小,适合精品 SKU。
- 3-5%:常用区间,平衡精度与规模。
- 10%:量大,适合高频次品类,精度大幅下降。
- 实操:同时跑 1%、3%、5%,看哪档 ROAS 最优。

**多种子分层 LAL**:

- LAL 老客户:精准但有限,常 1-2%。
- LAL 加购未付:量大,3%。
- LAL 高 LTV 客户:付费意愿强,1%。
- LAL 高互动用户:适合品牌广告,5%。

**算法原理简化**:

- 种子人群在平台标签体系下是高维特征向量(年龄、性别、设备、兴趣、行为序列)。
- 平台模型学习种子的"特征分布"。
- 在全平台用户中找特征向量距离种子最近的 X% 用户。
- Meta 使用深度学习,Google 用 Smart Bidding 内嵌的 ML,巨量用 oCPM 模型联合优化。

**与 DMP / CDP 协同**:

- 第一方数据(自有 CRM、网站行为)是种子最大宝藏。
- CDP(Customer Data Platform)统一打通跨域数据,生产高质量种子。
- [[转化API]] / S2S 把后端转化数据回传,让 LAL 算法学到真实价值信号。

**关键指标**:

- CTR / CR vs 拉新冷启动:LAL 应高 30-100%。
- ROAS vs 拉新冷启动:LAL 应高 50%+。
- 与种子的重合度:重合度 < 5% 才算扩散成功(否则就是再营销)。

**反模式**:

- 用全站访客作种子 → 信号太弱,扩散等于广撒网。
- 不剔除已购用户 → LAL 中混入大量已转化的人,ROAS 假性高。
- 单一 LAL 跑到死 → 与拉新冷启动一样会衰减,需轮换种子。
- 跨国扩散 → 文化差异让模型失效,必须按市场分别建种子。

**隐私冲击**:

- 客户匹配上传需 hashed 数据,合规性高。
- iOS ATT 后,LAL 主要靠 Meta 自身的非 IDFA 信号(设备、行为、社交图谱)。
- Privacy Sandbox 的 Topics API 等正在替代精确人群定向。

## 和其他概念的关系

Lookalike 与 [[再营销]] 是 DMP 体系两条腿:再营销做窄而深的转化收割,Lookalike 做宽而准的拉新规模化。两者在 [[归因模型]] 中常被错误地相互替代——再营销吃掉本来会自然成交的流量(过誉),LAL 才是真正"做大"的力量(常被低估)。

LAL 依赖 [[精准营销]] 的标签体系、[[用户画像]] 的精细化与 [[CDP客户数据平台]] 的数据底座。它与 [[信息流广告]]、[[搜索广告]] 的人群定向能力共同构成现代 [[程序化广告]] 体系。

种子选取本质上是一个 [[聚类分析]] 问题,扩散是 [[监督学习]] / 协同过滤问题。在 [[B2B营销]] 中,LAL 应用受限,因为 B2B 公司决策方少且画像离散,反而是 ABM(Account-based Marketing)更有效。
