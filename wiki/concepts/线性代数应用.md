# 线性代数应用

## 定义

**线性代数应用**是将线性代数的理论和方法应用于金融领域,解决投资组合最优化、风险分析、因子建模、降维分析等问题的数学工具。它是 [[量化分析]] 的核心数学语言,与 [[微积分应用]]、[[概率论与统计学]]、[[随机过程]] 共同构成金融数学四大支柱。

## 核心要点

### 线性代数基础
- **向量空间**:向量及其运算、线性无关、基与维数
- **矩阵运算**:加法、乘法、转置、逆、行列式、迹
- **特殊矩阵**:单位矩阵 I、对角矩阵、对称矩阵、正定矩阵、正交矩阵
- **线性变换**:变换矩阵、特征向量、特征值、谱定理
- **矩阵分解**:特征值分解、奇异值分解(SVD)、LU、QR、Cholesky

### 金融应用一:投资组合
- **协方差矩阵**Σ:n 个资产的方差-协方差,n×n 对称正定矩阵
  - 对角元素为方差 σᵢ²,非对角为协方差 σᵢⱼ
  - Cholesky 分解 Σ = LL' 用于多资产 [[蒙特卡洛模拟]]
- **投资组合方差**:σ_p² = w'Σw,其中 w 为权重向量
- **最优化(均值-方差)**
  - min w'Σw,s.t. w'μ = R*, w'1 = 1
  - 拉格朗日乘数法或 KKT 条件求解
  - 解析解涉及矩阵逆 Σ⁻¹
- **有效前沿**:风险-收益最优组合的几何曲线
- **资本市场线(CML)** 与 **证券市场线(SML)**:延伸应用

### 金融应用二:风险分析
- **风险分解**:将组合风险按因子或资产分解
  - 边际风险贡献:MCR_i = (Σw)_i / σ_p
  - 成分风险贡献:CCR_i = w_i × MCR_i,且 ΣCCR_i = σ_p
- **风险预算**:基于 CCR 分配风险预算
- **风险平价**(Risk Parity):每个资产贡献相同风险

### 金融应用三:因子模型
- **多因子模型**:R_i = α_i + β_i,1·F_1 + β_i,2·F_2 + ... + β_i,k·F_k + ε_i
  - 矩阵形式:R = α + Bf + ε
  - β 矩阵称为因子载荷矩阵
- **因子风险分解**:协方差矩阵分解为因子风险 + 特异风险
  - Σ = B·Σ_f·B' + D(D 为对角矩阵)
- **Fama-French 三因子/五因子**、**Barra 风险模型**

### 金融应用四:主成分分析(PCA)
- **原理**:对协方差矩阵进行特征值分解,提取主成分
  - Σ = VΛV',V 为特征向量矩阵,Λ 为对角特征值
  - 主成分 = X·V(数据 X 投影到特征向量)
- **应用**
  - 利率期限结构降维(三个主成分:水平/斜率/曲率)
  - 因子识别(找出主导市场的隐含因子)
  - 数据压缩(用少数主成分代表多维数据)
- **奇异值分解(SVD)**:对一般矩阵的分解,A = UΣV'
  - 推荐系统、文本分析、图像处理

### 金融应用五:优化问题
- **线性规划(LP)**:线性目标 + 线性约束,如套利、税务优化
- **二次规划(QP)**:二次目标 + 线性约束,如投资组合最优化
- **半正定规划(SDP)**:协方差矩阵需正定约束
- **凸优化**:更广泛的凸目标 + 凸约束,数值求解器(CVXPY、Gurobi)

### 数值方法与软件
- **数值稳定性**:矩阵条件数、奇异性问题
- **稀疏矩阵**:大规模问题的高效存储与运算
- **并行计算**:GPU 加速大规模矩阵运算
- **软件**:MATLAB、Python(NumPy/SciPy)、R、Julia

## 和其他概念的关系

线性代数应用是 [[投资组合理论]] 的数学语言——马科维茨的均值-方差最优化本质上是二次规划,涉及协方差矩阵的逆。 [[资产定价模型]] CAPM、APT、Fama-French 多因子模型的数学基础都是线性代数。

它与 [[微积分应用]] 紧密配合——多变量优化既需梯度(微积分),也需矩阵(线性代数)。 [[概率论与统计学]] 中的多元正态分布、回归分析都需要矩阵运算。 [[回归分析]] 的最小二乘解 β̂ = (X'X)⁻¹X'y 是线性代数核心公式。

[[蒙特卡洛模拟]] 多资产路径生成需要 Cholesky 分解协方差矩阵。 [[期权定价]] 的多资产期权(篮子期权、彩虹期权)定价依赖矩阵运算。 [[衍生品风险管理]] 中的多资产组合 Greeks 也涉及线性代数。

[[投资组合风险管理]] 中的风险预算、风险平价、有效前沿构建都是线性代数应用。 [[绩效评估]] 中的归因分析常用 Brinson 模型,涉及矩阵分解。 [[量化分析]] 中的因子投资、Smart Beta 大量使用 PCA 与因子模型。

[[随机过程]] 中的多维布朗运动也涉及矩阵运算。 [[金融科技]] 中的机器学习(神经网络、SVM、PCA 降维)本质上是大量矩阵运算。线性代数为这些应用提供了高效、清晰的数学表达,是定量金融工程师必备技能。
