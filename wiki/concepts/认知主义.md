# 认知主义

## 定义

**认知主义**(Cognitivism)是 20 世纪 50-60 年代兴起的心理学流派,标志了对 [[行为主义]] 的"**认知革命**"反叛。其核心立场:**心智是信息处理系统**,可通过研究内在的**知觉、注意、记忆、思维、问题解决**等过程来理解行为。它与计算机科学、 [[人工智能]]、语言学共同孕育了现代**认知科学**。

## 兴起背景

### 行为主义的局限

- [[行为主义]] 排斥内在心理过程,但语言习得、复杂问题解决无法仅用 S-R 解释
- 乔姆斯基对斯金纳《语言行为》(1959)的批判:语法不能由强化习得

### 三个推动力

- **计算机科学兴起**:为"心智 = 信息处理"提供模型
- **数学—逻辑发展**:图灵机、香农信息论
- **语言学革命**:乔姆斯基的转换生成语法

### 标志性时刻

- **1956 年 MIT 研讨会**:乔姆斯基、纽厄尔、西蒙等同台,认知科学的诞生
- 米勒《神奇的数字 7±2》(1956):工作记忆容量
- 奈瑟《认知心理学》(1967):学科确立

## 核心模型

### 信息处理模型

- 类比计算机:**输入 → 编码 → 处理 → 存储 → 输出**
- 心智有**容量限制**(注意、工作记忆)
- 信息有**多级处理**(感官记忆 → 短时记忆 → 长时记忆)

### 多级记忆模型(Atkinson & Shiffrin,1968)

- **感官记忆**:几百毫秒,容量大
- **短时记忆/工作记忆**:7±2 单位,30 秒左右
- **长时记忆**:几乎无限容量,可持续终身

### 长时记忆类型

- **陈述性**(declarative):语义记忆 + 情景记忆
- **程序性**(procedural):"如何做"的技能
- **隐性记忆**(implicit):不需有意识提取

### 加工层次理论(Craik & Lockhart,1972)

- 不是结构性容器,而是加工**深度**
- 浅层(语音)< 深层(语义)
- 深加工记忆更牢

## 重点研究领域

### 注意

- **选择性注意**:只能聚焦少量信息
- **分散注意**:多任务的代价
- 鸡尾酒会效应、Stroop 任务

### 记忆

- 编码—存储—提取三阶段
- **遗忘曲线**(艾宾浩斯)
- **错误记忆**(Loftus 重建模型)—— 影响法庭目击证人证词研究

### 问题解决

- **算法 vs 启发式**(详见 [[启发式]])
- 心理表征、问题空间
- 顿悟问题

### 决策

- **卡尼曼—特沃斯基**:启发式与偏差
- **前景理论**:损失厌恶
- 这部分与 [[行为经济学]]、 [[卡尼曼]] 直接相关
- 详见 [[认知偏差]]、 [[损失厌恶]]、 [[可得性启发]]、 [[锚定效应]]

### 语言

- 乔姆斯基的句法结构
- 语义、语用、阅读理解
- 心理语言学的诞生

### 推理

- 演绎(沃森选择任务)、归纳、因果推理
- **双系统理论**:系统 1(快、直觉)vs 系统 2(慢、分析)
- 详见 [[启发式]]、 [[卡尼曼]]

## 与其他流派的关系

| 流派 | 关键差异 |
|---|---|
| [[行为主义]] | 反对其忽视内在过程 |
| [[精神分析]] | 反对其无意识中心,认知主义关注**有意识**信息处理 |
| [[人本主义心理学]] | 互补:认知关注机制,人本关注意义 |
| 认知神经科学 | 现代延伸:补上脑机制 |

## 治疗应用:认知行为疗法(CBT)

- 贝克(Aaron Beck)、艾利斯(Albert Ellis)创立
- 抑郁、焦虑由**认知扭曲**(catastrophizing、过度概括等)引起
- 治疗 = 识别并修正认知扭曲
- 是当代实证支持最强的心理治疗
- 详见 [[认知行为疗法]]

## 现代延伸

### 认知科学

- 认知主义 + 神经科学 + AI + 语言学 + 哲学 + 人类学 = **认知科学**
- 统一研究"心智"

### [[人工智能]]

- 早期符号主义 AI 与认知主义同源
- 纽厄尔、西蒙的"通用问题求解器"(GPS)
- 后来连接主义([[神经网络]])崛起,与认知主义关系复杂化
- 详见 [[赫伯特·西蒙]]

### 嵌入式认知(4E Cognition)

- Embodied、Embedded、Enacted、Extended
- 反对纯计算式信息处理
- 与 [[现象学]] 主体—世界关系相通

### 认知神经科学

- 用脑成像(fMRI、EEG)定位认知过程
- 把认知主义带入神经层面

## 批评

- **过度计算化**:忽视情感、身体、文化
- **生态效度低**:实验情境与日常脱节
- **个体主义**:忽视社会与文化对认知的塑造

## 和其他概念的关系

- 与 [[行为主义]] 是 60 年代后的取代关系
- 与 [[精神分析]] 在心智理论上方法迥异
- 与 [[人本主义心理学]] 互补
- 与 [[认知偏差]]、 [[损失厌恶]]、 [[启发式]]、 [[锚定效应]]、 [[可得性启发]]、 [[卡尼曼]] 直接相关
- 与 [[皮亚杰]]、 [[皮亚杰认知发展]] 在认知发展研究上相承
- 与 [[认知行为疗法]]、 [[认知失调]] 是其延伸
- 与 [[人工智能]]、 [[神经网络]]、 [[Transformer架构|Transformer]] 在信息处理模型上同源
- 与 [[赫伯特·西蒙]] 跨学科工作直接相关
- 与 [[行为经济学]] 是其在经济学的延伸
- 与 [[语言哲学]]、乔姆斯基语言学血缘
- 与 [[心灵哲学]] 之"功能主义"在结构上相同
- 历史定位:[[心理学]] 流派之"认知革命",当代主流之一
