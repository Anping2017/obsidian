# 程序化广告 Programmatic Advertising

## 定义

程序化广告(Programmatic Advertising)是**通过自动化软件平台、基于数据与算法实时竞价购买与销售在线广告位**的广告投放方式。它取代了传统的「人工对接、固定 CPM、合同制」广告购买,把广告交易转化为类似金融市场的实时拍卖。

到 2024 年,北美 80%+ 的数字展示广告通过程序化方式售卖。

## 核心要点

### 关键角色

| 角色 | 职能 |
|---|---|
| Advertiser 广告主 | 购买广告 |
| DSP(Demand-Side Platform) | 帮广告主自动竞价,代表 The Trade Desk、DV360 |
| SSP(Supply-Side Platform) | 帮发布商最大化收益,代表 Magnite、Xandr |
| Ad Exchange 广告交易所 | 撮合双方,代表 Google AdX |
| Publisher 发布商 | 提供广告位(网站、App、CTV) |
| DMP(Data Management Platform) | 整合用户数据 |
| CDP(Customer Data Platform) | 第一方数据平台 |
| Ad Verification | 防作弊、可见度核查(IAS、DV) |

### 主要购买方式

| 方式 | 说明 |
|---|---|
| RTB(Real-Time Bidding,实时竞价) | 公开竞价,毫秒级完成 |
| PMP(Private Marketplace,私有市场) | 受邀竞价,质量保证 |
| Programmatic Direct(程序化直采) | 固定价、保证量,但程序化交付 |
| Preferred Deal(优先交易) | 优先购买权,固定价 |

### RTB 流程(简化)

1. 用户访问网页
2. 网页插槽(Ad Slot)向 SSP 发请求
3. SSP 把请求广播到多个 Ad Exchange / DSP
4. 各 DSP 在 100ms 内基于用户画像决定是否出价、价格几何
5. 最高出价获胜,广告物料即时返回
6. 用户看到广告,点击/曝光数据回流

整个过程在浏览器加载时间内完成,通常 < 200ms。

### 广告类型

- **展示广告(Display)**:Banner、Native、富媒体
- **视频广告**:YouTube、流媒体内贴片
- **CTV(联网电视)**:Roku、Amazon Fire、智能电视
- **DOOH(数字户外)**:程序化购买地铁站、楼宇屏
- **音频广告**:Spotify、podcast
- **零售媒体广告(Retail Media)**:Amazon、Walmart 等内部广告网络

### 竞价机制演进

- **First-Price Auction**:出价多少付多少(2018 后主流)
- **Second-Price Auction**:付次高价(传统 Google AdX)
- **Header Bidding**:让多个 SSP 同时出价,提升发布商收益

### 隐私时代的挑战

- **iOS ATT**:IDFA 受限,移动应用归因难
- **Cookieless**:Chrome 第三方 cookie 终结(Privacy Sandbox)
- **GDPR/CCPA**:必须用户同意才能用 cookie 与个性化广告
- **Universal ID 替代方案**:UID 2.0、ID5、LiveRamp ATS

行业从「拼细粒度个人数据」转向「上下文广告 + 第一方数据 + Cohort」。

### 程序化的优势

- 规模化:一次设置,全球数千网站投放
- 实时优化:数据驱动,不停调价
- 精准度:用户画像匹配
- 透明度(理论):每次曝光可追溯
- 成本效率:消除中间人手续费

### 痛点

- **广告欺诈**:机器流量、虚假曝光,行业损失上百亿美元
- **品牌安全**:广告可能出现在不合适内容旁
- **黑箱**:DSP/SSP/Exchange 各取一段费用,广告主真实成本不透明
- **隐私合规**:用户追踪边界
- **AI 生成内容污染**:垃圾站点抢占广告费

## 和其他概念的关系

程序化广告是 [[数字营销]] 的核心组件,与 [[搜索引擎营销]](Google Ads)、[[社交媒体营销]](Meta、TikTok)并列。

[[转化API]] 是程序化广告在隐私时代的关键升级——用服务端数据弥补 cookie 与 IDFA 损失;[[归因模型]] 决定如何评价程序化广告的真实贡献。

[[Lookalike人群]]、[[再营销]]、[[受众定向]] 都建立在程序化基础上;[[CAC获客成本]] 与程序化效率紧密相关。

[[品牌定位]] 与 [[品牌权益]] 在程序化时代需要平衡——精准转化广告挤压品牌广告预算,长期可能损害品牌资产(Binet & Field 的 60/40 法则)。

[[隐私优先时代]]、[[GDPR]]、[[ATT隐私框架]] 重塑了程序化的合规边界;Privacy Sandbox 是 Google 在 cookieless 后的下一代程序化基础设施实验。
