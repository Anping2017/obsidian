# 连带销售

## 定义

连带销售(Cross-sell / Add-on Sales / Attach Rate)指在客户购买主商品的同时,销售员推荐并销售相关配件、服务、延保、增值产品的行为。它是零售业提升 ARPU(每客户平均收入)与毛利率最有效的战术之一——因为客户已处于决策完成、信任建立、付款准备的"购买兴奋期",此时附加销售的转化率比独立销售高 5-10 倍。手机店连带销售比例(Attach Rate)往往决定店铺净利润。

## 核心要点

**手机店典型连带品类**:

### 1. 配件类(高毛利、高 Attach Rate)

- **手机壳**:成本 5-30 元,售价 30-200 元,毛利 70-90%。
- **钢化膜 / 水凝膜 / 高清膜**:成本 3-20 元,售价 30-150 元。
- **充电器 / 数据线 / 充电宝**:原装 vs 第三方,客户教育空间大。
- **耳机 / 蓝牙耳机**:与手机品牌 / 颜色匹配。
- **车载支架 / 充电器**:车主刚需。

### 2. 服务类(低成本、高粘性)

- **延保(Extended Warranty)**:1-2 年额外保修,毛利极高。
- **碎屏险 / 进水险 / 整机意外险**:与第三方保险公司分账。
- **以旧换新承诺**:1 年内回收同型号高于市场 10%。
- **数据迁移服务**:免费 → 增值(指纹/Face ID 录入、应用恢复、备份订阅)。

### 3. 增值套餐

- **手机 + 配件 + 服务三件套**:打包价 vs 单独购买,显得超值。
- **会员套餐**:月度 / 年度卡,绑定持续到店。

**核心战术 6 法**:

### 1. FAB 介绍法

- **Feature(功能)**:这是钢化膜。
- **Advantage(优势)**:抗 9H 硬度,防摔抗刮。
- **Benefit(利益)**:屏幕维修动辄 800+,贴膜只要 80,1/10 成本保护。

### 2. 损失规避(Loss Aversion)

不强调"加这个有什么好处",强调"不加可能损失什么":

- "屏幕一摔就要 800 修",而钢化膜 80。
- "电池 1 年衰减 30%,用快充更耗电",建议买原装慢充。
- "新手机指纹刚录,数据迁移做不好后面要重来"。

### 3. 锚定 + 对比

- 销售员先拿 200 元的高端壳介绍,然后说"如果觉得贵,这款 80 也很好"——客户买中档(50%-70% 概率)。
- 把 100 元配件描述为"日均 0.3 元"。

### 4. 默认选项(Default)

- 套餐预包配件,客户主动减项 vs 主动加项,前者保留率更高。
- "我已经把贴膜钢化膜放了一份,如果不需要可以拿掉"。

### 5. 限时配套(Bundling)

- "买手机送贴膜" → 客户感觉占便宜。
- 实际成本贴膜 5 元,毛利不损。

### 6. 时机把握

- **试机 / Demo 时**:演示功能时自然引出"这个建议加个保护"。
- **付款前**:确认订单时一句"再来一个",阻力最小。
- **付款后取机时**:已成交无戒心,推荐数据迁移 / 保险。

**Attach Rate 度量**:

- **件数 Attach**:平均每单连带件数(健康线 ≥ 1.5)。
- **金额 Attach**:连带销售额 / 主商品销售额(健康线 ≥ 15%)。
- **品类 Attach Rate**:贴膜 / 壳 / 充电器 / 保险各自的连带率。
- **店均 vs 个人**:个人 Attach 远低于店均说明销售员需要培训。

**KPI 设计**:

- 不要只奖励主商品销售额(销售员只卖贵机器,不连带)。
- 不要只奖励连带件数(销售员塞低价配件凑数)。
- **奖励连带毛利额** + **客户满意度评分**双维度,才是健康激励。

**反模式**:

- **强卖 / 推不需要的配件**:客户回家发现不实用 → 退货 + 差评。
- **每个产品都推全套**:客户被压力,反而买基础款流失。
- **连带成功率低却归罪销售员**:没培训 / 没话术 / 没奖励机制。
- **不区分客户类型**:商务人士与学生需要的连带差异巨大。

**心理学根基**:

- **承诺一致性**:既然买了主商品,继续买配件保持决策一致。
- **认知失调消除**:已花 3000 买手机,再花 200 加保险显得"理性"。
- **峰终定律**:连带后赠品给惊喜 → 离店感受峰值更高。

## 和其他概念的关系

连带销售是 [[销售技巧]] 和 [[价格谈判技巧]] 的进阶,也是 [[零售门店运营]] 单店利润的关键杠杆。它与 [[消费者行为]] 中的"决策疲劳"、"承诺一致"、"损失厌恶"深度绑定,是 [[营销心理学]] 在零售场景的实操化。

它对应数字营销的 [[Up-sell / Cross-sell]] 自动化—— Amazon 的"购买此商品的用户也买了"、电商详情页"看了又看",都是连带销售的算法版本。在 [[CRM客户关系管理|CRM]] 中,连带销售数据是 [[用户画像]] 的细化维度,识别"配件忠诚客户"。

[[客户终身价值]](LTV)的提升一半来自复购,一半来自每次连带——连带销售直接抬升 LTV。在 [[二手回收以旧换新]] 业务中,连带销售可绑定回收 + 新机 + 配件的三合一套餐。
