# 变革管理

## 定义

**变革管理**(Change Management)是指**有计划、有组织地引导个人、团队或组织从当前状态过渡到目标状态**的系统过程。它的核心命题是:

> **变革的难点不是设计目标,而是让人接受和实现目标**

70% 以上的组织变革被认为以失败告终(McKinsey 等机构反复印证),因此变革管理成为现代领导者的关键能力,也是 [[战略管理]] 战略落地的瓶颈。

## 核心要点

### 经典理论框架

**1. 勒温三阶段模型(Lewin 1947)**

最早的变革理论,把变革视为打破平衡-改变-重建平衡:

- **解冻**(Unfreeze):打破现有惯性,制造变革紧迫感
- **变革**(Change):实施新做法、新结构、新行为
- **再冻结**(Refreeze):把新状态制度化、文化化

**2. 科特八步法(Kotter 1996)**

哈佛商学院 [[约翰·科特]] 在《领导变革》一书中提出,被引用最多的实操框架:

| 步骤 | 内容 |
|---|---|
| 1. 制造紧迫感 | 让组织看到不变革的危机 |
| 2. 组建领导联盟 | 建立强有力的指导小组 |
| 3. 制定愿景 | 描绘清晰、令人振奋的未来 |
| 4. 沟通愿景 | 用各种渠道反复传播 |
| 5. 授权员工行动 | 移除障碍,使变革者能行动 |
| 6. 创造短期成果 | 早期胜利建立信心 |
| 7. 巩固成果 | 不庆祝过早,继续推进 |
| 8. 制度化 | 把新做法嵌入文化 |

**3. ADKAR 模型(Hiatt 2003)**

聚焦个体变革,Prosci 公司提出的微观模型:

- **A**wareness 认知:为什么要变?
- **D**esire 意愿:愿意参与吗?
- **K**nowledge 知识:知道怎么做?
- **A**bility 能力:能做到吗?
- **R**einforcement 巩固:如何维持?

**4. McKinsey 7S 模型**

变革涉及七要素的整体协调:战略、结构、系统、风格、员工、技能、共同价值观。任一要素不到位都会拖累变革。

### 变革阻力

变革失败的主因是阻力,可分四层:

| 层次 | 来源 | 应对 |
|---|---|---|
| 个人 | 习惯、利益、能力恐惧 | 沟通教育、培训、激励 |
| 组织 | 结构、流程、制度刚性 | 结构调整、流程再造 |
| 文化 | 价值观、行为模式 | 文化重塑、领导示范 |
| 技术 | 系统、技能差距 | 技术升级、技能培训 |

### 变革沟通的关键

研究显示,**变革沟通频次、清晰度、双向性**是变革成功的最大相关因子。

- **What**:讲清"为什么变"远比"变什么"重要
- **How often**:沟通频次至少为日常的 5-10 倍
- **Who**:中层管理者是变革沟通的关键节点
- **Channel**:多渠道结合(全员会、小团队、一对一)

### 变革节奏

- **激进式变革**:快速、全面、自上而下,适合危机情境
- **渐进式变革**:小步快走、试点先行,适合稳定环境
- **混合式变革**:核心要素激进 + 配套渐进

### 数字化变革的特殊性

- 速度更快、影响更广
- 涉及业务模式根本改变(参见 [[商业模式画布]])
- 要求 [[组织文化]] 从层级走向网络
- 数据与算法成为新的决策权来源

### 实施成功要素

- 高层强力支持
- 清晰愿景和路线图
- 中层激活与赋能
- 持续沟通透明
- 早期可见胜利
- 容错与学习文化
- 不轻易宣布"成功"
