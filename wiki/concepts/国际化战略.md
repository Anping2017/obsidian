# 国际化战略

## 定义

**国际化战略(International Strategy)** 指企业跨越国界开展经营活动的战略选择,涉及"为何走出去"、"去哪里"、"如何进入"、"如何组织"四个核心问题。

Bartlett 与 Ghoshal 的经典框架按"**全球整合压力**(Global Integration Pressure)" vs "**本地响应压力**(Local Responsiveness Pressure)" 两维度,划分四种战略类型。

## 核心要点

### 四种国际化战略类型(I-R 框架)

|   | 本地响应压力低 | 本地响应压力高 |
|---|---|---|
| **全球整合压力低** | **国际战略**(International)<br>母国创新→海外延伸 | **多本土战略**(Multi-Domestic)<br>各国独立运营 |
| **全球整合压力高** | **全球战略**(Global)<br>标准化、规模化 | **跨国战略**(Transnational)<br>整合 + 响应 + 学习 |

| 类型 | 特征 | 代表 |
|---|---|---|
| 国际战略 | 母国基地输出,海外简单复制 | 早期可口可乐、麦当劳进入新市场 |
| 多本土战略 | 各国子公司高度自治,产品本地化 | 联合利华、宝洁早期 |
| 全球战略 | 全球统一产品/品牌,集中采购生产 | 苹果、英特尔、华为芯片 |
| 跨国战略 | 全球效率 + 本地响应 + 跨国学习,理想但难 | IBM、ABB、IKEA |

### 进入模式(Entry Modes)谱系

按**承诺/控制度从低到高**:

```
出口 → 许可/特许经营 → 战略联盟/合资 → 独资子公司(并购或新建)
```

| 模式 | 投入 | 控制 | 风险 | 适用 |
|---|---|---|---|---|
| 出口 | 低 | 低 | 低 | 试水阶段、运输成本低 |
| 许可经营 | 极低 | 低 | 中(技术泄露) | 知识产权可保护 |
| 特许经营 | 低 | 中 | 中 | 服务业、成熟模式(快餐) |
| 合资 | 中 | 中 | 中 | 政治敏感、需要本地资源 |
| 独资 | 高 | 高 | 高 | 长期承诺、控制核心 |

### CAGE 距离框架(Ghemawat)

评估两国"距离"的四维框架,影响战略选择:

- **C**ultural(文化):语言、宗教、规范、信任
- **A**dministrative(政治制度):政体、贸易协议、监管
- **G**eographic(地理):距离、时区、气候、基础设施
- **E**conomic(经济):收入水平、市场规模、产业结构

距离越远,投资越要审慎或本地化越深。

### 国际化的常见动机

| 动机类型 | 内涵 |
|---|---|
| **市场寻求** | 海外需求、规模扩张 |
| **资源寻求** | 自然资源、廉价劳动力、技术人才 |
| **效率寻求** | 全球分工、利用要素差异 |
| **战略资产寻求** | 海外品牌、研发能力、专利 |
