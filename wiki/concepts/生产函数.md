# 生产函数

## 定义

**生产函数(Production Function)**:在给定技术条件下,描述生产要素投入(劳动 L、资本 K、土地、原材料等)与最大可能产出 Q 之间映射关系的函数。

```
Q = f(L, K, T, ...)
```

它是企业层面与宏观层面共同的核心工具 —— 微观上推出 [[成本理论]] 与企业供给,宏观上构成 [[经济增长理论]](索洛模型、内生增长)的基础。

## 核心要点

### 短期 vs. 长期

- **短期**:至少一种要素固定(通常资本 K̄);唯一可变要素假定为劳动 L
- **长期**:所有要素均可变,可调整厂房、技术、规模

### 短期生产:总产量、平均产量、边际产量

```
TP = Q = f(L, K̄)
AP = TP/L
MP = dTP/dL
```

**边际产量递减规律**:固定其他要素,持续增加可变要素后,其边际产量必然递减。这是经济学最基本的物理-技术约束。

三阶段划分:
- **第 I 阶段**:MP 上升,TP 加速增长(规模报酬递增段)
- **第 II 阶段**:MP 递减但仍为正,TP 增速放缓(理性生产区域)
- **第 III 阶段**:MP < 0,TP 下降(投入过度)

理性企业必然在第 II 阶段生产,且最终选择由 [[成本理论]] 与市场结构决定。

### 长期生产:等产量曲线与 MRTS

**等产量曲线(Isoquant)**:产生相同产出的所有要素组合轨迹。其斜率绝对值为**边际技术替代率**:

```
MRTS = MPL/MPK = −dK/dL
```

含义:保持产出不变,增加 1 单位劳动可减少多少资本。MRTS 递减→等产量曲线凸向原点。

要素替代关系特例:
- **完全替代**:MRTS 为常数,等产量线为直线
- **完全互补**(列昂惕夫):MRTS = 0 或 ∞,等产量线为 L 形

### 规模报酬

所有要素同比例 λ 倍变化时产出的反应:

| 类型 | 数学条件 | 经济含义 |
|---|---|---|
| 规模报酬递增 | f(λL, λK) > λf(L, K) | 大规模更经济(自然垄断常见) |
| 规模报酬不变 | f(λL, λK) = λf(L, K) | 一次齐次,完全竞争长期均衡 |
| 规模报酬递减 | f(λL, λK) < λf(L, K) | 管理跨度受限 |

注意:规模报酬关注**全部要素**同比例变化,边际产量递减关注**单一要素**变化,二者完全不同。

### 经典函数形式

- **柯布-道格拉斯**:Q = A·L^α·K^β,规模报酬由 α+β 决定,要素替代弹性 = 1
- **CES**:常替代弹性,涵盖前两种为特例
- **列昂惕夫**:Q = min(aL, bK),要素无替代

A 称为**全要素生产率(TFP)**,反映技术水平,是 [[经济增长理论]] 增长核算的核心。

## 和其他概念的关系

生产函数是 [[成本理论]] 的对偶 —— 给定要素价格,从生产函数可对偶导出成本函数(谢泼德引理)。这一对偶关系把技术约束转化为经济成本。

[[市场结构]] 各形态的供给曲线均源自生产函数:[[完全竞争市场]] 的供给即 MC ≥ AVC 部分;[[垄断市场]] 的产量决策由 MC = MR 给出,而 MC 来自生产函数。

宏观层面,聚合生产函数 Y = F(K, L) 是 [[经济增长理论]] 索洛模型核心方程的来源;TFP 增长率(索洛余值)是衡量技术进步贡献的标准指标。

跨域:[[企业价值评估]] 中 DCF 模型的自由现金流预测,本质上需要预测企业的生产能力增长,与生产函数密切相关;[[资本结构理论]] 中 MM 定理依赖生产决策与融资决策可分性,而生产函数定义了前者。
