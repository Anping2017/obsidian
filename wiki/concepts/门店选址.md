# 门店选址

## 定义

门店选址(Store Location Selection)是实体零售/服务业开店前最关键的战略决策——所选位置决定了门店未来 5-10 年自然客流的天花板。零售业有句老话:"成功 = 位置 + 位置 + 位置"。错误选址几乎不可能用经营能力弥补。手机店、餐饮、便利店、服装店均共用核心评估框架,只是权重不同。

## 核心要点

**五大核心要素**:

### 1. 客流量(Foot Traffic)

- **核心指标**:每小时通过该位置的人流数。
- **测量方法**:
  - 现场计数(工作日 / 周末分别在 11am、3pm、7pm 计 30 分钟,推算总量)。
  - 平台数据(高德地图开放平台、腾讯位置大数据)。
  - 同行业实地参考(看同区域已开门店的客流分布)。
- **基准**(以中国二线城市为例):
  - 一类商圈(王府井、解放碑):3000+ 人/小时。
  - 二类商圈(社区中心):500-1500 人/小时。
  - 三类商圈(街边小区):100-500 人/小时。

### 2. 可见度(Visibility)

- 招牌可见距离 ≥ 30 米。
- 不被树 / 信号灯 / 邻店招牌遮挡。
- 拐角位 vs 直线街:拐角位曝光面积 × 2,租金溢价 30-50% 但常值得。
- 上下楼层差异:一楼 > 地下一层 > 二楼以上。手机店尤其要一楼。

### 3. 便利度(Accessibility)

- **公共交通**:300 米内有地铁站 / 公交站。
- **停车便利**:商场地下车库、街边即停即走、电瓶车停放点。
- **过马路无障碍**:无栅栏 / 中央隔离带阻隔。
- **进店摩擦**:无台阶 / 无玻璃门压迫感 / 入口宽敞。

### 4. 商圈匹配(Trade Area Match)

- **目标用户密度**:周边 3 公里内目标客户数量。
- **消费能力匹配**:商圈平均消费水平与产品价位带契合。
- **互补业态(Complementary)**:手机店与电脑城、3C 维修、配件批发互利。
- **竞争密度**:同业过密(走半条街 5 家手机店)→ 价格战;过疏 → 没形成 "买手机就来这条街" 的认知。
- **流量带动者(Anchor)**:大超市 / 影院 / 书店 / 餐饮聚集会持续带客流。

### 5. 租金与回本(Cost & ROI)

- **租金 / 客流比**:同区域内对比 — 王府井贵但客流值,郊外便宜但客流低。
- **租金 / 月销售额比**:零售一般 8-15%,租金占比 > 20% 几乎注定亏损。
- **递增条款**:一般每年涨 5-10%,总租期内复利惊人。
- **押金 + 装修 + 设备投入**:回本周期建议 ≤ 18 个月。
- **退出成本**:违约金、装修折损、设备搬迁。

**进阶分析方法**:

- **GIS 商圈分析(地理信息系统)**:用美团 / 大众点评 / 高德的 POI 数据,绘制 1km / 3km 商圈内目标用户密度热力图。
- **客流时段分布**:工作日午晚 / 周末全天的客流形态决定营业时间。
- **A/B 选址验证**:有条件下,先开"快闪店"或"小店面"试 1-2 个月,验证流量假设。

**手机店选址的特殊考量**:

- **目标人群特征**:25-50 岁中等收入为主,商圈选择偏中端而非高端商圈。
- **维修业务空间需求**:需要 5-10㎡ 后场操作区,纯橱窗店做不了维修。
- **二手回收信任建设**:街区固定门店比临时摊位更受信任,选址应稳定可见。
- **竞品距离**:适当距离(同业聚集 + 个体差异)而非贴脸。
- **配件供应商邻近**:深圳华强北、北京中关村、杭州数码城等批发市场附近成本低。

**反模式**:

- **唯租金低**:省了租金,客流没了,日均零客户。
- **跟风网红商圈**:网红流量与目标客户错位,Z 世代逛得多但买手机的少。
- **不实地观察**:只看地图与平台数据,没算交叉路口的真实通行情况。
- **不签长期租约**:短租 1 年 → 涨租被动;长租 5 年 → 锁定优惠。
- **忽视周边业态变迁**:旁边餐厅倒闭、市政整改、地铁延期 → 商圈变冷。

**财务模型**:

- 月毛利 = 月销售额 × 毛利率
- 月净利 = 月毛利 - 房租 - 工资 - 水电网 - 装修分摊 - 营销 - 其他
- 投资回本周期 = 总投资 / 月净利
- 健康线:回本周期 ≤ 18 个月,前 6 个月不亏损。

## 和其他概念的关系

门店选址是 [[零售门店运营]] 与 [[营销渠道]] 战略的交点——线下渠道的可达性由选址决定。它直接影响 [[到店率]]、[[客流量]] 与 [[销售漏斗]] 顶部输入。

它与 [[竞争分析]] 的"商圈竞品分布"和 [[市场调研]] 的"目标客户地理画像"互为输入。在 [[本地SEO]] 与 [[Local Pack本地包]] 时代,线上的"附近搜索"流量也部分由门店物理位置决定——门店离用户越近,Google / 百度越倾向推荐。

[[全渠道营销]] 中,门店选址决定 [[O2O]] 自提与同城配送的便利性。线下门店与电商的关系也在选址决策中考虑:核心商圈门店做品牌 + 体验,郊外仓储门店做配送中心。
