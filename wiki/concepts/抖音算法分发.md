# 抖音算法分发

## 定义

抖音算法分发(Douyin Algorithmic Distribution)是抖音(及其国际版 TikTok)将创作者发布内容投递给用户的核心机制,以"**分级流量池递推**"为骨架——每条新内容首先被推入一个 200-500 人的初始流量池(基础观看池),根据这一池的核心数据指标决定是否进入下一更大流量池,如此层层递推。理解算法分发是创作者、品牌、信息流广告投放(千川/Feed)的实战基础。

## 流量池递推机制

### 初始池(0-500 视频曝光)

- 系统先冷启动测试,推送给与创作者标签匹配的小批量用户
- 数据观察重点:**完播率**、点赞、评论、关注、转发
- 通过门槛 → 进入下一级池

### 递推路径(典型分级)

```
500 → 1000-3000 → 5000-10000 → 5万-10万 → 50万-100万 → 100万+
```

每一级的"通过率"约为 5-15%,即 100 个新视频中只有 5-15 个能从 500 池晋升到 5000 池,从 100 万池往上更稀少。

### 单一指标卡点

如果某指标(如完播率)突然跌破基线,即便其他指标好,也会停止递推。算法是"全维度通过制",非单维度优势制。

## 五大核心指标

### 1. 完播率(Completion Rate)

- 公式:看完视频的人数 / 看到视频的人数
- 不同时长基准:< 15s 期望 > 50%,15-30s 期望 > 30%,> 60s 期望 > 15%
- 提升:开头 1-3 秒钩子、节奏紧凑、避免长尾介绍

### 2. 互动率(Engagement Rate)

- 包括点赞率、评论率、收藏率、转发率
- 综合权重:转发 > 收藏 > 评论 > 点赞
- 提升:互动话题、争议性观点、问句结尾

### 3. 关注率(Follow Rate)

- 视频带来的新关注数 / 视频曝光数
- 较低门槛,但对账号长期权重影响大
- 提升:人设清晰、价值连续、引导关注

### 4. 复看率(Repeat View)

- 同一用户多次观看
- 短视频的"高难"指标
- 提升:信息密度高、节奏快、可反复看的"金句"

### 5. 主页访问率(Profile Visit)

- 视频引导观众访问账号主页
- 间接驱动关注与多视频观看
- 提升:置顶视频强、主页头图清晰、Bio 利益点明确

## 标签匹配机制

### 内容标签(由系统提取)

- 视频本身被打多重标签:垂直类目(美妆/3C/汽车)、人物属性(性别/年龄)、场景(室内/室外)、情绪(温情/搞笑)等
- 提取来源:封面 OCR、视频画面识别、字幕/语音、文案

### 用户标签(行为画像)

- 用户被打类似标签集
- 标签组合成兴趣指纹
- 高频互动 → 强信号 → 标签加权

### 匹配:用户标签 ∩ 内容标签

- 完全匹配:进入推荐
- 边缘匹配:小流量测试,根据完播决定是否更广推
- 不匹配:不推送

## 自然流 vs 商业流

| 维度 | 自然流(抖加之外) | 商业流(千川/品牌广告) |
|---|---|---|
| 成本 | 0 | 付费 |
| 流量来源 | 推荐池 | 信息流硬广 |
| 入口 | 推荐 Tab | 推荐 Tab(标"广告") |
| 算法权重 | 内容质量 + 互动 | 出价 + 创意质量 + 落地体验 |
| 持久度 | 长尾,可一直推 | 投放停即停 |
| 适用 | 内容种草、IP 建设 | 销售转化、流量获取 |

## 账号权重养成

### 标签清晰度

- 持续发同主题内容,30-50 篇后标签锐利
- 标签清晰 → 推送精准 → 互动率高 → 流量上行循环

### 黄金 7 天

- 新账号前 7 天发布 3-5 条优质内容,定调权重
- 不要乱发:旅游账号发美食视频会"标签污染"

### 起号策略

- **垂直深耕**:同一主题 30 天 30 篇
- **第一爆款**:首条破 100 万曝光对账号是关键里程碑
- **更新频率**:稳定每天 1-3 条,周连续 5-7 天

### 限流红线

- 违禁词、敏感内容
- 搬运/低质重复
- 互动数据异常(刷量)
- 账号违规历史

## 抖音 vs 小红书 vs 快手 算法差异

| 平台 | 核心权重 | 分发逻辑 |
|---|---|---|
| 抖音 | 完播率 + 互动 | 强算法,标签精准 |
| 小红书 | 互动率 + 收藏 + 搜索 | 算法 + 搜索双轨 |
| 快手 | 关注 + 老铁忠诚 | 关注体系强 |
| TikTok | 完播率 + 跨地域 | 全球分发 |

## 实务策略

1. **跑数据非跑感觉**:每条视频后台分析五大指标,找出薄弱
2. **首条爆款先行**:倾全力做 1 条爆款,带动账号权重
3. **不要瞎蹭热点**:与账号定位无关的热点反伤标签
4. **千川辅助而非替代**:自然流是地基,千川是放大器
5. **承接力同等重要**:流量来了能不能转化,看主页/橱窗/简介
