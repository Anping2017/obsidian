# 负载均衡

## 定义

**负载均衡(Load Balancing,LB)** 是把流量分发到多个后端服务器的技术,目的是水平扩展性能、提升可用性、隔离故障。按工作层级分 L4(传输层)和 L7(应用层),按部署方式分硬件 LB(F5/A10)、软件 LB(LVS/Nginx/HAProxy)、云 LB(AWS ALB/NLB、阿里云 SLB)。是分布式系统的流量入口标配。

## 核心要点

- **工作层级分类**
  - **L4 负载均衡(传输层)**
    - 基于 TCP/UDP 的 IP+端口转发
    - 不解析应用层内容,性能极高(10M+ QPS)
    - 适合 HTTPS 透传、TCP 协议(数据库、Redis)
    - 实现:LVS、AWS NLB、F5(L4 模式)
  - **L7 负载均衡(应用层)**
    - 解析 HTTP / gRPC / WebSocket
    - 可基于 URL、Header、Cookie 路由
    - 支持 SSL 卸载、HTTP/2、压缩、静态缓存
    - 实现:Nginx、HAProxy、Envoy、AWS ALB、Traefik
- **调度算法**
  - **轮询(Round Robin)**:依次分发,简单
  - **加权轮询**:按服务器权重(配置高低)分配
  - **最少连接(Least Connections)**:发给当前连接最少的节点,适合长连接
  - **加权最少连接**
  - **源 IP 哈希(IP Hash)**:同 IP 总到同节点,实现会话保持
  - **URL 哈希 / Consistent Hash**:同 URL 到同节点,提升缓存命中,见 [[一致性Hash]]
  - **响应时间最快**:动态测量延迟选最优
  - **随机加权**:Twitter 的 P2C(Power of Two Choices)算法
- **健康检查**
  - **主动检查**:LB 定时探活(TCP/HTTP)
  - **被动检查**:统计请求失败率,超阈值剔除
  - **慢启动(Slow Start)**:新上线节点逐步引流,避免冷启动雪崩
- **会话保持(Sticky Session)**
  - 同用户的请求路由到同节点
  - 实现:Cookie 注入、IP Hash
  - **代价**:节点扩缩容时会话断,且单点压力不均
  - **更好做法**:无状态服务 + Session 存 Redis
- **SSL/TLS 卸载**
  - LB 处理 HTTPS 解密,后端走 HTTP,节省后端 CPU
  - 但 LB 成为加密单点,需要硬件加速 / 横向扩展
  - 现代趋势:端到端 mTLS([[服务网格]]),LB 透传
- **典型架构**
  - **DNS 轮询 → 入口 LB → 应用 LB → 后端服务**
  - 入口 LB 是 L4(NLB)处理 TCP 入向
  - 应用 LB 是 L7(ALB / Nginx)做 HTTP 路由
  - 服务间通信通过 [[服务网格]] sidecar
- **LB 的 HA**
  - LB 自身需高可用,主备 + 心跳 + VIP 漂移
  - DNS 解析多 IP 实现客户端侧负载
  - Anycast IP:多个 LB 共用 IP,BGP 路由就近
- **客户端负载均衡**
  - 客户端集成 LB 逻辑,直连后端
  - 优势:少一跳、可感知后端拓扑
  - 实现:Spring Cloud Ribbon、gRPC 内置、Envoy + xDS
  - 微服务流行做法
- **CDN 是特殊的负载均衡**
  - 全球分布的边缘节点 + DNS 调度
  - 用户请求自动路由到最近节点
  - 见 [[CDN]]
- **限流 / 熔断 / 灰度**
  - 现代 LB 集成限流([[限流]])、熔断([[熔断与降级]])、按权重灰度发布
  - Envoy 是这一趋势的代表

## 和其他概念的关系

负载均衡是 [[微服务]] 架构的流量基础设施,与 [[API网关]]、[[服务发现]] 配合工作。L7 LB 与 [[API网关]] 边界模糊,Kong、APISIX 都同时承担两职。

[[CDN]] 是地理分布的负载均衡 + 缓存。

调度算法的 [[一致性Hash]] 是 LB 与缓存集群协作的关键:同请求到同节点,提升缓存命中率,节点变动时数据迁移最小。

[[服务网格]](Istio、Linkerd)把 LB 推到 sidecar,每服务实例自带 LB,简化中心 LB。

[[Kubernetes]] Service 内部就是 kube-proxy 实现的简易 L4 LB,Ingress 是 L7 LB 入口。
