# 多模态学习

## 定义

**多模态学习**(Multimodal Learning)指机器学习模型同时处理**两种及以上模态**(文本、图像、音频、视频、3D、传感器信号等)的范式。核心目标是:

> 让模型在统一的表征空间内理解模态之间的对应关系,并能跨模态推理、检索、生成。

相对单模态(text-only / image-only),多模态学习更接近人类认知方式 —— 人天然通过视觉 + 听觉 + 语言综合理解世界。它是从 [[预训练语言模型]] 通向通用人工智能(AGI)的必经之路,也是 [[多模态AI]] 产品形态的底层技术。

## 核心要点

### 模态类型

| 模态 | 典型表征 |
|---|---|
| **文本** | token 序列 + Embedding |
| **图像** | 像素网格 → Vision Transformer (ViT) patch embedding |
| **音频** | 波形 / mel-spectrogram → Whisper、AudioLM |
| **视频** | 时序图像帧 + 音频轨道 |
| **3D / 点云** | 体素 / NeRF / Gaussian Splatting |
| **结构化** | 表格、知识图谱、代码 AST |

### 三大技术路线

| 路线 | 代表 | 思路 |
|---|---|---|
| **对齐(Alignment)** | CLIP、ALIGN | 双塔架构 + 对比学习,把图文映射到同一向量空间 |
| **融合(Fusion)** | Flamingo、BLIP-2、LLaVA | 视觉编码器 + 投影层接入 LLM,共同生成 |
| **原生多模态** | GPT-4o、[[Gemini系列模型]]、Claude 3 | 从预训练开始就混合多模态 token,统一 Transformer 处理 |

### 关键技术里程碑

- **CLIP(OpenAI, 2021)**:4 亿图文对对比学习,开启图文对齐时代
- **DALL·E / Stable Diffusion / Midjourney(2021-2022)**:文本生图突破
- **Flamingo(DeepMind, 2022)**:少样本视觉问答
- **GPT-4V(2023)**:大模型首次看懂图片
- **Sora / Veo / Kling(2024)**:文本生视频走向工业级
- **GPT-4o / Gemini 2.0 / Claude 3.5(2024)**:原生多模态实时交互

### 训练范式

1. **对比学习**:图文配对正样本拉近、错配负样本推远(CLIP)
2. **掩码重建**:遮挡部分像素 / token,让模型还原(MAE、BEiT)
3. **跨模态生成**:文 → 图、图 → 文、视频 → 文,扩散模型 + 自回归
4. **指令微调**:多模态版的 SFT + RLHF,让模型听懂"看这张图回答"

### 核心难题:模态对齐

不同模态原始分布天差地别(像素 vs 离散 token),需在某层(early / mid / late fusion)对齐。对齐质量直接决定模型能否"真理解"图,而非靠语言先验猜。

## 典型应用 / 主流模型工具

- **视觉问答**:看图回答、读图表、识别表情、医学影像诊断
- **OCR + 文档理解**:GPT-4V、Claude 3、Gemini 处理 PDF、票据、表格
- **文生图 / 图生图**:Midjourney、Stable Diffusion、DALL·E 3、Flux
- **文生视频**:Sora、Veo、Kling、Runway Gen-3
- **语音交互**:GPT-4o Voice、Gemini Live —— 端到端语音对话
- **具身智能**:RT-2、Gemini Robotics —— VLA(Vision-Language-Action)模型驱动机器人
- **多模态搜索**:以图搜图、以文搜图、跨模态电商
- **无障碍**:Be My Eyes + GPT-4V 为盲人描述周围环境

## 局限与挑战

| 挑战 | 描述 |
|---|---|
| **数据稀缺** | 高质量图文 / 视频—文本配对数据远少于纯文本 |
| **对齐偏差** | 模型可能依赖语言先验"猜",而非真正看图 |
| **细粒度识别** | 数清图中物体、读懂复杂图表仍不可靠 |
| **时序推理** | 长视频的因果与时序理解远未解决 |
| **算力爆炸** | 视频模态 token 数是文本的百倍,训练成本高昂 |
| **多模态幻觉** | 编造图中不存在的物体或属性 |
| **版权与伦理** | 训练数据中的图像、视频版权争议剧烈 |

## 与其他概念的关系

- 文本模态来自 [[预训练语言模型]] 与 [[大语言模型]] 的演化
- 统一骨干仍是 [[Transformer架构]](ViT / Audio Transformer / Video Transformer)
- 模态间桥梁是共享的 [[Embedding]] 空间
- 与 [[BERT]] 类双向编码思想衍生出 ViLBERT、VLBERT 等早期多模态模型
- 主流产品代表 [[Gemini系列模型]] 是原生多模态架构
- 应用层产品形态见 [[多模态AI]]
- 跨模态检索是 [[RAG|检索增强生成]] 的扩展(图文混合 RAG)
- 通过 [[Function Calling]] 调用视觉 / 音频专用工具,可增强多模态 agent
- 与 [[联邦学习]] 结合可做跨机构的隐私保护多模态训练
