# 信息流广告

## 定义

信息流广告(Feed Ads / Native Feed Ads)指投放在用户内容浏览流(News Feed、视频流、商品流、朋友圈)中,在样式上模拟原生内容形态,但在标识上明确标注"广告/推广"的广告形式。它结合了原生广告的低打扰与精准定向的高 ROI,是字节跳动、腾讯、Meta、抖音、小红书等内容平台主要的变现形式与广告主的主流投放方式。

## 核心要点

**主流平台与产品**:

- **巨量引擎**(字节系):抖音、今日头条、西瓜视频、抖音火山版。
- **腾讯广告**:朋友圈、微信公众号底部、视频号、QQ 看点。
- **百度信息流**:百度 App、百度贴吧。
- **小红书广告**(聚光平台):笔记信息流、搜索信息流。
- **快手磁力引擎**。
- **Meta Ads**(Facebook / Instagram Feed)。
- **YouTube In-Feed Ads**、**TikTok Ads**。

**计费方式**:

- **CPM**(千次曝光,品牌曝光):品牌广告主常用。
- **CPC**(点击):效果导向,中等投放阶段。
- **oCPM/oCPC/oCPA**(优化目标 CPM/CPC/Action):依算法预估转化概率,以转化目标计费。这是当前主流。
- **CPA / CPS**(行动 / 销售):风险共担,平台政策限制使用。

**素材体裁**:

- 单图、组图(3-6 图)、横版视频、竖版视频、九宫格、动态图文。
- **短视频是主流**:5-15 秒钩子,20-60 秒完整素材,平台算法奖励高完播率。
- **真人口播 / 实拍 / 剧情广告**:CTR 高于纯动效。
- **原生标题**:模拟内容标题口吻,避免广告腔。

**核心定向能力**:

- **基础定向**:地域 / 性别 / 年龄 / 设备 / 系统。
- **兴趣行为**:近期关注品类、互动行为。
- **人群包(DMP)**:第一方数据回传 + 平台标签融合。
- **[[Lookalike人群]]**:基于种子用户扩散相似画像。
- **[[再营销]] (Retargeting)**:已看过 / 加购 / 注册的人群再触达。

**优化关键(以巨量为例)**:

- **创意是 70% 杠杆**:同一定向不同素材,转化率差 5-10 倍。每周 3-5 条新素材是高频迭代节奏。
- **巨量引擎 GeRiBai 模式**:多创意、多账户、多计划同步起量,机器分配预算给跑量好的创意。
- **冷启动期**(0-50 转化):算法摸索阶段,不要急停。
- **学习期**(50-200 转化):稳定期,可优化定向。
- **稳定期**:进入成熟,可放量但需提防衰减。
- **DMP 二次圈选**:已转化 + 高 LTV 用户作为 Lookalike 种子。

**素材生命周期(Material Lifecycle)**:

- 新素材点击率 / 转化率随展现量积累递减(广告疲劳)。
- 一般 3-7 天衰减一半,需新素材接力。
- 视频前 3 秒决定 CTR,决定能否被推到下一波流量池。

**反模式**:

- 单一素材跑到死(Frequency 高但 CTR 已极低)。
- 不区分 [[再营销]] 和拉新人群,公用一套素材。
- oCPA 出价过低导致冷启动失败,长期不出量。
- 不设置 [[转化API]] / 数据回传 → 算法没有学习信号。

## 和其他概念的关系

信息流广告是 [[数字营销]] 与 [[程序化广告]] 的主战场,与 [[搜索广告]]、[[展示广告]]、[[KOL营销]] 共同构成付费投放矩阵。它依赖 [[精准营销]] 的人群定向、[[AB测试]] 的素材验证、[[归因模型]] 的效果度量。

信息流投放效果评估必须配合 [[转化漏斗]] 全链路埋点,否则只能看到平台口径转化(已被高估)。它与 [[再营销]] 和 [[Lookalike人群]] 是同一个 DMP 体系下的不同应用方式。素材创意越来越多依赖 [[AIGC]] 生成,广告主用 Midjourney、Sora、ChatGPT 进行流水化产出。

[[信息流广告]] 与 [[内容营销]] 的边界正模糊化——优秀的信息流广告本身就是有价值的内容(剧情广告、剧情短剧)。在中国,信息流广告也是 [[小红书种草]]、[[直播营销]] 转化漏斗顶部的关键流量入口。
