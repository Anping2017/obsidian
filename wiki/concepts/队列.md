# 队列 Queue

## 定义

**队列(Queue)**是一种**先进先出(FIFO, First-In First-Out)**的受限线性[[数据结构]]:只能在**队尾 rear**插入(enqueue),只能从**队首 front**删除(dequeue)。它对应现实中"排队"的语义。

主要变种:
- **普通队列**:FIFO
- **双端队列(Deque)**:两端都可插入/删除
- **优先队列(Priority Queue)**:按优先级出队,通常用[[堆]]实现
- **循环队列(Circular Queue)**:数组实现时把首尾相连,避免假溢出

## 核心要点

### 基本操作复杂度

| 操作 | 复杂度 |
|---|---|
| enqueue / push_back | O(1) |
| dequeue / pop_front | O(1) |
| front / back | O(1) |
| isEmpty / size | O(1) |

### 实现方式

- **链表实现**:维护 head 和 tail 指针,两端 O(1)
- **数组 + 双指针(循环队列)**:用 (rear+1) % capacity 实现循环;需注意区分空队列与满队列(留一空位或额外计数)
- **两个栈实现**:经典面试题;摊还 O(1)

### 队列的关键应用

1. **[[BFS广度优先搜索]]**:图/树的层次遍历
2. **任务调度**:[[操作系统]]进程就绪队列、磁盘 IO 请求
3. **生产者-消费者**:解耦生产与消费速度
4. **消息队列**:[[Apache Kafka|Kafka]]、RabbitMQ、ActiveMQ 把队列升级为分布式中间件
5. **缓冲区**:键盘输入、网络包接收
6. **限流**:漏桶算法用 FIFO 队列平滑流量
7. **打印队列、网络包重传队列**

### 优先队列(Priority Queue)

不严格 FIFO,而是按"优先级"出队。底层通常用**最大堆/最小堆**实现:
- enqueue / dequeue: O(log n)
- peek_max / peek_min: O(1)

应用:Dijkstra 最短路径、Huffman 编码、Top-K 问题、任务调度(优先级)、A* 搜索。

### 双端队列(Deque)

两端都支持 O(1) 插删。可同时模拟栈和队列。STL `std::deque` 用块状数组实现。
应用:LRU 缓存中的链表部分、滑动窗口最大值、Steal-Work 调度算法。

## 和其他概念的关系

队列与[[栈]]都是受限的线性[[数据结构]]但语义相反:栈对应递归/回溯,队列对应层次扩散。[[BFS广度优先搜索]]用队列、[[DFS深度优先搜索]]用栈,本质区别在于结点的展开顺序。

队列在分布式系统中升级为**[[消息队列]]中间件**,实现服务解耦、流量削峰、异步处理。Kafka 内部分区(Partition)就是磁盘上的有序追加日志,语义上等价于持久化队列。

[[操作系统]]调度器中,就绪队列、IO 等待队列、工作线程池都是队列;CFS 调度器用红黑树近似优先队列实现公平调度。
