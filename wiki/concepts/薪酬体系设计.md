# 薪酬体系设计

## 定义

**薪酬体系(Compensation System)** 指企业对员工劳动给付的总报酬结构,涵盖**直接报酬**(基本工资、奖金、佣金)与 **间接报酬**(福利、津贴、长期激励、非物质回报)。设计目标是同时满足**内部公平、外部竞争、激励有效、成本可控**四原则。

## 核心要点

### 全面薪酬(Total Rewards)模型

现代薪酬观把"薪"扩展为"全面回报":

| 维度 | 内涵 | 例子 |
|---|---|---|
| **基本薪酬** | 月薪、年薪 | 工资 |
| **变动薪酬** | 与绩效挂钩 | 季度奖、年终奖、佣金、提成 |
| **长期激励** | 多年绑定 | 期权、限制性股票(RSU)、虚拟股 |
| **福利** | 法定 + 补充 | 五险一金、商保、年金 |
| **津贴** | 特定情境 | 交通、餐补、夜班、外派 |
| **非物质** | 工作体验 | 弹性工时、远程、培训、成长 |

### 薪酬"3P"模型

经典分析框架,薪酬应反映三要素:

| P | 含义 | 体现 |
|---|---|---|
| **Position(岗位)** | 岗位本身的价值 | 岗位评估、薪级薪等 |
| **Person(个人)** | 任职者能力与经验 | 能力薪酬、技能加薪 |
| **Performance(绩效)** | 实际产出 | 浮动奖金、佣金 |

健康体系三要素都体现,过度强调一方面会失衡。

### 岗位评估(Job Evaluation)四方法

确定岗位相对价值的方法:

| 方法 | 原理 | 特点 |
|---|---|---|
| **排序法** | 整体相对排名 | 简单、主观 |
| **分类法** | 按类别归级 | 政府/事业单位常见 |
| **要素比较法** | 多要素直接对比 | 工程量大 |
| **要素计点法(Hay)** | 投入-产出-知识三维度评分 | 精细、流行 |

Hay 评点法成为全球通用语言,可与外部市场数据对接。

### 薪酬曲线与薪点

- **薪等(Grade)**:岗位评估的层级,如 P1-P10
- **薪幅(Range)**:每等级的最低-中位-最高 = 通常 80%-100%-120%
- **薪点(Compa-Ratio)**:个人薪酬 / 中位 = 100% 表示标准
- **薪酬政策线**:目标定位市场 P50/P75/P90?

### 内部公平 vs 外部竞争

| 矛盾 | 体现 | 平衡 |
|---|---|---|
| 内部公平 | 同岗同酬、纵向合理 | 岗位评估、薪等结构 |
| 外部竞争 | 市场对标、防止流失 | 薪酬调研(Mercer、韦莱韬悦) |

完全内部公平 → 关键岗位流失;完全外部对标 → 内部不和。

### 变动薪酬设计(浮动机制)

| 形式 | 适用 | 风险 |
|---|---|---|
| **个人 KPI 奖** | 个人绩效清晰 | 内卷、内耗 |
| **团队奖** | 协同重要 | 搭便车 |
| **公司利润分享** | 共担命运 | 个人激励弱 |
| **销售佣金** | 销售岗 | 短视、客户体验损失 |
| **长期激励(LTI)** | 高管、核心员工 | 设计复杂 |

### 长期激励工具

| 工具 | 特点 |
|---|---|
| **期权(Stock Option)** | 授予未来按行权价买股的权利,科技股权重 |
| **RSU(限制性股票单位)** | 授予未来获股,简单、确定 |
| **虚拟股/分红权** | 不真实持股,模拟分享 |
| **业绩股票** | 达成目标才解锁 |
| **股权激励计划** | 中国上市公司常用 |

### 薪酬透明度的争议

- **传统**:严格保密,防止比较冲突
- **现代**:逐步透明,体现公平正义
- **激进**:全公开(Buffer、SumAll),依靠规则公平

### 同工同酬与性别薪酬差距

- 全球性别薪酬差距(Gender Pay Gap)长期存在
- 法律(欧盟薪酬透明指令、美国 Equal Pay Act)要求审查
- 同一岗位男女薪酬应一致(同工同酬),全公司差距可由职业分布解释

## 和其他概念的关系

- 是 [[人力资源管理]] 核心子领域
- 与 [[激励理论]] 紧密耦合——薪酬是外在激励的主要载体
- 直接影响 [[员工敬业度]](本 vault 待立 stub)与离职率
- 长期激励连接 [[公司治理]] 与 [[代理问题与激励]]——通过股权对齐管理层利益
- [[绩效管理]] 输出驱动浮动薪酬决策
- 在 [[战略执行]] 中,薪酬应与战略目标对齐
- 跨国薪酬涉及 [[国际化战略]] 中的派遣政策
- 与心理学公平理论(Adams)、期望理论(Vroom)、双因素理论(Herzberg)直接对接
- 在 [[组织文化]] 中传达"什么被奖励"的信号,塑造行为
