# 微积分应用

## 定义

**微积分应用**是将微积分(导数与积分)应用于金融领域,解决最优化、风险度量、衍生品定价等问题的数学工具。它是定量金融的基础,与 [[概率论与统计学]]、[[线性代数应用]]、[[随机过程]] 共同构成金融数学的四大支柱。

## 核心要点

### 导数应用
1. **边际分析**
   - **边际成本**:MC = dC/dQ
   - **边际收益**:MR = dR/dQ
   - **边际效用**:MU = dU/dX
   - **最优条件**:利润最大化 MR = MC,效用最大化 MU₁/P₁ = MU₂/P₂
2. **弹性分析**
   - **价格弹性**:Ed = (dQ/dP) × (P/Q)
   - **收入弹性**:Ey = (dQ/dY) × (Y/Q)
   - **交叉弹性**:Exy = (dQx/dPy) × (Py/Qx)
   - 用于定价策略、市场分析
3. **Greeks(期权敏感度)**
   - **Delta(Δ)**= ∂C/∂S:对标的价格敏感
   - **Gamma(Γ)**= ∂²C/∂S²:Delta 的变化率
   - **Theta(Θ)**= ∂C/∂t:时间衰减
   - **Vega(ν)**= ∂C/∂σ:对波动率敏感
   - **Rho(ρ)**= ∂C/∂r:对利率敏感
   - 是 [[衍生品风险管理]] 与对冲的核心工具

### 积分应用
1. **累积分析**
   - **累积收益**:R = ∫r(t)dt
   - **累积风险**:V = ∫σ²(t)dt
   - **累积损失**:L = ∫λ(t)dt
2. **概率密度函数**
   - **正态分布**:f(x) = (1/√(2πσ²)) × exp(-(x-μ)²/(2σ²))
   - **对数正态分布**:用于股价建模
   - **t 分布**:小样本推断、厚尾建模
3. **风险价值计算**
   - **VaR**:VaR = μ - z_α × σ
   - **CVaR/ES**:E[R | R ≤ VaR] = ∫x·f(x)dx (x ≤ VaR)
   - 是 [[风险识别与度量]] 与 [[风险模型与工具]] 的数学基础

### 偏微分方程(PDE)应用
1. **Black-Scholes 方程**
   - ∂C/∂t + rS·∂C/∂S + (1/2)σ²S²·∂²C/∂S² - rC = 0
   - 边界条件:C(T,S) = max(S-K, 0)(看涨期权)
   - 解析解(看涨):C = S·N(d₁) - K·e^(-rT)·N(d₂)
   - 是 [[期权定价]] 的核心方程
2. **热传导方程**:Black-Scholes 方程经变量代换可转化为热传导方程,提供数值求解通路
3. **随机微分方程(SDE)**
   - **几何布朗运动**:dS = μS·dt + σS·dW(股价)
   - **Ornstein-Uhlenbeck 过程**:dX = κ(θ - X)dt + σdW(均值回归,如利率、波动率)
   - **跳跃扩散过程**:dS = μS·dt + σS·dW + S·dJ(包含跳跃)

### 应用领域
- **期权定价**:Black-Scholes(欧式)、二叉树、有限差分(美式)、Monte Carlo(亚式)
- **利率模型**:Vasicek、CIR、Hull-White、HJM
- **信用风险**:Merton 模型、Jarrow-Turnbull、强度模型
- **投资组合优化**:Lagrange 乘数、KKT 条件
- **风险度量**:VaR、ES、Greeks、敏感性分析

## 和其他概念的关系

微积分应用是 [[期权定价]] 的语言——Black-Scholes 模型整体就是一个偏微分方程,其解涉及大量积分技巧;Greeks 直接是偏导数。 [[衍生品风险管理]] 中的对冲策略(Delta 中性、Vega 中性)是 Greeks 的实战应用。

它与 [[概率论与统计学]] 紧密交织——分布函数(累积分布)是概率密度函数的积分,VaR 计算需要积分概率密度。 [[随机过程]] 中的伊藤引理(Itô's Lemma)是随机微积分的核心工具,连接经典微积分与随机过程。

[[线性代数应用]] 与微积分常配合使用——多变量优化(投资组合 [[投资组合理论]])既需要微分(梯度、Hessian),也需要矩阵运算。 [[蒙特卡洛模拟]] 是当解析积分困难时的替代方法,模拟期望值。 [[数值方法]] 提供有限差分、辛普森法等数值积分技巧。

[[资本成本]]、[[现金流折现模型]] 中的连续时间贴现都是积分。 [[利率理论]] 中的瞬时利率、远期利率涉及微积分。 [[投资组合理论]] 的均值-方差最优化是约束最优化问题。 [[资产定价模型]] 中的 CAPM、APT 推导也涉及微积分。

[[行为金融学]] 与微积分的关系较弱,但前景理论的价值函数也用到导数(边际效用)。 [[金融科技]] 中的 AI 算法(梯度下降)本质上是数值优化,涉及大量微积分。微积分是定量金融的基础语言,理解它是阅读现代金融文献的前提。
