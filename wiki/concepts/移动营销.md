# 移动营销

## 定义

**移动营销**(Mobile Marketing)是利用智能手机、平板、可穿戴等移动设备的特性(LBS、推送、相机、NFC、麦克风、加速度计)向用户传递广告与互动体验的营销活动。

广义包括:移动搜索、APP 内广告、信息流、推送通知、二维码、SMS/RCS、移动支付场景营销、社交移动应用(微信、抖音、小红书)、位置营销、AR/VR 营销等。

它不只是把 PC 营销搬到小屏,而是基于"个人化、永远在线、地理感知、传感器丰富、即时支付"的全新营销范式。

## 核心要点

### 移动设备的营销特性

| 特性 | 营销意义 |
|---|---|
| **个人化** | 一人一机,用户画像更精准 |
| **永远在线** | 任何时间触达,但要避免打扰 |
| **位置感知** | LBS 推送、本地搜索、店内导航 |
| **传感器丰富** | 摄像头、麦克风、陀螺仪支持 AR、扫码 |
| **即时支付** | 看到即购买的极短链路 |
| **APP 生态** | 应用内闭环,跳出率高于浏览器 |

### 主要触达方式

1. **APP 内广告**:展示、激励视频、原生
2. **移动搜索**:Google、百度、应用商店
3. **信息流广告**:抖音/小红书/微博/快手 → 见 [[信息流广告]]、[[信息流广告投放]]
4. **推送通知**:[[Push通知]] / [[APNs推送通知]] 的最高效免费触点
5. **私信**:[[私信引流]] / [[私信运营SOP]] 是公私域桥梁
6. **短信/RCS**:精确直达但成本高,需合规
7. **二维码 + LBS**:线下扫码 → 私域沉淀
8. **应用商店优化**:[[ASO应用商店优化]]

### 移动营销关键技术与挑战

- **追踪与归因**:[[ATT隐私框架]] 后 IDFA 限制大幅改写
- **服务端追踪**:[[Server-side Tracking]] / [[转化API]] 应对
- **跨设备**:[[跨设备追踪]] 从概率走向确定性
- **隐私监管**:[[GDPR]]、[[ATT隐私框架]]、苹果/Google 隐私沙盒
- **端侧 AI**:[[端侧AI]] + [[多模态AI]] 推动个性化进入设备本地

### 与桌面营销的差异

| 维度 | 桌面 | 移动 |
|---|---|---|
| 屏幕 | 大,信息密 | 小,信息稀 |
| 时间 | 工作时段 | 全天碎片 |
| 场景 | 办公/家庭 | 通勤/排队/睡前 |
| 输入 | 键盘鼠标 | 触屏/语音/相机 |
| 闭环 | 浏览器 | APP 内闭环 |
| 决策周期 | 较长 | 短/即时 |

## 应用场景

- **电商**:移动 70%+ GMV 占比,直播 + 短视频成主战场
- **本地零售**:LBS + 优惠券引流到店,见 [[本地SEO]]
- **金融服务**:APP 推送 + 短信触达
- **餐饮**:外卖 APP + 扫码点餐 + 会员体系
- **教育**:碎片时间内容 + 推送复习

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **打扰用户** | 推送过频导致卸载 |
| **追踪受限** | ATT 与 Cookie 退役改写归因 |
| **生态封闭** | 苹果/Google/微信各家围墙 |
| **创意疲劳** | 信息流刷新极快,创意半衰期短 |
| **小屏 UX** | 文案、设计、加载需重新适配 |
