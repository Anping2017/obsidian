# 自然语言处理 NLP

## 定义

自然语言处理(Natural Language Processing, NLP)是 [[人工智能]] 的子领域,研究**让计算机理解、生成、交互人类语言**的理论与技术。它跨越语言学、计算机科学、统计学、认知科学,目标涵盖:

- **理解**:解析语义、抽取信息、判别意图
- **生成**:撰写流畅、相关、合规的文本
- **转换**:翻译、摘要、改写、风格迁移
- **交互**:对话、问答、推理

NLP 与 NLU(理解)、NLG(生成)三者关系:NLP ⊃ NLU ∪ NLG。

## 核心要点

### 历史演进四阶段

1. **规则时代(1950s-1990s)**:专家手写语法规则与词典,如 ELIZA、SHRDLU。脆弱,难规模化。
2. **统计时代(1990s-2010s)**:n-gram 语言模型、HMM、CRF、SVM,基于人工特征工程。
3. **深度学习时代(2013-2017)**:[[词嵌入]](Word2Vec、GloVe)、RNN/LSTM 端到端学习。
4. **大模型时代(2018-)**:BERT、GPT 系列,用 [[Transformer架构|Transformer]] 在海量语料上预训练 + 下游微调或 [[提示词工程方法论|提示工程]]。详见 [[大语言模型]]。

### 核心任务

| 任务 | 描述 | 评测 |
|---|---|---|
| 分词 / 标注 | 切分单词、词性标注、命名实体识别 | F1 |
| 句法分析 | 短语结构树、依存树 | UAS/LAS |
| 语义理解 | 词义消歧、语义角色标注 | F1/Accuracy |
| 文本分类 | 情感、主题、垃圾邮件 | Accuracy/F1 |
| 信息抽取 | 实体、关系、事件 | F1 |
| 问答 | 抽取式、生成式、对话式 | EM/F1/Rouge |
| 机器翻译 | 跨语言映射 | BLEU/CHRF |
| 摘要 | 抽取式、生成式 | Rouge |
| 对话 | 任务型、闲聊型 | 人工评估、用户满意度 |

### 关键技术

- **[[Tokenization 分词]]**:BPE、WordPiece、SentencePiece
- **[[词嵌入]]**:词向量化是 NLP 进入深度学习时代的钥匙
- **[[Transformer架构|Transformer]]**:[[自注意力机制]] 取代 RNN,成为统一架构
- **预训练 + 微调**:在大规模无标注语料上预训练通用表征,下游小数据微调
- **[[提示词工程方法论|提示工程]]**:少样本/零样本学习,无需微调即可完成任务
- **[[RAG|RAG检索增强生成]]**:外接知识库,缓解幻觉与时效问题

### 当前挑战

- 幻觉(hallucination)与事实性
- 推理与规划能力(数学、多步逻辑)
- 长上下文与记忆
- 多模态融合
- 低资源语言
- 评测的科学性

## 和其他概念的关系

NLP 是 [[人工智能]] 三大经典方向之一(另两为 [[计算机视觉]] 与机器人/控制),与 [[机器学习]]、[[深度学习]] 共生演化。

[[Transformer架构|Transformer]] 既是 NLP 突破的引擎,也反向输出到 CV、生物、多模态等领域。[[大语言模型]] 是 NLP 当前的旗舰产物。[[词嵌入]]、[[自注意力机制]]、[[位置编码]] 是其底层武器。

NLP 与认知科学、语言学交叉,涉及 [[语义学]]、[[句法]];应用层渗透 [[搜索引擎优化|搜索引擎]]、[[推荐系统]]、智能客服、AI 写作、代码补全([[Copilot]] 类)。

[[RAG|RAG检索增强生成]] 把 NLP 与 [[向量数据库]]、信息检索结合,是当前 LLM 工程化的标准范式。
