# 归并排序 Merge Sort

## 定义

归并排序(Merge Sort)是 John von Neumann 1945 年提出的**基于分治(Divide & Conquer)的稳定排序算法**。其核心思想:

1. 把数组从中间一分为二
2. 递归对左右两半分别排序
3. **归并(merge)** 两个有序子数组为一个有序数组

```python
def merge_sort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(a, b):
    result, i, j = [], 0, 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i]); i += 1
        else:
            result.append(b[j]); j += 1
    result.extend(a[i:]); result.extend(b[j:])
    return result
```

## 核心要点

### 复杂度

| 情况 | 时间 | 空间 |
|---|---|---|
| 平均/最好/最坏 | O(n log n) | O(n) |

时间复杂度对所有输入恒为 O(n log n),不像 [[快速排序]] 最坏退化 O(n²),但需要 O(n) 额外空间。

### 关键特性

- **稳定**:相等元素相对顺序保持(快排不稳定)
- **可外排序**:适合数据量超过内存的场景(外排序、多路归并)
- **易并行化**:左右子排序天然独立,适合多核/分布式
- **顺序访问**:对内存/磁盘缓存友好,适合链表
- **额外空间**:需要 O(n) 临时数组(原地归并算法存在但复杂)

### 工业实现

- **Python `sorted` / `list.sort`**:Timsort,归并排序 + 插入排序混合
- **Java `Arrays.sort(对象)`** :归并排序变体(因稳定要求)
- **Java `Collections.sort`** :归并排序
- **C++ `std::stable_sort`**:通常归并排序

### 优化技巧

1. **小区间用插入排序**:n < 16 时直接插入排序
2. **跳过已序段**:Timsort 检测自然有序的段(run)
3. **归并优化**:若 `a[mid] <= a[mid+1]` 已有序,跳过归并
4. **就地归并**:用旋转或块交换实现 O(1) 额外空间(但常数大)
5. **多路归并**:k 路归并 + 堆,降低数据搬运次数(外排序常用)

### 与快速排序的对比

| 维度 | 归并排序 | [[快速排序]] |
|---|---|---|
| 平均时间 | O(n log n) | O(n log n) |
| 最坏时间 | O(n log n) | O(n²) |
| 空间 | O(n) | O(log n) 递归栈 |
| 稳定 | ✓ | ✗ |
| 缓存友好 | 中 | 高(原地) |
| 适合外排序 | ✓ | ✗ |
| 链表友好 | ✓ | ✗ |

## 和其他概念的关系

归并排序是 [[分治算法]] 思想的最纯粹示范,与 [[快速排序]]、[[堆排序]] 共同构成 O(n log n) 比较排序三杰。

它在 [[数据结构]] 课程中常与 [[递归]]、[[复杂度分析]](Master Theorem)联动教学;主定理(Master Theorem)告诉我们 T(n) = 2T(n/2) + O(n) 解为 O(n log n),归并排序是其经典案例。

外排序(External Sorting)与 [[大数据]] 处理深度依赖归并思想——MapReduce 的 Reduce 阶段通常涉及多路归并;数据库的排序操作、[[B+树]] 的批量构建都用归并。

[[数据结构]] 中链表的排序首选归并排序(快速排序对链表不友好);[[操作系统]] 内核常见多路归并合并多个有序链。
