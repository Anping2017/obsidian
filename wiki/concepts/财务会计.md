# 财务会计

## 定义

**财务会计**(Financial Accounting)是按照**公认会计准则**(IFRS / 美国 GAAP / 中国企业会计准则)对企业经济业务进行**确认、计量、记录、报告**,主要面向**外部使用者**(投资者、债权人、监管机构、潜在合作伙伴)的会计分支。

它的核心交付物是**财务报表**:[[资产负债表]]、[[利润表]]、[[现金流量表]],以及在 IFRS 与 GAAP 下逐渐重要的 [[所有者权益变动表]] 与附注。

## 核心要点

### 三大特征

| 特征 | 描述 |
|---|---|
| **外部导向** | 面向投资者/监管,而非内部管理(后者是 [[管理会计]]) |
| **准则约束** | IFRS / GAAP / CAS 严格规范,不能任意 |
| **历史导向** | 主要反映已发生的事项,与决策导向的财务管理形成补充 |
| **货币计量** | 一切事项以货币表达 |
| **强制性** | 上市公司、规模以上企业法定披露 |

### 核心假设与原则

- **会计主体**:企业作为独立单位,与所有者分离
- **持续经营**:假设企业未来可持续运营
- **会计分期**:把无限经营切分为可比期间
- **货币计量**:稳定货币假设
- **[[权责发生制]]** vs 收付实现制:是现代财务会计的核心
- **[[配比原则]]**:成本费用与对应收入在同一期间
- **谨慎性**:不夸大资产收益,不低估负债费用
- **实质重于形式**:经济实质优先于法律形式
- **重要性**:重要事项重点披露
- **[[历史成本]]** vs [[公允价值]]:两大计量基础

### 主要交付物:三大报表

| 报表 | 内容 | 时点/期间 |
|---|---|---|
| **[[资产负债表]]** | 资产=负债+权益,反映财务状况 | 时点 |
| **[[利润表]]** | 收入-费用=利润,反映经营成果 | 期间 |
| **[[现金流量表]]** | 经营/投资/筹资三类现金流 | 期间 |
| **[[所有者权益变动表]]** | 权益各项目变动 | 期间 |
| **附注** | 重大事项、政策、估计、风险 | 全维度 |

详见 [[财务报表]] 总览。

### 关键会计循环

[[会计循环]] 是从交易到报表的标准流程:

1. 经济业务发生 → 凭证编制
2. 登记日记账 / 总账
3. 编制试算平衡表
4. 期末调整(应计、递延、估计)
5. 编制工作底稿
6. 结账
7. 编制财务报表
8. 利润分配

### 主流会计准则

| 准则 | 制定者 | 特征 |
|---|---|---|
| [[国际财务报告准则]] (IFRS) | IASB | 原则导向、公允价值倾向 |
| [[美国GAAP]] | FASB | 规则导向、详细具体 |
| 中国企业会计准则 (CAS) | 财政部 | 持续与 IFRS 趋同 |
| 日本 J-GAAP / JGAAP | ASBJ | 与 IFRS 双轨 |
| 印度 Ind AS | ICAI | 基于 IFRS |

### 财务会计与其他分支

| 分支 | 受众 | 特征 |
|---|---|---|
| **财务会计** | 外部 | 准则强制、历史导向 |
| **[[管理会计]]** | 内部 | 自由灵活、决策导向 |
| **[[税务会计]]** | 税务机关 | 税法导向、与会计有差异 |
| **[[审计]]** | 鉴证 | 第三方对财务报表表达意见 |
| **[[成本会计]]** | 内部为主 | 介于财务/管理之间 |

## 应用场景

- **资本市场披露**:上市公司年报、季报
- **银行信贷**:贷款审批基础
- **并购估值**:[[企业价值评估]] 输入
- **税务申报**:基础
- **公司治理**:董事会、审计委员会、监管
- **ESG 报告**:与可持续会计准则交融

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **历史导向** | 反映过去,对未来预测有限 |
| **公允价值波动** | 引入主观估值与顺周期性 |
| **盈余管理** | 在准则灰区内调节利润,见 [[舞弊三角理论]] |
| **复杂披露** | 准则越来越多,中小企业不堪重负 |
| **跨国不一致** | IFRS vs GAAP 仍有差异 |
| **无形资产滞后** | 品牌、人才、数据难以计量 |
