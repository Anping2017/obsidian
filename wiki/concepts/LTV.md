# LTV(客户终生价值)

## 定义

LTV(Lifetime Value),又称 CLV(Customer Lifetime Value)、客户终生价值,是**一名客户在与企业关系存续期间贡献的全部利润的现值**。它是衡量客户经济价值的最重要指标之一,也是评估商业模式健康度的核心维度。

(本文与 [[客户生命周期价值]] 同一概念)

## 核心要点

### 基础公式

简化版:

```
LTV ≈ ARPU × 客户生命周期(月) × 毛利率
```

或基于流失率:

```
LTV ≈ ARPU × (1 / 月流失率) × 毛利率
```

更严格用现值:

```
LTV = Σ_t (利润_t × 留存率^t / (1+折现率)^t)
```

### 与 CAC 的关系

LTV 单看意义有限,必须与 [[CAC获客成本]] 配对:

| LTV/CAC | 评估 |
|---|---|
| < 1 | 烧钱,不可持续 |
| 1-3 | 收支接近平衡 |
| 3 | 健康标准 |
| > 5 | 营销投入不足 |

SaaS 行业还看 **Payback Period**(回本周期):月数 = CAC ÷ 月毛利,< 12 月为优。

### 行业基准(参考)

- SaaS B2B:LTV $5,000~$100,000+(企业级)
- 电商:LTV $50~$500
- 订阅 DTC:LTV $200~$1,000
- 移动游戏:LTV $0.5~$10(休闲)~$100+(重度)
- 流媒体:LTV $200~$500(年付订阅)

### 提升 LTV 的杠杆

1. **降低流失**(留存率从 90% → 95% 可使 LTV 翻倍)
2. **提升 ARPU**:涨价、升级套餐、增售
3. **延长生命周期**:绑定服务、社区粘性
4. **拓展使用场景**:跨产品线
5. **降低服务成本**:自助化、知识库
6. **客户成功投入**:主动续约、降低取消

### 测量陷阱

- **新客户 LTV vs 全体 LTV**:历史平均不能代表未来
- **预测 vs 实际**:依赖留存假设,产品/市场变化会破坏假设
- **群体差异**:渠道、地区、用户画像 LTV 差异巨大,平均值掩盖问题
- **品牌外溢**:有些 LTV 来自老客带新,纯归因困难

### 在产品决策中的应用

- **定价策略**:免费试用 vs 直接付费,测试哪种 LTV 更高
- **付费墙时机**:游戏、内容产品的付费引导节点
- **特征优先级**:开发功能时评估对 LTV 的影响
- **人群投放**:LTV 高的画像加大获客投入

## 和其他概念的关系

LTV 是 [[营销定义与本质|营销]] 与 [[管理学|商业管理]] 共享的核心指标,与 [[CAC获客成本]]、[[留存率]]、[[复购率]]、[[ARPU]] 共同构成单元经济学。

[[CRM客户关系管理]] 的核心目标是提升 LTV;[[精准营销]]、[[再营销]]、[[Lookalike人群]] 是基于高 LTV 用户画像的具体战术。

[[私域流量运营]]、[[品牌权益]]、[[网络效应]] 都是放大 LTV 的杠杆——粘性越高、群体效应越强、LTV 越高。

[[销售漏斗]] 的后端(留存、复购、推荐)直接影响 LTV;[[转化率优化]] 主要影响 CAC,LTV 影响是间接的。

[[订阅经济]] 与 SaaS 模式的兴起把 LTV 从「事后总结指标」变成「事前规划指标」——投资人、产品经理在产品发布前就建模 LTV/CAC。
