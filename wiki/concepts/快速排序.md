# 快速排序 Quicksort

## 定义

快速排序(Quicksort)由 Tony Hoare 1960 年提出,是基于**分治(Divide & Conquer)** 范式的比较排序算法。其核心思想:

1. 选一个**枢轴(pivot)** 元素
2. **分区(partition)**:把小于枢轴的放左侧,大于枢轴的放右侧
3. 递归对左右子区间排序

```python
def quicksort(arr, lo=0, hi=None):
    if hi is None: hi = len(arr) - 1
    if lo < hi:
        p = partition(arr, lo, hi)
        quicksort(arr, lo, p - 1)
        quicksort(arr, p + 1, hi)

def partition(arr, lo, hi):
    pivot = arr[hi]
    i = lo - 1
    for j in range(lo, hi):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[hi] = arr[hi], arr[i + 1]
    return i + 1
```

## 核心要点

### 复杂度

| 情况 | 时间 | 空间(递归栈) |
|---|---|---|
| 平均 | O(n log n) | O(log n) |
| 最佳 | O(n log n) | O(log n) |
| 最坏 | O(n²) | O(n) |

最坏发生在每次分区严重失衡(如已序输入用首/尾元素作枢轴)。

### 枢轴选择策略

- **固定首/尾**:实现简单,已序数据退化
- **随机选择**:期望 O(n log n),抗最坏输入
- **三数取中(median-of-three)**:取首尾中三元素的中位数,实践常用
- **快速选择(Quickselect)**:同分区思想,O(n) 平均找第 k 大

### 原地与稳定性

- **原地**:经典实现只用 O(1) 额外空间(不计递归栈)
- **不稳定**:相等元素的相对顺序可能改变(Java `Arrays.sort` 对对象用归并保稳定)

### 工业实现

- C `qsort`:多用快排,但已混合插入排序
- C++ `std::sort`:Introsort,递归过深降级为堆排序避免最坏 O(n²)
- Java 基本类型 `Arrays.sort`:Dual-Pivot Quicksort
- Python `sorted` / `list.sort`:Timsort(归并 + 插入)

### 优化技巧

1. **小区间用插入排序**:n < 16 时直接插入排序
2. **三向切分(Dijkstra 三路快排)**:把数组分成 < pivot、= pivot、> pivot 三段,适合大量重复元素
3. **尾递归优化**:递归较小子区间,迭代处理较大,降低栈深度
4. **混合算法**:Introsort、Pdqsort

## 和其他概念的关系

快速排序是 [[分治算法]] 思想的经典实例,与 [[归并排序]]、[[堆排序]] 同属 O(n log n) 比较排序。

理解快速排序是建立 [[复杂度分析]] 直觉的好样本——平均 vs 最坏的差距、随机化降低风险、缓存友好性带来实际性能优势。

它的 partition 操作在 [[Quickselect]] 中复用,可以 O(n) 找第 k 小,衍生出中位数算法、Top-K 算法。

[[算法]] 工程化常见的「混合算法」哲学(如 Introsort、Timsort)正是基于「没有银弹」的工程智慧——快速排序快,但不抗最坏,需要其他算法兜底。
