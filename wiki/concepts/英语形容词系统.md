# 英语形容词系统

## 定义

形容词(Adjective)是修饰名词或代词、表达事物属性、状态、特征、数量的词类。它在句中可作三种成分:**定语**(放名词前)、**表语**(连系动词后)、**宾语补足语**(宾语后)。

英语形容词系统的难点不在形态(英语形容词无性、数变化),而在两点:
1. **比较等级**(原级、比较级、最高级)的形态变化
2. **多形容词修饰同一名词时的固定语序**——这是中国学生最易忽视的隐形规则

## 比较等级

**三级形态**

- 原级(positive):tall
- 比较级(comparative):taller / more tall
- 最高级(superlative):tallest / the tallest

**形态规则**

| 类型 | 比较级 | 最高级 |
|---|---|---|
| 单音节 | -er | -est |
| 双音节以 -y 结尾 | 变 y 为 i + er | 变 y 为 i + est |
| 多音节 | more + 形容词 | most + 形容词 |
| 不规则 | good→better, bad→worse, far→farther/further, many→more, little→less | best, worst, farthest/furthest, most, least |

**比较级的核心句型**

- A + 比较级 + than + B:*She is taller than he (is).*
- as + 原级 + as:*She is as tall as he is.*
- not as/so + 原级 + as:*She is not so tall as he.*
- the + 比较级,the + 比较级:*The harder you study, the better grades you get.*
- 比较级 + and + 比较级:*It's getting hotter and hotter.*

**最高级的核心句型**

- the + 最高级 + 范围:*She is the tallest in the class.*
- the + 最高级 + that 从句:*This is the best book I've ever read.*

## 形容词的三种位置

**1. 定语**(attributive)— 名词前

- *a **beautiful** girl*
- *the **old** man*

例外:有些形容词只能作表语,不能作定语,如 alive、awake、afraid、alone、asleep、ill(英)、glad
- 错 *an alive cat*,对 *a living cat* / *the cat is alive*

**2. 表语**(predicative)— 连系动词后

- *She is **happy**.*
- *He looks **tired**.*

**3. 宾语补足语**(object complement)

- *I find this book **interesting**.*
- *They painted the wall **red**.*

## 多形容词的语序规则

当多个形容词修饰同一名词时,英语有严格的语序,记忆口诀 **OSASCOMP**(限性形龄色源材用):

| 顺序 | 类型 | 例 |
|---|---|---|
| **O**pinion 主观评价 | beautiful, lovely, awful | |
| **S**ize 大小 | big, small | |
| **A**ge 年龄 | old, young, new | |
| **S**hape 形状 | round, square | |
| **C**olour 颜色 | red, blue | |
| **O**rigin 来源 | Chinese, French | |
| **M**aterial 材质 | wooden, silk | |
| **P**urpose 用途 | sleeping (bag), running (shoes) | |

例:*a **beautiful** **small** **old** **round** **red** **Chinese** **wooden** **dining** table*

母语者凭直觉就能排对,中国学生需有意识记忆 OSASCOMP。

## 形容词的特殊用法

**the + 形容词作复数名词**

表一类人或抽象概念:
- the rich(富人们)、the poor、the young、the elderly、the unemployed
- the beautiful(美的事物)、the unknown

**形容词后置**

- 不定代词后:*something **important**, anything **new***
- 分词作定语后置:*the people **involved**, the books **available***

## 高频陷阱

- a/an + 形容词 + 名词,数量词位置:*He is a very tall boy*,不是 *very a tall*
- 主语单复数与表语形容词无关:*The problem is **complex**.*(永远 complex)
- 比较级前的修饰词:much/even/far/a lot 用于比较级,very 不行(*very taller* 错)
- enough 修饰形容词时后置:*tall **enough***
- 不规则比较级 farther vs further:farther 强调物理距离,further 比喻"进一步"(进一步研究 further study)
