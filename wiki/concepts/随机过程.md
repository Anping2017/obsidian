# 随机过程

## 定义

**随机过程**(Stochastic Process)是按时间索引的随机变量集合 {X_t},描述某个量随时间的随机演化。在金融中,股价、利率、汇率都被建模为随机过程。

## 核心要点

### 关键过程

**1. 随机游走(Random Walk)**
最简单的离散随机过程:X_{t+1} = X_t + ε_t,ε_t 独立同分布。
- 应用:股价的短期建模、检验 EMH

**2. 布朗运动(Brownian Motion / Wiener Process)**
连续时间的随机游走,W_t 满足:
- W_0 = 0
- 增量独立
- W_t − W_s ~ N(0, t−s)
- 路径连续

**几何布朗运动(GBM)**:dS_t = μS_t dt + σS_t dW_t —— [[期权定价|Black-Scholes]] 假设的股价过程。

**3. 伊藤过程(Itô Process)**
更一般:dX_t = μ(X,t)dt + σ(X,t)dW_t

**伊藤引理**(Itô's Lemma):随机微积分的链式法则,是衍生品定价的核心工具。

**4. 鞅(Martingale)**
E[X_{t+s} | F_t] = X_t —— 当前最佳预测就是现在的值。在风险中性测度下,贴现资产价格是鞅,这是无套利定价的核心。

**5. 跳过程**
泊松过程 + 跳幅,刻画极端事件(违约、央行决议)。

**6. 均值回归过程**
- Vasicek 模型:dr = a(b−r)dt + σdW
- CIR 模型:dr = a(b−r)dt + σ√r dW

用于利率建模 —— 假设利率围绕长期均值回归。

### 随机分析关键概念

- **测度变换(Girsanov)**:从真实测度到风险中性测度
- **二次变差**:布朗运动的"波动率"在数学上的精确含义
- **随机微分方程**(SDE):描述资产路径的方程

### 金融应用

| 模型 | 过程类型 | 应用 |
|---|---|---|
| Black-Scholes | 几何布朗运动 | 期权定价 |
| Vasicek/CIR | 均值回归 | 利率衍生品 |
| Heston | 随机波动率 | 改进 BS |
| Merton 跳扩散 | 布朗 + 跳 | 信用风险、极端事件 |
| Hull-White | 二维高斯过程 | 利率曲线建模 |

## 和其他概念的关系

- 是 [[概率论与统计学]] 的连续时间动态化版本
- 是 [[期权定价]] 与 [[金融衍生品]] 定价的数学基础
- [[蒙特卡洛模拟]] 通常用 SDE 模拟随机过程的样本路径
- 用于 [[利率理论]] 模型、[[风险识别与度量]]
