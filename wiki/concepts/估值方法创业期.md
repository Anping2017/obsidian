# 估值方法创业期

## 定义

**创业期估值(Startup Valuation)** 指对早期阶段企业(种子-成长期)进行价值评估的方法。它与成熟期估值不同——创业公司**没有稳定现金流、没有可比上市公司、未来高度不确定**——传统 [[现金流折现模型]] 与 [[相对估值法]] 难以直接应用。

创业估值更多是**艺术 + 科学**的混合:数据少、判断重、谈判结果。

## 核心要点

### Pre-Money 与 Post-Money

最基本概念:

- **Pre-Money 估值**:融资前公司价值
- **Post-Money 估值**:融资后公司价值
- 关系:**Post = Pre + 投资额**

例:Pre-Money $10M,投资 $2M → Post-Money $12M;投资人占 $2M / $12M = 16.7%。

### 不同阶段的估值范围(美国硅谷参考)

| 阶段 | 状态 | 典型估值范围 |
|---|---|---|
| **Pre-Seed** | 想法、团队 | $0.5M-$3M |
| **Seed** | MVP、早期用户 | $3M-$15M |
| **Series A** | PMF 信号 | $15M-$60M |
| **Series B** | 规模化 | $50M-$200M |
| **Series C+** | 高增长 | $200M+ |

中国与硅谷有差异,但量级相似。

### 五种主流估值方法

#### 1. Berkus 法(种子轮)

把创业前期"价值"分解为五个无形维度,每项最高 $0.5M(总上限 $2.5M):

| 维度 | 价值上限 |
|---|---|
| 想法的健全性 | $0.5M |
| 原型可用 | $0.5M |
| 优秀管理团队 | $0.5M |
| 战略关系/伙伴 | $0.5M |
| 产品发布或已有销售 | $0.5M |

简单但有用,主要用于 Pre-Seed/Seed。

#### 2. 风险因素汇总法

从一个基础估值(行业平均)开始,按 12 类风险加减:

风险类型(各 -2 到 +2 万美金):
- 管理团队、所处阶段、立法/政治、制造业、销售/营销、融资风险、竞争、技术、诉讼、国际、声誉、退出可能

#### 3. 可比交易法(Scorecard Method)

参考相似阶段、相似行业的近期融资:

1. 找区域内类似公司平均 Pre-Money
2. 按维度评分(团队、产品、市场等)
3. 加权得到目标公司估值

#### 4. VC 法(VC Method)

逆向估值,从退出反推:

```
退出估值(5-7 年后)
÷ 期望回报倍数(VC 通常 10x)
= 现在的目标 Post-Money
÷ 投资额放进去后的稀释
= Pre-Money 估值
```

例:退出估值 $200M / 10x = $20M Post-Money,投资 $5M → Pre-Money = $15M。

#### 5. 现金流折现 + 多场景

适用于有明确营收路径的成长期:

- 三种场景(乐观、基准、悲观)
- 每种 DCF + 概率加权
- 加上**期权价值**(未来可能性)

#### 6. 风险投资倍数法(后期阶段)

成长期常用:

- **PSR(Price-to-Sales)**:估值 / 收入
- **EV/ARR**:企业价值 / 年度经常性收入(SaaS 标准,5-15x)
- **PE 倍数**:盈利已稳定时

### 估值的关键驱动因素

| 因素 | 影响方向 |
|---|---|
| **市场规模(TAM)** | 越大越值钱 |
| **增长率** | 高增长溢价(Rule of 40 in SaaS) |
| **毛利率** | 软件 > 制造 > 服务 |
| **CAC 回收期** | 越短越值钱 |
| **NRR(净留存率)** | > 100% 显著溢价 |
| **创始人/团队** | "队伍 > 想法 > 时机" |
| **行业热度** | 风口加成 |
| **资本环境** | 加息周期估值压缩 |

### 期权池(Option Pool)的影响

融资时通常要求增设**未来员工期权池(10-20%)**,这部分稀释**创始人**而非新投资人:

- 创始人需理解"实质 Pre-Money" = 名义 Pre-Money - 期权池
- 期权池应在融资前还是融资后设?——会显著影响创始人股权!

### 估值的"人为"因素

实战中,估值常由以下因素决定:

- **谈判筹码**:多家投资人竞争 = 估值高
- **市场热度**:行业风口期估值偏高
- **创始人 FOMO**:创始人压力会让估值低
- **同期比较**:周边类似公司估值参考
- **赛道**:AI、生命科学溢价显著
- **退出预期**:被并购可能性影响 VC 倍数选择

### 高估值的双刃剑

不是"估值越高越好":

- **下轮压力**:必须实现增长才能让下轮再估更高
- **Down Round(降价轮)**:估值下降发新股,严重打击士气与信心
- **清算优先**:高估值 + 优先清算条款 = 创始人退出可能空手
- **过早进入**:估值过高让 IPO 投资人没回报空间
- **客户感知**:高估值招摇可能反损 B2B 信任

## 和其他概念的关系

- 是 [[创业机会识别]] 后融资阶段的核心工具
- 与 [[风险投资]] 体系紧密结合
- 创业估值理念与 [[企业价值评估]]、[[现金流折现模型]] 同源,但调整应用
- 与 [[相对估值法]] 中可比公司倍数法对接,但需调整
- 在 [[精益创业]]、[[商业模式画布]] 工具支撑下,估值故事更可信
- 验证用户增长后估值跃迁,见 [[产品市场契合度]]
- 期权池设计涉及 [[薪酬体系设计]] 中的长期激励
- 退出方式(IPO、并购)与 [[并购战略]] 接轨
- 在 [[国际化战略]] 中,跨国融资估值面临货币、监管、文化差异
- 受宏观影响:利率、流动性、风险偏好(参见金融学篇章)
