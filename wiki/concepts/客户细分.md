# 客户细分

## 定义

客户细分(Customer Segmentation)是把企业全部客户按属性、行为、价值、需求等维度分成若干同质组,以便对不同组实施差异化的营销、服务、产品策略。它是 [[STP分析]] 中"S"(Segmentation)的具体执行,也是 [[精准营销]]、[[CRM]]、[[CDP客户数据平台]] 的基础工作。"千人千面"的实施始于客户细分。

## 核心要点

**经典细分维度(可叠加)**:

### 1. 人口统计(Demographic)

- 年龄、性别、收入、学历、职业、家庭结构、所属城市等级。
- **优**:数据易得。**缺**:同维度内偏好可能差异巨大。

### 2. 地理(Geographic)

- 国家 / 区域 / 城市 / 街区。
- 适合本地化业务(餐饮 / 零售 / 房产)。

### 3. 心理(Psychographic)

- 价值观、生活方式、性格、兴趣偏好。
- VALS 框架(8 个心理类型)、Hofstede 文化维度。
- **优**:解释力强。**缺**:数据获取成本高,常通过问卷 / 小红书行为推断。

### 4. 行为(Behavioral)

- **购买行为**:首单 / 复购 / 频次 / 客单价。
- **使用行为**:活跃 / 使用功能 / 使用场景。
- **互动行为**:打开邮件 / 点击 / 评论。
- **决策周期**:研究 / 比较 / 决定时长。

### 5. 价值(Value-based)

- LTV(客户终身价值)分位 → Top 20% / Middle 60% / Bottom 20%。
- 高价值老客 vs 一次性流失客差别巨大。

### 6. 需求(Need-based)

- 用户为什么买?解决什么问题?
- Jobs to be Done(JTBD)框架的"任务"维度。

**RFM 模型 — 行为 + 价值的经典三维**:

- **R(Recency)最近购买**:多少天前最近一次购买?
- **F(Frequency)频次**:过去 X 月购买次数?
- **M(Monetary)金额**:累计消费多少?

各维度分高 / 低 → 8 类客户:

| RFM 组合 | 客户类型 | 应对策略 |
|---|---|---|
| HHH | 重要价值客户(VIP) | 高端服务、专属客服 |
| HHM | 一般价值客户 | 升级会员引导 |
| HHL | 一般保持客户 | 复购激励 |
| HLH | 重要发展客户 | 复购召回 |
| HLM | 一般发展客户 | 频次提升 |
| HLL | 一般新客 | 二次购买促销 |
| LHH | 重要保持客户(沉睡) | Win-back 强力召回 |
| LHM/LHL | 一般客户(流失风险) | 召回评估,放弃或挽回 |
| LLL | 流失客户 | 极简成本召回 / 放弃 |

**用户分层金字塔(常用 5 层)**:

```
        Top 5%(VIP / 超级用户)
       Top 5-20%(高价值核心)
      Middle 20-50%(中等活跃)
     Bottom 50-80%(低活跃)
    Bottom 80-100%(僵尸 / 流失)
```

每层不同营销策略:

- **VIP**:专属客服 + 优先体验 + 深度访谈。
- **高价值核心**:升级到 VIP + 维护粘性。
- **中等活跃**:激发为高价值(复购 / 升级)。
- **低活跃**:激活召回。
- **僵尸 / 流失**:降低成本触达 / 放弃。

**机器学习驱动的细分(2024+)**:

- **聚类(Clustering)**:K-Means、DBSCAN 在多维特征上自动找群。
- **隐变量模型(LDA)**:在行为序列中识别"主题"客群。
- **图聚类**:在社交关系图中识别社区。
- **深度聚类**:Autoencoder + K-means。
- 优:自动发现隐藏群,不依赖预设。缺:解释性差,需业务专家审视。

**实施流程**:

1. **数据准备**:汇聚到 [[CDP客户数据平台]] / 数仓。
2. **维度选取**:战略目标决定维度选择(留存 vs 增长 vs 复购)。
3. **细分建模**:统计 / 规则 / ML。
4. **群体特征验证**:每个群足够大(≥ 1000 人)且差异显著(业务上有意义)。
5. **策略制定**:每个群差异化营销动作。
6. **执行 + 度量**:在不同群上的转化率 / 留存率对比。
7. **迭代**:每季度重新细分(用户行为会变)。

**反模式**:

- **细分过细**:50 个细分群,每群 100 人,运营无法落地。
- **细分过粗**:全员一个营销动作 → 失去细分意义。
- **静态细分**:做一次永久不更新 → 客户已经变化。
- **不与执行挂钩**:细分报告精美但运营不用。
- **维度堆砌不取舍**:30 个维度但分不清主次。

**度量细分价值**:

- 不同群的 LTV / CR / 留存率差异(差异越大,细分越有价值)。
- 针对不同群的营销 ROI 对比。
- 跨群迁移率(用户从低价值升级为高价值的比例)。

## 和其他概念的关系

客户细分是 [[STP分析]] / [[市场细分]] 的具体执行,与 [[用户画像]]、[[用户旅程地图]]、[[CDP客户数据平台]] 三位一体。它是 [[精准营销]]、[[再营销]]、[[Lookalike人群]]、[[邮件序列设计]]、[[Push通知]] 等所有差异化触达战术的基础。

[[CRM]] / [[客户关系管理]] 与会员体系都建立在客户细分之上——会员等级是细分的可见化。它与 [[同期群分析]] 互补:同期群按时间维度切,客户细分按属性维度切。

[[销售KPI体系]] 中,不同细分群的转化目标 / 客单价 / 服务深度都不同。在 [[B2B营销]] 中,客户细分演变为 ICP(Ideal Customer Profile)+ ABM(Account-Based Marketing),按公司规模、行业、技术栈等维度。
