# 小红书广告体系

## 定义

小红书广告体系(Xiaohongshu Advertising System)是小红书平台为品牌商家提供的全链路广告产品组合,核心由四大产品线构成:**蒲公英**(达人投放交易平台)、**聚光**(效果广告投放,2023 年从原"灵犀+品牌广告"整合而来)、**品牌广告**(开屏、搜索品专、信息流大牌)、**笔记加热"薯条"**。理解整个体系是品牌在小红书做"种草-收割"闭环的基础。

## 四大核心产品

### 1. 蒲公英(达人交易平台)

- 品牌与小红书认证达人(KOL/KOC)合作的官方平台,2020 年上线
- 强制走平台:头部达人广告交易必须通过蒲公英,2023 年 9 月起未通过蒲公英的合作笔记会被限流
- 报备机制:品牌报备的笔记带"赞助"标识
- 计费方式:按笔记报价,单篇 500-50 万元不等
- 数据后台:阅读量、互动量、品牌词搜索增量等真实数据
- 选号工具:按行业、粉丝量、互动率、价格筛选

### 2. 聚光(效果广告)

- 2023 年从"灵犀+品牌广告"整合而来,小红书的"巨量千川+广点通"
- 主要广告位:信息流、搜索结果、详情页、个人主页
- 出价方式:CPC、CPM、oCPC、oCPM、oCPX
- 投放目标:商品销量、表单线索、私信咨询、店铺访问、加粉
- 人群定向:小红书自有标签 + 行业标签 + Lookalike 拓展
- 创意素材:笔记原生素材(投放笔记 + 蒲公英笔记授权投放)

### 3. 品牌广告

- **开屏广告**:App 启动时的全屏广告,品牌曝光首选
- **搜索品专**:搜索品牌词时,品牌专属落地页占据首位
- **信息流大牌**:信息流首条/Top 3 位置预定式广告
- 计价:CPM 或固定包段
- 适用:大品牌曝光、新品上市、节点营销

### 4. 薯条(笔记加热)

- 创作者自主加热笔记的低门槛工具
- 单次最低 50 元,2-24 小时分发
- 投放目标:点击、点赞、收藏、关注、商品、私信
- 主要用户:中小商家、个人 KOC
- 区别于聚光:更轻量、单次预算小、个人创作者也能用

## 投放策略矩阵

### 按品牌阶段

| 阶段 | 主用产品 | 目标 |
|---|---|---|
| 新品冷启 | 薯条 + 蒲公英(KOC 矩阵) | 测试种草卖点 |
| 品牌建立 | 蒲公英(头部 KOL) + 信息流大牌 | 心智占领 |
| 销量爆发 | 聚光 oCPX + 蒲公英(中腰部) | 转化收割 |
| 品类教育 | 蒲公英(科普类 KOL) + 搜索品专 | 教育用户 |
| 周年大促 | 品牌开屏 + 聚光 + 蒲公英 | 流量峰值 |

### 按预算

- **5 万以下**:薯条 + 1-2 篇头部 KOC + 聚光小预算测试
- **5-50 万**:聚光铺面 + 中腰部 KOC 矩阵
- **50-500 万**:加入头部 KOL + 搜索品专 + 节点品牌广告
- **500 万+**:品牌广告全套 + 跨平台联动

## 关键效果指标

1. **CPM**(展现成本):信息流 30-80 元,搜索 50-120 元
2. **CPC**(点击成本):效果广告 1-5 元
3. **CPE**(互动成本):评论/收藏成本,KPI 类项目核心
4. **品牌词搜索增量**:种草 ROI 的核心代理指标
5. **CGR**(Comment-to-Group Rate):评论引私信转化率
6. **店铺访问率**:点击广告后到店铺的比例
7. **GMV ROI**:闭环交易品牌的核心指标

## 与种草-收割闭环

小红书广告体系核心逻辑是"内容种草 → 搜索拦截 → 站内成交"三段式:
1. **种草**:蒲公英铺笔记 + 薯条加热,触达兴趣人群
2. **拦截**:用户被种草后搜索品牌词,搜索品专 + 聚光抢占首位
3. **成交**:小红书电商闭环 / 私信引流到外部 / 店铺接单

## 重要政策与红线

1. **必须报备**:商业合作笔记必须报备,2023 年 9 月后强执行
2. **品牌词审核**:某些行业(医美、保健品、教育)对品牌词保护严格
3. **违禁词**:绝对化用语、医疗效果暗示、夸大功效一律禁止
4. **薅羊毛流量**:大量低质广告会被算法拉低账号权重
5. **CPS/外链限制**:链接外站需通过官方导流功能,不可在文中放外站链接
