# Odoo 电子签名

## 定义

**Odoo Sign**(电子签名模块)是 Odoo 内置的 PDF 电子签名工具,允许用户上传 PDF 模板、定义签名 / 文本 / 日期 / 复选框字段、设置签署人顺序与角色,通过邮件链接邀请签署人完成签字,生成带审计追踪(IP、时间戳、签名图)的可执行 PDF。它是 DocuSign、Adobe Sign 的 Odoo 内嵌替代,与销售、采购、HR 流程无缝衔接。

## 核心要点

**核心功能**

1. **PDF 模板**:上传合同 / 协议 PDF,在画布上拖拽放置字段
2. **字段类型**:签名(手写或键入)、姓名、日期、文本、复选框、单选
3. **角色设定**:每字段属于"客户"、"销售经理"、"法务"等角色
4. **签署顺序**:依次签(A → B → C)或同时签
5. **邮件邀请**:每签署人收到唯一签署链接,无需 Odoo 账号
6. **完成回调**:全员签完后归档,触发后续流程(创建订单、发货等)

**审计追溯(Audit Trail)**

每次签字记录:
- 签署人 IP 地址
- 签署时间(精确到秒)
- 浏览器 User-Agent
- 签署人邮箱与身份验证方式
- 字段填写明细
- 完整 PDF 的哈希值

最终生成**审计追溯证书**(单独 PDF),与签名 PDF 一同归档,司法证据级别。

**法律效力**

- 多数国家承认电子签名等同于手写签名(美国 ESIGN Act、欧盟 eIDAS、中国《电子签名法》)
- 但**重大合同**(地产、婚姻)某些司法区仍需公证或手写
- eIDAS 三级:简单(SES)、高级(AES)、合格(QES);Odoo Sign 默认提供 SES,集成第三方可达 QES

**与其他模块的集成**

- **销售订单**:报价单发送时附 Sign 文档
- **采购订单**:供应商签字确认
- **HR 招聘**:Offer Letter 签字
- **租赁 / 订阅**:续约自动发起签字
- **合同模块**:每合同自动绑定一个签字流程

**安全机制**

- 链接含一次性 token,过期失效
- 可加密 PDF 防篡改
- 双因素验证(SMS / 邮箱二次确认)在敏感场景启用
- iCloud / OneDrive / Dropbox 集成可作为外部归档

**API 集成**

- REST API 可外部系统触发签字流程
- Webhook 在签字状态变化时回调
- 与 [[Odoo API与集成]] 一致的 OAuth 鉴权

## 与其他概念的关系

电子签名是 [[Odoo工作流]] 的关键节点,常与 [[Odoo电子发票]] 形成"电子合同 + 电子发票"的全数字交易链。在 [[Odoo HR与招聘]]、[[Odoo电商模块]] 中是合同自动化的基础。审计追溯部分关联 [[Odoo安全模型]] 的访问日志体系。

## 高频陷阱

- "签名 PDF"与"原始 PDF"的版本管理:必须固定原始版,避免签后修改
- 跨境合同需考虑各方司法辖区的电子签名法
- 链接邮件被误判垃圾邮件需检查 SPF/DKIM
- 移动端签名手写体显示要清晰,过细的笔触在 PDF 缩放时模糊
- Odoo Sign 默认级别在欧盟非合格签名,高合规场景需第三方 CA
