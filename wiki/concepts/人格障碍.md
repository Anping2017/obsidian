# 人格障碍

## 定义

人格障碍(Personality Disorders, PD)是一类稳定的、僵化的、影响认知、情感、人际、冲动控制等多个领域的人格模式。它从青少年或成年早期开始,持续存在,导致显著痛苦或功能损害。它不只是"性格古怪",而是真正的精神障碍。

DSM-5 将人格障碍分三大类:

## A 类(古怪—怪异型)

| 障碍 | 核心特征 |
|---|---|
| **偏执型**(Paranoid PD) | 长期不信任他人、被害感、敏感 |
| **分裂样**(Schizoid PD) | 社交退缩、情感淡漠、独来独往 |
| **分裂型**(Schizotypal PD) | 古怪信念、感知扭曲、奇异行为 |

## B 类(戏剧—不稳定—情绪化)

最棘手、最具临床意义:

| 障碍 | 核心特征 |
|---|---|
| **反社会型**(ASPD) | 无视他人权利、缺乏悔意、欺骗、冲动违法 |
| **边缘型**(BPD) | 情绪极度不稳、人际震荡、自伤、空虚 |
| **表演型**(HPD) | 戏剧化、寻求关注、过度情绪化 |
| **自恋型**(NPD) | 夸大自我、缺乏共情、需要赞美 |

## C 类(焦虑—回避型)

| 障碍 | 核心特征 |
|---|---|
| **回避型**(AvPD) | 社交抑制、不足感、对负评价过敏 |
| **依赖型**(DPD) | 过度依赖、无法独立决策、被动 |
| **强迫型**(OCPD) | 完美主义、刻板、不灵活(≠ OCD) |

## 边缘型人格障碍(BPD)详解

最常被研究、临床关注最多:

### 九大诊断标准(满足 5 项)
1. 极力避免被抛弃
2. 不稳定且强烈的人际关系
3. 身份不稳定
4. 冲动行为(花钱、性、物质、暴食)
5. 自杀威胁、自伤
6. 情绪不稳
7. 长期空虚感
8. 不适当的强烈愤怒
9. 应激相关偏执或解离

### 病因
- 遗传约 40-60% 可解释
- 童年创伤、忽视、不安全 [[依恋理论]]
- 神经生物学:前额叶—杏仁核回路异常
- 表观遗传与压力相互作用

### 治疗
- **辩证行为疗法(DBT)**:Marsha Linehan 开创,最有效
  - 正念、痛苦容忍、情绪调节、人际效能
- **基于心智化的疗法**(MBT):Bateman & Fonagy
- **图式疗法**:Young
- **移情焦点疗法**(TFP):Kernberg
- 药物辅助但不治本

## 自恋型人格障碍(NPD)

近年公共讨论焦点(政治、商业、社交媒体):

### 特征
- 夸大重要性
- 沉迷成功、权力、美貌幻想
- 觉得自己特别
- 需要不断赞美
- 特权感
- 利用他人
- 缺乏共情
- 嫉妒
- 傲慢

### 类型
- **浮夸型**(Grandiose):外显自大
- **脆弱型**(Vulnerable):内心脆弱、敏感、嫉妒(更难识别)
- **恶性型**(Malignant):合并反社会特征

### 治疗
- 极难,患者很少自愿求助
- 心理动力学、移情焦点

## 反社会型(ASPD)与精神病态(Psychopathy)

- ASPD 是 DSM 类别,行为为主
- 精神病态(Hare PCL-R)是更窄概念,情感缺陷为核心
- 两者重叠但不等同
- 监狱中 15-25% 满足 ASPD,但仅 1-3% 高 PCL-R 评分

## 维度模型(DSM-5 替代模型)

DSM-5 第三部分提出**替代模型**(AMPD):
- 取代分类,改用维度
- 评估人格功能损害(自我 + 人际)
- 加 25 个病理特质 facet
- ICD-11 已采用维度路径
- 学界向维度迁移趋势

## 流行病学

- 一般人群约 9-15% 满足某一 PD
- 临床样本中 50%+ 满足
- 性别:BPD 女多,ASPD 男多
- 起病:青春期晚期到成年早期
- 跨文化:核心特征普遍,但表现因文化而异

## 与其他概念关系

- 是 [[DSM-5诊断系统]] 重要部分
- 与 [[大五人格]] 维度对应:神经质↑、宜人性↓、尽责性↓
- 与 [[依恋理论]] 不安全依恋强相关
- 与 [[精神分析]] 客体关系理论密切
- [[认知行为疗法]] 演化出 DBT 应对 BPD
- [[认知偏差]] 在 NPD 自我服务表现极端
- 与 [[防御机制]] 原始防御(投射、分裂)
- 影响 [[人际关系]] 与 [[依恋理论]]
- [[团队建设]] 中难处理的"高冲突人格"

- 社交媒体与自恋流行率
- 政治领袖人格分析(Trump 等)
