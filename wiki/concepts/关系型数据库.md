# 关系型数据库 RDBMS

## 定义

**关系型数据库(Relational Database Management System, RDBMS)**是基于**关系模型**(Codd 1970)的数据库:数据以**二维表**(关系)形式组织,每行代表一条记录,每列代表一个属性。表之间通过**外键**建立关联。SQL 是其标准操作语言。

代表产品:**MySQL、PostgreSQL、Oracle、SQL Server、SQLite、MariaDB**。

## 核心要点

### 关系模型核心概念

- **表(Table / Relation)**:无序行集
- **行(Row / Tuple)**:一条记录
- **列(Column / Attribute)**:具有数据类型
- **主键(Primary Key)**:唯一标识一行
- **外键(Foreign Key)**:引用另一表的主键
- **索引(Index)**:加速查询的辅助[[数据结构]],通常是[[B+树]]
- **视图(View)**:虚拟表,基于查询的逻辑封装
- **触发器/存储过程**:DB 端业务逻辑

### SQL 三大子语言

- **DDL**(Data Definition):CREATE / ALTER / DROP
- **DML**(Data Manipulation):SELECT / INSERT / UPDATE / DELETE
- **DCL**(Data Control):GRANT / REVOKE

### JOIN 类型

| JOIN | 含义 |
|---|---|
| INNER JOIN | 两表都匹配的行 |
| LEFT/RIGHT JOIN | 保留左/右表所有行 |
| FULL OUTER JOIN | 全部保留 |
| CROSS JOIN | 笛卡尔积 |
| SELF JOIN | 自身连接(如员工-上级) |

JOIN 性能依赖索引和优化器选择的连接算法(嵌套循环、哈希连接、归并连接)。

### 范式(Normalization)

减少冗余、避免更新异常的设计指南:
- **1NF**:列不可再分(原子性)
- **2NF**:消除部分函数依赖(主键非组合或非主属性完全依赖主键)
- **3NF**:消除传递依赖
- **BCNF**:更严格的 3NF
- **反范式化**:为了性能(读优化)允许少量冗余,如电商订单冗余商品信息

### [[ACID事务]]

- **原子性 Atomicity**:全成功或全失败
- **一致性 Consistency**:满足完整性约束
- **隔离性 Isolation**:并发事务互不干扰(4 级隔离:读未提交/读已提交/可重复读/串行化)
- **持久性 Durability**:提交后数据永存(WAL 日志)

### 索引

- **B+ 树索引(默认)**:适合等值与范围
- **Hash 索引**:仅等值,如 MySQL Memory 引擎
- **位图索引(Bitmap)**:列基数小时高效,Oracle、列存
- **全文索引(Full-text)**:文本搜索
- **空间索引(R-tree)**:地理数据
- **覆盖索引**:索引含查询所需所有列,无需回表

设计原则:WHERE / JOIN / ORDER BY / GROUP BY 涉及的列考虑加索引;但每加一索引,写入变慢。

### 查询执行流程(简化)

SQL → 解析(语法树)→ 优化(代价估计)→ 执行计划(EXPLAIN)→ 存储引擎读取

慢查询分析的关键是看执行计划。MySQL InnoDB 用 B+ 树聚簇索引,主键查找一次 IO,二级索引需要"回表"两次 IO。

### 与编程语言的对接:ORM

ORM 框架(Hibernate、SQLAlchemy、Active Record、Django ORM)把表映射为对象。优势:开发快、跨数据库;缺点:**N+1 查询问题**、复杂场景生成低效 SQL。

## 和其他概念的关系

关系型数据库是[[NoSQL数据库]]的"对照面":前者结构化、强一致、支持复杂查询;后者弱化结构、追求扩展性。CAP 定理说明:在网络分区下,一致性与可用性不可兼得 → RDBMS 偏 CA;NoSQL 多偏 AP/CP。

[[数据库索引]]、[[B+树]]、[[Hash表]]构成 DB 内部数据结构基础。事务的隔离性靠 MVCC([[多版本并发控制]])或 2PL(两阶段锁)实现。WAL(Write-Ahead Log)保证持久性和崩溃恢复。

[[微服务]]架构推动"每服务一数据库",反范式化、分库分表、读写分离成为常态。NewSQL(Spanner、CockroachDB、TiDB)试图在分布式环境下保留 SQL 与 ACID。
