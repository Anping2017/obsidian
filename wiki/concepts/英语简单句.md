# 英语简单句

## 定义

简单句(Simple Sentence)是英语句法的基本单元——**仅含一个独立主谓结构**(一套主语+谓语)的句子。它可以很短(*I run.*),也可以很长(通过形容词、介词短语、不定式、分词扩展);但只要核心主谓不超过一套,就是简单句。

## 核心要点

**五大基本句型**

1. **SV(主+谓)**:不及物动词 → *Birds fly.* / *She smiled.*
2. **SVO(主+谓+宾)**:及物动词 → *I love you.* / *He wrote a book.*
3. **SVOO(主+谓+间宾+直宾)**:双宾动词 → *She gave **me a gift**.* / *He told **us a story**.*
4. **SVOC(主+谓+宾+宾补)**:复合宾语动词 → *We elected him **president**.* / *I find this **interesting**.*
5. **SVC(主+系+表)**:系动词 → *She is **a doctor**.* / *He looks **tired**.*

**SV 句型的"看似简单"扩展**

简单句不一定短:*The young engineer with the briefcase silently walked into the conference room early in the morning.* 仍是简单句——只有一个主语 the engineer + 一个谓语 walked。所有其他成分都是修饰扩展。

**辨别简单句的关键**

数主谓核心:不论形容词、介词短语、分词短语堆多少,只要主语和谓语**各只有一套**且没有连词连接其他独立分句,就是简单句。

**简单句的扩展手段**

简单句可借以下手段而不改变其"简单句"身份:
- 形容词、副词修饰
- 介词短语修饰
- 分词短语作状语 / 定语
- 不定式短语作状语 / 定语 / 主语 / 宾语
- 同位语
- 独立主格结构(虽含主语但不算独立从句)

**与其他句型的对比**

| 句型 | 独立分句数 | 连接方式 |
|---|---|---|
| 简单句 | 1 | 无 |
| 并列句 | 2+ | 并列连词(and、but、or) |
| 复合句 | 1 主 + 1 从 | 从属连词(that、because、if) |
| 并列复合句 | 2+ 主 + 1+ 从 | 兼有上述两种 |

## 与其他概念的关系

简单句是 [[英语并列句]] 与 [[英语复合句]] 的构件;其内部由 [[英语主谓宾结构]] 与 [[英语句子成分]] 详细描述。所有 [[英语时态体系]] 的练习起点都是简单句。

## 高频陷阱

- 把"长句子"误以为是复合句:不要看长度,要数主谓核心数量
- SVOC 与 SVOO 易混:补足语(指向宾语)vs 直接宾语(独立指称)
- 系动词不只 be 一个:look、seem、become、grow、turn、prove、appear 也接表语
- 简单句中宾语补足语的形式多样:形容词(happy)/ 名词(president)/ 动名词(working)/ 不定式(to leave)/ 分词(broken)
