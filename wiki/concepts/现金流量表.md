# 现金流量表

## 定义

**现金流量表**(Cash Flow Statement, CFS)是反映企业在一定会计期间内现金及现金等价物**流入和流出**情况的会计报表。它弥补了 [[利润表]] 的"权责发生制"局限——账面利润不等于现金,而企业死亡多由现金枯竭(而非亏损)直接导致。

现金流量表与 [[资产负债表]]、[[利润表]] 并称三大主表,1987 年起在国际范围广泛采用,是评估企业**短期偿债能力**与**真实盈利质量**的关键工具。

## 核心要点

### 三大活动分类

| 活动类别 | 现金流入 | 现金流出 |
|---|---|---|
| **经营活动** | 销售商品、提供劳务收到的现金;收到税费返还 | 购买商品、接受劳务支付的现金;支付员工薪酬;支付各项税费 |
| **投资活动** | 收回投资、取得投资收益;处置固定/无形/长期资产 | 购建固定/无形/长期资产;对外投资 |
| **筹资活动** | 吸收投资、取得借款、发行债券 | 偿还债务本金、分配股利、利息支付 |

健康的成熟企业典型特征:**经营活动现金流为正且持续增长,投资活动为负(扩张),筹资活动取决于战略**。

### 编制方法

- **直接法**:按现金流入流出项目逐项列示,直观清晰,中国准则要求作为正表
- **间接法**:从净利润出发,通过非现金项目调整(折旧摊销、营运资本变动等)倒推经营活动现金流,作为附注披露

间接法的核心调整公式:
```
经营现金流 = 净利润 + 折旧摊销 + 减值损失 - 应收账款增加
           - 存货增加 + 应付账款增加 + 财务费用 + 投资损失 (调出投资活动)
           - 所得税费用调整等
```

### 自由现金流(FCF)

不是会计准则的列报项目,但极其重要,是 [[现金流折现模型]] 的核心:

- **FCFF**(企业自由现金流)= EBIT × (1-T) + 折旧摊销 - 营运资本增量 - 资本性支出
- **FCFE**(股权自由现金流)= 净利润 + 折旧摊销 - 营运资本增量 - 资本性支出 + 净借款

### 分析视角

- **盈利质量**:经营现金流/净利润,>1 说明利润有现金支撑
- **现金充足率**:经营现金流/(资本支出+股利)
- **现金偿债比率**:经营现金流/总负债

许多财务舞弊案例(安然、瑞幸)本质是利润表"造假"而现金流量表"失真"——这正是 SEC 与 IFRS 加强 CFS 审计的根源。

## 和其他概念的关系

- 是 [[利润表]] 在现金口径下的"翻译",揭示权责发生制与收付实现制的差异
- 期末现金余额对应 [[资产负债表]] 的货币资金,形成三表交叉验证
- 是 [[企业价值评估]] 中 [[现金流折现模型]] 唯一可靠的输入源(双向:估值倒过来要求现金流可持续)
- [[财务比率分析]] 中现金流比率属于专门一类
- 与 [[营运资金管理]]、[[资本预算]] 决策直接关联
- [[投资银行]] IPO 审核、[[信用评估]] 都把 CFS 作为优先核查对象
- [[基本面分析]] 把"经营现金流是否长期健康"列为价值投资的硬性筛选标准
