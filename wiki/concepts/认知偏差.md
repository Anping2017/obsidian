# 认知偏差

## 定义

**认知偏差**(Cognitive Bias)指人在信息加工中**系统性偏离理性判断的思维模式**。它不是随机错误,而是在大量人群中可复现的、有方向的偏差。源头是大脑容量有限、依赖启发式(heuristic)简化、情绪卷入。它是 [[行为金融学]] 与 [[行为经济学]] 的心理基础,也是 [[芒格]] 提出的"误判心理学"的核心议题。

## 核心要点

### 三大特征

- **系统性**:同一种偏差在大量人身上可重复出现
- **无意识性**:不是有意为之,通常被偏差者本人觉察不到
- **抗教育性**:即便知道存在,仍难完全避免(自身偏差盲点)

### 核心偏差清单(简表)

| 类型 | 偏差 | 简述 |
|---|---|---|
| **信息处理** | [[确认偏差]] | 优先寻找支持现有信念的证据 |
| | [[可得性启发]] | 用容易回忆的例子代替统计概率 |
| | 代表性启发 | 用相似性代替基础概率 |
| **决策** | [[锚定效应]] | 过度依赖最初信息 |
| | [[损失厌恶]] | 损失痛苦约为同等收益快乐的 2 倍 |
| | 现状偏差 | 偏好维持现状 |
| | 沉没成本 | 让已不可挽回的投入影响后续决策 |
| **社交** | [[羊群效应]] | 跟随多数人决策 |
| | [[首因效应]] | 第一印象主导整体评价 |
| | 光环效应 | 一项突出特征影响整体评判 |
| **自我评价** | 过度自信 | 高估自己能力与判断准确性 |
| | 邓宁-克鲁格效应 | 能力差者反而最自信 |
| | 自利偏差 | 成功归己,失败归外 |
| **记忆** | 后视偏差 | 事后觉得"早就知道" |
| | [[近因效应]] | 最近信息权重过大 |

### 卡尼曼双系统理论

- **系统 1**:快、自动、直觉、低耗能 —— 偏差来源
- **系统 2**:慢、刻意、逻辑、高耗能 —— 偏差纠正
- 关键:多数日常决策由系统 1 接管;系统 2 因费力而懒得介入

### 进化解释

- 启发式在祖先环境中是有效近似:见到草丛动→快速逃跑(假阳性代价低)
- 现代信息环境与决策结构改变,但大脑硬件没变 → 偏差暴露
- 不能完全消除,但可通过制度设计、认知训练**降低危害**

### 应对策略

1. **慢思考**:重要决策强制延迟,激活系统 2
2. **预承诺**:提前定下规则,避免临时被偏差劫持(投资设定纪律)
3. **逆向检查**:专门寻找反证(对抗确认偏差)
4. **基础概率**:用统计数据而非个例(对抗代表性启发)
5. **多元化决策环境**:由不同视角的人参与
6. **清单制度**:用 checklist 把易遗忘项目硬性化

## 和其他概念的关系

- 认知偏差是 [[行为金融学]] 与 [[行为经济学]] 的心理基础
- 是 [[卡尼曼]] 前景理论与双系统理论的实证集合
- [[芒格]] 在《人类误判心理学》中系统列出 25 类
- 与 [[确认偏差]]、[[锚定效应]]、[[损失厌恶]]、[[可得性启发]]、[[首因效应]]、[[近因效应]] 等具体偏差互为子条目
- [[批判性思维]] 是其主要解药
- 与 [[启发式]](heuristic)是一体两面
- 在投资中影响 [[投资决策框架]] 的实际运行
- 衔接 [[芒格多元思维模型]] —— 多模型对冲单一思路偏差
- 营销应用:认知偏差体系是 [[营销心理学]] 实操工具箱的"心理学元目录",几乎所有营销技巧都可归类为对某种偏差的利用或缓解;在 [[用户画像]] 的心理特征维度中,记录用户主导的偏差类型可以指导差异化沟通策略;在 [[消费者行为]] 的决策过程中,从信息搜索到购后评价每一阶段都受不同偏差驱动,理解这一点是从"猜用户"到"懂用户"的分水岭
