# 树 Tree

## 定义

**树(Tree)**是一种由节点(Node)和边(Edge)构成的**层次型**[[数据结构]],满足:
- 有且只有一个**根节点(Root)**,没有父节点
- 除根外每个节点恰有一个父节点
- 不存在环路(否则就是[[图]])

关键术语:**度(Degree)**=子节点数;**高度(Height)**=根到最深叶的边数;**深度(Depth)**=节点到根的距离;**叶子(Leaf)**=度为 0 的节点。

## 核心要点

### 主要变种

| 类型 | 特征 | 典型应用 |
|---|---|---|
| 二叉树(Binary Tree) | 每节点至多 2 子 | 表达式树、Huffman 树 |
| 二叉搜索树(BST) | 左 < 根 < 右 | 有序集合、字典 |
| 平衡树(AVL/红黑树) | 高度 O(log n) | Java TreeMap、Linux CFS 调度 |
| B 树 / B+ 树 | 多路平衡 | [[数据库索引]]、文件系统 |
| 字典树(Trie) | 路径表示前缀 | 自动补全、IP 路由 |
| 堆(Heap) | 完全二叉树 + 偏序 | 优先队列、堆排序 |
| 线段树/树状数组 | 区间统计 | 区间和、最值查询 |

### 二叉搜索树(BST)

性质:对任意节点,左子树所有键 < 该节点键 < 右子树所有键。
- 平均 O(log n) 增删查,但最坏 O(n)(退化为链表)
- 中序遍历得到有序序列

### 自平衡树(AVL / 红黑树)

通过旋转操作维持高度 O(log n)。
- **AVL**:严格平衡(任意节点左右子树高度差 ≤ 1),查询快、插删慢
- **红黑树**:近似平衡(最长路径 ≤ 2 × 最短),插删少 (Java HashMap、TreeMap、Linux 内核 epoll/CFS 用)

### 树的遍历

- **前序(Pre-order)**:根 → 左 → 右,常用于序列化
- **中序(In-order)**:左 → 根 → 右,BST 中得到有序序列
- **后序(Post-order)**:左 → 右 → 根,删除/求子树值
- **层序(Level-order)**:[[BFS广度优先搜索]]

### B 树与 B+ 树(磁盘友好)

针对**磁盘 IO 高代价**优化的多路平衡树:
- 每个节点存几十到几百个键
- 高度极低(几亿数据高度仅 3-4)
- B+ 树叶子节点串成链表,利于范围扫描
- **应用**:MySQL InnoDB(B+ 树)、PostgreSQL、MongoDB(B-Tree)、Linux ext4

### 字典树(Trie / Prefix Tree)

每条路径表示一个字符串,公共前缀共享节点。
- 时间 O(m),m 是字符串长度,与树中字符串数无关
- 应用:输入法、搜索引擎自动补全、IP 路由表(最长前缀匹配)、敏感词过滤

## 和其他概念的关系

树是[[图]]的特例(无环连通图)。它在系统软件中无处不在:
- **[[操作系统]]**:进程树、文件目录树、虚拟内存的多级页表
- **[[数据库]]**:索引几乎都是 [[B+树]] 或其变体
- **[[编译原理]]**:抽象语法树(AST)、解析树、表达式树
- **网络**:DNS 是分布式树形命名空间;路由表用 Trie
- **算法**:[[动态规划]]在树上的"树形 DP"是经典模型;[[排序算法]]中的堆排序、归并排序的递归调用栈构成树

[[堆]]是完全二叉树 + 偏序的特殊树。[[Hash表]]在 Java 8 后冲突链长会转红黑树。Git 的对象模型是 Merkle 树(Commit→Tree→Blob)。区块链同样用 Merkle 树。
