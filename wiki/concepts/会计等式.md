# 会计等式

## 定义

**会计等式**(Accounting Equation)是反映会计要素之间数量关系的等式,是会计核算的理论基石,也称为**会计恒等式**或**资产负债平衡式**。

它有三种主要形态:

- **基本式**(静态):资产 = 负债 + 所有者权益
- **扩展式**(动态):资产 = 负债 + 所有者权益 + (收入 - 费用)
- **综合式**:资产 = 负债 + 所有者权益 + 利润 (期末未分配前)

## 核心要点

### 经济含义

基本式可从两个角度解读:

- **资金运动角度**:左边代表企业拥有的"经济资源",右边代表这些资源的"资金来源"——一部分来自债权人(负债),一部分来自股东(所有者权益)
- **法律产权角度**:总资产 = 债权人对资产的求偿权 + 股东对净资产的剩余索取权

### 经济业务对等式的影响

任何业务都不会破坏等式平衡,共有 9 种基本类型:

| 业务类型 | 等式变化 | 例子 |
|---|---|---|
| 资产内部一增一减 | 不变 | 用银行存款购买原材料 |
| 负债内部一增一减 | 不变 | 短期借款偿还应付账款 |
| 权益内部一增一减 | 不变 | 盈余公积转增资本 |
| 资产+负债同增 | 两边同增 | 赊购原材料 |
| 资产+权益同增 | 两边同增 | 收到投资 |
| 资产+负债同减 | 两边同减 | 偿还短期借款 |
| 资产+权益同减 | 两边同减 | 用利润分红 |
| 负债+权益一增一减 | 不变 | 债转股 |
| 涉及收入费用 | 间接通过利润影响权益 | 销售商品 |

### 扩展式的意义

将收入费用纳入后,等式变为"**资产 = 负债 + 所有者权益 + 收入 - 费用**"。这把利润表的两大要素与资产负债表打通,是 [[复式记账法]] 同时维护两张主表平衡关系的数学保障。

### 与三大报表的对应

- [[资产负债表]] 直接映射基本式,左右两栏分别列示等式两边
- [[利润表]] 展开"收入 - 费用 = 利润"
- [[现金流量表]] 间接法是从净利润倒推现金流,本质仍依赖等式逻辑

## 和其他概念的关系

- 是 [[会计要素]] 之间数量关系的形式化表述
- 是 [[复式记账法]] "有借必有贷,借贷必相等"规则的根本依据
- 是 [[资产负债表]] 编制和 [[试算平衡]] 的理论基础
- 在 [[财务比率分析]] 中,资产负债率、权益乘数等指标本质都是等式各项的比率
- 与 [[资本结构理论]] 中"资产 = 债务融资 + 股权融资"的视角同源
- 现代公司治理(参见 [[公司治理结构]])关于"债权人 vs 股东"的代理问题源于等式右边的两类资金提供方
