# 创业

## 定义

**创业**(Entrepreneurship)是发现并把握机会,在不确定环境下整合资源、创造价值、承担风险的过程。古典定义来自经济学家熊彼特——创业者是"打破均衡的破坏式创新者";现代定义则强调机会识别、价值创造与组织建造的闭环。

它与"开公司"不完全等同——大企业内部也有创业(Intrapreneurship),社会创业(Social Entrepreneurship)目标是社会价值而非利润。

## 核心要点

### 创业的核心阶段

| 阶段 | 关键任务 |
|---|---|
| **机会识别** | 发现市场缺口或新需求,见 [[创业机会识别]] |
| **概念验证** | 用 [[MVP]] 与 [[精益创业]] 验证假设 |
| **产品市场契合** | 找到 [[产品市场契合度]],完成 PMF |
| **规模化** | 渠道、销售、组织扩张 |
| **组织化** | 治理、文化、流程,从初创到成熟企业 |
| **退出或永续** | IPO、并购、永续经营 |

### Timmons 创业铁三角

- **机会**(Opportunity):市场缺口、技术变革、监管变化
- **资源**(Resources):资金、人才、网络
- **团队**(Team):创始人组合与执行力

三者互动决定创业成败。

### 创业方法论的演进

| 阶段 | 代表 | 思想 |
|---|---|---|
| **熊彼特创业理论** | [[熊彼特]] | 创新是创业本质,[[创造性破坏]] |
| **Drucker 创业管理** | [[彼得·德鲁克]] | 创业是有方法可学的实践 |
| **Stevenson 机会观** | Howard Stevenson | "在不被资源约束下追求机会" |
| **客户开发** | Steve Blank | [[客户开发]] 四步走出办公室 |
| **精益创业** | [[艾瑞克·莱斯]] | [[精益创业]]、Build-Measure-Learn |
| **蓝海战略** | 钱·金 | [[蓝海战略]] 从竞争到价值创新 |

### 创业类型

- **生活型(Lifestyle)**:个人/家庭式,小而美
- **小企业(Small Business)**:稳定盈利,不追求高速增长
- **可扩展(Scalable Startup)**:VC 模式,追求大规模与指数增长
- **大企业内创业(Corporate Venture)**:IBM、3M、Google X
- **社会创业(Social Entrepreneurship)**:解决社会问题
- **买家型(Buyout Entrepreneurship)**:收购成熟企业并改造

### 关键能力

| 能力 | 内涵 |
|---|---|
| **机会识别** | 发现非显性需求与变化信号 |
| **韧性** | 面对失败、不确定、孤立的心理素质 |
| **决策** | 信息有限下的快速取舍 |
| **影响力** | 对客户、员工、投资人、媒体的说服 |
| **学习速度** | 持续比对手更快迭代 |
| **关系网络** | 创业是高密度社交的工作 |

### 融资阶段

- **种子轮 / 天使轮** → 验证想法与团队
- **A 轮** → PMF 后小规模放大
- **B/C 轮** → 规模化、扩品类、扩区域
- **D+/Pre-IPO** → 利润/治理为重
- **IPO** → 上市后组织根本变化

### 失败原因(CB Insights 复盘)

1. 没有市场需求(35%)
2. 钱烧完了(38%)
3. 团队不对(23%)
4. 被竞争压垮(20%)
5. 商业模式不行(18%)

很多原因彼此交织;PMF 是最常见的根本症结。

## 应用场景

- **科技创业**:SaaS、AI、消费电子
- **传统行业**:餐饮、零售、教育、医疗
- **数字内容**:自媒体、独立游戏、知识付费
- **社会创业**:扶贫、教育公平、环保
- **大企业内创业**:新业务孵化、企业风投(CVC)

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **想法 ≠ 公司** | 想法廉价,执行决定一切 |
| **过早扩张** | PMF 之前砸钱拉新会反向加速死亡 |
| **创始人摩擦** | 股权与角色不清是 1 号杀手 |
| **回避数据** | "我们的产品不适合 AB 测试" 是最常见自欺 |
| **错的投资人** | 估值高 ≠ 战略一致 |
| **忽视现金流** | 增长好看但断粮就完蛋 |
