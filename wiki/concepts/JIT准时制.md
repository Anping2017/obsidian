# JIT 准时制

## 定义

**JIT(Just-In-Time)准时制** 指**在需要的时间、需要的地点、按需要的数量**生产或交付物料的运营方式。它通过**拉动**(Pull)而非推动(Push)、缩小批量、消除缓冲库存,把库存从"必要之恶"转变为"需要消除的浪费"。

JIT 起源于 [[丰田生产方式]],后被泛化为制造、物流、零售各领域的核心理念,与 [[精益生产]] 互为表里。

## 核心要点

### JIT 的三大要素

| 要素 | 内涵 | 工具 |
|---|---|---|
| **持续流(Continuous Flow)** | 单件流、消除工序间停留 | 单元式布局、混合机型 |
| **拉动(Pull)** | 由下游需求触发上游 | 看板(Kanban)信号 |
| **节拍(Takt Time)** | 生产速度匹配需求速度 | Takt = 可用时间 / 需求量 |

### 看板系统(Kanban)

JIT 的可视化拉动机制:

- **生产看板**:授权某工序生产一定数量
- **领取看板**:授权从前工序领取物料
- 看板数量 = (需求量 × 提前期 × 安全系数) / 容器容量
- 看板减少 → 库存减少 → 暴露问题 → 改善 → 进一步减少

### JIT 与传统 MRP 推动式的对比

| 维度 | 传统推动(Push/MRP) | JIT 拉动(Pull) |
|---|---|---|
| 触发 | 计划预测 | 实际需求 |
| 库存 | 高(缓冲) | 极低 |
| 批量 | 经济批量(EOQ) | 接近单件 |
| 提前期 | 长 | 短 |
| 灵活性 | 低 | 高 |
| 风险 | 库存过剩/呆滞 | 供应中断 |

### JIT 实施的前提条件

JIT 不是无门槛技术,需要:

1. **稳定需求**:剧烈波动会击穿薄库存
2. **可靠供应**:供应商必须 JIT 配合
3. **质量过关**:无瑕疵的物料,出错即停产
4. **快速换模(SMED)**:小批量经济性靠这个
5. **组织文化**:全员改善、可视化管理
6. **物理布局**:供应商靠近、单元化产线

### JIT 的脆弱性与现代演化

JIT 在稳定环境下极强,但在突发危机下脆弱:

- 2011 日本地震使丰田全球停产
- 2020 新冠疫情暴露医疗物资 JIT 之痛
- 2021-2022 芯片短缺让汽车业大伤

后疫情时代趋势:

- **JIT + JIC(Just-In-Case)** 混合,关键物料保持战略库存
- **多源供应**:替代单一来源
- **近岸/友岸外包**(Nearshoring, Friendshoring)
- **供应链可视化与韧性**:从精益转向"敏捷+精益"

### JIT 的应用扩展

不仅限于制造业:
- **零售**(沃尔玛 Cross-Docking、ZARA 快时尚)
- **餐饮**(寿司之神现做现卖)
- **服务业**(医院按需备床)
- **软件开发**(看板法、Lean Startup)

## 和其他概念的关系

- 是 [[丰田生产方式]] 的核心支柱与 [[精益生产]] 的核心思想
- 重塑 [[供应链管理]] 的库存策略与供应商关系
- 与 [[库存管理]] 中的 EOQ 模型构成两种范式
- 数字时代演化为 [[敏捷供应链]](本 vault 未单立)与可视化平台
- 风险面对应 [[供应链中断风险]](疫情、地缘政治)
- 看板思想被软件开发界采用为 Kanban 方法,与敏捷开发结合
- 生产层面与 [[质量管理]]、[[六西格玛]] 协同(Lean Six Sigma)
- 体现 [[管理决策]] 的"暴露问题驱动改善"哲学
