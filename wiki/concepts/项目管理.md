# 项目管理

## 定义

**项目管理**(Project Management)是在**有限的范围、时间、成本、质量、资源、风险**约束下,通过系统的规划、执行、监控与收尾过程,达成既定目标的管理实践。它针对"项目"——有明确开始与结束、产出独特成果的临时性工作——区别于持续性的运营管理。该领域已发展为成熟学科,有 PMI、PRINCE2、IPMA 等国际标准化体系。

## 核心要点

### 五大过程组(PMBOK)

1. **启动**:立项、目标定义、利益相关者识别
2. **规划**:范围、时间表(WBS)、预算、风险计划
3. **执行**:团队组建、资源分配、交付物产出
4. **监控**:进度、成本、质量、风险跟踪与调整
5. **收尾**:验收、文档归档、复盘

### 十大知识领域

整合、范围、时间、成本、质量、资源、沟通、风险、采购、相关方管理。

### 经典约束三角(铁三角)

**范围、时间、成本** 三者互相制约,质量是中心。任意调整一边都影响其他边。

### 主要方法论

| 方法 | 特点 | 适合 |
|---|---|---|
| **瀑布(Waterfall)** | 阶段顺序,文档详尽 | 需求稳定的工程 |
| **敏捷(Agile)** | 迭代、短周期、拥抱变化 | 软件开发、不确定环境 |
| **Scrum** | 敏捷的具体实现,Sprint + 仪式 | 软件团队 |
| **看板(Kanban)** | 可视化流、限制 WIP | 持续运营、运维 |
| **PRINCE2** | 控制导向、阶段化 | 大型受控项目(欧洲多见) |
| **关键路径法 CPM / PERT** | 数学化进度优化 | 复杂工程项目 |

### 关键工具

- **WBS**(工作分解结构):把目标层层分解到可执行任务
- **甘特图**:时间轴上的任务排期
- **关键路径**:决定项目最短工期的任务链
- **燃尽图/燃起图**(敏捷):剩余/累积工作量趋势
- **挣值管理(EVM)**:预算执行与进度的统一度量
- **风险登记册**:风险识别、概率、影响、应对

### 项目经理的核心能力

- **沟通**:占项目经理 70–90% 时间
- **谈判**:范围、资源、优先级
- **风险敏感度**:提前识别隐患
- **领导**:[[领导力]] 在项目情境的应用
- **冲突管理**:跨职能协作不可避免冲突
- **业务理解**:不只是排期师,要懂项目背后的业务价值

### 现代趋势

- **混合方法**:同一组织内不同项目用不同方法
- **PMO 演进**:从控制中心到赋能中心
- **AI 辅助**:风险预测、自动排期、知识沉淀
- **远程协作**:对工具与文化的双重要求

## 和其他概念的关系

- 是 [[管理职能]] 中"计划"与"控制"的项目化形式
- 与 [[领导力]]、[[团队建设]] 在临时组织上紧密交织
- 与 [[运营管理]] 形成"项目 vs 运营"对照
- 与 [[资本预算]] 中的项目评估互为前后端
- 在数字化转型中,常作为变革管理的载体
