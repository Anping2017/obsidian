# 户外应急医疗

## 定义

户外应急医疗(Wilderness First Aid,WFA / Wilderness Medicine)是非专业医疗背景的户外人员在远离医院、救援困难的环境中处置伤病的实践体系。它的核心假设与城市急救完全不同:

- **救援延迟**:从数小时到数日才能后送
- **装备限制**:不能依赖医院级设备
- **环境恶劣**:极端温度、高度、孤立
- **决策权重**:何时撤离、何时继续行程是医疗外的关键判断

主流认证体系:
- **WFA(Wilderness First Aid,2 天)**:基础
- **WAFA(Advanced WFA,4 天)**
- **WFR(Wilderness First Responder,8-10 天)**:户外专业,登山向导、Outward Bound 标准
- **WEMT(Wilderness EMT,1 月)**:全职专业

## 核心评估流程(SOAP / DRABCDE)

**ABCDE 顺序**

1. **A(Airway,气道)**:意识、气道通畅
2. **B(Breathing,呼吸)**:呼吸频率、深度
3. **C(Circulation,循环)**:脉搏、出血、休克迹象
4. **D(Disability,意识)**:GCS 量表、瞳孔反应
5. **E(Exposure / Environment,暴露 / 环境)**:全身查体、防失温防中暑

**SOAP 记录**

- **S(Subjective)**:伤者主诉、病史、过敏、用药
- **O(Objective)**:客观体征、生命体征
- **A(Assessment)**:你的评估、可能问题
- **P(Plan)**:处理方案、撤离否

记录非常重要,即使无法立刻撤离,也是后送医院、保险理赔依据。

## 高频场景与处理

**1. 失温(Hypothermia)**

- 早期(轻度):颤抖、笨拙、不清醒。立即换干衣服 + 热饮 + 进帐篷睡袋
- 中度:停颤抖、意识模糊。被动回温 + 胸部贴热水袋
- 重度:无意识、呼吸微弱。极小心搬运(心脏脆弱),轻搬 ABM(防震、保暖、缓回温)
- 错误:不要快速浸热水(诱发心脏骤停)、不要让其饮酒

**2. 中暑(Heat Stroke)**

- 中暑前期(Heat Exhaustion):头晕、恶心、大量出汗。荫凉 + 补水 + 含盐
- 中暑(Heat Stroke):皮肤红干、不出汗、高烧、神志改变。**最危急**——立即降温(湿布、冷水、风吹),同时呼救后送

**3. 扭伤 / 骨折**

- RICE 原则:Rest(休息)、Ice(冰敷,有冰时)、Compression(压迫包扎)、Elevation(抬高)
- 怀疑骨折:固定(夹板、毛巾卷)、不复位、撤离
- 开放骨折:控出血 + 覆敷料 + 紧急后送

**4. 大出血**

- 直接压迫(15-30 分钟不松)
- 如肢体严重出血压迫无效:止血带(Tourniquet)
  - 美国军用 CAT 止血带、SOFTT-Wide 民用易用
  - 标记上止血时间
  - 仅在断肢、动脉出血时用
- 包扎止血敷料(Israeli Bandage、QuikClot)

**5. 过敏与休克**

- 蜂蛰、食物、虫咬可触发严重过敏(Anaphylaxis)
- 症状:荨麻疹、咽喉肿、呼吸困难、休克
- 处理:**EpiPen 肾上腺素自注射**(已知过敏者必带)、立即后送
- 抗组胺药(Benadryl、氯雷他定)用于轻度

**6. 毒蛇咬伤**

- 中国境内常见:蝮蛇、五步蛇、银环蛇等
- 处理:静卧 + 标记肿胀范围 + 解开束缚物 + **不要切开吸毒** + 紧急后送医院打抗蛇毒血清
- 中毒时间窗:6-24 小时

**7. 高原反应(AMS / HAPE / HACE)**

- 急性高山病(AMS):头痛、恶心、失眠。下降 300-500m 多数缓解
- 高原肺水肿(HAPE):咳粉红泡沫痰、呼吸困难。**立即下降 + 氧气**
- 高原脑水肿(HACE):神志改变、共济失调。**最危急,立即下降**
- 预防:逐步上升(每天 < 500m)、地塞米松(医嘱)

**8. 烧伤**

- 一度(红肿):流动凉水 10-20 分钟
- 二度(水泡):同上 + 不挑泡 + 覆敷料
- 三度(炭化):**紧急后送**,覆湿净敷料,防感染

**9. 头部外伤**

- 任何头部撞击 + 失忆/呕吐/视力问题 = 怀疑脑震荡
- 监测意识:每 30 分钟评估 GCS
- 严重头伤:48 小时观察、避免再撞、立即后送

## 装备:户外急救包

**核心物品**

- 创可贴各尺寸
- 纱布、敷料、医用胶带
- 弹性绷带(扭伤、压迫)
- 三角巾(固定、悬吊)
- 止血带(CAT)
- 镊子、剪刀、安全别针
- 体温计
- 个人药物(过敏药、抗生素、止泻、止痛)
- EpiPen(已知过敏)
- 防晒霜、晒后修复
- 防虫液、毒虫咬伤药
- 抗组胺药(氯雷他定)
- 止痛药(布洛芬、对乙酰氨基酚)
- 抗腹泻(蒙脱石散、洛哌丁胺)
- 抗细菌乳膏

**重型补充(长途/团队)**

- AED(自动体外除颤器,价格贵)
- 氧气瓶(高山专业)
- 缝合包(野外缝合需培训)
- 紧急保暖毯

## 决策:留 vs 撤

WFA 培训核心是教你"何时撤离":

**立即撤离指征**

- 失明、视力模糊
- 意识改变(嗜睡、谵妄)
- 严重头痛、颈僵
- 高烧不退
- 呼吸困难加重
- 不能行走的下肢损伤
- 大出血控不住
- 持续呕吐 / 腹泻 / 脱水
- 怀疑心脏问题

**可观察处理**

- 轻度割伤、扭伤
- 一度烧伤
- 轻度 AMS(下降即缓解)
- 短暂胃肠不适

## 求救方式

**电话**

- 普通电话:中国 110(救援)、120(医疗)
- 卫星电话:Iridium、海事卫星(高山远征必备)

**信号**

- 三声哨子(国际求救)
- SOS 镜面反射、火光
- 红色烟火
- 标志性 X 字符在地面

**SOS 设备**

- Garmin inReach(双向卫星短信、SOS 一键)
- ACR ResQLink PLB(单向 SOS)
- iPhone 14+ 卫星 SOS(美国/部分地区)

## 法律与责任

中国《民法典》"好人法"鼓励施救但需在能力范围。专业救援人员要求执照,业余救援无强制责任,但有道德义务。商业户外活动方应签免责书并配 WFA 资质人员。
