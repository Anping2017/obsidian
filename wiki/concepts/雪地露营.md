# 雪地露营

## 定义

雪地露营(Winter / Snow Camping)是在**地表覆盖积雪、气温常持续低于 0℃**环境下的过夜活动。它是难度最高的露营场景之一,核心挑战不是"冷",而是**失温**(Hypothermia)、**湿气管理**、**装备失效**、**地形识别**(雪下可能有暗河 / 冰裂缝)。需要专门装备、技能、风险评估,通常仅推荐有经验者参与。

## 核心要点

**核心风险**

1. **失温**:湿衣 + 风寒效应 → 体核温度下降 → 神志混乱 → 死亡
2. **冻伤**:暴露皮肤(指尖、脸颊、耳朵)在 -10℃ 以下 30 分钟内可冻伤
3. **雪盲**:紫外线雪面反射,无墨镜数小时即角膜损伤
4. **暗河 / 冰裂缝**:看似稳固的雪面下空洞
5. **雪崩**:特定坡度(30-45°)+ 新雪即高风险

**装备清单(冬营专用)**

| 类别 | 标准 |
|---|---|
| 帐篷 | 四季帐 / 棉布印第安帐(可烧火) |
| 睡袋 | 极限 -25℃ 以下,羽绒推荐(700+ FP) |
| 地垫 | R 值 ≥ 5(双层叠加更佳) |
| 服装 | 三层系统:速干内 + 抓绒 / 羽绒 + 硬壳冲锋衣 |
| 鞋 | 雪地靴 + 雪套(Gaiter) |
| 头部 | 抓绒帽 + 巴拉克拉法 + 滑雪镜 |
| 手 | 内手套 + 防水外套(双层) |
| 炊具 | 液体燃料炉(白汽油、油不冻,丁烷在 0℃ 以下失效) |
| 水 | 真空保温瓶或贴身放置防冻 |
| 紧急 | 卫星通讯(InReach / 北斗短报文)、急救包、雪铲 |

**搭建技巧**

1. **选址**:避开雪崩地形、风口、雪檐下方;选地势稍高、阳光充足处
2. **整地**:踩实雪面再扎营,否则一夜后帐内地面塌陷
3. **挖防风墙**:迎风方向堆雪墙,挡风又保温
4. **雪锥 / 死人锚(deadman)**:普通地钉无用,用十字交叉的雪锥或埋雪袋作锚
5. **挖前厅**:帐前挖凹坑放鞋 / 炊具,人坐姿不蜷缩

**保暖策略**

- **三层穿衣法**:内层排汗 / 中层保暖 / 外层防风防水
- **干燥优先**:湿衣立即换,睡袋里禁穿湿衣
- **羽绒服 vs 化纤**:羽绒轻保暖好但怕湿;湿润环境用 PrimaLoft / ThermoBall 化纤
- **睡前热饮 / 加餐**:身体新陈代谢生热
- **暖手宝 / 热水袋塞睡袋**:辅助加热,不是主热源
- **不要喝酒"取暖"**:酒精扩张外周血管,实际加速失温

**水源管理**

- 雪需融化才能喝(直接吃雪降低体温且效率低)
- 融雪先放少量"种子水"防糊锅
- 瓶装水夜间倒置(瓶口在下,冰从底部结冻不影响开瓶)
- 露天瓶子不用时埋雪(温度比空气更高更稳定)

**应急判断**

- 发现同伴语无伦次 / 协调失调 / 反应迟钝 → 失温前兆,立即停下处理
- 处理失温:换干衣 → 进睡袋 → 加暖水袋 → 摄入糖分热饮
- 严重失温(意识不清)需医疗救援

## 高频陷阱

- 丁烷 / 异丁烷气罐在 0℃ 以下气化效率骤降,需液体燃料炉
- 棉质内衣致命("Cotton Kills"——湿后不保暖且失温加速)
- 下雪夜帐顶积雪压坏杆架,需间歇起夜清雪
- 帐内做饭风险:CO 中毒 + 火灾(只在前厅 / 通风极佳处)
- 冬季日落早(下午 4 点天黑),晚出发会被困
