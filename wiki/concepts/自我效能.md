# 自我效能

## 定义

**自我效能感**(Self-Efficacy)是 [[班杜拉]] 1977 年提出的概念,**指个人对自己能否成功完成特定任务的信念**。它不是"我能做什么"的整体自我评价(self-esteem),而是**任务领域特定**的能力信念。是当代心理学、教育、组织、健康行为研究中**预测力最强**的心理变量之一。

## 核心要点

### 与相关概念的区别

| 概念 | 含义 | 例子 |
|---|---|---|
| **自我效能** | 对完成特定任务的信念 | "我能学会编程" |
| **自尊** | 对整体自我价值的评价 | "我是个不错的人" |
| **自信** | 对一般能力的信心 | "我比较聪明" |
| **乐观** | 对未来积极结果的期待 | "事情会好起来" |
| **控制感** | 对结果可控的信念 | "通过努力可以改变" |

自我效能是**最具体、最可干预**的概念,有清晰的应用路径。

### 自我效能的四大来源

| 来源 | 说明 | 强度 |
|---|---|---|
| **掌握经验**(Mastery Experiences) | 自己亲身的成功经历 | **最强** |
| **替代经验**(Vicarious Experiences) | 看类似的他人成功 | 中等(身份相似越强) |
| **言语劝说**(Verbal Persuasion) | 被信任者鼓励 | 较弱(但能起作用) |
| **生理情绪状态** | 紧张/放松、疲惫/活力 | 解释效应 |

掌握经验最有效,这就是为什么**循序渐进的小成功**比"鸡汤式鼓励"有用得多。

### 自我效能影响的四个过程

1. **认知过程**:制定目标、预测结果、构想路径
2. **动机过程**:决定多努力、多坚持
3. **情绪过程**:压力反应、焦虑水平
4. **选择过程**:选择什么任务、避开什么

低自我效能者可能避开有挑战但有益的活动,逐渐自我设限。

## 经验研究的发现

### 教育领域

- **学业自我效能**预测学习成绩,独立于实际能力
- 自我效能 → 努力与坚持 → 成绩
- 与**成长心态**(Dweck)有重叠但不同

### 健康行为

- 戒烟、运动、饮食改变成功率与自我效能正相关
- **健康行动过程取向**(HAPA):自我效能 + 计划
- 慢病管理(糖尿病、慢阻肺)中关键预测因子

### 工作绩效

- 任务自我效能预测绩效
- 团队效能(集体自我效能)预测团队产出
- 详见 [[组织行为学]]、 [[激励理论]]

### 临床

- 抑郁、焦虑、PTSD 患者自我效能普遍低
- 治疗(尤其 [[认知行为疗法]])显著提升效能
- 暴露疗法的成功机制部分是效能提升

### 创业与领导

- **创业自我效能**预测启动新业务可能性
- 领导自我效能预测领导行为
- 详见 [[领导力]]、 [[变革型领导]]

## 提升自我效能的实践

### 任务分解

- 把大任务拆成可控小步骤
- 每完成一步都创造**掌握经验**
- "**两分钟法则**":先做最简单版

### 模仿与导师

- 看到与自己相似的人成功
- "**他能我也能**"
- 这是导师制、励志故事的科学基础

### 情绪管理

- 区分"焦虑"与"无能"
- 重新解读紧张为"准备好"而非"我不行"

### 即时反馈

- 在小成功后立即标记
- 与 [[操作性条件反射]] 的塑造原理相承

### 建立支持性环境

- 减少"打击者",增加鼓励
- 心理安全的团队(Edmondson)

## 集体自我效能

- 团队对**集体能完成共同目标**的信念
- 预测团队绩效、组织变革成功
- 是 [[组织文化]] 的关键维度
- 影响 [[变革型领导]] 的有效性

## 自我效能与其他理论

### vs [[习得性无助]]

- 完全相反的两极
- 习得性无助:重复失败 → "我无能"
- 自我效能:重复掌握 → "我能"

### vs 内在动机

- 自我效能不等同**内在动机**(详见 [[内在驱动力]])
- 但二者高度相关:能做才会想做

### vs 韧性

- 自我效能是韧性的核心成分
- 有效能感更易在挫折后再起

### 与 [[积极心理学]]

- PERMA 之 A(Accomplishment)直接基于自我效能
- 详见 [[积极心理学]]、 [[塞利格曼]]

## 在数字时代的延伸

### 用户自我效能

- 用户使用产品/技术的信念
- UX 设计要培养用户效能
- "新手友好""有清晰反馈"

### AI 时代

- 人对 AI 工具的效能感
- 是否相信"我能用好这个 AI"决定使用程度
- 详见 [[人工智能]]

### 在线学习

- MOOC 完课率与学员自我效能正相关
- 自适应学习设计(详见 [[斯金纳]] 教学机思想)

## 局限与批评

- **过度乐观**:自我效能过高可能导致冒险
- **文化差异**:东亚文化中"谦虚"可能压低自报效能,但实际表现良好
- **测量挑战**:任务特异性高,通用量表难

## 和其他概念的关系

- 创始人:[[班杜拉]]
- 与 [[习得性无助]]、 [[塞利格曼]] 是反向极
- 与 [[认知行为疗法]]、 [[认知失调]]、 [[防御机制]] 在临床应用上相关
- 与 [[积极心理学]]、PERMA、 [[内在驱动力]] 紧密交织
- 与 [[激励理论]]、 [[组织行为学]]、 [[领导力]]、 [[变革型领导]] 直接相关
- 与 [[斯金纳]] 操作条件反射形成"内在信念 vs 外在强化"对话
- 与 [[依恋理论]]、 [[共情]] 在早期形成中相关
- 与 [[过度自信]] 是其极端版(自我效能过高)
- 与 [[认知偏差]] 中"邓宁—克鲁格效应"形成"低能 vs 自评高"的扭曲案例
- 与 [[消费者行为]]、 [[转化漏斗]]、 [[病毒系数K]] 中用户自信使用相关
- 与 [[创业]]、 [[商业模式创新]] 中创业者效能感
- 与 [[第一性原理]] 之"我能从头思考"信念有关
- 与 [[儒家]] "为仁由己"、 [[禅宗]] "本来面目"在精神上有相通之处
