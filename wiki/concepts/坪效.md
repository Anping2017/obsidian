# 坪效

## 定义

**坪效**(Sales per Square Meter,SPSM)是实体零售业评估单位营业面积经营效率的核心指标。源自日本零售业,"坪"是日本面积单位(1 坪 ≈ 3.3 平米),传入中国后用于便利店、超市、手机店、奶茶店、餐饮等线下业态。

公式:

```
坪效 = 营业额 / 营业面积
```

更精细的版本:

```
毛利坪效 = 毛利 / 营业面积
日均坪效 = 日均营业额 / 营业面积
```

它与 [[人效]]、[[到店转化率]] 共同构成实体零售的"三效"诊断框架。

## 核心要点

### 1. 不同业态的坪效基准(中国)

| 业态 | 优秀坪效(月,元/㎡) | 备注 |
|---|---|---|
| **手机店(品牌专卖)** | 5,000-15,000 | 客单价高、占地小 |
| **手机店(综合卖场)** | 3,000-8,000 | 多品牌 SKU 多 |
| **便利店** | 5,000-12,000 | 711 全家约 8,000 |
| **大型超市** | 1,500-4,000 | 客单低坪大 |
| **奶茶店** | 50,000-200,000 | 极高,因占地极小 |
| **快餐(肯德基)** | 30,000-60,000 | |
| **服饰品牌(中端)** | 3,000-8,000 | |
| **奢侈品店** | 10,000-30,000 | |

### 2. 坪效的影响因素

#### a) 选址(Location)
- 客流量
- 客流质量(目标客群匹配)
- 可见度
- 进店便利性
- 竞争密度

#### b) 商圈与定位匹配
高消费商圈 + 高客单业态 = 坪效爆发
低消费商圈 + 高客单业态 = 坪效灾难

#### c) 陈列与品类组合
- 黄金陈列位放高利润商品
- 引流款 + 利润款 + 形象款的金字塔
- 关联陈列提升连带率

#### d) 客单价
高客单价同时不影响进店量是坪效提升关键。手机店可加配件、保修、二手回收等提升客单。

#### e) 转化率
[[到店转化率]] 直接影响每坪产出。

#### f) 营业时间
24 小时便利店 vs 8 小时专卖店,营业时长差 3 倍。

### 3. 坪效提升路径

```
坪效 = 客流 × 转化率 × 客单价 × 频次
       ÷ 营业面积
```

各因子优化方向:

| 因子 | 提升手段 |
|---|---|
| **客流** | 选址、外摆、团购、微信引流 |
| **转化率** | 销售话术、陈列、试用、价格 |
| **客单价** | 加配件、套餐、套购优惠 |
| **频次** | 会员、私域、复购券 |
| **面积** | 减少非销售空间(库房、休息区) |

### 4. 坪效 vs 毛利坪效

营业额坪效高不等于赚钱多——可能毛利低。手机销售毛利 8-15%,但配件毛利 40-60%。优化重点应是 **毛利坪效**:

```
毛利坪效 = (销售额 × 毛利率)/ 面积
```

加配件、保险、二手回收能大幅提升毛利坪效。

### 5. 季节性与坪效

实体零售坪效有季节性:
- 手机店:9 月新机发布、双 11、春节高峰
- 便利店:夏季饮品高峰
- 服饰:换季高峰

年化平均坪效更准,单月数据需结合周期解读。

### 6. 坪效与租金合理性

经验法则:**月租金不应超过月销售额的 8-12%**(餐饮)、**6-10%**(零售)、**4-7%**(超市)。

```
租金健康度 = 月租金 / 月营业额
```

如租金占比 > 15%,要么提升坪效要么换地址。

## 实战诊断

#### 坪效低的常见原因

1. **选址错位**:商圈消费力 vs 业态客单不匹配
2. **陈列效率低**:大量空置或低周转 SKU 占位
3. **客单价低**:仅卖手机不卖配件
4. **转化率差**:销售技能、价格、信任问题
5. **面积过大**:扩张时多租了不必要空间

#### 坪效提升典型案例(框架)

- 减少库房占店面:库存集中存放 + 高频补货
- 增加体验区(可触摸所有手机)提升转化
- 加入二手回收柜台,占地小、毛利高
- 加入维修区,既增加客单又提升复购
- 数字屏代替实体陈列,显示更多商品

## 常见误区

### 误区 1:"坪效越高越好"
极致坪效可能牺牲体验(挤、乱),反损长期复购。

### 误区 2:"扩大面积会摊薄坪效"
若新增面积带来连带销售上升,可能反而提升毛利坪效。

### 误区 3:"坪效是唯一指标"
[[人效]] 与坪效共看才完整,只看坪效可能忽视人力成本。

### 误区 4:"坪效不能跨业态比较"
正确——便利店 8000 元/㎡ 与奶茶店 80000 元/㎡ 不可直接比。

## 数字化坪效

线上电商也有"线上坪效"的对应概念:

- **首页坪效**:首页位置 / GMV
- **流量坪效**:每访客 GMV
- **直播坪效**:直播间停留时长 / GMV

这是 [[直播营销]]、[[电商SEO]] 的延伸思考。
