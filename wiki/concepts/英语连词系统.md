# 英语连词系统

## 定义

连词(Conjunction)是连接词、短语或分句的虚词,本身不充当句子成分,但承担逻辑关系编码的核心功能。英语长难句的解读和创作能力,本质上就是对连词系统的掌握程度。

英语连词分三大类:
1. **并列连词**(coordinating)— 连接平等成分
2. **从属连词**(subordinating)— 引导从句依附主句
3. **复合(关联)连词**(correlative)— 成对出现

## 并列连词(Coordinating)

七大并列连词记忆口诀 **FANBOYS**:**F**or, **A**nd, **N**or, **B**ut, **O**r, **Y**et, **S**o

详见 [[英语并列句]]。

## 从属连词(Subordinating)

引导从句,使从句成为主句的一部分,按从句性质分:

**引导名词性从句**

- that(陈述)、whether/if(是否)、who、whom、which、what、when、where、why、how

**引导定语从句**

- 关系代词:that、which、who、whom、whose
- 关系副词:when、where、why
- 详见 [[英语关系代词与关系副词]]

**引导状语从句**(按语义)

| 状语类型 | 主要从属连词 |
|---|---|
| 时间 | when, while, as, since, until, before, after, as soon as, by the time, once, every time |
| 地点 | where, wherever |
| 原因 | because, since, as, now that, seeing that |
| 目的 | so that, in order that, lest, for fear that |
| 结果 | so...that, such...that, so that |
| 条件 | if, unless, provided (that), as long as, in case, suppose |
| 让步 | although, though, even if, even though, while, as, no matter how |
| 比较 | as...as, than, as if, as though |
| 方式 | as, as if, the way |

## 复合(关联)连词(Correlative)

成对出现,引导平行结构:

- both A and B
- either A or B
- neither A nor B
- not only A but also B
- whether A or B
- not A but B
- as A as B
- so A as B
- so/as...that
- such...that
- the more...the more

**关键规则:平行原则(parallelism)**

A 和 B 必须是同类语法成分(都是名词/都是从句/都是短语):
- 错:*She is **both** clever **and** loves reading.*
- 对:*She is **both** clever **and** diligent.*

**主谓一致规则**

- both A and B:谓语用复数
- either/neither A or/nor B:谓语就近一致(*Neither he nor I am wrong*)
- not only A but also B:谓语就近一致

## 连词与连接副词的区别

连接副词(however、therefore、moreover 等)虽然语义上像连词,但语法地位是副词,不能直接连接两个分句:

- 错:*I came, however he left.*
- 对:*I came; however, he left.*
- 对:*I came. However, he left.*

详见 [[英语并列句]]。

## 连词的高级用法

**让步从句的强化**

- much as I love you...(尽管我爱你)
- try as he might...(无论他怎么努力)
- 以 as 引导的让步从句要部分倒装

**条件让步混合**

- whether...or not(无论是否)
- no matter how/what/where/when(无论如何/什么/何处/何时)

**时间从句的精细差异**

- when:点状或段状时间均可
- while:强调时间段内进行
- as:强调"随着……同时……"
- since:从过去某点至今
- until:直到某时间为止

## 高频陷阱

- because vs since vs as:都表"因为",但 because 最强且回答 why,since/as 表已知原因
- though、although、even though 与 but:中文"虽然但是"是双连词,英文只能选一个
- if 表"如果"也表"是否";后者多在宾语从句中,通常用 whether 更安全
- for 作连词表"因为"罕见且书面化,日常英语用 because
- so that 表目的(后接 can/may/will)、so...that 表结果——一字之差功能不同
