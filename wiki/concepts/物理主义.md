# 物理主义

## 定义

**物理主义**(Physicalism),又称广义唯物主义,是一种 [[形而上学]] 立场,主张**一切存在物归根结底是物理的**——物理世界是唯一的实在,所有心理、社会、生命现象在某种意义上都依赖于、可还原为或随附于物理事实。它是 20 世纪以来心灵哲学与科学哲学的主流立场之一。

## 核心要点

### 主要变体

- **类型同一论**:每种心理状态类型 = 某种神经状态类型(如疼痛 = C 纤维激活)
- **个例同一论**:每个具体心理事件 = 某个具体物理事件,但不要求类型对应
- **功能主义**:心理状态是功能角色,物理实现可多重(硅基大脑也能"思考")
- **取消唯物论**:常识心理学概念是过时民间理论,应被神经科学替代
- **非还原物理主义**:心理事实"随附"(supervene)于物理事实,但概念上不可还原
- **物理主义的因果闭合**:物理领域中每个物理事件有充分物理原因

### 主要论证

- **科学统一**:物理学解释力日益扩展,心理学神经科学化趋势明显
- **因果闭合 + 因果效力**:若心理事件不是物理的,如何对身体起作用?
- **奥卡姆剃刀**:不必要的实体不应增设——除物质外何必再设"灵魂"

### 主要挑战

- **意识的硬问题**(查默斯):物理事实能否完全解释主观体验?
- **玛丽的房间**(杰克逊):了解所有关于颜色物理学的玛丽,首次见到红色时是否学到新东西?
- **僵尸论证**:能想象一个物理上一样但无意识的"哲学僵尸"吗?
- **知识论证**:第一人称知识似乎不可由第三人称物理描述穷尽

### 当代讨论

- 与功能主义、非还原物理主义、属性二元论等持续争论
- 与神经科学、AI 进展深度互动:LLM 是否"理解"等问题映射出物理主义的张力

## 和其他概念的关系

- 与 [[二元论]] 是心灵哲学的主要对立立场
- 与 [[决定论]] 在因果论上常并行(但不必然绑定)
- 是 [[科学方法]] 的形而上学背景假设之一
- [[意识]] 的硬问题是其至今最大挑战
- 与 [[形而上学]] 中的因果性、随附性等核心概念紧密相连
