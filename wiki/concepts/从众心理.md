# 从众心理

## 定义

**从众**(Conformity)是个体在**真实或想象的群体压力**下,**调整自己的判断、信念或行为**以符合群体的心理倾向。是 [[社会心理学]] 三大经典主题之一(与 [[米尔格拉姆服从实验|服从]]、 [[斯坦福监狱实验|角色化]] 并列)。从众与"羊群效应"在金融、营销、传播学中应用广泛。

## 经典实验

### 阿希线段实验(Solomon Asch,1951)

- 实验员给 7-9 人小组看两张图:基准线段 + 三条比较线
- 任务:说出哪条线与基准等长(正确答案明显)
- 8 人是同伙,故意答错
- 一名"真受试"在最后回答

#### 结果

- **75% 的真受试在至少一次试验中跟从错误答案**
- 平均跟从率约 **37%**(考虑所有试验)
- 如果有一个同伙说真话,跟从率显著降低
- 强调:这是简单感知任务,答案明显——但仍跟从

### 影响因素

| 因素 | 提高从众 | 降低从众 |
|---|---|---|
| 群体规模 | 3-5 人达到峰值 | 超过 5 人收益递减 |
| 群体一致性 | 全部一致 | **一个不同声音**就大幅降 |
| 任务难度 | 任务越难越从众 | 简单清晰则从众减少 |
| 公开性 | 公开回答 | 私下匿名 |
| 个人地位 | 低地位/新人 | 专家/权威 |
| 文化 | 集体主义文化 | 个人主义文化 |

## 两大机制

### 信息性影响(Informational Influence)

- "**别人都这么说,大概对**"
- 在不确定情境下用别人的判断作信息
- **真心改变信念**
- 例:股市跟风、科学共识接受

### 规范性影响(Normative Influence)

- "**我不想被群体排斥**"
- 知道自己对,但**口头**跟随
- 不真改变信念,只表面顺从
- 例:同辈压力、不敢提反对意见

## 表面顺从 vs 内在转变

| 类型 | 含义 | 例子 |
|---|---|---|
| **顺从**(Compliance) | 公开同意,私下不同意 | 会议上点头,实际不接受 |
| **认同**(Identification) | 因喜欢群体而接受其规范 | 加入团队后采纳团队风格 |
| **内化**(Internalization) | 真心相信,长期改变 | 接受科学共识 |

## 现实场景

### 群体决策

- **群体思维**(Groupthink,Janis):为维护一致性放弃批判
- 经典案例:猪湾入侵决策、挑战者号灾难
- 防范:**魔鬼代言人**、匿名投票、外部审查

### 金融市场

- **羊群效应**:大家买/卖,跟随
- 详见 [[羊群效应]]、 [[行为金融学]]
- 是泡沫与崩盘的心理引擎

### 营销与社会证明

- "**100 万人在用**" → 从众触发
- 评分、销量、好评数
- 详见 [[消费者行为]]、 [[营销心理学]]、 [[社会心理学]]
- 罗伯特·西奥迪尼《影响力》六大武器之一

### 社交媒体

- 点赞、转发数显示"群体行为"
- 信息瀑布(information cascade)放大初始偏见
- 算法推荐强化:"**像你的人都看这个**"
- 详见 [[羊群效应]]

### 政治

- 沉默螺旋(Spiral of Silence):少数派沉默,主流声音放大
- 民意调查、新闻报道塑造"主流"

### 工作场所

- 不敢提反对意见 → 决策被同温层统治
- 心理安全(Edmondson)是反从众设计
- 详见 [[组织文化]]、 [[领导力]]

## 反从众与少数派影响

- **少数派也能影响多数**(莫斯科维奇)
- 条件:**坚定、一致、有原则**
- 而不是表面妥协
- 历史案例:伽利略、马丁·路德、女性平权
- 现代企业内部异见者的关键作用

## 文化差异

- **个人主义文化**(美国、北欧):较低从众
- **集体主义文化**(东亚、拉美):较高从众
- 但当代研究复杂化了这一二分:
  - 集体主义并非"无条件从众",有复杂层级、情境依赖
  - 个人主义中也有强烈群体压力(政治极化)

## 神经基础

- 不与群体一致时**前扣带回**(冲突监测)激活
- 跟从带来**腹侧纹状体**(奖赏)激活
- 大脑硬连线偏好"与群体一致"
- 这是进化遗产:群体生存依赖

## 应用与建议

### 决策时

- 区分**事实**与**意见**:多人相同**意见**不增加证据
- 寻找异见者
- 匿名投票
- 角色扮演反方

### 设计时

- 利用社会证明:展示用户数、好评(详见 [[营销心理学]])
- 但避免人造"虚假从众"(刷单等)

### 反从众训练

- 心理安全文化([[组织文化]]、 [[领导力]])
- 鼓励"愚蠢问题"
- 高管承认错误的示范

### 个人成长

- 觉察自己的从众倾向
- 在重要决策前**写下**自己的判断,再听别人
- 与 [[第一性原理]]、 [[逆向思维]] 思维方法相承

## 和其他概念的关系

- 是 [[社会心理学]] 核心议题
- 与 [[米尔格拉姆服从实验]]、 [[斯坦福监狱实验]] 并称三大社会心理学经典
- 与 [[羊群效应]]、 [[行为金融学]]、 [[行为经济学]] 直接相关
- 与 [[认知偏差]]、 [[确认偏差]]、 [[可得性启发]] 在群体认知扭曲上互通
- 与 [[消费者行为]]、 [[营销心理学]]、 [[社群营销]]、 [[社交媒体营销]]、 [[KOL营销]] 中社会证明应用相关
- 与 [[内在驱动力]]、 [[责任]]、 [[自由意志]] 形成对话
- 与 [[班杜拉]] 观察学习不同(从众强调压力,观察是认知)
- 与 [[认知失调]] 在"我跟从了为什么"事后合理化中相关
- 与 [[领导力]]、 [[组织文化]]、 [[团队动力学]] 中"群体决策"相关
- 与 [[第一性原理]]、 [[逆向思维]] 反思维方法对照
- 与 [[儒家]] "和而不同"、 [[道家]] "独立不改"形成跨文化对话
- 与 [[人工智能]] 推荐算法的从众强化机制相关
