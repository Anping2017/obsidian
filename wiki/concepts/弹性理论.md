# 弹性理论

## 定义

**弹性(Elasticity)**:因变量变化率与自变量变化率的比值,衡量变量间的相对敏感程度。其无量纲特性使不同商品、不同变量间的反应强度可直接比较。

通用公式:

```
E = (ΔY/Y) / (ΔX/X) = (dY/dX) × (X/Y)
```

## 核心要点

### 需求价格弹性 Ed

**Ed = (ΔQ/Q) / (ΔP/P)**,衡量需求量对自身价格变化的反应度。

| 弹性 | 类型 | 典型商品 |
|---|---|---|
| Ed > 1 | 富有弹性 | 奢侈品、可选商品 |
| Ed = 1 | 单位弹性 | 特定中间商品 |
| Ed < 1 | 缺乏弹性 | 必需品 |
| Ed = 0 | 完全无弹性 | 救命药、刚需 |
| Ed = ∞ | 完全弹性 | 完全竞争个体需求 |

**影响因素**:替代品多寡、必需品/奢侈品属性、收入占比、时间(长期更富有弹性)。

### 需求收入弹性 Ei

**Ei = (ΔQ/Q) / (ΔI/I)**,据此区分商品类型:

- Ei > 1:奢侈品(收入↑则需求大幅↑)
- 0 < Ei < 1:必需品(正常商品)
- Ei < 0:劣等商品(吉芬商品的必要条件之一)

恩格尔系数(食品支出占比)是 Ei 的经典应用 —— 收入越高,食品占比越低,反映生活水平。

### 需求交叉弹性 Exy

**Exy = (ΔQx/Qx) / (ΔPy/Py)**,识别商品间关系:

- Exy > 0:替代品(咖啡与茶)
- Exy < 0:互补品(汽车与汽油)
- Exy ≈ 0:无关

### 供给价格弹性 Es

**Es = (ΔQ/Q) / (ΔP/P)**,影响因素:生产周期(短则弹性大)、技术、要素流动性、库存能力、时间维度。农产品短期 Es 极小是其价格剧烈波动的根源。

### 弹性与定价(关键应用)

由 MR = P(1 − 1/|Ed|),可得:

| Ed 状态 | 涨价对总收入 | 降价对总收入 |
|---|---|---|
| 富有弹性 | ↓ | ↑ |
| 缺乏弹性 | ↑ | ↓ |
| 单位弹性 | 不变 | 不变 |

这是 [[垄断市场]]、[[相对估值法]] 等定价决策的理论基石。

### 弹性与税收负担

税收实际由消费者与生产者分担,**弹性较小的一方承担更大税负**。例如对香烟征税(消费者无弹性)主要由消费者承担;对劳动征税在劳动供给弹性低时由工人承担。无谓损失的大小也取决于双方弹性 —— 弹性越大,无谓损失越大。

## 和其他概念的关系

弹性把 [[供给与需求]] 从定性比较推进到定量分析,是理解 [[市场均衡]] 比较静态、[[消费者剩余与生产者剩余]] 变化、税收福利效果的桥梁。

[[市场结构]] 中的不同形态对应不同的需求弹性面对方式:[[完全竞争市场]] 中企业面临完全弹性需求,[[垄断市场]] 中面临整个市场需求曲线(有限弹性)。

跨域:[[资本结构理论]] 中股价对资本结构变化的敏感性、[[期权定价]] 中 Greeks(Delta、Vega 等)、[[绩效评估]] 中投资组合对市场风险的 Beta —— 都是弹性思想在金融领域的具体化。[[蒙特卡洛模拟]] 与 [[回归分析]] 是弹性参数估计的常用方法。

宏观弹性概念有 [[菲利普斯曲线]] 的斜率(通胀对失业的弹性)、收入乘数(产出对支出的弹性)等。

跨域到营销层:[[定价策略]] 的撇脂 vs 渗透选择直接由需求价格弹性决定;价格调整、差别定价、捆绑销售的可行性都依赖弹性测度。
