# 助推

## 定义

助推(Nudge)是塞勒(Richard Thaler)与桑斯坦(Cass Sunstein)在 2008 年同名著作中提出的"自由家长制"(Libertarian Paternalism)政策理念:通过设计选择架构(choice architecture)引导人们做出更符合自身长远利益的选择,但不强制、不禁止、不显著改变经济激励。

## 核心要点

### 1. 设计原则(NUDGES)
- **iNcentives**:激励要明显
- **Understand mappings**:让选择后果可理解
- **Defaults**:默认选项要合理
- **Give feedback**:提供反馈
- **Expect error**:容忍错误
- **Structure complex choices**:简化复杂决策

### 2. 主要机制
- **默认选项**:利用现状偏差,把好选项设为默认(器官捐赠"Opt-out")
- **选择架构**:商品摆放、菜单顺序、可比性设计
- **社会规范**:展示他人在做什么(节能账单)
- **承诺机制**:Save More Tomorrow 储蓄计划
- **反馈与提醒**:用电对照、定期短信
- **简化**:减少决策摩擦,默认报税

## 关键贡献者

- [[Richard Thaler]]:塞勒,2017 诺贝尔经济学奖,行为经济学奠基人之一
- Cass Sunstein:法学教授,曾任奥巴马 OIRA 主任
- [[卡尼曼]]:为助推提供 [[损失厌恶]]、[[启发式]] 理论基础
- 英国"行为洞察小组"(BIT)、奥巴马"社会与行为科学小组"(SBST)将助推制度化

## 经典案例

| 领域 | 助推设计 | 效果 |
|---|---|---|
| 退休储蓄 | Save More Tomorrow 自动加薪储蓄 | 储蓄率从 3.5% 升至 13.6% |
| 器官捐赠 | Opt-out 默认 | 同意率 99% vs Opt-in 12% |
| 节能 | 邻居用电对照账单 | 平均省 2% 用电 |
| 健康饮食 | 食堂沙拉摆显眼处 | 沙拉销量 +50% |
| 税务申报 | 预填表格 | 合规率上升 |
| 学生选课 | 简化默认选课表 | 完成率提高 |

## 与其他概念关系

- 是 [[行为经济学]] 最重要应用
- 基于 [[认知偏差]]、[[损失厌恶]]、[[启发式]]、[[现状偏差]]
- 与 [[认知失调]] 设计干预呼应
- 区别于传统经济学的 [[激励理论]]:不改变激励
- 在 [[营销心理学]] 与 [[CRO]] 转化率优化中广泛应用
- 与 [[精准营销]] 个性化助推结合

## 批评与边界

- 操纵 vs 自由选择的伦理张力
- 短期改善 vs 长期理性培养
- 谁来决定"更好"?(家长制问题)
- 助推效应可能衰减,部分研究无法重复
- 富人/受教育者更易绕过助推
- "Sludge"反向助推增加摩擦

## 政策影响

- 全球 200+ 国家设立"助推单元"
- 英国 BIT 已扩展为咨询公司
- 中国:健康码默认设计、绿色出行助推
- 数字时代:推荐算法是"算法助推",边界模糊
- 与 [[GDPR]] 默认隐私设置相结合
