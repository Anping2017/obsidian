# Odoo Subscription

## 定义

**Odoo Subscription** 是 Odoo 内置的**订阅业务管理模块**,处理周期性收费的全生命周期:订阅创建、自动开账单、信用卡自动扣款、客户自助升降级、续约 / 取消、按比例(prorate)计费、终止结算。它生成 MRR(月度经常性收入)/ ARR(年度经常性收入)仪表盘,服务 SaaS、会员制、租赁、设备即服务等模式。

## 核心要点

**订阅生命周期**

1. **创建**:从销售订单转化或手工创建,选定订阅模板(每月 / 每年 / 自定义)
2. **首次发票**:确认时立即出第一张发票,扣首期款
3. **周期性账单**:Cron 按时(每月 / 每年)自动生成发票
4. **自动扣款**:绑定支付方式后通过支付网关(Stripe、Adyen)自动扣
5. **续约提醒**:到期前 N 天通知客户
6. **暂停 / 恢复 / 取消**:支持中途状态变更
7. **结算**:终止时按比例退款或扣末期

**订阅模板**

定义周期、价格、产品、折扣、合约期、自动续约规则、终止条款。每模板可配置:
- **计费频率**:月、季、年、自定义
- **付款条款**:预付 / 后付
- **试用期**:免费 N 天
- **最低承诺期**:不可中途取消的月数
- **自动延期**:到期自动续 1 年
- **取消通知期**:提前 30 天通知

**关键计费场景**

1. **按比例计费(Prorate)**:月中升级,补差价 = (新价-旧价) × 剩余天数 ÷ 月天数
2. **升降级**:Upsell(更贵套餐)/ Downsell(降级)
3. **附加产品(Add-on)**:核心订阅 + 按需附加
4. **使用量计费(Usage-Based)**:按 API 调用次数、流量、存储计费

**MRR / ARR 仪表盘**

订阅模块自动统计:
- **MRR**:当前月度经常性收入
- **ARR**:年度经常性收入(MRR × 12)
- **新增 MRR**:新客户带来
- **扩展 MRR**:升级带来
- **流失 MRR**:取消带来(Churn)
- **净收入留存**:扩展 + 续约 - 流失

这些是 SaaS 业务的核心指标。

**客户自助门户**

每个订阅客户有专属 portal:
- 查看订阅详情、当前周期
- 升级 / 降级 / 取消
- 下载历史发票
- 更新支付方式
- 自助续约 / 暂停

**与销售流程的关系**

报价单可包含订阅产品,确认后自动转为订阅;销售员仍能在传统销售流程中工作,订阅模块在背后接管周期性逻辑。

**集成支付网关**

- Stripe、Adyen、PayPal、Authorize.net
- 自动扣款失败重试机制(3 次后挂起订阅)
- Dunning(催收):失败后发送提醒邮件、最终暂停服务

## 与其他概念的关系

Odoo Subscription 是 [[订阅商业模式]] 在 ERP 层的实现,与 [[Odoo电商模块]] 配合处理 SaaS / 会员产品销售。计费引擎接 [[Odoo电子发票]],客户自助门户基于 [[Odoo视图体系]] 的 Portal 模式。

## 高频陷阱

- Cron 没启用 → 订阅永远不会自动续费
- 时区错位:UTC vs 公司时区导致首次开账单延迟一天
- prorate 公式各国有差异,本地化需校准
- 试用期到期未触发首次扣款 → 静默流失
- 订阅取消后历史发票不可删除(法定保留)
