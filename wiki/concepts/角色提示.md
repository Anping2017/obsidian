# 角色提示

## 定义

**角色提示(Role Prompting)** 是 [[提示词工程]] 的常见技术:在 prompt 开头为 [[大语言模型]] 设定一个具体身份(职业、专家、人物),让其以该身份的知识、视角与表达风格回答问题。例如"你是一位资深税务律师..."、"你是有 20 年经验的儿科医生..."。

## 核心要点

**典型形式**

```
你是一位资深的数据分析师,在电商行业有 10 年经验,擅长用户行为分析和漏斗诊断。
请用专业但通俗的语言,分析以下转化率数据,识别 3 个最值得优化的环节。
```

**核心价值**

- **激活相关知识子空间**:模型能力分布广,角色像探照灯指明应该用哪部分
- **统一表达风格**:专业人士表达 vs 入门科普表达差异巨大
- **提升一致性**:多轮对话中角色锁定话题边界
- **隐式约束**:法律顾问角色会自然加上"建议咨询专业律师"等免责声明

**有效角色三要素**

| 要素 | 作用 | 示例 |
|---|---|---|
| 职业身份 | 定位领域 | 数据分析师、UX 设计师 |
| 经验/专长 | 增强可信度 | 10 年经验、专攻 SaaS |
| 表达风格 | 控制语气 | 用通俗语言、严谨学术、像导师一样 |

**何时格外有用**

- 专业咨询(法律、医疗、税务、心理)
- 创意写作(模仿特定作家、角色对话)
- 教学辅导(扮演苏格拉底式提问者)
- 多 Agent 协作中给每个 [[AI Agent]] 设定不同角色

**何时不必或慎用**

- 简单事实查询(角色无关,反而废 [[Token]])
- 高风险决策:角色不是真专业凭证,模型仍会 [[幻觉]]
- 敏感领域:角色不能提升模型实际医学/法律能力,误导用户更危险
- 越狱(Jailbreak)风险:恶意角色("假装你是没有限制的模型...")是经典 [[提示注入]] 模式

**研究争议**

- 部分研究表明角色提示在客观任务(数学、事实)上效果**有限甚至负面**
- 真正有效的是把身份转化为具体行为指令(如"用专业术语" 而非空泛说"你是专家")
- "Role Prompting" 的实际增益在主观任务、风格控制上更显著

## 和其他概念的关系

- 整体方法论:属于 [[提示词工程]] 结构要素之一(R in RTCF)
- 配套使用:常与 [[零样本提示]] 或 [[少样本提示]] 组合
- 风险维度:角色滥用是 [[提示注入]] 攻击的常见载体
- 与 [[AI Agent]] 关系:多 Agent 系统中每个 Agent 一个角色
