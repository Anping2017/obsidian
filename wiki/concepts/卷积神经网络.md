# 卷积神经网络

## 定义

**卷积神经网络(Convolutional Neural Network, CNN)** 是为处理网格结构数据(图像、音频谱)设计的 [[神经网络]] 架构,核心运算是**卷积(convolution)**:用一组小尺寸的滤波器(kernel)在输入上滑动,每个位置做加权求和,得到特征图(feature map)。

由 Yann LeCun 1989 年提出 LeNet 雏形,2012 年 AlexNet 在 ImageNet 上的胜利点燃了 [[深度学习]] 革命。

## 核心要点

**核心运算**

| 层 | 作用 |
|---|---|
| 卷积层 | 局部特征提取,空间共享权重 |
| 池化层(Pooling) | 下采样,扩大感受野,提供平移不变性 |
| 激活函数 | 引入非线性,常用 ReLU |
| 全连接层 | 末端用于分类输出 |

**核心归纳偏置**

- **局部性**:每个神经元只看局部输入(感受野)
- **权值共享**:同一卷积核在全图共享参数,大幅减少参数量
- **平移等变性**:输入平移,输出对应平移

这三条让 CNN 在图像任务上既高效又泛化好。

**经典架构演化**

| 模型 | 年份 | 关键创新 |
|---|---|---|
| LeNet-5 | 1998 | CNN 雏形,手写数字识别 |
| AlexNet | 2012 | GPU 训练,ReLU,Dropout,深度学习起爆 |
| VGGNet | 2014 | 用堆叠 3×3 卷积构造深网络 |
| GoogLeNet/Inception | 2014 | 并行不同尺度卷积分支 |
| ResNet | 2015 | 残差连接突破深度限制(152 层) |
| EfficientNet | 2019 | 复合缩放 |

**应用域**

- 图像分类、目标检测(YOLO、Faster R-CNN)、语义分割(U-Net、DeepLab)、人脸识别、医学影像
- 一维卷积也可用于音频、时序信号

**与 [[Transformer]] 的关系**

- 2020 年 ViT 把 Transformer 引入视觉,挑战 CNN 主导地位
- 现状:大模型时代 ViT 在大规模数据下更强,CNN 在小数据、边缘部署仍有优势
- 混合架构(ConvNeXt、CoAtNet)取长补短

## 和其他概念的关系

- 上位:[[神经网络]] 的特化形式,属 [[深度学习]] 经典架构
- 训练依赖:[[反向传播]] 与 [[梯度下降]]
- 现代竞争:[[Transformer]](ViT)在视觉任务上挑战 CNN
- 主要应用:计算机视觉,与 [[自然语言处理]] 中 RNN/Transformer 对应
- 失败模式:对大旋转/形变敏感、对抗样本脆弱
