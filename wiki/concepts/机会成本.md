# 机会成本

## 定义

**机会成本**(Opportunity Cost)指**为获得某选择而放弃的、其他可行选择中价值最高的那个**。它不出现在会计账本上,但实质决定每个选择的真实代价。它是经济学最核心的概念之一,也是 [[多元思维模型]] 中"经济学维度"的关键模型。

## 核心要点

### 核心公式(概念)

```
真实成本 = 显性成本 + 隐性成本
机会成本 = 放弃的次优选择的价值
```

### 普遍性

- 任何选择都有机会成本,不存在"免费"
- 时间、金钱、关系、注意力 —— 一切有限资源都涉及
- "时间就是金钱"是机会成本的通俗版本

### 常见例子

| 选择 | 显性成本 | 机会成本 |
|---|---|---|
| 大学 4 年 | 学费 + 生活费 | 4 年工资 + 经验 |
| 创业 | 启动资金 | 工资 + 稳定性 + 时间 |
| 持有现金 | 0 | 投资可获得的收益 |
| 持有股票 A | 0 | 持有股票 B 可获得的收益 |
| 看 1 小时电视 | 电费 | 学习/锻炼/陪家人 |

### 隐藏的力量

- 多数人只看显性成本,忽略机会成本 → 长期错配资源
- 巴菲特原则:每个投资决策的机会成本是"我下一个最佳选择" → 持续抬高门槛
- 时间分配:每小时干 A,就放弃了 B —— 选择 = 排他

### 在投资中

- **持有现金的机会成本**:股市长期年化约 8%,持有现金 = 机会成本 8%/年
- **持有低收益股的机会成本**:本可买入更优标的
- **巴菲特的"可比":每次买入 = 不买其他标的;每次保留 = 不卖出换更好标的
- 高质量投资是连续做出"放弃次优"的决策

### 在职业与人生中

- **职业选择**:每个工作意味放弃所有别的工作
- **关系选择**:深度关系需时间,意味着放弃其他可能
- **学习选择**:学一门技能 = 不学其他;尤其需要选**复利大**的方向(参见 [[复利效应]])
- **拒绝的力量**:乔布斯"我为我没做的事一样自豪" —— 拒绝 = 保护机会成本

### 计算的难点

- 次优选择的价值常不可观测(如果没选另一条路)
- 主观因素:学习的"价值"包含意义、成就感
- 实践方法:明确列出 3-5 个备选,量化比较其期望价值

### 与显性成本的张力

- 心理上,显性成本(花了 100 块)比机会成本(没赚 100 块)更刺痛
- 这与 [[损失厌恶]] 相关:实现损失 vs 错失机会的不对称
- 必须刻意训练"机会成本意识"

### 在芒格的应用

- 芒格反复强调:每个投资决策都是与"持有指数"对比 —— 跑不赢就别搞主动
- "把每一次选择都看作放弃其他一切的代价"

## 和其他概念的关系

- 经济学最核心概念之一,也是 [[多元思维模型]] 的关键模型
- 与 [[复利效应]] 协同:错过的复利是巨大隐性损失
- 与 [[能力圈]] 配合:在圈外的"机会"往往机会成本被高估
- 与 [[损失厌恶]] 相关:实现损失刺痛,放弃机会感受弱
- 在 [[投资决策框架]] 中是"是否买入/持有"的核心标尺
- 与 [[资产配置]] 紧密相关 —— 各类资产间的机会成本比较
- 与"沉没成本"区分:沉没已花,机会成本是放弃的未来
- 在 [[第一性原理]] 中是评估选择真实价值的基础
