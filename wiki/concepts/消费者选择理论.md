# 消费者选择理论

## 定义

**消费者选择理论(Consumer Choice Theory)**:研究在给定收入和价格下,消费者如何选择商品组合以使**效用最大化**的理论。它是新古典微观经济学最核心的分析框架,从根本上推导出 [[供给与需求]] 中的需求曲线。

三大要素:
- **预算约束**:能买什么
- **效用函数(无差异曲线)**:想买什么
- **均衡条件**:实际买什么

## 核心要点

### 预算约束

```
Px·X + Py·Y = I
```

预算线:Y = I/Py − (Px/Py)·X

- **截距**:I/Px 与 I/Py(把全部收入花在单一商品上的最大量)
- **斜率**:−Px/Py(机会成本,放弃一单位 Y 可换得的 X)
- **可行集**:预算线下方区域

预算线的变化:
- **收入变化**:平行外移/内移
- **单一商品价格变化**:绕一个截距旋转
- **同比例变化**:可消除货币幻觉

### 效用与无差异曲线

**效用(Utility)**:消费者从商品组合中获得的满足感。**无差异曲线**(indifference curve)连接给消费者带来相同效用的所有组合。其性质:

- 向下倾斜(更多即更优,需取舍)
- 凸向原点(边际替代率递减)
- 不相交、密集分布

**边际替代率(MRS)** = ΔY/ΔX(保持效用不变),递减性是凸偏好的必然结果。

### 消费者均衡

均衡的两种等价表述:

```
MRS = Px/Py  (几何条件:无差异曲线与预算线相切)
MUx/Px = MUy/Py = λ  (边际等量原则:每元钱的边际效用相等)
```

直观含义:把最后一元用在哪种商品上都带来相同边际效用。如果 MUx/Px > MUy/Py,应增加 X;反之增加 Y。

### 价格变化的分解:替代效应与收入效应

**斯卢茨基分解**:总效应 = 替代效应 + 收入效应

- **替代效应**:相对价格变化引起的需求变化(总沿同一无差异曲线变化方向)
- **收入效应**:实际购买力变化引起的需求变化(平行移动方向)

**正常商品**:两效应同向,需求规律必然成立
**劣等商品**:两效应反向,但替代效应通常占优
**吉芬商品**(劣等且收入效应占优):需求曲线向上,违反需求规律

### 收入变化的需求路径

收入消费曲线(Income Expansion Path)与恩格尔曲线刻画收入变化下的最优选择轨迹,据此区分:
- **正常商品**:Ei > 0
- **劣等商品**:Ei < 0
- **奢侈品**:Ei > 1

详见 [[弹性理论]]。

### 扩展:不确定性与跨期选择

**不确定性下选择**:期望效用函数 EU = Σ pi·U(xi),引出风险厌恶/中性/偏好(见 [[风险识别与度量]])。**前景理论**(卡尼曼)挑战其描述充分性,见 [[行为经济学]]。

**跨期选择**:U = U(C1) + δ·U(C2),贴现因子 δ 反映时间偏好。这是 [[投资决策框架]] 与 [[现金流折现模型]] 的微观基础。

## 和其他概念的关系

消费者选择理论是 [[供给与需求]] 的微观基础 —— 个体需求曲线由价格变化下的最优选择轨迹推导而出,加总后得市场需求。

它通过 [[消费者剩余与生产者剩余]] 与福利分析对接,通过 [[弹性理论]] 与定量分析对接。预算约束在 [[国际经济学]] 中扩展为开放经济跨期约束。

[[行为经济学]] 系统挑战其理性、稳定偏好、最优化假设,引入有限理性、参考点、损失厌恶、双曲贴现等修正。[[行为金融学]] 把这些修正应用于金融决策。

跨域:[[投资组合理论]] 中马科维茨的均值-方差选择问题本质是消费者选择理论在风险-收益空间的版本;CAPM 中代表性投资者的最优化与一般均衡定价同源。

跨域到营销层:[[消费者行为]] 引入心理与情境约束,补足理性人模型的盲区;[[用户画像]] 把效用函数的偏好参数实务化为标签维度;[[STP分析]] 的细分本质是按效用函数的差异聚类。
