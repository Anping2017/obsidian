# 模型量化

## 定义

**模型量化**(Model Quantization)指把神经网络权重(weights)与激活值(activations)从**高精度浮点表示**(FP32、FP16、BF16)**压缩到低位宽**(INT8、INT4、INT2 甚至 1bit)的技术。

它通过牺牲少量精度换取**模型体积压缩 4-32 倍、内存带宽节省、推理加速 2-4 倍**,是 [[大语言模型]] 部署到消费级 GPU、边缘设备的核心使能技术。

## 核心要点

### 量化的数学本质

```
浮点值 x → 整数值 q
q = round(x / scale) + zero_point
反量化:x' = (q - zero_point) × scale
```

scale 与 zero_point 是量化参数,决定动态范围与精度。

### 主要类型

#### 按时机

| 类型 | 何时执行 | 优劣 |
|---|---|---|
| **训练后量化**(PTQ, Post-Training Quantization) | 训练完成后量化 | 简单快速,精度损失略大 |
| **量化感知训练**(QAT, Quantization-Aware Training) | 训练时模拟量化误差 | 精度更高,训练成本高 |

实务中 PTQ 是大模型部署主流;QAT 用于精度敏感场景。

#### 按粒度

- **Per-Tensor**:整个张量共享 scale
- **Per-Channel**:每个通道独立 scale
- **Per-Group**:每组通道共享 scale(权衡精度与内存)
- **Per-Token**(动态):激活值按 token 量化

#### 按对称性

- **对称量化**(Symmetric):零点固定为 0,简单高效
- **非对称量化**(Asymmetric):允许偏移零点,动态范围更大

### 主流位宽

| 位宽 | 内存 | 适用 | 例 |
|---|---|---|---|
| FP32 | 4B/参数 | 训练精度 | 早期深度学习 |
| FP16 / BF16 | 2B | 训练 + 推理标准 | 现代 GPU 训练 |
| INT8 | 1B | 推理标准 | NVIDIA Tensor RT |
| INT4 | 0.5B | 大模型部署 | GPTQ、AWQ 量化 LLaMA |
| INT2 / INT1 | 0.25B / 0.125B | 极端压缩 | 特定研究 |

LLaMA-7B 在 FP16 需 14GB 显存,INT4 仅需 4GB,可在消费级 RTX 3060 上运行。

### 关键算法

#### GPTQ(2022)

逐层量化,使用 Hessian 信息最小化量化误差,精度极高。
- 支持 INT4 / INT3 / INT2
- 主流 LLM 量化框架

#### AWQ(2023, MIT)

**Activation-aware Weight Quantization**:基于激活值幅度选择重要权重保护,更高质量。

#### GGUF / GGML(llama.cpp 格式)

把多种量化方案打包,支持 CPU 高效推理(K-quants Q4_K_M、Q5_K_S 等)。

#### Bitsandbytes(8-bit Optimizers)

支持 LLM.int8() 等技术,Transformers 库的事实标准。

#### SmoothQuant

通过激活与权重间的"平滑迁移"使大模型 8 位量化变得可行。

### 难点:大模型量化的特殊挑战

#### 异常值(Outliers)

LLM 的某些激活值数量级远高于均值(可达 1000×),导致量化范围被极少数值"霸占",其他值精度严重下降。

应对:
- LLM.int8() 对异常通道单独 FP16 处理
- SmoothQuant 把异常值"迁移"到权重侧
- AWQ 选择性保护

#### 分组量化

把权重切分为小组(如 128 元素一组),每组独立 scale,显著降低误差。

### 量化对精度的影响

经验法则:
- INT8:精度损失 < 1%
- INT4:精度损失 1-3%(配合 GPTQ/AWQ)
- INT2:精度损失明显,需特定技术(BitNet 1.58bit)

LLM 的某些任务(如代码、数学)对量化更敏感。

### 量化与推理优化

量化常配合其他技术联合优化:
- KV-Cache 量化(降低长上下文内存)
- 与 [[FlashAttention]] 配合
- 与 [[Speculative Decoding]] 配合
- 与 [[Continuous Batching]] 配合

### 极端边界:1.58 bit BitNet(2024)

微软提出每权重仅取 {-1, 0, +1} 三值:
- 模型大小压缩 ~10×
- 矩阵乘可被加法替代
- 在 7B 规模媲美 LLaMA 16-bit

预示未来定制硬件 + 极低位宽的可能。

### 与其他压缩技术的关系

| 技术 | 思路 | 损失 |
|---|---|---|
| 量化 | 降低数值精度 | 小,可控 |
| 蒸馏 | 小模型学大模型行为 | 中,需训练 |
| 剪枝 | 移除不重要参数 | 取决于稀疏率 |
| MoE | 仅激活部分专家 | 小,但调度复杂 |

实务中常**联合使用**:量化 + KV-Cache + Speculative Decoding + Continuous Batching。

## 和其他概念的关系

- 应用对象:[[大语言模型]]、[[Transformer架构|Transformer]]、[[卷积神经网络]]
- 与 [[模型蒸馏]]、模型剪枝构成"模型压缩三件套"
- 与 [[FlashAttention]]、KV-Cache 共同决定推理性能
- 部署场景:边缘 AI、消费级 GPU 推理、API 服务降本
- 影响 [[预训练与微调]] 后的部署阶段
- 与 [[神经网络]] 的浮点运算精度理论密切相关
- [[Anthropic]]、[[OpenAI]] 等内部用 INT8/FP8 优化推理成本
