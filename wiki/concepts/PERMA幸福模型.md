# PERMA 幸福模型

## 定义

PERMA 由 [[塞利格曼]](Martin Seligman)2011 年《Flourish》提出,是 [[积极心理学]] 第二阶段的核心理论框架。它替代塞利格曼早期"真实的幸福"(Authentic Happiness)三要素,把"繁盛"(flourishing)分解为五个可独立测量的元素:

| 字母 | 元素 | 定义 |
|---|---|---|
| **P** | Positive Emotion(积极情绪) | 喜悦、感激、安宁、希望 |
| **E** | Engagement(投入) | 心流体验,深度参与 |
| **R** | Relationships(关系) | 积极、支持性的关系 |
| **M** | Meaning(意义) | 服务于超越自我之目标 |
| **A** | Accomplishment(成就) | 追求并达成目标 |

每元素需满足三个条件:本身有内在价值、不仅作为达成其他元素的工具、可独立测量。

## 历史背景

| 年 | 事件 |
|---|---|
| 1998 | 塞利格曼任 APA 主席,创立积极心理学 |
| 2002 | 《真实的幸福》三要素:愉悦、投入、意义 |
| 2011 | 《Flourish》提出 PERMA |
| 2014 | PERMA-Profiler 量表发布 |
| 2017 | PERMA-H(加 Health 健康)扩展 |

## 五元素详解

### 1. Positive Emotion(积极情绪)
- 早期"愉悦"被扩展为多元情绪
- Barbara Fredrickson 扩建—构建理论(Broaden-and-Build)
- 积极情绪扩展认知与行为,构建持久资源
- 包括:喜悦、感激、宁静、兴趣、希望、自豪、好奇、灵感、敬畏、爱

### 2. Engagement(投入)
- 即 [[心流]] 体验
- 用 [[性格优势]] 做擅长之事
- 关键是技能—挑战平衡

### 3. Relationships(关系)
- 哈佛 80 年成人发展研究:关系是幸福第一预测因子
- 积极心理资本中"积极性"维度
- 包括家庭、友谊、社区
- 哈佛研究主任 Robert Waldinger:"高质量关系是良药"

### 4. Meaning(意义)
- 维克多·弗兰克尔《活出生命的意义》先驱
- 为超越自我之事服务(家庭、宗教、艺术、政治、科学)
- 与 [[意义疗法]] 紧密结合

### 5. Accomplishment(成就)
- 不只是为别的目标而设
- 内在追求成就感本身
- 与 [[自我决定论]] 胜任需求重叠

## 测量工具

### PERMA-Profiler
- 23 题(每元素 3 题 + 健康、孤独、整体幸福等)
- 11 点 Likert 量表
- 已被翻译 30+ 语言
- 用于研究、诊所、组织

### 与 SWB 的区别
- SWB(主观幸福感):快乐 + 生活满意度
- PERMA:更多元、更"人本"
- 二者高相关但 PERMA 提供更具体干预靶点

## 干预措施

### 经验证的"积极心理干预"(PPI)
1. **三件好事**(Three Good Things):每晚记录三件好事 → 增加 P
2. **使用标志性优势**:用 [[性格优势]] 做新事 → 增加 E
3. **感恩拜访**(Gratitude Visit):写信致谢并面读 → 增加 R
4. **意义日志**:记录有意义时刻 → 增加 M
5. **目标可视化与追求**:设定短期成就 → 增加 A

元分析显示 PPI 显著提升 well-being,降低抑郁,效果持续数月以上。

## 与其他概念关系

- 替代早期"快乐主义"或"伊壁鸠鲁式"幸福观
- 整合 [[亚里士多德]] eudaimonia 与情感愉悦
- 包含 [[心流]](E)、[[自我决定论]](隐含)、[[性格优势]](E、M)
- 与 [[积极心理学]]、[[人本主义心理学]] 一脉相承
- 与 [[阿马蒂亚·森]]/[[努斯鲍姆]] 可行能力相通
- 与 [[自我效能]] 在 A(成就)中体现
- 应用于 [[组织文化]]、 [[领导力发展]]
- [[赫兹伯格双因素理论]] 工作满意度的当代继承
- 与 [[商业伦理]] 利益相关者繁盛对话

## 批判与边界

- 五要素是否真独立?统计上常重叠
- 文化适用性:东亚集体主义中"关系"权重不同
- 缺少"健康"维度(后加 H 但未广泛采纳)
- 缺少环境/经济条件考虑
- 自评偏差:社会期望影响
- "幸福追求"本身可能消极(高目标导致焦虑)

## 现代发展

- PERMA-V(加 Vitality 活力)、PERMA-H(加 Health)、PERMA-LIA(加学习、影响、对齐)等扩展
- 与神经科学融合(默认模式网络 ↔ 意义)
- 数字 wellbeing 应用(Calm、Headspace 应用 PERMA 思路)
- 国家政策:多国 GDP 之外的幸福指标
