# 计算机视觉 Computer Vision

## 定义

计算机视觉(Computer Vision, CV)是 [[人工智能]] 的子领域,研究**让机器从数字图像或视频中提取、理解、推断信息**的理论与技术。它的目标是赋予机器与人类相当(或超过)的视觉感知与理解能力。

CV 的核心问题:从 2D 像素阵列恢复 3D 世界结构、识别物体类别、推断行为意图、生成新图像。

## 核心要点

### 经典任务

| 任务 | 描述 | 代表模型 |
|---|---|---|
| 图像分类 | 整图打类别标签 | AlexNet、ResNet、ViT |
| 目标检测 | 定位 + 分类 | YOLO、Faster R-CNN、DETR |
| 语义分割 | 像素级类别 | FCN、U-Net、DeepLab |
| 实例分割 | 像素级类别 + 实例 | Mask R-CNN |
| 关键点检测 | 人体姿态、人脸特征点 | OpenPose、HRNet |
| 图像生成 | 文本→图像 | Stable Diffusion、DALL-E、Imagen |
| 视频理解 | 动作识别、视频问答 | I3D、TimeSformer |
| 3D 重建 | 多视图→点云/Mesh | NeRF、SfM |
| OCR | 图像→文字 | Tesseract、PaddleOCR、Apple Vision |

### 历史演进

1. **手工特征时代(1960s-2010)**:Canny 边缘、SIFT/SURF 特征、HOG、词袋模型 + SVM
2. **深度学习突破(2012-2017)**:AlexNet 在 ImageNet 上 dropout 错误率,CNN 横扫;ResNet 让网络深度突破 100 层;FCN/U-Net 使分割端到端
3. **目标检测两派融合(2014-2020)**:两阶段(R-CNN 系)与单阶段(YOLO、SSD、RetinaNet),Anchor-free(CornerNet、CenterNet)
4. **Transformer 入侵(2020-)**:ViT 把 [[Transformer]] 引入图像,DETR 用 Transformer 做检测,Swin Transformer 兼顾效率
5. **多模态时代(2021-)**:CLIP 把图文映射到统一空间;Stable Diffusion 让文本生成图像走向大众;GPT-4V、Gemini、Claude 把视觉作为 LLM 的输入模态
6. **世界模型与具身智能(2023-)**:Sora、Genie 等视频生成模型,目标是建模物理世界

### 核心技术砖块

- **卷积神经网络([[CNN卷积神经网络]])**:局部感受野、权值共享、平移等变性
- **数据增强**:翻转、裁剪、色彩抖动、Mixup、CutMix
- **预训练 + 微调**:在 ImageNet/COCO 大数据预训练,下游任务微调
- **Self-Supervised Learning**:对比学习、MAE 图像掩码预训练
- **NeRF**:神经辐射场,新视角合成
- **Diffusion Models**:扩散模型,主导生成式 CV

## 和其他概念的关系

CV 与 [[自然语言处理]] 是 [[人工智能]] 的两大经典方向,二者通过 [[Transformer]]、[[多模态学习]]、CLIP 类对齐技术深度融合,催生了 [[GPT-4V]]、Sora 等多模态大模型。

应用层:[[Face ID]]、[[相机系统]]、[[自动驾驶]]、医学影像、零售客流分析、安防、AR/VR、游戏、内容审核都依赖 CV。

[[端侧AI]] 与 [[神经网络引擎]] 让 CV 模型在手机本地运行;[[Siri与Apple Intelligence|Apple Intelligence]]、Live Text、Visual Look Up 是手机 CV 的代表功能。

CV 与 [[机器人]]、[[强化学习]] 结合形成具身智能(Embodied AI),让 AI 能感知并行动于物理世界。
