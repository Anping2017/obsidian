# 户外背包

## 定义

户外背包(Backpack)是把户外装备**安全分散**到人体上的承载装置。区别于普通日用包,户外背包通过**腰带、肩带、胸带、背长系统**把负重的 70% 转移到髋部骨骼,30% 由肩膀承担,实现长时间舒适背负。容量、结构、承重系统、面料是选购四要素。

## 核心要点

**容量分级**

| 容量 | 用途 | 典型负重 |
|---|---|---|
| 10-25 L | 日间徒步 / 攀岩 | 3-7 kg |
| 25-40 L | 1 天 / 周末两日 | 5-12 kg |
| 40-65 L | 多日徒步过夜 | 10-20 kg |
| 65-85 L | 远征 / 重装备 | 18-30 kg |
| 85 L+ | 超远征 / 装备员 | 25-40 kg |

容量选择不能只看天数,还看气候(雪地装备占体积)和分担(团队装备如帐 / 食物可分摊)。

**结构形式**

1. **内框(Internal Frame)**:框架在面料内部,贴身、稳定、主流
2. **外框(External Frame)**:金属框露在外,通风好但稳定差,已少见
3. **无框(Frameless)**:UL 路线极简化,背 < 8 kg 才舒适

**承重系统四要素**

1. **腰带(Hip Belt)**:承担 70% 重量,必须扣在髋骨上方而非腰部
2. **肩带(Shoulder Strap)**:承担 30%,弧形包覆肩部
3. **胸带(Sternum Strap)**:稳定肩带不外滑
4. **背长(Torso Length)**:从颈椎 C7 到髂骨上沿的距离,必须匹配
5. **稳定带(Load Lifter)**:肩带顶部往后拉,把重心拉近背
6. **可调背长**:中高端背包提供 2-3 档调节

**背长测量**

- **测量起点**:颈椎 C7(低头时凸出最明显的椎骨)
- **测量终点**:髂骨上沿(髋骨上端)
- **数据范围**:女性 38-48 cm、男性 45-55 cm
- **错配后果**:腰带不在髋骨上 → 全部重量压肩 → 肩颈酸痛

**面料**

- **Cordura(高级)**:500D-1000D,耐磨抗撕,主流高端
- **Robic(创新)**:类似 Cordura 但更轻
- **Dyneema (DCF)**:超轻 + 防水 + 防撕,UL 玩家专用,贵
- **Ripstop Nylon**:经济、轻量化、稍弱
- **PU 涂层**:增加防水

**主流品牌**

- **Osprey(美国)**:Aether / Atmos 系列,百搭舒适
- **Gregory(美国)**:Baltoro / Deva,贴身度极佳
- **Deuter(德国)**:Aircontact 系列,通风好
- **Arc'teryx(加拿大)**:Bora / Beta,冷峻设计 + 顶级面料,贵
- **Black Diamond**:Speed 系列偏轻量
- **Hyperlite Mountain Gear(HMG)**:DCF 超轻量化先锋
- **MysteryRanch**:军用风格,扎实重型

**装包原则**

1. **重物贴背 + 中部**:重心稳定
2. **轻物在底 + 顶**:睡袋在底、衣物在顶
3. **常用品在外侧 / 顶口**:雨披 / 食物方便取
4. **长物垂直 / 平放**:不戳出
5. **重心不左右偏**:行走平衡
6. **水袋管 / 水瓶在侧袋**:不解包就能喝

**测试与试背**

- 装入实际重量(不是空包试)
- 走 10 分钟,关注:肩部痛?腰部痛?歪?
- 上下楼梯测试动态稳定
- 30 分钟后再问自己"还想穿吗?"

## 高频陷阱

- 被"50L 看起来够用"的容量数字误导,实际装上发现差 10L
- 不试背就网购 → 背长错配,长徒步酸到崩溃
- 腰带没扣对位置(扣在腰而非髂骨)→ 失去承重作用
- 雨罩仅防雨,泡水仍会进 → 内胆防水袋(Dry Bag)更可靠
- 雪地里冰镐 / 冰爪外挂位需提前规划
