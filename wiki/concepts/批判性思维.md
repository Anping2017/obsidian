# 批判性思维

## 定义

**批判性思维**(Critical Thinking)是对**信息、观点、论证进行理性分析、评估和反思**的思维方式。它不是凡事质疑或对立,而是要求**有根据地相信、有理由地拒绝、有方法地修正**。它是哲学训练的核心成果,也是 [[芒格]] 多元思维模型的关键工具之一。

## 核心要点

### 五项核心能力

| 能力 | 内涵 |
|---|---|
| **分析** | 拆解复杂论证,识别前提、假设、结论 |
| **评估** | 判断信息可靠性、论证有效性 |
| **推理** | 应用 [[逻辑]] 进行演绎、归纳、类比 |
| **反思** | 监控自己的思维过程,识别偏见 |
| **论证表达** | 清晰构建支持自己观点的论证 |

### 五项关键品格

- **质疑精神**:对一切默认主张主动追问"凭什么"
- **客观态度**:努力悬置个人立场和情感
- **开放胸襟**:愿意接受相反证据
- **理智谦逊**:承认自己可能错
- **思维独立**:不轻信权威或多数意见

### 思维过程的四步法

1. **问题识别**:辨清要回答的核心问题(避免被次要问题带偏)
2. **信息收集**:多源、对立观点都看
3. **论证评估**:前提是否真?推理是否有效?有无隐藏假设?
4. **结论与修正**:得出暂定结论,准备根据新证据修正

### 与认知偏差的对抗

批判性思维是 [[认知偏差]] 的解药:
- 应对 [[确认偏差]]:主动找反证
- 应对 [[锚定效应]]:独立估算后再看锚
- 应对 [[可得性启发]]:寻找统计数据而非生动例子
- 应对 [[羊群效应]]:在群体一致时反向多看

### 应用领域

- **投资**:多角度分析财报与商业模式,识破故事性偏差
- **决策**:列出反方意见(红队思维)
- **学习**:不机械接受权威,主动检验主张
- **媒介素养**:辨别新闻真伪、立场偏向

### 警告:批判 ≠ 否定

- 批判性思维要求"基于证据的暂定相信",不是预设否定
- 怀疑论的极端形式会瘫痪行动
- 健康的批判保留可错性,同时给出最佳判断

## 和其他概念的关系

- 批判性思维以 [[逻辑]] 为工具,同时关照 [[认知偏差]] 与 [[确认偏差]]
- 与 [[辩证法]] 共享"考虑反面"的思维倾向
- 与 [[逆向思维]] 互补:逆向是策略,批判是态度
- 是 [[芒格]] 多元思维模型 中"思维清单"必备项
- 应用于 [[第一性原理]] 推理 —— 怀疑既有结论、回到根基
- 与 [[科学方法]] 的可证伪精神同源
- 与 [[苏格拉底]] 问答法直接承接
