# 新柏拉图主义

## 定义

新柏拉图主义(Neoplatonism)是 3 世纪由普罗提诺(Plotinus, 204-270)在罗马创立的哲学—神秘主义传统,系统化重述柏拉图哲学,加入毕达哥拉斯、亚里士多德、斯多葛元素,形成一个统一的形而上学体系。它是古希腊哲学的最后伟大综合,深刻影响中世纪基督教、伊斯兰哲学、犹太卡巴拉、文艺复兴。

## 历史背景

### 与柏拉图的关系
- 普罗提诺自认是柏拉图忠实诠释者
- "新"是后世(19 世纪)所加,以区别于古典柏拉图
- 实际包含大量原创发展

### 历史阶段

| 阶段 | 时期 | 代表 |
|---|---|---|
| **早期**(罗马) | 250-330 | 普罗提诺、波菲利、扬布里柯 |
| **叙利亚学派** | 330-450 | 普罗克鲁斯前 |
| **雅典学派** | 410-529 | 普罗克鲁斯、达玛斯基乌斯 |
| **亚历山大学派** | 350-642 | 希帕蒂娅、希尔潘库斯 |
| 529 | 查士丁尼关闭雅典哲学院 | 古典哲学终结 |

## 核心形而上学

### 三个本体层次(流溢说)

普罗提诺《九章集》(Enneads):

1. **太一**(τὸ Ἕν, The One)
   - 超越一切存在与思想
   - 不可言说、不可思议
   - 万物源头
   - 完美超越善

2. **理智**(Νοῦς, Nous)
   - 太一第一次流溢
   - 同时是思想者与思想内容
   - 包含柏拉图所有理念
   - 永恒、统一、多

3. **灵魂**(Ψυχή, Psyche)
   - 理智第二次流溢
   - 世界灵魂 + 个体灵魂
   - 时间、运动、自然
   - 中介者

### 流溢(Emanation)概念
- 不是创造(creatio ex nihilo)
- 也不是溢出导致减损
- 类比:太阳发光不减
- 万物由太一向下层层流溢
- 上升回归是哲学/灵性目标

### 物质
- 流溢的最低端
- 既非"恶",也非"实体"
- 是缺乏

### 邪恶
- 不是实体,是缺乏善
- 与基督教传统兼容(奥古斯丁吸收)

## 灵魂学说

### 灵魂的三阶段
1. 灵魂从理智流出
2. 与肉体结合,沉沦
3. 通过哲学/神秘体验回归

### 上升路径
- **净化**(Catharsis):伦理生活
- **理智的升华**:沉思理念
- **神秘合一**:与太一合一
- 普罗提诺自述四次达到

## 主要代表人物

### 1. 普罗提诺(Plotinus, 204-270)
- 在埃及亚历山大跟随阿摩尼乌斯·萨卡斯学习
- 后到罗马办学
- 学生波菲利编辑其著作为《九章集》
- 影响奥古斯丁(自言读后"激发哲学")

### 2. 波菲利(Porphyry, 233-309)
- 普罗提诺学生
- 整理《九章集》
- 《亚里士多德范畴论引论》(Isagoge)统治中世纪逻辑
- 反基督教《反基督徒论》后被禁

### 3. 扬布里柯(Iamblichus, 245-325)
- 叙利亚学派
- 把神秘主义、 theurgia 仪式引入
- 与早期基督教竞争

### 4. 普罗克鲁斯(Proclus, 412-485)
- 雅典学派最后大家
- 《神学要素》系统化新柏拉图体系
- 《柏拉图神学》
- 影响伪狄奥尼修斯、托马斯·阿奎那

### 5. 希帕蒂娅(Hypatia, 355-415)
- 亚历山大学派,女性哲学家
- 数学家、天文学家
- 415 年被基督徒暴民杀害,标志古典哲学衰落

### 6. 伪狄奥尼修斯(Pseudo-Dionysius, 5-6 世纪)
- 假托使徒保罗弟子,实为新柏拉图主义者
- 把新柏拉图传入基督教神秘主义
- 《神圣等级制》《神秘神学》
- 否定神学(via negativa)

## 影响

### 1. 基督教神学
- [[奥古斯丁]]:三位一体、原罪、神光照
- 伪狄奥尼修斯
- 中世纪神秘主义(埃克哈特、库萨的尼古拉斯)
- 东正教光明神学

### 2. 伊斯兰哲学
- 法拉比、阿维森纳:亚里士多德 + 新柏拉图
- 伊本·阿拉比苏菲神秘主义
- "亚里士多德神学"实际为新柏拉图文本

### 3. 犹太哲学
- 卡巴拉(Kabbalah)
- 哈斯卡拉(Haskalah)启蒙
- Maimonides 部分整合

### 4. 文艺复兴
- 费奇诺翻译柏拉图与普罗提诺
- 米兰多拉
- 翡冷翠柏拉图学院

### 5. 早期现代
- 剑桥柏拉图学派(More、Cudworth)
- [[斯宾诺莎]] 实体一元论部分相通
- [[黑格尔]] 绝对精神有共鸣

### 6. 当代
- 神秘主义研究
- 比较宗教
- 哲学神学复兴

## 与其他传统对比

| 传统 | 共同 | 差异 |
|---|---|---|
| 印度吠檀多 | 一元论、流溢 | 业、轮回 |
| 中国道家 | 道生一二三 | 无神秘合一目标 |
| 佛教大乘 | 空性、流出 | 否定永恒实体 |
| 苏菲主义 | 神秘合一 | 一神教 |
| 卡巴拉 | 流溢、十球 | 创造神 |

## 与其他概念关系

- 是 [[西方哲学史脉络]] 关键桥梁(古典—中世纪)
- 与 [[柏拉图]] 理念论的演化
- 与 [[亚里士多德]] 形质论部分整合
- 影响 [[奥古斯丁]] 全部哲学
- 影响 [[经院哲学]] 神学体系
- 与 [[伊壁鸠鲁主义]]、[[斯多葛主义]] 同为希腊化遗产但路径迥异
- 与 [[佛家]]、[[禅宗]] 神秘合一传统跨文化对话
- [[宗教哲学]] 否定神学、神秘体验研究
- 在 [[现象学]] 之前的西方哲学,是另一种"回到事物本身"的尝试
