# 战略思维

## 定义

**战略思维(Strategic Thinking)** 指看清复杂局势、识别关键、做出长远决策、平衡当下与未来的高阶认知能力。它是优秀领导者最核心的差异化能力之一,与战术思维(执行问题)相对。

明茨伯格(Mintzberg)区分:**战略规划(Strategic Planning)** 是系统化分析、 **战略思维(Strategic Thinking)** 是综合洞察——前者把已知打包,后者发现未知。

## 核心要点

### 战略思维五要素(Liedtka)

Jeanne Liedtka 在《Strategic Thinking》中识别五大特征:

| 要素 | 内涵 |
|---|---|
| **系统视角(Systems Perspective)** | 看到整体而非碎片,价值链/生态系统视角 |
| **意图导向(Intent-Driven)** | 锁定长期目标,容忍短期挫折 |
| **明智机会主义(Intelligent Opportunism)** | 既有计划也敏锐捕捉机会 |
| **时间维度(Thinking in Time)** | 把过去-现在-未来联通,不孤立看当下 |
| **假设驱动(Hypothesis-Driven)** | 先假设后验证,而非穷举分析 |

### 战略思维 vs 战术思维

| 维度 | 战略思维 | 战术思维 |
|---|---|---|
| 视野 | 长期(3-10 年) | 短期(月-季) |
| 范围 | 全局/外部 | 局部/内部 |
| 不确定性 | 高 | 低 |
| 重点 | 做对的事 | 把事做对 |
| 工具 | 框架、模型、第一性原理 | 流程、SOP、KPI |
| 价值 | 选择 | 执行 |

### 培养战略思维的关键习惯

| 习惯 | 实践 |
|---|---|
| **跳出当下** | 阅读历史/未来学/异领域 |
| **系统化提问** | 5 Whys、第一性原理、反向思考 |
| **多元视角** | 不同行业、不同利益相关者视角 |
| **场景规划** | 多种未来场景的推演 |
| **写作思考** | 把模糊想法写成清晰文字 |
| **战略对话** | 与高人切磋,不闭门造车 |

### 第一性原理思维(First Principles)

回到不可分解的基本真相:

- **传统思维**:类比/经验,"别人都这么做"
- **第一性原理**:质疑前提,从基本物理/经济/人性规律推导

例:Elon Musk 算电池成本时不接受"电池就是这么贵",而是把电池拆解为锂、镍、钴等原材料的市场价 → 发现可降至现状的 1/10。

### 战略思维的常见陷阱

- **过度自信**:被过去成功蒙蔽
- **类比偏差**:用旧案例套新情境
- **可得性启发**:被显眼信息主导
- **沉没成本**:不愿放弃已投入
- **群体思维**:回避不同声音
- **短期主义**:股东压力下放弃长远

(均与 [[卡尼曼]] 系统 1/系统 2 决策研究相通)

### 战略反思工具

- **SWOT 自我检测**:对自己的认知盲点
- **预先验尸(Premortem)**:假设方案失败,反推原因
- **红队蓝队(Red Team)**:正反两方对辩
- **战略复盘**:定期对战略假设的验证
- **写战略备忘录**:把思路凝固成文字

### 战略思维的"行动悖论"

行动主义文化(尤其美国)鼓励"快速决断",但战略需要"慢思考"。优秀领导者能在两者间切换:

- 不重要事:快速决断
- 战略级:刻意慢下来
- "战略静默"(Strategic Pause):周期性退一步

## 和其他概念的关系

- 是 [[战略管理]] 的认知基础,与战略规划工具互补
- 是 [[管理者角色]] 中"决策角色"的高阶体现
- 与 [[管理决策]] 直接相关,需对抗多种认知偏差
- 战略思维差距决定 [[战略转型]] 与 [[战略制定]] 质量
- 与 [[亨利·明茨伯格]] 的"涌现战略"思想呼应——好战略不止于规划
- 通过 [[领导力发展]] 项目可被刻意训练
- 与心理学的双系统理论(快与慢思考)、批判性思维交叉
- 与第一性原理思维体现 [[管理决策]] 的认知重构
- [[组织学习]] 中的双环学习是战略思维的微观基础
- 与查理·芒格的"多元思维模型"高度相通
