# 管理理论发展史

## 定义

**管理理论发展史** 描述从 19 世纪末工业化兴起至今,管理思想随时代变迁而演化的脉络。每代管理理论都是对当时主要组织挑战的回应,也都不可避免地携带时代局限。

理解发展史的价值不在于"哪个对哪个错"——这是逻辑陷阱;而在于**看清每代理论解决的问题,以及在新情境中如何取舍**。

## 核心要点

### 五大主要阶段

| 阶段 | 时间 | 主要思想 | 代表人物 |
|---|---|---|---|
| **科学管理** | 1880s-1920s | 标准化、流水线、效率 | Taylor、Fayol、Ford |
| **行为科学** | 1920s-1960s | 人际关系、动机、需求 | Mayo、Maslow、Herzberg、McGregor |
| **管理学体系化** | 1950s-1980s | 系统论、决策、战略 | Drucker、Porter、Ansoff、Simon |
| **质量与精益** | 1950s-1990s | 全面质量、持续改善 | Deming、Ohno、Hammer |
| **现代/网络化** | 1990s-至今 | 学习型、平台、生态、敏捷 | Senge、Christensen、Hamel、Ries |

### 阶段一:科学管理(1880-1920)

**背景**:工业化大生产兴起,工厂规模空前。

| 人物 | 贡献 |
|---|---|
| **Frederick Taylor** | 时间-动作研究、标准化工序、《科学管理原理》(1911) |
| **Henri Fayol** | 14 项管理原则,首次提炼计划-组织-指挥-协调-控制五大管理职能 |
| **Henry Ford** | 流水线生产,T 型车、5 美元工资制 |
| **Max Weber** | 官僚组织(Bureaucracy)的理性化分析 |

**思想核心**:把管理变成一门科学,通过标准化和分工提升效率。

**局限**:把人当机器零件;忽视心理与社会维度。

### 阶段二:行为科学(1920-1960)

**背景**:工人不满、罢工频发,纯效率思维到达边界。

| 人物 | 贡献 |
|---|---|
| **Elton Mayo** | 霍桑实验,发现"被关注"提升效率 → 人际关系学派 |
| **Abraham Maslow** | 需求层次理论:生理→安全→社交→尊重→自我实现 |
| **Frederick Herzberg** | 双因素理论:卫生因素(防不满) + 激励因素(增满意) |
| **Douglas McGregor** | X 理论(人天生懒) vs Y 理论(人天生主动) |
| **Kurt Lewin** | 群体动力学、变革三步(解冻-改变-冻结) |

**思想核心**:人不是机器,要看心理、群体、文化维度。

### 阶段三:管理学体系化(1950-1980)

**背景**:管理学成为学科,商学院兴起。

| 人物 | 贡献 |
|---|---|
| **彼得·德鲁克** | 《管理实践》(1954)、目标管理、知识工作者、企业本质 |
| **Herbert Simon** | 有限理性、决策科学(图灵奖、诺贝尔经济学奖) |
| **Igor Ansoff** | 战略管理、Ansoff 矩阵 |
| **Henry Mintzberg** | 管理者实际工作研究、十大管理角色 |
| **Michael Porter** | 五力模型、通用战略、价值链 |

**思想核心**:管理是系统的、可学习的、决策导向的学科。

### 阶段四:质量与精益(1950-1990)

**背景**:战后日本崛起冲击美国制造业。

| 人物 | 贡献 |
|---|---|
| **W. Edwards Deming** | PDCA、统计质量、14 点管理法,日本质量教父 |
| **Joseph Juran** | 质量三步:计划-控制-改进 |
| **大野耐一** | 丰田生产方式、JIT、看板 |
| **Genichi Taguchi** | 田口质量工程、稳健设计 |
| **Michael Hammer** | BPR 流程再造 |

**思想核心**:质量与流程是竞争力源泉,持续改进是文化。

### 阶段五:现代/网络化(1990 至今)

**背景**:信息革命、全球化、数字化、平台经济。

| 人物 | 贡献 |
|---|---|
| **Peter Senge** | 学习型组织、五项修炼、系统思考 |
| **Clayton Christensen** | 颠覆式创新、创新者窘境 |
| **Gary Hamel & Prahalad** | 核心竞争力、战略致胜未来 |
| **Eric Ries** | 精益创业、MVP、Pivot |
| **Marc Andreessen / 硅谷思想家** | Product-Market Fit、平台、网络效应 |
| **张瑞敏** | 人单合一、平台型企业 |

**思想核心**:学习能力、创新韧性、平台思维、敏捷应对不确定。

### 跨阶段的贯穿主题

不同阶段之间持续的议题:

| 主题 | 不同阶段表现 |
|---|---|
| **效率 vs 创新** | Taylor 偏效率 → Christensen 偏创新 |
| **个人 vs 组织** | Maslow 关注个人 → Senge 关注组织 |
| **控制 vs 信任** | Weber 官僚 → 平台自治 |
| **本地 vs 全球** | 美国管理学 → 日本式 → 中国本土 |
| **物理 vs 数字** | 工厂 → 信息系统 → 平台生态 |

### 中国管理思想的角色

- 早期参考:儒家、道家、法家、孙子兵法
- 引入西方:1949 后引入苏联,80 年代后引入西方
- 当代输出:海尔人单合一、华为研发体系、阿里组织进化
- 综合趋势:中西融合,东方组织哲学输出

### 学习的方式

不是按时间线"先学旧的"——而是:

1. 理解当前问题
2. 找历史上有类似问题的阶段
3. 学其方法,看其局限
4. 综合迁移到当代
