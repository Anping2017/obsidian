# 借贷记账法

## 定义

**借贷记账法**(Double-Entry Bookkeeping)是以**借**(Debit)和**贷**(Credit)作为记账方向符号的复式记账方法,要求每笔经济交易至少在两个账户中以相等金额、方向相反地登记。它是 14 世纪意大利商人 Pacioli 在《算术、几何、比及比例概要》(1494)中首次系统化的会计制度,被誉为"商业文明的奠基石"。

它通过"有借必有贷,借贷必相等"自动维护 [[会计等式]] 的平衡,是现代财务会计的根本机制。

## 核心要点

### 借贷的方向规则

| 类别 | 借方(增加/减少) | 贷方 |
|---|---|---|
| 资产 | 增加 | 减少 |
| 负债 | 减少 | 增加 |
| 所有者权益 | 减少 | 增加 |
| 收入 | 减少 | 增加 |
| 费用 | 增加 | 减少 |
| 利得 | 减少 | 增加 |
| 损失 | 增加 | 减少 |

记忆口诀:
- "资产费用借增贷减"(增加在借方)
- "负债权益收入贷增借减"(增加在贷方)

### 借贷的本质并非"加减"

很多初学者把"借"等同于增加,"贷"等同于减少——错误。

借和贷只是**方向标签**,其增减含义取决于账户类别。本质是 Pacioli 把交易拆为两个对称面:
- 资金从哪里来(贷方)→ 借方表现资金到哪里
- 例:借钱买设备:借方"设备"(资产增加)+ 贷方"借款"(负债增加)

### 复式记账的优势

#### 1. 自动验证

每笔交易借贷相等 → 试算表借方合计 = 贷方合计,提供算术准确性的自检。

#### 2. 经济实质双面映射

任何交易至少影响两个账户,反映"原因-结果"或"来源-去向"的对偶。

#### 3. 全面信息

不仅记录现金流,而是反映企业整体财务状况和经营成果。

#### 4. 可审计性

每笔交易可追溯到双方账户,便于复核、审计、错弊查找。

### 会计分录(Journal Entry)

借贷记账法的具体表现形式:

```
6月15日,从美国进口商品支付货款 USD 10,000(汇率 6.50):

借:库存商品          65,000
   贷:银行存款        65,000
```

格式:
- 日期、凭证号、摘要
- 借方账户、金额(顶格)
- 贷方账户、金额(缩进)
- "借"在前,"贷"在后

### 复合分录

涉及多于两个账户的交易:

```
销售商品 100,000,收银行存款 90,000,客户欠 10,000:

借:银行存款           90,000
   应收账款           10,000
   贷:主营业务收入   100,000
```

借方两项,贷方一项,金额仍相等。

### 试算平衡

期末汇总所有账户余额:
- 借方余额合计 = 贷方余额合计
- 借方发生额合计 = 贷方发生额合计

不平衡 → 必有错误,需查找。但平衡 ≠ 完全正确(可能借贷错误同时记录、漏记交易等)。

### 与单式记账的对比

| 维度 | 单式记账 | 借贷记账 |
|---|---|---|
| 形式 | 流水账,主要记现金 | 双面账,反映完整业务 |
| 准确性 | 难发现错误 | 试算平衡自动检查 |
| 信息量 | 现金视角 | 资产、负债、收入、费用全维度 |
| 适用 | 个人、小本生意 | 现代企业 |

### 在 ERP / 会计信息系统中的体现

- 后台仍以借贷记账为基础
- 自动生成分录(凭证)、自动汇总试算表、自动出报表
- 业财一体化:业务凭证(订单、出库单)自动转化为会计分录

### 中国会计制度

中国《会计法》明确规定除农村集体经济组织等少数情形外,**单位会计核算必须采用借贷记账法**。

### 概念延伸

借贷记账思想不止于会计:
- 经济学:资产负债平衡(国民经济核算)
- 计算机:数据库的双向引用与外键
- 哲学:阴阳对偶、辩证法的对立统一思想
