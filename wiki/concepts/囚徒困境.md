# 囚徒困境

## 定义

囚徒困境(Prisoner's Dilemma)由 Albert Tucker 1950 年阐释,用于说明 [[纳什均衡]] 与 [[帕累托最优]] 之间的偏离。两名嫌疑犯被分别审讯,选择"沉默"(合作)或"招供"(背叛):若双方沉默各判 1 年,双方招供各判 5 年,一方招供另一方沉默,招供者无罪、沉默者判 10 年。

## 核心要点

### 1. 收益矩阵
| | 乙沉默 | 乙招供 |
|---|---|---|
| **甲沉默** | (-1, -1) | (-10, 0) |
| **甲招供** | (0, -10) | (-5, -5) |

- 无论对方选什么,招供都是个人最优 → 招供是严格优势策略
- 双方招供 (-5, -5) 是唯一纳什均衡
- 但双方沉默 (-1, -1) 帕累托优于双方招供 → 个体理性导致集体非理性

### 2. 一次博弈与重复博弈
- **一次博弈**:背叛是占优,合作不可能
- **有限重复**:逆向归纳仍预测每期背叛
- **无限重复**:Folk 定理,合作可作为均衡(以惩罚为威胁)
- [[Robert Axelrod]] 计算机锦标赛证明 Tit-for-Tat(以牙还牙)是稳健胜出策略

## 现实应用

| 场景 | 困境表现 |
|---|---|
| 寡头价格战 | 都降价两败俱伤,但不降价就被抢市场 |
| 军备竞赛 | 美苏冷战核扩张 |
| 公共物品供给 | 搭便车,无人贡献 |
| 广告战 | 烟草企业广告对消耗 |
| 渔业捕捞 | 公地悲剧的本质 |
| 团队偷懒 | 集体行动困境 |
| 环境治理 | 全球气候谈判失败 |
| 学术造假 | 论文军备竞赛 |

## 解决路径

- **沟通与协议**:私下协调,但需可信承诺
- **第三方惩罚**:法律、监管、行业规范
- **重复互动**:声誉、未来阴影使合作可行
- **结构改变**:改变收益矩阵(税收、补贴)
- **道德规范**:内化合作偏好([[儒家]] 仁,[[康德]] 绝对命令)
- **机制设计**:[[奥斯特罗姆共有资源]] 的多中心治理

## 与其他概念关系

- 是 [[博弈论]] 教学最经典案例
- 与 [[公共物品]] 供给问题同构
- 与 [[公地悲剧]] 是大规模 N 人版本
- [[行为经济学]] 实验显示真实合作率高于理论预测(20-50%)
- [[互惠原则]] 与道德情感解释偏离纯理性
- 与 [[Lollapalooza效应]] 相反:多重力量负协同
- 影响 [[亚当·斯密]]"看不见的手"的现代理解

## 哲学意涵

- 个体理性 ≠ 集体理性
- 帕累托效率与策略均衡可分离
- 霍布斯"自然状态"的形式化
- 卢梭社会契约的张力
- 集体行动的逻辑(Olson)
