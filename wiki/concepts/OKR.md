# OKR (Objectives and Key Results)

## 定义

OKR(Objectives and Key Results,目标与关键结果)是**一种目标管理框架**,把组织或团队抽象的方向(Objective)拆解为 3-5 个可量化、有挑战的关键结果(Key Results),并定期(通常季度)评估进度。

它由 Andy Grove 在 Intel 发明,John Doerr 1999 年带到 Google,后被 LinkedIn、Twitter、Spotify、字节跳动等众多公司采用。

## 核心要点

### 基本结构

```
Objective(目标):定性描述「想去哪里」
  ├── Key Result 1:可量化指标 1
  ├── Key Result 2:可量化指标 2
  └── Key Result 3:可量化指标 3
```

经典例子:

> **O**:成为该行业最受推荐的产品
> - **KR1**:NPS 从 35 提升到 60
> - **KR2**:月活用户从 100 万增至 300 万
> - **KR3**:客户支持响应时间 < 1 小时(目前 4 小时)

### 关键特征

| 特征 | 解释 |
|---|---|
| 透明 | 全公司可见,横向纵向对齐 |
| 对齐 | 上下级、跨部门 OKR 互相支撑 |
| 有挑战 | Google 风格:60-70% 完成率即「优秀」(stretch goal) |
| 可量化 | KR 必须能数值化,「试图」「努力」无效 |
| 高频复盘 | 月度/双周节奏,而非年度评审 |
| 与考核解耦 | 不直接挂钩薪酬,鼓励大胆设定 |

### OKR vs KPI

| 维度 | OKR | KPI |
|---|---|---|
| 用途 | 推动改变与突破 | 监控持续运营 |
| 时间窗口 | 季度 / 半年 | 月度 / 持续 |
| 完成率期望 | 60-70%(stretch) | 100%(达标) |
| 与薪酬 | 不直接挂钩 | 直接挂钩 |
| 数量 | 3-5 个 KR | 数十个细分指标 |

实践中常 OKR + KPI 并用:KPI 守住基本盘,OKR 推动创新。

### 设定 SMART KR

- **Specific 具体**:指向单一对象
- **Measurable 可衡量**:有数字,有时间窗
- **Aligned/Ambitious 对齐 + 有挑战**
- **Realistic 现实**:并非异想天开
- **Time-bound 限时**

### 常见误用

1. KR 列任务清单(应是结果,不是动作)
2. 太多 KR 失去焦点(> 5 个变 KPI)
3. 与考核硬挂钩(导致 sandbagging,故意降低目标)
4. 仅高层制定,基层不参与
5. 制定后不复盘,变成形式
6. 把 OKR 套用所有团队(运营团队不太适合)

### 节奏与流程

- 季度初:全公司目标 → 部门 → 团队 → 个人,自上而下 + 自下而上对齐
- 双周:check-in,评估进度,调整阻碍
- 季度末:全员复盘,公开总结,启发下季度

## 和其他概念的关系

OKR 是现代 [[绩效管理]] 三大体系之一(另两为 KPI、平衡计分卡),与 [[平衡计分卡]] 都强调战略落地,但 OKR 更敏捷、更适合科技与创业。

[[变革管理]] 与 OKR 协同——OKR 把变革目标可视化、可追踪;[[企业文化]] 决定 OKR 能否成功(透明文化是前提,惩罚失败的文化会扼杀挑战性目标)。

[[团队动力学]] 中,OKR 通过对齐降低协调成本;[[团队建设]] 与 OKR 设定过程本身就是团队对话;[[赫兹伯格双因素理论]] 视角下,OKR 让员工感知「成就」与「自主」激励因素。

[[Google]]、[[字节跳动]]、[[CRM客户关系管理|Salesforce]]、[[Linkedin]] 等以创新为核心的公司大量使用 OKR,而传统制造业、医疗、金融业更多保留 KPI 体系。
