# 福利国家

## 定义

福利国家(Welfare State)指由国家对其公民承担经济与社会福利责任的制度安排。通过税收-转移、强制保险、公共服务三大机制,在市场分配之上提供基本保障与机会平等,把公民从纯粹的市场依赖中"去商品化"(Decommodification)。

## 历史演进

| 阶段 | 代表事件 | 核心理念 |
|---|---|---|
| 19世纪末 | 俾斯麦德国社保 | 工人保险防社会主义 |
| 1942 | 贝弗里奇报告 | 普遍主义、消除五大恶 |
| 战后 | 北欧、英、德建立 | [[凯恩斯主义]] 充分就业 |
| 1970s | 滞胀危机 | 福利国家危机 |
| 1980s | 撒切尔/里根改革 | 收缩、市场化 |
| 1990s | 欧洲社会民主复兴 | 第三条道路、激活国家 |
| 2008-至今 | 紧缩+全球化 | 民粹冲击 |

## Esping-Andersen 三种体制

丹麦学者 Gøsta Esping-Andersen 1990《福利资本主义的三个世界》:

| 体制 | 核心特征 | 代表国家 |
|---|---|---|
| **自由主义** | 残余、市场为主、有限给付 | 美国、英国、加拿大 |
| **保守主义** | 职业等级、家庭中心、转移为主 | 德国、法国、意大利 |
| **社会民主主义** | 普遍主义、慷慨、去商品化 | 瑞典、丹麦、挪威 |

后续学者补充南欧、东亚、东欧等模式。

## 核心制度构成

- **社会保险**:养老、医疗、失业、工伤、生育五险
- **社会救助**:贫困线下兜底
- **公共服务**:免费义务教育、公立医疗、公租房
- **家庭政策**:育儿假、托幼补贴、儿童津贴
- **劳动力市场政策**:积极劳动力(培训) vs 消极(失业金)
- **税收再分配**:累进所得税、财产税

## 哲学基础

- [[罗尔斯]] 正义论:无知之幕选择最大化最差者(差别原则)
- T.H. Marshall 公民权三阶段:民事、政治、社会
- [[阿马蒂亚·森]] 可行能力理论:实质自由要求物质基础
- 北欧路德教会传统、欧陆基督教民主、英国费边社传统
- 与 [[商业伦理]] 中的利益相关者理论呼应

## 经济学论辩

| 支持论点 | 批评论点 |
|---|---|
| 修补 [[市场失灵]] | 高税收抑制工作激励 |
| 自动稳定器熨平周期 | 政府债务积累 |
| 人力资本投资 | 福利依赖、福利陷阱 |
| 政治稳定、社会团结 | 老龄化加速财政压力 |
| 解放女性、缩小不平等 | 全球化下税基侵蚀 |

## 当代挑战

- **老龄化**:养老金赤字
- **全球化**:资本流动 vs 高税
- **就业去标准化**:零工经济、平台劳动
- **移民**:福利与边界张力
- **数字化**:UBI 全民基本收入辩论
- **气候**:绿色福利国家(Just Transition)
- **不平等再上升**:Piketty《21世纪资本论》

## 与其他概念关系

- 与 [[凯恩斯主义]] 同一时代精神
- 与 [[公共选择理论]] 形成对立批评
- [[福利经济学]] 提供规范分析工具
- [[发展经济学]] 讨论中等收入国家如何建立
- 与 [[共享价值]]、[[ESG]] 在企业层面呼应
- 与 [[卫生经济学]] 全民医保设计相关
- 与 [[阿马蒂亚·森]] 可行能力路径深度对话
