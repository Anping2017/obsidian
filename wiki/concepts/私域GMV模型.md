# 私域 GMV 模型

## 定义

私域 GMV 模型(Private Domain GMV Model)是把私域(微信群+企业微信+公众号+视频号+小红书品牌专业号)的销售贡献分解为可拆解、可优化、可对比的五因子公式,是 CMO 与运营团队评估私域投入产出、设定季度目标、找出运营短板的核心工具。本概念是 [[私域流量运营]]、[[群聊运营]]、[[手机店LTV测算]] 在财务建模视角的统一。

## 核心公式

```
私域 GMV = 私域人数 × 触达率 × 转化率 × 客单价 × 复购次数
```

每一项都是独立可优化的杠杆,任何一项 +20%,整体 GMV +20%(乘积属性)。

## 五大因子拆解

### 1. 私域人数(Pool Size)

- 微信好友数 + 企业微信好友数 + 群成员数 + 公众号粉丝数 + 视频号粉丝数 - 去重
- 增长来源:
  - **公域转私域**:广告引流、内容种草后引流
  - **线下转私域**:门店扫码、外卖/订单包卡
  - **存量挖深**:沉睡用户激活
  - **裂变**:邀请好友送优惠
- 健康指标:**私域人数月增长率 ≥ 3%**(扣除流失后)

### 2. 触达率(Reach Rate)

- 私域消息被实际看到的比例
- 微信群:朋友圈/群消息打开率
- 公众号:推文打开率(行业典型 5-15%)
- 企业微信:私聊打开率(50-80%,远高于群)
- 视频号:粉丝看到率(算法决定)
- 提升:
  - 频次控制(不打扰 + 不被屏蔽)
  - 内容质量
  - 个性化推送
  - 多形态(图文 + 短视频 + 直播)

### 3. 转化率(Conversion Rate)

- 触达后下单的比例
- 私域转化率 vs 公域:
  - 公域(信息流广告):0.5-3%
  - 私域(信任型):3-15%(平均 5-8%)
- 提升:
  - 个性化优惠(基于客户标签)
  - 限时紧迫感
  - 简化下单链路
  - 1V1 私聊推荐

### 4. 客单价(AOV)

- 私域客户客单通常高于公域 1.2-2x
- 原因:信任建立后,接受套餐、复合 SKU、高端品
- 提升:
  - [[连带销售]] 训练
  - 套餐设计
  - VIP 阶梯
  - 跨品类推荐

### 5. 复购次数(Repeat)

- 单年复购次数 = 该客户全年下单次数
- 私域客户复购通常是公域客户的 2-3 倍
- 提升:
  - 客户分层运营
  - 节点营销(生日/纪念日)
  - SKU 互补提醒(详见 [[流失预警与召回]])
  - 会员体系激励

## 实例计算(中型品牌)

### 起点(Q1)

| 因子 | 数值 |
|---|---|
| 私域人数 | 10 万 |
| 月触达率 | 15% |
| 转化率 | 4% |
| 客单价 | 200 元 |
| 月复购次数 | 0.3 次 |
| **月私域 GMV** | **3.6 万元** |

### 优化后(Q4)

| 因子 | 数值 | 提升 |
|---|---|---|
| 私域人数 | 13 万 | +30% |
| 月触达率 | 25% | +67% |
| 转化率 | 6% | +50% |
| 客单价 | 250 元 | +25% |
| 月复购次数 | 0.5 次 | +67% |
| **月私域 GMV** | **24.4 万元** | **+577%** |

注意乘积效应:每个因子 50% 提升,整体可达 5-7 倍 GMV。

## 不同业态的因子权重

### 高频快消(零食、咖啡、母婴)

- 复购次数权重最大(年 5-10 次)
- 客单不重要
- 重点:复购次数

### 中频耐用品(美妆、服装、家居)

- 客单 + 复购并重
- 季节性强
- 重点:客单 + 转化率

### 低频高价(手机、家电、家装)

- 客单极重要
- 复购周期长(年 < 1 次)
- 重点:客单 + 私域人数

### 服务类(咨询、培训、医美)

- 客单与转化率并重
- 信任建立周期长
- 重点:转化率 + 客单

## 私域 GMV 模型的应用

### 1. 季度运营目标拆解

- 总目标:Q4 私域 GMV 翻倍
- 拆解到 5 个因子,每个因子目标 +15%
- 团队按因子分工,各负责一项

### 2. 团队 KPI 设计

- 私域人数 → 引流团队
- 触达率 → 内容团队
- 转化率 → 销售/客服团队
- 客单价 → 商品/活动团队
- 复购次数 → 客户运营团队

### 3. 投入产出比

- 每多投 1 元在哪个因子上 ROI 最高?
- 通常顺序:转化率 > 复购 > 触达 > 客单 > 人数
- 但取决于现状,弱项优先补

### 4. 跨品牌对标

- 同行业对手私域 GMV / 私域人数 = ARPU
- 找出自己 ARPU 低的因子

## 常见误区

### 1. 只拼私域人数

- "100 万好友"听起来牛,但触达率 5%、转化 1%、客单 50,GMV 只有 25 万
- 解药:看 ARPU(私域 GMV / 私域人数),而非纯人数

### 2. 触达过频

- 短期 GMV 上涨,但流失率猛增,长期 GMV 下滑
- 解药:每月退订/拒绝率监控

### 3. 客单依赖低价

- 用低价拉转化,客单越来越低
- 解药:VIP 阶梯 + 套餐组合

### 4. 复购全靠促销

- 用户只在促销时买,日常无复购
- 解药:内容运营 + 关系建立

### 5. 不分客户层级运营

- 一刀切发同样内容,VIP 与普通用户体验割裂
- 解药:客户标签 + CDP
