# 爬虫优化 Crawl Optimization

## 定义

爬虫优化(Crawl Optimization,又名 Crawl Budget Optimization)是**让搜索引擎爬虫(Googlebot、Bingbot 等)以最高效率发现、抓取、索引网站重要内容的一系列技术 SEO 工作**。它的目标包括:

- 提高重要页面被发现的概率
- 引导爬虫优先抓取高价值页面
- 减少对低价值/重复页面的抓取消耗
- 避免技术性障碍(超时、错误状态码、阻塞)

## 核心要点

### 抓取预算(Crawl Budget)

Google 等大型搜索引擎对每个站点分配「抓取预算」——单位时间内的抓取次数上限。抓取预算受两个因素决定:

1. **抓取速率限制(Crawl Rate Limit)**:服务器响应速度、错误率
2. **抓取需求(Crawl Demand)**:页面重要性、更新频率、外链数

中小站点抓取预算通常充裕;大型站点(电商、新闻)需精心管理。

### 关键工具与配置

| 工具 | 作用 |
|---|---|
| robots.txt | 告诉爬虫哪些 URL 不应抓取 |
| sitemap.xml | 主动提交 URL 清单 + 优先级 + 更新频率 |
| canonical 标签 | 指定重复内容的标准版本 |
| noindex meta | 允许抓取但不入索引 |
| 301/302 跳转 | 旧 URL 永久/临时迁移 |
| Hreflang | 多语言/区域版本 |
| robots meta(index/follow) | 页面级抓取/索引控制 |

### 内链结构优化

爬虫主要通过内链发现新页面,内链结构决定抓取深度:

- **扁平结构**:任何页面距首页 ≤ 3 次点击,提升抓取效率
- **面包屑**:层级清晰,引导爬虫与用户
- **相关推荐**:文章页底部链接同类内容,增加抓取入口
- **核心页(Hub Pages)**:汇集相关链接,集中权重
- **避免孤岛页面**:无内链指向的页面爬虫难以发现

### 常见浪费抓取预算的问题

- 大量参数化 URL(`?sort=&filter=&page=`)产生无限组合
- 重复内容(打印版、AMP 版未规范化)
- 软 404(返回 200 但内容是错误)
- 长重定向链
- 慢响应(超过 3 秒拖累抓取)
- 无价值低质量页(自动生成、薄内容)

### 监控指标

通过 Google Search Console:

- **抓取统计**:每日抓取页数、字节数、响应时间
- **索引覆盖**:已索引、已发现未索引、已抓取未索引
- **核心 Web 指标**:LCP、INP、CLS 反映服务器健康
- **服务器日志分析**:看 Googlebot 真实行为(深度、频率、状态码)

### 大型站点的进阶手段

- 动态 sitemap 按重要性分组
- 服务端日志监控爬虫行为
- 利用 [[CDN]] 与缓存确保稳定响应
- 使用 robots.txt 屏蔽参数页与无价值目录
- 用 noindex + nofollow 处理过滤器页

## 和其他概念的关系

爬虫优化是 [[技术SEO]] 的核心子集,与 [[页面SEO]](内容质量与关键词)、[[链接建设|外链建设]] 共同构成 SEO 三角。

[[网站结构]] 与 [[URL规范化]] 是爬虫优化的物理基础;[[页面加载速度]]、[[Core Web Vitals]] 既影响用户体验也影响抓取速率。

[[Lighthouse性能审计]]、[[Google Search Console]] 是诊断与监控爬虫问题的主要工具。[[结构化数据]] 帮助爬虫理解页面语义,提升富结果机会。

[[企业级SEO]] 中,大型站点(数百万 URL)的爬虫优化是关键瓶颈——一旦抓取预算被低价值页面消耗,新发布的高价值内容可能数周不被索引。

[[Helpful Content Update]] 等算法更新使得低质量页面被批量删除或 noindex 反而成为爬虫优化的策略——精简优质比堆砌数量更划算。
