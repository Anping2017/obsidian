# 复利效应

## 定义

**复利**(Compound Interest)指**收益再投入本金继续产生新收益**的指数增长机制 —— 用爱因斯坦的话说"世界第八大奇迹"。其数学公式为 A = P(1 + r)^t,关键在 r(收益率) 与 t(时间) 的非线性叠加。它是 [[芒格]] 多元思维模型中数学维度最核心的模型之一。

## 核心要点

### 数学结构

```
终值 = 本金 × (1 + 利率)^时间
```

- **r 的微小差异**经长时间被放大:5% 与 10% 30 年后差 4 倍
- **t 的提前**比 r 增加更具威力:早 10 年开始可弥补利率劣势
- **复利的反面**:复合损失同样指数累积(高佣金、税收、通胀)

### 爱因斯坦的洞察

> "复利是世界第八大奇迹。理解它的人能赚到它,不理解的人会付出它。"

### 在投资中的体现

- **巴菲特**:年化约 20%,60 余年使每美元变约 50,000 倍
- **指数基金**:长期持有市场组合,跨过短期波动获取复利
- **早开始 + 长持有 + 控制费用**是复利三要素
- **罕用的"复利杀手"**:频繁交易、高费率、错误择时

### 在个人成长中的隐喻

- "每天进步 1%,一年后是 37 倍"(1.01^365 ≈ 37.78)
- 习惯、技能、人脉的累积都遵循类似机制
- 最危险的反面:"每天差 1%,一年后只剩 0.03"(0.99^365 ≈ 0.026)

### 在商业中

- **网络效应**:用户规模 → 价值 → 更多用户 → 复利增长(Facebook、微信)
- **规模经济**:成本下降 → 价格优势 → 更多市场份额
- **品牌**:多年信任积累的非线性回报
- **供应链/护城河**:长期投入构成的壁垒

### 复利的关键挑战

| 挑战 | 描述 |
|---|---|
| **耐心** | 早期增长缓慢,人易放弃 |
| **复合损失** | 任何中断都损害指数底基 |
| **回归均值** | 高收益不易长期维持 |
| **黑天鹅** | 一次大亏可能抹平多年积累(资本永久损失) |

### 与其他模型的协同

- **复利 + [[认知偏差]]**:人天生用线性直觉理解非线性,严重低估复利
- **复利 + 习惯**:小步骤每日重复 → 不可逆改变
- **复利 + 关系**:信任是关系的复利
- **复利 + 学习**:跨学科知识互相 reinforce

### 反面警示

- 与复利同样可怕的是"反向复利":债务利息、固定支出膨胀、坏习惯
- 信用卡循环利息常以年化 18-24% 反向复利吞噬持卡人

## 和其他概念的关系

- 是 [[多元思维模型]] 的核心模型之一
- 在金融中应用为 [[现金流折现模型]] 中的折现率与时间价值
- 与 [[投资组合理论]] 中的长期投资理念呼应
- 与 [[能力圈]]、[[逆向思维]] 共同构成 [[芒格]] 的核心方法论
- 在商业上对应"护城河"、"网络效应"
- [[第一性原理]] 角度:复利是数学必然,任何有"再投入"的系统都遵循
- 与 [[心理学]] 中习惯养成、行为再投资关联
- 反面警示与 [[损失厌恶]] 共同提醒"避免大亏"
- [[资产配置]]:复利长期生效要求资产配置抗住短期波动不被打断
- [[资本结构理论]]:留存收益再投资的复利与债务利息的反向复利共同决定企业长期回报
