# 好恶扭曲倾向

## 定义

**好恶扭曲倾向**(Tendency to Distort Due to Liking/Loving or Disliking/Hating)指人在评估事物时,**会因为自己对它的喜欢或讨厌而扭曲判断**。喜欢的会被高估,讨厌的会被低估甚至全盘否定。来源可能是过去的关联、刻板印象、意识形态、基因倾向或亲身经验。

它和 [[巴甫洛夫联想]]、[[激励偏差]] 一道,是芒格在《误判心理学》中重点强调的认知扭曲源。

## 核心机制

### 喜欢侧的扭曲

| 表现 | 描述 |
|---|---|
| **光环效应** | 一个优点扩散到所有领域(明星好看 → 觉得有才) |
| **忽略缺陷** | 选择性失明,把错处归因为"环境" |
| **言听计从** | 喜欢的人说什么都接受 |
| **打包归类** | 喜欢的所有特征都成"优点" |

### 讨厌侧的扭曲

| 表现 | 描述 |
|---|---|
| **恶魔化** | 一个缺点扩散为人格全面否定 |
| **否定优点** | 即便对方做对了也找碴 |
| **拒听道理** | 内容因人废言 |
| **粗略归类** | 错过细节差异,统统贴标签 |

### 进化解释

部落时代区分敌我至关重要,**先打包归类再细究**是节能策略。代价是在复杂现代社会会产生大量误判:政治极化、招聘偏见、产品评估失真。

## 应用场景

- **招聘**:面试官无意识偏爱与自己同校、同地域的候选人
- **投资**:对偶像 CEO 的公司给出过高估值,对厌恶的行业一概不投
- **政治**:同样的政策,出自喜欢党派叫"灵活务实",出自对立党派叫"摇摆软弱"
- **司法**:研究显示陪审团对外貌好感会影响量刑
- **消费**:讨厌某品牌后,该品牌任何新品都被先入为主否定
- **学术争论**:对作者印象决定对论文评分

## 对治方法

1. **匿名评估**:重要决策时屏蔽身份信息(双盲评审、盲选)
2. **强制反向**:列出"喜欢对象的三个真实缺点"和"讨厌对象的三个真实优点"
3. **单点判断**:把整体评价拆成具体维度独立打分
4. **延迟评价**:在情绪高峰之外再下判断
5. **反方红队**:让人专门为你讨厌的对象辩护
6. **意识训练**:遇强烈好恶时停一拍,问"这是事实判断还是情绪判断?"

## 与其他概念的关系

- 与 [[巴甫洛夫联想]] 共享底层机制,前者侧重情绪迁移
- 是 [[确认偏差]] 的情绪燃料 —— 喜欢的就更愿验证
- 与 [[首结论偏差]] 协同:第一印象常基于好恶
- [[基本归因错误]]:讨厌的人的成功被归为运气,失败被归为人品
- [[Lollapalooga效应]] 中的常见组件
- 与 [[公平敏感性]] 共同决定群体冲突烈度
- [[激励偏差]] 与好恶共同形成认知双重扭曲
- [[批判性思维]] 中的对人不对事原则直接对治
