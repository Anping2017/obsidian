# 自由现金流

## 定义

**自由现金流**(Free Cash Flow, FCF)是企业经营活动产生的现金,在扣除维持业务运转所必需的资本支出之后,**真正可自由支配的剩余现金**——可用于偿债、分红、回购或再投资。

它弥补了**会计净利润**(包含非现金费用、应计调整)与**经营现金流**(未扣资本支出)的不足,是巴菲特、芒格等价值投资者评估企业内在价值的核心抓手。

## 核心要点

### 两个核心定义

#### 企业自由现金流(FCFF)

属于全体资本提供者(债权人 + 股东):

```
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 营运资本变动 - 资本支出
     = 经营现金流(税后) - 资本支出
```

#### 股权自由现金流(FCFE)

仅属于股东(扣除债权人现金流):

```
FCFE = 净利润 + 折旧摊销 - 营运资本变动 - 资本支出 + 净借款增加
     = FCFF - 利息(税后)+ 净借款
```

### 简化常见公式

```
FCF ≈ 经营现金流 - 资本支出
    = 经营现金流(CFO)- CapEx
```

实务中"经营现金流减投资活动现金流出"是最常见近似。

### 资本支出区分

- **维持性资本支出**(Maintenance CapEx):维持现有产能与竞争力的最低投入
- **增长性资本支出**(Growth CapEx):扩张产能、新业务的投入

理论上估值用 FCF 应用维持性资本支出,但财报无法直接看到拆分,实务用历史平均或行业基准近似。

### 与净利润的差异

```
净利润                       100
+ 折旧摊销                    30(非现金)
- 应收账款增加               -20(收入但未收现金)
+ 应付账款增加                15(费用但未付现金)
- 存货增加                   -10
= 经营现金流                 115
- 资本支出                  -50
= 自由现金流                  65
```

净利润 100 的公司可能 FCF 仅 65,质量下降原因:营运资本占用增加 + 资本支出。

### FCF 在估值中的应用

[[现金流折现模型]](DCF)的核心输入:

```
企业价值 = Σ FCFF_t / (1+WACC)^t + 终值/(1+WACC)^N
股权价值 = Σ FCFE_t / (1+r_e)^t + 终值/(1+r_e)^N
```

- 用 FCFF 配 WACC([[资本成本]] 加权平均),得企业价值,再扣净债得股权
- 用 FCFE 配 r_e(股权成本),直接得股权价值

### FCF Yield(自由现金流收益率)

```
FCF Yield = FCF / 市值(或企业价值)
```

类似于"现金回报率",高 FCF Yield 公司常被认为价值低估。

### 信号意义

- **正向且增长的 FCF**:健康经营,可分红/回购
- **负 FCF 但战略合理**:大举资本支出布局未来(亚马逊早期)
- **净利润正但 FCF 持续为负**:盈利质量存疑,可能存在收入虚增、应收账款泡沫
- **FCF 持续 > 净利润**:账面利润保守,留存价值丰厚

### 容易被操纵的环节

- 资本支出延后(短期 FCF 上升,长期产能下降)
- 应收账款保理变现(经营现金流虚高)
- 供应商付款拖延(经营现金流虚高,但供应商关系恶化)

故 FCF 也需结合应收账款周转、资本支出/折旧比、营运资本变化趋势综合判断。

### 行业差异

- **轻资产**(SaaS、咨询):FCF ≈ 净利润 + 折旧
- **重资产**(电力、电信、地产):大量 CapEx 长期压制 FCF
- **金融业**:传统 FCF 概念不适用,改用股利现金流模型
