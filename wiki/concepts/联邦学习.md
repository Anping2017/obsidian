# 联邦学习

## 定义

**联邦学习**(Federated Learning,FL)是 Google 于 2016 年提出的**分布式机器学习范式**,核心约束是:

> "数据不出本地,模型(梯度/参数)汇聚训练。"

参与方(手机、医院、银行……)在本地用自己的数据训练模型,只把**模型更新**(梯度或参数差)加密上传到中央服务器,服务器聚合后下发新的全局模型。整个过程**原始数据不离开持有方**,在隐私敏感场景下实现"数据可用不可见"。

联邦学习是隐私计算的三大支柱之一(另两个是安全多方计算 MPC 和可信执行环境 TEE),与差分隐私、同态加密常被组合使用。

## 核心要点

### 标准流程(FedAvg)

```
1. 服务器初始化全局模型 w₀,分发给 N 个客户端
2. 每轮 t:
   a. 服务器选 K 个客户端,下发当前 wₜ
   b. 每个客户端用本地数据训练若干 epoch,得到 wₜᵏ
   c. 客户端上传 wₜᵏ - wₜ (或新参数)到服务器
   d. 服务器加权平均:wₜ₊₁ = Σ (nₖ/n) · wₜᵏ
3. 直到收敛
```

McMahan 等人 2017 年发表的 FedAvg 是行业标杆算法。

### 三种典型形态

| 类型 | 数据分布 | 典型场景 |
|---|---|---|
| **横向联邦**(Horizontal) | 特征相同,样本不同 | 不同手机用户的输入法数据 |
| **纵向联邦**(Vertical) | 样本相同,特征不同 | 银行 + 电商联合建模同一人群信用 |
| **联邦迁移**(Federated Transfer) | 样本和特征都不完全重叠 | 跨域知识迁移 |

### 隐私强化技术

联邦学习本身只是"数据不出本地",但梯度仍可能泄露信息(梯度反推攻击)。需配合:

- **差分隐私(DP)**:梯度上传前加噪声,严格数学界限保证隐私
- **安全聚合(Secure Aggregation)**:服务器只能看到聚合结果,看不到单点
- **同态加密(HE)**:在密文上计算,服务器全程不解密
- **TEE 可信执行环境**:在硬件飞地内做聚合

### 系统挑战

| 维度 | 难点 |
|---|---|
| **统计异构** | 各客户端数据分布差异大(Non-IID),导致模型偏移 |
| **系统异构** | 手机算力、网络带宽、在线时间差别巨大 |
| **通信成本** | 千万级客户端的模型上传,带宽是瓶颈 |
| **掉线容错** | 客户端随时可能离线,需异步聚合 |
| **激励机制** | 商业联邦中,如何分配模型收益给参与方 |

### Cross-Device vs Cross-Silo

- **Cross-Device**:海量(百万级)移动端,每个数据少,Google 输入法 Gboard 是典型
- **Cross-Silo**:少数(几十个)机构,每个数据多,医院联邦、银行联邦属此类

## 典型应用 / 主流模型工具

- **Google Gboard**:输入法下一个词预测,首个大规模商用案例
- **Apple**:Siri 语音模型、Photos 人脸聚类,采用联邦 + DP
- **医疗影像**:NVIDIA Clara、英国 NHS、多家医院联合训练病灶检测模型
- **金融风控**:多家银行联合反洗钱、联合信贷模型(微众银行 FATE)
- **自动驾驶**:车厂之间联合训练感知模型而不共享行车数据
- **开源框架**:TensorFlow Federated、PySyft、FATE、Flower、OpenFL

## 局限与挑战

| 局限 | 描述 |
|---|---|
| **效果折损** | 相比集中训练,Non-IID 下精度通常下降 1-5% |
| **训练效率** | 通信轮次多,收敛比集中训练慢一个数量级 |
| **梯度泄露** | 没有 DP / 安全聚合时,梯度可被反推出训练样本 |
| **后门攻击** | 恶意客户端可上传"中毒"梯度污染全局模型 |
| **监管不确定** | "数据不出域"是否满足 GDPR / 个保法,各国判定不一 |
| **工程复杂度** | 异构客户端 + 加密 + 容错,系统比集中训练复杂数倍 |

## 与其他概念的关系

- 与 [[大语言模型]] 结合衍生出**联邦大模型微调**,在不汇集私域数据的前提下做行业大模型
- 与 [[RAG|检索增强生成]] 协同,实现"知识在本地、模型在云端"的私有 RAG
- 训练对象常是基于 [[Transformer架构]] 的神经网络
- 数据表征仍依赖 [[Embedding]] 与 [[预训练语言模型]] 的通用底座
- 跨模态场景下与 [[多模态学习]] 结合,做跨机构的图文联合建模
- 隐私计算技术栈:差分隐私 / MPC / 同态加密构成生态
