# 场景

## 定义

**场景**(Setting)是**故事展开的舞台**,是塑造并反映人物行动的**物理与时空语境**。它远不只是"事情发生的地方",**它本身是故事的能动参与者**:可以使能或阻碍、揭示或遮蔽、启发或欺骗。**场景不只是故事在哪里发生,而是故事为什么发生**。这是"场景"作为思维模型的最深刻面向:**环境塑造行为**。

## 核心要点

### 场景的多个维度

| 维度 | 内容 |
|---|---|
| **物理** | 地理、建筑、自然环境 |
| **时间** | 时代、季节、日夜 |
| **社会** | 阶层结构、人际网络、行为规范 |
| **文化** | 价值观、信仰、习俗 |
| **历史** | 过去事件留下的影响 |
| **科技** | 工具、媒介、信息环境 |

### 场景定义可能性

| 场景 | 行为可能 |
|---|---|
| 中世纪欧洲 vs 现代东京 | 完全不同的约束与机会 |
| 小村庄 vs 大都市 | 匿名性、关系密度、隐私感都不同 |
| 创业公司 vs 大企业 | 决策速度、风险接受度迥异 |
| 远程工作 vs 办公室 | 时间结构、沟通方式不同 |

**场景设定了"什么是可能的"和"什么是被允许的"边界**。

### 场景与人物的双向作用

> 场景**不是单向作用于人物**,人物也在**与场景互动**——他们驾驭挑战、利用机会、留下印记。

每个故事都是**人物与场景的共生关系**:相互影响、相互改变。

| 角色 | 作用 |
|---|---|
| 场景 → 人物 | 提供约束和机会 |
| 人物 → 场景 | 通过行动塑造与改造环境 |

### 关键洞见:想改变行为,先改变环境

> "**场景是塑造我们命运的沉默力量**。
>
> 我们的所思所行,极大地受环境影响。
>
> 这导出一个有力的结论:**要改变你的行为,改变你的环境。否则它会改变你**。"

这与意志力、习惯设计、行为经济学的研究高度一致:

- 与其反复挣扎控制食欲,不如**不在家放垃圾食品**
- 与其逼自己专注,不如**远离手机**
- 与其自责拖延,不如**进入约束更强的场所**
- 与其期待靠"决心"改变,不如**先改变默认选项**

### 环境的"暗能量"

环境通过多个机制塑造你:

1. **可得性**:身边的东西决定你做什么
2. **社会规范**:周围人怎么做,你也倾向怎么做
3. **暗示与触发**:视觉与听觉触发自动行为
4. **物理摩擦**:做某事的方便程度决定频率
5. **心理框架**:不同空间唤起不同心智状态

**即使你"以为"自己在自由选择,大半是环境替你选**。

### 场景的二阶效应

- 选择居住城市 → 影响交友圈 → 影响价值观 → 影响人生轨迹
- 选择工作公司 → 影响日常思维 → 影响判断习惯
- 选择社交平台 → 影响信息饮食 → 影响世界观

**短期看,环境是物理的;长期看,环境塑造灵魂**。

## 应用场景

- **个人成长**:把"我要更自律"转化为"我要重新设计我的环境"——更高杠杆、更可持续。
- **组织文化**:文化不是 PPT 上的口号,而是**每一个空间细节、流程默认值、可见行为**共同塑造的场景。
- **产品设计**:把用户的使用场景作为核心思考维度——同一功能在通勤、办公、睡前三种场景里需求完全不同。

## 局限与陷阱

- **环境决定论**:走向极端,认为人完全是环境的产物,失去能动性
- **理想环境幻想**:相信"换了环境就好了",但内在问题会跟随
- **忽视过渡期**:场景改变后需要时间适应,过早评估
- **错位场景**:把适合 A 场景的方法搬到 B 场景
- **不可见的隐性场景**:文化、社会规范这些隐性维度容易被忽视

## 与其他概念的关系

- 与 [[人物]] 共生:人物在场景中展开,场景给人物提供条件
- [[情节]]:情节在场景中发生,场景影响情节的可能走向
- [[激励理论]]:激励本质是改变环境的奖惩结构
- [[复利效应]]:每天身处的环境的小影响会累积
- 与 [[第一性原理]] 关联:很多"性格问题"实际是"环境问题"
- [[二阶思维]]:换环境的二阶后果常被低估
- [[相互依存]]:你的环境包括你依赖的一切人和物
- [[系统思维]]:个人是系统中的节点,环境是系统的其他部分
- 在 [[用户旅程地图]] 中,使用场景是关键的设计维度
- [[启发式]]:特定场景触发特定启发,设计场景可以引导决策
