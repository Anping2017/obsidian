# 认知心理学

## 定义

**认知心理学**(Cognitive Psychology)是研究人类知觉、注意、记忆、语言、思维、推理与问题解决等内部心智过程的心理学分支。它把心智比作信息处理系统,以"输入—编码—存储—提取—输出"模型替代行为主义的"刺激—反应"黑箱。

奠基性事件是 1956 年 MIT 信息理论会议(Miller、Chomsky、Newell-Simon),被视为**认知革命**的标志性年份;Ulric Neisser 1967 年同名教科书《Cognitive Psychology》正式确立学科名称。

## 核心要点

### 主要研究领域

| 领域 | 经典议题 |
|---|---|
| **知觉** | 自下而上 vs 自上而下、格式塔组织、知觉恒常性 |
| **注意** | 选择性注意、分配性注意、鸡尾酒会效应 |
| **记忆** | 感觉记忆、工作记忆、长期记忆;陈述/程序;Baddeley 工作记忆模型 |
| **语言** | 语言习得、句法加工、语义网络 |
| **范畴与概念** | 原型理论、家族相似性、范畴层级 |
| **思维与推理** | 演绎推理、归纳推理、心理表征 |
| **判断与决策** | [[启发式]]、[[认知偏差]]、[[双系统思维]] |
| **问题解决** | 算法 vs 启发、专家与新手差异 |

### 历史源流

- **行为主义反叛**:对斯金纳"无内部状态"立场的反动
- **信息论与计算机隐喻**:Shannon 信息论 + Turing 计算论
- **乔姆斯基语言学革命**:1959 年评 Skinner《言语行为》,主张语法天赋
- **Newell & Simon GPS**:用计算机程序模拟人类问题解决

### 关键人物

- **Ulric Neisser**:学科命名者
- **George Miller**:7 ± 2 工作记忆容量
- **Donald Broadbent**:注意过滤器模型
- **Endel Tulving**:语义记忆 vs 情景记忆
- **Allan Newell & Herbert Simon**:符号认知学派
- **Alan Baddeley**:工作记忆模型
- **Daniel Kahneman & Amos Tversky**:启发式与偏差(行为决策)
- **Aaron Beck**:认知三角—衍生 [[认知行为疗法]]

### 三大方法论

1. **行为实验**:反应时、错误率、记忆测验
2. **神经成像**:fMRI、EEG、ERP 揭示加工的脑区与时序
3. **计算建模**:符号 GPS、ACT-R、连接主义神经网络

### 与认知科学的关系

[[认知主义]] 是流派立场,**认知心理学**是学科分支;**认知科学**(Cognitive Science)是认知心理学 + 神经科学 + 计算机科学 + 语言学 + 哲学的跨学科联盟。

## 应用场景

- **教育**:学习科学、记忆策略、刻意练习
- **临床**:[[认知行为疗法]]、[[辩证行为疗法]] 的理论基础
- **人因工程**:界面设计、注意分配、防错设计
- **AI**:[[机器学习]] 的早期灵感,认知架构研究(SOAR、ACT-R)
- **法律**:目击证词记忆研究改写司法证据规则

## 局限与陷阱

| 局限 | 描述 |
|---|---|
| **过度计算机化** | 心智 ≠ 程序,具身认知与情绪受忽视 |
| **生态效度** | 实验室任务难推广到真实世界 |
| **脑—心因果** | 神经活动激活并不等于心理过程"位于"该区域 |
| **个体差异** | 早期理论假设普遍机制,忽视文化与年龄差异 |

## 与其他概念的关系

- 与 [[认知主义]] 流派同名相生
- 反对 [[行为主义]] 但吸收其严谨方法
- 与 [[心灵哲学]]、[[语言哲学]] 共享许多基础问题
- 衍生 [[认知行为疗法]] 与 [[接纳承诺疗法]]
- 与 [[人工智能]]、[[机器学习]] 互为母学科
- [[认知偏差]]、[[启发式]]、[[双系统思维]] 是其标志性输出
- 与 [[儿童发展心理学]]、[[皮亚杰认知发展]] 共享发生论
- [[卡尼曼]] 把认知心理学方法移植到经济学,创立 [[行为经济学]]
