# 利润表

## 定义

**利润表**(Income Statement),也称**损益表**(Profit & Loss Statement, P&L),是反映企业在**一定会计期间**(月、季、年)的经营成果的会计报表。它把动态要素(收入、费用、利润)按照"收入 - 费用 = 利润"的等式逐层展开,是判断企业**盈利能力**的最直接依据。

与 [[资产负债表]] 的"时点性"不同,利润表是**期间报表**,反映一段时间内的累计变化。

## 核心要点

### 多步式格式(中国准则主流)

利润表分四层逐步计算:

```
营业收入
- 营业成本
- 税金及附加
- 销售费用
- 管理费用
- 研发费用
- 财务费用
± 其他收益、投资收益、公允价值变动收益、信用减值损失、资产减值损失、资产处置收益
= 营业利润 (第一层)

+ 营业外收入
- 营业外支出
= 利润总额 (第二层)

- 所得税费用
= 净利润 (第三层)

± 其他综合收益的税后净额
= 综合收益总额 (第四层,新准则要求)
```

### 单步式 vs 多步式

- **多步式**:逐层计算各级利润,信息含量丰富,便于分析
- **单步式**:总收入直接减总费用得净利润,简洁但分析价值低

### 关键利润指标

| 指标 | 含义 | 用途 |
|---|---|---|
| 毛利润 = 营业收入 - 营业成本 | 主业初步盈利 | 看产品定价权、规模效应 |
| 营业利润 | 主业经营成果 | 排除偶发因素后的可持续盈利 |
| 利润总额 | 税前利润(EBT) | 国际比较常用 |
| 净利润 | 归属股东的最终结果 | 每股收益、ROE 计算基础 |
| EBITDA | 息税折旧摊销前利润 | 跨资本结构比较盈利能力 |

### 收入费用配比原则

利润表的核心逻辑是**配比原则**(Matching Principle):产生收入的相关成本费用应在同一会计期间确认,这是 [[权责发生制]] 的具体应用。例如销售商品确认收入时,同时结转销售成本。

### 与资产负债表的勾稽

净利润扣除股利后的部分进入"未分配利润",直接增加 [[资产负债表]] 中的所有者权益。两表通过这条管道形成动静结合的完整画像。

## 和其他概念的关系

- 反映 [[会计要素]] 中收入、费用、利润三大动态要素
- 与 [[资产负债表]] 通过未分配利润勾稽,与 [[现金流量表]] 通过净利润勾稽
- 是 [[财务比率分析]] 中盈利能力比率(毛利率、净利率、ROE、ROA)的数据源
- 是 [[企业价值评估]] 相对估值法(P/E 倍数)的核心
- 应用 [[权责发生制]] 与 [[收入确认]] 准则
- [[基本面分析]] 看利润表分析企业经营质量,识别"会计利润 vs 经济利润"差异
- [[管理会计]] 把利润表拆解为成本性态(变动/固定)进行决策分析
- [[现金流折现模型]]:EBIT、净利润是 FCFF/FCFE 推导的起点
