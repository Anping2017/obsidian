# AIDA-PASTOR-QUEST 对比

## 概述

AIDA、PASTOR、QUEST 是西方营销文案传统中流传最广的三大说服公式,分别诞生于不同时代,代表三种不同的销售心理学范式。理解三者差异有助于在不同场景(短视频/落地页/邮件/直播脚本)选用最适配的结构。本概念是 [[AIDA文案公式]]、[[PASTOR文案公式]]、[[QUEST文案公式]] 的对照分析。

## 三大公式速览

### AIDA(1898 年提出)

```
Attention 注意 → Interest 兴趣 → Desire 欲望 → Action 行动
```

- 提出者:E. St. Elmo Lewis(美国广告人)
- 适用:广告、海报、短视频、落地页
- 长度:适合 30 秒-3 分钟

### PASTOR(2010 年代普及)

```
Problem 问题 → Amplify 放大 → Story/Solution 故事/方案 → Transformation 转变 → Offer 报价 → Response 行动
```

- 提出者:John Meese / Ray Edwards(基督教营销圈)
- 适用:长销售文案、邮件序列、网络研讨会
- 长度:适合 3000+ 字长文

### QUEST(20 世纪后期)

```
Qualify 资格 → Understand 理解 → Educate 教育 → Stimulate 刺激 → Transition 过渡到购买
```

- 提出者:Michel Fortin(直销文案)
- 适用:高客单 B2B、教育产品、咨询服务
- 长度:中长篇,适合销售信、白皮书

## 范式差异

| 维度 | AIDA | PASTOR | QUEST |
|---|---|---|---|
| 时代 | 19 世纪末工业广告 | 2010 年代数字直销 | 20 世纪后期直销 |
| 模型 | 注意-说服线性 | 痛点-方案-转变 | 教育-顾问式 |
| 假设客户 | 浅层注意 | 有痛点未察觉 | 有需求需教育 |
| 卖方角色 | 广告主 | 故事讲述者 | 行业顾问 |
| 长度 | 短 | 长 | 中长 |
| 转化路径 | 即时点击/购买 | 多步信任建立 | 教育后决策 |

## 各阶段对应映射

| AIDA | PASTOR | QUEST |
|---|---|---|
| Attention | Problem | Qualify |
| Interest | Amplify | Understand |
| Desire | Story + Transformation | Educate + Stimulate |
| Action | Offer + Response | Transition |

## 场景适配指南

### 短视频/抖音/小红书(< 60 秒)

- **优先**:AIDA
- **理由**:注意力极短,必须快速抓眼球
- **结构**:
  - 0-3 秒:钩子(Attention)
  - 3-15 秒:卖点(Interest)
  - 15-45 秒:演示+情绪(Desire)
  - 最后 5-10 秒:CTA(Action)

### 落地页(电商/SaaS)

- **优先**:AIDA + PASTOR 混合
- **理由**:落地页篇幅中长,需要更多说服
- **结构**:
  - 首屏:钩子+核心价值(Attention)
  - 第二屏:痛点放大(Problem + Amplify)
  - 第三屏:方案演示(Solution + Transformation)
  - 第四屏:社会证明、案例
  - 第五屏:报价 + CTA(Offer + Response)

### 长邮件序列(培育客户)

- **优先**:PASTOR
- **理由**:多步信任建立,长文有空间讲故事
- **结构**:
  - 邮件 1:问题(Problem)
  - 邮件 2:放大与教育(Amplify)
  - 邮件 3:故事案例(Story)
  - 邮件 4:转变愿景(Transformation)
  - 邮件 5:报价(Offer)
  - 邮件 6:Last Chance(Response)
  - 详见 [[邮件序列设计]]

### B2B 销售信/白皮书(高客单)

- **优先**:QUEST
- **理由**:决策方多人,需要教育与权威建设
- **结构**:
  - 第一部分:你是谁(Qualify)
  - 第二部分:理解你的挑战(Understand)
  - 第三部分:行业知识与方案教育(Educate)
  - 第四部分:具体收益与对比(Stimulate)
  - 第五部分:下一步(Transition)

### 直播带货脚本

- **优先**:AIDA(单次循环)+ PASTOR(整场)
- **理由**:每 60 分钟一个 PASTOR 循环,内含多个 AIDA 微循环
- 详见 [[直播脚本结构]]、[[4321直播法则]]

### 播客/长视频

- **优先**:PASTOR + QUEST
- **理由**:长形态有时间深度叙事
- 详见 [[播客脚本结构]]

## 心理学根基

### AIDA

- 工业时代心理学:注意 → 认知 → 情绪 → 行动 的层级模型
- 假设:用户接触广告 → 立即决策

### PASTOR

- 直接响应营销心理学:**痛点是销售的金钥匙**
- 假设:用户已有潜在痛点,只是未被自我认知
- 强调"先放大问题,再给解药"的"坏-好"对比

### QUEST

- 顾问式销售心理学:教育胜于推销
- 假设:用户对类目不熟,需要先建立认知框架
- 适合复杂决策场景

## 三公式合一框架

实际项目中常组合使用:
- **大结构**:PASTOR(整体叙事弧)
- **关键节点**:AIDA(每个段落微转化)
- **教育部分**:QUEST(权威建设)

例如一封邮件:
- 首段 AIDA(让用户继续读)
- 中段 PASTOR(共情+方案)
- 结尾 AIDA(明确 CTA)
