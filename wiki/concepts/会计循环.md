# 会计循环

## 定义

**会计循环**(Accounting Cycle)指企业在每个会计期间(月、季、年)内,从**交易发生**开始,经凭证编制、记账、对账、调整、结账,直至**财务报表生成与归档**的标准化、周而复始的会计工作流程。它是 [[会计学]] 实务的核心骨架,也是 [[复式记账法]] 落地的具体节奏。

## 核心要点

### 主要步骤

1. **识别与分析交易**:发生经济业务,识别其会计影响
2. **编制原始凭证**:发票、收据、银行回单等
3. **填制记账凭证**(Voucher):借贷分录的正式载体
4. **登记日记账**(Journal):按时间顺序连续记录
5. **过账到总账**(Ledger):按 [[会计科目体系]] 分类汇总
6. **对账与调节**:银行对账单、应收应付往来
7. **期末调整分录**:应计、递延、折旧/摊销、坏账、存货跌价
8. **试算平衡**(参见 [[试算平衡]]):核对借贷总额
9. **编制工作底稿**:汇总各账户期末余额
10. **结账**:把损益类账户余额结转至本年利润,再结至未分配利润
11. **编制财务报表**:[[资产负债表]]、[[利润表]]、[[现金流量表]]、所有者权益变动表
12. **报表附注与披露**
13. **审计**(年报)与归档

### 月末 vs 年末的差别

- **月末**:轻量级循环,通常只到调整 + 试算 + 简版报表
- **季末**:中等规模,内部 + 监管报告(上市公司季报)
- **年末**:完整循环,加上详细附注、外部审计、年度报告
- **关账日**:多数公司月末后 5–10 天关账,称"close window"

### 现代化变化

- **传统手工**:严格按上述线性流程,以纸质凭证为主
- **ERP 时代**:许多步骤自动化或并行,如过账与试算实时进行
- **持续会计(Continuous Accounting)**:把月末高峰工作分散到日常,缓解关账压力
- **AI 辅助**:发票 OCR、自动分类、异常检测、自助式报表

### 调整分录的类型

期末必做的调整,以确保 [[权责发生制]] 与配比原则:

| 类型 | 例子 |
|---|---|
| **应计费用** | 已发生未支付的工资、利息 |
| **应计收入** | 已提供未开票的服务 |
| **递延费用摊销** | 预付保险、租金的当期份额 |
| **递延收入实现** | 预收款随服务提供转为收入 |
| **折旧/摊销** | [[固定资产折旧]]、[[摊销]] |
| **减值** | 应收账款坏账、存货跌价、商誉减值 |
| **税费计提** | 当期所得税、附加税 |

### 内部控制嵌入

会计循环每一步都是 [[内部控制]] 的实施点:
- 凭证审核与复核
- 不相容职务分离(开票、记账、收款)
- 银行对账双人核对
- 调整分录授权
- 报表与财报的多层审核签字

### 现代审计的钉点

外部审计师在年末:
- 检查关键调整分录
- 函证应收应付
- 监盘存货
- 复核会计政策变更
- 测试 [[内部控制]] 设计与运行有效性

## 和其他概念的关系

- 是 [[会计学]] 实务的核心流程
- 由 [[复式记账法]] 提供逻辑基础
- 通过 [[会计科目体系]] 组织数据
- 包含 [[试算平衡]] 这一关键节点
- 输出 [[资产负债表]]、[[利润表]]、[[现金流量表]] 等报表
- 与 [[内部控制]] 在每一步紧密耦合
