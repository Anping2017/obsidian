# 登门槛效应 Foot-in-the-Door (FITD)

## 定义

**登门槛效应**(Foot-in-the-Door, FITD)指当个体**先接受一个微不足道的小请求**后,随后**接受更大请求的概率显著上升**。Freedman & Fraser(1966)发表的经典实验,先请居民签署"安全驾驶"小请愿(几乎无人拒绝),两周后请他们在前院立大型"小心驾驶"广告牌——同意率从 17% 升到 76%。

## 核心要点

### 心理机制

1. **自我知觉理论**(Bem):答应小请求后,人通过观察自己的行为推断"我是个乐于助人/支持此事业的人",新身份要求一致性
2. **[[认知失调]] 减少**:答应大请求与已建立的"乐于助人"身份一致
3. **承诺与一致性**(Cialdini 七大武器之一,见 [[承诺与一致]])
4. **关系建立**:小互动建立"接触"和心理熟悉度

### 关键边界条件

- 小请求**不能太小**(没承诺感)、**不能太大**(直接拒绝)
- 两次请求之间**有时间间隔**最佳(让自我推断巩固)
- 大请求**与小请求主题相关**或价值观相通
- 不能**支付报酬**(报酬会让人归因于外部,而非自我特质)
- 同一人/机构提出更佳

### 与"留面子效应"对照

- **登门槛**:小 → 大,利用承诺一致
- **[[留面子效应]]**(Door-in-the-Face):大 → 小,利用互惠让步
- 两者在不同条件下都能提升依从性

### 应用场景

- **销售**:试用品 → 订阅 → 升级套餐
- **公益**:小额捐款 → 大额募捐 → 月度定捐
- **政治**:签请愿 → 参与游行 → 入党
- **互联网产品**:免费注册 → 完善资料 → 付费会员(见 [[订阅商业模式]])
- **谈判**:小让步开场,逐步推进
- **关系建立**:小礼物 → 邀请晚餐 → 深度承诺
- **成瘾设计**:每日签到 → 每日打卡 → 长期黏着

### 反登门槛策略

- 自觉识别"小请求"链条
- 询问"如果一开始就被要求做大事我会同意吗"
- 设定明确预算/时间上限再开始

## 和其他概念的关系

登门槛是 [[影响力]] (Cialdini)六大武器之 [[承诺与一致]] 的具体应用,与 [[互惠原则]]、[[社会证明]]、[[权威偏差]]、[[稀缺性]] 共同构成说服心理的工具集。

理论根基是 Bem 的自我知觉理论,与 [[认知失调]]、[[自我效能]] 形成完整的自我理论网络。

营销实操上与 [[AIDA文案公式]]、[[PASTOR文案公式]]、[[漏斗优化]]、[[病毒系数K]] 结合;[[销售漏斗]] 设计经常通过精心安排的"小承诺"链条把潜客推向购买。

[[精益创业]] 中"MVP+小承诺"获得早期用户也是登门槛思路;[[增长黑客]] 中的轻量化引流注册同理。

伦理上需与 [[暗黑模式]] 相区分——基于真实价值的微承诺可接受,而欺骗性微承诺属操控。
