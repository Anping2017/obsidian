# CDP客户数据平台

## 定义

CDP(Customer Data Platform)是一个集成型软件平台,负责把分散在各渠道(网站、App、CRM、ERP、客服、广告平台、线下门店)的客户身份与行为数据,通过 ID 打通形成统一的客户画像数据库,再将这些数据按标签 / 人群分发给下游营销系统使用。它是现代 MarTech 栈的核心枢纽,与 [[CRM客户关系管理|CRM]]、DMP 的差别在于:CRM 装"销售关系数据",DMP 装"匿名广告人群",CDP 装"全域可识别用户的全生命周期行为"。

## 核心要点

**关键能力**:

1. **数据采集**:SDK / API / Webhook / ETL 接入各源系统。
2. **身份解析(ID Resolution)**:把同一用户在 Cookie、设备 ID、手机号、邮箱、会员号等多个 ID 下的行为拼接为单一 Profile。常见技术:
   - 确定性匹配(Deterministic):基于登录态精确合并。
   - 概率性匹配(Probabilistic):依据 IP、设备、行为相似性推断同一用户。
   - 图数据库存储 ID 关系网络。
3. **统一画像存储**:每个客户一条记录,包含属性(年龄、性别、地域)+ 标签(高价值、加购未购)+ 行为序列(每次访问、每个事件)。
4. **细分人群与标签计算**:基于规则 / SQL / 机器学习生成动态人群。
5. **数据激活(Activation)**:把人群推送到下游系统——广告平台(Meta、Google、字节)、邮件营销(Klaviyo)、Push、客服、个性化推荐引擎。

**与相邻概念区别**:

| 系统 | 核心 | 数据 | 输出 |
|---|---|---|---|
| CRM | 销售关系 | 销售人员录入的客户/线索 | 销售跟进 |
| DMP | 广告匿名 | 第三方 Cookie 标签 | 广告定向(隐私时代衰退) |
| CDP | 全域可识别 | 第一方多源行为 + 属性 | 多渠道激活 |
| DWH | 分析仓库 | 全量数据,T+1 | BI 报表 |

CDP 与 DWH 的核心差异:CDP **实时 + 客户为中心 + 营销直接可用**。DWH 偏离线分析。

**主流厂商**:

- 国际:Segment(Twilio)、Adobe Real-Time CDP、Salesforce Data Cloud、mParticle、Tealium、ActionIQ、Treasure Data。
- 国内:腾讯营销云、阿里数据银行、神策、TalkingData、火山引擎 GMP。

**部署模式**:

- **All-in-one CDP**:集成营销激活,产品形态完整。
- **Composable CDP**:基于现有数据仓库(Snowflake、BigQuery)构建,只做激活层(Hightouch、Census 是这类的代表)。这是 2023 后的新趋势。
- **自建**:大平台(腾讯、字节)自建,不用商业 CDP。

**典型用例**:

- **个性化首页**:登录用户依据 CDP 标签实时推荐内容。
- **跨渠道一致体验**:用户在 App 加购,Push、邮件、Web 同步看到该 SKU 的促销。
- **流失预警**:CDP + ML 模型预测流失概率,自动触发 [[Win-back 序列]]。
- **广告人群同步**:每天把"VIP 客户"同步到 Meta 排除拉新预算。
- **客服 360°视图**:客服在客服系统中看到客户全渠道历史。

**实施挑战**:

- **数据治理**:命名规范、字段统一、事件 Schema 设计。
- **隐私合规**:GDPR / CCPA / 个保法对采集 / 同意 / 删除有强要求。
- **ID 打通**:跨域跨设备打通是技术与合规双难题。
- **激活的数据延迟**:实时 vs 准实时 vs 批量。
- **跨部门协作**:产品、营销、IT、合规、客服都要协同。

## 和其他概念的关系

CDP 是 [[数据驱动营销]] 与 [[精准营销]] 的数据底座,直接驱动 [[再营销]]、[[Lookalike人群]]、[[邮件序列设计]]、[[Push通知]]、[[AB测试]] 等下游能力。它是 [[全渠道营销]] 的"单一真理来源",没有 CDP 就只能做"渠道 + 渠道"的平铺,做不到一致体验。

CDP 与 [[CRM客户关系管理|CRM]] 在客户管理上互补:CRM 偏前向销售关系,CDP 偏全行为数据。它与 [[营销自动化]] 平台(MA)区别在于:MA 是规则执行引擎,CDP 是数据基础设施。两者常组合使用。

[[ATT隐私框架]] 后,以"第一方数据"为核心的 CDP 战略价值大幅提升——这是品牌主自己掌握的、不依赖第三方 cookie 的合规人群资产。CDP 也是 [[AI客服]] 与 [[个性化推荐系统]] 的数据上游。
