# 佛家

## 定义

**佛家(佛教哲学)** 由释迦牟尼(约前 563-前 483)在印度创立,核心问题是**"如何离苦得乐、达到解脱"**。其哲学包含本体论、认识论、伦理学、心理学多个维度,通过**四圣谛、八正道、三法印**奠定根本框架,后经龙树、世亲、慧能等思想家在不同传统中发展。

## 核心要点

### 四圣谛(Cattāri Ariyasaccāni)

| 谛 | 内容 |
|---|---|
| **苦谛(Dukkha)** | 人生本质是苦,包括生老病死、爱别离、怨憎会等 |
| **集谛(Samudaya)** | 苦的根源是渴爱(欲望)与无明 |
| **灭谛(Nirodha)** | 苦可以止息,达到涅槃 |
| **道谛(Magga)** | 止苦之道是八正道 |

### 八正道

- **正见、正思维、正语、正业、正命、正精进、正念、正定**
- 涵盖认知、动机、言行、生计、努力、注意、定境
- 不仅是修行清单,而是相互支撑的整体生活

### 三法印

- **诸行无常**:一切现象都在变化,没有固定不变
- **诸法无我**:没有独立永恒的"我"或本质,皆是因缘和合
- **涅槃寂静**:超越渴爱后达到的平静境界

### 主要哲学传统

| 传统 | 代表 | 核心 |
|---|---|---|
| **中观派** | 龙树(2-3 世纪) | 空、中道,破除一切边见 |
| **唯识派** | 无著、世亲(4-5 世纪) | 万法唯识,八识结构 |
| **禅宗** | 慧能(638-713) | 顿悟、直指人心 |
| **净土宗** | 善导 | 念佛、往生 |
| **密宗** | 莲花生 | 即身成佛、密法修行 |

### 缘起与空性

- **缘起(Pratītyasamutpāda)**:一切现象因缘而起,没有独立自性
- **空(Śūnyatā)**:并非"什么都没有",而是无独立永恒本质
- 不堕入有边(实有)也不堕入无边(虚无),即"中道"

### 在西方哲学语境的对应

- "无我"对照 [[二元论|心物二元论]] 和西方"自我"概念形成挑战
- "缘起"近似过程哲学(Whitehead)
- "无常"近似赫拉克利特"万物流变"
- "苦"的现象学描述与 [[存在主义]] 焦虑有共振

### 心理学维度

- 详细的心识分析(尤其唯识派的八识)是早期心理学
- "正念"经禅宗、内观传统传入西方,催生现代正念冥想运动
- 卡巴金 MBSR、ACT 接纳承诺疗法部分源自佛家禅修

### 在东方思想的位置

- 与 [[儒家]]、[[道家]] 共同构成"儒释道三家"
- 中国化后形成禅宗、净土、华严、天台等本土宗派
- 影响日本、韩国、东南亚的哲学与文化

## 和其他概念的关系

- 与 [[儒家]]、[[道家]] 共构 [[东方哲学]] 三大支柱
- [[禅宗]] 作为佛家的中国化形态,可设独立页
- "缘起空性"与西方 [[本体论]] 形成对照
- "无我"对应 [[意识与潜意识]] 的"自我"问题
- 八正道中"正念"催生现代 [[正念]] 冥想心理学
- 与 [[积极心理学]] 在"超越快乐主义"上有交集
- "无常"观念与 [[复利效应]] 的"持续变化"思维方式相通(避免执着固定预期)
- 与 [[现象学]] 在"如实观察现象"上方法相近
