# 视觉语言模型

## 定义

视觉语言模型(Vision-Language Model, VLM)是同时处理图像与文本的[[多模态AI]]模型,能够实现图像描述、视觉问答(VQA)、文档解析、图表理解、UI 操作等任务。VLM 标志着 AI 从单模态走向"看懂世界"的阶段。

## 主流架构

### 双塔(Two-tower)

- 视觉编码器([[CLIP]] 或 [[Vision Transformer]])与文本编码器分别编码,通过对比学习对齐
- 代表:CLIP、ALIGN、SigLIP
- 适合检索、分类,不擅长生成

### 单塔生成(Unified Generative)

- 视觉编码器输出 token 嵌入,与文本 token 一起喂入语言模型
- 代表:[[GPT系列模型]]-4V、Claude 3、[[Gemini系列模型]]、LLaVA、Qwen-VL
- 适合开放问答与生成

### 原生多模态

- 训练时统一 token 化文图音视
- 代表:Gemini、GPT-4o、Qwen2.5-Omni
- 多模态信号深度融合

## 关键技术

- **视觉 Token 化**:用 ViT 或 CNN 将图像转为序列
- **跨模态注意力**:让文本能"看到"图像 token
- **Vision Adapter**:LLaVA 风格用 MLP/Q-Former 桥接
- **图像分辨率适配**:动态分辨率(AnyRes)或瓦片切分(Tiling)

## 经典模型

- **CLIP**(OpenAI 2021):对比学习开山之作
- **Flamingo**(DeepMind):门控交叉注意力
- **BLIP-2**:Q-Former 桥接器
- **LLaVA**:开源视觉指令微调
- **Qwen-VL** / **InternVL**:中文圈代表
- **GPT-4V** / **Claude 3 Vision** / **Gemini Vision**:闭源旗舰

## 应用场景

- 文档/PDF 解析(发票、表格、图表)
- 网页与 UI 截图理解(GUI Agent)
- 医学影像辅助诊断
- 缺陷检测、自动驾驶感知
- 视觉创作辅助

## 与其他概念的关系

- 基于 [[Vision Transformer]] 与 [[CLIP]] 等视觉骨干
- 与 [[Stable Diffusion]] 形成"理解 vs 生成"对照
- 是 [[GPT系列模型]]、[[Claude系列模型]]、[[Gemini系列模型]]、[[Qwen系列模型]] 必备能力
- 与 [[AI Agent框架]] 结合形成 GUI Agent
- 评估通过 MMMU、MathVista 等多模态基准
