# 资产负债表

## 定义

**资产负债表**(Balance Sheet,简称 B/S),又称**财务状况表**(Statement of Financial Position),是反映企业**某一特定日期**财务状况的会计报表。它建立在 [[会计等式]] 基础上,左侧列示企业的全部资产,右侧列示其全部负债和所有者权益,左右金额必然相等。

它是**时点报表**(snapshot),与利润表、现金流量表的"期间报表"性质形成对比。

## 核心要点

### 报表结构

按流动性分类,三大栏目展开为:

**资产端**(按流动性递减排列):

- 流动资产:货币资金、交易性金融资产、应收账款、预付账款、存货、一年内到期的非流动资产等
- 非流动资产:长期股权投资、固定资产、在建工程、无形资产、商誉、递延所得税资产等

**负债端**:

- 流动负债:短期借款、应付账款、预收账款、应付职工薪酬、应交税费、一年内到期的非流动负债
- 非流动负债:长期借款、应付债券、长期应付款、递延所得税负债

**所有者权益端**:

- 实收资本(股本)
- 资本公积
- 盈余公积
- 未分配利润
- 上市公司另有"少数股东权益"和"库存股"等

### 编制方法

主要从总账账户余额取数,辅以三类调整:

- **直接填列**:大多数账户余额直接对应报表项目
- **计算填列**:如"货币资金 = 库存现金 + 银行存款 + 其他货币资金"
- **抵销填列**:如"应收账款 = 应收账款余额 - 坏账准备"
- **调整填列**:如"长期借款"扣除一年内到期部分

[[合并报表]] 涉及更复杂的内部交易抵销与少数股东权益处理。

### 分析维度

- **结构分析**:垂直分析,看流动资产/总资产、负债/总资产等比例
- **趋势分析**:水平分析,纵向看年度变化
- **比率分析**:横向比较

| 类别 | 关键比率 | 公式 |
|---|---|---|
| 短期偿债 | 流动比率、速动比率 | 流动资产/流动负债 |
| 长期偿债 | 资产负债率、权益乘数 | 总负债/总资产 |
| 营运能力 | 应收/存货/总资产周转率 | 营业收入/平均余额 |
| 资本结构 | 产权比率 | 总负债/所有者权益 |

### 局限性

- 只反映可计量的经济资源,品牌、人力资本等核心无形资产难以体现
- 历史成本计量使账面价值与公允价值偏离
- 时点性可能被"窗口粉饰"操纵(如年末突击回款)

## 和其他概念的关系

- 直接映射 [[会计等式]],由 [[复式记账法]] 数据汇总而成
- 与 [[利润表]] 通过"未分配利润"项目联结(本期净利润转入)
- 与 [[现金流量表]] 通过"货币资金"期末数联结
- [[财务比率分析]] 中超过半数比率以资产负债表数据为分子或分母
- 是 [[企业价值评估]] 中相对估值法(P/B 比率)和资产基础法的核心数据源
- [[资本结构理论]] 通过资产负债表观察债务/权益比例的演变;反过来理论指导债务/权益结构调整
- 银行授信、债券评级、IPO 审核都依赖资产负债表的真实性,这正是 [[审计]] 和 [[内部控制]] 的核心目标
- 宏观对应:全国所有企业资产负债表的聚合即"国家资产负债表",是 [[GDP核算]] 之外另一类核心宏观账户;企业层面的资产、负债、所有者权益结构变迁也直接反映宏观经济周期与产业升级
