# LoRA

## 定义

**LoRA(Low-Rank Adaptation, 低秩适配)** 是 Microsoft 于 2021 年提出的高效微调方法:冻结预训练 [[大语言模型]] 的全部主权重,在每个目标层旁路注入两个小的低秩矩阵 $A \in \mathbb{R}^{r \times d}$、$B \in \mathbb{R}^{d \times r}$($r \ll d$),只训练这一对矩阵。微调时新权重为 $W + BA$,推理时可与原权重融合,无额外开销。

它是 PEFT(Parameter-Efficient Fine-Tuning)方法的代表,把万亿参数模型的微调拉到单卡可做的水平。

## 核心要点

**核心数学**

原始全参微调更新 $W$:$W \leftarrow W + \Delta W$,$\Delta W$ 与 $W$ 同形,巨大。

LoRA 假设 $\Delta W$ 在低秩子空间足够:$\Delta W = BA$,只训练 $A, B$,参数量从 $d \times d$ 降到 $2 \times d \times r$,通常 $r=8\sim64$。

**主要优势**

| 维度 | 收益 |
|---|---|
| 参数量 | 通常降至原模型 0.01% - 1% |
| 显存 | 大幅降低,单卡可微调 70B 模型 |
| 存储 | 多任务可只存多份 LoRA 增量,共享主模型 |
| 切换 | 推理时切任务只需热替换 LoRA 权重 |
| 部署 | 与原权重融合后无推理开销 |

**与其他 PEFT 比较**

- Adapter:在每层插入小型瓶颈模块,但增加推理延迟
- Prefix Tuning / P-Tuning:训练可学习的 prompt 向量,适配能力较弱
- LoRA:参数效率与表达能力的最佳平衡,生态成熟

**主要变体**

- QLoRA(2023):4-bit 量化主模型 + LoRA 微调,把 65B 模型拉到 48GB 单卡
- DoRA、LoRA+、AdaLoRA、LoRA-FA 等改进版
- LoRA 也可应用于扩散模型(Stable Diffusion)做风格 / 角色微调

**典型工作流**

1. 加载基础模型(冻结)
2. 在目标层(常是 attention 中的 Q、K、V、O 投影)注入 LoRA 适配器
3. 在小规模数据集上训练
4. 保存只有几十 MB 的 LoRA 权重
5. 推理时合并或运行时叠加

**何时使用**

- 想让模型学新风格、新领域用语
- 预算有限,无法全参微调大模型
- 需要为不同客户/任务部署多个变体
- 想快速实验、迭代

**何时不够**

- 极度新的能力(模型几乎没见过的任务)
- 知识更新:用 [[RAG]] 比 LoRA 灵活
- 安全对齐:[[RLHF]] 等更系统的方法更适合

## 和其他概念的关系

- 整体方法论:属于 [[预训练与微调]] 中的高效微调路径
- 兼容性:可与 [[RLHF]]、量化等技术正交组合
- 替代/补充:[[RAG]] 用检索而非权重更新注入新知识,二者常并用
- 数学基础:基于"权重更新具有低秩结构"的实证假设
