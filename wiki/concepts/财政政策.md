# 财政政策

## 定义

**财政政策(Fiscal Policy)**:政府通过调整**税收**与**财政支出**(以及由此形成的政府债务)影响总需求与经济运行的政策工具。是宏观调控两大支柱之一(另一为 [[货币政策]])。

## 核心要点

### 政策工具

**税收(T)**:
- 直接税:个人所得税、企业所得税
- 间接税:增值税、消费税、关税
- 税收优惠:减免税、税收抵免

**政府支出(G)**:
- 购买性支出:政府消费、公共投资
- 转移性支出:社会保障、补贴、失业救济(不计入 GDP 但影响可支配收入)
- 资本性支出:基础设施、公共工程

**政府债务**:
- 国债融资当期赤字
- 期限结构与利率结构管理
- 债务可持续性(债务/GDP 比率)

### 政策类型

| 类型 | 工具 | 目标情景 |
|---|---|---|
| 扩张性 | G↑、T↓ | 衰退、低产出 |
| 紧缩性 | G↓、T↑ | 过热、高通胀 |
| 中性 | 财政平衡 | 稳定增长 |
| 自动稳定器 | 累进税、失业救济 | 内生反周期 |

**自动稳定器**:无需主动决策,经济自动反周期 —— 衰退时税收减、转移支付增,反之亦然。其内在反周期性是现代财政体系的重要内置机制。

### 乘数效应

财政政策对总需求的放大作用:

```
政府支出乘数:ΔY/ΔG = 1/(1−c)
税收乘数:ΔY/ΔT = −c/(1−c)
平衡预算乘数:1(等量增 G、增 T)
```

其中 c 为边际消费倾向。开放经济与税收下乘数缩小:1/(1 − c(1 − t) + m),m 为边际进口倾向。

### 挤出效应(Crowding Out)

扩张性财政政策推高利率,抑制私人投资 —— 部分财政效果被抵消。

```
[[IS-LM模型]] 中 IS 右移 → r↑、Y↑(部分被 r↑ 引发的 I↓ 抵消)
```

**完全挤出**情形:LM 垂直(古典假设),Y 不变 r 大涨。
**零挤出**情形:LM 水平(流动性陷阱),Y 大涨 r 不变。

财政政策有效性高度依赖货币市场状况。流动性陷阱(2008 后、2020 后)是财政政策的"黄金期"。

### 时滞效应

- **认识时滞**:问题出现到识别(数据迟滞)
- **决策时滞**:立法过程(可达数月数年)
- **执行时滞**:政策落地
- **效果时滞**:政策传导至实体经济

财政政策时滞通常长于货币政策,这是预算 + 立法过程的代价,也是货币政策成为短期调控主力的原因。

### 财政可持续性

**债务/GDP 比率动态**:

```
Δ(B/Y) = (r − g)·(B/Y) + (G − T)/Y
```

当债务利率 r > 增长率 g 时,即使财政平衡,债务/GDP 也会上升 —— 这是日本与南欧债务问题的核心数学。

**债务危机阈值**:理论上无单一阈值,但实证发现债务/GDP > 90% 时增长显著放缓(Reinhart-Rogoff)。该数字后被批评有数据问题,但债务过高确实抑制增长是共识。

### 长期影响:供给侧

财政政策不仅影响 AD,长期还影响 AS(LRAS):

- **基础设施投资**:提高生产效率
- **教育、研发支出**:增加人力资本与 TFP
- **税收结构**:影响劳动供给、储蓄、投资激励
- **政府效率**:减少交易成本

供给学派(拉弗曲线)主张减税刺激经济增长,但实证效果有限,2017 年美国减税未显著提升增长率。

### 国际经验

**美国**:大规模减税(2017、2025 试验性政策)、基建投资(IRA、CHIPS),债务/GDP 已超 120%。

**欧盟**:稳定与增长公约要求赤字 < 3%、债务 < 60%(常被违反),南欧债务危机暴露其结构问题。

**日本**:1990s 后财政刺激累计巨大,债务/GDP 超 250%,但经济长期低增长 —— 财政政策在结构性问题前作用有限的反例。

**中国**:积极财政政策为主,通过基建投资稳增长;地方政府债务、隐性债务是重大风险点。

### 政策协调

财政政策需与 [[货币政策]] 协调:
- 衰退期:财政扩张 + 货币宽松(双扩张)
- 滞胀期:政策两难,通常优先抗通胀
- 复苏期:财政正常化 + 货币正常化

国际协调通过 G20、IMF 框架。2008 与 2020 危机中,主要国家协调推出大规模财政刺激。

## 和其他概念的关系

财政政策是 [[凯恩斯]] 革命的核心政策遗产,通过 [[IS-LM模型]] 中 IS 移动直接影响产出;在 [[AD-AS模型]] 中表现为 AD 右/左移;通过 [[菲利普斯曲线]] 影响通胀-失业权衡。

它与 [[货币政策]] 互补又有竞争 —— 在 [[失业理论]] 中应对周期性失业,在 [[价格指数与通胀]] 中通过调节总需求影响通胀。挤出效应使其与 [[利率理论]] 紧密相关。

跨域:[[国际收支]] 中孪生赤字命题(财政赤字 ↔ 经常账户赤字)源自国民收入恒等式;[[汇率决定理论]] 中扩张性财政政策在浮动汇率下通过资本流入推高汇率,部分抵消政策效果(蒙代尔-弗莱明);[[债券市场]] 直接受财政赤字与债务发行规模影响;[[投资组合理论]] 与 [[资产配置]] 中"美林时钟"模型把财政政策周期作为大类资产轮动信号;[[金融市场概述]] 中政府债券市场是财政政策的实施渠道与定价基准。

会计学连接:政府财政收支与国债发行的真实性、合规性依赖政府 [[审计]] 体系——从中国国家审计署、美国 GAO 到各国最高审计机关,均通过对预算执行、政府投资、国企的审计为财政纪律与债务可持续性提供独立保证,审计意见也直接影响主权信用评级与债券融资成本。
