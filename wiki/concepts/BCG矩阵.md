# BCG 矩阵

## 定义

**BCG 矩阵**(BCG Matrix),又称**波士顿矩阵**或**增长-份额矩阵**(Growth-Share Matrix),由波士顿咨询集团(Boston Consulting Group)创始人 Bruce Henderson 在 1968-1970 年提出。它把企业的多个**业务单元(SBU)** 或产品按两个维度分类,帮助管理者做**业务组合管理**(Portfolio Management)与**资源分配**决策:

- **横轴**:相对市场份额(Relative Market Share)= 本业务份额 / 最大竞争对手份额
- **纵轴**:市场增长率(Market Growth Rate)

由此形成四象限:

```
                       高市场份额   低市场份额
                    ┌────────────┬────────────┐
   高增长率          │   明星     │   问题     │
                    │   Stars    │ Question   │
                    │            │   Marks    │
                    ├────────────┼────────────┤
   低增长率          │  现金牛    │  瘦狗      │
                    │ Cash Cows  │   Dogs     │
                    │            │            │
                    └────────────┴────────────┘
```

## 核心要点

### 四象限的特征与战略

**明星 (Stars)**:高增长 + 高份额
- 行业领先,但需大量投资维持增长
- 现金流通常**净流出**
- 战略:**投资增长**,期待未来变成现金牛
- 例:目前的 Tesla、字节跳动核心业务

**现金牛 (Cash Cows)**:低增长 + 高份额
- 成熟行业领导者
- 投资需求小,产生**大量净现金流**
- 战略:**收割现金**,补贴明星和问题业务
- 例:可口可乐主品牌、Apple iPhone(进入成熟期)

**问题 (Question Marks 或 Problem Children)**:高增长 + 低份额
- 行业有潜力,但本业务地位弱
- 现金流通常**净流出**
- 战略:**选择性投资**——能成为明星的加大投入,否则撤出
- 例:许多创业期产品

**瘦狗 (Dogs)**:低增长 + 低份额
- 行业衰退,本业务边缘化
- 现金流接近平衡或净流出
- 战略:**剥离或清算**,有时仍可"挤水"维持小利润
- 例:许多企业的非核心业务

### 现金流循环

BCG 矩阵的精髓不是单点分类,而是**现金流的内部循环**:

```
        现金牛产生现金
              ↓
       问题业务或明星投入
              ↓
       明星成熟为现金牛
              ↓
        瘦狗剥离释放资源
```

理想组合:**少量现金牛 + 几个明星 + 1-2 个问题(待孵化) + 不要过多瘦狗**。

### 应用步骤

1. **业务分解**:把企业拆为 SBU 或产品组
2. **数据收集**:每个 SBU 的市场份额、市场增长率、销售额、利润
3. **绘制矩阵**:气泡大小代表销售额或利润
4. **战略生成**:每个象限对应不同战略
5. **资源分配**:决定投资、收割、剥离
6. **跟踪演化**:动态监测 SBU 在矩阵中的移动

### 局限性

- **过度简化**:仅两个维度,忽略协同效应、技术壁垒、品牌溢价等
- **市场份额不等于盈利**:小份额可能高利润(差异化、聚焦战略)
- **"高/低"切分点主观**:阈值选择影响结论
- **静态视角**:忽略行业生命周期与战略机会
- **忽视协同**:有些瘦狗与明星协同强,不能简单剥离
- **数据获取困难**:小业务的市场份额数据常缺失

### 替代与改进框架

**1. GE/麦肯锡矩阵**(GE-McKinsey Matrix)

九宫格替代四象限,两个维度更复杂:

- 横轴:业务竞争力(多因素综合)
- 纵轴:行业吸引力(多因素综合)

包含更多变量,但操作复杂。

**2. ADL 矩阵**(Arthur D. Little Matrix)

按行业生命周期阶段(诞生-成长-成熟-衰退) × 竞争地位(主导-强-有利-可生存-弱)分 20 类。

**3. 麦肯锡 7S**

不专门做组合分析,但用于业务整体诊断。

### 现代评价

虽因简化受批评,BCG 矩阵在以下场合仍有价值:

- 多元化集团的资源分配讨论起点
- 投资组合管理的可视化工具
- 战略沟通中的简明语言
- 与其他工具(GE 矩阵、SWOT)配合使用

亨德森本人曾说:"它最大的价值是让管理者**对话**关于业务组合,而不是被它的标签所束缚。"

- 是 [[战略管理]] 中业务组合分析的代表工具

- [[平衡计分卡]] 在不同象限的 KPI 设置应有差异
- 在多元化战略评估中常作为初步筛查
