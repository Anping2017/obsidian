# 多元思维模型

## 定义

**多元思维模型**(Latticework of Mental Models)是 [[芒格]] 倡导的**跨学科思考方法**:在头脑中整合多个学科的核心原理,形成"格栅式"认知框架,用于分析复杂问题。其核心信念是:**单一学科的视角必然扭曲现实**;只有多元视角交叉验证,才能逼近真相。

## 核心要点

### 芒格的核心论断

> "如果你只有一把锤子,你会把所有问题都当作钉子。"
> "你必须拥有多元思维模型,因为如果你只有一种,你会扭曲现实来适应你的模型。"

### 为什么需要多元模型

1. **专业化分工**催生专家盲区:每个学科有自己的简化假设
2. **复杂系统的多因果性**:一个现象常被多个因素共同决定
3. **认知节能倾向**:大脑天然偏好单一解释 —— 必须刻意对抗
4. **避免锤子综合征**:工具决定问题的看法

### 模型组合的九大学科(芒格框架)

| 学科 | 核心模型 |
|---|---|
| **数学与统计** | [[复利效应]]、概率、贝叶斯、决策树 |
| **物理学** | 临界质量、杠杆、惯性、热力学(熵) |
| **生物学** | 进化、适应、共生、生态系统 |
| **化学** | 自动催化、稳定性 |
| **心理学** | [[认知偏差]]、激励、社会证明 |
| **经济学** | 供需、机会成本、规模经济、比较优势 |
| **管理学** | 系统思维、组织行为、决策 |
| **历史学** | 周期、教训、类比 |
| **工程学** | 系统设计、故障分析、冗余 |

### 模型如何使用:格栅(Latticework)思维

- 不是简单罗列模型,而是让模型间**互相加强、互相检验**
- 复利 + 心理学 → 习惯养成的指数效应
- 进化 + 经济学 → 商业生态中的"适者生存"
- 概率 + 心理学 → 识别概率被情绪扭曲的偏差

### 学习多元模型的原则

1. **掌握真正的"基础重大模型"**:每学科 5-10 个,不在数量在质量
2. **跨学科联系**:看到任一现象,主动用 3 个以上模型分析
3. **持续阅读**:芒格本人是阅读机器,涵盖各学科
4. **实践校验**:在投资、决策、生活中验证模型
5. **建立清单**:芒格自己在《人类误判心理学》列 25 类偏差清单

### 与"专家论"的对照

- 单一专家:在自己学科内深入,易在边界外失误
- 多元学习者:在边界处看到机会,能识别专家盲点
- [[芒格]] 与巴菲特的成功部分源自多元模型 + 长期学习

### 核心模型清单(芒格反复强调)

- **复利**(Compound Interest):时间是朋友
- **激励**(Incentives):"告诉我你的激励,我告诉你结果"
- **逆向思维**(Inversion):"反过来想,总是反过来想"
- **机会成本**:每个选择都放弃了别的
- **能力圈**:只在自己理解的范围里下重注
- **检查清单**:重要决策用 checklist
- **冗余/双备份**(Backup):工程思维应用于决策

## 和其他概念的关系

- 由 [[芒格]] 系统提出,与巴菲特价值投资法互补
- 包含 [[复利效应]]、[[逆向思维]]、[[能力圈]]、[[第一性原理]] 等子模型
- 心理学子模块对应 [[认知偏差]] 大全
- 与 [[批判性思维]]、[[第一性原理]] 共同构成现代决策思维三角
- 应用于 [[投资决策框架]]、[[企业价值评估]]、商业分析
- 与 [[行为金融学]] 共享心理学基础
- 从认识论看,是反对 [[认识论]] 中"单一真理"路径的实用主义版本
