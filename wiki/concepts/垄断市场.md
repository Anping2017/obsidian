# 垄断市场

## 定义

**垄断市场(Monopoly)**:只有一个卖者、产品无近似替代品的市场结构。垄断者既是供给的全部,也是价格制定者(price maker)。

形成原因:
- **自然垄断**:规模经济使大企业总能压低价格,新进入者难以生存(电力、自来水)
- **资源垄断**:控制关键投入(钻石矿)
- **技术垄断**:专利、商业秘密、网络效应(平台企业)
- **政府垄断**:法定特许、行政命令(电信、烟草)

## 核心要点

### 需求与收益

垄断者面对的需求曲线就是**整个市场需求曲线**(向下倾斜),因此:

```
MR = P + Q·(dP/dQ) < P  (因 dP/dQ < 0)
MR = P(1 − 1/|Ed|)
```

**关键结论**:MR 始终低于 P,且 MR 曲线斜率是需求曲线的两倍(在线性需求下)。垄断者绝不会在需求缺乏弹性段(|Ed| < 1)生产 —— 此时 MR < 0,涨价反增收入。

### 利润最大化

```
MR = MC ⟹ Q_m
P_m = P(Q_m) > MR(Q_m) = MC
```

加成定价公式(Lerner 形式):

```
(P − MC)/P = 1/|Ed|
```

需求弹性越低,加成越高 —— 这是垄断者的核心定价逻辑。

### 福利后果:无谓损失

与 [[完全竞争市场]] 相比:

| 指标 | 完全竞争 | 垄断 |
|---|---|---|
| 价格 P | = MC | > MC |
| 数量 Q | Qc(高) | Qm < Qc |
| 消费者剩余 | 大 | 小(部分被夺取为利润) |
| 生产者剩余 | 0(经济利润) | > 0 |
| 总剩余 | 最大 | 减少 |
| 无谓损失 | 0 | 存在 |

无谓损失三角形即为垄断的社会福利成本,详见 [[消费者剩余与生产者剩余#无谓损失]]。

### 价格歧视

垄断者通过价格歧视提取更多消费者剩余:

| 等级 | 含义 | 例子 |
|---|---|---|
| 一级 | 完全价格歧视,每位消费者按其支付意愿定价 | 拍卖、私人议价 |
| 二级 | 按购买量分段定价 | 阶梯电价、量大优惠 |
| 三级 | 按市场分段定价 | 学生票、地理价格、淡旺季 |

成立条件:市场可分割、需求弹性不同、套利不可行。一级歧视消除无谓损失但完全榨取消费者剩余;三级歧视效率介于完全垄断与完全竞争之间。

### 自然垄断的政府干预

自然垄断中,LAC 单调下降导致市场只能容纳一家企业:

- **平均成本定价**(P = ATC):零利润但产量低于社会最优
- **边际成本定价**(P = MC):产量最优但企业亏损,需补贴
- **拉姆齐定价**:在零利润约束下最大化总剩余

实际监管多采用回报率管制、价格上限管制(price cap)。

### 创新激励的双面性

熊彼特视角:垄断利润是研发投入的回报,推动创新(动态效率)。但垄断也可能压制竞争创新。这一争论是反垄断政策的核心分歧。

## 和其他概念的关系

垄断与 [[完全竞争市场]] 是 [[市场结构]] 的两个极端,[[垄断竞争]] 与 [[寡头垄断]] 是介于其间的中间形态。判定与分析工具仍依赖 [[供给与需求]] 与 [[弹性理论]],但企业一阶条件从 P = MC 改为 MR = MC。

垄断的福利损失通过 [[消费者剩余与生产者剩余]] 的几何度量呈现,是反垄断、价格管制等政策的福利依据。[[成本理论]] 中规模经济(LAC 下降)解释了自然垄断为何形成。

跨域:金融领域中 [[投资银行]] 的并购顾问业务、信用评级三巨头(穆迪、标普、惠誉)、清算所、交易所均具显著市场势力;[[金融监管体系]] 在维护金融市场竞争与防止行业垄断方面承担重要功能。[[期权定价]] 中"无套利定价"假设的反面 —— 套利受限,正是金融市场局部市场势力的体现。

[[公司治理结构]] 在垄断企业中尤为重要 —— 缺乏市场竞争纪律时,股东监督、董事会、外部监管成为效率的最后防线。
