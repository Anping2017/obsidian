# 正则表达式 Regular Expression

## 定义

正则表达式(Regular Expression, Regex 或 Regexp)是一种**用形式化语法描述字符串模式**的小型语言。它最初源自数学家 Stephen Kleene 的正则集合理论,通过可计算的方式判断「某字符串是否匹配某模式」「在文本中提取符合模式的片段」「按模式替换」等。

## 核心要点

### 基础语法(共同部分)

| 元素 | 含义 | 示例 |
|---|---|---|
| `.` | 任意单字符(除换行) | `a.c` 匹配 `abc` `axc` |
| `*` | 前一元素零或多次 | `ab*` 匹配 `a` `ab` `abb` |
| `+` | 前一元素一或多次 | `ab+` 匹配 `ab` `abb` |
| `?` | 前一元素零或一次 | `ab?` 匹配 `a` `ab` |
| `[]` | 字符集 | `[abc]` 匹配 a/b/c |
| `[^]` | 排除 | `[^0-9]` 非数字 |
| `^` `$` | 行首、行尾 | `^abc$` 整行匹配 |
| `\d` `\w` `\s` | 数字、单词字符、空白 | - |
| `()` | 分组捕获 | `(ab)+` |
| `|` | 或 | `cat|dog` |
| `{n,m}` | 重复 n 到 m 次 | `a{2,4}` |

### 实现原理两派

| 引擎 | 原理 | 代表 | 特征 |
|---|---|---|---|
| NFA(回溯) | 构造非确定有限自动机,失败回溯 | PCRE、Java、Python `re`、JavaScript | 支持回溯引用 `\1`、前后断言,但有指数级炸裂风险 |
| DFA | 转为确定有限自动机,不回溯 | grep、awk、Go `regexp`、RE2 | 时间线性,不支持回溯引用 |

### 常见用途

- **校验**:邮箱、手机号、密码强度
- **提取**:日志解析、爬虫提取链接、URL 参数
- **替换**:批量重命名、内容清洗
- **分词**:简单分词器
- **路由**:Web 框架 URL 路由、Nginx location

### 容易踩的坑

- **贪婪 vs 非贪婪**:`.*` 默认贪婪,`.*?` 非贪婪
- **回溯炸裂(Catastrophic Backtracking)**:如 `(a+)+b` 在 `aaaaaaaaac` 上指数级时间。生产环境用 RE2 类引擎或限制超时
- **多行模式 / 单行模式**:`m` 标志改变 `^$`,`s` 标志让 `.` 匹配换行
- **Unicode**:`\w` 默认只匹配 ASCII,需 `u` 标志或 `\p{L}` 字符类
- **可读性**:超过 50 字符的正则建议拆解或加注释(`x` 标志支持空白与注释)

## 和其他概念的关系

正则表达式背后的理论是 [[编译原理]] 中形式语言层级最简的「正则语言」(乔姆斯基 Type 3),与有限自动机一一对应。学习正则是入门 [[编译原理]] 的好途径。

[[字符串匹配]] 是更广义的话题,KMP/BM/AC 自动机用于固定模式高速匹配,而正则用于灵活的可参数化模式。

[[文本处理]] 工具(grep、sed、awk、ripgrep)、[[编辑器]](VSCode、Vim、Emacs)、[[日志分析]](ELK、Loki)、[[爬虫]] 都重度依赖正则。

[[安全]] 视角下,正则需防范 ReDoS(正则表达式拒绝服务)攻击;[[数据校验]] 推荐用专门库(如 `validator.js`)而非手写正则,以减少错误。
