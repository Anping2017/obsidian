# 货币政策传导机制

## 定义

**货币政策传导机制**是 [[中央银行]] 的政策工具(利率、准备金、公开市场操作)如何转化为对产出、就业、通胀的实际影响。这不是一步直接关系,而是经过多个金融与实体环节的链式传导。

## 核心要点

### 五大传导渠道

1. **利率渠道**:政策利率 → 市场利率 → 投资/消费成本 → 总需求
2. **信贷渠道**:银行准备金 → 信贷可得性 → 实体融资 → 投资
3. **资产价格渠道**:利率 → 股价、房价 → 财富效应、Tobin's Q → 消费/投资
4. **汇率渠道**:利差 → 资本流动 → 汇率 → 净出口
5. **预期渠道**:政策信号 → 通胀预期 + 增长预期 → 当下决策

### 传导效率的影响因素

- 金融市场发达程度
- 银行体系健康度
- 企业与居民对利率的敏感度
- 预期管理的可信度

### 现实复杂性

- **流动性陷阱**:利率接近零时利率渠道失效(2008 后欧美、长期日本)
- **零利率下限(ZLB)**:刺激转向 QE、前瞻指引等非传统工具
- **传导滞后**:政策到效果通常 6-18 个月
