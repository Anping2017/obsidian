# 内链优化

## 定义

内链优化(Internal Linking Optimization)是通过设计、布局、调整网站内部页面之间的超链接,把有限的链接权益(Link Equity / PageRank)分配到最重要的页面、引导搜索引擎爬虫高效抓取关键页面、并改善用户在站内的发现路径。它是 [[页面SEO]] 与 [[技术SEO]] 的交集,被严重低估却投入产出比极高的战术——大型站点的搜索流量,30-50% 取决于内链结构。

## 核心要点

**内链的三重作用**:

1. **权重传递**:外链给单页带来的权重通过内链分发,深页面也能获得排名能力。
2. **爬虫引导**:[[Googlebot]] 通过内链发现新页 / 重抓页面;深度过深(> 4 跳)的页面爬取频率显著低。
3. **用户路径**:相关链接降低跳出率,提升页面浏览数(PV/UV)。

**类型与位置**:

- **导航栏内链**:全站权重最高,但要谨慎(只放最关键的 5-7 项)。
- **面包屑(Breadcrumb)**:层级清晰,SEO 必备 + Schema 标记。
- **正文锚文本内链**:权重传递最自然,锚文本传递主题信号最强。
- **侧边栏 / 相关推荐**:相关性次高,自动化生成。
- **页脚链接**:权重低,主要用于次要页(About、Privacy、Contact)。
- **HTML 站点地图**:深度站点必备,辅助爬虫发现。

**锚文本(Anchor Text)策略**:

- **精确锚文本**(Exact Match):"链接建设"链向《链接建设指南》。优:主题信号强;缺:过度优化容易被反作弊。
- **部分匹配**:"链接建设的几种方法"。
- **品牌锚**:"我们的指南"。
- **裸 URL**:"https://example.com/link-building"。
- **泛锚**:"点击这里"——禁用,无 SEO 价值且不友好。

**最佳实践原则**:

1. **重要页 ≤ 3 跳深度**:从首页到任意核心页 ≤ 3 次点击。
2. **每页内链 50-100 条**:不宜过多稀释权重,但电商分类页需要 100+。
3. **避免孤儿页(Orphan Page)**:每个有价值的页都至少被 1 个内链指到。
4. **从权重高页指向权重低页**:把流量与权重导向新页 / 待提升页。
5. **使用 Hub Pages(枢纽页)**:主题集合页统一收集相关内容并互链。
6. **HTML 链接**(`<a>` 标签),不要 JS / Onclick——爬虫无法或低优先级抓取。

**进阶技术**:

- **Pillar-Cluster 互链**:见 [[内容集群Topic Cluster]]。
- **上下文相关链接**:相关推荐用算法(基于关键词、用户行为、嵌入向量相似度)动态生成。
- **Skip Navigation Links**:页面顶部加"Skip to content"对 SEO 影响小但提升可访问性。
- **NoFollow / NoOpener / NoReferrer**:对登录、用户生成内容、不信任站点使用 nofollow,但**注意**:站内一般不用 nofollow 屏蔽爬虫,会浪费 PageRank。
- **Hreflang 内链**(国际站):多语言版本互相 hreflang 链接,见 [[国际SEO]]。

**审计工具**:

- **Screaming Frog SEO Spider**:抓取全站,可视化内链分布,识别孤儿页与深度过深页。
- **Ahrefs Site Audit / SEMrush Site Audit**:云端版同等能力。
- **Google Search Console 内部链接报告**:看 Google 实际识别的内链分布。
- **Sitebulb / Oncrawl**:大型站点专用,高级图分析。

**反模式**:

- 把 nofollow 滥用于内链 → 浪费 PageRank。
- 锚文本全部精确匹配 → 反作弊算法识别。
- 全自动相关推荐(语义不强)→ 用户与爬虫都受困扰。
- 不更新内链(发新文章不反链相关老文)→ 错失互联机会。
- 把"导航 + 页脚"塞 200+ 链接 → 稀释权重,触发垃圾链接惩罚。

## 和其他概念的关系

内链优化是 [[页面SEO]] 与 [[技术SEO]] 的协同战术,与外部 [[链接建设]] 互补——外链带权重进站点,内链分发权重到目标页。它是 [[内容集群Topic Cluster]] 架构的实施基础,也是 [[网站审计]] 的高频检查项。

它与 [[Google搜索工作原理]] 中的爬取与索引环节深度耦合——内链是搜索引擎理解站点结构的核心信号。在 [[关键词研究]] 后,内链锚文本是把"目标关键词"信号注入页面的最自然方式。

[[Core Web Vitals]] 中的 LCP 与导航效率间接受到内链质量影响——优秀的内链结构让用户少跳转、更快找到所需。在 [[本地SEO]] 中,服务页 → 地区页的内链对 [[Local Pack本地包|Local Pack]] 排名也有贡献。
