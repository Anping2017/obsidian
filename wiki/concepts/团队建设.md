# 团队建设

## 定义

**团队建设**(Team Building)是通过**结构设计、关系培育、流程优化、能力补齐与文化塑造**,打造能高效协作完成共同目标的高绩效团队的系统过程。它不是一次拓展训练,而是 [[领导力]] 的长期实践,是 [[组织行为学]] 与 [[管理职能]] 中"领导"环节的核心内容之一。

## 核心要点

### Tuckman 团队发展五阶段

经典模型(布鲁斯·塔克曼,1965/1977):

1. **形成期**(Forming):成员相互试探、目标模糊、依赖领导
2. **冲突期**(Storming):分歧浮现、风格冲突、成员对角色与权威质疑
3. **规范期**(Norming):规则建立、信任增长、共同行为模式形成
4. **执行期**(Performing):高效协作、自驱、目标导向
5. **解散期**(Adjourning):任务结束,情感告别

### 高绩效团队的关键要素

谷歌"亚里士多德计划"研究 180 个团队后总结的五要素:
- **心理安全**:敢说真话、敢冒险、敢承认错误(最关键!)
- **可靠性**:成员都能按时交付高质量
- **结构与清晰**:角色、目标、计划清晰
- **意义感**:工作对个人有意义
- **影响力**:工作能产生实际成果

### 团队角色(贝尔宾模型)

九种互补角色:塑造者、监督者、协调者、智多星、外交家、执行者、完美主义者、团队工作者、专业专家。一个高绩效团队需多种角色平衡。

### 常见障碍(兰西奥尼"五大功能障碍")

倒金字塔的五层:
1. **缺乏信任** → 隐藏弱点
2. **惧怕冲突** → 表面和谐
3. **缺乏承诺** → 模糊决策
4. **逃避问责** → 标准低
5. **不重视结果** → 个人目标凌驾团队

### 实操方法

- **共同目标**:OKR、KR 共建
- **明确角色**:RACI 矩阵
- **定期回顾**:Retrospective、复盘
- **冲突管理**:正面冲突 vs 负面冲突的引导
- **关系培育**:工作之外的连接(共同就餐、户外活动)
- **能力建设**:培训、轮岗、配对编程
- **领导风格**:[[变革型领导]] 与 [[情境领导理论]] 灵活切换

### 远程时代的挑战

- 弱化的非正式交流
- 信任建立成本上升
- 异步协作的工具与文化
- 包容性面临新考验

## 和其他概念的关系

- 是 [[领导力]] 在团队层面的具体实践
- 与 [[激励理论]] 在动力机制上深度耦合
- [[变革型领导]]、[[情境领导理论]] 提供风格指导
- 体现于 [[组织行为学]] 群体层面研究
- 与 [[组织文化]] 互为骨架与血肉
