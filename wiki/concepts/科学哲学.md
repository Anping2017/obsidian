# 科学哲学

## 定义

**科学哲学**(Philosophy of Science)是反思**科学的本质、方法、知识地位、理论变迁、与非科学的划界**的哲学分支。它既属于 [[认识论]] 的一部分(科学知识何以为真),也属于 [[形而上学]] 的延伸(科学描述的世界是真实的吗)。

经典议题:**什么是科学?科学如何进步?科学知识为何可信?科学与伪科学如何划界?**

## 核心要点

### 主要流派与代表人物

| 学派 | 代表 | 核心命题 |
|---|---|---|
| **逻辑实证主义** | 维也纳学派、Carnap、Schlick | 有意义的命题=可经验证实;形而上学是无意义 |
| **批判理性主义** | [[波普尔]] | 科学=可证伪;归纳无效,猜想—反驳 |
| **范式论** | [[库恩]] | 常规科学—危机—革命;[[范式]] 不可通约 |
| **研究纲领** | Lakatos | 硬核 + 保护带;进步 vs 退化研究纲领 |
| **方法多元主义** | Feyerabend | "Against Method";Anything Goes |
| **科学实在论** | Putnam、Boyd | 成熟科学理论近似真;实体存在 |
| **社会建构论** | Bloor、Latour | 科学知识是社会过程的产物 |
| **新实验主义** | Hacking | 实验有自己的生命,理论之外 |
| **结构实在论** | Worrall | 理论的结构传承,本体不传承 |

### 几个核心问题

#### 1. 划界问题(Demarcation)

科学与非科学的边界:
- **逻辑实证主义**:可经验证实 → 但全称命题永远无法证实
- **波普尔可证伪**:能被证伪即科学 → 但被反复证伪后科学家也保留理论
- **库恩**:范式内的常规研究即科学 → 但范式外的革命算什么?
- 现代:多准则、家族相似,见 [[证伪原则]]

#### 2. 归纳问题(Hume Problem)

[[休谟]] 指出归纳推理无逻辑保障(过去如此不必然预示未来)。
- 波普尔:科学不靠归纳,靠演绎与反驳
- 贝叶斯:用概率版本的归纳替代

#### 3. 不可通约性(Incommensurability)

库恩主张不同范式间术语含义、研究问题、衡量标准都变了,无法直接比较。这一立场被批评导致相对主义,但也揭示了科学史的复杂性。

#### 4. 理论选择(Underdetermination)

同一组数据可被多个理论解释(Quine-Duhem),科学实践中如何择优?
- [[奥卡姆剃刀]]:简单优先
- 美感与统一性
- 解释力与预测精度
- 实验经济

#### 5. 科学进步与实在性

成熟科学理论是真还是仅"有用"?
- **实在论**:理论实体(电子、夸克)真实存在
- **反实在论 / 工具主义**:理论是预测工具
- **悲观元归纳**:历史上多数被赞美的理论后被推翻 → 现在的也可能是错

### 与其他哲学领域的交叉

- [[形而上学]]:理论实体是否真存在
- [[认识论]]:科学知识是否优于其他知识
- [[伦理学]]:科学家责任、科技伦理
- [[政治哲学]]:科学与民主、科学共识与公共政策
- [[语言哲学]]:理论术语的意义

### 与具体科学的关系

每门科学都有自己的科学哲学:
- 物理哲学(决定论、量子力学诠释)
- 生物哲学(还原论 vs 突现、物种、目的论)
- 心理学/认知科学哲学(意识、表征)
- 社会科学哲学(自然主义 vs 解释学)
- AI 哲学(智能、意识、对齐)

## 应用场景

- **学术训练**:博士生方法论与认识论基础
- **科技伦理**:从 Galilei 案到基因编辑、AI 风险
- **公共政策**:科学共识如何转为政策(气候、疫苗、AI 安全)
- **管理与商业**:决策中区分科学结论与伪科学,见 [[批判性思维]]
- **研究设计**:可证伪、对照、可复制是核心基础

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **天真实证主义** | 数据自己说话,忽视理论负载 |
| **解构主义滥用** | 以"建构"否定科学客观性 |
| **划界绝对化** | 划界本身是程度问题 |
| **过度普遍化** | 物理学方法直接套到社会科学 |
| **范式概念滥用** | 把"换个角度"叫"范式转换" |

## 与其他概念的关系

- 代表人物:[[波普尔]]、[[库恩]],以及 [[休谟]]、[[康德]] 的认识论遗产
- 核心概念:[[科学方法]]、[[证伪原则]]、[[归纳推理]]、[[演绎推理]]、[[演绎与归纳]]
- 与 [[认识论]]、[[形而上学]]、[[本体论]] 父子相生
- [[奥卡姆剃刀]] 是科学理论选择启发
- [[第一性原理]] 是科学方法的元层应用
- [[决定论]] 与 [[自由意志]] 是物理哲学经典议题
- 与 [[技术哲学]] 协同处理 AI、生物技术
- [[多元思维模型]] 在某种意义上是科学哲学方法多元化
- [[批判性思维]] 是其方法论遗产
