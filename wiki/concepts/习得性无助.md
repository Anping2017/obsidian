# 习得性无助

## 定义

**习得性无助**(Learned Helplessness)是 [[塞利格曼]] 与 Steven Maier 在 1967 年通过狗的电击实验发现的现象:**反复经历不可控的负面事件后,个体即使在能够逃避的新情境中也会放弃尝试**。这是抑郁的认知—动机模型核心,深刻塑造了 [[认知行为疗法]]、 [[积极心理学]]、教育、临床实践。

## 关键实验

### 狗的电击实验(1967)

- **第一阶段**:三组狗
  - 组 A:可通过按板逃避电击
  - 组 B:无论怎样都不能逃避(与 A 同步受电)
  - 组 C:不接受电击(对照)
- **第二阶段**:所有狗放入新的双室箱,跳过矮墙即可逃避电击
  - 组 A:正常学会跳过墙
  - 组 B:**很快放弃**,蹲在那受电
  - 组 C:正常学会
- **结论**:组 B 在第一阶段"**学到了无能为力**"

### 三联设计(triadic design)

- 同步两组之间唯一不同是**控制感**
- 排除"电击量""疲劳"等替代解释
- 这是**控制感本身**的效应

### 推广到人

- 后续研究在人类用噪音、字谜等非电击实验
- 同样观察到**习得性无助**反应

## 三大缺陷

塞利格曼总结习得性无助的三个特征:

1. **动机缺陷**:不再尝试
2. **认知缺陷**:即使有解决方案也学不到
3. **情绪缺陷**:抑郁情绪、被动

## 抑郁的认知模型

- 类比抑郁症患者:**反复经历失败 → 形成"我无能"信念 → 不再尝试 → 真的失败 → 强化信念**
- 这是**抑郁循环**
- 治疗:打破循环,重建**控制感**与**乐观解释风格**
- 详见 [[塞利格曼]]、 [[认知行为疗法]]

## 解释风格的修正(1978)

塞利格曼意识到狗与人都不是无差别的"无助":有些人在不可控经验后仍然韧性强。关键在**解释风格**:

| 维度 | 习得性无助倾向 | 韧性倾向 |
|---|---|---|
| 内/外因 | 内部("我不行") | 外部("情境如此") |
| 稳/暂时 | 稳定("永远") | 暂时("这次") |
| 普/特殊 | 普遍("什么都不行") | 特定("这件不行") |

**悲观三联**(内、稳、普)**预测抑郁**。这是后来 [[积极心理学]] 的雏形。

## 神经机制

- Maier 后期发现:**关键脑区不是大脑皮层,而是中缝核(dorsal raphe)的 5-HT 系统**
- 实际上"被动"是默认反应,**控制经验**激活皮层抑制 5-HT
- 这是 50 年后的"反转"——**我们不是学会无助,而是学会了控制**
- 影响抑郁的神经科学理解

## 应用领域

### 临床心理学

- **抑郁症**认知理论核心
- **PTSD** 中"无可控感"的核心
- **慢性疼痛**患者的"放弃"模式
- 治疗目标:重建**自我效能**(详见 [[班杜拉]])与控制感

### 教育

- 学生反复失败 → 习得性无助 → 厌学
- 干预:**任务分解、可控成功体验、归因再训练**
- 与"成长心态"(Dweck)研究衔接

### 组织管理

- 员工反复被否定 → 不再提建议、被动应付
- "**沉默组织**"的形成
- 影响 [[组织文化]]、 [[领导力]] 设计
- **变革型领导**(详见 [[变革型领导]])试图打破

### 健康行为

- 长期病人感觉"治不好" → 不再配合
- 干预:让其参与决策、看到改善

### 政治与社会

- 弱势群体面对结构性不公 → "**我个人努力没用**"
- 系统性改变需要打破集体习得性无助

### 营销与产品

- 用户反复尝试某功能不成功 → 放弃使用
- UX 设计避免"用户习得性无助"
- **建立小成功路径**

## 与相邻概念的关系

### vs [[认知失调]]

- 都涉及认知—行为不一致
- 习得性无助:**控制感**的丧失
- 认知失调:**信念**之间的冲突

### vs [[依恋理论]]

- 早期不安全依恋可视为习得性无助的关系版本
- 婴儿反复求关注无回应 → 学到"关系无用"

### vs [[卡尼曼]] 系统 1/2

- 习得性无助是系统 1 的快速被动模式
- 认知干预试图调动系统 2 重新评估

### vs 韧性(Resilience)

- 韧性是习得性无助的反面
- 都可被习得
- 详见 [[积极心理学]]

## 文化批评

- 个体主义的归因可能忽视**结构性**因素
- "**指责受害者**"风险:让被压迫者承担"无助责任"
- 当代讨论需要平衡**个体能动性**与**结构限制**

## 和其他概念的关系

- 创始人:[[塞利格曼]] 与 Maier
- 是 [[积极心理学]] 的反向起点(从研究无助到研究幸福)
- 与 [[认知行为疗法]]、 [[依恋理论]]、 [[防御机制]] 是临床心理学核心
- 与 [[班杜拉]] 自我效能形成对照(无助 vs 效能)
- 与 [[斯金纳]] 操作性条件反射有关(无强化 → 行为消退)
- 与 [[认知偏差]]、 [[认知失调]] 在认知扭曲分析上相关
- 与 [[损失厌恶]]、 [[过度自信]] 等行为决策概念可作"决策病理"对照
- 与 [[领导力]]、 [[变革型领导]]、 [[组织文化]]、 [[激励理论]] 中"赋能"主题对立面
- 与 [[消费者行为]]、 [[转化漏斗]] 中"用户放弃"机制相关
- 与 [[决定论]]/[[自由意志]] 议题:学到的"无能"是真还是错
- 与 [[佛家]] "执着痛苦"、 [[儒家]] "天行健"形成跨文化对话
