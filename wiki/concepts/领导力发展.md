# 领导力发展

## 定义

**领导力发展(Leadership Development)** 指系统性地培养个体与组织领导能力的过程,涵盖意识唤醒、能力建设、行为塑造、绩效提升的多层面工作。

它区别于"管理培训":管理培训聚焦工具技能,领导力发展更涉及自我认知、价值观、心智模式、行为改变。

## 核心要点

### 70-20-10 学习法则(McCall & Lombardo, CCL)

研究显示成功领导者能力发展来源比例:

| 来源 | 比例 | 内涵 |
|---|---|---|
| **挑战性工作** | 70% | 真实任务历练 |
| **他人(关系)** | 20% | 上级、同侪、导师反馈 |
| **正式培训** | 10% | 课程、阅读 |

这颠覆了"领导力靠上课"的迷思——**领导力主要在工作中练出来的**。

### 领导者能力金字塔(简化模型)

```
        价值观/品格(为什么领导)
         ↑
       自我认知与情商(领导自己)
         ↑
       人际能力(领导他人)
         ↑
       团队领导(领导团队)
         ↑
       组织领导(领导组织)
```

下层是上层的基础。多数领导者能力差距出在自我层面。

### 关键发展工具

| 工具 | 用途 |
|---|---|
| **360 度反馈** | 多视角评估,识别盲区 |
| **个人发展计划(IDP)** | 个性化发展路径 |
| **教练(Coaching)** | 一对一启发与陪伴 |
| **导师(Mentoring)** | 资深者经验传承 |
| **行动学习(Action Learning)** | 真实问题 + 团队 + 反思 |
| **领导力评估中心(AC)** | 模拟情境多维评估 |
| **轮岗与拉伸任务** | 跨职能历练 |
| **高管教练(Executive Coaching)** | 顶层个性化 |

### Kouzes-Posner 五种领导实践

研究上千案例提炼五项核心实践:

1. **以身作则(Model the Way)** - 言行一致
2. **共启愿景(Inspire a Shared Vision)** - 描绘未来
3. **挑战现状(Challenge the Process)** - 探索创新
4. **使众人行(Enable Others to Act)** - 协作授权
5. **激励人心(Encourage the Heart)** - 庆祝肯定

每项又对应具体行为,可被发展。

### 领导者发展阶段(Bass & Avolio)

| 阶段 | 特征 | 重点 |
|---|---|---|
| 初级管理 | 监督任务 | 计划、组织、控制基础 |
| 中级 | 部门管理 | 跨职能协调、资源争夺 |
| 高级 | 业务管理 | 战略制定、外部应对 |
| 高管 | 公司层 | 文化塑造、未来设计 |

每阶段要求的能力组合不同,**晋升不当 = "彼得原理"**(被提升到无能位置)。

### 高潜力人才识别(HiPo)

九宫格(9-Box Grid)模型:绩效×潜力 → 9 类人才,聚焦右上角(高绩效高潜力)做加速培养。

潜力(Potential)三要素(Korn Ferry):

- **学习敏锐度(Learning Agility)**:从经验中快速学习
- **驱动力(Drive)**:追求卓越的内在动力
- **领导能力(Leadership Capacity)**:复杂情境的领导能力

### 继任规划(Succession Planning)

针对关键岗位提前培养接班人:

- **关键岗位识别**:CEO、CFO、关键业务线
- **接班人池**:1-2 个 ready now,3-5 个 ready in 1-2 years
- **加速发展**:轮岗、教练、关键项目
- **应急计划**:突发情况下的过渡安排

### 领导力发展的失败原因

- **培训化**:只上课不练手,违反 70-20-10
- **断点式**:一次集训后无后续
- **不与战略挂钩**:发展通用而非战略所需能力
- **不评估效果**:停留 Kirkpatrick L1 反应
- **个人努力 vs 组织支持错配**:学了用不上

## 和其他概念的关系

- 与 [[人力资源管理]] 中 [[培训与发展体系]] 重叠但更聚焦领导层
- 服务于 [[战略执行]] 与 [[战略转型]] 的领导力前提
- 是 [[领导力理论演进]] 的应用面
- 通过 [[绩效管理]] 与 [[薪酬体系设计]] 系统支持
- 与 [[组织文化]] 互为塑造——文化决定领导风格,领导塑造文化
- 跨国企业领导力发展涉及 [[跨文化领导力]]
- 是 [[管理者角色]] 与 [[管理职能]] 的能力建设面
- 高管教练领域兴起,与心理学(尤其 [[卡尼曼]] 决策研究)交叉
- [[组织学习]] 与领导力发展互为前提
- 教练式领导(Coaching as Leadership)兼顾领导与发展
