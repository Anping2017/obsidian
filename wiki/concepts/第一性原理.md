# 第一性原理

## 定义

**第一性原理**(First Principles)指**从最基本、不可再还原的真理出发,通过演绎构建结论**的思维方式。源自 [[亚里士多德]] 的"第一哲学"中"那些不能再被推导出的命题",在工程、物理、商业领域被广泛应用,埃隆·马斯克通过公开倡导使其再度普及。

## 核心要点

### 与"类比思维"的对比

| 类比思维 | 第一性原理 |
|---|---|
| 既有方案微调 | 拆解到根基重新组合 |
| 速度快 | 慢但可能颠覆 |
| 受现状束缚 | 跳出框架 |
| 适合常规问题 | 适合突破问题 |

### 操作步骤

1. **质疑既有结论**:为什么大家都这么做?
2. **拆解到底层**:这个结论由哪些更基本的事实推出?
3. **检验底层假设**:这些事实是真的吗?现在还成立吗?
4. **从底层重新构造**:用新方法重组,可能得出非常规答案

### 经典案例:特斯拉电池成本

- **类比思维**:电池过去 600 美元/kWh,降不下来
- **第一性原理(马斯克)**:
  - 拆解电池构成:钴、镍、铝、钢、聚合物分隔膜
  - 计算原材料成本:从伦敦金属交易所约 80 美元/kWh
  - 结论:差价是制造、规模、设计 —— 都是可优化变量
  - 行动:超级工厂、垂直整合 → 大幅降本

### 哲学源头

- [[亚里士多德]]:第一哲学研究"是之为是",寻找最基本范畴
- 第一原理(prōtē archē):一切证明的起点,本身不可证
- 笛卡尔:"我思故我在"作为不可怀疑的第一原理
- 物理学:守恒定律、对称性是物理的"第一原理"

### 应用领域

| 领域 | 应用 |
|---|---|
| **物理工程** | 从守恒律推导设计 |
| **创业** | 不模仿既有商业模式,问"用户最根本的需求" |
| **投资** | 估值不靠倍数对比,直接算自由现金流 |
| **学习** | 不机械背公式,理解推导根基 |
| **决策** | 不被"惯例"绑架 |

### 局限与陷阱

- **耗时**:每事都从头推导,效率低
- **基础知识门槛**:必须真懂底层才能推
- **过度自信**:误以为自己已到第一性,其实还有更深一层
- **与类比互补**:大多数日常用类比即可,关键决策用第一性

### 与"奥卡姆剃刀"的关系

- **奥卡姆剃刀**:在解释力相同的多个假设中选最简单的
- **第一性原理**:从最基本前提推导
- 二者互补:剃刀防止假设过多,第一性确保推理彻底

## 和其他概念的关系

- 哲学源头是 [[亚里士多德]] 与 [[笛卡尔]]
- 是 [[多元思维模型]] 中重要的方法论原理
- 与 [[逻辑]] 中的演绎推理直接关联
- 与 [[逆向思维]] 互补 —— 第一性自底向上,逆向自顶往下
- 与 [[批判性思维]] 共享"质疑既有结论"的精神
- 与 [[认识论]] 中"知识基础"问题相关
- 在 [[认知偏差]] 对治中特别有效:打破锚定与确认
- 与 [[现金流折现模型]] 相通:估值的第一性是未来现金流贴现
- [[战略管理]]:用第一性原理重新追问行业基本结构和价值假设
- [[商业模式画布]]:从用户根本需求出发设计模块,而非模仿同行
- [[价值链分析]]:拆到环节本质重构成本与价值创造逻辑
