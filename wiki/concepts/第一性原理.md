# 第一性原理

## 定义

**第一性原理**(First Principles)指**从最基本、不可再还原的真理出发,通过演绎构建结论**的思维方式。源自 [[亚里士多德]] 的"第一哲学"中"那些不能再被推导出的命题",在工程、物理、商业领域被广泛应用,埃隆·马斯克通过公开倡导使其再度普及。

## 历史:三幕戏

### 第一幕:亚里士多德发明这个词(前 384-前 322)

[[亚里士多德]] 面对一个困境:任何证明都有前提,前提又需要前提,无穷无尽。要么知识是空中楼阁,要么必须有不能再被推导出的起点——他把这种起点叫 πρώτη ἀρχή(prōtē archē),拉丁化是 *prima principia*,字面就是"第一原理"。

亚里士多德的版本是**形式的、关于世界的**:
- 逻辑公理(同一律 / 矛盾律 / 排中律)
- 四因说(质料 / 形式 / 动力 / 目的)
- "不动的推动者"作为因果链终点

### 第二幕:笛卡尔把它从形而上学搬进认识论(1596-1650)

亚里士多德问的是"世界的基本结构是什么"。[[笛卡尔]] 反过来问:"我们怎么知道任何东西?"

笛卡尔的方法怀疑实验:感觉会骗我、梦境会骗我、可能有恶魔在骗我——什么都怀疑完之后,**唯一无法怀疑的,是"我正在怀疑"这件事本身**。所以"我思故我在"(Cogito ergo sum)。

这一步是哲学史的转折:**第一原理从"世界的起点"变成了"知识的起点"**。从这句话开始,笛卡尔重建了整个现代 [[认识论]]。

### 第三幕:马斯克把它从哲学搬进工程(2010s-)

埃隆·马斯克通过一系列采访普及"第一性原理思维",标志案例就是下面"经典案例"段那个电池故事。

但要注意:马斯克版本和哲学版本**有微妙不同**——
- **哲学版**:寻找永恒不变的逻辑/认识起点
- **工程版**:寻找**当前情境下**的物理/经济/化学基本量

工程版是个**约简版**:它要求你拆到"原子事实"(原料价格、物理常数、生物学基础),但不要求你拆到笛卡尔"我思"那么深。这种约简让方法在商业实战中可用,但也带来"争议"段的几个质疑。

**三幕递进**:亚里士多德(关于世界)→ 笛卡尔(关于知识)→ 马斯克(关于工程)。每一幕都是前一幕的应用化,但也是约简化——**离纯粹哲学越远,可操作性越强,但也越接近"营销话术"**。

## 核心要点

### 与"类比思维"的对比

| 类比思维 | 第一性原理 |
|---|---|
| 既有方案微调 | 拆解到根基重新组合 |
| 速度快 | 慢但可能颠覆 |
| 受现状束缚 | 跳出框架 |
| 适合常规问题 | 适合突破问题 |

### 操作步骤

1. **质疑既有结论**:为什么大家都这么做?
2. **拆解到底层**:这个结论由哪些更基本的事实推出?
3. **检验底层假设**:这些事实是真的吗?现在还成立吗?
4. **从底层重新构造**:用新方法重组,可能得出非常规答案

### 经典案例:特斯拉电池成本

- **类比思维**:电池过去 600 美元/kWh,降不下来
- **第一性原理(马斯克)**:
  - 拆解电池构成:钴、镍、铝、钢、聚合物分隔膜
  - 计算原材料成本:从伦敦金属交易所约 80 美元/kWh
  - 结论:差价是制造、规模、设计 —— 都是可优化变量
  - 行动:超级工厂、垂直整合 → 大幅降本

### 哲学源头

- [[亚里士多德]]:第一哲学研究"是之为是",寻找最基本范畴
- 第一原理(prōtē archē):一切证明的起点,本身不可证
- 笛卡尔:"我思故我在"作为不可怀疑的第一原理
- 物理学:守恒定律、对称性是物理的"第一原理"

### 应用领域

| 领域 | 应用 |
|---|---|
| **物理工程** | 从守恒律推导设计 |
| **创业** | 不模仿既有商业模式,问"用户最根本的需求" |
| **投资** | 估值不靠倍数对比,直接算自由现金流 |
| **学习** | 不机械背公式,理解推导根基 |
| **决策** | 不被"惯例"绑架 |

### 局限与陷阱

- **耗时**:每事都从头推导,效率低
- **基础知识门槛**:必须真懂底层才能推
- **过度自信**:误以为自己已到第一性,其实还有更深一层
- **与类比互补**:大多数日常用类比即可,关键决策用第一性
- **"假到底层"陷阱**:你以为拆到底了,其实还有更深一层。例:"用户根本需求是省钱"——但"省钱"还不是第一性,往下还有"省钱是为了感觉自己理性""为了对家人有交代"。**心理学的水比经济学深一层。**
- **库恩问题**:即使真拆到底,你的"底"也是当前范式下的底。重大决策留 30% 缓冲应对范式可能转变(详见下方"争议"段第 2 条)。
- **与 [[二阶思维]] 的张力**:第一性原理是**自底向上**(从根基推上去),二阶思维是**自顶向下**(从行动推后果)。两者互补但有时拉扯——把每阶后果都拆到第一性会指数爆炸。**实务建议**:第一性原理定**方向**,二阶思维评**风险**,[[逆向思维]] 找**陷阱**——三个工具不要混用,用错就互相打架。

### 与"奥卡姆剃刀"的关系

- **奥卡姆剃刀**:在解释力相同的多个假设中选最简单的
- **第一性原理**:从最基本前提推导
- 二者互补:剃刀防止假设过多,第一性确保推理彻底

## 争议

### 1. 真方法,还是事后合理化?

最常见的批评:很多人(包括用马斯克自己例子的人)是**先有了直觉答案,再回头找"原料价格"作为'第一性'证据**。真正的第一性推理应该是——在**没有结论倾向**的情况下,从地基出发能否推出非凡结论?这很难。

**实战检验**:下次用第一性原理时,先把直觉答案写下来,然后真的从地基推。看二者差多少——差小就说明你只是在合理化。

### 2. 库恩问题:第一性是相对的,不是绝对的

[[库恩]] 在《科学革命的结构》里指出:不同时代的科学家**眼中的"第一性"是不一样的**。
- 牛顿时代的第一性是绝对时空
- 爱因斯坦时代的第一性是光速恒定
- 量子时代的第一性是测不准

当你以为你拆到"地基"时,**可能只是拆到当前范式下的地基**。第一性原理给你的是**当前最好的答案,不是永恒答案**。

### 3. 哥德尔上限:数学的第一性也有顶

数学是第一性原理最干净的领域:欧几里得从 5 个公理推出整个几何。但 1931 年哥德尔证明:**任何足够强的形式系统,要么不一致,要么不完备**。也就是说,数学这个最纯粹的"第一性领域"也有它够不到的真理,这给"无限拆解"的野心定了上限。

### 4. 与经验主义的根本对立

第一性原理是 [[理性主义]] 的方法——相信纯粹推理能到真理。但 [[休谟]] 和 [[经验主义]] 会反问:**所有"第一原理"都来自经验,你怎么确定它真的是"第一"?**

这是西方哲学的老对立,第一性原理站在理性主义一边,所以继承了理性主义的所有麻烦。

## 和其他概念的关系

- 哲学源头是 [[亚里士多德]] 与 [[笛卡尔]]
- 是 [[多元思维模型]] 中重要的方法论原理
- 与 [[逻辑]] 中的演绎推理直接关联
- 与 [[逆向思维]] 互补 —— 第一性自底向上,逆向自顶往下
- 与 [[批判性思维]] 共享"质疑既有结论"的精神
- 与 [[认识论]] 中"知识基础"问题相关
- 在 [[认知偏差]] 对治中特别有效:打破锚定与确认
- 与 [[现金流折现模型]] 相通:估值的第一性是未来现金流贴现
- [[战略管理]]:用第一性原理重新追问行业基本结构和价值假设
- [[商业模式画布]]:从用户根本需求出发设计模块,而非模仿同行
- [[价值链分析]]:拆到环节本质重构成本与价值创造逻辑
