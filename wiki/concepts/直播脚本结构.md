# 直播脚本结构

## 定义

**直播脚本结构** 是把电商/品牌直播这一原本"即兴"的流程,工程化为 **可复制、可优化、可标准化的内容框架**。它要解决的核心问题:

- 用户进直播间 5 秒不走
- 1 分钟内有兴趣
- 5 分钟内信任建立
- 30 分钟内有转化动作
- 整场不间断刺激

科学的直播脚本能把停留、互动、转化全面拉升,是 [[直播营销]] 区别于"路边吆喝"的关键。

## 核心要点

### 1. 七模块直播脚本结构

```
开场聚人(5 min)
   ↓
留人钩子(3 min)
   ↓
福利暖场(5-10 min)
   ↓
主推商品讲解(15-30 min)← 循环
   ↓
高潮逼单(5-10 min)
   ↓
互动维持(5 min)
   ↓
收场预告(3 min)
```

整场直播以"主推商品讲解 + 高潮逼单"为单元循环 4-8 次,每次 30-60 分钟,1-4 小时一场。

### 2. 各模块要点

#### 开场聚人(5 分钟)

- **明确主题**:今天讲什么
- **强福利预告**:全场最低价 X 单/抽奖 X 份
- **节奏感**:用语速、表情、动作把氛围拉起
- **互动引导**:打"1"在公屏

目标:让进入直播间的人 **不滑走**,Live 数据中"5 秒留存率"是核心。

#### 留人钩子(3 分钟)

- **悬念抛出**:今天有 1 款绝对让你尖叫的产品
- **限定福利**:停留 X 分钟解锁福利
- **倒计时**:5 分钟后整点抽奖

目标:让用户 **愿意停留 5-10 分钟**,信任建立的最低门槛。

#### 福利暖场(5-10 分钟)

- **小额福袋**:门槛低,激发参与
- **免单/秒杀**:把直播间气氛拉到第一高峰
- **新人福利**:首次进入有专享

目标:让用户产生 **互惠义务**(领了福利会留下听产品介绍)。这是 [[互惠原则]] 的应用。

#### 主推商品讲解(15-30 分钟,循环)

经典 **6 步介绍法**:

1. **痛点切入**:你是不是有这个问题?
2. **场景描绘**:某个具体使用场景
3. **产品介绍**:特性 + 优势
4. **品牌背书**:工厂、检测、专利、明星推荐
5. **价格对比**:别处卖 X,我们 Y(锚定效应)
6. **限时限量**:今天只 1000 单

#### 高潮逼单(5-10 分钟)

- **倒计时**:30 秒上链接,30 秒卖完
- **重复关键信息**:价格、规格、链接位置
- **群体效应**:已经卖出 X 单!请没拍到的同学赶紧上车
- **稀缺感**:库存只剩 50,卖完不补

目标:把已心动用户推向 **决策动作**。这是 [[稀缺性]] 与 [[损失厌恶]] 的应用。

#### 互动维持(5 分钟)

- 抽奖、感谢
- 答疑高频问题
- 引导关注、加粉丝团

目标:让转化后的用户 **不离开**,继续看下一波产品。

#### 收场预告(3 分钟)

- 下次直播预告(时间 + 主推产品 + 福利)
- 引导关注以便下次提醒
- 引导加私域(粉丝群)

目标:把直播观众转为 **复访用户与私域用户**,提升 LTV。

### 3. 关键停留指标

| 指标 | 优秀 | 说明 |
|---|---|---|
| **5 秒留存率** | ≥ 60% | 决定 Algorithm 是否给更多流量 |
| **1 分钟留存率** | ≥ 30% | |
| **平均停留时长** | ≥ 3 分钟 | 抖音直播 |
| **GPM(千次曝光成交)** | 高度依赖客单 | |
| **UV 价值** | 单用户产生 GMV | |
| **互动率** | ≥ 5% | 评论 / 点赞 / 加粉丝团 |

### 4. 4321 直播法则

抖音直播的常用结构记忆法:
- **4 类内容**:产品讲解 / 福利环节 / 互动答疑 / 流量话题
- **3 个高潮**:开场福利 / 主推秒杀 / 整点抽奖
- **2 类用户**:进店即转化的成熟用户 / 需要养信的新用户
- **1 个目标**:GMV 最大化

### 5. 不同类型直播的脚本变体

| 类型 | 脚本重心 |
|---|---|
| **品牌专场** | 品牌故事 + 优惠机制 + 极致体验 |
| **达人直播(李佳琦/罗永浩)** | 个人 IP 信任 + 强福利 + 节奏感 |
| **店铺自播** | 高频常态 + 标准化流程 + 转化机制 |
| **新品发布** | 产品力深度 + 首发优惠 + 媒介矩阵导流 |
| **清仓促销** | 价格冲击 + 时间紧迫 + 重复曝光 |
| **教学型直播** | 知识 + 信任 + 软广 |

### 6. 千川投流与脚本配合

[[直播营销]] 在抖音常配合 **千川投流**(付费流量):

```
千川把流量送进直播间(强对比的 5 秒钩子是关键)
   ↓
脚本前 1 分钟决定流量价值
   ↓
留存与互动信号反哺自然流量推荐
   ↓
GMV 提升 → ROI 提升 → 加大千川投放
   ↓ 飞轮
```

脚本的开场与转化节奏直接决定千川投放的 ROI。

## 关键经验

### 节奏感重于内容深度
直播观众阈值低,15 秒不刺激就走。不必每个产品讲透,讲到让人想下单即可。

### 重复关键信息
价格、规格、链接位置每场重复 3-5 次。"忘了听"的用户也能跟上。

### 主播能量管理
4 小时直播极耗能量,顶级主播每 30 分钟有"能量峰值"设计避免后段衰退。

### 即时数据反馈
看停留、点击、加购、成交曲线,实时调整脚本节奏。

### 反 SOP 的"个人色彩"
极端 SOP 反而显得机械,顶级主播在标准结构上加"个人段子""临场反应",让观众记住人。

## 当代演进

- **AI 数字人主播**:24/7 不停播,标准化执行脚本
- **多机位 + 实时切换**:多视角增加沉浸感
- **直播 + 私域闭环**:看完不下单就加群再触达
- **多平台同步直播**:抖音、视频号、小红书、淘宝同步
- **AI 实时辅助**:实时建议主播该说什么、推什么
