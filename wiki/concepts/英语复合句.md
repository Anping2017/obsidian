# 英语复合句

## 定义

复合句(Complex Sentence)由**一个主句**(独立分句)与**一个或多个从句**(从属分句)组成。从句不能独立成句,必须依附于主句承担某个成分(主语、宾语、表语、定语、状语)。复合句是英语区别于汉语"流水句"的关键结构,通过显式从属关系把多重信息组织起来。

## 核心要点

**三大类从句对应三大类成分**

1. **名词性从句**(承担主语 / 宾语 / 表语 / 同位语):
   - *That he came surprised me.*(主语从句)
   - *I know that he came.*(宾语从句)
   - *The fact is that he came.*(表语从句)
   - *The news that he came is true.*(同位语从句)

2. **定语从句**(修饰名词):
   - *The book that I read is interesting.*(限制性)
   - *My brother, who lives in Paris, called.*(非限制性)

3. **状语从句**(修饰整个主句,九大语义类型):
   - 时间(when / while / before / after)
   - 地点(where / wherever)
   - 原因(because / since / as)
   - 目的(so that / in order that)
   - 结果(so...that / such...that)
   - 条件(if / unless / provided)
   - 让步(although / though / even if)
   - 比较(than / as...as)
   - 方式(as / as if / as though)

**从属连词的引导作用**

每种从句都有典型的引导词,这些词不仅起连接作用,还常常充当从句中的成分:
- 关系代词(who / whom / which / that)在定语从句中作主、宾语
- 关系副词(when / where / why)在定语从句中作状语
- 疑问词(what / when / how)在名词性从句中作成分

**从句嵌套**

复合句可以嵌套:*I knew that the man who came was lying about what he had done.*——主句 + 宾语从句 + 定语从句 + 介词宾语从句,四层嵌套。

**复合句与并列句的根本区别**

- **并列句**:两个**对等独立**的分句,by and、but、or 连接
- **复合句**:一个**主导**分句 + 若干**从属**分句,by 从属连词连接
- 标志:能否分裂为两个独立句而不丢逻辑

**主从句的标点**

- 状语从句在主句**前**:从句 + 逗号 + 主句(*When I came, he left.*)
- 状语从句在主句**后**:主句 +(无逗号或视语义)+ 从句(*He left when I came.*)
- 非限制性定语从句:必须用逗号
- 限制性定语从句:不用逗号

## 与其他概念的关系

复合句是 [[英语从句体系]] 的整体框架,内部由 [[英语名词性从句]]、[[英语定语从句]]、[[英语状语从句]] 三大块构成,与 [[英语简单句]]、[[英语并列句]] 形成英语句型四分体系。

## 高频陷阱

- that 引导宾语从句和定语从句的区别:宾语从句中 that 不作成分,定语从句中 that 作主语或宾语
- which 与 that:限制性可用 that 或 which;非限制性只能用 which
- 状语从句的时态规则:主将从现(*I will go when he comes*)
- 让步从句的倒装:*Try as he might, he failed*(尝试如何,他失败了)
