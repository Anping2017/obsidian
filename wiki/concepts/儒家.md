# 儒家

## 定义

**儒家**是由**孔子**(前 551-前 479)创立、绵延 2500 年的中国哲学主流学派,以**仁、义、礼、智、信**为核心德目,主张**修身、齐家、治国、平天下**的实践哲学。它既是哲学思想体系,也是塑造东亚社会伦理与政治制度的现实力量。

## 核心要点

### 五位关键人物

| 人物 | 时代 | 核心贡献 |
|---|---|---|
| **孔子** | 前 551-前 479 | 创建儒学,《论语》 |
| **孟子** | 前 372-前 289 | 性善论、仁政、《孟子》 |
| **荀子** | 前 313-前 238 | 性恶论、礼治、《荀子》 |
| **朱熹** | 1130-1200 | 理学集大成、《四书章句集注》 |
| **王阳明** | 1472-1529 | 心学创始人、知行合一、《传习录》 |

### 核心德目

- **仁**:爱人,"己所不欲,勿施于人";孝悌为本,推己及人
- **义**:正当,事之所宜;在情境中判断对错
- **礼**:社会秩序的规范化;不仅是仪式,更是关系的恰当方式
- **智**:明辨是非,知人识物
- **信**:言行一致,值得信赖

### 中庸

- "执两用中,过犹不及"
- 不是折中主义,而是"恰到好处"
- 与亚里士多德德性的"中道"有相似性
- 修养方法:诚、慎独、时中

### 性善 vs 性恶

| | 孟子 | 荀子 |
|---|---|---|
| **人性观** | 性善论 | 性恶论 |
| **基础** | 四端(恻隐、羞恶、辞让、是非) | 欲望、好利 |
| **修养** | 扩充善端 | 化性起伪(教化) |
| **政治** | 仁政、王道 | 礼治、法治结合 |

### 政治哲学

- **仁政**:以德服人,反对暴政
- **正名**:"君君、臣臣、父父、子子",每个角色应符合其名
- **大同**:理想社会的图景
- **民本**:"民为贵,社稷次之,君为轻"(孟子)

### 宋明理学的转向

- **程朱理学**:"存天理,灭人欲";理在事先,格物致知
- **陆王心学**:"心即理"、"知行合一";理就在心中
- **现代新儒家**:牟宗三、唐君毅 —— 重述儒学应对西方挑战

### 当代张力

- 与 [[西方哲学]] 个人主义的差异:儒家更强调关系性自我
- 与现代民主制度的兼容性:仍是开放议题
- 与 [[佛家]]、[[道家]] 形成"儒释道"三家互补格局
- 在亚洲管理学、人际伦理中仍有强生命力

## 和其他概念的关系

- [[孔子]]、[[孟子]]、[[王阳明]] 等人物各设独立 entity 页
- 与 [[佛家]]、[[道家]]、墨家、法家共同构成 [[东方哲学]] 主线
- 在德性伦理学维度与 [[亚里士多德]]、[[伦理学]] 中的美德论相通
- "中庸"与亚里士多德"中道"互为东西方对应
- 儒家"礼"对社会秩序的关注与韦伯的社会学共鸣
- 性善 vs 性恶之争与西方"自然状态"讨论(霍布斯/卢梭)有平行
- 王阳明"知行合一"影响日本明治维新及现代管理思想
