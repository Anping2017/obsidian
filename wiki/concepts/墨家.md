# 墨家

## 定义

**墨家**(Mohism)是先秦时期由**墨翟**(墨子,约公元前 470-前 391)创立的哲学—社会运动学派。在战国时与 [[儒家]] 并称"显学",《孟子》言"杨朱、墨翟之言盈天下"。其核心是**兼爱、非攻、尚贤、尚同、节用、节葬、非乐、非命、天志、明鬼**十大主张,以**实用、平等、逻辑论证**为特色。

## 核心主张

### 兼爱(Universal Love)

- "**兼相爱,交相利**"
- 反对儒家的差等之爱(亲亲)
- 应**无差别地**爱所有人
- 把战争、压迫归因于不能兼爱
- 此与 [[儒家]] 仁爱形成核心张力

### 非攻

- 反对**侵略战争**(攻);防卫战争(守)合理
- 通过严密论证:杀一人不义,杀百人不义,杀万人之战为何反被歌颂?
- 墨者团体擅守城技术,实际介入战争阻止侵略
- 影响后来反战、和平运动思想资源

### 尚贤、尚同

- **尚贤**:不分出身用人,任贤使能
- **尚同**:统一思想以达治
- 反对世袭贵族制
- 这是中国最早的"任人唯贤"思想

### 节用、节葬、非乐

- **节用**:反对奢侈,以实用为标准
- **节葬**:反对厚葬久丧,儒家三年之丧被批为浪费
- **非乐**:反对奢华礼乐,因其不能解决百姓饥寒
- 体现**功利主义**与平民立场

### 天志、明鬼

- **天志**:天有意志,降福罚恶
- **明鬼**:鬼神存在,作恶必受惩罚
- 用宗教信仰强化道德约束
- 与 [[儒家]] "敬鬼神而远之"形成对比

### 非命

- 反对宿命论
- "**强必富,不强必贫**"
- 强调**人力**与努力的作用
- 与 [[儒家]] "知命"形成对比

## 墨辩(墨家逻辑学)

- 后期墨家在《墨经》《大取》《小取》中发展出**逻辑学**
- 提出**类、故、理**等基本概念,接近"概念—理由—规律"
- **三表法**(本之者、原之者、用之者):判断真理的三个标准——历史经验、感官经验、实用效果
- 有"小故、大故"的因果讨论,接近现代必要/充分条件
- 这是中国古代逻辑学的高峰,与古希腊逻辑、印度因明并称世界三大逻辑系统

## 实用与技术

- 墨家是**工匠学派**:墨翟本人擅长机械,《墨经》记载光学、力学、几何学
- 中国最早讨论小孔成像、杠杆原理
- 体现"知行合一"的工匠传统

## 组织与衰落

- 墨家是**严密组织**:首领"巨子",成员"墨者",纪律严明
- 以技艺与道义自任,"赴汤蹈火,死不旋踵"
- **秦汉以后骤衰**:可能因严密组织违反帝制需要、思想平等冲击宗法
- 至清末才被重新发现(梁启超、章太炎)

## 现代意义

- **平等主义思想资源**:与现代人权、世界主义思想呼应
- **功利主义先驱**:与边沁、密尔形成跨文化对照
- **逻辑学先驱**:中国古代理性思维传统
- **工匠精神**:与现代工程伦理、产品哲学相承
- 当代研究复兴:葛瑞汉(Graham)、史华慈、艾文贺(Ivanhoe)

## 和其他概念的关系

- 与 [[儒家]] 是先秦"两大显学",立场相反
- 与 [[法家]] 都重实用,但法家偏权术,墨家偏道义
- 与 [[道家]] 在反礼乐上有共识,但目标不同
- 与 [[逻辑]]、 [[演绎推理]]、 [[归纳推理]] 在中国古代逻辑层面相承
- 与 [[实用主义]] 在效用判断标准上相通
- 与 [[政治哲学]] 之"任贤使能"主题
- 与 [[伦理学]] 之"普遍主义"立场可对照
- 与西方功利主义、世界主义思想可作跨文化比较
- 历史定位:中国哲学先秦黄金时期重要学派
