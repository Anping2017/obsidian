# 财务管理

## 定义

**财务管理**(Financial Management / Corporate Finance)是企业为实现战略目标,对资金的**筹集、投资、运营、分配**进行规划、组织、协调、控制的管理职能。它不同于 [[财务会计]]("记录"过去)或 [[管理会计]]("辅助"内部决策),核心是**前瞻性的价值创造与风险管理**。

经典三大决策(Brealey & Myers《公司财务原理》):
1. **投资决策**(Investment / Capital Budgeting)— 钱往哪里投
2. **融资决策**(Financing)— 钱从哪里来
3. **股利决策**(Dividend)— 利润如何分配

## 核心要点

### 主要职能

| 职能 | 核心议题 |
|---|---|
| **资本预算** | [[资本预算]],NPV/IRR/回收期评估项目 |
| **资本结构** | [[资本结构]]、[[资本结构理论]],股权 vs 债权 |
| **营运资金管理** | [[营运资金管理]],现金循环周期 |
| **股利政策** | [[股利政策]],分红 vs 回购 vs 留存 |
| **财务规划** | 预算、滚动预测、目标分解 |
| **现金管理** | 现金池、流动性、短期理财 |
| **风险管理** | 汇率、利率、商品对冲 |
| **绩效评估** | KPI、EVA、平衡计分卡 |

### 财务管理的目标

- **传统**:利润最大化(忽视时间与风险)
- **现代**:**股东价值最大化**(NPV、市值)
- **当代**:**利益相关者价值最大化**(ESG、共享价值)

不同治理理念决定了财务管理的边界和约束。

### 核心分析工具

- **[[财务报表分析]]** + [[财务比率分析]]
- **[[杜邦分析]]**:ROE 三因子分解
- **[[现金流折现模型]]**:DCF 价值评估
- **[[相对估值法]]**:PE / PB / EV/EBITDA
- **[[资本成本]]**:WACC 计算
- **[[企业价值评估]]**:DCF + 相对 + 资产基础

### 现金流的中心地位

> "现金为王"——利润是观点,现金是事实。

- **[[自由现金流]]**(FCF)是估值与可持续性核心
- **[[现金流量表]]** 比利润表更难造假
- **现金循环周期**(CCC)= 库存周期 + 应收周期 - 应付周期
- 高速增长企业常因现金流断裂而死

### 资本结构的权衡

[[资本结构理论]] 演进:
1. **MM 定理**:无税无破产成本下结构无关
2. **权衡理论**:税盾收益 vs 财务困境成本
3. **优序融资**:内部留存 → 债务 → 股权
4. **市场择时**:估值高时增发,低时回购

### 风险管理框架

- **市场风险**:汇率、利率、商品价
- **信用风险**:客户违约、坏账
- **流动性风险**:短期偿付能力
- **操作风险**:流程、欺诈、IT 故障
- **战略风险**:行业变迁、技术替代
- 工具:[[衍生品风险管理]]、自然对冲、保险、流动性储备

## 应用场景

- **战略并购**:估值、融资、整合的财务设计
- **IPO 与再融资**:发行结构、定价、路演
- **现金管理**:跨币种、跨国、税务优化
- **业绩管理**:从战略到月度滚动预测
- **创业期财务**:[[估值方法创业期]]、[[精益创业]] 单位经济
- **数字化**:FP&A 数字化、财务共享中心、AI 辅助决策

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **指标至上** | 唯 ROE/利润论致激励错位 |
| **短期主义** | 牺牲研发、品牌、人才换季度数字 |
| **杠杆迷恋** | 顺周期加杠杆,逆周期被清盘 |
| **过度对冲** | 把对冲当投机 |
| **现金/利润混淆** | 利润高但烧现金的"账面繁荣" |
| **代理问题** | 管理层利益偏离股东 |
