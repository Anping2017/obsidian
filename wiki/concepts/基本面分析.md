# 基本面分析

## 定义

**基本面分析**(Fundamental Analysis)研究影响证券**内在价值**的经济、行业、公司因素,目标是找到"价格 < 价值"的买入机会和"价格 > 价值"的卖出机会。代表性投资家:格雷厄姆、巴菲特、林奇。

## 核心要点

### 自上而下 vs 自下而上

- **自上而下**(Top-down):宏观 → 行业 → 公司,从大格局出发选行业再选股
- **自下而上**(Bottom-up):公司 → 行业 → 宏观,以个股为本,聚焦优秀企业

实战中两者常结合:宏观判断方向,个股决定仓位。

### 三层分析

**1. 宏观分析**:GDP、通胀、利率、汇率、政策、人口结构。决定行业景气方向。

**2. 行业分析**:
- 生命周期(导入/成长/成熟/衰退)
- 竞争结构(波特五力)
- 行业驱动因素
- 监管环境

**3. 公司分析**:
- **财务分析**:杜邦分析、现金流质量、资产负债健康度
- **经营分析**:商业模式、护城河、竞争优势
- **管理层评估**:战略、执行力、治理、薪酬一致性
- **估值**:用 [[现金流折现模型|DCF]] 或 [[相对估值法]]

### 关键财务指标

| 类别 | 指标 |
|---|---|
| 盈利能力 | ROE、ROA、净利率、毛利率 |
| 偿债能力 | 资产负债率、利息覆盖倍数、流动比率 |
| 营运能力 | 应收周转、存货周转、总资产周转 |
| 成长性 | 营收增速、净利增速、自由现金流增速 |
| 现金流 | 经营现金流/净利、自由现金流、现金转换周期 |

### 估值方法

- **绝对估值**:[[现金流折现模型|DCF]]、股利贴现模型(DDM)、剩余收益模型
- **相对估值**:PE、PB、PS、EV/EBITDA、PEG
- **资产基础法**:重置成本、清算价值

### 局限性

- 数据滞后性(财报已是历史)
- 假设主观性(增长率、贴现率敏感)
- 时间错配(便宜可以一直便宜,直到催化剂出现)
- 无法解释价格短期波动 —— 这是 [[技术分析]] 的领域

## 和其他概念的关系

- 与 [[技术分析]] 是证券分析的两大流派,互补不互斥
- 估值核心模型见 [[现金流折现模型]] 与 [[相对估值法]]
- 提供 [[资产定价模型|CAPM]] 等模型的输入(预期收益、Beta)
- 是 [[投资决策框架]] 中环境分析与个券选择的关键工具
- [[行为金融学]] 解释为何价格长期可能偏离价值
