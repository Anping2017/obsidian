# BFS 广度优先搜索 Breadth-First Search

## 定义

**广度优先搜索(BFS)**是一种[[图]]/[[树]]遍历算法:从起点出发,**按"距离层数"逐层扩散**地访问所有可达节点。第 1 层是起点的直接邻居,第 2 层是邻居的邻居,以此类推。BFS 用[[队列]]作为辅助数据结构。

时间复杂度 **O(V + E)**,空间 O(V)(队列与已访问标记)。

## 核心要点

### 标准模板

```
def bfs(start):
    visited = {start}
    q = Queue([start])
    while not q.empty():
        node = q.pop()
        for neighbor in node.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                q.push(neighbor)
```

按层访问:在循环每轮记录当前队列大小 layer_size,处理 layer_size 个节点视为一层。

### 关键性质

- **无权图最短路径**:从起点到任意节点,BFS 第一次访问到该节点时的层数 = 最短边数
- **二分图判定**:BFS 时给相邻节点交替染色,若发现冲突则不是二分图
- **连通分量**:从未访问节点开始 BFS,可标记一个连通分量

### BFS 与 [[DFS深度优先搜索]] 对比

| 维度 | BFS | DFS |
|---|---|---|
| 数据结构 | [[队列]] | [[栈]]/递归 |
| 扩展顺序 | 层次 | 深度 |
| 空间(树) | O(宽度) | O(深度) |
| 空间(图最坏) | O(V) | O(V) |
| 解 | 最短路径(无权) | 任一路径 |
| 适合 | 最短路、层序、扩散 | 拓扑、连通、强连通 |

### 经典应用

1. **二叉树层序遍历**:LeetCode 102
2. **网格最短路径**:迷宫、单词梯子(Word Ladder)
3. **多源 BFS**:多个起点同时入队,如"01 矩阵到最近 0 的距离"
4. **双向 BFS**:从起点和终点同时 BFS,在中间相遇,显著降低复杂度
5. **拓扑排序(Kahn 算法)**:每次取入度为 0 的节点
6. **社交网络度数(六度分隔)**
7. **网络爬虫**:广度爬,避免太深陷一个站
8. **病毒/谣言传播模拟**

### 隐式图 BFS

把状态视为图节点:
- **状态空间搜索**:八数码、华容道、魔方,把每个棋面状态作为节点
- **位运算游戏**:状态用整数表示,转移定义边

### 0-1 BFS

边权只有 0 和 1 时,用双端队列(deque):0 边走前面、1 边走后面,O(V+E) 求最短路。是 Dijkstra 的特例优化。

### 双向 BFS

A 从起点 BFS、B 从终点 BFS,各扩一层,直到 A 和 B 队列有交集。最坏复杂度从 O(b^d) 降到 O(b^(d/2))(b 是分支因子,d 是深度)。

## 和其他概念的关系

BFS 是[[图]]算法的两大基石之一(另一是 DFS),也是 Dijkstra 算法的"无权特例"。Dijkstra 用[[堆]]替代[[队列]],就升级为带权最短路径。

BFS 的"按层扩散"思想推广到[[操作系统]]进程调度(轮询)、[[网络协议]]中链路状态广播、消息中间件的 fanout(扇出)。

[[树]]的层序遍历就是 BFS。[[Hash表]]+[[队列]]的组合是 BFS 的工程标配:Hash 表去重已访问节点,队列管理待访问。
