# 索洛模型

## 定义

**索洛模型**(Solow Model)又称**索洛-斯旺增长模型**(Solow-Swan Model),由美国经济学家 **Robert Solow** 与澳洲经济学家 **Trevor Swan** 在 **1956 年** 几乎同时独立提出,是现代经济增长理论的奠基模型。它用一个简洁的新古典生产框架——资本积累、劳动力增长、外生技术进步——解释长期人均产出的演化,得出"**长期增长唯一来源是技术进步**"这一深刻结论。Solow 因此获 **1987 年诺贝尔经济学奖**。

## 核心要点

### 模型设定

总量生产函数:

$$Y = F(K, AL)$$

其中:
- Y = 总产出,K = 资本存量,L = 劳动力,A = 劳动效率(技术)
- F 满足规模报酬不变、对每个要素边际产出递减
- 常用 Cobb-Douglas:Y = K^α (AL)^(1-α)

定义有效劳动单位下的人均量:y = Y/(AL),k = K/(AL),则 y = f(k)。

### 资本积累动力学

资本变化方程(中心方程):

$$\dot{k} = sf(k) - (n + g + \delta)k$$

其中:
- s = 储蓄率
- n = 人口增长率,g = 技术进步率,δ = 折旧率

经济学含义:
- **sf(k)**:每单位有效劳动的储蓄/投资,单位资本增量
- **(n+g+δ)k**:维持 k 不变所需的"补充投资"——人口增长稀释 + 技术进步稀释 + 折旧

### 稳态(Steady State)

当 sf(k\*) = (n+g+δ)k\*,k 不再变化,达到稳态。

**核心结论**:
- **稳态人均产出 y\* 由 s, n, g, δ 决定**
- 储蓄率提高 → 稳态 k\* 提高,但**长期增长率不变**(仍为 g)
- **唯一驱动长期人均产出增长的是技术进步 g**
- 资本积累只能提供"水平效应"(level effect),不能改变"增长率效应"(growth effect)

### 收敛假说

各国若有相同 s, n, g, δ,会**收敛到相同稳态**。
- **绝对收敛**:相同参数下,起点不同最终趋同
- **条件收敛**:控制了不同 s, n, g, δ 后,各国会向各自稳态收敛
- 实证支持条件收敛而非绝对收敛(穷国不会自动追上富国)

### Solow 残差(Solow Residual)

把产出增长拆分:
$$\frac{\dot{Y}}{Y} = \alpha \frac{\dot{K}}{K} + (1-\alpha)\frac{\dot{L}}{L} + \text{残差}$$

残差就是无法用 K、L 增长解释的部分,被解释为**全要素生产率(TFP)增长**——即技术进步。

实证发现:战后美国增长中,Solow 残差占 50% 以上,资本积累远不是主导。这一发现震动了经济学界,把研究重点从资本积累引向技术进步与制度。

### 黄金法则水平(Golden Rule)

最大化稳态消费的资本存量 k_GR:

$$f'(k_{GR}) = n + g + \delta$$

即资本边际产出 = 资本"维持成本"。
- k* < k_GR:储蓄不足,提高 s 可同时提高消费
- k* > k_GR:动态无效率,可降低 s 同时提高消费(这种情况罕见)

### 模型扩展

**1. 增加人力资本**(Mankiw-Romer-Weil 1992):
Y = K^α H^β (AL)^(1-α-β),把人力资本 H 作为单独要素,显著提升解释力。

**2. 开放经济索洛**:加入资本流动,小国可借助外资加速接近稳态。

**3. 内生增长(Romer 1990)**:技术进步不再外生,源自专门 R&D 投入,详见 [[内生增长理论]]。

### 主要贡献

- **第一个严格的总量增长模型**
- **明确指出资本积累的局限**
- **发现 Solow 残差,催生 TFP 研究**
- **启发条件收敛实证文献**
- **为内生增长理论铺路**

### 主要批评

- 技术外生是黑箱,不解释技术从何而来
- 假设单一行业、同质资本,过度简化
- 忽略人力资本(Mankiw 等已修正)
- 忽略制度、政策、地理、文化等深层因素
- 与现实增长经历(东亚奇迹、苏联崩溃)的契合不全

### 政策含义

- 提高储蓄率提高稳态水平,但效果递减
- 长期增长重点应是 **R&D、教育、技术扩散**
- 收敛理论表明,落后国家有"后发优势",但需具备吸收技术的能力
- 对发展援助有启发:钱少不是关键,制度、人力资本与技术吸收力更重要

## 和其他概念的关系

索洛模型是 [[经济增长理论]] 的基石,被 [[内生增长理论]] 内生化技术进步而扩展。它的发现 Solow 残差直接催生现代 TFP 与生产率研究。它建立在 [[生产函数]](尤其 Cobb-Douglas)与新古典厂商最优化之上。其与 [[凯恩斯主义]] 形成短期-长期对照——凯恩斯关心需求侧短期波动,索洛关心供给侧长期增长。它的方法论属于 [[新古典经济学]] 的标志性应用。在 [[发展经济学]] 中,它解释了为何资本援助常常失效——技术与制度才是关键。
