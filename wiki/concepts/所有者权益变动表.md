# 所有者权益变动表

## 定义

**所有者权益变动表**(Statement of Changes in Equity)是反映企业在一个会计期间内**所有者权益各组成项目增减变动情况**的财务报表,作为四大基本财务报表之一(与 [[资产负债表]]、[[利润表]]、[[现金流量表]] 并列)。

它把分散在其他报表里的权益变动信息——综合收益、股东注资、分红回购、会计政策变更等——汇总为一张"权益全景表",回答"股东权益如何从年初变到年末"。

## 核心要点

### 所有者权益的构成

```
所有者权益 = 实收资本(股本)
          + 资本公积
          + 其他综合收益
          + 盈余公积
          + 未分配利润
          - 库存股
```

| 项目 | 含义 |
|---|---|
| 实收资本/股本 | 股东出资形成的注册资本 |
| 资本公积 | 资本溢价、其他股东直接投入但不计股本 |
| 其他综合收益(OCI) | 不进利润表的综合收益项(外币折算差额、可供出售金融资产公允价值变动等) |
| 盈余公积 | 法定与任意盈余公积,留存收益的法定锁定部分 |
| 未分配利润 | 累积未分配的净利润 |
| 库存股 | 公司回购的自身股份(权益减项) |

### 表格结构(横纵交叉)

行:权益变动事项
列:权益组成项目

```
                  股本    资本公积    OCI    盈余公积   未分配利润   总计
上年末余额        100     200          5      30        80          415
会计政策变更                                              -3          -3
重述后年初余额    100     200          5      30        77          412
本年综合收益                          +2                  +50         +52
股东出资           +20    +30                                          +50
利润分配                                       +5         -5            0
现金股利                                                  -10         -10
回购库存股(-15)                                                      -15
本年末余额        120     230          7      35        112         489
```

### 与其他三大表的勾稽

- **与利润表**:本年净利润 → 未分配利润增加
- **与综合收益**:本年其他综合收益(OCI) → OCI 项目增加
- **与现金流量表**:筹资活动现金流(增发、回购、分红)→ 股东权益对应变动
- **与资产负债表**:本表期末余额 = 资产负债表所有者权益项

### 重要变动类型

#### 综合收益

```
综合收益 = 净利润 + 其他综合收益
```

- 净利润进未分配利润
- OCI 进其他综合收益,不经利润表

#### 与所有者的资本交易

- 股东注资(IPO、定增、配股)→ 股本 + 资本公积增加
- 利润分配(分红)→ 未分配利润减少
- 股票回购 → 库存股增加(权益减项)
- 股权激励行权 → 股本 + 资本公积变动

#### 内部权益结构调整

- 提取盈余公积:未分配利润 → 盈余公积(总额不变)
- 资本公积转增股本:资本公积 → 股本

#### 会计政策变更与差错更正

- 追溯调整年初未分配利润,前期数据需要重述

### 国际差异

| 项目 | 中国准则 | IFRS |
|---|---|---|
| 名称 | 所有者权益变动表 | Statement of Changes in Equity |
| OCI 列报 | 在权益变动表内,也单列其他综合收益表 | 类似 |
| 盈余公积 | 中国特有的法定项目 | 无,大多并入留存收益 |
| 库存股 | 单独项目 | 单独项目 |

### 信息价值

- **股利政策**:观察累积分红与未分配利润比例
- **股东治理事件**:回购、增发、分立的痕迹
- **盈利质量**:OCI 占综合收益比例越高,越多波动来自非经营因素
- **资本结构**:库存股规模反映公司对自身估值的看法

## 和其他概念的关系

- 与 [[资产负债表]]、[[利润表]]、[[现金流量表]] 并列为四大报表
- 数据来源:本期 [[利润形成与分配]] 决定的未分配利润变化
- 关键勾稽:[[财务比率分析]] 中 ROE 分母期初/期末权益从此表读取
- 反映 [[股利政策]]、股票回购等股东回报决策
- 与 [[杜邦分析]] 中的权益乘数计算相关
- [[国际财务报告准则]] IAS 1 规定其披露
- 与 [[企业价值评估]] 中股权价值变化跟踪相关
