# 英语非谓语动词

## 定义

非谓语动词(Non-finite Verbs)指在句子中不充当谓语,但保留动词部分属性(可带宾语、状语、有语态时态变化)的动词形式。英语非谓语动词体系由三大类构成:**不定式(Infinitive,to do)**、**动名词(Gerund,doing)**、**分词(Participle,现在分词 doing 与过去分词 done)**。它们能让一个句子里只保留一个核心谓语动词,使表达紧凑、层次分明,是英语高级写作的重要标志。

## 核心要点

### 三类非谓语的定位

| 形式 | 核心特征 | 主要功能 |
|---|---|---|
| 不定式 to do | 名+动+副 三栖 | 主、宾、表、定、状、补、同位语 |
| 动名词 doing | 偏名词 | 主、宾(动词后/介词后)、表、定 |
| 现在分词 doing | 偏形容词/副词,主动/进行 | 定语、状语、补语 |
| 过去分词 done | 偏形容词,被动/完成 | 定语、状语、补语 |

### 不定式 vs 动名词作宾语

某些动词只接一种形式,需记忆:
- **只接不定式**:want, hope, decide, plan, agree, refuse, promise, choose, manage, expect。
- **只接动名词**:enjoy, mind, finish, avoid, suggest, consider, deny, admit, practice, give up。
- **两者都接但意义不同**:
  - *remember to do*(记得要去做)vs *remember doing*(记得做过)
  - *forget to do*(忘了要做)vs *forget doing*(忘了已经做过)
  - *stop to do*(停下来去做另一件事)vs *stop doing*(停止正在做的事)
  - *try to do*(努力去做)vs *try doing*(尝试做某事看看效果)
  - *mean to do*(打算做)vs *mean doing*(意味着做)

### 分词作定语和状语

**分词作定语**:可前置(单分词)或后置(分词短语)。
- *a sleeping baby*(现在分词,主动/进行)
- *the broken window*(过去分词,被动/完成)
- *the boy reading a book*(后置,= the boy who is reading a book)
- *the letter written by him*(后置,= the letter that was written by him)

**现在 vs 过去分词的根本区别**:
- 现在分词(doing)= 主动 + 进行/伴随
- 过去分词(done)= 被动 + 完成

判断标准:被修饰词是动作执行者用现在分词,被修饰词是动作承受者用过去分词。
- *exciting news*(令人兴奋的消息)vs *excited people*(感到兴奋的人)
- *interesting book*(有趣的书)vs *interested student*(感兴趣的学生)

**分词作状语**:充当状语时,分词的逻辑主语必须与主句主语一致。
- *Walking in the park, I saw a friend.*(我在公园散步时——逻辑主语是 I)
- 错误:*Walking in the park, the rain started.*(雨不会走路,逻辑主语错位)

### 独立主格结构

当分词的逻辑主语与主句主语不一致时,需要给分词加一个独立的主语,形成"独立主格":
- *Time permitting, we will go.*(如果时间允许)
- *The meeting being over, we left.*(会议结束后)
- *His task finished, he went home.*(任务完成后)

独立主格在书面语中常见,简化了大量从句结构。

### 非谓语的时态语态变化

| 形式 | 主动 | 被动 |
|---|---|---|
| 不定式一般式 | to do | to be done |
| 不定式完成式 | to have done | to have been done |
| 不定式进行式 | to be doing | — |
| 动名词一般式 | doing | being done |
| 动名词完成式 | having done | having been done |

## 和其他概念的关系

- 非谓语的"过去分词"形式与 [[英语语态系统]] 中被动语态的 `be + done` 同形,只是被动语态中作谓语,作分词时不作谓语。
- 非谓语状语和定语都是从句的简化形式,所以与 [[英语从句体系]] 是表达同一意思的两种语法手段——状语从句、定语从句往往可改写为分词短语。
- 不定式作主语常配合 [[英语 it 句型]] 用 it 作形式主语,避免句子头重脚轻。
- 在 [[英语主谓宾结构]] 中,非谓语可充当除谓语之外的所有成分,极大丰富了句子构造可能。
- 非谓语动词错误是中国学生写作常见错误来源,详见 [[英语常见错误分析]]。
- 在 [[英语写作结构]] 中,熟练运用分词短语和独立主格是写作风格成熟的标志。
