# 链表 Linked List

## 定义

**链表(Linked List)**是由若干**节点(Node)**通过指针串联起来的线性[[数据结构]]。每个节点至少包含两部分:数据域(value)和指针域(next)。节点在内存中**不要求连续**,通过指针建立逻辑顺序。

主要变种:
- **单链表(Singly)**:节点只有 next
- **双链表(Doubly)**:节点有 prev 和 next,可双向遍历
- **循环链表(Circular)**:尾节点 next 指向头节点,可无限遍历
- **跳表(Skip List)**:多层链表 + 索引层,见[[跳表]]

## 核心要点

### 操作复杂度

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 头部插入/删除 | O(1) | 只改两个指针 |
| 尾部插入(已知尾指针) | O(1) | 双链表或带尾指针 |
| 中间插入/删除(已知节点) | O(1) | vs [[数组]]的 O(n) |
| 按下标访问 | O(n) | 必须从头遍历 |
| 按值搜索 | O(n) | |

### 经典算法技巧

- **快慢指针**:慢指针每次走一步、快指针走两步。可用于检测环、找中点、找倒数第 k 个节点
- **Floyd 判环**:快慢指针相遇即有环,然后用数学推导定位环入口
- **反转链表**:三指针(prev/cur/next)迭代反转,或递归
- **链表合并**:双指针归并,与归并排序的合并步骤同构
- **虚拟头节点(Dummy Head)**:简化边界处理

### 链表 vs 数组的本质权衡

| 维度 | 链表 | [[数组]] |
|---|---|---|
| 内存布局 | 分散 | 连续 |
| 随机访问 | O(n) | O(1) |
| 中间插删 | O(1) | O(n) |
| 缓存友好 | 差 | 好 |
| 内存开销 | 高(每节点存指针) | 低 |
| 扩容代价 | 无 | 有时 O(n) |

工程上链表实际性能常被低估 —— 缓存不友好导致即使复杂度优势,链表也可能慢于数组。

### 应用场景

- **LRU 缓存**:Hash表 + 双向链表(O(1) 移到表头);见[[LRU缓存]]
- **进程调度链**:[[操作系统]]内核大量使用链表组织 task_struct
- **文件系统空闲块**:链表组织
- **[[Hash表]]冲突解决**:链地址法每个桶是链表
- **撤销 / 重做(Undo/Redo)**:双向链表
- **多项式 / 大整数**:稀疏表示

## 和其他概念的关系

链表与[[数组]]构成线性结构的两极,几乎所有更高级线性结构都是二者的混合:动态数组用数组 + 摊还、双端队列用块状链表、[[跳表]]在链表上加多级索引以实现 O(log n) 查找。

[[树]]、[[图]]本质都是带多个指针的"链表":二叉树节点有 left/right;图节点有邻居列表(常用链表表示)。垃圾回收(GC)的标记-清除依赖于通过指针穿过对象图,与链表遍历同构。

[[函数式编程]]中的"List"语义就是单链表(head + tail),因此 cons / car / cdr 在 Lisp / Haskell 中是基本运算,不可变更新天然友好。
