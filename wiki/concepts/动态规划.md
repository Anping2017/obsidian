# 动态规划 Dynamic Programming

## 定义

**动态规划(DP)**是一种通过把复杂问题分解为重叠子问题、保存子问题解避免重复计算的[[算法]]设计方法。它适用于满足两个条件的问题:
- **最优子结构(Optimal Substructure)**:大问题最优解由子问题最优解构成
- **重叠子问题(Overlapping Subproblems)**:子问题被多次求解(否则普通[[分治算法]]即可)

DP 把指数级朴素[[递归]](如斐波那契 O(2ⁿ))降到多项式级(O(n)),代价是 O(n) 空间存子问题答案。

## 核心要点

### 实现风格:记忆化 vs 表格化

| 风格 | 实现 | 特点 |
|---|---|---|
| 记忆化(Top-down) | 递归 + 缓存 | 直观,只算用到的子问题 |
| 表格化(Bottom-up) | 迭代填表 | 无递归开销,常可空间优化 |

### 经典模型

| 类型 | 状态 | 例题 |
|---|---|---|
| 线性 DP | dp[i] | 最大子段和、上升子序列、打家劫舍 |
| 区间 DP | dp[i][j] | 矩阵链乘、戳气球、回文分割 |
| 背包 DP | dp[i][j] | 0-1 背包、完全背包、分组背包 |
| 树形 DP | dp[node][...] | 树的最大独立集、树的直径 |
| 状压 DP | dp[mask] | TSP、子集枚举 |
| 数位 DP | dp[pos][...] | 区间内某性质数字计数 |
| 概率/期望 DP | dp[state] = 期望值 | 概率竞赛题 |

### 0-1 背包问题(范本)

容量 W,n 件物品(重 wᵢ、值 vᵢ),求最大总值。
- 状态:dp[i][j] = 前 i 件物品在容量 j 下最大值
- 转移:dp[i][j] = max(dp[i-1][j], dp[i-1][j-wᵢ] + vᵢ)
- 空间优化:用一维数组逆序遍历容量,O(W)

### 最长公共子序列(LCS)

dp[i][j] = X[0..i] 与 Y[0..j] 的 LCS 长度。
- 若 X[i] == Y[j]:dp[i][j] = dp[i-1][j-1] + 1
- 否则:dp[i][j] = max(dp[i-1][j], dp[i][j-1])
- 应用:diff 工具(Git/VSCode)、生物 DNA 比对、拼写检查

### 设计步骤

1. **定义状态**:把问题参数化(几乎是最难的一步)
2. **写状态转移方程**:dp[当前] 依赖哪些 dp[之前]
3. **确定边界**:dp[0]、dp[空集] 等初始值
4. **明确遍历顺序**:确保转移时依赖的状态已计算
5. **(可选)空间优化**:滚动数组、状态压缩

### 复杂度直觉

DP 复杂度 ≈ 状态数 × 单次转移成本。设计得当时:
- 一维线性 DP:O(n)
- 二维 DP:O(n²)
- 区间 DP:O(n³)
- 状压 DP:O(2ⁿ × n)

## 和其他概念的关系

DP 与[[递归]]共享思想(子问题分解),但增加了"记忆"。它与[[分治算法]]的区别在于:分治的子问题不重叠(归并排序两半互不相干),DP 的子问题重叠(斐波那契 fib(n-2) 在多处被算)。

[[贪心算法]]是 DP 的特殊情况:每步局部最优 → 全局最优,无需保存所有状态;但贪心要求严格的"贪心选择性质",证明远比 DP 难。

强化学习的**贝尔曼方程**就是状态价值的 DP 形式;Viterbi 算法是 HMM 的 DP;CYK 算法是上下文无关文法解析的 DP;Bellman-Ford 单源最短路是图上的 DP。

[[数据库]]查询优化器枚举 join 顺序也是 DP(System R 的经典做法)。
