# 伊壁鸠鲁主义

## 定义

伊壁鸠鲁主义(Epicureanism)是公元前 307 年伊壁鸠鲁(Epicurus, 前 341-270)在雅典"花园"(Kepos)创立的哲学学派,与 [[斯多葛主义]]、怀疑主义并列为希腊化时代三大派别。其核心是快乐主义伦理学与原子论自然哲学的结合。

## 核心要点

### 1. 物理学:原子论
- 继承德谟克利特的原子论
- **原子+虚空**:万物由不可分原子在虚空中运动构成
- **原子偏斜**(clinamen):卢克莱修发展,小幅偶然偏斜赋予自由意志空间
- **死亡不可怕**:灵魂也是原子聚合,死亡即解体,"死亡之时,我们已不在;我们在时,死亡未到"

### 2. 伦理学:快乐主义
- **快乐是最高善**(Hedonism)——但与世俗想象不同
- **静态快乐**(katastematic):无痛、无扰、心灵宁静(ataraxia)是最高
- **动态快乐**(kinetic):身体愉悦,但易转为痛苦
- **快乐三分类**:
  - 自然且必要(食、住、安全、友谊)→ 应满足
  - 自然但不必要(美食、性)→ 节制
  - 既不自然也不必要(名声、财富、权力)→ 拒绝

### 3. 反对四大恐惧(四重良药)
- **不必怕神**:神不干预人事
- **不必怕死**:死后无感觉
- **善易得**:简单生活即可获得
- **恶易忍**:剧痛短暂,长期痛苦不剧

### 4. 价值观
- **友谊**(philia):最珍贵的快乐之一
- **简朴**:抑制欲望比满足欲望更易达成快乐
- **退出公共生活**(lathe biosas):"过隐藏的生活"
- **理性反思**:用哲学疗治灵魂

## 主要传承

- **伊壁鸠鲁**(前 341-270):创始人,《自然论》《伦理学》多卷,大部分散佚
- **卢克莱修**(前 99-55):罗马诗人,《物性论》(De Rerum Natura)六卷,系统化原子论
- **菲洛德穆斯**(前 110-30):赫库兰尼姆图书馆藏书
- **第欧根尼·拉尔修**:保留三封伊壁鸠鲁书信(致希罗多德、致皮托克勒、致美诺凯乌斯)与重要箴言

## 与其他学派对比

| 维度 | 伊壁鸠鲁 | 斯多葛 |
|---|---|---|
| 最高善 | 快乐(无痛) | 德性 |
| 公共生活 | 退出 | 投身 |
| 神 | 存在但不干预 | 内在于宇宙(逻各斯) |
| 命运 | 部分由原子偏斜 | 全部决定 |
| 死亡 | 无感觉,不可怕 | 自然过程,接受 |
| 道德 | 工具性(为了快乐) | 内在价值 |

## 历史影响

- 罗马帝国后被基督教视为对手,边缘化
- 文艺复兴重新发现《物性论》(Poggio Bracciolini 1417)
- 影响伽桑狄、霍布斯、洛克的近代唯物主义
- 与 [[功利主义]] 边沁、密尔的"快乐主义"有谱系联系
- 杰斐逊自称伊壁鸠鲁主义者
- 卡尔·马克思博士论文研究伊壁鸠鲁原子论

## 与其他概念关系

- 反对 [[柏拉图]] 理念论,采取唯物主义路径
- 与 [[亚里士多德]] 幸福论可比,但快乐定义不同
- 与 [[佛家]] 苦谛、断欲传统部分相通
- 影响 [[行为经济学]] 对幸福的理解(适应、效用边际递减)
- 现代 [[积极心理学]] PERMA 模型有伊壁鸠鲁式快乐成分
- 与 [[斯多葛主义]] 共同构成古希腊化"生活哲学"双峰

## 当代复兴

- "慢生活"运动
- 极简主义(Minimalism)
- Stephen Greenblatt《大转向》(2011)讲述《物性论》如何塑造现代世界
- 神经科学享乐学(Hedonic Psychology)
- 与 [[幸福研究]]、PERMA 模型对话
