# 绩效管理

## 定义

**绩效管理**(Performance Management)是通过**目标设定、过程辅导、绩效评估、反馈与发展**的系统化、连续化流程,持续提升员工、团队与组织绩效的管理实践。它不是一年一次的"打分仪式",而是贯穿全年的循环:把战略 → 目标 → 行动 → 评估 → 发展闭环起来,是 [[人力资源管理]] 与 [[管理职能]] 的核心交集。

## 核心要点

### 核心流程(PDCA 循环)

1. **目标设定**(Plan):基于战略分解出可衡量目标
2. **执行与辅导**(Do):日常工作 + 经理一对一辅导
3. **评估与反馈**(Check):定期评价 + 绩效访谈
4. **改进与发展**(Act):奖惩 + 培训 + 晋升 + 调整

### 主要工具

- **[[KPI]]** 与目标分解
- **[[平衡计分卡]]**:四个维度的均衡评估
- **OKR**:目标 + 关键结果的对齐工具(Google、Intel 推动)
- **360 度反馈**:上级、同级、下级、客户多角度评价
- **强制分布**:GE 杰克·韦尔奇时代的活力曲线(20-70-10)
- **持续反馈**:Adobe Check-in、Microsoft Connect 等取消年度评分的新模式

### 评估维度

- **结果维度**:KPI、OKR、销售额等
- **行为维度**:胜任力模型、价值观契合
- **发展维度**:学习成长、潜力评估

### 评估常见偏差

- **晕轮效应**:好印象掩盖具体短板
- **[[首因效应]]** 与 **[[近因效应]]**:过度依赖最先或最近表现
- **趋中倾向**:不愿打高分或低分,都给中等
- **苛严或宽松倾向**:经理风格差异
- **同质偏好**:偏好与自己相似的人

### 现代趋势

- **从一年一次到持续反馈**:取消年度排名,改为季度甚至月度 Check-in
- **聚焦发展而非评判**:以教练辅导取代绩效法庭
- **数据驱动**:行为日志、协作数据、客户评价多源融合
- **去除强制分布**:适应高凝聚团队的需要
- **AI 辅助**:自然语言处理分析反馈,自动生成发展建议

### 失败的绩效管理

常见症状:
- 评分流于形式,没人当真
- 制造内部竞争,削弱协作
- 与战略脱节,KPI 各自为政
- 唯指标论导致博弈、造假
- 反馈延迟,问题积累成大事

成功的绩效管理需要 [[组织文化]] 的支持——心理安全、坦诚沟通、共同成长——而非仅靠工具。

## 和其他概念的关系

- 是 [[管理职能]] 中"控制 + 领导"环节的具体落地
- 与 [[人力资源管理]]、[[激励理论]] 紧密耦合
- 通过 [[KPI]]、[[平衡计分卡]] 实现可量化
- 与 [[团队建设]]、[[组织文化]] 互为支撑
- 在 [[销售管理]] 中是直接的考核工具
