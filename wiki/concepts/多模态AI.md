# 多模态AI

## 定义

**多模态 AI**(Multimodal AI)是能够同时感知、理解、生成多种信息模态(modality)的人工智能系统。模态包括文本、图像、视频、音频、语音、深度、力反馈、生物信号等。

它的核心命题是:**人类对世界的理解从来不是单模态的,智能体也不应该是**。在大模型时代,多模态从"图文搜索"扩展到统一的感知—推理—生成框架,代表如 [[Gemini系列模型]] 原生多模态、GPT-4o、[[Sora视频生成]]、[[Whisper语音识别]]。

## 核心要点

### 主流模态组合

| 组合 | 代表任务 | 代表系统 |
|---|---|---|
| 图+文 | 图文检索、VQA、描述 | [[CLIP]]、[[Vision Transformer]] |
| 视频+文 | 视频问答、视频生成 | [[Sora视频生成]] |
| 音频+文 | ASR、TTS、字幕 | [[Whisper语音识别]] |
| 文+图+音 | 多模态助手 | GPT-4o、Gemini 2 |
| 3D+文 | 3D 生成、CAD 助手 | DreamFusion、TRELLIS |
| 传感器+文 | 机器人、自动驾驶 | RT-2、LLaVA |

### 三种核心架构

1. **双塔对比**(CLIP 风格):图编码器 + 文编码器 → 共享空间 → 对齐
2. **统一 Token**(Gemini/GPT-4o):所有模态 token 化送入同一 Transformer
3. **桥接(Adapter)**:在已有 LLM 上加视觉/语音 adapter(LLaVA、MiniGPT)

### 多模态融合策略

- **早期融合(Early Fusion)**:输入阶段拼接,Transformer 内部全融合
- **晚期融合(Late Fusion)**:各模态独立编码,最后输出层融合
- **跨注意力(Cross-Attention)**:模态间通过 attention 流通信息
- **门控融合(Gated Fusion)**:动态决定哪条模态贡献当前任务

### 关键技术里程碑

| 年份 | 模型 | 贡献 |
|---|---|---|
| 2021 | [[CLIP]] | 大规模图文对比学习,零样本分类 |
| 2021 | DALL·E | 文本→图像生成 |
| 2022 | Whisper | 多语言鲁棒 ASR |
| 2022 | [[Stable Diffusion]] | 开源潜在扩散模型 |
| 2023 | LLaVA / MiniGPT | LLM + 视觉 adapter |
| 2023 | GPT-4V | 多模态理解通用化 |
| 2024 | Sora | 文本→分钟级视频 |
| 2024 | GPT-4o | 端到端实时语音多模态 |
| 2024 | Gemini 1.5/2 | 长上下文 + 原生多模态 |

### 与单模态 LLM 的本质差异

- **跨模态推理**:看图说话、听音生文、视频时序推理
- **统一接口**:输入输出都是任意模态混合
- **数据效率**:模态互补降低单模态需要的数据
- **真实世界落地**:机器人、AR/VR、医疗影像

## 应用场景

- **消费助手**:语音/拍照/对话三合一(Apple Intelligence、ChatGPT 语音)
- **教育**:解题拍照即讲解,见 [[教学提示模式]]
- **医疗**:影像 + 病历联合诊断
- **机器人**:视觉 + 语言指令 → 动作(VLA 模型)
- **媒体生产**:文生图、文生视频、图生视频
- **可访问性**:视障读图、聋人 ASR 字幕
- **企业 RAG**:文档 + 图表 + 截图统一检索

## 局限与陷阱

| 局限 | 描述 |
|---|---|
| **幻觉放大** | 跨模态时编造视觉细节风险更高 |
| **算力消耗** | 视频/音频远比文本贵 |
| **数据偏见** | 多模态语料分布失衡更严重 |
| **评估难** | 单模态指标(BLEU/ROUGE)不够 |
| **隐私** | 摄像头麦克风采集需合规 |
| **跨模态对齐** | 时间同步、空间对应仍是难题 |
