# 栈 Stack

## 定义

**栈(Stack)**是一种**后进先出(LIFO, Last-In First-Out)**的受限线性[[数据结构]],只允许在固定的一端(称为**栈顶 top**)进行插入(push)和删除(pop)。栈底位置不可直接访问,中间元素也不能跳过栈顶取出。

栈是抽象数据类型(ADT)的经典例子 —— 接口只暴露 push / pop / peek / isEmpty,实现可用[[数组]]或[[链表]]。

## 核心要点

### 基本操作复杂度

| 操作 | 复杂度 | 说明 |
|---|---|---|
| push(x) | O(1) | 入栈 |
| pop() | O(1) | 出栈 |
| peek() / top() | O(1) | 查看栈顶不出栈 |
| isEmpty() | O(1) | |
| size() | O(1) | |

### 实现方式

- **数组实现**:连续内存,top 是栈顶下标。需考虑扩容
- **链表实现**:头节点为栈顶,push/pop 都改头指针,无需扩容

工程上数组栈更常用,因缓存友好。

### 关键应用

1. **函数调用栈(Call Stack)**:每次函数调用入栈一帧(frame),包含返回地址、局部变量、参数;函数返回时弹栈。栈溢出(Stack Overflow)就是过深递归把调用栈压爆。
2. **表达式求值**:中缀转后缀(逆波兰式)、后缀求值都基于栈。
3. **括号匹配**:遇左括号入栈,遇右括号匹配栈顶
4. **DFS/[[回溯算法]]**:显式栈代替递归;[[图]]的深度优先遍历用栈
5. **撤销机制(Undo)**:每个操作入栈,撤销时弹出
6. **浏览器后退**:历史页面栈
7. **[[操作系统]]中断处理**:中断栈保存现场

### 单调栈

栈中元素保持单调(递增或递减)。常用于"下一个更大元素"、"柱状图最大矩形"、"接雨水"等问题,可把 O(n²) 暴力降到 O(n)。

### 栈与[[递归]]

任何递归都可用显式栈改写成迭代,反之亦然 —— 二者本质等价。但递归代码更简洁,栈版本可控制空间(避免栈溢出)、易于剪枝。

## 和其他概念的关系

栈、[[队列]]、[[堆]]、[[链表]]构成线性[[数据结构]]的核心阵营,栈和队列都是"受限的线性表",仅区别在操作端(栈一端,队列两端)。

[[递归]]在底层依赖调用栈,因此理解栈是理解函数式程序、[[动态规划]]递归实现的基础。[[编译原理]]中,语法分析器(Parser)用栈进行符号匹配,字节码虚拟机(JVM、CPython)很多都是基于栈架构。

[[操作系统]]每个线程有独立的用户栈和内核栈;栈是线程隔离的关键内存区域。线程切换时需保存/恢复栈指针(SP)。
