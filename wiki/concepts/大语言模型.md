# 大语言模型

## 定义

**大语言模型(Large Language Model, LLM)** 是基于 [[Transformer架构|Transformer]] 架构、参数量从数十亿到万亿级别、通过海量文本(常达万亿 [[Token]])预训练而获得通用语言理解与生成能力的 [[神经网络]] 模型。代表系列包括 GPT、Claude、Gemini、Llama、DeepSeek 等。

## 核心要点

**典型规模**

| 模型 | 参数量 | 特点 |
|---|---|---|
| GPT-2(2019) | 1.5B | 首次展示零样本能力 |
| GPT-3(2020) | 175B | 涌现 [[少样本提示]] 能力 |
| GPT-4(2023) | 估计 1T+(MoE) | 多模态、强推理 |
| Llama 3.1(2024) | 8B / 70B / 405B | 开源代表 |
| Claude 3.5/4(2024-25) | 未公开 | 长上下文、代码与工具使用见长 |

**训练范式三阶段**

1. **预训练**:从万亿级未标注语料中学习 next-token prediction(自监督)
2. **监督微调(SFT)**:用高质量人工指令数据微调
3. **对齐**:[[RLHF]] 或 DPO 等方法对齐人类偏好

整体见 [[预训练与微调]]。

**核心能力来源**

- [[涌现能力]]:某些能力在参数量和数据量越过临界规模后突然出现
- [[上下文学习]]:通过 [[少样本提示]] 在不更新参数下完成新任务
- [[思维链]]:被引导后展示推理步骤,显著提升数学和逻辑任务表现

**关键限制**

- [[幻觉]]:生成貌似合理但事实错误的内容
- 上下文窗口有限:虽已扩到 1M token 量级,但仍是约束
- 训练数据截止日期:对最新事件无知,需 [[RAG]] 弥补
- 计算成本高:训练耗资数百万至数亿美元,推理需 GPU 集群

**应用形态**

- 对话助手:ChatGPT、Claude、Gemini 等
- 代码助手:Copilot、Cursor、Claude Code
- 嵌入式 Agent:[[AI Agent]] 通过 [[函数调用]] 与 [[MCP协议]] 接入工具

## 和其他概念的关系

- 架构基础:[[Transformer架构|Transformer]]、[[自注意力机制]]、[[位置编码]]
- 输入单位:[[Token]],经 [[Embedding]] 进入网络
- 训练流程:[[预训练与微调]],其中对齐阶段使用 [[RLHF]]
- 使用接口:通过 [[提示词工程]] 引导,最常用 [[零样本提示]]、[[少样本提示]]、[[思维链]]
- 系统集成:[[RAG]]、[[函数调用]]、[[MCP协议]]、[[AI Agent]] 都构建在 LLM 之上
- 评测体系:[[模型评估]] 中的 MMLU、HumanEval 等基准
- 行为陷阱:[[幻觉]]、[[提示注入]] 是落地必须处理的问题
- 工程部署:大规模 LLM 服务普遍采用 [[微服务]] 架构(模型推理、向量召回、网关分层);[[缓存]] 与 KV-Cache、Prompt Cache 显著降低重复计算成本;持久化的语义记忆依赖 [[向量数据库]] 检索
- [[内容营销]]:批量生成 + 人工编辑的混合内容生产新范式
- [[AI对营销与SEO的影响]]:LLM 直接重塑搜索结果分发与内容生产成本
