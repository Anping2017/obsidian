# 转化漏斗

## 定义

**转化漏斗(Conversion Funnel)** 是把用户从首次接触到完成业务目标的过程切分成多个有序阶段,统计每阶段的留存与转化率,形成上宽下窄的"漏斗"形状,从而定位流失环节、量化优化机会的分析工具。

漏斗思想源自 1898 年艾里亚斯·圣埃尔莫·刘易斯(E. St. Elmo Lewis)提出的 AIDA 模型(Attention-Interest-Desire-Action),百年来不断演化为现代多形态的转化分析框架。

## 核心要点

- **典型电商漏斗**:曝光 → 点击 → 进站 → 浏览商品 → 加购 → 结账 → 支付 → 复购。每两阶段间的比值都是一个转化率。
- **典型 SaaS 漏斗**:访问官网 → 注册试用 → 激活(关键行为)→ 付费 → 续费 → 扩展付费(NRR > 100%)。
- **AIDA 与现代变体**:
  - AIDA:认知-兴趣-欲望-行动(经典营销)
  - AIDAS:增加 Satisfaction(满意度延伸到购后)
  - AISAS:增加 Search(搜索)与 Share(分享),反映社交时代特点
  - 5A(科特勒):Aware-Appeal-Ask-Act-Advocate
- **漏斗指标体系**:
  - 宏观转化率:整体目标转化率
  - 微观转化率:各阶段间转化率
  - 漏点(Drop-off):每阶段流失绝对数与相对率
  - 时间维度:从入口到转化的中位时长
  - 渠道维度:不同渠道的漏斗形状对比
- **优化方法**:
  - 找最大漏点:乘法效应下,优化最低转化率的一环回报最高
  - A/B 测试:对每一环的关键页面/文案/流程做对照实验
  - 用户行为分析:热力图、点击流、会话回放定位摩擦点
  - 转化路径优化:简化步骤、减少表单字段、明确 CTA、社交证明
- **常见漏点诊断清单**:
  - 着陆页相关性差(关键词与页面不匹配)
  - 加载速度慢(直接影响 LCP 与跳出)
  - 移动端体验差
  - CTA 不清晰
  - 表单字段过多
  - 信任不足(缺少评价、保障、品牌信号)
  - 价格不透明、运费意外
  - 支付环节失败率高
- **漏斗陷阱**:
  - 只看转化数不看转化率
  - 只看一次转化不看 LTV
  - 把漏斗看作线性而忽略循环(复购、推荐)
  - 不区分新客与老客
  - 平均掩盖差异(应分群分析)
- **漏斗外的形态**:
  - 飞轮(Flywheel,HubSpot):取代漏斗,强调推荐与续费的循环驱动
  - [[AARRR模型]](海盗指标):聚焦增长的五指标体系
  - [[HOOK模型]](尼尔·埃亚尔):聚焦习惯养成的微循环

## 和其他概念的关系

转化漏斗是 [[消费者行为]] 决策过程模型在数字场景的量化映射:认知-搜索-评估-购买-购后 → 漏斗各层。

漏斗是 [[数据驱动营销]] 与 [[增长黑客]] 的核心分析工具;[[用户旅程地图]] 提供横向视角(每个触点的体验),漏斗提供纵向视角(各阶段的转化率)。

[[AARRR模型]] 是漏斗的特定形态——专为产品增长设计;[[HOOK模型]] 是漏斗的微观循环视角。

漏斗优化与 [[转化率优化]](CRO)是同义实践,后者是前者的工程化、流程化。

在 SEO 场景下,漏斗顶端依赖 [[关键词研究]] 与 [[搜索意图]] 匹配——着陆页与搜索词的语义错位是顶端漏斗最大的隐形漏点。

漏斗与 [[用户画像]] 结合形成"分群漏斗",可发现不同人群的差异化漏点,是 [[精准营销]] 的诊断起点。

漏斗每一层的转化率优化本质上是对心理学机制的工程化:页面定价区域常用 [[锚定效应]] 设置参照价,放大主推方案的优惠感;限时限量、库存提示、放弃挽回利用 [[损失厌恶]] 推动决策;表单字段、CTA 文案、信任标识的设计要规避 [[认知偏差]] 中的"决策疲劳"与"选择过载"——这是从心理学到 CRO 的直接桥梁。
