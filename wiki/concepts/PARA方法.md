# PARA 方法

## 定义

**PARA 方法**是数字化时代由 **Tiago Forte** 在《Building a Second Brain》中系统提出的信息组织方法。其核心是**按"行动可用性"而非"主题相似性"组织信息**——把任何笔记、文件、资料归入四类:**P**roject(项目)、**A**rea(领域)、**R**esource(资源)、**A**rchive(档案)。它适用于任何工具(Notion、Evernote、Obsidian、文件夹、邮箱),被广泛用于知识工作者的"第二大脑"建设。

## 核心要点

### 四大类别

| 类别 | 定义 | 时间维度 | 例子 |
|---|---|---|---|
| **Project**(项目) | 有明确目标与截止时间的工作 | 短期(几周到几月) | "完成季度报告"、"装修房子" |
| **Area**(领域) | 持续承担的责任,无固定终点 | 长期 | "财务"、"健康"、"团队管理" |
| **Resource**(资源) | 未来可能用得上的兴趣或参考 | 备用 | "AI 写作技巧"、"设计灵感" |
| **Archive**(档案) | 不再活跃的项目、领域、资源 | 历史 | "已结束的旧项目"、"前公司笔记" |

### 设计哲学

- **行动导向**:笔记的归属由"在什么场景下我会用到它"决定,而非内容主题
- **跨工具一致性**:同一套四级体系可在所有工具中复制(电脑文件夹、Notion、Evernote 都用 P/A/R/A)
- **轻分类、重流转**:信息可以从 R 提升到 P(开始动作),从 P 落到 A(成为常态责任),也可以从任意层降到 Archive
- **拥抱不完美**:不必完美归类,经常移动是常态

### 与 GTD 等方法的关系

- **GTD**(David Allen):聚焦"下一步行动"——任务管理
- **PARA**:聚焦"信息归属"——资料管理
- 二者互补:PARA 组织笔记/资料,GTD 组织任务清单

### 与 Zettelkasten 的对比

| 维度 | PARA | [[Zettelkasten方法]] |
|---|---|---|
| 目的 | 行动支持 | 思想生长 |
| 组织 | 树状(四级) | 网状(链接) |
| 颗粒度 | 文件、笔记、资料 | 原子化卡片 |
| 适合 | 项目密集型工作者 | 学者、长期写作者 |
| 互补 | 可在 PARA 内部对 R 使用 Zettelkasten | 卡片可被 PARA 项目引用 |

很多人结合使用:用 PARA 管理活跃工作,用 Zettelkasten 沉淀长期知识。

### 实践要点

- **每周回顾**:评估 P 的进度,决定降级或归档
- **节制 R**:Resource 不是"未读列表",定期清理
- **Archive 不删除**:历史回看常带来意外灵感
- **五个文件夹模板**:Inbox / P / A / R / Archive(Inbox 是收件箱)

## 和其他概念的关系

- 是 [[PKM方法论]] 中"行动导向派"的代表
- 与 [[Zettelkasten方法]] 在哲学上互补
- 在 [[Obsidian插件生态]]、[[Obsidian双向链接]] 等工具中可直接落地
- 与 [[内在驱动力]]、个人生产力实践紧密相关
