# 国际SEO

## 定义

**国际 SEO(International SEO)** 是面向多个国家、地区或语言的用户群体进行搜索引擎优化的专门实践。其核心命题是:同一品牌如何让不同语言、不同国家、不同文化的用户在搜索时,看到属于他们的版本——既不互相抢排名,又不被算法判为重复内容。

国际 SEO 区别于一般 SEO 的复杂性来自三个维度:语言、地理、文化。一个英语网站在美国、英国、澳大利亚、印度可能需要四个版本;同一中文网站可能要服务大陆、港澳、台湾、海外华人四个市场。

## 核心要点

- **三种基本形态**:
  - **多语言(Multilingual)**:同一国家不同语言(瑞士的 de/fr/it/en)
  - **多地区(Multiregional)**:同一语言不同国家(en-US、en-GB、en-AU)
  - **多语言多地区(Multilingual & Multiregional)**:同时跨语言与跨地区
- **三种 URL 结构选择**:
  - **国家代码顶级域名(ccTLD)**:example.fr、example.de、example.cn
    - 优点:本地信号最强,符合用户习惯,SEO 与品牌均独立
    - 缺点:成本高,需独立维护多个域名,链接权重不互通
  - **子域名**:fr.example.com、de.example.com
    - 优点:可独立托管,可设置不同地理目标
    - 缺点:Google 视为不同站点,链接权重不直接传递
  - **子目录**:example.com/fr/、example.com/de/
    - 优点:链接权重合并,运维成本最低
    - 缺点:本地信号弱,无法用 GSC 分别设置目标国家
  - **URL 参数(?lang=fr)**:**强烈不推荐**,Google 与用户都难识别
- **hreflang 标签**:
  - 用途:告知 Google "本页适合 X 语言/地区的用户"
  - 实现位置:HTML `<head>`、HTTP Header、Sitemap
  - 必须**双向声明**(A 标 B,B 也要标 A,否则失效)
  - 必须**自指(self-referencing)**(每页指向自己)
  - 必须用 ISO 标准代码:语言用 ISO 639-1、地区用 ISO 3166-1 Alpha 2
  - 提供"x-default"作为兜底版本(为没匹配的用户准备)
- **国际化的内容策略**:
  - **直译 vs 本地化(Localization)**:仅翻译远不够,需要文化适配——货币、单位、日期格式、节日、案例、视觉
  - **关键词本地化**:同一概念在不同语言的搜索词不同(美式 vs 英式英语、简繁中文)
  - **内容深度本地化**:本地新闻、本地案例、本地用户证言
- **本地化技术信号**:
  - 服务器位置:本地 IP 或 CDN
  - 货币与价格本地化
  - 联系方式本地号码
  - 当地社交媒体链接
  - 本地评价系统集成
- **GSC 中的国际 SEO**:
  - 旧版"国际定位"功能让你为子域/子目录设定国家(已弃用)
  - 现代依赖 hreflang + 内容信号 + ccTLD 由 Google 自动判断
  - 通过 GSC 性能报告按国家分析流量
- **常见错误**:
  - hreflang 自指缺失或单向引用
  - 用 ccTLD 但用同一服务器、同样的英文内容(浪费 ccTLD 优势)
  - 把翻译当本地化(Google Translate 直翻 → 内容质量差)
  - 不同区域用同一份内容(被判重复)
  - 区域之间用 canonical 标签互相指向(自我消除)
  - 在子目录用不同的国家域名(混淆)
  - 用 IP 自动重定向(用户和 Googlebot 看不到其他版本)
- **特殊场景**:
  - **中国市场**:Google 没用,需面向百度、神马等中国搜索引擎,SEO 规则不同
  - **俄罗斯**:Yandex 主导
  - **韩国**:Naver、Daum 主导
  - **东南亚**:Google + 本地平台双轨

## 和其他概念的关系

国际 SEO 是 [[搜索引擎优化]] 在跨语言跨地区场景的特化,综合 [[技术SEO]](hreflang、ccTLD)、[[关键词研究]](本地化)、[[内容营销]](本地化内容)、[[链接建设]](本地权威源)。

国际 SEO 与 [[本地SEO]] 不同——前者跨国家,后者在国家内的本地;但在多国多店品牌(如餐饮连锁、零售)中两者协同。

[[结构化数据]] 在国际 SEO 中尤为重要——LocalBusiness、Organization、Product schema 都需按地区本地化。

国际 SEO 与企业的 [[品牌定位]] 交互——全球统一定位 vs 本地化定位的张力是跨国营销的永恒议题。

国际 SEO 在 [[资本市场]] 视角下与企业的国际扩张战略联动——自然搜索流量是判断品牌国际化深度的指标之一。
