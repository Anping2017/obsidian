# 二叉树 Binary Tree

## 定义

二叉树(Binary Tree)是**每个节点至多有两个子节点(分别称为左子节点与右子节点)** 的[[树]]结构。它是树家族最基础也最重要的成员,因为「至多两子」简化了实现,同时保留了树的所有核心性质,是大量复杂结构(BST、堆、AVL、红黑树、表达式树、霍夫曼树)的母体。

## 核心要点

### 节点定义

```python
class TreeNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
```

### 类型谱系

| 类型 | 性质 | 用途 |
|---|---|---|
| 满二叉树 | 每层节点数最大化 | 完美对称,理论分析 |
| 完全二叉树 | 除末层外都满,末层左对齐 | 堆、按数组隐式存储 |
| 平衡二叉树 | 任意子树高度差有界 | AVL、红黑树,保证 O(log n) |
| [[二叉搜索树]] | 左 < 根 < 右 | 有序查找 |
| 堆(完全二叉树) | 父 ≥/≤ 子 | 优先队列 |
| 哈夫曼树 | 频率加权路径最短 | 数据压缩 |
| 表达式树 | 内部节点为运算符,叶为操作数 | 编译器、计算器 |

### 四大遍历

| 遍历 | 顺序 | 应用 |
|---|---|---|
| 前序 (Pre-order) | 根→左→右 | 拷贝树、序列化 |
| 中序 (In-order) | 左→根→右 | BST 中序得有序序列 |
| 后序 (Post-order) | 左→右→根 | 删除树、计算表达式 |
| 层序 (Level-order) | 一层一层 BFS | 树的宽度、最大深度 |

```python
def inorder(node, result):
    if not node: return
    inorder(node.left, result)
    result.append(node.val)
    inorder(node.right, result)

# 迭代版用栈或 Morris 遍历(O(1) 空间)
```

### 关键性质

- **n 个节点的二叉树有 n+1 个空指针**:可用线索二叉树利用空指针加速遍历
- **完全二叉树用数组表示**:索引 i 的左子 = 2i+1,右子 = 2i+2,父 = (i-1)/2,无需指针
- **n 个节点的不同二叉树形态数 = Catalan(n) = C(2n,n)/(n+1)**
- **高度 h 的二叉树最多 2^(h+1)-1 个节点,最少 h+1 个**

### 常见算法

- **判定平衡**:递归求每子树高度,差 > 1 不平衡
- **最近公共祖先(LCA)**:Tarjan、倍增法、欧拉序 + RMQ
- **二叉树的直径**:任意两节点最长路径,递归同时记录最大左+右深度
- **路径和**:DFS 收集路径

### 空间表示

- **链式存储**:节点 + 左右指针,灵活但内存碎片
- **数组存储**:适合完全二叉树,缓存友好(堆排、Segment Tree)
- **左孩子右兄弟**:把任意多叉树转二叉树
- **括号表示法**:`A(B(D,E),C)`

## 和其他概念的关系

二叉树是 [[数据结构]] 课程的中段重点,承接 [[链表]]、[[数组]] 等线性结构,引出 [[二叉搜索树]]、[[红黑树]]、[[B+树]] 等高级结构。

它是 [[递归]] 思维训练的最佳样本——绝大多数算法都能用「左子树 + 根 + 右子树」三部分递归思考。这种思维同样适用于 [[分治算法]]、[[动态规划]] 中树形 DP。

实际应用极广:[[操作系统]] 进程管理、[[数据库]] 索引(B+ 树是多路平衡树,本质源自二叉)、[[编译原理]] 抽象语法树(AST)、[[Hash表]] 在 Java HashMap 桶过长时转红黑树、[[Linux内核]] CFS 调度器、[[文件系统]] 目录结构。

[[图]] 与树的关系:树是无环连通图,二叉树是限制度的特殊树。许多图算法在树上有简化版本(LCA、最短路、连通性)。
