# 商誉

## 定义

**商誉**(Goodwill)是企业并购中**收购对价超过被购方可辨认净资产公允价值的差额**,反映被收购企业的**品牌价值、客户关系、技术诀窍、员工团队、协同效应**等无法单独识别与计量的资产价值。它是现代会计中最特殊也最具争议的资产之一——既不能像存货那样卖出,也不像专利那样有清晰边界,完全是收购溢价的"残值"。在 [[国际财务报告准则]](IAS 36)与 [[美国GAAP]](ASC 350)下,商誉**不摊销**,但**至少每年进行减值测试**。

## 核心要点

### 计算公式

$$\text{商誉} = \text{收购对价} - \text{被购方可辨认净资产公允价值}$$

例:A 公司花 1000 万买下 B 公司:
- B 公司账面净资产 600 万
- B 公司可辨认净资产公允价值 800 万(发现土地市值高于账面)
- A 公司确认:可辨认资产 800 万 + 商誉 200 万

可辨认资产可能包括:
- 客户名单、品牌、未注册的商标
- 技术、专利
- 进行中的研发
- 合同关系
- 这些先单独评估,剩余才是商誉

### 与可辨认无形资产的区分

并购会计要求把溢价**先尽量分配到可辨认无形资产**,剩下才是商誉:

| 类型 | 例 | 处理 |
|---|---|---|
| **商誉** | 不可分割的协同价值 | 不摊销,减值测试 |
| **客户关系** | 客户名单、合同 | 摊销(有限寿命) |
| **品牌** | 商标、商号 | 寿命有限则摊销,无限则减值测试 |
| **技术** | 专利、专有技术 | 摊销 |
| **市场推广材料** | 广告 | 通常费用化 |

这一识别工作高度依赖估值师与会计师专业判断。

### 不摊销的逻辑

历史上商誉曾被摊销(US GAAP 1970-2001 年最长 40 年):
- **2001 SFAS 142**:US GAAP 改为减值测试
- **2004 IFRS 3**:IFRS 同步改为减值测试

理论根据:
- 商誉寿命不可估
- 摊销人为且难合理
- 让减值反映实际损耗更合适

但减值测试的复杂性引发争议,部分国家(如日本、印度税务、IFRS for SMEs)仍允许或要求摊销。

### 减值测试

**IAS 36 / ASC 350 流程**:

1. **分配商誉到现金产生单元(CGU)**:商誉与具体业务部门关联
2. **计算可收回金额**:取以下两者较高:
   - 公允价值减处置费用
   - 使用价值(未来现金流折现)
3. **比较可收回金额与账面金额**:
   - 可收回 < 账面 → 减值
   - 减值 = 账面 - 可收回(先冲减商誉,商誉清零后冲减其他长期资产)
4. **披露估值假设**:折现率、增长率、关键参数

**频率**:
- 每年至少一次
- 出现减值迹象立即测试
- 大公司常季报评估

### 经典减值案例

- **HP 收购 Autonomy(2011)**:88 亿美元 → 减值 89 亿(2012,几乎全部)。诉讼前 CEO Lynch 财务造假,2024 年 Lynch 被无罪释放但游艇沉没去世。
- **AOL-Time Warner(2000)**:1650 亿合并对价 → 2002 年减值 990 亿,21 世纪最大商誉减值
- **Microsoft 收购 Nokia 手机(2014)**:72 亿 → 一年后减值 76 亿
- **Yahoo 收购 Tumblr(2013)**:11 亿 → 2016 减值 7.1 亿
- **中国天广中茂(2018)**:16 亿商誉减值,A 股年度财报雷区

### 财务报表中的位置

**资产负债表**:
- 长期资产 → 无形资产 → 商誉(单独列示)
- 减值后净值

**利润表**:
- 减值损失 → "资产减值损失"科目,影响营业利润

**现金流量表**:
- 减值是非现金项目,不影响经营现金流
- 但反映企业前期收购决策

### 主要争议

#### 1. 估值主观性大

- 折现率、增长率假设大幅影响减值
- "管理层估计"操纵空间大
- 审计师压力大

#### 2. 减值"延迟、爆雷"

- 管理层倾向延迟确认减值(避免影响业绩)
- 一旦确认常一次性大额计提
- 企业易出现"洗大澡"现象

#### 3. 摊销 vs 减值争议

- 支持摊销:简单、无操纵空间、避免延迟
- 支持减值:更准确、不损失信息
- IASB 2020 年讨论是否回归摊销,未定

#### 4. 投资者怎么看

- **价值投资者**:常剔除商誉看"有形净资产"(book value tangible)
- **成长投资者**:愿意接受商誉,看后续协同效应实现
- **银行**:监管资本中扣除商誉(谨慎)

### 商誉与企业战略

#### 高商誉行业

- 互联网 / 软件:Yahoo、Microsoft 多次收购,商誉占资产 30%+
- 制药:并购研发管线,商誉巨大
- 媒体:品牌价值大
- 服务业:客户关系导向

#### 低商誉行业

- 制造业:实物资产为主
- 资源业:储量为主
- 商品业:品牌价值有限

### 现代议题

- **数字资产 / 数据**:数据资产是否算商誉?
- **ESG 商誉**:可持续性是否影响估值
- **AI 影响**:如果模型替代品牌效应,商誉如何评估
- **加密资产并购**:边界与计量
- **非控制性权益(NCI)**:全部商誉法 vs 部分商誉法的选择

### 中国特色议题

- **A 股商誉雷区(2018-2019)**:并购热潮 → 大规模减值,投资者损失重
- **监管收紧**:证监会 2018 年要求"减值测试"严格化
- **新企业会计准则**:与 IFRS 同步,减值测试为主

## 和其他概念的关系

商誉是 [[企业合并]] 会计的核心产物,在 [[国际财务报告准则]] IFRS 3 与 [[美国GAAP]] ASC 805 下都有详细规定。它在 [[资产负债表]] 中是无形资产大类。它是 [[财务报表分析]] 中"剔除商誉的有形净资产"的来源。它在 [[审计风险评估]] 中是高风险项目(主观估值)。它涉及 [[公司治理结构]] 中并购决策与监督。它在 [[企业价值评估]] 中是估值溢价的会计反映。它在 [[财务比率分析]] 中影响 ROA(剔除商誉看更准)。
