# 4321 直播法则

## 定义

4321 直播法则是抖音/快手直播带货实战派(以东方甄选、辛巴系等头部团队总结提炼)广泛使用的内容时间分配启发式公式,把一段直播切片(通常 30-60 分钟为一循环)按 **40% 福利氛围 + 30% 产品讲解 + 20% 互动答疑 + 10% 引流转化** 的比例分配。核心目的是兼顾直播间的三大核心算法指标:**停留时长、互动率、GPM**(每千次曝光销售额),从而获得抖音商业流量(千川)与自然流量(抖加)的双向加权。本概念是 [[直播脚本结构]] 的内容比例细化。

## 四大模块详解

### 1. 福利氛围(40%)

- **限时福利**:整点抽奖、点赞 1 万抽奖、关注送券
- **氛围话术**:"还有 5 单结束""今天主播亏本卖""手慢无"
- **场内互动玩法**:口令红包、福袋、连麦
- **作用**:
  - 拉长用户停留(停留时长)
  - 增加互动指标(评论、点赞、关注)
  - 制造紧迫感,促"冲动决策"

### 2. 产品讲解(30%)

- **核心卖点**:3-5 个差异化卖点,反复强调
- **使用场景**:让观众"代入"
- **价格对比**:与同价位/同品类对标
- **演示**:实物展示、试用、对比测试
- **作用**:
  - 教育用户,降低决策成本
  - 提升 GPM(产品本身吸引力)
  - 建立信任(亲眼见、亲手用)

### 3. 互动答疑(20%)

- **回答评论问题**:"主播,色号偏黄吗?""有没有 XL 码?"
- **粉丝点单**:"看到那位老铁要 XX,马上上"
- **走心连麦**:与"老粉"互动,塑造温度感
- **作用**:
  - 提升互动率(评论与回复)
  - 让"刚进来的人"看到"真实直播"而非念稿
  - 增加信任感

### 4. 引流转化(10%)

- **强 CTA 时刻**:"上链接""3 2 1 上车""库存只有 100 件"
- **关注+加购**:"先关注,等会有大福利""不下单也加购物车"
- **私域引流**:"加客服领赠品"
- **作用**:
  - 把高峰期注意力变成订单
  - 沉淀私域客户
  - 提升 UV 价值(访客平均贡献)

## 实操脚本模板(60 分钟单品讲解)

| 时段 | 模块 | 内容 |
|---|---|---|
| 0-3 min | 福利氛围 | 开场福袋、关注送券 |
| 3-8 min | 产品讲解 | 卖点 1-3 简介 |
| 8-12 min | 互动答疑 | 回答 3-5 个观众问题 |
| 12-15 min | 引流转化 | 第一波上链接 |
| 15-25 min | 福利氛围 | 整点抽奖、限时福袋 |
| 25-35 min | 产品讲解 | 卖点细节 + 演示 |
| 35-40 min | 互动答疑 | 走心连麦 / 评论回复 |
| 40-50 min | 福利氛围 | 第二波抽奖 + 库存压力 |
| 50-55 min | 产品讲解 | 总结 + 再次卖点 |
| 55-58 min | 互动答疑 | 解答最终顾虑 |
| 58-60 min | 引流转化 | 库存倒计时 + 加车 |

## 与抖音算法的对应关系

| 算法关注 | 对应模块 |
|---|---|
| 停留时长 > 90s | 福利氛围 + 产品演示 |
| 互动率 > 8% | 互动答疑 + 福袋 |
| 关注率 > 1% | 福利氛围(关注换福利) |
| GPM(千次曝光销售额) | 引流转化 + 产品讲解 |
| 转粉率 | 走心连麦 |

## 不同品类的比例微调

- **服装/美妆**:讲解占比可至 35-40%(看实物、试穿/试色)
- **食品/快消**:讲解占比 20%,福利占比 50%(冲动)
- **3C/手机**:讲解占比 40%(决策成本高,需教育)
- **知识/课程**:讲解占比 50%(干货输出本身即转化)
- **纯品牌曝光**:讲解占比 30%,故事 + 互动占比高

## 主播角色分工

直播间通常配置:
- **主播(Front)**:核心叙事,情绪带动
- **副播(Side)**:补充演示,递东西,辅助叙述
- **场控(Behind)**:控库存、控福利、监控数据
- **运营(Off-camera)**:监控千川投放、客服私信

## 常见错误

1. **比例倒置**:讲解占 60%、福利只占 10%,直播间冷场,留不住人
2. **死板执行**:不看实时数据机械按比例,失去临场判断
3. **福利空心**:每分钟"福利预告"但永远不发,信任崩塌
4. **互动表演**:不真实回答评论,只念好评,被识破
5. **CTA 滞后**:高峰期不上链接,错过最佳转化时机
