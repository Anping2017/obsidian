# 财务报表

## 定义

**财务报表**(Financial Statements)是按 [[财务会计]] 准则编制的、向外部使用者反映企业**财务状况、经营成果、现金流量、权益变动**的综合性文件。

它是会计循环的最终输出,也是 [[财务报表分析]]、[[企业价值评估]]、[[信用评估]]、监管披露的共同底座。

## 核心要点

### 三大主表 + 一个表 + 附注

| 报表 | 反映 | 时间维度 | 关键等式 |
|---|---|---|---|
| [[资产负债表]] | 财务状况 | 时点 | 资产 = 负债 + 所有者权益 |
| [[利润表]] | 经营成果 | 期间 | 收入 − 费用 = 利润 |
| [[现金流量表]] | 现金流动 | 期间 | 经营 + 投资 + 筹资 = 现金净增 |
| [[所有者权益变动表]] | 权益变动 | 期间 | 期初 + 增减 = 期末 |
| **附注** | 政策/估计/风险/分部 | — | 解释和细化 |

### 资产负债表(Balance Sheet)

- **资产**:流动资产 + 非流动资产
- **负债**:流动负债 + 非流动负债
- **所有者权益**:实收资本、资本公积、盈余公积、未分配利润
- 体现"我有什么、欠什么、谁的钱投进来"

### 利润表(Income Statement)

经典多步式结构:
1. 营业收入
2. − 营业成本
3. = 毛利
4. − 销售/管理/研发/财务费用
5. = 营业利润
6. ± 营业外收支
7. = 利润总额
8. − 所得税
9. = **净利润**

### 现金流量表(Cash Flow Statement)

三大类:
- **经营活动**:核心业务的现金流入/出
- **投资活动**:资产购置/处置、对外投资
- **筹资活动**:借款、还款、增资、分红、回购

经营现金流是企业"造血能力"的真实指标,与利润表的应计利润可能背离。

### 报表间的勾稽关系

- 利润表的"净利润" → 资产负债表"未分配利润"增加
- 利润表"折旧" → 资产负债表"累计折旧"增加
- 经营现金流间接法 → 从净利润调整为现金口径
- 综合反映:任意一张表的变化必能在其他表中找到对应

### 主要会计准则下的差异

| 准则 | 报表名称差异 | 关键差异点 |
|---|---|---|
| **[[国际财务报告准则]]** | Statement of Comprehensive Income 等 | 公允价值倾向、原则导向 |
| **[[美国GAAP]]** | Income Statement 等 | 规则细致 |
| **中国 CAS** | 利润表/损益表 | 与 IFRS 持续趋同 |

### 报表分析的层次

[[财务报表分析]] 的方法:
1. **结构分析**(共同比/百分比报表)
2. **趋势分析**(同期/环比/年度)
3. **比率分析**:见 [[财务比率分析]] 与 [[杜邦分析]]
4. **现金流分析**:见 [[自由现金流]]
5. **质量分析**:盈利质量、应计与现金的偏离
6. **同业比较**:与可比公司

### 附注的重要性

附注往往比主表更具信息量:
- **重要会计政策与估计**
- **关联方交易**:见 [[关联方披露]]
- **或有事项与承诺**
- **金融工具**
- **股权激励**
- **分部信息**
- **后续事项**
- **风险敞口**

## 应用场景

- **投资分析**:估值与基本面分析的输入
- **银行信贷**:授信决策的基础材料
- **审计**:[[审计]] 的对象
- **税务**:税务会计与纳税申报
- **监管披露**:上市公司年报、季报
- **并购尽调**:[[企业价值评估]] 的源头
- **绩效管理**:[[KPI]]、[[OKR]] 中的财务维度

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **历史导向** | 反映已发生的事项,对未来预测有限 |
| **盈余管理** | 准则灰区下利润可被操纵 |
| **公允价值波动** | 引入估值主观性与顺周期 |
| **无形资产缺位** | 品牌、人才、数据难以反映 |
| **跨期分摊误差** | 折旧、摊销、坏账估计差异巨大 |
| **关联交易** | 披露不充分时利润真实性存疑 |
| **格式僵化** | 无法适配新经济商业模式(SaaS、平台) |
