# 外部性

## 定义

**外部性**(Externality)指**经济主体的行为对第三方产生影响,但这种影响未通过市场价格反映、未得到补偿或赔付**。它是 [[市场均衡]] 失灵的最经典原因之一——当私人成本/收益与社会成本/收益不一致时,市场出清的均衡量偏离社会最优,需通过制度设计纠正。该概念由英国经济学家 **Arthur Pigou** 在 1920 年《福利经济学》中系统提出。

## 核心要点

### 四种基本类型

| 类型 | 例子 | 特征 |
|---|---|---|
| **负外部性(生产)** | 工厂污染、噪音 | 私人成本 < 社会成本,生产过多 |
| **正外部性(生产)** | 蜂农—果园、技术外溢 | 私人收益 < 社会收益,生产过少 |
| **负外部性(消费)** | 二手烟、酒驾 | 消费产生第三方成本 |
| **正外部性(消费)** | 疫苗、教育 | 消费产生第三方收益 |

### 边际成本-收益偏离

记 PMC = 私人边际成本,SMC = 社会边际成本,EMC = 外部边际成本:

$$\text{SMC} = \text{PMC} + \text{EMC}$$

负外部性:EMC > 0,自由市场产量 Q_私 > 社会最优 Q_社
正外部性:EMC < 0,自由市场产量 Q_私 < 社会最优 Q_社

### 庇古税(Pigouvian Tax)

Pigou 经典方案:对负外部性征收**等于外部边际成本的税**,使私人成本 = 社会成本,矫正市场。

- 例:碳税、排污税、香烟税、烈酒税
- 对正外部性的镜像:**庇古补贴**(教育补贴、研发补助)

### 科斯定理(Coase Theorem)

Coase 1960《社会成本问题》:**只要产权清晰且谈判成本足够低,无论产权初始分配给谁,双方都能通过谈判达到帕累托最优**——市场可能内在化外部性。

**例**:工厂污染下游渔民:
- 给工厂排污权:渔民可付钱让工厂减排
- 给渔民清洁权:工厂可付钱获排放权
- 关键是**产权明确** + **交易成本低**

科斯改变了外部性思维:从"市场失灵需政府"到"产权设计 + 交易成本"。

### 交易成本与公共政策

科斯本人强调,现实中交易成本通常很高,导致市场无法处理外部性,因此政府仍需介入。但介入方式不限于庇古税,还包括:

- **可交易许可证**(Cap-and-Trade):排污总量管控 + 配额可交易,美国 SO2 项目典范
- **直接管制**:污染标准、强制治理
- **侵权法**:事后赔偿
- **道德规范 / 教育**:Ostrom 公共池塘资源研究证明社区自治有效

### Coase 与 Pigou 的对比

| 方法 | 庇古 | 科斯 |
|---|---|---|
| 工具 | 税 / 补贴 | 产权 + 谈判 |
| 信息要求 | 政府需知 EMC | 双方需知收益与损失 |
| 适用 | 多人受影响、交易成本高 | 少数主体、产权易界定 |
| 公平 | 政府决定分配 | 取决于产权初始分配 |
| 现实例 | 碳税 | EU 碳排放交易体系(混合) |

### 现代应用

- **气候变化**:全球最大负外部性,各国争论碳税 vs 碳市场
- **交通拥堵**:伦敦/新加坡拥堵费(庇古税)
- **金融系统性风险**:大银行倒闭外部性 → 资本附加费、SIFI 监管
- **数据外部性**:个人数据使用对他人的隐私影响,新兴政策领域
- **网络效应**:正外部性(通讯网络、社交平台)
- **疫情公共健康**:疫苗 + 强制接种或补贴

### 内部化的限制

- **测度困难**:外部成本难精确量化(如碳的社会成本)
- **政府失灵**:监管捕获、政治经济
- **跨境外部性**:碳排放、传染病难单边治理
- **代际外部性**:气候变化影响未来世代,折现率争议
- **不可逆性**:有些外部性(灭绝、气候临界点)无法事后修复

## 和其他概念的关系

外部性是 [[市场均衡]] 失灵的核心原因之一,与 [[公共物品]]、[[信息不对称]] 并列三大市场失灵。其内部化机制是 [[财政政策]] 与税收设计的核心议题(碳税、烟酒税)。庇古税概念支撑 [[环境经济学]]。科斯定理与 [[新制度经济学]] 紧密相关。在 [[福利经济学]] 视角下,外部性导致竞争均衡偏离 [[帕累托最优]]。气候变化外部性是当代最重要的 [[国际贸易理论]] 与全球治理议题。
