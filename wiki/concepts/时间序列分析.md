# 时间序列分析

## 定义

**时间序列分析**是研究按时间顺序排列的数据序列的统计分析方法,用于识别时间模式、趋势和周期性,并进行预测。其特征是时间性(顺序排列)、相关性(时间点间相关)、趋势性(长期方向)、周期性(波动)。它是金融实证、宏观分析、量化交易的核心工具。

## 核心要点

### 时间序列基础
- **时间序列分解**
  - 加法模型:Y(t) = T(t) + S(t) + C(t) + I(t)
  - 乘法模型:Y(t) = T(t) × S(t) × C(t) × I(t)
  - 成分:趋势(T)、季节性(S)、循环(C)、不规则(I)
- **时间序列特征**
  - 趋势:长期方向
  - 季节性:固定周期波动(如月度)
  - 循环:非固定周期(如经济周期)
  - 随机性:不可预测部分

### 平稳性
- **弱平稳**(协方差平稳):均值、方差、自协方差不变
- **强平稳**:分布不随时间变化
- **检验方法**
  - **ADF**(Augmented Dickey-Fuller):单位根检验
  - **PP**(Phillips-Perron):非参数版 ADF
  - **KPSS**(Kwiatkowski-Phillips-Schmidt-Shin):平稳性检验(原假设平稳)
- **非平稳处理**
  - **差分**:一阶差分 ΔY = Y_t - Y_{t-1}(消除趋势)
  - **去趋势**:回归剔除趋势项
  - **协整**(Cointegration):两序列长期均衡(EG 检验)

### ARIMA 模型(Box-Jenkins 方法)
- **AR(p) 自回归**:X_t = φ_1·X_{t-1} + ... + φ_p·X_{t-p} + ε_t
- **MA(q) 移动平均**:X_t = ε_t + θ_1·ε_{t-1} + ... + θ_q·ε_{t-q}
- **ARMA(p,q)**:AR + MA
- **ARIMA(p,d,q)**:差分 d 阶后 ARMA
- **模型识别**:ACF(自相关)截尾 → MA;PACF(偏自相关)截尾 → AR
- **模型选择**:AIC、BIC、HQ 信息准则

### 异方差与 GARCH 模型
- **ARCH 检验**:Engle 1982,检测异方差
- **GARCH(1,1)**:σ²_t = ω + α·ε²_{t-1} + β·σ²_{t-1}
- **EGARCH**:不对称效应(坏消息冲击 > 好消息)
- **TGARCH/GJR-GARCH**:门槛 GARCH
- **DCC-GARCH**:动态条件相关 GARCH(多元)
- **应用**:波动率预测、VaR 计算、期权定价

### 多元时间序列模型
- **VAR**(向量自回归):多变量 AR
- **VECM**(向量误差修正模型):带协整约束的 VAR
- **Granger 因果检验**:X 是否 Granger 引起 Y
- **脉冲响应函数(IRF)**:冲击的动态影响
- **方差分解**:各变量对方差的贡献

### 金融应用
1. **股价预测**:ARIMA、GARCH(波动率)、VAR(多变量),配合 [[技术分析]]
2. **汇率预测**:ARIMA、VAR、协整(购买力平价检验)
3. **利率预测**:ARIMA、Vasicek、Nelson-Siegel(期限结构)
4. **波动率预测**:GARCH 族,直接服务于 [[期权定价]] 与 [[风险识别与度量]]
5. **风险管理**:VaR 计算需要波动率预测
6. **配对交易**:协整分析识别长期均衡关系

### 现代发展
- **机器学习时间序列**:LSTM、GRU、Transformer(注意力机制)
- **状态空间模型**:卡尔曼滤波、HMM
- **频域分析**:谱分析、小波分析
- **高频数据**:tick 级数据、实现波动率
- **大数据时间序列**:分布式计算、流式处理

## 和其他概念的关系

时间序列分析是 [[量化分析]] 的核心方法论之一,与 [[回归分析]]、[[蒙特卡洛模拟]] 共同构成实证金融的工具集。它依赖 [[概率论与统计学]] 的分布与推断方法。

[[基本面分析]] 与 [[技术分析]] 都隐含时间序列假设——基本面分析中的财务比率趋势分析,技术分析中的移动平均、动量都是时间序列方法。 [[行为金融学]] 通过时间序列方法识别市场异常(动量效应、反转效应、日历效应)。

GARCH 模型与 [[期权定价]] 中的波动率预测直接相关——隐含波动率与历史波动率的差异是 GARCH 应用核心。 [[衍生品风险管理]] 与 [[风险模型与工具]] 中的 VaR 计算依赖波动率时间序列。

[[投资环境分析]] 中的宏观经济时间序列分析是其重要应用——GDP、CPI、利率的趋势与周期。 [[国际收支]]、[[汇率预测方法]] 中的计量模型多基于时间序列。 [[金融发展评价]] 用面板时间序列研究金融-增长关系。

[[投资组合理论]] 中的协方差估计涉及多元时间序列(DCC-GARCH 比静态协方差更准确)。 [[资产定价模型]] 的实证检验是时间序列检验的经典应用。

机器学习时间序列(LSTM/Transformer)是 [[金融科技]] 与传统量化的融合趋势。时间序列分析的局限:**结构变化**(模型在政策变化后失效)、**过拟合**、**伪回归**(非平稳序列假回归)、**预测不确定性**(置信区间常被忽视)。
