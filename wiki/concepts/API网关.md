# API 网关

## 定义

**API 网关(API Gateway)** 是微服务架构的统一对外入口,所有外部请求先到网关,由网关执行身份认证、流量控制、路由分发、协议转换、聚合编排等"横切关注点"后再转发给后端服务。是把跨业务的通用能力从各服务剥离的统一抽象层。

## 核心要点

- **核心职责**
  - **路由(Routing)**:按 URL/Host/Header 把请求路由到对应后端服务
  - **认证授权(AuthN/AuthZ)**:JWT/OAuth2/API Key 校验,免去每服务重复实现
  - **限流(Rate Limiting)**:见 [[限流]],防过载
  - **熔断与降级**:见 [[熔断与降级]],下游故障时快速失败
  - **协议转换**:HTTP ↔ gRPC / WebSocket / GraphQL
  - **聚合(BFF / Aggregation)**:一次请求调用多个后端,返回组合结果,减少客户端往返
  - **监控可观测**:统一打点、日志、追踪,见 [[可观测性三支柱]]
  - **缓存**:对相同请求返回缓存响应
  - **SSL 终止**:统一处理 HTTPS,后端走 HTTP
  - **CORS / 跨域处理**:统一配置
- **典型实现**
  - **Kong**:Nginx + Lua,插件丰富,声明式配置
  - **APISIX**:基于 etcd 配置,云原生,性能高
  - **Spring Cloud Gateway**:Java/Spring 生态首选,响应式编程
  - **Zuul**:Netflix 早期 LB+网关,Zuul2 已退役
  - **AWS API Gateway**:Serverless,集成 Lambda
  - **Tyk / Express Gateway**:Node.js 生态
  - **Envoy**:本是 [[服务网格]] 数据面,也常作 API 网关(L7 智能路由)
- **架构位置**
  - 客户端 → CDN → DNS / 入口 LB → API 网关 → 后端服务
  - 网关上游是 [[负载均衡]],下游是 [[微服务]]
  - 内部服务间调用通常不经过网关,走 [[服务网格]] 或直连
- **BFF(Backend For Frontend)模式**
  - 不同客户端(Web、iOS、小程序)需要不同聚合
  - 为每客户端建一个 BFF 网关,定制响应格式
  - 例:Netflix 为 iOS / Android / TV 各自维护 BFF
  - 减少客户端复杂度,代价是 BFF 数量增加
- **API 网关 vs 服务网格 vs 反向代理**
  - **反向代理(Nginx)**:仅转发 + 简单负载均衡
  - **API 网关**:面向"南北流量"(外 → 内),功能丰富
  - **服务网格**:面向"东西流量"(内部服务间),关注通信治理
  - 三者职能有重叠,常组合使用
- **设计原则**
  - **薄网关**:只做横切关注点,不藏业务逻辑
  - **无状态**:水平扩展友好,会话存外部 KV
  - **配置即代码**:声明式 + 版本控制(GitOps)
  - **插件化**:认证、限流、监控等用插件而非硬编码
  - **避免成单点**:网关本身要 HA,多副本 + 健康检查
- **典型坑**
  - **网关性能瓶颈**:网关复杂逻辑成单点,QPS 上来后是瓶颈
  - **聚合层过度膨胀**:把业务逻辑塞网关,变成"大网关"
  - **认证逻辑下沉到服务**:网关只校验 token,业务级权限由服务做(避免网关知道太多业务)
  - **熔断阈值不合理**:导致级联故障
- **现代趋势**
  - **GraphQL 网关**:统一查询,客户端按需取
  - **gRPC-Gateway**:HTTP ↔ gRPC 自动转换
  - **eBPF 网关**:绕过用户态加速
  - **Serverless 网关**:无服务器集成(AWS API Gateway + Lambda)

## 和其他概念的关系

API 网关与 [[服务发现]]、[[负载均衡]] 协同工作:网关从注册中心拉取后端列表后做请求转发。

L7 [[负载均衡]] 与 API 网关在功能上有大量重叠(Kong/APISIX 实际都是 L7 LB+插件)。

API 网关承担入向流量的 [[限流]]、[[熔断与降级]]、[[幂等性]] 校验等通用治理。

[[微服务]] 架构通常 API 网关 + [[服务网格]] 双层:网关处理南北流量、网格处理东西流量。

[[Web安全]] 中的认证、授权、CSRF/CORS 处理多在网关层统一实施。

[[RESTful API]]、GraphQL、gRPC 等接口风格通常透过网关对外暴露。
