# 会计科目体系

## 定义

**会计科目体系**(Chart of Accounts, CoA)指企业按 [[会计要素]] 与经济业务性质分类设置的、用于归集与分类记录交易的**标准化账户名称及编码体系**。它是连接"原始凭证 → 财务报表"的中间层,既是会计核算的载体,也是管理决策、税务申报、监管报告的数据骨架。

## 核心要点

### 按要素分类

| 大类 | 编码段(中国 CAS) | 例子 |
|---|---|---|
| **资产类** | 1xxx | 库存现金、银行存款、应收账款、原材料、固定资产 |
| **负债类** | 2xxx | 短期借款、应付账款、应交税费、长期借款 |
| **共同类** | 3xxx | 衍生工具、套期工具(银行业用) |
| **所有者权益类** | 4xxx | 实收资本、资本公积、盈余公积、未分配利润 |
| **成本类** | 5xxx | 生产成本、制造费用、劳务成本 |
| **损益类** | 6xxx | 主营业务收入、主营业务成本、销售费用、管理费用 |

### 编码层级

通常分四级:
- **一级科目**:由准则统一规定,如"应收账款"
- **二级科目**:企业根据需要细分,如"应收账款—甲客户"
- **明细科目 / 辅助核算**:更细分类,如按部门、产品、项目

现代 ERP 多采用"会计科目 + 多个辅助核算维度"的设计,而非把所有维度都做成科目层级。

### 设置原则

- **合规性**:符合企业适用的会计准则(中国 CAS、IFRS、US GAAP)
- **完整性**:覆盖所有经济业务
- **稳定性**:不轻易增删,保证可比性
- **细致性 vs 简便性平衡**:过细导致维护负担,过粗丧失分析能力
- **与报表对应**:每个科目最终映射到某张报表的某一行

### 与报表的对应

- 资产 + 负债 + 所有者权益类科目期末余额 → [[资产负债表]]
- 损益类科目期间发生额 → [[利润表]]
- 现金流量表通过特殊调整或现金流量表附注采集

### 行业差异

- **制造业**:重视存货、生产成本、制造费用细分
- **零售业**:重视库存、店面成本、营业税费
- **服务业**:重视劳务成本、人工费用
- **金融业**:大量金融工具、风险准备金科目
- **房地产**:开发成本、预收款、土地科目

### 数字化趋势

- **ERP 全面取代手工记账**:科目体系内嵌于 SAP、Oracle、用友、金蝶等系统
- **多语言、多准则、多币种**:跨国公司同一交易可同时按 IFRS、US GAAP、本地准则报告
- **分析维度独立**:科目维持简洁,部门、产品、项目等做辅助核算
- **AI 辅助分类**:OCR + NLP 自动识别票据并建议会计科目

## 和其他概念的关系

- 是 [[复式记账法]] 落地的载体
- 实现 [[会计要素]] 的具体分类
- 服务 [[会计循环]] 中"日记账 → 总账"的过账
- 直接对应 [[资产负债表]] 与 [[利润表]] 的报表项
- 是 [[内部控制]] 中科目使用规范的基础
