# 失业理论

## 定义

**失业率(Unemployment Rate)**:失业人数占劳动力总数(就业 + 失业)的百分比。

```
失业率 = U / (E + U) × 100%
```

失业的统计标准:愿意工作、有能力工作、正在积极寻找工作但未找到工作的人数。**未找工作的灰心者(discouraged workers)** 不计入劳动力,可能造成统计低估。

失业是 [[GDP核算]]、[[价格指数与通胀]] 之外的第三个宏观核心变量,是社会稳定与经济政策的关键关注点。

## 核心要点

### 关键劳动力指标

| 指标 | 公式 | 含义 |
|---|---|---|
| 失业率 | U/(E+U) | 失业占劳动力比例 |
| 就业率 | E/(E+U) | 就业占劳动力比例 |
| 劳动参与率 | (E+U)/POP | 劳动力占工龄人口比例 |
| 就业人口比 | E/POP | 就业占工龄人口比例 |

劳动参与率长期下降(老龄化、教育延长、非工作选择增加)是发达国家共同趋势,会导致失业率"看似改善"但就业率不变。

### 失业的四种类型

**1. 摩擦性失业(Frictional)**:
- 求职匹配过程中的短期失业(毕业找工、跳槽间隙)
- 自愿性、信息成本性、不可消除
- 政策方向:就业服务、信息平台

**2. 结构性失业(Structural)**:
- 经济结构变迁导致技能/地理不匹配
- 长期性、技术进步与产业转型的副产物
- 政策方向:再培训、教育投资、地区协调

**3. 周期性失业(Cyclical)**:
- 由经济衰退、总需求不足导致
- 与 [[GDP核算]] 缺口相伴(奥肯定律:Y 缺口每 2-3% 对应 U 缺口 1%)
- 政策方向:扩张性 [[财政政策]]、[[货币政策]]

**4. 季节性失业(Seasonal)**:
- 农业、旅游业、建筑业等行业的季节性波动
- 可预测、临时性
- 数据上通常做季节调整

### 自然失业率

**自然失业率(NAIRU, Non-Accelerating Inflation Rate of Unemployment)**:不引发通胀加速的失业率水平。

```
自然失业率 = 摩擦性失业 + 结构性失业
当前失业率 − 自然失业率 = 周期性失业
```

当 U > NAIRU,通胀压力下行;U < NAIRU,通胀压力上行。这是 [[菲利普斯曲线]] 的核心思想,也是 [[货币政策]] 紧/松判断的基础。

NAIRU 在不同国家、不同时期不同(美国估计 4-5%,欧洲历史 8-10%),受劳动力市场制度(最低工资、工会、福利、解雇规制)影响极大。

### 失业的成本

**经济成本**:
- 产出损失(奥肯定律量化)
- 人力资本贬值(长期失业者技能退化)
- 财政损失(失业救济 + 税收减少)

**社会成本**:
- 心理健康(抑郁率上升)
- 家庭破裂、犯罪率
- 社会信任与政治稳定

**长期失业的滞后效应(hysteresis)**:长期失业者很难再就业,自然失业率本身可能因衰退而上升 —— 这是"工资黏性"的根源之一。

### 工资黏性与失业

为何工资不随失业上升而立即下降?
- **效率工资**:支付高于市场出清的工资以激励员工(Shapiro-Stiglitz)
- **隐性合约**:雇主分担风险
- **内部-外部理论**:在职员工议价力高于求职者
- **菜单成本**:调整工资有成本

工资黏性是凯恩斯主义存在周期性失业的核心机制,也是 [[菲利普斯曲线]] 短期负斜率的基础(详见 [[凯恩斯]])。

### 政策选择

**需求管理**(应对周期性失业):
- 扩张性 [[财政政策]]:增 G、减 T
- 扩张性 [[货币政策]]:降息、增加货币供给
- 见 [[IS-LM模型]]、[[AD-AS模型]]

**供给管理**(应对结构性失业):
- 教育与职业培训
- 劳动力市场改革(降低解雇成本、灵活就业)
- 创业支持与产业升级

**就业服务**:
- 求职信息平台
- 失业救济(避免过度补偿造成"福利陷阱")

## 和其他概念的关系

失业理论与 [[GDP核算]] 通过奥肯定律相联,与 [[价格指数与通胀]] 通过 [[菲利普斯曲线]] 相联,三者构成宏观核心三角。

[[IS-LM模型]] 与 [[AD-AS模型]] 中产出缺口直接对应失业率缺口;长期 LRAS 处对应自然失业率;NAIRU 是央行 [[货币政策]] 的关键参照。

[[财政政策]] 与 [[货币政策]] 在衰退期间共同对抗周期性失业;[[经济增长理论]] 在长期决定潜在产出与就业容量;[[国际贸易理论]] 中贸易冲击造成的结构性失业是反全球化政治的根源之一。

跨域:[[行为金融学]] 与 [[行为经济学]] 中长期失业心理研究为社会保障设计提供依据;[[投资决策框架]] 中失业率是经济周期判断的核心信号(失业率上行往往领先于股市低点),影响 [[资产配置]] 与 [[基本面分析]] 中的宏观判断;[[商业银行]] 信贷违约率与失业率高度相关,是 [[风险识别与度量]] 的核心宏观因子。
