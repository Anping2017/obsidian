# 营销日历

## 定义

营销日历(Marketing Calendar / Editorial Calendar)是把全年的营销节点(节日、电商大促、行业事件、产品发布)、品牌活动、内容产出排程汇总到一个时间表的规划与执行工具。它的核心价值是把"零散的营销动作"转为"有节奏的内容剧本",让团队提前 1-3 个月备战大节点,避免临时抱佛脚导致的低质内容,并保障跨渠道(SEM / 信息流 / KOL / 私域 / 邮件)的协同节奏。

## 核心要点

**典型营销日历结构(分层)**:

### 第 1 层 — 全年战略节点

中国电商:

- **3.8 女神节**:女性消费品爆发期。
- **5.20 / 6.18**:618 大促,京东 / 天猫 / 小红书都参与。
- **8.18 苏宁周年**。
- **9.9 拼多多大促**。
- **10.1 国庆**:出行、家居。
- **11.11 双 11**:全年最大,准备 2-3 个月。
- **12.12 双 12 / 双蛋节**。
- **春节 / 元旦**:礼品 + 团圆主题。

国际:

- **春节、清明、端午、中秋、国庆、双 11、双 12**(亚洲市场)。
- **黑五、网一、圣诞**(欧美电商)。
- **斋月、开斋节**(中东市场)。
- **印度排灯节**。

### 第 2 层 — 行业 / 品牌专属节点

- **3C 品类**:Apple WWDC(6 月)、华为发布会、小米发布会、CES、IFA。
- **美妆**:520 / 七夕 / 双 11 / 圣诞 / 春节。
- **母婴**:520 / 母亲节 / 父亲节 / 儿童节 / 七夕。
- **健身**:春节后(减肥)、夏季前(露肉季)、双 11(囤货)。

### 第 3 层 — 品牌自有事件

- 新品发布、品牌周年庆、用户日、CEO 直播、品牌联名。

### 第 4 层 — 内容产出排期

- 每日 / 每周固定栏目。
- 大节点专题。
- 实时热点应对。

**日历维度(列结构)**:

| 字段 | 说明 |
|---|---|
| **日期** | 具体日 / 时段 |
| **节点 / 主题** | 双 11、520、新品发布 |
| **目标** | 销售 / 拉新 / 品牌曝光 / 私域转化 |
| **预算** | 该节点预算分配 |
| **渠道** | SEM / 信息流 / 小红书 / 抖音 / 私域 / 邮件 |
| **内容** | 笔记 / 短视频 / 直播 / Push / 邮件 |
| **达人 / 合作** | 邀请的 KOL / 合作品牌 |
| **责任人** | 内容 / 投放 / 私域 / 设计 |
| **截止时间** | 内容产出 / 上线时间 |
| **依赖** | 设计图 / 视频 / 落地页 |

**节奏化排程模板(以双 11 为例)**:

```
T-90 天(8 月初):立项 + 战略目标 + 预算锁定
T-60 天(9 月初):产品准备 + 内容大纲 + 达人接洽
T-45 天(9 月底):落地页设计 + 素材初稿 + 投放策略
T-30 天(10 月中):预热期内容上线(种草启动)
T-15 天(10 月底):拉收藏期(优惠券预发)
T-7 天(11 月 4 日):蓄水期(直播倒计时)
T-3 天(11 月 8 日):预售开启
T-1 天(11 月 10 日):决战日预备 + 24 小时直播
T-0(11 月 11 日):正日 + 全力冲量
T+1 天(11 月 12 日):返场 + 数据复盘
T+30 天(12 月 11 日):RFM 复盘 + Win-back
```

每个时段都有具体的 KPI 与执行项。

**协同工具**:

- **Asana / Monday / 飞书多维表格 / Notion**:看板式排期,支持多视图。
- **Google Calendar / 飞书日历**:节点同步全员。
- **Slack / 飞书群**:实时沟通。
- **甘特图(Gantt)**:依赖关系可视化。
- **Trello**:轻量内容看板。

**版本化管理**:

- **年度营销日历**:战略层面,每年 12 月制定下一年。
- **季度日历**:细化到周。
- **月度日历**:细化到日 + 责任人。
- **周日历**:执行级,每周一列出本周交付物。

**跨渠道协同要点**:

- **SEM / SEO 提前布关键词**:大节点的搜索词热度提前 30 天上涨。
- **信息流广告提前训练**:新素材冷启动需 7-14 天磨合,大节点前要早投。
- **KOL / 达人提前 30-45 天 brief**:档期紧张需提前锁定。
- **私域 / 邮件分阶段触达**:预热 / 决策 / 决战 / 售后四阶段不同内容。
- **客服话术预演**:常见问题 + 优惠规则 + 投诉处理预案。

**热点借势**:

- 行业突发事件(竞品翻车、明星代言、政策变化)→ 24 小时内决策是否借势。
- 借势的 3 个原则:**与品牌相关**、**速度**、**不冒犯**。

**反模式**:

- **临时抱佛脚**:大节点前 1 周才开始准备 → 内容质量低,跨渠道不协同。
- **节点堆砌不取舍**:每个节点都参与,资源摊薄,无重点突破。
- **日历不更新**:静态计划忽略实际市场变化。
- **不复盘**:每年同样错误重复,不积累经验。
- **跨部门信息不通**:营销 / 销售 / 客服 / 物流互相不知节点细节。

**度量**:

- 各节点 ROI(销售额 / 投入)。
- 各节点 vs 上年同期增长率。
- 各节点 vs 竞品市场份额。
- 团队按时交付率。

## 和其他概念的关系

营销日历是 [[整合营销传播]] 与 [[全渠道营销]] 的执行抓手,把 [[内容营销]]、[[搜索广告]]、[[信息流广告]]、[[小红书种草]]、[[KOL营销]]、[[私域流量运营]]、[[邮件序列设计]] 等不同战术统一在时间维度。

它与 [[营销自动化]] 平台中"工作流"的关系类似工程师的"项目计划 vs 任务执行"——日历是策略层,自动化是执行层。日历的精度与 [[数据驱动营销]] 提升正相关——数据反馈让下一年的日历更精准。

[[B2B营销]] 的日历周期不同(决策周期长 6-12 个月),节点更多围绕展会、白皮书、客户大会而非电商大促。在 [[品牌定位]] 中,什么节点参与什么不参与,就是品牌调性的具体体现(奢侈品不参与双 11)。
