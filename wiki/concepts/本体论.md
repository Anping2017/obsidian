# 本体论

## 定义

**本体论**(Ontology,源自希腊语 ontos = 存在 + logos = 学说)是 [[形而上学]] 的核心子领域,研究**什么东西存在、以何种方式存在、存在的基本范畴是什么**。它不问"这朵花是红的吗",而问"颜色作为属性是否独立存在"。

## 核心要点

### 核心问题

1. **存在分几类?**:实体、属性、关系、事件、过程、抽象对象?
2. **什么是基础实在?**:物质、心灵、信息、过程?
3. **共相是否存在?**:"红"作为普遍性是实存的还是仅仅命名?
4. **数学对象的存在?**:数字、集合是发现还是发明?

### 主要立场

| 立场 | 主张 | 代表 |
|---|---|---|
| **唯物主义** | 只有物质实在 | 德谟克利特、马克思、丘奇兰德 |
| **观念论** | 心灵/观念是基础 | 柏拉图、贝克莱、黑格尔 |
| **二元论** | 心灵与物质都基本 | 笛卡尔 |
| **中性一元论** | 二者都源自更基本第三者 | 斯宾诺莎、罗素 |
| **实体一元论** | 只有一种实体(神或自然) | 斯宾诺莎 |

### 共相之争(中世纪经典议题)

- **唯实论(Realism)**:共相独立存在(柏拉图式或亚里士多德式)
- **唯名论(Nominalism)**:共相只是名称,只有殊相实存(奥卡姆)
- **概念论(Conceptualism)**:共相只在心灵中作为概念

### 当代分析本体论

- 蒯因:"存在就是变量的值" —— 量化承诺(quantifier commitment)
- 戴维森:事件本体论
- 自然种类(Natural Kinds):水、金等是否有客观本质
- 三层本体:基本物理实在 → 涌现的化学/生物 → 心灵与社会

### 本体论的实用化

- **领域本体**:在 AI、知识图谱、Semantic Web 中,"ontology"指特定领域中的概念分类与关系
- 本体论已从纯哲学议题扩展到**信息系统建模**

## 和其他概念的关系

- 本体论是 [[形而上学]] 的核心 —— 多数语境下二者可互换
- [[二元论|心物二元论]] 是本体论的经典立场
- [[理念论]] 是柏拉图式的本体论立场:理念为根基
- 与 [[认识论]] 互相约束:能认识的限定可存在的提问
- [[现象学]] 主张悬置存在判断,直接描述现象
- 在 AI 领域延伸为知识表示的"领域本体"
