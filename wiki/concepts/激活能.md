# 激活能

## 定义

**激活能**(Activation Energy)作为思维模型,源于化学动力学:**反应物分子必须越过的能量势垒,才能打断旧化学键、形成新化学键**。势垒以下,即使反应物理论上能放出能量,反应也不会自发发生。把它当透镜,可以理解一切"为什么改变这么难起步"的现象 —— 习惯养成、组织转型、关系修复都需要先过那道势垒。

## 核心要点

### 化学本源

- 反应物 → 中间过渡态 → 产物
- 即使产物比反应物能量更低(放热),也必须先注入能量越过势垒
- 没有这门"入场费",反应永远不会开始

### 现实世界的势垒

| 场景 | 势垒形式 |
|---|---|
| 健身习惯 | 第一次穿鞋出门 |
| 写作 | 打开文档、写第一段 |
| 创业 | 辞职 + 注册公司的那一刻 |
| 公司转型 | 高层决心 + 第一笔预算 |
| 困难对话 | 主动开口的勇气 |

### 一次性成本 vs 永久阻碍

- **关键洞见**:激活能是**一次性的启动成本**,不是永久障碍
- 反应一旦开始,后续靠反应放出的能量自我维持
- 习惯一旦形成,后续运行成本极低(参见 [[最小能量倾向]])

### 降低激活能的方式

1. **加催化剂**:导师、伙伴、工具(参见 [[催化剂]])
2. **预先布置环境**:把第一步变得不可能拒绝
3. **拆解粒度**:把大目标拆成小到无法失败的第一步
4. **公开承诺**:用社会压力补足初始能量
5. **绑定既有习惯**:Habit stacking,借已有反应"接力"

### 错误归因

- 很多人把"开始难"误判为"我不行" —— 其实只是势垒还没翻过去
- 看到他人轻松产出,误以为他们没费力 —— 实际上他们已翻过势垒,正在被反应释放的能量推动

## 应用场景

- **产品冷启动**:用户首次注册到首次价值体验之间,就是产品要降的激活能
- **学习新技能**:第一周最痛,过了这周,正反馈接管
- **写作**:很多写作老师说"先写糟糕的草稿"就是为了降势垒
- **企业创新**:内部创新基金的本质是为新项目支付激活能
- **戒除依赖**:戒烟最难的是前 72 小时,过去就显著容易

## 局限与陷阱

- **误以为持续高能量**:翻过势垒后还硬撑高能量,反而把自己耗尽
- **过度乐观**:以为只要开始就会成功 —— 反应方向也要对(参见 [[速度]])
- **忽略反应物质量**:激活能是必要条件,不是充分条件 —— 没有"反应物"(资源、能力)再多能量也白费
- **混淆激活能与坚持**:激活能解决"开始",坚持解决"持续",两者机制不同
- **环境劣化**:即使过了一次势垒,环境恶化时势垒会重新升高
- **忽视退路**:有人把激活能投入后,因小障碍重新跨回起点 —— 应想办法"锁住"反应

## 与其他概念的关系

- 与 [[催化剂]] 直接配合:催化剂的核心功能就是降低激活能
- 与 [[惯性]] 等价于物理表述 —— 惯性是质量阻力,激活能是能量阻力
- 与 [[最小能量倾向]] 互补:最小能量解释为何不愿动,激活能解释要动需多少
- 与 [[复利效应]] 配合:激活能后是反应自维持 → 时间复利
- [[杠杆]] 是放大反应强度的方法,激活能是反应启动的门槛
- 与 [[激励]] 协同:外部激励有时就是为人提供激活能
- [[战略思维]] 中"什么是高 ROI 的第一步"本质是寻找最低激活能突破口
