# 实用主义

## 定义

**实用主义**(Pragmatism)是 19 世纪末诞生于美国的哲学传统,以**皮尔斯(C. S. Peirce)、威廉·詹姆斯(William James)、约翰·杜威(John Dewey)** 为奠基者。核心立场:**思想的意义在于其实践后果,真理的标准是工作有效性**。是美国本土最重要的哲学贡献。

## 核心要点

### 皮尔斯准则

> "考察一个概念的对象会有什么实际后果。这些后果的总和就是该概念的全部意义。"

- 概念的意义由它在实际经验中可能产生的后果定义
- 没有后果差别的形而上学争论是**伪问题**
- 与维特根斯坦"意义即用法"在结构上相通(详见 [[维特根斯坦]])

### 詹姆斯的真理观

- **"真理就是行得通"**(it works,what works is true)
- 真理是一种**事件**,在验证过程中**变成**真
- 与符合论(真理 = 与事实相符)、融贯论(真理 = 内部一致)对立
- 诉诸经验、效果、引导力

### 杜威的工具主义

- **观念是工具**,不是镜像
- 思维是问题—解决的过程:遇到困境→提出假设→检验→修正
- 教育即生活、做中学(learning by doing)
- 影响美国现代教育、 [[皮亚杰认知发展]] 之"主动建构"取向

### 反基础主义

- 拒绝寻找"知识的最终基础"(笛卡尔式 cogito、洛克式简单观念)
- 知识是**正在进行的探究共同体**的产物
- **可错论**(fallibilism):任何信念都可能错,都开放修订
- 这是 [[科学方法]]、 [[贝叶斯]] 思维的哲学共鸣

### 三阶段历史

- **古典实用主义**(1870-1940):皮尔斯、詹姆斯、杜威、米德
- **逻辑实用主义**(20 世纪中):奎因、塞拉斯、戴维森、罗蒂
- **新实用主义**(20 世纪末-今):罗蒂、普特南、布兰顿、哈贝马斯部分采纳

### 与其他流派关系

- **经验主义传承**:把英国经验论本土化、美国化
- **达尔文主义**:把进化—适应观念引入哲学
- 与 [[分析哲学]] 既对立又对话,奎因后逐渐融合
- 与 [[现象学]] 主体—世界关系有共鸣
- 反对 [[理性主义]] 的先验路径,但比英国经验论更重视行动

### 在公共领域的延伸

- **教育**:杜威的进步主义教育、芝加哥大学实验学校
- **政治**:民主作为生活方式而非投票机器
- **法律**:霍姆斯大法官"法律的生命不在逻辑而在经验"
- **心理学**:詹姆斯《心理学原理》(1890)开启美国心理学
- **管理学**:行动学习、设计思维都有实用主义血统

### 实用主义的批评

- **被斥为"用处即真理"的庸俗化**:詹姆斯被嘲为"现金价值真理论"
- **罗蒂等被批"反实在论"**:似乎放弃客观真理
- **缺乏批判维度**:法兰克福学派批评其与资本主义共谋
- 但当代实用主义已大幅细化与回应

## 和其他概念的关系

- 与 [[经验主义]] 直接传承,但更强调行动
- 与 [[理性主义]] 反基础主义对立
- 与 [[认识论]] 之"真理理论"
- 与 [[科学方法]]、 [[贝叶斯]] 在可错论上相通
- 与 [[皮亚杰]] [[皮亚杰认知发展]] 中"建构主义"血缘
- 与 [[卡尼曼]] 行为决策可作"实践理性"对话
- 与 [[第一性原理]] 在反对"先验权威"上相通,但反对其根基论
- 影响 [[积极心理学]] 之"行动"取向
- 与 [[禅宗]] "实践即悟" 在精神上有可比之处
- 与 [[商业模式]]、 [[管理决策]] 之"行得通就用"传统
- 是美国 [[公司治理]] 实用倾向的哲学背景
- 历史定位:美国本土最具世界影响的哲学传统
