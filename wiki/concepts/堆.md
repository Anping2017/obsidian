# 堆 Heap

## 定义

**堆(Heap)**是一种特殊的[[树]]型[[数据结构]],满足两个条件:
- **结构性**:是**完全二叉树**(除最后一层外满,最后一层从左向右填充)
- **堆序性**:每个节点 ≥ 其子节点(**最大堆**)或 ≤ 其子节点(**最小堆**)

由于完全二叉树可用[[数组]]隐式存储 —— 节点 i 的左子是 2i+1,右子是 2i+2,父是 (i-1)/2 —— 堆通常用一段连续数组实现,无需指针。

注意:这里的"堆"是数据结构,与[[操作系统]]中"堆内存(heap memory)"是不同概念。

## 核心要点

### 操作复杂度

| 操作 | 复杂度 | 说明 |
|---|---|---|
| peek (取极值) | O(1) | 根节点 |
| insert (push) | O(log n) | 上浮(sift-up) |
| extractMax/Min (pop) | O(log n) | 下沉(sift-down) |
| heapify(建堆) | O(n) | 自底向上 |
| 删除任意节点 | O(log n) | 需要先定位 |

`heapify` 是关键技巧:n 个元素直接逐个 insert 是 O(n log n),但自底向上调整是 O(n)。证明用调和级数。

### 堆排序(Heap Sort)

1. heapify 建最大堆(O(n))
2. 反复 swap(arr[0], arr[end]) 后下沉,有序部分从后往前增长
3. 总复杂度 O(n log n),原地排序、不稳定

### 优先队列(Priority Queue)实现

堆是优先队列最常见实现:
- 入队 / 出队 O(log n)
- 取最高优先级 O(1)

C++ `priority_queue`、Python `heapq`、Java `PriorityQueue` 都基于堆。

### 重要应用

1. **Top-K 问题**:维护大小为 K 的最小堆(求最大 K),复杂度 O(n log K),空间 O(K)
2. **Dijkstra 最短路径**:用最小堆维护"未确定的最近顶点"
3. **Huffman 编码**:每次合并两个最小频率节点
4. **任务调度**:CPU 调度、网络包优先转发
5. **流式中位数**:大顶堆 + 小顶堆各存一半,O(log n) 维护
6. **A\* 搜索**:开放列表(open list)用最小堆按 f(n) 排序
7. **流式数据 Top-K**:LeetCode 高频考点

### 二项堆 / 斐波那契堆

更高级的堆,支持 O(1) 摊还合并和 decrease-key,理论上 Dijkstra 可达 O(E + V log V)。但常数大,实际工程很少用。

## 和其他概念的关系

堆是[[树]]的特殊形式(完全二叉 + 偏序),物理上是[[数组]]。它和[[Hash表]]都是基础组合数据结构,但侧重不同:Hash 表 O(1) 查找无序;堆 O(log n) 增删但保持极值。

[[排序算法]]家族中,堆排序是 O(n log n)、原地、不稳定;[[快速排序]]同样 O(n log n) 但缓存更友好,工程更常用。但堆排序最坏仍 O(n log n),关键场景(实时系统)价值高。

[[图]]算法 Dijkstra、Prim 都依赖优先队列。[[操作系统]]的进程调度(实时优先级)、定时器(timer wheel 替代品)、IO 调度也用堆。
