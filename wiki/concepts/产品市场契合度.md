# 产品市场契合度

## 定义

**产品市场契合度(Product-Market Fit, PMF)** 由 Marc Andreessen 在 2007 年博客中提出:

> "PMF 意味着在一个好市场里有一个能满足该市场的产品。"

更具操作性的描述(Sean Ellis):**至少 40% 的现有用户表示"如果不能再用这个产品会非常失望"。**

PMF 是创业的关键转折点:**之前一切都是寻找,之后才是放大**。Andreessen 强调"PMF 之前所有事情都不重要,PMF 之后所有事情都重要"。

## 核心要点

### PMF 的标志(感知信号)

未达 PMF 的状态:
- 用户不告诉别人
- 销售周期长
- 客户流失高
- 媒体没兴趣
- 团队焦虑

达到 PMF 的状态:
- 用户口口相传
- 服务器频繁告警(用得太多)
- 销售一打就成
- 媒体主动找上门
- 招聘时人才主动来

Andreessen 形容:"**PMF 来临时,你能感觉到。**"

### Sean Ellis 测量法

最常用的 PMF 量化指标:

> 问题:"如果你不能再使用这个产品,你会感到?"
>
> 选项:非常失望 / 有点失望 / 不会失望 / 不再使用
>
> **如果"非常失望"≥ 40%,你已达 PMF。**

补充指标:
- **NPS(净推荐值)** ≥ 50
- **DAU/MAU**(粘性) ≥ 20%
- **月留存曲线** 在某点变平(不再衰减)
- **付费转化率** 对比同类显著高
- **客户主动推荐率(viral)**

### PMF 金字塔(Dan Olsen)

从下到上:

```
1. 目标客户
2. 客户未满足需求
3. 价值主张
4. 功能集
5. UX 体验
```

每层支持上层。多数失败因下层错而非上层差。

### 寻找 PMF 的过程

不是单点而是路径:

```
问题假设 → 客户验证 → 解决方案设计 → MVP → 数据
   ↑                                          │
   └────────── Pivot 调整 ←────────────────────┘
```

[[精益创业]] 的 Build-Measure-Learn 循环就是寻找 PMF 的引擎。

### PMF 之后的"踩油门"

达到 PMF 后,工作焦点彻底转变:

| 阶段 | 重点 | 关键问题 |
|---|---|---|
| Pre-PMF | 探索 | 客户是谁? 痛点是什么? 解决方案对吗? |
| Post-PMF | 扩张 | 怎么获客? 怎么留存? 怎么变现? |

过早扩张是创业最大杀手——把不工作的产品砸钱推广,只会更快烧光资金。

### 不同业务的 PMF 信号

| 业务类型 | 关键 PMF 指标 |
|---|---|
| **C 端工具** | 留存 + 频次 + 自传播 |
| **C 端社交** | DAU/MAU + 病毒系数 |
| **C 端电商** | 复购率 + LTV/CAC |
| **B2B SaaS** | 客户流失率 + NPS + ACV |
| **B2B 企业级** | 客户成功故事 + 续约率 |
| **平台型** | 双边活跃度 + 留存交叉率 |

### PMF 的"假阳性"警告

- **早期粉丝偏差**:Reddit 几个铁粉 ≠ 大众市场
- **媒体一波流**:被报道带来短期高峰,无留存
- **付费拉新挖洞**:停广告就消失
- **垂直 PMF**:在某子集 PMF 不等于整个市场 PMF
- **时间延迟**:用户表面满意但 6 个月后流失

### PMF 的可丢失性

PMF 不是终点,可能因竞争、需求变化、自己腐化而丢失:

- 黑莓在 iPhone 时代失去 PMF
- Yahoo 失去搜索 PMF
- Snapchat 在 Instagram Stories 后部分丢失

需要持续创新维持 PMF,同时寻找下一个 PMF。

## 和其他概念的关系

- 是 [[精益创业]] 方法论追求的核心目标
- 衔接 [[创业机会识别]] 与后续 [[增长战略]]
- 验证 [[商业模式画布]] 的"价值主张"是否有效
- 决定 [[风险投资]] 估值与轮次跃迁(Series A 之前必须看 PMF 信号)
- 在 [[战略转型]] 中,大公司也可能"重新寻找 PMF"
- PMF 后才能讨论 [[客户生命周期价值]] 与单位经济
- 与 [[营销定义与本质]] 的"创造价值-传递价值"逻辑一致
- "踩油门"阶段与 [[增长黑客]] 紧密结合
- Andreessen 与 a16z 把 PMF 概念推广为硅谷通用语
- 体现 [[管理决策]] 中"信号-噪声"的判断难题
