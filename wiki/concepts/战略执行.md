# 战略执行

## 定义

**战略执行(Strategy Execution)** 指企业把已制定的战略转化为日常行动并取得预期成果的过程。研究反复证明:**60-90% 的战略未能成功实施**,失败原因多在执行而非制定。

Bossidy 与 Charan 在《Execution》中强调:执行不是战略的"下游环节",而是战略的"内核";好执行 + 一般战略 > 好战略 + 差执行。

## 核心要点

### 战略执行五大支柱

| 支柱 | 内涵 | 关键问题 |
|---|---|---|
| **结构(Structure)** | 组织架构匹配战略 | 是否有人对战略目标负责? |
| **流程(Process)** | 关键流程支撑战略 | 资金、人才、决策流程对齐了吗? |
| **人(People)** | 关键岗位放对人 | 谁是战略的"执行人"? |
| **文化(Culture)** | 行为习惯支持战略 | 文化是助力还是阻力? |
| **考核(Measurement)** | KPI/OKR 闭环 | 如何衡量进度?如何激励? |

战略与五要素任一脱节都会导致执行失败,这就是著名的 **"7S 框架"**(McKinsey:战略、结构、系统、共同价值观、风格、人员、技能)的核心思想。

### 执行的四大障碍(Kaplan-Norton 调研)

1. **愿景障碍**:仅 5% 员工理解战略
2. **人员障碍**:25% 经理的激励与战略挂钩
3. **管理障碍**:85% 高管在战略上花费 < 1 小时/月
4. **资源障碍**:60% 组织预算与战略不挂钩

### 战略地图(Strategy Map):从蓝图到行动

战略地图把战略目标按 [[平衡计分卡]] 四维度可视化为因果链:

```
学习成长(员工/能力/系统)
    ↓
内部流程(运营/客户/创新)
    ↓
客户价值(满意度/留存/份额)
    ↓
财务结果(收入/利润/股东价值)
```

### 关键执行机制

- **PDCA 循环**(Plan-Do-Check-Act):戴明的持续改进
- **OKR**:目标-关键结果,Google 风格透明执行
- **战略复盘(Strategy Review)**:定期(月/季)对照计划-实际差距
- **A3 报告**:丰田 1 页解决问题模板
- **战略沟通**:把战略翻译成员工能理解的语言

### 执行的常见失败模式

| 失败模式 | 表现 | 对策 |
|---|---|---|
| **战略-预算脱节** | 战略目标无资金支持 | 战略预算化 |
| **沟通衰减** | 高层清晰、基层模糊 | 多频道反复传达 |
| **激励不一致** | 考核未挂钩战略 | KPI 重新设计 |
| **责任真空** | 战略目标无具体负责人 | 单一可问责负责人 |
| **变革阻力** | 旧文化抵制新战略 | 见 [[变革管理]] |

## 和其他概念的关系

- 是 [[战略管理]] 闭环的下半部分,与战略制定相辅相成
- 工具上由 [[平衡计分卡]] 与战略地图驱动
- 起点是 [[战略目标设定]] 的 SMART 与 OKR
- 通过 [[绩效管理]] 体系把战略落到 [[KPI]]
- 需要 [[变革管理]] 与 [[变革型领导]] 推动组织转型
- 与 [[组织文化]] 双向作用:战略塑造文化,文化反向制约战略
- 失败时往往需要 [[战略调整]] 或转型
- 在 [[精益生产]]、丰田生产方式中体现为持续改善(Kaizen)与现地现物
- 执行能力本身是 [[动态能力]] 的体现
