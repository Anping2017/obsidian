# 移动优先索引

## 定义

移动优先索引(Mobile-First Indexing, MFI)是 Google 自 2018 年 3 月开始、2023 年 10 月最终全面完成的索引方式变革:Google 用网站的**移动版**作为爬取、索引、排名的主要版本,桌面版仅作为补充。这是对"移动用户已是绝对多数"现实的索引层响应。对网站的影响:移动版若功能 / 内容缺失 / 加载慢,整体 SEO 表现都会下降——即使桌面版完美。

## 核心要点

**响应式设计是首选(Google 推荐)**:

| 移动适配方案 | 描述 | 优势 | 劣势 |
|---|---|---|---|
| **响应式设计** | 同 URL,CSS 响应不同尺寸 | URL 唯一、维护简单、Google 推荐 | 移动性能可能受桌面代码拖累 |
| **动态服务(Dynamic Serving)** | 同 URL,服务端依 User-Agent 返回不同 HTML | 可定制,但需 Vary header | 复杂、易出错 |
| **独立移动站(m.example.com)** | 独立 URL | 性能极致 | 维护成本高、需 rel=alternate / canonical 配对 |

**移动友好性 — 核心要求**:

1. **可视区域(Viewport)正确配置**:`<meta name="viewport" content="width=device-width, initial-scale=1">`。
2. **文本可读**:基础字号 ≥ 16px,行高 ≥ 1.5,无需缩放。
3. **触摸目标**:按钮 / 链接 ≥ 48×48 像素,间距 ≥ 8 像素。
4. **不依赖 Flash 或不支持移动的技术**。
5. **横向无溢出**:页面不需要左右滚动。
6. **重要内容不在折叠下**:首屏 LCP 元素必须可见。

**[[Core Web Vitals]] — 性能三指标**:

- **LCP(Largest Contentful Paint)** ≤ 2.5s:最大内容加载时间。
- **INP(Interaction to Next Paint)** ≤ 200ms(2024 起替代 FID):交互响应。
- **CLS(Cumulative Layout Shift)** ≤ 0.1:布局偏移累计。

移动版本要单独通过这些指标——桌面达标移动不达标,SEO 表现仍差。

**移动 vs 桌面内容一致性**:

- 移动版的内容必须包含桌面版的核心信息。常见错误:移动版隐藏文本、折叠 FAQ、删减作者署名,导致 Google 索引到的是"瘦身版"。
- 结构化数据(Schema.org)必须在移动版完整存在。
- Hreflang 标签必须在移动版存在。
- 内链结构在移动版必须保留。

**测试工具**:

- **Mobile-Friendly Test**(已在 2023 关停)→ 改用 Lighthouse / PageSpeed Insights。
- **Lighthouse**(Chrome DevTools 内置):综合评分 + 性能 / 可访问性 / SEO 报告。
- **PageSpeed Insights**:Web 版 Lighthouse + 真实用户数据(CrUX)。
- **Search Console 移动可用性**(已在 2023 关停)→ 现以 Page Experience 报告替代。
- **Search Console URL 检查工具**:看 Googlebot 抓取的移动版具体 HTML。

**国内特殊性**:

- 百度同样实施移动优先索引,但 ROI 与 Google 不完全对应。
- 国产 ROM 上的 Chrome / 自带浏览器 User-Agent 表现各异。
- 国内 CDN 加速(阿里云 CDN、腾讯云 CDN)对移动 LCP 影响大。

**反模式**:

- 移动版功能阉割(如不能搜索、不能注册)。
- 移动版加载慢(首屏 LCP > 4s)。
- 不响应式 / 不动态服务 → 桌面用户看到移动布局。
- 弹窗 Interstitial 占满首屏 → Google 处罚 "Intrusive Interstitial"。
- 移动版 robots.txt 屏蔽 CSS/JS → Google 无法判断移动友好。

**Google 优先级演进**:

1. **2015**:Mobile-Friendly 算法(Mobilegeddon)。
2. **2018**:开始 MFI 渐进切换。
3. **2020**:Page Experience 信号纳入排名。
4. **2021**:Core Web Vitals 移动指标正式作为排名因素。
5. **2023**:MFI 完全切换,所有新站默认移动索引。
6. **2024+**:INP 替换 FID,Page Experience 整合到 Helpful Content。

## 和其他概念的关系

移动优先索引是 [[技术SEO]] 的基础设施性变革,直接关联 [[Core Web Vitals]] 与 [[Page Experience]] 信号。它是 [[Google搜索工作原理]] 中"爬取与索引"环节的根本变化。

它要求 [[页面SEO]] 在移动场景重新审视——折叠菜单、长内容、复杂表格在移动场景的展示方式直接影响排名。在 [[本地SEO]] 中,移动用户占比更高(用户常在路上查找),Local Pack 与 GBP 的移动表现更关键。

它与 [[响应式设计]]、[[CSS 媒体查询]]、[[Service Worker]]、[[PWA]] 等前端技术深度耦合。在 [[电商SEO]] 中,移动 Conversion Rate 直接影响 [[转化漏斗]] 的整体表现。
