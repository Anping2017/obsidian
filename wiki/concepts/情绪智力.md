# 情绪智力

## 定义

情绪智力(Emotional Intelligence, EI 或 EQ)指个体识别、理解、表达、调节自己与他人情绪,并运用情绪信息指导思维与行为的能力。

- **学术起源**:Peter Salovey 与 John D. Mayer 1990 年首篇学术论文
- **大众化**:Daniel Goleman 1995 年畅销书《Emotional Intelligence》
- **职场应用**:Goleman 1998 年《What Makes a Leader》引爆 HR 兴趣

## 主要模型

### 1. Mayer-Salovey 能力模型(MSCEIT)
四分支能力:

| 分支 | 内涵 |
|---|---|
| **感知情绪** | 准确识别面部、声音、艺术中的情绪 |
| **使用情绪** | 用情绪促进思维(创造、解决) |
| **理解情绪** | 理解情绪原因、转化、组合 |
| **管理情绪** | 调节自己与他人情绪 |

- 用最大化测试(像 IQ),不靠自评
- 学术界更接受

### 2. Goleman 混合模型
五要素:
1. **自我意识**(Self-awareness)
2. **自我调节**(Self-regulation)
3. **动机**(Motivation)
4. **共情**(Empathy)
5. **社交技能**(Social skills)
- 包括能力 + 人格特质 + 动机
- 商业畅销但学术批评其"什么都包"

### 3. Bar-On 情商模型(EQ-i)
五大领域 15 量表:
- 内省(自尊、自我实现等)
- 人际(共情、社交责任)
- 应力管理
- 适应能力
- 一般心境

## 主要测量

| 工具 | 类型 | 用途 |
|---|---|---|
| **MSCEIT** | 能力测试 | 学术研究 |
| **EQ-i** | 自评 | 临床、教练 |
| **TEIQue**(Petrides) | 自评 | 学术 |
| **ESCI**(Goleman) | 360 度 | 企业领导力 |
| **WLEIS** | 自评短版 | 跨文化 |

## 神经基础

- **杏仁核**:情绪检测、恐惧
- **腹内侧前额叶**:情绪调节
- **岛叶**:内感受、共情
- **眶额皮层**:奖励、社会决策
- 镜像神经元系统(争议):自动模仿与共情
- 多迷走神经理论(Polyvagal):社交连接神经基础

## 情绪调节策略(Gross 模型)

| 阶段 | 策略 |
|---|---|
| 情境选择 | 避开导致负面情绪的情境 |
| 情境调整 | 改变情境特征 |
| 注意分配 | 分散或聚焦注意 |
| **认知重评** | 改变情境意义解释 |
| **反应调节** | 抑制表达、放松 |

研究显示**认知重评**最有效,长期抑制反而损害健康。

## 应用领域

### 1. 领导力
- "情商比 IQ 更预测领导成功"(Goleman 主张)
- 情绪传染:领导情绪影响团队
- 真诚领导、变革型领导根基
- [[变革型领导]] 与 EI 强相关

### 2. 团队
- 心理安全感建立
- 冲突管理
- [[团队动力学]] Tuckman 阶段中起润滑

### 3. 教育
- SEL(社交情绪学习)校本课程
- CASEL 五能力框架
- 与 [[积极心理学]] 整合

### 4. 临床
- 边缘型人格障碍 DBT 情绪调节模块
- 抑郁、焦虑情绪调节训练
- 自闭症谱系干预

### 5. 销售与客服
- 情绪劳动管理
- 客户共情

### 6. 跨文化
- 面部识别准确率跨文化稳定但有差异
- 情绪规则文化不同(显示规则)

## 与其他概念关系

- 与 [[共情]] 重叠但更宽
- 与 [[大五人格]] 神经质负相关、宜人性正相关
- 与 [[性格优势]] 仁爱组高度相关
- 与 [[自我效能]] 互补:能力信念 + 情绪能力
- 是 [[领导力]] 重要组件
- 与 [[变革型领导]] 强连接
- 与 [[团队建设]] 心理安全感、[[组织文化]] 相关
- 与 [[认知行为疗法]] 情绪—思维链整合
- [[卡尼曼]] 双系统:EI 是 System 1 与 System 2 之间的桥
- 与 [[正念]] 互补提升情绪觉察

## 批评

- 概念边界模糊,与人格特质重叠
- 商业过度宣传(Goleman 模型)
- 自评偏差严重(社会期望)
- "EQ 比 IQ 更重要"主张缺乏支持
- 跨文化效度限制
- "暗面 EI":高情商可被用于操纵(自恋型)

## 当代议题

- AI 情绪识别(affective computing)
- 数字时代情绪劳动外包
- 远程工作中的情绪连接
- 神经多样性视角(自闭谱系)
- 元素情绪 vs 复合情绪争论
- 文化普适性 vs 建构主义辩论(Lisa Feldman Barrett)
