# 皮格马利翁效应

## 定义

**皮格马利翁效应**(Pygmalion Effect)指**他人(特别是权威者)对个体的期望会通过日常互动潜移默化地影响个体行为,最终使期望成真**。

名称源于希腊神话:塞浦路斯雕刻家皮格马利翁深爱自己雕刻的少女像,以至于雕像被女神赋予生命。心理学层面由 Robert Rosenthal 与 Lenore Jacobson 在 1968 年的"哈佛实验"中证实——又称 [[罗森塔尔效应]]。

它是**自我实现预言**(Self-Fulfilling Prophecy, Robert Merton 1948)在期望领域的具体形态。

## 核心要点

### 经典实验:Pygmalion in the Classroom (1968)

- Rosenthal 在小学随机告诉教师某些学生是"高潜力者"(实际随机抽取)
- 一年后,这些"高潜力"学生 IQ 实际增长显著高于对照组
- 解释:教师对他们更关注、更耐心、提供更多挑战与反馈

### 期望转化为表现的四条路径

Rosenthal 1973 总结的"四因素模型":

| 因素 | 内容 |
|---|---|
| **气候(Climate)** | 高期待者获得更温暖的非言语信号 |
| **输入(Input)** | 高期待者获得更多教学/资源 |
| **机会(Output)** | 高期待者被给予更多回答/参与机会 |
| **反馈(Feedback)** | 高期待者得到更具体、更建设性的反馈 |

### 反向:格兰效应(Golem Effect)

低期望同样会自我实现——被低估的学生表现更差,这是皮格马利翁效应的暗面,在教育公平、性别偏见、刻板印象中尤为有害。

### 与相关概念的区分

| 概念 | 核心 |
|---|---|
| **皮格马利翁效应** | 他人期待 → 个体表现 |
| **自我实现预言** | 信念 → 行为 → 结果验证信念(更广) |
| **加拉太亚效应** | 自己对自己的期待 → 自身表现 |
| **格兰效应** | 低期待 → 低表现 |
| [[罗森塔尔效应]] | 同名,以实验者命名 |
| [[首因效应]] | 第一印象主导 |

## 应用场景

- **教育**:教师期待塑造学生学业表现,差异化对待最严重隐患
- **领导力**:管理者高期待 → 员工高产出,见 [[变革型领导]]、[[激励理论]]
- **临床医学**:医生对治愈的乐观会影响患者依从性与康复
- **运动训练**:教练相信运动员潜力 → 实际突破
- **亲子关系**:父母期待塑造孩子自我形象
- **客服与销售**:对客户的"假设友好"促成实际友好

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **复制困难** | Rosenthal 原实验效应规模在元分析中弱化 |
| **不能造假** | 单纯说"我相信你"无效,关键是真实行为差异 |
| **群体伤害** | 对低期待群体的隐性贬抑造成系统不公 |
| **过度乐观** | 期望脱离现实导致后续失望与压力 |
| **混淆自变量** | 期待 vs 资源 vs 关注难分离 |

## 与其他概念的关系

- 与 [[罗森塔尔效应]] 同名相生
- 与 [[自我实现预言]] 是父子概念
- [[成长型思维]](Carol Dweck)与之协同——成长信念是元层皮格马利翁
- 与 [[自我效能]](班杜拉)互补——前者来自他人,后者来自自身
- [[刻板印象威胁]] 是其在群体层面的反向作用
- [[棉花糖实验]]、[[米尔格拉姆服从实验]] 同属社会心理学经典
- 与 [[变革型领导]]、[[领导力]] 中"激励"维度深度耦合
- 与 [[首因效应]]、[[晕轮效应]] 共同构成印象管理三角
