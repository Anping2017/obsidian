# 精神分析

## 定义

**精神分析**(Psychoanalysis)是 19 世纪末由 [[弗洛伊德]] 创立的心理学—心理治疗流派。其核心命题是:**潜意识决定行为**,被压抑的欲望与冲突通过梦、口误、症状显现,通过自由联想、梦的解析等技术可以接触到无意识内容并达到治愈。它不仅是心理治疗,也是 20 世纪最有影响力的思想运动之一。

## 核心要点

### 潜意识(Unconscious)

- 心灵分**意识、前意识、潜意识**三层
- **潜意识**包含被压抑的欲望、冲突、创伤
- 不可被直接觉察,但**驱动**行为
- 这是对自笛卡尔以来"心灵 = 意识"传统的根本颠覆
- 详见 [[意识与潜意识]]

### 人格结构:本我、自我、超我

- **本我(Id)**:本能驱力、快乐原则、潜意识
- **自我(Ego)**:与现实协调、现实原则、部分意识
- **超我(Superego)**:道德标准、内化的父母与社会

三者持续冲突,自我在本我与超我之间求取平衡。

### 心理性发展五阶段

| 阶段 | 年龄 | 关键 | 滞留后果 |
|---|---|---|---|
| 口唇期 | 0-1 | 吃、吸 | 依赖、贪食 |
| 肛门期 | 1-3 | 排便控制 | 强迫、洁癖 |
| 性器期 | 3-6 | 俄狄浦斯情结 | 同性化失败 |
| 潜伏期 | 6-12 | 性欲压抑 | 社会化主导 |
| 生殖期 | 12+ | 成熟两性关系 | 健康人格 |

弗洛伊德认为成年神经症往往源于某阶段固着。

### [[防御机制]](Defense Mechanisms)

- 自我对抗焦虑的无意识策略
- 主要类型:**压抑、投射、否认、合理化、置换、升华、反向形成、退行**
- 安娜·弗洛伊德系统化
- 详见 [[防御机制]]

### 经典分析技术

- **自由联想**:让来访者无审查表达,捕捉潜意识内容
- **梦的解析**:梦是"通往潜意识的康庄大道",含**显梦**与**隐梦**
- **解释与移情**:分析师指出意义,来访者把情感移到分析师身上
- **阻抗分析**:阻抗本身是无意识冲突的标志

### 主要流派分裂

| 学派 | 创始人 | 核心 |
|---|---|---|
| 经典精神分析 | [[弗洛伊德]] | 性驱力、俄狄浦斯 |
| 分析心理学 | [[荣格]] | 集体无意识、原型 |
| 个体心理学 | 阿德勒 | 自卑、追求优越、社会兴趣 |
| 自我心理学 | A. Freud、Hartmann | 自我功能与适应 |
| 客体关系 | Klein、Winnicott、Fairbairn | 早期母婴关系 |
| 自体心理学 | Kohut | 自体凝聚、自恋 |
| 拉康精神分析 | 拉康 | 镜像阶段、能指链 |
| 关系精神分析 | Mitchell | 主体间性 |

### 与现代心理学的关系

- 主流学术心理学(20 世纪中后)倾向**实证性不足**而疏远
- 但**临床心理学、咨询、人文方向**仍重要
- 神经科学研究(Solms 神经精神分析)开始重新对话
- 行为主义、认知主义在主流方法论上替代精神分析

### 影响范围

- **文学批评**:意象、欲望、压抑分析
- **电影理论**:Mulvey 男性凝视
- **女性主义**:Irigaray、Kristeva
- **哲学**:[[弗洛伊德]] 与 [[尼采]]、 [[马克思]] 并列"颠覆三大师"
- **流行文化**:潜意识、口误、性压抑成为日常词汇

### 批评

- 不可证伪性([[卡尔·波普尔]] 名指其为伪科学)
- 性中心论被女性主义批判
- 治疗效果难以严格量化
- 过度依赖个案,缺乏对照研究

## 和其他概念的关系

- 创始人:[[弗洛伊德]],继承者 [[荣格]]、阿德勒
- 与 [[心理学]] 流派之奠基性
- 与 [[意识与潜意识]]、 [[防御机制]] 直接相关
- 与 [[人际关系]]、 [[依恋理论]] 在客体关系延伸
- 与 [[认知偏差]]、 [[认知失调]] 在"自我欺骗机制"上有共鸣
- 与 [[行为主义]]、 [[认知主义]] 在方法论上对立
- 与 [[积极心理学]] 在关切焦点上对立(病理 vs 优势)
- 与 [[存在主义]]、 [[克尔凯郭尔]] 焦虑分析有共鸣
- 与 [[尼采]] 在"潜意识驱力"上有思想血缘
- 与 [[马克思]] 同为 20 世纪"解释学三大师"
- 影响 [[消费者行为]]、 [[营销心理学]]、广告研究(动机研究)
- 与 [[超我]]、 [[本我]] 等概念是其专有词汇
- 历史定位:[[心理学]] 第一大流派,人文学科 20 世纪基础
