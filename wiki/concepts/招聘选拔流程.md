# 招聘选拔流程

## 定义

**招聘选拔(Recruitment and Selection)** 指识别人才需求、吸引候选人、筛选评估、做出录用决定的系统流程,是人力资源管理的入口环节。"招聘"侧重外部吸引,"选拔"侧重内部判断,两者紧密衔接。

研究反复证明:**招错一个人的成本约为其年薪的 1.5-3 倍**(培训沉没、机会成本、士气损失),招聘流程是 HR 投资回报最高的环节之一。

## 核心要点

### 招聘漏斗(Recruitment Funnel)

经典量化模型,各环节有转化率:

```
品牌触达 → 投递简历 → 简历筛选 → 笔试/初面 → 复面/终面 → 发 Offer → 接受 Offer → 入职
   1000     →  100    →    50    →    20    →    8     →   3   →     2     →   2
```

每环节计算:

- **来源效率**:不同渠道的有效候选人占比
- **转化率**:每环节通过率
- **CPH(Cost Per Hire)**:每招一人的总成本
- **TTH(Time To Hire)**:从开缺到入职天数

漏斗是诊断工具:**哪个环节流失最多 → 投放重点改进**。

### 选拔工具的预测效度(Schmidt-Hunter 元分析)

不同工具预测未来工作绩效的能力(0-1):

| 工具 | 预测效度 |
|---|---|
| **结构化面试** | **0.51** |
| 工作样本测试 | 0.54 |
| 一般智力测试(GMA) | 0.51 |
| 同事评价 | 0.49 |
| 评估中心 | 0.37 |
| 非结构化面试 | 0.38(易受偏见) |
| 人格测试(尽职性) | 0.31 |
| 兴趣测试 | 0.18 |
| 笔迹分析 | 0.02(无效!) |

**结论**:结构化面试 + GMA + 工作样本组合预测效度最高(>0.65)。

### 结构化面试 vs 非结构化面试

| 维度 | 结构化 | 非结构化 |
|---|---|---|
| 问题 | 标准化、按职责设计 | 随意聊 |
| 评分 | 量表评分 | 主观印象 |
| 多人 | 评分独立后讨论 | 影响相互 |
| 偏见 | 显著降低 | 严重 |
| 法律 | 防歧视 | 高风险 |

### 行为面试与情境面试

- **行为面试(Behavioral)**:STAR 法,问"过去做过什么"
  - **S**ituation:情境
  - **T**ask:任务
  - **A**ction:行动
  - **R**esult:结果

- **情境面试(Situational)**:问"假设遇到 X,你会怎么做"

行为问题预测效度更高(过去行为是未来行为最佳预测)。

### 候选人评估的多元方法

- **简历筛选**:关键词、教育、经验、间隔
- **背景调查**:学历核验、犯罪记录、推荐人(Reference Check)
- **能力测试**:GMA、专业知识、英语
- **工作样本**:写代码、做案例、模拟销售
- **人格测试**:大五、Hogan、MBTI(警惕信效度问题)
- **评估中心**:多任务、多评委、多维度

### 招聘渠道与雇主品牌

- **内部招聘**:晋升、调岗,成本低、风险小、有晋升通道激励
- **员工推荐**:质量最高、留存最好的渠道之一
- **校招**:批量获新血,但培训成本高
- **社招**:即战力,但溢价、文化适配风险
- **猎头**:高端职位,有溢价
- **社交平台**:LinkedIn、脉脉、垂直社区
- **雇主品牌**:Glassdoor、看准、口碑营销

### 多样性与包容(DEI)

- **结构化流程**减少潜意识偏见
- **盲选**(隐藏姓名、学校、性别)
- **多元化招聘委员会**
- **目标性招聘**(targeted sourcing)拓宽候选池

## 和其他概念的关系

- 是 [[人力资源管理]] 的入口环节,影响后续培训、绩效、留存
- 与 [[组织文化]] 双向关联——文化吸引候选人,招聘塑造文化
- 错误招聘是 [[绩效管理]] 失败的常见根源
- 与 [[管理决策]] 中的认知偏差(光环效应、相似性偏好、首因效应)斗争
- 涉及社会心理学的群体决策动力学
- 雇主品牌是营销的镜像:把候选人当客户经营
- 数字化招聘(ATS、AI 筛选)是 [[数字化转型]] 的细分场景
- 高效招聘是 [[战略执行]] 的人力前提——战略转型常需新血
- 涉及合规与平等就业法规
