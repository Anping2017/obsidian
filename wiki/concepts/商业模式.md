# 商业模式

## 定义

**商业模式**(Business Model)是描述一个组织如何**创造价值**(Value Creation)、**传递价值**(Value Delivery)、**捕获价值**(Value Capture)的系统逻辑。它回答"我们为谁解决什么问题、怎么解决、怎么赚钱、为什么我们能可持续地赚到"这一组核心问题。

经典定义来自 Osterwalder & Pigneur《商业模式新生代》(2010):**商业模式描述了一个组织如何创造、传递和获取价值的基本原理**。

## 核心要点

### 经典框架:商业模式画布

[[商业模式画布]] 把商业模式拆解为九个模块:

| 模块 | 关键问题 |
|---|---|
| **客户细分** | 我们为谁创造价值? |
| **价值主张** | 我们解决什么问题、提供什么独特价值? |
| **渠道通路** | 通过哪些触点送达客户? |
| **客户关系** | 与客户建立什么样的互动? |
| **收入来源** | 通过什么定价机制赚钱? |
| **核心资源** | 需要哪些关键资产? |
| **关键业务** | 必须做哪些活动? |
| **重要伙伴** | 与谁结盟分担成本与扩展能力? |
| **成本结构** | 主要成本在哪? |

### 主流商业模式类型

| 类型 | 特征 | 代表 |
|---|---|---|
| **产品销售型** | 一次性买断 | iPhone、家电 |
| **订阅型** | 周期付费持续访问 | Netflix、SaaS,见 [[订阅商业模式]] |
| **平台型** | 撮合多边参与者 | Uber、淘宝,见 [[平台商业模式]] |
| **广告型** | 流量变现 | Google、Facebook |
| **免费增值** | 基础免费、增值付费 | Spotify、Notion |
| **服务型** | 按时/按项目计费 | 咨询、外包 |
| **共享型** | 闲置资源被多人使用 | Airbnb,见 [[共享经济]] |
| **数据型** | 数据积累与变现 | Bloomberg、Palantir |
| **生态型** | 多业务协同 | Apple、阿里 |

### 商业模式的演化

- **工业时代**:产品-销售线性
- **互联网 1.0**:门户、电商、搜索广告
- **互联网 2.0**:社交、UGC、平台
- **移动互联网**:O2O、共享经济、直播电商
- **AI 时代**:Agent 即服务、按 Token 计费、AI 赋能传统业态

每一波技术浪潮都重新定义价值创造与捕获的边界。

### 商业模式 vs 战略

- **战略**:在竞争环境中如何获得持续优势
- **商业模式**:实现战略所选的"赚钱机制"
- 战略回答"为什么赢",商业模式回答"怎么赚"
- 二者交叉于 [[价值主张]]、[[竞争优势]]、[[核心竞争力]]

### 商业模式创新

[[商业模式创新]] 比产品创新更难复制,是数字时代的核心壁垒。Christensen 区分 sustaining innovation 与 disruptive innovation,后者常通过新商业模式发动 [[颠覆式创新]]。

## 应用场景

- **创业**:[[精益创业]] 用 [[MVP]] 快速验证商业模式假设
- **战略转型**:Adobe、Microsoft 从软件买断转 SaaS 是商业模式重塑
- **投资分析**:VC 与价值投资都先看商业模式,再看团队与执行
- **跨行业借鉴**:Razor-Blade 模式从吉列推广到打印机墨盒、游戏机

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **画布完整 ≠ 模式可行** | 九宫格写满不代表能赚钱 |
| **抄袭流行模式** | 平台/订阅不是万能,需匹配品类 |
| **忽视单位经济** | 增长好看但 LTV<CAC 终将崩盘 |
| **路径依赖** | 既有商业模式形成路径依赖,转型阻力大 |

## 与其他概念的关系

- 与 [[商业模式画布]]、[[商业模式创新]] 是父子关系
- [[价值主张]]、[[价值链分析]] 是核心子模块
- 通过 [[CAC获客成本]]、[[LTV]]、[[客户终身价值]] 衡量单位经济
- 与 [[战略管理]]、[[竞争优势]]、[[核心竞争力]] 形成战略-模式两层
- [[平台商业模式]]、[[订阅商业模式]]、[[共享经济]]、[[平台经济]] 是其子类型
- [[颠覆式创新]] 常通过新商业模式发动
- [[精益创业]]、[[MVP]]、[[客户开发]] 是验证商业模式的方法论
- [[产品市场契合度]] 是商业模式可行的前置信号
