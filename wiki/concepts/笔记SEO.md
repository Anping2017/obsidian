# 笔记 SEO

## 定义

笔记 SEO(Note SEO / 站内搜索优化)是把 [[搜索引擎优化]] 的方法论迁移到小红书、抖音、B 站、视频号等内容平台的"站内搜索"流量获取优化,核心目标是**让一篇笔记/视频在平台搜索结果中长尾稳定获得自然流量**。区别于推荐流量的"短爆周期",搜索流量是长尾稳定的,半年至两年内仍持续带来浏览与转化。本概念是 [[小红书笔记SEO]] 的概念抽象与平台扩展。

## 与 Google SEO 的核心差异

| 维度 | Google SEO | 笔记 SEO |
|---|---|---|
| 排名信号 | 链接、E-E-A-T、CWV、内容质量 | 互动率、转化率、用户标签、内容标签 |
| 时效性 | 长尾内容半永久 | 平台算法波动大,但搜索结果较稳定 |
| 内容形态 | 文字主导 | 图文/视频主导,首图首帧定生死 |
| 可操作性 | 站点全控 | 受平台算法黑盒约束 |
| 关键词工具 | Google Trends/Ahrefs | 小红书数据/灰豚/新红 |

## 五大优化要点

### 1. 关键词研究

- **平台自带搜索框**:输入种子词,看下拉建议(用户真实搜索)
- **历史爆款分析**:看竞品爆款标题中复用的核心词
- **平台数据工具**:小红书蒲公英、新红、灰豚数据;抖音巨量算数;B 站云犀
- **关键词分类**:核心词(月搜索量大)+ 长尾词(精准意图)+ 场景词(使用场景)
- **关键词强度匹配**:新账号优先抢长尾,头部账号可冲核心词

### 2. 标题与正文关键词布局

- **标题前 7 字**:小红书搜索结果只显示标题前 18-20 字符,核心词必须前置
- **标题包含核心词的同义词**:如"小红书引流方法"+ "私域引流技巧"
- **正文 200-500 字**:核心词出现 3-5 次,密度 3-5%,不堆砌
- **段首句包含关键词**:平台 OCR + 文本提取重点扫描首句
- **标签 #关键词#**:精确匹配 + 相关扩展,小红书 5-10 个为宜

### 3. 互动率信号

- 平台优先展示**高完播、高点赞、高评论、高收藏、高分享**的笔记
- 搜索结果排名 = 内容相关性 × 互动率(粗略乘积)
- 优化手段:
  - 引导评论的开放性问题
  - 收藏按钮提示("觉得有用先收藏")
  - 末尾 CTA 引导关注/收藏

### 4. 首图与首帧视觉钩子

- 搜索结果首图是用户决定点击的唯一信息源
- 小红书:封面图主标题 + 视觉对比 + 高对比度配色
- 抖音:首帧 0.5 秒抓眼睛,字幕醒目
- 视觉一致性:同账号首图风格统一,提升账号品牌识别

### 5. 账号权重与垂直度

- **账号垂直**:同一账号长期发同主题内容,搜索权重更高
- **账号活跃度**:发布频次稳定(每周 3-5 篇)
- **账号互动健康**:粉丝活跃、评论真实、零违规
- 新号 3 个月内难抢核心词,先用长尾词积累权重

## 平台差异

### 小红书

- 强搜索流量平台,30%+ 流量来自搜索
- 关键词工具:小红书蒲公英、新红
- 标签 5-10 个,前 3 标签权重最高
- 搜索权重:相关性 + 互动率 + 时效性

### 抖音

- 搜索流量占比 15-25%,逐年提升
- 标题包含搜索词重要性高
- 抖音搜索后 2024 年开放搜索广告
- 关键词工具:巨量算数

### B 站

- 标题与简介关键词权重高
- 长视频在 SEO 上有独特优势(完播率长,搜索权重高)
- 三连(点赞、收藏、投币)是核心互动信号
- 关键词工具:云犀、B 站搜索 API

### 视频号

- 微信生态,搜一搜联通公众号、小程序、视频号
- SEO 价值在于"微信内闭环"
- 标签与简介关键词重要

## 内容更新与维护

- **再编辑**:小红书允许标题与正文修改(限定次数),根据数据反馈持续优化
- **评论互动**:对热门评论回复,延长内容生命周期
- **用户搜索数据回流**:看自己笔记从哪些关键词进来,反推优化方向
- **季度内容审计**:同主题保留最高互动版本,删除/合并低效版本

## 与其他概念的关系

- 与 [[小红书笔记SEO]]:平台特化版
- 与 [[小红书笔记结构]]:结构化创作模型
- 与 [[笔记爆款公式]]:互动率提升的内容模板
- 与 [[小红书推荐机制]]:笔记 SEO 与推荐流量是双轮驱动
- 与 [[搜索引擎优化]]:思路迁移自 Google SEO
- 与 [[ASO应用商店优化]]:同为站内搜索优化分支

## 与 [[KOL营销]] 的协同

笔记 SEO 是品牌方与 KOL 合作时的"长尾价值"判定依据——好的 KOL 内容在搜索结果上稳定长尾,而非只靠首日推荐曝光。CMO 评估 KOL ROI 时,搜索流量贡献是关键维度。
