# 创业机会识别

## 定义

**创业机会识别(Opportunity Recognition)** 指创业者在复杂不确定环境中**发现、构建、评估**有商业价值且可执行的创业机会的过程。它是创业的起点,也是后续商业模式与融资的依据。

学术界长期争论"机会是被发现还是被创造":Kirzner 主张发现(机会客观存在),Schumpeter 与 Sarasvathy 主张创造(机会由创业者构建)。当代综合观:**机会既可被发现,也常被创造,关键看创业者如何与环境互动**。

## 核心要点

### Timmons 创业铁三角

Jeffrey Timmons 经典模型,把创业成功归因于三要素的匹配:

```
       机会(Opportunity)
            ▲
            │
       创业者及团队 ────── 资源
       (Entrepreneur)    (Resources)
```

- **机会**:市场需求、解决方案、增长潜力
- **团队**:技能互补、价值观一致、抗压能力
- **资源**:资金、人才、技术、关系

三者动态平衡,缺一不可。

### 机会的来源(Drucker 七大来源)

德鲁克在《创新与企业家精神》中识别创新机会七来源:

| # | 来源 | 例子 |
|---|---|---|
| 1 | 意外的成功/失败 | 3M 便利贴源于失败的强力胶 |
| 2 | 不一致(预期与现实差距) | 钢铁业生产率提升而工厂关停 |
| 3 | 流程需求 | 印刷术解决了知识传播瓶颈 |
| 4 | 行业/市场结构变化 | 移动互联网改变媒体业 |
| 5 | 人口结构变化 | 老龄化催生养老产业 |
| 6 | 认知/价值观变化 | 健身、可持续 |
| 7 | 新知识/技术 | 半导体、生物技术、AI |

前六是显性的"低悬果实",第七是高风险高回报的科学突破。

### 优秀机会的判断准则(Timmons 提炼)

不是所有"想法"都是好机会:

| 维度 | 好机会特征 |
|---|---|
| **市场** | 大且增长(10 亿+)、清晰客户、痛点强烈 |
| **价值主张** | 比现有方案好 5-10 倍,不是 10% |
| **盈利** | 健康毛利、可重复、单位经济正 |
| **进入壁垒** | 后进者难复制(网络/数据/IP/规模) |
| **退出** | 5-7 年有清晰退出路径(IPO、并购) |
| **团队-机会匹配** | 团队是这个机会的最佳人选 |

### 机会识别的认知模式

- **模式识别(Pattern Recognition)**:在多个领域看到相似规律
- **类比迁移**:把 A 领域的方案带到 B 领域
- **缺口探测(Gap Detection)**:识别需求与供给的不匹配
- **趋势放大**:识别正在加速的弱信号
- **第一性原理**:从基本规律重新设计

### 创业机会评估工具

- **客户访谈(CustDev)**:Steve Blank 方法论,验证问题真实性
- **MVP(最小可行产品)**:用最少投入验证假设
- **商业画布(Business Model Canvas)**:9 个模块快速描绘
- **精益创业循环**:Build-Measure-Learn
- **SWOT** 与 [[Porter五力模型|波特五力模型]]:行业级评估

### 常见陷阱

| 陷阱 | 表现 | 解药 |
|---|---|---|
| **解决方案先行** | 有锤子找钉子 | 从问题出发 |
| **市场幻觉** | "10 亿市场我占 1%" | 自下而上估市场 |
| **创始人偏见** | 自己是用户 ≠ 大众用户 | 走出去访谈 |
| **过早保密** | 怕被偷想法 | 想法不值钱,执行才值钱 |
| **不可证伪** | 假设无法验证 | 提前定义"什么会让我放弃" |

### 效果推理(Effectuation, Sarasvathy)

不同于因果推理(给定目标,找资源),专家创业者用**效果推理**:

- **从手段出发**:我有什么?(自我、资源、人脉)
- **可承受损失**:愿意承担多少?
- **拼贴**:边做边发现机会
- **意外友好**:把意外变成创新

这解释了为什么连续创业者更成功——他们用资源驱动而非目标驱动。

## 和其他概念的关系

- 是创业过程的起点,后续衔接 [[商业模式画布]]、[[商业计划书]]
- 与 [[战略管理]] 的"机会"分析相通,但更聚焦从零到一
- 涉及 [[管理决策]] 中的认知偏差和判断启发
- 与 [[平台商业模式]]、[[商业生态系统]] 中的机会发现协同
- Drucker 的"创新与企业家精神"与 [[彼得·德鲁克]] 思想一脉相承
- Timmons 模型在 MBA 创业课中是经典框架
- 创业失败统计与 [[企业生命周期]] 早期阶段相关
- 与心理学的"机会识别 vs 风险规避"个性差异交叉
- 在数字时代,平台与 AI 工具加速机会识别,关联 [[数字化转型]]
- 国际化语境下机会识别交叉 [[国际化战略]] 与跨文化敏感
