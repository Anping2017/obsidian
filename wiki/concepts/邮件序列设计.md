# 邮件序列设计

## 定义

邮件序列(Email Sequence / Drip Campaign)是依据用户特定行为或时间触发器,自动按预设节奏与内容路径发送的多封邮件。它把单点邮件升级为有起承转合的内容剧本——每封都为下一封铺垫,目标是把用户从陌生人推到激活、付费、复购或召回。是 [[邮件营销]] 区别于群发的核心战术。

## 核心要点

**四类经典序列**:

1. **Welcome 序列**(注册触发,3-5 封,7-14 天)
   - E1 立刻发送:确认订阅、品牌问候、立刻给一个甜头(优惠码 / 入门指南)。
   - E2 D1-D2:讲品牌故事 / 创始人来信,建立情感连接。
   - E3 D3-D5:产品价值展示 / 客户案例。
   - E4 D7:首次促销 / 新人专享。
   - E5 D14:二次跟进 + 调研问卷。

2. **Onboarding 序列**(SaaS / App 注册,5-10 封,30 天)
   - 围绕通往 [[Aha Moment]] 的关键动作设计:每封邮件引导一个核心功能。例 Notion: E1 创建首个文档 → E2 邀请协作者 → E3 探索模板 → E4 移动端使用 → E5 Pro 升级。
   - 行为分支:已完成动作的不再发该步邮件,跳到下一步。

3. **Nurture(培育)序列**(下载白皮书 / 看 demo,B2B 主战场,8-12 封,90 天)
   - 教育内容 → 案例研究 → 产品演示 → 销售对话邀约。
   - 与 [[销售漏斗]] 阶段对齐:TOFU/MOFU/BOFU 各发 2-3 封。

4. **Win-back(召回)序列**(60 天未活跃,3-5 封,14 天)
   - E1 "我们想念你" + 简单 CTA。
   - E2 推荐爆款 / 个性化内容。
   - E3 限时强折扣。
   - E4 询问是否继续订阅(否则降频或退订)。
   - E5(可选):告别邮件 + 退订前调研。

**触发器类型**:

- **行为触发**:注册、加入购物车未付款、完成购买、查看某品类页面 X 次、X 天未登录。
- **时间触发**:生日、注册周年、订阅到期前 N 天。
- **属性触发**:画像变化(从 Lead 升级为 MQL)、订阅计划变更。

**关键指标**:

- 打开率(Open Rate):标题 + 发件人决定,B2B 20-30%、B2C 15-25%。
- 点击率(CTR):内容 + CTA 决定,2-5%。
- 点开率(CTOR = 点击/打开):衡量内容质量,纯净指标。
- 转化率:CTR × 落地页转化。
- 退订率:健康 < 0.5%,> 1% 警报。
- 投诉率:> 0.1% 进入垃圾箱风险。

**最佳实践**:

- **频率把控**:Welcome 可密集,Nurture 周/双周,主动询问偏好。
- **个性化**:不是简单插姓名,而是依用户画像分支不同内容。
- **A/B测试主题行**:开信率提升 10-20% 仅需主题行优化。
- **预热(Warm-up)**:新域名渐进式提量,避免 ESP 风控。
- **DKIM/SPF/DMARC 配置**:技术合规决定能否进收件箱。
- **可测试**:每封邮件至少一个可改的元素(主题/CTA/发送时间)。

**反模式**:

- 序列过长 / 节奏过密 → 退订潮。
- 全员同一序列 → 个性化为零。
- 只看打开率 → 忽视真正转化。
- 不断扩张序列条数 → 失控,需归并和回顾。

## 和其他概念的关系

邮件序列是 [[邮件营销]] 的高级形态,本质是 [[营销自动化]] 平台(MailChimp、Klaviyo、HubSpot、ActiveCampaign)对 [[用户旅程地图]] 的工程化实现。它常与 [[Push通知]]、短信、站内消息组合成 [[全渠道营销]] 的触达矩阵。

序列效果依赖 [[用户画像]] 细分和 [[AB测试]] 持续优化,对应的指标进入 [[转化漏斗]] 与 [[归因模型]] 计算。Win-back 序列直接关联 [[客户复购]] 与 [[客户终身价值]] 的提升。Nurture 序列是 [[B2B营销]] 中 SDR 与营销协同的关键武器,也是 [[内容营销]] 资产的最长尾分发渠道。

[[GDPR]]、[[CASL]]、《数据安全法》对邮件营销的同意与退订机制有强制要求,合规失败会导致整个域名被拉黑。
