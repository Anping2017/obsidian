# 价格谈判技巧

## 定义

价格谈判(Price Negotiation)指销售方与客户在最终成交价上的博弈过程。它不是简单的"砍价"游戏,而是综合 [[消费者行为]]、[[营销心理学]]、信息不对称、心理偏差的系统化战术。手机零售、二手回收、维修服务、B2B 报价都依赖价格谈判技巧。优秀谈判者既能保护毛利,又能让客户感觉"赢"。

## 核心要点

**三个心理学锚**:

### 1. 锚定效应(Anchoring)

第一个出现的价格深刻影响后续判断。客户提出"你们便宜点",销售本能让 10%——但这把"原价"作锚,谈判从原价开始下降。

**反向应用**:

- **先报高再降**:旗舰款先报,客户觉得贵后引导次旗舰,显得"实惠"。
- **三档定价(High / Middle / Low)**:中档锚定中间值,大部分客户买中档(中间偏好)。
- **价格分解**:不说"3000 元",说"每天不到 9 元"(年化分摊)。
- **对比商品**:"这款贵 200,但电池多 1000mAh + 多保修 1 年"——把对比项的价值放大。

### 2. 高低球(High-Ball / Low-Ball)

- **高球(对客户)**:先抛出高价,等客户砍价,降到目标价 → 客户觉得占便宜。
- **低球(回收方)**:先估低价,客户离开;等客户找了几家都差不多,回头补一点 → 客户觉得已尽力。

### 3. 互惠原则(Reciprocity)

主动给客户一点(免费贴膜、延保 30 天、配件赠品),客户被诱发回报欲望(让一步达成成交)。让的不一定是钱,免费服务 / 体验 / 延保都同样有效。

**典型谈判场景与战术**:

### 场景 1:客户问最低价

- **错误**:直接报底价 → 客户继续砍。
- **正确**:"现在做活动是 X 价,如果今天定可以再申请赠品",把降价转化为"今日决策奖励",同时把价格"锁定在某条件下"。

### 场景 2:客户对比竞品报价

- **错误**:盲目跟价 → 进入价格战。
- **正确**:"对方那款是 X 配置,我们是 Y,差价主要在 Z(如延保 / 服务 / 售后)";把竞争从"价格"升维到"价值"。
- 若价格 + 服务都比不过 → 主动放弃这个客户(不要打亏本生意拖累毛利)。

### 场景 3:客户犹豫不决

- **错误**:继续夸产品,客户疲劳。
- **正确**:**FOMO + 紧迫**:"这是最后一台,后面要等 2 周到货";"今天到 5 点前的活动价"。但**不能撒谎**(被识破信任完全失去)。

### 场景 4:二手回收砍价

- **客户**心态:卖低了亏。**销售**心态:报高了亏。
- **战术**:
  - **先评估,不报价**:"我先看看屏幕、电池、外观"。
  - **指出问题**:屏幕轻微划痕、电池效率 85%、按键松动。每发现一个问题客户预期下调。
  - **市场参考**:"行情价 X,我们是按这个标准。"
  - **正回报**:发现优点也明示"屏幕完美无划痕,可以加 50"——平衡感与公正感。

### 场景 5:维修报价

- **错误**:直接报最高价。客户去对比,流失。
- **正确**:**透明化报价**——分三层(零件成本 + 工时 + 保修)。透明 = 信任 = 不容易被砍。
- **追加销售**:维修同时推荐贴膜 / 保护壳(乘势成交)。

**让步原则**:

1. **每次让步要让客户付出代价(条件交换)**:"我可以让 100,但需要您今天定下来" / "套餐购买才能享受"。
2. **让步幅度递减**:第一次让 100、第二次让 50、第三次让 20——递减让客户感觉到"已逼近底线"。
3. **不主动让步,等客户提**:主动让步 = 暗示原价虚高。
4. **把"让钱"换成"让物"**:50 元现金 vs 价值 100 元的赠品——成本相近但客户感受不同。

**反模式**:

- **第一次接触就报底价**:无回旋空间。
- **快速降价**:每次让步幅度大且快 → 客户觉得"水分大",继续砍。
- **抱怨利润薄**:"我已经亏本卖了"——客户不信,且觉得你不诚实。
- **施压客户决策**:"今天必须定"过度催促 → 反感离开。
- **不准备 BATNA**:谈不成不离场 → 越谈越被动。BATNA(最佳替代方案)是底气。

**手机店谈判口诀**:

- **报价 → 询问 → 试探 → 让步 → 加礼 → 成交 → 跟进**。
- 始终以"价值"而非"价格"为对话主轴。
- 客户买的不是手机,是新机的喜悦 + 服务安全感。

## 和其他概念的关系

价格谈判融合 [[销售技巧]] 的执行层面与 [[营销心理学]] 的理论支撑——[[锚定效应]]、[[损失厌恶]]、[[互惠原则]]、[[FOMO]] 都是其武器库的核心。它是 [[定价策略]] 在终端的临场博弈,也是 [[消费者行为]] 在现实场景的微观体现。

在 [[手机店]]、[[零售门店运营]] 等高频次个人交易场景,谈判技巧直接影响成交率和毛利率,是培训新销售员的核心技能。它与 [[二手回收以旧换新]]、[[连带销售]]、[[会员体系]] 等具体战术互相支撑。

[[B2B营销]] 与采购谈判共享许多原则但战术更长期(多轮 + 合同条款 + 关系)。在线上场景,价格谈判被算法化为 [[动态定价]] 与 [[A/B测试]] 验证最优价位的实验。
