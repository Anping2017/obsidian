# 市场失灵

## 定义

市场失灵(Market Failure)指完全自由市场无法实现帕累托最优资源配置的情形。在福利经济学第一定理中,完全竞争市场达到帕累托最优;市场失灵是这些前提被违背时的结果。

## 核心要点

### 1. 四大主要原因

#### 1.1 外部性
- 见 [[外部性]] 词条
- 经济活动对第三方未补偿的影响
- 负外部性(污染)产出过多,正外部性(教育)产出过少
- 矫正:庇古税、补贴、产权(科斯定理)

#### 1.2 公共物品
- 见 [[公共物品]] 词条
- 非竞争性 + 非排他性
- 搭便车问题导致私人供给不足
- 矫正:政府税收提供、私人筹款、俱乐部物品

#### 1.3 信息不对称
- 见 [[信息不对称]] 词条
- 逆向选择(交易前):柠檬市场
- 道德风险(交易后):保险投保后行为
- 矫正:信号、筛选、监管披露、声誉

#### 1.4 垄断与不完全竞争
- 见 [[垄断市场]]、[[寡头垄断]] 词条
- P > MC 产生无谓损失
- 矫正:反垄断、价格管制、自然垄断公共所有

### 2. 其他失灵
- **不完全市场**:某些市场缺失(再保险、未来市场)
- **宏观稳定性**:失业、通胀、金融危机
- **分配不公**:市场给定要素禀赋不分配公平
- **优值品/非优值品**:个人选择不符合长期福利(吸烟)
- **行为偏差**:[[认知偏差]]、自我控制问题

## 政策反应

| 失灵类型 | 主要工具 | 案例 |
|---|---|---|
| 外部性 | 庇古税/补贴、碳交易 | 碳税、汽车排放标准 |
| 公共物品 | 政府提供、税收融资 | 国防、灯塔、基础研究 |
| 信息不对称 | 强制披露、监管、认证 | 食品标签、IPO 招股书 |
| 垄断 | 反垄断、价格上限、拆分 | 反托拉斯法、电力管制 |
| 行为偏差 | [[助推]]、教育、限制 | 默认储蓄、警示标签 |
| 宏观波动 | 财政政策、货币政策 | QE、自动稳定器 |

## 与其他概念关系

- 与 [[帕累托最优]] 偏离
- 与 [[完全竞争市场]] 假设违背
- 是 [[凯恩斯主义]] 与现代规制经济学的核心论据
- [[公共选择理论]] 警告政府失灵也存在
- 与 [[行为经济学]] 提供新失灵类型
- 在 [[环境经济学]] 与 [[卫生经济学]] 应用最广

## 政府干预的边界

- 政府失灵:寻租、信息缺失、官僚低效
- 公共选择视角:政府不必比市场更善
- 第二最优:存在多种失灵时,纠正一种可能恶化另一种
- 监管成本 vs 失灵成本权衡
- 自愿性、市场化干预优先
