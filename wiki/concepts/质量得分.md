# 质量得分

## 定义

质量得分(Quality Score)是 [[Google Ads]] 关键词级别的广告质量评估指标,采用 1-10 分制(10 最高),综合预测某关键词触发广告时的相关性、可点击性、用户落地体验。质量得分是 [[广告竞价机制]] 中决定广告评级(Ad Rank)与最终 CPC 的关键乘数,是同样预算下提升广告效果的最大杠杆之一。Meta、TikTok 等平台有等价机制,称谓不同(广告相关性、广告质量等)。

## 三大组成维度

### 1. 预期点击率(Expected CTR)

- 衡量在该搜索词下,该广告被点击的概率(剔除广告位置因素)
- 三档评级:Below average / Average / Above average
- 提升手段:
  - 关键词与广告文案匹配度高
  - 广告标题前置核心关键词
  - 文案利益点明确,触发用户点击欲
  - 广告附加信息(网站链接、电话、Callout)增加点击面积

### 2. 广告相关性(Ad Relevance)

- 广告内容与关键词意图的契合度
- 三档评级:Below average / Average / Above average
- 提升手段:
  - 关键词分组细颗粒度,避免一组里塞 100 个无关关键词
  - 广告组(Ad Group)主题集中,广告文案围绕组主题
  - 使用 Dynamic Keyword Insertion 自动插入用户搜索词
  - 否定关键词排除偏离意图的搜索

### 3. 落地页体验(Landing Page Experience)

- 用户点击广告后到达的页面质量
- 三档评级:Below average / Average / Above average
- 提升手段:
  - 落地页内容与广告承诺一致(避免 bait-and-switch)
  - 页面加载速度(Core Web Vitals 直接相关)
  - 移动端适配
  - 内容深度与原创性
  - 联系信息、信任符号、隐私政策齐全
  - 无侵入式弹窗与误导性元素

## 实务影响

1. **CPC 折扣**:质量得分每升 1 分,平均 CPC 下降约 13%(Google 内部研究);7 分 vs 5 分可能差出 25-30% 成本。
2. **广告评级提升**:同样出价下,Q7 广告比 Q5 排名更靠前。
3. **拍卖参与资格**:Q1-Q3 可能根本无法触发广告位展示。
4. **整体账户健康**:大量低质关键词拖累整体账户表现。

## 查看与诊断

- Google Ads → 关键词 tab → 添加列 → Quality Score(及三个分项)
- 历史质量得分:Quality Score(hist.) 列展示数据漂移
- 用 Auction Insights 看竞品同关键词的展现/重叠情况

## 提升路径(优先级排序)

### 高 ROI 优化

1. **重组广告组**:把同类意图的关键词分到一组,文案紧扣
2. **改写广告文案**:确保首行有关键词,价值点明确,加 CTA
3. **启用所有相关广告附加信息**:Sitelinks、Callouts、Structured Snippets、Call、Location、Lead Form
4. **落地页技术优化**:LCP < 2.5s、CLS < 0.1、移动端友好
5. **落地页文案对齐**:广告说"免费试用",落地页第一屏必须出现"免费试用"

### 中等 ROI 优化

6. **添加否定关键词**:排除无关搜索
7. **添加更多变体广告**:让平台 ML 自动选优
8. **响应式搜索广告**(RSA):提供 15 个标题 + 4 个描述,平台自由组合

### 低 ROI 但合规必需

9. 隐私政策、Contact、About 页面齐全
10. HTTPS 全站

## 与其他平台等价指标

| 平台 | 等价指标 | 维度 |
|---|---|---|
| Google Ads | 质量得分 | 预期 CTR、相关性、落地页 |
| Meta Ads | 广告质量排名 + 互动率排名 + 转化率排名 | 三档(优质 / 平均 / 较差) |
| TikTok Ads | 广告质量得分 | 完播、互动、相关性 |
| 百度搜索推广 | 质量度 | 五星制,相关性 + 点击率 + 落地页 |

## 与其他概念的关系

- 与 [[广告竞价机制]]:质量得分是计算广告评级的关键乘数
- 与 [[Google Ads]]:本概念是该平台的核心实战指标
- 与 [[落地页优化]]:落地页维度直接影响质量得分
- 与 [[Core Web Vitals]]:落地页技术性能的核心指标
- 与 [[转化率优化]]:CRO 改善通常带动落地页评分上升
- 与 [[搜索引擎营销]]:SEM 实战的核心杠杆

## 常见误区

1. **追求满分 10**:Q7 与 Q10 实务差异不大,投入产出比低,把精力放在改善 Q5 以下
2. **忽视广告组细分**:一个组塞太多关键词,文案无法都对齐
3. **落地页用主页**:专门投放落地页比通用主页质量得分通常高 2-3 分
4. **不用响应式搜索广告**:RSA 是当前最重要的格式
5. **怪平台**:质量得分低 99% 是账户结构与素材问题,不是 Google 偏见
