# Odoo BoM 物料清单

## 定义

**BoM(Bill of Materials,物料清单)** 是制造业核心数据结构,描述"为生产 1 单位成品需要消耗哪些原料 / 半成品及数量"的标准配方。Odoo Manufacturing 模块的 BoM 支持多层嵌套(成品的子件本身也有 BoM)、产品变体共享 BoM、副产品(by-products)产出、阶段化生产(各工序分别记录),是 MRP 计算和生产订单生成的基础数据。

## 核心要点

**BoM 类型**

1. **生产 BoM(Manufacture)**:标准制造配方,系统自动按需生成生产订单
2. **套件 BoM(Kit)**:不实际制造,销售时分解为子件出库(组装套件、礼包)
3. **分包 BoM(Subcontracting)**:外包给第三方加工的配方

**BoM 字段**

- **产品**:目标成品
- **数量**:生产 X 单位的配方
- **组件列表**:每个子件 + 数量 + 操作(可选)
- **路由(Routing)**:工序顺序与工作中心
- **副产品**:生产过程中除主产品外的产出
- **替代项**:可用作替代的等效组件

**多层 BoM**

成品 → 半成品 → 原料的多级配方:

```
成品(笔记本电脑)
├─ 主板(自制半成品,有自己的 BoM)
│  ├─ CPU
│  ├─ 内存
│  └─ 主板 PCB
├─ 屏幕(外购)
└─ 外壳(自制半成品,有 BoM)
   ├─ 上盖
   └─ 底壳
```

MRP 自动展开多层,计算最深层原料需求。

**BoM 与产品变体**

支持"一个 BoM 应用多个变体":
- 默认 BoM 适用所有变体
- 可对特定变体覆盖某些组件(*这个变体的颜色用 X 而非 Y*)
- 变体特定 BoM 优先于通用 BoM

**副产品(By-products)**

某些工艺天然产出多种产品:
- 木材加工:目标成品木板 + 副产品木屑
- 食品加工:奶酪 + 乳清
- 副产品自动入库,可作为后续工序原料

**阶段化生产(Routing / Work Orders)**

BoM 配合**路由**(工序序列)生成多工单:
- 工序 1:切割(工作中心 A,30 分钟)
- 工序 2:钻孔(工作中心 B,15 分钟)
- 工序 3:组装(工作中心 C,45 分钟)
- 每工序对应一个工单,工人在生产终端确认完成

**BoM 成本核算**

- 标准成本:BoM 各组件标准成本之和 + 工序工时成本
- 实际成本:按工单实际消耗 + 工时反推
- 差异分析:实际 vs 标准的偏差揭示生产问题

## 与其他概念的关系

BoM 是 [[Odoo Manufacturing]] 的核心数据,**MRP**(Material Requirements Planning,物料需求计划)依赖 BoM 展开计算需求。在多公司场景下 BoM 可跨 [[Odoo多公司架构]] 共享。修改 BoM 通过 [[Odoo工作流]] 触发版本管理,涉及 PLM(Product Lifecycle Management)的工程变更控制。

## 高频陷阱

- 修改 BoM 不影响已下达的生产订单(订单冻结当时的 BoM 快照)
- 多层 BoM 循环引用 → 致命错误,系统检测但开发者需设计避免
- 套件 BoM 在销售订单出库时不会触发 MRP(因为不真制造)
- 数量小数精度:0.0001 vs 0.001 在大批量乘积时差异显著
- 副产品的成本分摊规则需明确(否则成本核算混乱)
