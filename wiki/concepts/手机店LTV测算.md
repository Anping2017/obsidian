# 手机店 LTV 测算

## 定义

手机店 LTV 测算(Mobile Phone Retail LTV Calculation)是把通用 [[客户终身价值]] / [[LTV]] 框架适配到线下手机零售业态的具体测算方法。手机店区别于纯电商或纯服务业,具有"主商品(手机)+ 配件 + 服务 + 二手 + 运营商套餐分成 + 保险"多元收入结构,客户购买一部手机后通常在 2-4 年生命周期内产生多次衍生消费,因此 LTV 测算需采用三层结构。

## 三层 LTV 结构

### 第一层:首单价值

```
首单毛利 = 手机售价 × 毛利率(8-15%)
       + 首日附加(膜+壳+耳机+保险等)毛利
```

- 手机本身毛利薄(头部品牌如 iPhone 仅 5-10%,小品牌可 15-25%)
- 首日附加销售(俗称"五连"或"六连"):贴膜、保护壳、充电器、耳机、内存卡、延保
- 经验值:首日附加销售可贡献首单 30-60% 的毛利
- 关键:进店 → 看机 → 选机 → 试机 → 加售 → 离店的标准化 [[客户接待流程]]

### 第二层:衍生消费(2-4 年生命周期)

| 衍生品类 | 频次/客户 | 单次毛利 |
|---|---|---|
| 贴膜更换 | 2-4 次 | 30-100 元 |
| 保护壳更换 | 1-3 次 | 20-80 元 |
| 充电器/数据线 | 1-2 次 | 20-50 元 |
| 维修(屏幕/电池) | 0.3-0.8 次 | 200-800 元 |
| 数据迁移/恢复 | 0.2-0.5 次 | 50-200 元 |
| 周边配件(支架、耳机等) | 1-3 次 | 50-300 元 |

### 第三层:换机与二手

```
换机频次 = 1 / 平均换机周期(2-4 年)
换机 LTV 贡献 = 换机毛利 × 换机次数 × 留存率
二手回收价值 = 旧机回收差价 × 回收覆盖率
```

- 高留存客户 4-6 年内可能在同一店换 1-2 部手机
- [[二手回收以旧换新]] 业务是关键留存与利润来源,旧机置换毛利可观

## 完整 LTV 公式

```
LTV = 首单毛利
     + Σ(衍生消费 × 复购概率)
     + 换机毛利 × 复购概率
     + 二手回收差价
     - 服务成本
     - 客户维护成本
```

## 关键假设与数据采集

1. **平均换机周期**:行业 2.5-3.5 年,Apple 用户偏长(3-4 年),安卓中端 2-2.5 年
2. **店内复购率**:取决于店铺服务质量,优质店铺 30-50%,差店铺 5-10%
3. **数据采集起点**:每客户进店开会员、留手机号、扫码加微信
4. **追踪工具**:CRM/会员系统 + 企业微信 + 收银 POS 数据
5. **客户分层**:新客 / 老客 / VIP 不同 LTV 模型

## 实例测算(中型城市中端机店)

假设单客买华为 Mate 60 售价 5499 元:

| 项目 | 金额 | 备注 |
|---|---|---|
| 首单毛利(手机) | 350 | 6.4% 毛利率 |
| 首单附加毛利(配件+保险) | 250 | 玻璃膜+壳+耳机+延保 |
| 第一年衍生(膜壳) | 120 | 2 次更换 |
| 第二年衍生(膜壳+电池维修) | 280 | |
| 第三年换机毛利(40% 留存) | 600 × 40% = 240 | 留存复购 |
| 二手回收差价 | 200 × 60% = 120 | 60% 回收覆盖 |
| **3 年期 LTV** | **1360 元** | |

## 与 CAC 的配对

```
LTV/CAC = 1360 / CAC
```

- 手机店 CAC 主要来自:店面租金摊销、人员成本摊销、外部引流(美团/抖音)
- 业内典型 CAC 200-500 元(线下纯靠地段)、抖音/美团引流 50-200 元
- LTV/CAC ≥ 3 视为健康,≥ 5 优秀

## 实务杠杆点(从大到小排序)

1. **首单附加销售训练**:店员转化率从 30% 升到 60% 直接翻倍 LTV
2. **会员体系设计**:[[会员体系]] 锁住 4 年内的复购
3. **二手回收业务化**:从被动报价升级为主动业务,可提升 LTV 15-25%
4. **维修服务延伸**:维修是高毛利且高粘性的衍生
5. **运营商套餐分成**:号卡套餐 + 宽带分成,长期被动收入
6. **保险/延保**:50-80% 毛利,且不耗损库存

## 常见错误

1. **只看首单不算生命周期**:把"卖出一部手机"当终点,忽视后续 60% 价值
2. **不留客户联系方式**:无 CRM 等于无 LTV 数据
3. **把高客单等同高 LTV**:5499 元 iPhone 与 1999 元小米可能 LTV 相近(iPhone 用户复购周期长)
4. **二手回收随便报价**:把高毛利业务做成"赔本送旧机"
5. **不做客户分层**:VIP 与一般客户用同样套路
