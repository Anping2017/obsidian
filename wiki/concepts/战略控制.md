# 战略控制

## 定义

**战略控制(Strategic Control)** 指持续监控战略执行进展、检验战略前提、识别偏差并采取纠正行动的管理过程。它区别于传统**财务/运营控制**——后者仅关注"怎么做"是否高效,而战略控制还要问"是否还要做这件事"。

Schreyögg 与 Steinmann 提出战略控制三要素:**前提控制 + 实施控制 + 战略监督**。

## 核心要点

### 战略控制三类型

| 类型 | 关注点 | 工具 |
|---|---|---|
| **前提控制(Premise Control)** | 战略所依赖的外部假设是否仍成立? | PESTEL 监控、情景规划 |
| **实施控制(Implementation Control)** | 战略动作的进展与里程碑 | KPI、平衡计分卡、阶段评审 |
| **战略监督(Strategic Surveillance)** | 未预期事件的扫描 | 弱信号、情报系统、红队 |

### 控制循环(Control Loop)

```
设定标准 → 测量绩效 → 比较差距 → 分析原因 → 采取行动
       ↑                                          ↓
       └──────────────────────────────────────────┘
                      反馈
```

行动可能有四种:**继续 / 调整执行 / 修订战略 / 终止战略**。

### 控制的"前馈-同步-反馈"三层

| 层次 | 时机 | 例子 |
|---|---|---|
| **前馈控制(Feedforward)** | 行动前预判 | 预算审批、风险评估 |
| **同步控制(Concurrent)** | 行动中实时 | 仪表盘监控、日报告 |
| **反馈控制(Feedback)** | 行动后纠偏 | 季度复盘、绩效面谈 |

### 与传统预算控制的区别

| 维度 | 预算控制 | 战略控制 |
|---|---|---|
| 时间观 | 短期(年度) | 长期(数年) |
| 焦点 | 财务变量 | 战略变量 |
| 触发 | 数字偏差 | 假设变化 |
| 行动 | 调资源 | 调方向 |

### 战略控制的常见难题

- **滞后指标问题**:财务结果反映过去而非未来
- **指标固化**:KPI 一旦设定难以及时改
- **测量黑洞**:难以量化的"软指标"被忽视(文化、品牌)
- **报告噪音**:为应付检查而非实际改进
- **控制悖论**:过度控制扼杀创新与执行速度

### 关键工具

- **平衡计分卡**:四维度战略指标体系,见 [[平衡计分卡]]
- **战略仪表盘**:实时数据可视化
- **战略复盘(After Action Review)**:军方起源,事后反思
- **情景规划**:壳牌石油经典工具,前提控制的标杆
- **OKR**:把控制内嵌于目标体系

## 和其他概念的关系

- 是 [[战略执行]] 闭环的反馈机制,与执行不可分割

- 通过 [[平衡计分卡]] 和战略地图工具化
