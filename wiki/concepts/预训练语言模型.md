# 预训练语言模型

## 定义

**预训练语言模型**(Pre-trained Language Model,PLM)指在海量无标注文本上,通过**自监督学习**(self-supervised learning)预先训练得到的通用语言模型。其核心思想是:

> "先在大规模通用语料上学语言本身,再针对下游任务做小规模微调或直接提示。"

预训练阶段让模型学到词法、句法、语义、世界知识等通用表征;下游任务阶段(微调 / few-shot / zero-shot)调用这些表征解决具体问题。PLM 是 [[大语言模型]] 与现代 NLP 的基础范式。

## 核心要点

### 三大预训练范式

| 范式 | 代表模型 | 训练目标 | 适用场景 |
|---|---|---|---|
| **自回归(Causal LM)** | GPT 系列、LLaMA | 给定前文预测下一个 token | 文本生成、对话 |
| **掩码(Masked LM)** | [[BERT]]、RoBERTa | 还原被遮挡的 token | 文本理解、分类、NER |
| **编码—解码(Seq2Seq)** | T5、BART | 输入序列 → 输出序列 | 翻译、摘要、QA |

三种范式的统一基座都是 [[Transformer架构]]。

### 训练流程

1. **数据准备**:抓取并清洗 TB 级语料(Common Crawl、Wikipedia、书籍、代码、对话)
2. **分词与编码**:用 BPE / WordPiece / SentencePiece 切分为 token
3. **自监督预训练**:在数千张 GPU/TPU 上训练数周至数月,优化交叉熵损失
4. **对齐与微调**:SFT(监督微调)→ RLHF / DPO(对齐)→ 任务化部署

### Scaling Law(规模法则)

OpenAI 和 DeepMind 的研究表明:模型损失随**参数量、数据量、算力**的对数线性下降。这条规律驱动了从 GPT-2(15 亿)到 GPT-4、Claude、Gemini(千亿—万亿)的参数军备竞赛。

### 涌现能力(Emergent Abilities)

当参数规模跨过某个阈值,模型会突然出现小模型不具备的能力:in-context learning、chain-of-thought 推理、多步规划等。这是 PLM 区别于传统 NLP 模型的关键特征。

### 从预训练到通用模型

- **GPT-3(2020)**:展示了 few-shot prompting 取代微调的可能
- **InstructGPT / ChatGPT(2022)**:通过 RLHF 让 PLM 学会"听指令"
- **GPT-4 / Claude 3 / Gemini(2023+)**:多模态 + 长上下文 + 工具调用,进入通用助手时代

## 典型应用 / 主流模型工具

- **生成式**:GPT 系列(OpenAI)、Claude 系列(Anthropic)、[[Gemini系列模型]](Google)、LLaMA(Meta)、Qwen(阿里)、DeepSeek
- **理解式**:BERT、RoBERTa、DeBERTa,广泛用于搜索、分类、信息抽取
- **代码**:Codex、Code Llama、StarCoder、Claude Code
- **行业垂直**:BloombergGPT(金融)、Med-PaLM(医学)、Galactica(科研)

## 局限与挑战

| 问题 | 描述 |
|---|---|
| **训练成本** | 千亿模型训练一次需千万至亿美元算力 |
| **数据偏见** | 语料中的性别、种族、文化偏见会被放大 |
| **幻觉** | 自回归概率采样导致编造看似合理但错误的内容 |
| **知识截止** | 训练后世界变化无法感知,需依赖 [[检索增强生成]] |
| **可解释性** | 千亿参数的决策过程仍是黑盒 |
| **能耗与碳排** | 大模型训练耗电相当于一个小城市 |

## 与其他概念的关系

- 架构基座是 [[Transformer架构]],没有 Transformer 就没有 PLM 时代
- 微调阶段衍生出 [[大语言模型]] 的对齐方法(RLHF、DPO)
- 通过 [[Embedding]] 把 token 映射为高维向量,是表征学习的载体
- 双向掩码代表是 [[BERT]],自回归代表是 GPT
- 与 [[检索增强生成]] 结合解决知识更新与幻觉问题
- 通过 [[Function Calling]] 扩展为可调用外部工具的智能体
- 跨模态延伸为 [[多模态学习]] 与 [[多模态AI]]
