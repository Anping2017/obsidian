# 作业基础管理

## 定义

**作业基础管理**(Activity-Based Management, ABM)是把 [[ABC作业成本法]](Activity-Based Costing)的成本核算结果转化为**管理决策与持续改进工具**的方法体系。

ABC 解决"成本是怎么发生的",ABM 进一步问"哪些作业值得保留、改进或剔除",把核算从"账"延伸到"管理"。两者共同构成现代 [[管理会计]] 的核心。

## 核心要点

### 与 ABC 的递进关系

| 层次 | 焦点 | 产出 |
|---|---|---|
| **ABC**(成本核算) | 成本动因如何分摊 | 准确的产品/服务/客户成本 |
| **ABM**(管理改进) | 作业是否增值 | 持续改进与流程优化决策 |

```
ABC: 资源 → 作业 → 成本对象(产品/客户)
ABM: 作业分类 → 增值/非增值 → 改进或消除
```

### 增值作业 vs 非增值作业

**增值作业**(Value-Added Activities):客户愿意付费的作业,直接创造价值。
- 装配、加工、设计、关键服务交付

**非增值作业**(Non-Value-Added Activities):客户不愿付费但当前必要的作业,理论上应消除。
- 检验、返工、等待、移动、储存、监督

精益管理目标:把非增值作业最小化,把增值作业流程化。

### 操作型 ABM vs 战略型 ABM

| 类型 | 关注 | 应用 |
|---|---|---|
| **操作型 ABM** | 作业执行效率 | 流程改进、消除浪费、提高质量 |
| **战略型 ABM** | 作业是否应保留 | 业务组合、定价、客户取舍、外包决策 |

操作型回答"把作业做对",战略型回答"做对的作业"。

### 价值流分析

把企业全流程的作业按"价值流"组合分析:
- 端到端追踪:从订单到交付
- 时间维度:周期时间(Cycle Time)、价值时间占比
- 浪费识别:七大浪费(过量生产、等待、运输、过度处理、库存、动作、缺陷)

### 客户盈利性分析

ABM 把客户也当作成本对象:

```
客户盈利 = 客户收入 - 直接成本 - 客户相关作业成本(销售、服务、退货、账期)
```

发现:
- 大客户未必最赚钱(账期长、定制成本高、退货多)
- 80/20 法则常被颠覆为 30/70(30% 客户贡献 100% 利润,70% 客户拖累)
- 应淘汰、提价或差异化服务底部客户

### Pareto 与作业分类

```
20% 的作业占 80% 成本
50% 的作业为非增值或可消除
关键作业仅占 10-20%,但贡献 80% 价值
```

ABM 实施前先做 80/20 筛选,聚焦最重要作业。

### 实施步骤

1. **作业识别**:列出主要作业及其分类
2. **资源-作业映射**:用 ABC 核算每作业成本
3. **作业评估**:增值/非增值、效率/质量
4. **改进方案**:消除、合并、简化、自动化
5. **绩效跟踪**:用作业指标(KPI)持续监督

### 与 [[作业基础预算]](ABB)的关系

ABM 改进作业 → ABB 把改进后的作业资源需求纳入预算 → 预算执行反馈给 ABM → 闭环

### 典型 KPI

- 单作业成本(单位作业完成成本)
- 作业增值率(增值作业 / 总作业时间)
- 周期时间(Cycle Time)
- 一次合格率(First-Pass Yield)
- 客户盈利分布(Profitability Mix)

### 局限

- 实施成本高,需 ERP 支撑
- 行政性作业难以量化分摊
- 短期可能与传统会计利润冲突
- 文化阻力:被剔除的作业意味着岗位变动

## 和其他概念的关系

- 直接基础:[[ABC作业成本法]] 提供数据
- 上游战略:与企业战略、[[价值链]] 分析对接
- 下游执行:与 [[作业基础预算]]、绩效评价整合
- [[精益思想]] 中的"消除浪费"与 ABM 的"消除非增值作业"同源
- 与 [[平衡计分卡]] 在多维绩效衡量上互补
- [[管理会计]] 体系的核心组成
- 与 [[供应链管理]]、[[运营管理]] 实务紧密结合
