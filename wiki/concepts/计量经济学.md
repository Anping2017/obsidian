# 计量经济学

## 定义

**计量经济学(Econometrics)**:把统计学方法应用于经济学,以**测量、检验、预测、政策评估**为目标的学科。术语由 **Ragnar Frisch** 1933 年提出,与挪威 Tinbergen 同获 1969 年第一届诺贝尔经济学奖,标志计量经济学的核心地位。

它是经济学从思辨学科转向实证科学的关键 —— 没有计量,经济学只能停留在文字推演;有了计量,理论可被数据检验、参数可被估计、政策效果可被量化。

## 核心要点

### 回归分析

最基础也是最重要的计量工具,见 [[回归分析]]。

**经典线性回归(OLS)**:Y = β₀ + β₁X₁ + ... + β_kX_k + ε

最小二乘估计:min Σε²,得到估计量 β̂。

**关键假设**:
- 线性关系
- 误差期望为 0
- 同方差(误差方差恒定)
- 无自相关
- 解释变量与误差不相关(外生性)
- 误差正态分布(用于推断)

任一假设违反,需要相应修正(GLS、HAC 标准误、IV 等)。

**OLS 性质(高斯-马尔可夫定理)**:在经典假设下,OLS 是 BLUE(最佳线性无偏估计量)。

### 内生性问题

计量分析最大障碍是 X 与 ε 相关(**内生性**),导致 β̂ 偏倚。来源:

- **遗漏变量(omitted variable bias)**:忽略相关因子
- **反向因果(reverse causality)**:Y 影响 X 而非 X 影响 Y
- **样本选择(selection bias)**:样本非随机
- **测量误差(measurement error)**

正确识别因果效应需消除内生性。

### 处理内生性的方法

**1. 工具变量(IV)**:
- 找一个 Z 满足:与 X 相关 + 与 ε 不相关(排除性约束)
- 二阶段最小二乘(2SLS)估计
- 经典例子:Angrist 用越战抽签 Z 估计教育对收入影响
- 局限:好工具变量稀缺,弱工具变量问题

**2. 自然实验**:
- 利用偶然变异(政策非连续变化、地震、抽签)模拟随机分配
- Card 1990 用 Mariel 船户研究移民对工资影响
- 是 1990s 以来"可信性革命"的核心方法

**3. 断点回归(RDD)**:
- 利用阈值(如分数线、时点)产生的"准随机"分配
- 比较阈值附近样本
- 例:贫困线 SNAP 资格、最低分录取大学

**4. 差分中差分(DiD)**:
- 比较政策影响群与对照群在时间上的差异变化
- 例:美国不同州不同时间最低工资变化

**5. 随机对照试验(RCT)**:
- 真正随机分配处理与控制组
- Banerjee-Duflo-Kremer 2019 诺奖,发展经济学应用
- 局限:外部有效性、伦理、成本

**6. 倾向得分匹配(PSM)**:
- 给每个处理组找对应特征的控制组
- 局限:仅控制可观察变量

### 时间序列分析

研究时间维度数据(GDP、利率、股价等),核心问题:

- **平稳性(stationarity)**:单位根、协整
- **自相关与季节性**
- **结构突变**

主要模型:
- **AR、MA、ARIMA**:线性时间序列
- **GARCH**(Engle 2003 诺奖):波动率聚类
- **VAR**(Sims 2011 诺奖):多变量同时建模
- **协整与误差修正模型**(Engle-Granger):非平稳变量长期均衡

应用:GDP 预测、利率预测、央行政策传导分析、 [[蒙特卡洛模拟]] 与场景分析的输入参数。

### 面板数据

横截面 + 时间序列结合,优点:控制不可观察的个体异质性。

**固定效应模型**:Y_it = α_i + βX_it + ε_it,α_i 吸收时不变个体效应。
**随机效应模型**:α_i 视为随机变量,效率高但需更强假设。
**Hausman 检验**:在固定 vs. 随机效应间选择。

应用:Card-Krueger 最低工资研究、企业生产率分析、跨国增长研究。

### 因果推断与可信性革命

1990s-2000s 起,经济学经历**可信性革命**(Credibility Revolution):
- Imbens、Angrist、Card 等人推动
- 强调**因果识别**而非"漂亮回归"
- 工具变量、自然实验、RDD、DiD、RCT 成主流
- 大量论文聚焦因果识别策略,而非复杂模型

**潜在结果框架(Rubin Causal Model)**:每个个体有 Y_1(处理后) 与 Y_0(未处理) 两个潜在结果,但只观察其一,因果效应 = Y_1 − Y_0。

**平均处理效应(ATE)**、**处理组上的处理效应(ATT)**、**局部平均处理效应(LATE)** 是不同识别参数。

### 现代发展

- **机器学习方法**:Lasso、Random Forest、神经网络用于异质性效应估计、文本分析、图像识别
- **大数据**:行政记录、平台数据、卫星图像
- **结构估计**:基于经济模型直接估计参数,与降低式估计互补
- **空间计量**:邻近效应、地理信息整合
- **网络计量**:社交网络、贸易网络效应

### 计量的局限

- 数据质量始终是核心制约
- 因果识别需要可信策略,不存在"万灵药"
- 外部有效性问题(本研究结果适用于其他场合吗?)
- 模型设定灵敏性
- 发表偏倚与"P 值钓鱼"问题
- 经济学理论本身的假设局限

### 软件工具

- **Stata**:经济学最广泛使用,商业软件
- **R**:免费开源,统计学界主流
- **Python**:近年快速崛起,机器学习、文本分析
- **Matlab**:结构估计、动态规划
- **EViews**:时间序列特长

## 和其他概念的关系

计量经济学是 [[经济学方法论]] 中实证维度的核心工具,把所有经济学理论与现实数据连接。它通过 [[回归分析]]、[[蒙特卡洛模拟]]、[[随机过程]] 与 [[概率论与统计学]] 等数学工具实现。

它对所有应用领域至关重要:[[弹性理论]] 中弹性参数的估计依赖回归;[[菲利普斯曲线]] 的斜率需要时间序列估计;[[经济增长理论]] 中增长核算与跨国研究;[[国际贸易理论]] 中引力模型估计;[[行为经济学]] 中实验数据分析。

[[财政政策]] 与 [[货币政策]] 的有效性依赖计量评估,不再是纯理论辩论。

跨域:[[投资组合理论]] 中 Beta 估计、因子模型回归是计量应用;[[资产定价模型]] CAPM、APT 实证检验全是计量;[[期权定价]] 中波动率估计依赖时间序列(GARCH);[[风险识别与度量]] 中 VaR 估计、CVaR 估计依赖统计建模;[[绩效评估]] 中归因分析是回归技术;[[基本面分析]] 量化投资完全建立在计量预测之上;[[行为金融学]] 通过事件研究、横截面回归检验异象。计量经济学是连接经济学与金融实证研究的统一语言。
