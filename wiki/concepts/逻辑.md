# 逻辑

## 定义

**逻辑**(Logic)研究**有效推理的形式、规则与谬误**。它不关心命题内容是否真,而关心从前提到结论的推理是否**形式上有效**。逻辑既是哲学分支(始于 [[亚里士多德]] 《工具论》),也是现代数学与计算机科学的基础。

## 核心要点

### 四类推理

| 类型 | 走向 | 特征 | 例子 |
|---|---|---|---|
| **演绎(Deduction)** | 一般 → 特殊 | 必然性;前提真则结论必真 | 凡人皆死,苏格拉底是人 → 苏格拉底会死 |
| **归纳(Induction)** | 特殊 → 一般 | 或然性;支持但不必然 | 观察的天鹅都白 → 所有天鹅都白(被黑天鹅证伪) |
| **类比(Analogy)** | 特殊 → 特殊 | 基于相似性 | 地球有生命,火星与地球相似 → 火星可能有生命 |
| **溯因(Abduction)** | 结果 → 最可能原因 | 解释推理 | 地湿了 → 推断下过雨 |

### 三大基本规律

1. **同一律**:A = A;一个命题在论证中含义保持一致
2. **矛盾律**:A 与 ¬A 不能同时为真
3. **排中律**:A 或 ¬A 必有一真(经典逻辑;直觉逻辑放弃此律)

### 经典推理规则

- **肯定前件(Modus Ponens)**:A → B,A,故 B
- **否定后件(Modus Tollens)**:A → B,¬B,故 ¬A
- **假言三段论**:A → B,B → C,故 A → C
- **选言三段论**:A 或 B,¬A,故 B

### 常见逻辑谬误

| 谬误 | 描述 |
|---|---|
| **诉诸权威** | 用名人背书代替论证 |
| **稻草人** | 歪曲对方观点再攻击 |
| **人身攻击** | 攻击人而非论点 |
| **滑坡谬误** | 没根据地把小恶夸大为大恶链条 |
| **假二分法** | 把多元选项简化为非此即彼 |
| **以偏概全** | 用少数样本断言普遍 |
| **循环论证** | 用结论作前提 |
| **诉诸众人** | 多数人这么想就对 |

### 现代逻辑分支

- **命题逻辑**(0 阶):用真值表分析连接词
- **谓词逻辑**(1 阶):引入量词和关系
- **模态逻辑**:加入"必然"、"可能"
- **直觉逻辑**:不接受排中律
- **模糊逻辑**:真值是 0 到 1 之间
- **数理逻辑**:支撑数学基础(集合论、形式系统)

### 归纳问题(休谟)

- [[休谟]]:归纳无法被演绎证成 —— 你不能从"过去如此"演绎出"未来必如此"
- 波普尔回应:科学是不断证伪的猜想,不是归纳

## 和其他概念的关系

- 逻辑由 [[亚里士多德]] 系统化,是 [[认识论]] 与 [[批判性思维]] 的核心工具
- [[辩证法]] 是处理矛盾、动态发展的另一种思维方式,二者互补
- 与 [[演绎推理|演绎]]、[[归纳推理|归纳]] 直接相关 —— 二者都属逻辑下的推理类型
- 应用于 [[认知偏差]] 识别 —— 许多偏差是隐藏的逻辑谬误
- [[第一性原理]] 思考依赖严格演绎
- 与 [[贝叶斯]] 概率推理在不确定性下补充
- 与 [[休谟]] 的归纳问题、康德的先验综合判断直接相关
