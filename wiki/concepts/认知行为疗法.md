# 认知行为疗法 Cognitive Behavioral Therapy

## 定义

认知行为疗法(Cognitive Behavioral Therapy, CBT)是**短程、目标导向、循证为基础的心理治疗方法**,核心理论:

> **个体的情绪与行为不直接源于事件本身,而是源于对事件的认知与解释。** 因此修改「失功能认知」与「不良行为模式」可以缓解情绪困扰。

它不是单一技术,而是一组共享认知-行为视角的疗法集合。

奠基人:

- Aaron Beck(美国精神科医生,1960s 创立认知疗法)
- Albert Ellis(理性情绪行为疗法 REBT)
- B.F. Skinner、Joseph Wolpe(行为主义传统)

## 核心要点

### ABC 模型(Ellis)

```
A (Activating Event 触发事件) → B (Belief 信念) → C (Consequence 后果情绪/行为)
                                ↑
                              干预点在这
```

例:被同事忽视 → 「他讨厌我,我没价值」→ 抑郁与回避
改为:被同事忽视 → 「他可能很忙」→ 平静地继续工作

### 认知三角(Beck)

抑郁的认知特征:

- 对**自我**的负面看法(我没用)
- 对**世界**的负面看法(世界冷漠)
- 对**未来**的负面看法(永远好不了)

CBT 通过识别这三个维度的认知扭曲来治疗抑郁。

### 常见认知扭曲(认知歪曲)

| 类型 | 例子 |
|---|---|
| 全或无思维 | 「我必须完美,否则就是失败者」 |
| 过度概括 | 一次拒绝 → 「永远没人爱我」 |
| 心理过滤 | 只关注负面,忽略正面证据 |
| 应该思维 | 「我应该……」造成压力 |
| 灾难化 | 把小事预想为最坏结果 |
| 个人化 | 把无关的事归咎于自己 |
| 读心术 | 「他肯定觉得我蠢」 |
| 情绪推理 | 「我感觉失败,所以我就是失败者」 |

### 行为部分

- **行为激活**:抑郁者倾向回避,治疗鼓励逐步增加愉悦/成就感活动
- **暴露疗法**:逐步面对恐惧情境,如 PTSD、恐惧症、强迫症
- **放松训练**:深呼吸、渐进式肌肉放松、正念
- **行为实验**:把信念变为可检验假设,通过实际行动收集证据

### 第三波 CBT

传统 CBT 之上,1990s+ 发展出更广义的疗法群:

- **正念认知疗法 MBCT**:正念冥想 + CBT,防复发
- **接纳承诺疗法 ACT**:接纳痛苦,聚焦价值导向行动
- **辩证行为疗法 DBT**:Marsha Linehan 创立,专攻边缘人格、自伤
- **图式疗法 Schema Therapy**:深层早期适应不良图式

### 适用障碍

CBT 是治疗以下障碍的循证一线疗法:

- 抑郁症(Major Depression)
- 焦虑障碍(广泛性焦虑、恐慌、恐惧症)
- 强迫症(OCD)
- 创伤后应激障碍(PTSD)
- 进食障碍
- 失眠(CBT-I)
- 物质使用障碍
- 慢性疼痛的心理部分

### 实施方式

- 个体/团体治疗,通常 8-20 次 50 分钟会谈
- 家庭作业(行为实验、思想记录)是核心
- 数字化 CBT(iCBT、App 如 Woebot、Wysa)使其规模化
- 短程、聚焦,与精神分析的长程不同

## 和其他概念的关系

CBT 是当代 [[临床心理学]] 与 [[心理学]] 治疗的主流,与 [[精神分析]]、人本主义、[[家庭系统疗法]] 等并列,但在循证证据数量上居首。

理论根源融合 [[行为主义]](Skinner、Wolpe)与 [[认知主义]](Beck、Ellis),代表了「认知革命」后心理治疗的整合方向。

[[积极心理学]] 与 CBT 互补——前者强调发展优势,后者强调修正问题。MBCT 桥接了二者与 [[禅宗]] / 正念传统。

[[认知失调]]、[[确认偏差]]、[[首因效应]] 等社会心理学概念与 CBT 中的认知扭曲在机制上相通——大脑的预测性建构与节能倾向产生系统性偏误,CBT 是「治疗性的元认知训练」。

[[抑郁]]、[[焦虑]]、[[羊群效应]] 等议题在 CBT 视角下都有具体干预方案;[[变革管理]] 中员工抗拒变革也常源于认知扭曲(灾难化、过度概括),CBT 思路可借鉴。
