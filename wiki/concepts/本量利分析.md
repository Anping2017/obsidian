# 本量利分析

## 定义

**本量利分析**(Cost-Volume-Profit Analysis, CVP)是 [[管理会计]] 中分析**成本(Cost)、产量(Volume)、利润(Profit)三者关系**的核心工具。它把成本按习性分为**变动成本与固定成本**,计算盈亏平衡点、目标利润、安全边际、经营杠杆等关键指标,是短期定价、生产组合、销量预测的基础工具。中文也称"量本利分析"或 CVP 分析。

## 核心要点

### 基本公式

利润 = 收入 - 总变动成本 - 固定成本

$$\pi = (P - VC) \cdot Q - FC$$

其中:
- P = 单位价格
- VC = 单位变动成本
- Q = 销量
- FC = 期间固定成本
- (P - VC) = **单位边际贡献(Unit Contribution Margin)**
- (P - VC)/P = **边际贡献率(CM Ratio)**

### 盈亏平衡点(Break-even Point)

利润为零时的销量:

$$Q^* = \frac{FC}{P - VC}$$

或盈亏平衡销售额:

$$\text{BE Sales} = \frac{FC}{(P-VC)/P} = \frac{FC}{\text{CM Ratio}}$$

### 目标利润下的销量

要赚目标利润 π_T:

$$Q = \frac{FC + \pi_T}{P - VC}$$

若考虑所得税,目标税前利润 π_T = π_after / (1 - t)。

### 安全边际(Margin of Safety)

$$\text{安全边际率} = \frac{\text{实际销量} - \text{盈亏平衡销量}}{\text{实际销量}}$$

衡量销量下降多少才会亏损,反映经营风险。

### 经营杠杆(Operating Leverage)

$$\text{DOL} = \frac{\text{边际贡献}}{\text{利润}} = \frac{(P-VC)Q}{(P-VC)Q - FC}$$

DOL 衡量销量变动 1% 对利润的放大倍数:
- 高 FC、低 VC 业务(航空、酒店、SaaS)→ DOL 高
- 低 FC、高 VC 业务(零售、餐饮)→ DOL 低

DOL 越高,经营波动越大(高利润潜力 + 高亏损风险)。

### CVP 图

横轴销量 Q,纵轴金额:
- 总收入线:y = P·Q,过原点斜率 P
- 总成本线:y = FC + VC·Q,起点 FC,斜率 VC
- 两线交点 = 盈亏平衡点
- 交点右方:利润区
- 交点左方:亏损区

### 假设条件

CVP 严格成立需:
1. 价格 P 不随销量变化(线性收入)
2. 单位变动成本不变(线性成本)
3. 总固定成本不变
4. 单一产品或固定产品组合
5. 生产 = 销售(无库存累积)

现实中常需放宽:
- **分段线性**:价格折扣、规模经济
- **产品组合**:用加权平均边际贡献率
- **相关范围**:在一定产销范围内假设线性

### 多产品 CVP

加权平均边际贡献率:

$$\overline{CM\%} = \sum_i (CM\%_i \cdot w_i)$$

其中 w_i 是产品 i 的销售额占比。

整体盈亏平衡销售额:

$$\text{BE} = \frac{FC}{\overline{CM\%}}$$

注意:产品组合变化会改变盈亏平衡点(即使总销售额不变)。

### 主要应用

**1. 定价决策**
- 用边际贡献思维评估降价的销量补偿要求
- 折扣策略评估

**2. 产品组合**
- 在瓶颈资源下,优先生产单位瓶颈资源边际贡献最高产品

**3. 是否接受特殊订单**
- 增量收入 > 增量变动成本 + 增量相关固定成本 即可考虑

**4. 自制 vs 外购**
- 比较增量成本 + 机会成本

**5. 销售策略**
- 销售额 vs 边际贡献:销售员激励机制

**6. 投资决策**
- 新设备的盈亏平衡销量、增量经营杠杆

### CVP 与 ABC 的对话

- CVP 假设变动 / 固定二元划分,但 ABC 显示"批次成本""产品成本"是中间层
- 现代管理会计常把 CVP 与 [[ABC作业成本法]] 结合:
  - 单位级成本归入变动成本
  - 批次级、产品级、设施级单独考虑
- 这避免了 CVP 在多元化场景的失真

### 主要局限

- **线性假设**:价格、成本对销量非线性时失真
- **短期视角**:固定成本"固定"只是短期假设
- **忽略不确定性**:实际销量是分布而非点估计
- **单一价值动因**:利润只看销量,忽视质量、服务、品牌
- **静态**:不反映动态调整

### 现代扩展

- **概率 CVP**:用销量分布得到利润分布
- **敏感性分析**:逐一调整价格、成本、销量看影响
- **情景分析**:乐观、中性、悲观三种情景
- **CVP + 蒙特卡洛**:用模拟得风险概率

## 和其他概念的关系

本量利分析是 [[成本会计]] 与 [[管理会计]] 的核心工具,与 [[ABC作业成本法]] 在分析维度上互补。它直接应用于 [[财务报表分析]] 中盈利能力评估与情景分析。它在 [[资本预算]] 决策中作为快速可行性筛选。它的"单位边际贡献"概念与 [[消费者剩余与生产者剩余]] 在思维上相通——都是单位决策。它与 [[弹性理论]] 在量价关系分析上有交集。在 [[财务比率分析]] 中,它支撑"经营杠杆"等指标的解读。
