# 精益生产

## 定义

**精益生产**(Lean Production / Lean Manufacturing)是一种以**消除浪费、持续改善**为核心的运营哲学与方法体系,起源于二战后日本丰田汽车公司的**丰田生产方式**(TPS),由大野耐一、新乡重夫等人创立。

"精益"(Lean)一词由 MIT 学者 James Womack、Daniel Jones 在 1990 年的著作 *The Machine That Changed the World* 中提出,把丰田做法系统化为可移植的方法论。

它的根本目标:**用最少的人、最少的库存、最短的时间,生产最高质量、最贴合客户需求的产品**。

## 核心要点

### 五大原则(Womack & Jones)

1. **定义价值**(Value):从**客户视角**定义什么是价值,客户不愿付钱的就是浪费
2. **绘制价值流**(Value Stream):画出端到端的所有活动,识别增值与非增值步骤
3. **创造流动**(Flow):让产品在不间断的流动中通过价值流,理想是单件流
4. **拉动生产**(Pull):由下游需求拉动上游生产,而非上游推动下游
5. **追求完美**(Perfection):持续改善 (Kaizen),无尽头

### 七大浪费(Muda)

大野耐一识别的工厂中常见浪费,后扩展为八大:

| 浪费 | 含义 |
|---|---|
| 过量生产 | 生产超过需求(最严重的浪费) |
| 等待 | 设备故障、断料、批次切换造成的停滞 |
| 运输 | 不必要的物料搬运 |
| 过度加工 | 超过客户需求的工序或精度 |
| 库存 | 占用资金、掩盖问题、风险大 |
| 动作 | 操作员的多余动作 |
| 缺陷 | 返工、报废、客户投诉 |
| (扩展)未利用的人才 | 员工智慧未被发挥 |

### 核心工具

| 工具 | 用途 |
|---|---|
| 5S | 整理、整顿、清扫、清洁、素养 — 现场管理基础 |
| 看板 (Kanban) | 拉动生产的信息卡片,控制在制品 |
| 价值流图 (VSM) | 端到端流程可视化诊断 |
| SMED 快速换模 | 把换模时间从小时级降到分钟级 |
| 防错法 (Poka-Yoke) | 设计上消除错误可能 |
| 标准作业 | 当前最佳方法的明文规定 |
| 单件流 | 一次只做一件,缩短周期 |
| Andon 呼叫系统 | 任何员工发现异常立即停线 |
| Hoshin Kanri 方针管理 | 把战略层层下沉到日常改善 |

### 精益文化

工具只是表象,精益的灵魂是文化:

- **现场主义**(Genchi Genbutsu):管理者去现场观察事实,而非看报告
- **持续改善**(Kaizen):微小、持续、全员参与
- **尊重员工**:员工是问题解决者,而非指令执行者
- **长期思维**:管理决策要服务长期理念而非短期财报

### 与六西格玛的对比与融合

| 维度 | 精益 | 六西格玛 |
|---|---|---|
| 关注 | 流速、消除浪费 | 质量、降低变异 |
| 工具 | VSM、看板、5S | DMAIC、统计工具 |
| 思维 | 流程视角 | 数据驱动 |

二者融合为**精益六西格玛**(Lean Six Sigma),既消除浪费又降低变异。

### 适用范围扩展

- **精益服务**:医院、银行、政府服务的应用
- **精益创业** (Lean Startup):Eric Ries 借鉴精益思想形成"构建-测量-学习"循环,创业方法论
- **精益软件开发**:看板方法在敏捷软件开发中的延伸

### 实施陷阱

- **工具至上**:生搬硬套 5S 而忽略文化
- **领导短视**:精益需 3-5 年才见根本改变
- **绩效冲突**:精益强调减少库存,与传统绩效考核(产量、稼动率)矛盾
- **没有"为何"**:员工不理解目的,改善活动流于形式

## 和其他概念的关系

- 是 [[运营管理]] 的核心方法论
- 通过 [[供应链管理]] 与上下游协同(JIT 拉动延伸至供应商)
- [[价值链分析]] 视角下精益是优化价值链每个环节的方法
- 与 [[变革管理]] 紧密结合,精益转型是组织变革
- [[平衡计分卡]] 内部流程维度常以精益指标衡量
- [[管理会计]] 中精益核算(Lean Accounting)替代传统标准成本法
- [[领导力]] 中"现场主义""赋能员工"是精益领导力特征,与 [[变革型领导]]、服务型领导高度共鸣
- 持续改善文化是 [[组织文化]] 的具象化
- 与 TQM(全面质量管理)、TPM(全面生产维护)同源
