# 户外保险

## 定义

户外保险(Outdoor / Adventure Insurance)是**专门覆盖户外高风险活动**的人身意外与紧急救援保险,与普通旅游意外险的核心区别在于**承保活动范围**——后者通常排除登山、攀岩、潜水、滑雪等高风险项目,户外保险则把这些列为可保。其核心保障是**医疗费用**、**紧急救援费用**(直升机、马队、向导)、**搜寻费用**、**身故 / 残疾赔偿**。

## 核心要点

**户外保险 vs 普通旅游险的关键差异**

| 维度 | 普通旅游险 | 户外保险 |
|---|---|---|
| 高山徒步(>3000m) | 多数不保 | 可保(分海拔档) |
| 攀岩 / 攀冰 | 排除 | 可保(注明等级) |
| 高海拔登山(>4000m) | 全排除 | 专项产品 |
| 滑雪 / 冲浪 | 部分保 | 详细分级 |
| 潜水 | 看深度 | 详细分级 |
| 直升机救援 | 几千 | 几十万至无上限 |
| 搜救费用 | 不保 | 单独条款 |
| 户外向导 | 不保 | 可保 |

**核心条款逐项审查**

1. **承保活动列表**:逐字读"可保活动"清单,模糊的就当不保
2. **海拔限制**:常见 3000m / 4500m / 6000m / 8000m 多档,超额无保障
3. **救援费用上限**:50 万 / 100 万 / 无上限,直升机一次出动 ¥10-30 万
4. **医疗费用上限**:与境内 / 境外区分,境外医院贵
5. **医疗转运(Medical Repatriation)**:海外受伤后转回国内的费用,几十万级
6. **遗体送返**:海外身故后遗体送返费用
7. **免赔额**:每次出险自付门槛
8. **保险期间**:精确到时区与小时(过保后受伤不赔)

**主流国际产品**

- **Global Rescue**:专业搜救公司,会员制 + 单次,无救援费用上限
- **World Nomads**:背包客最熟悉,200+ 国家、活动可定制
- **IMG Patriot**:留学 / 长期居留,医疗为主
- **Garmin inReach + Insurance**:卫星通讯设备 + 配套救援保险
- **AAC American Alpine Club**:登山协会会员含 7500 美元搜救保障

**国内产品**

- **平安户外险**、**中国人寿境外险**:覆盖国内徒步、滑雪
- **专业户外险(美亚 / 安联)**:涵盖更广,但高海拔仍需个案核保
- **登山协会团体险**:某些俱乐部统一购买,价格优惠但限制活动

**典型理赔流程**

1. 受伤后立即联系保险救援电话(24/7)
2. 保险方安排救援(直升机 / 当地向导队)
3. 治疗:在保险方网络医院或自付后报销
4. 提交材料:警方报告 / 医疗证明 / 收据 / 出险经过
5. 审核:1-3 个月,大额需调查
6. 赔付:打款保险账户

**容易踩雷的"小字"**

- "酒后受伤"不赔
- "未购票登山"(未办登山许可证)不赔
- "无向导独攀"被部分产品排除
- "已知的高血压 / 高反史"未告知 → 拒赔
- "战争 / 恐袭区域"自动排除
- 投保后 24-72 小时等待期,新购隔日活动可能未生效

## 与其他概念的关系

户外保险是 [[户外安全与应急]]、[[户外应急医疗]] 的金融兜底,与 [[徒步露营]]、[[雪地露营]]、[[Bushcraft]] 等高风险活动配套。在 [[保险市场]] 整体中是细分险种。也与 [[风险管理体系]] 思路一致——不是为了"省事",而是为了"风险转移"。

## 高频陷阱

- 看保费便宜直接买 → 高海拔 / 攀岩没覆盖,出事不赔
- 国内徒步保险常排除"未开发线路"——很多徒步路线属于
- 大多数国内意外险救援额度 5-50 万,直升机救援远不够
- 不通知保险公司自行下山治疗 → 后续报销困难
- 保单语言陷阱:"登山"(mountaineering)≠"徒步"(hiking)≠"攀岩"(climbing),分级精细
