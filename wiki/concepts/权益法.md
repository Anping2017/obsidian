# 权益法

## 定义

**权益法**(Equity Method of Accounting)是一种 [[长期股权投资]] 核算方法:投资方按其在被投资方所有者权益中享有的份额,**动态调整投资账面价值**——被投资方实现净损益、宣告分红或其他权益变动,投资方按持股比例反映在自身账上。

它适用于对被投资方具有**重大影响**(通常持股 20%-50%)或**共同控制**(合营企业)的情形,是对子公司"合并"与对纯金融工具"公允价值"之间的中间档。

## 核心要点

### 适用条件

| 持股 | 影响 | 方法 |
|---|---|---|
| > 50%(或控制) | 控制 | 单体用成本法 + 集团合并 |
| 20%-50% | 重大影响 | **权益法** |
| 50% 共同控制 | 共同控制 | **权益法** |
| < 20% 无重大影响 | 无 | 公允价值计量 |

判断"重大影响"考虑:
- 在董事会拥有席位
- 参与制定财务和经营政策
- 重要交易往来
- 关键技术资料互换
- 互派管理人员

### 核心会计处理

#### 取得投资

```
借:长期股权投资—投资成本     按对价或公允价值
   贷:银行存款或其他对价

如果投资成本 > 应享有可辨认净资产公允价值份额:
   差额体现为隐性商誉,不单独确认,不调整投资成本
如果投资成本 < 应享有公允价值份额:
   借:长期股权投资
   贷:营业外收入(差额)
```

#### 持有期间的核心动作

**1. 确认应享有的损益**:

被投资方实现净利润 100,持股 30%:
```
借:长期股权投资—损益调整    30
   贷:投资收益                30
```

**2. 收到分红**:

被投资方分红 60,持股 30%:
```
借:应收股利                  18
   贷:长期股权投资—损益调整  18
```

**3. 反映其他综合收益变化**:

被投资方 OCI 变动 50,持股 30%:
```
借:长期股权投资—其他综合收益  15
   贷:其他综合收益              15
```

**4. 反映其他权益变动**:

被投资方接受捐赠等导致资本公积变动:
```
借:长期股权投资—其他权益变动  份额
   贷:资本公积                   份额
```

### 处置投资

```
借:银行存款                       处置款
   长期股权投资—损益调整(贷方)
   长期股权投资—其他综合收益(贷方)
   贷:长期股权投资—投资成本(借方)
       投资收益(差额,可正可负)

同时把累计 OCI 转入投资收益(若是权益工具部分:计入留存收益)
```

### 内部交易抵销

投资方与被投资方间的内部交易未实现损益,需按持股比例**抵销**:

例:投资方向联营企业销售存货 100,成本 80,联营企业未售出,持股 30%。

```
未实现内部利润 = (100 - 80) × 30% = 6
借:投资收益          6
   贷:长期股权投资    6
```

类似 [[合并报表]] 中的内部交易抵销原理,只是按比例抵销。

### 减值

资产负债表日检查是否有减值迹象。计提:

```
借:资产减值损失
   贷:长期股权投资减值准备
```

权益法投资减值后**不可转回**(除非通过重新计量进入合并范围等特殊情况)。

### 关键差异:权益法 vs 比例合并

| 维度 | 权益法 | 比例合并 |
|---|---|---|
| 资产负债 | 仅一项"长期股权投资" | 按比例并入各项 |
| 收入费用 | 仅一项"投资收益" | 按比例并入各项 |
| IFRS 11 后 | 合营企业必用权益法 | 已废止 |

IFRS 11(2013 起)要求合营企业一律用权益法,简化国际差异。

### 持股比例变化的转换

| 变化方向 | 处理 |
|---|---|
| 从公允价值计量 → 权益法 | 重新计量原投资,差额进损益 |
| 从权益法 → 公允价值计量 | 剩余股权按公允价值,累计 OCI 转损益 |
| 从权益法 → 控制(合并) | 加购对价 + 原股权公允价值,差额进损益,累计 OCI 转损益 |

### 权益法的局限

- 单一报表项目浓缩复杂经济关系
- 重大影响判断主观性强
- 内部交易抵销实务繁琐
- 对小持股但有重大影响场景适用,公允价值变化无法反映

## 和其他概念的关系

- 是 [[长期股权投资]] 三大核算方法之一(成本法、权益法、公允价值)
- 与 [[合并报表]] 中的全面合并形成"持股比例 vs 影响"梯度
- 减值与 [[商誉]] 减值原理相通,但商誉不单独确认
- [[国际财务报告准则]] IAS 28 / IFRS 11 / IFRS 12 是制度依据
- 影响 [[财务报表分析]] 中"投资收益"的解读
- 与 [[杜邦分析]] 拆解中"投资收益占比"密切相关
