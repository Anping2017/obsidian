# 计算摄影

## 定义

计算摄影(Computational Photography)指 **不依赖单次曝光的物理成像,而通过多帧采集 + 神经网络合成 + 实时算法重建** 来生成最终照片的技术范式。iPhone 是这一范式的旗手,从 iPhone 6s 的 HDR 起步,到 iPhone 11 的 Deep Fusion、iPhone 13 的 Photonic Engine、iPhone 15 Pro 的 ProRAW + Smart HDR 5,每代相机的画质提升主要来自算法,而非传感器尺寸。

## 核心要点

### 关键技术管线

- **Smart HDR**:在按下快门前后分别拍摄欠曝、正常、过曝多帧,神经网络融合出高动态范围。
- **Deep Fusion**:9 帧像素级融合,在中低光场景增强纹理细节,处理过程在 [[A系列芯片]] 神经网络引擎进行。
- **夜景模式**:长曝光多帧叠加 + AI 降噪,弱光下亮度提升数倍。
- **人像模式**:用景深图模拟大光圈虚化,边缘羽化由神经网络判定。
- **Photonic Engine(iPhone 14+)**:在像素融合早期就引入深度学习,而非仅在最后阶段。
- **ProRAW**:保留计算摄影的处理链,但允许专业用户在 RAW 工作流中再调整。

### 与传统摄影的差异

| 维度 | 传统摄影 | 计算摄影 |
|---|---|---|
| 输入 | 单次曝光 | 多帧序列 |
| 处理 | 模拟/简单 ISP | 神经网络管线 |
| 主导因素 | 镜头 + 传感器 | 算法 + 算力 |
| 物理瓶颈 | 难以突破 | 可被软件迭代缓解 |

### 硬件依赖

计算摄影**不是纯软件**。它依赖:
- **ISP**(图像信号处理器,集成于 [[A系列芯片]])
- **神经网络引擎**(运行 Core ML 模型)
- **大光圈传感器**(提供原始光信号)
- **OIS/sensor-shift**(为多帧对齐提供稳定输入)

少了任一环都跑不动。Android 阵营追赶 iPhone 计算摄影的难点,正在于专用 ISP/NPU 和 OS 层 API 的协同。

### 美学倾向

iPhone 的计算摄影风格被批评为"过于干净、白平衡偏冷、HDR 过强";iPhone 13/14 后逐步降低算法干预强度,iPhone 15 Pro 的 ProRAW 提供了完全可控的工作流,反映出 Apple 对"算法 vs 真实"边界的修正。

## 关系

- 由 [[A系列芯片]] 中的 ISP + 神经网络引擎驱动
- 是 [[iOS系统架构]] 中 Media 层 Core Image / AVFoundation 的下游
- 与 [[iPhone电池技术]] 形成 trade-off(每张照片处理消耗显著能量)
