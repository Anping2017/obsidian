# 英语状语从句

## 定义

状语从句(Adverbial Clause)是在复合句中充当主句状语、修饰主句谓语动词或整句的从句,由从属连词引导。按语义功能,状语从句分九大类型:**时间、地点、原因、条件、目的、结果、让步、比较、方式**。状语从句的引导词决定从句类型,从句的时态和语气受具体类型影响,是英语写作和阅读理解的关键句型。

## 核心要点

### 九大类状语从句及核心连词

| 类型 | 主要连词 | 例句 |
|---|---|---|
| 时间 | when, while, as, before, after, until/till, since, as soon as, by the time | When I was young, I liked music. |
| 地点 | where, wherever, anywhere, everywhere | Wherever you go, I will follow. |
| 原因 | because, since, as, for, now that, seeing that | Because it rained, we stayed. |
| 条件 | if, unless, as/so long as, provided/providing (that), in case, on condition that | If it rains, we will stay home. |
| 目的 | so that, in order that, that, lest, for fear that | I study so that I can pass. |
| 结果 | so...that, such...that, so that, with the result that | He worked so hard that he passed. |
| 让步 | although, though, even though, even if, while, as, no matter wh-, however/whatever | Although it rained, we went out. |
| 比较 | than, as...as, not so/as...as, the more...the more | He runs faster than I do. |
| 方式 | as, as if, as though, the way, like(口语) | Do it as I told you. |

### 时间状语从句的关键规则

**主将从现规则**:在时间和条件状语从句中,从句一般不用将来时,而用一般现在时表将来:
- *When he comes, I will tell him.*(不用 will come)
- *I will wait until he arrives.*(不用 will arrive)

**when / while / as 的区别**:
- when 接时间点或时间段都可,既接持续动作也接瞬间动作。
- while 主要接持续动作("当...的时候"),只能接时间段。
- as 强调"一边...一边"或"随着"。

**before / after / since 的语法暗示**:
- after 引导从句时,从句可用过去完成时或一般过去时(after 已表先后)。
- since 引导从句必用过去时,主句用现在完成时:*I have lived here since I was born.*

### 条件状语从句与虚拟语气

if 引导的条件句分三类(详见 [[英语虚拟语气]]):
- 真实条件:if + 现在时, 主句 + will/can。
- 现在不可能:if + did/were, 主句 + would/could do。
- 过去不可能:if + had done, 主句 + would have done。

**unless = if not**,但 unless 不能用于不可能的虚拟假设:
- ✓ Unless it rains, we will go out.(= If it doesn't rain)
- ✗ Unless I were you, I wouldn't.(应改为 If I weren't you)

### 让步状语从句的特殊性

**although / though / even though** 引导让步从句,主句**不能用 but**(中文"虽然...但是"在英文中只用一个连词):
- ✓ *Although he is young, he is wise.*
- ✗ *Although he is young, but he is wise.*

**however/whatever/whenever** 引导让步从句,意为"无论":
- *However hard you try, success is not guaranteed.*
- *Whatever you say, I won't believe.*
- *Whenever you come, you are welcome.*

**as 引导让步从句**需把表语/副词倒装到 as 前:
- *Young as he is, he is mature.*(他虽然年轻)
- *Hard as he tried, he failed.*

### 结果状语从句的两种主要句型

- **so + adj/adv + that**:*He ran so fast that no one could catch him.*
- **such + (a/an) + adj + n + that**:*He is such a good student that everyone likes him.*
- **so + adj + a/an + n + that**:*It was so cold a day that we stayed home.*(此句型 so 后接 adj + a/an + n)

### 目的状语从句与结果状语从句的混淆

- 目的从句通常用情态动词 can/could/may/might 表"以便、为了":*I study hard so that I can pass.*
- 结果从句不用情态动词,而用一般动词陈述事实:*He worked hard so that he passed.*(从句中不用 can,表示已实现的结果)

so that 可引导两种从句,通过有无情态动词判断。

### 比较状语从句的省略

比较句中常省略与主句重复的成分:
- *He is taller than I (am).*(省略 am)
- *She runs as fast as he (does).*

注意比较对象必须可比:*The weather here is better than (that) in Beijing.*(不可直接 *better than Beijing*)

## 和其他概念的关系

- 状语从句是 [[英语从句体系]] 三大类之一,与名词性从句和定语从句并列。
- 时间和条件状语从句的"主将从现"规则与 [[英语时态体系]] 紧密相关。
- 条件状语从句中的非真实条件与 [[英语虚拟语气]] 完全重合,需要联合掌握。
- 让步从句的 as 引导句涉及 [[英语倒装句]] 中的部分倒装。
- 状语从句可简化为非谓语短语(见 [[英语非谓语动词]]):*When I was walking* → *Walking*; *Because he was tired* → *Tired,...*。
- 在 [[英语写作结构]] 中,状语从句提供逻辑连接(因果、转折、条件),是议论文的关键句式。
