# 响应式设计

## 定义

**响应式 Web 设计(Responsive Web Design, RWD)** 由 Ethan Marcotte 在 2010 年提出,核心思想是用**单一代码库 + 流式布局 + 媒体查询**,让网页**自动适应**从手机到平板到桌面到大屏的所有视口。它取代了早期"为移动单独建 m.xxx.com"的多站点方案。

## 核心要点

### 1. 三大支柱

1. **流式网格(Fluid Grid)**:用 % / fr / vw 而非固定 px
2. **弹性媒体(Flexible Media)**:`img { max-width: 100% }`
3. **媒体查询(Media Query)**:按视口调整样式

```css
.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
```

### 2. 媒体查询断点

```css
/* Mobile First */
.card { padding: 1rem; }
@media (min-width: 768px) { .card { padding: 2rem; } }
@media (min-width: 1280px) { .card { padding: 3rem; } }
```

常见断点(Tailwind 风格):
- `sm`: 640px
- `md`: 768px
- `lg`: 1024px
- `xl`: 1280px
- `2xl`: 1536px

### 3. 移动优先(Mobile First)

先写小屏 CSS,用 `min-width` 媒体查询往上加。原因:

- 移动占比超 60%
- CSS 上溯比下溯更自然
- 在限制中思考,关键内容先呈现

### 4. 视口元标签

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

不加,移动浏览器会按 980px 假宽缩放渲染,所有移动样式失效。

### 5. 现代单位

| 单位 | 含义 |
|---|---|
| `%` | 父容器百分比 |
| `vw / vh` | 视口宽高百分比 |
| `vmin / vmax` | 视口较小/较大边 |
| `rem` | 根字号倍数(主题切换友好) |
| `em` | 父字号倍数 |
| `ch` | "0" 字符宽度 |
| `dvh / svh / lvh` | 动态/最小/最大视口高度(避 iOS 地址栏问题) |

### 6. 容器查询(Container Queries)

2023 年浏览器全支持,**按父容器尺寸**而非视口设样式:

```css
.card { container-type: inline-size; }
@container (min-width: 400px) { .card-content { display: grid; } }
```

侧边栏的卡片可独立判断自己宽度,这是 RWD 真正的"组件化"。

### 7. 响应式图片

```html
<img srcset="small.jpg 400w, medium.jpg 800w, large.jpg 1600w"
     sizes="(max-width: 600px) 100vw, 50vw"
     src="medium.jpg" alt="...">

<picture>
  <source media="(min-width: 800px)" srcset="hero-wide.webp">
  <source srcset="hero-mobile.webp">
  <img src="hero-mobile.jpg" alt="...">
</picture>
```

浏览器自动选最合适。Next.js `<Image>` 等框架封装这些。

### 8. 排版

- `clamp(min, fluid, max)`:`font-size: clamp(1rem, 2vw, 1.5rem)`
- 阅读宽度上限 `max-width: 65ch`
- 行高 1.5-1.7

### 9. 测试

- Chrome DevTools 设备模拟
- 真机:iOS Safari、Android Chrome、各尺寸
- 主流分辨率:375 / 390 / 768 / 1024 / 1280 / 1920

### 10. 与适应式设计区别

| 概念 | RWD 响应式 | AWD 适应式 |
|---|---|---|
| 代码 | 一套 + 媒体查询 | 多套(几个固定断点) |
| 流畅度 | 像水流连续 | 跳跃 |
| 灵活性 | 高 | 低 |
| 维护 | 容易 | 多套要同步 |

现代基本都用 RWD。
