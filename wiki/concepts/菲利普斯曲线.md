# 菲利普斯曲线

## 定义

**菲利普斯曲线(Phillips Curve)**:刻画通货膨胀率 π 与失业率 U 之间关系的曲线。原始版本由 A.W.菲利普斯 1958 年通过研究英国 1861-1957 年数据发现工资增长率与失业率的负相关关系,后被萨缪尔森与索洛推广为通胀-失业关系,成为 1960s 凯恩斯主义政策的核心工具。

历经三代演进:**原始 → 附加预期 → 新凯恩斯**,反映宏观理论从经验关系到微观基础的不断深化。

## 核心要点

### 第一代:原始菲利普斯曲线(1958-1960s)

经验性观察:π = π_0 − β(U − U_0)

含义:存在稳定的通胀-失业权衡 —— 政府可通过提高通胀换取低失业,反之亦然。这是 1960s "新经济学"政策乐观主义的理论基础。

### 第二代:附加预期菲利普斯曲线(Friedman-Phelps,1968)

```
π = π^e − β(U − U_n) + ε
```

加入**预期通胀 π^e**与**自然失业率 U_n**两个关键变量。

核心论断(自然率假说):
- **短期**:π^e 给定时,π 与 U 仍存在权衡
- **长期**:π^e 调整至 π,U → U_n,菲利普斯曲线垂直
- **政策含义**:任何试图把 U 长期压低于 U_n 的尝试只会带来加速通胀

这一理论在 1970s 美国滞胀中得到实证验证 —— 早期通胀-失业曲线"打结"现象正是预期调整的体现。它彻底改变了宏观政策思维。详见 [[弗里德曼]]。

### 第三代:理性预期与新古典(Lucas, 1972)

理性预期下,公众正确预期央行政策,只有**未预期到的**政策能产生短期效果(菲利普斯曲线的"惊喜"形式)。

```
π − π^e = −β(U − U_n) + ε
```

含义:有规则、可预测的政策完全无效。这是"政策无效命题"的经典形式,推动了规则 vs. 相机抉择的辩论。

### 第四代:新凯恩斯菲利普斯曲线(NKPC)

```
π_t = β·E_t[π_{t+1}] + κ·(Y_t − Y_t^*)
```

或用边际成本:π_t = β·E_t[π_{t+1}] + κ·mc_t

特征:
- 微观基础来自卡尔沃定价(部分企业每期能调价的几何分布模型)
- 通胀由预期未来通胀和当前产出缺口共同决定
- 是新凯恩斯 DSGE 模型的核心方程

### 现实经验:曲线"扁平化"

后金融危机时代,美国与欧元区菲利普斯曲线呈现历史性扁平化:
- 失业率大幅下降但通胀持续低于 2% 目标
- 解释:全球化、人口老龄化、平台经济、预期锚定良好

但 2021-2022 年美国通胀飙升至 9% 又使曲线恢复"陡峭",显示其形态可能依赖预期是否锚定与冲击规模。

### 政策含义:NAIRU 与货币政策

**NAIRU = 非加速通胀失业率** ≈ 自然失业率,是央行决定加息时机的核心参照。U < NAIRU → 紧缩;U > NAIRU → 宽松。

**牺牲率(Sacrifice Ratio)**:为降低 1 个百分点通胀必须付出的累积失业率。1980s 沃尔克反通胀的代价约为 5(失业上升 5 点·年降通胀 1 点),强化了"通胀目标制"的理论吸引力。

### 供给冲击下的菲利普斯曲线

负向供给冲击(石油涨价)使曲线整体右移 —— 同一失业率水平对应更高通胀,产生滞胀。1970s 是经典案例。这与 [[AD-AS模型]] 中 SRAS 左移分析等价。

## 和其他概念的关系

菲利普斯曲线把 [[价格指数与通胀]]、[[失业理论]]、[[GDP核算]] 三大宏观变量统合于一个方程,是 [[货币政策]] 决策的核心理论参照(尤其是通胀目标制)。

它与 [[AD-AS模型]] 内在等价 —— AS 曲线斜率反映通胀-产出权衡,通过奥肯定律(失业-产出关系)即转化为通胀-失业权衡。供给冲击在两个模型中分析一致。

[[凯恩斯]] 思想是第一代菲利普斯曲线的灵感,而 [[弗里德曼]] 通过自然率假说彻底改造了它,引入预期机制。Lucas 的理性预期革命再度推进。

跨域:[[利率理论]] 中央行通过观察菲利普斯曲线决定政策利率;[[货币政策传导机制]] 中预期渠道(forward guidance)正是基于附加预期菲利普斯曲线的逻辑;[[行为经济学]] 与 [[行为金融学]] 对预期形成的研究为新一代菲利普斯曲线提供心理学基础;[[投资组合理论]] 与 [[资产配置]] 中"经济周期定位"分析直接以菲利普斯曲线判断当前在通胀-失业空间的位置;[[债券市场]] 中通胀预期是名义利率的决定性因素之一。
