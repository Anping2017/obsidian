# 自一致性

## 定义

**自一致性**(Self-Consistency, SC)是 **Xuezhi Wang** 等人在 **2022 年** 论文《Self-Consistency Improves Chain of Thought Reasoning in Language Models》中提出的提示工程技术,核心思想:**对同一问题让 LLM 在 [[思维链]](CoT)模式下多次独立采样不同推理路径,然后对最终答案投票取众数**。它基于"复杂问题往往有多种正确推理路径都通向同一答案"的观察,通过多数投票剔除偶发错误,显著提升数学、常识、符号推理任务的准确率。

## 核心要点

### 基本流程

1. 用 [[思维链]] 风格提示问题
2. 设置 temperature > 0(常用 0.5-0.7)
3. 独立采样 N 次(常 5-40 次)
4. 提取每条推理的最终答案
5. 多数投票得出最终答案

```python
def self_consistency(question, n=10, temp=0.7):
    answers = []
    for _ in range(n):
        response = llm.generate(
            prompt=f"问题: {question}\n让我们一步步思考:",
            temperature=temp
        )
        answer = extract_answer(response)
        answers.append(answer)
    return Counter(answers).most_common(1)[0][0]
```

### 与 CoT 的关系

- CoT 是基础:必须先用 CoT prompt 触发推理
- SC 是扩展:在 CoT 基础上多采样
- **SC 不会改善只有一种推理路径的任务**(如简单事实问答)
- **SC 对开放式任务无效**(投票需可比较的离散答案)

### 实证效果

Wang 2022 在 GSM8K(数学题)、SVAMP、AQuA、StrategyQA、ARC 等基准上:
- 单次 CoT:GPT-3 在 GSM8K 约 17%
- SC + CoT(40 samples):GSM8K 约 56%(纯 CoT 约 47%)
- 越复杂的任务提升越大
- 后期 GPT-4、Claude 等已默认包含部分类似机制

### 为何有效

理论解释:
1. **多种路径通向同一正确答案**:正确答案是"吸引子"
2. **错误路径分散**:不同的错误路径,答案各异
3. **投票剔除偶发错误**:多数路径+多数答案 → 鲁棒性

数学上,如果每条推理独立有 p 概率正确(且错误答案分散),多数投票准确率随 N 单调上升。

### 主要参数

| 参数 | 推荐 | 影响 |
|---|---|---|
| **temperature** | 0.5-0.7 | 多样性来源,过低无变化,过高混乱 |
| **N(采样数)** | 5-40 | 越多越准但成本线性增加 |
| **top_p / top_k** | 默认 | 与 temperature 共同控制采样 |
| **prompt** | CoT 触发 | 必须包含"step by step" |

### 主要变体

#### Universal Self-Consistency

多种 prompt 模板 × 多种推理风格 × 多次采样,聚合后投票。

#### Self-Refine

不用投票,用模型自身评估每个答案,选最优。

#### Reasoning Paths Aggregation

不只投票,还分析推理路径的质量,加权聚合。

### 适用场景

**适合**:
- **数学题**:答案是数字,易聚合
- **多选题**:答案是选项标签
- **结构化推理**:可解析为离散答案
- **代码生成 + 单元测试**:用测试通过率投票

**不适合**:
- **开放写作**:答案不可比较
- **对话**:多轮交互不便重采样
- **需要确定性场景**:每次回答需一致
- **成本敏感**:N 倍 LLM 调用

### 实战权衡

- **N 与准确率**:边际递减,N>20 提升通常很小
- **N 与成本**:线性增加,GSM8K 一次 SC = 10-40 次 LLM 调用
- **延迟**:并行采样可缓解
- **答案抽取**:需要稳健的答案 parser
- **平局处理**:多数投票出现平票时,可加权或随机

### 与其他方法的对比

| 方法 | 思想 | 提升 | 成本 |
|---|---|---|---|
| CoT | 引出推理 | +20-30% | 1× |
| **SC + CoT** | 多采样投票 | +5-15% | N× |
| ToT | 树搜索 | +50%(难题) | N×M× |
| ReAct | 工具增强 | 视任务 | N× + 工具 |
| Reflexion | 失败反思 | 视任务 | 多轮 |

SC 是性价比最高的"无脑提升"方法之一。

### 现代落地

- **OpenAI o1 / Claude reasoning**:内置类似机制(beam search + voting)
- **MathAgent / AlphaProof**:数学竞赛 AI 大量用 SC
- **Code completion**:代码 + 测试 + 投票
- **API 工具**:Anthropic、OpenAI 提供 batch sampling 接口

### 主要批评

- **粗糙**:不利用推理过程,只看最终答案
- **路径质量浪费**:好的推理路径与坏的同等权重
- **只对可聚合答案有效**
- **被更精细方法部分取代**:Self-Refine、ToT 等

但因其简单、稳健、易部署,自一致性仍是工程首选基线。

## 和其他概念的关系

自一致性是 [[思维链]] 的简单而有效的扩展,与 [[思维树]] 在思路上相通(都是探索多路径)但 SC 是无结构的并行采样。它与 [[ReAct提示]] 可结合形成 self-consistent ReAct。它属于 [[提示词工程方法论]] 中"采样多样化"的方法。它在 [[模型评估]] 中作为强基线常被对比。它与 [[少样本提示]] 兼容(few-shot CoT + SC)。它与 [[Reflexion]] 在"利用多次尝试"上相似但 Reflexion 是序贯反思,SC 是并行投票。
