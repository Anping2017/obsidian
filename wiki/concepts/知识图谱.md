# 知识图谱 Knowledge Graph

## 定义

知识图谱(Knowledge Graph, KG)是**用图结构(节点 + 边)组织和表达实体、属性、关系的语义网络**,目标是把人类知识转化为机器可理解、可检索、可推理的形式。

Google 在 2012 年首次大规模公开使用「Knowledge Graph」一词,把搜索结果右侧的实体卡片背后的知识库命名为此。

知识图谱本质是 **三元组(Subject, Predicate, Object)** 的集合:

- (Steve Jobs, founded, Apple)
- (Apple, headquartered_in, Cupertino)
- (Cupertino, located_in, California)

## 核心要点

### 关键技术

| 任务 | 描述 | 方法 |
|---|---|---|
| 实体识别 NER | 从文本提取实体 | LSTM-CRF、BERT |
| 关系抽取 RE | 识别实体间关系 | 远程监督、Prompt LLM |
| 实体消歧 | 「Apple」是水果还是公司 | 上下文 + 链接 |
| 实体对齐 | 跨数据源同实体识别 | 嵌入相似度、规则 |
| 知识表示 | 图上向量化 | TransE、TransR、Node2Vec、Graph Neural Networks |
| 知识推理 | 已有事实推断新事实 | 路径推理、规则、嵌入 |
| 知识问答 KBQA | 自然语言→图查询 | 语义解析、检索 |

### 表示方法

- **RDF + SPARQL**:W3C 标准,Wikidata、DBpedia 使用
- **属性图**:Neo4j、Cypher 查询语言
- **领域本体(Ontology)**:OWL 描述类、关系、约束
- **嵌入向量**:把节点与边映射到向量空间

### 应用场景

| 场景 | 用法 |
|---|---|
| 搜索引擎 | Google 知识卡片、Bing 实体面板 |
| 推荐系统 | 通过「相关实体」打开发现路径 |
| 问答系统 | 客服、医疗、法律领域 KBQA |
| 风控反欺诈 | 关联挖掘可疑账号 |
| 制药与生信 | 蛋白-基因-疾病关系图 |
| 企业知识库 | 内部文档、流程、人物图谱 |
| RAG 增强 | KG + LLM 提供事实底座 |

### 与 LLM 的关系

[[大语言模型]] 兴起后曾被认为会替代知识图谱,但实践中二者越来越互补:

- LLM 强生成、弱事实精确
- KG 强结构、弱泛化
- **GraphRAG**:把 KG 检索结果作为 LLM 上下文,提升事实正确性
- **LLM 自动构建 KG**:用 LLM 从非结构化文本抽取三元组,降低人工成本

## 和其他概念的关系

知识图谱处于 [[人工智能]]、[[数据库]]、[[语义网]]、[[认知科学]] 的交叉地带。它是符号主义 AI 的现代代表,与连接主义([[神经网络]])形成对照。

[[图数据库]](Neo4j、JanusGraph、TigerGraph)是知识图谱的存储底座;[[图算法]](最短路径、社区发现、PageRank、连通分量)是其分析手段。

[[NLP]] 中的 [[实体识别]]、[[关系抽取]] 是构建 KG 的关键技术;[[向量数据库]] 与 KG 互补——后者强结构精确,前者强语义模糊。

[[RAG|RAG检索增强生成]] 与 GraphRAG 结合 KG,显著提升 LLM 在专业领域的事实可靠性。[[Siri与Apple Intelligence|Apple Intelligence]]、ChatGPT、Copilot 等系统内部都引用结构化知识源(Wolfram Alpha、Wikidata、维基百科)。
