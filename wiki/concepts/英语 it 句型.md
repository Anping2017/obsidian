# 英语 it 句型

## 定义

it 句型指英语中以代词 it 担当特殊语法功能而非具体指代的句型集合,主要包括四类:**形式主语 it**、**形式宾语 it**、**强调句的引导词 it**、**无指代意义的 it**(指天气、时间、距离等)。it 句型解决了英语句子结构平衡(避免头重脚轻)、强调表达、特定句式约定等问题,是英语区别于中文的典型语法特征。

## 核心要点

### 形式主语 it

当真正的主语是不定式短语、动名词短语或从句,且较长时,常把它后置,在句首用 it 占位:

- 不定式作主语:*It is important to learn English.*(原型:To learn English is important.)
- 动名词作主语:*It is no use crying over spilt milk.*
- that 从句作主语:*It is true that he is honest.*
- whether 从句作主语:*It is unknown whether he will come.*
- 疑问词从句作主语:*It is unclear what he meant.*

常见句型:
- *It is + adj + (for sb) + to do*:*It is necessary for you to study hard.*
- *It is + adj + (of sb) + to do*:*It is kind of you to help me.*(of 表特征)
- *It takes + 时间 + to do*:*It takes me an hour to walk to school.*
- *It seems/appears that...*:*It seems that he is right.*

### 形式宾语 it

当谓语动词后既要带宾语又要带宾语补足语,而真正的宾语很长时,用 it 占位,真正的宾语后置:

- *I find it difficult to learn English.*(it = to learn English)
- *He makes it a rule to exercise daily.*
- *She considers it important that everyone be on time.*
- *We think it necessary to help others.*

形式宾语只用于带宾补的句型:`主 + 谓 + it + 宾补 + 真正宾语(不定式/从句)`。

### 强调句的引导 it

it is/was...that... 强调句中 it 没有意义,只是引导词。详见 [[英语强调句]]。

### 无指代意义的 it

英语中"零主语句"(中文常见)在英语中必须有主语,it 充当无意义的形式主语:

- 天气:*It is raining/snowing/sunny.*
- 时间:*It is 8 o'clock.* / *It's Monday.*
- 距离:*It is 5 miles to the station.*
- 温度:*It is cold today.*
- 客观情况:*It is dark.* / *It is quiet here.*

中国学生常错说 *Today is raining.*(❌)、*Now is 8 o'clock.*(❌)。

### it 与 there be 的区分

- it 用于具体存在状态、时间、天气等。
- there be 用于"有...存在"的存现句:*There is a book on the desk.*
- 错误:*It is a book on the desk.*(❌,中式英语)

### 三个常考辨析

1. **It is/was + adj + that...**(主语从句)vs **It is/was + 名词/代词 + that...**(强调句):
   - *It is important that he comes.*(主语从句,important 是表语)
   - *It is Tom that came.*(强调句,Tom 是被强调主语)
   - 判断:去掉 it is...that 是否还是完整句。

2. **It is + 时间长度 + since...** vs **It is + 时间点 + when...**:
   - *It is two years since I graduated.*(自从毕业已经两年)
   - 时间长度用 since,时间点用 when。

3. **it 与 one 的区别**:
   - *I lost my pen and bought a new one.*(one 指同类的另一个)
   - *I lost my pen and finally found it.*(it 指原物)

## 和其他概念的关系

- 形式主语 it 主要服务于 [[英语主谓宾结构]] 中长主语的平衡问题,与 [[英语非谓语动词]] 作主语、[[英语从句体系]] 中名词性从句作主语的场景密切相关。
- 强调句中的 it 引导词与 [[英语强调句]] 是同一概念。
- 无指代 it 体现了英语作为"主语优先"语言的特征,与中文"话题优先"形成对比。
- 在 [[英语写作结构]] 中,合理使用 it 句型能使表达更地道、句式更平衡。
- 形式主语句也大量出现在 [[英语虚拟语气]] 的"It is necessary/important that..."建议结构中。
