# 递延所得税

## 定义

**递延所得税**(Deferred Income Tax)源于**会计利润**(按 [[权责发生制]] 与会计准则计算)与**应税所得**(按税法计算)之间存在的**暂时性差异**(Temporary Differences)。

按照"资产负债表债务法",企业不仅要确认本期"当期所得税"现金负担,还要把未来可抵或可补的差异提前在资产负债表上确认为**递延所得税资产**(DTA)或**递延所得税负债**(DTL)。这是 [[税务会计]] 与 [[财务会计]] 衔接的核心机制。

## 核心要点

### 永久性差异 vs 暂时性差异

| 类型 | 含义 | 是否产生递延 |
|---|---|---|
| **永久性差异** | 会计与税法对某项目的口径根本不同(如罚款不可税前抵扣) | 不产生递延 |
| **暂时性差异** | 仅时点不同,未来必将转回(如折旧年限不同) | 产生递延 |

### 应纳税暂时性差异 → 递延所得税负债

资产账面价值 > 计税基础,或负债账面价值 < 计税基础。
未来期间将产生应税所得,提前确认负债。

典型例:
- **加速折旧**:税法允许快速折旧,初期税前抵扣多,会计折旧少 → 现在少交税,未来多交 → DTL
- **公允价值上升**:交易性金融资产升值确认会计利得但未实际处置纳税

### 可抵扣暂时性差异 → 递延所得税资产

资产账面价值 < 计税基础,或负债账面价值 > 计税基础。
未来期间可抵扣应税所得,提前确认资产。

典型例:
- **资产减值准备**:会计计提减值但税法未允许扣除 → 现在多交税,未来转回 → DTA
- **预提费用**:会计已计提但税法不认可 → 同上
- **可抵扣亏损**(Tax Loss Carryforward):本年亏损可在未来 5 年内抵扣应税所得

### 计算公式

```
递延所得税资产 = 可抵扣暂时性差异 × 未来转回时的所得税税率
递延所得税负债 = 应纳税暂时性差异 × 未来转回时的所得税税率
```

注意使用**未来生效税率**而非当期税率;税率变化时需重估调整。

### 在 [[利润表]] 中的影响

```
所得税费用 = 当期所得税 + 递延所得税费用
           = 应交所得税 + (期末DTL - 期初DTL) - (期末DTA - 期初DTA)
```

- 当期现金税负反映在"应交税费"
- 暂时性差异变动反映在"递延所得税"

### 减值与确认条件

DTA 必须满足"未来很可能取得足够应税所得"才能确认,否则计提减值。亏损连续年的科技公司常被审计师挑战其 DTA 的可回收性。

### 实务示例

某公司本年:
- 会计折旧 100,税务折旧 150,差异 50(应纳税)
- 计提坏账 30,税法不认,差异 30(可抵扣)
- 税率 25%

```
DTL 增加 = 50 × 25% = 12.5
DTA 增加 = 30 × 25% = 7.5
递延所得税费用 = 12.5 - 7.5 = 5(增加)
```

### 与国际准则差异

- IFRS(IAS 12)与中国准则口径接近,均采用资产负债表债务法
- US GAAP(ASC 740)对不确定税收头寸(UTP)处理更复杂

## 和其他概念的关系

- 来源:[[权责发生制]] 与税法在时点上的不一致
- 计量基础:[[历史成本]]、[[公允价值]] 计量差异引发暂时性差异
- 影响:[[利润表]] 所得税费用、[[资产负债表]] 资产/负债项
- 上游:[[会计准则体系]]、[[国际财务报告准则]] 规定确认与计量
- 实务对接:[[税务会计]]、[[审计]] 的复核重点
- 与 [[财务报表分析]] 关系:DTA 大量增长可能预示未来盈利预期,DTL 反映税收推迟收益
