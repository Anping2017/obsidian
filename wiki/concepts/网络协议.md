# 网络协议 Network Protocol

## 定义

网络协议(Network Protocol)是**计算机或网络设备间通信所遵循的规则与约定**。它精确规定:

- **语法**:消息的格式、字段、编码
- **语义**:每个字段的含义与控制信息
- **时序**:消息发送与响应的顺序、超时处理

协议是分布式系统能够互联互通的基石——没有协议,设备间的「通信」只是无意义的字节流。

## 核心要点

### 分层模型

| OSI 七层 | TCP/IP 四层 | 代表协议 |
|---|---|---|
| 应用层 | 应用层 | HTTP、HTTPS、DNS、SMTP、FTP、WebSocket、gRPC |
| 表示层 | (并入应用层) | TLS、SSL |
| 会话层 | (并入应用层) | - |
| 传输层 | 传输层 | TCP、UDP、QUIC |
| 网络层 | 网络层 | IP、ICMP、路由协议 |
| 数据链路层 | 链路层 | Ethernet、Wi-Fi、PPP |
| 物理层 | 链路层 | 电气信号、光信号 |

### 协议特性维度

- **可靠 vs 不可靠**:TCP 保证有序无丢失;UDP 不保证
- **有连接 vs 无连接**:TCP 三次握手建立连接;UDP/IP 无状态
- **流式 vs 数据报**:TCP 是字节流;UDP 是离散数据报
- **同步 vs 异步**:HTTP/1 同步;WebSocket、gRPC streaming 异步
- **文本 vs 二进制**:HTTP 文本;Protocol Buffers/MessagePack 二进制紧凑

### 常见协议速览

- [[HTTP协议|HTTP]] / [[HTTPS]] / [[HTTP2协议|HTTP_2]] / [[HTTP3协议|HTTP_3]]:Web 通信骨干
- [[TCP]] / [[UDP]] / [[QUIC]]:传输层三大主力
- [[WebSocket]]:全双工实时通信
- [[gRPC]]:基于 HTTP/2 的二进制 RPC
- [[MQTT]]:物联网轻量发布/订阅
- [[DNS]]:域名解析
- [[OAuth]]:授权框架(应用层协议)

## 和其他概念的关系

网络协议是 [[计算机网络]] 体系的核心,既约束 [[操作系统]] 的网络栈实现,也定义 [[微服务]] 间通信方式。

[[HTTP协议|HTTP]] 已成为 Web 与 API 的事实标准;[[gRPC]]、GraphQL 是其上层抽象。[[TCP]]/[[UDP]] 之上的协议设计是 [[分布式系统]] 工程的基本功。

[[网络安全]] 强烈依赖协议设计:[[HTTPS]]、TLS、DNSSEC、IPsec 都通过密码学保护协议安全。
