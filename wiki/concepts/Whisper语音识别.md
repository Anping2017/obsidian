# Whisper语音识别

## 定义

**Whisper** 是 [[OpenAI]] 在 2022 年 9 月发布的**开源多语言语音识别模型**(Automatic Speech Recognition, ASR),发表于论文 *Robust Speech Recognition via Large-Scale Weak Supervision*。

它通过**68 万小时**(2 万小时英文 + 11.7 万小时其他语种 + 12.5 万小时翻译)的弱监督数据训练,在多语言转写、跨噪声鲁棒性、口音适应上接近人类水平,完全开源(MIT 协议)使其成为当代 ASR 的事实标准。

## 核心要点

### 架构

完全基于 [[Transformer]] 的编码-解码结构:

```
原始音频(WAV/MP3 等)
   ↓
Mel 频谱图(80 通道)
   ↓
卷积层(下采样)
   ↓
Transformer Encoder(理解音频)
   ↓
Transformer Decoder(生成文本)
   ↓
转录文本(可指定语言、是否翻译)
```

### 多任务训练

Whisper 不仅做"音频→文本"转录,而是同时学习:

| 任务 | 输入 → 输出 |
|---|---|
| 多语言转录 | 音频(法语)→ 法语文本 |
| 语音翻译 | 音频(法语)→ 英语文本 |
| 语言识别 | 音频 → 语种 |
| 时间戳 | 音频 → 文本 + 时间 |
| 静默检测 | 音频 → 无说话信号 |

通过特殊 token(`<|transcribe|>`, `<|translate|>`, `<|en|>`, `<|fr|>`, `<|notimestamps|>`)在解码端引导任务。

### 模型规模

| 模型 | 参数 | 显存 | 速度 |
|---|---|---|---|
| tiny | 39M | <1GB | 极快 |
| base | 74M | 1GB | 快 |
| small | 244M | 2GB | 中等 |
| medium | 769M | 5GB | 较慢 |
| large-v3 | 1550M | 10GB | 慢 |
| turbo(2024) | 809M | 6GB | 快(蒸馏自 large) |

### 数据策略:质 vs 量

#### 弱监督而非强监督

- 不要求严格人工校对
- 包含字幕、视频转录、播客等"半准确"配对
- 用质量过滤(自动检测低质对)清洗
- 68 万小时 vs 当时最大公开数据(3 万小时)

#### 多语言均衡

- 99 种语言
- 大语种数据多,小语种数据少但仍有覆盖
- 跨语言能力(零样本翻译)

### 性能突出点

#### 1. 噪声鲁棒性

通过多样训练数据(咖啡馆、街道、电话、会议室),对真实环境噪声适应良好。

#### 2. 口音泛化

不同英语口音(印度、苏格兰、澳大利亚)、汉语方言(普通话、粤语转录)表现稳定。

#### 3. 跨域适应

医疗、法律、技术、娱乐等领域无需专门微调即可使用。

#### 4. 长音频处理

支持 30 秒分块拼接,可处理小时级音频。

### 局限

#### 1. 幻觉

模型在静默或不清晰段落可能"凭空"生成文本——医疗、法律转录场景的严重风险。

#### 2. 实时性

最大模型(large)在 CPU 上较慢,实时转录需 GPU 或小模型。

#### 3. 说话人分离

Whisper 不区分多人说话,需配合 pyannote 等说话人日志(diarization)工具。

#### 4. 多语种混合

代码切换(中英混合)的句子可能无法完美转录。

### 实务部署

#### faster-whisper

Python 库,用 CTranslate2 引擎,推理速度提升 4 倍,显存减半。

#### whisper.cpp

C++ 移植,支持 CPU、Mac M 系列、Android,无 GPU 也能跑。

#### Whisper API

OpenAI 提供托管服务($0.006/分钟),用于不想自部署的场景。

#### 本地部署生态

- WhisperX:增强版,带说话人分离 + 强制对齐
- Subtitle Edit:GUI 字幕生成
- Buzz:开源 ASR 桌面应用

### 应用场景

#### 1. 字幕与转录

- YouTube 自动字幕替代
- 播客文字版
- 会议录音整理
- 视频本地化(转录后翻译)

#### 2. 语音助手

集成到 ChatGPT 语音模式、Siri、Alexa 类产品的转录端。

#### 3. 内容理解

- 视频内容索引
- 客服录音质检
- 法律证据转录

#### 4. 无障碍

- 听障人士实时字幕
- 教育录音文本化

### 与传统 ASR 的对比

| 维度 | 传统 ASR(Kaldi) | Whisper |
|---|---|---|
| 架构 | HMM + DNN/RNN | Transformer 端到端 |
| 训练数据 | 严格标注小数据 | 68 万小时弱监督 |
| 多语言 | 需独立模型 | 单模型 99 语种 |
| 部署 | 复杂(声学+语言模型分离) | 单文件加载 |
| 准确率(英文) | WER ~5-10% | WER ~5%(挑战集) |

### 后续与替代

#### Whisper Large-v3(2023.11)

- 训练数据增加(包括合成数据)
- 时间戳准确度提升
- 支持广东话等更多方言

#### Whisper Turbo(2024.10)

- 蒸馏自 large-v3
- 速度 8 倍快于 large,精度仅微降
- 推荐生产环境使用

#### 竞品

- **Google USM**(Universal Speech Model)
- **Meta SeamlessM4T**:语音 + 文本翻译统一
- **Nvidia NeMo Canary**
- **AssemblyAI**(商业 API)
- **Microsoft Azure Speech**

### 与 LLM 的协同

```
音频 → Whisper → 文本 → LLM → 理解、问答、摘要
                        ↓
                 LLM → TTS → 音频(回答)
```

构成"语音 LLM 应用"的标准流程。GPT-4o 后,直接处理音频的"端到端语音 LLM"开始挑战 Whisper 的中间地位。

## 和其他概念的关系

- 基于 [[Transformer]] 编码器-解码器架构
- 是 [[OpenAI]] 在多模态领域的早期开源贡献
- 与 [[CLIP]](图文)在多模态思路上互补(语音-文本)
- 与 [[大语言模型]] 配合形成语音助手 / 智能客服等应用
- 训练上利用大规模弱监督数据,与 [[预训练与微调]] 思想呼应
- 与 [[模型量化]]、[[模型蒸馏]] 配合实现边缘部署
- 是 [[计算机视觉]] 之外,Transformer 一统多模态的另一里程碑
