# 销售管理

## 定义

**销售管理**(Sales Management)指对**销售队伍、销售流程与销售业绩**进行系统规划、组织、激励与控制的管理职能。它把企业的 [[市场营销]] 战略转化为客户拜访、订单签订、回款实现的具体行动,是营销战略落地、收入实现的关键环节。在 B2B 与高客单 B2C 业务中尤为重要。

## 核心要点

### 主要职责

- **目标设定**:基于 [[资本预算]] 与公司预期,分解到团队、人头、客户
- **区域与客户划分**:地理、行业、客户级别的合理分配
- **销售流程设计**:线索 → 商机 → 报价 → 谈判 → 成交 → 回款 → 复购
- **团队激励**(参见 [[激励理论]]):基本工资 + 提成 + 奖金 + 非财务激励
- **培训与赋能**:产品、流程、行业知识、谈判技巧
- **绩效管理**:KPI 设定、月度复盘、季度评估

### 销售模型

- **传统模型**:陌拜、电话、客户关系驱动
- **顾问式销售**(Consultative):理解需求 → 定制方案 → 长期关系
- **挑战者销售**(Challenger):向客户提供新洞见、推动其改变思考
- **解决方案销售**:产品打包成解决业务问题的方案
- **企业大客户销售**(Key Account):一对一深度定制
- **数字化销售**:通过 CRM、营销自动化、社交销售

### 关键 KPI

- **结果类**:销售额、毛利、回款、客户增长
- **过程类**:拜访量、商机转化率、漏斗各阶段转化、平均成交周期
- **客户类**:[[客户生命周期价值]](LTV)、复购率、NPS
- **效率类**:人均产出、销售费用率、成交周期

### 现代趋势

- **CRM + 数据驱动**:Salesforce、HubSpot 等
- **PLG**(Product-Led Growth):产品驱动而非销售驱动
- **AI 赋能**:线索打分、对话分析、报价优化
- **混合模式**:内部销售(Inside Sales)+ 现场销售
- **销售运营**(Sales Ops):专门职能优化销售机器

### 与 [[激励理论]] 的紧密耦合

销售管理是激励理论应用最密集的领域:
- 期望理论:努力 → 业绩 → 提成 → 满足
- 公平理论:同岗位提成机制公平至关重要
- 强化理论:即时反馈与奖励
- 双因素理论:除了提成,工作意义、晋升、认可同样关键

## 和其他概念的关系

- 是 [[市场营销]] 战略落地到收入的桥梁
- 与 [[激励理论]] 在团队管理上深度交叉
- 与 [[组织行为学]]、[[领导力]] 在销售文化上交融
- 输出由 [[平衡计分卡]] 等绩效工具评估
- 是 [[营销定义与本质]] 的下游执行环节
