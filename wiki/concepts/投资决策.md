# 投资决策

## 定义

**投资决策**(Investment Decision)是投资主体(个人、企业、机构)在面对多种资产或项目时,为达成既定收益与风险目标而做出的资金配置与时机选择。

它涵盖三个层级:
- **个人理财**:储蓄/股票/基金/房产/养老
- **企业资本预算**:扩产、并购、研发、IT 系统
- **机构投资**:基金、保险、主权财富的资产配置

[[投资决策框架]] 是其系统化方法论。

## 核心要点

### 决策五要素

| 要素 | 内容 |
|---|---|
| **目标** | 收益要求、保值/增值/现金流、时间跨度 |
| **约束** | 风险承受度、流动性需求、税收、监管、ESG |
| **信息** | 宏观、行业、公司、价格、舆情 |
| **方法** | 基本面、技术、量化、行为 |
| **执行** | 仓位、时机、再平衡、止损 |

### 经典分析方法

- **[[现金流折现模型]]**:从未来现金流折回现值,DCF 是最严谨估值方法
- **[[相对估值法]]**:用 PE / PB / EV/EBITDA 等乘数对标可比公司
- **[[基本面分析]]**:宏观→行业→公司财务的自上而下
- **[[技术分析]]**:价格量能模式预测走势
- **[[量化分析]]** / [[量化投资策略]]:模型与算法驱动
- **[[行为金融学]]**:把 [[认知偏差]] 与 [[损失规避]] 纳入分析

### 决策框架的标准流程

1. **目标设定** → SMART 化收益与风险目标
2. **环境分析** → [[投资环境分析]]
3. **资产配置** → [[资产配置]] 解释 80%+ 长期方差
4. **证券选择** → 基本面 / 技术 / 量化
5. **执行与调整** → 再平衡、风险监控
6. **绩效评估** → [[绩效评估]],夏普 / 信息比率

### 风险管理

- **分散化** → 见 [[投资组合理论]]
- **对冲** → 衍生品工具
- **止损纪律** → 限制单次损失
- **仓位管理** → Kelly 公式、固定比例

### 行为陷阱

| 偏差 | 影响 |
|---|---|
| [[过度自信]] | 高估自身判断,频繁交易,跑输被动 |
| [[损失规避]] | 不愿割肉,过早卖出盈利 |
| [[沉没成本]] | 因已投入继续追加 |
| [[羊群效应]] | 跟随大众进入泡沫 |
| [[确认偏差]] | 只看支持自己持仓的信息 |
| [[锚定效应]] | 锁定买入价无法平衡判断 |

### 个人 vs 企业投资决策

| 维度 | 个人 | 企业 |
|---|---|---|
| 目标 | 长期保值增值 | 战略协同 + ROI |
| 工具 | 股、债、基、房 | 项目 NPV / IRR / 回收期 |
| 关键 | 资产配置 | [[资本预算]] |
| 心理 | 个人情绪 | 委托代理问题 |

## 应用场景

- **个人**:养老规划、子女教育、房产决策
- **企业**:[[资本预算]] 中的扩产、并购、研发优先级
- **机构**:养老金、保险、主权财富按 [[资产配置]] 与 [[投资组合理论]] 操作
- **风险投资**:[[精益创业]] 阶段下的不确定性投资决策

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **过度精确** | 把不确定问题精确化反而误导 |
| **忽略基础概率** | 见 [[忽略基础概率]],只看故事不看分布 |
| **回测过拟合** | 量化策略在历史好,实盘崩 |
| **黑天鹅低估** | 用正态分布度量肥尾世界 |
| **忽视成本** | 频繁交易、税费侵蚀长期收益 |
