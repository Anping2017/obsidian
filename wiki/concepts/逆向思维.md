# 逆向思维

## 定义

**逆向思维**(Inversion)是 [[芒格]] 反复倡导的思维方法,核心口号是"**反过来想,总是反过来想**"(Invert, always invert)。它要求在解决问题时,**不直接问"如何成功",而问"如何确保失败"**;然后系统避免那些失败路径。源自德国数学家雅可比"Invert, always invert"。

## 核心要点

### 核心机制

- **正向思维**:目标 → 步骤 → 行动(在不确定性下易遗漏重要陷阱)
- **逆向思维**:列出所有失败方式 → 排除它们 → 剩下的更可能成功
- **非对称信息**:导致失败的因素往往比导致成功的因素更明确

### 经典示例

- 想活得幸福? → 先列出"如何让自己悲惨" → 避免它们
- 想做好投资? → 先列出"如何亏掉所有钱" → 避开杠杆、避开能力圈外、避开高费用
- 想做好领导? → 先列出"如何当糟糕领导" → 避免独裁、不公、贪婪
- 想找对人生伴侣? → 先列出"什么样的人不能要" → 避免红旗

### 为什么有效

1. **失败更可识别**:成功路径多元,失败模式相对集中
2. **避错优先于求好**:大多数情况下不犯大错就能跑赢平均
3. **反方思考激活批判**:逆向触发系统 2(慢思考),抑制 [[认知偏差]]
4. **风险管理本质**:专注下行,锁住生存,等待向上机会

### 在投资中

- 巴菲特的两条规则:第一,不要亏钱;第二,不要忘记第一条
- 不问"哪只股票会大涨",问"哪只股票会零归" → 排除后选剩下的
- 不问"如何变富",问"如何避免破产" → 远离杠杆、欺诈、能力圈外

### 与"反事实思考"的关联

- **反事实思考**:如果我没做那个,会怎样?(回顾)
- **逆向思维**:如果我想失败,该怎么做?(前瞻)
- 两者互补,前者用于复盘,后者用于决策

### 与"前瞻 premortem"

- 卡尼曼推荐的工具:在决策前假设"已失败,现在写为什么"
- 先把所有可能失败原因列出 → 修订决策
- 是逆向思维的可操作版本

### 在多元思维模型中的位置

- 逆向思维不是独立模型,而是**应用模型时的角度**
- 配合 [[认知偏差]] 清单 → 逆向问"我会犯哪些偏差"
- 配合 [[复利效应]] → 逆向问"什么会打断我的复利"
- 配合 [[能力圈]] → 逆向问"在哪些领域我必败"

## 和其他概念的关系

- 由 [[芒格]] 系统倡导,是 [[多元思维模型]] 的核心方法
- 与 [[批判性思维]]、[[辩证法]] 共享"考虑反面"机制
- 是对治 [[认知偏差]] 特别是 [[确认偏差]] 的实践工具
- 在投资中影响 [[投资决策框架]] —— 先排除明显错误
- 与 [[第一性原理]] 互补:第一性自下而上构建,逆向自上而下排除
- 与 [[风险识别与度量]] 紧密关联 —— 从下行风险出发
- [[佛家]] "无常"观念与"避免执着"有相似精神
- [[战略管理]]:用 premortem 在战略实施前识别失败模式
- [[管理决策]]:作为偏见对治工具嵌入决策流程
