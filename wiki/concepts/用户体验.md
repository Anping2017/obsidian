# 用户体验

## 定义

**用户体验**(User Experience, UX)指**用户在与产品、系统、服务交互的整个过程中所感受到的主观整体反应与态度**——包括认知、情感、使用、记忆、口碑等方面。该概念由 Don Norman 在 1990 年代在 Apple 工作时提出,如今已扩展至产品设计、软件、服务、零售、医疗、教育等广泛领域,是数字时代产品差异化的关键来源之一。

## 核心要点

### 主要维度(以 Peter Morville 蜂巢图为例)

- **有用**(Useful):满足真实需求
- **可用**(Usable):易学、易操作、低出错
- **可寻**(Findable):信息容易被找到
- **可信**(Credible):用户信任产品
- **可达**(Accessible):无障碍设计,残障人士也能用
- **价值**(Valuable):为用户和企业都创造价值
- **令人愉悦**(Desirable):情感与美学
- **包容**(Inclusive):跨文化、跨能力

### 用户研究方法

- **定性**:用户访谈、可用性测试、日记研究、民族志
- **定量**:问卷、A/B 测试、行为日志分析
- **混合**:关键路径分析、漏斗分析、热图、点击流

### 设计输出

- **角色画像**(Persona):典型用户的虚拟代表
- **用户旅程地图**(Customer Journey Map):用户接触产品的全流程
- **信息架构**:内容组织与导航
- **交互设计**:控件、流程、反馈
- **视觉设计**:颜色、排版、品牌一致性
- **原型**:线框图 → 高保真 → 可点击原型

### UX 与 UI 的区别

- **UX**:体验全过程,包括产品外的关注与售后
- **UI**(User Interface):用户接口,通常指视觉与交互层
- 类比:UX 是骨,UI 是皮;UI 设计师专注屏上呈现,UX 设计师还要研究、信息架构、交付与衡量

### 衡量方法

- **行为指标**:任务完成率、时间、错误数、放弃率
- **态度指标**:NPS、CSAT、SUS(System Usability Scale)
- **业务指标**:留存、转化、ARPU、LTV
- **方法**:UEQ、UMUX、ResearchOps 工具链

### 经典范式

- **以用户为中心的设计(UCD)**:把用户研究放在每个阶段
- **设计思维(Design Thinking)**:同理 → 定义 → 创意 → 原型 → 测试
- **服务设计(Service Design)**:把 UX 扩展到线下、跨触点、组织流程
- **体验设计(XD)**:把数字与物理触点统一在一个体验框架下

### 现代趋势

- **AI 注入**:个性化推荐、对话式界面、生成式 UI
- **无障碍**:从合规走向"为所有人设计"
- **隐私优先**:数据收集与用户体验的张力
- **跨设备**:iPhone、Watch、CarPlay、Vision Pro 多模态联动([[Apple生态系统]] 是范例)
- **服务化**:从一次交易体验到长期关系体验

## 和其他概念的关系

- 是 [[消费者行为]] 在数字产品语境的具体体现
- 与 [[STP战略]]、[[价值主张]] 在产品策略上接续
- 与 [[市场营销]] 中"产品(Product)"模块紧密相连
- 影响 [[客户生命周期价值]] 与口碑传播
- 在 [[Apple生态系统]] 与设计驱动型公司中作为核心竞争力
