# Push通知

## 定义

Push 通知(Push Notification)是 App 在用户设备未打开应用时,通过 APNs(iOS)、FCM(Android)等推送通道把消息推到锁屏或通知中心的机制。它是移动 App 区别于 Web 的最强触达手段:无需用户在线、可瞬时触达、点击直接深链到对应页面。但同时也是用户反感度最高的渠道——授权率与 [[激活率]]、留存高度相关。

## 核心要点

**推送类型**:

- **Local Push**:本地调度,不依赖服务器(如签到提醒)。
- **Remote Push**:服务端发起,需 device token + 推送通道。
- **Silent Push**:静默推送,不展示给用户,仅唤醒后台逻辑(数据同步、内容预拉取)。
- **Rich Push**:带图片/视频/操作按钮(iOS Notification Service Extension、Android Big Picture Style)。
- **Web Push**:浏览器推送,Chrome / Firefox / Safari 支持,iOS Safari 16.4+ 才支持。

**授权率(Opt-in Rate)**:

- iOS 默认必须显式授权,平均 50-60%。
- Android 12 起也强制授权,平均 70-80%。
- **优化关键**:不要在打开 App 第 1 秒弹系统授权框,要先用 pre-permission 软提示让用户理解价值,再触发系统硬框。授权失败一次,就需要引导去系统设置——转化率骤降。

**分层细化**:

- 用 [[用户画像]] / 行为标签拆分人群,不要群发。
- 频率上限:消费 App 每天 1-2 条,资讯类可 3-5 条,工具类每周 1-2 条。
- **静音时段**:用户当地深夜不推送(否则集体退订)。

**内容设计**:

- **标题 < 40 字**,**正文 < 100 字**,iOS 锁屏只显示前几行。
- 第一句必须有"信息钩子"——好奇 / 紧迫 / 个性化具体名字。
- 表情符号可提升 CTR 5-15%,但与品牌调性不符则反效果。
- **深链(Deep Link)**:点击直接跳到对应内页,不是首页。否则用户找不到内容直接关掉。

**关键指标**:

- 授权率(Opt-in Rate)
- 送达率(Delivery Rate):iOS 95%+、Android 80-90%(国产 ROM 杀后台严重)
- 展现率(Impression Rate)
- 点击率(CTR / OTR Open-through Rate):2-10%
- 转化率:CTR × 内页转化
- 取消订阅率 / 关闭授权率

**触发场景**:

- **行为触发**:加购未付款 1 小时、内容更新、好友互动、订单状态变化。
- **时间触发**:每日早报、签到提醒、限时优惠倒计时。
- **位置触发**(LBS Push):门店附近 / 入境某城市。
- **AI 个性化**:基于用户活跃时段算法预测最佳推送时机(Optimal Send Time)。

**反模式**:

- 频繁广告推送 → 关闭通知 → 长期推送权限丧失。
- 标题党 → 点开发现内容货不对板 → 信任损耗。
- 全员同条文案 → 个性化为零。
- 重要消息只走推送不走站内消息 → 用户错过。

**国内特殊性**:

- 厂商通道(华为 Push、小米 Push、OPPO/VIVO/魅族)与第三方厂商通道(极光 / 个推 / 友盟)并存。
- 国产 ROM 后台杀进程严重,送达率比 iOS 低 10-30 个百分点。
- iOS 的 Critical Alert(紧急通知)需要苹果审核特殊权限。

## 和其他概念的关系

Push 是 [[移动营销]] 与 [[全渠道营销]] 的核心一环,与 [[邮件序列设计]]、短信(SMS)、站内消息构成"立体触达矩阵"。其触发逻辑常由 [[营销自动化]] 平台(MoEngage、Braze、Leanplum、CleverTap)统一调度,与 [[CRM]] 数据打通做精细分发。

Push CTR 直接影响 DAU、[[激活率]] 与 [[客户复购]]。在 [[AARRR模型]] 中,Push 是 Retention 的关键武器。它依赖 [[AB测试]] 优化标题与发送时机,效果记录进入 [[归因模型]] 分析。Web Push 与 [[搜索引擎优化]] 中的 [[Service Worker]] 同源——是 PWA 关键能力之一。

[[ATT隐私框架]] 与 [[隐私政策]] 影响 Push 的标识符使用和精准定向。过度推送会触发系统级反感(iOS Focus Mode、Android Notification Drawer)和 App Store 评分下降。
