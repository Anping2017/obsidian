# 页面SEO

## 定义

**页面 SEO(On-Page SEO)** 指在单个网页层面进行的优化,使该页面能在搜索引擎中精准匹配目标关键词与搜索意图、获得有竞争力的排名、吸引用户点击并产生转化。

页面 SEO 处于 [[搜索引擎优化]] 三大支柱(技术、内容、链接)中的"内容侧",与 [[技术SEO]](站点级别)和 [[链接建设]](站外信号)互补。它是普通内容创作者最需要掌握的 SEO 子领域。

## 核心要点

- **TDK(Title-Description-Keywords)**:
  - **Title 标签**:页面最重要的 SEO 元素之一,直接影响排名和 CTR
    - 长度:50-60 字符(中文 25-30 字)以避免在 SERP 截断
    - 结构:主关键词靠前、附加修饰、品牌名结尾
    - 唯一性:每页 Title 必须独特
    - 吸引力:数字、行动词、情感词提升 CTR
  - **Meta Description**:不是直接排名因素,但显著影响 CTR
    - 长度:150-160 字符(中文 75-80 字)
    - 内容:概括页面主题、引发点击欲望、自然包含关键词
    - 注意:Google 经常重写 Meta Description 用 SERP 实际相关片段替换
  - **Keywords Meta**:已被 Google 弃用,可不写
- **H 标签层级**:
  - **H1**:页面主标题,通常每页一个,与 Title 相关但可不同
  - **H2-H6**:层级化的副标题,反映内容结构
  - 良好的 H 结构既帮助 SEO 也帮助辅助技术(屏幕阅读器)
  - 避免:用 H 标签做样式(应用 CSS)、跳级使用
- **URL 优化**:
  - 简短(< 60 字符理想)
  - 包含主关键词
  - 用连字符(-)分隔单词,不用下划线(_)
  - 避免参数堆砌(?id=123&category=...)
  - 静态化 URL,可读性强
- **内容结构与质量**:
  - **匹配搜索意图**:见 [[搜索意图]]——内容形态、深度、风格匹配查询意图
  - **覆盖完整性**:回答主问题及相关子问题(PAA)
  - **深度与原创**:不重复 SERP 已有内容,提供新价值
  - **可扫描性**:小标题、列表、表格、加粗、引用
  - **多媒体**:图片、视频、信息图、图表丰富体验
  - **更新机制**:定期更新内容时间戳,反映新信息
- **图片 SEO**:
  - 文件名描述性(red-running-shoes.jpg 而非 IMG_001.jpg)
  - **alt 属性**:描述图片内容,辅助无障碍 + SEO + 图片搜索流量
  - 适当大小与格式(WebP、AVIF)优化加载速度
  - 懒加载(lazy loading)
  - Image Sitemap 帮助索引
- **内部链接**:
  - 引导用户深度浏览
  - 传递 PageRank 给重要页面
  - 用关键词锚文本(自然不堆砌)
  - Topic Cluster 互链(详见 [[链接建设]])
- **关键词应用**:
  - 主关键词:Title、H1、URL、首段、自然分布
  - 长尾词与变体:H2/H3、内容内、FAQ
  - LSI(语义相关词):自然嵌入提升相关性
  - **避免堆砌**:Panda 算法严打关键词堆砌
- **SERP 元素优化**:
  - 通过结构化数据获得富媒体结果(详见 [[结构化数据]])
  - 通过 FAQ Schema 占据更多 SERP 面积
  - 通过 HowTo Schema 触发步骤展示
- **页面停留与互动信号**:
  - 高跳出率与短停留可能影响排名
  - 改善:首屏吸引、内容深度、易读性、相关阅读、CTA
- **常见错误**:
  - 多页同 Title(造成内部竞争)
  - 关键词堆砌(算法惩罚)
  - 内容稀薄(<300 字的页面被 Helpful Content 系统降权)
  - 无 H1 或多个 H1
  - 图片无 alt
  - 内链锚文本全用"点击这里"
  - 内容长期不更新

## 和其他概念的关系

页面 SEO 是 [[搜索引擎优化]] 的"单页面层面",与 [[技术SEO]](站点层面)、[[链接建设]](站外)互补。

页面 SEO 的所有决策都基于 [[关键词研究]] 与 [[搜索意图]] 的洞察——没有关键词与意图清晰,Title 怎么写、内容怎么组织都是猜测。

页面 SEO 与 [[内容营销]] 的关系:页面 SEO 是内容在搜索引擎层的"翻译"——同样优秀的内容,有页面 SEO 处理 vs 没有,搜索流量可能差 5-10 倍。

页面 SEO 中的 H 标签结构与 [[结构化数据]] 共同构成"机器可读的内容结构"——前者是 HTML 语义,后者是显式语义。

页面 SEO 直接影响 [[转化漏斗]] 顶端的两环节:CTR(从 SERP 到落地)和落地页的相关性匹配(决定跳出与转化)。

页面 SEO 与 [[E-E-A-T]] 的实施层挂钩——作者署名、引用来源、更新时间这些都是页面级实施。
