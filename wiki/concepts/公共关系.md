# 公共关系 Public Relations

## 定义

公共关系(Public Relations, PR)是**组织(企业、政府、非营利)与其各类利益相关方(媒体、客户、员工、投资者、监管方、公众)之间的双向沟通管理**,旨在建立、维护、修复信任与正面形象,影响舆论与认知。

Edward Bernays(「PR 之父」)早期定义:「PR 是关于知情同意的工程学」;Grunig 现代定义偏向对称沟通,强调互利。

## 核心要点

### PR vs 广告 vs 营销

| 维度 | PR | 广告 | 营销 |
|---|---|---|---|
| 目标 | 信任与形象 | 销售与认知 | 客户全生命周期 |
| 渠道 | 媒体、社交、活动 | 付费媒体 | 综合 |
| 信息控制 | 较弱(媒体过滤) | 完全控制 | 部分 |
| 信任度 | 高(第三方背书) | 低 | 中 |
| 时间 | 长期、缓慢 | 短期可见 | 中长期 |
| 成本 | 中等 | 高 | 取决于 |

### 主要职能领域

| 领域 | 内容 |
|---|---|
| 媒体关系 | 新闻发布会、新闻稿、媒体专访、媒体培训 |
| 危机管理 | 突发事件应对、声明、新闻反向控制 |
| 投资者关系(IR) | 财报会议、ESG 沟通、监管披露 |
| 政府关系(GR) | 政策游说、监管对话 |
| 内部沟通 | 员工内刊、文化传播、变革沟通 |
| 社区关系 | 慈善、公益、当地参与 |
| 内容公关 | 企业博客、白皮书、行业报告 |
| 思想领袖(Thought Leadership) | 高管演讲、专栏、播客 |

### 经典模型

**Grunig 四大模型**:

1. 媒体宣传(Press Agentry):单向、夸大宣传
2. 公共信息:单向、客观信息
3. 双向不对称:双向但偏说服
4. 双向对称:真正对话与互利,理想模型

现代 PR 倾向第 4 类,但实践中仍有 1-3 类。

### 危机公关黄金法则

- **24 小时内回应**:沉默被解读为承认
- **承担责任**:即使非全部责任,也表达关切
- **事实导向**:数据、时间线、行动
- **统一口径**:全员对外信息一致
- **主动透明**:坦白短期承担,赢得长期信任
- **修复行动**:补救措施 + 制度改进

### 数字时代变化

- **去中心化**:每个员工都是 PR 节点(出格言论可能毁掉品牌)
- **社交媒体即时性**:危机发酵以小时计
- **网红/KOL**:第三方背书的新形态
- **算法影响**:内容触达取决于平台算法
- **舆情监测**:实时监控品牌提及与情感
- **AI 生成内容**:深度伪造与谣言挑战
- **Zero-Click 内容**:在平台内完成阅读,品牌曝光机会减少

## 和其他概念的关系

公共关系是 [[营销定义与本质]] 中沟通组合(Promotion)的重要组件,与 [[广告]]、[[销售管理]]、[[活动营销]] 并列;近年与 [[内容营销]]、[[社交媒体营销]] 边界模糊。

[[品牌定位]]、[[品牌权益]] 离不开 PR 的长期建设——产品功能可能被复制,但信任与形象很难。[[企业文化]] 决定了 PR 的真实底色,空有口号的 PR 不可持续。

[[消费者行为]] 中口碑(Word of Mouth)与 PR 紧密相关;[[羊群效应]]、[[羊群效应|从众心理]]、[[首因效应]] 等心理学机制解释了 PR 的影响路径。

数字 PR 与 [[搜索引擎优化SEO]]、[[链接建设]] 互通——优质媒体报道带来的高质量外链是 SEO 的重要支柱。

[[变革管理]] 中,内部 PR(变革沟通)是消除变革阻力的关键;[[领导力]] 在外的可见度本身就是高管 PR 的核心命题。
