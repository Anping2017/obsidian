# 管理职能

## 定义

**管理职能**(Management Functions)是管理工作的基本类别,即管理者必须执行的核心活动。最经典的版本由法国工程师亨利·法约尔(Henri Fayol)1916 年在《工业管理与一般管理》(*Administration Industrielle et Générale*)中提出**五职能**:**计划、组织、指挥、协调、控制**。

现代管理教材通常简化为**四职能 POLC**:

- **P**lanning 计划
- **O**rganizing 组织
- **L**eading 领导(整合"指挥+协调")
- **C**ontrolling 控制

这是 MBA 教科书最常用的管理工作框架。

## 核心要点

### 1. 计划(Planning)

确定组织目标并制定实现路径。

- **战略层**:愿景、使命、长期战略目标(参见 [[战略管理]])
- **战术层**:中期目标与方案
- **作业层**:短期具体任务与日程
- **类型**:战略计划、战术计划、运营计划、应急计划
- **工具**:[[SWOT分析]]、[[PESTEL分析]]、目标管理(MBO)、OKR
- **核心命题**:目标具体可衡量、路径可行、资源对位

### 2. 组织(Organizing)

设计组织结构、配置资源、明确职责权限。

**组织结构类型**:

| 类型 | 特征 | 适用 |
|---|---|---|
| 直线制 | 命令统一 | 小型、稳定 |
| 职能制 | 按职能分工 | 中型 |
| 事业部制 | 按产品/地区分 | 大型多业务 |
| 矩阵制 | 双重汇报 | 项目导向 |
| 网络型 | 核心 + 外包 | 创新、轻资产 |
| 扁平化 | 减少层级 | 数字化时代 |

**核心命题**:

- 战略决定结构(钱德勒)
- 集权 vs 分权
- 控制幅度
- 部门化与协调机制

### 3. 领导(Leading)

激励、引导员工实现目标,涵盖原五职能中的"指挥+协调"。

- 激励:参见 [[激励理论]]
- 沟通:层级、横向、对外
- 领导风格:参见 [[变革型领导]]、[[情境领导理论]]
- 团队建设
- 冲突管理

### 4. 控制(Controlling)

衡量与纠正实际绩效,确保按计划进行。

**控制过程四步**:

1. 设定标准
2. 衡量绩效
3. 比较差异
4. 纠正偏差

**控制类型**:

- **前馈控制**(Feedforward):事前预防
- **同期控制**(Concurrent):过程纠偏
- **反馈控制**(Feedback):事后改进

**控制工具**:[[平衡计分卡]]、[[财务比率分析]]、KPI 仪表板、预算控制、统计过程控制(SPC)、[[审计]]

### 五职能的关系

四(五)职能形成**循环**而非线性:

```
   计划 → 组织 → 领导 → 控制
     ↑                    ↓
     └──── 反馈调整 ────┘
```

控制结果反哺下一轮计划,形成持续改进循环(类似 PDCA)。

### 法约尔十四原则

法约尔在五职能之外,还提出十四条管理原则,至今仍有指导意义:

1. 劳动分工 2. 权力与责任 3. 纪律 4. 命令统一 5. 指挥统一 6. 个人利益服从整体利益 7. 报酬合理 8. 集中化 9. 等级链 10. 秩序 11. 公平 12. 人员稳定 13. 首创精神 14. 团结精神

### 现代评价与发展

- **明茨伯格的批评**:实证观察发现,管理者实际行为远比"五职能"碎片化(参见 [[管理者角色]])
- **数字化时代演变**:计算机和数据接管部分计划与控制,管理者角色更偏向"领导"和"组织设计"
- **敏捷管理**:计划-控制循环从月/年缩短到周/天,与传统职能在时间尺度上不同
- **复杂性管理**:VUCA 环境下,刚性计划让位于动态规划与情景规划

## 和其他概念的关系

- 是现代 [[管理学]] 的元框架
- 是 [[管理者角色]] 的活动维度,与明茨伯格的角色维度互补
- 计划职能对接 [[战略管理]]、[[资本预算]]
- 组织职能对接 [[组织结构]]、[[组织文化]]
- 领导职能对接 [[领导力]]、[[变革型领导]]、[[激励理论]]
- 控制职能对接 [[财务比率分析]]、[[平衡计分卡]]、[[内部控制]]、[[审计]]
- 与 [[管理学发展史]] 中科学管理([[泰勒]])、行政管理(法约尔)、行为科学(梅奥)等流派演进相关
- [[运营管理]] 是各职能在生产领域的具体化
- [[项目管理]] 体系(PMBOK)的五大过程组本质是职能在项目情境的应用
