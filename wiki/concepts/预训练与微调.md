# 预训练与微调

## 定义

**预训练-微调(Pretrain-Finetune)** 是现代 [[深度学习]],尤其是 [[大语言模型]] 的主导工程范式:

- **预训练(Pretraining)**:在大规模、通用、无标签语料上以自监督目标(next-token、掩码语言模型等)训练超大模型,获得通用语言/视觉表示
- **微调(Finetuning)**:在小规模、目标场景的标注数据上继续训练,使模型适应特定任务、风格或安全偏好

这种"通用预训练 + 专用微调"的两阶段思想最早在视觉(ImageNet 预训练 → 下游分类)中流行,2018 年由 [[BERT]]、GPT 引爆 NLP,如今是几乎所有大模型的基本套路。

## 核心要点

**预训练**

- 数据:数百 GB 至数万亿 [[Token]] 网页、书籍、代码
- 目标:无监督的下一 token 预测 / 掩码恢复
- 算力:数千 GPU 数周至数月,成本数百万美元起
- 结果:基础模型(Base Model 或 Foundation Model)

**微调主要类型**

| 类型 | 思想 | 代价 | 用途 |
|---|---|---|---|
| 全参微调 | 更新所有权重 | 极高(等同二次训练) | 大改任务行为 |
| [[LoRA]] / PEFT | 只训练低秩增量矩阵 | 极低 | 单卡可做,主流 |
| 指令微调(SFT) | 在 (指令, 回答) 对上微调 | 中 | 让基础模型变助手 |
| [[RLHF]] / DPO | 用人类偏好对齐 | 中高 | 安全、有用、诚实 |
| Prompt Tuning | 只训练 soft prompt 向量 | 极低 | 极少参数适应 |

**完整大模型训练流水线**

1. 大规模预训练 → Base Model
2. 指令微调(SFT)→ Instruct Model
3. 偏好对齐([[RLHF]]/DPO)→ Aligned Chat Model
4. 安全红队、Constitutional AI 等迭代

**何时不必微调**

- 通用知识问答:[[零样本提示]] 或 [[少样本提示]] 即可
- 知识更新:用 [[RAG]] 比微调更新更便捷
- 工具集成:[[函数调用]]、[[MCP协议]] 而非塞进权重

## 和其他概念的关系

- 主要载体:[[大语言模型]] 训练的标准范式
- 微调高效路径:[[LoRA]] 是 PEFT 的代表
- 对齐阶段:[[RLHF]] 是预训练之后让模型变听话变安全的关键
- 替代或补充方案:[[RAG]] 用检索而非权重更新注入新知识
- 与 [[过拟合与正则化]] 关系:大规模预训练相当于强先验,极大缓解小数据微调过拟合
- 失败模式:微调过头会引发"灾难性遗忘"
