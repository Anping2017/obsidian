# Penguin 算法

## 定义

**Penguin 算法** 是 Google 在 2012 年 4 月推出的算法更新,与 [[Panda算法]] 在内容侧并立——**Panda 打内容质量,Penguin 打链接质量**。它系统性识别和惩罚违规链接建设(Black-hat Link Building),把过去 14 年(自 PageRank 1998 起)"链接越多越好"的简单逻辑彻底改写。

Penguin 影响约 3% 英语查询,在某些垂直行业(医疗、博彩、贷款)影响超 10%。

## 核心要点

### 1. Penguin 打击的具体行为

| 行为 | 描述 |
|---|---|
| **购买链接** | 直接付费购买反向链接 |
| **链接交易** | "你链我我链你"(Link Exchange) |
| **链接农场** | 大量低价值站点互相链接 |
| **PBN(Private Blog Network)** | 私人博客网络,自建链接矩阵 |
| **自动化建链** | 软件批量在论坛、博客评论留链 |
| **过度精确锚文本** | 大量精确匹配关键词锚文本 |
| **垃圾目录提交** | 大量低质量目录 |
| **隐藏链接** | 字号小、颜色与背景同 |
| **过度互链** | 同一公司多个网站不自然互链 |

### 2. Penguin 的判断信号

#### a) 链接 profile 的"过于干净"
正常网站的反向链接应该自然多样:有锚文本变体、有 URL 链接、有图链接、有不同质量层级。如果太规整或全是精确匹配,Penguin 会怀疑。

#### b) 链接来源域多样性
1000 个反向链接但都来自 50 个域 vs 1000 个反向链接来自 800 个域,后者更自然。

#### c) 锚文本分布
精确匹配比例过高(如 60% 锚文本都是"便宜买耐克鞋")是典型 Penguin 红旗。健康分布:品牌词 + URL + 通用词("点这里"、"了解更多")+ 部分关键词。

#### d) 链接获取速度异常
新站突然一个月获得 10000 反链是典型作弊信号。健康增长应该是渐进的。

#### e) 链接质量与上下文
来自高 DA 但内容完全不相关的站(博彩站链接到母婴产品),信号异常。

### 3. Penguin 的演进

| 版本 | 时间 | 重点 |
|---|---|---|
| **Penguin 1.0** | 2012.04 | 首次推出 |
| **Penguin 2.0** | 2013.05 | 算法重写,影响更广 |
| **Penguin 3.0** | 2014.10 | 跨年更新 |
| **Penguin 4.0(实时)** | 2016.09 | 整合到核心算法,实时运行 |

Penguin 4.0 的关键变化:
- 实时:不再等月度刷新
- 更精细:从"惩罚整站"变为"贬值劣链",而非黑洞掉网站
- 整合到核心算法

### 4. Penguin 之后的链接建设

#### 旧战术(已死)
- 大量目录提交
- 论坛签名链接
- 评论刷链
- 文章轮发(Article Spinning)
- PBN
- 锚文本完全控制

#### 现代战术(EAT 链接)
- **Skyscraper Technique**:写比对手更好的内容,自然吸引链接
- **Broken Link Building**:找他人死链替换为自家内容
- **Digital PR**:做新闻级内容获得媒体报道
- **HARO(Help A Reporter Out)**:为记者提供专家观点换引用
- **Linkable Asset**:数据报告、工具、可视化吸引自然链接
- **Guest Post(高质量)**:在权威站客座,内容优先链接其次
- **关系链接**:行业伙伴、客户、合作方的自然链接

### 5. Disavow Tool(免责工具)

Google 2012 年推出 Disavow Tool,允许站长 **声明拒绝某些反向链接的"投票"**——避免恶意 SEO(竞争对手买垃圾链指向你的站陷害)。

使用 Disavow:
1. 用 Ahrefs/Semrush 分析反向链接
2. 标记可疑/有害链接
3. 在 GSC 提交 Disavow 文件

### 6. 对 SEO 行业的深远影响

Penguin 是 SEO 行业最大转折点之一:
- "链接"从"建链(Build Links)"变为"赚链(Earn Links)"
- 链接公司大量倒闭(尤其卖 PBN 的)
- 内容营销与公关合并到 SEO
- 链接质量评估工具(MozBar、Ahrefs DR)成为标配
- 大量旧站因历史链接遗留被罚,需要 Disavow 救命

## 现代意义

虽然 Penguin 早已并入核心算法,其思想仍是当代链接 SEO 基石:

1. **质量重于数量**
2. **自然增长重于计划性建链**
3. **品牌相关性重于 DA 高低**
4. **多样性重于精准匹配**
5. **品牌建设是最好的链接建设**

[[E-E-A-T]] 与 [[Helpful Content Update]] 是 Penguin 思想在内容时代的延续——把"链接信任"扩展为"全方位信任"。

## 实战教训

### 教训 1:历史包袱比新错更危险
2010 年代的旧链接策略可能仍在拖累网站,Disavow + 主动清理。

### 教训 2:不要盲信"高 DA 链接"
DA 高但内容不相关的链接价值低,有时甚至有害。

### 教训 3:负面 SEO 可能是真的
竞争对手买垃圾链指向你的站确实存在。要监控 Disavow。

### 教训 4:Earn 比 Build 慢但安全
赚到的链接是品牌资产,买来的可能瞬间被清算。
