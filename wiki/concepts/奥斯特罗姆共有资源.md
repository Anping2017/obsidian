# 奥斯特罗姆共有资源

## 定义

共有资源(Commons / Common-Pool Resources, CPR)是同时具备**减损性**(竞争性)与**难排他性**两个特征的资源,如渔场、灌溉、森林、放牧地、地下水。Hardin 1968 年《公地悲剧》预言此类资源必然过度使用、走向毁灭,主张要么国有化要么私有化。

埃莉诺·奥斯特罗姆(Elinor Ostrom)1990 年《公共事务的治理之道》(Governing the Commons)以 30 年实证调查反驳此预言:**自治社区可以通过制度安排有效治理共有资源**。她由此成为首位获诺贝尔经济学奖的女性(2009)。

## 核心要点

### 1. 设计原则(成功 CPR 治理八原则)

| 原则 | 内容 |
|---|---|
| 1. 边界清晰 | 资源边界与用户边界都明确 |
| 2. 占用规则与本地条件相称 | 规则适应当地生态、文化 |
| 3. 集体选择 | 多数受影响者参与规则制定 |
| 4. 监督 | 监督者对用户负责或本身就是用户 |
| 5. 分级制裁 | 违规惩罚由轻到重 |
| 6. 冲突解决机制 | 低成本本地纠纷解决 |
| 7. 组织权获得最低承认 | 上级不否认社区自治权 |
| 8. 嵌套企业 | 大规模 CPR 通过多层嵌套治理 |

### 2. 与公地悲剧的差异
- Hardin 假设:陌生人、无沟通、一次博弈
- 奥斯特罗姆现实:熟人、可沟通、长期互动
- 此时 [[囚徒困境]] 解构,合作可作为均衡

### 3. 案例研究
- 西班牙 1000 年灌溉社区(Huerta)
- 瑞士山区放牧
- 菲律宾梯田灌溉(Zanjera)
- 缅因龙虾捕捞自治
- 内布拉斯加地下水管理
- 涉及森林、渔业、灌溉、渔场上千案例

## 多中心治理

奥斯特罗姆与丈夫 Vincent Ostrom 提出"多中心治理"(Polycentricity):
- 多层级、多类型治理单位并存
- 反对国家/市场二分
- 嵌套规则适应不同尺度问题
- 与 [[公共选择理论]] 部分重合但更乐观
- 与 [[商业生态系统]] 有思想关联

## 与其他概念关系

- 反驳 [[公共物品]] 必须由政府提供的简化看法
- 与 [[博弈论]] 重复博弈合作均衡相符
- 与 [[新制度经济学]] 制度演化呼应
- 应用于 [[环境经济学]] 气候治理(碳预算 CPR)
- 与 [[儒家]] 礼治传统、印度村社传统有跨文化共鸣
- 影响 [[发展经济学]] 抛弃"政府或市场"两极

## 现代延伸

- **数字共有资源**:Wikipedia、开源软件、Linux
- **气候治理**:全球大气作为 CPR
- **数据治理**:个人数据集体治理新范式
- **平台经济**:平台是否能算共有资源
- 知识共有(Creative Commons)运动
- Yochai Benkler 同行生产理论

## 影响与意义

- 颠覆"市场 or 国家"二选一思维
- 重视本地知识、文化、习俗
- 为草根、社区运动提供理论支持
- 推动制度多元主义
- 经济学引入实地调研方法(田野政治经济学)
- 启发 [[管理学]] 网络组织、[[平台商业模式]] 治理
