# 管理会计

## 定义

**管理会计**(Management Accounting / Managerial Accounting)是**为企业内部管理者提供决策、规划、控制信息**的会计分支,与对外披露的**财务会计**形成根本区别。它的核心使命是回答管理者关心的问题:

- 哪个产品最赚钱?
- 应该自制还是外购?
- 应该接受这个特殊订单吗?
- 部门该如何考核?
- 资本投资项目是否值得?

管理会计无强制准则约束,服务于**经济决策**而非合规披露,因而方法多元、灵活。

## 核心要点

### 管理会计 vs 财务会计

| 维度 | 财务会计 | 管理会计 |
|---|---|---|
| 服务对象 | 外部(投资者、债权人、税务) | 内部管理者 |
| 强制性 | 准则强制 | 内部自定 |
| 时间视角 | 历史 | 历史 + 未来 |
| 颗粒度 | 整体公司 | 部门、产品、项目、客户 |
| 频率 | 月/季/年 | 实时 / 按需 |
| 准确度要求 | 精确 | 相关性优于精确 |
| 计量 | 货币 | 货币 + 实物 + 非财务 |

### 核心方法体系

**1. 成本会计(Cost Accounting)**

- **成本性态**:固定成本、变动成本、混合成本
- **产品成本**:直接材料、直接人工、制造费用
- **成本核算方法**:品种法、分批法、分步法、标准成本法
- **作业成本法 ABC**(Activity-Based Costing):按动因把间接费用更精准分摊到产品

**2. 本量利分析(CVP Analysis)**

研究成本、销量、利润关系:

```
利润 = (单价 - 单位变动成本) × 销量 - 固定成本
盈亏平衡点(BEP) = 固定成本 / 单位边际贡献
安全边际 = 实际销量 - BEP 销量
经营杠杆 = 边际贡献 / 利润
```

应用:定价、促销决策、产品组合决策。

**3. 短期决策分析**

基于**相关成本**与**机会成本**的决策:

- **特殊订单**:接受低于全成本的价格?(若 > 变动成本且产能闲置,接受)
- **自制 vs 外购**:比较相关成本,考虑机会成本
- **产品取舍**:看边际贡献而非全成本利润
- **生产瓶颈**:按"单位约束资源边际贡献"排序

注意:**沉没成本不相关,机会成本相关**。

**4. 预算管理**

- 全面预算:经营预算、财务预算、资本预算
- 弹性预算:按实际产量调整
- 滚动预算:不断推进的 12 个月预算
- 零基预算:每年从零开始论证(消耗资源大但破除惯性)

**5. 责任会计**

把组织划分为责任中心:

- **成本中心**:只控成本(生产部门)
- **利润中心**:控收入与成本(事业部)
- **投资中心**:控资产配置(集团子公司)
- 评估指标:可控成本、利润、ROI、EVA

**6. 战略管理会计(Strategic Management Accounting)**

把会计视角扩展到战略层:

- 客户盈利能力分析
- 价值链成本分析(参见 [[价值链分析]])
- 平衡计分卡(参见 [[平衡计分卡]])
- 经济附加值 EVA = NOPAT - 资本占用 × WACC

### 现代发展

- **精益会计**(Lean Accounting):服务 [[精益生产]],按价值流核算而非传统成本
- **EVA 与价值管理**:聚焦经济利润而非会计利润
- **数据分析与 BI**:实时仪表板替代月度报告
- **集成 ERP**:数据自动流入,管理会计师从核算转向分析与咨询
- **可持续会计**:把环境、社会成本纳入决策

### 管理会计师角色转型

传统:成本核算员、预算编制者(后台)

现代:**业务伙伴**(Business Partner)——参与决策、提供洞察、支持战略。CFO 角色亦从"账房"转向"战略合伙人"。

## 和其他概念的关系

- 是 [[会计学]] 的两大分支之一(另一支为财务会计)
- 数据基础来自 [[复式记账法]] 与 [[会计要素]]
- 与 [[财务比率分析]] 有交叉,但更精细到部门/产品
- 是 [[战略管理]] 战略实施的关键工具
- [[平衡计分卡]] 是战略管理会计的代表
- [[精益生产]] 中 JIT 与精益会计配套
- [[供应链管理]] 中作业成本法用于库存与物流成本管理
- 资本预算决策应用 [[现金流折现模型]]、[[资本成本]]
- [[管理者角色]] 中决策与控制角色依赖管理会计
- [[激励理论]] 与责任会计绩效考核结合
- [[企业价值评估]] 视角下,管理会计支持价值创造分析
