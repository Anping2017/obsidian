# 夏季露营

## 定义

夏季露营(Summer Camping)是在**气温常超 20℃、阳光强烈、可能伴随雷暴 / 蚊虫 / 高湿度**的环境下的露营活动。它是露营入门门槛最低的季节,但也是最易失误的场景——新手常按冬营思路准备装备(厚睡袋 / 棉帐),结果热到无法入睡。夏季的核心策略是**通风、防晒、防虫、防雷**,而非保暖。

## 核心要点

**核心挑战与对应**

| 挑战 | 后果 | 对应 |
|---|---|---|
| 高温闷热 | 失眠、中暑 | 透气帐、薄睡袋 / 沙滩单 |
| 紫外线 | 晒伤、雪盲(高山) | UPF 50+ 衣物、帽子、墨镜、防晒霜 |
| 雷暴 | 闪电击中、洪水 | 远离孤树 / 山顶,不在干河床扎营 |
| 蚊虫 | 叮咬、传染病 | 蚊帐、驱蚊液(DEET/Picaridin)、长袖 |
| 中暑 | 脱水、热射病 | 大量补水、电解质、避正午活动 |
| 高湿度 | 装备霉变 | 通风、晒干、防霉盒 |

**装备策略反向**

1. **帐篷**:三季帐或网纱帐,优先**透气**而非保暖;内帐大面积纱网
2. **睡袋**:5-15℃ 极限的化纤薄睡袋,或干脆用睡袋单(silk liner)
3. **地垫**:R 值 1-2 的轻量充气垫即可
4. **服装**:吸湿排汗 + UPF 50+ 长袖(防晒比防热更重要)
5. **炊具**:气炉首选(夏季气化好、清洁、轻);避免炭火(防火季限制)
6. **水**:体重 × 60-80 ml/小时活动量,夏季 4-6 L/天/人

**防晒系统**

- 物理防晒:宽檐帽(7cm+)、UPF 50+ 长袖、墨镜(UV400)
- 化学防晒:SPF 50+ PA++++ 防晒霜,2 小时补涂一次
- 时段管理:11:00-15:00 紫外线最强,尽量休息或在阴影
- 海拔效应:每升 1000 米紫外线增 10-12%
- 反射效应:水面、雪面、白沙滩反射率高,需双倍防晒

**防虫系统**

- **驱蚊液**:DEET(20-30%)有效 4-6 小时,Picaridin 同等且不腐塑;天然(柠檬桉)效果较弱但安全
- **物理屏障**:长袖长裤、紧口衣、蚊帐
- **营地选择**:远离静水(蚊虫滋生地)、避开溪流死水湾
- **特殊**:蜱虫(检查腋下、腹股沟、头皮)、马蜂(避开蜂巢和挥手)

**雷暴应对**

雷暴预警征兆:
- 远处闷雷
- 云底变低、由白转黑
- 体毛站立(电场积累,极危险信号)

避雷规则:
- 远离孤立树木、电塔、山顶
- 不在水边、沼泽、湿草地停留
- 不躲在洞穴口或岩石下凹处(感应雷)
- 蹲姿(脚并拢、抱头),减少接地面积
- 群体分散,每人间隔 10 米以上

**洪水风险(夏季雷暴 + 河流)**

- 不在干河床扎营(山洪可能数分钟到达)
- 看天看坡:上游雷暴 → 下游洪水
- 雨中观察溪流颜色,泛黄即山洪先兆

**水分与电解质**

- 持续出汗 → 仅补水会"水中毒"(低钠血症)
- 长时间运动需电解质泡腾片或运动饮料
- 颜色尿黄即缺水,深黄即重度缺水

## 与其他概念的关系

夏季露营涉及 [[户外安全与应急]] 的中暑、雷暴、虫咬应急,[[户外应急医疗]] 的脱水处置;装备策略与 [[帐篷类型]] 中三季帐选择对应。在 [[Glamping精致露营]] 场景下舒适度优先,可用大型 cabin 帐 + 风扇;[[徒步露营]] 场景需轻量化优先。

## 高频陷阱

- 把厚睡袋带去夏营 → 半夜热醒 + 重背
- 不防晒 → 高山徒步几小时即严重晒伤
- 营地选河边平地"风景好" → 山洪带走全装备
- 帐内不通风 → 凝结水 + 闷热失眠
- 驱蚊液涂帐布上 → 部分 DEET 腐蚀涤纶面料
