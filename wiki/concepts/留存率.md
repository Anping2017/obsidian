# 留存率 Retention Rate

## 定义

留存率(Retention Rate)是**衡量在某个时间段过后,有多少用户仍然在使用产品或服务**的核心指标:

```
留存率 = (期末留存用户数 / 期初用户数) × 100%
```

它的对立指标是**流失率(Churn Rate)** = 1 − 留存率。

留存率是 SaaS、移动 App、电商、订阅服务的健康度核心指标,深刻影响 [[LTV]]、[[CAC获客成本]] 与商业模式的可持续性。

## 核心要点

### 主要测量类型

| 类型 | 定义 |
|---|---|
| Cohort Retention(同期群留存) | 按用户加入时间分组,跟踪每群随时间的留存曲线 |
| 滚动留存(Rolling Retention) | N 天后仍至少使用过一次 |
| 经典留存(Classic Retention) | 第 N 天恰好使用 |
| 区间留存(Bracket Retention) | 第 N-7 至 N+7 天有使用 |
| 收入留存(NRR / GRR) | 按金额而非用户数计算 |

### 关键时间点

| 时间点 | 关注 |
|---|---|
| 次日(D1) | 新用户基本体验是否到位 |
| D7 | 周流失,是否养成使用习惯 |
| D30 | 月留存,产品价值是否被持续感知 |
| D60 / D90 | 中长期粘性 |
| Y1 | 年度留存,SaaS 续约关键 |

### 留存曲线形态

- **平坦曲线**:产品找到 PMF(Product-Market Fit)
- **下滑曲线**:用户持续流失,产品有问题
- **微笑曲线**:某些用户回归,如季节性产品

### NDR 与 GRR(SaaS)

- **GRR**(Gross Revenue Retention)= 留存收入 / 期初收入,不计 upsell
- **NDR / NRR**(Net Revenue Retention)= 含 upsell / cross-sell

NRR > 100% 是 SaaS 「负流失」状态,极佳;Snowflake、Datadog 等企业软件 NRR 常达 130%+。

### 提升留存的策略

1. **激活(Activation)**:让新用户尽快达到「Aha 时刻」
2. **建立习惯**:推送、提醒、连续奖励、习惯触发
3. **提供持续价值**:更新、内容、社区、新功能
4. **减少摩擦**:更快、更稳、更易用
5. **个性化**:推荐、千人千面
6. **客户成功**:主动检查、培训、支持
7. **社交锁定**:让用户带着朋友/团队进来
8. **复购召回**:邮件、Push、广告再营销

### 行业基准(粗略)

- 移动游戏 D1:25-50%,D30:5-10%
- 移动 App D30:6-15%(顶级 25%+)
- SaaS 年留存:75-90%(企业软件)、60-80%(SMB)
- 电商月复购:20-40%(高频品类)
- 内容订阅(Netflix、Spotify):月流失 < 5%

### 与 LTV 的关系

留存率直接驱动 LTV:

```
LTV ≈ ARPU × (1 / 流失率) × 毛利率
```

留存率从 90% 提升到 95%(流失从 10% 降到 5%)时,LTV **翻倍**——因为分母减半。这就是「留存的杠杆效应」。

### 「磁石指标」(North Star Metric)

许多产品把留存相关指标作为北极星:

- WhatsApp:消息发送数(留存的代理)
- Airbnb:夜间订房数
- Spotify:月活听歌时长
- Slack:发出 2000+ 条消息的活跃团队数

## 和其他概念的关系

留存率是 [[CAC获客成本]] 的对偶——CAC 决定获取成本,留存决定回收周期。两者共同决定 [[LTV]] 与单元经济学。

[[销售漏斗]] 的后端就是留存与复购;[[飞轮]] 模型把留存放到中心位置。

[[CRM客户关系管理]] 的核心目标之一就是提升留存;[[私域流量运营]] 在中国语境下是留存运营的本土化。

[[精准营销]]、[[再营销]]、[[转化API]] 都涉及如何识别有流失风险的用户并干预;[[AB测试|AB测试]] 是验证干预措施的标准方法。

[[网络效应]] 与 [[病毒系数K]] 是留存的强化剂——朋友/同事都在用的产品天然难以离开;[[赫兹伯格双因素理论]]、[[内在驱动力]] 则解释了用户长期粘性的心理来源。
