# 销售KPI体系

## 定义

销售 KPI 体系(Sales Key Performance Indicators)是企业用于衡量销售团队和个人销售员绩效的量化指标体系。它由"过程指标"(可日常控制的行为)和"结果指标"(财务结果)分层构成。优秀的 KPI 体系既能驱动短期业绩,又能维护客户体验和团队健康——单纯销售额导向往往导致"涸泽而渔"(强卖、压库存、不连带、流失客户)。手机零售的 KPI 设计有其特殊性,新机 + 二手 + 维修 + 配件四象限并行。

## 核心要点

**双层 KPI 结构**:

### 结果指标(Outcome / Lagging)— 慢但精

- **销售额**:GMV,最直观但有滞后。
- **毛利额**:扣除货物成本,反映真实贡献。
- **净利润**:扣除房租 / 工资 / 成本后利润(店级,不到个人)。
- **市场份额**:同区域竞争对比。

### 过程指标(Process / Leading)— 快但粗

- **客流量**:每日进店数。
- **接待数**:店员主动接待数。
- **试机数**:让客户体验产品次数。
- **报价数**:出具报价单 / 协商数。
- **成交数**:实际成交客户数。
- **连带件数 / 金额**:见 [[连带销售]]。
- **转化率**:[[到店转化率]]。
- **客单价**:平均订单金额。

**结果 = 过程 × 杠杆**:

- 销售额 = 客流量 × 转化率 × 客单价。
- 这是销售员每日可干预的 3 个杠杆。

**手机店专属 KPI 矩阵**:

| 维度 | 个人 KPI | 店级 KPI |
|---|---|---|
| **新机销售** | 销售台数、毛利额 | 单店月销额、市场份额 |
| **二手回收** | 收购台数、转售毛利 | 库存周转、回收转化率 |
| **维修业务** | 工单数、客户满意度 | 月维修营收、回修率 |
| **配件销售** | 连带件数、毛利 | Attach Rate、配件占比 |
| **客户运营** | 加微数、复购率 | 会员渗透率、NPS |
| **个人成长** | 培训完成、考核通过 | 团队稳定率、人均产值 |

**关键比率**:

- **件单价 vs 客单价**:平均件单价高说明销售更倾向高单价产品;客单价高包含连带,反映综合卖力。
- **新老客户成交比**:新客 70% / 老客 30% → 拉新强,留存弱;反之亦然。
- **退货 / 投诉率**:健康 ≤ 1%。
- **会员渗透率**:健康 ≥ 60%(每个客户加入会员/私域)。

**分级激励设计**:

### 第 1 级 — 底薪(基础保障)

- 当地最低工资水平 + 30%。
- 保障团队稳定,新人有学习期。

### 第 2 级 — 绩效奖金(过程导向)

- 完成日 / 周 KPI(如接待数 / 试机数 / 加微数)即得固定奖金。
- 鼓励行为,不卷结果。

### 第 3 级 — 提成(结果导向)

- 阶梯式提成:
  - 完成 80% 目标 → 1% 销售提成。
  - 完成 100% → 2%。
  - 完成 120% → 3% + 额外奖金。
- 阶梯让"差一点没冲到"反而成为强动力。
- 毛利提成 vs 销售提成:**毛利提成更优**——避免低毛利冲量。

### 第 4 级 — 团队奖金(协同导向)

- 全店达标团队奖金 → 防止个人内卷不互助。
- 每月最佳团队 / 帮带新人最佳奖。

### 第 5 级 — 长期激励

- 季度 / 年度积分累计 → 年终大奖(国际旅游、奖金、晋升)。
- 优秀员工股权 / 期权(连锁店主向员工)→ 把员工变事业合伙人。

**反激励陷阱**:

- **唯销售额**:销售员只卖贵机器,不连带 / 不维护客户。
- **唯件数**:销售员塞低端机凑数。
- **唯个人**:不互助,新人无人带。
- **不奖励服务质量**:差评满天飞,长期客户流失。
- **过激励个别明星**:其他人放弃,团队两极分化。
- **频繁改 KPI**:员工无法适应,失去信任。

**月度复盘流程**:

1. **数据公示**:全员 KPI 公开(透明 = 公平感)。
2. **对标 Top**:Top 10% 怎么做的?可复制经验。
3. **改进项**:个人 / 团队下月聚焦的 1-2 个改进项。
4. **培训计划**:针对薄弱环节的针对性培训。
5. **结果应用**:晋升 / 调岗 / 辞退 / 加薪基于数据。

**OKR vs KPI 在销售场景**:

- **KPI**:适合稳定业务,过程结果都明确。
- **OKR**:适合战略转型,如新业务突破(从纯卖机切入回收 / 维修 / 私域)。
- 实操中混用:KPI 管日常,OKR 推战略目标。

## 和其他概念的关系

销售 KPI 体系与 [[销售技巧]]、[[价格谈判技巧]]、[[连带销售]]、[[到店转化率]] 等具体战术互相支撑——KPI 是激励战术执行的"指挥棒"。它是 [[零售门店运营]] 与 [[团队管理]] 的交点。

KPI 设计原理与 [[北极星指标]] 同源——核心是单一 / 可衡量 / 可影响 / 反映长期价值。在 [[销售漏斗]] 与 [[转化漏斗]] 中,KPI 把每一步漏斗指标个体化、责任化。

[[CRM]] 与 [[POS 系统]] 是 KPI 数据的采集底座。在 [[精益管理]] 中,KPI 体系也是 PDCA(计划-执行-检查-行动)循环的"检查"环节。错误的 KPI 设计是 [[Goodhart 定律]]("当一个指标变成目标,它就不再是好指标")的最常见来源。
