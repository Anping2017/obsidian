# 操作性条件反射

## 定义

**操作性条件反射**(Operant Conditioning,Instrumental Conditioning)是 [[斯金纳]] 系统化的学习机制:**行为受其后果(强化或惩罚)影响,被强化的行为增加,被惩罚的行为减少**。它与 [[经典条件反射]] 一起构成行为学习的两大基石,是 [[行为主义]]、 [[激励理论]]、现代 [[强化学习]] 的基础。

## 核心要点

### 与经典条件反射的关键差异

| 维度 | 经典条件反射 | 操作性条件反射 |
|---|---|---|
| 学习内容 | 刺激—刺激(S-S) | 行为—结果(R-S) |
| 反应类型 | 不随意(自主神经) | 随意(肌肉) |
| 角色 | 被动反应 | 主动操作 |
| 例子 | 流唾液、心跳加速 | 按按钮、举手 |
| 创始人 | [[巴甫洛夫]] | [[斯金纳]](由桑代克奠基) |

### 强化与惩罚四象限

| | 给予刺激 | 撤除刺激 |
|---|---|---|
| **增加行为** | **正强化** Positive Reinforcement(给奖励) | **负强化** Negative Reinforcement(撤除厌恶刺激) |
| **减少行为** | **正惩罚** Positive Punishment(给厌恶刺激) | **负惩罚** Negative Punishment(撤除奖励) |

举例:
- 正强化:孩子做作业 → 给糖
- 负强化:孩子安静 → 关掉刺耳的音乐
- 正惩罚:孩子打人 → 罚站
- 正(应为负)惩罚:孩子不分享玩具 → 没收玩具

### 强化时间表(Schedules of Reinforcement)

| 时间表 | 规则 | 反应模式 | 抗消退 |
|---|---|---|---|
| 连续强化(CRF) | 每次行为都强化 | 习得快 | 弱 |
| 固定比率(FR) | 每 N 次强化 | 高速、稍歇 | 中 |
| 可变比率(VR) | 平均 N 次但随机 | 最高、稳定 | **最强** |
| 固定间隔(FI) | 时间到首次行为强化 | "扇形"模式 | 弱 |
| 可变间隔(VI) | 时间随机首次行为强化 | 中等稳定 | 中 |

**VR 为何最有效**:每次都可能是奖励,无法预测 → 持续尝试。这就是**老虎机、抽奖、游戏氪金、社交媒体推送**的科学原理。

详见 [[HOOK模型]]、 [[消费者行为]]。

### 行为塑造(Shaping)

- 通过**逐步逼近**(successive approximation)塑造复杂行为
- 不等到完整目标行为出现才强化
- 先强化任何接近目标的简单行为,再逐步抬高标准
- 鸽子可被训练打乒乓球
- 人类训练复杂技能(钢琴、舞蹈、语言)同样适用

### 链式塑造与连锁反应

- 把复杂行为分解成步骤
- 每步用前一步作为强化
- 应用于职业训练、自闭症 ABA、动物表演

### 消退、辨别、泛化

- **消退**:不再强化 → 行为减少
- **泛化**:相似情境也能引发行为
- **辨别**:学会只在特定信号(SD,discriminative stimulus)下做反应
- 老鼠学会:绿灯亮按按钮得食,红灯按则无 → 红灯不按

## 重要研究范式

### 桑代克效果律(1898)

- 早于斯金纳
- 猫在迷箱中,**带来满意结果的反应被强化**,带来不快的被弱化
- "效果律"是操作性条件反射的雏形

### 斯金纳箱(Skinner Box)

- 标准化研究装置
- 鸽子或老鼠按键得食
- 详见 [[斯金纳]]

### 自动塑造(Auto-shaping)

- 鸽子接近食盘前会有"准备性"啄击,即使啄击不导致食物
- 揭示**生物预备性**(biological preparedness)
- 学习不是中性的,有种属适应性

## 应用领域

### 教育

- 即时反馈、积极强化、塑造程序
- 程序教学、自适应学习
- 详见 [[斯金纳]] 教学机
- 与 [[班杜拉]] 自我效能模型整合

### 临床

- **代币法**(token economy):强化代币换奖励,用于精神病院、自闭症
- **应用行为分析**(ABA):自闭症儿童干预主流方法
- **行为塑造**用于成瘾戒断
- 与 [[认知行为疗法]] 整合

### 组织管理

- KPI、奖金、晋升:**正强化**
- 严密考核 + 不达标处罚:**正惩罚**
- 团队绩效奖励、销售提成:**强化时间表设计**
- 详见 [[激励理论]]、 [[组织行为学]]

### 数字产品设计

- 游戏化、积分、成就、排行榜
- 老虎机式 UI(可变比率强化)
- **道德争议**:成瘾、注意力剥夺
- 详见 [[HOOK模型]]、 [[消费者行为]]

### [[人工智能]] 与 [[强化学习]]

- **强化学习**直接源自操作性条件反射
- 智能体在环境中行动 → 获得奖励 → 调整策略
- AlphaGo、ChatGPT [[RLHF]] 都是这个框架
- 详见 [[强化学习]]、 [[RLHF]]

### 个人成长

- 习惯设计:把目标行为与即时奖励配对
- "**两分钟法则**":先做简单版,再扩大(行为塑造)
- 戒除坏习惯:负惩罚(撤除积极结果)

## 局限与批评

- **极端环境主义**:忽视生物预备性、认知中介
- **道德争议**:操控人 vs 帮助人
- **生态效度**:实验室结果在真实社会中要复杂
- **乔姆斯基对斯金纳《言语行为》的批判**:语言不能仅靠强化习得

## 和其他概念的关系

- 与 [[经典条件反射]] 是两大学习机制
- 创始人 [[斯金纳]],奠基者桑代克
- 是 [[行为主义]] 核心机制
- 与 [[激励理论]]、 [[组织行为学]]、 [[领导力]] 直接相关
- 与 [[强化学习]]、 [[RLHF]]、 [[人工智能]] 同源
- 与 [[认知行为疗法]]、 [[依恋理论]]、 [[防御机制]] 在临床应用上相关
- 与 [[班杜拉]] 社会学习扩展(观察 vs 直接强化)
- 与 [[HOOK模型]]、 [[消费者行为]]、 [[转化漏斗]]、 [[病毒系数K]] 在产品设计上相关
- 与 [[认知偏差]]、 [[卡尼曼]] 决策心理学交叠
- 与 [[决定论]]/[[自由意志]] 议题之"行为是塑造的产物"
- 与 [[内在驱动力]] 形成"外在强化 vs 内在动机"对话
- 与 [[正念]] 在"反应—结果"觉察上有异曲同工
