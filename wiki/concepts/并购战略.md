# 并购战略

## 定义

**并购(M&A, Mergers and Acquisitions)** 是企业通过购买股权、资产或合并方式获取目标公司控制权或资源,实现外部增长的战略行动。

- **合并(Merger)**:两家或多家公司联合成新实体
- **收购(Acquisition)**:一家收购另一家,目标公司可能存续或被吸收

并购研究反复显示:**约 60-70% 的并购未能实现宣称的协同效应**,主要原因是溢价过高、整合失败、文化冲突。

## 核心要点

### 并购的战略动机

| 动机 | 内涵 | 案例 |
|---|---|---|
| **规模协同** | 成本协同、规模经济 | 钢铁、银行业整合 |
| **范围协同** | 产品/市场互补 | 迪士尼收购皮克斯、漫威 |
| **能力获取** | 获得技术、人才、专利 | Google 收购 Android、DeepMind |
| **市场进入** | 跨地域/跨行业 | 海外并购、跨界并购 |
| **垂直控制** | 锁定供应或渠道 | 见 [[垂直整合与水平整合]] |
| **财务协同** | 税盾、内部资本市场 | 高现金低负债 + 高负债低现金 |
| **管理改善** | 替换低效管理层 | 私募基金收购 |

### 并购流程(五阶段)

```
战略制定 → 目标筛选 → 尽职调查 → 估值与谈判 → 整合执行
```

| 阶段 | 关键活动 |
|---|---|
| 战略制定 | 确认并购在战略中的角色,设定准则 |
| 目标筛选 | 行业扫描、长名单/短名单 |
| 尽职调查(DD) | 财务、法律、运营、商业、技术、人力六维度 |
| 估值与谈判 | DCF / 可比公司 / 可比交易,溢价确定 |
| 整合(PMI) | 100 天计划、组织融合、系统整合 |

### 并购支付方式与风险信号

| 方式 | 含义 | 信号 |
|---|---|---|
| 现金 | 现金对价 | 收购方对自身股价信心强 |
| 换股 | 股票换股票 | 收购方认为自家股票被高估 |
| 混合 | 现金+股票 | 平衡风险 |

### 协同效应的来源(与高估陷阱)

- **收入协同**(交叉销售、定价权):最难实现,常被高估
- **成本协同**(裁员、整合后台、采购):最易量化、相对可达
- **财务协同**(税务、融资):稳定但有限
- 高估陷阱:winner's curse(赢家诅咒)、CEO 自负、投行激励错位

### 整合管理(PMI)成功要素

- **速度**:100 天内决定关键人事和组织
- **沟通**:双向、坦诚、频繁
- **文化**:文化融合或共生,而非压制
- **保留人才**:核心人员锁定计划
- **客户保护**:防止业务流失窗口期

## 和其他概念的关系

- 是实现 [[垂直整合与水平整合]] 的最常见外部增长手段
- 决策深度依赖 [[企业价值评估]]、[[现金流折现模型]]、[[相对估值法]]
- 整合阶段需要 [[变革管理]]、[[组织文化]] 融合、[[变革型领导]]
- 体现 [[战略管理]] 中公司层战略,与战略联盟、内部增长互为替代
- 受 [[公司治理]] 监督,代理问题可能导致 CEO 帝国主义并购
- 受 [[反垄断]] 监管约束(虽未在本 vault 单独成篇,但是关键背景)
- 与 [[投资银行]] 业务高度相关——并购顾问、融资安排
- 跨境并购涉及 [[国际化战略]] 与跨文化管理
