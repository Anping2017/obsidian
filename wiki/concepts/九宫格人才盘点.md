# 九宫格人才盘点

## 定义

**九宫格(9-Box Grid)** 是把员工按"**绩效**"与"**潜力**"两个维度各分三档,产生 **9 个格子** 的人才盘点工具。它最早由 McKinsey 与 GE 共同开发,Jack Welch 时代的 GE 用其作为人才识别核心方法,后被全球大企业广泛采用。

九宫格的核心价值:**把抽象的"人才评估" 变成结构化的、可对话的、跨部门可比的工具**,让 HR 决策有依据。

## 核心要点

### 九宫格的二维矩阵

|   | **低绩效** | **中绩效** | **高绩效** |
|---|---|---|---|
| **高潜力** | 1 待发现 | 2 成长之星 | **3 高潜明星** |
| **中潜力** | 4 不一致表现 | 5 中坚骨干 | 6 有效贡献者 |
| **低潜力** | 7 风险信号 | 8 稳定贡献 | 9 专家型 |

> **注**:不同企业格子描述略有差异,核心逻辑相同。

### 九大类型与差异化对策

| 类型 | 描述 | 对策 |
|---|---|---|
| **3 高潜明星(右上)** | 高绩效高潜力,未来领导者 | 重点培养、轮岗、加速晋升 |
| **2 成长之星** | 高潜中绩效,需机会 | 拉伸任务、教练、关注 |
| **1 待发现** | 高潜低绩效(可能错位) | 深入分析、可能调岗 |
| **6 有效贡献者** | 中潜高绩效,业务骨干 | 留住、发展专业深度 |
| **5 中坚骨干** | 中潜中绩效,稳定主力 | 维持、提供成长机会 |
| **4 不一致** | 中潜低绩效 | 辅导、目标重设 |
| **9 专家型** | 低潜高绩效,业务专家 | 专家通道、技术专家奖励 |
| **8 稳定贡献** | 低潜中绩效,履职合格 | 维持现状、技能更新 |
| **7 风险信号** | 低潜低绩效 | 改进计划或退出 |

### 评估维度的内涵

#### 绩效(横轴)

通常基于过去 12-24 个月的:
- 业绩目标完成度
- 关键结果交付
- 同事/客户反馈
- 价值观对齐

#### 潜力(纵轴)

更复杂,常用维度:

| 维度(Korn Ferry "Learning Agility") | 内涵 |
|---|---|
| **学习敏锐度** | 从经验中快速学习的能力 |
| **驱动力** | 追求卓越的内在动力 |
| **思考敏锐度** | 复杂情境下的认知能力 |
| **人际敏锐度** | 关系建立与影响力 |
| **变化敏锐度** | 应对模糊与不确定 |
| **结果敏锐度** | 在挑战下交付的能力 |

潜力比绩效更难评估,常需多人讨论。

### 实施流程

```
1. 准备 → 2. 自评 → 3. 直接上级评 → 4. 校准会议 → 5. 行动计划 → 6. 跟踪
```

**校准会议(Calibration)是关键**:

- 跨部门 HR + 经理共同讨论
- 防止"all my people are stars"偏差
- 用具体行为证据支撑评级
- 跨部门可比

### 九宫格的限制与批评

| 局限 | 表现 |
|---|---|
| **潜力难评估** | 比绩效更主观,易陷光环效应 |
| **静态视角** | 一次评估 ≠ 长期标签 |
| **标签效应** | 被评为低潜后难翻身 |
| **保密 vs 透明** | 是否告诉员工?各有利弊 |
| **僵化** | 强制分布(强制 10% 必为低)伤士气 |
| **文化适配** | 在某些文化中难接受赤裸标签 |

GE 后来放弃了"末位淘汰"+ 强制分布的做法,改为更灵活的对话式管理。

### 当代演化

- **多场景应用**:不仅干部盘点,扩展到关键岗位继任
- **数据化**:HRIS 系统支撑,360 反馈 + KPI 数据
- **持续性**:从年度盘点变持续追踪
- **对话化**:校准会议比评分更重要
- **柔性化**:不强制分布,关注真实分布

### 与其他人才管理工具的关系

| 工具 | 焦点 |
|---|---|
| **九宫格** | 静态分类 |
| **绩效评估** | 单一维度 |
| **360 度反馈** | 全方位行为反馈 |
| **能力模型** | 标准化期望 |
| **个人发展计划(IDP)** | 个性化路径 |
| **继任规划** | 关键岗位接班 |

健康人才管理同时使用多种工具。
