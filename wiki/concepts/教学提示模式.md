# 教学提示模式

## 定义

教学提示模式是为充分利用[[大语言模型]]的教学能力,设计 LLM 扮演辅导老师角色的一类提示工程模式。其核心是让模型不直接给答案,而是通过提问、阶梯讲解、错误诊断引导学生自主理解,模仿苏格拉底教学法。

## 核心模式

### 苏格拉底提问

```
你是物理学辅导老师。学生提问后,先问 2-3 个引导性问题让他自己思考,
不要直接给答案。如果学生回答错误,通过反例引导他发现自己的错误。
```

### 阶梯解释

```
当解释复杂概念时,按以下阶梯:
1. 用日常类比(目标:5 岁能听懂)
2. 给出简化模型(目标:中学生)
3. 完整原理(目标:大学生)
4. 严格数学(目标:研究生)
学生选择停在哪一阶。
```

### 错误诊断

```
学生提交作业后:
1. 找出第一个错误的位置
2. 推测他为什么会犯这个错(常见误解)
3. 给出针对性反例
4. 提示他重做这一步,而非给出正确答案
```

### 间隔重复

```
今天讲完后,给出 5 道题:3 道立即测试、2 道明天/一周后复习。
按遗忘曲线安排。
```

## 关键技术

- **角色锚定**:明确"耐心、不直接给答案"
- **学习目标声明**:概念性 vs 程序性 vs 元认知
- **学生模型**:让 AI 维护"已掌握/部分掌握/未掌握"状态
- **反思引导**:提问"你是怎么想到这个的?"

## 经典反模式

- 学生提问 → AI 直接给完整答案(短期满意,长期无效)
- 不诊断错误,直接告知"对/错"
- 难度均匀(应自适应)
- 缺乏间隔复习

## 与其他概念的关系

- 是 [[提示词反模式]] 的对立——专门设计对抗"直接答题"反模式
- 与 [[反思提示]] 结合实现自我评估
- 与 [[多智能体提示]] 中的"老师/学生/裁判"组合
- 与 [[费曼学习法]] 同源,要求学生反向解释
- 与 [[心流]]、[[元认知]] 等[[心理学]] 概念衔接
