# 错误合取

## 定义

**错误合取**(Failure to See False Conjunctions / Conjunction Fallacy)指人在判断概率时,**误以为更具体的描述比更宽泛的描述更可能为真**。但根据概率论,**A 且 B 的概率永远不可能高于 A**。由 [[卡尼曼]] 与特沃斯基在 1983 年通过著名的 **Linda 测试** 演示,是 [[代表性启发]] 三大子项之一。

## 核心机制

### Linda 测试(经典实验)

> Linda 31 岁,单身,坦率,非常聪明。她大学主修哲学,曾积极参与反核游行,关注社会正义与歧视议题。
>
> 她现在更可能是哪一个?
> A. 银行职员
> B. 银行职员且活跃于女权运动

约 85% 的本科生选 B。

**逻辑上不可能**:B 是 A 的真子集,P(A 且 B) ≤ P(A)。但生动具体的描述让 B "看起来更像 Linda",违反基本概率法则。

### 为什么大脑这么蠢

| 原因 | 解释 |
|---|---|
| **代表性主导** | 用"像不像"代替"概率多大" |
| **细节增可信度** | 越多细节越像真实故事 |
| **叙事吸引力** | "银行职员+女权"是个完整人物,"银行职员"太抽象 |
| **逻辑反直觉** | 加约束应该减少概率,但直觉觉得增加了说服力 |

### 一般化形式

任何形如 "X 且 Y 比 X 更可能" 的判断都触发了错误合取。**每加一个条件,概率都该下降**(或最多不变)。

## 应用场景

- **预测未来**:"中美脱钩 + 台海冲突 + 美元崩溃"的"完整剧情"被觉得比单一事件概率高
- **股市分析师**:"公司 A 增长 + 行业景气 + 政策利好 + 宏观转暖"的剧本看似确凿,概率其实更低
- **法庭叙述**:细节越具体的"作案过程"越令陪审团相信,而具体性反而该降低概率
- **创业故事**:"团队这样 + 时机那样 + 产品如此 + 国际形势"的故事让投资人感觉确定性更高
- **保险/风险**:精确描述的灾害剧本被高估
- **小说与新闻**:"具体到时间地点人物"的报道在直觉上更可信,但更具体不等于更可能

## 对治方法

1. **数条件法**:每加一个条件就把概率乘一个 ≤1 的数,而非加分
2. **拆开估计**:分别估计 P(A) 和 P(B|A),再相乘,而不是直接评估 P(A 且 B)
3. **替换练习**:把"且"换成"或"会怎样?注意区别
4. **画文氏图**:可视化集合关系,直观感受子集
5. **质疑生动剧本**:剧本越精彩越要打折
6. **训练贝叶斯直觉**:做习题培养"加约束减概率"的直觉

## 与其他概念的关系

- 是 [[代表性启发]] 的子项,与 [[忽略基础概率]]、[[刻板印象倾向]] 并列
- [[叙事本能]] 让具体剧本看似更可信,直接喂养错误合取
- 与 [[可得性启发]] 协作:鲜活描述更易回忆
- [[过度概括小样本]] 是相关性错误,基础概率被低估
- [[确认偏差]]:挑剧本时偏爱与既有信念相符的具体版本
- [[概率论与统计学]] 与 [[第一性原理]] 是直接解药
- 与 [[批判性思维]] 中的"奥卡姆剃刀"相通——简单解释通常更可能
- 在 [[预测]] 与 [[风险识别与度量]] 中尤其危险
