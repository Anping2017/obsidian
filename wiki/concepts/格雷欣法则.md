# 格雷欣法则

## 定义

**格雷欣法则**(Gresham's Law)的经典表述是:**"劣币驱逐良币"**(Bad money drives out good)。但这一原理远不止于货币——它适用于任何**两种品质不同的"等价"事物并存的场景**:被认为高品质的那个被收藏、低品质的那个被流通,**结果整个市场逐渐被低品质统治**。

## 核心要点

### 货币起源

- 16 世纪英国金融家 Sir Thomas Gresham 观察到:
- 当政府发行成色不足的"劣币"与足值的"良币"以同等面值流通
- 民众会**藏起良币、花掉劣币**
- 结果:良币退出流通,市场上只剩劣币
- 历代王朝"减重铸币"贬值故事都是格雷欣法则的活案例

### 推广形式:任何"质量混淆"的市场

| 领域 | 格雷欣式现象 |
|---|---|
| **借贷** | 不严谨的借贷把严谨的挤出市场 |
| **道德** | 没原则的人在没惩罚环境下逐渐主导 |
| **媒体** | 哗众取宠驱逐严肃报道 |
| **学术** | 灌水论文淹没真创新 |
| **二手车** | 柠檬市场理论 —— 低质量车驱逐高质量(阿克洛夫,获诺奖) |
| **职场** | 摸鱼者排挤实干者(若激励错位) |

### 人性的"暗面"

格雷欣法则反映了人性的一个深刻规律:

> 我们天然倾向于**短期最优**——以最少代价获取最大价值。
>
> 如果**没有惩罚**,我们就会保留好的、给出去坏的。

这不是道德问题,而是**激励机制问题**:在没有约束的环境里,坏的会自然胜出。

### 没有干预,坏会驱逐好

- 没有诚信代价 → 不诚信驱逐诚信
- 没有质量监管 → 假货驱逐真货
- 没有抄袭追责 → 抄袭驱逐原创
- 没有社交后果 → 投机者驱逐合作者

**克服格雷欣法则需要持续努力**:制度、监管、文化、社区都在做这件事。

### 长期反转

> "短期内,坏经常驱逐好;但长期看,真正的价值会胜出。"

格雷欣法则在短期内成立,但长期看:

- 用劣币的国家 → 信任崩塌 → 转用外币或贵金属
- 充满假货的市场 → 消费者撤离 → 整个行业萎缩
- 道德败坏的组织 → 内部松散 → 被替代
- **真正的好不会永远沉默**,它会以更高代价艰难胜出

### 反向格雷欣

在"质量可识别"的市场,反过来:好驱逐坏。

- 有公开评分的餐厅
- 有透明评论的产品
- 有可追溯的食材
- **信息透明 + 信誉机制 = 反转格雷欣法则**

## 应用场景

- **品牌管理**:在质量难以辨识的市场,用持续的高品质投入对抗格雷欣压力——直到客户愿意为可信付溢价。
- **组织治理**:如果没有奖优罚劣的机制,坏行为会蔓延;善治始于设计正确的激励与惩罚。
- **个人决策**:避免进入"没有惩罚机制"的环境,在那里你的诚信无人识别,只会被劣胜出。

## 局限与陷阱

- **预设"等价"前提**:法则成立需要两种东西被强制视为等价(如政府强制等值流通)
- **不适用于所有市场**:可观察质量的市场常出现反向效应
- **过度悲观**:并非所有领域都会被劣币占据
- **混淆短期与长期**:短期可能劣胜,长期未必
- **道德等价的危险**:不能因此为"劣的合理性"辩护
