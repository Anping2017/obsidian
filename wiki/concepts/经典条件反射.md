# 经典条件反射

## 定义

**经典条件反射**(Classical Conditioning,Pavlovian Conditioning)是 [[巴甫洛夫]] 在 1900 年前后通过狗的唾液实验发现的学习机制:**反复将中性刺激与能引起反应的刺激配对,中性刺激最终能单独引起类似反应**。它是现代 [[行为主义]] 与学习心理学的奠基性发现。

## 核心要点

### 基本范式

- **无条件刺激(US, Unconditioned Stimulus)**:无需学习就能引起反应,如食物
- **无条件反应(UR, Unconditioned Response)**:US 自然引起的反应,如唾液
- **中性刺激(NS, Neutral Stimulus)**:本来与反应无关,如铃声
- **条件刺激(CS, Conditioned Stimulus)**:NS 经过配对后获得引起反应的能力
- **条件反应(CR, Conditioned Response)**:CS 引起的反应,如唾液(对铃声)

经典实验流程:
```
配对前:铃声(NS)→ 无反应      食物(US)→ 唾液(UR)
配对中:铃声 + 食物 → 唾液
配对后:铃声(CS)→ 唾液(CR)
```

### 关键现象

| 现象 | 含义 |
|---|---|
| **习得**(Acquisition) | CS-US 配对后形成条件反射 |
| **消退**(Extinction) | 反复 CS 不伴 US,CR 减弱 |
| **自发恢复**(Spontaneous Recovery) | 消退后过段时间,CR 部分重现 |
| **泛化**(Generalization) | 类似 CS 引发类似 CR(高音铃声→低音也部分有效) |
| **辨别**(Discrimination) | 学会区分相似刺激,只对特定 CS 反应 |
| **高级条件作用**(Higher-Order) | 用 CS 当 US,建立新 CR(灯+铃声→唾液) |

### 影响习得效率的因素

- **时间安排**:CS 略先于 US 最有效(延迟条件作用)
- **强度**:US 越强,习得越快
- **次数**:配对次数与习得程度正相关
- **预测性**:CS 对 US 的预测越可靠,习得越强(Rescorla 修正)

### Rescorla-Wagner 模型(1972)

- 不只是机械配对,而是**预测性学习**
- 当 CS 对 US 的出现有预测信息时,联结才形成
- 已经被另一个 CS 完全预测的 US,新 CS 学不到("阻碍效应")
- 这是连接经典条件反射与现代 [[强化学习]] 的关键
- 影响 [[人工智能]] 中 TD 学习算法

## 经典实验

### 巴甫洛夫的狗

- 详见 [[巴甫洛夫]]
- 食物(US)+ 铃声(NS)→ 多次配对后铃声单独引唾液

### 小阿尔伯特实验(华生,1920)

- 一岁婴儿阿尔伯特原本不怕白鼠
- 白鼠出现 + 巨响(US)→ 哭泣(UR)
- 配对后:白鼠(CS)→ 哭泣(CR)
- **泛化**:阿尔伯特也害怕白兔、白胡子
- 说明**情感、恐惧也可被条件化**
- 实验伦理至今受到批评

### 味觉厌恶学习(Garcia 效应)

- 老鼠在吃过新食物后被注射使其恶心的药
- 此后回避该食物
- 即使**配对间隔几小时**也能习得 —— 突破了经典条件反射"必须立刻配对"的预设
- 这是**进化适应**的特例:与生存密切相关的反应有特殊学习机制

## 与操作性条件反射的区别

| 维度 | 经典条件反射 | 操作性条件反射 |
|---|---|---|
| 学习对象 | 刺激—刺激联结 | 行为—结果联结 |
| 反应类型 | 不随意的 | 随意的 |
| 关键人物 | [[巴甫洛夫]] | [[斯金纳]] |
| 例子 | 听到牙医钻头声紧张 | 按按钮得糖 |
| 强化方式 | US 自动引起反应 | 行为后果增减行为 |

## 现代应用

### 心理治疗

- **系统脱敏**(Wolpe):用放松反应**对抗**条件化的恐惧
- **暴露疗法**:让来访者反复接触恐惧刺激而无可怕后果,达到消退
- **厌恶疗法**:把不良行为(如成瘾)与厌恶刺激配对
- 详见 [[认知行为疗法]]

### 营销与广告

- 把产品(NS)与正面情境(US,如美女、欢笑、名人)反复配对
- 消费者看到产品产生正面情感(CR)
- 这是品牌情感联结的科学基础
- 详见 [[营销心理学]]、 [[品牌定位]]、 [[消费者行为]]

### 健康行为

- 化疗预期恶心(预期性条件反应)
- 食物厌恶(食物中毒后的回避)
- 安慰剂效应有部分条件反射机制

### [[人工智能]]

- 强化学习 TD 算法源自 Rescorla-Wagner 修正
- 大脑多巴胺系统被发现实现 TD 学习
- 详见 [[强化学习]]

### 日常生活

- 闹钟铃声与起床的痛苦关联
- 特定香味与回忆的连接(普鲁斯特现象)
- 餐厅环境与用餐情绪
- 这就是为何"巴甫洛夫的狗"成为日常隐喻

## 和其他概念的关系

- 是 [[行为主义]] 创始基石之一
- 与 [[操作性条件反射]] 是两大学习机制
- 创始人 [[巴甫洛夫]],推广者华生、 [[斯金纳]]
- 与 [[认知行为疗法]]、 [[依恋理论]] 在临床应用上相关
- 与 [[强化学习]]、 [[人工智能]] TD 学习同源
- 与 [[营销心理学]]、 [[品牌定位]]、 [[消费者行为]]、 [[HOOK模型]] 中"刺激联想"机制
- 与 [[认知偏差]]、 [[启发式]] 在直觉反应形成上相关
- 与 [[激励理论]]、 [[组织行为学]] 中习惯化机制相关
- 与 [[防御机制]] 之"恐惧条件反射"在临床上相通
- 与 [[积极心理学]] 中正向条件反射(快乐与积极行为联结)
