# 抓取渲染索引

## 定义

抓取-渲染-索引(Crawl-Render-Index)是搜索引擎将网页变为搜索结果的三阶段流水线:**抓取**让爬虫发现并下载 HTML;**渲染**对包含 JavaScript 的页面执行脚本得到最终 DOM;**索引**把渲染后的内容解析、提取、存入倒排索引并参与排名。每个阶段都有独立的失败模式,技术 SEO 工程师必须理解三阶段的衔接才能精准诊断"页面为什么不排名"。本概念是 [[Google搜索工作原理]] 的工程视角延伸。

## 三阶段详解

### 阶段 1:抓取(Crawling)

**目标**:发现 URL 并下载源 HTML

**输入信号**:
- [[XML Sitemap]] 提交的 URL
- 已抓取页面中的内链与外链
- Search Console URL Inspection 主动提交
- 历史抓取记录

**控制因素**:
- [[Robots.txt]]:Disallow 规则
- HTTP 状态码:200 OK、301、404、503
- robots meta tag(noindex 此阶段不影响,在索引阶段)
- 服务器响应速度
- [[抓取预算]](Crawl Budget):大型站点的抓取频次配额

**失败模式**:
- robots.txt 误屏蔽
- 服务器频繁 5xx 错误
- 响应时间过长(>3s)
- 死循环/陷阱(无限分页、Session ID 链)

### 阶段 2:渲染(Rendering)

**目标**:对包含 JavaScript 的页面执行脚本,获得最终 DOM

**Google 的渲染引擎**:Web Rendering Service(WRS),基于无头 Chromium,与最新 Chrome 同代

**两种渲染路径**:
1. **第一波抓取后立即索引(初始 HTML)**:对内容已在 HTML 中的页面快速索引
2. **渲染队列**:JS 重的页面进入 render queue,稍后执行,典型延迟数秒到数天

**关键限制**:
- 无 cookies、无 localStorage、无登录状态
- 网络请求超时短(15-20s)
- 部分 fetch 被拒绝(用户交互依赖)
- 首屏外的内容仍需可被发现(无限滚动需 SSR/Pagination 兜底)

**失败模式**:
- 客户端渲染(CSR)且首屏内容依赖用户交互
- API 调用失败/慢
- 关键内容在 onClick 后才加载
- 错误边界吞掉异常,Google 看到空白
- robots.txt 屏蔽了 JS/CSS 资源

### 阶段 3:索引(Indexing)

**目标**:解析渲染后的 DOM,提取内容、信号、元数据,存入倒排索引

**提取的信号**:
- 标题、描述、H1-H6
- 正文内容(去除导航、广告)
- 图片 alt、视频元数据
- 结构化数据(Schema.org)
- 内外链
- 规范化标签([[Canonical规范化标签]])
- hreflang 标签([[Hreflang国际化标签]])
- robots meta(noindex 此处生效)

**索引决策**:
- noindex → 不索引
- canonical 指向其他 URL → 当前 URL 不索引
- 重复内容 → 只索引一个版本(canonical/规则选择)
- 低质量页面(thin content)→ 索引但低权重
- 页面 ranking signals 可被多次重新评估,索引非一次性

**失败模式**:
- noindex meta 误加
- canonical 错误指向其他 URL
- 完全重复内容,Google 选择别人的版本
- 低质量内容被 [[Helpful Content Update]] 降权
- 页面有内容但 Google 判断为"不值得索引"(Crawled - Currently Not Indexed)

## 实战诊断流程

页面没排名时,按 流水线倒序 排查:

1. **索引检查**:`site:domain.com/url` 看是否被索引
2. 如未索引,**Search Console URL Inspection** 看抓取状态、渲染快照、索引判定
3. 如抓取失败:看服务器响应、robots.txt、状态码
4. 如抓取成功但渲染失败:看 Inspection 中的 Live Test 渲染截图
5. 如渲染成功但未索引:看 noindex、canonical、duplicate 信号
6. 如已索引但不排名:回到内容质量、E-E-A-T、外链等"排名层"问题(超出本概念范围)

## 三阶段的常见混淆点

1. **noindex 不阻止抓取**:robots.txt Disallow 才阻止抓取,noindex 在渲染后才被解析
2. **canonical 是建议非命令**:Google 可能忽略你的 canonical 选择别的 URL
3. **JS SEO 不是渲染失败**:更多是渲染延迟、内容首屏外、内链 JS 化
4. **被抓取不等于被索引**:Crawled - Currently Not Indexed 是 GSC 常见状态
5. **被索引不等于会排名**:索引只是入门,排名取决于多维度信号
