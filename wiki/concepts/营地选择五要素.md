# 营地选择五要素

## 定义

营地选择五要素(Five W's of Campsite Selection,有时也叫 5 个标准)是户外人在**野外快速判断营地是否合适**的实操框架。它把"哪里扎营"这个看似主观的问题分解为五个**客观可检查项**,新手熟练后能在十几分钟内排除大部分隐藏风险。

英文记忆法:**Wind, Water, Widow-makers, Wildlife, Wood**(风、水、悬树、野生动物、燃料)。中文常表述为五要素:**水源、地势、避风、安全、撤退**。

## 核心要点

**要素一:水源(Water)**

- 距离:200 米内最佳,既方便取水也避免水边湿度
- 不要紧贴水边:潮气、虫多、蛇近、夜里涨水
- 不要在干河床扎营:山洪可在数分钟到达
- 上下游分离:取水点在上游,洗漱 / 厕所在下游 60+ 米
- 注意水质标记:发臭 / 漂浮藻类 / 死动物的水源不取

**要素二:地势(Terrain)**

- **平整度**:稍倾斜可接受(头高脚低,排水方向),严重倾斜睡袋会滑
- **排水**:不在凹地扎营,雨夜变水池
- **地表**:松软草地最佳;石板地需选大块平整者;沙地睡前要平整
- **海拔分层**:山谷阴冷潮湿,山脊风大易雷击;山腰最舒适
- **植被**:不踩高山垫状植被(脆弱难恢复),Leave No Trace 原则

**要素三:避风 / 风向(Wind)**

- 夜风方向:山风 vs 谷风,白天吹谷风(谷向上),夜里吹山风(山向下)
- 帐篷开口背风:门口对着背风方向,迎风面是抗风设计的尾部
- 风速 > 20 km/h 不在山脊扎营
- 阻挡物:大石 / 树丛背风面是天然屏障,但避免**正下方**(落树 / 落石)

**要素四:安全 / 上方危险(Widow-makers / Hazards)**

- **悬枝(Widow-makers)**:头顶松动的树枝,夜间风大可能掉落致死
- **落石区**:岩壁下方、碎石坡顶 / 底
- **雪崩 / 滑坡**:坡度 30-45°、新雪 / 湿润松软土
- **雷击区**:孤树、山顶、湿草地、山脊
- **昆虫 / 野生动物**:不在动物足迹密集处、不在蜂巢附近、远离游客投食地

**要素五:撤退路径(Escape Route)**

- 知道天黑后如何离开
- 至少备一个备选下撤方向(主路被洪水阻断时)
- 与村庄 / 公路距离记录(救援车辆能否抵达)
- 信号覆盖检查:卫星电话 / 北斗短报文 / 手机信号
- 紧急联系人提前告知大致营地坐标 + 预计返回时间

**额外补充要素(扩展版)**

- **燃料(Wood)**:Bushcraft 营地需附近有可烧木柴(干 / 死 / 落地);车露 / 营地不重要
- **隐私(Privacy)**:他人营地距离最少 50 米
- **法律 / 许可**:国家公园需扎营许可,核心保护区禁营
- **Leave No Trace 七原则**:营地选择是 LNT 第二原则"在耐用地表行进与扎营"

**实操检查清单**

到达可能营地后,5 分钟快速过一遍:
1. 抬头看树梢(悬枝?)
2. 低头看地面(尖石 / 蚁窝 / 坑?)
3. 远望天气(雷云?)
4. 测试坡度(平躺或站立 30 秒,头脚高差体感)
5. 走出去 50 米看撤退方向是否可达

## 与其他概念的关系

营地选择五要素是 [[露营营地选择]] 的实操检查清单,与 [[Leave No Trace原则]] 配合形成"既要安全也要环保"的选址标准。直接关联 [[户外安全与应急]] 的风险预防、[[徒步露营]] / [[雪地露营]] 等场景的具体取舍。

## 高频陷阱

- "风景好"的悬崖边、湖中央小岛、瀑布下,大多有致命风险
- 看到他人留下营地痕迹就照搬:可能是他们错选了
- 干河床平坦诱人但极危险(山洪)
- 山谷底凉爽但夜里冷风下沉,体感比山腰冷 5-10℃
- 第一晚累了"凑合"扎营 → 半夜要重新搬
