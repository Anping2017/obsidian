# 再营销

## 定义

再营销(Retargeting / Remarketing)指对已与品牌发生过互动(访问网站、加入购物车、注册未购、看过特定品类)但未完成最终转化的用户,通过广告平台再次定向投放的策略。其核心价值是命中"已经表达过兴趣"的高意向人群,CTR 与转化率通常是冷启动拉新的 3-10 倍,是降低 [[CAC获客成本]] 最直接的杠杆之一。

## 核心要点

**人群构建方式**:

- **像素埋点(Pixel)**:Meta Pixel、Google Ads Tag、字节像素,放置在网站收集访问数据。
- **客户匹配(Customer Match)**:上传手机号 / 邮箱列表,平台 Hash 匹配账户。
- **App 事件回传(SDK)**:Adjust / AppsFlyer 把 App 内行为传给广告平台。
- **CRM 名单导入**:把高价值客户导入做差异化沟通。
- **服务器到服务器(S2S)/ Conversion API**:绕过浏览器追踪限制(隐私时代核心)。

**人群细分**:

- 全站访问 30 天(广义,流量大但精度低)。
- 具体品类页 / SKU 浏览(精准)。
- 加购未付款(转化率最高)。
- 注册未付费(适合优惠召回)。
- 已购老客户(交叉销售 / 复购触达)。
- 高 LTV 客户的排除人群(避免对老客投拉新广告)。

**典型场景**:

- **加购弃单召回**:看到加购 SKU 的同款 / 类似款广告 → 转化率提升 30-50%。
- **品类教育**:浏览过该品类未下单 → 推内容性广告(如评测、对比)。
- **续费提醒**:订阅到期前 14 天 → 优惠券广告。
- **跨品类种草**:已购 A 品类 → 推 B 品类。

**[[Lookalike人群]] 衍生**:

- 用高价值再营销人群作种子,扩散相似人群——把"小而精"扩为"大而准"。
- 1% Lookalike 最像种子但量小,5-10% 量大相似度低。
- 推荐:1% LAL 跑测 → 验证 ROI → 扩到 3-5%。

**频次控制(Frequency Capping)**:

- 同一用户每天看到的广告次数上限,常设 3-5 次/天。
- 过度曝光导致负面感知 + 广告失能("我已经看了 20 次,你烦不烦")。
- 不同人群组别(已购 vs 未购)用不同上限。

**衰减策略**:

- 时间窗口分组:1-7 天 / 8-30 天 / 31-90 天,不同窗口出价不同。
- 越近期意向越强,出价应越高。
- 90 天以上人群转化率断崖,转入 [[邮件序列设计]] 与 [[Push通知]] 而非付费广告。

**隐私冲击**:

- [[ATT隐私框架]] 后,iOS 用户授权率 25%,人群池断崖。
- Cookie 弃用让浏览器跨域追踪失效。
- 应对:Conversion API、第一方数据中台(CDP)、Lookalike 算法替代。

**反模式**:

- 全站访问者一桶水广告 → 浪费预算。
- 已购老客继续投拉新广告 → 招恨,且 ROAS 假性高(本来就要复购的人)。
- 频控不严 → 广告疲劳。
- 与拉新广告同套素材 → 失去针对性。

## 和其他概念的关系

再营销是 [[精准营销]] 的高强度形态,依赖 [[转化漏斗]] 的全链路追踪与 [[用户画像]] 的细化标签。它与 [[Lookalike人群]] 是 DMP 体系一体两面,种子-扩散是它的基本算法逻辑。在 [[归因模型]] 中,再营销人群往往被末次模型高估、被首次模型低估——多触点归因才能看到真实贡献。

工具上,Meta Ads、Google Ads、字节巨量引擎、腾讯广告、TikTok Ads、Criteo、AdRoll 都是再营销主流平台。再营销 ROAS 远高于拉新但**不可孤立扩张**——没有充分的拉新流量,再营销人群池会枯竭,出现规模天花板。

它与 [[邮件序列设计]] 的"Win-back"序列、[[Push通知]] 的"召回"逻辑同构,只是触达通道不同。在 [[隐私优先时代]],再营销正经历从"个人级追踪"向"群体级建模(Privacy Sandbox、SKAdNetwork、聚合测量)"的转型。
