# 沉没成本

## 定义

**沉没成本**(Sunk Cost)是已经支付且**无法因未来任何决定而收回**的成本。经济学的标准结论:**理性决策应忽略沉没成本,只看未来增量成本与收益**。

但行为经济学的核心发现是:**人无法做到这一点**——这种偏差称为**沉没成本谬误**(Sunk Cost Fallacy),广泛影响投资、消费、感情、组织决策。

## 核心要点

### 经济学标准定义

边际决策原则:
- **决策标准** = 未来增量收益 − 未来增量成本
- **沉没成本不可改变** → 不影响最优行为
- 例:已支付不可退的电影票,只看"剩下时间看完是否带来正效用",而非"票钱不能浪费"

### 沉没成本谬误(行为视角)

研究者 Hal Arkes 与 Catherine Blumer 1985 的经典研究给出两个代表性证据:

> **剧院季票田野实验**:季票买家被随机分为原价、小折扣、大折扣三组。付全价者在上半季观剧次数显著更多——付得越多越舍不得"浪费"。

> **滑雪旅行假设情境**:你已花 $100 买了密歇根滑雪票,又花 $50 买了威斯康星滑雪票,随后发现两趟在同一周末、只能去一个;你其实预期威斯康星更好玩,但多数人仍选已花更多钱的密歇根。

理性来看已付的钱都已沉没,选择应基于"哪个更享受";但人们系统性地被更大的已付金额牵着走——典型的沉没成本谬误。

### 心理机制

| 机制 | 描述 |
|---|---|
| **损失规避** | 见 [[损失规避]],承认损失痛苦大于放弃收益 |
| **承诺一致** | 见 [[承诺与一致]],已投入要保持自我一致形象 |
| **认知失调** | 见 [[认知失调]],承认放弃 = 承认决策错误 |
| **预期遗憾** | 害怕将来后悔"那么多投入白费" |
| **公开承诺** | 投入越公开,越难退出 |
| **职业声誉** | 管理者怕被评价"反复无常" |

### 与"沉没成本陷阱"相关的现象

#### Concorde 谬误
英法政府明知协和号客机商业上不可行,仍因已投入巨额研发继续推进,1969 年首飞、1976 年投入商业运营、2003 年退役 → 损失数十亿英镑。

#### 越战升级
McNamara 等决策者已看到失败迹象,但已投入太多军力与声誉,加码至难以收场。

#### 个人投资追加
股票账面亏损 → "等回本就卖" → 长期套牢,本质是把不该影响决策的沉没成本计入。

#### 续命产品
公司明知产品已落后市场,因"团队投入这么多年"不愿停产,占用资源拖累其他线。

#### 维持坏关系
已投入感情、时间、共同财产,即使关系恶化仍难离开。

### 何时不是真正的"沉没成本谬误"

并非所有"看似沉没成本"的考虑都错:
- **学习价值**:已投入的时间产生了知识/能力 → 不算沉没,有持续收益
- **声誉与信任**:撤回的代价是关系受损 → 是真实未来成本
- **信号功能**:坚持本身向他人传达信息 → 是工具,而非误判
- **重启成本高**:再启动需要新的固定成本

理性分析需要清晰区分**真正不可挽回**的部分与**仍有价值流**的部分。

### 防御沉没成本谬误

1. **零基决策**:每次决策假装从零开始
2. **第三方视角**:"如果是别人面临这局面,我会建议什么?"
3. **预设止损**:决策前定好"满足什么条件就退出"
4. **小步迭代**:把大投入拆为多次小决策,每次重评
5. **隔离决策与人**:把项目从"创始人血汗"分离,见 [[逆向思维]]
6. **建立组织文化**:奖励"承认错误及时止损",而非死磕

## 应用场景

- **投资**:止损纪律的认知基础,见 [[损失规避]]、[[行为金融学]]
- **创业**:不再有 PMF 的项目何时关停
- **企业**:数字化项目、并购整合中的"已投入"陷阱
- **个人**:学位、感情、习惯的退出决策
- **政府**:大型工程、战争、政策路径依赖

## 局限与陷阱

| 陷阱 | 描述 |
|---|---|
| **滥用为合理化** | "这就是沉没成本"被用来逃避承诺 |
| **忽视真实未来成本** | 退出本身有声誉/学习/网络代价 |
| **过度理性化** | 完全忽略情感纽带也不健康 |
| **群体决策稀释责任** | 群体更易陷入沉没成本陷阱 |

## 与其他概念的关系

- 与 [[机会成本]] 是镜像概念——后者是"应考虑而常忽略",前者是"不应考虑而常考虑"
- 与 [[损失规避]]、[[认知失调]]、[[承诺与一致]] 共同构成行为机制
- 与 [[禀赋效应]]、[[过度自信]]、[[确认偏差]] 在投资场景叠加
- 与 [[逆向思维]]、[[第一性原理]] 是对治工具
- [[行为经济学]]、[[行为金融学]] 是其学术家园
- 与 [[安全边际]]、[[能力圈]] 在投资决策中协同
- 与 [[战略转型]]、[[变革管理]] 在组织层面的对应议题
- [[精益创业]] 的"早失败"哲学是工程化对治
