# 战略地图

## 定义

**战略地图(Strategy Map)** 由 **Robert Kaplan** 与 **David Norton** 在 2000 年代提出(《Strategy Maps》2004),是把企业战略可视化为**因果链** 的工具。

核心命题:**多数战略失败不在于战略错,而在于无法沟通和执行战略**。战略地图通过单一图表把战略目标、因果关系、衡量指标串联,让组织各级"看见同一张图"。

战略地图是 [[平衡计分卡]] 的进化——计分卡列出指标,但不显示指标之间的关系;战略地图把这些关系可视化为因果链。

## 核心要点

### 战略地图的标准架构(四维度)

Kaplan-Norton 战略地图按四个维度由下到上构建因果链:

```
财务维度(收入增长 + 生产率)
    ↑
客户维度(价值主张:客户感知)
    ↑
内部流程维度(运营/客户/创新/法规社会)
    ↑
学习与成长维度(人才 + 信息 + 组织资本)
```

### 四维度详解

#### 1. 学习与成长(基础维度)

无形资产驱动一切:

| 类别 | 内涵 |
|---|---|
| **人力资本** | 战略性能力、技能、知识 |
| **信息资本** | 系统、数据库、网络 |
| **组织资本** | 文化、领导力、协同、知识管理 |

**关键问题**:我们有合适的人和能力吗?

#### 2. 内部流程(转化层)

把无形资产转化为客户价值:

| 流程类别 | 焦点 |
|---|---|
| **运营管理** | 提供产品和服务 |
| **客户管理** | 建立深层客户关系 |
| **创新** | 开发新产品和服务 |
| **法规社会** | 改善社区与环境 |

#### 3. 客户维度(价值主张)

向客户承诺什么独特价值?三大价值主张选择(波特/特西)模式:

- **运营卓越**(Operational Excellence):便宜、便捷
- **产品领先**(Product Leadership):创新、最佳
- **客户亲密**(Customer Intimacy):定制、深关系

每种主张需要不同的内部流程和能力支撑。

#### 4. 财务维度(最终结果)

两条路径增加股东价值:

- **生产率(降本)**:改善成本结构、利用现有资产
- **增长(增收)**:增收新客户、深化现有客户

### 战略地图的因果逻辑

例(零售连锁):

```
财务:收入增长 15% / 营业利润率提升
   ↑
客户:客户满意度提升 / 复购率提升
   ↑
内部:门店服务流程优化 / 缺货率下降
   ↑
学习:店员培训完成率 / 系统能力升级
```

每一步可量化,环环相扣。任何一环失效,上层无法实现。

### 战略地图与平衡计分卡的区别

| 维度 | 战略地图 | [[平衡计分卡]] |
|---|---|---|
| 形式 | 因果图 | 指标矩阵 |
| 内容 | 目标 + 关系 | 目标 + 衡量 + 目标值 + 行动 |
| 用途 | 沟通战略 | 执行管理 |
| 时机 | 战略制定后 | 战略执行中 |

两者配套使用——战略地图回答"为什么",计分卡回答"怎么做"。

### 战略地图的"四个连接"

Kaplan-Norton 强调战略地图必须显示:

1. **战略 → 业务单元**(顶层到 BU 的级联)
2. **战略 → 部门**(横向跨部门支持)
3. **战略 → 个人**(KPI 与战略地图对齐)
4. **战略 → 资源配置**(预算与战略对齐)

未连接 = 战略飘在空中。

### 主题(Theme)的概念

战略地图常按"战略主题"组织,而非单一图。主题是**战略的某一个支柱**:

- 例如银行可能有三个主题:零售客户体验 / 数字化转型 / 风险管理
- 每个主题是一条独立的因果链
- 主题汇总成总图

主题让复杂战略变得可管理。

### 应用流程(实施战略地图)

```
1. 高层战略共识 → 2. 绘制战略地图 → 3. 设计平衡计分卡 →
4. 战略沟通 → 5. 各部门级联 → 6. 个人对齐 → 7. 持续监控
```

每一步都是项目,通常需 6-12 个月完整落地。

### 常见问题

- **目标过多**:战略地图最多 15-20 个目标,多了失焦
- **因果牵强**:有些"关系"是想当然不是真实因果
- **指标不挂钩**:地图画了,KPI 不变,等于没画
- **静态**:做完不更新,与现实脱节
- **战略地图就够了**:还需要执行管理与文化变革配合

## 和其他概念的关系

- 是 [[平衡计分卡]] 的可视化进化,与 BSC 互补
- 是 [[战略执行]] 的核心工具
- 把 [[战略目标设定]] 系统化呈现
- 客户维度对应 [[STP战略]] 中的定位与价值主张
- 学习与成长维度对应 [[组织学习]]、[[人力资源管理]]、[[培训与发展体系]]
- 内部流程对应 [[运营管理]]、[[供应链管理]]、[[创新]]
- 财务维度对应传统 [[管理会计]] 与 [[企业价值评估]]
- 与 [[OKR目标管理法]] 互补:OKR 短周期,战略地图长周期
- 在 [[战略转型]] 中是描述未来状态的工具
- 跨业务集团企业可绘制多层级战略地图
- 与 [[管理决策]] 中"系统视角" 一致
