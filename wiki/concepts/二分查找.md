# 二分查找 Binary Search

## 定义

**二分查找(Binary Search)**是在**有序数组**中查找目标值的算法:每次取中间元素与目标比较,根据大小关系把搜索区间折半,直到找到或区间为空。时间复杂度 **O(log n)**,空间 O(1)(迭代)或 O(log n)(递归)。

二分的本质是"在每次操作上排除一半的可能性",可推广到任何**单调性可判定**的搜索空间,远不止数组查找。

## 核心要点

### 标准模板

```
left = 0; right = n - 1
while left <= right:
    mid = left + (right - left) / 2  # 防溢出
    if arr[mid] == target: return mid
    elif arr[mid] < target: left = mid + 1
    else: right = mid - 1
return -1
```

### 三种边界变体

1. **找等于 target 的任一索引**:经典模板
2. **找第一个 ≥ target 的索引(lower_bound)**:返回插入位置
3. **找最后一个 ≤ target 的索引(upper_bound - 1)**

不同变体的循环条件、左右更新方式微妙差异,极易写错。建议固定一种"红蓝染色"或"左闭右开"模板熟练记忆。

### 二分答案(Binary Search on Answer)

当问题不是"在有序数组中找值",而是"在某个数值范围内找满足某条件的最小/最大值"时:
- 若该条件在数值上单调(满足→满足、或不满足→满足)
- 就可以二分搜索这个**答案范围**,每次用 O(check) 检验

经典例题:**最小化最大值**(切木头、分饭量、传送带运货)、**最大化最小值**(分糖、调度)。把 O(n) 的暴力枚举降到 O(log(范围) × check)。

### 三分搜索(Ternary Search)

适用于**单峰函数**找极值:每次取两个中间点,排除其中三分之一。复杂度 O(log n)。常用于凸函数极值、几何最优化。

### 复杂度推导

T(n) = T(n/2) + O(1),由主定理得 O(log n)。这意味着:
- 1024 个元素:10 次比较
- 100 万:20 次
- 10 亿:30 次

是工程上"几乎免费"的查询。

## 和其他概念的关系

二分查找的前提是**有序**,与[[排序算法]]互补:先 O(n log n) 排序、然后多次 O(log n) 查询,是大量"预处理 + 多次查询"模式的核心。

[[树]]中的[[二叉搜索树]]、平衡树本质是动态维护的二分查找;[[B+树]]在每个节点上做二分,把磁盘 IO 降到 O(log n)。[[Hash表]] O(1) 但无序,二分支持范围查询,这是为何[[数据库索引]]普遍用 B+ 树而非 hash。

[[分治算法]]的母版思想就是"折半":归并排序、快速排序、最近点对、FFT 都共享这个 idea。"二分答案"在算法竞赛和工程参数调优(如 SLO 阈值搜索、线性回归学习率搜索)中也极为常用。
