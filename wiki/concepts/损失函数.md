# 损失函数

## 定义

**损失函数(Loss Function)** 又称代价函数(Cost Function),是 [[机器学习]] 中量化模型预测 $\hat{y}$ 与真实标签 $y$ 之间差距的标量函数 $L(\hat{y}, y)$。训练的目标就是找到参数使该函数在训练集上最小化(同时不至于 [[过拟合与正则化]])。

## 核心要点

**回归任务**

- 均方误差(MSE):$L = \frac{1}{n} \sum (y - \hat{y})^2$,对大误差敏感
- 平均绝对误差(MAE / L1):$L = \frac{1}{n} \sum |y - \hat{y}|$,对异常值更鲁棒
- Huber loss:小误差用 MSE、大误差用 MAE,兼顾两者优点

**分类任务**

- 二分类交叉熵(BCE):$L = -[y \log \hat{p} + (1-y) \log (1-\hat{p})]$
- 多分类交叉熵:$L = -\sum_c y_c \log \hat{p}_c$,与 softmax 输出搭配
- Hinge loss:SVM 使用,鼓励正确类别的间隔大于一定阈值

**生成与对比任务**

- 负对数似然(NLL):语言模型预测下一 token 的标准目标
- KL 散度(KL Divergence):度量两个分布差距,变分自编码器、知识蒸馏常用
- 对比损失(Contrastive Loss / InfoNCE):自监督学习中拉近正样本、推远负样本

**训练机制**

- 训练流程:前向计算 $\hat{y}$ → 计算 $L$ → [[反向传播]] 求梯度 → [[梯度下降]] 更新参数
- 加正则项:$L_{\text{total}} = L_{\text{data}} + \lambda \cdot R(\theta)$,$R$ 是 L1/L2 等
- 多任务学习:常用加权和 $L = \sum_i w_i L_i$

## 和其他概念的关系

- 与 [[反向传播]]:损失函数提供反向传播的起点(对损失求梯度)
- 与 [[梯度下降]]:损失函数定义优化目标,梯度下降是求解工具
- 与 [[过拟合与正则化]]:正则化作为损失函数的附加项实现
- 任务决定形式:[[监督学习]] 的分类、回归任务有不同标准选择
- 在 [[大语言模型]] 中:预训练阶段普遍使用 next-token prediction 的交叉熵
- 与 [[RLHF]] 中的奖励模型:奖励模型的训练损失用偏好对比形式
