# 留面子效应 Door-in-the-Face (DITF)

## 定义

**留面子效应**(Door-in-the-Face, DITF)指**先提一个对方几乎肯定拒绝的大请求,再提一个真正想要的小请求**时,**第二个请求被接受的概率显著提升**。Cialdini 等(1975)经典实验:请大学生做志愿者陪青少年罪犯参观动物园 2 小时(目标请求)成功率 17%;若先请他们承诺每周做 2 小时志愿者持续 2 年(超大请求,99% 拒),再降级到 2 小时陪游园,成功率升至 50%。

## 核心要点

### 心理机制

1. **互惠让步**(reciprocal concession):对方"让步"了大请求,我感到也应"让步"答应小请求(见 [[互惠原则]])
2. **[[对比效应]]**:与超大锚定相比,真实请求显得合理(见 [[锚定效应]])
3. **拒绝内疚**:刚拒了一次,再拒第二次心理负担更重
4. **关系维护**:不愿让对方完全空手

### 关键边界条件

- 第一个请求**必须真的"大"且具一定合理性**(乱开价会破坏信任)
- 两个请求**间隔很短**(让步感才显著)
- **同一人提出**两个请求(让步主体一致)
- 第二个请求**与第一个相关**(同主题让步才算让步)
- 第二个请求**真的小**(不仅仅是名义上小)

### 与登门槛效应对照

| 维度 | 登门槛 FITD | 留面子 DITF |
|---|---|---|
| 顺序 | 小 → 大 | 大 → 小 |
| 机制 | 自我一致性、承诺 | 互惠让步、对比 |
| 时间间隔 | 越长效果越好 | 越短效果越好 |
| 第一请求被接受率 | 高(几乎都接) | 低(几乎都拒) |
| 适用 | 培养长期关系/订阅 | 单次决定/谈判 |

两种策略不可同时用:用了登门槛再用留面子会让对方"识破"。

### 应用场景

- **谈判**:开高价 → 真实价格落实(锚定+让步双重作用)
- **销售**:旗舰版报价 → 标准版成交
- **筹款**:大额请求 → 小额捐款
- **请假**:请一周 → 退到三天
- **政策**:激进方案 → "妥协"到原本目标
- **儿童教育**:大要求 → 真实要求(谨慎使用)
- **B2B 招标**:复杂方案 → 简化方案
- **学术求助**:深度合作 → 单次评审

### 失败模式

- 第一请求过分荒谬 → 对方愤怒,不给让步机会
- 让步幅度过小 → 觉得在被忽悠
- 隔天才提小请求 → 互惠感消失
- 不同人提 → 没有"同一主体让步"

## 和其他概念的关系

留面子与 [[登门槛效应]] 互为镜像,共同构成 [[影响力]] (Cialdini)中 [[互惠原则]] 与 [[承诺与一致]] 两大武器的应用。

机制上深度依赖 [[锚定效应]]、[[对比]]、[[互惠原则]] 三个基础概念,与 [[损失厌恶]]、[[框架]]效应也有交叉。

[[价格谈判技巧]]、[[销售技巧]]、[[销售漏斗]] 的高阶设计常包含留面子结构;B2B 销售的"先报旗舰、再退中端"正是其工程化版本。

[[行为经济学]]、[[助推]] 设计中均会用到此技巧;[[营销心理学]]、[[文案公式]] 中"原价划掉、现价突出"也利用类似锚定逻辑。

伦理上与 [[暗黑模式]] 边界明显——合理价格策略可接受,欺诈性"假高锚定"违反 [[商业伦理]]。
