# 户外保温杯系统

## 定义

户外保温杯(Insulated Bottle / Tumbler)是利用**真空夹层**(双层不锈钢之间抽真空)阻断热传导的便携饮水器。在户外场景,它解决"冬天 4 小时后的热水"和"夏天的冰镇饮料"两大需求。一只完整的户外保温杯涉及内胆材质、真空层质量、瓶口设计、密封盖结构、防滑底等多个工程细节。

## 核心要点

**真空保温原理**

热量传递有三种途径:**热传导**、**对流**、**辐射**。
- 真空夹层断绝热传导和对流
- 内胆抛光 / 镀层减少辐射
- 瓶口塑料密封是最大热桥(为何瓶口大的杯保温差)

**容量规格**

| 容量 | 用途 | 重量参考 |
|---|---|---|
| 350 ml | 单人一次饮 | 200-260 g |
| 500 ml | 通勤标准 | 280-340 g |
| 750 ml | 半天户外 | 380-450 g |
| 1 L | 全天主水壶 | 500-650 g |
| 1.5-2 L | 多人共享 / 长途 | 800-1200 g |

**保温时长指标**

国标 / 商家自标"保温 12 小时不低于 X 度":
- 95℃ 注满 → 6 小时 ≥ 70℃(基本)
- 95℃ 注满 → 12 小时 ≥ 50℃(优秀)
- 95℃ 注满 → 24 小时 ≥ 35℃(顶级)

实际表现受**容量、外温、是否摇晃**影响。容量越大保温越久(物理表面积比),容量小的保温杯实际更难维持高温。

**口径与盖子设计**

1. **小口直饮(50-60mm)**:漏液少、保温好、不能加冰块
2. **大口杯口(70-90mm)**:可塞冰块、易清洁、保温稍差
3. **吸管盖**:开车 / 运动方便,但密封性弱
4. **按钮盖**:单手开合,防漏中等
5. **运动盖(Sport Lid)**:挤压出水,Yeti / Hydro Flask 主推
6. **军绿盖 / 全密封**:Stanley 经典,几乎不漏

**主流品牌流派**

- **Yeti**(美国):粗犷工业风、双壁真空、口径多样、价格高
- **Stanley**(美国百年):全密封军绿水壶、超长保温、亮粉色 Quencher 火爆
- **Hydro Flask**(美国):彩色喷涂、口径标准、吸管 / 运动 / 经典三系列
- **象印 / 虎牌**(日本):工艺细腻、小口直饮、保温时长行业标杆
- **Klean Kanteen**(美国):简约不锈钢、环保理念
- **Hydaway / Bobble**:折叠 / 滤芯创新型

**清洁与维护**

- 内胆不能入洗碗机(会褪色 / 影响真空)
- 瓶口缝隙是细菌温床,需用瓶刷
- 长期不用前彻底干燥
- 真空层一旦漏(撞凹严重)即失去保温,需整杯报废

## 与其他概念的关系

保温杯是 [[户外炊具系统]] 的延伸,与 [[户外净水方法]] 配合保证野外饮水安全(净水后装保温杯保持温度)。在 [[Bushcraft]] 与 [[Glamping精致露营]] 两端都有适用场景。

## 高频陷阱

- "保温 24 小时"宣传常常是低温起点测试,实际起始温度更高时保温变短
- 真空杯不能装碳酸饮料(密闭加压可能爆裂)
- 装牛奶 / 果汁后必须当天清洗(滋生细菌)
- 撞凹后保温骤降但外观可能完好,易误判
- 大杯口 + 长时间冰镇可能在杯外凝冷凝水(双层杯不会,真空夹层时不会)
