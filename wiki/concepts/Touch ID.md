# Touch ID

## 定义

**Touch ID** 是 Apple 在 2013 年 iPhone 5s 上首次引入的**电容式指纹识别技术**,集成于 Home 键(后期 iPad 在电源键)。它能在不到一秒内完成指纹采集与识别,通过专用安全协处理器**Secure Enclave** 加密存储指纹特征,而非完整图像。Touch ID 是消费电子生物识别普及化的标志性产品,后被 [[Face ID]] 在多数 iPhone 机型上替代,但在 iPad 与部分 iPhone(如 SE 系列)上延续。

## 核心要点

### 技术原理

- **电容式传感器**:不是拍照,而是测量指纹脊与谷在传感器上不同的电容值
- **不锈钢检测环**:激活传感器并防伪
- **多角度采集**:首次设置时引导用户从多角度按压,提升识别覆盖率
- **持续学习**:每次成功识别都微调模型,适应指纹的微妙变化

### 安全设计

- 指纹特征(数学特征,非图像)由 [[Secure Enclave]] 在 A 系列芯片内的安全区生成与存储
- iOS 主系统永远访问不到指纹数据,只能问"是否匹配"——回答 yes/no
- 不上传 iCloud,不与 Apple 共享
- 5 次错误后强制输入密码;48 小时不解锁也强制密码
- 重启后第一次解锁强制密码

### 应用场景

- **解锁设备**:替代复杂密码
- **Apple Pay**:支付时一键确认
- **App Store / iTunes**:应用购买
- **第三方 App**:开发者通过 LocalAuthentication 框架接入
- **iCloud Keychain**:密码自动填充

### 与 Face ID 对比

| 维度 | Touch ID | [[Face ID]] |
|---|---|---|
| 传感器 | 电容指纹 | 结构光 + 红外 |
| 误识率 | 1/50,000 | 1/1,000,000 |
| 戴口罩 | 不影响 | 早期失效,后期改进 |
| 暗光 | 不影响 | 红外不依赖光线 |
| 双胞胎 | 不易混淆 | 可能混淆 |

### 演进与现状

- 第一代(2013):iPhone 5s 起
- 第二代(2015):iPhone 6s 起,显著提速
- 2017 年起 Face ID 取代主流 iPhone 上的 Touch ID
- 2020 年 iPad Air 4 起,Touch ID 集成于电源键,延续到今天

## 和其他概念的关系

- 与 [[Face ID]] 同为 Apple 生物识别两大方案
- 安全根基都是 [[Secure Enclave]]
- 是 [[iOS隐私机制]] 的关键支柱之一
- 与 [[Apple生态系统]] 中的 Apple Pay 直接耦合
- 是 [[A系列芯片]] 安全协处理器架构的早期落地
