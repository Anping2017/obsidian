# 上下游议价能力

## 定义

上下游议价能力(Bargaining Power across Value Chain)是 [[Porter五力模型]] 中"供应商议价能力(上游)"与"购买者议价能力(下游)"两维的整合视角。在零售业态尤其手机/3C/快消零售中,经销商被夹在上游(品牌厂商/品牌总代)与下游(消费者/团购采购方)之间,议价能力直接决定:进货价、付款账期、退换货条款、价格谈判空间、促销让利幅度——最终落到毛利结构与现金流稳定。

## 上游(对供应商/厂商)议价能力

### 决定因素

1. **采购规模**:月采 1000 万与月采 10 万,价格相差 5-15%
2. **品牌依赖度**:高溢价品牌(Apple、华为)上游话语权极强,经销商几乎无议价空间
3. **替代性**:同类品牌之间可切换的程度,决定经销商威胁离开的可信度
4. **付款方式**:现款现货 vs 月结/季结,影响进货价 1-3%
5. **专营/分销层级**:总代理 > 省代 > 市代 > 零售商,层级越深加价越多
6. **数据共享**:经销商把销售数据回传厂商可换取返点
7. **联合采购**:连锁化或加盟联盟提升集体议价

### 提升上游议价的方式

- 加入连锁/加盟体系,享受集采价格
- 集中订货,减少 SKU 数量
- 与厂商建立长期合作,争取专属授权(独家区域、专属机型)
- 共享会员数据,换取价格让利
- 大型节点联合促销,争取"销售奖励池"

## 下游(对消费者/采购方)议价能力

### 决定因素

1. **品牌独特性**:店铺品牌力越强,下游议价压力越小
2. **服务差异化**:售后、维修、账户绑定让客户难以走人
3. **位置垄断**:某地段独家店,客户切换成本高
4. **价格透明度**:互联网把价格压到全网最低,下游议价压垮线下
5. **购买频次**:高频客户对价格敏感度高,需让利保留
6. **决策方人数**:个人消费 < 家庭消费 < 企业采购的议价能力梯度

### 应对下游议价压力

- **价值差异化**:不靠价格而靠服务、体验、信任竞争
- **套餐与组合**:用复杂搭配让单品价格难比对
- **会员体系**:[[会员体系]] 锁住客户,降低跳槽议价能力
- **服务货币化**:维修、换膜、技术支持等服务收费,与产品价格脱钩
- **品牌矩阵**:高端机吃毛利,低端机吃流量,差异化客户层
- **二手回收业务**:新机价让利,但旧机回收差价对冲毛利

## 双向博弈的现金流影响

```
现金流压力 = 上游账期 - 下游收款 - 库存周转天数
```

- 上游强势(现款现货)+ 下游弱势(账期长)= 经销商资金紧张
- 上游让利(月结)+ 下游消费者现款 = 现金流舒服
- 这是为什么经销商愿意给上游更多采购量换取账期

## 不同业态的对比

| 业态 | 上游议价 | 下游议价 | 净议价空间 |
|---|---|---|---|
| 苹果授权店 | 极弱 | 中(全网比价) | 极薄毛利 |
| 华为优选店 | 较弱 | 中 | 薄毛利 |
| 多品牌综合店 | 中 | 中 | 中等毛利 |
| 二手机店 | 灵活 | 中(信任溢价) | 中-高毛利 |
| 配件专营店 | 中 | 弱(冲动购买) | 高毛利 |
| 维修连锁 | 弱(配件供应商) | 弱(应急需求) | 高毛利 |

## 与 [[毛利结构]] 的关系

议价能力直接决定各品类毛利:
- 上游强势品类(苹果)→ 经销商接受薄毛利,以销量换返点
- 上游弱势品类(配件、二手、保险)→ 经销商有定价权,毛利可达 30-60%
- 综合毛利率 = 各品类销售占比 × 各品类毛利,议价能力决定加权平均

## 实操建议(针对中小手机/3C 零售)

1. **不要把所有鸡蛋放苹果**:苹果客流大但毛利薄,需配高毛利配件/保险
2. **加入连锁体系**:虽然要交加盟费,但集采价值远超
3. **做好二手回收业务**:议价灵活的高毛利渠道
4. **服务货币化**:贴膜、维修、教学独立定价
5. **避免价格战**:线下店打不过电商,差异化才有出路
6. **节点采购**:厂商促销节点(618、双 11、新品上市)拿低价

## 与其他概念的关系

- 与 [[Porter五力模型]]:本概念是其零售视角实操化
- 与 [[毛利结构]]:议价能力的财务结果
- 与 [[门店经济模型]]:议价能力影响成本结构
- 与 [[供应链管理]]、[[库存管理]]:议价能力决定库存压款
- 与 [[手机店LTV测算]]:上下游协同提升单店利润
- 与 [[竞争分析]]:理解竞品的上下游议价决定差异化策略
- 与 [[市场失灵]]:议价能力悬殊的市场可能存在结构性失衡
