# 营销自动化

## 定义

营销自动化(Marketing Automation, MA)是用软件平台基于触发条件、规则、用户旅程,自动执行邮件、短信、Push、站内消息、广告人群同步、销售线索分配等营销动作的体系。它的本质是把"营销人员手动重复的动作"转为"机器按规则规模化执行",使个性化触达从奢侈变成标配。是 MarTech 栈中应用最广、与 [[CRM客户关系管理|CRM]] / [[CDP客户数据平台]] 紧密耦合的层。

## 核心要点

**核心组件**:

1. **触发器(Trigger)**:行为触发(注册 / 加购 / 浏览)、时间触发(注册 N 天 / 生日)、属性触发(画像变化 / 套餐升级)。
2. **条件分支(Branching Logic)**:If/Else 树,基于用户标签 / 行为分流。
3. **动作(Action)**:发邮件 / 短信 / Push / 站内消息、给标签、分配销售、同步广告人群、触发 Webhook。
4. **延迟(Wait/Delay)**:等待 N 天 / 等到指定时间。
5. **目标(Goal)**:达成则退出工作流,统计成功率。
6. **退出条件(Exit Criteria)**:防止用户被多个工作流重复触达。

**典型工作流**:

- **欢迎序列(Welcome Drip)**:见 [[邮件序列设计]]。
- **加购弃单召回**:加购未付款 1 小时 → 邮件 1;24 小时 → 邮件 2 + 优惠券;72 小时 → 退出或 [[再营销]]。
- **生日 / 周年 / 节日营销**。
- **续费提醒**:订阅到期前 30 / 14 / 7 / 1 天分级提醒。
- **流失预警**:7 天未活跃 → 触发个性化召回。
- **销售线索分级与分配**:Lead Scoring 达阈值 → 分配给销售 → 跟进任务自动创建。
- **Cross-sell / Up-sell**:已购 A → N 天后推 B。
- **NPS 分发**:低分进入服务挽回流,高分引导评价/推荐。

**主流平台**:

- **大型企业级**:Salesforce Marketing Cloud、Adobe Marketo、Oracle Eloqua。
- **B2B 中型**:HubSpot、Pardot、ActiveCampaign。
- **B2C 电商**:Klaviyo(邮件 + 短信电商专用)、MailChimp、Iterable、Braze、MoEngage。
- **国内**:神策、火山引擎 GMP、Convertlab、达摩盘、有赞 SCRM。

**Lead Scoring 模型**:

- **基于属性(Demographic)**:行业、职位、公司规模 +/- 分。
- **基于行为(Behavioral)**:打开邮件 +5,点击 +10,看 Pricing 页 +30,Demo 申请 +50。
- 阈值触发(如 100 分 → MQL → 销售跟进)。
- 衰减(Decay):时间太久未活跃自动减分。

**分级智能化**:

1. **L1 规则自动化**:if-then 硬编码。
2. **L2 个性化(Personalization)**:依用户属性动态填充内容。
3. **L3 推荐引擎**:[[协同过滤推荐]] / [[向量召回]] 决定推什么内容。
4. **L4 AI 优化(AI Optimization)**:Send Time Optimization、Subject Line Optimization、Content Optimization 都自动化。
5. **L5 全 AI 编排**:LLM 生成内容 + 旅程自动设计(Adobe Genstudio、Salesforce Einstein 1)。

**实施陷阱**:

- 数据不通(MA 与 CRM 与 CDP 各管一段)→ 用户被重复触达。
- 工作流过多(几百个)→ 无人维护,失效率高。
- 模板太多 → 个性化失效。
- 频次失控 → 退订率上升,触发邮件 ESP 风控降低送达率。
- 把 MA 当群发工具 → 失去自动化价值。

**成功指标**:

- **运营效率**:节省人力工时。
- **触达率 / 打开率 / 点击率 / 转化率**:对比手动批次。
- **MQL → SQL 转化率**:B2B 关键。
- **客户旅程完成率**:工作流目标达成的比例。
- **整体 [[客户终身价值]] 提升**:终极价值证明。

## 和其他概念的关系

营销自动化是 [[精准营销]] 与 [[全渠道营销]] 的执行引擎,与 [[CRM客户关系管理|CRM]] 提供客户与销售上下文、[[CDP客户数据平台]] 提供数据底座共同构成现代 MarTech 三件套。它是 [[邮件序列设计]]、[[Push通知]]、[[再营销]] 的统一调度层。

它的工作流逻辑与 [[用户旅程地图]] 一一对应——前者是后者的工程化执行。Lead Scoring 是 [[销售漏斗]] 数字化的代表。在 [[B2B营销]] 中,MA + CRM 是营销与销售协同的标配。

[[AI×营销]] 趋势下,LLM 与 MA 的融合大量降低工作流维护成本,生成式 AI 实时生成个性化内容,自动化"内容生产"环节。但 [[GDPR]]、《个人信息保护法》对自动化决策的"可解释性"要求,会限制纯黑盒 AI 自动化的应用。
