# 作业基础预算

## 定义

**作业基础预算**(Activity-Based Budgeting, ABB)是以**作业**为编制起点的预算方法:先预测下期产品/服务的工作量,再推导每项作业的工作量,最后据此推导资源(人、设备、材料)需求与成本预算。

它是 [[作业基础管理]] 与 [[ABC作业成本法]] 在预算管理领域的延伸,克服传统**增量预算**(去年 + 5%)的盲目性,实现"输出驱动输入"的精细管理。

## 核心要点

### ABB 与传统预算对比

| 维度 | 传统增量预算 | ABB |
|---|---|---|
| **起点** | 上年实际 + 增长率 | 下年业务量预测 |
| **逻辑** | 资源 → 部门 → 产品 | 产品 → 作业 → 资源 |
| **可控性** | 部门负责人按经验 | 作业动因驱动可量化 |
| **改进激励** | 弱(花完明年才不被砍) | 强(消除非增值作业可见) |
| **复杂度** | 低 | 高,需 ERP 支撑 |

### ABB 编制流程

```
步骤 1:预测产品/服务销售量与组合
步骤 2:推导每项产品所需作业量(用 ABC 模型)
步骤 3:汇总各作业总工作量
步骤 4:推算每作业所需资源(人时、设备时、材料)
步骤 5:推算资源单价 → 预算成本
步骤 6:与产能对比,识别瓶颈与冗余
步骤 7:形成部门 / 作业 / 项目预算
```

### 简单示例

```
预测销售:10,000 单订单
作业:订单处理(每订单需 0.5 人时)、配送(每订单需 1 公里)、客服(每订单 0.2 通)

订单处理人时 = 10,000 × 0.5 = 5,000 人时
配送公里数 = 10,000 × 1 = 10,000 公里
客服通话 = 10,000 × 0.2 = 2,000 通

资源预算:
人员 = 5,000 / 1,800(人/年) = 2.8 人,预算 280,000 元
配送 = 10,000 × 5 元/公里 = 50,000 元
客服 = 2,000 × 8 元/通 = 16,000 元
```

### 与零基预算(ZBB)的差异

| 方法 | 起点 | 重点 |
|---|---|---|
| **零基预算** | 0 起步,每项支出从头辩护 | 财务可承受 |
| **作业基础预算** | 作业量驱动 | 业务输出与资源匹配 |

两者都对抗"惯性预算",但 ZBB 偏财务视角(削减),ABB 偏业务视角(精准)。

### 战略性 ABB 的应用

- **产能规划**:识别瓶颈作业,提前增加产能或外包
- **业务组合决策**:不同产品线的资源消耗差异显性化
- **成本控制目标**:把每作业成本目标化,形成 KPI
- **产品定价**:基于作业成本的精准定价

### 弹性预算化的 ABB

ABB 可结合**弹性预算**:不同业务量假设下作业量动态调整,形成"销售低/中/高"三套预算,提高应变能力。

### 实施挑战

- **数据基础**:需 ABC 模型先就绪
- **跨部门协作**:作业横跨多部门,预算分配复杂
- **管理文化**:从"花钱思维"切换到"创造价值思维"
- **不可量化作业**:研发、品牌投入难以与作业量挂钩

### 在不同行业的形态

- **制造业**:加工作业、检验作业、设备调整作业
- **服务业**:客户咨询、订单处理、运维支持
- **金融业**:贷款审批、风控、客户开户
- **政府/非营利**:审批、监管、公共服务

### 与 ABM 的闭环

```
ABC(核算) → ABM(管理改进)→ ABB(预算)→ 执行 → 差异分析 → ABC 更新
```

形成 PDCA 循环,使 [[管理会计]] 真正"管理化"。
