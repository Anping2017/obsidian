# 商业模式创新

## 定义

**商业模式创新**(Business Model Innovation, BMI)指企业通过**重新设计创造价值、传递价值、捕获价值的方式**——而非仅推出新产品或新技术——实现差异化竞争优势的创新形式。它常常**比产品创新更难被复制**,因为涉及组织、合作、流程、激励、定价等多个互相依赖的子系统的同步重构,是数字时代竞争优势的关键来源。

## 核心要点

### 三大维度

- **价值创造**:为什么客户/合作方愿意参与?(产品、服务、体验、网络)
- **价值传递**:如何把价值送达客户?(渠道、关系、触点)
- **价值捕获**:如何从中赚钱?(收入模式、成本结构、护城河)

### 创新切入点(以 [[商业模式画布]] 为框架)

每一个模块都可成为创新点:
- **客户细分**:开拓被忽视的市场(新兴市场、小众群体)
- **[[价值主张]]**:重新定义"卖的是什么"
- **渠道**:数字直销、平台、社群
- **客户关系**:订阅、社区、共创
- **收入模式**:从产品到服务,从一次到订阅,从直接到广告/数据
- **关键资源**:数据、平台、生态
- **关键活动**:从制造到运营到匹配
- **关键合作**:开放生态、API 经济
- **成本结构**:固定→变动,资本密集→轻资产

### 经典案例

| 公司 | 创新维度 | 关键差异 |
|---|---|---|
| **吉列剃须刀** | 收入模式 | 刀架便宜、刀片重复购买("基地+耗材") |
| **苹果 iPod + iTunes** | 价值传递 | 把音乐从 CD 拆为单曲下载 |
| **Netflix** | 多次重构 | 邮寄租赁 → 流媒体 → 自制内容 |
| **Uber/Airbnb** | 平台模式 | 不拥有车/房,匹配供需 |
| **小米早期** | 渠道 + 粉丝 | 互联网直销 + 极致性价比 + 社群 |
| **SaaS 行业整体** | 收入模式 | 一次性 → 订阅 |
| **共享单车** | 资源所有 | 分布式 → 集中托管 |
| **Tesla** | 多重 | 直销、空中升级、能源生态 |

### 创新触发条件

- 技术变革打开新可能(互联网、移动、AI、区块链)
- 客户需求未被满足或重定义
- 竞争对手陷入既有模式刚性
- 监管变化(开放数据、能源政策)
- 经济环境(衰退中的"穷人创新")

### 实施挑战

- **认知障碍**:成功公司难想象抛弃赚钱模式
- **组织惯性**:既有部门、激励、流程都依赖旧模式
- **资源冲突**:新模式与旧模式互相蚕食(eg. iPhone 蚕食 iPod)
- **生态对齐**:供应商、渠道、合作伙伴需共同改变
- **客户教育**:新模式可能需要市场长期教育期

### 双轨策略

- **经营当下 + 探索明天**:O'Reilly 与 Tushman 的"Ambidextrous Organization"
- **设立独立单元**:小团队、独立预算、不同 KPI
- **逐步切换**:订阅化常用此法,逐步从永久授权转向订阅
