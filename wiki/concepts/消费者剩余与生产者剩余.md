# 消费者剩余与生产者剩余

## 定义

**消费者剩余(Consumer Surplus, CS)**:消费者愿意支付的最高价格与实际支付价格的差额之和。几何上等于需求曲线下方、市场价格线上方的面积。

**生产者剩余(Producer Surplus, PS)**:生产者实际获得的价格与愿意接受的最低价格(边际成本)的差额之和。几何上等于价格线下方、供给曲线上方的面积。

**总剩余 = CS + PS**,代表市场交易创造的总社会福利。

## 核心要点

### 数学表达

```
CS = ∫₀^Q* [P_d(Q) − P*] dQ
PS = ∫₀^Q* [P* − P_s(Q)] dQ
```

其中 P_d 为需求(逆)函数,P_s 为供给(逆)函数,Q* 为均衡数量。

### 福利变化的衡量

价格、数量变化通过 CS、PS 的变化量化福利效应:

- 价格上升:CS 减少、PS 增加
- 价格下降:CS 增加、PS 减少
- 需求增加:CS 通常增加(支付意愿提升)
- 供给增加:PS 通常增加(成本降低)

对于政策评估,关注 ΔCS + ΔPS 即可衡量净福利变化。

### 完全竞争均衡的福利最优

在完全竞争市场的 [[市场均衡]] 处,总剩余达最大,称为"市场效率"或 [[帕累托最优]]。任何偏离 —— 价格管制、税收、垄断、配额 —— 都会减少总剩余。

### 无谓损失

**无谓损失(Deadweight Loss, DWL)**:由于市场扭曲(税、补贴、价格管制、垄断)使总剩余低于最优水平的部分。它是消费者与生产者双方失去而无人获得的福利,衡量市场扭曲的效率成本。

经典例子:
- **税收无谓损失**:三角形面积 = ½ × 税额 × 数量减少;弹性越大,无谓损失越大(见 [[弹性理论]])
- **价格上限**(低于均衡):造成短缺与黑市,产生 DWL
- **价格下限**(高于均衡):造成过剩与库存,产生 DWL
- **垄断**:产量受限于 MR = MC < P 处,产生 DWL,见 [[垄断市场]]

### 应用领域

- **税收政策评估**:在弹性低的商品上征税效率损失最小(拉姆齐法则)
- **国际贸易福利**:进口可能减少 PS 但增加 CS,且 ΔCS + ΔPS > 0(见 [[国际贸易理论]])
- **垄断社会成本**:用 DWL 量化反垄断政策必要性
- **环境政策**:外部性导致的 DWL 通过庇古税内部化

## 和其他概念的关系

CS 与 PS 是 [[供给与需求]] 框架下的福利度量,与 [[市场均衡]]、[[弹性理论]] 共同构成微观福利分析三件套。它们将抽象的"市场效率"转化为可计算的面积,使政策的福利成本得以量化。

CS 与 [[消费者选择理论]] 中的等价变化(EV)、补偿变化(CV)概念相关 —— 后者是更精细的福利度量,但 CS 在大多数情形下是足够好的近似。PS 直接对应企业的"经济利润 + 固定成本"。

[[市场结构]] 比较中,完全竞争 → 垄断竞争 → 寡头 → 垄断,DWL 依次增大。[[政策分析]] 框架(尤其是国际贸易、税收、外部性)几乎全部以 CS+PS 变化为评估准绳。

跨域:[[行为金融学]] 与 [[行为经济学]] 指出,消费者支付意愿可能不稳定(参考点依赖),挑战 CS 测量;在金融市场中,流动性溢价、时间偏好对剩余的扭曲也是研究热点。
