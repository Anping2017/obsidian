# 门店经济模型

## 定义

门店经济模型(Store Unit Economics)是把单店运营从"经营感觉"升级为"财务模型"的量化工具,核心是把每月/每年的收入、毛利、固定成本、变动成本、人工、租金、回本周期压缩为单店可验证、可对比、可决策的指标体系。线下零售、餐饮、服务业、加盟连锁的投资决策、扩张速度、加盟体系设计都基于此模型。本概念是 [[零售门店运营]]、[[毛利结构]] 的财务建模视角延伸。

## 六大核心模块

### 1. 收入(Revenue)

- **客流量(Traffic)** × **进店率(Footprint%)** × **[[到店转化率]]**(Close%) × **客单价(AOV)**
- 月收入 = 日均成交单数 × 客单价 × 30
- 收入结构按品类拆分(主商品 / 高毛利配件 / 服务 / 增值)

### 2. 毛利(Gross Profit)

- 毛利 = 收入 - 销售成本(COGS)
- 毛利率 = 毛利 / 收入 × 100%
- 按品类拆分:手机零售 8-15%,配件 30-60%,服务 60-90%,二手回收 25-40%
- 综合毛利率 = Σ(品类收入 × 品类毛利率) / 总收入

### 3. 固定成本(Fixed Costs)

| 项目 | 占月销售比重(参考) |
|---|---|
| 房租 | 8-15% |
| 物业费/水电 | 1-2% |
| 装修摊销(5 年) | 1-3% |
| 设备摊销(3 年) | 0.5-1% |
| 系统/软件费 | 0.3-0.8% |
| 加盟费摊销 | 0.5-2% |
| 总部品牌费 | 1-3% |

### 4. 变动成本(Variable Costs)

- 销售提成
- 营销推广(美团、抖音、外引流)
- 电费(空调、设备)
- 包装、耗材
- 占月销售 5-15%

### 5. 人工(Labor)

- 店长 + 店员 × 数量
- 一线手机店典型:店长 8000-12000,店员 4500-7500
- 人工占月销售比 12-20%(零售业经验值)
- 包含社保、餐补、绩效

### 6. 利润(Profit)与回本周期

```
月净利 = 毛利 - 固定成本 - 变动成本 - 人工 - 税
回本周期 = 总投资 / 月净利
```

- 总投资 = 装修 + 进货首批 + 租金押金 + 设备 + 加盟费
- 健康门店:回本周期 12-24 月
- 良性扩张:回本周期 < 18 月
- 警戒线:回本周期 > 36 月

## 单店财务模型示例(中型城市中端手机店)

| 项目 | 月度金额 | 备注 |
|---|---|---|
| **收入** | 60 万 | 100 单/月,客单 6000 |
| **毛利** | 11.4 万 | 综合毛利率 19% |
| 房租 | 6 万 | 10% |
| 装修摊销 | 1.5 万 | |
| 人工(1+3) | 4 万 | |
| 营销推广 | 2 万 | 美团+抖音 |
| 其他固定 | 1.2 万 | 物业、水电、系统 |
| 销售提成 | 2.4 万 | 4% |
| **月净利** | **-5.7 万 / +5.7 万** | 视具体业态 |

(注:此为示意,实际受地段、品牌、规模影响巨大)

## 与坪效、人效的协同

- **[[坪效]]**:每平米月销售/月毛利,衡量空间利用效率
- **[[人效]]**:每员工月销售/月毛利,衡量人力效率
- 优秀门店:坪效 > 1500 元/月/平米,人效 > 15 万/月/人
- 门店经济模型把这两个比率融入完整 PnL

## 关键决策杠杆(按 ROI 排序)

1. **客流提升**:抖音/美团/小红书 引流是杠杆最大的变量
2. **[[到店转化率]] 提升**:店员训练、动线设计、首屏陈列
3. **客单价提升**:[[连带销售]] 训练、套餐设计
4. **毛利率提升**:配件加售、保险延保、二手业务
5. **房租谈判**:每年续约时谈,长期最大固定成本
6. **人效提升**:绩效设计 + 数字化工具
7. **库存周转**:库存压一万就是死钱

## 加盟体系应用

- 总部用门店经济模型论证"加盟可行"
- 给加盟商可信的"3 年回本"承诺需基于真实模型,而非营销宣传
- 模型提供加盟商:启动金、月毛利、回本周期三组数字
- 加盟商决策应抠模型每个假设:客流哪来?转化怎么算?房租为何这么低?

## 三大常见模型陷阱

### 1. 客流过度乐观

- 总部给的"日均 100 客流"是头部店,均值往往 60-70
- 实际新店开张前 6 月达不到稳态客流

### 2. 毛利率高估

- 总部宣传"30% 毛利"按混合算,实际加盟商主销低毛利商品
- 配件加售率达不到总部模型假设

### 3. 隐性成本忽略

- 加盟费摊销、系统费、装修首笔
- 员工流失招聘成本
- 节假日不开店损失

## 与其他概念的关系

- 与 [[零售门店运营]]:本概念是其财务建模视角
- 与 [[手机店LTV测算]]:LTV 是收入端的客户视角,门店模型是月度的现金流视角
- 与 [[毛利结构]]、[[坪效]]、[[人效]]:核心三角
- 与 [[CAC获客成本]]:获客投入计入营销变动成本
- 与 [[现金流量表]]:门店现金流模型映射
- 与 [[资本预算]]:门店投资是公司层资本预算决策
- 与 [[供应链管理]]、[[库存管理]]:库存压款影响现金流
- 与 [[门店选址]]:决定房租与客流两大关键参数
