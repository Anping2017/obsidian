# 字典树 Trie

## 定义

字典树(Trie),又称前缀树(Prefix Tree)或单词查找树,是一种**按字符逐层组织的多叉树**,每个节点代表一个字符,从根到任意节点的路径对应一个字符串前缀。具有相同前缀的字符串**共享路径**,这是它的核心优势。

「Trie」一词源于英文 Retrieval(检索),发音为 "tree" 或 "try"。

## 核心要点

### 基本结构

```python
class TrieNode:
    def __init__(self):
        self.children = {}  # char -> TrieNode
        self.is_end = False  # 标记此处是否为单词结尾

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self._find(word)
        return node is not None and node.is_end

    def starts_with(self, prefix):
        return self._find(prefix) is not None

    def _find(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node.children: return None
            node = node.children[ch]
        return node
```

### 时间复杂度

| 操作 | 复杂度(L = 字符串长度) |
|---|---|
| 插入 | O(L) |
| 查找 | O(L) |
| 前缀匹配 | O(L) |
| 删除 | O(L) |

时间与已存储字符串数量**无关**,只与目标字符串长度成正比,这是 Trie 相比 [[Hash表]] 的关键优势。

### 空间优化

朴素 Trie 内存开销可能很大(每个节点要存所有可能字符的指针)。优化方案:

- **压缩 Trie(Patricia / Radix Tree)**:合并只有一个子节点的链,显著节省空间
- **DAWG(有向无环字图)**:合并相同后缀,适合静态词典
- **双数组 Trie(Double-Array Trie)**:用两个数组紧凑存储,内存极小,日韩文输入法常用
- **HAT-Trie、Burst Trie**:混合 Trie 与哈希,平衡缓存友好与查询速度

### 应用场景

| 场景 | 用法 |
|---|---|
| 自动补全 | 输入前缀,DFS 遍历 Trie 收集候选 |
| 敏感词过滤 | AC 自动机(Trie + KMP) |
| 拼写纠错 | 计算编辑距离,在 Trie 上剪枝 |
| IP 路由表 | 二进制 Trie(LPM 最长前缀匹配) |
| 词典压缩 | DAWG 合并后缀 |
| 字符串排序 | 中序遍历 Trie 输出有序字符串 |
| 异或最大值 | 二进制 Trie + 贪心 |

### 与其他数据结构对比

| 维度 | Trie | Hash表 | 平衡 BST |
|---|---|---|---|
| 单字符串查找 | O(L) | O(L) 平均 | O(L log n) |
| 前缀查询 | 高效 O(L) | 不支持 | 不支持 |
| 字符串排序 | 自然有序 | 无序 | 有序但 O(n log n) |
| 内存 | 较大(共享前缀可摊薄) | 中等 | 中等 |

## 和其他概念的关系

字典树属于 [[树]] 的特化变体,与 [[二叉搜索树]]、[[Hash表]] 共同覆盖了「快速查找」的不同维度——BST 适合数值有序,Hash 适合等值,Trie 适合字符串前缀。

[[字符串匹配]] 中的 AC 自动机就是 Trie + 失败指针,实现多模式串匹配 O(n + m),是文本过滤、IDS、生信序列比对的核心算法。

[[搜索引擎优化|搜索引擎]]、[[数据库]] 索引(尤其全文索引)中常见 Trie 衍生结构;Lucene 的 FST(有限状态转换器)是 DAWG 的高度优化版。

[[操作系统]] 的虚拟内存页表本质是基数 Trie(Radix Tree);Linux 内核 IP 路由表用 Trie 加速最长前缀匹配。
