# 完全竞争市场

## 定义

**完全竞争市场(Perfectly Competitive Market)**:满足以下五项严格条件的理想市场结构:

1. **大量买者卖者** —— 任何单一参与者都无法影响市场价格
2. **产品同质** —— 不同卖家产品完全可替代,无差异化
3. **完全信息** —— 所有参与者拥有完整、对称的信息
4. **自由进出** —— 无进入退出壁垒,无沉没成本
5. **价格接受者(price taker)** —— 企业必须按市场决定的价格销售

农产品现货市场、外汇即期交易、部分大宗商品市场近似具备这些特征。

## 核心要点

### 企业的需求与收益

由于产品同质且企业是价格接受者:

- **企业需求曲线**:在市场价格 P* 处水平,弹性无穷
- **TR = P*·Q,AR = P*,MR = P***
- 三者重合于水平直线

这与 [[垄断市场]] 形成根本对比 —— 那里 MR < P。

### 短期均衡

利润最大化:**P = MR = MC**(且 MC 上升段)

短期可能出现三种情形:

| 价格关系 | 结果 |
|---|---|
| P > ATC | 经济利润 > 0(超额利润) |
| P = ATC | 正常利润(零经济利润) |
| AVC ≤ P < ATC | 短期亏损但仍生产(覆盖可变成本) |
| P < AVC | 关闭(stop production) |

### 长期均衡

自由进出导致经济利润必然趋零:

- 短期超额利润 → 新企业进入 → 市场供给右移 → 价格下降 → 利润减少
- 短期亏损 → 企业退出 → 供给左移 → 价格上升 → 亏损消除

最终长期均衡条件:

```
P = MR = MC = ATC = LAC_min
```

意义:每家企业在 LAC 最低点生产,实现**生产效率**;价格等于边际成本,实现**配置效率**。

### 福利性质:帕累托最优

完全竞争长期均衡下:
- [[消费者剩余与生产者剩余]] 之和达最大
- 无 [[消费者剩余与生产者剩余#无谓损失]]
- 资源配置满足 [[帕累托最优]]
- 这是"看不见的手"定理(亚当·斯密)的现代严格表述,也称**福利经济学第一定理**

### 现实偏离:市场失灵

完全竞争是理论基准,实际市场常因下列因素偏离:
- **外部性**(环境污染、教育外溢)
- **公共品**(国防、灯塔)
- **信息不对称**(逆向选择、道德风险)
- **市场势力**(规模经济、品牌、专利)

这些偏离是 [[金融监管体系]] 与产业政策干预的理论依据,详见 [[市场结构]]。

## 和其他概念的关系

完全竞争是 [[市场结构]] 谱系的极端基准点,与 [[垄断市场]] 构成两端,中间为 [[垄断竞争]]、[[寡头垄断]]。各种偏离的福利损失都以完全竞争为参照系测量。

它把 [[供给与需求]] 简化到极致 —— 企业完全融入市场供给曲线,个体决策仅为选择产量。MC 曲线(超过 AVC 部分)即为企业供给曲线。

完全竞争结论严重依赖 [[消费者选择理论]] 与 [[生产者理论]] 的标准假设。一旦放松(如 [[行为经济学]] 引入有限理性、信息不对称引入道德风险),福利结论需重新评估。

跨域:[[金融市场概述]] 中流动性极高的二级市场(如外汇、国债)接近完全竞争;[[资产定价模型]] 中 CAPM、APT 都假设市场无套利、所有信息已被定价,本质是金融版的完全竞争;[[投资组合理论]] 中"价格接受者"假设也来自这一传统。

完全竞争还是 [[国际贸易理论]] 中比较优势模型的标准前提,放松后产生新贸易理论(规模经济、产品差异化驱动的贸易)。
