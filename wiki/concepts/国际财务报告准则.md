# 国际财务报告准则

## 定义

**国际财务报告准则**(International Financial Reporting Standards, IFRS)由位于伦敦的**国际会计准则理事会(IASB)**于 2001 年起制定与发布,是全球应用最广泛的会计准则体系——目前在 **140+ 个国家与地区**强制或允许使用,涵盖欧盟、英国、加拿大、澳洲、日本(允许)、新兴市场绝大多数国家。它与美国 **US GAAP** 是当今全球两大主流准则体系,也是 [[会计学]] 领域最重要的国际化产物。

## 核心要点

### 历史演变

- **1973 年**:国际会计准则委员会(IASC)成立,发布 IAS(国际会计准则)
- **2001 年**:IASB 取代 IASC,重新组织,新发准则称 IFRS
- **2005 年**:欧盟强制上市公司用 IFRS,标志全球化跨越
- **2018 年起**:中国新准则(CAS)与 IFRS 实质性趋同
- **持续演进**:与 US GAAP 长期趋同,但 SEC 仍要求美国本土公司用 GAAP

### 与 US GAAP 的核心区别

| 维度 | IFRS | US GAAP |
|---|---|---|
| **导向** | 原则导向 | 规则导向 |
| **页数** | 较薄 | 极厚(数千页细则) |
| **存货** | 不允许 LIFO | 允许 LIFO |
| **研发** | 满足条件可资本化 | 一般费用化 |
| **资产重估** | 允许公允价值上调 | 一般不允许 |
| **现金流量表 利息** | 经营/投资可选 | 一般经营 |
| **报表样式** | 流动性顺序灵活 | 流动性顺序固定 |
| **合并范围** | 控制概念 | 表决权过半 |

### 主要 IFRS 准则

| 准则号 | 名称 | 核心 |
|---|---|---|
| **IFRS 1** | 首次采用 | 转换指引 |
| **IFRS 3** | 企业合并 | 购买法,商誉确认 |
| **IFRS 9** | 金融工具 | ECL 模型 + 公允价值分类 |
| **IFRS 10** | 合并财务报表 | 控制概念三要素 |
| **IFRS 13** | 公允价值计量 | 三层级、估值技术 |
| **IFRS 15** | [[收入确认]] | 五步法 |
| **IFRS 16** | 租赁 | 承租人表上化 |
| **IFRS 17** | 保险合同 | GMM/PAA 模型 |
| **IFRS 18** | 财务报表列报 | 2027 生效,新分类 |
| **IFRS S1/S2** | 可持续披露 | 新发,ESG 披露 |
| **IAS 1** | 财务报表列报 | 报表基本要求 |
| **IAS 2** | 存货 | 计量与流转 |
| **IAS 16** | 不动产、厂房与设备 | 折旧、重估 |
| **IAS 36** | 资产减值 | 可收回金额 |
| **IAS 38** | 无形资产 | 内部研发分阶段 |

### IFRS 概念框架

2018 年版,核心结构:
- **目标**:为现有/潜在投资者、贷款人、债权人提供决策有用信息
- **质量特征**:
  - 基本:相关性、忠实表述
  - 增强:可比性、可验证性、及时性、可理解性
- **要素**:资产、负债、所有者权益、收入、费用
- **确认**:可能性 + 可靠计量
- **计量**:历史成本、当前成本、公允价值、使用价值

### 公允价值层级(IFRS 13)

- **层级 1**:活跃市场报价(最可靠)
- **层级 2**:可观测的可比交易
- **层级 3**:不可观测输入(估值,主观)

层级 3 资产风险大,披露要求严格。

### 主要影响

**对企业**:
- 跨境融资便利(国际投资者使用同一语言)
- 编报成本(尤其首次采用)
- 信息系统改造
- 税务影响(IFRS 利润 ≠ 税基)

**对投资者**:
- 跨境可比性提升
- 公允价值波动可能放大利润波动
- 估值灵活性带来的不可比

**对监管**:
- 减少各国为不同准则单独维护
- 但许可监管仍需对接本地

### 现代议题

- **可持续披露(IFRS S1/S2)**:2023 发布,与气候和 ESG 相关
- **加密资产计量**:仍在持续演变
- **IFRS 与 GAAP 趋同停滞**:2014 后趋同努力放缓
- **新兴市场采用**:小企业 IFRS、IFRS for SMEs
- **审计与 IFRS**:[[审计]] 框架同步演进

### 中国采用情况

- 2006 年发布与 IFRS 趋同的新企业会计准则(CAS)
- 上市公司必须采用 CAS
- A+H 股有时同时编 IFRS 报表
- 香港直接用 HKFRS(等同 IFRS)
- 实务上 IFRS 与 CAS 仍有少数差异(如政府补助、合并范围)

### 主要批评

- **公允价值在危机中放大波动**(2008 反思)
- **原则导向太宽,操纵空间大**
- **复杂度增加**(IFRS 17 保险准则就 100+ 页)
- **小企业负担重**
- **趋同进展缓慢**

## 和其他概念的关系

IFRS 是 [[会计学]] 全球化的核心制度产物,直接影响 [[资产负债表]]、[[利润表]]、[[现金流量表]] 的具体编制。它通过 IFRS 9 重塑 [[金融工具]] 会计、IFRS 15 重塑 [[收入确认]]、IFRS 16 重塑租赁会计。它支撑 [[财务报表分析]] 的跨国可比性。它与 [[审计]]、[[内部控制]] 制度紧密相连。它对 [[历史成本]] 与公允价值的混合计量做出系统化安排。其新发可持续准则(S1/S2)与 [[ESG]] 议题深度交叉。
