# 九型人格

## 定义

九型人格(Enneagram)是把人按九种基本动机模式分类的人格框架。"Ennea"希腊语"九","gram"是"图形"。它源于苏菲伊斯兰、东正教沙漠教父等灵性传统,20 世纪由格奥尔基·伊万诺维奇·古吉夫(Gurdjieff)、奥斯卡·伊查佐(Oscar Ichazo)、克劳迪奥·纳兰霍(Claudio Naranjo)现代化,1980 年代被 Don Riso 与 Russ Hudson 系统化为商业畅销人格类型。

学术心理学界对其效度存疑,但在自我成长、咨询、领导力、关系实务中广泛应用。

## 九种类型

| 编号 | 名称 | 核心动机 | 核心恐惧 |
|---|---|---|---|
| **1** | 完美主义者(改革者) | 想要正确、好、完美 | 害怕错误、被批评 |
| **2** | 助人者(给予者) | 想被爱、被需要 | 害怕不被爱 |
| **3** | 成就者(实干家) | 想成功、被欣赏 | 害怕无价值 |
| **4** | 个性者(浪漫者) | 想找到独特身份 | 害怕平庸、缺失 |
| **5** | 观察者(研究者) | 想理解、独立 | 害怕无能、被侵入 |
| **6** | 忠诚者(怀疑者) | 想安全、有支持 | 害怕被遗弃、危险 |
| **7** | 享乐者(冒险家) | 想避免痛苦、获快乐 | 害怕被困、痛苦 |
| **8** | 挑战者(领袖) | 想强大、自主 | 害怕被控制 |
| **9** | 和平者(协调者) | 想内外和平 | 害怕冲突、分离 |

## 三大中心

九型分为三组:

| 中心 | 类型 | 主导反应 | 核心情绪 |
|---|---|---|---|
| **直觉/本能**(Gut) | 8、9、1 | 行动、控制 | 愤怒 |
| **情感/心**(Heart) | 2、3、4 | 形象、关系 | 羞耻 |
| **思维/头**(Head) | 5、6、7 | 思考、应对 | 恐惧 |

每个中心有"压抑"(retreated)与"反向"(externalized)处理情绪的不同模式。

## 子结构

### 翼(Wings)
- 每型受相邻型号影响(如 5w4 vs 5w6)
- 同型有不同表现

### 整合与解离方向
- 健康时向整合点移动(如 1 → 7)
- 压力时向解离点移动(如 1 → 4)
- 提供成长地图

### 健康水平(Riso-Hudson)
- 9 个层次:1-3 健康、4-6 平均、7-9 不健康
- 强调动态变化

### 子类型(Instincts)
- 自我保护(Self-Preservation, sp)
- 性/亲密(Sexual / One-to-One, sx)
- 社交(Social, so)
- 27 = 9 × 3 个子类型

## 应用领域

### 自我成长
- 识别核心动机与恐惧
- 看到自动化模式
- 整合阴影
- 灵性发展

### 关系
- 理解配偶、朋友、家人
- 减少误解
- 提升沟通

### 领导力
- 识别领导风格
- 团队多元
- 盲点觉察

### 咨询与教练
- 工具化诊断
- 客户化路径
- 整合心理治疗

### 职业发展
- 适配岗位
- 团队组合
- 传统应用

### 教育
- 教师自我觉察
- 学生差异

### 商业
- 销售心理
- 客户细分(谨慎)
- 谈判风格

## 与其他人格模型对比

| 模型 | 特点 |
|---|---|
| **九型** | 动机驱动、灵性传统 |
| **MBTI** | 偏好类型、Jung 起源 |
| **大五人格** | 描述性、学术 |
| **HEXACO** | 大六、加诚实-谦逊 |
| **DISC** | 行为风格、商业 |
| **VIA 性格优势** | 美德、积极心理学 |

九型独特在于关注**为什么**(动机)而非"什么"(行为)。

## 主要测量

- **RHETI**(Riso-Hudson Enneagram Type Indicator):144 题
- **IEQ9**:免费在线
- **WEPSS**(Wagner Enneagram Personality Style Scales)
- 自评偏差严重,推荐结合自反思与他评

## 学术争议

### 支持
- 跨文化稳定的描述
- 整合动机、情绪、行为
- 重视成长动态
- 实务效果

### 批评
- 缺乏严格因子分析支持
- 信效度研究有限
- 类型理论本身科学化弱(类似 MBTI 批评)
- "Forer 效应"(模糊描述都觉得对)
- 起源神秘主义而非心理学

## 与其他概念关系

- 与 [[大五人格]] 学术上更稳但九型更深入动机
- 与 [[MBTI]] 都是类型论(争议)

- 与 [[精神分析]] 深层动机相通

- 与 [[依恋理论]] 早期模式
- 与 [[认知行为疗法]] 模式识别

- 与 [[团队建设]] 多元理解
- 与 [[斯多葛主义]]、[[佛家]] 自我观察传统部分共鸣
- 与 [[正念]] 自我觉察工具

## 实务建议

- 测试只是起点,不是终点
- 类型不是宿命,是模式
- 关注动机而非行为
- 整合阴影,不只发挥优势
- 别把人简化为编号
- 文化敏感(西方个人主义偏好)

## 当代发展

- Don Riso、Russ Hudson 著作普及
- Christopher Heuertz 灵性整合
- Beatrice Chestnut 子类型研究
- 数字平台(Truity、9Types)
