# 手机店人货场

## 定义

人货场(People-Product-Place)是 2017 年阿里巴巴在新零售战略中系统化推广并被零售业广泛采用的零售三要素分析框架,以"重构人货场"作为零售业升级的核心命题。在手机店业态中:**人**指目标顾客与一线员工、**货**指销售商品组合(主机+配件+服务)、**场**指实体店物理场景与线上线下融合的全场景。三要素协同决定门店运营效率、顾客体验与最终利润,是 [[零售门店运营]]、[[门店经济模型]] 的实操骨架。

## 三要素详解(手机店视角)

### 人(People)

#### 顾客侧

- **客户分层**:刚需更换 / 商务高端 / 数码爱好者 / 父母老人 / 学生
- **决策旅程**:线上种草 → 线下体验 → 比价 → 决策 → 售后
- **购买动机**:刚需 / 升级 / 礼物 / 商务 / 工作工具
- **客单价分布**:1500 元以下 / 1500-3500 / 3500-6000 / 6000+
- **复购周期**:2.5-3.5 年(整体平均)

#### 员工侧

- **店长**:经营、管控、人员、采购
- **销售员**:接待、转化、连带销售、售后
- **维修师傅**:增值服务、技术权威、客户信任
- **员工激励**:基薪 + 销售提成 + 配件提成 + 服务提成
- **培训体系**:产品知识 / 销售技能 / 服务规范

### 货(Product)

#### 商品结构(典型综合店)

| 品类 | 销售占比 | 毛利占比 |
|---|---|---|
| 主机(手机) | 60-70% | 25-35% |
| 配件(壳膜耳机数据线) | 10-15% | 25-35% |
| 服务(贴膜维修保险) | 5-10% | 20-30% |
| 二手回收差价 | 5-10% | 10-15% |
| 增值服务(套餐分成) | 3-5% | 5-10% |

#### 商品策略

- **流量品**:头部品牌(苹果/华为)吸引客流,毛利薄
- **利润品**:配件、保险、维修服务,毛利厚
- **形象品**:旗舰机型陈列、品牌墙面,提升店铺档次
- **特价品**:清库存、引流促销
- **新品**:首发节点抢曝光与社交话题

#### 库存管理

- 详见 [[库存管理]]
- ABC 分类:A 类(20% SKU 80% 销售)重点保障
- 周转率目标:整体 30-45 天,配件 60-90 天
- 滞销预警:90 天未动 → 降价 / 退货 / 退仓

### 场(Place)

#### 物理店

- **选址**:详见 [[门店选址]],客流、可见性、商圈
- **店面陈列**:主推机型主灯位、配件腰间陈列、形象墙
- **动线设计**:进店-体验区-收银-售后,动线流畅
- **声光氛围**:展机通电、灯光突出、店员着装统一
- **服务体验**:WiFi、座椅、冷热水、儿童区
- **数据基础设施**:POS、客流统计、热力图、Wi-Fi 探针

#### 线上场景

- **内容渠道**:抖音、小红书、视频号(详见 [[抖音算法分发]])
- **电商渠道**:店铺(美团 / 大众点评 / 抖音橱窗)
- **私域渠道**:微信群 / 公众号 / 企业微信
- **数据分析**:每个渠道的进店、咨询、转化、复购

#### 线上线下融合

- **看店进店**:抖音种草 → 美团预约 → 进店核销
- **进店转化**:店内试机 → 私信下单 → 当日提货
- **售后引流**:售后服务 → 加微信 → 进群 → 复购

## 三要素协同案例

### 案例 1:商务高端机型(华为 Mate 60 系列)

- **人**:35-50 岁商务客 + 同行业老板带新客
- **货**:旗舰机 + 商务配件包(车充、皮套、保险)
- **场**:商业区门店,陈列高端,VIP 包间式洽谈区,线上私域社群

### 案例 2:学生入门机(红米/iPhone SE)

- **人**:18-22 岁学生,价格敏感,社交决策
- **货**:中端机 + 学生套餐(碎屏险、长保)+ 社交配件(壳膜个性化)
- **场**:大学城店 + 抖音直播切片 + 美团团购 + 学生群

### 案例 3:中老年用户

- **人**:55+,需要"教用机"服务
- **货**:大屏机 + 助听耳机 + 防摔壳 + 定期回访服务
- **场**:社区店 + 老年群 + 子女介绍

## 数字化升级(新零售范式)

| 维度 | 传统模式 | 新零售模式 |
|---|---|---|
| 人 | 线下进店为主 | 线上线下融合,全渠道 |
| 货 | 单一线下库存 | 全渠道一盘货,跨店共享 |
| 场 | 物理门店为主 | 物理 + 直播 + 私域 + 电商 |
