# 确认偏差

## 定义

**确认偏差**(Confirmation Bias)指人**优先寻找、解释和记忆支持自己既有信念的信息**,同时忽视或贬低相反证据。它是 [[认知偏差]] 中最普遍、最隐蔽的一种,广泛影响投资决策、政治判断、医学诊断、人际关系。

## 核心要点

### 四种表现形式

| 类型 | 描述 |
|---|---|
| **选择性搜索** | 只在支持自己观点的来源里找证据 |
| **选择性注意** | 同一信息中只关注支持的细节 |
| **选择性解释** | 把模糊证据按自己倾向解读 |
| **选择性记忆** | 更易记住支持的事例,忘记反例 |

### 经典实验

- **沃森选择任务(Wason 1960)**:被试给规则"2-4-6 是按某规律",测试时大多举支持例子,而非反例 → 发现真规律的能力大幅下降
- **政治极化研究**:同一事实给不同立场者,反而会强化各自原立场(逆火效应)

### 为什么如此普遍

1. **认知节能**:确认信念比修订信念省脑
2. **自我一致**:信念是身份,反证威胁自尊
3. **社会身份**:与同温层一致带来归属感
4. **进化遗产**:在小群体中,共识比真理更重要

### 在投资与决策中

- 投资者:买入后只读支持持仓的研报,亏损不止损
- 创业者:把 critic 当噪音,只听用户中的好评
- 医生:初步诊断后只检测支持该诊断的证据(锚定 + 确认共同作用)
- 招聘者:面试中只问能验证第一印象的问题

### 与其他偏差的协同

- + [[锚定效应]]:第一印象固化为锚点,后续验证它
- + [[首因效应]]:开头的信息形成基调,后续被再确认
- + 沉没成本:为已投入辩护,寻找继续投入的理由

### 解药

1. **主动证伪**:专门设计"如果我错了,会看到什么证据"的检验
2. **预承诺反方观点**:写下事先愿意改变想法的条件(克尔曼 disconfirming)
3. **红队思维**:让某人专职扮演反方
4. **双盲、随机化**:在科研与产品决策中制度性消除偏差
5. **跨视角对话**:邀请异见者实质性参与决策
6. **延迟结论**:在搜集到反证之前不下定论

### 与科学方法

- 波普尔:科学的标志是**可证伪**,不是寻找证实
- "好理论拒绝大量经验,坏理论解释一切"
- 制度化的同行评议、复制实验是为对抗确认偏差而设
