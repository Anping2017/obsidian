# 质量管理

## 定义

**质量管理**(Quality Management)是通过制定质量方针、目标、责任,并通过质量策划、控制、保证与改进等活动实现这些目标的一系列管理职能。它的最终目标是**让产品/服务持续满足客户需求**,从而提升竞争力。

朱兰(Joseph Juran)定义质量为"**适用性**"(Fitness for Use),戴明(Edwards Deming)强调"**减少变异**",克劳斯比(Philip Crosby)主张"**零缺陷**",石川馨(Kaoru Ishikawa)推动**全员参与**。这些先驱共同奠定了现代质量管理。

## 核心要点

### 历史演进

| 阶段 | 时期 | 特征 |
|---|---|---|
| 质量检验 | 1900-1940 | 事后把关,挑出次品 |
| 统计质量控制 SQC | 1940-1960 | 引入统计抽样、控制图 |
| 全面质量控制 TQC | 1960-1980 | 全员参与,日本崛起 |
| 全面质量管理 TQM | 1980-2000 | 战略层面,文化转型 |
| 六西格玛 | 1986- | 数据驱动,严格 DMAIC |
| 精益六西格玛 | 2000- | 精益 + 六西格玛融合 |

### 戴明 14 点管理原则

[[爱德华兹·戴明]] 在《转危为安》(*Out of the Crisis*)中提出的 14 项要点,核心包括:

- 创造恒久不变的目标
- 采纳新哲学
- 停止依赖大批量检验
- 不再以最低价采购
- 持续改进每一个过程
- 推行教育培训
- 摒弃恐惧
- 打破部门壁垒
- 取消计件工资
- 做好计划与执行的分离

戴明的思想直接启发日本制造业崛起,尤其丰田生产方式(TPS,参见 [[精益生产]])。

### PDCA 循环(戴明环)

```
   计划 (Plan) → 执行 (Do) → 检查 (Check) → 处理 (Act)
        ↑________________________________________↓
                    持续循环
```

是质量管理与持续改进的元方法论。后扩展为 PDSA(Study)。

### 七大质量工具(石川七工具)

老 7 工具(数据分析):

1. 检查表
2. 直方图
3. 帕累托图(80/20)
4. 因果图(鱼骨图,石川图)
5. 散点图
6. 控制图
7. 流程图

新 7 工具(管理与计划):亲和图、关联图、系统图、矩阵图、矩阵数据分析、过程决策程序图、箭头图。

### 六西格玛(Six Sigma)

由摩托罗拉 1986 年提出,目标:**每百万机会缺陷数 ≤ 3.4(6σ 水平)**。

核心方法:**DMAIC**(改进现有流程):

- **D**efine 定义问题
- **M**easure 测量基线
- **A**nalyze 分析根因
- **I**mprove 改进
- **C**ontrol 控制保持

变体 **DMADV** 用于设计新流程。

组织角色:**绿带、黑带、黑带大师、倡议者**(Champion)。

### ISO 9000 系列

国际标准化组织发布的质量管理体系标准:

- ISO 9001:质量管理体系要求,可认证
- ISO 9004:绩效改进指南
- 行业版本:汽车 IATF 16949、医疗 ISO 13485

七项质量管理原则:

1. 以顾客为关注焦点
2. 领导作用
3. 全员积极参与
4. 过程方法
5. 改进
6. 循证决策
7. 关系管理

### 全面质量管理(TQM)

把质量从"生产部门"扩展到全公司:

- **顾客导向**:内外部顾客
- **持续改善**(Kaizen)
- **全员参与**
- **基于事实的决策**
- **过程导向**

### 质量成本

费根鲍姆(Armand Feigenbaum)把质量成本分为:

- **预防成本**:培训、设计审查、过程优化
- **鉴定成本**:检验、测试
- **内部失效成本**:返工、报废
- **外部失效成本**:客户投诉、保修、召回、声誉损失

经验法则:**预防成本投入 1 元,可节省 10 元失效成本**。

### 现代质量管理趋势

- **从产品到体验**:服务业、数字产品的质量
- **数字化质量**:实时数据、AI 视觉检测
- **可持续性整合**:把环境质量纳入(参见 [[ESG]])
- **与精益融合**:精益六西格玛
- **质量 4.0**:工业 4.0 时代的质量管理

## 和其他概念的关系

- 是 [[运营管理]] 的核心领域
- 与 [[精益生产]] 共同构成现代制造管理双支柱
- 戴明 PDCA 是 [[变革管理]] 与 [[管理决策]] 的元方法
- 在 [[供应链管理]] 中延伸为供应商质量保证
- ISO 标准是 [[公司治理结构]] 与合规体系的一部分
- 与 [[平衡计分卡]] 内部流程维度直接对接
- [[组织文化]] 中"质量文化"是 TQM 的灵魂
- [[领导力]] 中戴明强调高层承诺,与 [[变革型领导]] 共鸣
- [[管理会计]] 中质量成本核算
- 在 [[企业价值评估]] 中,质量声誉作为无形资产影响品牌价值
