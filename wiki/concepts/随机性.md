# 随机性

## 定义

**随机性**(Randomness)指**没有可预测模式、不能由前因充分决定**的现象。它不是"我们还没找到规律",而是某些过程本质上不可被精确预测——量子涨落是物理意义上的随机;在宏观世界,因变量太多导致**实际不可预测**的事件也常被当作随机处理。

随机性最反直觉的一点是:**人脑对识别它非常糟糕**。我们在云朵里看到脸,在涨跌图里看到趋势,在三连胜里看到天才,即使这些只是噪声起伏。

## 核心要点

### 真随机的特征

- **不可预测**:即使你知道全部历史,也不能精确预测下一个
- **长期可统计**:单次不可测,但大量样本表现出稳定分布
- **无记忆**:很多随机过程(抛硬币、辐射衰变)与历史无关
- **聚集错觉**:真随机其实经常出现"连续相同"的小簇,人却觉得"不随机"

### 人类感知随机的偏差

| 偏差 | 表现 |
|---|---|
| **故事错觉** | 给随机事件硬套因果叙事 |
| **赌徒谬误** | 连续 5 次正面 → 觉得反面"该来了"(其实概率不变) |
| **热手谬误** | 球员连续命中就觉得状态来了,常被数据驳回 |
| **集群错觉** | 把随机分布的"小簇"解读为有规律 |
| **自我归因偏差** | 赢了归因于能力,输了归因于运气 |

### 运气 vs 能力

许多领域(投资、创业、体育、写作)结果都是**能力 + 运气**的混合:

- **能力主导**:网球、围棋、考试 —— 长期与短期强相关
- **运气主导**:短期股市、彩票、扑克单局 —— 短期与能力几乎不相关
- **混合**:大部分商业决策属于此类,需要长样本与多次重复才能区分

判断一个人或一家公司"是不是真厉害",首先要看其所在领域**运气占比有多大**。

### 反脆弱与随机

- 在以随机性为主的领域,**减少暴露于灾难性下行 + 保留对正向意外的暴露** 才是稳健策略
- 不试图预测下一个随机事件,而是设计对随机不敏感的系统:留余量、多元化、可逆性

### 数学化表达

- **概率分布**描述随机变量的可能取值与频率
- **大数定律**保证大样本均值收敛
- **中心极限定理**:许多独立小因素相加会逼近正态分布
- **分形与厚尾**:有些领域分布并非正态,极端事件比直觉以为的常见得多

## 应用场景

- **投资**:把短期波动当随机,长期看公司本质,而非每天对账户余额下结论
- **创业**:接受成功包含巨大运气成分;同领域复制别人套路常因忽略随机条件而失败
- **绩效评估**:对运气占比高的角色(销售、基金经理),用长周期、跨周期、相对基准比较
- **个人决策**:不在 1~2 次坏结果后大幅改变策略;长期复利来自反复在期望值正向的位置上下注
- **预测与规划**:从"我能预测明年"转向"我准备好应对多种可能"
- **文化叙事**:警惕"成功学"把幸存者的随机好运包装成可复制公式

## 局限与陷阱

- **过度归因为随机**:把一切都说"运气",会让人不愿改进真正可控的部分
- **躺平借口**:用"反正都是运气"逃避学习与训练
- **数学化误用**:把高度复杂、非独立的现实强行套正态分布(2008 年金融危机的部分根源)
- **样本太小**:在小样本里 declarations of "随机"和"非随机"都可疑

## 与其他概念的关系

- 与 [[概率思维]] 同源 —— 概率思维是处理随机性的基本姿态
- 与 [[概率论与统计学]] 关联 —— 提供建模随机性的数学语言
- 与 [[样本量]] 配合 —— 小样本里随机噪声主导,大样本里规律才显现
- 与 [[回归均值]] 协同 —— 极端值往往是随机的,会回归均值
- 与 [[可得性启发]] 对治 —— 鲜活的随机巧合容易被记成"规律"
- 与 [[确认偏差]] 对治 —— 我们倾向只记得"灵验"的预测
- 与 [[第一性原理]] 互补 —— 第一性原理给出确定性的根基;随机性提醒在确定根基之上还有不可消除的噪声
- 与 [[二阶思维]] 同用 —— 二阶推演要包含"如果这次只是随机,我会怎样反应"
- 与 [[反向思考]] 联动 —— 反过来问"如果完全是运气,我现在的策略会怎样表现"
- 在 [[战略思维]] 中作为冗余、备份、容错设计的依据
