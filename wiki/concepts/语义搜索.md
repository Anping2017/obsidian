# 语义搜索

## 定义

**语义搜索**(Semantic Search)是基于**语义理解**而非**字符串匹配**的检索方式。它通过自然语言处理与机器学习模型,把查询(query)与文档映射到共享的语义空间,根据**含义相近**而非"是否包含同样字"返回结果。

它的两条技术路线:
1. **知识图谱路线**:用实体—关系—事实的结构化网络回答(代表 [[Google知识图谱]])
2. **向量路线**:用 [[Embedding]] 把文本投到稠密向量空间,用近邻算法找相似(代表 [[向量数据库]])

现代搜索(Google、Bing、企业 RAG)都是两路融合。

## 核心要点

### 历史演进

| 阶段 | 时间 | 代表 |
|---|---|---|
| **关键词匹配** | 1995-2010 | TF-IDF、BM25 |
| **早期语义** | 2010-2013 | Hummingbird,见 [[Hummingbird算法]] |
| **机器学习排名** | 2015 | [[RankBrain]] |
| **预训练语言模型** | 2018-2019 | [[BERT语义搜索算法]] 用于 Google 搜索 |
| **多任务统一** | 2021 | [[MUM多任务统一模型]] 跨语言跨模态 |
| **生成式答案** | 2023+ | [[AI Overviews]] 直接生成综合回答 |
| **企业 RAG** | 2023+ | [[RAG]] + [[向量数据库]] + LLM 结合 |

### 核心技术

- **嵌入模型(Embedding)**:Word2Vec → BERT → OpenAI text-embedding → BGE/E5
- **向量数据库**:Pinecone、Weaviate、Milvus、pgvector,见 [[向量数据库]]
- **重排序(Rerank)**:Cross-encoder 在 top-K 上精排
- **混合检索**:稠密向量 + 稀疏关键词(BM25)+ 知识图谱
- **查询扩展**:同义词、相关问题、改写
- **意图分类**:导航 / 信息 / 交易 / 本地

### 与关键词搜索的对比

| 维度 | 关键词搜索 | 语义搜索 |
|---|---|---|
| 匹配 | 字面字符串 | 含义/向量距离 |
| 同义词 | 需手工同义词表 | 自动捕捉 |
| 长查询 | 越长越差 | 越长越好 |
| 跨语言 | 难 | 嵌入对齐即可 |
| 实体识别 | 弱 | 与 KG 协同识别 |
| 资源消耗 | 低 | 高(GPU) |

### 在 SEO 与营销的影响

- 关键词堆砌彻底失效 → 见 [[Helpful Content Update]]
- [[搜索意图]] 成为内容设计核心
- [[Topical Authority主题权威]] 比单点关键词更重要
- 实体优化 + [[Schema markup]] + [[Google知识图谱]] 入图
- AI 时代衍生 GEO(Generative Engine Optimization)新学科

### 在企业内的应用

- **[[RAG]] 系统**:语义搜索是 RAG 检索环节
- **客服知识库**:用户口语化查询→语义匹配 FAQ
- **代码搜索**:GitHub Copilot、Sourcegraph
- **文档智能**:法律、医学、专利的语义检索
- **推荐系统**:用户—物品双塔嵌入

## 应用场景

- **Web 搜索**:Google、Bing、百度
- **电商**:淘宝、亚马逊的"看了又看"
- **企业知识库**:Notion AI、Glean、Coveo
- **垂直应用**:法律 ROSS、医学 IBM Watson Health
- **多模态**:文搜图、图搜图,见 [[CLIP]]、[[多模态AI]]

## 局限与陷阱

| 局限 | 描述 |
|---|---|
| **黑盒性** | 为什么这条排第一,难解释 |
| **嵌入偏见** | 训练语料偏见会传到检索结果 |
| **稀有词召回差** | 罕见名词可能被语义"匀掉" |
| **延迟与成本** | GPU 推理比 BM25 贵几个量级 |
| **新词新事件** | 模型未见过的最新事实需要 RAG 补 |

## 与其他概念的关系

- 与 [[Embedding]]、[[向量数据库]]、[[RAG]] 是"基础设施—应用"链
- [[BERT语义搜索算法]]、[[MUM多任务统一模型]]、[[RankBrain]] 是 Google 实现路径
- [[Google知识图谱]] 提供事实锚,反幻觉
- [[Hummingbird算法]] 是语义化序章
- 在 AI 时代衍生 [[AI Overviews]]、[[Featured Snippet精选摘要]]
- 与 [[搜索意图]]、[[Topical Authority主题权威]]、[[E-E-A-T]] 协同
- 与 [[多模态AI]] 结合形成跨模态语义搜索
- [[CLIP]] 是图文语义对齐的奠基模型
