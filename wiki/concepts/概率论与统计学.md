# 概率论与统计学

## 定义

**概率论**研究随机现象的规律性,提供描述不确定性的语言;**统计学**从数据中提取信息、检验假设、估计参数。两者是金融定量分析的最基础工具,任何严肃的金融模型都建立在它们之上。

## 核心要点

### 概率论核心

**1. 随机变量与分布**

| 分布 | 用途 |
|---|---|
| 正态分布(Normal) | 收益率近似、误差项 |
| 对数正态分布(Lognormal) | 股价路径(Black-Scholes 假设) |
| t 分布 | 小样本推断,肥尾收益建模 |
| 卡方 / F 分布 | 方差检验、回归显著性 |
| 泊松分布 | 极端事件计数(违约) |
| 帕累托 / 极值分布 | 尾部风险建模 |

**2. 一阶/二阶矩**

- **期望** E(X):中心趋势,等于平均回报
- **方差** Var(X) = E[(X−E(X))²]:离散程度,即"风险"的经典度量
- **协方差/相关系数**:[[投资组合理论|分散化]] 的数学基础

**3. 中心极限定理**

独立同分布随机变量的均值随样本量增大趋于正态。这是为什么"分散化能降低风险"、"大样本统计推断有效"的根本原因。

### 统计学核心

**1. 描述性统计**:均值、中位数、标准差、偏度、峰度。金融收益常具有负偏 + 高峰度("肥尾")特征。

**2. 推断统计**:点估计、区间估计、假设检验(t 检验、F 检验、卡方检验)。

**3. 时间序列基础**:平稳性、自相关、单位根。

**4. [[回归分析]]**:线性回归、多元回归、最小二乘估计。

### 金融应用

- **风险度量**:[[风险识别与度量|VaR、ES]] 都基于分布假设
- **资产定价**:Beta 估计是回归;CAPM 假设收益正态
- **期权定价**:[[期权定价|Black-Scholes]] 基于对数正态
- **组合优化**:[[投资组合理论|MPT]] 用方差作为风险

### 常见误区

- **正态假设失效**:实际收益肥尾,极端事件比正态预测频繁得多
- **过拟合**:历史样本表现好不代表未来
- **相关性突变**:危机时相关性飙升,分散效果失效

## 和其他概念的关系

- 是 [[回归分析]]、[[蒙特卡洛模拟]] 的基础
- 与 [[随机过程]] 密切相关(后者是动态概率论)
- 直接支撑 [[风险识别与度量]] 和 [[投资组合理论]]
- [[行为金融学]] 挑战传统概率假设
