# 毛利结构

## 定义

**毛利结构** 是一家企业 **毛利来源在不同维度上的分布**——按品类、渠道、客户类型、价格段的拆解。它揭示的不是"赚不赚",而是"靠什么赚钱"。在手机店、便利店、餐饮等 **微利业态**,毛利结构是经营的灵魂——主营产品毛利极薄(手机 8-15%),不能仅靠它生存,必须设计 **多元毛利组合** 平衡。

公式:

```
毛利 = 营业额 - 直接成本(进货 + 直接人工 + 直接物料)
毛利率 = 毛利 / 营业额
```

## 核心要点

### 1. 毛利率的层级与意义

| 毛利率 | 业态 | 说明 |
|---|---|---|
| **3-8%** | 大宗商品、批发 | 极薄,靠规模 |
| **8-15%** | 手机销售、家电、3C 数码 | 标品红海 |
| **15-30%** | 便利店、超市 | 中等,靠周转 |
| **30-50%** | 服饰、化妆品 | 较高,靠品牌 |
| **50-70%** | 餐饮、奶茶 | 高,靠位置与体验 |
| **70-90%** | 软件、SaaS | 极高,靠数字化 |
| **80%+** | 知识产品、咨询 | 极致,靠认知 |

### 2. 手机店的典型毛利结构

#### 主力产品(裸机销售)
- iPhone 新机:5-10%
- 安卓旗舰(华米OV):8-15%
- 中低端机:10-20%

仅靠这个无法生存。

#### 高毛利补充(占毛利总额可能 50%+)

| 类目 | 毛利率 | 经营要点 |
|---|---|---|
| **手机配件** | 40-70% | 充电器、耳机、保护壳、贴膜 |
| **手机保险/碎屏险** | 30-50% | 与保险公司合作分润 |
| **延保/增值服务** | 60-80% | 标准化、纯利 |
| **二手回收 + 翻新销售** | 30-60% | 大型连锁的核心毛利源 |
| **维修服务** | 50-80% | 配件 + 工时双重利润 |
| **流量套餐分销** | 20-40% | 与运营商合作 |
| **金融分期** | 5-15% | 利率分润 |
| **数据迁移服务** | 80-90% | 几乎零成本 |

### 3. 毛利结构优化的三层思维

#### a) 高毛利补充比例
通过增加上述高毛利品类,把综合毛利率从 10% 拉到 18-25%。

#### b) 关联销售提升
**Attach Rate(配件挂单率)**:每卖 1 部手机捆绑卖出多少件配件。
- 行业平均:1.2-1.5 件
- 优秀店:2-3 件
- 顶级店:4-5 件

每提升 0.5 件,综合毛利可提升 3-5 个百分点。

#### c) 客户分层定价
- 散客 / 成本敏感 → 主力机 + 基础配件
- 商务 / 工具型 → 高端机 + 保护套装 + 延保
- 礼品需求 → 全套配件 + 包装

不同分层对应不同毛利组合。

### 4. 便利店的毛利结构(对比)

| 类目 | 毛利率 | 占比 |
|---|---|---|
| **快餐/熟食/饮料** | 25-40% | 35% |
| **包装食品** | 15-25% | 30% |
| **日用品** | 10-20% | 15% |
| **烟草** | 8-12% | 10% |
| **服务费(代收/代缴/印件)** | 60-90% | 5% |
| **自有品牌商品** | 30-50% | 5% |

便利店的核心策略是 **高频低毛利商品引流 + 高毛利现制食品赚钱**(711、全家鲜食占毛利 50%+)。

### 5. 毛利结构的诊断框架

#### 三看
- **看占比**:每个品类贡献多少毛利
- **看趋势**:某品类毛利占比的月/季/年变化
- **看天花板**:某品类是否到了规模上限

#### 三问
- 哪个品类毛利率最高但没做大?
- 哪个品类毛利率最低但占很大?
- 哪个品类是 **高毛利但顾客需要培育认知** 的(如保险、延保)?

#### 三动作
- **做大高毛利品类**(配件、服务)
- **优化低毛利品类**(议价、套购)
- **退出无毛利品类**(纯引流不挣钱的留在原位即可)

### 6. 毛利率 vs 毛利额

容易混淆——10% × 100 万 = 10 万 vs 50% × 5 万 = 2.5 万。

实际管理要看 **毛利额**,毛利率高但销量小可能毛利额并不高。

最优组合是 **高毛利率 × 较高销量** 的"明星品类",大力推广。

## 实战陷阱

### 陷阱 1:盲目追求高毛利率
高毛利但低销量品类不能撑起店面。要看 **毛利额**。

### 陷阱 2:忽视低毛利引流品
便利店饮料毛利低但是引流核心。完全砍掉会丢客流。

### 陷阱 3:不算清"间接毛利"
卖手机时连带卖一张套餐卡(运营商分润 100 元)、加上数据迁移 30 元、配件 200 元——账上这些是不同品类,实际是 **同一笔交易的总毛利**。要看 **整单毛利贡献**。

### 陷阱 4:低毛利但高客单的伪健康
卖一部 8000 元手机赚 500 毛利看起来不错,但占用空间、库存、人力都高。和卖 100 件配件赚 500 毛利的成本结构差很多。

## 当代演进

### 数字化对毛利结构的影响
- 电商挤压裸机毛利,迫使线下转向服务+体验
- 数据让"客户分层定价"更精准
- 私域复购让低毛利商品也能高毛利额

### 服务化趋势
- 苹果 Apple One 订阅 = 软件高毛利
- 手机厂商自建零售(华为旗舰店)= 控渠道、提毛利
- 二手手机市场爆发(转转、爱回收)= 翻新毛利空间

### AI 与毛利结构优化
- 实时定价让高毛利品在不同时段动态推荐
- 客户画像让销售员知道该推哪类高毛利
- 库存预测让滞销低毛利品减少积压
