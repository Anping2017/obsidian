# 无形资产

## 定义

**无形资产**(Intangible Assets)是企业拥有或控制的、**没有实物形态、可辨认的非货币性资产**,且预期使用期限超过一年。

它与 [[商誉]] 的关键区别在于"**可辨认性**"——无形资产能单独识别、出售、转让;商誉只能依附于企业整体存在。

## 核心要点

### 主要类型

| 类型 | 示例 | 来源 |
|---|---|---|
| **专利权** | 发明、实用新型、外观设计 | 自主研发或外购 |
| **商标权** | 品牌名、Logo、商号 | 注册或购买 |
| **著作权** | 软件、出版物、影视 | 创作或购买 |
| **特许权** | 加盟权、特许经营权、采矿权 | 行政或合同授权 |
| **非专利技术** | 商业秘密、Know-how | 自主积累或购买 |
| **土地使用权** | 国有建设用地 | 出让取得 |
| **软件** | 自研软件、外购软件 | 自研或购买 |
| **客户关系** | 已建立的客户名单及关系 | 收购获得 |
| **合同权益** | 长期供货合同、租赁合同 | 商业合作 |

### 确认条件

同时满足:
1. 与该资产相关的经济利益**很可能流入**企业
2. 该资产成本能**可靠计量**
3. **可辨认**:可单独分离 OR 源于合同/法定权利

研究阶段支出**全部费用化**,开发阶段支出在满足六条件后**可资本化**(IAS 38 / 企业会计准则第 6 号):
- 技术可行
- 完成意图
- 销售或使用能力
- 经济利益可期
- 资源充足
- 支出可计量

### 初始计量

- **外购**:购买价款 + 相关税费 + 直接费用
- **自行研发**:开发阶段符合资本化条件的支出
- **接受投资**:投资合同约定价值
- **政府补助**:公允价值或名义金额
- **企业合并取得**:公允价值

### 后续计量与摊销

#### 摊销期限

按**使用寿命**判断:
- **有限寿命**:在合同/法定/经济寿命较短者内摊销
- **不确定寿命**:不摊销,但每年减值测试

#### 摊销方法

通常**直线法**,反映消耗模式特殊时可用产量法、加速法。

```
某专利原值 1,000,000,使用寿命 10 年:
年摊销额 = 1,000,000 / 10 = 100,000

借:管理费用(或制造费用、销售费用)100,000
   贷:累计摊销                       100,000
```

#### 残值

通常假设为 0,除非:
- 第三方承诺购买
- 存在活跃交易市场

### 减值测试

每个资产负债表日检查迹象:
- 市场价值显著下降
- 市场环境恶化
- 使用方式变化
- 资产物理或经济性损耗

可收回金额 < 账面价值 → 计提减值,且**不得转回**(IFRS、中国准则)。

### 处置与终止确认

- 出售:差额计入"资产处置损益"
- 报废:账面净值结转"营业外支出"

### 自创无形资产 vs 外购无形资产

| 维度 | 自创 | 外购 |
|---|---|---|
| 入账金额 | 仅开发阶段符合条件的支出 | 实际支付价 |
| 价值低估 | 普遍(品牌、技术等真实价值远高于账面) | 接近公允 |
| 信息披露 | 研发支出占比、资本化政策 | 直接列示 |

某些公司账面无形资产很少但实际价值巨大(如可口可乐的品牌),这是 [[财务报表分析]] 的常见盲点。

### 与商誉的区分

```
商誉 = 收购对价 - 应享有可辨认净资产公允价值份额
      ↑(非可辨认,不可分离,只能合并产生)

无形资产 = 可辨认 + 可分离(单独出售)
```

商誉每年减值测试不摊销;无形资产通常摊销 + 减值测试。

### 实务难题

- **品牌价值**:自创品牌不入账,外购品牌按对价入账,导致同业账面差异
- **客户关系估值**:并购中需独立估值师评估
- **软件资本化边界**:维护性 vs 改进性支出区分
- **IP 跨国转让定价**:税务关注点

### 数字经济时代的挑战

- 数据资产会计处理(IFRS、中国均在研究)
- 软件即服务(SaaS)开发成本资本化标准
- AI 模型作为无形资产的识别
- NFT 与数字资产入账标准

## 和其他概念的关系

- 与 [[固定资产折旧]] 形成"折旧 vs 摊销"的对偶
- 与 [[商誉]] 都是非实物资产,但可辨认性不同
- 自创时与 [[研发支出资本化]] 相关
- 减值机制与 [[存货计价方法]] 中的跌价准备同源
- 在 [[企业价值评估]]、并购中是关键评估对象
- 与 [[国际财务报告准则]] IAS 38 / 企业会计准则第 6 号一致
- [[财务报表分析]] 中"无形资产 / 总资产"反映行业属性
