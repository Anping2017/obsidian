# Embedding

## 定义

**Embedding(嵌入)** 是把离散对象(单词、句子、用户、商品、图像、token)映射到连续稠密向量空间 $\mathbb{R}^d$ 的表示学习技术,使得语义或行为上相似的对象在向量空间中距离相近(余弦相似度高)。

它是 [[深度学习]] 处理离散输入的标准入口,也是现代 [[RAG]]、推荐系统、语义搜索的核心数据结构。

## 核心要点

**主要类型**

| 类型 | 输入 | 代表方法 |
|---|---|---|
| 词嵌入(Word) | 单词 | Word2Vec(2013)、GloVe、FastText |
| 上下文嵌入 | 单词在具体上下文中 | ELMo、[[BERT]] 输出 |
| 句嵌入 / 文档嵌入 | 完整句子或文档 | Sentence-BERT、OpenAI text-embedding-3 |
| 多模态嵌入 | 图文对、音视频 | CLIP、ImageBind |
| 通用对象嵌入 | 用户、商品、节点 | 推荐系统、图嵌入(Node2Vec) |

**关键性质**

- 维度通常 128-1536(轻量场景)或 768-4096(大模型隐藏层)
- 距离度量:余弦相似度最常用,欧氏距离次之
- 类比性质:经典例子 $\vec{\text{king}} - \vec{\text{man}} + \vec{\text{woman}} \approx \vec{\text{queen}}$
- 训练目标多用对比学习、自监督任务(如 next-token、掩码、对比对)

**典型应用**

- 语义搜索:把查询和文档都嵌入,按相似度排序
- [[RAG]]:检索阶段把外部知识嵌入存入向量库,问题嵌入后召回相关片段
- 聚类与去重:相似内容自动分组
- 推荐:用户与物品共享嵌入空间,内积或双塔召回
- 跨模态检索:用文本搜图像(CLIP)

## 和其他概念的关系

- 输入端口:[[Transformer架构|Transformer]] 输入的 token Embedding 与 [[位置编码]] 相加
- 关键载体:[[向量数据库]] 存储和检索 Embedding
- 主要应用:[[RAG]] 系统检索阶段
- 表示学习:本质是 [[无监督学习]] 或自监督学习的产物
- 与 Token 关系:[[Token]] 是离散单元,Embedding 是其连续表示
- [[精准营销]]:用户与商品共嵌入空间,支撑双塔召回与相似受众扩展
- [[搜索意图]]:查询与文档同空间向量化,意图相似度=向量相似度
- [[数据驱动营销]]:把非结构化行为/评论转为可建模特征
