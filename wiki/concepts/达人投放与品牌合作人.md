# 达人投放与品牌合作人

## 定义

达人投放(Influencer Marketing)在小红书生态特指品牌方通过官方"蒲公英平台"或私下合作,与"品牌合作人"(开通商业接单资格的小红书博主)签订协议,由对方创作并发布带 #广告 标识的合规商业笔记,以换取曝光、种草、流量与转化。这是 [[KOL营销]] 在小红书生态的具体形态,有完整的报备-合作-数据-结算闭环,与"野生 KOC 投放"并行。

## 核心要点

**蒲公英平台核心机制**:

- 小红书官方达人交易平台,所有商业合作必须通过蒲公英报备(否则违规限流)。
- 品牌方注册 → 找达人 / 发布招募 → 签订合同 → 达人创作 → 发布带 #ad 标识 → 数据回收。
- **报备的好处**:
  - 内容受官方保护(不会被处罚)。
  - 数据透明(蒲公英后台可看真实曝光、互动、回链)。
  - 可同步信息流广告投放(笔记加热)。
  - 可加品牌追踪锚点(蒲公英追踪)。

**达人分级**:

| 等级 | 粉丝数 | 一篇报价(参考) | 适合场景 |
|---|---|---|---|
| **腰部 / KOC** | 5K-5W | 800-5000 | 大量铺量、真实感强 |
| **中腰部** | 5W-50W | 5000-3 万 | 性价比高、垂直深度 |
| **头部** | 50W-200W | 3-15 万 | 信任背书、爆品引爆 |
| **超头部** | 200W+ | 15-100 万 | 品牌曝光、新品发布 |

价格与垂直领域、内容形式、独家程度相关浮动。

**投放策略 — 金字塔模型**:

1. **超头部 / 头部 1-2 个**:打品牌信号,产生话题。
2. **中腰部 5-10 个**:深度种草,提供详尽测评与故事。
3. **KOC 50-200 个**:真实口碑铺量,占据搜索结果。
4. **品牌自有矩阵号**:见 [[矩阵账号运营]]。
5. **再营销加热**:对优质笔记做信息流加热,扩大曝光。

**笔记内容协作**:

- **简报(Brief)清晰**:产品卖点、目标人群、必含信息、禁忌。
- **创作自由度**:60% 给达人发挥(他更懂粉丝),40% 品牌指引。过紧的脚本反而降低真实感。
- **反复修改**:小红书上达人对甲方过度干预反感最强。建议两轮以内修改完毕。
- **上线时间**:节点紧密时(双 11、618)需提前 2-4 周锁档期。

**核心 KPI 与归因**:

- **品牌曝光**:CPM(千次曝光成本)。
- **互动**:CPE(单次互动成本)。
- **种草效率**:CPM 加权 + 互动率合算。
- **转化**:回链点击 + 蒲公英追踪订单(蒲公英已对接淘宝 / 京东 / 抖音 / 自有店铺)。
- **声量提升**:品牌词搜索量增长(GSC / 巨量算数)。
- **品牌合作人 NPS**:达人对合作过程的满意度,影响后续合作。

**避坑指南**:

- **数据造假识别**:看历史笔记的"流量曲线"——爆点笔记 vs 平均的差距,真实账号通常有几个爆点;数据全平均说明刷量。
- **粉丝画像匹配**:粉丝是否真的是目标客户(查粉丝地域、性别、年龄分布)。
- **签约多平台保留**:在抖音 / 微博等也活跃的达人,小红书表现更稳定。
- **避免"硬广打法"**:一打开就是产品介绍 → 完播率惨淡。
- **强制只用品牌指定话术**:刻意感强,效果差。

**KOL vs KOC 选择**:

| 维度 | KOL(头部 / 腰部) | KOC(草根) |
|---|---|---|
| 信任度 | 中(被广告化) | 高(像朋友) |
| 转化率 | 中 | 高 |
| 影响力广度 | 广 | 窄 |
| 单次成本 | 高 | 低 |
| 规模化难度 | 易(找几个) | 难(找几十几百个) |

**Dou+ / 信息流加热同步投放**:

- 蒲公英笔记可同步开 Dou+ 加热(抖音类)或小红书信息流加热。
- 自然流量到顶后用付费杠杆继续放大。
- 加热预算建议自然流量爆款后追加,而非自然冷的笔记硬推。

**反模式**:

- **不报备做商业合作**:被平台识别后双方都罚。
- **只看粉丝数**:大粉丝低互动的"僵尸大 V"性价比极低。
- **短期速成思维**:种草需要积累,3-6 个月才能见品牌词搜索量提升。
- **不复盘投放数据**:重复签约表现差的达人。
- **完全外包给 MCN 不亲自管理**:中间商赚差价,信息不透明。

## 和其他概念的关系

达人投放是 [[KOL营销]] 在小红书生态的具体落地,与 [[小红书种草]]、[[内容营销]]、[[小红书推荐机制]] 三位一体。它依赖 [[小红书笔记结构]] 的内容质量门槛,优秀笔记结构是付费投放也能跑出 ROI 的前提。

它与 [[矩阵账号运营]] 形成"自有 + 外购"的内容矩阵——前者是低成本长期资产,后者是快速规模化能力。在 [[KOC]] 投放时也使用相同蒲公英机制,只是体量与策略不同。

[[归因模型]] 在达人投放中尤其复杂——种草链路长、跨平台决策、最后下单可能在淘宝 / 京东。蒲公英的 UTM 锚点 + 第三方监测工具(电商平台店铺访问来源)是基础归因方式。在 [[品牌定位]] 中,达人选择本身就是品牌定位的延伸——选错达人即选错人群。
