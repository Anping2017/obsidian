# 公地悲剧

## 定义

公地悲剧(Tragedy of the Commons)由生态学家加勒特·哈丁(Garrett Hardin)1968 年发表于《Science》的同名论文提出。它描述当多个独立行为者各自追求自身利益、共享有限的可枯竭资源时,理性行为加总会导致资源过度使用、最终所有人福利下降。

经典例子:村庄共有牧场,每位牧民理性选择多放养一头牛(获得 100% 收益,污染成本由全村均摊),最终牧场过度放牧、所有人无草可用。

## 核心要点

### 1. 数学结构
- 共有资源 R(t),N 个用户
- 每用户 i 边际收益 = +1(私人独得)
- 每用户 i 边际成本 = -1/N(全员均摊)
- 私人净收益 ≈ 1 - 1/N > 0(只要 N > 1)
- 每人理性增加使用 → 集体过载

### 2. 与 [[囚徒困境]] 的关系
- 公地悲剧是 N 人版囚徒困境
- 个人理性 ≠ 集体理性
- 帕累托劣均衡

### 3. Hardin 的解决方案二选一
- **国有化**:政府接管
- **私有化**:产权分割
- 这一二元论被 [[奥斯特罗姆]] 1990 反驳

## 经典例子

| 资源 | 公地悲剧表现 |
|---|---|
| **公海渔业** | 全球渔业崩溃 |
| **大气** | 温室气体过排 |
| **地下水** | 抽干含水层 |
| **森林** | 滥伐 |
| **公共停车场** | 满到无法使用 |
| **抗生素** | 滥用导致耐药 |
| **疫苗免疫** | 不打疫苗搭便车 |
| **共享数据** | 数据滥用、侵蚀隐私 |
| **AI 算法权重** | 共同训练数据被污染 |
| **平台治理** | 评论区垃圾内容 |
| **开源维护** | "燃尽"维护者 |
| **学术共有** | 抢发表、引用造假 |
| **太空轨道** | 太空垃圾 |

## 解决方案谱

### 1. 国有化(Hardin)
- 政府管制、配额、税收
- 例:NMFS 渔业配额
- 难点:执行能力、信息

### 2. 私有化(Hardin)
- 产权切分
- 例:水权交易、个体可转让配额(ITQ)
- 难点:边界划定难、不公

### 3. 自治(Ostrom)
- 见 [[奥斯特罗姆共有资源]]
- 社区规则、监督、制裁
- 八原则:边界、规则与本地、参与、监督、分级制裁、冲突解决、组织权认可、嵌套
- 例:瑞士山区放牧、菲律宾梯田

### 4. 庇古税(Pigovian Tax)
- 对负外部性征税
- 让私人成本 = 社会成本
- 例:碳税、拥堵费

### 5. 科斯定理(Coase Theorem)
- 明确产权 + 低交易成本 → 自愿协商解决
- 限制:交易成本高时失效

### 6. 多中心治理
- 见 [[奥斯特罗姆]] 词条
- 多层级、多类型并存
- 应对全球 + 本地

### 7. 道德规范
- 内化自我约束
- 文化、宗教、教育
- 与 [[儒家]]、[[斯多葛主义]] 道德传统

## 公地的反例(Hardin 误判)

奥斯特罗姆与同事数千案例显示:
- 真正"开放进入"(open access)资源极少
- 大多数"公地"实际是社区共管(commons)
- Hardin 混淆了两者
- 现实有制度安排避免悲剧

实际情况公地悲剧主要发生于:
- 大规模匿名互动
- 缺乏监督
- 无沟通
- 缺乏权威支持
- 文化解体

## 当代应用

### 气候变化
- 全球大气 = 全球公地
- 巴黎协定试图建立合作
- 各国"搭便车"激励
- 一国减排,他国搭便车
- 多中心 + 强制整合是关键

### 海洋
- 公海渔业枯竭
- 联合国《海洋公约》
- 区域渔业管理组织(RFMO)

### 网络空间
- 域名、IP 地址(某种意义)
- 算力(平台滥用)
- 注意力(广告污染)

### 数据
- 个人数据集体被采集
- 训练数据中的合理使用辩论
- 数据信托(data trust)新形态

### 抗生素与公共卫生
- 滥用导致耐药菌
- 个体获益,社会承担

### AI 与共有
- 训练数据公地化
- 但模型私有
- 创作者抗议(诉讼、罢工)

## 哲学含义

- 个人理性 ≠ 集体最优
- 自由市场失效一域
- 制度设计的必要性
- 人性是否本自私的辩论
- 与 [[霍布斯]]"自然状态"形式化
- 与 [[卢梭]] 公意理论

## 当代理论扩展

### 反公地悲剧(Anti-commons)
- Heller 1998
- 过多产权所有者阻挡使用
- 例:基因专利碎片化
- 私有化解决方案的反面问题

### 数字共有
- Yochai Benkler、Lessig
- 信息可无限复制 → 不是经典公地
- 但开发者注意力是公地

### 知识共有
- 维基百科
- 开源软件
- Creative Commons
- 治理实验
