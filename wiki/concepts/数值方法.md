# 数值方法

## 定义

**数值方法**(Numerical Methods)是用计算机求解数学问题的近似方法,在解析解不存在或计算困难时通过数值计算获得近似解。其特征是近似性、计算性(基于计算机)、迭代性、误差性。它是 [[期权定价]] 复杂模型、 [[蒙特卡洛模拟]] 等实务应用的基础。

## 核心要点

### 基础概念
- **数值方法分类**:数值积分、数值微分、方程求解、优化方法、插值与逼近
- **数值误差**
  - **截断误差**(Truncation Error):近似方法本身的误差,通过提高阶数控制
  - **舍入误差**(Roundoff Error):浮点运算精度限制,通过提高精度控制
  - **总误差** = 截断 + 舍入,且二者常此消彼长
- **收敛性**:算法迭代是否收敛,以何种速度
- **收敛速度**
  - 线性收敛:O(h)
  - 二次收敛:O(h²)
  - 超线性、指数收敛
- **稳定性**:对输入扰动的敏感性

### 数值积分
1. **矩形法**:∫f(x)dx ≈ h·Σf(x_i),精度 O(h),最简单
2. **梯形法**:∫f(x)dx ≈ h/2·[f(x_0) + 2·Σf(x_i) + f(x_n)],精度 O(h²)
3. **辛普森法**(Simpson's Rule):∫f(x)dx ≈ h/3·[f(x_0) + 4f(x_1) + 2f(x_2) + ... + f(x_n)],精度 O(h⁴)
4. **高斯求积**:最优节点选择,极高精度,适合特殊函数
5. **自适应积分**:根据函数局部行为自动调整步长
6. **蒙特卡洛积分**:[[蒙特卡洛模拟]] 是高维积分的有效方法

### 数值微分
- **前向差分**:f'(x) ≈ [f(x+h) - f(x)] / h,精度 O(h)
- **后向差分**:f'(x) ≈ [f(x) - f(x-h)] / h,精度 O(h)
- **中心差分**:f'(x) ≈ [f(x+h) - f(x-h)] / (2h),精度 O(h²)
- **二阶导数**:f''(x) ≈ [f(x+h) - 2f(x) + f(x-h)] / h²
- **自动微分**(Automatic Differentiation):机器精度,深度学习核心技术

### 方程求解
- **二分法**:稳定但慢,O(log)
- **牛顿法**:x_{n+1} = x_n - f(x_n)/f'(x_n),二次收敛但需导数
- **割线法**:无需导数,速度介于二分与牛顿
- **不动点迭代**:x_{n+1} = g(x_n)
- **隐含波动率**:通过牛顿法求解 BSM 反问题

### 偏微分方程数值解
- **有限差分法**(FDM):时间空间网格离散化
  - 显式差分(Explicit):简单但稳定性条件苛刻
  - 隐式差分(Implicit):稳定性好但需求解线性方程组
  - Crank-Nicolson:稳定且二阶精度
- **有限元法**(FEM):适应不规则区域
- **应用**:Black-Scholes PDE、利率模型、信用模型

### 优化数值方法
- **梯度下降法**:适合无约束优化
- **牛顿法**:利用二阶信息,收敛快
- **共轭梯度法**:大规模问题
- **拟牛顿法**(BFGS、L-BFGS):近似 Hessian
- **内点法**:线性规划与凸优化
- **机器学习优化**:Adam、SGD、动量法

### 金融应用
1. **期权定价**
   - **Black-Scholes**:正态累积分布需数值积分
   - **美式期权**:有限差分法 / 二叉树 / 最小二乘蒙特卡洛(LSM)
   - **亚式期权**:[[蒙特卡洛模拟]]
   - **障碍期权**:有限差分 / 蒙特卡洛
2. **风险计算**
   - **VaR/ES**:积分概率密度,常用数值积分
   - **压力测试**:大量情景数值计算
3. **利率模型**
   - 随机微分方程数值求解(Euler-Maruyama、Milstein)
   - 树模型(Hull-White)、蒙特卡洛模拟
4. **信用衍生品**:Copula 模型、相关性建模
5. **校准**:模型参数对市场价格的校准是逆问题,需数值优化

## 和其他概念的关系

数值方法是金融定量分析的"实现层"——理论用 [[微积分应用]] 与 [[随机过程]] 表达,但实际计算多依赖数值方法。 [[期权定价]] 中除欧式期权外大量定价依赖数值方法,如美式期权、亚式期权、障碍期权、复杂衍生品。

[[蒙特卡洛模拟]] 是数值方法的特例(高维积分的随机方法),适合解析解不可得的问题。 [[线性代数应用]] 中的大规模矩阵运算需要数值线性代数。 [[时间序列分析]] 中 GARCH 等模型的参数估计需要数值优化。

[[衍生品风险管理]] 与 [[风险模型与工具]] 大量使用数值方法计算 VaR、ES、Greeks,尤其对复杂衍生品组合。 [[投资组合理论]] 的最优化是二次规划数值求解。 [[投资组合风险管理]] 中的压力测试是大规模数值计算。

[[量化分析]] 整体依赖数值方法,从因子构建、回测到执行。 [[金融科技]] 中的机器学习训练(神经网络反向传播)是大规模数值优化。 [[资产定价模型]] 的实证检验、[[企业价值评估]] 中的 [[蒙特卡洛模拟]] 估值都依赖数值方法。

数值方法的局限与挑战:**精度 vs 速度**(高精度需更多计算)、**稳定性**(数值病态问题)、**维度灾难**(高维问题指数爆炸)、**计算资源**(并行化、GPU)、**模型校准困难**(逆问题非唯一)。当代趋势是结合数值方法与机器学习,利用神经网络逼近复杂函数(PINN 物理信息神经网络)。
