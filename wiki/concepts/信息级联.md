# 信息级联

## 定义

**信息级联**(Information Cascade)是社会心理学与博弈论中的现象:**个体在不完全信息下,优先观察他人的行为而非寻找独立证据来做决策**。当多个人依次这样行动时,后续个体也跟随,产生**与个体私有信号严重偏离的群体行为**——即使群体行为基于错误判断。

它由 Bikhchandani、Hirshleifer、Welch 在 1992 年正式建模,是 [[社会证明]] 偏差的"动态版"——理解市场泡沫、流行趋势、政治运动、技术采纳波的关键工具。

## 核心要点

### 经典模型设定

设有连续决策者,每人:
- 有一个私有信号(noisy)指示某事真假
- 能观察前人的行为(不能看其私有信号)
- 必须公开做决定

```
第 1 人:基于私有信号决定 A 或 B
第 2 人:看第 1 人选择 + 自己信号
第 3 人:看前 2 人 + 自己信号
...
```

#### 级联开始

当前几人都选 A,某一时点后续个体的私有信号已被"群体共识"压倒,**即使他自己信号说 B,也选 A**。

```
1A 1B 时,第 3 人按自己信号
2A 0B 时,第 3 人即使信号说 B 也跟选 A(贝叶斯理性)
→ 信号被丢弃,级联开始
```

#### 关键性质

- **理性但易错**:每个人都是贝叶斯理性,但群体可走错
- **路径依赖**:前几人决定方向
- **脆弱**:新公开信息可能瞬间逆转
- **信息浪费**:后人的私有信号未被利用

### 经典案例

#### 1. 餐厅选择

街上两家餐厅,A 看起来差不多 B,但 A 有几桌人,B 空。
→ 第 5 个游客看见 A 多人,选 A
→ A 越来越多人,B 越来越少
→ 不论实际质量,A 形成"网红效应"

实际餐厅装修类似 + 偶然先来的几个人选 A → A 主导。

#### 2. 股市泡沫与崩盘

#### 上涨:

- 早期投资者基于基本面买入
- 价格上涨
- 媒体报道推荐
- 后续投资者主要看"价格在涨"
- 价格远超基本面但仍上涨
- 泡沫

#### 崩盘:

- 某一冲击让少数人卖
- 其他人看到卖盘 → 跟卖
- 雪崩
- 价格远低于合理价值

→ 经典级联两端。

#### 3. 学术研究"热点"

- 早期论文研究 X 取得成果
- 后续研究者跟进 X
- 资金、期刊倾向 X
- "X 显学"
- 即使 X 已边际收益递减,仍有人跟

直到某个突破改变方向(如 NLP 从 RNN → Transformer)。

#### 4. 时尚潮流

- 几个名人穿某款
- 跟随者拍同款
- 媒体报道 → 大众跟随
- 流行
- 不再流行(因新潮流取代)

#### 5. 学术八卦 / 政治流言

- 几个人传一个未经证实的故事
- 后续人听到后默认"已确认"传播
- 短时间内全社区"知道"
- 即使源头查无实据

#### 6. 创业公司估值

- 早期投资人看一家公司估值 X
- 后续轮按 1.5X 投
- 媒体报道"独角兽"
- 后续投资人按 2X 跟入
- 估值远超基本面
- 上市破发崩盘

### 与 [[社会证明]] 的区别

| 维度 | 社会证明 | 信息级联 |
|---|---|---|
| 核心 | 心理倾向("别人这样做我也这样") | 贝叶斯理性下的均衡 |
| 范围 | 静态心理现象 | 动态群体过程 |
| 治愈 | 提醒、教育 | 公开私有信号 |

社会证明是级联的**心理基础**,级联是社会证明在序列决策中的**结构化结果**。

### 反向级联(Counter-cascade)

新强信号公开 → 级联反转
- "皇帝的新衣":一个孩子说出真相 → 全城承认
- 公司丑闻一旦曝光 → 卖盘瞬间
- 假货被揭穿 → 时尚崩塌

级联的**脆弱性**体现:看似坚固的群体共识可在一瞬间土崩瓦解。

### 设计利用 / 抵御级联

#### 利用(营销)

- 制造"先到效应"(初始受众种子)
- 公开展示"已购人数"、"评分"
- "Limited time, X people are watching"
- 影响者营销

#### 抵御(决策者)

- **公开私有信号机制**:让每人独立投票后再公布(避免依次发言)
- **盲评**:学术评审、试听会
- **多元数据源**:不依赖共识,寻找独立证据
- **挑战机制**:制度化的反对者

### 在群体决策中的应用

#### 公司董事会

- 串行表态 → 后表态者受先表态影响
- 改善:同时投票后再讨论

#### 学术评审

- 第一位评审者意见过于影响后续
- 改善:盲评,各自独立打分

#### 法院陪审团

- 投票顺序影响结果
- 改善:同时书面投票

#### 群体讨论

- 老板先发言 → 下属跟从
- 改善:老板最后发言

### 在 AI 时代的新形态

#### 算法放大级联

- 推荐算法"火上浇油"
- 高初始热度 → 更多曝光 → 更多热度
- 偏离客观质量

#### LLM 的"训练数据级联"

- 早期 LLM 输出被收录到后续训练数据
- 错误观点被反复复制
- "AI 共识"误以为人类共识

→ 数据筛选与新鲜数据来源是 [[预训练与微调]] 的关键。

#### 加密货币与网红币

- 价格剧烈波动驱动 FOMO 级联
- 名人推文引发瞬间崩盘 / 上涨
- 散户在级联高峰入场,低谷离场

### 与 Lollapalooza 的关系

[[Lollapalooza效应]] 中,信息级联常是关键加速器:
- 多偏差同时启动
- 信息级联放大它们
- 短时间形成超常结果

### Solomon Asch 实验的关联

经典从众实验:75% 的人在多人错误回答后会跟随错误答案。
这是信息级联在受控环境的简化版。

### 历史性级联

- **郁金香狂热**(1637)
- **南海泡沫**(1720)
- **1929 大萧条前夜**
- **1999 互联网泡沫**
- **2008 房地产泡沫**
- **2017 加密货币狂热**
- **2021 SPAC 热**

每次都有"这次不一样"的信念。每次最终被打破。

### 与"群体智慧"(Wisdom of Crowds)的张力

Surowiecki 的《群体智慧》主张:多元、独立、分散的群体平均估计接近真相。
**条件:个体独立**

但级联破坏了独立性:
- 个体观察他人 → 不再独立
- 群体智慧消失,集体愚蠢出现

→ 解决:独立信号 + 后聚合,而非串行影响。

### 实务原则

1. **重大决策时寻找独立证据**,不仅看群体共识
2. **询问不流行的观点**(逆向思考)
3. **关注"皇帝新衣"信号**(明显矛盾被忽略)
4. **不在群体亢奋时入场,不在群体恐慌时离场**
5. **设计制度抵御级联**(盲评、独立投票)

## 和其他概念的关系

- 是 [[社会证明]] 偏差的动态形式
- 与 [[从众心理]]、[[群体心理]] 紧密相关
- 是 [[Lollapalooza效应]] 的常见扩散机制
- 与 [[确认偏差]] 共同维持群体共识
- 与 [[逆向思维]]、[[智识诚实]] 是抵御工具
- 应用于 [[投资决策]]、[[营销心理学]]、[[政治学]]
- 与 [[网络效应]] 在"自我强化"上有异曲同工
- [[Black-Scholes]]、[[现代投资组合理论]] 假设的"理性独立"被信息级联破坏
- AI 时代延伸到推荐算法、模型训练数据生态
