# 丰田生产方式

## 定义

**丰田生产方式(Toyota Production System, TPS)** 是日本丰田汽车公司在二战后由大野耐一(Taiichi Ohno)主导构建的综合生产系统,目标是用最少资源、最短时间、最低成本生产高质量产品。它是 [[精益生产]] 思想的源流。

TPS 后来通过《改变世界的机器》(Womack 等)被西方学界提炼为"精益(Lean)",成为全球制造业标杆。

## 核心要点

### TPS 之屋(House of TPS)

```
            目标:最高质量、最低成本、最短交期、安全、士气
                          ┌───┴───┐
                          ▼       ▼
              JIT 准时制       Jidoka 自働化
              (持续流、拉动、节拍)  (人字旁的"动",出错即停)
                          │       │
                  ┌───────┴───────┴───────┐
                  │ 持续改善(Kaizen)        │
                  │ 标准化作业 + 平稳化生产    │
                  │ 全员参与 + 现地现物       │
                  └────────────────────────┘
```

### 两大支柱

#### 支柱一:JIT 准时制(Just-In-Time)
- 在**需要的时间、需要的地点、生产需要的数量**
- 拉动式生产(Pull):后工序拉动前工序,而非推送
- 看板(Kanban)系统:可视化拉动信号
- 单件流(One-Piece Flow):减小批量、暴露问题
- 节拍时间(Takt Time):与客户需求节奏对齐

#### 支柱二:Jidoka 自働化(Autonomation)
- "带人字旁的自动化",人 + 机器协作
- 异常即停(Andon 安灯):发现缺陷,产线立即停止
- 内嵌质量(Built-in Quality):不传递不良品
- 防错(Poka-Yoke):工装设计让出错变得不可能

### 七大浪费(Muda)

大野耐一识别的非增值活动:

1. **过量生产(Overproduction)** - 最严重,所有浪费之源
2. **等待(Waiting)** - 设备/人闲置
3. **运输(Transportation)** - 不必要搬运
4. **过度加工(Overprocessing)** - 多余工序
5. **库存(Inventory)** - 占资金、藏问题
6. **动作(Motion)** - 不必要肢体动作
7. **缺陷(Defects)** - 返工或废品

后来添加第八种:**未利用的人才创造力(Unused Talent)**。

### 持续改善(Kaizen)

- **小步快跑**:每天微小改进,累积巨大效果
- **5 Whys**:追问五次"为什么",到达根因
- **Genchi Genbutsu**(现地现物):管理者亲赴现场观察事实
- **A3 报告**:1 页 PDCA 思考模板

### 标准化作业(Standard Work)

并非"僵化",而是**改善的基线**——只有标准化才能识别异常,才能持续改善。包含三要素:节拍、作业顺序、标准在制品。

## 和其他概念的关系

- 是 [[精益生产]] 思想之源,后被泛化为各行业精益
- 与 [[质量管理]]、[[全面质量管理]] 高度耦合,同属戴明圈影响
- 受 [[爱德华兹·戴明]] 战后日本质量讲座深刻影响
- 现代演化为 [[六西格玛]] (Lean Six Sigma)
- 拉动思想反向影响 [[供应链管理]]、ERP/MRP 系统
- 体现 [[组织学习]]:每个员工是"改善者"
- A3 思维与 PDCA 是 [[战略执行]] 与 [[管理决策]] 的微观底座
- Kaizen 文化是一种特殊的 [[组织文化]]
- 体现东方管理智慧与西方科学管理的融合
