# 帐篷类型

## 定义

帐篷(Tent)是露营的核心庇护所(Shelter),把"人"与"自然环境"分隔的最小单元。不同类型的帐篷在结构稳定性、空间利用、抗风性、防水性、重量、搭建难度上做出不同权衡,选择没有最优答案,只有"匹配场景"的答案。

帐篷分类有三个独立维度:**结构形态**(决定空间和抗风)、**层数**(决定保暖防水)、**季节适用**(决定面料与杆架强度)。三者交叉构成实际产品线。

## 按结构形态分类

**1. 圆顶帐(Dome Tent)**

- 两根弓杆交叉成穹顶,自立结构
- 优点:空间均衡、搭建简单、稳定
- 缺点:大风时形变明显、空间利用一般
- 适用:入门、家庭、固定营地
- 代表:Marmot Limelight、MSR Hubba Hubba(经典)

**2. 隧道帐(Tunnel Tent)**

- 多根平行弓杆构成长筒结构
- 优点:抗风性极佳(顺风方向)、空间利用率高
- 缺点:必须打地钉(非自立)、横向风险
- 适用:风口营地、长期驻扎、高山
- 代表:Hilleberg Nallo、Naturehike Cloud Up Tunnel

**3. 金字塔帐(Pyramid Tent / Pyramid Shelter)**

- 单根中央杆 + 周边地钉,极简结构
- 优点:超轻、搭建快、抗风优良
- 缺点:需地钉、内部斜面减少有效空间
- 适用:UL 轻量化徒步、Bushcraft、雪地
- 代表:Black Diamond Mega Light、SeekOutside Cimarron

**4. A 字帐 / 屋脊帐(A-Frame / Ridge Tent)**

- 两根直立杆 + 中央横杆,经典三角结构
- 优点:经典美学、稳定
- 缺点:重、空间利用率低
- 适用:复古风格营地
- 代表:Snow Peak Pent Eagle

**5. 印第安帐 / 锥形帐(Tipi Tent)**

- 锥形结构,可在内部生火(需带烟囱口)
- 优点:大空间、可烧火、高仪式感
- 缺点:重、不防水(火塘版)
- 适用:冬季雪地、家庭/团体
- 代表:Luxe Megahorn、SeekOutside Redcliff

**6. 屋脊式 / 拱顶式(Cabin Tent)**

- 立柱式垂直墙,接近房屋形状
- 优点:站立空间、家庭舒适
- 缺点:重、抗风差
- 适用:汽车营地、家庭长期驻扎
- 代表:Coleman Sundome、北面 Wawona 6

**7. 单杆帐 / 速搭帐(Pop-Up / Insta-Tent)**

- 弹簧自动展开
- 优点:5 秒搭建、低门槛
- 缺点:防水抗风差、寿命短
- 适用:儿童、短途、节庆

**8. 吊帐 / 树帐(Hammock Tent)**

- 悬挂在两树之间的吊床 + 防雨布 + 蚊帐
- 优点:无需地面平整、舒适、轻
- 缺点:需树、夜间冷
- 适用:森林、徒步
- 代表:Hennessy Hammock、Warbonnet

## 按层数分类

**单层帐(Single-Wall)**

- 仅一层面料,常用 Silnylon 或 DCF(Cuben)
- 优点:轻、紧凑
- 缺点:易冷凝水、保暖差
- 适用:UL 徒步、干燥环境

**双层帐(Double-Wall)**

- 内帐(透气网纱+面料)+ 外帐(防雨)
- 优点:防冷凝、保暖、空间感好
- 缺点:重、搭建步骤多
- 适用:大多数场景

**三层 / 棉帐(Multi-layer Cotton)**

- 棉/帆布,自带保暖
- 优点:冬季舒适、可烧火
- 缺点:超重、需晾干
- 适用:冬营、固定营地

## 按季节分类

**三季帐(3-Season)**

- 春夏秋适用
- 重量较轻、通风好
- 杆架不耐重雪

**四季帐(4-Season)**

- 增强杆架(常用 DAC NSL)、密封面料
- 抗大风、能压雪
- 重、不通风(夏季用反闷)

**冬帐(Winter / Mountaineering)**

- 极端环境(高海拔、暴风雪)
- 双杆架、强密封
- 极重(2-4 人 5-8kg)

## 选择决策框架

**场景维度**

| 场景 | 推荐 |
|---|---|
| 汽车营地家庭 | 大空间双层 Dome 或 Cabin |
| 公园露营 | Dome / 隧道 |
| 徒步过夜 | 双层 Dome / 单层金字塔 UL |
| 高山营地 | 隧道 / 四季帐 |
| 雪地冬营 | 棉帐 / 四季帐 |
| 森林徒步 | 吊帐 |

**人数与空间**

- 商家"X 人帐"标的是"挤满人不堆装备"
- 实际舒适居住 = 人数 - 1(2 人帐适合 1 人 + 装备)

**重量考量**

- UL(Ultra-Light)<= 1.2 kg/人
- 标准 1.5-2.5 kg/人
- 家庭/重型 3-6 kg

**预算锚点**

- 入门 ¥200-500(品质堪忧但够新手)
- 中端 ¥800-2500(主流品牌、长期可用)
- 高端 ¥3000-8000(MSR、Hilleberg、Big Agnes)
- 顶级 ¥8000+(Hilleberg 远征、定制)
