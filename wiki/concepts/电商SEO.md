# 电商SEO

## 定义

**电商 SEO(eCommerce SEO)** 是面向在线商品零售网站(品牌官网、垂直电商、综合电商)进行的搜索引擎优化,核心目标是让品类页、商品详情页(PDP)、品牌页、专题页在 Google 等搜索引擎中获得高排名,以低成本获取具有购买意图的自然流量。

电商 SEO 不同于一般 SEO 的关键挑战在于:页面数量极大(从几百到数千万)、内容动态(库存、价格变化)、重复内容(同款多色多尺寸 SKU)、搜索意图多样(从信息型到交易型)、与平台 SEO(Amazon、淘宝、京东、Shopee 等)同时博弈。

## 核心要点

- **关键页面类型**:
  - **首页(Homepage)**:承接品牌词,权重最高,导流给重要分类
  - **品类页(Category / Collection Page)**:核心 SEO 战场,承接"品类+人群+特性"等大量交易/商业研究意图查询
  - **产品详情页(PDP)**:承接"品牌+型号"、长尾产品词、shopping 类查询
  - **筛选页(Faceted Pages)**:基于属性组合的页面(如"红色女款 38 码运动鞋")
  - **品牌页(Brand Page)**:承接品牌+品类查询
  - **博客/内容页**:承接信息型与商业研究型查询(详见 [[内容营销]])
  - **本地店面页**:承接本地查询(如品牌+城市)
- **品类页优化要点**:
  - 关键词:品类核心词 + 修饰词(性别、价格区间、品牌、风格)
  - URL 结构:/men/shoes/running 这类层级清晰
  - 标题:"分类名 - 子分类 - 品牌名"
  - 内容:简介段落(SEO 内容)+ 商品列表 + FAQ
  - 内链:Topic Cluster(同主题相关分类的相互链接)
- **产品详情页优化要点**:
  - 唯一描述(避免厂商提供的重复描述被多电商复制)
  - 用户评价(UGC,长尾词覆盖)
  - 高清图片 + 视频 + alt 文本
  - 结构化数据(Product schema:价格、库存、评分、品牌、SKU)
  - FAQ schema(回答常见购买疑虑)
  - 相关产品/搭配推荐(内链)
  - 加载速度(电商 PDP 通常重资源,优化关键)
- **筛选(Faceted Navigation)的特殊处理**:
  - 价值高的组合页(如"耐克男款跑鞋 < 1000 元")可索引并 SEO
  - 价值低的组合页(如"红色 + S 码 + 折扣 + 标签 X 的某品类")应 noindex 或 canonical 到上层
  - 防止生成数百万个稀薄相似页面消耗抓取预算
- **库存与价格动态**:
  - 缺货页面策略:保留并提示"缺货+替代品"(保留 SEO)、或 410(永久)/302(暂时)、或重定向
  - 价格变动通过 Product schema 实时同步
  - 季节性产品(圣诞、夏装)的归档与回暖
- **重复内容问题**:
  - 同一商品不同 URL(参数、排序、SKU 变体)
  - 用 canonical 标签指定主版本
  - 不要 noindex 主商品页(常见错误)
- **大规模 SEO 的工程问题**:
  - 抓取预算管理(Crawl Budget)
  - Sitemap 分级与优先级
  - 日志分析定位 Googlebot 行为问题
  - 模板化优化(改一处优化全站)
  - SaaS 平台限制(Shopify、Magento 等的 SEO 上限)
- **平台型电商 SEO**:
  - 在 Amazon、淘宝、Shopee 等平台站内的 SEO,核心算法是 A9/A10 类的转化率排名
  - 与 Google SEO 的差异:站内不需链接,转化率与销量是核心信号
  - 双轨策略:平台站内 SEO + 品牌官网 Google SEO
- **电商 SEO 的现代趋势**:
  - **Google Shopping**:免费列出 + 付费 PLA,Merchant Center 与 schema 数据成为关键
  - **AI 推荐与 SGE**:Google AI Overviews 推荐商品时引用结构化产品数据
  - **图片搜索 + Google Lens**:图片优化与图片 schema 重要性提升
  - **本地+电商融合**:Buy Online Pickup In-Store(BOPIS)与本地库存广告

## 和其他概念的关系

电商 SEO 是 [[搜索引擎优化]] 的垂直应用,综合了 [[关键词研究]]、[[搜索意图]]、[[页面SEO]]、[[技术SEO]]、[[结构化数据]]、[[链接建设]] 在电商场景的所有特化。

电商 SEO 与 [[本地SEO]] 在多门店品牌中协同——本地店面页同时服务本地搜索与电商客流。

电商 SEO 与 [[转化漏斗]] 优化(CRO)紧密结合——SEO 把流量带来,CRO 把流量变成订单,整体 ROI 才有意义。

电商页面的产品评价、问答、UGC 是 [[E-E-A-T]] 在电商场景的体现——真实评价是信任信号也是长尾关键词来源。

电商 SEO 在企业层面影响 [[企业价值评估]]——自然流量的占比与品质是判断 D2C 品牌护城河的关键指标(高自然流量 = 低获客成本 = 高 LTV/CAC)。
