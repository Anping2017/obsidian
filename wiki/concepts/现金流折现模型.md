# 现金流折现模型

## 定义

**现金流折现模型**(Discounted Cash Flow, DCF)把企业未来产生的**自由现金流**按合适的折现率折回到今天,加总即为企业内在价值。这是估值理论最严谨的方法,是金融学时间价值思想的直接应用。

## 核心要点

### 基本公式

```
V = Σ [FCFₜ / (1+r)ᵗ]   t=1..N    +   TV / (1+r)^N
```

- **V**:企业价值(或股权价值,取决于版本)
- **FCFₜ**:第 t 年的自由现金流
- **r**:折现率([[资本成本|WACC]] 用于 EV,Ke 用于股权)
- **TV**:终值(Terminal Value),通常永续增长法 TV = FCF_{N+1} / (r − g)

### 自由现金流的两种形式

**1. FCFF(企业自由现金流)**:用 WACC 折现 → EV
```
FCFF = EBIT × (1−T) + 折旧摊销 − 资本支出 − 营运资本变动
```

**2. FCFE(股权自由现金流)**:用 Ke 折现 → 股权价值
```
FCFE = FCFF − 利息 × (1−T) + 净借款
```

两条路径理论上等价,选哪个取决于资本结构是否稳定。

### DCF 的关键假设

| 假设 | 影响 |
|---|---|
| 显性预测期长度(通常 5-10 年) | 期内增长 vs 进入永续 |
| 永续增长率 g | 通常 ≤ 长期 GDP 增长(2-3%) |
| WACC / Ke | 使用 [[资产定价模型|CAPM]] 估算 Ke,加权 Kd 与 Ke 得 WACC |
| 终值占比 | 常达 60-80%,对终值假设极敏感 |

### 实操步骤

1. **历史财报**梳理:剔除非经常性损益、调整一次性项目
2. **驱动因素建模**:营收 → 毛利 → 营业利润 → 净利 → 现金流
3. **预测期假设**:增长率、利润率、资本开支、营运资本
4. **折现率**:股权成本(CAPM)、债务成本、资本结构权重
5. **终值**:永续增长法 vs 退出倍数法
6. **加总折现 + 调整**:加非经营资产、减债务、调整少数股东
7. **敏感性 + 情景**:给出估值区间

### 优缺点

✅ 理论严谨,直接基于现金创造能力
✅ 透明,假设可逐项检验
❌ 对假设极敏感(g、r 微变 → 估值大变)
❌ 不适合无现金流(初创亏损)、周期性极强、高度不确定的企业
