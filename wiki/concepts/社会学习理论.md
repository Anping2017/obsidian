# 社会学习理论

## 定义

社会学习理论(Social Learning Theory, SLT)由阿尔伯特·班杜拉(Albert Bandura)从 1960 年代起发展,主张人不仅通过直接经验学习,更通过观察他人(榜样)的行为及其后果学习。它弥补了 [[行为主义]] 仅关注直接强化的不足,1986 年班杜拉将其扩展为社会认知理论(Social Cognitive Theory),强调认知、行为、环境的三向交互。

## 历史发展

| 年 | 事件 |
|---|---|
| 1941 | Miller & Dollard《社会学习与模仿》 |
| 1961 | 班杜拉波波娃娃实验 |
| 1965 | 《榜样替代强化》论文 |
| 1977 | 《社会学习理论》经典著作 |
| 1986 | 《思想与行动的社会基础》转向社会认知理论 |
| 1997 | 《自我效能:控制的实施》 |

## 核心要点

### 1. 观察学习四过程

Bandura 提出四个必要过程:

| 过程 | 内涵 |
|---|---|
| **注意**(Attention) | 选择性注意榜样 |
| **保持**(Retention) | 编码与存储记忆 |
| **再现**(Reproduction) | 行为输出 |
| **动机**(Motivation) | 是否实施(替代强化) |

只有四过程都完成,观察学习才发生。

### 2. 替代强化与替代惩罚
- 看到他人因行为获奖 → 我倾向模仿
- 看到他人因行为被罚 → 我倾向避免
- 不需自己亲历

### 3. 三向交互决定论
- **行为**(B)
- **个人因素**(P, 认知、情感、生物)
- **环境**(E)
- 三者相互决定,彼此因果
- 反对单向行为主义"环境 → 行为"

### 4. 自我调节(Self-Regulation)
- 自我观察、自我判断、自我反应
- 不依赖外部强化的内在调节系统
- 与 [[自我效能]] 紧密结合

### 5. 自我效能
- 见 [[自我效能]] 词条
- 来自四源:成功经验、替代经验、言语说服、生理状态
- 是社会学习理论的核心机制

## 经典实验

### 波波娃娃实验(1961)
- 学龄前儿童分组观看不同榜样
- 攻击榜样组儿童明显更多模仿攻击
- 性别同性榜样更易被模仿
- 直接证明攻击行为可通过观察学习

### 后续变体
- 看动画片攻击榜样也产生模仿
- 暴力 → 被惩罚组减少模仿
- 但当被告知"我会奖励你"时,所有组都能再现 → 区分学习与表现

## 与其他流派对比

| 流派 | 学习机制 |
|---|---|
| **古典条件反射**(巴甫洛夫) | 刺激配对 |
| **操作性条件反射**(斯金纳) | 行为—后果强化 |
| **社会学习理论**(班杜拉) | 观察 + 认知 + 替代强化 |
| **认知主义** | 信息加工 |

## 应用领域

### 教育
- 教师作为榜样
- 同伴学习
- "看视频学",MOOC 设计
- 班杜拉自评效能测量
- 与 [[培训与发展体系]] 70-20-10 关联

### 临床
- 儿童行为问题
- 攻击与暴力预防
- 焦虑暴露与榜样疗法
- 自闭症行为干预

### 组织
- 领导榜样
- 入职文化传递
- 学徒制
- 案例教学
- [[组织学习]] 部分基础

### 媒体
- 暴力媒体效应辩论
- 亲社会节目设计
- 广告榜样效应
- 名人代言效力

### 健康
- 健康行为养成
- 戒烟、运动榜样
- 同伴干预

### 犯罪学
- 犯罪行为代际传递
- 帮派文化习得

## 与其他概念关系

- 修正 [[行为主义]] 但保留其严谨实验传统
- 与 [[认知主义]] 整合(后期社会认知理论)
- [[自我效能]] 是其核心子概念
- 与 [[依恋理论]] 早年榜样相通
- 与 [[操作性条件反射]] 互补
- 与 [[经典条件反射]] 不同机制
- 影响 [[变革型领导]] 榜样作用
- 影响 [[组织文化]] 行为塑造
- 与 [[培训与发展体系]] 师徒制关联
- [[KOL营销]] 替代强化的商业版

## 班杜拉本人贡献

- 详见 [[班杜拉]] 实体页
- 一人推动多个心理学领域
- 从社会学习到社会认知到代理理论
- 2002 美国心理学家终身贡献奖
- 2016 美国国家科学奖章

## 现代延伸

- 神经科学:镜像神经元提供生物基础(争议)
- 算法推荐:用户互相影响(社会证明强化)
- 在线学习与替代强化
- AI 模仿学习(Imitation Learning)
- 数字榜样(网红、虚拟主播)
