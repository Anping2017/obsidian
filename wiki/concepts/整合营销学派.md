# 整合营销学派

## 定义

整合营销学派(Integrated Marketing School)由唐·舒尔茨(Don Schultz)在 1990 年代初于美国西北大学麦迪尔学院(Medill School)创立,以《Integrated Marketing Communications》(1993)为奠基之作,核心命题是"营销与传播应当从顾客视角出发,所有触点(广告、PR、销售、客服、产品、包装、网站、社交媒体、终端)以一致的声音、对一致的目标受众、讲一致的故事"。该学派反对营销职能的部门化分裂,推动企业从"广告中心"转向"顾客中心"的传播范式。

## 核心命题与四原则

### 1. 一个声音(One Voice)

所有触点信息一致,品牌人格统一。用户在任何接触点遇到品牌都"是同一个品牌",而不是营销说一套、客服说一套、销售说一套。

### 2. 数据库为基础(Database Marketing)

整合的前提是能识别同一客户在不同触点的行为,数据库技术(后来演进为 [[CDP客户数据平台]])是 IMC 的基础设施。Schultz 比同期学者早十年看到这一点。

### 3. 由外而内(Outside-In)

从客户感知出发设计传播,而非从企业组织结构出发。客户不在乎"广告部还是 PR 部",只感知一致的品牌体验。

### 4. ROI 衡量

每个传播活动应能衡量对客户行为的影响,推动了营销从"创意展示"向"效果可验证"的转型。

## SOSTAC 框架与 IMC 实施

整合营销实施常用 SOSTAC(由 PR Smith 1996 年提出但与 IMC 高度兼容):

- **S**ituation(现状):品牌、市场、客户、竞争分析
- **O**bjectives(目标):SMART 目标
- **S**trategy(战略):STP + 定位
- **T**actics(战术):4P/4C/9P 在各触点的展开
- **A**ction(行动):时间表、责任分配、预算
- **C**ontrol(控制):衡量、反馈、迭代

## 与其他学派的辩证关系

### 与 [[科特勒主义]]

- 科特勒 4P 偏内部职能视角
- IMC 偏外部受众感知视角
- 两者后续融合,形成"科特勒+IMC"的当代主流

### 与 [[品牌资产学派]]

- 品牌资产是结果,IMC 是过程
- 一致性 IMC 是品牌资产积累的关键路径

### 与 [[Trout定位学派]]

- 定位是"占住一个词",IMC 是"用所有渠道反复说这个词"
- IMC 是定位执行的工程化

### 与 [[关系营销学派]]

- IMC 偏传播一致,关系营销偏长期深度
- 后续融合为"客户体验管理(CXM)"

## 数字时代的演进

### 1990s-2000s:IMC 1.0

- 重点:统一广告、PR、促销、终端
- 工具:CRM 数据库、Direct Mail
- 衡量:CPM、Reach、Frequency

### 2010s:IMC 2.0(Digital Integration)

- 加入数字渠道:网站、SEO、SEM、Email、SNS
- 工具:Marketing Automation、CDP、归因分析
- 衡量:多触点归因、CTR、CR、ROAS

### 2020s:IMC 3.0(Customer Experience)

- 跨线上线下、跨设备、跨触点的统一体验
- AI 驱动的实时个性化
- 工具:CDP + DMP + AI、客户旅程编排
- 衡量:LTV、NPS、CLV/CAC、客户体验指数

## 实务挑战

### 1. 组织壁垒

- 营销、销售、客服、产品分属不同部门,KPI 不同甚至冲突
- 解药:跨职能 squad、共同 OKR

### 2. 数据孤岛

- 各系统数据不互通,无法形成统一视图
- 解药:CDP 与 ETL 基础设施

### 3. 信息一致性

- 大企业有上千个内容产出者,如何让"声音"一致
- 解药:品牌指南、内容审核、AI 辅助合规

### 4. 渠道权重失衡

- 某渠道效果好,资源全压上,其他渠道萎缩
- 解药:[[Marketing Mix Modeling]] 评估边际贡献

### 5. 实时一致性

- 危机公关一句失误,所有触点要紧急同步
- 解药:危机响应 SOP

## IMC 与 [[整合营销传播]] 的关系

[[整合营销传播]] 是 IMC 在中文营销学语境下的标准译名,本概念是其学派思想史与方法论的延展,涵盖更大的"整合"范畴(不仅传播,还包括渠道、服务、产品体验整合)。

## 整合的四个层次(Schultz 进阶)

1. **战术整合**(Tactical Coordination):各广告创意视觉一致
2. **重新定义传播范畴**(Redefining Scope):把客服、销售、包装也作为传播工具
3. **应用 IT 与数据**(Application of IT/Database):用数据驱动整合
4. **战略整合**(Strategic Integration):品牌、定位、客户体验的全企业整合

最高境界是第四层——整合不只是营销部的事,而是全企业的事。

## 与其他概念的关系

- 与 [[整合营销传播]]:中文标准译名
- 与 [[全渠道营销]]:全渠道是整合的当代实施
- 与 [[品牌定位]]、[[品牌权益]]:整合的目标
- 与 [[CDP客户数据平台]]:基础设施
- 与 [[客户旅程地图实操]]:整合的可视化工具
- 与 [[CRM客户关系管理]]:数据基础
- 与 [[Marketing Mix Modeling]]:衡量工具
- 与 [[科特勒主义]]:理论互补
