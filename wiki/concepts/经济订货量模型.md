# 经济订货量模型

## 定义

**经济订货量(Economic Order Quantity, EOQ)** 是 Ford W. Harris 在 1913 年提出的库存管理基础模型,通过权衡**订货成本**(每次下单的固定费用)与**持有成本**(库存占用资金与仓储)求出最小总成本批量。

EOQ 公式简洁优美,是运营研究(Operations Research)历史上第一个广泛应用的数学模型,至今仍是 [[库存管理]] 教学起点。

## 核心要点

### EOQ 公式

$$Q^* = \sqrt{\frac{2DS}{H}}$$

| 符号 | 含义 |
|---|---|
| $Q^*$ | 最优订货量(Lot Size) |
| $D$ | 年需求量 |
| $S$ | 每次订货固定成本 |
| $H$ | 单位年持有成本 |

总年成本(TC):

$$TC = \frac{D}{Q}S + \frac{Q}{2}H + DC$$

(订货费 + 持有费 + 采购成本)

最优批量满足:**订货成本 = 持有成本**(两曲线交点)

### EOQ 的核心假设(批判性)

| 假设 | 现实问题 |
|---|---|
| 需求恒定且已知 | 实际需求波动 |
| 提前期固定 | 实际供货不确定 |
| 一次性到货 | 实际可能分批 |
| 无数量折扣 | 实际有阶梯价 |
| 无缺货 | 实际可能断货 |
| 单一产品 | 实际多产品共享资源 |

### EOQ 的"开方"特性与启示

由于公式是平方根,**Q 对参数变化不敏感**:

- 需求 D 翻 4 倍 → Q 仅翻 2 倍
- 这意味着 EOQ 在估算误差面前**鲁棒**——粗略估也不会差太远
- 但意味着规模效应递减:大批量好处有限

### 安全库存与再订货点(ROP)

EOQ 决定**多少**,ROP 决定**何时**:

$$ROP = d \times L + \text{Safety Stock}$$

- $d$:日需求
- $L$:提前期(天)
- 安全库存 = $z \cdot \sigma_{LT} \cdot \sqrt{L}$($z$ 取决服务水平,如 95% → z=1.65)

### EOQ 的扩展模型

| 扩展 | 适用 |
|---|---|
| **EPQ(Economic Production Quantity)** | 自产而非采购,渐进入库 |
| **数量折扣 EOQ** | 阶梯价 |
| **允许缺货 EOQ** | 缺货成本可量化 |
| **多产品 EOQ** | 共享订货约束 |
| **随机需求模型(news vendor)** | 一次性订货,如季节品 |

### 与 JIT 的范式对比

| 维度 | EOQ 范式 | [[JIT准时制]] 范式 |
|---|---|---|
| 目标批量 | 最优批量(平衡成本) | 单件流(批量趋 1) |
| 库存视角 | 必要资金占用 | 浪费,需消除 |
| 订货成本 | 接受、不变 | 通过 SMED 等手段降低 |
| 关注 | 计算批量 | 改善流程 |

JIT 主张通过**降低订货成本(快速换模)** 让 EOQ 自然趋近 1,而不是接受订货成本求最优批量。

## 和其他概念的关系

- 是 [[库存管理]] 课程的入门模型,后续 MRP/ERP 系统中仍嵌入
- 与 [[JIT准时制]] 体现两种库存哲学的交锋
- 是 [[运营管理]] 与 [[供应链管理]] 共享的基础工具
- 与统计学的随机过程、运筹优化方法相邻
- 决策逻辑(权衡两类成本)是 [[管理决策]] 经典案例
- 体现 [[管理会计]] 中"成本分类"在运营决策中的作用
- 服务业延伸:门诊预约批次、生产线换班节奏
- 现代延伸:电商动态补货模型、Amazon 仓库再订货算法
- Harris 1913 年的这篇论文与 Taylor 科学管理同期,是 [[现代管理学发展史]] 的起点之一
