# AIDA 文案公式

## 定义

**AIDA 公式** 是销售/广告/文案史上最古老最有影响力的框架,由美国广告先驱 Elias St. Elmo Lewis 1898 年首次提出。它把任何说服性沟通拆为四阶段:

- **A**ttention(注意)— 让对方注意到你
- **I**nterest(兴趣)— 引起兴趣不离开
- **D**esire(欲望)— 让对方想要
- **A**ction(行动)— 推动具体行动

历经 120+ 年仍是文案、邮件、广告、销售页、社交媒体、 [[直播营销]] 话术的基础结构。它是 [[营销心理学]] 的早期工程化产物。

## 核心要点

### 1. 四阶段对应的写作动作

| 阶段 | 写作目的 | 工具/技巧 |
|---|---|---|
| **Attention** | 抓眼球 | 强标题、惊悚事实、痛点提问、视觉冲击 |
| **Interest** | 留住读者 | 故事、数据、新颖观点、引人好奇 |
| **Desire** | 让 TA 想要 | 痛苦放大、收益描绘、社会证明、稀缺感 |
| **Action** | 触发行动 | 清晰 CTA、零摩擦、紧迫感 |

### 2. AIDA 在不同形式的应用

#### 邮件营销

```
[Subject 标题] - 抓注意:你的网站每月在漏 50% 转化
[预览/首段] - 兴趣:大多数 SaaS 创始人不知道这一点...
[主体] - 欲望:案例 X 用 1 个修改让转化升 23%
[CTA] - 行动:免费下载 50 个落地页对比
```

#### 落地页

```
[Hero/Headline]:Attention - 价值主张 + 痛点共鸣
[Subhead + Video]:Interest - 解释为什么有效
[特性 + 案例 + 社证]:Desire - 让访客想拥有
[CTA 区]:Action - "免费试用"按钮
```

#### 短视频(15-60 秒)

```
0-3s: Attention - 反差、问题、震撼画面
3-15s: Interest - 故事/演示/反转
15-45s: Desire - 价值与好处可视化
45-60s: Action - "点击/留言/购买"
```

### 3. AIDA 的扩展变体

| 公式 | 扩展点 | 适用 |
|---|---|---|
| **AIDA** | 经典 4 阶段 | 通用 |
| **AIDAS** | 加 Satisfaction(满意,促复购) | 客户营销 |
| **AISDALSLove** | 加 Search/Like/Share/Love | 数字营销 |
| **ACCA** | Awareness/Comprehension/Conviction/Action | 教育型 |
| **PASTOR** | Problem/Amplify/Story/Transform/Offer/Response | 长文案,见 [[PASTOR文案公式]] |
| **QUEST** | Qualify/Understand/Educate/Stimulate/Transition | B2B SaaS,见 [[QUEST文案公式]] |
| **FAB** | Features/Advantages/Benefits | 产品介绍 |
| **PAS** | Problem/Agitate/Solution | 短文案 |

### 4. 关键原则

#### a) Attention 之外什么都不重要
读者花在你内容上的时间从前 3 秒决定。这与 [[注意力经济]]、[[首因效应与近因效应]] 深度对应。

#### b) Interest 必须立即兑现 Attention 承诺
Clickbait 标题让点击率飙升但跳出率暴跌——破坏品牌信誉。Interest 阶段要兑现 Attention 阶段的"勾子承诺"。

#### c) Desire 是放大痛/赚乐
**两种基本驱动**:
- 减痛:解决问题、消除焦虑
- 增乐:实现目标、获得地位

[[损失厌恶]] 心理学说明减痛的说服力是增乐的 2 倍。

#### d) Action 必须降摩擦
- 单一 CTA 比多 CTA 转化高
- "立即试用"比"了解更多"具体
- 紧迫感(限时、限量)激活 [[稀缺性]]

### 5. 常见误用

- **Attention 用力过猛但 Interest 苍白**:震惊标题但内容平庸
- **跳过 Desire 直接 Action**:用户没被打动就 CTA,转化必差
- **Action 模糊**:"如有兴趣可联系我们"远不如"点击下单立省 30%"
- **每段都 AIDA**:整个内容应一次 AIDA,不是每段重复

## 当代演进

- **AI 写作辅助**:GPT/Claude 等在 prompt 中标 AIDA 结构能输出更可靠的销售文案
- **多平台微调**:TikTok 的 AIDA 必须在 3 秒内完成 A,小红书的 A 是封面而 I 是首段
- **AB 测试取代直觉**:不同 AIDA 变体用 A/B 测试找最优
- **超越 AIDA 的旅程视角**:[[用户旅程地图]]、[[客户旅程分析]] 把 AIDA 扩展为多次循环
