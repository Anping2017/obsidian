# 运营管理

## 定义

**运营管理**(Operations Management, OM)是对**将各种投入(资源)转化为产出(产品或服务)**的全过程进行**设计、运行、控制和改进**的管理活动。它的核心命题是:

> **如何在质量、成本、速度、灵活性、可靠性之间取得最佳平衡,以最有效地满足客户需求**

运营管理是企业**价值创造的引擎**,从工厂的物料流动到银行的服务流程、从医院的就诊路径到电商的物流配送,无所不包。

## 核心要点

### 投入-转化-产出模型

```
投入(Inputs)         转化过程(Transformation)        产出(Outputs)
- 原材料                                                 - 产品
- 人力                  增值活动:                       - 服务
- 资金        →        - 物理变换                  →    - 信息
- 信息                  - 服务交付                       
- 设备                  - 信息处理                       
- 客户(服务业)                                         
                              ↑
                          反馈控制
```

### 运营战略的四个维度(竞争优先级)

- **成本**(Cost):用最低成本生产
- **质量**(Quality):产品/服务符合标准
- **速度**(Speed):快速响应订单
- **灵活性**(Flexibility):适应需求变化
- **可靠性**(Dependability):按承诺交付

通常**不能同时四优**,需明确战略重点(运营战略层级与 [[波特三种竞争战略]] 对接)。

### 运营管理的核心活动

**1. 流程设计**(Process Design)

- 流程类型:项目型、车间型、批量型、装配线型、连续型
- 流程地图、价值流图(VSM)
- 自动化与数字化设计

**2. 产能规划**(Capacity Planning)

- 长期产能(投资决策)
- 中期产能(产品组合)
- 短期产能(排产)

**3. 设施选址与布局**(Facility Layout)

- 选址因素:成本、市场、人才、政策
- 布局类型:产品式、过程式、定位式、单元式

**4. 生产计划与控制**

- 主生产计划(MPS)
- 物料需求计划(MRP)
- 制造资源计划(MRP II)
- 企业资源计划(ERP)

**5. 库存管理**

- ABC 分类法
- 经济订货量 EOQ
- 安全库存
- JIT 即时生产

**6. 质量管理**(参见 [[质量管理]])

**7. 供应链管理**(参见 [[供应链管理]])

**8. 项目管理**(Project Management)

- PMBOK 五大过程组:启动、规划、执行、监控、收尾
- 关键路径法(CPM)、PERT、甘特图
- 敏捷项目管理(Agile / Scrum)

### 服务运营的特殊性

服务与制造的根本差异:

| 维度 | 制造 | 服务 |
|---|---|---|
| 有形性 | 有形 | 无形 |
| 库存 | 可库存 | 不可库存 |
| 客户参与 | 低 | 高 |
| 同质性 | 标准化 | 高度异质 |
| 生产消费 | 分离 | 同时 |
| 质量评估 | 客观 | 主观 |

催生服务设计、服务蓝图、服务质量(SERVQUAL)等专门方法。

### 现代运营管理趋势

**1. 数字化运营**

- 工业 4.0:物联网、信息物理系统、数字孪生
- 智能工厂:AI 视觉检测、预测性维护
- ERP 升级为数据驱动平台

**2. 可持续运营**

- 绿色制造、循环经济
- ESG 整合到运营 KPI(参见 [[ESG]])
- 碳足迹核算

**3. 韧性运营**

- 疫情、地缘政治冲击使"效率优先"被反思
- 多源采购、近岸生产、安全库存重新评估

**4. 敏捷与精益结合**

- [[精益生产]] + 敏捷 = 精益敏捷
- 软件开发的敏捷思想反向输出制造业

**5. 服务化制造**

- 制造企业销售"产品+服务"组合
- 罗罗发动机按飞行小时收费

### 关键 KPI

| 维度 | 指标 |
|---|---|
| 成本 | 单位成本、运营成本占收入比 |
| 质量 | 缺陷率、首次合格率、退货率 |
| 速度 | 周期时间、交付周期、客户响应时间 |
| 可靠性 | 准时交付率、设备综合效率 OEE |
| 灵活性 | 产品切换时间、订单变更响应 |
| 资产 | 库存周转率、固定资产周转率 |

### 实施挑战

- 平衡多目标的冲突(成本 vs 质量 vs 速度)
- 跨部门协调(运营 vs 销售 vs 财务)
- 文化转型(参见 [[组织文化]])
- 数字化与员工技能差距
- 持续改进与日常执行的张力

## 和其他概念的关系

- 是企业 [[价值链分析]] 中"主要活动"的核心
- 与 [[供应链管理]]、[[精益生产]]、[[质量管理]] 形成运营三剑客
- [[平衡计分卡]] 内部流程维度的主要内容
- 项目管理是运营管理的子领域
- 流程设计与 [[变革管理]] 紧密相关(流程再造 BPR)
- [[管理会计]] 提供运营决策数据支持
- [[财务比率分析]] 中营运能力比率衡量运营效率
- 与 [[战略管理]] 的对接体现为运营战略的优先级选择
- [[领导力]] 在持续改进文化建设中起决定作用(参见 [[变革型领导]])
- 服务运营对接 [[STP分析]]、[[客户关系管理]]、[[客户生命周期价值]]
