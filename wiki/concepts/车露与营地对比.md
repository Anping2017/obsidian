# 车露与营地对比

## 定义

**车露(Car Camping / Overlanding)** 指车开到目的地后**装备从车内取出 / 车顶帐展开 / 车厢改睡眠空间**,车始终是"基地"和"物流中心"的露营方式。

**营地露营(Campground Camping)** 指车开到指定营地停车场,把全部装备**搬运至步行可达的营位**,车不再参与日常生活。

两者最大差异是**车的角色**:车露是"车 + 自然",营地露营是"营位 + 自然"。

## 核心要点

**核心维度对比**

| 维度 | 车露 | 营地露营 |
|---|---|---|
| 空间预算 | 车厢空间(2-4 m³ 货箱) | 几乎无限(可拉拖车) |
| 移动性 | 高(随时换地) | 低(扎营后大件不动) |
| 舒适度 | 中-高(车顶帐 / 车内床) | 高(大型棚 + 户外厨) |
| 营位规则 | 弱(野营点 / 营地皆可) | 强(指定营位 + 时间) |
| 价格 | 油费 + 装备 | 营位费(¥50-300/晚) |
| 设施配套 | 自给自足 | 营地有水电厕浴 |
| 风险等级 | 中(野营无救援) | 低(管理员 / 邻居) |

**车露的子流派**

1. **车顶帐(Roof Top Tent, RTT)**:车顶展开式帐篷
   - 优点:扎营 1 分钟、离地高(防虫蛇)、视野好
   - 缺点:重(40-80 kg)、油耗增、限车型
   - 代表:iKamper、Roofnest、自由之魂

2. **拖车房车(Travel Trailer)**:房车房型,带轮可拉
   - 优点:有床有厨有卫(部分)、长期居住
   - 缺点:需 SUV / 越野车牵引、停车难
   - 代表:Airstream、Forest River

3. **货车改装(Van Life)**:面包车 / 厢式车改睡卧厨
   - 优点:一体化、隐蔽性好、长居生活
   - 缺点:改装成本(¥2-20 万)、转售贬值
   - 代表:Sprinter、Transit、Promaster 改装

4. **皮卡 + 后斗帐(Truck Bed Tent)**:皮卡后斗装帐
   - 优点:载货 + 睡眠双能
   - 缺点:防雨依赖帐质量

5. **越野车 + 地面帐**:车作储物 / 充电,人睡地面帐
   - 优点:灵活、保留车性能
   - 缺点:扎营时间长

**营地的等级**

| 等级 | 特征 | 价格(中国/美国) |
|---|---|---|
| 国家公园营地 | 基本水电、洗浴、车位 | ¥80-200 / $30-50 |
| 商业营地 | 完善设施、Wi-Fi、餐饮 | ¥200-800 / $50-100 |
| 野营点 | 无设施、自带水电、可能违法 | 免费 |
| Glamping 营地 | 帐已搭好、有床、含餐 | ¥800-3000 / $150-500 |

**车露的电力问题**

车露常需为冰箱、灯、手机、车顶帐充气泵供电。方案:
- **车载电瓶 + 隔离器**:防止露营把启动电瓶用空
- **便携储能(Power Station)**:Anker / EcoFlow / Jackery,500-2000Wh
- **太阳能板 + MPPT**:长途车露关键补能
- **车载冰箱**:压缩式 12V/24V,40-80W 持续

**Overlanding 的全球流派**

- **澳大利亚 Outback**:四驱 + 越野房车,长距离穿越
- **北美 Rockies**:皮卡 + RTT,周末短途
- **非洲 Safari**:专业旅行车 + 帐篷,商业组织
- **中亚丝路**:摩托 / 越野车 + 远征装备
- **中国新疆 / 青藏**:近年崛起,需车辆改装防高反 / 防故障

## 与其他概念的关系

车露与 [[徒步露营]] 是装备复杂度光谱两端,与 [[Glamping精致露营]] 在舒适度上重叠。营地露营基础上的 [[户外电力系统]]、[[户外炊具系统]]、[[帐篷类型]] 选择都比徒步松弛得多。

## 高频陷阱

- 车顶帐增加车风阻 → 油耗 +10-30%、限速降
- 国内多数自然保护区禁止野营 → 需提前查规
- 车载冰箱 12V 持续耗电,3-4 天无补能就耗光
- 车顶帐展开后底盘升高,留意低矮树枝 / 限高
- 房车不是能停哪都停,大多数城市禁止房车过夜
