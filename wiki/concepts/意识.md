# 意识

## 定义

**意识**(Consciousness)是主体对自身经验、感觉、思维与外部世界的**主观觉知能力**,具备"现象性质"(qualia)——红色之"红"、痛之"痛"在第一人称视角下是什么感受。它是心灵哲学中所谓"**意识的硬问题**"(查默斯, 1995)的核心,也是认知科学、神经科学、人工智能领域的前沿议题。

## 核心要点

### 多重维度

- **觉醒度**(Wakefulness):清醒 vs 睡眠 vs 麻醉
- **觉知**(Awareness):对内容的把握(感知、记忆、思维)
- **自我意识**:对"我是谁"的反思
- **现象意识**:第一人称感受质(qualia)
- **接入意识**:可被报告、用于推理与行为控制的内容

### 意识的"硬问题"

- **易问题**:意识如何从神经活动产生(可由认知神经科学逐步攻克)
- **硬问题**:为什么这些过程**伴随**主观体验?物理过程为何不"沉默"?
- 这是哲学家大卫·查默斯的著名提问,至今无公认答案

### 主要哲学立场

| 立场 | 核心主张 |
|---|---|
| **二元论** | 心灵与物质是两种实体(笛卡尔) |
| **[[物理主义]]** | 一切心灵状态归根是物理状态 |
| **功能主义** | 意识是一种功能角色,可在不同基质中实现(硅基也行) |
| **泛心论** | 意识是物质的基本属性之一 |
| **取消论** | "意识"概念应被神经科学概念取代 |

### 现代理论候选

- **全局工作空间理论(GWT)**:意识是信息广播到全局工作空间
- **整合信息理论(IIT)**:意识量 = 系统中整合信息(Φ)
- **高阶理论**:意识是关于心理状态的元表征
- **预测加工**:大脑作为预测机器,意识是预测的最优解

### 与潜意识的关系

参见 [[意识与潜意识]]、[[弗洛伊德]] 与 [[荣格]] 的精神分析传统;现代认知科学揭示了大量"无意识加工"(注意、记忆、决策)。

## 和其他概念的关系

- 与 [[二元论]]、[[物理主义]] 在心灵哲学上互为答案
- 是 [[现象学]] 关注的核心(胡塞尔、梅洛-庞蒂)
- 与 [[自由意志]]、[[决定论]] 议题深度交织
- 在 [[禅宗]]、[[佛家]] 等东方传统中有不同进路
- 与 [[认识论]] 关于"我们如何知道自己在思考"的问题相连
