# 分治算法 Divide and Conquer

## 定义

**分治(Divide and Conquer)**是一种[[算法]]设计范式,分三步:
1. **分(Divide)**:把原问题分解为若干**互不重叠**、规模更小的同类子问题
2. **治(Conquer)**:[[递归]]地求解各子问题
3. **合(Combine)**:把子问题的解组合成原问题的解

关键特征是子问题"互不重叠":这区分了分治与[[动态规划]](DP 的子问题重叠,需保存)。

## 核心要点

### 复杂度分析:主定理

分治的递推:T(n) = a·T(n/b) + f(n),a 是子问题数,b 是规模缩减因子,f(n) 是合并代价。

主定理(Master Theorem)三种情形:
- f(n) = O(n^c),c < log_b(a) → T(n) = O(n^(log_b a))
- f(n) = O(n^c),c = log_b(a) → T(n) = O(n^c · log n)
- f(n) = Ω(n^c),c > log_b(a) → T(n) = O(f(n))

例:归并排序 T(n) = 2T(n/2) + O(n),c=1=log₂2 → O(n log n)。

### 经典分治算法

| 算法 | 分 | 合 | 复杂度 |
|---|---|---|---|
| 归并排序 | 数组对半分 | 双指针归并 | O(n log n) |
| 快速排序 | 按 pivot 分区 | 无需(原地) | 平均 O(n log n) |
| 二分查找 | 折半 | 无需 | O(log n) |
| 大整数乘法(Karatsuba) | 数字对半 | 三次乘法+加法 | O(n^1.585) |
| 矩阵乘法(Strassen) | 矩阵分块 | 7 次子矩阵乘+加 | O(n^2.807) |
| 最近点对 | 按 x 中位分 | 跨界 O(n) 检查 | O(n log n) |
| FFT 快速傅立叶 | 偶/奇下标分 | 蝴蝶变换 | O(n log n) |
| 棋盘覆盖 | 田字分 | 拼接 L 形骨牌 | O(4^n) |

### 与其他范式对比

| 维度 | 分治 | [[动态规划]] | [[贪心算法]] |
|---|---|---|---|
| 子问题 | 互不重叠 | 重叠 | 退化(每步唯一) |
| 状态保存 | 否 | 是 | 否 |
| 复杂度提升来源 | 把 O(n²) 降到 O(n log n) | 避免重算指数级展开 | 单步贪心 |

### 工程实现要点

- **递归基(Base Case)** 必须正确,否则栈溢出
- **小规模切换迭代**:n 很小时分治反而慢,常切换到插入排序
- **并行化**:子问题独立 → 可分配到多核/多机
  - 归并排序、快速排序的并行版本是高性能计算入门
  - MapReduce 是大规模分治
- **栈深度**:T(n) = T(n/2) 递归 log n 层,问题不大;T(n) = 2T(n/2) 串行也只 log n 层。但快排最坏 O(n) 深度,需注意

### 分治在系统设计中的体现

- **[[分布式系统]]**:分片(sharding)就是分治,每个分片独立处理后聚合
- **数据库的 partition + merge**:OLAP 引擎(Presto、Spark)在多台机器上分别计算后合并
- **CDN 的多级回源** 也接近分治

## 和其他概念的关系

分治紧密依赖[[递归]]作为实现工具,但思想上更强调"互不重叠的子结构"。[[动态规划]]从分治演化而来,加上"记忆"以处理重叠子问题。[[贪心算法]]在某种意义上是分治的极简形式。

[[排序算法]]中,归并和快排是分治范例;非分治的排序(冒泡、插入、堆排)分别基于其他思想。

[[图]]算法 Floyd-Warshall 全源最短路是 DP 形式但内核是分治思想。机器学习的"集成学习(Ensemble)"——bagging、随机森林——也带分治色彩(对数据子集独立训练再投票合并)。
