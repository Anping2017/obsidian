# 印度哲学

## 定义

**印度哲学**(Indian Philosophy)是世界最古老、最连续的哲学传统之一,起源于约公元前 1500 年的**吠陀经典**,经奥义书、史诗、佛陀时代、各派论典、中古综合,延续 3500 年至今。其核心关切是**解脱**(moksha,从轮回中解放)与**自我**(atman)与**梵**(brahman)的关系。

## 历史脉络

### 吠陀时期(前 1500-前 600)

- **四吠陀**:《梨俱吠陀》《娑摩吠陀》《耶柔吠陀》《阿闼婆吠陀》
- 以**祭祀**为核心,神话与仪式并行
- 早期诗篇展现哲学萌芽:"创世何来?谁知此事?"

### 奥义书时期(前 800-前 500)

- **奥义书**(Upanishads):"近坐而传"的秘密哲学
- 提出根本命题:**"梵我合一"**(Tat tvam asi —— 你即是那)
- **阿特曼**(atman,自我)与**梵**(brahman,绝对)是同一
- 业(karma)、轮回(samsara)、解脱(moksha)三大概念
- 这是印度哲学心脏

### 史诗与经典时期(前 500-公元 200)

- **《薄伽梵歌》**(Bhagavad Gita):史诗《摩诃婆罗多》中的哲学诗
- **三种瑜伽**:业瑜伽、知瑜伽、信瑜伽
- 同期出现**佛教**(详见 [[佛家]])与**耆那教**

### 经典体系化时期(200-1200)

- 正统六派(Astika)与异端(Nastika)系统化
- 各派写下**经**(sutra)与**注释**(bhasya)

### 中古综合(1200-1700)

- 商羯罗、罗摩奴阇、摩陀婆等大师不同诠释
- 与伊斯兰苏非传统接触
- 锡克教兴起

### 现代复兴(1850-)

- 罗摩克里希纳、辨喜(Vivekananda):吠陀的现代化
- 甘地:实践哲学
- 奥罗宾多:整体瑜伽
- 与西方哲学对话

## 正统六派(Astika)

承认吠陀权威的六个系统:

| 派别 | 核心 | 代表 |
|---|---|---|
| **数论**(Samkhya) | 二元:神我(purusha)与原质(prakriti) | 自在黑 |
| **瑜伽**(Yoga) | 实践方法,八支瑜伽 | 帕坦伽利《瑜伽经》 |
| **正理**(Nyaya) | 逻辑学、认识论 | 乔达摩 |
| **胜论**(Vaisheshika) | 范畴论、原子论 | 迦那陀 |
| **弥曼差**(Mimamsa) | 吠陀诠释、祭祀 | 阇弥尼 |
| **吠檀多**(Vedanta) | 奥义书诠释、最有影响 | 商羯罗 |

## 异端(Nastika)

不承认吠陀权威的传统:

- **[[佛家|佛教]]**:四圣谛、八正道、缘起、空(详见 [[佛家]])
- **耆那教**(Jainism):非暴力(ahimsa)、灵魂多元、相对真理
- **顺世派**(Carvaka):唯物主义、无神论(罕见)

## 核心概念

### 业(Karma)

- 行为的因果效力
- 不只是行为,还包括意图与思想
- 决定来世形态(轮回)
- 与西方道德责任、 [[决定论]] 不同:业是非人格化的因果律

### 轮回(Samsara)

- 生命在六道中轮转
- 由业牵引
- 是受苦的循环
- 解脱即跳出轮回

### 解脱(Moksha)

- 从轮回中解放
- 不同派别理解不同:与梵合一(吠檀多)、灭尽烦恼(佛教)、灵魂净化(耆那教)
- 这是印度哲学的最高目标

### 阿特曼与梵

- **阿特曼**(atman):内在自我、灵魂
- **梵**(brahman):宇宙绝对本体
- **梵我合一**(advaita):二者本质同一
- 这是吠檀多核心命题

### 三德(Gunas)

- **悦性**(sattva)、**激性**(rajas)、**惰性**(tamas)
- 描述事物三种基本性质
- 影响行为与世界状态

### 八正道与八支瑜伽

- 佛家八正道:正见、正思、正语、正业、正命、正精进、正念、正定
- 瑜伽八支:禁戒、劝戒、坐法、调息、制感、专注、禅定、三摩地

## 与西方哲学的对话

- 叔本华深受奥义书影响
- 爱默生、梭罗超验主义引用
- 海德格尔后期与京都学派对话(连带印度)
- 当代分析哲学家(Matthew Dasti、Jonardon Ganeri)研究正理派逻辑

## 现代实践影响

- **瑜伽**:身心修炼传遍全球
- **正念**(mindfulness):源自佛教,影响 [[正念]]、 [[积极心理学]]
- **非暴力**:甘地通过马丁·路德·金影响美国民权运动
- **冥想科学**:神经科学验证冥想效果

## 和其他概念的关系

- 与 [[佛家]] 直接同根(印度哲学的异端派之一)
- 与 [[儒家]]、 [[道家]] 在东方哲学传统中的并列
- 与 [[西方哲学]] 形成跨文化对照
- 与 [[本体论]] 之"绝对实体"问题
- 与 [[认识论]] 之"现量、比量"等知识来源
- 与 [[决定论]]/[[自由意志]] 之"业"的因果性
- 与 [[心理学]] 现代正念(详见 [[正念]])直接源流
- 与 [[积极心理学]] 之"自我超越"主题
- 与 [[逻辑]] 中印度因明学(正理派)是世界三大逻辑之一
- 与 [[心灵哲学]] 之"自我同一性"问题
- 影响叔本华、爱默生、容格、马斯洛
- 历史定位:与 [[西方哲学]]、中国哲学并列世界三大哲学传统
