# 结构化数据

## 定义

**结构化数据(Structured Data)** 是用标准化词汇与格式为网页内容添加机器可读的语义标记,使搜索引擎能精确理解"这是什么内容、其中各属性是什么"的技术。

主流标准是 **Schema.org**(由 Google、Bing、Yahoo、Yandex 联合维护)。最常用的实现格式是 **JSON-LD**(JavaScript Object Notation for Linked Data),其他还有 Microdata 与 RDFa。

结构化数据的最直接收益是触发**富媒体结果(Rich Results)**——搜索结果页中的星级评价、价格、库存、FAQ 折叠、HowTo 步骤、招聘信息卡片等。AI 搜索时代(Google AI Overviews、Perplexity)结构化数据的重要性进一步提升,因为 AI 需要明确的结构化信号来引用与摘要内容。

## 核心要点

- **Schema.org 标准**:由 Google 等主流搜索引擎联合维护,提供数百种类型(Type)与属性(Property)。常用类型包括:
  - **Article / NewsArticle / BlogPosting**:文章类
  - **Product / Offer / AggregateRating / Review**:电商类
  - **Organization / Person**:实体类
  - **LocalBusiness**(及其细分如 Restaurant、Store):本地商家
  - **FAQPage / QAPage**:问答类
  - **HowTo**:操作指南
  - **Recipe**:食谱
  - **Event**:活动
  - **JobPosting**:招聘
  - **VideoObject**:视频
  - **Course**:课程
  - **BreadcrumbList**:面包屑
  - **WebSite + SearchAction**:站内搜索框
- **三种实现格式**:
  - **JSON-LD**(推荐):独立 `<script>` 标签,与 HTML 分离,易维护,Google 强烈推荐
  - **Microdata**:HTML 属性内嵌,需要修改原 HTML 结构
  - **RDFa**:类似 Microdata,主要用于学术/政府数据
- **富媒体结果(Rich Results)** 收益:
  - **CTR 提升**:大量研究显示 30-50% CTR 提升
  - **点击质量提升**:用户从 SERP 看到更多信息后,点击意图更明确
  - **品牌曝光**:同样的排名位置,占的视觉面积更大
- **AI 搜索时代的新角色**:
  - 结构化数据是 AI 引用的"可信源信号"
  - LLM 抓取偏好结构化页面,更容易被 AI Overviews 引用
  - schema.org 正在扩展支持 AI Agent(如 SchemaAgent)
- **常见 Schema 应用**:
  - **博客/媒体站**:Article + BreadcrumbList + FAQPage(在合适页面)
  - **电商站**:Product + Offer + AggregateRating + Review
  - **本地商家**:LocalBusiness + 子类型 + GeoCoordinates + OpeningHoursSpecification
  - **SaaS / 公司站**:Organization + WebSite + SearchAction + 各类页面 schema
  - **教程/技术博客**:HowTo + Article + FAQPage
- **测试与验证**:
  - **Schema Markup Validator**(由 schema.org 维护):检验语法
  - **Rich Results Test**(Google):检验是否能触发富媒体结果
  - **Google Search Console**:监控生效率与错误
  - **Schema Markup Generator**:辅助生成
- **常见误区**:
  - 结构化数据虚假标记(标错、标不存在的内容)→ Google 会降权或人工惩罚
  - 标记完忘了维护(产品价格变了 schema 没改)
  - 使用过时的 schema 类型(部分类型已弃用)
  - 在小站点过度使用(如对每篇文章都加 FAQ)
  - 把 schema 当排名捷径(实际是相关性放大器,而非排名因素本身)

## 和其他概念的关系

结构化数据是 [[技术SEO]] 中重要的子项,影响 [[Google搜索工作原理]] 中的索引环节(帮助 Google 理解内容)。

结构化数据是 [[E-E-A-T]] 在技术层的补充——准确的 schema(作者、组织、出版日期、引用)是机器可识别的信任信号。

[[本地SEO]] 严重依赖 LocalBusiness schema 与 NAP 信息的结构化标记。

[[电商SEO]] 中 Product schema(价格、库存、评价、品牌)是 Google Shopping、AI 推荐的基础。

结构化数据与 AI 搜索时代的 RAG(Retrieval-Augmented Generation)系统天然契合——结构化页面更容易被 AI 检索、解析、引用。

[[关键词研究]] 与 [[搜索意图]] 在结构化数据时代加入新维度:某些查询的 SERP 是结构化驱动的(食谱、HowTo、FAQ),不做 schema 等于不参与该 SERP 形态。
