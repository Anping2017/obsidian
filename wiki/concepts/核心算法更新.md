# 核心算法更新

## 定义

Core Update(核心算法更新)是 Google 每年发布 3-4 次的全局算法整体调整,2018 年 8 月 Medic Update 起 Google 开始正式命名并预告 Core Update。区别于针对单一问题的专项更新(如 Spam Update 反垃圾、HCU 反低质内容),Core Update **不针对特定问题,而是重新评估整个排名系统对内容质量与相关性的判断**,涉及 E-E-A-T、内容质量、用户体验等多维度信号的整体重权。每次 Core Update 通常导致 SERP 大规模波动,被惩罚的网站若不调整可能数月不恢复,是 SEO 从业者必须实时跟踪的关键事件。

## Core Update 的特点

### 1. 全局影响

- 涵盖几乎所有类目与查询
- 不同行业波动幅度差异大
- 中小站点波动通常大于大站

### 2. 慢速展开(Rollout)

- 单次 Core Update 通常 1-3 周完成全球展开
- 部分大型更新延长至 4-6 周
- 期间 SERP 反复震荡,不要过早下结论

### 3. 难以"修复"

- Google 多次表态:Core Update 不针对具体问题,无法通过单点修改快速恢复
- 唯一路径:全面提升内容质量与 E-E-A-T 信号
- 通常需要等下次 Core Update 才能反弹(可能 3-6 月)

### 4. 输赢双向

- 不仅惩罚低质,也奖励高质
- 流量损失方与流量获得方同时存在
- Sistrix/SEMrush 等工具发布"赢家与输家"报告

## 应对方法论

### 监测期(更新公布到完全展开)

1. 立即在 Search Console 中标注更新日期(Annotation)
2. 每天观察品牌词、核心词排名波动
3. 对比 GA 与 GSC 流量与点击曲线
4. 不要急于"修复"——展开未完前判断会误导

### 评估期(展开完成后 2-4 周)

1. 对比展开前后流量、排名、CTR、印象数
2. 找出**显著下跌的页面与查询**
3. 对比竞品与赢家页面,找差异化信号
4. 分类下跌类型:
   - YMYL 类目下跌 → E-E-A-T 信号弱
   - 信息查询下跌 → 内容质量、Helpful Content
   - 评测类下跌 → Reviews Update 同期影响
   - 全站下跌 → 站点级质量问题

### 改进期(整改 2-6 个月)

1. **内容质量审计**:删除低质 / 合并 / 重写
2. **E-E-A-T 加固**(参见 [[E-E-A-T操作化]]):作者档案、外链、权威信号
3. **技术 SEO 检查**:Core Web Vitals、可访问性、移动端
4. **链接资料净化**:Disavow 垃圾外链
5. **持续高质量内容产出**:保持发布节奏

### 等待恢复期

- 大幅惩罚通常需要等下一次 Core Update 才能恢复
- 期间持续整改,不要操之过急
- 与 Google 的"惩罚"不同,Core Update 是算法重权,无申诉机制

## 与其他更新的区分

| 类型 | 频率 | 特点 |
|---|---|---|
| **Core Update** | 年 3-4 次 | 全局重权 |
| **Spam Update** | 年 1-2 次 | 反垃圾,人工 + 算法 |
| **Helpful Content Update** | 不定期 | 反低质内容 |
| **Reviews Update** | 不定期 | 评测类专项 |
| **Product Reviews Update** | 已并入 Reviews | 历史名 |
| **小型算法更新** | 持续 | 不公布,自动迭代 |

## 行业典型受灾案例

### 2024-03 March Core Update

- 史上最长(持续 45 天)
- 重点打击:AI 量产内容、过期域劫持、薄附属营销
- 大量 niche 站、内容农场、HARO 滥用站损失 50-95%
- Reddit、社交平台流量大涨,因 Google 强调"真人体验"
