# 决策科学

## 定义

**决策科学**(Decision Science)是一门**跨越行为经济学、运筹学、统计学、心理学、认知科学、计算机科学的交叉学科**,系统研究**人类与机构在不确定性、有限信息、复杂目标下如何做出决策,以及决策如何被改进**。

它既包含**规范性研究**(理性应当如何)、**描述性研究**(人实际怎么做)、**处方性研究**(如何帮助决策更好),也包含工程化实践,如**数据驱动决策、A/B 测试、行为助推、决策支持系统、AI 辅助决策**等。

代表机构:卡内基梅隆大学 SDS、哈佛 Kennedy School Behavioral Insights Group、Carnegie Mellon Decision Sciences Lab、Penn Wharton's Decision Lab、英国 BIT(Behavioural Insights Team)。

## 核心要点

### 学科地图

| 维度 | 代表理论 / 工具 |
|---|---|
| **规范性** | 期望效用、贝叶斯决策、博弈论 |
| **描述性** | [[前景理论]]、双系统理论(Kahneman 系统 1 / 系统 2)、有限理性(Simon) |
| **处方性** | Nudge、决策辅助系统、Pre-mortem |
| **方法论** | 实验经济学、田野实验、神经经济学、计算建模 |
| **应用领域** | 医疗、公共政策、金融、产品设计、AI 治理 |

### 关键人物

- **Herbert Simon**:有限理性(Bounded Rationality)、satisficing
- **Daniel Kahneman / Amos Tversky**:[[前景理论]]、启发式与偏差
- **Richard Thaler / Cass Sunstein**:Nudge、行为公共政策
- **Gerd Gigerenzer**:启发式的"生态理性"
- **Gary Klein**:自然主义决策(NDM)、[[Pre-mortem]]
- **Philip Tetlock**:Superforecasters,决策预测竞赛
- **Robyn Dawes**:统计预测 vs 临床预测
- **Howard Raiffa**:决策分析的奠基者

### 决策科学的核心议题

#### 1. 偏差与启发式

- 代表性、可得性、锚定 → 系统性偏差
- 但启发式在生态合适下高效(Gigerenzer)

#### 2. 不确定性与概率

- 频率派 vs 贝叶斯
- 风险(probability known) vs 不确定性(unknown)
- 极端事件(黑天鹅、灰犀牛)

#### 3. 多目标决策

- AHP 层次分析法
- 加权评分模型
- 帕累托前沿

#### 4. 群体决策

- 投票悖论(Arrow)
- 协商 vs 投票
- 集体智慧(Wisdom of Crowds)与群体迷思

#### 5. 决策质量评估

- 决策 vs 结果:好决策也可能坏结果
- 校准与可问责性
- 决策日志(decision journal)实践

#### 6. 与 AI 的边界

- 算法辅助 vs 算法替代
- 人机协同(human-in-the-loop)
- 算法透明度与公平性

### 关键方法工具

| 工具 | 用途 |
|---|---|
| **决策树** | 把决策可视化、量化期望值 |
| **蒙特卡洛模拟** | 处理不确定性分布 |
| **场景规划** | 构造多个未来,而非单点预测 |
| **决策矩阵** | 多目标加权 |
| **Pre-mortem** | 前瞻性风险识别(见 [[Pre-mortem]]) |
| **校准训练** | 提升概率估计准确度 |
| **决策日志** | 区分决策质量与结果质量 |
| **OODA Loop** | 高速循环决策(军事 → 商业) |
| **Cynefin 框架** | 区分简单/复杂/混沌情境 |

### 描述性 vs 规范性 vs 处方性

- **规范性**:理性人应该怎么做(期望效用、贝叶斯)
- **描述性**:真实人实际怎么做(前景理论、双系统)
- **处方性**:如何帮助真实人做得更好(Nudge、Pre-mortem、决策训练)

三个层次的张力是决策科学的核心议题。

## 应用场景

- **公共政策**:Nudge Unit 的行为政策设计
- **医疗**:循证决策、临床决策支持系统
- **金融**:风险定价、信贷模型、量化投资
- **国防与情报**:Tetlock 预测竞赛、ICA 评估方法
- **产品与运营**:A/B 测试体系、定价优化、推荐系统
- **企业战略**:场景规划、Pre-mortem、决策委员会设计
- **个人决策**:重大人生选择的结构化方法

## 局限与陷阱

- **学科边界模糊**:与 OR、心理学、AI 多重交叉,定义不清
- **实验外推问题**:实验室结论难以推广到真实复杂情境
- **可复制性危机**:行为经济学多个经典实验复制失败
- **量化盲点**:难以量化的因素(伦理、文化)被遗漏
- **算法替代风险**:决策科学工具被简化为"让算法做"
- **专业精英主义**:Nudge 等被批评"家长式"
- **个体 vs 系统**:个体决策训练难以改善系统问题
- **认知改造有限**:偏差教育的效果远不如制度设计

- [[卡尼曼]]、[[塞勒]] 是核心人物
