# GDP核算

## 定义

**国内生产总值(GDP, Gross Domestic Product)**:一国(或地区)在**一定时期**内、**境内**生产的全部**最终**商品和服务的**市场价值**之和。

四个限定词缺一不可:
- **境内**:按地理位置而非国籍(GDP 与 GNP 区别的核心)
- **一定时期**:流量概念,通常以年或季度为单位
- **最终**:仅最终用途产品,避免中间产品重复计算
- **市场价值**:按市场价格统一加总

GDP 是宏观经济学的核心总量指标,是 [[IS-LM模型]]、[[AD-AS模型]]、[[经济增长理论]] 的关键变量,也是制定 [[财政政策]]、[[货币政策]] 的基础数据。

## 核心要点

### 三种等价计算方法

**生产法(增加值法)**:

```
GDP = Σ 各行业增加值 = Σ (总产出 − 中间投入)
```

**收入法(分配法)**:

```
GDP = 劳动者报酬 + 生产税净额 + 固定资产折旧 + 营业盈余
```

**支出法(使用法)**:

```
GDP = C + I + G + (X − M)
```

其中 C 为消费,I 为投资(含存货变动),G 为政府购买,X 为出口,M 为进口。NX = X − M 称为净出口。

三种方法在理论上完全相等(国民经济会计恒等式),实践中略有统计误差。

### 名义 GDP vs. 实际 GDP

```
实际 GDP = 名义 GDP / GDP 平减指数 × 100
```

- **名义 GDP**:按当年市场价格 P_t × Q_t 计算,包含价格变化
- **实际 GDP**:按基年价格 P_0 × Q_t 计算,剔除价格变化,衡量真实产出

GDP 平减指数(GDP Deflator)是衡量整体价格水平的最广义价格指数,详见 [[价格指数与通胀]]。

### GDP 与 GNP

- **GDP**:境内国民产值(地理标准)
- **GNP**:本国国民产值(国籍标准)

```
GNP = GDP + 本国人在外国的净要素收入
```

中国留学生在美国打工:计入美国 GDP、中国 GNP。富士康在中国生产:计入中国 GDP、台湾 GNP。

随经济全球化,GDP 与 GNP 差异在小型开放经济中可达 GDP 的 5-15%(如爱尔兰、新加坡)。

### 国民收入循环

封闭经济中,生产环节(企业)创造价值 → 收入环节(家庭)获得报酬 → 支出环节(消费)回流企业 → 形成循环。

引入政府(税收、转移支付、政府购买)、外国部门(进出口)、金融部门([[商业银行]] 把储蓄转化为投资)后,循环更复杂但恒等式仍成立:

```
S − I = G − T + NX
私人储蓄缺口 = 政府赤字 + 经常账户盈余
```

这是宏观三大账户的核心恒等式,在 [[国际收支]] 分析中至关重要。

### GDP 的局限性

GDP 不衡量:
- **非市场活动**:家务劳动、志愿服务、影子经济
- **质量提升**:同一产品质量改善难以纳入
- **环境成本**:GDP 把治污支出加进来,但不扣除环境破坏
- **收入分配**:总量 GDP 高 ≠ 普遍富裕(基尼系数补足)
- **生活质量**:闲暇、健康、安全感无法捕捉
- **可持续性**:消耗自然资本是当下 GDP 的虚高

替代指标:HDI(人类发展指数)、GPI(真实进步指标)、GNH(国民幸福总值)、绿色 GDP。但 GDP 仍因数据可比、定义清晰、与生产能力高度相关,而保持核心地位。

## 和其他概念的关系

GDP 是宏观经济学的核心因变量。短期经济波动通过 [[IS-LM模型]]、[[AD-AS模型]] 解释 Y 的偏离潜在产出 Y* 的幅度;长期增长通过 [[经济增长理论]] 分析 Y* 自身扩张速度。

[[价格指数与通胀]] 通过 GDP 平减指数与 GDP 直接关联;[[失业理论]] 通过奥肯定律(Okun's Law)与 GDP 相联(GDP 缺口 ↔ 失业缺口);[[菲利普斯曲线]] 把通胀与失业关联,从而把 GDP、π、U 三大变量纳入统一框架。

[[财政政策]] 直接通过 G、T 影响 AD = C + I + G + NX;[[货币政策]] 通过利率影响 I 与 NX(汇率渠道)从而影响 GDP。

跨域:[[企业价值评估]] 中宏观经济增长率(GDP 增速)是 DCF 模型永续增长率假设的上限;[[资产定价模型]] 中 CAPM 的市场组合通常以 GDP 加权或市值加权;[[资产配置]] 跨国分散需考虑各国 GDP 规模与增长前景;[[国际收支]] 与 GDP 共同构成开放宏观分析的双支柱。

会计学连接:GDP 核算与企业财务报表本质同源 —— 国民账户体系(SNA)就是把全国所有企业的报表按统一规则汇总。生产法的"总产出 − 中间投入 = 增加值"对应每家企业的 [[利润表]] 视角(全国版);收入法的"劳动者报酬 + 营业盈余 + 折旧"恰是企业利润表的成本费用结构,其"固定资产折旧"项与会计上的折旧概念完全一致;支出法的 C+I+G+NX 对应全社会终端用户的购买记录。SNA 全套核算所采用的方法即 [[复式记账法]] 在国家层面的应用,而 [[会计要素]] 中的资产、负债、所有者权益是国家资产负债表(类似企业 [[资产负债表]])的微观基础。
