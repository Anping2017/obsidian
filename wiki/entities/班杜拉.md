# 班杜拉 Albert Bandura

## 简介

**阿尔伯特·班杜拉**(Albert Bandura,1925-2021),加拿大裔美国心理学家,斯坦福大学教授。**社会认知理论**(Social Cognitive Theory)创始人。多次被评为 **20 世纪最有影响力的心理学家**之一(仅次于 [[斯金纳]]、 [[弗洛伊德]]、 [[皮亚杰]])。其工作架起了 [[行为主义]] 与 [[认知主义]] 的桥梁。

## 关键贡献

### 观察学习(Observational Learning)

- 学习不必通过亲身经验,**观察他人**就够
- 这突破了 [[行为主义]] 的"亲身强化"框架
- 关键步骤:**注意 → 保持 → 复制 → 动机**
- 强化可以是**替代性**的(看别人受奖也学会)

### 波波玩偶实验(Bobo Doll Experiment,1961)

- **经典研究**:儿童看到成人攻击充气玩偶后,自己也表现出更多攻击
- 证明:**暴力可以通过模仿习得**
- 引发对**电视暴力对儿童影响**的长期研究与政策辩论
- 是 20 世纪最被引用的心理学实验之一

### 社会学习理论(Social Learning Theory,1977)

- 整合行为主义与认知主义
- 学习涉及:行为—认知—环境的**三元交互**
- 这是对斯金纳"环境决定论"的关键修正
- 后扩展为"社会认知理论"

### 三元交互决定论(Triadic Reciprocity)

- **行为(B)、个人因素(P)、环境(E)**相互影响
- B ↔ P ↔ E
- 不同于纯环境决定或纯个人决定

### 自我效能感(Self-Efficacy,1977)

- **自我效能**:个人对自己能否成功完成特定任务的信念
- 来源四类:
  1. **掌握经验**(过往成功)
  2. **替代经验**(看他人成功)
  3. **言语劝说**(被告知能行)
  4. **生理情绪状态**(放松/紧张)
- 影响选择、努力、坚持
- 这是当代 [[积极心理学]]、教育、组织、健康行为研究的核心概念
- 与 [[组织行为学]]、 [[领导力]]、 [[激励理论]] 紧密相关

### 自我调节(Self-Regulation)

- 通过**自我监控、自我评价、自我反应**调控行为
- 不需要外部强化
- 是斯金纳模型缺失的"内在控制"维度

### 道德脱离(Moral Disengagement)

- 后期研究:为何"好人"也会做坏事
- 八种机制:道德合理化、委婉语、扩散责任等
- 与汉娜·阿伦特"恶之平庸"、 [[认知失调]] 形成解释链
- 应用于战争心理、企业丑闻、网络欺凌

## 主要著作

- **《社会学习理论》**(Social Learning Theory,1977)
- **《思想与行动的社会基础》**(Social Foundations of Thought and Action,1986)
- **《自我效能:控制感的实施》**(Self-Efficacy: The Exercise of Control,1997)
- **《道德脱离》**(Moral Disengagement,2016)

## 现代影响

### 教育

- **自我效能**是动机研究核心
- 对成绩、坚持、目标设定有强预测力
- 影响学习设计、教师培训

### 健康行为

- 戒烟、运动、饮食习惯改变都用自我效能模型
- **健康行动过程取向**(HAPA)
- 结合 [[卡尼曼]] 行为决策做"助推"干预

### 组织管理

- **员工自我效能**与绩效正相关
- 领导通过示范行为塑造组织文化
- 影响 [[组织行为学]]、 [[激励理论]]

### 临床

- 自我效能不足是抑郁、焦虑核心
- [[认知行为疗法]] 中常作为治疗目标

### 媒体心理学

- 波波玩偶实验催生了媒体暴力研究
- 拓展到电视、电影、电子游戏、社交媒体的心理影响

### 数字产品

- 用户的"我能用好这个产品"信念决定留存
- UX 设计中**自我效能友好**(成就反馈、任务分解)

## 个人

- 1925 年生于加拿大艾伯塔小镇,家庭来自波兰、乌克兰
- 在没有书的小镇长大,反而培养自学习惯
- 不列颠哥伦比亚大学本科,爱荷华大学博士
- 1953 年加入斯坦福,任教 60+ 年
- 2016 年获美国国家科学奖章(总统颁发)
- 95 岁高龄逝世,仍在工作

## 相关概念/实体

- 与 [[行为主义]]、 [[认知主义]] 是桥梁人物
- 与 [[斯金纳]]、 [[巴甫洛夫]] 之严格行为主义形成扩展
- 与 [[精神分析]] 在解释攻击性上是替代框架
- 与 [[激励理论]]、 [[组织行为学]]、 [[领导力]] 直接相关
- 与 [[认知行为疗法]] 之自我效能取向
- 与 [[积极心理学]] 之内在动机研究
- 与 [[人本主义心理学]] 之"自我"系列概念互补
- 与 [[皮亚杰]] 在儿童学习模型上互补(观察 vs 主动建构)
- 与 [[依恋理论]] 在早期社会学习上有关
- 与 [[内在驱动力]]、 [[责任]]、 [[认知失调]] 在道德行为分析上相关
- 与 [[HOOK模型]]、 [[消费者行为]]、 [[营销心理学]] 中观察学习应用
- 影响 [[人工智能]] 中 imitation learning(模仿学习)
- 历史定位:[[心理学]] 20 世纪后期最有影响的心理学家之一
