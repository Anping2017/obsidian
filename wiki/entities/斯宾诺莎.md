# 斯宾诺莎 Baruch Spinoza

## 简介

**巴鲁赫·斯宾诺莎**(Baruch / Benedictus de Spinoza,1632-1677),阿姆斯特丹出生的犹太裔荷兰哲学家、磨镜片工匠。**理性主义三巨头**之一(与 [[笛卡尔]]、莱布尼茨并列)。23 岁因异端被犹太教会开除,终生靠磨镜片谋生,撰写《伦理学》《神学政治论》。被黑格尔称作"近代哲学的真正起点"。

## 关键贡献

### 实体一元论:神即自然(Deus sive Natura)

- 真正的实体只有一个:**神 / 自然**
- 思维和广延不是两个实体,而是同一实体的两种属性
- 这是对 [[笛卡尔]] [[二元论]] 的根本性反驳
- 同时反对人格化上帝,**神是无限本质的总体**而非超越者

### 几何学方法

- 《伦理学》以欧几里得式公理体系写成
- 定义→公理→命题→证明→推论
- 表达哲学应当像数学一样严格的理想

### 平行论(Parallelism)

- 思维秩序与广延秩序**完全平行**
- 心灵中的观念与身体中的物理事件一一对应
- 解决了笛卡尔留下的心物互动难题
- 影响后来 [[心灵哲学]] 中的"双面理论"

### 决定论与必然性

- 一切事物按神之必然性发生,**没有偶然**
- 人的"自由"是**理解必然性**(知其不可逃)
- 此与 [[决定论]] 立场一致,与 [[自由意志]] 传统形成张力
- 对后来 [[弗洛伊德]] "潜意识决定论"有思想血缘

### 情感伦理学

- 情感(affectus)分**主动**与**被动**
- 被动情感(激情)源自不充分观念,削弱人的力量
- 主动情感(理性的快乐)源自充分观念,增强人的力量
- 自由人的目标:让心灵被理解所主导
- 影响存在主义心理治疗、现代正念取向

### 政治哲学

- **《神学政治论》**(1670):匿名出版即遭禁
- 主张**思想言论自由**是国家强大的基础
- 国家目的不是控制公民,而是让人发展理性
- 反对神权干涉学术,影响后来启蒙运动

### 圣经批判先驱

- 把《圣经》视为历史文献,非字面无误的天启
- 指出《摩西五经》并非摩西所作
- 现代圣经文献学的开端

## 主要著作

- **《伦理学》**(Ethics,1677 遗著):公理化形而上学+伦理
- **《神学政治论》**(1670):宗教批判与政治自由
- **《知性改进论》**:认识论草稿
- **《政治论》**(未完):政治制度构想

## 哲学影响

### 18 世纪影响

- 启蒙时期被视作**异端**,但秘密追随者众
- 影响赫尔德、歌德"泛神论"潮流

### 19-20 世纪复兴

- **黑格尔**:实体即主体的辩证发展
- **尼采**:称斯宾诺莎为"先驱"
- **爱因斯坦**:多次表示"我信仰斯宾诺莎的神"
- **德勒兹**:把斯宾诺莎读作"内在性平面"哲学
- **现代心灵哲学**:平行论的当代版本

## 个人

- 拒绝海德堡大学教授职位以保留思想自由
- 一生独居,以磨镜片度日,积劳成疾(玻璃尘可能加速肺病)
- 拒绝家族遗产,把精神留给后世
- 罗素称其"伟大哲学家中道德最高尚的人"

## 相关概念/实体

- 反对 [[笛卡尔]] [[二元论]],建构实体一元论
- 与 [[决定论]] 立场强相关
- 与 [[本体论]] 之"实体"问题
- 与 [[伦理学]] 中"理性快乐"传统
- 影响后来 [[尼采]]、爱因斯坦、 [[弗洛伊德]]
- 与 [[佛家]] "缘起"在"必然性"上有可比之处
- 与 [[斯多葛主义]](raw 中提及)在"理性服从必然"上相通
- 历史定位:[[西方哲学]] 近代理性主义代表
