# 哈耶克

## 简介

弗里德里希·奥古斯特·冯·哈耶克(Friedrich August von Hayek,1899-1992),奥地利—英国—美国经济学家、社会哲学家、政治理论家。维也纳大学法律与经济学博士,师从米塞斯。先后在 LSE、芝加哥、弗赖堡、萨尔茨堡任教。1974 年与 Gunnar Myrdal 共获诺贝尔经济学奖。

他是 [[奥地利学派]] 第三代核心,新自由主义思想最系统的建构者,长期与 [[凯恩斯]] 论辩。生于 19 世纪末维也纳,经历两次大战,1992 年弗赖堡去世。

## 主要贡献

### 1. 价格信号与知识分散
- 1945《知识在社会中的运用》(经典论文)
- 经济信息分散在数百万行动者中
- 没有任何中央计划者能集中所有信息
- **价格是信息系统**:浓缩并传递分散知识
- 计划经济从根本上不可能(经济计算辩论)

### 2. 经济计算辩论(Calculation Debate)
- 1920-30s 与米塞斯共同对抗社会主义计算可能论
- 兰格、勒纳"市场社会主义"反驳
- 哈耶克反复重申:不是计算而是知识问题
- 苏联崩溃后被广泛认为获胜

### 3. 自发秩序(Spontaneous Order)
- 借用苏格兰启蒙(Adam Smith、Hume、Ferguson)
- "人之行动而非设计"的产物
- 市场、语言、法律、习俗、货币都是自发演化
- 反对建构理性主义(constructivist rationalism)
- 与 [[亚当·斯密]] "看不见的手"延续

### 4. 商业周期理论
- 早期(1929-31)作品
- 货币扩张 → 利率失真 → 投资过度延伸 → 必然萧条
- 与凯恩斯 1930s 大辩论
- 后来"奥地利商业周期理论"被发展

### 5. 法治与自由
- 1944《通往奴役之路》(畅销书)
- 计划经济必然导致政治集权与极权
- 法治是自由的制度保障
- 《自由宪章》(1960)系统化

### 6. 法律理论
- 三卷《法律、立法与自由》(1973-79)
- 区分:
  - **法律**(nomos):自发演化、普遍适用
  - **立法**(thesis):立法机构有意制定
- 普通法 vs 大陆法
- 反对扩大行政立法

### 7. 演化论方法论
- 文化演化 + 群体选择
- 制度通过竞争演化优化
- 反对设计的"完美"制度
- 与 [[演化博弈]]、[[进化论思维]] 呼应

### 8. 货币竞争
- 后期(1976)《货币的非国家化》
- 主张废除央行垄断
- 私人货币竞争
- 影响后世密码货币(Bitcoin 受启发)

## 与其他思想家

- **米塞斯**:导师,奥地利学派传承
- **凯恩斯**:头号论辩对手,但相互尊重
- **波普尔**:朋友,共享反极权立场
- **罗宾斯**:LSE 同事
- **弗里德曼**:芝加哥同事,新自由主义共建,但方法论不同
- **波兰尼**(Karl):反对方,《大转型》论辩
- **加尔布雷思**:左翼对手
- **诺齐克**(Nozick):自由意志主义继承者
- **沃尔特·阿夫尔德**:学生

## 与其他概念关系

- 是 [[奥地利学派]] 核心人物
- 与 [[新古典经济学]] 部分整合部分区分
- 与 [[凯恩斯主义]] 长期对峙
- 与 [[公共选择理论]] 共享个人主义方法论
- 与 [[新制度经济学]] [[诺斯]] 制度演化呼应
- 与 [[市场失灵]] 概念部分对立
- 与 [[行为经济学]] 张力(理性人 vs 知识分散)
- 与 [[弗里德曼]] 同营但路径不同
- 与 [[阿罗不可能定理]] 相通(集中决策不可能)
- 与 [[自发秩序]] 词条核心
- 与 [[商业生态系统]] 演化思想前驱
- 与 [[斯宾诺莎]]、[[休谟]] 苏格兰启蒙传承

## 影响

### 政治
- 撒切尔(以《自由宪章》为座右铭)
- 里根
- 智利皮诺切特(争议)
- 后冷战东欧改革
- 自由市场全球化的思想根基

### 学术
- 新自由主义学派
- 公共选择
- 法律经济学
- 复杂科学(Santa Fe Institute)
- 行为金融部分整合

### 政策
- 1990 年代私有化、放松管制
- 货币主义崛起
- 中央银行改革

## 当代回响

### 数字时代
- 价格机制更广(平台经济)
- 算法 vs 自发秩序
- 加密货币 + 去中心化金融
- 大数据是否改变知识问题?

### 反思与批评
- 2008 金融危机削弱市场万能信仰
- 不平等扩大引来 Piketty 等新挑战
- "新自由主义"成为左右都批评的标签
- 哈耶克本人比通俗"新自由主义"复杂

### 哈耶克协会、Mont Pelerin
- 1947 朝圣山学社创立
- 全球自由主义网络
- 持续学术与政策影响

## 思想复杂性

- 经常被归为简单"自由市场",但他重视:
  - 法治
  - 文化演化的保守
  - 反唯理论
  - 反对社会工程
  - 不反对最低保障(《自由宪章》)
- 反对"放任"标签
- 自称"不情愿的自由意志主义者"

## 评价

- 20 世纪最重要的自由主义思想家之一
- 跨学科广度罕见(经济、法律、心理、哲学)
- 1992 维也纳追悼会聚集全球自由派
- 持续争议但思想深度无可置疑
- "如果哈耶克错了,他也错得很有趣"
