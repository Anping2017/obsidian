# 诺斯

## 简介

道格拉斯·塞西尔·诺斯(Douglass Cecil North,1920-2015),美国经济学家、经济史学家。圣路易斯华盛顿大学、斯坦福大学、剑桥任教。1993 年与 Robert Fogel 共同获诺贝尔经济学奖,获奖词:"重新构建经济与制度变迁理论,创立新经济史"。

他是 [[新制度经济学]] 主要奠基人,把制度作为经济增长的核心解释变量,而非传统新古典理论的"外生因素"。

## 关键贡献

### 1. 新经济史
- 1960-70 年代用计量方法重新研究经济史
- 与 Fogel 等人创立"克利欧史"(Cliometrics)
- 把数据与理论结合,挑战定性叙事

### 2. 制度的中心地位
- 制度 = 社会博弈规则(formal + informal)
- "制度是为减少交易成本而演化的"
- 制度结构决定激励结构,激励决定行为,行为决定经济结果

### 3. 交易成本理论
- 与 [[科斯]]、Williamson 共同发展
- 区分:**信息成本**、**测量成本**、**实施成本**
- 高交易成本 → 抑制贸易、专业化、创新
- 制度通过降低交易成本促进发展

### 4. 产权理论
- 私有产权 + 法治 + 合同执行 = 投资激励
- 缺乏明确产权 → 资源浪费、无法长期投资
- 产权不只是法律,是社会共识

### 5. 路径依赖(Path Dependence)
- 历史选择限制未来选择
- 小事件的大后果
- "锁定"机制
- 解释为何制度变迁慢

### 6. 北方—贝里—温加斯特模型(NWW, 2009)
- 《暴力与社会秩序》
- **限制进入秩序**(Limited Access Order):前现代,精英共谋
- **开放进入秩序**(Open Access Order):现代,竞争 + 法治
- 转型门槛:法治、永续组织、政治军事控制
- 解释为何大多数发展中国家陷入"自然国家"陷阱

### 7. 认知与意识形态
- 制度由心智模型塑造
- 后期(2005)《理解经济变迁过程》:认知科学整合
- 信念、文化、意识形态是制度变迁的深层基础

## 核心命题

### 1. 制度 vs 组织
- **制度**:社会博弈规则
- **组织**:玩家(企业、政党、工会、教会)
- 制度决定组织类型

### 2. 正式 vs 非正式制度
- **正式**:宪法、法律、契约
- **非正式**:文化、习俗、规范
- 转型需要二者匹配

### 3. 制度变迁的边际性
- 通常渐进
- 革命性变迁罕见且常失败
- 路径依赖与"锁定"

### 4. 比较经济发展
- 西欧崛起 = 制度优势
- 不是地理、人种、宗教(单纯)
- 产权 + 法治 + 议会限政 + 商业革命

### 5. 国家悖论
- 国家既保护产权又掠夺
- "诺斯悖论":国家是必要的也是危险的

## 影响

### 学术
- 重写经济史方法论
- 《制度、制度变迁与经济绩效》是必读
- 新制度经济学 1990s 起主流
- Acemoglu 等接班继承
- 比较政治经济学的基础

### 政策
- 世界银行、IMF 转向制度议题
- "良治"运动
- 法治援助
- 产权登记项目(de Soto)

### 中国研究
- 中国改革经验是新制度经济学测试场
- "渐进式改革"诠释
- "中国奇迹"vs 制度短板

## 局限与批评

- 制度内生化困难(制度从哪来?)
- 非正式制度难量化
- 西方制度作为标杆隐含偏见
- 暴力问题分析不够
- 殖民历史责任处理不充分
- 与文化决定论的张力

## 当代回响

### 数字时代制度
- 平台作为"私有政府"
- 算法治理
- 数据产权

### 全球治理
- 跨境制度
- WTO、巴黎协定
- 互联网治理

### 中国新制度学派
- 周其仁、张维迎、陈志武等
- 中国经验"新案例"

### Acemoglu/Robinson 后续
- 《国家为何失败》(2012)
- 《狭窄的廊道》(2019)
- 《权力与进步》(2023)
- 直接继承诺斯
