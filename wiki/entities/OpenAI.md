# OpenAI

## 简介

OpenAI 成立于 2015 年 12 月,由 Sam Altman、Elon Musk 等人创立,初期定位为非营利研究机构,使命是"确保通用人工智能(AGI)惠及全人类"。2019 年转型为"capped profit"混合架构以筹集训练资金,与 Microsoft 建立深度战略合作。它通过 GPT 系列模型与 ChatGPT(2022 年 11 月)直接引爆了当代 [[大语言模型]] 浪潮,长期处于全球 AI 商业化前沿。

## 关键贡献

**模型系列**

- GPT-1(2018):首次系统展示生成式预训练 + 微调范式
- GPT-2(2019):15 亿参数,因"过于强大"延迟开源,引发安全讨论
- GPT-3(2020):1750 亿参数,系统展示 [[少样本提示]] 与 [[上下文学习]] 能力
- GPT-3.5 / Codex:代码理解与生成,催生 GitHub Copilot
- ChatGPT(2022):对话产品引爆全球 AI 关注
- GPT-4(2023):多模态、强推理
- GPT-4o / GPT-4 Turbo:多模态实时交互
- o1 / o3 系列:推理模型,把 [[思维链]] 内化训练
- DALL-E 系列:文生图模型
- Whisper:开源语音识别
- text-embedding 系列:[[Embedding]] 模型

**技术与产品贡献**

- InstructGPT(2022)率先把 [[RLHF]] 大规模产品化
- 普及 [[函数调用]](2023 年 6 月)和 JSON 模式
- API 与计费模型成为行业事实标准
- ChatGPT Plus / Pro / Enterprise 订阅模式
- GPT Store / Custom GPT 探索 LLM 应用生态
