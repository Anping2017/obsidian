# 雅克·德里达 Jacques Derrida

## 简介

雅克·德里达(Jacques Derrida, 1930-2004)是 **20 世纪最具影响也最具争议的法国哲学家之一**,被誉为「解构主义」(Déconstruction / Deconstruction)的创始人。他出生于法属阿尔及利亚,后到巴黎高师任教,是 20 世纪后期欧陆哲学的代表人物之一。

德里达的工作横跨哲学、文学、语言学、政治、宗教、伦理,影响了文学批评、女性主义、后殖民研究、酷儿理论等众多领域,但同时被分析哲学传统视为模糊与不严谨的代表。1992 年剑桥大学授予他荣誉博士学位时,引发分析哲学家们的公开抗议。

## 关键贡献

### 解构主义(Deconstruction)

德里达的解构不是「拆毁」,而是揭示文本内部的**逻辑张力、概念二元对立的不稳定性**:

- 西方哲学习惯于「在场/缺席」「言语/书写」「自然/文化」「真理/谬误」等二元对立
- 这些对立隐含**等级关系**(前者优于后者)
- 解构通过仔细阅读揭示这种等级是文本自身的矛盾产物,既不可彻底维持也无法真正消除

### 「在场形而上学」批判

德里达追溯柏拉图以来,西方哲学有一种把「在场」(presence)作为终极实在的倾向:

- 柏拉图的「理念」直接呈现于灵魂
- 笛卡尔的「我思」直接自明
- 黑格尔的「绝对精神」最终自我在场

德里达指出这种「在场」总是被「延异」(différance,差异 + 延宕的合成词)所打断——意义永远在差异中、在延后到来的所指中,从未真正完全在场。

### 主要著作

- 《论文字学》De la grammatologie(1967)
- 《书写与差异》L'écriture et la différence(1967)
- 《声音与现象》La voix et le phénomène(1967)
- 《播散》La dissémination(1972)
- 《马克思的幽灵》Spectres de Marx(1993)

### 关键概念

| 概念 | 含义 |
|---|---|
| 延异(Différance) | 意义产生于差异 + 时间延宕,既差异又延宕 |
| 痕迹(Trace) | 任一符号都带着不在场者的痕迹 |
| 替补(Supplément) | 表面上是次要的添加,实际揭示主要项的不完整 |
| 不可决断性(Undecidability) | 文本中无法在两可解读间最终决断 |
| 异质性 | 内部含有自我颠覆的他者 |
| 礼物 / 友谊 / 好客 | 后期伦理-政治转向的核心议题 |

### 后期转向

1990 年代起,德里达从语言、文本转向**伦理、政治、宗教、法律**议题:

- 友谊(《友谊政治学》)
- 礼物(纯粹的礼物何以可能)
- 好客(对他者的绝对欢迎)
- 死刑(《死刑》)
- 民主政治(「将到来的民主」)

## 相关概念

德里达与 [[哲学]] 中的现象学([[海德格尔]]、[[胡塞尔]])、结构主义(列维-斯特劳斯)、精神分析([[弗洛伊德]]、拉康)深度对话,把这些思想推向「后结构主义」。

他与 [[福柯]]、[[让-保罗·萨特|萨特]] 等同时代法国哲学家形成对照与论战;[[语言哲学]] 与德里达解构形成「分析」(英美)与「欧陆」两条路线。

[[认识论]] 与 [[形而上学]] 受其挑战——「真理」「主体」「同一性」等概念都被解构;[[心灵哲学]] 中的「自我同一性」也被「延异」消解。

[[政治哲学]] 与 [[伦理学]] 在德里达后期受到深刻影响——「好客」「他者」概念扩展了 Levinas 的伦理学。

文学批评、女性主义([[西方哲学史脉络]] 的当代分支)、后殖民研究、酷儿理论等都从解构中受益,成为人文学科 1980-2000 年代的主导范式之一。
