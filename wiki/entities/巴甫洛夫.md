# 巴甫洛夫 Ivan Pavlov

## 简介

**伊万·彼得罗维奇·巴甫洛夫**(Иван Петрович Павлов,1849-1936),俄罗斯/苏联生理学家、心理学家。1904 年获**诺贝尔生理学或医学奖**,以**消化生理学**研究赢得声誉,但他真正改变学术史的是**经典条件反射**(classical conditioning)发现,被誉为"条件反射之父",[[行为主义]] 心理学的远祖。

## 关键贡献

### 经典条件反射的发现(1900 前后)

- 在研究狗的消化过程中,意外注意到**狗在看到实验员脚步声时就开始流唾液**
- 这激发了"条件反射"研究
- 经典实验设计:
  - **无条件刺激(US)**:食物
  - **无条件反应(UR)**:唾液
  - **中性刺激(NS)**:铃声
  - 反复 NS + US 配对后……
  - **条件刺激(CS)** = 铃声
  - **条件反应(CR)** = 唾液

### 关键概念体系

| 概念 | 含义 | 案例 |
|---|---|---|
| 习得 | 条件反应被建立 | 铃声+食物配对 |
| 消退 | 不再配对,条件反应减弱 | 多次铃声但无食物 |
| 自发恢复 | 消退后,过段时间反应重现 | 第二天铃声又引起唾液 |
| 泛化 | 类似刺激引起类似反应 | 铃声→哨声也部分有效 |
| 辨别 | 学会区分相似刺激 | 高音铃声有食,低音无 |
| 高级条件作用 | 用 CS 当 US,建立新 CR | 灯+铃声→唾液 |

### 反射学(Reflexology)

- 把心理学还原为**反射现象**
- 反对当时占主流的内省心理学
- 主张**客观、生理、可测量**的研究路径

### 大脑皮层与高级神经活动

- 提出**高级神经活动学说**
- 兴奋与抑制是大脑的两个基本过程
- 它们的相互制约塑造行为
- 后被苏联心理学(列昂捷夫、维果茨基的对立面)继承

### 类型说

- 根据兴奋抑制比例区分四种神经类型
- 与古希腊**四体液说**呼应
- 影响后来人格类型理论(详见 [[人格理论]])

## 历史影响

### 对 [[行为主义]] 的奠基

- **华生**直接以巴甫洛夫为榜样,1913 年发表行为主义宣言
- **斯金纳**操作性条件反射建立在经典条件反射基础上
- 详见 [[斯金纳]]、 [[行为主义]]

### 对临床的影响

- **系统脱敏疗法**(Wolpe):用经典条件反射框架治焦虑
- **暴露疗法**:治恐惧症
- **厌恶疗法**:配对不良行为与厌恶刺激
- 对成瘾、PTSD 等仍有指导意义

### 对认知—行为整合

- 现代研究发现条件反射涉及**期待**(Rescorla & Wagner)
- 不是机械配对,而是预测性学习
- 这是连接行为主义与认知主义的桥梁
- 与 [[强化学习]] 之**时间差分(TD)学习**直接相关

### 对 [[人工智能]]

- 强化学习的形式化模型
- TD 学习被发现在大脑多巴胺系统中实现
- 详见 [[强化学习]]

### 文化影响

- "**巴甫洛夫的狗**"成为日常隐喻:被反复条件化的反应
- 比如:看到广告就想买、刷手机停不下来
- 是对**习惯化、成瘾、营销操纵**的常用警示
- 详见 [[HOOK模型]]、 [[消费者行为]]

## 个人

- 出身俄罗斯小镇神职家庭
- 圣彼得堡大学学生理学
- 一生大部分时间在圣彼得堡帝国实验医学研究所
- 沙俄→苏俄过渡期受赏识,但他公开批判布尔什维克
- 列宁特批保护其研究 —— 巴甫洛夫被认为对国家有用
- 87 岁去世,工作至最后

## 相关概念/实体

- 是 [[行为主义]] 之远祖,直接影响 [[斯金纳]]、华生
- 与 [[经典条件反射]] 是其专有发现
- 与 [[操作性条件反射]] 形成对照(行为后果 vs 刺激配对)
- 与 [[强化学习]]、 [[人工智能]] 中 TD 学习同源
- 与 [[依恋理论]]、 [[人际关系]] 在习惯化机制上相关
- 与 [[认知行为疗法]] 中暴露、脱敏技术相承
- 与 [[HOOK模型]]、 [[消费者行为]]、 [[营销心理学]]、 [[品牌定位]] 中"刺激—联想"机制
- 与 [[班杜拉]] 社会学习的"非配对"路径形成对比
- 与 [[弗洛伊德]] 同代,但科学路径完全不同
- 历史定位:[[心理学]] 行为主义先驱、诺贝尔生理学奖获得者
