# 弗里德曼 / Milton Friedman

## 简介

米尔顿·弗里德曼(Milton Friedman, 1912-2006),美国经济学家,**芝加哥学派**领军人物,20 世纪最具影响力的自由市场经济学家,1976 年诺贝尔经济学奖得主。

罗格斯大学本科,芝加哥大学硕士,哥伦比亚大学博士。1946 年起执教芝加哥大学,创建了影响数代经济学家的"芝加哥学派"。胡佛研究所高级研究员。

公共影响力:
- 美国总统经济顾问委员会成员(里根)
- 撒切尔与里根经济政策的理论灵感
- 电视纪录片《自由选择》(1980)使经济学普及大众
- 与妻子罗丝合著《自由选择》《资本主义与自由》传播自由市场理念

代表作:
- **《消费函数理论》(1957)**:永久收入假说
- **《美国货币史》(1963,与 Anna Schwartz)**:货币主义经验基础,论证大萧条是货币政策失败
- **《价格理论》(1976)**:经典微观教材
- **《自由选择》《资本主义与自由》**:面向大众的政策论著

## 关键贡献

### 1. 永久收入假说(1957)

挑战凯恩斯消费函数 C = C₀ + cY。弗里德曼提出消费由**永久收入(permanent income)** —— 长期收入预期 —— 而非当期收入决定。

```
C = α·Y_P
其中 Y_P = 永久收入(长期平均)
```

含义:
- 临时收入冲击对消费影响小,人们倾向平滑消费
- 凯恩斯式财政刺激(临时减税)效果有限 —— 人们存起来而非花掉
- 消费函数实证拟合大幅改善

这一思想与霍尔(Hall)的随机游走消费假说、Modigliani 生命周期假说共同奠定了现代消费理论。

### 2. 货币主义与货币数量论

复兴货币数量论 **MV = PY**,论证:
- 长期通胀始终是货币现象(通胀 = 货币增速 − 实际增长 − ΔV)
- 货币 V(流通速度)在长期相对稳定
- 央行应稳定货币增长率,放弃相机抉择

**著名论断**:"通货膨胀,任何时间和任何地点都是一个货币现象。"

《美国货币史》(1963)实证论证:1929-1933 大萧条主因是美联储货币政策失误(M2 收缩 1/3),而非凯恩斯式需求冲击。这一研究使大萧条理论从凯恩斯式转向货币主义解读。

### 3. 自然失业率假说(与 Phelps, 1968)

挑战 [[菲利普斯曲线]] 的稳定通胀-失业权衡。弗里德曼论证:

- 短期菲利普斯曲线源自工人对实际工资的判断错误
- 长期工人形成正确通胀预期,菲利普斯曲线垂直于自然失业率
- 试图压低失业率低于自然率只会带来加速通胀

```
长期:π → π^e,U → U_n
```

详见 [[菲利普斯曲线]] 与 [[失业理论]]。这一预测在 1970s 滞胀中得到惊人验证 —— 美国通胀失业齐升,凯恩斯曲线"打结"。这是货币主义崛起的关键经验。

### 4. 政策无效与规则 vs. 相机抉择

弗里德曼主张:

- 货币政策时滞长且不可预测(6-18 个月,不一)
- 相机抉择反而加剧波动,如同"在浴缸里加水又开排水"
- 应采用**简单规则**:稳定货币增长率(如 k%规则)
- 这一思想被理性预期学派(Lucas, Sargent)推进至"政策无效命题"

虽然简单货币规则未被实际采纳,但"规则约束相机抉择"思想塑造了 1990s 通胀目标制(Inflation Targeting)的兴起。

### 5. 浮动汇率主张

弗里德曼 1953 年提出**浮动汇率制**优越性:

- 自动调节贸易失衡
- 允许独立货币政策
- 减少投机攻击

布雷顿森林体系崩溃后(1971-1973),浮动汇率成为主要货币的标准制度,弗里德曼预言成真。详见 [[汇率制度]]。

### 6. 自由市场政策主张

《资本主义与自由》(1962)的政策建议:
- **教育券**:政府资助但学生选择学校(市场化教育)
- **负所得税**:简化福利体系(后影响 EITC 设计)
- **职业资格自由化**:废除许可证制度
- **毒品合法化**:从经济角度论证
- **志愿兵役制**:取代征兵
- **教育、社保、医疗市场化**

这些主张深刻影响了 1980s 撒切尔-里根改革,也是当代自由意志主义经济政策的思想基础。

### 7. 实证经济学方法论

《实证经济学方法论》(1953)论文:经济学应被假设的"预测能力"评判,而非假设的"现实性"。

> "假设是否‘现实'不是关键。任何模型都是简化,关键是它的预测是否准确。"

这一方法论支持高度抽象的理论(如理性人假设)只要预测准确即合法。与制度学派、行为经济学的方法论形成对照。

### 8. 反对凯恩斯主义

弗里德曼是 [[凯恩斯]] 主义最有力的反对者。他认为:

- 凯恩斯式财政刺激主要被永久收入平滑抵消
- 货币政策远比财政政策有效(虽然他本人主张规则化)
- 政府越大越低效,自由市场是繁荣源泉
- 政府失灵往往严重于市场失灵

但他承认凯恩斯的天才,并曾说"我们都是凯恩斯主义者(in some sense)" —— 即指 GDP 核算、宏观分析框架已普及。

## 相关概念/实体

弗里德曼塑造的核心概念:[[价格指数与通胀]] 中"通胀总是货币现象"、[[失业理论]] 中自然失业率、[[菲利普斯曲线]] 长期垂直、[[货币政策]] 规则化、[[汇率制度]] 中浮动汇率优越性。永久收入假说重塑 [[消费者选择理论]] 与跨期决策分析。

继承者(芝加哥学派):
- **Lucas**:理性预期革命,接续货币主义微观基础工作
- **Becker**:把价格理论应用至非市场领域(家庭、犯罪、歧视)
- **Stigler**:管制理论
- **Heckman**:计量经济学

对手:
- **[[凯恩斯]]** 与凯恩斯主义传统(萨缪尔森、托宾、莫迪利安尼)
- **斯蒂格利茨**:信息经济学,论证市场失灵普遍
- 后凯恩斯学派与马克思主义

跨域:[[货币政策]] 现代框架(尤其是通胀目标制)是货币主义遗产;[[利率理论]] 中费雪方程被弗里德曼实证应用;[[投资组合理论]] 在芝加哥学派(Markowitz、Sharpe、Fama)整体主导下发展;[[行为金融学]] 是对 Fama 有效市场假说(直接源自芝加哥学派)的反向挑战;[[投资决策框架]] 中"市场基本有效"信念是芝加哥学派的延伸;[[公司治理结构]] 中"股东价值最大化"教条来自弗里德曼 1970 年纽约时报文章("企业的社会责任就是增加利润")。
