# 科尔伯格

## 简介

**劳伦斯·科尔伯格**(Lawrence Kohlberg, 1927–1987)是美国发展心理学家,芝加哥大学博士,后长期任教哈佛。他在 [[皮亚杰]] 认知发展理论基础上,通过对道德两难情境(如"海因兹偷药")的访谈研究,提出**道德发展三层次六阶段理论**,系统化了对人如何形成道德判断的研究,是 20 世纪道德心理学的奠基者。

## 关键贡献

### 道德发展三层次六阶段

| 层次 | 阶段 | 核心 |
|---|---|---|
| **前习俗水平** | 1. 惩罚-服从取向 | 避免惩罚 |
| | 2. 工具-相对取向 | 满足自身需求,互惠交换 |
| **习俗水平** | 3. 好孩子取向 | 取悦他人、符合期望 |
| | 4. 法律与秩序取向 | 维护权威与社会秩序 |
| **后习俗水平** | 5. 社会契约取向 | 法律可议,基于社会契约 |
| | 6. 普遍伦理原则 | 良心与普遍伦理(正义、人性尊严) |

多数人停留在第 3–4 阶段,仅少数达到第 5–6 阶段。

### 海因兹两难

经典访谈情境:海因兹的妻子病危,药商索价高昂他无力承担,他是否应当偷药?
科尔伯格不关心答案是"偷"还是"不偷",**而看推理理由**——同样的"应当偷"答案,可能源自不同阶段的道德推理。

### 研究方法贡献

- **道德判断访谈**(MJI):标准化两难情境 + 半结构化访谈
- **道德判断量表**(MJI 评分系统)
- 大规模纵向研究:跟踪同一批被试 20 年验证阶段稳定性

### 影响与批评

**影响**:
- 道德教育课程设计("正义共同体"学校)
- 推动后续阶段论(图列尔的领域理论)
- 与法律与伦理教育对接

**批评**:
- **吉莉根**(Carol Gilligan):性别偏倚,女性更倾向"关怀伦理"而非"正义伦理"
- 跨文化效度受质疑,后习俗阶段是否带西方偏见
- 道德判断与实际道德行为之间存在"知行差距"
- 阶段刚性、过度认知化,情绪与直觉作用被低估(海特等批评)

## 相关概念/实体

- 直接继承 [[皮亚杰]] 的阶段论范式
- 影响 [[积极心理学]] 的德性发展研究
- 与 [[伦理学]] 中的康德义务论与功利主义对话密切
- 在企业 [[公司治理]] 与商业伦理培训中作为发展模型应用
