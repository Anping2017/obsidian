# 波伏娃

## 简介

西蒙娜·吕西-埃内斯婷-玛丽-贝尔特朗·德·波伏娃(Simone Lucie-Ernestine-Marie-Bertrand de Beauvoir,1908-1986),法国哲学家、作家、社会理论家。1929 年法国哲学教师资格考试(agrégation)第二名(萨特第一,但她较他年轻),终生与 [[萨特]] 是哲学伴侣。

虽然长期被视为"萨特女友",近年学界已确立其作为独立哲学家的核心地位,在伦理学、性别哲学、自我哲学上有自己的原创贡献。

## 主要贡献

### 1. 《第二性》(1949)
- 20 世纪女性主义最重要文本
- 卷一(事实与神话):女性的历史、生物、心理分析
- 卷二(亲身经历):女孩、青春、婚姻、母亲到老年
- 核心命题:**"女人不是生而为女人,而是被造就成女人"**(On ne naît pas femme, on le devient)
- 引入自我/他者辩证:女性被构造为男性"他者"
- 拒绝本质女性气质,主张通过自由超越境遇

### 2. 道德的模糊性(1947)
- 《模糊的伦理学》(Pour une morale de l'ambiguïté)
- 存在主义伦理学独立著作
- 处理萨特《存在与虚无》提出但未解决的伦理问题
- 自由不是任意:他者也是自由,我的自由依赖他人自由
- "我必须想要他人自由"

### 3. 老年研究(1970)
- 《老年》(La Vieillesse)
- 系统分析老年的社会、心理、哲学维度
- 老人在西方现代社会被边缘化
- 与《第二性》相对应的"另一个他者"研究
- 老年学(gerontology)开创性著作

### 4. 自传与小说
- 四卷自传:《一个本分女孩的回忆》《岁月的力量》《时势的力量》《归根到底》
- 《名士风流》(Les Mandarins, 1954)获 1954 年龚古尔奖
- 《人都是要死的》:存在主义寓言
- 《告别礼》:萨特最后岁月,引争议

## 思想脉络

### 哲学根基
- 法国大学严格哲学训练(笛卡尔、康德、胡塞尔、海德格尔)
- 1929 年与萨特、莫里斯·梅洛-庞蒂同代
- 接受 [[现象学]] 与 [[存在主义]]
- 同时阅读 [[黑格尔]] 主奴辩证法、[[马克思]]、[[尼采]]

### 与萨特
- 终生哲学伴侣(开放关系)
- 互相影响,平等对话
- 但波伏娃哲学有自己的独立路径,尤其在伦理与性别
- 1980 年萨特去世,1986 年波伏娃去世,合葬蒙帕纳斯公墓

### 政治参与
- 反殖民:支持阿尔及利亚独立
- 1971 年签署"343 婊子宣言"自承堕胎,推动法国堕胎合法化
- 1972 年公开身份"女性主义者"
- 1974 年创办《女性问题》(Questions Féministes)
- 终生反战、反法西斯

## 与其他思想家

- **[[萨特]]**:终生伴侣
- **梅洛-庞蒂**:同代,身体哲学影响波伏娃
- **加缪**:朋友后决裂(政治分歧)
- **理查德·赖特、纳尔逊·阿尔格仁**:重要友人
- **凯特·米勒特、贝蒂·弗里丹**:第二波美国女权领袖,深受影响
- **巴特勒**(Judith Butler):《第二性》理论的当代继承与批判

## 与其他概念关系

- 是 [[存在主义]] 哲学家(虽然她个人与萨特皆抗拒标签)
- 是 [[女性主义哲学]] 第二波奠基人
- 把 [[现象学]] 应用到性别身体经验
- 与 [[黑格尔]] 主奴辩证法对话
- 影响 [[巴特勒]] 性别表演理论(虽然巴特勒批判)
- 与 [[努斯鲍姆]] 可行能力路径精神相通
- 与 [[阿伦特]] 同时代女性思想巨人,但路径迥异
- 老年研究为 [[卫生经济学]]、[[发展心理学]] 提供哲学基础

## 评价

- 20 世纪最重要女性哲学家之一
- 《第二性》是女权主义经典与伦理学经典
- 长期被低估为"萨特从属",已被纠正
- 把哲学带入文学、自传、新闻
- 学界仍在挖掘其早期论文与未发表手稿
- 持续争议:与学生关系、对萨特的过度奉献叙事
