# 塞利格曼 Martin Seligman

## 简介

**马丁·E·P·塞利格曼**(Martin Elias Peter Seligman,1942-),美国心理学家,宾夕法尼亚大学教授。前期以**习得性无助**(learned helplessness)研究奠定抑郁认知模型;1998 年任**美国心理学会(APA)主席**期间发起**积极心理学**(Positive Psychology)运动,使"研究让人活得好"成为合法学术领域。

## 关键贡献

### 习得性无助(Learned Helplessness,1967)

- 与 Steven Maier 在狗实验中发现:
  - 不可逃避电击的狗 → 后来即使能逃也放弃
  - 这是**"学到了无能为力"**
- 类比解释**抑郁症**:重复失败 → 放弃尝试
- 与 [[认知失调]]、 [[认知行为疗法]] 之核心机制相关

### 解释风格(Explanatory Style)

- **悲观解释**:把坏事归因为**内在、稳定、普遍**(我不行、永远不行、什么都不行)
- **乐观解释**:坏事归因为**外在、暂时、特定**(运气不好、这次而已、只是这件事)
- 解释风格预测抑郁、健康、绩效、寿命
- 这是**认知—行为治疗**的核心机制

### 习得性乐观(Learned Optimism,1990)

- 既然无助可以习得,**乐观**也可以习得
- 训练 ABCDE 法:逆境(A)→ 信念(B)→ 后果(C)→ 反驳(D)→ 振奋(E)
- 同名畅销书把心理学推向大众

### 积极心理学的发起(1998)

- APA 主席就职演讲:**心理学不能只研究痛苦,也要研究幸福**
- 召集 Csikszentmihalyi、Diener、Peterson 等
- 倡议:用**实证方法**研究**优势、美德、繁荣**
- 详见 [[积极心理学]]

### 幸福理论的演进

#### 真实幸福理论(Authentic Happiness,2002)

- 三种幸福:**愉悦的生活**(快乐)、**投入的生活**(心流)、**意义的生活**(服务更大目标)

#### PERMA 模型(2011,《Flourish》)

- 修正为 5 要素的**繁荣**(flourishing)模型:
- **P**ositive Emotion(积极情绪)
- **E**ngagement(投入)
- **R**elationships(关系)
- **M**eaning(意义)
- **A**ccomplishment(成就)
- 详见 [[积极心理学]]

### VIA 性格优势分类(2004)

- 与 Christopher Peterson 合作
- 24 项跨文化性格优势,归入 6 大美德
- 智慧、勇气、人道、正义、节制、超越
- 提供心理学的"DSM 反面" —— 不是疾病分类,是优势分类

### 积极教育与韧性

- 在宾州军校、澳洲学校推广**幸福课程**
- **U.S. Army Comprehensive Soldier Fitness**(全军心理韧性项目)
- 教孩子和士兵识别认知扭曲、感恩、培养优势

### Prospection(前瞻性思维)

- 后期理论:人是**面向未来的生物**(Homo Prospectus)
- 大脑大量资源用于模拟未来
- 不只是反应过去,而是**预测**
- 这与 [[贝叶斯]]、 [[强化学习]] 之预测理论呼应

## 主要著作

- **《习得性无助》**(Helplessness,1975)
- **《习得性乐观》**(Learned Optimism,1990)
- **《教出乐观的孩子》**(The Optimistic Child,1995)
- **《真实的幸福》**(Authentic Happiness,2002)
- **《性格优势与美德》**(与 Peterson 合著,Character Strengths and Virtues,2004)
- **《繁荣》**(Flourish,2011)
- **《Homo Prospectus》**(2016)

## 历史影响

### 学术心理学

- 改变了**积极/消极研究比例**(过去 21:1 偏负)
- 创立期刊《Journal of Positive Psychology》
- 全球开设积极心理学课程

### 教育

- 学校"幸福课"在英、澳、美、中国都有实践
- 哈佛 Tal Ben-Shahar 课程曾全校最受欢迎

### 商业

- 员工**敬业度**(engagement)研究
- 企业积极文化、 [[组织文化]] 设计
- 高管教练业普遍使用 PERMA

### 临床

- 积极心理治疗(Positive Psychotherapy)
- 与 [[认知行为疗法]] 整合

### 军事

- 美军全面心理韧性项目
- 影响 PTSD 预防与干预

## 批评

- 文化偏见:研究多基于西方个人主义
- "积极"被批评为忽视真实痛苦
- 过度商业化、自助化的滥用风险
- "幸福警察"——把不幸福病理化的隐忧

## 个人

- 1942 年生于纽约犹太家庭
- 普林斯顿哲学本科
- 宾大心理学博士
- 长期任宾大教授
- 与 Csikszentmihalyi、 [[卡尼曼]] 等合作
- 有 6 个孩子(成为后来"积极养育"研究素材)

## 相关概念/实体

- 是 [[积极心理学]] 的发起者与代表
- 与 [[认知行为疗法]] 在解释风格上相承
- 与 [[人本主义心理学]]、 [[马斯洛]] 之精神继承(实证化)
- 与 [[卡尼曼]]、 [[行为经济学]] 在决策与幸福研究上交织
- 与 [[班杜拉]] 之自我效能、 [[阿德勒]] 之社会兴趣思想血缘
- 与 [[依恋理论]]、 [[共情]]、 [[人际关系]] 在 PERMA 中关系维度相关
- 与 [[正念]]、心流(Csikszentmihalyi)在投入维度相关
- 与 [[内在驱动力]]、 [[激励理论]] 直接相关
- 与 [[领导力]]、 [[变革型领导]]、 [[组织文化]] 中"积极组织"运动相关
- 与 [[责任]]、 [[认知失调]] 中"做与说"机制相关
- 与 [[儒家]] "成德" 、 [[佛家]] "慈悲" 在品德优势上有跨文化呼应
- 历史定位:[[心理学]] 积极心理学创始人,21 世纪最具影响力的心理学家之一
