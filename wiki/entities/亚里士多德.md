# 亚里士多德 Aristotle

## 简介

**亚里士多德**(Aristotle,前 384-前 322),古希腊哲学家,出生于斯塔吉拉,父亲是马其顿王医。17 岁入 [[柏拉图]] 学院学习 20 年,师承柏拉图但部分批判其 [[理念论]]。后任亚历山大大帝的老师,在雅典创办**吕克昂学院**(Lyceum)。他的著作覆盖**逻辑、形而上学、物理、生物、伦理、政治、修辞、诗学**几乎所有领域,是百科全书式的奠基者。中世纪经院哲学称他为"哲学家"(The Philosopher)。

## 关键贡献

### 形式逻辑

- 《工具论》创立**三段论(syllogism)** 作为系统逻辑
- 区分**演绎**(从一般到特殊)与**归纳**(从特殊到一般)
- 三大基本规律:同一律、矛盾律、排中律
- 直至 19 世纪弗雷格之前,亚里士多德逻辑是西方逻辑学的全部
- 详见 [[逻辑]]

### 实体与四因说

- **实体(substance)** 是独立存在的个体(这只马、这个人)
- **形式**(eidos) + **质料**(hylē) 共构事物
- 四因说解释事物变化:
  - **质料因**:构成材料(青铜)
  - **形式因**:结构与功能(雕像的形状)
  - **动力因**:制造者(雕塑家)
  - **目的因**:为什么做(美感、宗教仪式)
- 这是 [[第一性原理]] 思维的源头之一

### 形而上学

- "[[形而上学]]"一词源自亚里士多德著作的编排:"物理学之后"
- 研究"是之为是"(being qua being)
- 区分**潜在**(potentiality)与**现实**(actuality)
- 第一推动者:不动的推动者(后被托马斯·阿奎那用作神的论证)

### 德性伦理学

- **《尼各马可伦理学》**:德性是**习惯**的产物
- 德性 = 两个极端之间的**中道**(mesotēs):
  - 勇敢 = 怯懦 与 鲁莽 之间
  - 慷慨 = 吝啬 与 挥霍 之间
- 人生最高目标是**幸福(eudaimonia)** —— 不是快乐,而是合乎德性的活动
- 与 [[儒家]]"中庸"惊人相似
- 详见 [[伦理学]]

### 政治哲学

- "人是政治的动物"(zoon politikon)
- **《政治学》**:比较各种政体优劣
- 君主制、贵族制、共和制为正常形态;僭主、寡头、民主为变态形态
- 中产阶级稳定民主

### 自然哲学

- 大量生物学、物理学、天文学著作
- 虽然部分结论(如四元素、地心说)被证伪,但**观察—分类—解释**的科学方法影响深远

### 修辞学与诗学

- **《修辞学》**:三种说服手段 —— 逻辑(logos)、品格(ethos)、情感(pathos)
- **《诗学》**:悲剧理论,情感净化(catharsis)

## 与柏拉图的差异

| | 柏拉图 | 亚里士多德 |
|---|---|---|
| **理念位置** | 独立于事物的理念世界 | 内在于事物的形式 |
| **认识论** | 回忆说 | 经验主义倾向 |
| **方法** | 辩证法 | 三段论与观察 |
| **政治** | 哲人王、理想国 | 比较政体、中产稳定 |
| **伦理** | 善的理念 | 中道与习惯 |

亚里士多德有名言:"吾爱吾师,吾更爱真理。"

## 历史影响

- **中世纪**:阿拉伯哲学家(阿威罗伊)、托马斯·阿奎那综合亚里士多德与基督教
- **科学革命**:伽利略、开普勒**部分推翻**亚里士多德物理学,但保留其方法论
- **现代德性伦理复兴**:麦金太尔、努斯鲍姆
- **逻辑学**:三段论至今仍是逻辑入门
