# 托马斯·阿奎那 Thomas Aquinas

## 简介

**托马斯·阿奎那**(Thomas Aquinas,1225-1274),意大利道明会修士、神学家、哲学家。**经院哲学集大成者**,完成把希腊哲学(尤其是亚里士多德)与基督教信仰整合的伟业。其代表作《神学大全》(Summa Theologiae)是中世纪思想巅峰之一。

## 人生轨迹

- 1225 年生于意大利洛卡塞卡贵族家庭
- 蒙特卡西诺修道院、那不勒斯大学受教育
- 1244 年加入新兴的道明会(被家族反对囚禁一年)
- 在巴黎与科隆求学,师从大阿尔伯特(Albertus Magnus)
- 1252-1259 巴黎大学任教,与方济各会的波纳文图拉同代
- 1273 年神秘宗教经验后封笔,称所写如"稻草"
- 1274 年赴里昂会议途中病逝

## 关键贡献

### 五路证明(Quinque Viae)

证明上帝存在的五条经验路径:
1. **运动论证**:任何运动需有推动者 → 第一推动者
2. **因果论证**:有效因果不能无限上溯 → 第一因
3. **偶然性论证**:偶然存在需有必然存在为基础 → 必然者
4. **完美程度论证**:程度差别要有最高标准 → 至善者
5. **目的论论证**:无意识物表现合目的性 → 智慧设计者

与 [[奥古斯丁]] 的内省式证明不同,这是从经验世界出发的**自然神学**。

### 信仰与理性的协调

- 信仰与理性不冲突,只是层次不同
- 理性能证明上帝存在,但**三位一体、道成肉身**等真理需启示
- 此模式开启了中世纪学院"哲学是神学的婢女"之结构

### 存在与本质的实在区分

- **本质(essentia)**:某物之"是其所是"
- **存在(esse)**:实存的现实活动
- 有限存在中两者不同,只有上帝中两者同一
- 影响后来 [[海德格尔]] "存在论差异"的源头

### 自然法理论

- 法律分四层:**永恒法 → 神法 → 自然法 → 人法**
- 自然法是理性参与永恒法的方式
- 基本规范:行善避恶,且具体诫命可由理性推出
- 是西方**自然权利**与**人权**理论的源头之一

### 德性伦理与七德

- 沿用亚里士多德四枢德:智、义、勇、节
- 加上三神学德:信、望、爱
- 把追求"至善"重新界定为"与上帝合一的真福"

### 共相问题:温和实在论

- 共相在物前(在上帝心中)、在物中(具体物的形式)、在物后(人心抽象的概念)
- 兼容柏拉图与亚里士多德,避免极端实在论与唯名论

## 主要著作

- **《神学大全》**(Summa Theologica,1265-1274):3 部 38 论 612 题,体系化
- **《反异教大全》**(Summa contra Gentiles):写给穆斯林、犹太学者的护教学
- **《论存在与本质》**(De Ente et Essentia):本体论核心论文
- **《论真理》**(De Veritate):认识论与意志专论
- **《论自然原理》**:亚里士多德式自然学

## 哲学定位

### 集大成者

- **基督教 + 亚里士多德** = 经院哲学(Scholasticism)成熟形态
- 1323 年封圣,1567 年立为教会博士
- 1879 年教皇利奥十三世通谕《永恒之父》定为天主教官方哲学

### 后世传承

- **托马斯主义**:13 世纪后持续发展
- 19-20 世纪**新托马斯主义**(吉尔松、马里坦)与现代哲学对话
- 当代**分析托马斯主义**(MacIntyre 等)

## 相关概念/实体

- 综合 [[亚里士多德]] 的形而上学与基督教
- 接续 [[奥古斯丁]] 的神学传统但取径不同(经验 vs 内省)
- 与 [[认识论]] 之"中庸经验主义"
- 与 [[本体论]] 之"存在 vs 本质"
- 与 [[伦理学]] 之"自然法"传统
- 与 [[政治哲学]] 之"君主政体—共同善"模型
- 与 [[宗教哲学]] 直接交叠
- 与现代 [[决定论]]/[[自由意志]] 议题之"协同因果"立场
- 影响但丁、笛卡尔(尽管笛卡尔反经院)、莱布尼茨
- 在东方对照可参考 [[儒家]] 之"理"与"性"
