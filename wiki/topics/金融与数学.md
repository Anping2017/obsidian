# 金融与数学

## 概述

20 世纪以前的金融学更像描述性的"政治经济学"分支;20 世纪后,马科维茨(1952)、Sharpe(1964)、Black-Scholes-Merton(1973)、Engle/Granger(时间序列)等一系列工作,把金融变成了一门深度数学化的学科。今天,**没有数学就没有现代金融学**——估值要解微分方程,风险要算分布,组合要做最优化,衍生品要构造复制策略。

数学之于金融,扮演的是"语言"和"望远镜"的双重角色:语言把模糊的金融直觉表达为精确命题(可证伪),望远镜把人眼看不见的随机性结构呈现出来(可计算)。

## 多角度分析

### 五大核心数学工具及其金融对应

| 数学领域 | 金融用途 | 关键概念 |
|---|---|---|
| [[概率论与统计学]] | 收益分布、风险度量、参数估计 | 期望、方差、协方差、分布族、矩 |
| 微积分 | 边际分析、最优化、连续复利 | 导数、积分、Taylor 展开、Lagrange |
| 线性代数 | 多资产组合、因子模型、风险分解 | 矩阵、特征值、协方差矩阵 |
| [[随机过程]] | 价格演化、利率模型、衍生品定价 | 布朗运动、伊藤引理、马尔可夫性 |
| 最优化理论 | [[投资组合理论]]、对冲、参数估计 | 凸优化、KKT 条件、动态规划 |

这五条线在 Black-Scholes 公式中汇合:股票价格服从几何布朗运动(随机过程),期权价值满足 Black-Scholes PDE(微积分),通过无套利复制(最优化)与对数正态分布(概率)推导出闭式解。

### 概率与统计:不确定性的量化

[[投资组合理论]] 的核心命题——分散化降低风险——只有在协方差矩阵的语言下才能精确表达。马科维茨给定均值向量 μ 和协方差矩阵 Σ,求解 `min wᵀΣw s.t. wᵀμ ≥ 目标收益, wᵀ𝟏=1`,得到有效前沿。

[[资产定价模型]] 中的 CAPM 用最简单的一元线性回归(`Rᵢ-Rf = α + β(Rₘ-Rf) + ε`)就刻画了风险与收益的关系,而 [[回归分析]] 是这个关系能从数据中估出来的根本原因。

[[风险识别与度量]] 的现代核心 VaR、Expected Shortfall 都是分布函数的特定分位数与条件期望——没有概率分布就没有风险数字。

### 随机过程:时间维度的数学化

静态概率告诉我们某个时点的不确定性,但金融资产价格是动态演化的。布朗运动 `dWₜ` 与几何布朗运动 `dSₜ = μSₜdt + σSₜdWₜ` 是描述资产价格连续演化的标准工具。

[[期权定价]] 的革命性突破在于发现:期权价值可以通过持续调整股票与无风险债券头寸来"合成"——这就是 Black-Scholes 的 delta hedge 思想。这一构造性证明依赖伊藤引理与 PDE 求解,是 [[随机过程]] 在金融中最深刻的应用。

[[蒙特卡洛模拟]] 是当解析解不可得时的通用利器——通过抽样路径估计期权价值、组合分布、风险指标,广泛用于结构化产品定价、信用组合损失分布、保险精算。

### 最优化:从理论到落地的桥梁

金融问题几乎都可以表达为约束最优化:
- [[投资组合理论]]:最大化效用 / 最小化风险
- [[资本结构理论]]:最大化企业价值
- 算法交易:最小化交易成本(Almgren-Chriss 模型)
- 风险预算:在预定风险预算下最大化收益

凸优化保证全局最优;非凸问题需要启发式算法(遗传算法、模拟退火);深度学习引入了一类新的、规模更大的非凸优化问题。

### 衍生品定价:数学最密集的领域

| 工具 | 数学方法 |
|---|---|
| 欧式期权 | Black-Scholes PDE,闭式解 |
| 美式期权 | 自由边界 PDE 或最优停时,数值方法 |
| 路径依赖期权 | 蒙特卡洛模拟 |
| 利率衍生品 | Hull-White、HJM、LMM 利率模型 |
| 信用衍生品 | 强度模型(Cox 过程)、结构模型(Merton) |
| Greeks 风险 | 价值函数对各参数的偏导 |

这是为什么 quant 行业偏好物理、应用数学、数学统计博士——这些方向训练的正是金融工程所需的工具。

### 数学的局限与陷阱

数学是工具不是教条,几个常见陷阱:
- **正态假设失灵**:真实收益有肥尾,VaR 低估极端损失(LTCM 1998 教训)
- **过度拟合**:历史数据上完美的模型未必能 out-of-sample 工作
- **模型风险**:同一现象可以用不同模型描述,选择本身是风险
- **可计算 ≠ 可信**:精确到小数点后四位的估值,可能假设错得离谱

合格的金融从业者既要会用数学,也要知道何时不该信数学。

### 新兴方向:机器学习与量子计算

机器学习在金融中的渗透——从经典统计学习(SVM、随机森林)到深度学习(LSTM、Transformer)、再到强化学习(交易策略),改变了量化研究的工作流。可解释性(SHAP、LIME)与泛化性能成为新课题。

量子计算对组合优化、蒙特卡洛加速有理论上的指数级加速空间,虽然商用化仍早,但是已有金融机构在探索量子算法在 [[投资组合理论]] 与 [[期权定价]] 中的应用。

## 结论

数学之于金融,不是"加分项"而是"通行证"。但用好数学的关键不在公式的复杂度,而在三个判断:**模型刻画了什么、忽略了什么、在何种情境下失效**。能精准回答这三个问题的,才是真正掌握了金融数学,而不是被它绑架。
