# 金融体系功能

## 概述

**金融体系** = 金融机构 + 金融市场 + 金融工具 + 金融制度,负责资金在时间和空间上的配置。形象地说,机构是车站,市场是道路,工具是车辆,制度是交规。

## 多角度分析

### 四大基本功能

**1. 资源配置**
将资金从盈余部门转移到赤字部门,通过两种渠道:
- **直接融资**:经 [[金融市场概述]] 直接对接(发股、发债)
- **间接融资**:经金融中介(银行)间接对接

**2. 风险管理**
分散、转移、对冲风险。工具上对应 [[投资组合理论]]、保险、[[金融衍生品]]。详见 [[风险识别与度量]]。

**3. 支付结算**
提供安全、高效的资金清算。基础设施包括银行间支付系统、证券结算系统、外汇清算等。

**4. 信息提供**
价格发现、信息披露、信用评级,降低信息不对称,提升市场效率。

### 体系结构

```
资金供给方 → [金融中介] → 资金需求方   (间接融资)
       ↘ [金融市场] ↗               (直接融资)
```

[[中央银行]] 处于体系中枢,负责货币发行、货币政策、最后贷款人职能。商业银行、投资银行、保险公司等是主要中介。

### 衡量标准

金融体系的质量通常用三个维度评估:**深度**(金融总量/GDP)、**效率**(资金配置效率)、**稳定性**(系统性风险水平)。

## 结论

金融体系的设计目标是让资金以最低成本流向最有生产力的用途,同时把风险分散到能够承担它的人身上。当某项功能失灵(如信息严重不对称、风险过度集中),就可能引发金融危机。
