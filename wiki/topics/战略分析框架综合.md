# 战略分析框架综合

## 概述

战略管理的核心问题是回答"**我们在哪里、想去哪里、怎么去**"。围绕这三个问题,百年来管理学界发展出大量分析工具,各自从不同视角切入。优秀的战略实践者不会拘泥单一工具,而是**组合使用、互相验证**。

本主题梳理主流战略分析工具的定位、关系与最佳搭配。

## 多角度分析

### 一、按分析层次分类

战略分析可分三层,各层有专属工具:

```
            宏观环境
              ↓ (外部最远端)
            行业环境
              ↓ (外部行业)
              企业
              ↓ (内部)
              资源能力
```

| 层次 | 主要工具 | 输出 |
|---|---|---|
| 宏观 | [[PESTEL分析]] | 政治、经济、社会、技术等趋势 |
| 行业 | [[Porter五力模型|波特五力模型]] | 行业吸引力评价 |
| 企业-外部 | 竞争对手分析 | 对手优势与意图 |
| 企业-内部 | [[价值链分析]]、VRIO、核心竞争力 | 内部能力诊断 |
| 综合 | [[SWOT分析]] | 内外整合的战略选项 |

### 二、按战略问题分类

**Q1. 行业是否吸引人?**

- [[Porter五力模型|波特五力模型]]:五力越强,行业越不吸引人
- [[BCG矩阵]]:用市场增长率衡量行业活力
- [[PESTEL分析]]:宏观趋势是否对行业有利

**Q2. 我们的定位应该是什么?**

- [[波特三种竞争战略]]:成本领先、差异化、聚焦
- [[STP分析]]:细分市场选择与定位
- [[蓝海战略]]:创造新市场而非在红海竞争

**Q3. 我们的能力是否支持?**

- [[价值链分析]]:每个活动的成本与差异化贡献
- VRIO 分析(Value, Rare, Inimitable, Organized):资源是否构成持续优势
- 核心竞争力(Hamel & Prahalad)

**Q4. 多业务如何配置资源?**

- [[BCG矩阵]]:业务组合分析
- GE/麦肯锡矩阵:更精细的九宫格

**Q5. 商业模式是什么?**

- [[商业模式画布]]:九大模块系统设计
- 价值主张画布(VPC):客户洞察细化

**Q6. 怎么落地战略?**

- [[平衡计分卡]]:战略地图与四维度 KPI
- OKR、KPI 体系
- 战略沟通与变革管理(参见 [[变革管理]])

### 三、典型组合使用

**经典组合 1:外部环境分析**

```
PESTEL → 五力模型 → 竞争对手分析
(宏观)  (行业)   (微观)
```

输出:行业吸引力 + 关键威胁/机会。

**经典组合 2:战略制定全流程**

```
PESTEL + 五力模型 → SWOT(O/T)
价值链 + VRIO     → SWOT(S/W)
              ↓
          SWOT 综合
              ↓
       TOWS 战略矩阵
              ↓
       波特三种战略 / 蓝海
              ↓
        商业模式画布
              ↓
        平衡计分卡 + KPI
```

**经典组合 3:多元化集团**

```
公司层:BCG / GE 矩阵 → 业务组合决策
业务层:五力 + 价值链 → 各业务竞争战略
职能层:营销 4P/STP、运营战略、HR 战略
```

### 四、工具特征对比

| 工具 | 视角 | 强项 | 弱项 |
|---|---|---|---|
| **PESTEL** | 宏观环境 | 系统扫描宏观因素 | 难量化、与企业关联远 |
| **波特五力** | 行业结构 | 解释行业利润 | 静态、忽视互补品 |
| **SWOT** | 综合 | 简单直观 | 罗列倾向、缺乏深度 |
| **价值链** | 内部活动 | 找成本/差异化来源 | 复杂、难量化 |
| **BCG 矩阵** | 业务组合 | 资源分配可视化 | 二维过简化 |
| **三种战略** | 业务战略 | 强迫定位选择 | 二选一可能错失双优 |
| **STP** | 营销战略 | 市场聚焦 | 实施细节弱 |
| **蓝海** | 创新战略 | 突破红海思维 | 不可复制、概念模糊 |
| **商业模式画布** | 整体设计 | 全要素可视化 | 静态、缺乏竞争视角 |
| **平衡计分卡** | 战略实施 | 多维平衡、可考核 | 设计复杂、KPI 过载风险 |

### 五、传统工具的局限与新框架

主流工具多源于 20 世纪 70-80 年代,面对当代议题有适应性问题:

**1. 平台与生态(参见 [[平台商业模式]])**

- 五力模型未涵盖互补品(第六力)
- 价值链是线性的,平台是网络的
- 应补充网络效应、生态系统视角

**2. 数字化与数据**

- 价值链中"数据"应成为核心活动
- 算法、AI 改变运营逻辑
- 客户数据所有权成为新议题

**3. 可持续与 ESG**

- 传统 SWOT 未强调可持续性
- 价值链需扩展到环境影响
- 共同价值(波特 2011)是补充

**4. VUCA 与敏捷**

- 静态规划工具难应对快速变化
- 突现战略(明茨伯格)与精益创业更适合
- 战略需要"试探-学习-调整"循环

### 六、避免的常见误区

- **工具崇拜**:为用 SWOT 而 SWOT,缺乏战略洞察
- **罗列而无判断**:列出 20 项 S/W/O/T 不分主次
- **静态分析**:只看当前不看趋势
- **缺乏证据**:基于直觉而非数据
- **不与行动联结**:分析后不做决策、不执行
- **过度复杂**:小公司用大模型,反而拖慢决策
- **忽视情境**:把硅谷玩法套用传统行业

## 结论

战略分析框架是**思维脚手架**,不是答案本身。优秀战略家具备的是:

- **多框架视角**:从不同角度看问题
- **整合判断**:在多种分析间形成连贯叙事
- **行动导向**:分析服务于决策
- **持续更新**:战略是过程而非事件

最好的战略往往**简单到一句话能讲清楚**,但其背后是大量分析的积淀。框架帮助我们思考得更全面,但**最终的战略洞察来自人的智慧、经验与勇气**。

正如 [[亨利·明茨伯格]] 所说:**"战略不是工程项目,而是手艺活。"**
