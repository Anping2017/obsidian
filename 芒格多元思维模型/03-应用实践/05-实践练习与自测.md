## 1. 基础概念练习

### 1.1 数学与统计思维练习
> "通过练习掌握数学与统计思维模型。"

#### 练习1：复利思维计算
**题目**：假设你每年投资10万元，年化收益率8%，连续投资30年，最终能获得多少资金？

**解题步骤**：
1. 识别复利公式：FV = PV × (1 + r)^n
2. 计算单次投资：10万 × (1.08)^30
3. 计算年金终值：使用年金终值公式
4. 分析复利效应：对比单利和复利差异

**扩展思考**：
- 如果收益率提高到12%，结果如何？
- 如果投资时间延长到40年，结果如何？
- 复利思维在个人成长中如何应用？

#### 练习2：概率统计应用
**题目**：某投资项目成功概率60%，失败概率40%。成功时收益100万，失败时损失50万。是否应该投资？

**解题步骤**：
1. 计算期望收益：E(X) = 0.6 × 100 + 0.4 × (-50)
2. 计算风险指标：方差、标准差
3. 风险收益分析：权衡风险与收益
4. 决策建议：基于期望效用理论

### 1.2 心理学思维练习
> "通过练习掌握心理学思维模型。"

#### 练习3：认知偏差识别
**题目**：分析以下场景中的认知偏差：
- 投资者只关注支持自己观点的新闻
- 消费者因为商品原价高而认为打折后便宜
- 团队因为前期投入大而不愿意放弃失败项目

**分析框架**：
1. 识别偏差类型：确认偏差、锚定效应、沉没成本
2. 分析偏差机制：心理机制、行为表现
3. 提出避免方法：多角度思考、数据验证
4. 设计纠正措施：建立检查机制

#### 练习4：激励理论应用
**题目**：设计员工激励方案，提高团队绩效。

**设计步骤**：
1. 需求分析：马斯洛需求层次分析
2. 激励设计：内在激励vs外在激励
3. 方案制定：具体激励措施
4. 效果评估：激励效果评估方法

## 2. 综合应用练习

### 2.1 投资决策综合练习
> "综合运用多种思维模型进行投资决策。"

#### 练习5：科技股投资分析
**背景**：某科技公司，主营业务为人工智能，当前股价50元，市盈率30倍。

**分析要求**：
1. **市场分析**：运用供需关系、历史周期律分析行业趋势
2. **公司分析**：运用系统思维、进化论思维分析公司优势
3. **估值分析**：运用复利思维、概率统计进行估值
4. **风险评估**：运用认知偏差、故障模式分析识别风险
5. **决策建议**：运用批判性思维、优化思维给出建议

**输出要求**：
- 投资分析报告（2000字）
- 风险收益分析图表
- 投资决策建议书

### 2.2 商业分析综合练习
> "综合运用多种思维模型进行商业分析。"

#### 练习6：新零售商业模式分析
**背景**：某传统零售企业计划转型新零售，需要分析转型策略。

**分析要求**：
1. **市场分析**：分析新零售市场机会和威胁
2. **竞争分析**：分析竞争格局和竞争优势
3. **商业模式**：设计新零售商业模式
4. **组织分析**：分析组织转型挑战
5. **风险分析**：识别转型风险和控制措施

**输出要求**：
- 商业分析报告（3000字）
- 商业模式画布
- 转型实施计划
