# 快速开始

## Odoo 17 快速入门指南

本指南将帮助您在30分钟内完成Odoo 17的安装、配置和第一个模块的创建。

### 快速安装

#### 使用Docker快速启动
```bash
# 1. 拉取Odoo镜像
docker pull odoo:17.0

# 2. 启动PostgreSQL
docker run -d \
  --name odoo-postgres \
  -e POSTGRES_DB=odoo17 \
  -e POSTGRES_USER=odoo \
  -e POSTGRES_PASSWORD=odoo \
  -e PGDATA=/var/lib/postgresql/data/pgdata \
  -v odoo-db-data:/var/lib/postgresql/data/pgdata \
  postgres:15

# 3. 启动Odoo
docker run -d \
  --name odoo \
  --link odoo-postgres:db \
  -p 8069:8069 \
  -e HOST=db \
  -e USER=odoo \
  -e PASSWORD=odoo \
  -v odoo-web-data:/var/lib/odoo \
  odoo:17.0

# 4. 访问Odoo
# 打开浏览器访问: http://localhost:8069
```

#### 本地安装（Ubuntu）
```bash
# 1. 安装依赖
sudo apt update
sudo apt install -y python3.10 python3.10-venv postgresql

# 2. 下载Odoo
wget https://nightly.odoo.com/17.0/nightly/src/odoo_17.0.latest.tar.gz
tar -xzf odoo_17.0.latest.tar.gz

# 3. 安装Python依赖
cd odoo-17.0
python3.10 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 4. 启动Odoo
./odoo-bin --init=base --stop-after-init
./odoo-bin
```

#### 数据模型
```python
# models/__init__.py
from . import hello_world

# models/hello_world.py
from odoo import models, fields, api

class HelloWorld(models.Model):
    _name = 'hello.world'
    _description = 'Hello World Model'
    
    name = fields.Char('名称', required=True)
    message = fields.Text('消息')
    active = fields.Boolean('激活', default=True)
    
    @api.model
    def create(self, vals):
        if not vals.get('message'):
            vals['message'] = f"欢迎使用 {vals.get('name', 'Odoo')}!"
        return super().create(vals)
```

### 进阶功能

#### 添加计算字段
```python
# models/hello_world.py
class HelloWorld(models.Model):
    _name = 'hello.world'
    _description = 'Hello World Model'
    
    name = fields.Char('名称', required=True)
    message = fields.Text('消息')
    active = fields.Boolean('激活', default=True)
    char_count = fields.Integer('字符数', compute='_compute_char_count')
    
    @api.depends('message')
    def _compute_char_count(self):
        for record in self:
            record.char_count = len(record.message or '')
```

#### 添加约束
```python
from odoo.exceptions import ValidationError

class HelloWorld(models.Model):
    _name = 'hello.world'
    _description = 'Hello World Model'
    
    name = fields.Char('名称', required=True)
    message = fields.Text('消息')
    active = fields.Boolean('激活', default=True)
    
    @api.constrains('name')
    def _check_name(self):
        for record in self:
            if len(record.name) < 3:
                raise ValidationError("名称长度不能少于3个字符")
```

#### 添加工作流
```python
class HelloWorld(models.Model):
    _name = 'hello.world'
    _description = 'Hello World Model'
    
    name = fields.Char('名称', required=True)
    message = fields.Text('消息')
    active = fields.Boolean('激活', default=True)
    state = fields.Selection([
        ('draft', '草稿'),
        ('confirmed', '已确认'),
        ('done', '完成')
    ], '状态', default='draft')
    
    def action_confirm(self):
        self.write({'state': 'confirmed'})
    
    def action_done(self):
        self.write({'state': 'done'})
```
