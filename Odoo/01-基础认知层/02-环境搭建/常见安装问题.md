## 🐍 Python环境问题

### Python版本不兼容
**问题描述**: 提示Python版本不支持
```
Error: Python 3.7 is not supported. Please use Python 3.8 or higher.
```

**解决方案**:
```bash
# 检查Python版本
python3 --version

# 安装正确的Python版本
# Ubuntu/Debian
sudo apt install python3.8 python3.8-venv python3.8-dev

# 创建新的虚拟环境
python3.8 -m venv odoo-env
source odoo-env/bin/activate

# 验证版本
python --version
```

### 依赖包安装失败
**问题描述**: pip安装依赖包时出现错误
```
ERROR: Failed building wheel for lxml
```

**解决方案**:
```bash
# 安装系统依赖
# Ubuntu/Debian
sudo apt update
sudo apt install build-essential libxml2-dev libxslt1-dev libevent-dev libsasl2-dev libldap2-dev libpq-dev libpng-dev libjpeg-dev libfreetype6-dev liblcms2-dev libwebp-dev libharfbuzz-dev libfribidi-dev libxcb1-dev

# CentOS/RHEL
sudo yum groupinstall "Development Tools"
sudo yum install libxml2-devel libxslt-devel libevent-devel cyrus-sasl-devel openldap-devel postgresql-devel libpng-devel libjpeg-devel freetype-devel lcms2-devel libwebp-devel harfbuzz-devel fribidi-devel libxcb-devel

# 重新安装依赖
pip install --upgrade pip
pip install -r requirements.txt
```

### 虚拟环境问题
**问题描述**: 虚拟环境激活失败
```
bash: odoo-env/bin/activate: No such file or directory
```

**解决方案**:
```bash
# 检查虚拟环境是否存在
ls -la odoo-env/

# 重新创建虚拟环境
rm -rf odoo-env
python3 -m venv odoo-env

# 激活虚拟环境
source odoo-env/bin/activate

# 验证激活状态
which python
```

## 🗄️ 数据库连接问题

### PostgreSQL服务未启动
**问题描述**: 无法连接到数据库
```
FATAL: password authentication failed for user "odoo"
```

**解决方案**:
```bash
# 检查PostgreSQL服务状态
sudo systemctl status postgresql

# 启动PostgreSQL服务
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 检查端口是否监听
sudo netstat -tlnp | grep 5432

# 测试连接
psql -h localhost -U odoo -d odoo_db
```

### 数据库用户权限问题
**问题描述**: 用户没有创建数据库的权限
```
ERROR: permission denied to create database
```

**解决方案**:
```bash
# 切换到postgres用户
sudo -u postgres psql

# 创建用户并授权
CREATE USER odoo WITH PASSWORD 'odoo';
ALTER USER odoo CREATEDB;
ALTER USER odoo WITH SUPERUSER;

# 或者修改现有用户
ALTER USER odoo CREATEDB;
ALTER USER odoo WITH SUPERUSER;
```

### 数据库不存在
**问题描述**: 指定的数据库不存在
```
FATAL: database "odoo_db" does not exist
```

**解决方案**:
```bash
# 创建数据库
sudo -u postgres createdb odoo_db -O odoo

# 或者通过psql创建
sudo -u postgres psql
CREATE DATABASE odoo_db OWNER odoo;
GRANT ALL PRIVILEGES ON DATABASE odoo_db TO odoo;
```

## 🌐 网络和端口问题

### 端口被占用
**问题描述**: 8069端口已被占用
```
ERROR: Address already in use
```

**解决方案**:
```bash
# 查找占用端口的进程
sudo lsof -i :8069
sudo netstat -tlnp | grep 8069

# 杀死占用进程
sudo kill -9 <PID>

# 或者使用其他端口
odoo -c odoo.conf --http-port=8070
```

### 防火墙阻止访问
**问题描述**: 无法从外部访问Odoo
```
Connection refused
```

**解决方案**:
```bash
# Ubuntu/Debian (ufw)
sudo ufw allow 8069
sudo ufw reload

# CentOS/RHEL (firewalld)
sudo firewall-cmd --permanent --add-port=8069/tcp
sudo firewall-cmd --reload

# 检查防火墙状态
sudo ufw status
sudo firewall-cmd --list-ports
```

## 📁 文件和权限问题

### 权限不足
**问题描述**: 没有写入权限
```
Permission denied: '/var/lib/odoo'
```

**解决方案**:
```bash
# 创建目录并设置权限
sudo mkdir -p /var/lib/odoo
sudo chown -R odoo:odoo /var/lib/odoo
sudo chmod -R 755 /var/lib/odoo

# 检查权限
ls -la /var/lib/odoo
```

### 配置文件路径错误
**问题描述**: 找不到配置文件
```
FileNotFoundError: [Errno 2] No such file or directory: 'odoo.conf'
```

**解决方案**:
```bash
# 检查配置文件是否存在
ls -la odoo.conf

# 创建配置文件
cp odoo.conf.example odoo.conf

# 指定配置文件路径
odoo -c /path/to/odoo.conf
```

## 🔧 配置问题

### 配置文件语法错误
**问题描述**: 配置文件格式错误
```
ConfigParser.MissingSectionHeaderError: File contains no section headers.
```

**解决方案**:
```ini
# 检查配置文件格式
[options]
; 确保有[options]节
db_host = localhost
db_port = 5432
db_user = odoo
db_password = odoo
db_name = odoo_db
```

### 模块路径错误
**问题描述**: 找不到模块
```
ModuleNotFoundError: No module named 'odoo'
```

**解决方案**:
```bash
# 检查Python路径
python -c "import sys; print(sys.path)"

# 添加Odoo路径
export PYTHONPATH=/path/to/odoo:$PYTHONPATH

# 或者在配置文件中指定
addons_path = /path/to/odoo/addons,/path/to/custom/addons
```

## 🐳 Docker相关问题

### Docker容器启动失败
**问题描述**: 容器无法启动
```
ERROR: Container failed to start
```

**解决方案**:
```bash
# 检查Docker服务
sudo systemctl status docker

# 查看容器日志
docker logs <container_name>

# 检查端口冲突
docker ps -a

# 重新构建镜像
docker-compose build --no-cache
```

### 数据卷挂载问题
**问题描述**: 数据卷挂载失败
```
ERROR: Volume mount failed
```

**解决方案**:
```yaml
# 检查docker-compose.yml
version: '3.8'
services:
  odoo:
    volumes:
      - ./addons:/mnt/extra-addons:ro
      - ./config:/etc/odoo:ro
      - odoo-data:/var/lib/odoo
```

## 🔍 故障排除工具

### 日志分析
```bash
# 查看Odoo日志
tail -f /var/log/odoo/odoo.log

# 查看系统日志
sudo journalctl -u odoo -f

# 查看PostgreSQL日志
sudo tail -f /var/log/postgresql/postgresql-13-main.log
```

### 网络诊断
```bash
# 测试端口连通性
telnet localhost 8069
nc -zv localhost 8069

# 检查DNS解析
nslookup localhost
dig localhost

# 网络路由检查
traceroute localhost
```

### 系统资源检查
```bash
# 检查内存使用
free -h
top -p $(pgrep odoo)

# 检查磁盘空间
df -h
du -sh /var/lib/odoo

# 检查CPU使用
htop
iostat 1
```
