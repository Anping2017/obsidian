# 部署问题排查

## Odoo 17 部署问题排查指南

本文档提供了Odoo 17部署过程中常见问题的排查指南，包括环境配置、服务启动、网络连接、权限问题、数据库连接等，帮助开发者快速解决部署问题。

### 环境配置问题

#### 1. Python环境问题
```bash
# 检查Python版本
python3 --version
# 应该显示 Python 3.8+ 

# 检查Python路径
which python3
# 应该指向正确的Python解释器

# 检查Python模块
python3 -c "import sys; print(sys.path)"
# 检查模块搜索路径

# 常见Python环境问题
# 1. Python版本不兼容
# 解决方案：安装Python 3.8+
sudo apt update
sudo apt install python3.8 python3.8-venv python3.8-dev

# 2. 缺少开发工具
# 解决方案：安装编译工具
sudo apt install build-essential libssl-dev libffi-dev

# 3. 虚拟环境问题
# 解决方案：重新创建虚拟环境
python3 -m venv odoo-venv
source odoo-venv/bin/activate
pip install --upgrade pip
```

#### 3. 配置文件问题

### 服务启动问题

#### 1. systemd服务问题
```bash
# 检查服务状态
sudo systemctl status odoo
# 查看服务运行状态

# 查看服务日志
sudo journalctl -u odoo -f
# 实时查看服务日志

# 重启服务
sudo systemctl restart odoo
# 重启Odoo服务

# 常见服务问题
# 1. 服务启动失败
# 解决方案：检查配置文件和服务文件
sudo systemctl daemon-reload
sudo systemctl enable odoo
sudo systemctl start odoo

# 2. 权限问题
# 解决方案：检查用户和权限
sudo chown -R odoo:odoo /opt/odoo
sudo chown -R odoo:odoo /var/log/odoo
sudo chown -R odoo:odoo /var/lib/odoo

# 3. 端口占用问题
# 解决方案：检查端口使用情况
sudo netstat -tlnp | grep :8069
sudo lsof -i :8069
# 杀死占用端口的进程
sudo kill -9 <PID>
```

#### 2. 进程管理问题
```bash
# 检查Odoo进程
ps aux | grep odoo
# 查看Odoo进程

# 检查进程资源使用
top -p $(pgrep odoo)
# 查看进程资源使用情况

# 杀死Odoo进程
sudo pkill -f odoo
# 杀死所有Odoo进程

# 常见进程问题
# 1. 进程卡死
# 解决方案：强制杀死进程
sudo pkill -9 -f odoo
sudo systemctl restart odoo

# 2. 内存泄漏
# 解决方案：监控内存使用，定期重启
# 在crontab中添加定期重启任务
0 2 * * * systemctl restart odoo

# 3. 进程数量过多
# 解决方案：限制worker数量
# 在odoo.conf中设置
workers = 4
max_cron_threads = 2
```

#### 3. 日志分析
```bash
# 查看Odoo日志
tail -f /var/log/odoo/odoo.log
# 实时查看日志

# 搜索错误日志
grep -i error /var/log/odoo/odoo.log
# 搜索错误信息

# 搜索警告日志
grep -i warning /var/log/odoo/odoo.log
# 搜索警告信息

# 分析日志文件
# 1. 查看最近的错误
tail -100 /var/log/odoo/odoo.log | grep -i error

# 2. 统计错误类型
grep -i error /var/log/odoo/odoo.log | awk '{print $4}' | sort | uniq -c

# 3. 查看特定时间段的日志
grep "2024-01-01" /var/log/odoo/odoo.log
```

### 网络连接问题

#### 1. 端口和防火墙
```bash
# 检查端口监听
sudo netstat -tlnp | grep :8069
# 检查8069端口是否监听

# 检查防火墙状态
sudo ufw status
# 检查UFW防火墙状态

# 开放Odoo端口
sudo ufw allow 8069/tcp
# 开放8069端口

# 检查SELinux状态（CentOS/RHEL）
sestatus
# 检查SELinux状态

# 临时禁用SELinux
sudo setenforce 0
# 临时禁用SELinux

# 永久禁用SELinux
sudo sed -i 's/SELINUX=enforcing/SELINUX=disabled/' /etc/selinux/config
```

#### 2. 反向代理配置
```nginx
# Nginx配置示例
server {
    listen 80;
    server_name your-domain.com;
    
    # 重定向到HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name your-domain.com;
    
    # SSL证书配置
    ssl_certificate /path/to/certificate.crt;
    ssl_certificate_key /path/to/private.key;
    
    # 安全配置
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512;
    ssl_prefer_server_ciphers off;
    
    # 代理配置
    location / {
        proxy_pass http://127.0.0.1:8069;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时配置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
        
        # 缓冲配置
        proxy_buffering on;
        proxy_buffer_size 4k;
        proxy_buffers 8 4k;
    }
    
    # 静态文件配置
    location /web/static/ {
        alias /opt/odoo/addons/web/static/;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

### 数据库连接问题

#### 1. PostgreSQL连接问题
```bash
# 检查PostgreSQL服务状态
sudo systemctl status postgresql
# 查看PostgreSQL服务状态

# 检查PostgreSQL端口
sudo netstat -tlnp | grep :5432
# 检查5432端口

# 测试数据库连接
psql -h localhost -U odoo -d odoo_db
# 测试数据库连接

# 常见数据库问题
# 1. 连接被拒绝
# 解决方案：检查pg_hba.conf
sudo nano /etc/postgresql/15/main/pg_hba.conf
# 添加：local   all             odoo                                    md5

# 2. 认证失败
# 解决方案：重置用户密码
sudo -u postgres psql
ALTER USER odoo PASSWORD 'new_password';

# 3. 数据库不存在
# 解决方案：创建数据库
sudo -u postgres createdb odoo_db
```

#### 2. 数据库权限问题
```sql
-- 检查用户权限
SELECT usename, usecreatedb, usesuper FROM pg_user WHERE usename = 'odoo';

-- 授予必要权限
GRANT CREATE ON DATABASE odoo_db TO odoo;
GRANT USAGE ON SCHEMA public TO odoo;
GRANT CREATE ON SCHEMA public TO odoo;

-- 检查表权限
SELECT table_name, privilege_type 
FROM information_schema.table_privileges 
WHERE grantee = 'odoo';
```

#### 3. 数据库性能问题
```bash
# 检查数据库大小
sudo -u postgres psql -c "SELECT pg_size_pretty(pg_database_size('odoo_db'));"

# 检查表大小
sudo -u postgres psql -d odoo_db -c "
SELECT 
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) as size
FROM pg_tables
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC
LIMIT 10;"

# 检查连接数
sudo -u postgres psql -c "SELECT count(*) FROM pg_stat_activity;"

# 检查慢查询
sudo -u postgres psql -c "SELECT query, mean_time FROM pg_stat_statements ORDER BY mean_time DESC LIMIT 5;"
```

#### 2. 数据库性能监控
```sql
-- 检查活跃连接
SELECT count(*) FROM pg_stat_activity WHERE state = 'active';

-- 检查慢查询
SELECT query, mean_time, calls 
FROM pg_stat_statements 
ORDER BY mean_time DESC 
LIMIT 10;

-- 检查锁等待
SELECT blocked_locks.pid AS blocked_pid,
       blocked_activity.usename AS blocked_user,
       blocking_locks.pid AS blocking_pid,
       blocking_activity.usename AS blocking_user,
       blocked_activity.query AS blocked_statement
FROM pg_catalog.pg_locks blocked_locks
JOIN pg_catalog.pg_stat_activity blocked_activity ON blocked_activity.pid = blocked_locks.pid
JOIN pg_catalog.pg_locks blocking_locks ON blocking_locks.locktype = blocked_locks.locktype
JOIN pg_catalog.pg_stat_activity blocking_activity ON blocking_activity.pid = blocking_locks.pid
WHERE NOT blocked_locks.granted;
```
