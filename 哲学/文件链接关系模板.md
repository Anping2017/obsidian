# 文件链接关系模板

## 核心链接模式

### 概念链接
```markdown
# 存在与实在
- 相关概念：[[真理与知识]] [[价值与意义]] [[时间与空间]]
- 对立概念：[[现象与本质]] [[主观与客观]]
- 哲学家观点：[[柏拉图]] [[亚里士多德]] [[海德格尔]]
- 理论体系：[[理念论]] [[存在主义]] [[现象学]]
```

### 哲学家链接
```markdown
# 柏拉图
- 老师：[[苏格拉底]]
- 学生：[[亚里士多德]]
- 核心理论：[[理念论]]
- 主要著作：《理想国》 《斐多篇》
- 影响：[[新柏拉图主义]] [[基督教哲学]]
```

### 理论体系链接
```markdown
# 存在主义
- 代表人物：[[萨特]] [[海德格尔]] [[尼采]]
- 核心概念：[[存在]] [[自由]] [[焦虑]]
- 对立理论：[[本质主义]] [[决定论]]
- 应用领域：[[生命伦理问题]] [[个人哲学构建]]
```

## 双向链接规则
1. 每个概念都要链接到相关哲学家
2. 每个哲学家都要链接到其理论
3. 每个理论都要链接到应用场景
4. 建立时间线链接（古代→中世纪→近代→现代→当代）
