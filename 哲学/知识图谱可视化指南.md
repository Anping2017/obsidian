## 📊 数据可视化模板

### 使用Dataview插件
```dataview
TABLE file.ctime as "创建时间", tags as "标签"
FROM #认识层
SORT file.ctime DESC
```

### 学习进度追踪
```dataview
TABLE status as "状态", difficulty as "难度"
FROM #学习中
WHERE status = "进行中"
```

### 概念关联查询
```dataview
LIST
FROM [[存在与实在]]
FLATTEN file.outlinks as 链接
WHERE 链接 != null
```

## 🎨 图谱设计原则

### 颜色编码
- 🔵 蓝色：认识层内容
- 🟢 绿色：理解层内容
- 🟡 黄色：应用层内容
- 🔴 红色：重要概念
- 🟣 紫色：关键哲学家

### 节点大小
- 大节点：核心概念
- 中节点：重要理论
- 小节点：具体问题

### 连接线类型
- 实线：直接关系
- 虚线：间接关系
- 粗线：强关联
- 细线：弱关联

## 🔗 图谱更新规则
1. 每学习一个新概念，立即建立链接
2. 定期检查图谱的完整性和准确性
3. 根据学习进度调整图谱结构
4. 利用图谱发现知识盲点
