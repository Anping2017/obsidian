## 🔍 理论体系分类

### 按哲学传统分类
- **大陆哲学传统**：现象学、存在主义、后现代主义
- **分析哲学传统**：逻辑实证主义、日常语言哲学
- **实用主义传统**：皮尔士、詹姆斯、杜威
- **批判理论传统**：法兰克福学派、哈贝马斯

### 按哲学领域分类
- **形而上学理论**：理念论、实体论、存在主义
- **认识论理论**：经验主义、理性主义、现象学
- **伦理学理论**：德性伦理学、义务伦理学、功利主义
- **政治哲学理论**：自由主义、社群主义、无政府主义

### 按哲学方法分类
- **理性主义方法**：笛卡尔主义、斯宾诺莎主义
- **经验主义方法**：洛克主义、休谟主义
- **现象学方法**：胡塞尔现象学、海德格尔存在主义
- **分析哲学方法**：逻辑分析、语言分析

## 🔗 理论体系关系

### 发展关系
- **理念论** → **新柏拉图主义** → **奥古斯丁主义**
- **亚里士多德主义** → **托马斯主义** → **现代实体论**
- **经验主义** → **实证主义** → **逻辑实证主义**

### 对立关系
- **理念论** ↔ **实体论**（柏拉图 vs 亚里士多德）
- **理性主义** ↔ **经验主义**（笛卡尔 vs 洛克）
- **现象学** ↔ **分析哲学**（大陆哲学 vs 英美哲学）

### 综合关系
- **康德主义**：综合理性主义与经验主义
- **黑格尔主义**：综合各种对立理论
- **实用主义**：综合理论与实践

## 📚 学习建议

### 学习顺序
1. **古代理论**：理念论、实体论
2. **近代理论**：理性主义、经验主义
3. **现代理论**：现象学、存在主义
4. **当代理论**：后现代主义、批判理论

### 学习方法
1. **历史脉络**：按时间顺序学习
2. **理论对比**：对比不同理论体系
3. **问题导向**：围绕核心问题学习
4. **原著阅读**：阅读重要理论家的原著

### 重点理论
- **必读**：理念论、实体论、康德主义、现象学
- **重要**：经验主义、理性主义、存在主义、分析哲学
- **现代**：后现代主义、批判理论、实用主义

## 🎯 学习要点

### 理解要点
1. 每个理论体系都有其核心观点
2. 理论体系之间存在发展关系
3. 不同传统有不同的理论方法
4. 理论发展有其内在逻辑

### 思考问题
1. 理论体系的核心观点是什么？
2. 不同理论如何回应相同问题？
3. 理论体系如何影响后世？
4. 现代理论如何发展？
