## 🔍 哲学家分类

- **大陆哲学**：德国、法国哲学传统
- **分析哲学**：英美哲学传统
- **现象学**：胡塞尔、海德格尔传统
- **存在主义**：萨特、加缪传统

### 按哲学领域分类
- **形而上学**：柏拉图、亚里士多德、海德格尔
- **认识论**：笛卡尔、洛克、康德
- **伦理学**：苏格拉底、康德、罗尔斯
- **政治哲学**：霍布斯、洛克、罗尔斯

### 按哲学方法分类

### 师生关系
- **苏格拉底** → **柏拉图** → **亚里士多德**
- **康德** → **费希特** → **谢林** → **黑格尔**
- **胡塞尔** → **海德格尔** → **萨特**

### 思想影响
- **柏拉图** → **奥古斯丁** → **笛卡尔**
- **亚里士多德** → **托马斯·阿奎那** → **洛克**
- **康德** → **叔本华** → **尼采**

### 对立关系
- **柏拉图** ↔ **亚里士多德**（理念论 vs 实体论）
- **笛卡尔** ↔ **洛克**（理性主义 vs 经验主义）
- **康德** ↔ **休谟**（先验哲学 vs 怀疑论）

## 📚 学习建议

### 学习顺序
1. **古代哲学**：从苏格拉底、柏拉图、亚里士多德开始
2. **近代哲学**：重点学习笛卡尔、洛克、康德
3. **现代哲学**：关注尼采、海德格尔、维特根斯坦
4. **当代哲学**：了解福柯、德里达、罗尔斯

### 学习方法
1. **历史脉络**：按时间顺序学习
2. **思想对比**：对比不同哲学家的观点
3. **问题导向**：围绕核心问题学习
4. **原著阅读**：阅读重要哲学家的原著

### 重点哲学家
- **必读**：苏格拉底、柏拉图、亚里士多德、笛卡尔、康德
- **重要**：洛克、休谟、黑格尔、尼采、海德格尔
- **现代**：维特根斯坦、萨特、福柯、罗尔斯

## 🎯 学习要点

### 理解要点
1. 每个哲学家都有其核心思想
2. 哲学家之间存在思想传承关系
3. 不同传统有不同的哲学方法
4. 哲学发展有其内在逻辑

### 思考问题
1. 哲学家的核心思想是什么？
2. 不同哲学家如何回应相同问题？
3. 哲学思想如何影响后世？
4. 现代哲学如何发展？
