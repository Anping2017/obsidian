# 哲学知识体系总览

## 🎯 体系概述
本知识体系采用**金字塔模型**，从基础认知到深度理解再到实践应用，为INTJ学习者提供结构化的哲学学习路径。

## 📚 三层结构

### 🧠 认识层 - 基础认知
**目标**：建立哲学基础概念和整体框架
- **哲学导论与入门**：什么是哲学、哲学价值、哲学思维
- **哲学史发展脉络**：古代→中世纪→近代→现代→当代
- **核心概念体系**：存在、真理、价值、自由、正义等
- **哲学分支概览**：形而上学、认识论、伦理学等

### 🔍 理解层 - 深度分析
**目标**：深入理解哲学理论和思想
- **重要哲学家**：从苏格拉底到当代哲学家的思想
- **核心理论体系**：理念论、存在主义、现象学等
- **经典哲学问题**：身心问题、自由意志、道德基础等
- **哲学方法论**：辩证法、现象学方法、分析哲学方法

### 🚀 应用层 - 实践运用
**目标**：将哲学智慧应用于实际生活
- **哲学思维训练**：批判性思维、逻辑推理、概念分析
- **现实问题应用**：科技伦理、环境哲学、生命伦理
- **跨学科整合**：哲学与科学、艺术、宗教的关系
- **个人哲学构建**：世界观、人生观、价值观的确立

## 🗺️ 学习路径

### 初学者路径（3-6个月）
1. 哲学导论 → 核心概念 → 哲学史概览 → 重要哲学家
2. **重点**：建立基础认知，培养哲学思维

### 进阶者路径（6-12个月）
1. 理论体系 → 经典问题 → 现代哲学 → 应用实践
2. **重点**：深入理解，形成批判性思维

### 研究者路径（12个月以上）
1. 深度研究 → 跨学科整合 → 原创思考 → 实践应用
2. **重点**：构建个人哲学体系，形成独立见解
