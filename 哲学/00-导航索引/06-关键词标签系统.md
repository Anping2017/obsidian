# 关键词标签系统

## 🎯 标签系统说明

本标签系统为INTJ学习者设计，采用**层次化**和**交叉分类**的方式组织哲学知识，便于快速检索和建立知识关联。

## 📊 标签分类体系

### 🏷️ 层次标签

#### 学习层次
| 标签 | 含义 | 适用范围 | 示例 |
|------|------|----------|------|
| `#认识层` | 基础认知层次 | 基础概念、导论内容 | 什么是哲学、哲学价值 |
| `#理解层` | 深度理解层次 | 理论分析、哲学家研究 | 理念论、苏格拉底 |
| `#应用层` | 实践应用层次 | 思维训练、现实应用 | 批判性思维、科技伦理 |

| 标签 | 含义 | 适用范围 | 示例 |

## 🔗 标签使用规则

### 标签组合原则
1. **层次标签** + **学科标签** + **历史标签**
2. **难度标签** + **主题标签** + **功能标签**
3. **核心标签** + **辅助标签** + **特色标签**

### 标签使用示例
```
#认识层 #形而上学 #古代哲学 #入门级 #存在 #核心概念
#理解层 #认识论 #近代哲学 #进阶级 #知识 #重要哲学家
#应用层 #伦理学 #现代哲学 #高级 #正义 #现实应用
```

### 标签检索技巧
1. **单一标签**：快速定位特定内容
2. **组合标签**：精确查找相关内容
3. **排除标签**：排除不需要的内容
4. **相关标签**：发现相关内容
