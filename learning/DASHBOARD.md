## 评分标尺

### Coverage 覆盖度
- **1**:只接触少数核心概念
- **2**:覆盖 1-2 个子领域
- **3**:覆盖主要子领域之半
- **4**:主要子领域大致覆盖
- **5**:子领域基本完整,边角也有

**客观锚点**(篇数→分):< 40 → 2 / 40-100 → 3 / 100-200 → 4 / > 200 → 5(粗略,首月校准)

### Depth 深度
- **1**:多 stub,只是定义
- **2**:能复述但无独立见解
- **3**:能讲清楚机制
- **4**:能识别局限与争议
- **5**:能写综述给别人看

**客观锚点**:mature 占比、平均篇长、被引次数;首月精细化时再调整

### Connectedness 连接度
- **1**:孤立成块
- **2**:学科内部互通
- **3**:有跨域意识
- **4**:能跨域联想
- **5**:自由跨学科分析

**客观锚点**:wikilinks 平均度、参与跨域桥接对的数量

### Application 应用度
- **1**:纯阅读,0 应用
- **2**:偶尔说起
- **3**:用来分析过 1-2 次具体问题
- **4**:每月用 1-2 次分析决策
- **5**:日常思维默认嵌入

**客观锚点**:被 D mode 调用的次数、被 output/ 引用的次数

## 标尺外状态注释

ⁿ = 用户自评原始为 **0**,表达"vault 中有但未亲读/未内化"。当前标尺 1-5 不能表达这个状态,**月复盘候选议题**:是否在标尺加 0 级(`0 = 知识库中存在但未亲自阅读`)。

## 使用提示

- **何时看 DASHBOARD**:开始 session 前看 1 分钟,知道当前在哪;不要花太多时间研究表格
- **何时改 DASHBOARD**:① 每次 session 结束自动更新客观字段 ② 月复盘重打主观
- **不要"刷分"**:主观以你的真实感受为准,客观数据只是对照,不要为了让 Self=5 反推该做什么
- **盲点信号**:某格 Obj-Self 差 ≥ 2 分 → 提醒月复盘讨论(可能是过度自信或假性熟悉)
