# D mode session — 产品能力设计

## 与前面 output 的关系
- 首轮(华人聚焦)+ 第二轮(NZ 全市场)是**战略层**
- 本轮是**产品层**——具体到要做什么 AI 能力

## 核心拆解
1. 行业流程 4 阶段:进货-销售-维修-二手
2. AI 能力矩阵 13 个候选,按 价值/难度/垂直壁垒 排序
3. 核心 5 项:故障诊断+报价 / 二手估价 / AIGC 工厂 / AI 客服 / 多平台投放
4. 护城河 3 项:垂直语料 / 全流程闭环 / 多语言本地化
5. 长期能力 3 项:网络效应 / 供应链整合 / 2C 信任品牌

## 设计原则(7 条)
垂直深度 > 通用 / 闭环 > 单点 / 数据资产 > 模型代码 / 低门槛 / 可解释 / 本地化 / 隐私合规

## MVP wedge
**AI 故障诊断 + 透明报价工具**

为何这个先做:高频痛点 / NO.1 客诉 / 粘性极高 / 垂直壁垒厚 / 1 人可做 / 自然延展

## 一句话
"手机行业垂直 AI 的核心,不是'用 AI 做手机行业的事',是'用 AI 做通用工具做不到的事'。"
