# C mode session — Bezos 思维框架(四人合集完结)

## 四人合集总览
| 篇 | 核心 | 最可复用 | 时间焦点 | 谁该学 |
|---|---|---|---|---|
| Musk | 物理+激进 | Algorithm 5 步 | 短期突破 | 深科技创业者 |
| Jobs | 品味+简洁 | Say No 2x2 | 中期完美 | 消费产品驱动 |
| Munger | 多学科+谦逊 | Inversion+激励 | 长期存活 | 投资人/长期决策 |
| **Bezos** | **客户+长期+系统** | **Type 1/2 决策** | **20-50 年** | **平台/服务/生态** |

## Bezos 独特贡献
前三位都有"稀缺资源":
- Musk 稀缺 = 极限风险容忍(不可复制)
- Jobs 稀缺 = 天赋级品味(不可复制)
- Munger 稀缺 = 广谱学习纪律(可训练但需长时间)
- **Bezos 稀缺 = 决策系统化 + 组织长寿化(最可教)**

## 教学策略
- 12 大模式(与 Musk/Jobs/Munger 篇同长度)
- Type 1/2 决策法单独深度展开(最原创方法论)
- 4 方对比(完整版)
- **四人融合公式最终版**(战略级产出,给用户的最终框架)
- 强调"谁最适合谁"(用户是平台/服务型 → Bezos 最匹配)

## 核心洞察
- Bezos 与 Munger 是最可教的一对(都靠系统不靠天赋)
- **对用户(手机 AI 营销 / 露营变现),Bezos 方法最匹配** — 因为都是"客户长期价值+慢积累资产"型生意
- 特别强调 **Type 1/2 分类** — 用户 vault 里大多数纠结是把 Type 2 当 Type 1 处理

## 与用户路径的直接应用
1. Working Backwards 写 press release (先写发布新闻稿,写不出来别做)
2. Type 1/2 分类现有纠结(手机 vs 露营 = Type 2,立刻试)
3. Regret Minimization for Type 1(辞主业问 80 岁)
4. 押 10 年不变的东西(客户想信任+省时间+有把握)
5. Day 1 审视 vault(每季度问"如果是第一天怎么建")
