# C mode session — Messaging Framework 教学

## 触发
用户读 2026 数字营销框架 output 层 2.2 后反馈"有点看不懂",请求展开。

## 教学策略
1. **同心圆关系**:先说 4 个组件不是并列,是递进,从全景到实战
2. **公式化**:每个组件给经典公式(可复用)
3. **双例子**:用户已在做的两条业务路径(手机营销 + 露营)贯穿 4 个 framework
4. **模板化**:结尾给可直接填的模板
5. **常见错误**:9 条清单让用户自查

## 核心澄清点(用户可能没看懂)

1. **Positioning 的"类别"字段** — 选一个"好比较"的类别,让客户知道把你放哪个盒子
2. **利益 vs 功能** — Positioning 提供的是**利益**(客户得到什么),不是功能(你做什么)
3. **Persona 不只是人口统计** — 要加"他们的话"式痛点
4. **Elevator Pitch 的 Ask** — 没有 Ask 对方就走了,永远要留下一步

## 4 个 Framework 使用场景速查

| Framework | 用途 | 长度 |
|---|---|---|
| Value Proposition | 团队统一认知 | 5 句 |
| Positioning | 拉开竞品距离 | 4 句 |
| Key Messages | 定制化沟通 | 每 persona 3 项 |
| Elevator Pitch | 陌生场合 30 秒 | 30 秒讲稿 |
