# 关键事件:Mode D 重大返工

## 触发
用户回复"我在新西兰"后,意识到之前的 Mode D 分析默认中国市场假设,与现实严重错位。

## 重大错位点(对比)

| 维度 | 中国默认(错) | 新西兰实际 |
|---|---|---|
| 市场规模 | 14 亿人 / 几十万店 | 500 万人 / 1-3K 店 |
| 平台 | 抖音/小红书/视频号 | TikTok/IG/FB/Google/YouTube + 微信小红书(华人) |
| 私域 | 微信 | WhatsApp / FB / IG DM |
| 二手 | 闲鱼/转转 | Trade Me |
| 客户特征 | 价格敏感 | 信任驱动 + 客单高 |
| SaaS 可行性 | 可行 | 单国 TAM 太小,不可行 |

## NZ 版核心调整

1. **定位升级**:从"手机行业 AI 营销人" → "**NZ 亚裔小生意双语营销人**"
2. **五重稀缺**:营销 × AI × 手机 × NZ 在地 × 中英双语
3. **路径调整**:B → F → 课程/模板/SaaS-lite(不做重 SaaS,NZ 市场太小)
4. **扩展路线**:NZ → ANZ(澳新)→ 海外华人圈 → 亚洲跨境
5. **客单价**:NZ$1,500-4,000/月/店,10-30 家客户即稳健

## 一句话(NZ 版)

"别做 NZ 的 AI 营销公司,做在 NZ 服务亚裔小生意的双语营销人。"

- **PLAYBOOK Mode D 步骤 1**:必要项从 4 项 → 5 项
- 新增:**"市场/区域"**(决策落在哪个地理市场)

## 月复盘必讨论

1. **市场/区域必要项**:本次教训触发的 PLAYBOOK 修订,月复盘正式归档与版本号处理
2. **是否所有 mode 都该问"市场/区域"**?A mode 诊断、B mode 跨域、C mode 深读、F mode 兜底,有些可能也受影响(C mode 深读"营销"概念时,NZ 营销 vs 中国营销分歧很大)
3. **Claude 的隐性假设审计**:除了"市场",还有哪些 Claude 默认假设可能错位?(语言 / 行业法规 / 文化 / 货币 / 时间区 / 平台栈)→ 建议月复盘做一次系统性"假设审计"清单
