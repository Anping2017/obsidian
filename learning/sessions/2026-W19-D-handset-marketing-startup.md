# D mode session 要点

## 决策输入(用户提供)
- 时间:现在就做(0-1)
- 能力:行业经验 + 营销
- 资源:1 人 → 2-5 人
- 垂直:手机销售/维修/配件

## 6 个心智模型应用要点

| 模型 | 关键发现 |
|---|---|
| **第一性原理** | 4 类客户痛点 + AI 7 个动作切口 + "营销×AI×手机"三角形稀缺 |
| **生态位** | 8 候选,B(IP)/F(服务)/E(2B 服务) 适合 1 人,其他不可行 |
| **二阶思维** | SaaS 实际是"服务伪装" / IP 个人有上限 / 服务必须沉淀产品 |
| **逆向思维** | 7 大失败陷阱清单,主线"不要忘垂直、不要烧投流、要订阅、要 IP 资产" |
| **杠杆** | 1 人=IP 杠杆 / 2-5 人=服务杠杆 / 10+人=产品杠杆 |
| **能力圈** | 营销+手机行业 = 三角形里少数有的人,这是最大资产 |

## 推荐路径

**双引擎三阶段**:
1. 0-6m(1 人):垂直 KOC IP + AI 放大,5-30K 粉 + 5-20 家咨询
2. 6-18m(2-5 人):门店营销代运营+AI 工具包,30-100 家服务客户
3. 18m+:沉淀为手机门店专用 SaaS + IP 矩阵孵化

## 6 个可能错的假设
1. 小微商家愿付费 2. 抖音小红书还主流 3. 服务有续费 4. 行业经验够深 5. AI 工具门槛维持 6m+ 6. 真愿从 1 转 5 人

## 5 个反转信号
1. IP 3 月无转化 2. 同行已融大额 3. 店主有免费替代 4. 自己发现不爱手机行业 5. 头部品牌做店主 SaaS

## 一句话
"别做 AI 营销公司,做手机行业的 AI 营销人。"
