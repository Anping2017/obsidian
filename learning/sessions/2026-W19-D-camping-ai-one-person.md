# D mode session — 露营一人公司

## 与之前 D mode 的对比
| Session | 决策类型 | 角色 |
|---|---|---|
| AI 营销未来分析 | 行业未来背景 | 旁观分析 |
| 手机营销切入(华人) | 战略-niche | 切入决策 |
| NZ 全市场营销 | 战略-全市场 | 切入决策 |
| 手机垂直 AI(产品) | 产品-能力 | 产品规划 |
| 手机营销 AI(营销) | 产品-营销视角 | 产品规划 |
| **露营博主一人公司(本次)** | 个人变现-内容创作 | 个人 endeavor |

→ D mode 已涵盖战略 / 产品 / 个人变现 三大类决策。这种多样性触发月复盘讨论:**D mode 是否应明确分这 3 子类**

## 核心拆解
1. **约束信息价值极大**:不收营费/不带团/要 AI 自动 → 直接淘汰一半选项
2. 营收源 15 个 → 符合约束的 5 个 → 推荐 3 个
3. A + B + C 三层递进
4. NZ 双语+中国游客真空是真护城河

## 关键洞察
**约束是创意的朋友,不是敌人。**
- 用户明确"不要什么"→ 帮 Claude 锁定"要什么"
- 不收营费 + 不带团 = 排除服务业 → 必走内容资产/数字产品/SaaS 路线
- AI 自动 = 必走 leverage 路线 → 排除时间换钱模式

## 三层路径
| 层 | 时长 | 形态 | 月收入估算 |
|---|---|---|---|
| A. Affiliate 内容工厂 | 0-3m | 多平台内容+链接 | NZ$500-3K |
| B. 数字产品 | 3-9m | 路书/地图/攻略 PDF | NZ$1K-5K |
| C. AI 工具 SaaS-lite | 9-18m | 推荐器/规划器/数据库 | NZ$3K-15K |

## 一句话
"你的位置不是'露营博主',是'NZ 露营信息的 AI 化提供者'。"

## 与"AI 营销公司"决策不冲突
两个决策互补:
- 露营 = 睡后收入资产(被动)
- 营销公司 = 积极成长事业(主动)
- 可并行,也可先后

1. **D mode 第 6 必要项 候选:"约束信息(不做什么)"** — 本次用户明确排除两项,价值极大
2. **D mode 已分类**:战略-切入 / 产品-能力 / 个人-变现 —— 是否在 PLAYBOOK 中明确
