# C mode session — 马斯克思维模式

## 教学策略
不做人物崇拜,做**思维模式抽取**。10 大模式 + Algorithm 5 步深度展开 + 局限 + 可复用性对照 + 与其他大师对比。

## 核心澄清点(容易被误解的)

1. **长时间 + 极限紧迫是配套** — 大多数人只学一半:要么只谈长期主义(没紧迫感),要么只谈 hardcore(没长期目标)
2. **Algorithm 5 步顺序不能乱** — 最常见错误是跳过 1-3 直接 automate
3. **物理约束 vs 工程约束 vs 流程约束** — 三种"做不到"处理方式完全不同
4. **反主流验证要限定在深度知识领域** — 领域外反主流 = 高概率错
5. **知识树先主干后叶子** — 大多数人错在直接学叶子

## Musk 的黑暗面(诚实评估)
1. 员工燃尽率(生存者偏差)
2. Musk time = 承诺的 2-5 倍
3. 冲动决策(尤其社交媒体驱动)
4. 家庭代价
5. 领域迁移过度自信
6. 公众人格极化

## 与用户路径的连接
- Algorithm 5 步 → 用户的 AI 内容工厂 MVP 可能可砍 50% 功能
- 三种约束分类 → 破"NZ 小市场没法赚"的借口
- 远大目标+极限紧迫 → 校准用户对"18 月月入 3-15 万"的心理定位
- 知识树 → 用户 vault [[2026 数字营销完整框架]] 就是主干,可挂枝叶
