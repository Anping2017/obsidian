# C mode session — 乔布斯思维框架

## 教学策略
与 Musk 篇同款结构,但重点突出**根本不同**:
- Musk 篇最可复用:Algorithm 5 步
- Jobs 篇最可复用:**Say No 方法(2x2 矩阵 / Top 10→3)**

## 核心澄清点

1. **Taste-First vs Physics-First**:两人根本方法差异
2. **Say No 是稀缺勇气**:任何人都想加功能,少人敢删被骂
3. **技术能力 ≠ 产品能力**:AI 时代尤为重要
4. **Reality Distortion 双刃剑**:成就奇迹,败就灾难(Jobs 拒手术就是极端负面)
5. **人文 × 科技交叉**:AI 时代人味 = 稀缺资源

## 与 Musk 对比的核心结论
- Musk = 如何造出以前造不出的东西(物理主导)
- Jobs = 如何造出让人爱到不行的东西(体验主导)
- **两个方向不冲突**,普通人可融合使用:
  - Musk 方法解决"如何做"
  - Jobs 品味解决"做什么"

## 与用户路径的连接
- Say No 2x2 矩阵:直接应用于用户 AI 内容工厂 MVP 精简
- Taste-First 检验:如果你自己不会用,别指望客户会用
- Musk + Jobs 融合:Algorithm 5 步 + Say No 2x2 一起用效果更强
