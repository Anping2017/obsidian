# C mode session — 需求分析三件套

## 触发
接续 2026 数字营销框架层 1.2 展开(用户明确请求 JTBD / VPC / Kano)。同款教学式清晰化格式。

## 教学策略
1. 先讲 3 工具关系(递进,不是并列)
2. 每工具:定义+公式+经典案例+双例子(手机+露营)
3. 强调易被忽略的深层(3 层 job / Kano 时间衰减)
4. 2 小时实战流程串起来
5. 与 Messaging Framework 挂钩:需求分析 → 定位 → 消息

## 核心澄清点
1. **JTBD 3 层**:功能/情感/社交 — 大多数人只做功能层就动手
2. **VPC Fit**:不是列清单,是画连线;每 Pain 都要有 Reliever
3. **Kano 兴奋衰减**:今天惊喜→明天期望→后天基本(iPhone 触屏案例)
4. **无差异 vs 反向**:两个常被忽略的 Kano 类别,前者浪费资源,后者赶走客户

## 与之前 output 的连接
- 需求分析(本次)是 [[2026 数字营销完整框架]] 层 1.2 的展开
- 与 [[Messaging Framework 详解]] 是姊妹篇:需求→定位→消息
- 可用于验证之前 D mode 分析中的产品能力假设:
  - 手机行业垂直 AI 核心能力 → VPC 检查每项能力对应的 Pain/Gain
  - NZ 露营变现 → JTBD 检查真需求(不只功能层)
