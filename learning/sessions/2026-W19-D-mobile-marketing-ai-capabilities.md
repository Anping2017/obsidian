# D mode session — 营销视角

## 与前一篇(产品版)的关系
两个 wedge 并行可行:
- **产品版 wedge**:AI 故障诊断+报价 → 走"工具产品"路线
- **营销版 wedge**:AIGC 内容工厂(店主 IP) → 走"服务公司+工具"路线

## 核心拆解
1. Customer journey 5 阶段 + 1 横切层
2. AI 能力矩阵 22 个候选
3. 核心 5:AIGC 工厂 / AI 客服+比对 / 多平台投放 / 售后复购 / 数据归因
4. 护城河 3:垂直内容语料 / NZ 营销栈 / 全链路打通
5. 长期 3:跨店数据网络 / IP 矩阵 / 2C 信任品牌

## 设计原则(营销专属 7 条)
垂直话术 > 通用文案 / 全漏斗 > 单点 / 多平台原生 > 模板 / 多语原生 > 翻译 / 店主在前 AI 在后 / 数据透明 / 私域 > 公域

## MVP 形态:AIGC 内容工厂
输入(机型/维修/配件/店主)→ 输出(TikTok 脚本 / 长文 / 商品描述 / 教学视频 / 店主 IP 短视频)

## 与现有市场对比
所有通用工具都缺:手机话术语料 + Trade Me 接入 + 多语言原生

## 一句话
"通用 AI 营销卖'帮你写文案',垂直 AI 营销卖'替你做手机生意的营销'。主语不同,价值不同。"
