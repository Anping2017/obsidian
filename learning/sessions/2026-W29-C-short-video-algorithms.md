## 核心内容浓缩
1. **通用**:召回→粗排→精排,目标是留存
2. **TikTok**:8:2 推荐主导,完播 + 重播为核心;流量池阶梯 200 → 1M+
3. **Reels**:5:5 关注/推荐平衡,**DM 分享是第一信号**(Meta 2024)
4. **Shorts**:4:6 订阅主导,**跨格式(Shorts → 长视频)独有强信号**,频道健康度是底层
5. **共同 anti-signals**:3 秒滑走 / Not Interested / 举报 / 搬运 / 未披露 AI / 刷量
6. **2026 十大趋势**:完播主导 / 私信 >> 公开 / AI 披露 / 原创性分数化 / Fatigue 检测

## 关键洞察
- 2022-2026 5 年最大变化:**点赞贬值,完播主导,DM/私信分享成新王**
- YouTube 独有优势:频道健康度 + 跨格式漏斗(Shorts → 长视频)—— 老账号做 Shorts 有先天优势
- TikTok 长尾最强,Reels 前 24h 最重要,Shorts 中等
- **AI 内容主动披露 > 隐藏**——2026 全平台一致
