# 关键帧动画

## 关键帧动画概述

关键帧动画是CSS动画的核心，通过@keyframes定义动画序列，实现复杂的动画效果。

## @keyframes语法

### 基本语法
```css
@keyframes 动画名称 {
    0% {
        /* 动画开始状态 */
    }
    50% {
        /* 动画中间状态 */
    }
    100% {
        /* 动画结束状态 */
    }
}
```

### 关键帧选择器
```css
/* 百分比形式 */
@keyframes slideIn {
    0% { transform: translateX(-100%); }
    50% { transform: translateX(0); }
    100% { transform: translateX(100%); }
}

/* 关键字形式 */
@keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }
}
```

## animation属性

### 1. animation-name
```css
/* 指定动画名称 */
.animated {
    animation-name: slideIn;
    animation-name: fadeIn, slideIn;  /* 多个动画 */
    animation-name: none;             /* 无动画 */
}
```

### 2. animation-duration
```css
/* 指定动画持续时间 */
.duration {
    animation-duration: 2s;
    animation-duration: 2000ms;
    animation-duration: 1s, 2s;  /* 多个动画不同时长 */
}
```

### 3. animation-timing-function
```css
/* 指定时间函数 */
.timing {
    animation-timing-function: ease;
    animation-timing-function: linear;
    animation-timing-function: ease-in-out;
    animation-timing-function: cubic-bezier(0.25, 0.46, 0.45, 0.94);
}
```

### 4. animation-delay
```css
/* 指定延迟时间 */
.delay {
    animation-delay: 1s;
    animation-delay: 1000ms;
    animation-delay: 0s, 0.5s;  /* 多个动画不同延迟 */
}
```

### 5. animation-iteration-count
```css
/* 指定播放次数 */
.iteration {
    animation-iteration-count: 1;      /* 播放1次 */
    animation-iteration-count: 3;      /* 播放3次 */
    animation-iteration-count: infinite; /* 无限循环 */
    animation-iteration-count: 0.5;    /* 播放0.5次 */
}
```

### 6. animation-direction
```css
/* 指定播放方向 */
.direction {
    animation-direction: normal;       /* 正常播放 */
    animation-direction: reverse;      /* 反向播放 */
    animation-direction: alternate;    /* 交替播放 */
    animation-direction: alternate-reverse; /* 反向交替 */
}
```

### 7. animation-fill-mode
```css
/* 指定填充模式 */
.fill-mode {
    animation-fill-mode: none;         /* 不填充 */
    animation-fill-mode: forwards;     /* 保持结束状态 */
    animation-fill-mode: backwards;    /* 保持开始状态 */
    animation-fill-mode: both;         /* 保持开始和结束状态 */
}
```

### 8. animation-play-state
```css
/* 指定播放状态 */
.play-state {
    animation-play-state: running;     /* 播放中 */
    animation-play-state: paused;      /* 暂停 */
}
```

## 动画简写

### 完整语法
```css
animation: 名称 持续时间 时间函数 延迟 次数 方向 填充模式 播放状态;
```

### 示例
```css
/* 完整动画 */
.complete-animation {
    animation: slideIn 2s ease-in-out 1s 3 alternate both running;
}

/* 简化动画 */
.simple-animation {
    animation: fadeIn 1s ease;
}

/* 多个动画 */
.multiple-animations {
    animation: 
        fadeIn 1s ease,
        slideIn 2s ease-in-out 0.5s;
}
```

## 实际应用场景

### 1. 加载动画
```css
/* 旋转加载 */
@keyframes spin {
    0% { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}

.loading-spinner {
    width: 40px;
    height: 40px;
    border: 4px solid #f3f3f3;
    border-top: 4px solid #3498db;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}

/* 脉冲加载 */
@keyframes pulse {
    0% { opacity: 1; }
    50% { opacity: 0.5; }
    100% { opacity: 1; }
}

.pulse-loading {
    animation: pulse 1.5s ease-in-out infinite;
}
```

### 2. 页面过渡
```css
/* 淡入动画 */
@keyframes fadeIn {
    from { 
        opacity: 0; 
        transform: translateY(20px);
    }
    to { 
        opacity: 1; 
        transform: translateY(0);
    }
}

.fade-in {
    animation: fadeIn 0.6s ease-out;
}

/* 滑入动画 */
@keyframes slideInLeft {
    from { 
        transform: translateX(-100%); 
        opacity: 0;
    }
    to { 
        transform: translateX(0); 
        opacity: 1;
    }
}

.slide-in-left {
    animation: slideInLeft 0.8s ease-out;
}
```

### 3. 交互动画
```css
/* 弹跳效果 */
@keyframes bounce {
    0%, 20%, 53%, 80%, 100% {
        transform: translateY(0);
    }
    40%, 43% {
        transform: translateY(-30px);
    }
    70% {
        transform: translateY(-15px);
    }
    90% {
        transform: translateY(-4px);
    }
}

.bounce-effect {
    animation: bounce 1s ease;
}

/* 摇摆效果 */
@keyframes shake {
    0%, 100% { transform: translateX(0); }
    10%, 30%, 50%, 70%, 90% { transform: translateX(-10px); }
    20%, 40%, 60%, 80% { transform: translateX(10px); }
}

.shake-effect {
    animation: shake 0.5s ease-in-out;
}
```

### 4. 背景动画
```css
/* 渐变背景动画 */
@keyframes gradientShift {
    0% { background-position: 0% 50%; }
    50% { background-position: 100% 50%; }
    100% { background-position: 0% 50%; }
}

.gradient-bg {
    background: linear-gradient(-45deg, #ee7752, #e73c7e, #23a6d5, #23d5ab);
    background-size: 400% 400%;
    animation: gradientShift 15s ease infinite;
}

/* 粒子效果 */
@keyframes float {
    0% { transform: translateY(0px); }
    50% { transform: translateY(-20px); }
    100% { transform: translateY(0px); }
}

.floating-particle {
    animation: float 3s ease-in-out infinite;
}
```

## 高级技巧

### 1. 动画序列
```css
/* 连续动画 */
@keyframes sequence {
    0% { transform: scale(1); }
    25% { transform: scale(1.1); }
    50% { transform: scale(1); }
    75% { transform: scale(0.9); }
    100% { transform: scale(1); }
}

.sequence-animation {
    animation: sequence 2s ease-in-out;
}
```

### 2. 动画暂停和恢复
```css
/* 可控制的动画 */
.controllable-animation {
    animation: spin 2s linear infinite;
    animation-play-state: paused;
}

.controllable-animation:hover {
    animation-play-state: running;
}
```

### 3. 动画组合
```css
/* 组合多个动画 */
@keyframes combo {
    0% { 
        transform: translateX(-100%) rotate(0deg); 
        opacity: 0;
    }
    50% { 
        transform: translateX(0) rotate(180deg); 
        opacity: 0.5;
    }
    100% { 
        transform: translateX(100%) rotate(360deg); 
        opacity: 1;
    }
}

.combo-animation {
    animation: combo 3s ease-in-out;
}
```

## 性能优化

### 1. 使用transform和opacity
```css
/* 推荐：使用GPU加速属性 */
.optimized {
    animation: optimizedMove 1s ease;
}

@keyframes optimizedMove {
    0% { 
        transform: translateX(0) scale(1); 
        opacity: 1;
    }
    100% { 
        transform: translateX(100px) scale(1.2); 
        opacity: 0.8;
    }
}

/* 避免：使用布局属性 */
.avoid {
    animation: avoidMove 1s ease;
}

@keyframes avoidMove {
    0% { left: 0; width: 100px; }
    100% { left: 100px; width: 200px; }
}
```

### 2. 使用will-change
```css
/* 提示浏览器优化 */
.will-change {
    will-change: transform, opacity;
    animation: optimizedMove 1s ease;
}
```

### 3. 减少动画数量
```css
/* 推荐：合并动画 */
.efficient {
    animation: combined 2s ease;
}

@keyframes combined {
    0% { 
        transform: translateX(0) scale(1); 
        opacity: 1;
    }
    100% { 
        transform: translateX(100px) scale(1.2); 
        opacity: 0.8;
    }
}
```

## 常见问题

### 1. 动画不流畅
```css
/* 问题：动画卡顿 */
.stutter {
    animation: stutterMove 1s ease;
}

@keyframes stutterMove {
    0% { left: 0; }
    100% { left: 100px; }
}

/* 解决：使用transform */
.smooth {
    animation: smoothMove 1s ease;
}

@keyframes smoothMove {
    0% { transform: translateX(0); }
    100% { transform: translateX(100px); }
}
```

### 2. 动画重复播放
```css
/* 问题：动画重复播放 */
.repeat-issue {
    animation: fadeIn 1s ease;
}

/* 解决：设置播放次数 */
.repeat-fix {
    animation: fadeIn 1s ease 1;
    animation-fill-mode: forwards;
}
```

### 3. 动画性能问题
```css
/* 问题：性能差 */
.performance-issue {
    animation: complex 2s ease;
}

@keyframes complex {
    0% { 
        left: 0; top: 0; width: 100px; height: 100px;
        background-color: red; border-radius: 0;
    }
    100% { 
        left: 100px; top: 100px; width: 200px; height: 200px;
        background-color: blue; border-radius: 50%;
    }
}

/* 解决：优化动画 */
.performance-fix {
    animation: optimized 2s ease;
}

@keyframes optimized {
    0% { 
        transform: translate(0, 0) scale(1); 
        background-color: red; 
        border-radius: 0;
    }
    100% { 
        transform: translate(100px, 100px) scale(2); 
        background-color: blue; 
        border-radius: 50%;
    }
}
```
