# 布局对比与选择

## 布局方式概述

CSS提供了多种布局方式，每种方式都有其适用场景和特点。

## 布局方式对比

### 1. 传统布局方式

#### 表格布局
```css
/* 表格布局 */
.table-layout {
    display: table;
    width: 100%;
}

.table-row {
    display: table-row;
}

.table-cell {
    display: table-cell;
    vertical-align: middle;
}
```

**特点：**
- 兼容性好
- 语义化差
- 响应式困难
- 性能一般

#### 浮动布局
```css
/* 浮动布局 */
.float-layout {
    overflow: hidden;
}

.float-item {
    float: left;
    width: 33.333%;
    box-sizing: border-box;
}
```

**特点：**
- 兼容性好
- 需要清除浮动
- 响应式复杂
- 性能一般

#### 定位布局
```css
/* 定位布局 */
.position-layout {
    position: relative;
}

.position-item {
    position: absolute;
    top: 0;
    left: 0;
    width: 100px;
    height: 100px;
}
```

**特点：**
- 精确控制
- 脱离文档流
- 响应式困难
- 性能较好

### 2. 现代布局方式

#### Flexbox布局
```css
/* Flexbox布局 */
.flex-layout {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.flex-item {
    flex: 1;
}
```

**特点：**
- 一维布局
- 对齐能力强
- 响应式友好
- 性能优秀

#### Grid布局
```css
/* Grid布局 */
.grid-layout {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1rem;
}

.grid-item {
    /* 自动成为网格项目 */
}
```

**特点：**
- 二维布局
- 布局能力强
- 响应式优秀
- 性能优秀

## 布局选择策略

### 1. 一维 vs 二维

#### 一维布局（Flexbox）
```css
/* 适用场景：水平或垂直排列 */
.navigation {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.button-group {
    display: flex;
    gap: 1rem;
}

.vertical-stack {
    display: flex;
    flex-direction: column;
    gap: 1rem;
}
```

#### 二维布局（Grid）
```css
/* 适用场景：复杂的二维布局 */
.page-layout {
    display: grid;
    grid-template-areas: 
        "header header header"
        "sidebar main aside"
        "footer footer footer";
    grid-template-rows: 60px 1fr 40px;
    grid-template-columns: 200px 1fr 200px;
}

.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 2rem;
}
```

### 2. 内容驱动 vs 容器驱动

#### 内容驱动（Flexbox）
```css
/* 内容决定布局 */
.flex-content {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}

.flex-content .item {
    flex: 1 1 200px;
    /* 内容决定最终大小 */
}
```

#### 容器驱动（Grid）
```css
/* 容器决定布局 */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1rem;
}

.grid-container .item {
    /* 容器决定项目位置 */
}
```

### 3. 响应式考虑

#### Flexbox响应式
```css
/* Flexbox响应式 */
.flex-responsive {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}

.flex-responsive .item {
    flex: 1 1 300px;
}

@media (max-width: 767px) {
    .flex-responsive .item {
        flex: 1 1 100%;
    }
}
```

#### Grid响应式
```css
/* Grid响应式 */
.grid-responsive {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 1rem;
}

/* 或者使用媒体查询 */
.grid-responsive-mq {
    display: grid;
    gap: 1rem;
}

@media (min-width: 768px) {
    .grid-responsive-mq {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (min-width: 1024px) {
    .grid-responsive-mq {
        grid-template-columns: repeat(3, 1fr);
    }
}
```

## 实际应用场景

### 1. 导航菜单
```css
/* 水平导航 - Flexbox */
.nav-horizontal {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 1rem;
}

.nav-menu {
    display: flex;
    gap: 2rem;
}

/* 垂直导航 - Flexbox */
.nav-vertical {
    display: flex;
    flex-direction: column;
    gap: 1rem;
    padding: 1rem;
}
```

### 2. 卡片布局
```css
/* 卡片网格 - Grid */
.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 2rem;
    padding: 2rem;
}

/* 卡片列表 - Flexbox */
.card-list {
    display: flex;
    flex-direction: column;
    gap: 1rem;
}

.card-list .card {
    display: flex;
    gap: 1rem;
    padding: 1rem;
}
```

### 3. 表单布局
```css
/* 表单布局 - Grid */
.form-grid {
    display: grid;
    grid-template-columns: 1fr 2fr;
    gap: 1rem 2rem;
    max-width: 600px;
}

.form-label {
    align-self: center;
}

/* 表单布局 - Flexbox */
.form-flex {
    display: flex;
    flex-direction: column;
    gap: 1rem;
    max-width: 600px;
}

.form-row {
    display: flex;
    gap: 1rem;
}

.form-group {
    flex: 1;
}
```

### 4. 页面布局
```css
/* 页面布局 - Grid */
.page-layout {
    display: grid;
    grid-template-areas: 
        "header header header"
        "sidebar main aside"
        "footer footer footer";
    grid-template-rows: 60px 1fr 40px;
    grid-template-columns: 200px 1fr 200px;
    min-height: 100vh;
    gap: 1rem;
}

/* 页面布局 - Flexbox */
.page-layout-flex {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

.page-header {
    flex: 0 0 60px;
}

.page-main {
    display: flex;
    flex: 1;
}

.page-sidebar {
    flex: 0 0 200px;
}

.page-content {
    flex: 1;
}

.page-aside {
    flex: 0 0 200px;
}

.page-footer {
    flex: 0 0 40px;
}
```

## 混合布局策略

### 1. Grid + Flexbox
```css
/* 外层Grid，内层Flexbox */
.mixed-layout {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: 60px 1fr 40px;
    min-height: 100vh;
    gap: 1rem;
}

.header {
    grid-column: 1 / -1;
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.sidebar {
    display: flex;
    flex-direction: column;
    gap: 1rem;
}

.main {
    display: flex;
    flex-direction: column;
    gap: 2rem;
}

.footer {
    grid-column: 1 / -1;
    display: flex;
    justify-content: center;
    align-items: center;
}
```

### 2. 响应式混合布局
```css
/* 响应式混合布局 */
.responsive-mixed {
    display: grid;
    gap: 1rem;
    padding: 1rem;
}

/* 移动端：单列Flexbox */
@media (max-width: 767px) {
    .responsive-mixed {
        display: flex;
        flex-direction: column;
    }
}

/* 平板端：Grid布局 */
@media (min-width: 768px) and (max-width: 1023px) {
    .responsive-mixed {
        grid-template-columns: 1fr 1fr;
    }
}

/* 桌面端：复杂Grid布局 */
@media (min-width: 1024px) {
    .responsive-mixed {
        grid-template-columns: 200px 1fr 200px;
        grid-template-areas: 
            "sidebar main aside";
    }
}
```

## 性能对比

### 1. 渲染性能
| 布局方式 | 性能 | 重排 | 重绘 | 合成 |
|----------|------|------|------|------|
| 表格布局 | 低 | 高 | 高 | 低 |
| 浮动布局 | 中 | 中 | 中 | 低 |
| 定位布局 | 中 | 低 | 中 | 中 |
| Flexbox | 高 | 低 | 低 | 高 |
| Grid | 高 | 低 | 低 | 高 |

### 2. 兼容性
| 布局方式 | IE | Chrome | Firefox | Safari |
|----------|----|--------|---------|--------|
| 表格布局 | 8+ | 1+ | 1+ | 1+ |
| 浮动布局 | 6+ | 1+ | 1+ | 1+ |
| 定位布局 | 6+ | 1+ | 1+ | 1+ |
| Flexbox | 10+ | 21+ | 28+ | 9+ |
| Grid | 16+ | 57+ | 52+ | 10.1+ |

## 最佳实践

### 1. 选择原则
- **简单一维布局**：使用Flexbox
- **复杂二维布局**：使用Grid
- **传统浏览器支持**：使用浮动或定位
- **响应式设计**：优先使用现代布局

### 2. 性能优化
```css
/* 避免过度嵌套 */
.avoid-nesting {
    display: grid;
    grid-template-columns: repeat(12, 1fr);
}

/* 使用高效属性 */
.efficient {
    display: flex;
    gap: 1rem;
}

/* 减少重排重绘 */
.optimized {
    will-change: transform;
    transform: translateZ(0);
}
```

### 3. 渐进增强
```css
/* 基础布局 */
.fallback {
    display: block;
}

/* 现代浏览器增强 */
@supports (display: grid) {
    .fallback {
        display: grid;
        grid-template-columns: repeat(3, 1fr);
    }
}
```
