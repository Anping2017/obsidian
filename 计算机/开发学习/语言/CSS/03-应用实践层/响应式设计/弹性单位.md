# 弹性单位

## 弹性单位概述

弹性单位是响应式设计的重要组成部分，能够根据不同的设备和上下文自动调整大小。

## 相对单位类型

### 1. 百分比（%）
```css
/* 相对于父元素 */
.container {
    width: 100%;
    height: 50%;
}

/* 相对于自身 */
.element {
    width: 50%;
    margin: 10%;
    padding: 5%;
}
```

### 2. em单位
```css
/* 相对于当前元素字体大小 */
.element {
    font-size: 16px;
    padding: 1em;    /* 16px */
    margin: 2em;     /* 32px */
}

/* 相对于父元素字体大小 */
.parent {
    font-size: 20px;
}

.child {
    font-size: 1.5em;  /* 30px */
    padding: 0.5em;    /* 15px */
}
```

### 3. rem单位
```css
/* 相对于根元素字体大小 */
:root {
    font-size: 16px;
}

.element {
    font-size: 1.5rem;  /* 24px */
    padding: 1rem;      /* 16px */
    margin: 2rem;       /* 32px */
}
```

### 4. vw/vh单位
```css
/* 视口宽度单位 */
.viewport-width {
    width: 50vw;        /* 视口宽度的50% */
    height: 100vh;      /* 视口高度的100% */
}

/* 视口最小/最大单位 */
.viewport-min-max {
    width: 100vw;
    height: 100vh;
    min-width: 100vw;
    min-height: 100vh;
}
```

### 5. vmin/vmax单位
```css
/* 视口最小/最大尺寸 */
.viewport-min {
    width: 100vmin;     /* 视口较小尺寸的100% */
    height: 100vmin;
}

.viewport-max {
    width: 100vmax;     /* 视口较大尺寸的100% */
    height: 100vmax;
}
```

## 单位对比

### 单位特性对比
| 单位 | 基准 | 继承性 | 响应性 | 适用场景 |
|------|------|--------|--------|----------|
| px | 固定像素 | 无 | 无 | 精确控制 |
| % | 父元素 | 无 | 有 | 相对布局 |
| em | 当前/父元素字体 | 有 | 有 | 字体相关 |
| rem | 根元素字体 | 无 | 有 | 全局缩放 |
| vw/vh | 视口尺寸 | 无 | 有 | 视口相关 |
| vmin/vmax | 视口最小/最大 | 无 | 有 | 响应式设计 |

### 计算示例
```css
/* 假设根字体大小为16px，视口为1200x800px */
:root {
    font-size: 16px;
}

.element {
    width: 50%;         /* 父元素宽度的50% */
    font-size: 1.5em;   /* 24px (16px × 1.5) */
    padding: 2rem;      /* 32px (16px × 2) */
    height: 50vh;       /* 400px (800px × 0.5) */
    margin: 10vw;       /* 120px (1200px × 0.1) */
}
```

## 实际应用场景

### 1. 响应式字体
```css
/* 基础字体大小 */
:root {
    font-size: 16px;
}

/* 响应式字体缩放 */
@media (max-width: 767px) {
    :root {
        font-size: 14px;
    }
}

@media (min-width: 768px) {
    :root {
        font-size: 16px;
    }
}

@media (min-width: 1024px) {
    :root {
        font-size: 18px;
    }
}

/* 使用rem单位 */
h1 {
    font-size: 2rem;    /* 响应式缩放 */
    margin-bottom: 1rem;
}

p {
    font-size: 1rem;
    line-height: 1.5rem;
}
```

### 2. 响应式间距
```css
/* 响应式间距系统 */
:root {
    --spacing-xs: 0.25rem;   /* 4px */
    --spacing-sm: 0.5rem;    /* 8px */
    --spacing-md: 1rem;      /* 16px */
    --spacing-lg: 1.5rem;    /* 24px */
    --spacing-xl: 2rem;      /* 32px */
}

.section {
    padding: var(--spacing-lg) var(--spacing-md);
    margin-bottom: var(--spacing-xl);
}

.card {
    padding: var(--spacing-md);
    margin: var(--spacing-sm);
}
```

### 3. 视口相关布局
```css
/* 全屏布局 */
.hero-section {
    width: 100vw;
    height: 100vh;
    display: flex;
    align-items: center;
    justify-content: center;
}

/* 响应式容器 */
.container {
    width: 90vw;
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 5vw;
}

/* 响应式网格 */
.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 2vw;
    padding: 2vh 5vw;
}
```

### 4. 移动端优化
```css
/* 移动端触摸友好 */
.button {
    min-height: 44px;        /* 最小触摸目标 */
    padding: 0.75rem 1.5rem;
    font-size: 1rem;
    border-radius: 0.5rem;
}

/* 移动端间距 */
.mobile-spacing {
    padding: 1rem 5vw;
    margin: 1rem 0;
}

/* 移动端字体 */
.mobile-text {
    font-size: 1rem;
    line-height: 1.5rem;
}
```

## 高级技巧

### 1. 混合单位使用
```css
/* 混合使用不同单位 */
.responsive-element {
    width: 100%;
    max-width: 50rem;        /* 最大宽度限制 */
    padding: 2rem 5vw;       /* 垂直固定，水平响应式 */
    margin: 1rem auto;
    font-size: clamp(1rem, 2.5vw, 1.5rem);
}
```

### 2. 动态计算
```css
/* 使用calc()函数 */
.dynamic-width {
    width: calc(100% - 2rem);
    height: calc(100vh - 4rem);
    padding: calc(1rem + 2vw);
}

/* 响应式计算 */
.responsive-calc {
    width: calc(50% - 1rem);
    margin: calc(0.5rem + 1vw);
}
```

### 3. 自定义属性响应式
```css
/* 响应式CSS变量 */
:root {
    --base-size: 1rem;
    --scale-factor: 1;
}

@media (min-width: 768px) {
    :root {
        --base-size: 1.125rem;
        --scale-factor: 1.125;
    }
}

@media (min-width: 1024px) {
    :root {
        --base-size: 1.25rem;
        --scale-factor: 1.25;
    }
}

.element {
    font-size: var(--base-size);
    padding: calc(var(--base-size) * 1.5);
    margin: calc(var(--base-size) * 2);
}
```

## 性能优化

### 1. 合理选择单位
```css
/* 推荐：使用rem和vw */
.optimized {
    font-size: 1rem;
    width: 100vw;
    padding: 1rem 5vw;
}

/* 避免：过度使用em */
.avoid {
    font-size: 1em;
    padding: 1em;
    margin: 1em;
    /* em会继承，可能导致意外缩放 */
}
```

### 2. 减少计算
```css
/* 推荐：预计算值 */
.pre-calculated {
    width: 50%;
    padding: 1rem;
}

/* 避免：复杂计算 */
.complex-calc {
    width: calc(50% - 1rem + 2vw - 0.5em);
    /* 复杂计算影响性能 */
}
```

### 3. 使用clamp()函数
```css
/* 响应式字体大小 */
.responsive-font {
    font-size: clamp(1rem, 2.5vw, 2rem);
    /* 最小值1rem，首选值2.5vw，最大值2rem */
}

/* 响应式间距 */
.responsive-spacing {
    padding: clamp(1rem, 5vw, 3rem);
    margin: clamp(0.5rem, 2vw, 1.5rem);
}
```

## 常见问题

### 1. 单位继承问题
```css
/* 问题：em单位继承 */
.parent {
    font-size: 20px;
}

.child {
    font-size: 1.2em;  /* 24px */
    padding: 1em;      /* 24px，不是20px */
}

/* 解决：使用rem */
.solution {
    font-size: 1.2rem;  /* 相对于根元素 */
    padding: 1rem;      /* 相对于根元素 */
}
```

### 2. 视口单位兼容性
```css
/* 问题：旧浏览器不支持vw/vh */
.viewport-problem {
    width: 100vw;
    height: 100vh;
}

/* 解决：提供降级方案 */
.viewport-solution {
    width: 100%;
    height: 100vh;
    /* 降级到百分比和固定高度 */
}
```

### 3. 单位精度问题
```css
/* 问题：小数精度 */
.precision-problem {
    width: 33.333%;
    /* 可能导致布局问题 */
}

/* 解决：使用flexbox或grid */
.precision-solution {
    flex: 1;
    /* 或者使用grid */
}
```
