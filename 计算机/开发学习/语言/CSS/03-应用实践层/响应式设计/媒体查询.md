# 媒体查询

## 媒体查询概述

媒体查询是响应式设计的核心技术，允许根据设备特性应用不同的CSS样式。

## 媒体查询语法

### 基本语法
```css
@media 媒体类型 and (媒体特性) {
    /* CSS规则 */
}
```

### 语法组成
- **@media**：媒体查询关键字
- **媒体类型**：指定设备类型
- **媒体特性**：指定设备特性
- **逻辑操作符**：连接多个条件

## 媒体类型

### 常用媒体类型
```css
/* 所有设备 */
@media all { }

/* 屏幕设备 */
@media screen { }

/* 打印设备 */
@media print { }

/* 语音设备 */
@media speech { }
```

### 媒体类型示例
```css
/* 屏幕设备样式 */
@media screen {
    body {
        background-color: white;
        color: black;
    }
}

/* 打印样式 */
@media print {
    body {
        background-color: white;
        color: black;
    }
    
    .no-print {
        display: none;
    }
}
```

## 媒体特性

### 视口特性
```css
/* 视口宽度 */
@media (width: 768px) { }

/* 最小宽度 */
@media (min-width: 768px) { }

/* 最大宽度 */
@media (max-width: 767px) { }

/* 宽度范围 */
@media (min-width: 768px) and (max-width: 1023px) { }
```

### 高度特性
```css
/* 视口高度 */
@media (height: 600px) { }

/* 最小高度 */
@media (min-width: 600px) { }

/* 最大高度 */
@media (max-height: 599px) { }
```

### 方向特性
```css
/* 横屏 */
@media (orientation: landscape) { }

/* 竖屏 */
@media (orientation: portrait) { }
```

### 分辨率特性
```css
/* 设备像素比 */
@media (resolution: 2dppx) { }

/* 最小分辨率 */
@media (min-resolution: 2dppx) { }

/* 最大分辨率 */
@media (max-resolution: 1.5dppx) { }
```

## 逻辑操作符

### and操作符
```css
/* 同时满足多个条件 */
@media screen and (min-width: 768px) and (max-width: 1023px) {
    .container {
        width: 750px;
    }
}
```

### or操作符
```css
/* 满足任一条件 */
@media (min-width: 768px), (orientation: landscape) {
    .sidebar {
        display: block;
    }
}
```

### not操作符
```css
/* 不满足条件 */
@media not screen and (max-width: 767px) {
    .desktop-only {
        display: block;
    }
}
```

### only操作符
```css
/* 仅满足条件 */
@media only screen and (max-width: 767px) {
    .mobile-only {
        display: block;
    }
}
```

## 响应式断点

### 常用断点
```css
/* 移动设备 */
@media (max-width: 767px) {
    .container {
        width: 100%;
        padding: 0 15px;
    }
}

/* 平板设备 */
@media (min-width: 768px) and (max-width: 1023px) {
    .container {
        width: 750px;
        margin: 0 auto;
    }
}

/* 桌面设备 */
@media (min-width: 1024px) {
    .container {
        width: 1200px;
        margin: 0 auto;
    }
}
```

### 移动优先断点
```css
/* 移动优先设计 */
/* 基础样式（移动设备） */
.container {
    width: 100%;
    padding: 0 15px;
}

/* 平板设备 */
@media (min-width: 768px) {
    .container {
        width: 750px;
        margin: 0 auto;
    }
}

/* 桌面设备 */
@media (min-width: 1024px) {
    .container {
        width: 1200px;
    }
}

/* 大屏幕设备 */
@media (min-width: 1440px) {
    .container {
        width: 1400px;
    }
}
```

## 实际应用场景

### 1. 响应式导航
```css
/* 移动端导航 */
.nav {
    display: none;
}

.mobile-menu {
    display: block;
}

/* 桌面端导航 */
@media (min-width: 768px) {
    .nav {
        display: flex;
    }
    
    .mobile-menu {
        display: none;
    }
}
```

### 2. 响应式网格
```css
/* 移动端单列 */
.grid {
    display: block;
}

.grid-item {
    width: 100%;
    margin-bottom: 20px;
}

/* 平板端两列 */
@media (min-width: 768px) {
    .grid {
        display: flex;
        flex-wrap: wrap;
    }
    
    .grid-item {
        width: 50%;
        margin-bottom: 20px;
    }
}

/* 桌面端三列 */
@media (min-width: 1024px) {
    .grid-item {
        width: 33.333%;
    }
}
```

### 3. 响应式字体
```css
/* 移动端字体 */
body {
    font-size: 14px;
    line-height: 1.5;
}

h1 {
    font-size: 24px;
}

/* 平板端字体 */
@media (min-width: 768px) {
    body {
        font-size: 16px;
    }
    
    h1 {
        font-size: 32px;
    }
}

/* 桌面端字体 */
@media (min-width: 1024px) {
    body {
        font-size: 18px;
    }
    
    h1 {
        font-size: 40px;
    }
}
```

### 4. 响应式图片
```css
/* 响应式图片 */
.responsive-image {
    max-width: 100%;
    height: auto;
}

/* 不同屏幕尺寸的图片 */
@media (max-width: 767px) {
    .hero-image {
        width: 100%;
        height: 200px;
        object-fit: cover;
    }
}

@media (min-width: 768px) {
    .hero-image {
        width: 100%;
        height: 400px;
        object-fit: cover;
    }
}
```

## 高级技巧

### 1. 容器查询
```css
/* 容器查询（现代浏览器支持） */
@container (min-width: 300px) {
    .card {
        display: flex;
    }
}

@container (max-width: 299px) {
    .card {
        display: block;
    }
}
```

### 2. 自定义属性响应式
```css
/* 使用CSS变量实现响应式 */
:root {
    --container-width: 100%;
    --font-size: 14px;
}

@media (min-width: 768px) {
    :root {
        --container-width: 750px;
        --font-size: 16px;
    }
}

@media (min-width: 1024px) {
    :root {
        --container-width: 1200px;
        --font-size: 18px;
    }
}

.container {
    width: var(--container-width);
    font-size: var(--font-size);
}
```

### 3. 响应式间距
```css
/* 响应式间距系统 */
:root {
    --spacing-xs: 4px;
    --spacing-sm: 8px;
    --spacing-md: 16px;
    --spacing-lg: 24px;
    --spacing-xl: 32px;
}

@media (min-width: 768px) {
    :root {
        --spacing-xs: 8px;
        --spacing-sm: 16px;
        --spacing-md: 24px;
        --spacing-lg: 32px;
        --spacing-xl: 48px;
    }
}

.section {
    padding: var(--spacing-lg) var(--spacing-md);
}
```

## 性能优化

### 1. 减少媒体查询数量
```css
/* 避免过多的媒体查询 */
/* 不推荐 */
@media (max-width: 320px) { }
@media (max-width: 480px) { }
@media (max-width: 768px) { }
@media (max-width: 1024px) { }

/* 推荐 */
@media (max-width: 767px) { }
@media (min-width: 768px) { }
```

### 2. 使用相对单位
```css
/* 使用相对单位 */
.container {
    width: 100%;
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 5%;
}

@media (min-width: 768px) {
    .container {
        padding: 0 2%;
    }
}
```

### 3. 避免重复样式
```css
/* 避免重复定义 */
/* 不推荐 */
@media (max-width: 767px) {
    .button {
        padding: 10px 20px;
        font-size: 14px;
        border-radius: 4px;
    }
}

@media (min-width: 768px) {
    .button {
        padding: 12px 24px;
        font-size: 16px;
        border-radius: 4px;
    }
}

/* 推荐 */
.button {
    border-radius: 4px;
}

@media (max-width: 767px) {
    .button {
        padding: 10px 20px;
        font-size: 14px;
    }
}

@media (min-width: 768px) {
    .button {
        padding: 12px 24px;
        font-size: 16px;
    }
}
```
