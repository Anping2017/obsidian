# 盒模型应用

## 盒模型应用概述

掌握盒模型的实际应用技巧，能够解决常见的布局问题，提升开发效率。

## 1. 布局技巧

### 居中布局
```css
/* 水平居中 */
.center-horizontal {
    width: 300px;
    margin: 0 auto;
}

/* 垂直居中 */
.center-vertical {
    height: 200px;
    display: flex;
    align-items: center;
    justify-content: center;
}

/* 完全居中 */
.center-both {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}
```

### 等宽布局
```css
/* 三列等宽 */
.three-columns {
    display: flex;
}

.three-columns > div {
    box-sizing: border-box;
    width: 33.333%;
    padding: 20px;
    border: 1px solid #ddd;
}
```

### 响应式网格
```css
/* 响应式网格 */
.grid {
    display: flex;
    flex-wrap: wrap;
    margin: -10px;
}

.grid-item {
    box-sizing: border-box;
    width: 25%;
    padding: 10px;
}

@media (max-width: 768px) {
    .grid-item {
        width: 50%;
    }
}

@media (max-width: 480px) {
    .grid-item {
        width: 100%;
    }
}
```

## 3. 间距系统

### 统一间距
```css
/* 间距变量 */
:root {
    --spacing-xs: 4px;
    --spacing-sm: 8px;
    --spacing-md: 16px;
    --spacing-lg: 24px;
    --spacing-xl: 32px;
    --spacing-xxl: 48px;
}

/* 间距工具类 */
.m-0 { margin: 0; }
.m-xs { margin: var(--spacing-xs); }
.m-sm { margin: var(--spacing-sm); }
.m-md { margin: var(--spacing-md); }
.m-lg { margin: var(--spacing-lg); }
.m-xl { margin: var(--spacing-xl); }

.p-0 { padding: 0; }
.p-xs { padding: var(--spacing-xs); }
```

## 6. 布局问题解决

### 外边距重叠
```css
/* 问题：垂直外边距重叠 */
.problem {
    margin-bottom: 20px;
}

.problem + .problem {
    margin-top: 20px;
}
/* 实际间距只有20px */

/* 解决：使用padding或border */
.solution {
    margin-bottom: 20px;
}

.solution + .solution {
    margin-top: 0;
    padding-top: 20px;
    border-top: 1px solid transparent;
}
```

### 浮动清除
```css
/* 问题：浮动元素影响布局 */
.float-left {
    float: left;
    width: 50%;
}

/* 解决：清除浮动 */
.clearfix::after {
    content: "";
    display: table;
    clear: both;
}

/* 现代解决方案 */
.container {
    display: flow-root;
}
```

### 溢出处理
```css
/* 文本溢出 */
.text-ellipsis {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}

/* 多行文本溢出 */
.text-ellipsis-multiline {
    display: -webkit-box;
    -webkit-line-clamp: 3;
    -webkit-box-orient: vertical;
    overflow: hidden;
}
```
