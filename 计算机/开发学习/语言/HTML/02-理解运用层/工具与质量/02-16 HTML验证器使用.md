# HTML验证器使用

## 🔧 W3C HTML验证器

### 📍 官方验证工具

**W3C Markup Validator**: https://validator.w3.org/

### 🎯 验证标准类型

| 标准 | HTML5 | XHTML 1.0 | HTML 4.01 |
|------|-------|-----------|-----------|
| **DOCTYPE** | `<!DOCTYPE html>` | Strict DTD | Strict/Transitional |
| **语法要求** | 相对宽松 | 严格XML | 传统HTML |
| **错误等级** | 建议性 | 致命性 | 警告/错误 |

### ✅ 修正示例

```html
<!-- 错误：缺少alt属性 -->
<img src="image.jpg">

<!-- 修正：添加alt描述 -->
<img src="image.jpg" alt="描述性文本">

<!-- 错误：标签未闭合 -->
<p>段落内容

<!-- 修正：正确闭合 -->
<p>段落内容</p>
```
