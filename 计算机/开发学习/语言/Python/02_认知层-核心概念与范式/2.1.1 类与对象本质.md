# 2.1.1 类与对象本质

## 🎯 核心洞察

Python中"万物皆对象"不是口号，而是设计真相。理解类与对象的本质，就是理解Python运行时的底层机制。

### 🧠 Python对象模型

```python
# ✅ 对象特性的深度验证
class ObjectInspector:
    """对象检查器 - 揭示Python对象本质"""
    
    @staticmethod
    def inspect_object(obj):
        """全面检查Python对象"""
        print(f"🔍 对象检查: {obj}")
        print(f"📧 类型: {type(obj)}")
        print(f"🆔 内存地址: {id(obj)}")
        print(f"📂 属性: {dir(obj)}")
        print(f"🔤 模块: {getattr(obj, '__module__', 'N/A')}")
        print(f"📝 文档: {getattr(obj, '__doc__', 'N/A')}")
        print("-" * 40)

# 检查不同对象
strings = "Hello World"
numbers = 42
functions = lambda x: x ** 2
classes = object()

ObjectInspector.inspect_object(strings)
ObjectInspector.inspect_object(numbers)
ObjectInspector.inspect_object(functions)
ObjectInspector.inspect_object(classes)
```

### 🔬 类与实例的关系

```python
# ✅ 类创建过程的深度观察
class MetaClassInspector(type):
    """元类 - 监控类的创建过程"""
    
    def __new__(cls, name, bases, attrs):
        print(f"🏗️ 创建类: {name}")
        print(f"📋 继承自: {bases}")
        print(f"🔧 属性: {list(attrs.keys())}")
        
        # 添加默认属性
        attrs['_created_by_meta'] = cls.__name__
        
        return super().__new__(cls, name, bases, attrs)
    
    def __call__(cls, *args, **kwargs):
        print(f"📞 调用类构造函数: {cls.__name__}")
        print(f"📨 参数: args={args}, kwargs={kwargs}")
        
        instance = super().__call__(*args, **kwargs)
        print(f"✨ 实例创建完成: {instance}")
        return instance

class Person(metaclass=MetaClassInspector):
    """人类 - 演示对象创建过程"""
    
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def greet(self):
        return f"Hello, I'm {self.name}"

# 创建实例观察过程
person = Person("Alice", 25)
```

### 🎭 属性的动态特性

```python
class DynamicClass:
    """动态类 - 展示Python的动态特性"""
    
    def __init__(self):
        self._initialized = True
    
    def __getattr__(self, name):
        """属性不存在时的处理"""
        print(f"❓ 访问未定义属性: {name}")
        return f"Dynamic value for {name}"
    
    def __setattr__(self, name, value):
        """属性设置的特殊处理"""
        if name == 'special_attribute':
            value = f"Special: {value}"
        print(f"🔧 设置属性 {name} = {value}")
        super().__setattr__(name, value)
    
    def __delattr__(self, name):
        """属性删除的处理"""
        print(f"🗑️ 删除属性: {name}")
        super().__delattr__(name)

# 测试动态特性
obj = DynamicClass()
obj.normal_attr = "test"
obj.special_attribute = "data"

print(obj.nonexistent_attr)
del obj.normal_attr
```

## 💡 费曼检验

**解释：为什么在Python中，连数字和字符串都是对象？这种设计有什么优势？**

核心要点：
1. **一致性**：统一的对象模型简化了语言设计
2. **灵活性**：所有对象都可以有方法和属性
3. **可扩展性**：新的类型可以自然地融入系统
4. **元编程**：统一模型让元编程成为可能
