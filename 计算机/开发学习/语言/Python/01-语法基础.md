## 注释

Python中的注释用于解释代码，提高代码可读性。

### 单行注释
使用 `#` 符号开始单行注释：

```python
# 这是一个单行注释
print("Hello World")  # 这也是一个单行注释
```

### 多行注释
使用三引号 `"""` 或 `'''` 创建多行注释：

```python
"""
这是一个多行注释
可以写多行内容
用于文档说明
"""

'''
这也是多行注释
使用单引号
'''
```

### 注释最佳实践
- 解释代码的**为什么**，而不是**做什么**
- 保持注释简洁明了
- 及时更新注释，保持与代码同步

## 变量

变量是存储数据的容器，在Python中不需要声明类型。

### 变量命名规则
- 只能包含字母、数字和下划线
- 不能以数字开头
- 不能使用Python关键字
- 区分大小写

```python
# 正确的变量名
name = "张三"
age = 25
user_name = "zhangsan"
userName = "zhangsan"  # 驼峰命名
user_name = "zhangsan"  # 下划线命名

# 错误的变量名
# 2name = "错误"  # 不能以数字开头
# class = "错误"  # 不能使用关键字
```

### 变量赋值
Python使用 `=` 进行赋值：

```python
# 单个赋值
x = 10
name = "Python"

# 多个赋值
a, b, c = 1, 2, 3
x = y = z = 0

# 交换变量值
a, b = b, a
```

## 常量

Python没有真正的常量，通常用全大写字母表示常量：

```python
# 常量命名（全大写）
PI = 3.14159
MAX_SIZE = 100
DEFAULT_NAME = "Unknown"

# 使用常量
radius = 5
area = PI * radius * radius
```

## 数据类型

Python是动态类型语言，变量类型在运行时确定。

### 整数类型 (int)

```python
# 十进制整数
age = 25
count = -10

# 二进制整数（0b开头）
binary = 0b1010  # 等于10

# 八进制整数（0o开头）
octal = 0o17  # 等于15

# 十六进制整数（0x开头）
hexadecimal = 0xFF  # 等于255

# 大整数（Python自动处理）
big_number = 123456789012345678901234567890
```

### 浮点类型 (float)

```python
# 普通浮点数
price = 19.99
temperature = -5.5

# 科学计数法
scientific = 1.23e4  # 等于12300.0
small = 1.23e-4  # 等于0.000123

# 特殊值
infinity = float('inf')
not_a_number = float('nan')
```

### 字符串类型 (str)

```python
# 单引号字符串
name1 = 'Hello World'

# 双引号字符串
name2 = "Hello World"

# 三引号字符串（多行）
message = """
这是一个
多行字符串
"""

# 转义字符
escaped = "He said \"Hello\""
newline = "Line 1\nLine 2"
tab = "Column1\tColumn2"

# 原始字符串（r前缀）
path = r"C:\Users\Name\Documents"
```

### 布尔类型 (bool)

```python
# 布尔值
is_student = True
is_working = False

# 布尔运算结果
result1 = 5 > 3  # True
result2 = 5 < 3  # False
result3 = 5 == 5  # True
```

### None类型

```python
# None表示空值
data = None
result = None

# 检查None
if data is None:
    print("数据为空")
```

## 类型转换

Python提供内置函数进行类型转换：

```python
# 转换为整数
str_num = "123"
int_num = int(str_num)  # 123
float_to_int = int(3.14)  # 3

# 转换为浮点数
str_float = "3.14"
float_num = float(str_float)  # 3.14
int_to_float = float(5)  # 5.0

# 转换为字符串
num = 123
str_num = str(num)  # "123"
bool_str = str(True)  # "True"

# 转换为布尔值
bool1 = bool(1)  # True
bool2 = bool(0)  # False
bool3 = bool("")  # False
bool4 = bool("hello")  # True
```

## 示例代码

```python
# 个人信息示例
name = "张三"  # 字符串
age = 25  # 整数
height = 175.5  # 浮点数
is_student = True  # 布尔值
hobby = None  # None值

# 输出信息
print(f"姓名：{name}")
print(f"年龄：{age}岁")
print(f"身高：{height}cm")
print(f"是否为学生：{is_student}")
print(f"爱好：{hobby}")

# 类型检查
print(f"name的类型：{type(name)}")
print(f"age的类型：{type(age)}")
print(f"height的类型：{type(height)}")
print(f"is_student的类型：{type(is_student)}")
print(f"hobby的类型：{type(hobby)}")
```
