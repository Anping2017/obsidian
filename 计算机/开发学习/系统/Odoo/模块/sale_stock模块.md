# 📦 Odoo `sale_stock` 模块详解

## 一、`sale_stock` 模块的作用

- **销售与库存集成模块**。
- 连接 `sale` 和 `stock` 模块。
- 实现销售订单自动创建交货单。
- 提供库存可用性检查和预留功能。

📌 形象理解：  
👉 销售订单确认后，自动创建库存交货单，开始备货和发货流程。

---

## 二、核心功能

### 1. 销售订单自动创建交货单

- 订单确认时自动创建交货单（Picking）
- 无需手动创建交货单
- 自动化销售到交付流程

### 2. 库存可用性检查

- 实时检查产品库存可用性
- 显示可承诺数量（Available to Promise）
- 库存不足时提示警告

### 3. 自动预留库存

- 订单确认时自动预留库存
- 确保产品可用
- 防止超卖

### 4. 交付状态跟踪

- 在销售订单中显示交付状态
- 跟踪部分交付和完全交付
- 交付进度可视化

---

## 三、工作流程

### 1. 创建销售订单

```
创建销售订单（报价单）
 ↓
添加产品行
 ↓
检查库存可用性（可选）
 ↓
确认订单
```

### 2. 订单确认后的流程

```
确认销售订单
 ↓
自动创建交货单（Delivery Order）
 ↓
自动预留库存
 ↓
等待仓库处理
 ↓
发货完成
 ↓
订单标记为已交付
```

## 四、核心模型扩展

### 1. `sale.order` 扩展

添加库存相关字段：

```
sale.order 模型扩展：
- picking_ids: 关联的交货单（One2many）
- delivery_count: 交货单数量
- delivery_status: 交付状态
- warehouse_id: 仓库
```

### 2. `sale.order.line` 扩展

添加库存相关字段：

```
sale.order.line 模型扩展：
- product_type: 产品类型（可库存/不可库存）
- qty_delivered: 已交付数量
- qty_to_deliver: 待交付数量
- move_ids: 关联的库存移动
```

---

## 五、库存可用性

### 1. 可用数量检查

- **在手库存**（On Hand）：仓库中实际数量
- **已预留**（Reserved）：已为订单预留的数量
- **可用数量**（Available）：在手库存 - 已预留
- **可承诺数量**（ATP）：考虑未来收货的可用数量

### 2. 可用性显示

- 在订单行显示库存状态图标
- 库存充足：绿色
- 库存不足：红色警告
- 可配置库存阈值

### 3. 预测数量

- 考虑未来采购订单
- 考虑生产订单
- 提供更准确的可用性预测

---

## 六、交货单管理

### 1. 交货单创建

- 订单确认时自动创建
- 可按行拆分到多个交货单
- 支持多仓库交货

### 2. 交货单状态

- **草稿**（Draft）：已创建，未处理
- **等待**（Waiting）：等待可用库存
- **就绪**（Ready）：库存可用，可发货
- **已完成**（Done）：已发货
- **取消**（Cancelled）：已取消

### 3. 部分交付

- 支持部分交付
- 多次交付同一订单
- 跟踪交付进度

---

## 七、与其他模块的集成

### 1. 与 `sale` 模块

- 扩展销售订单功能
- 添加库存和交付信息

### 2. 与 `stock` 模块

- 自动创建库存移动
- 预留和释放库存
- 跟踪库存变动

### 3. 与 `account` 模块

- 交付后创建发票（可配置）
- 成本核算
- 库存估值

### 4. 与 `purchase` 模块

- 库存不足时提示采购
- 创建采购订单建议
- 采购到交付流程

---

## 八、配置和设置

### 1. 交付策略

- **订单时交付**：订单确认时立即交付
- **手动交付**：手动处理交付
- **基于库存**：库存可用时自动交付

### 2. 库存预留策略

- **立即预留**：订单确认时立即预留
- **延迟预留**：发货前预留
- **不预留**：不自动预留

### 3. 仓库配置

- 设置默认仓库
- 配置交付规则
- 多仓库支持

---

## 九、典型使用场景

1. **订单到交付**：订单确认后自动启动交付流程
2. **库存检查**：销售时实时检查库存，避免超卖
3. **交付跟踪**：在销售订单中查看交付状态
4. **自动化流程**：减少手动操作，提高效率
5. **多仓库**：从不同仓库发货到同一订单
