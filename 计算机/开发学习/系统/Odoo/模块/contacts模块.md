# 📇 Odoo `contacts` 模块详解

## 一、`contacts` 模块的作用

- 提供 **联系人管理**功能。
- 扩展 `base` 模块中的 `res.partner` 模型。
- 优化联系人视图和操作。
- 支持客户、供应商、联系人的完整生命周期管理。

📌 注意：`contacts` 模块依赖于 `base` 模块的 `res.partner` 模型，主要提供界面和功能增强。

---

## 二、核心功能

### 1. 客户和供应商管理

- **客户管理**：完整的客户档案
- **供应商管理**：供应商信息和评估
- **联系人管理**：个人联系人、合作伙伴

### 2. 联系人分类和标签

- 联系人分类（Categories/Tags）
- 自定义标签系统
- 快速筛选和分组

### 3. 地址簿功能

- 联系人地址管理
- 多个地址支持（账单地址、送货地址）
- 地址验证和格式化

### 4. 联系人视图优化

- 列表视图（Tree View）
- 表单视图（Form View）
- 看板视图（Kanban View）
- 地图视图（Map View）- 显示联系人地理位置

### 5. 联系人活动跟踪

- 与 `mail` 模块集成，显示联系人相关活动
- 最近的交互记录
- 跟进提醒

---

## 三、核心模型

### 1. `res.partner.category`

联系人分类/标签模型：

```
class PartnerCategory(models.Model):
    _name = 'res.partner.category'
    _description = 'Partner Category'
    
    name = fields.Char('Category Name', required=True)
    parent_id = fields.Many2one('res.partner.category', 'Parent Category')
    child_ids = fields.One2many('res.partner.category', 'parent_id', 'Child Categories')
```

用途：
- 标记客户类型（VIP客户、潜在客户等）
- 标记供应商类型（主要供应商、备用供应商等）
- 多级分类支持

### 2. `res.partner`（扩展）

`contacts` 模块扩展 `res.partner`，添加：

- 增强的联系人视图
- 更多的字段和功能
- 与销售、采购等模块的集成视图

---

## 四、联系人数据结构

### 1. 联系人类型

- **个人**（Person）：`is_company = False`
- **公司**（Company）：`is_company = True`
- **客户**（Customer）：`customer_rank > 0`
- **供应商**（Supplier）：`supplier_rank > 0`

### 2. 联系人关系

- **父-子关系**：公司与内部联系人
- **关联关系**：多个联系人关联到同一公司
- **层级关系**：联系人分类的层级结构

### 3. 地址信息

- **主地址**：主要联系地址
- **账单地址**：发票邮寄地址
- **送货地址**：货物配送地址
- **其他地址**：多个地址支持

## 五、与其他模块的集成

- 查看供应商的采购历史
- 供应商评估和评级

### 3. 与 `crm` 模块

- 联系人转化为商机
- 客户生命周期跟踪

### 4. 与 `account` 模块

- 查看客户的发票和付款历史
- 应收账款管理
- 供应商账单管理

### 5. 与 `mail` 模块

- Chatter 功能
- 邮件沟通记录
- 活动提醒和跟进
