# ⏰ Odoo `hr_attendance` 模块详解

## 一、`hr_attendance` 模块的作用

- **考勤管理模块**，扩展 `hr` 模块的考勤功能。
- 管理员工打卡记录（签到/签退）。
- 跟踪员工出勤时间和工作时间统计。
- 与薪资模块集成，用于计算加班费和工作天数。
- 支持多种打卡方式：手动打卡、自动打卡、移动端打卡等。

📌 形象理解：  
👉 `hr_attendance` 模块是"打卡系统"，记录员工上下班时间。

---

## 二、核心功能

### 1. 打卡记录管理

#### 考勤记录模型

```
class HrAttendance(models.Model):
    _name = 'hr.attendance'
    _description = 'Attendance'
    _order = 'check_in desc'
    
    employee_id = fields.Many2one('hr.employee', string='Employee', 
                                  required=True, ondelete='cascade', index=True)
    check_in = fields.Datetime(string='Check In', required=True, default=fields.Datetime.now)
    check_out = fields.Datetime(string='Check Out')
    worked_hours = fields.Float(string='Worked Hours', compute='_compute_worked_hours', 
                                store=True, readonly=True)
    overtime_hours = fields.Float(string='Overtime Hours', compute='_compute_overtime_hours',
                                  store=True)
```

#### 打卡类型

- **签到（Check In）**：员工上班打卡
- **签退（Check Out）**：员工下班打卡
- **自动打卡**：基于规则自动打卡
- **手动打卡**：管理员手动录入打卡记录

#### 打卡方式

- **Web端打卡**：在Odoo网页端打卡
- **移动端打卡**：通过Odoo移动应用打卡
- **Kiosk模式**：考勤机模式，员工快速打卡
- **GPS打卡**：基于位置的打卡（移动端）

### 2. 工作时间计算

#### 工作时间统计

- **实际工作时间**：签退时间 - 签到时间
- **标准工作时间**：标准工作日工作时间
- **加班时间**：超过标准工作时间的时间
- **工作时长**：按小时计算的工作时长

#### 计算公式

```
实际工作时间 = check_out - check_in
标准工作时间 = 8小时（可配置）
加班时间 = max(0, 实际工作时间 - 标准工作时间)
```

### 3. 考勤规则配置

#### 工作时间规则

- **标准工作时间**：每日标准工作时间
- **工作时间表**：不同日期的工作时间表
- **休息时间**：午餐休息时间扣除
- **弹性工作制**：支持弹性工作时间

#### 异常处理规则

- **迟到规则**：迟到时间阈值和处理方式
- **早退规则**：早退处理方式
- **缺勤规则**：缺勤判定和处理
- **异常提醒**：异常考勤自动提醒

## 三、核心模型详解

### 1. `hr.attendance` - 考勤记录

**主要字段**：
- `employee_id`：员工（必填）
- `check_in`：签到时间（必填）
- `check_out`：签退时间
- `worked_hours`：工作时长（自动计算）
- `overtime_hours`：加班时长（自动计算）

**使用示例**：

```python
# 创建签到记录
attendance = self.env['hr.attendance'].create({
    'employee_id': employee.id,
    'check_in': fields.Datetime.now(),
})

# 签退
attendance.write({
    'check_out': fields.Datetime.now(),
})

# 查询员工今日考勤
today = fields.Date.today()
attendance_today = self.env['hr.attendance'].search([
    ('employee_id', '=', employee.id),
    ('check_in', '>=', fields.Datetime.combine(today, datetime.time.min)),
    ('check_in', '<', fields.Datetime.combine(today + timedelta(days=1), datetime.time.min)),
], limit=1)
```

### 2. 工作时间统计

- **月度统计**：计算员工每月工作总时长
- **年度统计**：计算员工年度工作总时长
- **加班统计**：统计加班时长

## 四、与其他模块的集成

### 1. 与 `hr` 模块

- **员工信息**：从员工档案获取信息
- **部门信息**：按部门统计考勤
- **职位信息**：不同职位可能有不同的工作时间要求

### 2. 与 `hr_payroll` 模块

- **工作天数**：考勤数据用于工资单的工作天数计算
- **加班费**：加班时长用于计算加班费
- **缺勤扣除**：缺勤记录用于工资扣除

### 3. 与 `hr_holidays` 模块

- **请假验证**：请假期间不计算考勤
- **假期扣除**：请假天数从工作天数中扣除

## 五、典型使用场景

### 场景 1：员工日常打卡

**需求**：员工每天上下班打卡

**步骤**：

1. **签到**
   ```
   考勤 > 打卡 > 签到
   - 系统记录签到时间
   - 显示签到成功
   ```

2. **签退**
   ```
   考勤 > 打卡 > 签退
   - 系统记录签退时间
   - 自动计算工作时长
   - 显示今日工作时长
   ```

### 场景 2：月度考勤统计

**需求**：统计员工月度考勤情况

**步骤**：

1. **考勤 > 考勤报表**
2. 选择参数：
   - **员工**：选择要统计的员工
   - **期间**：选择月份
3. **查看报表**：
   - 总工作时长
   - 正常出勤天数
   - 迟到次数
   - 缺勤天数
   - 加班时长

### 场景 3：异常考勤处理

**需求**：处理异常考勤记录

**步骤**：

1. **识别异常**
   - 系统自动识别异常（迟到、早退、缺勤）
   - 或手动检查考勤记录

2. **处理异常**
   - 修改打卡记录（如需要）
   - 添加异常说明
   - 审批异常处理

## 六、配置和设置

### 1. 打卡配置

1. **人事 > 配置 > 考勤设置**
2. 配置选项：
   - **允许员工自己打卡**：是否允许员工自助打卡
   - **需要签到签退**：是否必须打卡
   - **GPS要求**：移动端是否要求GPS定位

### 2. 工作时间配置

1. **人事 > 配置 > 工作时间**
2. 配置工作时间：
   - **标准工作时间**：每日标准工作小时
   - **工作时间表**：工作日历
   - **休息时间**：休息时间扣除规则

### 3. Kiosk模式配置

Kiosk模式允许在没有登录的情况下快速打卡：

1. **考勤 > Kiosk模式**
2. 配置Kiosk：
   - **位置**：Kiosk位置（如办公室入口）
 brut   - **设备**：使用的设备（平板电脑等）
