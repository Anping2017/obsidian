# 🚪 Odoo `portal` 模块详解

## 一、`portal` 模块的作用

- 提供 **客户门户网站**（Customer Portal）功能。
- 允许客户/供应商通过独立的门户访问相关业务数据。
- 实现客户自助服务，减少人工处理。
- 提升客户体验和协作效率。

📌 形象理解：  
👉 企业内部用户使用 **Web 客户端**（`web` 模块），  
👉 外部客户/供应商使用 **门户网站**（`portal` 模块）。

---

## 二、核心功能

### 1. 客户自助登录

- 客户可以创建门户账户。
- 通过邮件邀请或注册链接访问。
- 独立的认证系统，与内部用户隔离。

### 2. 查看业务数据

客户可以在门户中查看：
- **销售订单**：报价、订单状态、历史订单
- **发票**：已发送的发票、付款状态
- **项目**：相关项目进度和任务
- **合同**：服务合同和文档
- **送货单**：发货状态和跟踪信息

### 3. 文档下载

- 下载发票 PDF
- 下载合同和协议
- 下载报表和凭证

### 4. 协作功能

- 在订单/发票上留言（Chatter）
- 上传相关文档
- 与内部团队沟通

### 5. 在线支付（集成）

- 查看未付发票
- 在线支付发票（需支付网关集成）
- 付款历史记录

---

## 三、技术实现

### 1. 门户用户组

- `base.group_portal`：门户用户组
- 与内部用户组（`base.group_user`）分离
- 权限受限，只能访问相关数据

### 2. 记录规则（Record Rules）

- 自动过滤，客户只能看到自己的数据
- 基于 `partner_id` 的数据隔离
- 确保数据安全和隐私

示例规则：
```
<record id="account_move_portal_rule" model="ir.rule">
    <field name="name">Portal: see own invoices</field>
    <field name="model_id" ref="account.model_account_move"/>
    <field name="domain_force">[('partner_id', '=', user.partner_id.id)]</field>
    <field name="groups" eval="[(4, ref('base.group_portal'))]"/>
</record>
```

### 3. 门户控制器

- 独立的 URL 路由（`/my` 前缀）
- 专门的模板和视图
- 与 Web 客户端分离的界面

## 四、与其他模块的集成

### 1. 与 `sale` 模块

- 门户显示销售订单
- 客户可以确认或拒绝报价
- 跟踪订单状态

### 2. 与 `account` 模块

- 显示发票和账单
- 发票付款状态
- 在线支付集成

### 3. 与 `project` 模块

- 客户查看项目进度
- 任务状态和里程碑
- 项目文档和沟通

### 4. 与 `mail` 模块

- Chatter 功能在门户中可用
- 客户可以在记录上留言
- 接收通知和更新

---

## 五、门户页面结构

### 1. 仪表板（Dashboard）

- 概览客户的关键信息
- 待处理订单、未付发票数量
- 快速链接

### 2. 订单页面

- 订单列表（只能看到自己的）
- 订单详情
- 确认/拒绝操作

### 3. 发票页面

- 发票列表
- 发票详情和 PDF 下载
- 付款按钮（如果配置）

### 4. 项目页面

- 相关项目列表
- 任务和进度查看
- 文档和沟通

---

## 六、配置和设置

### 1. 启用门户功能

- 在应用列表安装 `portal` 模块
- 自动配置必要的权限和规则

### 2. 创建门户用户

- 手动创建门户用户
- 或通过"共享"功能发送邀请链接
- 系统自动发送邀请邮件

### 3. 自定义门户页面

- 可以扩展和定制门户模板
- 添加自定义内容和功能
- 品牌化和主题设置

---

## 七、典型使用场景

1. **客户订单跟踪**：客户登录查看订单状态和物流信息
2. **自助开票**：客户下载发票，在线付款
3. **项目协作**：客户查看项目进度，与团队沟通
4. **文档管理**：客户上传和下载合同、证书等文档
5. **服务请求**：客户提交服务请求和反馈

---

## 八、安全考虑

### 1. 数据隔离

- 严格的记录规则确保数据隔离
- 客户只能访问自己的数据
- 不会泄露其他客户信息

### 2. 权限控制

- 门户用户权限受限
- 不能修改关键业务数据
- 只能查看和有限操作

### 3. 访问审计

- 记录门户访问日志
- 跟踪客户操作历史

---

## 九、总结

- **`portal` 模块**提供客户自助服务门户。
- 核心功能：
  - 客户自助登录和认证
  - 查看订单、发票、项目等业务数据
  - 文档下载和上传
  - 在线协作和沟通
  - 在线支付（集成）
- 与销售、会计、项目等模块深度集成。
- 提升客户满意度，减少人工处理成本。
- 确保数据安全和隐私，实现严格的数据隔离。
