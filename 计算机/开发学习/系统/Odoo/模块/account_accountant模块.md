# 📊 Odoo `account_accountant` 模块详解

## 一、`account_accountant` 模块的作用

- **会计功能增强模块**，扩展 `account` 模块的核心功能。
- 为会计人员提供专业化的会计工具和界面。
- 包含会计仪表板、高级报表、配置向导等高级功能。
- 简化会计操作流程，提高会计工作效率。

📌 形象理解：  
👉 `account` 模块提供基础会计功能，`account_accountant` 模块提供专业会计工具和界面。

---

## 二、核心功能

### 1. 会计仪表板（Dashboard）

会计仪表板是会计人员的主要工作界面，提供财务数据的可视化概览。

#### 仪表板功能

- **关键指标（KPI）展示**：
  - 总资产、总负债
  - 净收入
  - 应收账款余额
  - 应付账款余额
  - 现金流概览

- **快速链接**：
  - 创建发票
  - 创建账单
  - 创建付款
  - 日记账分录
  - 银行对账

- **待办事项**：
  - 待审核的发票
  - 待对账的交易
  - 到期的付款
  - 未匹配的银行对账单

- **图表和趋势**：
  - 收入趋势图
  - 费用趋势图
  - 利润趋势图
  - 现金流图表

#### 仪表板配置

会计人员可以自定义仪表板布局：
- 选择显示的 KPI
- 调整图表类型
- 设置时间范围
- 保存个人偏好

### 2. 高级财务报表

提供比基础 `account` 模块更丰富的财务报表功能。

#### 报表类型

**利润表（Profit & Loss Statement）**：
- 多期间比较
- 与预算对比
- 科目明细钻取
- 自定义分组

**资产负债表（Balance Sheet）**：
- 多期间对比
- 资产和负债明细
- 权益变动分析

**现金流量表（Cash Flow Statement）**：
- 经营活动现金流
- 投资活动现金流
- 筹资活动现金流

**总账报表（General Ledger）**：
- 详细交易记录
- 按科目筛选
- 按日期范围筛选
- 导出 Excel/PDF

**试算平衡表（Trial Balance）**：
- 科目余额汇总
- 借贷平衡验证
- 多期间对比

#### 报表功能增强

- **钻取功能**：从汇总数据钻取到明细
- **多维度分析**：按部门、项目、产品等维度分析
- **预算对比**：实际与预算对比分析
- **自定义报表**：创建自定义报表模板

### 3. 会计配置向导

提供向导式的会计系统初始化配置。

#### 配置向导步骤

**步骤 1：公司信息**
- 公司名称和地址
- 税务信息
- 联系方式

**步骤 2：会计科目表**
- 选择科目表模板
- 或导入自定义科目表
- 配置科目属性

**步骤 3：日记账设置**
- 创建销售日记账
- 创建采购日记账
- 创建银行日记账
- 创建现金日记账

**步骤 4：税务配置**
- 设置税率
- 配置税务规则
- 设置税种

**步骤 5：付款条件**
- 定义付款条件模板
- 设置付款条款

#### 快速配置

会计配置向导可以帮助新用户快速完成会计系统的基本配置，无需深入了解技术细节。

### 4. 会计年度管理

管理会计年度和会计期间。

#### 会计年度功能

- **创建会计年度**：
  - 定义年度开始和结束日期
  - 设置期间数量（12 个月、4 个季度等）
  - 配置期间类型（月度、季度、年度）

- **期间管理**：
  - 期间开启和关闭
  - 期间锁定（防止误操作）
  - 期间状态跟踪

- **会计年度设置**：

```
class AccountYear(models.Model):
    _name = 'account.fiscal.year'
    
    name = fields.Char('Fiscal Year Name', required=True)
    date_from = fields.Date('Start Date', required=True)
    date_to = fields.Date('End Date', required=True)
    period_ids = fields.One2many('account.period', 'fiscalyear_id', 'Periods')
    company_id = fields.Many2one('res.company', 'Company', required=True)
```

#### 期间模型

```
class AccountPeriod(models.Model):
    _name = 'account.period'
    
    name = fields.Char('Period Name', required=True)
    code = fields.Char('Code')
    date_start = fields.Date('Start Date', required=True)
    date_stop = fields.Date('End Date', required=True)
    fiscalyear_id = fields.Many2one('account.fiscal.year', 'Fiscal Year')
    state = fields.Selection([
        ('draft', 'Open'),
        ('done', 'Closed')
    ], string='Status', default='draft')
```

### 5. 期末结账功能

提供会计期末结账的完整流程。

#### 结账流程

**步骤 1：对账检查**
- 银行对账
- 应收应付对账
- 库存对账（如有）
- 确保所有交易都已对账

**步骤 2：调整分录**
- 折旧分录
- 预提费用
- 收入确认
- 其他调整

**步骤 3：生成报表**
- 利润表
- 资产负债表
- 试算平衡表
- 其他报表

**步骤 4：审核报表**
- 检查报表准确性
- 分析异常项目
- 与上期对比

**步骤 5：结账**
- 锁定当前期间
- 开启下一期间
- 结转未分配利润（如需要）

#### 结账向导

系统提供结账向导，引导会计人员完成结账流程：
- 检查清单
- 自动验证
- 步骤提示
- 错误提示

### 6. 高级搜索和筛选

增强的搜索和筛选功能，提高数据查找效率。

#### 搜索功能

- **智能搜索**：快速搜索发票、账单、付款等
- **高级搜索**：多条件组合搜索
- **保存搜索**：保存常用搜索条件

#### 筛选功能

- **按日期筛选**：快速选择日期范围
- **按状态筛选**：筛选不同状态的记录
- **按客户/供应商筛选**：快速找到特定客户/供应商的记录
- **自定义筛选器**：创建和保存自定义筛选器

### 7. 批量操作

支持批量处理，提高工作效率。

#### 批量操作类型

- **批量过账**：一次性过账多个发票
- **批量对账**：批量匹配付款和发票
- **批量导出**：导出多个记录
- **批量打印**：批量打印发票或报表

### 8. 审批流程

可选的发票和日记账审批流程。

#### 审批功能

- **审批规则配置**：
  - 设置需要审批的金额阈值
  - 定义审批人
  - 配置审批流程

- **审批流程**：
  ```
  创建发票/日记账
   ↓
  提交审批
   ↓
  审批人审核
   ↓
  批准/拒绝
   ↓
  过账（如批准）
  ```

## 五、配置和设置

### 1. 启用会计模块

1. 安装 `account_accountant` 模块
2. 运行会计配置向导
3. 完成基本配置

### 2. 配置仪表板

1. **会计 > 仪表板**
2. 自定义显示内容
3. 调整布局
4. 保存设置

### 3. 配置报表

1. **会计 > 报表**
2. 选择需要的报表类型
3. 配置报表参数
4. 保存报表模板

### 4. 配置审批流程

1. **设置 > 会计 > 审批**
2. 定义审批规则
3. 设置审批人
4. 启用审批流程

## 七、常见问题

### 问题 1：无法看到仪表板

**原因**：未安装 `account_accountant` 模块或权限不足

**解决方案**：
1. 确认模块已安装
2. 检查用户权限
3. 联系管理员

### 问题 2：报表数据不准确

**原因**：相关交易未过账或对账未完成

**解决方案**：
1. 检查交易状态
2. 完成对账
3. 重新生成报表
