# 📍 Odoo `base_address_extended` 模块详解

## 一、`base_address_extended` 模块的作用

- 扩展 `base` 模块的地址字段功能。
- 提供 **详细的地址管理**（街道、城市、州/省、邮编等）。
- 支持多国家的地址格式。
- 增强地址验证和标准化。

📌 注意：这是一个扩展模块，主要增强 `res.partner` 的地址管理能力。

---

## 二、核心功能

### 1. 详细地址字段

扩展地址包含：
- **街道**（Street）：详细街道地址
- **街道2**（Street2）：补充地址信息
- **城市**（City）：城市名称
- **州/省**（State/Province）：州或省份
- **邮编**（Zip Code）：邮政编码
- **国家**（Country）：国家

### 2. 多国家地址格式支持

- 不同国家的地址格式不同（如美国、中国、欧洲）
- 自动适配地址字段顺序和格式
- 符合各国地址规范

### 3. 地址标准化

- 地址格式验证
- 自动补全建议（如果集成地址服务）
- 地址数据清洗

---

## 三、地址字段结构

### 标准地址字段

```
res.partner 模型扩展：
- street: 街道地址（第一行）
- street2: 街道地址（第二行）
- city: 城市
- state_id: 州/省（Many2one 到 res.country.state）
- zip: 邮政编码
- country_id: 国家（Many2one 到 res.country）
```

### 地址模型关系

```
res.partner
 ├── street, street2 (详细地址)
 ├── city (城市)
 ├── state_id → res.country.state (州/省)
 ├── zip (邮编)
 └── country_id → res.country (国家)
```

## 五、与其他模块的集成

### 1. 与 `contacts` 模块

- 增强联系人地址管理
- 在地图视图中使用详细地址

### 2. 与 `sale` 模块

- 订单送货地址使用扩展地址字段
- 发票地址使用扩展地址字段

### 3. 与 `purchase` 模块

- 供应商地址管理
- 收货地址使用扩展地址

### 4. 与 `stock` 模块

- 详细的仓库地址
- 准确的配送地址信息

## 六、地址验证和补全

### 1. 地址验证

- 邮编格式验证
- 州/省与国家匹配验证
- 城市与州/省匹配验证

### 2. 地址补全（可选）

- 集成第三方地址服务（如 Google Address API）
- 输入邮编自动补全城市和州/省
- 地址建议和标准化

---

## 七、典型使用场景

1. **国际业务**：处理不同国家的地址格式
2. **物流配送**：准确的地址信息确保正确配送
3. **税务合规**：某些国家需要详细的地址信息用于税务报告
4. **地址分析**：按地区分析客户或供应商分布
5. **地图集成**：详细地址支持地图定位和路线规划

---

## 八、配置和设置

### 1. 安装模块

- 在应用列表中安装 `base_address_extended`
- 自动扩展 `res.partner` 模型

### 2. 地址格式配置

- 根据不同国家配置地址格式
- 设置必填字段
- 自定义地址显示格式

### 3. 地址验证服务（可选）

- 配置第三方地址验证 API
- 启用地址自动补全
- 设置验证规则

---

## 九、数据迁移

### 1. 从简单地址迁移

如果之前使用简单地址字段，可以：

- 数据导入时拆分地址字段
- 使用脚本批量处理现有数据
- 手动或自动填充扩展字段

### 2. 地址数据清洗

- 识别和修复不完整的地址
- 标准化地址格式
- 验证地址有效性

---

## 十、最佳实践

1. **完整性**：确保关键地址字段填写完整
2. **一致性**：使用标准化的地址格式
3. **验证**：在录入时验证地址信息
4. **国际化**：考虑多语言和不同国家的地址格式
5. **隐私**：遵守数据保护法规，安全处理地址信息

---

## 十一、总结

- **`base_address_extended` 模块**扩展了 Odoo 的地址管理功能。
- 核心功能：
  - 详细的地址字段（街道、城市、州、邮编、国家）
  - 多国家地址格式支持
  - 地址验证和标准化
  - 与销售、采购、库存等模块的集成
- 适用于需要详细地址信息的业务场景。
- 提升地址数据质量，支持更好的物流和地理分析。
- 是处理国际业务和多地区业务的重要工具。
