# 分析器算法对比

## 🎯 分析器算法对比概述

**分析器算法对比**是编译器原理学习的重要组成部分，通过对比不同分析器算法的特点、优缺点和适用场景，帮助学习者深入理解各种算法的本质差异，从而在实际应用中做出正确的选择。

## 🔍 对比维度

### 1. 性能维度
- **时间复杂度**：算法执行时间随输入规模的增长
- **空间复杂度**：算法所需内存随输入规模的增长
- **常数因子**：算法的实际执行效率

### 2. 功能维度
- **分析能力**：能处理的文法类型和复杂度
- **错误处理**：错误检测和恢复能力
- **扩展性**：算法的可扩展性和灵活性

### 3. 实现维度
- **实现难度**：算法的实现复杂度
- **维护成本**：算法的维护和调试成本
- **工具支持**：相关工具和库的支持情况

### 有限自动机算法对比

#### DFA vs NFA对比

| 特性 | DFA | NFA | 优势分析 |
|------|-----|-----|----------|
| **时间复杂度** | O(n) | O(n×|Q|) | DFA在时间效率上更优 |
| **空间复杂度** | O(|Q|×|Σ|) | O(|Q|) | NFA在空间效率上更优 |
| **确定性** | 确定性 | 非确定性 | DFA行为可预测，NFA更灵活 |
| **状态数** | 可能很多 | 相对较少 | NFA状态数通常更少 |
| **实现复杂度** | 中等 | 简单 | NFA实现相对简单 |
| **适用场景** | 生产环境 | 开发阶段 | DFA适合生产，NFA适合开发 |

```c
// DFA vs NFA性能对比示例
class FiniteAutomataComparison {
public:
    // DFA模拟：时间复杂度O(n)，空间复杂度O(|Q|×|Σ|)
    bool dfaSimulate(const string& input) {
        int currentState = startState;
        
        for (char c : input) {
            int symbol = getSymbolIndex(c);
            currentState = transitionTable[currentState][symbol];
            if (currentState == -1) return false;
        }
        
        return isAcceptState(currentState);
    }
    
    // NFA模拟：时间复杂度O(n×|Q|)，空间复杂度O(|Q|)
    bool nfaSimulate(const string& input) {
        set<int> currentStates = epsilonClosure(startState);
        
        for (char c : input) {
            set<int> nextStates;
            for (int state : currentStates) {
                for (int nextState : getTransitions(state, c)) {
                    nextStates.insert(nextState);
                }
            }
            currentStates = epsilonClosure(nextStates);
        }
        
        for (int state : currentStates) {
            if (isAcceptState(state)) return true;
        }
        return false;
    }
};
```

#### 状态转移表存储方式对比

| 存储方式 | 查找时间 | 空间使用 | 适用场景 | 优缺点 |
|----------|----------|----------|----------|--------|
| **二维数组** | O(1) | O(|Q|×|Σ|) | 状态数少、符号数少 | 快速但浪费空间 |
| **稀疏矩阵** | O(1) | O(实际转移数) | 状态数多、转移稀疏 | 平衡时间和空间 |
| **哈希表** | O(1) | O(实际转移数) | 状态数多、转移稀疏 | 灵活但可能冲突 |

```c
class TransitionTableComparison {
public:
    // 二维数组：快速但浪费空间
    class DenseArrayTable {
    private:
        vector<vector<int>> table;
        
    public:
        int getTransition(int state, int symbol) {
            return table[state][symbol];
        }
        
        void setTransition(int state, int symbol, int nextState) {
            table[state][symbol] = nextState;
        }

            auto key = make_pair(state, symbol);
            auto it = transitions.find(key);
            return (it != transitions.end()) ? it->second : -1;

        }

    public:

            string key = to_string(state) + "," + to_string(symbol);
            auto it = transitions.find(key);
            return (it != transitions.end()) ? it->second : -1;
        }
        
        void setTransition(int state, int symbol, int nextState) {
            string key = to_string(state) + "," + to_string(symbol);
            transitions[key] = nextState;
        }
    };
```

### 正则表达式算法对比

#### Thompson构造 vs Glushkov构造对比

| 特性 | Thompson构造 | Glushkov构造 | 优势分析 |
|------|--------------|--------------|----------|
| **时间复杂度** | O(|r|) | O(|r|²) | Thompson在时间效率上更优 |
| **空间复杂度** | O(|r|) | O(|r|) | 空间复杂度相同 |
| **状态数** | 2|r| | |r|+1 | Glushkov状态数更少 |
| **实现复杂度** | 简单 | 复杂 | Thompson实现更简单 |
| **适用场景** | 简单正则表达式 | 复杂正则表达式 | Thompson适合简单，Glushkov适合复杂 |

```c
// Thompson vs Glushkov构造对比示例
class RegexConstructionComparison {
public:
    // Thompson构造：时间复杂度O(|r|)，状态数2|r|
    NFA thompsonConstruct(const string& regex) {
        stack<NFA> nfaStack;
        
        for (char c : regex) {
            switch (c) {
                case '|':
                    if (nfaStack.size() >= 2) {
                        NFA nfa2 = nfaStack.top(); nfaStack.pop();
                        NFA nfa1 = nfaStack.top(); nfaStack.pop();
                        nfaStack.push(unionNFA(nfa1, nfa2));
                    }
                    break;
                case '*':
                    if (!nfaStack.empty()) {
                        NFA nfa = nfaStack.top(); nfaStack.pop();
                        nfaStack.push(kleeneStar(nfa));
                    }
                    break;
                default:
                    nfaStack.push(singleSymbolNFA(c));
                    break;
            }
        }
        
        return nfaStack.empty() ? NFA() : nfaStack.top();
    }
    
    // Glushkov构造：时间复杂度O(|r|²)，状态数|r|+1
    NFA glushkovConstruct(const string& regex) {
        // 计算位置集合
        set<int> positions = calculatePositions(regex);
        
        // 构建NFA
        NFA nfa;
        int startState = nfa.addState();
        nfa.setStartState(startState);
        
        for (int pos : positions) {
            int state = nfa.addState();
            nfa.addTransition(startState, getSymbolAt(pos), state);
            nfa.addAcceptState(state);
        }
        
        return nfa;
    }
};
```

### 自顶向下分析算法对比

#### LL(1) vs 递归下降对比

| 特性 | LL(1) | 递归下降 | 优势分析 |
|------|-------|----------|----------|
| **时间复杂度** | O(n) | O(n) | 时间复杂度相同 |
| **空间复杂度** | O(n) | O(n) | 空间复杂度相同 |
| **文法限制** | 严格LL(1) | 灵活 | 递归下降更灵活 |
| **错误处理** | 简单 | 复杂 | LL(1)错误处理更简单 |
| **实现难度** | 中等 | 简单 | 递归下降实现更简单 |
| **维护成本** | 低 | 高 | LL(1)维护成本更低 |

```c
// LL(1) vs 递归下降对比示例
class TopDownParserComparison {
public:
    // LL(1)分析：时间复杂度O(n)，空间复杂度O(n)
    class LL1Parser {
    private:
        map<pair<string, string>, Production> parseTable;
        
    public:
        bool parse(const vector<Token>& tokens) {
            stack<string> parseStack;
            parseStack.push("$");
            parseStack.push(startSymbol);
            
            int tokenIndex = 0;
            
            while (!parseStack.empty()) {
                string top = parseStack.top();
                parseStack.pop();
                
                if (top == "$") {
                    return tokenIndex == tokens.size();
                }
                
                if (isTerminal(top)) {
                    if (tokenIndex < tokens.size() && 
                        top == tokens[tokenIndex].type) {
                        tokenIndex++;
                    } else {
                        return false;
                    }
                } else {
                    string lookahead = tokenIndex < tokens.size() ? 
                        tokens[tokenIndex].type : "$";
                    
                    auto key = make_pair(top, lookahead);
                    if (parseTable.find(key) != parseTable.end()) {
                        Production prod = parseTable[key];
                        for (int i = prod.rhs.size() - 1; i >= 0; i--) {
                            parseStack.push(prod.rhs[i]);
                        }
                    } else {
                        return false;
                    }
                }
            }
            
            return false;
        }
    };
    
    // 递归下降分析：时间复杂度O(n)，空间复杂度O(n)
    class RecursiveDescentParser {
    private:
        vector<Token> tokens;
        int currentToken;
        
    public:
        bool parse(const vector<Token>& inputTokens) {
            tokens = inputTokens;
            currentToken = 0;
            
            try {
                parseProgram();
                return currentToken == tokens.size();
            } catch (const ParseError& e) {
                return false;
            }
        }
        
        void parseProgram() {
            while (currentToken < tokens.size()) {
                if (isTypeSpecifier()) {
                    parseDeclaration();
                } else if (isFunctionDefinition()) {
                    parseFunctionDefinition();
                } else {
                    throw ParseError("Expected declaration or function");
                }
            }
        }
    };
};
```

### 自底向上分析算法对比

#### LR算法家族对比

| 特性 | LR(0) | SLR(1) | LR(1) | LALR(1) | 优势分析 |
|------|-------|--------|-------|---------|----------|
| **时间复杂度** | O(n) | O(n) | O(n) | O(n) | 时间复杂度相同 |
| **空间复杂度** | O(n) | O(n) | O(n) | O(n) | 空间复杂度相同 |
| **状态数** | 最少 | 较少 | 最多 | 中等 | LR(0)状态最少，LR(1)最多 |
| **分析能力** | 最弱 | 较弱 | 最强 | 较强 | LR(1)分析能力最强 |
| **实现复杂度** | 简单 | 中等 | 复杂 | 中等 | LR(0)实现最简单 |
| **适用场景** | 简单文法 | 中等文法 | 复杂文法 | 平衡场景 | 根据文法复杂度选择 |

```c
// LR算法家族对比示例
class LRParserComparison {
public:
    // LR(0)分析：状态数最少，分析能力最弱
    class LR0Parser {
    private:
        vector<LR0State> states;
        map<pair<int, string>, Action> actionTable;
        
    public:
        bool parse(const vector<Token>& tokens) {
            stack<int> stateStack;
            stateStack.push(0);
            
            int tokenIndex = 0;
            
            while (tokenIndex < tokens.size()) {
                int currentState = stateStack.top();
                string currentSymbol = tokens[tokenIndex].type;
                
                auto key = make_pair(currentState, currentSymbol);
                if (actionTable.find(key) != actionTable.end()) {
                    Action action = actionTable[key];
                    
                    if (action.type == SHIFT) {
                        stateStack.push(action.state);
                        tokenIndex++;
                    } else if (action.type == REDUCE) {
                        Production prod = action.production;
                        for (int i = 0; i < prod.rhs.size(); i++) {
                            stateStack.pop();
                        }
                        // 处理归约
                    } else if (action.type == ACCEPT) {
                        return true;
                    }
                } else {
                    return false;
                }
            }
            
            return false;
        }
    };
    
    // LR(1)分析：状态数最多，分析能力最强
    class LR1Parser {
    private:
        vector<LR1State> states;
        map<pair<int, string>, Action> actionTable;
        
    public:
        bool parse(const vector<Token>& tokens) {
            stack<int> stateStack;
            stateStack.push(0);
            
            int tokenIndex = 0;
            
            while (tokenIndex < tokens.size()) {
                int currentState = stateStack.top();
                string currentSymbol = tokens[tokenIndex].type;
                
                auto key = make_pair(currentState, currentSymbol);
                if (actionTable.find(key) != actionTable.end()) {
                    Action action = actionTable[key];
                    
                    if (action.type == SHIFT) {
                        stateStack.push(action.state);
                        tokenIndex++;
                    } else if (action.type == REDUCE) {
                        Production prod = action.production;
                        for (int i = 0; i < prod.rhs.size(); i++) {
                            stateStack.pop();
                        }
                        // 处理归约
                    } else if (action.type == ACCEPT) {
                        return true;
                    }
                } else {
                    return false;
                }
            }
            
            return false;
        }
    };
};
```

#### 不同数据结构对比

| 数据结构 | 查找时间 | 插入时间 | 删除时间 | 空间复杂度 | 适用场景 |
|----------|----------|----------|----------|------------|----------|

| **B+树** | O(log n) | O(log n) | O(log n) | O(n) | 大量符号、有序访问 |

```c
// 不同符号表数据结构对比示例
class SymbolTableComparison {
public:
    // 链表：简单但效率低
    class LinkedListSymbolTable {
    private:
        struct SymbolNode {
            string name;
            Symbol symbol;
            SymbolNode* next;
        };
        SymbolNode* head;
        
    public:
        Symbol* lookup(const string& name) {
            SymbolNode* current = head;
            while (current != nullptr) {
                if (current->name == name) {
                    return &current->symbol;
                }
                current = current->next;
            }
            return nullptr;
        }
        
        void insert(const string& name, const Symbol& symbol) {
            SymbolNode* newNode = new SymbolNode{name, symbol, head};
            head = newNode;
        }
    };
    
    // 平衡树：平衡效率和复杂度
    class BalancedTreeSymbolTable {
    private:
        struct TreeNode {
            string name;
            Symbol symbol;
            TreeNode* left;
            TreeNode* right;
            int height;
        };
        TreeNode* root;
        
    public:
        Symbol* lookup(const string& name) {
            return lookupNode(root, name);
        }
        
        Symbol* lookupNode(TreeNode* node, const string& name) {
            if (node == nullptr) return nullptr;
            
            if (name < node->name) {
                return lookupNode(node->left, name);
            } else if (name > node->name) {
                return lookupNode(node->right, name);
            } else {
                return &node->symbol;
            }
        }
        
        void insert(const string& name, const Symbol& symbol) {
            root = insertNode(root, name, symbol);
        }
    };
    
    // 哈希表：快速但可能冲突
    class HashTableSymbolTable {
    private:
        map<string, Symbol> symbolTable;
        
    public:
        Symbol* lookup(const string& name) {
            auto it = symbolTable.find(name);
            return (it != symbolTable.end()) ? &it->second : nullptr;
        }
        
        void insert(const string& name, const Symbol& symbol) {
            symbolTable[name] = symbol;
        }
    };
};
```

```c
public:

    public:

            switch (node->type) {
                case "number":
                    return Type::INT;
                case "string":
                    return Type::STRING;
                case "add":
                case "sub":
                case "mul":
                case "div":
                    return Type::INT; // 简化处理
                default:
                    return Type::UNKNOWN;
            }
        }
    };
    
    // 约束求解：时间复杂度O(n²)，精度高
    class ConstraintSolvingInference {
    private:
        vector<TypeConstraint> constraints;
        
    public:
        Type inferType(ASTNode* node) {
            // 生成约束
            generateConstraints(node);
            
            // 求解约束
            return solveConstraints();
        }
        
        void generateConstraints(ASTNode* node) {
            if (node->type == "add") {
                Type leftType = inferType(node->children[0]);
                Type rightType = inferType(node->children[1]);
                Type resultType = inferType(node);
                
                // 添加约束：leftType + rightType = resultType
                constraints.emplace_back(leftType, rightType, resultType);
            }
        }
        
        Type solveConstraints() {
            // 约束求解算法
            return Type::INT;
        }
    };
    
    // 类型推导：时间复杂度O(n³)，精度最高
    class TypeDerivationInference {
    private:
        map<ASTNode*, Type> nodeTypes;
        map<string, Type> variableTypes;
        
    public:
        Type inferType(ASTNode* node) {
            if (nodeTypes.find(node) != nodeTypes.end()) {
                return nodeTypes[node];
            }
            
            Type type = deriveType(node);
            nodeTypes[node] = type;
            return type;
        }
        
        Type deriveType(ASTNode* node) {
            // 复杂的类型推导算法
            return Type::INT;
        }
    };
};
```
