# 自顶向下分析

## 🎯 自顶向下分析概述

**自顶向下分析**是从开始符号开始，逐步推导到输入字符串的语法分析方法。它通过预测和匹配的方式构建语法分析树。

## 🔍 基本概念

### 推导过程
从开始符号开始，逐步应用产生式，直到得到输入字符串：

```c
// 文法：E → E + T | T, T → T * F | F, F → (E) | id
// 输入：id + id * id

// 推导过程：
E → E + T
  → T + T
  → F + T
  → id + T
  → id + T * F
  → id + F * F
  → id + id * F
  → id + id * id
```

### 预测分析
根据当前非终结符和向前看符号，预测应该使用哪个产生式。

## 🔧 递归下降分析

### 基本思想
为每个非终结符编写一个递归函数，函数内部根据向前看符号选择相应的产生式。

### 实现示例
```c
class RecursiveDescentParser {
private:
    vector<Token> tokens;
    int position;
    Token currentToken;
    
public:
    RecursiveDescentParser(vector<Token> tokens) 
        : tokens(tokens), position(0) {
        currentToken = tokens[0];
    }
    
    ASTNode* parseExpression() {
        // E → T E'
        ASTNode* left = parseTerm();
        return parseExpressionPrime(left);
    }
    
    ASTNode* parseExpressionPrime(ASTNode* left) {
        // E' → + T E' | ε
        if (currentToken.type == PLUS) {
            match(PLUS);
            ASTNode* right = parseTerm();
            ASTNode* node = new BinaryOpNode(PLUS, left, right);
            return parseExpressionPrime(node);
        }
        return left;
    }
    
    ASTNode* parseTerm() {
        // T → F T'
        ASTNode* left = parseFactor();
        return parseTermPrime(left);
    }
    
    ASTNode* parseTermPrime(ASTNode* left) {
        // T' → * F T' | ε
        if (currentToken.type == MULTIPLY) {
            match(MULTIPLY);
            ASTNode* right = parseFactor();
            ASTNode* node = new BinaryOpNode(MULTIPLY, left, right);
            return parseTermPrime(node);
        }
        return left;
    }
    
    ASTNode* parseFactor() {
        // F → (E) | id
        if (currentToken.type == LPAREN) {
            match(LPAREN);
            ASTNode* expr = parseExpression();
            match(RPAREN);
            return expr;
        } else if (currentToken.type == IDENTIFIER) {
            string value = currentToken.value;
            match(IDENTIFIER);
            return new IdentifierNode(value);
        } else {
            error("Expected identifier or '('");
            return nullptr;
        }
    }
    
    void match(TokenType expected) {
        if (currentToken.type == expected) {
            advance();
        } else {
            error("Expected " + tokenTypeToString(expected));
        }
    }
    
    void advance() {
        position++;
        if (position < tokens.size()) {
            currentToken = tokens[position];
        }
    }
    
    void error(string message) {
        cout << "Error: " << message << " at position " << position << endl;
    }
};
```

## 📊 LL分析

### LL(1)分析
LL(1)分析是自顶向下分析的一种，其中：
- **L**：从左到右扫描输入
- **L**：最左推导
- **1**：向前看1个符号

### FIRST集合
FIRST(α)是能够从α推导出的所有字符串的第一个符号的集合：

```c
// 计算FIRST集合
set<TokenType> computeFirst(string production) {
    set<TokenType> first;
    
    if (production.empty()) {
        first.insert(EMPTY);
    } else {
        TokenType firstSymbol = production[0];
        
        if (isTerminal(firstSymbol)) {
            first.insert(firstSymbol);
        } else {
            // 非终结符，递归计算
            first = computeFirstForNonTerminal(firstSymbol);
        }
    }
    
    return first;
}
```

### FOLLOW集合
FOLLOW(A)是可能出现在A后面的所有符号的集合：

```c
// 计算FOLLOW集合
set<TokenType> computeFollow(TokenType nonTerminal) {
    set<TokenType> follow;
    
    // 如果A是开始符号，添加$
    if (nonTerminal == START_SYMBOL) {
        follow.insert(END_OF_INPUT);
    }
    
    // 遍历所有产生式
    for (auto& production : productions) {
        if (production.right.find(nonTerminal) != string::npos) {
            // 找到A在产生式右部的位置
            int pos = production.right.find(nonTerminal);
            string afterA = production.right.substr(pos + 1);
            
            if (afterA.empty()) {
                // A是产生式右部的最后一个符号
                follow.insert(computeFollow(production.left));
            } else {
                // 计算FIRST(afterA)
                set<TokenType> firstAfterA = computeFirst(afterA);
                follow.insert(firstAfterA.begin(), firstAfterA.end());
                
                // 如果FIRST(afterA)包含ε，添加FOLLOW(production.left)
                if (firstAfterA.count(EMPTY)) {
                    follow.insert(computeFollow(production.left));
                }
            }
        }
    }
    
    return follow;
}
```

## 🔄 LL(1)分析表构造

### 分析表
LL(1)分析表是一个二维表，行是非终结符，列是终结符：

```c
class LL1Parser {
private:
    map<pair<TokenType, TokenType>, string> parseTable;
    
public:
    void constructParseTable() {
        for (auto& production : productions) {
            TokenType left = production.left;
            string right = production.right;
            
            set<TokenType> first = computeFirst(right);
            
            for (TokenType terminal : first) {
                if (terminal != EMPTY) {
                    parseTable[{left, terminal}] = right;
                }
            }
            
            if (first.count(EMPTY)) {
                set<TokenType> follow = computeFollow(left);
                for (TokenType terminal : follow) {
                    parseTable[{left, terminal}] = right;
                }
            }
        }
    }
    
    bool parse(vector<Token> tokens) {
        stack<TokenType> parseStack;
        parseStack.push(END_OF_INPUT);
        parseStack.push(START_SYMBOL);
        
        int position = 0;
        
        while (!parseStack.empty()) {
            TokenType top = parseStack.top();
            TokenType current = tokens[position].type;
            
            if (top == current) {
                parseStack.pop();
                position++;
            } else if (isTerminal(top)) {
                error("Mismatch: expected " + tokenTypeToString(top) + 
                      ", found " + tokenTypeToString(current));
                return false;
            } else {
                string production = parseTable[{top, current}];
                if (production.empty()) {
                    error("No production for " + tokenTypeToString(top) + 
                          " and " + tokenTypeToString(current));
                    return false;
                }
                
                parseStack.pop();
                // 将产生式右部逆序压入栈
                for (int i = production.length() - 1; i >= 0; i--) {
                    parseStack.push(production[i]);
                }
            }
        }
        
        return true;
    }
};
```

## 🎯 自顶向下分析特点

### 优点
- **直观易懂**：分析过程直观
- **错误定位**：能够精确定位错误
- **实现简单**：递归下降实现简单

### 缺点
- **左递归问题**：不能处理左递归文法
- **左因子问题**：不能处理左因子
- **效率问题**：可能存在回溯

## 🔧 文法变换

### 消除左递归
将左递归文法转换为右递归文法：

```c
// 原文法（左递归）
// A → Aα | β

// 变换后（右递归）
// A → βA'
// A' → αA' | ε
```

### 消除左因子
提取左因子：

```c
// 原文法
// A → αβ | αγ

// 变换后
// A → αA'
// A' → β | γ
```
