# 语法分析概述

## 🎯 语法分析的作用

**语法分析**是编译过程的第二个阶段，负责根据语法规则分析token序列，构建语法分析树。它是连接词法分析和语义分析的重要桥梁。

## 🔍 基本概念

### 语法分析器
语法分析器是执行语法分析的程序，也称为解析器（Parser）。

### 语法分析树
语法分析树是表示程序语法结构的树形数据结构。

### 语法规则
语法规则定义了语言的语法结构，通常用上下文无关文法表示。

## 📊 语法分析方法分类

### 按分析方向分类

| 方法 | 分析方向 | 特点 | 应用 |
|------|----------|------|------|
| 自顶向下 | 从开始符号推导 | 递归下降、LL分析 | 简单文法 |
| 自底向上 | 从输入符号归约 | LR分析、SLR、LALR | 复杂文法 |

### 按分析能力分类

| 方法 | 分析能力 | 复杂度 | 应用 |
|------|----------|--------|------|
| LL(1) | 向前看1个符号 | 简单 | 简单文法 |
| LR(0) | 无向前看 | 中等 | 简单文法 |
| SLR(1) | 简单LR | 中等 | 中等文法 |
| LR(1) | 完整LR | 复杂 | 复杂文法 |
| LALR(1) | 向前看LR | 中等 | 实用文法 |

## 🔄 语法分析过程

### 输入输出
- **输入**：token序列
- **输出**：语法分析树

### 处理流程


## 🎯 语法分析任务

### 主要任务
1. **语法检查**：检查token序列是否符合语法规则
2. **树构建**：构建语法分析树
3. **错误检测**：检测语法错误
4. **错误恢复**：从语法错误中恢复

### 具体工作
- **识别结构**：识别程序的各种语法结构
- **构建树**：构建表示语法结构的树
- **验证语法**：验证语法的正确性
- **处理错误**：处理语法错误

## 📈 语法分析方法

### 自顶向下分析
从开始符号开始，逐步推导到输入字符串：

```c
// 推导过程
E → E + T → T + T → F + T → id + T → id + F → id + id
```

### 自底向上分析
从输入字符串开始，逐步归约到开始符号：

```c
// 归约过程
id + id → F + id → T + id → T + F → T + T → E + T → E
```

## 🔧 语法分析器实现

### 基本结构
```c
class Parser {
private:
    vector<Token> tokens;
    int position;
    Token currentToken;
    
public:
    Parser(vector<Token> tokens);
    ASTNode* parse();
    ASTNode* parseExpression();
    ASTNode* parseStatement();
    ASTNode* parseDeclaration();
    void advance();
    bool match(TokenType type);
    void error(string message);
};
```

### 核心算法
```c
ASTNode* Parser::parse() {
    ASTNode* root = new ProgramNode();
    
    while (position < tokens.size()) {
        ASTNode* statement = parseStatement();
        if (statement) {
            root->addChild(statement);
        }
    }
    
    return root;
}
```
