# 词法分析器实现

## 🎯 词法分析器设计

**词法分析器**是编译器的第一个组件，负责将源代码转换为token流。它需要高效、准确地识别各种词法单元。

## 🔧 基本结构

### 词法分析器类
```c
class Lexer {
private:
    string source;           // 源代码
    int position;           // 当前位置
    int line;              // 当前行号
    int column;            // 当前列号
    char currentChar;      // 当前字符
    
public:
    Lexer(string source);
    Token getNextToken();
    void advance();
    void skipWhitespace();
    Token readNumber();
    Token readIdentifier();
    Token readString();
    Token readOperator();
    char peek();
    bool isDigit(char c);
    bool isAlpha(char c);
    bool isAlphaNumeric(char c);
};
```

### Token结构
```c
struct Token {
    TokenType type;
    string value;
    int line;
    int column;
    
    Token(TokenType type, string value, int line, int column)
        : type(type), value(value), line(line), column(column) {}
};
```

## 🔄 核心算法

### 主循环
```c
Token Lexer::getNextToken() {
    while (position < source.length()) {
        skipWhitespace();
        
        if (position >= source.length()) {
            return Token(EOF_TOKEN, "", line, column);
        }
        
        currentChar = source[position];
        
        if (isDigit(currentChar)) {
            return readNumber();
        } else if (isAlpha(currentChar) || currentChar == '_') {
            return readIdentifier();
        } else if (currentChar == '"') {
            return readString();
        } else {
            return readOperator();
        }
    }
    
    return Token(EOF_TOKEN, "", line, column);
}
```

### 数字识别
```c
Token Lexer::readNumber() {
    string value = "";
    int startLine = line;
    int startColumn = column;
    
    // 读取整数部分
    while (isDigit(currentChar)) {
        value += currentChar;
        advance();
    }
    
    // 检查是否有小数点
    if (currentChar == '.' && isDigit(peek())) {
        value += currentChar;
        advance();
        
        // 读取小数部分
        while (isDigit(currentChar)) {
            value += currentChar;
            advance();
        }
        
        return Token(FLOAT, value, startLine, startColumn);
    }
    
    return Token(INTEGER, value, startLine, startColumn);
}
```

### 标识符识别
```c
Token Lexer::readIdentifier() {
    string value = "";
    int startLine = line;
    int startColumn = column;
    
    while (isAlphaNumeric(currentChar)) {
        value += currentChar;
        advance();
    }
    
    // 检查是否为关键字
    TokenType type = getKeywordType(value);
    if (type != IDENTIFIER) {
        return Token(type, value, startLine, startColumn);
    }
    
    return Token(IDENTIFIER, value, startLine, startColumn);
}
```

### 字符串识别
```c
Token Lexer::readString() {
    string value = "";
    int startLine = line;
    int startColumn = column;
    
    advance(); // 跳过开始的引号
    
    while (currentChar != '"' && position < source.length()) {
        if (currentChar == '\\') {
            advance();
            if (position < source.length()) {
                switch (currentChar) {
                    case 'n': value += '\n'; break;
                    case 't': value += '\t'; break;
                    case 'r': value += '\r'; break;
                    case '\\': value += '\\'; break;
                    case '"': value += '"'; break;
                    default: value += currentChar; break;
                }
                advance();
            }
        } else {
            value += currentChar;
            advance();
        }
    }
    
    if (currentChar == '"') {
        advance(); // 跳过结束的引号
    }
    
    return Token(STRING, value, startLine, startColumn);
}
```

## 📊 关键字处理

### 关键字表
```c
map<string, TokenType> keywords = {
    {"int", INT},
    {"float", FLOAT},
    {"char", CHAR},
    {"if", IF},
    {"else", ELSE},
    {"while", WHILE},
    {"for", FOR},
    {"return", RETURN},
    {"void", VOID},
    {"struct", STRUCT}
};

TokenType getKeywordType(string value) {
    auto it = keywords.find(value);
    if (it != keywords.end()) {
        return it->second;
    }
    return IDENTIFIER;
}
```

## 🔍 操作符识别

### 操作符表
```c
Token Lexer::readOperator() {
    int startLine = line;
    int startColumn = column;
    
    switch (currentChar) {
        case '+':
            advance();
            return Token(PLUS, "+", startLine, startColumn);
        case '-':
            advance();
            return Token(MINUS, "-", startLine, startColumn);
        case '*':
            advance();
            return Token(MULTIPLY, "*", startLine, startColumn);
        case '/':
            advance();
            return Token(DIVIDE, "/", startLine, startColumn);
        case '=':
            advance();
            if (currentChar == '=') {
                advance();
                return Token(EQUAL, "==", startLine, startColumn);
            }
            return Token(ASSIGN, "=", startLine, startColumn);
        case '!':
            advance();
            if (currentChar == '=') {
                advance();
                return Token(NOT_EQUAL, "!=", startLine, startColumn);
            }
            return Token(NOT, "!", startLine, startColumn);
        case '<':
            advance();
            if (currentChar == '=') {
                advance();
                return Token(LESS_EQUAL, "<=", startLine, startColumn);
            }
            return Token(LESS, "<", startLine, startColumn);
        case '>':
            advance();
            if (currentChar == '=') {
                advance();
                return Token(GREATER_EQUAL, ">=", startLine, startColumn);
            }
            return Token(GREATER, ">", startLine, startColumn);
        case '(':
            advance();
            return Token(LPAREN, "(", startLine, startColumn);
        case ')':
            advance();
            return Token(RPAREN, ")", startLine, startColumn);
        case '{':
            advance();
            return Token(LBRACE, "{", startLine, startColumn);
        case '}':
            advance();
            return Token(RBRACE, "}", startLine, startColumn);
        case ';':
            advance();
            return Token(SEMICOLON, ";", startLine, startColumn);
        case ',':
            advance();
            return Token(COMMA, ",", startLine, startColumn);
        default:
            advance();
            return Token(ERROR, string(1, currentChar), startLine, startColumn);
    }
}
```

## 🎯 错误处理

### 错误类型
```c
enum LexicalError {
    UNKNOWN_CHARACTER,
    UNTERMINATED_STRING,
    INVALID_NUMBER,
    INVALID_ESCAPE
};
```

### 错误处理
```c
void Lexer::handleError(LexicalError error, string message) {
    switch (error) {
        case UNKNOWN_CHARACTER:
            cout << "Error at line " << line << ", column " << column 
                 << ": Unknown character '" << currentChar << "'" << endl;
            break;
        case UNTERMINATED_STRING:
            cout << "Error at line " << line << ", column " << column 
                 << ": Unterminated string" << endl;
            break;
        case INVALID_NUMBER:
            cout << "Error at line " << line << ", column " << column 
                 << ": Invalid number format" << endl;
            break;
        case INVALID_ESCAPE:
            cout << "Error at line " << line << ", column " << column 
                 << ": Invalid escape sequence" << endl;
            break;
    }
}
```
