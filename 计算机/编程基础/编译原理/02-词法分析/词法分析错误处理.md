# 词法分析错误处理

## 🎯 错误处理概述

**词法分析错误处理**是词法分析器的重要组成部分，它需要能够检测、报告和恢复各种词法错误，确保编译过程的连续性。

## 🔍 错误类型

### 常见词法错误

| 错误类型 | 描述 | 示例 |
|----------|------|------|
| 未知字符 | 不在字母表中的字符 | `@`, `#`, `$` |
| 未终止字符串 | 字符串没有结束引号 | `"hello world` |
| 无效数字 | 数字格式错误 | `123.456.789` |
| 无效转义 | 转义序列错误 | `\x`, `\9` |
| 过长标识符 | 标识符长度超限 | `very_long_identifier...` |

### 错误严重程度

| 严重程度 | 处理方式 | 示例 |
|----------|----------|------|
| 致命错误 | 停止编译 | 语法错误 |
| 错误 | 报告并继续 | 词法错误 |
| 警告 | 提示但继续 | 未使用变量 |
| 信息 | 仅记录 | 优化建议 |

## 🔧 错误检测

### 字符验证
```c
bool Lexer::isValidCharacter(char c) {
    return isAlphaNumeric(c) || isOperator(c) || isDelimiter(c) || 
           isWhitespace(c) || c == '"' || c == '\'';
}

void Lexer::validateCharacter(char c) {
    if (!isValidCharacter(c)) {
        handleError(UNKNOWN_CHARACTER, 
                   "Unknown character '" + string(1, c) + "'");
    }
}
```

### 字符串验证
```c
Token Lexer::readString() {
    string value = "";
    int startLine = line;
    int startColumn = column;
    
    advance(); // 跳过开始的引号
    
    while (position < source.length()) {
        if (currentChar == '"') {
            advance(); // 跳过结束的引号
            return Token(STRING, value, startLine, startColumn);
        }
        
        if (currentChar == '\\') {
            advance();
            if (position >= source.length()) {
                handleError(INVALID_ESCAPE, "Incomplete escape sequence");
                break;
            }
            
            char escaped = getEscapedChar(currentChar);
            if (escaped == '\0') {
                handleError(INVALID_ESCAPE, 
                           "Invalid escape sequence '\\" + string(1, currentChar) + "'");
            }
            value += escaped;
        } else {
            value += currentChar;
        }
        
        advance();
    }
    
    // 如果到达文件末尾仍未找到结束引号
    handleError(UNTERMINATED_STRING, "Unterminated string");
    return Token(ERROR, value, startLine, startColumn);
}
```

### 数字验证
```c
Token Lexer::readNumber() {
    string value = "";
    int startLine = line;
    int startColumn = column;
    
    // 读取整数部分
    while (isDigit(currentChar)) {
        value += currentChar;
        advance();
    }
    
    // 检查是否有小数点
    if (currentChar == '.') {
        value += currentChar;
        advance();
        
        if (!isDigit(currentChar)) {
            handleError(INVALID_NUMBER, "Expected digit after decimal point");
            return Token(ERROR, value, startLine, startColumn);
        }
        
        // 读取小数部分
        while (isDigit(currentChar)) {
            value += currentChar;
            advance();
        }
        
        return Token(FLOAT, value, startLine, startColumn);
    }
    
    return Token(INTEGER, value, startLine, startColumn);
}
```

## 📊 错误报告

### 错误信息格式
```c
struct ErrorInfo {
    ErrorType type;
    string message;
    int line;
    int column;
    string context;
    
    ErrorInfo(ErrorType type, string message, int line, int column, string context)
        : type(type), message(message), line(line), column(column), context(context) {}
};
```

### 错误报告器
```c
class ErrorReporter {
private:
    vector<ErrorInfo> errors;
    int maxErrors;
    
public:
    ErrorReporter(int maxErrors = 100) : maxErrors(maxErrors) {}
    
    void reportError(ErrorType type, string message, int line, int column, string context = "") {
        if (errors.size() >= maxErrors) {
            return;
        }
        
        errors.push_back(ErrorInfo(type, message, line, column, context));
        
        // 立即输出错误信息
        cout << "Error at line " << line << ", column " << column 
             << ": " << message << endl;
        
        if (!context.empty()) {
            cout << "Context: " << context << endl;
        }
    }
    
    bool hasErrors() const {
        return !errors.empty();
    }
    
    int getErrorCount() const {
        return errors.size();
    }
    
    void printSummary() {
        cout << "Total errors: " << errors.size() << endl;
    }
};
```

## 🔄 错误恢复

### 恢复策略

| 策略 | 描述 | 适用场景 |
|------|------|----------|
| 跳过字符 | 跳过错误字符继续 | 未知字符 |
| 插入字符 | 插入缺失字符 | 缺失引号 |
| 删除字符 | 删除多余字符 | 多余字符 |
| 替换字符 | 替换错误字符 | 拼写错误 |

### 恢复实现
```c
Token Lexer::getNextToken() {
    while (position < source.length()) {
        skipWhitespace();
        
        if (position >= source.length()) {
            return Token(EOF_TOKEN, "", line, column);
        }
        
        currentChar = source[position];
        
        try {
            if (isDigit(currentChar)) {
                return readNumber();
            } else if (isAlpha(currentChar) || currentChar == '_') {
                return readIdentifier();
            } else if (currentChar == '"') {
                return readString();
            } else if (isOperator(currentChar)) {
                return readOperator();
            } else {
                // 未知字符，尝试恢复
                return handleUnknownCharacter();
            }
        } catch (LexicalError& error) {
            // 错误恢复
            recoverFromError(error);
            continue;
        }
    }
    
    return Token(EOF_TOKEN, "", line, column);
}

Token Lexer::handleUnknownCharacter() {
    int startLine = line;
    int startColumn = column;
    char unknownChar = currentChar;
    
    // 报告错误
    errorReporter.reportError(UNKNOWN_CHARACTER, 
                             "Unknown character '" + string(1, unknownChar) + "'",
                             startLine, startColumn);
    
    // 跳过未知字符
    advance();
    
    // 返回错误token
    return Token(ERROR, string(1, unknownChar), startLine, startColumn);
}

void Lexer::recoverFromError(LexicalError error) {
    switch (error.type) {
        case UNTERMINATED_STRING:
            // 尝试找到下一个引号或行尾
            while (position < source.length() && currentChar != '"' && currentChar != '\n') {
                advance();
            }
            if (currentChar == '"') {
                advance();
            }
            break;
            
        case INVALID_NUMBER:
            // 跳过无效数字
            while (position < source.length() && 
                   (isDigit(currentChar) || currentChar == '.')) {
                advance();
            }
            break;
            
        case INVALID_ESCAPE:
            // 跳过转义序列
            advance();
            break;
            
        default:
            // 默认恢复：跳过当前字符
            advance();
            break;
    }
}
```

## 🎯 错误处理最佳实践

### 设计原则
- **快速失败**：尽早检测错误
- **清晰报告**：提供有用的错误信息
- **优雅恢复**：尽可能继续编译
- **错误限制**：限制错误数量

### 实现建议
- **错误上下文**：提供错误周围的代码
- **建议修复**：提供修复建议
- **错误分类**：按严重程度分类
- **统计信息**：提供错误统计
