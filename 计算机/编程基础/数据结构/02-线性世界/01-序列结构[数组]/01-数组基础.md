# 🔢 数组基础

## 🎯 核心定义

**数组**是一种线性数据结构，由相同类型的元素按顺序排列组成，通过索引访问元素。

### 🔍 本质理解
数组 = 连续内存 + 相同类型 + 索引访问

```mermaid
graph TD
    A[数组] --> B[连续内存]
    A --> C[相同类型]
    A --> D[索引访问]
    A --> E[固定大小]
    
    B --> B1[物理连续]
    B --> B2[地址计算]
    B --> B3[缓存友好]
    
    C --> C1[int数组]
    C --> C2[char数组]
    C --> C3[对象数组]
    
    D --> D1[随机访问]
    D --> D2[O(1)时间复杂度]
    D --> D3[索引范围]
    
    E --> E1[静态分配]
    E --> E2[空间固定]
    E --> E3[内存效率]
```

## 🏗️ 数组的基本特性

### 📊 特性对比表

| 特性 | 描述 | 优势 | 劣势 |
|------|------|------|------|
| **连续存储** | 元素在内存中连续存放 | 缓存友好、访问快速 | 内存碎片问题 |
| **相同类型** | 所有元素类型相同 | 类型安全、计算简单 | 灵活性受限 |
| **固定大小** | 创建时确定大小 | 内存管理简单 | 大小不可变 |
| **索引访问** | 通过下标直接访问 | O(1)时间复杂度 | 需要边界检查 |

### 🎯 内存布局

#### 📊 一维数组
```
内存地址: [1000] [1004] [1008] [1012] [1016]
数组索引:   0      1      2      3      4
数组元素:  [10]   [20]   [30]   [40]   [50]
```

**地址计算公式：**
`address[i] = base_address + i × element_size`

#### 📊 二维数组
```
内存地址: [1000] [1004] [1008] [1012] [1016] [1020] [1024] [1028] [1032]
数组索引: (0,0)  (0,1)  (0,2)  (1,0)  (1,1)  (1,2)  (2,0)  (2,1)  (2,2)
数组元素:  [1]    [2]    [3]    [4]    [5]    [6]    [7]    [8]    [9]
```

**地址计算公式：**
`address[i][j] = base_address + (i × cols + j) × element_size`

## 💻 数组操作实现

### 🔧 基本操作

#### 📋 操作接口
```cpp
template<typename T>
class Array {
private:
    T* data;           // 数据指针
    int size;          // 数组大小
    int capacity;      // 数组容量
    
public:
    // 构造和析构
    Array(int capacity);
    ~Array();
    
    // 基本操作
    T get(int index) const;
    void set(int index, const T& value);
    void insert(int index, const T& value);
    void remove(int index);
    
    // 查询操作
    int size() const;
    bool isEmpty() const;
    int find(const T& value) const;
    
    // 工具操作
    void print() const;
    void clear();
};
```

#### 🎯 核心操作实现

##### 📖 访问操作
```cpp
template<typename T>
T Array<T>::get(int index) const {
    if (index < 0 || index >= size) {
        throw std::out_of_range("Index out of range");
    }
    return data[index];
}

template<typename T>
void Array<T>::set(int index, const T& value) {
    if (index < 0 || index >= size) {
        throw std::out_of_range("Index out of range");
    }
    data[index] = value;
}
```

##### ➕ 插入操作
```cpp
template<typename T>
void Array<T>::insert(int index, const T& value) {
    if (index < 0 || index > size) {
        throw std::out_of_range("Index out of range");
    }
    
    if (size >= capacity) {
        resize();  // 扩容
    }
    
    // 从后往前移动元素
    for (int i = size; i > index; i--) {
        data[i] = data[i - 1];
    }
    
    data[index] = value;
    size++;
}
```

##### ➖ 删除操作
```cpp
template<typename T>
void Array<T>::remove(int index) {
    if (index < 0 || index >= size) {
        throw std::out_of_range("Index out of range");
    }
    
    // 从前往后移动元素
    for (int i = index; i < size - 1; i++) {
        data[i] = data[i + 1];
    }
    
    size--;
}
```

## 📊 数组操作复杂度分析

### ⏱️ 时间复杂度分析

| 操作 | 时间复杂度 | 说明 | 示例 |
|------|------------|------|------|
| **访问** | O(1) | 直接通过索引访问 | `arr[i]` |
| **搜索** | O(n) | 需要遍历查找 | 线性搜索 |
| **插入** | O(n) | 需要移动后续元素 | 在中间插入 |
| **删除** | O(n) | 需要移动后续元素 | 删除中间元素 |
| **更新** | O(1) | 直接修改指定位置 | `arr[i] = value` |

### 💾 空间复杂度分析

| 方面 | 空间复杂度 | 说明 |
|------|------------|------|
| **存储空间** | O(n) | n个元素需要n个存储单元 |
| **额外空间** | O(1) | 除存储空间外无额外开销 |
| **内存利用率** | 100% | 无指针等额外开销 |

## 🎯 数组应用场景

### 📋 适用场景

#### ✅ 适合使用数组的情况
1. **随机访问频繁**：需要频繁通过索引访问元素
2. **数据量固定**：数据大小在创建时确定
3. **内存效率要求高**：需要最小的内存开销
4. **缓存友好**：需要良好的缓存局部性

#### ❌ 不适合使用数组的情况
1. **频繁插入删除**：中间位置插入删除效率低
2. **大小不确定**：数据量变化较大
3. **类型多样化**：需要存储不同类型的数据
4. **内存碎片敏感**：连续内存分配困难

### 🎯 典型应用

#### 🔢 数值计算
- **矩阵运算**：二维数组存储矩阵
- **图像处理**：像素数据存储
- **科学计算**：向量和矩阵运算

#### 🎮 游戏开发
- **地图数据**：游戏地图的网格表示
- **角色属性**：固定数量的属性数组
- **粒子系统**：粒子位置和属性数组

#### 💾 系统编程
- **缓冲区**：网络数据缓冲区
- **查找表**：预计算的查找表
- **状态机**：状态转换表

## 🔄 数组变种

### 📊 动态数组

#### 🎯 定义
动态数组（Vector）是大小可变的数组，支持自动扩容。

#### 💻 实现要点
```cpp
template<typename T>
class DynamicArray {
private:
    T* data;
    int size;
    int capacity;
    
    void resize() {
        capacity *= 2;  // 扩容策略
        T* newData = new T[capacity];
        for (int i = 0; i < size; i++) {
            newData[i] = data[i];
        }
        delete[] data;
        data = newData;
    }
    
public:
    void push_back(const T& value) {
        if (size >= capacity) {
            resize();
        }
        data[size++] = value;
    }
};
```

#### 📈 性能分析
- **扩容策略**：通常按2倍扩容
- **摊还复杂度**：插入操作O(1)摊还时间
- **空间开销**：最多浪费50%空间

### 📊 多维数组

#### 🎯 二维数组
```cpp
// 静态二维数组
int matrix[3][4];

// 动态二维数组
int** matrix = new int*[3];
for (int i = 0; i < 3; i++) {
    matrix[i] = new int[4];
}

// 一维数组模拟二维数组
int* matrix = new int[3 * 4];
// 访问 matrix[i][j] 等价于 matrix[i * 4 + j]
```

#### 🎯 三维数组
```cpp
// 静态三维数组
int cube[3][4][5];

// 动态三维数组
int*** cube = new int**[3];
for (int i = 0; i < 3; i++) {
    cube[i] = new int*[4];
    for (int j = 0; j < 4; j++) {
        cube[i][j] = new int[5];
    }
}
```

### 🔍 常见错误

#### ❌ 常见错误
1. **越界访问**：访问超出数组范围的索引
2. **内存泄漏**：动态数组忘记释放内存
3. **类型不匹配**：数组元素类型不一致
4. **大小错误**：数组大小计算错误

#### ✅ 最佳实践
1. **边界检查**：始终检查数组边界
2. **内存管理**：及时释放动态分配的内存
3. **类型安全**：使用模板确保类型安全
4. **异常处理**：处理数组操作异常
