# ⏱️ 时间复杂度详解

## 🎯 核心定义

**时间复杂度**是算法执行时间随输入规模增长的变化规律，用大O记号表示算法在最坏情况下的时间效率。

### 🔍 本质理解
时间复杂度 = 基本操作次数 × 基本操作时间

```mermaid
graph TD
    A[时间复杂度] --> B[基本操作]
    A --> C[输入规模]
    A --> D[增长规律]
    
    B --> B1[比较操作]
    B --> B2[赋值操作]
    B --> B3[算术运算]
    
    C --> C1[数组长度n]
    C --> C2[节点数量n]
    C --> C3[数据量n]
    
    D --> D1[常数O(1)]
    D --> D2[对数O(log n)]
    D --> D3[线性O(n)]
    D --> D4[平方O(n²)]
```

## 📊 常见时间复杂度

### 🚀 时间复杂度等级

| 复杂度 | 名称 | 描述 | 典型算法 | 性能评价 |
|--------|------|------|----------|----------|
| **O(1)** | 常数时间 | 执行时间固定 | 数组访问、哈希查找 | ⭐⭐⭐⭐⭐ 优秀 |
| **O(log n)** | 对数时间 | 执行时间对数增长 | 二分查找、平衡树 | ⭐⭐⭐⭐ 很好 |
| **O(n)** | 线性时间 | 执行时间线性增长 | 线性查找、遍历 | ⭐⭐⭐ 良好 |
| **O(n log n)** | 线性对数 | 执行时间线性对数增长 | 快速排序、归并排序 | ⭐⭐⭐ 良好 |
| **O(n²)** | 平方时间 | 执行时间平方增长 | 冒泡排序、选择排序 | ⭐⭐ 一般 |
| **O(2ⁿ)** | 指数时间 | 执行时间指数增长 | 递归斐波那契、汉诺塔 | ⭐ 较差 |

## 🔍 时间复杂度分析方法

### 📋 分析步骤

#### 1️⃣ 识别基本操作
- **比较操作**：if (a > b)
- **赋值操作**：a = b
- **算术运算**：a + b, a * b
- **函数调用**：function()

#### 2️⃣ 计算操作次数
- **循环分析**：分析循环次数
- **递归分析**：分析递归深度和每层操作
- **条件分析**：分析条件分支

#### 3️⃣ 确定增长规律
- **最高次项**：忽略低次项和常数
- **系数忽略**：忽略常数系数
- **最坏情况**：考虑最坏情况

### 🎯 分析示例

#### 📊 线性查找算法
```cpp
int linearSearch(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {        // 循环n次
        if (arr[i] == target) {           // 比较操作
            return i;                    // 返回操作
        }
    }
    return -1;                           // 返回操作
}
```

**分析过程：**
1. **基本操作**：比较操作 `arr[i] == target`
2. **循环次数**：最多n次
3. **时间复杂度**：O(n)

#### 🔍 二分查找算法
```cpp
int binarySearch(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    while (left <= right) {              // 循环log n次
        int mid = (left + right) / 2;    // 算术运算
        if (arr[mid] == target) {        // 比较操作
            return mid;                  // 返回操作
        } else if (arr[mid] < target) {  // 比较操作
            left = mid + 1;              // 赋值操作
        } else {
            right = mid - 1;             // 赋值操作
        }
    }
    return -1;                           // 返回操作
}
```

**分析过程：**
1. **基本操作**：比较操作 `arr[mid] == target`
2. **循环次数**：每次搜索空间减半，最多log₂n次
3. **时间复杂度**：O(log n)

#### 🔄 冒泡排序算法
```cpp
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {           // 外层循环n-1次
        for (int j = 0; j < n - i - 1; j++) {   // 内层循环n-i-1次
            if (arr[j] > arr[j + 1]) {          // 比较操作
                swap(arr[j], arr[j + 1]);       // 交换操作
            }
        }
    }
}
```

**分析过程：**
1. **基本操作**：比较操作 `arr[j] > arr[j + 1]`
2. **循环次数**：外层n-1次，内层最多n-1次
3. **总操作次数**：(n-1) + (n-2) + ... + 1 = n(n-1)/2
4. **时间复杂度**：O(n²)

## 🎯 特殊情况分析

### 🔄 递归算法分析

#### 📊 递归关系式
递归算法的时间复杂度通常通过递归关系式求解：

**示例：斐波那契数列**
```cpp
int fibonacci(int n) {
    if (n <= 1) return n;                    // 基本情况O(1)
    return fibonacci(n-1) + fibonacci(n-2); // 递归调用
}
```

**递归关系式：**
T(n) = T(n-1) + T(n-2) + O(1)

**求解过程：**
- 展开递归：T(n) = 2T(n-1) + O(1)
- 继续展开：T(n) = 2²T(n-2) + 2O(1) + O(1)
- 最终得到：T(n) = O(2ⁿ)

#### 🎯 主定理应用
对于形如 T(n) = aT(n/b) + f(n) 的递归关系式：

| 情况 | 条件 | 时间复杂度 |
|------|------|------------|
| **情况1** | f(n) = O(n^c), c < log_b(a) | T(n) = Θ(n^log_b(a)) |
| **情况2** | f(n) = Θ(n^log_b(a)) | T(n) = Θ(n^log_b(a) log n) |
| **情况3** | f(n) = Ω(n^c), c > log_b(a) | T(n) = Θ(f(n)) |

### 🔄 平均情况分析

#### 📊 概率分析
某些算法的平均时间复杂度需要考虑输入分布：

**示例：快速排序**
- **最坏情况**：O(n²) - 每次选择的基准都是最大或最小值
- **最好情况**：O(n log n) - 每次选择的基准都是中位数
- **平均情况**：O(n log n) - 随机选择基准

#### 🎯 期望分析
```cpp
int quickSelect(int arr[], int left, int right, int k) {
    if (left == right) return arr[left];
    
    int pivotIndex = partition(arr, left, right);  // O(n)
    
    if (k == pivotIndex) {
        return arr[k];
    } else if (k < pivotIndex) {
        return quickSelect(arr, left, pivotIndex - 1, k);  // 期望O(n/2)
    } else {
        return quickSelect(arr, pivotIndex + 1, right, k); // 期望O(n/2)
    }
}
```

**期望分析：**
- 每次递归期望减少一半元素
- 期望递归深度：O(log n)
- 每层期望操作：O(n)
- 期望时间复杂度：O(n)

## 🎯 实际应用考虑

### ⚡ 性能优化策略

#### 📊 算法选择
| 数据规模 | 推荐复杂度 | 原因 | 典型应用 |
|----------|------------|------|----------|
| **小规模(n<100)** | O(n²) | 常数小，实现简单 | 小数组排序 |
| **中等规模(100<n<10000)** | O(n log n) | 平衡效率和实现 | 一般排序 |
| **大规模(n>10000)** | O(n)或O(log n) | 效率优先 | 大数据处理 |

#### 🔄 优化技巧
1. **减少循环嵌套**：将O(n²)优化为O(n)
2. **使用数据结构**：用哈希表将O(n)优化为O(1)
3. **分治策略**：将大问题分解为小问题
4. **动态规划**：避免重复计算

### 📈 性能测试

#### 🧪 测试方法
```cpp
#include <chrono>
#include <iostream>

void performanceTest() {
    const int n = 10000;
    int arr[n];
    
    // 初始化数组
    for (int i = 0; i < n; i++) {
        arr[i] = rand() % 1000;
    }
    
    // 测试线性查找
    auto start = std::chrono::high_resolution_clock::now();
    linearSearch(arr, n, 999);
    auto end = std::chrono::high_resolution_clock::now();
    
    auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    std::cout << "Linear search time: " << duration.count() << " microseconds" << std::endl;
}
```

#### 📊 性能对比
| 算法 | 时间复杂度 | 实际测试时间(ms) | 相对性能 |
|------|------------|------------------|----------|
| **线性查找** | O(n) | 0.5 | 基准 |
| **二分查找** | O(log n) | 0.01 | 50倍快 |
| **哈希查找** | O(1) | 0.001 | 500倍快 |
