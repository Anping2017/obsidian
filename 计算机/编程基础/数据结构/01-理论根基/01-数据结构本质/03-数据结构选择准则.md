# 数据结构选择准则

## 📖 核心概念

**数据结构选择准则**是解决实际问题的关键技能。正确的数据结构选择能够显著提升程序性能，降低开发复杂度。

### 🏗️ 选择决策树

```mermaid
graph TD
    A[需要什么操作?] --> B{主要操作}
    
    B -->|查找| C{查找频率}
    C -->|频繁| D[哈希表/平衡树]
    C -->|偶尔| E[线性结构]
    
    B -->|插入删除| F{操作位置}
    F -->|任意位置| G[链表]
    F -->|两端| H[栈/队列]
    F -->|有序插入| I[平衡树]
    
    B -->|排序| J[堆/平衡树]
    B -->|遍历| K[图结构]
    
    D --> D1[哈希表: O(1)]
    D --> D2[平衡树: O(log n)]
    
    G --> G1[单链表: O(1)]
    G --> G2[双链表: O(1)]
```

## 🎯 选择维度分析

### 1. 操作特性维度

| 操作类型 | 频率 | 推荐结构 | 时间复杂度 | 空间复杂度 |
|----------|------|----------|------------|------------|
| **随机查找** | 高 | 哈希表 | O(1) | O(n) |
| **有序查找** | 高 | 平衡树 | O(log n) | O(n) |
| **顺序查找** | 低 | 数组/链表 | O(n) | O(n) |
| **频繁插入** | 任意位置 | 链表 | O(1) | O(n) |
| **频繁删除** | 任意位置 | 链表 | O(1) | O(n) |
| **排序维护** | 持续 | 堆/平衡树 | O(log n) | O(n) |

### 2. 数据规模维度

```cpp
// 小规模数据 (< 1000)
vector<int> smallData;  // 简单数组

// 中规模数据 (1000 - 10000)
set<int> mediumData;    // 平衡树

// 大规模数据 (> 10000)
unordered_map<string, int> largeData;  // 哈希表
```

### 3. 内存约束维度

| 内存情况 | 推荐结构 | 原因 |
|----------|----------|------|
| **内存充足** | 哈希表 | 最快访问 |
| **内存受限** | 链表 | 动态分配 |
| **内存紧张** | 数组 | 连续存储 |
| **缓存友好** | 数组 | 局部性原理 |

## 🔍 具体场景分析

### 场景1：用户管理系统

```cpp
// 需求：频繁按ID查找用户
class UserManager {
private:
    unordered_map<int, User> users;  // 哈希表：O(1)查找
    
public:
    User* findUser(int id) {
        auto it = users.find(id);
        return (it != users.end()) ? &it->second : nullptr;
    }
};
```

### 场景2：任务调度系统

```cpp
// 需求：按优先级调度任务
class TaskScheduler {
private:
    priority_queue<Task> tasks;  // 堆：自动排序
    
public:
    void addTask(Task task) {
        tasks.push(task);  // O(log n)
    }
    
    Task getNextTask() {
        Task task = tasks.top();
        tasks.pop();  // O(log n)
        return task;
    }
};
```

### 场景3：文件系统目录

```cpp
// 需求：层次结构，支持路径查找
class Directory {
private:
    unordered_map<string, Directory*> children;  // 哈希表：快速子目录查找
    string name;
    
public:
    Directory* findChild(string name) {
        auto it = children.find(name);
        return (it != children.end()) ? it->second : nullptr;
    }
};
```

|----------|----------|----------|----------|----------|

## 🎯 选择决策流程

### 步骤1：分析需求

```cpp
// 1. 确定主要操作
enum OperationType {
    SEARCH_DOMINANT,    // 查找为主
    INSERT_DELETE_DOMINANT,  // 插入删除为主
    SORT_DOMINANT,      // 排序为主
    TRAVERSE_DOMINANT   // 遍历为主
};
```

### 步骤2：评估约束

```cpp
// 2. 评估系统约束
struct Constraints {
    size_t maxMemory;      // 内存限制
    size_t expectedSize;   // 预期数据规模
    double searchRatio;    // 查找操作比例
    double insertRatio;    // 插入操作比例
};
```

### 步骤3：选择结构

```cpp
// 3. 根据约束选择
DataStructure selectStructure(const Constraints& constraints) {
    if (constraints.searchRatio > 0.7) {
        return constraints.maxMemory > 100MB ? 
               HASH_TABLE : BALANCED_TREE;
    }
    if (constraints.insertRatio > 0.5) {
        return LINKED_LIST;
    }
    return ARRAY;
}
```
