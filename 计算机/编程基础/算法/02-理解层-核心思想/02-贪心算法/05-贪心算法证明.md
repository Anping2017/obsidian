    # 2. 归纳假设：假设对n=k个活动，贪心算法正确

    # 2. 设O是S的最优解
    # 3. 如果O不包含a1，可以用a1替换O中的某个活动
    # 4. 因此可以假设O包含a1
    # 5. 那么O-{a1}是S'的解
    # 6. 由于A'是S'的贪心解，|A'| >= |O-{a1}|
    # 7. 因此|A| = |A'| + 1 >= |O-{a1}| + 1 = |O|
