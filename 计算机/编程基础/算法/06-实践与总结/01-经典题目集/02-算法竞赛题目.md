### 基础题目

#### 1. 最大子数组和
**题目描述**：给定一个整数数组，找出其中最大和的连续子数组。

**解题思路**：
- 使用动态规划
- 维护当前最大和
- 时间复杂度：O(n)，空间复杂度：O(1)

**代码实现**：
```python
def max_subarray_sum(nums):
    """最大子数组和"""
    if not nums:
        return 0
    
    max_sum = current_sum = nums[0]
    
    for i in range(1, len(nums)):
        current_sum = max(nums[i], current_sum + nums[i])
        max_sum = max(max_sum, current_sum)
    
    return max_sum
```

#### 2. 最长公共子序列
**题目描述**：给定两个字符串，找出它们的最长公共子序列。

**解题思路**：
- 使用动态规划
- 二维状态转移
- 时间复杂度：O(mn)，空间复杂度：O(mn)

**代码实现**：
```python
def longest_common_subsequence(text1, text2):
    """最长公共子序列"""
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    
    return dp[m][n]
```

#### 3. 最短路径
**题目描述**：给定一个带权图，找出从起点到终点的最短路径。

**解题思路**：
- 使用Dijkstra算法
- 优先队列优化
- 时间复杂度：O((V + E) log V)，空间复杂度：O(V)

**代码实现**：
```python
import heapq

def dijkstra(graph, start, end):
    """Dijkstra算法"""
    n = len(graph)
    distances = [float('inf')] * n
    distances[start] = 0
    pq = [(0, start)]
    
    while pq:
        dist, u = heapq.heappop(pq)
        
        if u == end:
            return dist
        
        if dist > distances[u]:
            continue
        
        for v, weight in graph[u]:
            new_dist = dist + weight
            if new_dist < distances[v]:
                distances[v] = new_dist
                heapq.heappush(pq, (new_dist, v))
    
    return -1
```

### 中等题目

#### 1. 最小生成树
**题目描述**：给定一个带权图，找出连接所有顶点的最小生成树。

**解题思路**：
- 使用Kruskal算法
- 并查集优化
- 时间复杂度：O(E log E)，空间复杂度：O(V)

**代码实现**：
```python
def kruskal(graph):
    """Kruskal算法"""
    n = len(graph)
    edges = []
    
    for u in range(n):
        for v, weight in graph[u]:
            if u < v:  # 避免重复边
                edges.append((weight, u, v))
    
    edges.sort()
    
    parent = list(range(n))
    
    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]
    
    def union(x, y):
        px, py = find(x), find(y)
        if px != py:
            parent[px] = py
            return True
        return False
    
    mst = []
    total_weight = 0
    
    for weight, u, v in edges:
        if union(u, v):
            mst.append((u, v, weight))
            total_weight += weight
            if len(mst) == n - 1:
                break
    
    return mst, total_weight
```

#### 2. 网络流
**题目描述**：给定一个网络，计算从源点到汇点的最大流。

**解题思路**：
- 使用Edmonds-Karp算法
- BFS找增广路径
- 时间复杂度：O(V * E²)，空间复杂度：O(V)

**代码实现**：
```python
from collections import deque

def edmonds_karp(graph, source, sink):
    """Edmonds-Karp算法"""
    n = len(graph)
    residual_graph = [row[:] for row in graph]
    max_flow = 0
    
    def bfs(start, end):
        parent = [-1] * n
        queue = deque([start])
        parent[start] = start
        
        while queue:
            u = queue.popleft()
            for v in range(n):
                if parent[v] == -1 and residual_graph[u][v] > 0:
                    parent[v] = u
                    queue.append(v)
                    if v == end:
                        break
        
        if parent[end] == -1:
            return [], 0
        
        path = []
        min_capacity = float('inf')
        v = end
        while v != start:
            path.append(v)
            u = parent[v]
            min_capacity = min(min_capacity, residual_graph[u][v])
            v = u
        path.append(start)
        path.reverse()
        
        return path, min_capacity
    
    while True:
        path, min_capacity = bfs(source, sink)
        if not path:
            break
        
        for i in range(len(path) - 1):
            u, v = path[i], path[i + 1]
            residual_graph[u][v] -= min_capacity
            residual_graph[v][u] += min_capacity
        
        max_flow += min_capacity
    
    return max_flow
```

#### 3. 线段树
**题目描述**：实现线段树，支持区间查询和区间更新。

**解题思路**：
- 使用线段树数据结构
- 递归构建和查询
- 时间复杂度：O(log n)，空间复杂度：O(n)

**代码实现**：
```python
class SegmentTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)
        self.build(arr, 0, 0, self.n - 1)
    
    def build(self, arr, node, start, end):
        if start == end:
            self.tree[node] = arr[start]
        else:
            mid = (start + end) // 2
            self.build(arr, 2 * node + 1, start, mid)
            self.build(arr, 2 * node + 2, mid + 1, end)
            self.tree[node] = self.tree[2 * node + 1] + self.tree[2 * node + 2]
    
    def update_range(self, node, start, end, l, r, val):
        if self.lazy[node] != 0:
            self.tree[node] += (end - start + 1) * self.lazy[node]
            if start != end:
                self.lazy[2 * node + 1] += self.lazy[node]
                self.lazy[2 * node + 2] += self.lazy[node]
            self.lazy[node] = 0
        
        if start > end or start > r or end < l:
            return
        
        if start >= l and end <= r:
            self.tree[node] += (end - start + 1) * val
            if start != end:
                self.lazy[2 * node + 1] += val
                self.lazy[2 * node + 2] += val
        else:
            mid = (start + end) // 2
            self.update_range(2 * node + 1, start, mid, l, r, val)
            self.update_range(2 * node + 2, mid + 1, end, l, r, val)
            self.tree[node] = self.tree[2 * node + 1] + self.tree[2 * node + 2]
    
    def query_range(self, node, start, end, l, r):
        if start > end or start > r or end < l:
            return 0
        
        if self.lazy[node] != 0:
            self.tree[node] += (end - start + 1) * self.lazy[node]
            if start != end:
                self.lazy[2 * node + 1] += self.lazy[node]
                self.lazy[2 * node + 2] += self.lazy[node]
            self.lazy[node] = 0
        
        if start >= l and end <= r:
            return self.tree[node]
        
        mid = (start + end) // 2
        left = self.query_range(2 * node + 1, start, mid, l, r)
        right = self.query_range(2 * node + 2, mid + 1, end, l, r)
        return left + right
```

### 困难题目

#### 1. 动态规划优化
**题目描述**：给定一个序列，找出最长递增子序列。

**解题思路**：
- 使用动态规划
- 二分查找优化
- 时间复杂度：O(n log n)，空间复杂度：O(n)

**代码实现**：
```python
def longest_increasing_subsequence(nums):
    """最长递增子序列"""
    if not nums:
        return 0
    
    tails = []
    
    for num in nums:
        left, right = 0, len(tails)
        while left < right:
            mid = (left + right) // 2
            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid
        
        if left == len(tails):
            tails.append(num)
        else:
            tails[left] = num
    
    return len(tails)
```

#### 2. 数论算法
**题目描述**：计算大数的模幂运算。

**解题思路**：
- 使用快速幂算法
- 二进制分解
- 时间复杂度：O(log n)，空间复杂度：O(1)

**代码实现**：
```python
def fast_power(base, exponent, modulus):
    """快速幂"""
    result = 1
    base = base % modulus
    
    while exponent > 0:
        if exponent % 2 == 1:
            result = (result * base) % modulus
        
        base = (base * base) % modulus
        exponent //= 2
    
    return result
```
