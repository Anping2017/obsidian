#### 2. 滑动窗口技巧
**核心思想**：维护一个动态窗口来解决问题

**代表题目**：
- 无重复字符的最长子串（Medium）
- 最多K个不同字符的子串（Medium）
- 长度最小的子数组（Medium）
- 最小覆盖子串（Hard）
- 字符串的排列（Medium）
- 水果成篮（Medium）

**解题模板**：
```python
def sliding_window_template(s):
    """滑动窗口模板"""
    left = 0
    window = {}
    
    for right in range(len(s)):
        # 扩大窗口
        window[s[right]] = window.get(s[right], 0) + 1
        
        # 收缩窗口
        while condition:
            window[s[left]] -= 1
            if window[s[left]] == 0:
                del window[s[left]]
            left += 1
        
        # 更新结果
        result = max(result, right - left + 1)
    
    return result
```

#### 3. 动态规划
**核心思想**：将复杂问题分解为简单的子问题

**代表题目**：

- 最长递增子序列（Medium）

- 编辑距离（Hard）
- 背包问题（Medium）
- 股票买卖问题（Medium）

**解题模板**：
```python
def dp_template(nums):
    """动态规划模板"""
    n = len(nums)
    dp = [0] * n
    
    for i in range(n):
        for j in range(i):
            if condition:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)
```

## 学习路径建议

### 1. 基础阶段
- **目标**：掌握基本算法和数据结构
- **重点**：Easy题目
- **时间**：2-3个月
- **方法**：理论学习 + 实践练习

### 2. 进阶阶段
- **目标**：熟练运用各种算法思想
- **重点**：Medium题目
- **时间**：3-4个月
- **方法**：分类练习 + 总结归纳

### 3. 高级阶段
- **目标**：解决复杂问题
- **重点**：Hard题目
- **时间**：2-3个月
- **方法**：综合练习 + 创新思考

## 学习建议

### 费曼学习法
1. **理解概念**：用简单语言解释算法思想
2. **举例说明**：用具体例子说明算法应用
3. **实践应用**：实现相关的算法示例
4. **教授他人**：向他人解释算法思想

### 刻意练习
1. **基础练习**：从基础题目开始
2. **进阶练习**：逐步挑战中等和困难题目
3. **综合练习**：练习不同类型的题目
4. **创新练习**：尝试优化算法

### 学习路径
1. **理论学习**：理解各种算法思想
2. **实践练习**：大量练习相关题目
3. **总结归纳**：总结解题规律和技巧
4. **持续改进**：不断优化解题方法
