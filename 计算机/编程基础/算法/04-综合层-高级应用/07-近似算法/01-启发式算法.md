# 启发式算法

## 概述

启发式算法（Heuristic Algorithms）是一种基于经验和直觉的算法设计方法，通过使用启发式规则来指导搜索过程，在合理的时间内找到问题的近似最优解。启发式算法特别适用于NP难问题，能够在可接受的时间内找到较好的解决方案。

## 核心概念

### 基本思想
- **启发式规则**：基于问题特征的搜索策略
- **局部搜索**：在解空间中局部搜索
- **贪心选择**：每步选择当前最优
- **回溯机制**：遇到死路时回退

### 关键特性
- **近似性**：找到近似最优解
- **效率性**：在合理时间内完成
- **灵活性**：适应不同问题类型
- **实用性**：解决实际问题

### 贪心启发式

```python
from typing import List, Tuple, Any, Optional
import random
import time

class GreedyHeuristic:
    """贪心启发式算法"""
    
    def __init__(self):
        self.solution = []
        self.best_solution = []
        self.best_value = float('inf')
    
    def solve_knapsack(self, items: List[Tuple[int, int]], capacity: int) -> List[int]:
        """贪心解决背包问题"""
        # 按价值密度排序
        items_with_index = [(i, items[i][0], items[i][1]) for i in range(len(items))]
        items_with_index.sort(key=lambda x: x[1] / x[2], reverse=True)
        
        solution = []
        current_weight = 0
        
        for index, value, weight in items_with_index:
            if current_weight + weight <= capacity:
                solution.append(index)
                current_weight += weight
        
        return solution
    
    def solve_tsp(self, distances: List[List[float]]) -> List[int]:
        """贪心解决旅行商问题"""
        n = len(distances)
        if n == 0:
            return []
        
        # 从城市0开始
        path = [0]
        unvisited = set(range(1, n))
        current_city = 0
        
        while unvisited:
            # 找到最近的城市
            nearest_city = min(unvisited, key=lambda city: distances[current_city][city])
            path.append(nearest_city)
            unvisited.remove(nearest_city)
            current_city = nearest_city
        
        return path
    
    def solve_set_cover(self, universe: set, sets: List[set]) -> List[int]:
        """贪心解决集合覆盖问题"""
        uncovered = universe.copy()
        solution = []
        
        while uncovered:
            # 选择覆盖最多未覆盖元素的集合
            best_set_index = max(
                range(len(sets)),
                key=lambda i: len(sets[i] & uncovered)
            )
            
            solution.append(best_set_index)
            uncovered -= sets[best_set_index]
        
        return solution
```

### 局部搜索启发式

```python
from typing import List, Tuple, Any, Optional, Callable
import random
import time

class LocalSearchHeuristic:
    """局部搜索启发式算法"""
    
    def __init__(self):
        self.current_solution = []
        self.best_solution = []
        self.best_value = float('inf')
    
    def hill_climbing(self, initial_solution: List[int], 
                     objective_function: Callable[[List[int]], float],
                     neighbor_function: Callable[[List[int]], List[List[int]]],
                     max_iterations: int = 1000) -> List[int]:
        """爬山算法"""
        current_solution = initial_solution.copy()
        current_value = objective_function(current_solution)
        
        for _ in range(max_iterations):
            neighbors = neighbor_function(current_solution)
            best_neighbor = None
            best_neighbor_value = current_value
            
            for neighbor in neighbors:
                neighbor_value = objective_function(neighbor)
                if neighbor_value < best_neighbor_value:
                    best_neighbor = neighbor
                    best_neighbor_value = neighbor_value
            
            if best_neighbor is None:
                break
            
            current_solution = best_neighbor
            current_value = best_neighbor_value
        
        return current_solution
    
    def simulated_annealing(self, initial_solution: List[int],
                           objective_function: Callable[[List[int]], float],
                           neighbor_function: Callable[[List[int]], List[int]],
                           temperature: float = 100.0,
                           cooling_rate: float = 0.95,
                           max_iterations: int = 1000) -> List[int]:
        """模拟退火算法"""
        current_solution = initial_solution.copy()
        current_value = objective_function(current_solution)
        best_solution = current_solution.copy()
        best_value = current_value
        
        for _ in range(max_iterations):
            neighbor = neighbor_function(current_solution)
            neighbor_value = objective_function(neighbor)
            
            # 接受更好的解
            if neighbor_value < current_value:
                current_solution = neighbor
                current_value = neighbor_value
                
                if current_value < best_value:
                    best_solution = current_solution.copy()
                    best_value = current_value
            else:
                # 以一定概率接受更差的解
                delta = neighbor_value - current_value
                if random.random() < math.exp(-delta / temperature):
                    current_solution = neighbor
                    current_value = neighbor_value
            
            # 降低温度
            temperature *= cooling_rate
        
        return best_solution
    
    def tabu_search(self, initial_solution: List[int],
                   objective_function: Callable[[List[int]], float],
                   neighbor_function: Callable[[List[int]], List[List[int]]],
                   tabu_list_size: int = 10,
                   max_iterations: int = 1000) -> List[int]:
        """禁忌搜索算法"""
        current_solution = initial_solution.copy()
        current_value = objective_function(current_solution)
        best_solution = current_solution.copy()
        best_value = current_value
        
        tabu_list = []
        
        for _ in range(max_iterations):
            neighbors = neighbor_function(current_solution)
            best_neighbor = None
            best_neighbor_value = float('inf')
            
            for neighbor in neighbors:
                neighbor_value = objective_function(neighbor)
                
                # 检查是否在禁忌列表中
                if neighbor not in tabu_list and neighbor_value < best_neighbor_value:
                    best_neighbor = neighbor
                    best_neighbor_value = neighbor_value
            
            if best_neighbor is None:
                break
            
            current_solution = best_neighbor
            current_value = best_neighbor_value
            
            # 更新最佳解
            if current_value < best_value:
                best_solution = current_solution.copy()
                best_value = current_value
            
            # 更新禁忌列表
            tabu_list.append(current_solution)
            if len(tabu_list) > tabu_list_size:
                tabu_list.pop(0)
        
        return best_solution
```

### 1. 蚁群算法

```python
from typing import List, Tuple, Dict, Any
import random
import math
import time

class AntColonyOptimization:
    """蚁群优化算法"""
    
    def __init__(self, num_ants: int = 10, num_iterations: int = 100,
                 alpha: float = 1.0, beta: float = 2.0, rho: float = 0.5):
        self.num_ants = num_ants
        self.num_iterations = num_iterations
        self.alpha = alpha  # 信息素重要程度
        self.beta = beta    # 启发式信息重要程度
        self.rho = rho      # 信息素挥发率
        
        self.pheromone = {}
        self.best_solution = []
        self.best_value = float('inf')
    
    def solve_tsp(self, distances: List[List[float]]) -> List[int]:
        """蚁群算法解决旅行商问题"""
        n = len(distances)
        if n == 0:
            return []
        
        # 初始化信息素
        self._initialize_pheromone(n)
        
        for iteration in range(self.num_iterations):
            # 每只蚂蚁构建解
            solutions = []
            for ant in range(self.num_ants):
                solution = self._construct_solution(distances)
                solutions.append(solution)
            
            # 更新信息素
            self._update_pheromone(solutions, distances)
            
            # 更新最佳解
            for solution in solutions:
                value = self._calculate_tsp_value(solution, distances)
                if value < self.best_value:
                    self.best_solution = solution.copy()
                    self.best_value = value
        
        return self.best_solution
    
    def _initialize_pheromone(self, n: int) -> None:
        """初始化信息素"""
        initial_pheromone = 1.0
        for i in range(n):
            for j in range(n):
                if i != j:
                    self.pheromone[(i, j)] = initial_pheromone
    
    def _construct_solution(self, distances: List[List[float]]) -> List[int]:
        """构建解"""
        n = len(distances)
        start_city = random.randint(0, n - 1)
        solution = [start_city]
        unvisited = set(range(n)) - {start_city}
        
        current_city = start_city
        while unvisited:
            next_city = self._select_next_city(current_city, unvisited, distances)
            solution.append(next_city)
            unvisited.remove(next_city)
            current_city = next_city
        
        return solution
    
    def _select_next_city(self, current_city: int, unvisited: set, 
                          distances: List[List[float]]) -> int:
        """选择下一个城市"""
        probabilities = []
        cities = list(unvisited)
        
        for city in cities:
            pheromone = self.pheromone.get((current_city, city), 0)
            heuristic = 1.0 / distances[current_city][city] if distances[current_city][city] > 0 else 0
            
            probability = (pheromone ** self.alpha) * (heuristic ** self.beta)
            probabilities.append(probability)
        
        # 轮盘赌选择
        total_probability = sum(probabilities)
        if total_probability == 0:
            return random.choice(cities)
        
        probabilities = [p / total_probability for p in probabilities]
        
        rand = random.random()
        cumulative = 0
        for i, prob in enumerate(probabilities):
            cumulative += prob
            if rand <= cumulative:
                return cities[i]
        
        return cities[-1]
    
    def _update_pheromone(self, solutions: List[List[int]], 
                          distances: List[List[float]]) -> None:
        """更新信息素"""
        # 信息素挥发
        for key in self.pheromone:
            self.pheromone[key] *= (1 - self.rho)
        
        # 信息素沉积
        for solution in solutions:
            value = self._calculate_tsp_value(solution, distances)
            pheromone_deposit = 1.0 / value
            
            for i in range(len(solution)):
                current_city = solution[i]
                next_city = solution[(i + 1) % len(solution)]
                self.pheromone[(current_city, next_city)] += pheromone_deposit
    
    def _calculate_tsp_value(self, solution: List[int], 
                            distances: List[List[float]]) -> float:
        """计算TSP解的值"""
        if len(solution) < 2:
            return 0
        
        total_distance = 0
        for i in range(len(solution)):
            current_city = solution[i]
            next_city = solution[(i + 1) % len(solution)]
            total_distance += distances[current_city][next_city]
        
        return total_distance
```

```python
from typing import List, Tuple, Dict, Any
import random
import math
import time

class ParticleSwarmOptimization:
    """粒子群优化算法"""
    
    def __init__(self, num_particles: int = 20, num_iterations: int = 100,
                 w: float = 0.9, c1: float = 2.0, c2: float = 2.0):
        self.num_particles = num_particles
        self.num_iterations = num_iterations
        self.w = w      # 惯性权重
        self.c1 = c1    # 个体学习因子
        self.c2 = c2    # 社会学习因子
        
        self.particles = []
        self.global_best_position = []
        self.global_best_value = float('inf')
    
    def solve_continuous_optimization(self, objective_function: callable,
                                    bounds: List[Tuple[float, float]],
                                    dimensions: int) -> Tuple[List[float], float]:
        """解决连续优化问题"""
        # 初始化粒子
        self._initialize_particles(bounds, dimensions)
        
        for iteration in range(self.num_iterations):
            # 评估粒子
            for particle in self.particles:
                particle['value'] = objective_function(particle['position'])
                
                # 更新个体最佳
                if particle['value'] < particle['best_value']:
                    particle['best_position'] = particle['position'].copy()
                    particle['best_value'] = particle['value']
                
                # 更新全局最佳
                if particle['value'] < self.global_best_value:
                    self.global_best_position = particle['position'].copy()
                    self.global_best_value = particle['value']
            
            # 更新粒子速度和位置
            for particle in self.particles:
                self._update_particle(particle, bounds)
        
        return self.global_best_position, self.global_best_value
    
    def _initialize_particles(self, bounds: List[Tuple[float, float]], 
                             dimensions: int) -> None:
        """初始化粒子"""
        self.particles = []
        
        for _ in range(self.num_particles):
            position = []
            velocity = []
            
            for i in range(dimensions):
                lower_bound, upper_bound = bounds[i]
                pos = random.uniform(lower_bound, upper_bound)
                vel = random.uniform(-1, 1)
                
                position.append(pos)
                velocity.append(vel)
            
            particle = {
                'position': position,
                'velocity': velocity,
                'best_position': position.copy(),
                'best_value': float('inf'),
                'value': float('inf')
            }
            
            self.particles.append(particle)
    
    def _update_particle(self, particle: Dict, bounds: List[Tuple[float, float]]) -> None:
        """更新粒子"""
        for i in range(len(particle['position'])):
            # 更新速度
            r1 = random.random()
            r2 = random.random()
            
            cognitive = self.c1 * r1 * (particle['best_position'][i] - particle['position'][i])
            social = self.c2 * r2 * (self.global_best_position[i] - particle['position'][i])
            
            particle['velocity'][i] = (self.w * particle['velocity'][i] + 
                                      cognitive + social)
            
            # 更新位置
            particle['position'][i] += particle['velocity'][i]
            
            # 边界处理
            lower_bound, upper_bound = bounds[i]
            particle['position'][i] = max(lower_bound, 
                                        min(upper_bound, particle['position'][i]))
```

## 性能分析

### 时间复杂度
- **贪心算法**：O(n log n)
- **爬山算法**：O(n * iterations)
- **模拟退火**：O(n * iterations)
- **蚁群算法**：O(ants * iterations * n²)

### 空间复杂度
- **贪心算法**：O(n)
- **爬山算法**：O(n)
- **模拟退火**：O(n)
- **蚁群算法**：O(n²)

### 性能对比表

| 算法类型 | 时间复杂度 | 空间复杂度 | 解质量 | 适用场景 |
|---------|-----------|-----------|--------|----------|
| 贪心算法 | O(n log n) | O(n) | 中等 | 简单问题 |
| 爬山算法 | O(n * iter) | O(n) | 中等 | 局部最优 |
| 模拟退火 | O(n * iter) | O(n) | 较好 | 全局搜索 |
| 蚁群算法 | O(ants * iter * n²) | O(n²) | 好 | 组合优化 |
| 粒子群 | O(particles * iter * n) | O(n) | 好 | 连续优化 |
