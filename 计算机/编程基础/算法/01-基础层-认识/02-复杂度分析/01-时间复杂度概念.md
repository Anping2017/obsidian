# 时间复杂度概念

## 🎯 核心概念

**时间复杂度**是算法执行时间随输入规模增长的变化规律，是算法效率分析的核心指标。

## 🔍 基本定义

### 时间复杂度的含义
- **定义**：算法在最坏情况下执行基本操作次数的函数
- **目的**：评估算法的时间效率
- **表示**：用大O记号法表示

### 基本操作
| 操作类型 | 示例 | 时间复杂度 |
|----------|------|------------|
| 赋值 | `a = b` | O(1) |
| 比较 | `a > b` | O(1) |
| 算术运算 | `a + b` | O(1) |
| 数组访问 | `arr[i]` | O(1) |
| 函数调用 | `func()` | 取决于函数 |

## 📊 常见时间复杂度

### 1. 常数时间 O(1)
- **含义**：执行时间不随输入规模变化
- **示例**：数组随机访问、变量赋值
- **特点**：最高效的时间复杂度

```python
def get_first_element(arr):
    """获取数组第一个元素 - O(1)"""
    return arr[0] if arr else None
```

### 2. 对数时间 O(log n)
- **含义**：执行时间随输入规模对数增长
- **示例**：二分查找、平衡树操作
- **特点**：非常高效

```python
def binary_search(arr, target):
    """二分查找 - O(log n)"""
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1
```

### 3. 线性时间 O(n)
- **含义**：执行时间与输入规模成正比
- **示例**：遍历数组、线性查找
- **特点**：效率较高

```python
def linear_search(arr, target):
    """线性查找 - O(n)"""
    for i, value in enumerate(arr):
        if value == target:
            return i
    return -1
```

### 4. 线性对数时间 O(n log n)
- **含义**：执行时间介于线性和平方之间
- **示例**：归并排序、堆排序
- **特点**：高效排序算法

```python
def merge_sort(arr):
    """归并排序 - O(n log n)"""
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    
    return merge(left, right)

def merge(left, right):
    """合并两个有序数组 - O(n)"""
    result = []
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

### 5. 平方时间 O(n²)
- **含义**：执行时间与输入规模的平方成正比
- **示例**：冒泡排序、选择排序
- **特点**：效率较低

```python
def bubble_sort(arr):
    """冒泡排序 - O(n²)"""
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
```

### 6. 指数时间 O(2ⁿ)
- **含义**：执行时间随输入规模指数增长
- **示例**：递归斐波那契、子集生成
- **特点**：效率极低

```python
def fibonacci_recursive(n):
    """递归斐波那契 - O(2ⁿ)"""
    if n <= 1:
        return n
    return fibonacci_recursive(n - 1) + fibonacci_recursive(n - 2)
```

## 📈 时间复杂度对比

| 复杂度 | 增长趋势 | 示例 | 效率评价 |
|--------|----------|------|----------|
| O(1) | 常数 | 数组访问 | 优秀 |
| O(log n) | 对数 | 二分查找 | 很好 |
| O(n) | 线性 | 遍历数组 | 良好 |
| O(n log n) | 线性对数 | 归并排序 | 较好 |
| O(n²) | 平方 | 冒泡排序 | 较差 |
| O(n³) | 立方 | 三重循环 | 差 |
| O(2ⁿ) | 指数 | 递归斐波那契 | 很差 |

## 🎨 复杂度分析示例

### 嵌套循环分析
```python
def nested_loops_example(n):
    """嵌套循环示例 - O(n²)"""
    count = 0
    for i in range(n):        # 外层循环：n次
        for j in range(n):    # 内层循环：n次
            count += 1        # 基本操作：O(1)
    return count
# 总时间复杂度：O(n) × O(n) × O(1) = O(n²)
```

### 条件分支分析
```python
def conditional_example(arr):
    """条件分支示例"""
    if len(arr) == 0:         # O(1)
        return 0
    
    max_val = arr[0]          # O(1)
    for i in range(1, len(arr)):  # O(n)
        if arr[i] > max_val:      # O(1)
            max_val = arr[i]      # O(1)
    
    return max_val
# 总时间复杂度：O(1) + O(1) + O(n) × O(1) = O(n)
```

## 🔍 分析方法

### 1. 基本操作计数法
- **步骤**：统计基本操作执行次数
- **适用**：简单算法
- **示例**：循环中的比较、赋值操作

### 2. 循环分析法
- **步骤**：分析循环次数和循环体复杂度
- **适用**：包含循环的算法
- **公式**：总复杂度 = 循环次数 × 循环体复杂度

### 3. 递归分析法
- **步骤**：建立递归关系式
- **适用**：递归算法
- **方法**：主定理、递归树

### 理解重点
1. **增长趋势**：理解不同复杂度的增长规律
2. **实际意义**：复杂度对实际性能的影响
3. **分析方法**：如何分析算法的时间复杂度
4. **选择原则**：根据场景选择合适的复杂度

### 常见误区
- **误区1**：认为O(1)一定比O(n)快
- **误区2**：忽略常数因子
- **误区3**：不考虑最坏情况
- **误区4**：混淆时间复杂度和实际运行时间
