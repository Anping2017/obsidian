# 复杂度比较表

## 🎯 核心概念

**复杂度比较表**是不同算法复杂度之间的对比分析，帮助理解各种复杂度的实际意义和适用场景。

## 📊 时间复杂度对比

### 基本复杂度对比
| 复杂度 | 表示法 | 增长趋势 | 示例算法 | 效率评价 | 适用场景 |
|--------|--------|----------|----------|----------|----------|
| 常数时间 | O(1) | 不增长 | 数组访问 | 优秀 | 实时系统 |
| 对数时间 | O(log n) | 对数增长 | 二分查找 | 很好 | 搜索算法 |
| 线性时间 | O(n) | 线性增长 | 遍历数组 | 良好 | 数据处理 |
| 线性对数时间 | O(n log n) | 线性对数增长 | 归并排序 | 较好 | 排序算法 |
| 平方时间 | O(n²) | 平方增长 | 冒泡排序 | 较差 | 小规模数据 |
| 立方时间 | O(n³) | 立方增长 | 三重循环 | 差 | 特殊算法 |
| 指数时间 | O(2ⁿ) | 指数增长 | 递归斐波那契 | 很差 | 小规模问题 |

## 🎯 实际应用对比

### 数据规模与算法选择
| 数据规模 | 推荐时间复杂度 | 推荐算法 | 原因 |
|----------|----------------|----------|------|
| n < 50 | O(n²) | 冒泡排序、选择排序 | 简单实现 |
| 50 ≤ n < 1000 | O(n log n) | 快速排序、归并排序 | 平衡效率 |
| 1000 ≤ n < 10000 | O(n log n) | 堆排序、归并排序 | 稳定高效 |
| n ≥ 10000 | O(n) | 计数排序、基数排序 | 线性时间 |

### 内存限制与算法选择
| 内存限制 | 推荐空间复杂度 | 推荐算法 | 原因 |
|----------|----------------|----------|------|
| 严格限制 | O(1) | 原地排序 | 节省内存 |
| 中等限制 | O(log n) | 快速排序 | 平衡内存 |
| 充足内存 | O(n) | 归并排序 | 稳定排序 |

### 应用场景与复杂度选择
| 应用场景 | 时间要求 | 推荐复杂度 | 示例算法 |
|----------|----------|------------|----------|
| 实时系统 | < 1ms | O(1), O(log n) | 哈希表、二分查找 |
| 交互应用 | < 100ms | O(n), O(n log n) | 线性搜索、快速排序 |
| 批处理 | < 1s | O(n²) | 冒泡排序 |
| 离线处理 | < 1min | O(n³) | 三重循环 |

## 🎯 学习要点

### 理解重点
1. **增长趋势**：理解不同复杂度的增长规律
2. **实际意义**：复杂度对实际性能的影响
3. **选择原则**：根据场景选择合适的复杂度
4. **权衡考虑**：时间与空间的权衡

### 常见误区
- **误区1**：认为O(1)一定比O(n)快
- **误区2**：忽略常数因子
- **误区3**：不考虑最坏情况
- **误区4**：混淆时间复杂度和实际运行时间
