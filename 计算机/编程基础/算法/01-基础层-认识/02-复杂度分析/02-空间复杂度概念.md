# 空间复杂度概念

## 🎯 核心概念

**空间复杂度**是算法执行过程中所需内存空间随输入规模增长的变化规律，是算法效率分析的重要指标。

## 🔍 基本定义

### 空间复杂度的含义
- **定义**：算法在最坏情况下所需额外内存空间的函数
- **目的**：评估算法的空间效率
- **表示**：用大O记号法表示

### 内存空间分类
| 空间类型 | 含义 | 示例 |
|----------|------|------|
| 输入空间 | 存储输入数据 | 数组、字符串 |
| 输出空间 | 存储输出结果 | 返回值、输出数组 |
| 辅助空间 | 算法执行过程中的额外空间 | 临时变量、递归栈 |

## 📊 常见空间复杂度

### 1. 常数空间 O(1)
- **含义**：所需空间不随输入规模变化
- **示例**：原地排序、简单计算
- **特点**：空间效率最高

```python
def swap_elements(arr, i, j):
    """交换数组元素 - O(1)"""
    arr[i], arr[j] = arr[j], arr[i]
    # 只使用常数个临时变量
```

### 2. 线性空间 O(n)
- **含义**：所需空间与输入规模成正比
- **示例**：复制数组、递归深度
- **特点**：空间效率较高

```python
def copy_array(arr):
    """复制数组 - O(n)"""
    return arr.copy()  # 需要与原数组相同大小的空间
```

### 3. 线性对数空间 O(n log n)
- **含义**：所需空间介于线性和平方之间
- **示例**：归并排序、快速排序
- **特点**：空间效率中等

```python
def merge_sort(arr):
    """归并排序 - O(n log n)"""
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])    # O(n/2)
    right = merge_sort(arr[mid:])   # O(n/2)
    
    return merge(left, right)       # O(n)
# 递归深度：O(log n)，每层空间：O(n)
# 总空间复杂度：O(n log n)
```

### 4. 平方空间 O(n²)
- **含义**：所需空间与输入规模的平方成正比
- **示例**：二维数组、邻接矩阵
- **特点**：空间效率较低

```python
def create_matrix(n):
    """创建n×n矩阵 - O(n²)"""
    matrix = []
    for i in range(n):
        row = []
        for j in range(n):
            row.append(i * j)
        matrix.append(row)
    return matrix
```

## 🎨 空间复杂度分析示例

### 递归算法空间分析
```python
def fibonacci_recursive(n):
    """递归斐波那契 - O(n)"""
    if n <= 1:
        return n
    return fibonacci_recursive(n - 1) + fibonacci_recursive(n - 2)
# 递归深度：O(n)
# 每层空间：O(1)
# 总空间复杂度：O(n)
```

### 迭代算法空间分析
```python
def fibonacci_iterative(n):
    """迭代斐波那契 - O(1)"""
    if n <= 1:
        return n
    
    a, b = 0, 1
    for i in range(2, n + 1):
        a, b = b, a + b
    return b
# 只使用常数个变量
# 空间复杂度：O(1)
```

### 动态规划空间分析
```python
def fibonacci_dp(n):
    """动态规划斐波那契 - O(n)"""
    if n <= 1:
        return n
    
    dp = [0] * (n + 1)  # O(n)空间
    dp[0], dp[1] = 0, 1
    
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    
    return dp[n]
```

## 📈 空间复杂度对比

| 复杂度 | 空间需求 | 示例 | 效率评价 |
|--------|----------|------|----------|
| O(1) | 常数 | 原地排序 | 优秀 |
| O(log n) | 对数 | 递归深度 | 很好 |
| O(n) | 线性 | 复制数组 | 良好 |
| O(n log n) | 线性对数 | 归并排序 | 较好 |
| O(n²) | 平方 | 邻接矩阵 | 较差 |
| O(2ⁿ) | 指数 | 递归子集 | 很差 |

## 🔄 时间与空间权衡

### 常见权衡策略
| 策略 | 时间 | 空间 | 示例 |
|------|------|------|------|
| 空间换时间 | 降低 | 增加 | 哈希表 |
| 时间换空间 | 增加 | 降低 | 重复计算 |
| 平衡策略 | 适中 | 适中 | 动态规划 |

### 权衡示例
```python
# 空间换时间：使用哈希表
def two_sum_hash(nums, target):
    """两数之和 - 哈希表方法"""
    hash_map = {}  # O(n)空间
    for i, num in enumerate(nums):  # O(n)时间
        complement = target - num
        if complement in hash_map:
            return [hash_map[complement], i]
        hash_map[num] = i
    return []

# 时间换空间：暴力方法
def two_sum_brute(nums, target):
    """两数之和 - 暴力方法"""
    for i in range(len(nums)):      # O(n²)时间
        for j in range(i + 1, len(nums)):
            if nums[i] + nums[j] == target:
                return [i, j]
    return []
```

## 🎯 空间优化技巧

### 1. 原地算法
- **原理**：不使用额外空间
- **示例**：原地排序、原地反转
- **限制**：可能影响输入数据

```python
def reverse_array_inplace(arr):
    """原地反转数组 - O(1)"""
    left, right = 0, len(arr) - 1
    while left < right:
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1
```

### 2. 滚动数组
- **原理**：只保存必要的状态
- **示例**：动态规划优化
- **效果**：降低空间复杂度

```python
def fibonacci_optimized(n):
    """优化的斐波那契 - O(1)"""
    if n <= 1:
        return n
    
    a, b = 0, 1
    for i in range(2, n + 1):
        a, b = b, a + b
    return b
```

### 3. 位运算优化
- **原理**：使用位运算减少空间
- **示例**：状态压缩、集合表示
- **效果**：大幅降低空间需求

```python
def subset_sum_bitmask(nums, target):
    """位运算子集和 - O(1)额外空间"""
    n = len(nums)
    for mask in range(1 << n):  # 2^n种可能
        total = 0
        for i in range(n):
            if mask & (1 << i):
                total += nums[i]
        if total == target:
            return True
    return False
```

## 🔍 分析方法

### 1. 变量计数法
- **步骤**：统计算法中使用的变量
- **适用**：简单算法
- **注意**：区分输入空间和辅助空间

### 2. 递归深度法
- **步骤**：分析递归调用深度
- **适用**：递归算法
- **公式**：空间复杂度 = 递归深度 × 每层空间

### 3. 数据结构法
- **步骤**：分析使用的数据结构大小
- **适用**：使用复杂数据结构的算法
- **考虑**：数据结构的空间开销
