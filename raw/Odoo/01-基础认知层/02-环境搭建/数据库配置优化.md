## ⚡ 性能优化配置

### 内存优化
```ini
# 共享缓冲区 (推荐为系统内存的25%)
shared_buffers = 2GB

# 有效缓存大小 (推荐为系统内存的75%)
effective_cache_size = 6GB

# 工作内存 (每个查询操作可用)

# 维护工作内存 (VACUUM, CREATE INDEX等)
```

## 📊 索引优化策略

### 常用索引类型
```sql
-- B-tree索引 (默认)
CREATE INDEX idx_sale_order_date ON sale_order (date_order);

-- 复合索引
CREATE INDEX idx_sale_order_partner_date ON sale_order (partner_id, date_order);

-- 部分索引
CREATE INDEX idx_sale_order_draft ON sale_order (id) WHERE state = 'draft';

-- 表达式索引
CREATE INDEX idx_sale_order_year ON sale_order (EXTRACT(year FROM date_order));

-- 唯一索引
CREATE UNIQUE INDEX idx_product_code ON product_product (default_code) WHERE active = true;
```

### 索引维护
```sql
-- 分析索引使用情况
SELECT 
    schemaname,
    tablename,
    indexname,
    idx_scan,
    idx_tup_read,
    idx_tup_fetch
FROM pg_stat_user_indexes
ORDER BY idx_scan DESC;

-- 重建索引
REINDEX INDEX idx_sale_order_date;

-- 分析表统计信息
ANALYZE sale_order;
```

## 🔍 查询性能分析

### 慢查询监控
```sql
-- 启用慢查询日志
ALTER SYSTEM SET log_min_duration_statement = 1000;
SELECT pg_reload_conf();

-- 查看当前慢查询
SELECT 
    pid,
    now() - pg_stat_activity.query_start AS duration,
    query,
    state
FROM pg_stat_activity
WHERE (now() - pg_stat_activity.query_start) > interval '5 minutes'
ORDER BY duration DESC;
```

### 执行计划分析

```sql
WHERE partner_id = 123;
```

## 📈 性能监控

### 系统监控查询
```sql
-- 数据库大小
SELECT 
    pg_database.datname,
    pg_size_pretty(pg_database_size(pg_database.datname)) AS size
FROM pg_database
ORDER BY pg_database_size(pg_database.datname) DESC;

-- 表大小
SELECT 
    schemaname,
    tablename,
    pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
FROM pg_tables
WHERE schemaname = 'public'
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;

-- 连接数统计
SELECT 
    state,
    count(*) as connections
FROM pg_stat_activity
GROUP BY state;
```

### 性能指标监控
```sql
-- 缓存命中率
SELECT 
    round(100.0 * sum(blks_hit) / (sum(blks_hit) + sum(blks_read)), 2) AS cache_hit_ratio
FROM pg_stat_database;

-- 索引使用率
SELECT 
    schemaname,
    tablename,
    indexname,
    idx_scan,
    idx_tup_read,
    idx_tup_fetch
FROM pg_stat_user_indexes
WHERE idx_scan = 0
ORDER BY schemaname, tablename;
```

### 自动化维护
```bash

# maintenance.sh - 数据库维护脚本

# 设置变量
DB_NAME="odoo_db"
DB_USER="odoo"
DB_HOST="localhost"

# 更新统计信息
psql -h $DB_HOST -U $DB_USER -d $DB_NAME -c "ANALYZE;"

SELECT 
    pg_database.datname,
    pg_size_pretty(pg_database_size(pg_database.datname)) AS size
FROM pg_database
WHERE datname = '$DB_NAME';"
```

## 📊 监控工具配置

### pg_stat_statements扩展
```sql
-- 安装扩展
CREATE EXTENSION IF NOT EXISTS pg_stat_statements;

-- 查看最耗时的查询
SELECT 
    query,
    calls,
    total_time,
    mean_time,
    rows
FROM pg_stat_statements

```

### 监控脚本
```python
# monitor.py - 数据库监控脚本
import psycopg2
import time
import json

def monitor_database():
    conn = psycopg2.connect(
        host="localhost",
        database="odoo_db",
        user="odoo",
        password="odoo"
    )
    
    cursor = conn.cursor()
    
    # 获取连接数
    cursor.execute("SELECT count(*) FROM pg_stat_activity")
    connections = cursor.fetchone()[0]
    
    # 获取数据库大小
    cursor.execute("SELECT pg_size_pretty(pg_database_size('odoo_db'))")
    db_size = cursor.fetchone()[0]
    
    # 获取缓存命中率
    cursor.execute("""
        SELECT round(100.0 * sum(blks_hit) / (sum(blks_hit) + sum(blks_read)), 2)
        FROM pg_stat_database WHERE datname = 'odoo_db'
    """)
    cache_hit_ratio = cursor.fetchone()[0]
    
    print(f"连接数: {connections}")
    print(f"数据库大小: {db_size}")
    print(f"缓存命中率: {cache_hit_ratio}%")
    
    cursor.close()
    conn.close()

if __name__ == "__main__":
    while True:
        monitor_database()
        time.sleep(60)
```
