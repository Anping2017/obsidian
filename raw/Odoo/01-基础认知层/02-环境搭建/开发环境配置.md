# 开发环境配置

## 🎯 学习目标
- 掌握Odoo开发环境的搭建方法
- 了解不同操作系统的配置差异
- 学会使用Docker简化环境配置

## 🖥️ 系统要求

### 硬件要求
| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 2核心 | 4核心+ |
| 内存 | 4GB | 8GB+ |
| 存储 | 20GB | 50GB+ |
| 网络 | 宽带连接 | 稳定网络 |

### 操作系统支持
- **Linux**: Ubuntu 18.04+, CentOS 7+, Debian 9+
- **Windows**: Windows 10+, Windows Server 2016+
- **macOS**: macOS 10.14+

## 🐍 Python环境配置

### Python版本要求
- **Odoo 17.0**: Python 3.8+
- **Odoo 16.0**: Python 3.8+
- **Odoo 15.0**: Python 3.8+

### 安装Python
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip python3-venv

# CentOS/RHEL
sudo yum install python3 python3-pip

# Windows (使用Chocolatey)
choco install python

# macOS (使用Homebrew)
brew install python3
```

### 创建虚拟环境
```bash
# 创建虚拟环境
python3 -m venv odoo-env

# 激活虚拟环境
# Linux/macOS
source odoo-env/bin/activate

# Windows
odoo-env\Scripts\activate
```

## 🗄️ 数据库配置

### PostgreSQL安装
```bash
# Ubuntu/Debian
sudo apt install postgresql postgresql-contrib

# CentOS/RHEL
sudo yum install postgresql-server postgresql-contrib

# Windows
# 下载并安装PostgreSQL官方安装包

# macOS
brew install postgresql
```

### 数据库配置
```bash
# 切换到postgres用户
sudo -u postgres psql

# 创建Odoo用户
CREATE USER odoo WITH PASSWORD 'odoo';

# 创建数据库
CREATE DATABASE odoo_db OWNER odoo;

# 授权
GRANT ALL PRIVILEGES ON DATABASE odoo_db TO odoo;
```

## 📦 Odoo安装

### 方法一：源码安装
```bash
# 克隆Odoo源码
git clone https://github.com/odoo/odoo.git
cd odoo

# 安装依赖
pip install -r requirements.txt

# 安装系统依赖
# Ubuntu/Debian
sudo apt install libxml2-dev libxslt1-dev libevent-dev libsasl2-dev libldap2-dev libpq-dev libpng-dev libjpeg-dev libfreetype6-dev liblcms2-dev libwebp-dev libharfbuzz-dev libfribidi-dev libxcb1-dev

# CentOS/RHEL
sudo yum install libxml2-devel libxslt-devel libevent-devel cyrus-sasl-devel openldap-devel postgresql-devel libpng-devel libjpeg-devel freetype-devel lcms2-devel libwebp-devel harfbuzz-devel fribidi-devel libxcb-devel
```

### 方法二：Docker安装
```dockerfile
# Dockerfile
FROM odoo:17.0

# 安装额外依赖
USER root
RUN apt-get update && apt-get install -y \
    git \
    && rm -rf /var/lib/apt/lists/*

USER odoo
```

```yaml
# docker-compose.yml
version: '3.8'
services:
  db:
    image: postgres:13
    environment:
      POSTGRES_DB: odoo
      POSTGRES_USER: odoo
      POSTGRES_PASSWORD: odoo
    volumes:
      - odoo-db-data:/var/lib/postgresql/data

  odoo:
    image: odoo:17.0
    depends_on:
      - db
    ports:
      - "8069:8069"
    environment:
      HOST: db
      USER: odoo
      PASSWORD: odoo
    volumes:
      - ./addons:/mnt/extra-addons
      - ./config:/etc/odoo
      - odoo-web-data:/var/lib/odoo

volumes:
  odoo-web-data:
  odoo-db-data:
```

## ⚙️ 配置文件

### Odoo配置文件
```ini
# odoo.conf
[options]
; 数据库配置
db_host = localhost
db_port = 5432
db_user = odoo
db_password = odoo
db_name = odoo_db

; 服务器配置
http_port = 8069
http_interface = 0.0.0.0

; 日志配置
log_level = info
log_handler = :INFO

; 开发模式
dev_mode = True
auto_reload = True

; 插件路径
addons_path = /path/to/odoo/addons,/path/to/custom/addons

; 数据目录
data_dir = /var/lib/odoo

; 工作进程
workers = 2
max_cron_threads = 1

; 安全配置
admin_passwd = admin
```

# .env文件

## 🐳 Docker开发环境

### 完整开发环境
```yaml
# docker-compose.dev.yml
version: '3.8'
services:
  db:
    image: postgres:13
    environment:
      POSTGRES_DB: odoo_dev
      POSTGRES_USER: odoo
      POSTGRES_PASSWORD: odoo
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  odoo:
    build: .
    depends_on:
      - db
    ports:
      - "8069:8069"
    environment:
      HOST: db
      USER: odoo
      PASSWORD: odoo
      DATABASE: odoo_dev
    volumes:
      - ./odoo:/opt/odoo
      - ./addons:/mnt/extra-addons
      - ./config:/etc/odoo
      - odoo_data:/var/lib/odoo
    command: ["odoo", "--dev=reload,qweb,werkzeug,xml"]

  pgadmin:
    image: dpage/pgadmin4
    environment:
      PGADMIN_DEFAULT_EMAIL: admin@admin.com
      PGADMIN_DEFAULT_PASSWORD: admin
    ports:
      - "5050:80"
    depends_on:
      - db

volumes:
  postgres_data:
  odoo_data:
```

### 开发脚本
```bash
#!/bin/bash
# dev.sh - 开发环境启动脚本

# 启动开发环境
docker-compose -f docker-compose.dev.yml up -d

# 等待数据库启动
sleep 10

# 创建数据库
docker-compose -f docker-compose.dev.yml exec odoo odoo -d odoo_dev -i base --stop-after-init

# 启动Odoo
docker-compose -f docker-compose.dev.yml exec odoo odoo -d odoo_dev --dev=reload
```

## 🔧 性能优化配置

### 生产环境配置
```ini
# odoo.prod.conf
[options]
; 性能配置
workers = 4
max_cron_threads = 2
limit_memory_hard = 2684354560
limit_memory_soft = 2147483648
limit_request = 8192
limit_time_cpu = 600
limit_time_real = 1200

; 缓存配置
proxy_mode = True
xmlrpc = False
xmlrpcs = True

; 日志配置
log_level = warn
log_handler = :WARNING

; 安全配置
admin_passwd = strong_password
```

### 系统优化
```bash
# 系统参数优化
echo "vm.overcommit_memory = 1" >> /etc/sysctl.conf
echo "net.core.somaxconn = 65535" >> /etc/sysctl.conf
sysctl -p

# 文件描述符限制
echo "* soft nofile 65535" >> /etc/security/limits.conf
echo "* hard nofile 65535" >> /etc/security/limits.conf
```
