# 微积分应用

## 🎯 核心概念

### 微积分在金融中的应用
**微积分**是研究函数变化率的数学分支，在金融学中广泛应用于优化问题、风险度量、期权定价等领域。

> **费曼解释**：微积分就像"变化的数学"，它帮助我们理解事物如何变化。在金融中，就像计算股票价格的变化速度，或者找到最优的投资组合。就像开车时看速度表一样，微积分帮我们看"金融的速度表"。

### 微积分在金融中的基本特征
- **变化率分析**：分析金融变量的变化率
- **优化问题**：求解最优解
- **风险度量**：量化金融风险
- **定价模型**：金融工具定价

## 📊 导数应用

### 1. 边际分析
**边际成本**：
- **定义**：增加一单位产量所增加的成本
- **公式**：MC = dC/dQ
- **C**：总成本
- **Q**：产量
- **应用**：生产决策、定价策略

**边际收益**：
- **定义**：增加一单位产量所增加的收益
- **公式**：MR = dR/dQ
- **R**：总收益
- **Q**：产量
- **应用**：收益最大化

**边际效用**：
- **定义**：增加一单位消费所增加的效用
- **公式**：MU = dU/dX
- **U**：总效用
- **X**：消费量
- **应用**：消费决策

**最优条件**：
- **利润最大化**：MR = MC
- **效用最大化**：MU1/P1 = MU2/P2
- **成本最小化**：MPL/w = MPK/r
- **应用**：经济决策

### 2. 弹性分析
**价格弹性**：
- **定义**：价格变化对需求量的影响程度
- **公式**：Ed = (dQ/dP) × (P/Q)
- **Q**：需求量
- **P**：价格
- **应用**：定价策略

**收入弹性**：
- **定义**：收入变化对需求量的影响程度
- **公式**：Ey = (dQ/dY) × (Y/Q)
- **Y**：收入
- **应用**：市场分析

**交叉弹性**：
- **定义**：一种商品价格变化对另一种商品需求量的影响
- **公式**：Exy = (dQx/dPy) × (Py/Qx)
- **应用**：替代品分析

**关联学习**：[[01-基础理论/货币与信用/利率理论|利率理论]]

### 3. 风险度量
**Delta**：
- **定义**：期权价格对标的资产价格的敏感度
- **公式**：Δ = ∂C/∂S
- **C**：期权价格
- **S**：标的资产价格
- **应用**：期权对冲

**Gamma**：
- **定义**：Delta对标的资产价格的变化率
- **公式**：Γ = ∂²C/∂S²
- **应用**：期权风险管理

**Theta**：
- **定义**：期权价格对时间的变化率
- **公式**：Θ = ∂C/∂t
- **t**：时间
- **应用**：时间价值分析

**Vega**：
- **定义**：期权价格对波动率的变化率
- **公式**：ν = ∂C/∂σ
- **σ**：波动率
- **应用**：波动率风险管理

## 🔄 积分应用

### 1. 累积分析
**累积收益**：
- **定义**：一段时间内的总收益
- **公式**：R = ∫[r(t)dt]
- **r(t)**：瞬时收益率
- **应用**：投资绩效评估

**累积风险**：
- **定义**：一段时间内的总风险
- **公式**：V = ∫[σ²(t)dt]
- **σ(t)**：瞬时波动率
- **应用**：风险度量

**累积损失**：
- **定义**：一段时间内的总损失
- **公式**：L = ∫[λ(t)dt]
- **λ(t)**：瞬时损失率
- **应用**：保险定价

### 2. 概率密度函数
**正态分布**：
- **定义**：连续型概率分布
- **公式**：f(x) = (1/√(2πσ²)) × e^(-(x-μ)²/(2σ²))
- **μ**：均值
- **σ**：标准差
- **应用**：资产收益率建模

**对数正态分布**：
- **定义**：对数服从正态分布
- **公式**：f(x) = (1/(xσ√(2π))) × e^(-(ln(x)-μ)²/(2σ²))
- **应用**：股票价格建模

**t分布**：
- **定义**：小样本的分布
- **公式**：f(x) = Γ((ν+1)/2) / (√(νπ) × Γ(ν/2)) × (1 + x²/ν)^(-(ν+1)/2)
- **ν**：自由度
- **应用**：小样本统计

**关联学习**：[[07-数学工具/金融数学基础/概率论与统计学|概率论与统计学]]

### 3. 风险价值计算
**VaR计算**：
- **定义**：在险价值
- **公式**：VaR = μ - zα × σ
- **zα**：置信水平对应的分位数
- **应用**：风险度量

**CVaR计算**：
- **定义**：条件在险价值
- **公式**：CVaR = E[R|R ≤ VaR]
- **应用**：尾部风险管理

**ES计算**：
- **定义**：期望损失
- **公式**：ES = ∫[x × f(x)dx] (x ≤ VaR)
- **应用**：极端风险度量

## 📈 偏微分方程应用

### 1. Black-Scholes方程
**Black-Scholes方程**：
- **定义**：期权定价的偏微分方程
- **公式**：∂C/∂t + rS∂C/∂S + (1/2)σ²S²∂²C/∂S² - rC = 0
- **C**：期权价格
- **S**：标的资产价格
- **r**：无风险利率
- **σ**：波动率
- **t**：时间

**边界条件**：
- **到期条件**：C(T,S) = max(S-K,0)
- **边界条件**：C(t,0) = 0, C(t,∞) = S
- **K**：执行价格
- **T**：到期时间

**解析解**：
- **看涨期权**：C = SN(d1) - Ke^(-rT)N(d2)
- **看跌期权**：P = Ke^(-rT)N(-d2) - SN(-d1)
- **N(d)**：标准正态分布累积函数
- **d1, d2**：Black-Scholes参数

**关联学习**：[[03-投资学/衍生品/期权定价|期权定价]]

### 2. 热传导方程
**热传导方程**：
- **定义**：描述热量传导的方程
- **公式**：∂u/∂t = α∇²u
- **u**：温度
- **α**：热扩散系数
- **∇²**：拉普拉斯算子

**金融应用**：
- **期权定价**：Black-Scholes方程的简化
- **利率模型**：利率期限结构
- **信用风险**：信用价差模型
- **流动性风险**：流动性扩散模型

### 3. 随机微分方程
**几何布朗运动**：
- **定义**：股票价格的随机过程
- **公式**：dS = μSdt + σSdW
- **μ**：漂移率
- **σ**：波动率
- **dW**：维纳过程

**Ornstein-Uhlenbeck过程**：
- **定义**：均值回归过程
- **公式**：dX = κ(θ - X)dt + σdW
- **κ**：均值回归速度
- **θ**：长期均值
- **应用**：利率模型、波动率模型

**跳跃扩散过程**：
- **定义**：包含跳跃的扩散过程
- **公式**：dS = μSdt + σSdW + SdJ
- **dJ**：跳跃过程
- **应用**：信用风险、极端事件
