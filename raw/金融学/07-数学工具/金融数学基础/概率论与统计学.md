# 概率论与统计学

## 🎯 核心概念

### 概率论在金融中的作用
**概率论**是研究随机现象规律性的数学分支，在金融中用于风险度量、期权定价和投资决策。

> **费曼解释**：概率论就像天气预报，虽然不能100%准确，但能告诉我们下雨的可能性有多大。金融中的概率论告诉我们投资赚钱的可能性有多大。

### 统计学在金融中的应用
**统计学**是收集、分析、解释数据的科学，在金融中用于数据分析、模型验证和风险管理。

## 📊 概率论基础

### 1. 基本概念
**随机变量**：
- **离散型**：取有限或可数无限个值
- **连续型**：取连续区间内的值

**概率分布**：
- **概率质量函数**：离散型随机变量
- **概率密度函数**：连续型随机变量

**期望值**：
```
E(X) = Σxi × P(xi)  (离散型)
E(X) = ∫xf(x)dx     (连续型)
```

### 2. 常用分布
**正态分布**：
- **特点**：钟形曲线，对称分布
- **参数**：均值μ，标准差σ
- **应用**：股票收益率、期权定价

**对数正态分布**：
- **特点**：对数服从正态分布
- **应用**：股票价格、资产价值

**t分布**：
- **特点**：尾部较厚
- **应用**：小样本统计推断

**卡方分布**：
- **特点**：非负值
- **应用**：方差检验、风险度量

**关联学习**：[[03-投资学/风险管理/风险识别与度量|风险识别与度量]]

### 3. 中心极限定理
**内容**：独立同分布随机变量的样本均值趋于正态分布

**应用**：
- **大样本推断**
- **投资组合理论**
- **风险管理**

## 📈 统计学方法

### 1. 描述性统计
**集中趋势**：
- **均值**：算术平均数
- **中位数**：中间值
- **众数**：最频繁值

**离散程度**：
- **方差**：σ² = E[(X-μ)²]
- **标准差**：σ = √σ²
- **变异系数**：CV = σ/μ

**分布形状**：
- **偏度**：分布对称性
- **峰度**：分布尖锐程度

### 2. 推断统计
**假设检验**：
- **原假设H0**：要检验的假设
- **备择假设H1**：对立假设
- **显著性水平α**：犯第一类错误的概率
- **p值**：在原假设下观察到当前结果的概率

**置信区间**：
- **定义**：包含参数真值的区间
- **置信水平**：1-α
- **应用**：参数估计、风险度量

**关联学习**：[[07-数学工具/量化方法/回归分析|回归分析]]

### 3. 相关分析
**相关系数**：
```
r = Σ(xi-x̄)(yi-ȳ) / √[Σ(xi-x̄)²Σ(yi-ȳ)²]
```

**含义**：
- **r = 1**：完全正相关
- **r = -1**：完全负相关
- **r = 0**：无相关

**应用**：
- **投资组合**：资产相关性
- **风险管理**：风险分散
- **市场分析**：市场关联性

## 🎯 金融应用

### 1. 风险度量
**VaR（风险价值）**：
- **定义**：在给定置信水平下的最大损失
- **计算**：VaR = μ - zα × σ
- **应用**：风险管理、资本配置

**CVaR（条件风险价值）**：
- **定义**：超过VaR的期望损失
- **计算**：CVaR = E[L|L > VaR]
- **应用**：尾部风险管理

**关联学习**：[[03-投资学/风险管理/风险模型与工具|风险模型与工具]]

### 2. 期权定价
**Black-Scholes模型**：
```
C = S₀N(d₁) - Ke^(-rT)N(d₂)
d₁ = [ln(S₀/K) + (r + σ²/2)T] / (σ√T)
d₂ = d₁ - σ√T
```

**参数**：
- **S₀**：标的资产价格
- **K**：执行价格
- **r**：无风险利率
- **T**：到期时间
- **σ**：波动率

**关联学习**：[[01-基础理论/金融市场基础/金融衍生品市场|金融衍生品市场]]

### 3. 投资组合优化
**马科维茨模型**：
```
目标函数：Max E(Rp) = Σwi × E(Ri)
约束条件：Σwi = 1, wi ≥ 0
风险约束：σp² = ΣΣwiwjσij ≤ σtarget
```

**参数**：
- **wi**：资产i的权重
- **E(Ri)**：资产i的预期收益
- **σij**：资产i和j的协方差

**关联学习**：[[03-投资学/投资基础/投资组合理论|投资组合理论]]

## 📊 时间序列分析

### 1. 基本概念
**时间序列**：按时间顺序排列的数据序列

**特点**：
- **趋势**：长期变化方向
- **季节性**：周期性变化
- **随机性**：不可预测的波动

### 2. 平稳性
**弱平稳**：
- **均值恒定**：E[Xt] = μ
- **方差恒定**：Var[Xt] = σ²
- **协方差恒定**：Cov[Xt, Xt+k] = γ(k)

**检验方法**：
- **ADF检验**：增广迪基-富勒检验
- **PP检验**：菲利普斯-佩龙检验

### 3. ARIMA模型
**ARIMA(p,d,q)**：
- **AR(p)**：自回归项
- **I(d)**：差分次数
- **MA(q)**：移动平均项

**应用**：
- **股价预测**
- **收益率建模**
- **风险管理**

**关联学习**：[[07-数学工具/量化方法/时间序列分析|时间序列分析]]

## 🔄 蒙特卡洛模拟

### 1. 基本原理
**蒙特卡洛方法**：通过随机抽样来近似计算数学期望

**步骤**：
1. **建立模型**：确定随机变量和分布
2. **生成随机数**：模拟随机过程
3. **计算统计量**：估计期望值
4. **分析结果**：评估不确定性

### 2. 金融应用
**期权定价**：
- **路径依赖期权**
- **美式期权**
- **复杂衍生品**

**风险管理**：
- **投资组合风险**
- **信用风险**
- **操作风险**

**关联学习**：[[07-数学工具/量化方法/蒙特卡洛模拟|蒙特卡洛模拟]]

### 不同市场的统计特征
| 市场 | 收益率分布 | 波动率 | 相关性 | 特点 |
|------|------------|--------|--------|------|
| **美国** | 接近正态 | 中等 | 中等 | 成熟市场 |
| **欧洲** | 接近正态 | 中等 | 高 | 一体化程度高 |
| **中国** | 偏态分布 | 高 | 低 | 新兴市场 |
| **日本** | 接近正态 | 低 | 中等 | 低增长 |

### 不同资产的统计特征
| 资产 | 预期收益 | 波动率 | 偏度 | 峰度 | 特点 |
|------|----------|--------|------|------|------|
| **股票** | 高 | 高 | 负偏 | 高峰 | 高风险高收益 |
| **债券** | 中 | 低 | 正偏 | 低峰 | 低风险低收益 |
| **商品** | 中 | 高 | 正偏 | 高峰 | 周期性 |
| **外汇** | 低 | 中 | 接近0 | 接近3 | 相对稳定 |
