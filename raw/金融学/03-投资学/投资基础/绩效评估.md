# 绩效评估

## 🎯 核心概念

### 绩效评估的定义
**绩效评估**是对投资组合或投资策略的表现进行量化分析和评价的过程，通过比较实际收益与基准收益来评估投资效果。

> **费曼解释**：绩效评估就像"投资成绩单"一样。就像学生有成绩单，投资也有成绩单。就像"投资的表现报告"，告诉你投资做得好不好。

### 绩效评估的基本特征
- **量化性**：量化分析指标
- **比较性**：与基准比较
- **全面性**：多维度评估
- **动态性**：动态跟踪评估

## 📊 绩效评估指标

### 1. 收益指标
**绝对收益**：
- **定义**：绝对收益率
- **计算**：R = (P1 - P0) / P0
- **特点**：简单直观
- **应用**：基础收益评估

**年化收益**：
- **定义**：年化收益率
- **计算**：R_annual = (1 + R)^(1/t) - 1
- **特点**：标准化收益
- **应用**：跨期比较

**累计收益**：
- **定义**：累计收益率
- **计算**：R_cumulative = (1 + R1)(1 + R2)...(1 + Rn) - 1
- **特点**：复合收益
- **应用**：长期收益评估

**关联学习**：[[03-投资学/投资基础/投资组合理论|投资组合理论]]

### 2. 风险指标
**波动率**：
- **定义**：收益率标准差
- **计算**：σ = √(Σ(Ri - R̄)² / (n-1))
- **特点**：风险度量
- **应用**：风险评估

**最大回撤**：
- **定义**：最大回撤
- **计算**：MD = max(0, max(Pi) - Pi)
- **特点**：下行风险
- **应用**：风险控制

**VaR**：
- **定义**：风险价值
- **计算**：VaR = μ - σ × Zα
- **特点**：风险度量
- **应用**：风险管理

### 3. 风险调整收益指标
**夏普比率**：
- **定义**：夏普比率
- **计算**：SR = (R - Rf) / σ
- **特点**：风险调整收益
- **应用**：绩效评估

**信息比率**：
- **定义**：信息比率
- **计算**：IR = (R - Rb) / TE
- **特点**：超额收益风险调整
- **应用**：主动管理评估

**索提诺比率**：
- **定义**：索提诺比率
- **计算**：ST = (R - Rf) / σd
- **特点**：下行风险调整
- **应用**：下行风险评估

### 4. 基准比较指标
**超额收益**：
- **定义**：超额收益率
- **计算**：ER = R - Rb
- **特点**：相对收益
- **应用**：基准比较

**跟踪误差**：
- **定义**：跟踪误差
- **计算**：TE = σ(R - Rb)
- **特点**：偏离程度
- **应用**：基准跟踪

**信息比率**：
- **定义**：信息比率
- **计算**：IR = ER / TE
- **特点**：超额收益效率
- **应用**：主动管理评估

## 🔄 绩效评估方法

### 1. 时间序列分析
**收益率分析**：
- **定义**：收益率时间序列分析
- **方法**：统计分析方法
- **指标**：均值、方差、偏度、峰度
- **应用**：收益特征分析

**风险分析**：
- **定义**：风险时间序列分析
- **方法**：风险度量方法
- **指标**：波动率、VaR、ES
- **应用**：风险特征分析

**相关性分析**：
- **定义**：相关性分析
- **方法**：相关系数分析
- **指标**：相关系数、协方差
- **应用**：相关性分析

### 2. 横截面分析
**行业分析**：
- **定义**：行业绩效分析
- **方法**：行业比较分析
- **指标**：行业收益、风险
- **应用**：行业选择

**风格分析**：
- **定义**：投资风格分析
- **方法**：风格分析
- **指标**：价值、成长、小盘、大盘
- **应用**：风格选择

**因子分析**：
- **定义**：因子绩效分析
- **方法**：因子分析
- **指标**：因子收益、风险
- **应用**：因子选择

### 3. 归因分析
**收益归因**：
- **定义**：收益归因分析
- **方法**：收益分解
- **因子**：资产配置、证券选择、交互效应
- **应用**：收益来源分析

**风险归因**：
- **定义**：风险归因分析
- **方法**：风险分解
- **因子**：系统性风险、特异性风险
- **应用**：风险来源分析

**绩效归因**：
- **定义**：绩效归因分析
- **方法**：绩效分解
- **因子**：市场因子、风格因子、个股因子
- **应用**：绩效来源分析

## 📈 绩效评估实践

### 1. 评估流程
**数据收集**：
- **定义**：数据收集
- **内容**：收益率数据、基准数据、风险数据
- **来源**：市场数据、基金数据
- **质量**：数据质量检查

**指标计算**：
- **定义**：指标计算
- **方法**：统计计算方法
- **工具**：Excel、Python、R
- **验证**：计算结果验证

**结果分析**：
- **定义**：结果分析
- **方法**：定量分析方法
- **工具**：图表、统计检验
- **解释**：结果解释

**报告撰写**：
- **定义**：报告撰写
- **内容**：评估结果、分析结论、建议
- **格式**：标准化格式
- **分发**：报告分发

### 2. 评估工具
**Excel工具**：
- **定义**：Excel评估工具
- **功能**：基础计算、图表制作
- **优势**：简单易用
- **局限**：功能有限

**专业软件**：
- **定义**：专业评估软件
- **功能**：高级分析、报告生成
- **优势**：功能强大
- **局限**：成本较高

**编程工具**：
- **定义**：编程评估工具
- **功能**：自定义分析、自动化
- **优势**：灵活性强
- **局限**：技术要求高

### 3. 评估标准
**行业标准**：
- **定义**：行业评估标准
- **内容**：标准指标、计算方法
- **来源**：行业协会、监管机构
- **应用**：标准化评估

**内部标准**：
- **定义**：内部评估标准
- **内容**：内部指标、计算方法
- **来源**：内部制定
- **应用**：内部评估

**客户标准**：
- **定义**：客户评估标准
- **内容**：客户要求、偏好
- **来源**：客户需求
- **应用**：客户评估
