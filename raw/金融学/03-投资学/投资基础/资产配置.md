# 资产配置

## 🎯 核心概念

### 资产配置的定义
**资产配置**是根据投资目标、风险偏好和时间期限，将投资资金分配到不同资产类别的过程，是投资组合管理的核心环节。

> **费曼解释**：资产配置就像"投资资金的分配"一样。就像厨师做菜要分配各种食材，投资者要分配各种资产。就像"投资资金的菜谱"，告诉你如何搭配不同的投资。

### 资产配置的基本特征
- **战略性**：长期投资策略
- **系统性**：系统化配置
- **动态性**：动态调整
- **个性化**：个性化配置

## 📊 资产配置理论

### 1. 现代投资组合理论
**马科维茨模型**：
- **定义**：现代投资组合理论
- **原理**：风险与收益权衡
- **方法**：均值-方差优化
- **应用**：投资组合构建

**有效前沿**：
- **定义**：有效前沿
- **特点**：最优风险收益组合
- **构建**：有效前沿构建
- **应用**：投资组合选择

**资本配置线**：
- **定义**：资本配置线
- **特点**：无风险资产与风险资产组合
- **斜率**：夏普比率
- **应用**：最优配置

**关联学习**：[[03-投资学/投资基础/投资组合理论|投资组合理论]]

### 2. 资本资产定价模型
**CAPM模型**：
- **定义**：资本资产定价模型
- **公式**：E(R) = Rf + β[E(Rm) - Rf]
- **假设**：市场均衡、理性投资者
- **应用**：资产定价

**Beta系数**：
- **定义**：Beta系数
- **计算**：β = Cov(Ri, Rm)/Var(Rm)
- **含义**：系统性风险
- **应用**：风险度量

**证券市场线**：
- **定义**：证券市场线
- **特点**：风险与收益关系
- **应用**：资产定价
- **意义**：市场均衡

### 3. 多因子模型
**Fama-French三因子模型**：
- **定义**：三因子模型
- **因子**：市场因子、规模因子、价值因子
- **公式**：E(R) = Rf + β1[E(Rm) - Rf] + β2SMB + β3HML
- **应用**：资产定价

**Carhart四因子模型**：
- **定义**：四因子模型
- **因子**：市场、规模、价值、动量
- **公式**：E(R) = Rf + β1[E(Rm) - Rf] + β2SMB + β3HML + β4MOM
- **应用**：资产定价

**多因子模型**：
- **定义**：多因子模型
- **因子**：宏观经济因子、基本面因子
- **应用**：资产定价
- **优势**：解释力强
