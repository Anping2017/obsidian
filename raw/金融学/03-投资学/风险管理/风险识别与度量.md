# 风险识别与度量

## 🎯 核心概念

### 风险识别与度量的定义
**风险识别与度量**是投资管理中识别各类风险并对其进行量化分析的过程，为风险管理决策提供科学依据。

> **费曼解释**：风险识别与度量就像"投资的安全检查"一样。就像医生检查病人找出疾病，风险识别找出投资中的危险，风险度量测量危险的程度。就像"投资的健康体检"。

### 风险识别与度量的基本特征
- **系统性**：全面识别各类风险
- **量化性**：对风险进行量化分析
- **动态性**：持续监控风险变化
- **前瞻性**：预测未来风险

## 📊 风险识别

### 1. 市场风险识别
**定义**：
- **概念**：由于市场价格变动导致损失的风险
- **类型**：利率风险、汇率风险、股价风险、商品价格风险
- **特点**：影响面广、难以预测
- **识别**：价格波动分析、相关性分析

**市场风险类型**：
- **利率风险**：利率变动对债券价格的影响
- **汇率风险**：汇率变动对投资的影响
- **股价风险**：股价波动风险
- **商品价格风险**：商品价格波动风险

**市场风险识别方法**：
- **历史分析**：分析历史价格波动
- **相关性分析**：分析资产间相关性
- **情景分析**：分析不同市场情景
- **压力测试**：测试极端市场情况

**关联学习**：[[03-投资学/风险管理/投资组合风险管理|投资组合风险管理]]

### 2. 信用风险识别
**定义**：
- **概念**：交易对手违约导致损失的风险
- **类型**：违约风险、信用等级下降风险
- **特点**：损失严重、难以恢复
- **识别**：信用评级分析、财务分析

**信用风险类型**：
- **违约风险**：交易对手违约
- **信用等级下降**：信用等级下调
- **集中度风险**：信用集中风险
- **关联风险**：关联方风险

**信用风险识别方法**：
- **信用评级**：评估交易对手信用
- **财务分析**：分析财务状况
- **行业分析**：分析行业风险
- **宏观经济分析**：分析宏观环境

### 3. 流动性风险识别
**定义**：
- **概念**：无法及时获得足够资金的风险
- **类型**：融资流动性风险、市场流动性风险
- **特点**：突发性强、影响严重
- **识别**：流动性分析、资金需求分析

**流动性风险类型**：
- **融资流动性风险**：无法获得融资
- **市场流动性风险**：市场流动性不足
- **期限错配风险**：期限不匹配
- **集中度风险**：资金来源集中

**流动性风险识别方法**：
- **现金流分析**：分析现金流状况
- **资金需求分析**：分析资金需求
- **市场流动性分析**：分析市场流动性
- **压力测试**：测试流动性压力

### 4. 操作风险识别
**定义**：
- **概念**：由于内部程序、人员、系统或外部事件导致损失的风险
- **类型**：内部欺诈、外部欺诈、系统故障
- **特点**：难以量化、影响广泛
- **识别**：流程分析、系统分析

**操作风险类型**：
- **内部欺诈**：内部人员欺诈
- **外部欺诈**：外部人员欺诈
- **系统故障**：系统技术故障
- **流程风险**：业务流程风险

**操作风险识别方法**：
- **流程分析**：分析业务流程
- **系统分析**：分析系统风险
- **人员分析**：分析人员风险
- **外部环境分析**：分析外部环境

## 🔄 风险度量

### 1. VaR模型
**定义**：
- **概念**：风险价值模型，衡量在正常市场条件下可能的最大损失
- **计算**：历史模拟法、蒙特卡洛法、参数法
- **应用**：风险限额、资本配置
- **优势**：直观易懂、广泛应用

**VaR计算方法**：
- **历史模拟法**：基于历史数据
- **蒙特卡洛法**：基于随机模拟
- **参数法**：基于统计参数
- **极值理论**：基于极值理论

**VaR模型应用**：
- **风险限额**：设定风险限额
- **资本配置**：配置风险资本
- **绩效评估**：评估风险调整收益
- **监管报告**：向监管机构报告

**关联学习**：[[03-投资学/风险管理/风险模型与工具|风险模型与工具]]

### 2. 压力测试
**定义**：
- **概念**：在极端市场条件下测试投资组合的表现
- **方法**：情景分析、敏感性分析
- **应用**：资本规划、风险预警
- **优势**：测试极端情况

**压力测试方法**：
- **情景分析**：分析特定情景
- **敏感性分析**：分析参数敏感性
- **历史情景**：使用历史极端情景
- **假设情景**：使用假设极端情景

**压力测试应用**：
- **资本规划**：规划风险资本
- **风险预警**：预警极端风险
- **策略调整**：调整投资策略
- **监管合规**：满足监管要求

### 3. 风险指标
**定义**：
- **概念**：衡量投资组合风险的量化指标
- **类型**：波动率、最大回撤、夏普比率
- **应用**：风险监控、绩效评估
- **优势**：简单直观、易于比较

**主要风险指标**：
- **波动率**：衡量价格波动程度
- **最大回撤**：衡量最大损失
- **夏普比率**：衡量风险调整收益
- **信息比率**：衡量超额收益

**风险指标应用**：
- **风险监控**：监控投资组合风险
- **绩效评估**：评估投资绩效
- **基准比较**：与基准比较
- **风险报告**：制作风险报告

### 4. 相关性分析
**定义**：
- **概念**：分析不同资产间的相关性
- **方法**：相关系数、协方差矩阵
- **应用**：分散投资、风险控制
- **优势**：识别风险分散机会

**相关性分析方法**：
- **相关系数**：计算相关系数
- **协方差矩阵**：构建协方差矩阵
- **动态相关性**：分析动态相关性
- **条件相关性**：分析条件相关性

**相关性分析应用**：
- **分散投资**：优化分散投资
- **风险控制**：控制相关性风险
- **对冲策略**：设计对冲策略
- **组合优化**：优化投资组合
