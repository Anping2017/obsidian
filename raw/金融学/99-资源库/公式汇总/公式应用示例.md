# 公式应用示例

## 🎯 核心概念

### 公式应用的重要性
**公式应用**是将金融学公式转化为实际计算和问题解决的过程，是连接理论与实践的桥梁，对于深入理解金融概念和提高实践能力具有重要意义。

> **费曼解释**：公式应用就像"数学公式的实战演练"一样。就像学会了武功招式，还需要在实战中练习才能真正掌握。公式应用就是让金融公式在"实战"中发挥作用，解决实际问题。

### 公式应用的基本特征
- **实用性**：解决实际问题
- **准确性**：计算准确无误
- **灵活性**：适应不同情况
- **可验证性**：结果可验证

## 📊 基础公式应用

### 1. 货币公式应用
**货币乘数计算**：
- **公式**：m = 1 / (r + c + e)
- **应用场景**：分析货币政策效果
- **计算步骤**：
  1. 确定法定准备金率(r)
  2. 确定现金漏损率(c)
  3. 确定超额准备金率(e)
  4. 代入公式计算货币乘数

**实际案例**：
- **数据**：r = 0.1, c = 0.05, e = 0.02
- **计算**：m = 1 / (0.1 + 0.05 + 0.02) = 1 / 0.17 = 5.88
- **解释**：货币乘数为5.88，意味着基础货币每增加1元，货币供应量增加5.88元

**关联学习**：[[01-基础理论/货币与信用/货币供求理论|货币供求理论]]

### 2. 利率公式应用
**实际利率计算**：
- **公式**：实际利率 = 名义利率 - 通货膨胀率
- **应用场景**：投资决策分析
- **计算步骤**：
  1. 确定名义利率
  2. 确定通货膨胀率
  3. 计算实际利率
  4. 分析投资价值

**实际案例**：
- **数据**：名义利率 = 5%, 通货膨胀率 = 2%
- **计算**：实际利率 = 5% - 2% = 3%
- **解释**：实际利率为3%，表示扣除通胀后的真实收益

**复利计算应用**：
- **公式**：FV = PV × (1 + r)^n
- **应用场景**：长期投资规划
- **计算步骤**：
  1. 确定现值(PV)
  2. 确定利率(r)
  3. 确定期数(n)
  4. 计算终值(FV)

**实际案例**：
- **数据**：PV = 10000元, r = 8%, n = 10年
- **计算**：FV = 10000 × (1 + 0.08)^10 = 10000 × 2.159 = 21590元
- **解释**：10年后10000元将增长到21590元

### 3. 其他基础应用
**年金现值计算**：
- **公式**：PVA = PMT × [1 - (1 + r)^(-n)] / r
- **应用场景**：贷款还款计算
- **实际案例**：
  - 贷款金额：100万元
  - 年利率：6%
  - 还款期限：20年
  - 计算：PVA = PMT × [1 - (1 + 0.06)^(-20)] / 0.06
  - 解得：PMT = 87185元/年

## 🔄 投资学公式应用

### 1. 投资组合应用
**投资组合收益计算**：
- **公式**：E(Rp) = Σwi × E(Ri)
- **应用场景**：投资组合构建
- **计算步骤**：
  1. 确定各资产权重(wi)
  2. 确定各资产预期收益(E(Ri))
  3. 计算投资组合预期收益

**实际案例**：
- **资产A**：权重60%，预期收益8%
- **资产B**：权重40%，预期收益12%
- **计算**：E(Rp) = 0.6 × 8% + 0.4 × 12% = 4.8% + 4.8% = 9.6%

**投资组合风险计算**：
- **公式**：σp² = w1²σ1² + w2²σ2² + 2w1w2σ12
- **应用场景**：风险控制
- **实际案例**：
  - 资产A：权重60%，标准差15%
  - 资产B：权重40%，标准差20%
  - 相关系数：0.3
  - 计算：σp² = 0.6² × 15² + 0.4² × 20² + 2 × 0.6 × 0.4 × 0.3 × 15 × 20
  - 结果：σp = 13.2%

**关联学习**：[[03-投资学/投资基础/投资组合理论|投资组合理论]]

### 2. 资产定价应用
**CAPM模型应用**：
- **公式**：E(Ri) = Rf + βi[E(Rm) - Rf]
- **应用场景**：股票估值
- **计算步骤**：
  1. 确定无风险利率(Rf)
  2. 确定市场预期收益(E(Rm))
  3. 确定Beta系数(βi)
  4. 计算股票预期收益

**实际案例**：
- **无风险利率**：3%
- **市场预期收益**：10%
- **Beta系数**：1.2
- **计算**：E(Ri) = 3% + 1.2 × (10% - 3%) = 3% + 8.4% = 11.4%

**债券定价应用**：
- **公式**：P = Σ[C / (1 + r)^t] + [F / (1 + r)^n]
- **应用场景**：债券投资决策
- **实际案例**：
  - 面值：1000元
  - 票面利率：5%
  - 到期时间：3年
  - 市场利率：6%
  - 计算：P = 50/(1.06) + 50/(1.06)² + 50/(1.06)³ + 1000/(1.06)³ = 973.27元

### 3. 风险度量应用
**VaR计算应用**：
- **公式**：VaR = μ - zα × σ
- **应用场景**：风险管理
- **计算步骤**：
  1. 确定置信水平(α)
  2. 计算对应分位数(zα)
  3. 确定预期收益(μ)和标准差(σ)
  4. 计算VaR

**实际案例**：
- **置信水平**：95%
- **预期收益**：8%
- **标准差**：15%
- **分位数**：1.645
- **计算**：VaR = 8% - 1.645 × 15% = -16.7%
- **解释**：95%置信度下，最大损失为16.7%

**关联学习**：[[03-投资学/风险管理/风险识别与度量|风险识别与度量]]

## 📈 公司金融公式应用

### 1. 估值公式应用
**DCF模型应用**：
- **公式**：企业价值 = Σ[CFt / (1 + r)^t] + TV / (1 + r)^n
- **应用场景**：企业估值
- **计算步骤**：
  1. 预测未来现金流(CFt)
  2. 确定折现率(r)
  3. 计算终值(TV)
  4. 计算企业价值

**实际案例**：
- **未来5年现金流**：100, 120, 140, 160, 180万元
- **折现率**：10%
- **终值**：2000万元
- **计算**：
  - 现值 = 100/1.1 + 120/1.1² + 140/1.1³ + 160/1.1⁴ + 180/1.1⁵ = 500万元
  - 终值现值 = 2000/1.1⁵ = 1242万元
  - 企业价值 = 500 + 1242 = 1742万元

**关联学习**：[[04-公司金融/价值评估/现金流折现模型|现金流折现模型]]

### 2. 资本成本应用
**WACC计算应用**：
- **公式**：WACC = (E/V) × Re + (D/V) × Rd × (1 - T)
- **应用场景**：投资决策
- **计算步骤**：
  1. 确定股权价值(E)和债务价值(D)
  2. 计算股权成本(Re)和债务成本(Rd)
  3. 确定税率(T)
  4. 计算WACC

**实际案例**：
- **股权价值**：600万元
- **债务价值**：400万元
- **股权成本**：12%
- **债务成本**：6%
- **税率**：25%
- **计算**：WACC = (600/1000) × 12% + (400/1000) × 6% × (1-0.25) = 7.2% + 1.8% = 9%

### 3. 财务分析应用
**财务比率计算**：
- **流动比率**：流动资产 / 流动负债
- **速动比率**：(流动资产 - 存货) / 流动负债
- **资产负债率**：总负债 / 总资产
- **权益乘数**：总资产 / 股东权益

**实际案例**：
- **流动资产**：200万元
- **存货**：50万元
- **流动负债**：100万元
- **总负债**：300万元
- **总资产**：500万元
- **股东权益**：200万元
- **计算**：
  - 流动比率 = 200/100 = 2
  - 速动比率 = (200-50)/100 = 1.5
  - 资产负债率 = 300/500 = 60%
  - 权益乘数 = 500/200 = 2.5

## 🔒 衍生品公式应用

### 1. 期权定价应用
**Black-Scholes模型应用**：
- **公式**：C = S₀N(d₁) - Ke^(-rT)N(d₂)
- **应用场景**：期权交易
- **计算步骤**：
  1. 确定标的资产价格(S₀)
  2. 确定执行价格(K)
  3. 确定无风险利率(r)
  4. 确定到期时间(T)
  5. 确定波动率(σ)
  6. 计算d₁和d₂
  7. 计算期权价格

**实际案例**：
- **股票价格**：100元
- **执行价格**：105元
- **无风险利率**：5%
- **到期时间**：0.25年
- **波动率**：20%
- **计算**：
  - d₁ = [ln(100/105) + (0.05 + 0.2²/2) × 0.25] / (0.2 × √0.25) = -0.073
  - d₂ = -0.073 - 0.2 × √0.25 = -0.173
  - N(d₁) = 0.471, N(d₂) = 0.431
  - C = 100 × 0.471 - 105 × e^(-0.05×0.25) × 0.431 = 2.13元

**关联学习**：[[03-投资学/衍生品/期权定价|期权定价]]

### 2. 期货定价应用
**期货价格计算**：
- **公式**：F = S × e^(rT)
- **应用场景**：期货交易
- **实际案例**：
  - 现货价格：100元
  - 无风险利率：5%
  - 到期时间：0.5年
  - 计算：F = 100 × e^(0.05×0.5) = 102.53元

### 3. 风险管理应用
**Delta对冲应用**：
- **公式**：Δ = ∂C/∂S = N(d₁)
- **应用场景**：期权风险管理
- **实际案例**：
  - Delta = 0.5
  - 期权数量：1000份
  - 对冲比例：0.5
  - 需要卖空股票：1000 × 0.5 = 500股
