# 金融学公式大全

## 🎯 核心概念

### 公式学习的重要性
**金融学公式**是金融理论的数学表达，掌握公式有助于理解金融现象、进行定量分析和解决实际问题。

> **费曼解释**：金融公式就像数学公式一样，是描述金融规律的"语言"。就像物理公式描述物理规律一样，金融公式描述金融规律。

### 公式分类
- **基础公式**：时间价值、复利计算
- **投资公式**：投资组合、资产定价
- **风险管理公式**：VaR、期权定价
- **公司金融公式**：估值、资本成本

## 💰 时间价值公式

### 1. 复利公式
**终值公式**：
```
FV = PV × (1 + r)^n
```
- **FV**：终值
- **PV**：现值
- **r**：利率
- **n**：期数

**现值公式**：
```
PV = FV / (1 + r)^n
```

**关联学习**：[[01-基础理论/货币与信用/利率理论|利率理论]]

### 2. 年金公式
**普通年金终值**：
```
FVA = PMT × [(1 + r)^n - 1] / r
```
- **FVA**：年金终值
- **PMT**：每期支付额

**普通年金现值**：
```
PVA = PMT × [1 - (1 + r)^(-n)] / r
```

**永续年金现值**：
```
PVA = PMT / r
```

### 3. 连续复利
**连续复利终值**：
```
FV = PV × e^(rt)
```
- **e**：自然对数的底数
- **t**：时间（年）

## 📊 投资组合公式

### 1. 投资组合收益
**投资组合预期收益**：
```
E(Rp) = Σwi × E(Ri)
```
- **E(Rp)**：投资组合预期收益
- **wi**：资产i的权重
- **E(Ri)**：资产i的预期收益

**关联学习**：[[03-投资学/投资基础/投资组合理论|投资组合理论]]

### 2. 投资组合风险
**投资组合方差**：
```
σp² = ΣΣwiwjσij
```
- **σp²**：投资组合方差
- **σij**：资产i和j的协方差

**两资产组合方差**：
```
σp² = w1²σ1² + w2²σ2² + 2w1w2σ12
```

### 3. 相关系数
**相关系数**：
```
ρij = σij / (σi × σj)
```
- **ρij**：资产i和j的相关系数
- **σi**：资产i的标准差

## 🎯 资产定价公式

### 1. CAPM模型
**CAPM公式**：
```
E(Ri) = Rf + βi[E(Rm) - Rf]
```
- **E(Ri)**：资产i的预期收益
- **Rf**：无风险利率
- **βi**：资产i的Beta系数
- **E(Rm)**：市场组合的预期收益

**Beta系数**：
```
βi = Cov(Ri, Rm) / Var(Rm)
```

**关联学习**：[[03-投资学/投资基础/资产定价模型|资产定价模型]]

### 2. APT模型
**APT公式**：
```
E(Ri) = Rf + Σβij × λj
```
- **βij**：资产i对因子j的敏感度
- **λj**：因子j的风险溢价

### 3. 债券定价
**债券价格**：
```
P = Σ[C / (1 + r)^t] + [F / (1 + r)^n]
```
- **P**：债券价格
- **C**：每期利息
- **F**：面值
- **r**：到期收益率

## 🔒 风险管理公式

### 1. VaR计算
**参数VaR**：
```
VaR = μ - zα × σ
```
- **μ**：预期收益
- **zα**：置信水平对应的分位数
- **σ**：标准差

**历史VaR**：
```
VaR = -Percentile(Returns, α)
```

**关联学习**：[[03-投资学/风险管理/风险识别与度量|风险识别与度量]]

### 2. 期权定价
**Black-Scholes公式**：
```
C = S₀N(d₁) - Ke^(-rT)N(d₂)
P = Ke^(-rT)N(-d₂) - S₀N(-d₁)
```

**其中**：
```
d₁ = [ln(S₀/K) + (r + σ²/2)T] / (σ√T)
d₂ = d₁ - σ√T
```
- **C**：看涨期权价格
- **P**：看跌期权价格
- **S₀**：标的资产价格
- **K**：执行价格
- **r**：无风险利率
- **T**：到期时间
- **σ**：波动率

### 3. 希腊字母
**Delta**：
```
Δ = ∂C/∂S = N(d₁)
```

**Gamma**：
```
Γ = ∂²C/∂S² = N'(d₁) / (Sσ√T)
```

**Theta**：
```
Θ = ∂C/∂T = -SN'(d₁)σ/(2√T) - rKe^(-rT)N(d₂)
```

**Vega**：
```
ν = ∂C/∂σ = S√TN'(d₁)
```

## 🏢 公司金融公式

### 1. 企业估值
**DCF模型**：
```
企业价值 = Σ[CFt / (1 + r)^t] + TV / (1 + r)^n
```
- **CFt**：第t年现金流
- **r**：折现率
- **TV**：终值

**关联学习**：[[04-公司金融/价值评估/现金流折现模型|现金流折现模型]]

### 2. 资本成本
**WACC公式**：
```
WACC = (E/V) × Re + (D/V) × Rd × (1 - T)
```
- **E**：股权价值
- **D**：债务价值
- **V**：企业总价值
- **Re**：股权成本
- **Rd**：债务成本
- **T**：税率

**股权成本（CAPM）**：
```
Re = Rf + β[E(Rm) - Rf]
```

**关联学习**：[[04-公司金融/资本结构/资本成本|资本成本]]

### 3. 财务比率
**流动比率**：
```
流动比率 = 流动资产 / 流动负债
```

**速动比率**：
```
速动比率 = (流动资产 - 存货) / 流动负债
```

**资产负债率**：
```
资产负债率 = 总负债 / 总资产
```

**权益乘数**：
```
权益乘数 = 总资产 / 股东权益
```

## 🌍 国际金融公式

### 1. 汇率理论
**购买力平价**：
```
S = P / P*
```
- **S**：汇率
- **P**：国内价格水平
- **P***：国外价格水平

**利率平价**：
```
F = S × (1 + r) / (1 + r*)
```
- **F**：远期汇率
- **S**：即期汇率
- **r**：国内利率
- **r***：国外利率

**关联学习**：[[05-国际金融/汇率理论/汇率决定理论|汇率决定理论]]

### 2. 国际收支
**国际收支平衡**：
```
CA + KA + FA = 0
```
- **CA**：经常账户
- **KA**：资本账户
- **FA**：金融账户

## 📈 统计公式

### 1. 描述性统计
**均值**：
```
μ = Σxi / n
```

**方差**：
```
σ² = Σ(xi - μ)² / n
```

**标准差**：
```
σ = √σ²
```

**协方差**：
```
Cov(X,Y) = Σ(xi - μx)(yi - μy) / n
```

### 2. 回归分析
**简单线性回归**：
```
Y = α + βX + ε
```

**回归系数**：
```
β = Cov(X,Y) / Var(X)
α = Ȳ - βX̄
```

**R²**：
```
R² = 1 - SSE / SST
```

**关联学习**：[[07-数学工具/量化方法/回归分析|回归分析]]
