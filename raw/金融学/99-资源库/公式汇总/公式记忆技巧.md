## 🎯 核心概念

### 公式记忆的重要性
**公式记忆**是掌握金融学公式的关键环节，有效的记忆方法能够提高学习效率，加深对公式的理解，为实际应用打下坚实基础。

> **费曼解释**：公式记忆就像"数学公式的背诵技巧"一样。就像背古诗需要理解意境，背公式也需要理解含义。就像"公式的密码本"，掌握了记忆技巧，就能快速"解码"各种金融公式。

### 公式记忆的基本特征
- **理解性**：基于理解的记忆
- **系统性**：系统化的记忆方法
- **实用性**：注重实际应用
- **持久性**：长期记忆效果

## 🔄 公式分类记忆

### 1. 货币金融公式
**时间价值公式**：
- **复利公式**：FV = PV(1+r)^n
- **现值公式**：PV = FV/(1+r)^n
- **年金公式**：PVA = PMT[1-(1+r)^(-n)]/r
- **记忆技巧**：时间价值是金融基础，复利是核心

**利率公式**：
- **名义利率**：i = r + π
- **实际利率**：r = i - π
- **连续复利**：FV = PV × e^(rt)
- **记忆技巧**：利率是货币价格，名义实际要区分

**货币乘数公式**：
- **货币乘数**：m = 1/(r+c+e)
- **货币供应**：M = m × B
- **记忆技巧**：乘数效应，准备金是关键

**关联学习**：[[01-基础理论/货币与信用/利率理论|利率理论]]

### 2. 投资学公式
**投资组合公式**：
- **组合收益**：E(Rp) = ΣwiE(Ri)
- **组合风险**：σp² = ΣΣwiwjσij
- **相关系数**：ρij = σij/(σiσj)
- **记忆技巧**：组合是加权平均，风险要考虑相关性

**资产定价公式**：
- **CAPM**：E(Ri) = Rf + βi[E(Rm)-Rf]
- **Beta系数**：βi = Cov(Ri,Rm)/Var(Rm)
- **APT**：E(Ri) = Rf + Σβijλj
- **记忆技巧**：定价看风险，Beta是关键

**债券定价公式**：
- **债券价格**：P = Σ[C/(1+r)^t] + [F/(1+r)^n]
- **久期公式**：D = Σ[t×C/(1+r)^t]/P
- **凸性公式**：C = Σ[t(t+1)×C/(1+r)^t]/P
- **记忆技巧**：债券是现金流，久期凸性看敏感性

**关联学习**：[[03-投资学/投资基础/投资组合理论|投资组合理论]]

### 3. 公司金融公式
**估值公式**：
- **DCF模型**：V = Σ[CFt/(1+r)^t] + TV/(1+r)^n
- **WACC**：WACC = (E/V)Re + (D/V)Rd(1-T)
- **股权成本**：Re = Rf + β[E(Rm)-Rf]
- **记忆技巧**：估值看现金流，折现率是关键

**财务比率公式**：
- **流动比率**：流动资产/流动负债
- **速动比率**：(流动资产-存货)/流动负债
- **资产负债率**：总负债/总资产
- **权益乘数**：总资产/股东权益
- **记忆技巧**：比率看结构，流动性是关键

**资本结构公式**：
- **MM理论**：VL = VU + TD
- **最优资本结构**：WACC最小化
- **记忆技巧**：结构影响成本，税收是关键

**关联学习**：[[04-公司金融/价值评估/现金流折现模型|现金流折现模型]]

### 4. 衍生品公式
**期权定价公式**：
- **Black-Scholes**：C = S₀N(d₁) - Ke^(-rT)N(d₂)
- **d₁公式**：d₁ = [ln(S₀/K) + (r+σ²/2)T]/(σ√T)
- **d₂公式**：d₂ = d₁ - σ√T
- **记忆技巧**：期权看概率，波动率是关键

**希腊字母公式**：
- **Delta**：Δ = ∂C/∂S = N(d₁)
- **Gamma**：Γ = ∂²C/∂S² = N'(d₁)/(Sσ√T)
- **Theta**：Θ = ∂C/∂T
- **Vega**：ν = ∂C/∂σ = S√TN'(d₁)
- **记忆技巧**：希腊字母看敏感性，Delta最重要

**期货定价公式**：
- **期货价格**：F = S × e^(rT)
- **基差**：Basis = S - F
- **记忆技巧**：期货看现货，利率是关键

**关联学习**：[[03-投资学/衍生品/期权定价|期权定价]]
