# 术语学习卡片

## 🎯 核心概念

### 术语学习卡片的重要性
**术语学习卡片**是金融学学习的重要工具，通过卡片化的方式帮助学习者系统掌握金融学术语，提高学习效率和记忆效果。

> **费曼解释**：术语学习卡片就像"金融学的单词卡片"一样。就像学英语需要单词卡片，学金融需要术语卡片。就像"金融学的记忆工具"，通过卡片反复练习，让术语深深印在脑海里。

### 术语学习卡片的基本特征
- **便携性**：便于携带和使用
- **系统性**：系统化的知识组织
- **互动性**：支持互动学习
- **有效性**：提高学习效果

## 🔄 术语卡片分类

### 1. 货币金融卡片
**货币基础卡片**：
- **货币**：作为交换媒介、价值尺度和价值储藏手段的商品
- **基础货币**：中央银行发行的货币，包括流通中现金和银行准备金
- **货币供应量**：一定时点上全社会货币存量的总和
- **货币乘数**：货币供应量与基础货币的比率

**利率相关卡片**：
- **利率**：资金使用权的价格
- **名义利率**：未扣除通货膨胀因素的利率
- **实际利率**：扣除通货膨胀因素后的利率
- **基准利率**：金融市场的基础利率

**货币政策卡片**：
- **货币政策**：中央银行调节货币供应量和利率的政策
- **公开市场操作**：央行在公开市场买卖证券的操作
- **存款准备金率**：银行必须向央行缴纳的准备金比率
- **再贴现率**：央行向银行提供贷款的利率

**关联学习**：[[01-基础理论/货币与信用/货币本质与职能|货币本质与职能]]

### 2. 投资学卡片
**投资工具卡片**：
- **股票**：股份公司发行的所有权凭证
- **债券**：债务人发行的债务凭证
- **基金**：集合投资工具
- **衍生品**：以基础资产为标的的金融工具

**投资策略卡片**：
- **价值投资**：以低于内在价值的价格买入股票
- **成长投资**：投资具有高成长潜力的公司
- **技术分析**：通过价格和成交量分析预测走势
- **量化投资**：运用数学模型和计算机技术投资

**风险管理卡片**：
- **风险**：未来结果的不确定性
- **VaR**：风险价值，在给定置信水平下的最大损失
- **对冲**：通过相反头寸降低风险
- **分散化**：通过投资组合降低风险

**关联学习**：[[03-投资学/投资基础/投资工具|投资工具]]

### 3. 公司金融卡片
**估值相关卡片**：
- **企业价值**：企业所有资产的市场价值
- **DCF**：现金流折现模型
- **WACC**：加权平均资本成本
- **Beta系数**：资产相对于市场的风险系数

**资本结构卡片**：
- **资本结构**：企业各种资本的构成比例
- **MM理论**：莫迪利安尼-米勒理论
- **财务杠杆**：企业使用债务资本的程度
- **股利政策**：企业股利分配的政策

**公司治理卡片**：
- **公司治理**：公司内部权力分配和制衡机制
- **董事会**：公司最高决策机构
- **内部控制**：企业内部风险控制机制
- **并购**：企业合并与收购

**关联学习**：[[04-公司金融/价值评估/企业价值评估|企业价值评估]]

### 4. 国际金融卡片
**汇率相关卡片**：
- **汇率**：两种货币之间的兑换比率
- **购买力平价**：汇率等于两国价格水平之比
- **利率平价**：远期汇率等于即期汇率乘以利率比
- **汇率风险**：汇率变动带来的风险

**国际市场卡片**：
- **国际收支**：一国对外经济往来的记录
- **经常账户**：货物和服务贸易、收入、转移支付
- **资本账户**：资本转移和非生产性资产交易
- **金融账户**：直接投资、证券投资、其他投资

**国际组织卡片**：
- **IMF**：国际货币基金组织
- **世界银行**：世界银行集团
- **BIS**：国际清算银行
- **G20**：二十国集团

**关联学习**：[[05-国际金融/汇率理论/汇率决定理论|汇率决定理论]]
