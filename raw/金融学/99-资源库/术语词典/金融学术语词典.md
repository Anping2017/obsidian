# 金融学术语词典

## 🎯 核心概念

### 金融学术语的重要性
**金融学术语**是金融学知识体系的基础构成要素，准确理解和掌握专业术语是深入学习金融学的前提条件，也是进行专业交流和学术研究的重要工具。

> **费曼解释**：金融学术语就像"金融学的词汇表"一样。就像学英语需要掌握单词，学金融需要掌握术语。就像"金融学的语言"，掌握了术语，就能更好地理解和表达金融概念。

### 金融学术语的基本特征
- **专业性**：具有专业含义
- **准确性**：定义准确清晰
- **系统性**：形成完整体系
- **发展性**：不断更新发展

## 📊 货币金融术语

### 1. 货币相关术语
**货币**：
- **定义**：作为交换媒介、价值尺度和价值储藏手段的商品
- **特征**：普遍接受性、可分割性、耐久性、便携性
- **类型**：商品货币、信用货币、电子货币
- **功能**：交换媒介、价值尺度、价值储藏、支付手段

**基础货币**：
- **定义**：中央银行发行的货币，包括流通中现金和银行准备金
- **构成**：流通中现金(C) + 银行准备金(R)
- **特点**：中央银行直接控制、货币创造基础
- **影响**：货币供应量的基础

**货币供应量**：
- **定义**：一定时点上全社会货币存量的总和
- **层次**：M0、M1、M2、M3
- **计算**：M = C + D（现金+存款）
- **影响**：影响物价水平和经济活动

**货币乘数**：
- **定义**：货币供应量与基础货币的比率
- **公式**：m = M/B = (C+D)/(C+R)
- **影响因素**：法定准备金率、现金漏损率、超额准备金率
- **作用**：反映货币创造能力

**关联学习**：[[01-基础理论/货币与信用/货币本质与职能|货币本质与职能]]

### 2. 信用相关术语
**信用**：
- **定义**：以偿还为条件的价值运动形式
- **特征**：偿还性、有偿性、风险性
- **类型**：商业信用、银行信用、国家信用、消费信用
- **作用**：促进经济发展、调节经济结构

**信用工具**：
- **定义**：证明债权债务关系的书面凭证
- **类型**：商业票据、银行票据、债券、股票
- **特征**：流动性、收益性、风险性
- **功能**：融资工具、投资工具、支付工具

**信用风险**：
- **定义**：债务人不能按时偿还债务的风险
- **类型**：违约风险、信用降级风险、集中度风险
- **评估**：信用评级、财务分析、行业分析
- **管理**：分散化、担保、保险

**信用评级**：
- **定义**：对债务人信用状况的评估
- **等级**：AAA、AA、A、BBB、BB、B、CCC、CC、C、D
- **机构**：标普、穆迪、惠誉、中诚信
- **作用**：投资决策、风险管理、监管要求

### 3. 利率相关术语
**利率**：
- **定义**：资金使用权的价格
- **类型**：名义利率、实际利率、市场利率、政策利率
- **决定因素**：资金供求、通货膨胀、风险水平、政策因素
- **作用**：资源配置、经济调节、投资决策

**名义利率**：
- **定义**：未扣除通货膨胀因素的利率
- **特点**：包含通货膨胀预期
- **计算**：i = r + π（实际利率+通胀率）
- **应用**：合同利率、市场报价利率

**实际利率**：
- **定义**：扣除通货膨胀因素后的利率
- **特点**：反映真实收益
- **计算**：r = i - π（名义利率-通胀率）
- **应用**：投资决策、经济分析

**基准利率**：
- **定义**：金融市场的基础利率
- **类型**：央行基准利率、市场基准利率
- **作用**：定价基准、政策工具
- **影响**：影响其他利率水平

**关联学习**：[[01-基础理论/货币与信用/利率理论|利率理论]]

### 4. 其他货币术语
**货币政策**：
- **定义**：中央银行调节货币供应量和利率的政策
- **目标**：物价稳定、充分就业、经济增长、国际收支平衡
- **工具**：公开市场操作、存款准备金率、再贴现率
- **传导机制**：利率渠道、信贷渠道、资产价格渠道

**货币市场**：
- **定义**：短期资金融通市场
- **特点**：期限短、流动性强、风险低
- **工具**：国库券、商业票据、银行承兑汇票、回购协议
- **参与者**：银行、企业、政府、个人

**资本市场**：
- **定义**：长期资金融通市场
- **特点**：期限长、流动性相对较弱、风险较高
- **工具**：股票、债券、基金
- **参与者**：企业、政府、机构投资者、个人投资者

## 🔄 投资学术语

### 1. 投资工具术语
**股票**：
- **定义**：股份公司发行的所有权凭证
- **类型**：普通股、优先股、A股、B股、H股
- **特征**：所有权、收益权、投票权、转让权
- **风险**：市场风险、公司风险、流动性风险

**债券**：
- **定义**：债务人发行的债务凭证
- **类型**：国债、企业债、金融债、可转债
- **特征**：固定收益、到期还本、优先受偿
- **风险**：信用风险、利率风险、流动性风险

**基金**：
- **定义**：集合投资工具
- **类型**：股票基金、债券基金、混合基金、指数基金
- **特征**：专业管理、分散投资、流动性好
- **风险**：市场风险、管理风险、流动性风险

**衍生品**：
- **定义**：以基础资产为标的的金融工具
- **类型**：期货、期权、互换、远期
- **特征**：杠杆效应、风险转移、价格发现
- **风险**：市场风险、信用风险、流动性风险

**关联学习**：[[03-投资学/投资基础/投资工具|投资工具]]

### 2. 投资策略术语
**价值投资**：
- **定义**：以低于内在价值的价格买入股票
- **特点**：长期持有、基本面分析、安全边际
- **代表人物**：巴菲特、格雷厄姆
- **适用条件**：市场低估、公司基本面良好

**成长投资**：
- **定义**：投资具有高成长潜力的公司
- **特点**：关注成长性、高估值、高风险
- **代表人物**：彼得·林奇
- **适用条件**：高成长行业、优秀管理层

**技术分析**：
- **定义**：通过价格和成交量分析预测走势
- **方法**：图表分析、技术指标、形态分析
- **假设**：价格反映一切信息、趋势延续
- **局限性**：滞后性、主观性

**量化投资**：
- **定义**：运用数学模型和计算机技术投资
- **特点**：系统性、客观性、高效性
- **方法**：统计套利、因子投资、机器学习
- **优势**：消除情绪影响、提高效率

**关联学习**：[[03-投资学/投资策略/投资策略|投资策略]]

### 3. 风险管理术语
**风险**：
- **定义**：未来结果的不确定性
- **类型**：市场风险、信用风险、操作风险、流动性风险
- **特征**：客观性、不确定性、可测性
- **管理**：识别、评估、控制、监控

**VaR**：
- **定义**：风险价值，在给定置信水平下的最大损失
- **计算**：VaR = μ - zα × σ
- **应用**：风险管理、资本配置、绩效评估
- **局限性**：假设条件、尾部风险

**对冲**：
- **定义**：通过相反头寸降低风险
- **类型**：完全对冲、部分对冲、动态对冲
- **工具**：期货、期权、互换
- **目的**：降低风险、锁定收益

**分散化**：
- **定义**：通过投资组合降低风险
- **原理**：相关性、协方差
- **方法**：资产配置、行业分散、地域分散
- **效果**：降低非系统性风险

**关联学习**：[[03-投资学/风险管理/风险识别与度量|风险识别与度量]]

### 4. 其他投资术语
**投资组合**：
- **定义**：投资者持有的各种资产的组合
- **理论**：马科维茨投资组合理论
- **优化**：有效前沿、最优组合
- **管理**：资产配置、再平衡、绩效评估

**有效市场假说**：
- **定义**：市场价格充分反映所有信息
- **形式**：弱式、半强式、强式
- **含义**：无法通过分析获得超额收益
- **挑战**：行为金融学、市场异常

**CAPM**：
- **定义**：资本资产定价模型
- **公式**：E(Ri) = Rf + βi[E(Rm) - Rf]
- **假设**：市场均衡、同质预期、无摩擦
- **应用**：资产定价、投资决策

## 📈 公司金融术语

### 1. 估值相关术语
**企业价值**：
- **定义**：企业所有资产的市场价值
- **计算**：股权价值 + 净债务
- **方法**：DCF、相对估值、资产基础法
- **应用**：投资决策、并购定价

**DCF**：
- **定义**：现金流折现模型
- **公式**：V = Σ[CFt/(1+r)^t] + TV/(1+r)^n
- **要素**：现金流、折现率、终值
- **优势**：理论基础强、适用性广

**WACC**：
- **定义**：加权平均资本成本
- **公式**：WACC = (E/V)Re + (D/V)Rd(1-T)
- **构成**：股权成本、债务成本、权重
- **应用**：投资决策、企业估值

**Beta系数**：
- **定义**：资产相对于市场的风险系数
- **计算**：β = Cov(Ri,Rm)/Var(Rm)
- **含义**：系统性风险、市场敏感性
- **应用**：风险调整、资本成本

**关联学习**：[[04-公司金融/价值评估/企业价值评估|企业价值评估]]

### 2. 资本结构术语
**资本结构**：
- **定义**：企业各种资本的构成比例
- **构成**：股权资本、债务资本
- **理论**：MM理论、权衡理论、优序融资理论
- **影响**：资本成本、企业价值、财务风险

**MM理论**：
- **定义**：莫迪利安尼-米勒理论
- **内容**：无税情况下资本结构不影响企业价值
- **修正**：有税情况下债务有税盾效应
- **意义**：资本结构理论的基础

**财务杠杆**：
- **定义**：企业使用债务资本的程度
- **计算**：财务杠杆 = 总资产/股东权益
- **作用**：放大收益、放大风险
- **管理**：适度杠杆、风险控制

**股利政策**：
- **定义**：企业股利分配的政策
- **类型**：稳定股利、固定股利支付率、剩余股利
- **理论**：股利无关论、股利相关论
- **因素**：盈利能力、现金流、投资机会

### 3. 公司治理术语
**公司治理**：
- **定义**：公司内部权力分配和制衡机制
- **结构**：股东大会、董事会、监事会、管理层
- **原则**：股东权利、平等对待、信息披露
- **目标**：保护股东利益、提高企业价值

**董事会**：
- **定义**：公司最高决策机构
- **构成**：执行董事、独立董事
- **职责**：战略决策、监督管理层、风险控制
- **独立性**：独立董事、专业委员会

**内部控制**：
- **定义**：企业内部风险控制机制
- **要素**：控制环境、风险评估、控制活动、信息沟通、监督
- **目标**：经营效率、财务报告、合规性
- **实施**：制度建设、流程设计、监督检查

**关联学习**：[[04-公司金融/公司治理/公司治理结构|公司治理结构]]

### 4. 其他公司金融术语
**并购**：
- **定义**：企业合并与收购
- **类型**：横向并购、纵向并购、混合并购
- **动机**：协同效应、规模经济、市场扩张
- **风险**：整合风险、财务风险、文化风险

**IPO**：
- **定义**：首次公开发行
- **过程**：尽职调查、路演、定价、发行
- **条件**：盈利能力、公司治理、信息披露
- **影响**：融资、知名度、流动性

**私募股权**：
- **定义**：非公开市场的股权投资
- **类型**：风险投资、成长资本、并购基金
- **特点**：长期投资、主动管理、高收益
- **风险**：流动性风险、管理风险

## 🌍 国际金融术语

### 1. 汇率相关术语
**汇率**：
- **定义**：两种货币之间的兑换比率
- **标价**：直接标价、间接标价
- **类型**：即期汇率、远期汇率
- **决定**：购买力平价、利率平价、国际收支

**购买力平价**：
- **定义**：汇率等于两国价格水平之比
- **公式**：S = P/P*
- **类型**：绝对购买力平价、相对购买力平价
- **局限性**：假设条件、实际偏差

**利率平价**：
- **定义**：远期汇率等于即期汇率乘以利率比
- **公式**：F = S × (1+r)/(1+r*)
- **类型**：抛补利率平价、非抛补利率平价
- **含义**：利率差异决定汇率预期

**汇率风险**：
- **定义**：汇率变动带来的风险
- **类型**：交易风险、折算风险、经济风险
- **管理**：对冲、分散化、自然对冲
- **工具**：远期、期货、期权

**关联学习**：[[05-国际金融/汇率理论/汇率决定理论|汇率决定理论]]

### 2. 国际市场术语
**国际收支**：
- **定义**：一国对外经济往来的记录
- **构成**：经常账户、资本账户、金融账户
- **平衡**：CA + KA + FA = 0
- **分析**：结构分析、趋势分析、政策含义

**经常账户**：
- **定义**：货物和服务贸易、收入、转移支付
- **构成**：贸易收支、服务收支、收入收支、转移收支
- **影响**：汇率、经济增长、就业
- **政策**：贸易政策、汇率政策

**资本账户**：
- **定义**：资本转移和非生产性资产交易
- **构成**：资本转移、非生产性资产
- **特点**：规模小、波动大
- **管理**：资本管制、自由化

**金融账户**：
- **定义**：直接投资、证券投资、其他投资
- **构成**：直接投资、证券投资、其他投资、储备资产
- **影响**：资本流动、汇率、货币政策
- **管理**：资本流动管理、宏观审慎政策

- **议题**：经济增长、金融稳定、贸易
- **影响**：全球经济治理、政策协调
