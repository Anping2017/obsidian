# 金融衍生品

## 🎯 核心概念

### 金融衍生品的定义
**金融衍生品**是以基础金融工具为标的，通过合约形式约定未来某一时间进行交割的金融工具，包括期货、期权、掉期、远期等。

> **费曼解释**：金融衍生品就像"金融工具的保险"一样。就像保险保护你的财产，衍生品保护你的金融投资。就像"金融工具的未来合约"，约定未来某个时间以某个价格交易。

### 金融衍生品的基本特征
- **衍生性**：基于基础工具衍生
- **合约性**：通过合约约定
- **杠杆性**：具有杠杆效应
- **风险性**：风险较高

### 2. 按交易方式分类
**场内衍生品**：
- **定义**：交易所交易衍生品
- **特点**：标准化、透明度高
- **参与者**：各类投资者
- **功能**：价格发现、风险管理

- **定义**：柜台交易衍生品

### 3. 按合约类型分类
**期货合约**：
- **定义**：标准化远期合约
- **特点**：标准化、保证金交易
- **功能**：套期保值、投机
- **风险**：价格风险、流动性风险

**期权合约**：
- **定义**：选择权合约
- **特点**：权利非义务、非线性收益
- **功能**：风险管理、投机
- **风险**：时间价值风险、波动率风险

**掉期合约**：
- **定义**：交换现金流合约
- **特点**：定制化、长期性
- **功能**：风险管理、套利
- **风险**：信用风险、流动性风险

**远期合约**：
- **定义**：未来交割合约
- **特点**：定制化、无保证金
- **功能**：套期保值、投机
- **风险**：信用风险、价格风险

## 🔄 金融衍生品定价

### 1. 期货定价理论
**无套利定价**：
- **定义**：无套利定价理论
- **原理**：无套利机会
- **公式**：F = S(1+r)^T
- **应用**：期货定价

**持有成本模型**：
- **定义**：持有成本模型
- **构成**：现货价格、持有成本、便利收益
- **公式**：F = S + C - Y
- **应用**：商品期货定价

**期货价格影响因素**：
- **现货价格**：现货价格变化
- **利率水平**：利率水平变化
- **持有成本**：持有成本变化
- **便利收益**：便利收益变化

### 2. 期权定价理论
**Black-Scholes模型**：
- **定义**：Black-Scholes期权定价模型
- **假设**：无风险利率、无股息、对数正态分布
- **公式**：C = SN(d1) - Ke^(-rT)N(d2)
- **应用**：欧式期权定价

**二叉树模型**：
- **定义**：二叉树期权定价模型
- **原理**：风险中性定价
- **方法**：动态规划
- **应用**：美式期权定价

**期权价格影响因素**：
- **标的资产价格**：标的资产价格
- **执行价格**：执行价格
- **到期时间**：到期时间
- **波动率**：波动率
- **无风险利率**：无风险利率

### 3. 掉期定价理论
**利率掉期定价**：
- **定义**：利率掉期定价
- **原理**：固定利率与浮动利率交换
- **定价**：基于利率曲线
- **应用**：利率风险管理

**货币掉期定价**：
- **定义**：货币掉期定价
- **原理**：不同货币交换
- **定价**：基于汇率和利率
- **应用**：汇率风险管理

**掉期价格影响因素**：
- **利率水平**：利率水平变化
- **汇率水平**：汇率水平变化
- **信用风险**：信用风险变化
- **流动性风险**：流动性风险变化
