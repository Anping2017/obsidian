# 借贷记账法

## 借贷记账法的定义

### 📖 基本定义
**借贷记账法**是以"借"和"贷"作为记账符号，以"有借必有贷，借贷必相等"作为记账规则的一种复式记账方法。

### 🔍 定义解析
- **记账符号**：以"借"和"贷"作为记账符号
- **记账规则**：有借必有贷，借贷必相等
- **记账方法**：复式记账方法
- **理论基础**：会计等式理论

### 🎯 基本特点
1. **复式记账**：对每笔经济业务都要在两个或两个以上账户中记录
2. **借贷平衡**：每笔经济业务的借贷金额相等
3. **账户对应**：账户之间存在对应关系
4. **试算平衡**：可以通过试算平衡检查记账正确性

## 借贷记账法的基本原理

### ⚖️ 理论基础

#### 1. 会计等式理论
- **基本等式**：资产 = 负债 + 所有者权益
- **扩展等式**：资产 = 负债 + 所有者权益 + 收入 - 费用
- **平衡原理**：等式两边必须保持平衡
- **变化规律**：经济业务不会破坏等式平衡

#### 2. 复式记账原理
- **双重记录**：每笔经济业务都要在两个或两个以上账户中记录
- **相互联系**：账户之间相互联系
- **完整反映**：完整反映经济业务的来龙去脉
- **平衡验证**：通过平衡关系验证记账正确性

### 🔄 记账规则

#### 1. 基本规则
**有借必有贷，借贷必相等**

#### 2. 规则解析
- **有借必有贷**：每笔经济业务至少涉及一个借方账户和一个贷方账户
- **借贷必相等**：每笔经济业务的借方金额合计等于贷方金额合计
- **方向相反**：借方和贷方方向相反
- **金额相等**：借方和贷方金额相等

#### 3. 规则应用
- **简单分录**：一借一贷
- **复合分录**：一借多贷或多借一贷
- **复杂分录**：多借多贷

```
│  借方（左方）    │  贷方（右方）
├─────────────────┤
│                 │
│                 │
│                 │
└─────────────────┘
```

#### 结构特点
- **左右对称**：借方在左，贷方在右
- **方向明确**：借贷方向明确
- **平衡关系**：保持借贷平衡
- **便于理解**：结构简单明了

### 🎯 各类账户结构

#### 1. 资产类账户
- **增加方向**：借方
- **减少方向**：贷方
- **余额方向**：借方
- **余额计算**：期末余额 = 期初余额 + 本期借方发生额 - 本期贷方发生额

#### 2. 负债类账户
- **增加方向**：贷方
- **减少方向**：借方
- **余额方向**：贷方
- **余额计算**：期末余额 = 期初余额 + 本期贷方发生额 - 本期借方发生额

#### 3. 所有者权益类账户
- **增加方向**：贷方
- **减少方向**：借方
- **余额方向**：贷方
- **余额计算**：期末余额 = 期初余额 + 本期贷方发生额 - 本期借方发生额

#### 4. 成本类账户
- **增加方向**：借方
- **减少方向**：贷方
- **余额方向**：借方
- **余额计算**：期末余额 = 期初余额 + 本期借方发生额 - 本期贷方发生额

#### 5. 收入类账户
- **增加方向**：贷方
- **减少方向**：借方
- **余额方向**：期末无余额
- **结转方向**：转入本年利润

#### 6. 费用类账户
- **增加方向**：借方
- **减少方向**：贷方
- **余额方向**：期末无余额
- **结转方向**：转入本年利润

## 借贷记账法的试算平衡

### ⚖️ 试算平衡原理

#### 1. 发生额试算平衡
- **平衡公式**：全部账户借方发生额合计 = 全部账户贷方发生额合计
- **平衡原理**：借贷记账法的记账规则
- **平衡时间**：每个会计期间结束时
- **平衡作用**：检查记账是否正确

#### 2. 余额试算平衡
- **平衡公式**：全部账户借方余额合计 = 全部账户贷方余额合计
