# 预算管理实务

## 📖 基本定义
**预算管理实务**是指企业通过建立预算管理体系，对预算进行编制、执行、控制和评价，实现预算目标的管理过程。

### 1. 预算编制
- **预算目标**：制定预算目标
- **预算计划**：制定预算计划
- **预算分解**：分解预算目标
- **预算审批**：审批预算方案

### 2. 预算执行
- **预算下达**：下达预算指标
- **预算监控**：监控预算执行
- **预算调整**：调整预算方案
- **预算报告**：报告预算执行

### 3. 预算控制
- **预算预警**：建立预算预警
- **预算干预**：实施预算干预
- **预算纠偏**：纠正预算偏差
- **预算改进**：改进预算管理

### 4. 预算评价
- **预算分析**：分析预算执行
- **预算评价**：评价预算效果
- **预算考核**：考核预算责任
- **预算改进**：改进预算管理
