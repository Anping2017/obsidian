# 提示词工程快速入门

## 🚀 30分钟快速上手

### 第一步：理解基本概念（5分钟）

**什么是提示词工程？**
提示词工程是通过精心设计输入文本来引导AI模型产生期望输出的技术。

**核心价值**
- 提高AI输出质量
- 减少无效交互
- 降低使用成本
- 提升用户体验

### 第二步：掌握基本结构（10分钟）

#### 提示词基本结构
```
角色设定 + 任务描述 + 上下文信息 + 输出格式 + 约束条件
```

#### 实际示例
```
你是一位资深的数据分析师（角色设定）
请分析以下销售数据并给出改进建议（任务描述）
公司是一家电商企业，主要销售电子产品，最近3个月销售额下降15%（上下文信息）
请以表格形式输出，包含问题分析、原因分析、改进建议三列（输出格式）
字数限制在500字以内（约束条件）
```

### 第三步：实践基础技巧（15分钟）

#### 技巧1：角色设定
```markdown
❌ 不好的示例：
"帮我写一篇文章"

✅ 好的示例：
"你是一位资深的科技记者，请帮我写一篇关于人工智能发展的文章"
```

#### 技巧2：具体化描述
```markdown
❌ 不好的示例：
"写一个故事"

✅ 好的示例：
"写一个关于一位年轻程序员在硅谷创业的励志故事，包含技术挑战、团队合作、最终成功的情节"
```

#### 技巧3：输出格式控制
```markdown
❌ 不好的示例：
"分析这个数据"

✅ 好的示例：
"请分析以下数据，并以以下格式输出：
1. 数据概览
2. 关键发现
3. 趋势分析
4. 建议措施"
```

## 🎯 核心原则速记

### 5大设计原则
1. **清晰性** - 表达清晰，逻辑明确
2. **具体性** - 细节具体，避免模糊
3. **上下文** - 提供充分背景信息
4. **角色设定** - 明确AI角色身份
5. **格式控制** - 结构化输出

### 5大结构要素
1. **Role** - 角色设定
2. **Task** - 任务描述
3. **Context** - 上下文信息
4. **Format** - 输出格式
5. **Constraints** - 约束条件

## 🔧 常见问题快速解决

### 问题1：输出质量不高
**解决方案**：
- 增加角色设定的专业性
- 提供更具体的任务描述
- 补充相关上下文信息

### 问题2：输出格式不符合要求
**解决方案**：
- 明确指定输出格式
- 提供格式示例
- 使用结构化指令

### 问题3：输出内容偏离主题
**解决方案**：
- 强化角色设定
- 明确任务边界
- 添加约束条件

## 📊 效果评估快速检查

### 质量检查清单
- [ ] 角色设定是否专业具体？
- [ ] 任务描述是否清晰明确？
- [ ] 上下文信息是否充分？
- [ ] 输出格式是否明确？
- [ ] 约束条件是否合理？

### 效果评估指标
- **相关性**：输出内容是否与需求匹配
- **准确性**：输出内容是否正确
- **完整性**：输出内容是否完整
- **可读性**：输出内容是否易读
