# 项目1-基础提示词练习

## 🎯 项目概述

### 项目目标
通过基础提示词练习，掌握提示词工程的基本概念、设计原则和常用技巧，为后续学习打下坚实基础。

### 学习目标
- 理解提示词工程的基本概念
- 掌握提示词设计的基本原则
- 学会使用基础提示词技巧
- 能够设计简单的提示词

### 项目价值
- **基础建设**：建立扎实的基础知识
- **实践能力**：培养实际应用能力
- **思维训练**：训练逻辑思维能力
- **技能提升**：提升提示词设计技能

## 📋 练习内容

### 1. 基础概念练习
#### 练习1.1：提示词结构理解
**目标**：理解提示词的基本结构

**任务**：分析以下提示词的结构
```
你是一个专业的写作助手，擅长创作各种类型的文章。
请根据用户需求，创作一篇关于{主题}的文章。
要求：字数{字数}，风格{风格}，包含{要求}。
请按照以下格式输出：
标题：{标题}
摘要：{摘要}
正文：{正文}
```

**分析要点**：
- 角色设定部分
- 任务描述部分
- 约束条件部分
- 输出格式部分

**练习要求**：
1. 识别提示词的各个组成部分
2. 分析每个部分的作用
3. 思考如何优化这个提示词

#### 练习1.2：角色设定练习
**目标**：掌握角色设定的技巧

**任务**：为不同场景设计角色设定

**场景1**：教育辅导
```
你是一个{学科}老师，具有{经验}年教学经验。
你擅长{教学方法}，能够{能力描述}。
你的教学风格是{风格特点}。
```

**场景2**：商业咨询
```
你是一个{行业}专家，拥有{背景}。
你擅长{专业领域}，能够{服务内容}。
你的咨询风格是{风格特点}。
```

**练习要求**：
1. 为每个场景设计3个不同的角色设定
2. 比较不同角色设定的效果
3. 总结角色设定的最佳实践

### 2. 设计原则练习
#### 练习2.1：清晰性原则
**目标**：掌握清晰性原则的应用

**任务**：优化模糊的提示词

**原始提示词**：
```
帮我写一篇文章。
```

**优化要求**：
1. 明确文章类型
2. 指定目标受众
3. 设定内容要求
4. 规定输出格式

**练习步骤**：
1. 分析原始提示词的问题
2. 逐步优化提示词
3. 测试优化效果
4. 总结优化经验

#### 练习2.2：具体性原则
**目标**：掌握具体性原则的应用

**任务**：将抽象要求具体化

**抽象要求**：
- 写一篇关于技术的文章
- 内容要有趣
- 语言要专业
- 结构要清晰

**具体化要求**：
- 文章类型：技术博客
- 目标受众：初级开发者
- 内容要求：介绍Python基础语法
- 语言要求：通俗易懂，避免过于技术化
- 结构要求：引言-主体-总结

**练习要求**：
1. 将抽象要求转化为具体指标
2. 设计可衡量的标准
3. 验证具体化的效果

### 3. 基础技巧练习
#### 练习3.1：Few-shot示例
**目标**：掌握Few-shot示例的使用

**任务**：设计Few-shot示例

**场景**：邮件写作助手

**提示词模板**：
```
你是一个专业的邮件写作助手。

请根据以下示例，帮助用户写邮件：

示例1：
输入：向客户道歉，因为产品延迟交付
输出：尊敬的客户，我们深表歉意，由于供应链问题，您的订单将延迟3天交付。我们会尽快处理并通知您最新进展。

示例2：
输入：邀请同事参加项目会议
输出：大家好，我们计划在下周三下午2点召开项目进度会议，请各位准时参加。会议地点：会议室A。

现在请根据用户需求写邮件：
输入：{用户需求}
输出：
```

**练习要求**：
1. 设计3个不同的Few-shot示例
2. 测试示例的效果
3. 分析示例设计的原则

#### 练习3.2：思维链提示
**目标**：掌握思维链提示的使用

**任务**：设计思维链提示

**场景**：数学问题解答

**提示词模板**：
```
你是一个数学老师，请按照以下步骤解答数学问题：

1. 理解问题：仔细阅读题目，明确要求
2. 分析条件：找出已知条件和未知量
3. 选择方法：确定解题方法
4. 计算过程：详细展示计算步骤
5. 验证答案：检查答案的合理性

问题：{数学问题}

解答：
步骤1：理解问题
{理解过程}

步骤2：分析条件
{条件分析}

步骤3：选择方法
{方法选择}

步骤4：计算过程
{计算过程}

步骤5：验证答案
{答案验证}
```

**练习要求**：
1. 设计不同题型的思维链提示
2. 测试思维链的效果
3. 优化思维链结构

### 4. 综合应用练习
#### 练习4.1：内容创作提示词
**目标**：综合运用所学技巧

**任务**：设计内容创作提示词

**需求**：
- 创作一篇技术文章
- 主题：人工智能在医疗领域的应用
- 目标受众：医疗从业者
- 字数：1500字
- 风格：专业但易懂

**提示词设计**：
```
你是一个医疗技术专家，具有10年医疗行业经验，熟悉人工智能技术。

请创作一篇关于人工智能在医疗领域应用的文章。

文章要求：
- 目标受众：医疗从业者（医生、护士、医疗管理人员）
- 文章长度：1500字左右
- 写作风格：专业但易懂，避免过于技术化
- 内容结构：引言-现状分析-应用案例-挑战与机遇-未来展望-结论

写作步骤：
1. 分析目标受众的需求和关注点
2. 确定文章的核心观点
3. 收集相关案例和数据
4. 组织文章结构
5. 撰写各部分内容
6. 检查逻辑性和可读性

请按照以下格式输出：
标题：{吸引人的标题}
摘要：{200字左右的摘要}
引言：{背景介绍和问题提出}
现状分析：{当前AI在医疗领域的应用现状}
应用案例：{3-5个具体应用案例}
挑战与机遇：{分析面临的挑战和发展机遇}
未来展望：{预测未来发展趋势}
结论：{总结和行动建议}
```

**练习要求**：
1. 测试提示词的效果
2. 根据结果优化提示词
3. 总结设计经验

#### 练习4.2：问题解答提示词
**目标**：设计问题解答提示词

**任务**：设计技术问题解答提示词

**需求**：
- 解答编程问题
- 提供代码示例
- 解释原理
- 给出最佳实践

**提示词设计**：
```
你是一个资深的软件工程师，具有15年编程经验，精通多种编程语言。

请帮助用户解答编程问题，按照以下步骤进行：

1. 理解问题：分析用户的问题和需求
2. 提供解决方案：给出具体的解决方案
3. 代码示例：提供可运行的代码示例
4. 原理解释：解释解决方案的原理
5. 最佳实践：提供相关的最佳实践建议
6. 注意事项：提醒可能的问题和注意事项

回答格式：
问题分析：{分析用户问题}
解决方案：{提供解决方案}
代码示例：
```{语言}
{代码内容}
```

原理解释：{解释原理}
最佳实践：{最佳实践建议}
注意事项：{注意事项}

请回答以下问题：
{用户问题}
```

**练习要求**：
1. 测试不同问题的解答效果
2. 优化提示词结构
3. 总结优化经验
