# HTML属性大全参考

## 🏷️ Global Attributes（全局属性）

### 📋 所有元素都支持的属性

| 属性名 | 类型 | 用途 | 示例 |
|--------|------|------|------|
| **id** | string | 唯一标识符 | `id="main-content"` |
| **class** | string | CSS类名 | `class="btn btn-primary"` |
| **title** | string | 提示文本 | `title="鼠标悬停显示"` |
| **lang** | string | 元素语言 | `lang="zh-CN"` |
| **dir** | string | 文本方向 | `dir="ltr"` |
| **hidden** | boolean | 隐藏元素 | `hidden` |
| **tabindex** | number | 键盘导航顺序 | `tabindex="1"` |
| **contenteditable** | boolean | 可编辑内容 | `contenteditable="true"` |
| **data-*** | string | 自定义数据 | `data-user-id="123"` |

## 🎨 Data Attributes（数据属性）

### 📊 自定义数据存储

```html
<!-- ✅ data-* 属性的正确使用 -->
<div class="user-card" 
     data-user-id="12345"
     data-user-type="premium"
     data-last-login="2024-01-15"
     data-country="CN">
    <h3>用户信息</h3>
</div>

<!-- JavaScript访问data属性 -->
<script>
const userCard = document.querySelector('.user-card');
console.log(userCard.dataset.userId);     // "12345"
console.log(userCard.dataset.userType);   // "premium"
console.log(userCard.dataset.lastLogin);  // "2024-01-15"
console.log(userCard.dataset.country);    // "CN"
</script>
```

## ⚙️ Event Attributes（事件属性）

### 📋 JavaScript事件处理器

| 事件类型 | 属性 | 触发时机 |
|----------|------|----------|
| **鼠标事件** | onclick | 鼠标点击 |
| **鼠标事件** | onmouseover | 鼠标悬停 |
| **鼠标事件** | onmouseout | 鼠标离开 |
| **键盘事件** | onkeydown | 按下键盘 |
| **键盘事件** | onkeyup | 松开键盘 |
| **表单事件** | onsubmit | 表单提交 |
| **表单事件** | onchange | 值改变 |
| **页面事件** | onload | 页面加载完成 |
| **页面事件** | onresize | 窗口大小变化 |

### 🔧 现代事件处理推荐

```html
<!-- ❌ 传统方式：直接在HTML中写事件 -->
<button onclick="handleClick()">点击我</button>

<!-- ✅ 现代方式：使用addEventListener -->
<button id="myButton">点击我</button>
<script>
document.getElementById('myButton').addEventListener('click', function() {
    console.log('按钮被点击');
});
</script>
```
