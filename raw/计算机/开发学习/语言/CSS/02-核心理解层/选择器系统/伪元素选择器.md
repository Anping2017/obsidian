# 伪元素选择器

## 伪元素选择器概述

伪元素选择器用于选择元素的特定部分或创建虚拟元素，是CSS中强大的内容操作工具。

## 1. 内容伪元素

### ::before 伪元素
```css
/* 在元素前插入内容 */
.element::before {
    content: "前缀: ";
    color: blue;
    font-weight: bold;
}
```

### ::after 伪元素
```css
/* 在元素后插入内容 */
.element::after {
    content: " (后缀)";
    color: gray;
    font-size: 12px;
}
```

### content 属性
```css
/* 文本内容 */
.element::before {
    content: "文本内容";
}

/* 空内容 */
.element::after {
    content: "";
    display: block;
    width: 100px;
    height: 1px;
    background: #ccc;
}

/* 属性值 */
.element::after {
    content: attr(data-label);
}

/* 计数器 */
.element::before {
    content: counter(item) ". ";
    counter-increment: item;
}
```

## 2. 文本伪元素

### ::first-line 伪元素
```css
/* 选择第一行文本 */
p::first-line {
    font-weight: bold;
    color: blue;
    text-transform: uppercase;
}
```

### ::first-letter 伪元素
```css
/* 选择第一个字母 */
p::first-letter {
    font-size: 2em;
    float: left;
    margin-right: 5px;
    color: red;
}
```

### ::selection 伪元素
```css
/* 选择文本时的样式 */
::selection {
    background-color: yellow;
    color: black;
}

/* 特定元素的选中样式 */
p::selection {
    background-color: blue;
    color: white;
}
```

## 3. 其他伪元素

### ::placeholder 伪元素
```css
/* 输入框占位符样式 */
input::placeholder {
    color: #999;
    font-style: italic;
}

/* 特定输入框的占位符 */
input[type="email"]::placeholder {
    color: #007bff;
}
```

### ::marker 伪元素
```css
/* 列表标记样式 */
li::marker {
    color: red;
    font-weight: bold;
}

/* 有序列表标记 */
ol li::marker {
    content: counter(list-item) "→ ";
}
```

## 实际应用场景

### 1. 装饰性元素
```css
/* 添加引号 */
.quote::before {
    content: """;
    font-size: 2em;
    color: #ccc;
}

.quote::after {
    content: """;
    font-size: 2em;
    color: #ccc;
}

/* 添加图标 */
.icon::before {
    content: "★";
    color: gold;
    margin-right: 5px;
}
```

### 2. 清除浮动
```css
/* 清除浮动 */
.clearfix::after {
    content: "";
    display: table;
    clear: both;
}

/* 现代清除浮动 */
.clearfix::after {
    content: "";
    display: block;
    clear: both;
}
```

### 3. 工具提示
```css
/* 工具提示 */
.tooltip {
    position: relative;
}

.tooltip::after {
    content: attr(data-tooltip);
    position: absolute;
    bottom: 100%;
    left: 50%;
    transform: translateX(-50%);
    background: #333;
    color: white;
    padding: 5px 10px;
    border-radius: 4px;
    font-size: 12px;
    white-space: nowrap;
    opacity: 0;
    pointer-events: none;
    transition: opacity 0.3s;
}

.tooltip:hover::after {
    opacity: 1;
}
```

### 4. 加载动画
```css
/* 加载动画 */
.loading::after {
    content: "";
    display: inline-block;
    width: 20px;
    height: 20px;
    border: 2px solid #f3f3f3;
    border-top: 2px solid #3498db;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}

@keyframes spin {
    0% { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}
```

### 5. 表单验证
```css
/* 必填字段标识 */
.required::after {
    content: " *";
    color: red;
    font-weight: bold;
}

/* 验证状态 */
.valid::after {
    content: "✓";
    color: green;
    margin-left: 5px;
}

.invalid::after {
    content: "✗";
    color: red;
    margin-left: 5px;
}
```

## 伪元素与伪类的区别

| 特性 | 伪类 | 伪元素 |
|------|------|--------|
| 语法 | `:伪类` | `::伪元素` |
| 作用 | 选择元素状态 | 选择元素部分 |
| 内容 | 不创建内容 | 可创建内容 |
| 数量 | 可多个 | 每个元素最多2个 |

## 权重和优先级

### 权重计算
```css
/* 权重：10 */
.button::before { content: "按钮"; }

/* 权重：11 */
.button:hover::before { content: "悬停"; }

/* 权重：20 */
.button.primary::before { content: "主要"; }
```

## 性能优化

### 1. 避免过度使用
```css
/* 避免：每个元素都使用伪元素 */
*::before, *::after { content: ""; }

/* 推荐：按需使用 */
.specific-element::before { content: ""; }
```

### 2. 合理使用content
```css
/* 推荐：使用简单的content */
.icon::before { content: "★"; }

/* 避免：复杂的content */
.icon::before { content: "这是一个很长的文本内容"; }
```

## 常见错误

### 1. 语法错误
```css
/* 错误：单冒号 */
.element:before { content: ""; }

/* 正确：双冒号 */
.element::before { content: ""; }
```

### 2. 缺少content属性
```css
/* 错误：缺少content */
.element::before {
    width: 100px;
    height: 100px;
    background: red;
}

/* 正确：添加content */
.element::before {
    content: "";
    width: 100px;
    height: 100px;
    background: red;
}
```

### 3. 过度依赖伪元素
```css
/* 避免：用伪元素创建复杂布局 */
.element::before {
    content: "";
    position: absolute;
    top: 0;
    left: 0;
    right: 0;
    bottom: 0;
    background: linear-gradient(...);
}

/* 推荐：使用实际元素 */
.element .background { }
```
