# 组合选择器

## 组合选择器概述

组合选择器通过组合多个基础选择器，实现更精确的元素选择。掌握组合选择器是编写高效CSS的关键。

## 1. 后代选择器（Descendant Selector）

### 语法
```css
祖先元素 后代元素 {
    属性: 值;
}
```

### 示例
```css
/* 选择div内的所有p元素 */
div p {
    color: blue;
    margin: 10px;
}

/* 选择article内的所有h2元素 */
article h2 {
    font-size: 24px;
    color: #333;
}
```

### HTML结构
```html
<div class="content">
    <p>这是div内的段落</p>
    <section>
        <p>这是嵌套的段落</p>
    </section>
</div>
```

### 特点
- **权重值**：各选择器权重相加
- **影响范围**：所有后代元素（不限层级）
- **适用场景**：组件内部样式

## 2. 子选择器（Child Selector）

### 语法
```css
父元素 > 子元素 {
    属性: 值;
}
```

### 示例
```css
/* 选择div的直接子元素p */
div > p {
    color: red;
    font-weight: bold;
}

/* 选择ul的直接子元素li */
ul > li {
    list-style: none;
    padding: 5px;
}
```

### HTML结构
```html
<div class="container">
    <p>直接子元素</p>
    <section>
        <p>非直接子元素</p>
    </section>
</div>
```

### 特点
- **权重值**：各选择器权重相加
- **影响范围**：仅直接子元素
- **适用场景**：精确控制层级

## 3. 相邻兄弟选择器（Adjacent Sibling Selector）

### 语法
```css
元素1 + 元素2 {
    属性: 值;
}
```

### 示例
```css
/* 选择紧跟在h2后的p元素 */
h2 + p {
    margin-top: 0;
    font-style: italic;
}

/* 选择紧跟在li后的li元素 */
li + li {
    border-top: 1px solid #ccc;
}
```

### HTML结构
```html
<h2>标题</h2>
<p>紧跟在h2后的段落</p>
<p>不是紧跟在h2后的段落</p>
```

### 特点
- **权重值**：各选择器权重相加
- **影响范围**：仅相邻的下一个兄弟元素
- **适用场景**：相邻元素样式

## 4. 通用兄弟选择器（General Sibling Selector）

### 语法
```css
元素1 ~ 元素2 {
    属性: 值;
}
```

### 示例
```css
/* 选择h2后的所有p元素 */
h2 ~ p {
    color: gray;
    font-size: 14px;
}

/* 选择.active后的所有.option元素 */
.active ~ .option {
    opacity: 0.5;
}
```

### HTML结构
```html
<h2>标题</h2>
<p>第一个段落</p>
<div>其他内容</div>
<p>第二个段落</p>
```

### 特点
- **权重值**：各选择器权重相加
- **影响范围**：所有后续兄弟元素
- **适用场景**：兄弟元素样式

## 组合选择器对比

| 选择器 | 语法 | 影响范围 | 示例 |
|--------|------|----------|------|
| 后代选择器 | `A B` | 所有后代 | `div p` |
| 子选择器 | `A > B` | 直接子元素 | `div > p` |
| 相邻兄弟 | `A + B` | 相邻下一个 | `h2 + p` |
| 通用兄弟 | `A ~ B` | 所有后续兄弟 | `h2 ~ p` |

## 权重计算

### 组合选择器权重
```css
/* 权重：1 + 1 = 2 */
div p { color: red; }

/* 权重：10 + 1 = 11 */
.button p { color: blue; }

/* 权重：100 + 10 + 1 = 111 */
#header .nav li { color: green; }
```

### 权重示例
```css
/* 权重：1 */
p { color: black; }

/* 权重：2，优先级更高 */
div p { color: red; }

/* 权重：11，优先级最高 */
.container p { color: blue; }
```

## 实际应用场景

### 1. 导航菜单
```css
/* 导航菜单样式 */
.nav > li {
    display: inline-block;
    margin-right: 20px;
}

.nav > li + li {
    border-left: 1px solid #ccc;
    padding-left: 20px;
}
```

### 2. 表单样式
```css
/* 表单标签和输入框 */
label + input {
    margin-top: 5px;
    width: 100%;
}

input + .error {
    color: red;
    font-size: 12px;
}
```

### 3. 文章内容
```css
/* 文章标题和段落 */
.article h2 + p {
    margin-top: 0;
    font-size: 18px;
}

.article p + p {
    margin-top: 15px;
}
```

## 性能优化

### 1. 避免过度嵌套
```css
/* 避免：过度嵌套 */
div div div div p { color: red; }

/* 推荐：简化选择器 */
.content p { color: red; }
```

### 2. 使用高效选择器
```css
/* 推荐：使用类选择器 */
.button { color: blue; }

/* 避免：复杂后代选择器 */
div > section > article > p { color: blue; }
```

### 3. 合理使用通配符
```css
/* 推荐：限制范围 */
.container * { box-sizing: border-box; }

/* 避免：全局通配符 */
* { box-sizing: border-box; }
```

## 常见错误

### 1. 选择器语法错误
```css
/* 错误：缺少空格 */
div>p { color: red; }

/* 正确 */
div > p { color: red; }
```

### 2. 权重理解错误
```css
/* 错误理解：认为权重是相乘 */
div p { /* 权重不是1×1=1，而是1+1=2 */ }

/* 正确理解：权重是相加 */
div p { /* 权重：1+1=2 */ }
```

### 3. 过度使用组合选择器
```css
/* 避免：过度组合 */
div > section > article > h2 + p { color: red; }

/* 推荐：简化选择器 */
.article-intro { color: red; }
```
