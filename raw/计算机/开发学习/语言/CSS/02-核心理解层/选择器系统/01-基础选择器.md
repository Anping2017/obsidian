# 基础选择器

## 选择器概述

选择器是CSS的核心，用于指定要样式化的HTML元素。理解选择器是掌握CSS的基础。

## 1. 元素选择器（Element Selector）

### 语法
```css
元素名 {
    属性: 值;
}
```

### 示例
```css
/* 选择所有段落 */
p {
    color: blue;
    font-size: 16px;
}

/* 选择所有标题 */
h1, h2, h3 {
    font-weight: bold;
    margin-bottom: 20px;
}
```

### 特点
- **权重值**：1
- **影响范围**：所有匹配元素
- **适用场景**：全局样式、重置样式

## 2. 类选择器（Class Selector）

### 语法
```css
.类名 {
    属性: 值;
}
```

### 示例
```css
/* 选择所有具有highlight类的元素 */
.highlight {
    background-color: yellow;
    padding: 5px;
}

/* 多类选择器 */
.button.primary {
    background-color: blue;
    color: white;
}
```

### HTML对应
```html
<p class="highlight">高亮文本</p>
<button class="button primary">主要按钮</button>
```

### 特点
- **权重值**：10
- **可重复使用**：一个类可应用于多个元素
- **适用场景**：组件样式、状态样式

## 3. ID选择器（ID Selector）

### 语法
```css
#ID名 {
    属性: 值;
}
```

### 示例
```css
/* 选择ID为header的元素 */
#header {
    background-color: #333;
    color: white;
    padding: 20px;
}

/* 选择ID为main-content的元素 */
#main-content {
    max-width: 1200px;
    margin: 0 auto;
}
```

### HTML对应
```html
<header id="header">网站头部</header>
<main id="main-content">主要内容</main>
```

### 特点
- **权重值**：100
- **唯一性**：一个ID只能用于一个元素
- **适用场景**：页面结构、JavaScript操作

## 4. 通配符选择器（Universal Selector）

### 语法
```css
* {
    属性: 值;
}
```

### 示例
```css
/* 重置所有元素的边距和内边距 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

/* 选择所有元素 */
* {
    border: 1px solid red;
}
```

### 特点
- **权重值**：0
- **影响范围**：所有元素
- **适用场景**：CSS重置、全局样式

## 选择器权重

### 权重计算规则
| 选择器类型 | 权重值 | 示例 |
|------------|--------|------|
| 内联样式 | 1000 | `style="color: red"` |
| ID选择器 | 100 | `#header` |
| 类选择器 | 10 | `.button` |
| 元素选择器 | 1 | `p` |
| 通配符选择器 | 0 | `*` |

### 权重计算示例
```css
/* 权重：1 */
p { color: red; }

/* 权重：10 */
.text { color: blue; }

/* 权重：100 */
#title { color: green; }

/* 权重：111 (100+10+1) */
#title.text p { color: purple; }
```

## 选择器优先级

### 优先级规则
1. **权重值高的优先**
2. **权重值相同时，后定义的优先**
3. **!important 最高优先级**

### 示例
```css
/* 权重：1 */
p { color: red; }

/* 权重：10，优先级更高 */
.text { color: blue; }

/* 权重：1，但后定义，优先级更高 */
p { color: green; }

/* 最高优先级 */
p { color: yellow !important; }
```

## 最佳实践

### 1. 选择器命名
```css
/* 推荐：语义化命名 */
.primary-button { }
.navigation-menu { }
.article-title { }

/* 避免：无意义命名 */
.red { }
.big { }
.box1 { }
```

### 2. 避免过度使用ID
```css
/* 避免：过度使用ID */
#header-title { }
#header-nav { }
#header-logo { }

/* 推荐：使用类选择器 */
.header-title { }
.header-nav { }
.header-logo { }
```

### 3. 合理使用通配符
```css
/* 推荐：用于重置样式 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

/* 避免：用于其他目的 */
* {
    color: blue; /* 影响所有元素 */
}
```

## 常见错误

### 1. 选择器语法错误
```css
/* 错误：缺少点号 */
highlight { color: red; }

/* 正确 */
.highlight { color: red; }
```

### 2. 权重冲突
```css
/* 问题：权重冲突 */
p { color: red; }
.text { color: blue; }

/* 解决：提高权重 */
p.text { color: blue; }
```

### 3. 过度嵌套
```css
/* 避免：过度嵌套 */
div div div p { color: red; }

/* 推荐：简化选择器 */
.content p { color: red; }
```
