# 伪类选择器

## 伪类选择器概述

伪类选择器用于选择元素的特定状态或位置，是CSS中强大的选择器类型。

## 1. 状态伪类（State Pseudo-classes）

### 链接状态伪类
```css
/* 未访问的链接 */
a:link {
    color: blue;
    text-decoration: none;
}

/* 已访问的链接 */
a:visited {
    color: purple;
}

/* 鼠标悬停 */
a:hover {
    color: red;
    text-decoration: underline;
}

/* 激活状态（点击时） */
a:active {
    color: green;
}
```

### 表单状态伪类
```css
/* 获得焦点 */
input:focus {
    border: 2px solid blue;
    outline: none;
}

/* 禁用状态 */
input:disabled {
    background-color: #f5f5f5;
    cursor: not-allowed;
}

/* 启用状态 */
input:enabled {
    background-color: white;
}

/* 必填字段 */
input:required {
    border-left: 3px solid red;
}

/* 可选字段 */
input:optional {
    border-left: 3px solid green;
}
```

### 复选框和单选框状态
```css
/* 选中的复选框 */
input[type="checkbox"]:checked {
    accent-color: blue;
}

/* 选中的单选框 */
input[type="radio"]:checked {
    accent-color: green;
}
```

## 2. 结构伪类（Structural Pseudo-classes）

### 位置伪类
```css
/* 第一个子元素 */
li:first-child {
    font-weight: bold;
}

/* 最后一个子元素 */
li:last-child {
    border-bottom: none;
}

/* 第n个子元素 */
li:nth-child(3) {
    color: red;
}

/* 奇数子元素 */
li:nth-child(odd) {
    background-color: #f0f0f0;
}

/* 偶数子元素 */
li:nth-child(even) {
    background-color: white;
}

/* 每3个元素 */
li:nth-child(3n) {
    border-top: 1px solid #ccc;
}
```

### 类型伪类
```css
/* 第一个p元素 */
p:first-of-type {
    font-size: 18px;
}

/* 最后一个h2元素 */
h2:last-of-type {
    margin-bottom: 0;
}

/* 第n个p元素 */
p:nth-of-type(2) {
    color: blue;
}
```

### 唯一伪类
```css
/* 唯一子元素 */
.only-child {
    text-align: center;
}

/* 唯一类型元素 */
p:only-of-type {
    font-style: italic;
}
```

## 3. 否定伪类（Negation Pseudo-class）

### 语法
```css
:not(选择器) {
    属性: 值;
}
```

### 示例
```css
/* 选择不是p的元素 */
:not(p) {
    margin: 10px;
}

/* 选择没有disabled类的按钮 */
button:not(.disabled) {
    cursor: pointer;
}

/* 选择不是第一个的li元素 */
li:not(:first-child) {
    border-top: 1px solid #ccc;
}
```

## 4. 其他常用伪类

### 目标伪类
```css
/* 当前锚点目标 */
:target {
    background-color: yellow;
    padding: 10px;
}
```

### 范围伪类
```css
/* 在指定范围内的元素 */
input:in-range {
    border: 2px solid green;
}

/* 超出指定范围的元素 */
input:out-of-range {
    border: 2px solid red;
}
```

### 有效性伪类
```css
/* 有效的表单元素 */
input:valid {
    border: 2px solid green;
}

/* 无效的表单元素 */
input:invalid {
    border: 2px solid red;
}
```

## 伪类选择器权重

### 权重计算
```css
/* 权重：10 */
.button:hover { color: red; }

/* 权重：11 */
.button:first-child { color: blue; }

/* 权重：20 */
.button:not(.disabled):hover { color: green; }
```

## 实际应用场景

### 1. 导航菜单
```css
/* 导航菜单样式 */
.nav li:first-child {
    border-left: none;
}

.nav li:last-child {
    border-right: none;
}

.nav li:nth-child(odd) {
    background-color: #f8f8f8;
}
```

### 2. 表单样式
```css
/* 表单输入框样式 */
input:focus {
    border-color: #007bff;
    box-shadow: 0 0 5px rgba(0,123,255,0.3);
}

input:invalid {
    border-color: #dc3545;
}

input:valid {
    border-color: #28a745;
}
```

### 3. 列表样式
```css
/* 列表项样式 */
.list li:not(:last-child) {
    border-bottom: 1px solid #eee;
}

.list li:nth-child(3n) {
    background-color: #f9f9f9;
}
```

### 4. 按钮状态
```css
/* 按钮状态样式 */
.btn {
    padding: 10px 20px;
    border: none;
    cursor: pointer;
}

.btn:hover {
    background-color: #0056b3;
}

.btn:active {
    transform: translateY(1px);
}

.btn:disabled {
    opacity: 0.6;
    cursor: not-allowed;
}
```

## 性能优化

### 1. 避免复杂伪类
```css
/* 避免：过于复杂的伪类 */
div:not(:first-child):not(:last-child):nth-child(odd) { }

/* 推荐：简化选择器 */
.middle-item { }
```

### 2. 合理使用nth-child
```css
/* 推荐：使用简单的nth-child */
li:nth-child(odd) { background: #f0f0f0; }

/* 避免：复杂的nth-child表达式 */
li:nth-child(2n+1) { background: #f0f0f0; }
```

## 常见错误

### 1. 伪类语法错误
```css
/* 错误：缺少冒号 */
a hover { color: red; }

/* 正确 */
a:hover { color: red; }
```

### 2. 伪类顺序错误
```css
/* 错误：顺序不当 */
a:visited:hover { color: red; }

/* 正确：LVHA顺序 */
a:link { color: blue; }
a:visited { color: purple; }
a:hover { color: red; }
a:active { color: green; }
```

### 3. 过度使用伪类
```css
/* 避免：过度使用伪类 */
div:not(:first-child):not(:last-child):nth-child(odd):hover { }

/* 推荐：使用类选择器 */
.middle-item:hover { }
```
