# 浮动布局

## 浮动布局概述

浮动布局是CSS早期的主要布局方式，虽然现代布局更推荐使用Flexbox和Grid，但理解浮动布局仍然重要。

## float属性

### 浮动类型
```css
/* 左浮动 */
.float-left {
    float: left;
}

/* 右浮动 */
.float-right {
    float: right;
}

/* 不浮动 */
.float-none {
    float: none;
}
```

### 浮动特点
- **脱离文档流**：浮动元素脱离正常文档流
- **水平排列**：浮动元素可以水平排列
- **文字环绕**：文字会环绕浮动元素
- **宽度收缩**：浮动元素宽度由内容决定

## 浮动布局示例

### 1. 基础浮动
```css
/* 左浮动元素 */
.float-item {
    float: left;
    width: 200px;
    height: 100px;
    margin: 10px;
    background-color: #f0f0f0;
}
```

```html
<div class="container">
    <div class="float-item">浮动元素1</div>
    <div class="float-item">浮动元素2</div>
    <div class="float-item">浮动元素3</div>
</div>
```

### 2. 左右浮动
```css
/* 左浮动 */
.left-column {
    float: left;
    width: 70%;
    background-color: #e0e0e0;
}

/* 右浮动 */
.right-column {
    float: right;
    width: 30%;
    background-color: #d0d0d0;
}
```

### 3. 文字环绕
```css
/* 图片浮动 */
.float-image {
    float: left;
    margin: 0 20px 20px 0;
    width: 200px;
    height: 150px;
}

/* 文字内容 */
.text-content {
    text-align: justify;
    line-height: 1.6;
}
```

## 浮动布局技巧

### 1. 多列布局
```css
/* 三列布局 */
.three-column {
    width: 33.333%;
    float: left;
    padding: 20px;
    box-sizing: border-box;
}

/* 两列布局 */
.two-column {
    width: 50%;
    float: left;
    padding: 20px;
    box-sizing: border-box;
}
```

### 2. 响应式浮动
```css
/* 响应式三列布局 */
.responsive-column {
    float: left;
    width: 33.333%;
    padding: 20px;
    box-sizing: border-box;
}

@media (max-width: 768px) {
    .responsive-column {
        width: 50%;
    }
}

@media (max-width: 480px) {
    .responsive-column {
        width: 100%;
        float: none;
    }
}
```

### 3. 浮动导航
```css
/* 水平导航 */
.nav {
    list-style: none;
    margin: 0;
    padding: 0;
}

.nav li {
    float: left;
    margin-right: 20px;
}

.nav a {
    display: block;
    padding: 10px 15px;
    text-decoration: none;
    color: #333;
}

.nav a:hover {
    background-color: #f0f0f0;
}
```

## 浮动问题

### 1. 高度塌陷
```css
/* 问题：父元素高度塌陷 */
.float-container {
    border: 1px solid #ccc;
}

.float-item {
    float: left;
    width: 200px;
    height: 100px;
    background-color: #f0f0f0;
}
```

**问题表现：**
- 父元素高度为0
- 边框不显示
- 背景色不显示

### 2. 元素重叠
```css
/* 问题：浮动元素重叠 */
.float-overlap {
    float: left;
    width: 200px;
    height: 100px;
    background-color: #f0f0f0;
}

.normal-element {
    width: 150px;
    height: 150px;
    background-color: #e0e0e0;
}
```

### 3. 布局错乱
```css
/* 问题：浮动元素影响后续元素 */
.float-problem {
    float: left;
    width: 200px;
    height: 100px;
}

.affected-element {
    width: 300px;
    height: 200px;
    background-color: #d0d0d0;
}
```

## 清除浮动

### 1. clear属性
```css
/* 清除左浮动 */
.clear-left {
    clear: left;
}

/* 清除右浮动 */
.clear-right {
    clear: right;
}

/* 清除所有浮动 */
.clear-both {
    clear: both;
}
```

### 2. 空元素清除
```html
<div class="float-container">
    <div class="float-item">浮动元素</div>
    <div class="clear-both"></div>
</div>
```

```css
.clear-both {
    clear: both;
    height: 0;
    line-height: 0;
    font-size: 0;
}
```

### 3. 伪元素清除
```css
/* 现代清除浮动方法 */
.clearfix::after {
    content: "";
    display: table;
    clear: both;
}

/* 兼容性更好的方法 */
.clearfix::after {
    content: "";
    display: block;
    clear: both;
    height: 0;
    visibility: hidden;
}
```

### 4. overflow清除
```css
/* 使用overflow清除浮动 */
.overflow-clear {
    overflow: hidden;
}

/* 或者使用auto */
.overflow-auto {
    overflow: auto;
}
```

## 浮动布局最佳实践

### 1. 容器设置
```css
/* 浮动容器 */
.float-container {
    width: 100%;
    overflow: hidden; /* 清除浮动 */
}

.float-item {
    float: left;
    width: 33.333%;
    padding: 20px;
    box-sizing: border-box;
}
```

### 2. 响应式设计
```css
/* 响应式浮动布局 */
.responsive-float {
    float: left;
    width: 25%;
    padding: 20px;
    box-sizing: border-box;
}

@media (max-width: 768px) {
    .responsive-float {
        width: 50%;
    }
}

@media (max-width: 480px) {
    .responsive-float {
        width: 100%;
        float: none;
    }
}
```

### 3. 性能优化
```css
/* 避免过度浮动 */
.float-optimized {
    float: left;
    width: 200px;
    height: 100px;
    /* 避免频繁重排 */
    will-change: transform;
}
```

## 现代替代方案

### 1. Flexbox替代
```css
/* 浮动布局 */
.float-layout {
    float: left;
    width: 33.333%;
}

/* Flexbox替代 */
.flex-layout {
    display: flex;
}

.flex-item {
    flex: 1;
}
```

### 2. Grid替代
```css
/* 浮动网格 */
.float-grid {
    float: left;
    width: 25%;
}

/* Grid替代 */
.grid-layout {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
}
```
