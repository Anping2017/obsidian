# 文档流

## 文档流概述

文档流是CSS布局的基础概念，理解文档流对于掌握CSS布局至关重要。

## 什么是文档流

文档流是元素在页面中的自然排列方式，就像水流一样，元素按照在HTML中的顺序从上到下、从左到右排列。

### 文档流特点
- **自然排列**：元素按照HTML顺序排列
- **占据空间**：元素在文档流中占据实际空间
- **相互影响**：元素之间相互影响位置

## 文档流类型

### 1. 正常文档流（Normal Flow）
```css
/* 块级元素 */
.block-element {
    display: block;
    width: 100%;
    margin: 10px 0;
}

/* 行内元素 */
.inline-element {
    display: inline;
    margin: 0 5px;
}

/* 行内块元素 */
.inline-block-element {
    display: inline-block;
    width: 200px;
    margin: 10px;
}
```

### 2. 浮动文档流（Float Flow）
```css
/* 左浮动 */
.float-left {
    float: left;
    width: 50%;
}

/* 右浮动 */
.float-right {
    float: right;
    width: 50%;
}

/* 清除浮动 */
.clear-float {
    clear: both;
}
```

### 3. 定位文档流（Positioned Flow）
```css
/* 相对定位 */
.relative {
    position: relative;
    top: 10px;
    left: 20px;
}

/* 绝对定位 */
.absolute {
    position: absolute;
    top: 0;
    right: 0;
}

/* 固定定位 */
.fixed {
    position: fixed;
    top: 0;
    left: 0;
}
```

## 元素类型

### 块级元素（Block Elements）
```css
/* 块级元素特点 */
.block {
    display: block;
    width: 100%;
    height: auto;
    margin: 10px 0;
    padding: 10px;
}
```

**块级元素特点：**
- 独占一行
- 可以设置宽高
- 可以设置内外边距
- 默认宽度为100%

**常见块级元素：**
- `div`, `p`, `h1-h6`
- `ul`, `ol`, `li`
- `table`, `form`

### 行内元素（Inline Elements）
```css
/* 行内元素特点 */
.inline {
    display: inline;
    width: auto;
    height: auto;
    margin: 0 5px;
    padding: 2px 5px;
}
```

**行内元素特点：**
- 不独占一行
- 不能设置宽高
- 只能设置左右外边距
- 宽度由内容决定

**常见行内元素：**
- `span`, `a`, `strong`
- `em`, `img`, `input`

### 行内块元素（Inline-block Elements）
```css
/* 行内块元素特点 */
.inline-block {
    display: inline-block;
    width: 200px;
    height: 100px;
    margin: 10px;
    padding: 10px;
}
```

**行内块元素特点：**
- 不独占一行
- 可以设置宽高
- 可以设置内外边距
- 宽度可以自定义

## 文档流布局

### 1. 垂直排列
```html
<div class="container">
    <div class="block">块级元素1</div>
    <div class="block">块级元素2</div>
    <div class="block">块级元素3</div>
</div>
```

```css
.container {
    width: 100%;
}

.block {
    display: block;
    width: 100%;
    height: 100px;
    background-color: #f0f0f0;
    margin: 10px 0;
    padding: 20px;
}
```

### 2. 水平排列
```html
<div class="container">
    <span class="inline">行内元素1</span>
    <span class="inline">行内元素2</span>
    <span class="inline">行内元素3</span>
</div>
```

```css
.container {
    width: 100%;
    padding: 20px;
}

.inline {
    display: inline;
    background-color: #e0e0e0;
    padding: 5px 10px;
    margin: 0 5px;
}
```

### 3. 混合排列
```html
<div class="container">
    <div class="inline-block">行内块1</div>
    <div class="inline-block">行内块2</div>
    <div class="inline-block">行内块3</div>
</div>
```

```css
.container {
    width: 100%;
    padding: 20px;
}

.inline-block {
    display: inline-block;
    width: 200px;
    height: 100px;
    background-color: #d0d0d0;
    margin: 10px;
    padding: 20px;
}
```

## 文档流控制

### 1. display属性
```css
/* 改变元素类型 */
.element {
    display: block;        /* 块级 */
    display: inline;       /* 行内 */
    display: inline-block; /* 行内块 */
    display: none;         /* 隐藏 */
    display: flex;         /* 弹性盒子 */
    display: grid;         /* 网格 */
}
```

### 2. visibility属性
```css
/* 控制元素可见性 */
.element {
    visibility: visible;   /* 可见 */
    visibility: hidden;    /* 隐藏但占据空间 */
    visibility: collapse;  /* 折叠（表格用） */
}
```

### 3. overflow属性
```css
/* 控制溢出内容 */
.element {
    overflow: visible;     /* 显示溢出 */
    overflow: hidden;      /* 隐藏溢出 */
    overflow: scroll;      /* 显示滚动条 */
    overflow: auto;        /* 自动显示滚动条 */
}
```

## 文档流问题

### 1. 外边距重叠
```css
/* 问题：垂直外边距重叠 */
.margin-collapse {
    margin-top: 20px;
    margin-bottom: 20px;
}

/* 解决：使用padding或border */
.margin-solution {
    margin-top: 20px;
    padding-bottom: 20px;
    border-bottom: 1px solid transparent;
}
```

### 2. 浮动影响
```css
/* 问题：浮动元素影响布局 */
.float-problem {
    float: left;
    width: 50%;
}

/* 解决：清除浮动 */
.clearfix::after {
    content: "";
    display: table;
    clear: both;
}
```

### 3. 定位脱离文档流
```css
/* 问题：绝对定位脱离文档流 */
.absolute-problem {
    position: absolute;
    top: 0;
    left: 0;
}

/* 解决：使用相对定位 */
.relative-solution {
    position: relative;
    top: 0;
    left: 0;
}
```

## 现代布局方式

### 1. Flexbox布局
```css
/* 弹性盒子布局 */
.flex-container {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

.flex-item {
    flex: 1;
    margin: 10px;
}
```

### 2. Grid布局
```css
/* 网格布局 */
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

.grid-item {
    padding: 20px;
    background-color: #f0f0f0;
}
```
