# 🛒 Odoo `purchase` 模块详解

## 一、`purchase` 模块的作用

- **采购管理核心模块**。
- 管理从采购请求到订单支付的完整采购流程。
- 提供供应商管理、采购订单、价格比较等功能。
- 是采购业务的基础模块。

📌 形象理解：  
👉 采购团队使用 `purchase` 模块管理供应商和采购订单。

---

## 二、核心功能

### 1. 采购请求（RFQ - Request for Quotation）

- 创建采购请求
- 向多个供应商发送询价
- 收集和比较报价
- 选择最佳供应商

### 2. 采购订单（Purchase Orders）

- 创建和管理采购订单
- 订单确认和取消
- 订单修改和历史
- 订单状态跟踪

### 3. 供应商管理

- 供应商档案管理
- 供应商评估和评级
- 供应商价格表
- 供应商历史记录

### 4. 采购分析报表

- 采购报表和分析
- 供应商绩效分析
- 价格趋势分析
- 采购成本分析

### 5. 价格比较和谈判

- 多供应商价格比较
- 价格谈判记录
- 批量采购折扣

## 三、核心模型

### 1. `purchase.order` - 采购订单

采购订单主模型：

```
class PurchaseOrder(models.Model):
    _name = 'purchase.order'
    _inherit = ['mail.thread', 'mail.activity.mixin']
    
    name = fields.Char('Order Reference', required=True)
    partner_id = fields.Many2one('res.partner', 'Vendor', required=True)
    date_order = fields.Datetime('Order Date', required=True)
    state = fields.Selection([
        ('draft', 'RFQ'),
        ('sent', 'RFQ Sent'),
        ('to approve', 'To Approve'),
        ('purchase', 'Purchase Order'),
        ('done', 'Locked'),
        ('cancel', 'Cancelled')
    ], string='Status')
    order_line = fields.One2many('purchase.order.line', 'order_id', 'Order Lines')
    amount_total = fields.Monetary('Total', compute='_compute_amount')
```

订单状态：
- **草稿**（Draft）：采购请求（RFQ）阶段
- **已发送**（Sent）：询价已发送给供应商
- **待审批**（To Approve）：等待审批
- **采购订单**（Purchase）：已确认的采购订单
- **已完成**（Done）：订单已完成
- **已取消**（Cancelled）：订单已取消

### 2. `purchase.order.line` - 订单行

采购订单明细行：

```
class PurchaseOrderLine(models.Model):
    _name = 'purchase.order.line'
    
    order_id = fields.Many2one('purchase.order', 'Order', required=True)
    product_id = fields.Many2one('product.product', 'Product', required=True)
    name = fields.Text('Description', required=True)
    product_qty = fields.Float('Quantity', required=True)
    price_unit = fields.Float('Unit Price', required=True)
    price_subtotal = fields.Monetary('Subtotal', compute='_compute_amount')
    tax_id = fields.Many2many('account.tax', 'Tax')
```

## 四、采购流程

### 1. 创建采购请求（RFQ）

1. 选择供应商或创建新的询价
2. 添加需要采购的产品
3. 设置数量和价格要求
4. 生成 RFQ

### 2. 发送询价

- 通过邮件发送 RFQ 给供应商
- 生成 PDF 附件
- 跟踪询价状态

### 3. 接收报价

- 供应商返回报价
- 比较多个供应商的报价
- 选择最佳报价

### 4. 审批流程

- 提交采购订单审批
- 审批规则配置
- 审批历史记录

### 5. 确认订单

- 审批通过后确认订单
- 订单状态从"RFQ"变为"采购订单"
- 触发收货流程（如果安装了 `purchase_stock`）

### 6. 收货和发票

- 与库存模块集成，创建收货单
- 与会计模块集成，处理供应商发票
- 跟踪收货和付款状态

## 九、配置和设置

### 1. 采购团队配置

#### 创建采购团队

1. **采购 > 配置 > 采购团队**
2. 创建采购团队（如"采购部"、"国际采购"）
3. 分配采购人员到团队
4. 设置团队采购目标

#### 采购团队模型

```
class PurchaseTeam(models.Model):
    _name = 'purchase.team'
    _description = 'Purchase Team'
    
    name = fields.Char('Team Name', required=True)
    member_ids = fields.Many2many('res.users', 'Team Members')
    company_id = fields.Many2one('res.company', 'Company')
```

### 2. 审批规则配置

#### 设置审批流程

1. **采购 > 配置 > 设置**
2. **审批**选项卡
3. 配置审批规则：
   - **审批阈值**：超过此金额需要审批
   - **审批人**：指定审批人
   - **审批流程**：单级或多级审批

#### 审批规则示例

```
审批规则配置：
- 金额 < 1,000：无需审批
- 金额 1,000 - 10,000：部门经理审批
- 金额 > 10,000：总经理审批
```

#### 审批流程

```
创建采购订单（金额超过阈值）
 ↓
提交审批
 ↓
发送审批请求给审批人
 ↓
审批人审核
 ↓
批准/拒绝
 ↓
如批准，订单状态变为"待确认"
 ↓
确认订单
```

### 3. 供应商配置

#### 供应商基本设置

1. **联系人 > 供应商**
2. 创建或编辑供应商
3. 关键配置：
   - **价格表**：供应商特定价格
   - **付款条件**：付款期限和条件
   - **货币**：供应商使用货币
   - **税务**：税务信息

#### 供应商价格表

- **创建价格表**：
  1. **库存 > 配置 > 价格表**
  2. 创建供应商价格表
  3. 设置供应商特定价格

- **价格规则**：
  - 基于数量的价格
  - 基于订单金额的折扣
  - 有效期管理

### 4. 产品采购配置

#### 产品采购设置

1. **库存 > 产品 > 产品**
2. 编辑产品
3. **采购**选项卡：
   - **可采购**：产品是否可采购
   - **采购员**：默认采购员
   - **供应商**：首选供应商
   - **采购单位**：采购时的计量单位

#### 多个供应商配置

- 为产品配置多个供应商
- 设置供应商优先级
- 价格比较和选择

### 5. 工作流配置

#### 自动化规则

1. **设置 > 技术 > 自动化 > 自动化规则**
2. 创建采购自动化规则

#### 自动化场景示例

- **自动确认订单**：满足条件自动确认
- **自动发送 RFQ**：新 RFQ 自动发送给供应商
- **自动创建收货单**：订单确认自动创建收货单（需 `purchase_stock`）
- **自动创建账单**：收货后自动创建供应商账单（需配置）

### 6. 通知配置

#### 邮件通知

1. **采购 > 配置 > 设置**
2. **通知**选项卡
3. 配置通知规则：
   - 新 RFQ 发送通知
   - 订单确认通知
   - 收货通知
   - 发票到达通知

## 十、典型使用场景详解

### 场景 1：标准采购流程

**需求**：从询价到付款的完整采购流程

**详细步骤**：

1. **需求识别**
   - 库存不足触发采购需求
   - 或手动创建采购请求

2. **创建 RFQ**
   ```
   采购 > 采购订单 > 新建
   - 选择供应商
   - 添加产品（产品、数量）
   - 系统自动填充供应商价格（如有）
   - 调整价格（如需要）
   - 设置交货日期
   ```

3. **发送询价**
   - 点击"发送 RFQ"
   - 系统生成 PDF
   - 通过邮件发送给供应商
   - 跟踪邮件状态

4. **接收报价**
   - 供应商返回报价
   - 比较多个供应商报价（如有）
   - 选择最佳供应商和价格

5. **审批流程**（如需要）
   - 订单金额超过阈值
   - 提交审批
   - 审批人审核
   - 批准或拒绝

6. **确认订单**
   - 审批通过后（或无需审批）
   - 点击"确认订单"
   - 订单状态变为"采购订单"
   - 系统创建收货单（如安装了 `purchase_stock`）

7. **收货处理**（需 `purchase_stock`）
   - 供应商发货
   - 货物到达，确认收货
   - 库存入库
   - 订单部分或完全收货

8. **发票处理**（需 `account`）
   - 接收供应商发票
   - 创建供应商账单
   - 三向匹配（订单、收货、发票）
   - 审核并过账账单

9. **付款处理**（需 `account_payment`）
   - 审批付款
   - 创建付款单
   - 执行付款
   - 对账完成

### 场景 2：紧急采购

**需求**：快速处理紧急采购需求

**步骤**：

1. **创建采购订单**
   - 直接创建采购订单（跳过 RFQ）
   - 或快速将 RFQ 转为订单

2. **简化审批**
   - 使用紧急审批流程
   - 或临时提高审批阈值

3. **快速确认**
   - 确认订单
   - 通知供应商紧急发货

4. **跟踪交付**
   - 密切跟踪供应商交付
   - 确保及时到货

### 场景 3：多供应商比价

**需求**：通过比较多个供应商选择最佳供应商

**步骤**：

1. **创建多个 RFQ**
   - 为同一产品创建多个 RFQ
   - 发送给不同供应商

2. **收集报价**
   - 等待供应商报价
   - 记录所有报价

3. **比较分析**
   - 比较价格
   - 考虑质量、交付时间等因素
   - 使用采购分析报表

4. **选择供应商**
   - 选择最佳供应商
   - 确认采购订单

## 十三、常见问题和解决方案

### 问题 1：无法创建采购订单

**原因**：缺少必填字段或权限不足

**解决方案**：
1. 确保已选择供应商
2. 确保订单行中有产品
3. 检查用户权限

### 问题 2：审批流程不工作

**原因**：审批规则配置不正确

**解决方案**：
1. 检查审批阈值设置
2. 确认审批人已配置
3. 检查审批流程配置

### 问题 3：无法接收供应商价格

**原因**：供应商价格表未配置

**解决方案**：
1. 检查供应商价格表
2. 确认产品价格已设置
3. 检查价格表有效期
