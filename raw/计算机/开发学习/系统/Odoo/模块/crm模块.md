# 🎯 Odoo `crm` 模块详解

## 一、`crm` 模块的作用

- **客户关系管理**（Customer Relationship Management）核心模块。
- 管理潜在客户（Leads）和商机（Opportunities）。
- 跟踪销售管道（Pipeline）和销售活动。
- 优化销售流程，提高转化率。

📌 形象理解：  
👉 CRM 是销售团队的"作战地图"，跟踪从潜在客户到成交的整个过程。

---

## 二、核心功能

### 1. 潜在客户管理（Leads）

- 捕获和管理潜在客户信息
- 客户来源跟踪
- 潜在客户评分和分类
- 转化为商机

### 2. 商机管理（Opportunities）

- 管理销售商机
- 商机阶段跟踪
- 商机价值评估
- 转化预测

### 3. 销售管道（Pipeline）

- 可视化销售流程
- 每个阶段的管理
- 转化率分析
- 销售漏斗视图

### 4. 销售活动跟踪

- 记录客户互动（电话、邮件、会议）
- 活动历史记录
- 下一步行动提醒
- 活动统计分析

### 5. CRM 报表和看板

- 销售团队绩效分析
- 商机转化分析
- 客户分析
- 预测报表

## 三、核心模型

### 1. `crm.lead` - 潜在客户/商机

潜在客户和商机的统一模型：

```
class CrmLead(models.Model):
    _name = 'crm.lead'
    _inherit = ['mail.thread', 'mail.activity.mixin']
    
    name = fields.Char('Opportunity', required=True)
    partner_id = fields.Many2one('res.partner', 'Customer')
    type = fields.Selection([
        ('lead', 'Lead'),
        ('opportunity', 'Opportunity')
    ], string='Type', default='lead')
    stage_id = fields.Many2one('crm.stage', 'Stage')
    probability = fields.Float('Probability', group_operator='avg')
    expected_revenue = fields.Monetary('Expected Revenue')
    date_deadline = fields.Date('Expected Closing')
    user_id = fields.Many2one('res.users', 'Salesperson')
    team_id = fields.Many2one('crm.team', 'Sales Team')
```

**类型**：
- **潜在客户**（Lead）：初步联系，未确认需求
- **商机**（Opportunity）：确认需求，进入销售流程

**阶段（Stages）**：
- 新建（New）
- 确认（Qualified）
- 提案（Proposal）
- 谈判（Negotiation）
- 成交（Won）
- 丢失（Lost）

### 2. `crm.stage` - 销售阶段

定义销售流程的各个阶段。

### 3. `crm.team` - 销售团队

销售团队配置：
- 团队成员
- 销售目标
- 阶段配置

## 四、销售管道流程

### 典型销售流程

```
潜在客户（Lead）
 ↓ 确认需求
商机（Opportunity）
 ↓
新建阶段（New）
 ↓
确认阶段（Qualified）
 ↓
提案阶段（Proposal）
 ↓
谈判阶段（Negotiation）
 ↓
成交（Won）或丢失（Lost）
```

- **看板视图**：按阶段显示商机卡片
- **列表视图**：详细数据表格
- **图表视图**：统计分析
- **日历视图**：按截止日期查看

## 十、配置和设置详解

### 1. 销售团队配置

#### 销售团队模型

```
class CrmTeam(models.Model):
    _name = 'crm.team'
    _description = 'Sales Team'
    _inherit = ['mail.thread', 'mail.activity.mixin']
    
    name = fields.Char('Sales Team', required=True)
    sequence = fields.Integer('Sequence', default=10)
    active = fields.Boolean('Active', default=True)
    company_id = fields.Many2one('res.company', 'Company')
    member_ids = fields.One2many('crm.team.member', 'team_id', 'Team Members')
    user_id = fields.Many2one('res.users', 'Team Leader')
    stage_ids = fields.One2many('crm.stage', 'team_id', 'Stages')
    color = fields.Integer('Color')
    favorite_user_ids = fields.Many2many('res.users', 'User Favorites')
    is_membership_multi = fields.Boolean('Multiple Memberships')
    crm_team_tag_ids = fields.Many2many('crm.tag', 'Team Tags')
```

#### 创建销售团队

1. **CRM > 配置 > 销售团队**
2. 创建销售团队：
   - **名称**：团队名称（如"大客户销售"、"渠道销售"）
   - **团队负责人**：指定团队负责人
   - **团队成员**：添加团队成员
   - **销售目标**：设置团队销售目标

#### 团队功能

- **线索分配**：自动将线索分配给团队成员
- **绩效跟踪**：跟踪团队和个人的销售绩效
- **报告层级**：按团队组织报表

### 2. 销售阶段配置详解

#### 阶段模型

```
class CrmStage(models.Model):
    _name = 'crm.stage'
    _description = 'CRM Stage'
    
    name = fields.Char('Stage Name', required=True)
    sequence = fields.Integer('Sequence', default=10)
    team_id = fields.Many2one('crm.team', 'Sales Team')
    fold = fields.Boolean('Folded in Pipeline')
    requirements = fields.Text('Requirements')
    probability = fields.Float('Probability (%)', default=10.0)
    on_change = fields.Boolean('Change Probability Automatically')
    type = fields.Selection([
        ('lead', 'Lead'),
        ('opportunity', 'Opportunity'),
        ('both', 'Lead & Opportunity')
    ], string='Type', default='both')
```

#### 创建销售阶段

1. **CRM > 配置 > 销售阶段**
2. 创建阶段：
   - **阶段名称**：如"新建"、"确认"、"提案"
   - **顺序**：阶段在管道中的顺序
   - **转化率**：此阶段的转化概率
   - **要求**：进入此阶段的要求

#### 阶段配置选项

- **折叠**：在管道视图中是否折叠
- **自动转化率**：阶段变更时自动更新转化率
- **类型**：适用于潜在客户、商机或两者

#### 典型销售阶段

```
1. 新建（New）
   - 转化率：10%
   - 刚捕获的潜在客户

2. 确认（Qualified）
   - 转化率：30%
   - 需求已确认

3. 提案（Proposal）
   - 转化率：50%
   - 已发送提案

4. 谈判（Negotiation）
   - 转化率：70%
   - 正在谈判

5. 成交（Won）
   - 转化率：100%
   - 已成交

6. 丢失（Lost）
   - 转化率：0%
   - 未成交
```

## 十一、高级功能详解

- **姓名匹配**：匹配联系人姓名
- **邮箱匹配**：匹配邮箱地址
- **电话匹配**：匹配电话号码

```
发现重复线索
 ↓

合并重复记录
 ↓
保留所有相关数据：
- 活动记录
```

#### 去重配置

1. **CRM > 配置 > 设置**
2. **去重**选项卡
3. 配置去重规则：
   - 启用自动去重
   - 设置匹配字段
   - 设置相似度阈值

#### 预测模型

```
预测销售额 = Σ(商机价值 × 商机转化率 × 阶段转化率)
```

#### 预测报表

- **团队预测**：团队销售预测

- **产品预测**：按产品的销售预测

## 十二、典型使用场景详解

### 场景 1：完整销售流程

**需求**：从捕获线索到成交的完整流程

**详细步骤**：

1. **捕获线索**
   ```
   来源：
   - 网站表单自动创建
   - 展会手动录入
   - 电话咨询记录
   - 邮件导入
   ```

2. **线索确认**
   ```
   CRM > 线索 > 新建
   - 输入基本信息（姓名、公司、联系方式）
   - 选择来源
   - 分配销售人员
   - 设置初始评分
   ```

3. **线索跟进**
   ```
   - 首次联系（电话/邮件）
   - 了解客户需求
   - 判断是否为有效线索
   - 更新线索信息
   ```

4. **转化为商机**
   ```
   - 确认客户有真实需求
   - 将线索转化为商机
   - 设置商机价值
   - 进入销售管道
   ```

5. **商机跟进**
   ```
   - 创建跟进活动
   - 发送产品资料
   - 安排演示或会议
   - 推进到下一阶段
   ```

6. **提案和谈判**
   ```
   - 发送正式提案
   - 价格谈判
   - 条款讨论
   - 进入谈判阶段
   ```

7. **成交或丢失**
   ```
   成交：
   - 商机标记为"成交"
   - 创建销售订单
   - 记录成交金额
   
   丢失：
   - 商机标记为"丢失"
   - 记录丢失原因
   - 分析失败原因
   ```

### 场景 2：团队协作销售

**需求**：多个销售人员协作处理大客户

**步骤**：

1. **创建商机**
   - 设置商机类型为"团队协作"
   - 分配多个销售人员

2. **任务分工**
   - 负责人分配任务
   - 每个成员负责不同方面

3. **协作沟通**
   - 在商机Chatter中沟通
   - 共享客户信息
   - 协调跟进活动

4. **统一管理**
   - 负责人统一协调
   - 确保信息同步
   - 避免重复跟进

### 场景 3：销售活动管理

**需求**：管理所有销售活动

**步骤**：

1. **创建活动**
   ```
   活动类型：
   - 电话：电话呼叫客户
   - 邮件：发送邮件
   - 会议：安排会议
   - 演示：产品演示
   - 任务：待办事项
   ```

2. **计划活动**
   - 设置活动日期
   - 设置活动提醒
   - 关联相关商机

3. **执行活动**
   - 按照计划执行
   - 记录活动结果
   - 更新商机状态

4. **活动分析**
   - 统计活动数量
   - 分析活动效果
   - 优化活动策略

## 十四、常见问题

### 问题 1：线索转化率低

**原因**：
- 线索质量差
- 跟进不及时
- 销售技能不足

**解决方案**：
1. 优化线索来源，提高线索质量
2. 及时跟进新线索
3. 提供销售培训
4. 优化销售流程

### 问题 2：商机流失率高

**原因**：
- 跟进不及时
- 提案不匹配
- 价格不合适

**解决方案**：
1. 加强客户跟进
2. 改进提案质量
3. 灵活定价策略
4. 分析流失原因

### 问题 3：销售数据不准确

**原因**：
- 数据录入错误
- 状态更新不及时
- 系统配置错误

**解决方案**：
1. 确保数据录入准确
2. 及时更新商机状态
3. 检查系统配置
4. 培训销售人员

## 十五、总结

- **`crm` 模块**是 Odoo 客户关系管理的核心。
- 核心功能：
  - 潜在客户管理和评分
  - 商机管理和销售管道
  - 销售阶段和转化跟踪
  - 销售活动管理
  - 线索分配和自动化
  - CRM 报表和预测分析
  - 与销售、网站、营销等模块的深度集成
- 帮助销售团队管理客户关系，提高销售效率。
- 提供数据驱动的销售决策支持。
- 是构建完整销售体系的基础模块。
- 适用于各种规模和类型的销售业务。
- 支持B2B和B2C客户管理。
