# 🔍 Odoo `crm_iap_mine` 模块详解

## 一、`crm_iap_mine` 模块的作用

- **CRM 数据增强模块**。
- 通过 IAP（In-App Purchase）服务获取潜在客户信息。
- 自动填充联系人数据。
- 增强 CRM 线索质量。

📌 注意：IAP 是 Odoo 的应用内购买服务，可能需要订阅相关服务才能使用。

---

## 二、核心功能

### 1. 潜在客户信息增强

- 通过 IAP 服务获取潜在客户的详细信息
- 自动填充联系人的缺失信息
- 验证和更新联系人数据

### 2. 数据自动填充

- 公司信息（地址、电话、网站等）
- 联系人信息（职位、邮箱等）
- 行业和规模信息

### 3. 数据验证

- 验证邮箱有效性
- 验证电话号码
- 验证公司信息

---

## 三、IAP 服务

### 1. IAP 概念

- **In-App Purchase**：应用内购买服务
- Odoo 提供的第三方数据服务
- 通过 API 获取外部数据

### 2. 数据来源

- 商业数据库
- 公开的企业信息
- 第三方数据提供商

### 3. 服务类型

- **公司信息查找**：根据公司名称查找详细信息
- **联系人信息查找**：根据邮箱或姓名查找信息
- **数据验证**：验证现有数据的准确性

---

## 四、使用场景

### 1. 创建潜在客户时

```
创建潜在客户（仅知道公司名称）
 ↓
调用 IAP 服务查找公司信息
 ↓
自动填充公司详细信息
（地址、电话、网站、员工数等）
 ↓
提升线索质量
```

### 2. 线索数据完善

- 补充缺失的联系人信息
- 验证现有数据准确性
- 更新过时的信息

### 3. 批量数据增强

- 批量处理现有线索
- 自动填充大量缺失数据
- 提高数据库完整性

## 五、配置和设置

### 1. IAP 服务配置

- 在 Odoo 设置中配置 IAP 服务
- 订阅所需的数据服务
- 设置 API 密钥和权限

### 2. 自动填充设置

- 配置何时自动查找数据
- 设置数据字段优先级
- 配置数据更新策略

### 3. 权限设置

- 设置谁可以使用 IAP 服务
- 控制数据访问权限
- 保护敏感信息

## 七、注意事项

1. **服务费用**：IAP 服务可能需要付费
2. **数据准确性**：依赖第三方数据源，需要验证
3. **隐私合规**：确保符合数据保护法规
4. **API 限制**：注意 API 调用频率限制
