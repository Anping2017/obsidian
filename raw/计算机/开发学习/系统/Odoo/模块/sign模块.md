# ✍️ Odoo `sign` 模块详解

## 一、`sign` 模块的作用

- **电子签名模块**，提供完整的电子签名解决方案。
- 在线文档签名，无需打印和扫描。
- 支持多人顺序签名和并行签名。
- 签名请求发送、跟踪和管理。
- 与业务模块集成，自动发送签名请求（如销售合同）。

📌 形象理解：  
👉 `sign` 模块是"电子签名系统"，让文档签署变得简单高效。

---

## 二、核心功能

### 1. 签名请求管理

#### 签名请求模型

```
class SignRequest(models.Model):
    _name = 'sign.request'
    _description = 'Signature Request'
    _inherit = ['mail.thread', 'mail.activity.mixin']
    
    name = fields.Char('Name', required=True)
    reference = fields.Char('Reference')
    template_id = fields.Many2one('sign.template', 'Template')
    request_item_ids = fields.One2many('sign.request.item', 'sign_request_id', 'Signers')
    state = fields.Selection([
        ('draft', 'Draft'),
        ('sent', 'Sent'),
        ('signed', 'Signed'),
        ('canceled', 'Canceled')
    ], string='Status', default='draft')
    completed = fields.Boolean('Completed')
    favorited_ids = fields.Many2many('res.users', 'sign_request_favorite_rel', 
                                     'sign_request_id', 'user_id', string='Favorited By')
    start_date = fields.Datetime('Start Date')
    expiration_date = fields.Datetime('Expiration Date')
    deadline = fields.Date('Deadline')
    company_id = fields.Many2one('res.company', 'Company')
    attachment_id = fields.Many2one('ir.attachment', 'Attachment')
```

#### 签名请求状态

- **草稿**（Draft）：已创建，未发送
- **已发送**（Sent）：已发送给签名人
- **已签署**（Signed）：所有签名人已完成签名
- **已取消**（Canceled）：签名请求已取消

### 2. 签名模板

#### 模板模型

```
class SignTemplate(models.Model):
    _name = 'sign.template'
    _description = 'Signature Template'
    
    name = fields.Char('Name', required=True)
    attachment_id = fields.Many2one('ir.attachment', 'Document', required=True)
    sign_item_ids = fields.One2many('sign.item', 'template_id', 'Items to Sign')
    active = fields.Boolean('Active', default=True)
```

#### 模板功能

- **文档上传**：上传需要签名的文档（PDF）
- **签名位置**：标记文档中需要签名的位置
- **字段位置**：标记需要填写的字段（如日期、公司名称）
- **签名顺序**：Choix签名顺序（顺序签名或并行签名）

### 3. 签名位置和字段

#### 签名项类型

- **签名**：签名位置
- **初始**：首字母签名
- **文本**：文本输入字段
- **日期**：日期字段
- **复选框**：勾选框
- **下拉列表**：下拉杂列表字段

#### 签名位置标记

- **拖放标记**：在文档上拖放标记签名位置
- **精确位置**：设置签名的精确坐标
- **自动定位**：系统自动定位签名位置

### 4. 签名流程

#### 顺序签名

```
发送签名请求
 ↓
第一位签名人签名
 ↓
第二位签名人签名
 ↓
...依次签名
 ↓
所有签名完成
 ↓
生成最终签署文档
```

#### 并行签名

```
发送签名请求
 ↓
所有签名人同时收到请求
 ↓
各自独立签名（可以同时签）
 ↓
所有签名完成
 ↓
生成最终签署文档
```

### 5. 签名验证和安全性

#### 安全性特性

- **身份验证**：签名人身份验证
- **数字签名**：使用数字签名技术
- **防篡改**：文档防篡改保护
- **审计跟踪**：完整的签名审计跟踪

#### 签名证书

- **签名证书**：每个签名关联证书
- **时间戳**：签名时间戳
- **IP地址**：记录签名IP地址
- **设备信息**：记录签名设备信息

## 四、典型使用场景

### 场景 1：销售合同签名

**需求**：客户签署销售合同

**详细步骤**：

1. **创建签名模板**
   ```
   电子签名 > 模板 > 新建
   - 上传合同PDF
   - 标记客户签名位置
   - 标记公司签名位置
   - 设置签名顺序（客户先签，然后公司签）
   ```

2. **发送签名请求**
   ```
   从销售订单发送：
   - 选择客户合同模板
   - 输入客户邮箱
   - 点击"发送签名请求"
   ```

3. **客户签名**
   ```
   - 客户收到邮件
   - 点击链接打开签名页面
   - 在标记位置签名
   - 确认并提交
   ```

4. **公司签名**
   ```
   - 客户签名后，公司收到通知
   - 公司代表签名
   ```

5. **完成签署**
   ```
   - 所有签名完成
   - 生成最终签署文档
   - 发送给所有相关方
   ```

### 场景 2：员工合同签名

**需求**：新员工签署劳动合同

**步骤**：

1. **准备合同模板**
   - 上传劳动合同模板
   - 标记员工签名位置

2. **发送给员工**
   - 输入员工邮箱
   - 发送签名请求

3. **员工签名**
   - 员工在线签名
   - 提交签名

4. **HR确认**
   - HR签名确认
   - 合同签署完成

### 场景 3：批量签名请求

**需求**：向多个客户发送相同的签名请求

**步骤**：

1. **准备模板**
   - 创建通用签名模板

2. **批量发送**
   - 选择多个客户
   - 批量发送签名请求

3. **跟踪状态**
   - 查看每个请求的签名状态
   - 跟进未签署的请求

## 五、配置和设置

### 1. 签名设置

1. **电子签名 > 配置 > 设置**
2. 配置选项：
   - **默认签名有效天数**：签名请求默认有效期
   - **自动提醒**：设置自动提醒时间
   - **签名方式**：支持的签名方式

### 2. 模板配置

1. **电子签名 > 模板 > 新建**
2. 创建模板：
   - **名称**：模板名称
   - **上传文档**：上传PDF文档
   - **标记位置**：标记签名和字段位置
   - **设置签名顺序**：配置签名流程

### 3. 集成配置

1. **配置与业务模块的集成**
2. **设置自动发送规则**：
   - 哪些文档需要自动发送签名请求
   - 发送给谁
   - 何时发送
