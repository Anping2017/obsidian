# 📦 Odoo 17 系统自带模块完整清单

> 本文档列出了 Odoo 17 版本中的所有系统自带模块，按功能分类整理。

---

## 一、核心基础模块（Core/Foundation Modules）

### 1. `base`
- **作用**：Odoo 的核心基础模块，所有其他模块都依赖它
- **功能**：
  - 定义核心数据模型（`res.partner`, `res.users`, `res.company`）
  - ORM 字段系统（Char, Integer, Many2one 等）
  - 安全机制（ACL、Record Rules）
  - 国际化支持
  - 系统配置参数

### 2. `web`
- **作用**：Web 客户端核心框架
- **功能**：
  - 前端界面框架（菜单、导航、表单、列表、看板）
  - Action Manager（动作管理）
  - 视图系统（Form/Tree/Kanban/Calendar/Graph/Pivot）
  - Widgets（字段小部件库）
  - QWeb 模板引擎
  - RPC 通信（JSON-RPC）

### 3. `mail`
- **作用**：统一的消息和通知系统
- **功能**：
  - Chatter（消息面板）
  - 邮件发送/接收
  - 内部消息和通知
  - 关注者机制（Followers）
  - 活动提醒（Activities）
  - 邮件网关集成

### 4. `bus`
- **作用**：实时消息总线
- **功能**：
  - WebSocket 长连接
  - 实时通知推送
  - 在线状态显示
  - 即时消息传递

### 5. `portal`
- **作用**：客户门户网站
- **功能**：
  - 客户自助登录
  - 查看订单、发票、项目
  - 文档下载
  - 与供应商/客户协作

## 二十七、模块依赖关系

### 核心依赖链
```
base
 ├── web
 ├── mail
 │    └── bus
 └── contacts
```

### 业务模块依赖
- 大多数业务模块依赖 `base`, `web`, `mail`
- `sale` 依赖 `contacts`
- `purchase` 依赖 `contacts`
- `stock` 依赖 `purchase`, `sale`
- `mrp` 依赖 `stock`
- `account` 依赖 `sale`, `purchase`
- `project` 依赖 `hr_timesheet`
