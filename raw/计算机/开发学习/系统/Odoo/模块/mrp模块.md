# 🏭 Odoo `mrp` 模块详解

## 一、`mrp` 模块的作用

- **生产制造管理**（Manufacturing Resource Planning）核心模块。
- 管理生产订单、物料清单（BOM）、工作中心等。
- 支持离散制造和流程制造。
- 是制造业务的基础模块。

📌 形象理解：  
👉 制造团队使用 `mrp` 模块管理生产计划和生产执行。

---

## 二、核心功能

### 1. 物料清单（BOM - Bill of Materials）

- 定义产品组成和配方
- 多层级 BOM 支持
- BOM 版本管理
- 替代物料支持

### 2. 生产订单（Manufacturing Orders）

- 创建和管理生产订单
- 生产计划
- 生产执行跟踪
- 生产完成处理

### 3. 工作中心管理

- 定义工作中心（生产线、工作站）
- 工作中心产能
- 工作中心成本

### 4. 生产计划

- 主生产计划（MPS）
- 物料需求计划（MRP）
- 自动生成采购建议

### 5. 生产报表

- 生产报表和分析
- 工作中心绩效
- 生产成本分析

class MrpProduction(models.Model):

## 四、物料清单（BOM）详解

### 1. BOM 类型

#### 标准BOM（Normal）

- **用途**：正常的生产BOM
- **结构**：包含产品所需的所有组件
- **计算**：参与MRP计算

#### 虚拟BOM（Phantom/Kit）

- **用途**：套装产品或虚拟组件
- **特点**：不实际生产，直接展开子组件
- **示例**：电脑套装（包含主机、显示器等）

### 2. BOM 结构

#### BOM 行模型

```
class MrpBomLine(models.Model):
    _name = 'mrp.bom.line'
    _description = 'Bill of Material Line'
    
    bom_id = fields.Many2one('mrp.bom', 'Bill of Material', required=True)
    product_id = fields.Many2one('product.product', 'Component', required=True)
    product_qty = fields.Float('Quantity', required=True, default=1.0)
    product_uom_id = fields.Many2one('uom.uom', 'Unit of Measure', required=True)
    operation_id = fields.Many2one('mrp.routing.workcenter', 'Operation')
    attribute_value_ids = fields.Many2many('product.attribute.value', 'Component Attributes')
```

#### 多层级BOM

- **父BOM**：成品产品的BOM
- **子BOM**：组件本身也是组装产品，有自己的BOM
- **BOM展开**：系统自动展开所有层级的BOM

#### 多层级BOM示例

```
最终产品：电脑（Computer）
 ├── 组件1：主板（Motherboard）- 标准BOM
 │    ├── CPU
 │    ├── 内存
 │    └── 芯片组
 ├── 组件2：机箱（Case）- 标准BOM
 │    ├── 外壳
 │    └── 电源
 └── 组件3：显示器（Monitor）- 采购件
```

### 3. BOM 版本管理

- **版本控制**：同一产品可以有多个BOM版本
- **版本生效日期**：设置版本的生效和失效日期
- **自动选择**：系统根据日期自动选择BOM版本

### 4. 替代物料

- **替代组件**：为组件配置替代物料
- **替代规则**：何时使用替代物料
- **成本影响**：替代物料对成本的影响

## 五、生产订单详解

### 1. 生产订单状态流转

```
草稿（Draft）
 ↓
已确认（Confirmed）
 ↓
进行中（In Progress）
 ↓
待关闭（To Close）
 ↓
已完成（Done）
```

#### 状态说明

- **草稿**：新创建的生产订单
- **已确认**：订单已确认，开始准备
- **进行中**：生产正在进行
- **待关闭**：生产完成，待最终确认
- **已完成**：订单已完成并关闭

### 2. 生产订单创建方式

#### 手动创建

```
制造 > 制造订单 > 新建
- 选择产品
- 输入数量
- 选择BOM（或自动选择）
- 确认订单
```

#### 从销售订单创建

- 销售订单确认后
- 如果产品是"按订单生产"（MTO）
- 自动创建生产订单

#### MRP自动创建

- 基于需求预测
- MRP计算后
- 自动生成生产订单建议

### 3. 生产订单执行流程

#### 步骤 1：确认订单

```
确认生产订单
 ↓
系统检查：
- BOM是否存在
- 原材料是否可用
- 工作中心是否可用
 ↓
创建原材料移动（预留）
 ↓
创建工作单（如需要）
```

#### 步骤 2：原材料准备

```
检查原材料库存
 ↓
预留原材料（从库存位置到生产位置）
 ↓
如果库存不足：
- 创建采购订单（如配置）
- 或等待原材料到货
```

#### 步骤 3：生产执行

```
开始生产
 ↓
消耗原材料（从生产位置移出）
 ↓
记录生产数据：
- 实际使用原材料
- 实际生产数量
- 生产时间
 ↓
完成生产
```

#### 步骤 4：成品入库

```
成品入库（从生产位置到库存位置）
 ↓
更新成品库存
 ↓
释放原材料预留（如有剩余）
 ↓
关闭生产订单
```

class MrpWorkcenter(models.Model):

## 七、生产计划和MRP详解

### 1. 主生产计划（MPS）

#### MPS功能

- **需求预测**：基于销售预测
- **生产计划**：生成主生产计划
- **时间安排**：安排生产时间

#### MPS流程

```
销售预测
 ↓
主生产计划
 ↓
产品需求汇总
 ↓
生成生产订单建议
```

### 2. 物料需求计划（MRP）

#### MRP功能

- **计算原材料需求**：基于生产计划计算原材料需求
- **考虑现有库存**：减去在手库存
- **生成采购建议**：自动生成采购订单建议

#### MRP计算逻辑

```
1. 汇总产品需求
2. 展开BOM（所有层级）
3. 计算每个组件的需求
4. 减去现有库存
5. 减去在途采购
6. 生成净需求
7. 生成采购/生产建议
```

#### MRP运行

1. **制造 > 计划 > 运行计划**
2. 选择计划参数：
   - 计划期间
   - 产品范围
   - 仓库范围
3. 运行MRP计算
4. 查看MRP建议

### 3. 需求来源

- **销售订单**：客户订单
- **销售预测**：预测的需求
- **库存补货**：基于再订购点
- **生产订单**：其他生产订单的原材料需求

## 九、典型使用场景详解

### 场景 1：标准生产流程

**需求**：管理一个标准产品的生产过程

**详细步骤**：

1. **创建BOM**
   ```
   制造 > 产品 > BOM
   - 选择产品
   - 添加组件（原材料）
   - 设置每个组件的数量
   - 选择BOM版本
   ```

2. **创建生产订单**
   ```
   制造 > 制造订单 > 新建
   - 选择产品
   - 输入生产数量
   - 选择BOM（自动选择或手动）
   - 确认订单
   ```

3. **原材料准备**
   - 系统检查原材料库存
   - 自动预留原材料
   - 如果库存不足，创建采购建议

4. **生产执行**
   - 开始生产
   - 从仓库领取原材料
   - 在生产线上生产
   - 记录实际消耗

5. **成品入库**
   - 生产完成
   - 成品检验（可选）
   - 确认入库
   - 关闭生产订单

### 场景 2：按订单生产（MTO）

**需求**：根据客户订单生产定制产品

**详细步骤**：

1. **创建销售订单**
   - 客户下订单
   - 产品设置为"按订单生产"（MTO）
   - 确认销售订单

2. **自动创建生产订单**
   - 系统自动创建生产订单
   - 生产订单关联销售订单

3. **生产执行**
   - 按照标准流程生产
   - 跟踪生产进度

4. **完工发货**
   - 生产完成后
   - 自动创建交货单
   - 发货给客户

### 场景 3：MRP物料计划

**需求**：基于需求预测进行物料计划

**详细步骤**：

1. **输入需求预测**
   ```
   制造 > 计划 > 需求预测
   - 选择产品
   - 输入预测数量
   - 设置预测期间
   ```

2. **运行MRP**
   ```
   制造 > 计划 > 运行计划
   - 选择计划参数
   - 运行计算
   ```

3. **查看MRP建议**
   - 查看生产订单建议
   - 查看采购订单建议
   - 分析物料需求

4. **确认建议**
   - 确认生产订单
   - 确认采购订单
   - 开始执行计划

## 十、配置和设置详解

### 1. BOM配置

#### 创建BOM

1. **制造 > 产品 > BOM**
2. 创建新BOM：
   - **产品**：要生产的产品
   - **数量**：此BOM生产的产品数量
   - **类型**：标准BOM或虚拟BOM
   - **组件**：添加所需的组件和数量

#### BOM版本管理

1. 创建BOM时设置：
   - **生效日期**：BOM生效日期
   - **失效日期**：BOM失效日期
2. 多个版本并存，系统自动选择

### 2. 工作中心配置

#### 创建工作中心

1. **制造 > 配置 > 工作中心**
2. 创建工作中心：
   - **名称**：工作中心名称
   - **代码**：工作中心代码
   - **成本**：每小时成本
   - **产能**：工作中心产能

#### 工作中心成本

- **直接成本**：工资、设备折旧等
- **间接成本**：管理费用分摊
- **总成本**：用于计算生产成本

### 3. 生产配置

#### 生产设置

1. **制造 > 配置 > 设置**
2. 配置选项：
   - **生产类型**：离散制造或流程制造
   - **默认工作中心**
   - **自动预留**：是否自动预留原材料
   - **成品单位**：生产单位设置

#### 生产路由配置

1. **制造 > 配置 > 路由**
2. 定义生产路由：
   - **工序序列**：生产工序顺序
   - **工作中心**：每个工序使用的工作中心
   - **时间**：每个工序的时间

## 十二、常见问题

### 问题 1：无法创建生产订单

**原因**：
- 产品未设置BOM
- 缺少必填字段
- 权限不足

**解决方案**：
1. 确保产品有有效的BOM
2. 检查必填字段
3. 检查用户权限

### 问题 2：原材料不足

**原因**：
- 库存不足
- 预留失败
- 位置配置错误

**解决方案**：
1. 检查原材料库存
2. 运行MRP生成采购建议
3. 等待采购到货
4. 检查位置配置

### 问题 3：BOM展开错误

**原因**：
- BOM结构错误
- 循环引用
- 版本问题

**解决方案**：
1. 检查BOM结构
2. 确认无循环引用
3. 检查BOM版本和生效日期
