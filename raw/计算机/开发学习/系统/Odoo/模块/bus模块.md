# 🚌 Odoo `bus` 模块详解

## 一、`bus` 模块的作用

- 提供 **实时消息总线**（Message Bus）功能。
- 实现 **WebSocket 长连接**，支持实时双向通信。
- 用于推送实时通知、在线状态、即时消息等。
- 是 Odoo 实时功能的技术基础。

📌 形象理解：  
👉 `mail` 模块管理消息的**存储和业务逻辑**，  
👉 `bus` 模块负责消息的**实时传输和推送**。

---

## 二、核心功能

### 1. WebSocket 长连接

- 建立浏览器与服务器的持久连接。
- 避免频繁的 HTTP 轮询，提高效率。
- 支持实时数据推送。

### 2. 实时通知推送

- 当有新消息、任务、活动时，立即推送到前端。
- 无需用户刷新页面。
- 实时更新界面状态。

### 3. 在线状态显示

- 显示用户的在线/离线状态。
- 实时更新用户活动状态。

### 4. 消息频道（Channels）

- 支持多频道消息分发。
- 可以订阅特定类型的消息。
- 频道隔离，提高性能。

---

## 三、技术实现

### 1. 服务器端

- 使用 Python 的 WebSocket 服务器。
- 维护活跃连接池。
- 处理消息路由和分发。

### 2. 客户端

- JavaScript WebSocket 客户端。
- 自动重连机制。
- 消息队列和缓冲。

### 3. 消息格式

```
{
    "channel": "channel_name",
    "data": {
        "message": "content",
        "type": "notification"
    }
}
```

---

## 四、与其他模块的集成

### 1. 与 `mail` 模块

- `mail` 模块创建消息后，通过 `bus` 推送通知。
- 实现在线聊天和即时消息功能。

### 2. 与前端 Web Client

- 前端订阅 `bus` 频道。
- 接收实时更新，动态刷新界面。

---

## 五、典型使用场景

1. **新消息通知**：用户收到消息时，浏览器弹窗提醒
2. **任务更新**：项目任务状态变更时，实时显示
3. **在线协作**：多人编辑时，实时显示其他用户的操作
4. **系统通知**：系统维护、重要更新等实时推送

---

## 六、配置和调试

### 1. WebSocket 端口

- 默认使用独立端口（如 8072）。
- 可通过配置文件调整。

### 2. 连接检查

- 前端会自动检测 WebSocket 连接状态。
- 连接断开时自动重连。

### 3. 调试工具

- 浏览器控制台可查看 WebSocket 消息。
- 服务器日志记录连接和消息信息。

---

## 七、总结

- **`bus` 模块**是 Odoo 实时通信的基础设施。
- 核心功能：
  - WebSocket 长连接
  - 实时消息推送
  - 在线状态管理
  - 多频道消息分发
- 与 `mail` 模块配合，实现完整的实时消息和通知系统。
- 提升用户体验，支持实时协作和即时通知。
