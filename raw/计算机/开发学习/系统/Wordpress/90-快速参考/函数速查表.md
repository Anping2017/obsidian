## 📱 Ajax和API函数

### 🔌 Ajax处理函数

| 函数名 | 用途 | 参数 | 示例 |
|--------|------|------|------|
| **wp_ajax_** | 登录用户Ajax钩子前缀 | 无 | `add_action('wp_ajax_my_action', 'handler')` |
| **wp_ajax_nopriv_** | 未登录用户Ajax钩子前缀 | 无 | `add_action('wp_ajax_nopriv_my_action', 'handler')` |
| **wp_die()** | Ajax请求结束 | `$message` | `wp_die('成功')` |
| **wp_send_json_success()** | 返回成功JSON | `$data` | `wp_send_json_success($result)` |
| **wp_send_json_error()** | 返回错误JSON | `$data` | `wp_send_json_error('错误信息')` |

```php
// Ajax处理示例
add_action('wp_ajax_search_posts', 'handle_post_search');
add_action('wp_ajax_nopriv_search_posts', 'handle_post_search');

function handle_post_search() {
    check_ajax_referer('search_nonce'); // 安全检查
    
    $search_term = sanitize_text_field($_POST['term']);
    
    if (empty($search_term)) {
        wp_send_json_error('搜索词不能为空');
        return;
    }
    
    $posts = get_posts(array(
        's' => $search_term,
        'posts_per_page' => 10,
        'post_status' => 'publish'
    ));
    
    $results = array();
    foreach ($posts as $post) {
        $results[] = array(
            'title' => get_the_title($post->ID),
            'url' => get_permalink($post->ID),
            'excerpt' => wp_trim_words($post->post_content, 20)
        );
    }
    
    wp_send_json_success($results);
}
```

## 🔗 常用函数组合模式

### 🎯 模式1：安全的数据处理

```php
// 安全获取和处理用户输入
function secure_data_handling() {
    // 获取用户输入
    $user_input = isset($_POST['data']) ? $_POST['data'] : '';
    
    // 清理输入
    $clean_data = sanitize_text_field($user_input);
    
    // 验证数据

        wp_die('数据不能为空');
    }
    
    // 转义输出
    echo esc_html($clean_data);
```

### 🎯 模式2：高效查询

```php
// 高性能文章查询
function efficient_post_query() {
    // 查询参数优化
    $args = array(
        'post_type' => 'post',
        'posts_per_page' => 10,
        'no_found_rows' => true,          // 跳过分页计数
        'update_post_meta_cache' => false, // 跳过字段缓存
        'update_post_term_cache' => false  // 跳过分类缓存
    );
    
    $query = new WP_Query($args);
    
    if ($query->have_posts()) {
        while ($query->have_posts()) {
            $query->the_post();
            // 显示文章内容
            echo '<h2>' . get_the_title() . '</h2>';
            echo '<p>' . wp_trim_words(get_the_content(), 20) . '</p>';
        }
        wp_reset_postdata(); // 重置全局变量
    }
}
```

## 💡 使用说明和建议

### 📋 快速查找技巧
1. 使用 `Ctrl+F` 搜索需要的函数名
2. 注意函数的参数类型和默认值
3. 查看函数的返回值类型避免错误

### 🛡️ 安全检查
1. 用户输入必须清理：`sanitize_text_field()`, `esc_html()`
2. 数据库查询使用准备语句：`$wpdb->prepare()`
3. Ajax请求验证nonce：`check_ajax_referer()`

### 🚀 性能建议
1. 使用缓存减少数据库查询
2. 合理使用临时数据存储
3. 避免在循环中执行查询
