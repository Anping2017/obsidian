# 最近点对

## 概述

最近点对（Closest Pair of Points）是计算几何中的经典问题，用于找到平面上一组点中距离最近的两个点。最近点对算法在计算机图形学、数据挖掘、模式识别等领域有重要应用。

## 核心概念

### 基本定义
- **最近点对**：距离最小的两个点
- **欧几里得距离**：两点间的直线距离
- **分治策略**：将问题分解为子问题求解
- **合并策略**：将子问题的解合并为原问题的解

### 关键特性
- **唯一性**：最近点对可能不唯一
- **最优性**：算法保证找到最优解
- **分治性**：使用分治策略求解
- **合并性**：需要合并子问题的解

## 最近点对算法基础

### 基本最近点对算法

```python
from typing import List, Tuple, Any, Callable, Optional
import time
import math

class ClosestPairAlgorithms:
    """最近点对算法示例"""
    
    def __init__(self):
        self.algorithms = {}
        self.points = []
    
    def add_algorithm(self, name: str, algorithm: Callable) -> None:
        """添加算法"""
        self.algorithms[name] = algorithm
    
    def execute_algorithm(self, name: str, points: List[Tuple[float, float]]) -> Tuple[float, Tuple[Tuple[float, float], Tuple[float, float]]]:
        """执行算法"""
        if name not in self.algorithms:
            raise ValueError(f"未知算法: {name}")
        
        algorithm = self.algorithms[name]
        return algorithm(points)
    
    def set_points(self, points: List[Tuple[float, float]]) -> None:
        """设置点集"""
        self.points = points

# 暴力算法
def brute_force_closest_pair(points: List[Tuple[float, float]]) -> Tuple[float, Tuple[Tuple[float, float], Tuple[float, float]]]:
    """暴力算法求解最近点对"""
    if len(points) < 2:
        return float('inf'), (None, None)
    
    min_distance = float('inf')
    closest_pair = (None, None)
    
    for i in range(len(points)):
        for j in range(i + 1, len(points)):
            distance = math.sqrt((points[i][0] - points[j][0])**2 + (points[i][1] - points[j][1])**2)
            if distance < min_distance:
                min_distance = distance
                closest_pair = (points[i], points[j])
    
    return min_distance, closest_pair

# 分治算法
def divide_and_conquer_closest_pair(points: List[Tuple[float, float]]) -> Tuple[float, Tuple[Tuple[float, float], Tuple[float, float]]]:
    """分治算法求解最近点对"""
    if len(points) < 2:
        return float('inf'), (None, None)
    
    if len(points) == 2:
        distance = math.sqrt((points[0][0] - points[1][0])**2 + (points[0][1] - points[1][1])**2)
        return distance, (points[0], points[1])
    
    # 按x坐标排序
    sorted_points = sorted(points, key=lambda p: p[0])
    
    def closest_pair_recursive(pts: List[Tuple[float, float]]) -> Tuple[float, Tuple[Tuple[float, float], Tuple[float, float]]]:
        n = len(pts)
        
        if n <= 3:
            return brute_force_closest_pair(pts)
        
        # 分割点
        mid = n // 2
        mid_point = pts[mid]
        
        # 递归求解左右两部分
        left_distance, left_pair = closest_pair_recursive(pts[:mid])
        right_distance, right_pair = closest_pair_recursive(pts[mid:])
        
        # 取较小的距离
        min_distance = min(left_distance, right_distance)
        closest_pair = left_pair if left_distance < right_distance else right_pair
        
        # 检查跨越分割线的点对
        strip = []
        for point in pts:
            if abs(point[0] - mid_point[0]) < min_distance:
                strip.append(point)
        
        # 按y坐标排序strip
        strip.sort(key=lambda p: p[1])
        
        # 检查strip中的点对
        for i in range(len(strip)):
            j = i + 1
            while j < len(strip) and (strip[j][1] - strip[i][1]) < min_distance:
                distance = math.sqrt((strip[i][0] - strip[j][0])**2 + (strip[i][1] - strip[j][1])**2)
                if distance < min_distance:
                    min_distance = distance
                    closest_pair = (strip[i], strip[j])
                j += 1
        
        return min_distance, closest_pair
    
    return closest_pair_recursive(sorted_points)

# 使用示例
if __name__ == "__main__":
    algorithms = ClosestPairAlgorithms()
    
    # 添加算法
    algorithms.add_algorithm("brute_force", brute_force_closest_pair)
    algorithms.add_algorithm("divide_and_conquer", divide_and_conquer_closest_pair)
    
    # 测试点集
    test_points = [(0, 0), (1, 1), (2, 0), (1, -1), (0, 1), (2, 1), (1, 0), (0.5, 0.5)]
    
    # 测试暴力算法
    result = algorithms.execute_algorithm("brute_force", test_points)
    print(f"暴力算法结果: {result}")
    
    # 测试分治算法
    result = algorithms.execute_algorithm("divide_and_conquer", test_points)
    print(f"分治算法结果: {result}")
```

## 性能分析

### 最近点对算法分析

| 算法类型 | 时间复杂度 | 空间复杂度 | 适用场景 | 学习难度 |
|---------|-----------|-----------|----------|----------|
| 暴力算法 | O(n²) | O(1) | 小规模 | 简单 |
| 分治算法 | O(n log n) | O(n) | 一般情况 | 中等 |
| 优化的分治算法 | O(n log n) | O(n) | 大规模 | 中等 |
| 三维最近点对 | O(n log n) | O(n) | 三维空间 | 困难 |

| 问题特征 | 推荐算法 | 优势 | 劣势 |
