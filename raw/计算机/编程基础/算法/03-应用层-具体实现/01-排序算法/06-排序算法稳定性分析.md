## 🎯 核心概念

    """冒泡排序稳定实现"""
    n = len(arr)
    for i in range(n):
        swapped = False

def merge_stable(left, right):

    result = []
    i = j = 0

            i += 1

            j += 1

## 📊 稳定性对比总结

### 1. 稳定性分类表
| 算法 | 稳定性 | 时间复杂度 | 空间复杂度 | 说明 |
|------|--------|------------|------------|------|
| 冒泡排序 | 稳定 | O(N^2) | O(1) | 相等元素不交换 |
| 选择排序 | 不稳定 | O(N^2) | O(1) | 选择过程改变相对位置 |
| 插入排序 | 稳定 | O(N^2) | O(1) | 相等元素不交换 |
| 希尔排序 | 不稳定 | O(N^1.3) | O(1) | 增量排序改变相对位置 |
| 归并排序 | 稳定 | O(N log N) | O(N) | 合并时保持相对位置 |
| 快速排序 | 不稳定 | O(N log N) | O(log N) | 分区过程改变相对位置 |
| 堆排序 | 不稳定 | O(N log N) | O(1) | 堆化过程改变相对位置 |
| 计数排序 | 稳定 | O(N + K) | O(K) | 使用累积计数保持相对位置 |
| 桶排序 | 稳定 | O(N + K) | O(N + K) | 桶内排序保持相对位置 |
| 基数排序 | 稳定 | O(D * (N + K)) | O(N + K) | 每次排序都使用稳定排序 |

### 2. 稳定性选择指南

| 保持原有顺序 | 插入排序 | 稳定 | 简单稳定 |
