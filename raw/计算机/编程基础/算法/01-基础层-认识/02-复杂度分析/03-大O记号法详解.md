# 大O记号法详解

## 🎯 核心概念

**大O记号法**是描述算法复杂度增长趋势的数学表示方法，是算法分析的标准工具。

## 🔍 基本定义

### 大O记号的含义
- **定义**：对于函数f(n)和g(n)，如果存在常数c和n₀，使得当n ≥ n₀时，f(n) ≤ c·g(n)，则记作f(n) = O(g(n))
- **含义**：f(n)的增长速度不超过g(n)
- **目的**：描述算法的渐近行为

### 数学表示
```
f(n) = O(g(n)) ⟺ ∃c > 0, n₀ > 0, ∀n ≥ n₀: f(n) ≤ c·g(n)
```

## 📊 常见大O记号

### 1. O(1) - 常数时间
- **含义**：执行时间不随输入规模变化
- **示例**：数组访问、变量赋值
- **特点**：最高效

```python
def constant_time_operation(arr):
    """常数时间操作 - O(1)"""
    return arr[0] if arr else None
```

### 2. O(log n) - 对数时间
- **含义**：执行时间随输入规模对数增长
- **示例**：二分查找、平衡树操作
- **特点**：非常高效

```python
def binary_search(arr, target):
    """二分查找 - O(log n)"""
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1
```

### 3. O(n) - 线性时间
- **含义**：执行时间与输入规模成正比
- **示例**：遍历数组、线性查找
- **特点**：效率较高

```python
def linear_search(arr, target):
    """线性查找 - O(n)"""
    for i, value in enumerate(arr):
        if value == target:
            return i
    return -1
```

### 4. O(n log n) - 线性对数时间
- **含义**：执行时间介于线性和平方之间
- **示例**：归并排序、堆排序
- **特点**：高效排序算法

```python
def merge_sort(arr):
    """归并排序 - O(n log n)"""
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    
    return merge(left, right)
```

### 5. O(n²) - 平方时间
- **含义**：执行时间与输入规模的平方成正比
- **示例**：冒泡排序、选择排序
- **特点**：效率较低

```python
def bubble_sort(arr):
    """冒泡排序 - O(n²)"""
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr
```

### 6. O(2ⁿ) - 指数时间
- **含义**：执行时间随输入规模指数增长
- **示例**：递归斐波那契、子集生成
- **特点**：效率极低

```python
def fibonacci_recursive(n):
    """递归斐波那契 - O(2ⁿ)"""
    if n <= 1:
        return n
    return fibonacci_recursive(n - 1) + fibonacci_recursive(n - 2)
```

## 📈 复杂度对比

| 复杂度 | 增长趋势 | 示例 | 效率评价 |
|--------|----------|------|----------|
| O(1) | 常数 | 数组访问 | 优秀 |
| O(log n) | 对数 | 二分查找 | 很好 |
| O(n) | 线性 | 遍历数组 | 良好 |
| O(n log n) | 线性对数 | 归并排序 | 较好 |
| O(n²) | 平方 | 冒泡排序 | 较差 |
| O(n³) | 立方 | 三重循环 | 差 |
| O(2ⁿ) | 指数 | 递归斐波那契 | 很差 |

## 🎨 大O记号的性质

### 1. 传递性
```
如果 f(n) = O(g(n)) 且 g(n) = O(h(n))，则 f(n) = O(h(n))
```

### 2. 加法规则
```
如果 f(n) = O(g(n)) 且 h(n) = O(k(n))，则 f(n) + h(n) = O(max(g(n), k(n)))
```

### 3. 乘法规则
```
如果 f(n) = O(g(n)) 且 h(n) = O(k(n))，则 f(n) × h(n) = O(g(n) × k(n))
```

## 🔍 大O记号分析示例

### 嵌套循环分析
```python
def nested_loops_example(n):
    """嵌套循环示例 - O(n²)"""
    count = 0
    for i in range(n):        # 外层循环：n次
        for j in range(n):    # 内层循环：n次
            count += 1        # 基本操作：O(1)
    return count
# 总时间复杂度：O(n) × O(n) × O(1) = O(n²)
```

### 条件分支分析
```python
def conditional_example(arr):
    """条件分支示例"""
    if len(arr) == 0:         # O(1)
        return 0
    
    max_val = arr[0]          # O(1)
    for i in range(1, len(arr)):  # O(n)
        if arr[i] > max_val:      # O(1)
            max_val = arr[i]      # O(1)
    
    return max_val
# 总时间复杂度：O(1) + O(1) + O(n) × O(1) = O(n)
```

### 常见误区
- **误区1**：认为O(1)一定比O(n)快
- **误区2**：忽略常数因子
- **误区3**：不考虑最坏情况
- **误区4**：混淆时间复杂度和实际运行时间
