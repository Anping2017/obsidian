# 算法定义与特征

## 🎯 算法定义

**算法**是解决特定问题的有限步骤序列，是计算机科学的核心概念。

### 精确定义
算法是一个**有限的、明确的、可执行的**指令序列，用于解决特定问题或完成特定任务。

## 🔍 算法特征

### 1. 有穷性 (Finiteness)
- **定义**：算法必须在有限步骤后终止
- **要求**：不能无限循环
- **示例**：排序算法必须在对有限个元素排序后结束

### 2. 确定性 (Definiteness)
- **定义**：每一步都必须有明确的含义
- **要求**：无歧义，相同输入产生相同输出
- **示例**：`a = b + c` 是确定的，`a = random()` 是不确定的

### 3. 可行性 (Effectiveness)
- **定义**：每一步都可以通过基本操作实现
- **要求**：操作必须是可执行的
- **示例**：加法、比较、赋值等基本操作

### 4. 输入 (Input)
- **定义**：算法有零个或多个输入
- **要求**：输入必须明确定义
- **示例**：排序算法的输入是待排序数组

### 5. 输出 (Output)
- **定义**：算法有一个或多个输出
- **要求**：输出与输入有确定关系
- **示例**：排序算法的输出是排序后的数组

## 📊 算法特征对比

| 特征 | 含义 | 重要性 | 违反后果 |
|------|------|--------|----------|
| 有穷性 | 有限步骤 | ⭐⭐⭐ | 程序死循环 |
| 确定性 | 无歧义 | ⭐⭐⭐ | 结果不可预测 |
| 可行性 | 可执行 | ⭐⭐ | 无法实现 |
| 输入 | 明确输入 | ⭐⭐ | 参数不明确 |
| 输出 | 明确输出 | ⭐⭐ | 结果不明确 |

## 🎨 算法示例

### 简单算法：求最大值
```python
def find_max(arr):
    """找到数组中的最大值"""
    if not arr:  # 有穷性：检查输入
        return None
    
    max_val = arr[0]  # 确定性：明确赋值
    
    for i in range(1, len(arr)):  # 可行性：基本循环
        if arr[i] > max_val:  # 确定性：明确比较
            max_val = arr[i]  # 确定性：明确赋值
    
    return max_val  # 输出：明确返回值
```

### 算法特征验证
- ✅ **有穷性**：循环次数有限（数组长度）
- ✅ **确定性**：每一步操作明确
- ✅ **可行性**：使用基本操作（比较、赋值）
- ✅ **输入**：数组参数
- ✅ **输出**：最大值

## 🧠 算法与程序的区别

| 方面 | 算法 | 程序 |
|------|------|------|
| 定义 | 解决问题的步骤 | 算法的具体实现 |
| 语言 | 自然语言/伪代码 | 编程语言 |
| 执行 | 概念性 | 可执行 |
| 平台 | 独立 | 依赖平台 |
| 效率 | 理论分析 | 实际测量 |

## 🎯 算法设计目标

### 1. 正确性 (Correctness)
- **定义**：算法能够正确解决问题
- **验证**：通过测试用例验证
- **重要性**：最基本的要求

### 2. 效率 (Efficiency)
- **定义**：算法的时间和空间效率
- **分析**：[[02-复杂度分析]]中详细讨论
- **重要性**：实际应用的关键

### 3. 可读性 (Readability)
- **定义**：算法易于理解和维护
- **要求**：清晰的逻辑结构
- **重要性**：团队协作的基础

### 4. 健壮性 (Robustness)
- **定义**：算法对异常输入的处理能力
- **要求**：错误处理和边界检查
- **重要性**：实际应用的保障

## 🔗 相关概念

### 算法 vs 数据结构
- **算法**：解决问题的步骤
- **数据结构**：数据的组织方式
- **关系**：算法依赖数据结构，数据结构支持算法

### 算法 vs 程序
- **算法**：抽象的问题解决方法
- **程序**：算法的具体实现
- **关系**：程序是算法的载体
