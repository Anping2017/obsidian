# 代码规范

## 概述

代码规范是算法实现中的重要标准，通过遵循统一的代码规范可以提高代码的可读性、可维护性和团队协作效率。良好的代码规范是高质量算法实现的基础，也是专业程序员必备的技能。

## 核心概念

### 基本定义
- **代码规范**：统一的代码编写标准
- **命名规范**：变量、函数、类的命名规则
- **格式规范**：代码的格式和排版规则
- **注释规范**：代码注释的编写标准

### 关键特性
- **一致性**：保持代码风格一致
- **可读性**：提高代码可读性
- **可维护性**：便于代码维护
- **团队协作**：便于团队协作

#### 3.1 函数注释
```python
def function_comment_examples():
    """函数注释示例"""
    
    def binary_search(arr, target):
        """
        在有序数组中查找目标值
        
        Args:
            arr (list): 有序数组
            target (int): 目标值
        
        Returns:
            int: 目标值的索引，如果未找到返回-1
        
        Raises:
            ValueError: 如果数组为空
        
        Example:
            >>> binary_search([1, 3, 5, 7, 9], 5)
            2
            >>> binary_search([1, 3, 5, 7, 9], 6)
            -1
        """
        if not arr:
            raise ValueError("数组不能为空")
        
        left, right = 0, len(arr) - 1
        
        while left <= right:
            mid = (left + right) // 2
            
            if arr[mid] == target:
                return mid
            elif arr[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
        
        return -1
    
    def quick_sort(arr):
        """
        快速排序算法
        
        Args:
            arr (list): 待排序的数组
        
        Returns:
            list: 排序后的数组
        
        Note:
            时间复杂度: O(n log n) 平均情况, O(n^2) 最坏情况
            空间复杂度: O(log n)
        """
        if len(arr) <= 1:
            return arr
        
        pivot = arr[len(arr) // 2]
        left = [x for x in arr if x < pivot]
        middle = [x for x in arr if x == pivot]
        right = [x for x in arr if x > pivot]
        
        return quick_sort(left) + middle + quick_sort(right)
    
    # 测试
    arr = [1, 3, 5, 7, 9, 11, 13]
    result = binary_search(arr, 7)
    print(f"二分搜索结果: {result}")
    
    unsorted = [64, 34, 25, 12, 22, 11, 90]
    sorted_arr = quick_sort(unsorted)
    print(f"快速排序结果: {sorted_arr}")

# 使用示例
function_comment_examples()
```

```python
def inline_comment_examples():
    """行内注释示例"""
    
    def complex_algorithm(arr):
        """复杂算法示例"""
        # 初始化变量
        result = 0
        temp = []
        
        # 遍历数组
        for i in range(len(arr)):
            # 检查条件
            if arr[i] > 0:
                # 处理正数
                result += arr[i]
                temp.append(arr[i])
            else:
                # 处理负数
                result -= abs(arr[i])
        
        # 返回结果
        return result, temp
    
    def optimization_example():
        """优化示例"""
        data = [1, 2, 3, 4, 5]
        
        # 使用列表推导式而不是循环
        squared = [x**2 for x in data]  # 更Pythonic的写法
        
        # 使用内置函数而不是手动实现
        total = sum(data)  # 比手动循环更高效
        
        return squared, total
    
    # 测试
    arr = [1, -2, 3, -4, 5]
    result, temp = complex_algorithm(arr)
    print(f"复杂算法结果: {result}, 临时数组: {temp}")
    
    squared, total = optimization_example()
    print(f"平方数组: {squared}, 总和: {total}")

# 使用示例
inline_comment_examples()
```

## 代码规范最佳实践

### 1. 命名最佳实践
- **使用有意义的名称**：变量名应该描述其用途
- **避免缩写**：除非是广泛认知的缩写
- **使用一致的命名风格**：如snake_case或camelCase
- **避免使用保留字**：不要使用Python保留字作为变量名

### 2. 格式最佳实践
- **使用4个空格缩进**：不要使用制表符
- **限制行长度**：每行不超过80个字符
- **使用空行分隔**：逻辑块之间使用空行分隔
- **保持一致的格式**：整个项目保持一致的格式

### 3. 注释最佳实践
- **编写清晰的注释**：注释应该解释为什么而不是什么
- **保持注释更新**：代码修改时同步更新注释
- **避免冗余注释**：不要注释显而易见的代码
- **使用文档字符串**：为函数和类编写文档字符串

### 4. 组织最佳实践
- **合理组织导入**：按标准库、第三方库、本地模块的顺序导入
- **定义常量**：将魔法数字定义为常量
- **模块化设计**：将相关功能组织到模块中
- **保持简洁**：避免过度复杂的代码结构
