# 考试重点

## 🎯 编译原理考试重点

**编译原理考试重点**是编译器原理学习的重要组成部分，通过系统总结编译原理的考试重点，帮助学习者有针对性地复习和准备考试。

## 📚 基础理论考试重点

### 1. 编译原理概述
**重点内容：**
- 编译器的定义和作用
- 编译过程的六个阶段
- 编译器和解释器的区别
- 编译器分类

**考试题型：**
- 选择题：编译过程顺序
- 填空题：编译器定义
- 简答题：编译器和解释器区别

**记忆要点：**
- 编译过程：词法分析 → 语法分析 → 语义分析 → 中间代码生成 → 代码优化 → 目标代码生成
- 编译器：先编译后执行，执行速度快
- 解释器：边解释边执行，开发效率高

### 2. 形式语言理论
**重点内容：**
- 字母表、字符串、语言的定义
- 语言运算：连接、并集、闭包
- 乔姆斯基层次：Type 0、Type 1、Type 2、Type 3
- 语言的性质：封闭性、可判定性

**考试题型：**
- 选择题：语言运算结果
- 填空题：乔姆斯基层次
- 计算题：语言运算

**记忆要点：**
- 字母表：符号的有限集合
- 字符串：字母表中符号的有限序列
- 语言：字符串的集合
- 乔姆斯基层次：0型递归可枚举，1型上下文有关，2型上下文无关，3型正则

### 3. 正则表达式与正则语言
**重点内容：**
- 正则表达式语法：ε、a、|、*、+、?
- 扩展符号：[abc]、[a-z]、[^abc]、.、^、$
- 操作符优先级：* > + > ? > 连接 > |
- 正则表达式的应用

**考试题型：**
- 选择题：正则表达式匹配
- 填空题：操作符优先级
- 计算题：正则表达式构造

**记忆要点：**
- 基本符号：ε（空串）、a（字符）
- 操作符：|（或）、*（闭包）、+（正闭包）、?（可选）
- 优先级：星号正号问号高，连接并集优先级低

## 🔍 词法分析考试重点

### 1. 有限自动机理论
**重点内容：**
- DFA定义：五元组 (Q, Σ, δ, q₀, F)
- NFA定义：五元组 (Q, Σ, δ, q₀, F)
- 状态转换函数：δ: Q × Σ → Q (DFA) 或 δ: Q × Σ → 2^Q (NFA)
- DFA和NFA的区别

**考试题型：**
- 选择题：DFA/NFA定义
- 填空题：状态转换函数
- 计算题：DFA/NFA构造

**记忆要点：**
- DFA：确定性，每个状态对每个输入符号有唯一转换
- NFA：非确定性，可能有多个转换
- 状态转换函数：DFA返回单个状态，NFA返回状态集合

### 2. 正则表达式到NFA转换
**重点内容：**
- Thompson构造算法
- 基本规则：ε、a、|、*、+、?
- 构造步骤：递归应用构造规则
- 复杂度分析：O(n)时间和空间复杂度

**考试题型：**
- 选择题：Thompson构造规则
- 填空题：构造步骤
- 计算题：正则表达式到NFA转换

**记忆要点：**
- 基本字符：直接创建NFA
- 栈：使用栈存储NFA
- 操作符：遇到操作符时弹出NFA
- 弹出：进行相应的NFA操作

### 3. NFA到DFA转换
**重点内容：**
- 子集构造算法
- ε-闭包计算
- 转换函数：δ'(S, a) = ε-closure(δ(S, a))
- 复杂度分析：O(2^n)状态数

**考试题型：**
- 选择题：子集构造算法
- 填空题：ε-闭包定义
- 计算题：NFA到DFA转换

**记忆要点：**
- 状态集合：NFA状态集合
- 映射：映射到DFA状态
- ε闭包：计算ε闭包
- 转换：计算转换函数

### 4. DFA最小化
**重点内容：**
- Hopcroft算法
- 等价关系：不可区分状态
- 分割过程：逐步细化等价类
- 复杂度分析：O(n log n)时间复杂度

**考试题型：**
- 选择题：Hopcroft算法
- 填空题：等价关系定义
- 计算题：DFA最小化

**记忆要点：**
- 初始分割：接受状态和非接受状态
- 迭代分割：根据转换函数分割
- 直到不变：分割不再改变

## 📊 语法分析考试重点

### 1. 语法分析概述
**重点内容：**
- 语法分析器的作用
- 语法分析树的结构
- 语法分析过程
- 错误处理策略

**考试题型：**
- 选择题：语法分析器作用
- 填空题：语法分析过程
- 简答题：错误处理策略

**记忆要点：**
- 作用：将词法单元流转换为语法树
- 过程：输入 → 分析 → 输出
- 错误处理：语法错误、恢复策略

### 2. 自顶向下分析
**重点内容：**
- 递归下降分析
- LL(1)分析
- FIRST集合计算
- FOLLOW集合计算

**考试题型：**
- 选择题：LL(1)分析
- 填空题：FIRST/FOLLOW集合
- 计算题：FIRST/FOLLOW集合计算

**记忆要点：**
- 递归下降：每个非终结符一个函数
- LL(1)：自顶向下，向前看一个符号
- FIRST：产生式右部第一个符号
- FOLLOW：非终结符后跟符号

### 3. 自底向上分析
**重点内容：**
- 移进-归约分析
- LR(0)分析
- SLR(1)分析
- LR(1)分析
- LALR(1)分析

**考试题型：**
- 选择题：LR分析类型
- 填空题：移进-归约操作
- 计算题：LR分析表构造

**记忆要点：**
- 移进：将输入符号移入栈
- 归约：将栈顶符号串归约为非终结符
- 接受：分析成功
- 错误：分析失败

### 4. 语法分析表构造
**重点内容：**
- 预测分析表构造
- 动作表构造
- 转移表构造
- 表构造算法

**考试题型：**
- 选择题：分析表构造
- 填空题：动作表内容
- 计算题：分析表构造

**记忆要点：**
- 预测分析表：LL(1)分析表
- 动作表：移进、归约、接受、错误
- 转移表：状态转移
