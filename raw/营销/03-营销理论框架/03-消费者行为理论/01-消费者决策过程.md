# 消费者决策过程

## 消费者决策概述

### 决策定义
**消费者决策**：消费者在购买过程中，从识别需求到购后评价的完整决策过程。

### 决策特点
| 特点 | 内容 | 影响 |
|------|------|------|
| **复杂性** | 涉及多个因素 | 决策难度大 |
| **动态性** | 过程动态变化 | 需要灵活应对 |
| **个体性** | 个体差异明显 | 需要个性化 |
| **情境性** | 受情境影响 | 需要情境化 |

### 决策过程模型
```mermaid
graph LR
    A[需求识别] --> B[信息搜索]
    B --> C[方案评估]
    C --> D[购买决策]
    D --> E[购后行为]
    
    A --> A1[内部刺激]
    A --> A2[外部刺激]
    
    B --> B1[内部搜索]
    B --> B2[外部搜索]
    
    C --> C1[属性评估]
    C --> C2[品牌比较]
    
    D --> D1[购买意图]
    D --> D2[实际购买]
    
    E --> E1[使用体验]
    E --> E2[满意度评价]
    E --> E3[重复购买]
```

### 需求识别过程
| 过程 | 内容 | 营销策略 |
|------|------|----------|
| **需求感知** | 感知到需求存在 | 需求唤醒、刺激需求 |
| **需求分析** | 分析需求内容 | 需求理解、需求引导 |
| **需求确认** | 确认需求真实性 | 需求验证、需求强化 |
| **需求优先级** | 确定需求优先级 | 需求排序、需求重点 |

### 需求识别影响因素
| 因素 | 内容 | 影响机制 |
|------|------|----------|
| **内部因素** | 生理、心理状态 | 直接驱动需求 |
| **外部因素** | 环境、社会影响 | 间接影响需求 |
| **情境因素** | 时间、地点、场合 | 情境化需求 |
| **个人因素** | 个性、价值观 | 个性化需求 |

## 方案评估阶段

### 评估标准
```mermaid
graph TD
    A[评估标准] --> B[产品属性]
    A --> C[品牌形象]
    A --> D[价格水平]
    A --> E[服务质量]
    
    B --> B1[功能属性]
    B --> B2[质量属性]
    B --> B3[外观属性]
    
    C --> C1[品牌知名度]
    C --> C2[品牌美誉度]
    C --> C3[品牌忠诚度]
    
    D --> D1[价格水平]
    D --> D2[性价比]
    D --> D3[支付方式]
    
    E --> E1[售前服务]
    E --> E2[售中服务]
    E --> E3[售后服务]
```

### 评估方法
| 方法 | 内容 | 特点 |
|------|------|------|
| **补偿性模型** | 综合评估各属性 | 全面但复杂 |
| **非补偿性模型** | 关键属性决定 | 简单但片面 |
| **词典式模型** | 按重要性排序 | 层次清晰 |
| **排除式模型** | 逐步排除选项 | 效率较高 |

### 评估过程
1. **属性识别**：识别重要属性
2. **权重分配**：分配属性权重
3. **评分评估**：对各选项评分
4. **综合比较**：综合比较各选项
5. **选择决策**：做出最终选择

## 购买决策阶段

### 决策类型
```mermaid
graph TD
    A[决策类型] --> B[扩展型决策]
    A --> C[有限型决策]
    A --> D[习惯型决策]
    
    B --> B1[高参与度]
    B --> B2[信息搜索多]
    B --> B3[评估时间长]
    B --> B4[风险感知高]
    
    C --> C1[中等参与度]
    C --> C2[信息搜索中等]
    C --> C3[评估时间中等]
    C --> C4[风险感知中等]
    
    D --> D1[低参与度]
    D --> D2[信息搜索少]
    D --> D3[评估时间短]
    D --> D4[风险感知低]
```

### 决策影响因素
| 因素 | 内容 | 影响程度 |
|------|------|----------|
| **个人因素** | 年龄、性别、收入 | 中等 |
| **心理因素** | 动机、态度、个性 | 高 |
| **社会因素** | 文化、社会阶层 | 中等 |
| **情境因素** | 时间、地点、场合 | 高 |

### 决策过程
1. **购买意图**：形成购买意图
2. **购买计划**：制定购买计划
3. **购买执行**：执行购买行为
4. **购买确认**：确认购买结果
