# 批判性思维

## 📋 基本定义

### 批判性思维
- **定义**：对信息、观点、论证进行理性分析和评估的思维过程
- **特征**：理性、客观、系统、开放
- **目标**：寻求真理、避免错误、做出正确判断
- **方法**：分析、评估、推理、反思

### 核心要素
- **分析能力**：分解复杂问题
- **评估能力**：评估信息的可靠性
- **推理能力**：进行逻辑推理
- **反思能力**：反思自己的思维过程

## 🧠 思维特征

### 理性特征
- **逻辑性**：遵循逻辑规律
- **客观性**：避免主观偏见
- **系统性**：全面分析问题
- **一致性**：保持思维一致

### 批判特征
- **质疑精神**：对一切保持质疑
- **反思能力**：反思自己的观点
- **开放态度**：接受不同观点
- **自我修正**：根据新证据修正观点

### 创新特征
- **创造性**：提出新观点
- **灵活性**：灵活运用方法
- **适应性**：适应不同情况
- **发展性**：持续发展思维

## 🔍 思维过程

### 问题识别
1. **问题发现**：发现需要思考的问题
2. **问题分析**：分析问题的结构和层次
3. **问题分解**：将复杂问题分解为简单问题
4. **问题排序**：确定问题的优先顺序

### 信息收集
1. **信息搜索**：搜索相关信息
2. **信息筛选**：筛选有用信息
3. **信息验证**：验证信息的可靠性
4. **信息整理**：整理和分类信息

### 分析评估
1. **逻辑分析**：分析论证的逻辑结构
2. **证据评估**：评估证据的可靠性
3. **假设检验**：检验假设的合理性
4. **结论评估**：评估结论的合理性

### 推理判断
1. **逻辑推理**：进行逻辑推理
2. **归纳推理**：进行归纳推理
3. **类比推理**：进行类比推理
4. **综合判断**：综合各种因素做出判断

### 反思修正
1. **自我反思**：反思自己的思维过程
2. **他人反馈**：接受他人的反馈
3. **错误修正**：修正思维错误
4. **持续改进**：持续改进思维
