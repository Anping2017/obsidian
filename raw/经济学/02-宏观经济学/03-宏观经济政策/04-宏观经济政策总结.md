# 宏观经济政策总结

## 政策体系概览

### 核心政策框架
- **财政政策**：税收、支出、债务管理
- **货币政策**：货币供应量、利率、汇率
- **政策协调**：财政与货币、宏观与微观、国内与国际

### 政策目标体系
- **短期目标**：经济稳定、充分就业
- **中期目标**：经济增长、价格稳定
- **长期目标**：可持续发展、社会公平

## 政策工具对比

| 政策类型 | 主要工具 | 作用机制 | 政策效果 | 时滞特征 |
|----------|----------|----------|----------|----------|
| 财政政策 | 税收、支出、债务 | 直接需求管理 | 乘数效应 | 较长时滞 |
| 货币政策 | 利率、货币量、汇率 | 间接需求管理 | 传导效应 | 较短时滞 |
| 政策协调 | 工具组合、目标协调 | 综合效应 | 协同效应 | 复杂时滞 |

## 政策传导机制

### 财政政策传导
```
政府支出↑ → 总需求↑ → 产出↑ → 就业↑
税收↓ → 可支配收入↑ → 消费↑ → 产出↑
```

### 货币政策传导
```
货币量↑ → 利率↓ → 投资↑ → 产出↑
利率↓ → 汇率↓ → 净出口↑ → 产出↑
```

### 政策协调传导
```
财政+货币 → 需求管理 → 经济稳定
宏观+微观 → 结构优化 → 长期增长
国内+国际 → 政策协调 → 全球稳定
```
