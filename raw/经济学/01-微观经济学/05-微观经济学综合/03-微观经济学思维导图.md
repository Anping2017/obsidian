## 思维导图概述

### 导图定义

- **导图目标**：知识梳理、逻辑清晰、记忆辅助
- **导图特点**：层次性、系统性、可视化

### 导图结构

- **主要分支**：市场机制、消费者行为、生产者行为、市场结构

## 理论联系网络

### 需求供给网络
- **需求形成**：消费者行为 → 需求函数 → 市场需求
- **供给形成**：生产者行为 → 供给函数 → 市场供给
- **市场均衡**：需求供给相互作用 → 均衡价格数量
- **均衡调整**：价格机制 → 市场调整 → 新均衡

### 行为选择网络
- **消费者选择**：效用最大化 → 最优选择 → 需求函数
- **生产者选择**：利润最大化 → 最优选择 → 供给函数
- **市场选择**：市场机制 → 资源配置 → 经济效率
- **政策选择**：市场失灵 → 政府干预 → 政策效果

### 效率福利网络
- **生产效率**：技术效率 → 配置效率 → 动态效率
- **消费者福利**：消费者剩余 → 效用最大化 → 福利改善
- **生产者福利**：生产者剩余 → 利润最大化 → 福利改善
- **社会福利**：总剩余 → 帕累托效率 → 社会福利
