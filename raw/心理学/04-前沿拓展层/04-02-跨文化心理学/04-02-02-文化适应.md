# 文化适应

## 🔄 核心概念

### 文化适应定义
文化适应是不同文化背景的群体或个体接触时，其文化模式、价值观和行为发生改变的过程。

### 适应过程模型
```
文化接触 → 文化冲突 → 适应策略 → 文化整合
    ↓         ↓         ↓         ↓
  初始阶段   冲突阶段   调整阶段   整合阶段
```

## 🔍 文化适应理论

### 1. Berry的二维模型
#### 文化保持维度
- **保持**：维持原有文化
- **不保持**：放弃原有文化

#### 文化参与维度
- **参与**：积极参与新文化
- **不参与**：拒绝参与新文化

#### 四种适应策略
```
整合 (Integration)
├── 保持原文化 + 参与新文化
├── 最理想的适应策略
└── 双文化身份

同化 (Assimilation)
├── 放弃原文化 + 参与新文化
├── 完全融入新文化
└── 单一文化身份

分离 (Separation)
├── 保持原文化 + 拒绝新文化
├── 文化隔离
└── 原文化身份

边缘化 (Marginalization)
├── 放弃原文化 + 拒绝新文化
├── 最不利的适应策略
└── 无文化归属
```

### 2. 压力-适应-成长模型
#### 适应阶段
1. **蜜月期**：对新文化的好奇和兴奋
2. **危机期**：文化冲突和适应压力
3. **恢复期**：逐渐适应和调整
4. **适应期**：达到文化平衡

#### 压力源
- **文化冲击**：价值观冲突
- **语言障碍**：沟通困难
- **社会隔离**：缺乏社会支持
- **身份危机**：自我认同困惑

## 💡 适应影响因素

### 1. 个体因素
#### 人格特质
| 人格特质 | 适应影响 | 机制 |
|---------|---------|------|
| **开放性** | 促进适应 | 接受新经验 |
| **外向性** | 促进适应 | 社会交往能力 |
| **神经质** | 阻碍适应 | 情绪不稳定 |
| **宜人性** | 促进适应 | 人际和谐 |
| **尽责性** | 促进适应 | 目标导向 |

#### 认知因素
- **文化智力**：理解和适应不同文化的能力
- **认知灵活性**：调整思维模式的能力
- **元认知**：对文化适应过程的认知

#### 动机因素
- **内在动机**：对新文化的兴趣
- **外在动机**：适应压力
- **目标导向**：适应目标设定

### 2. 环境因素
#### 社会支持
```
社会支持网络
├── 家庭支持
│   ├── 情感支持
│   └── 实际帮助
├── 朋友支持
│   ├── 同伴支持
│   └── 社会网络
└── 社区支持
    ├── 文化社区
    └── 专业支持
```

#### 文化距离
- **文化相似性**：文化距离越小，适应越容易
- **文化差异**：价值观、语言、习俗差异
- **文化冲突**：文化价值观的冲突程度

#### 社会态度
- **接受态度**：新文化对移民的接受程度
- **歧视态度**：偏见和歧视的影响
- **多元文化政策**：政策支持程度
