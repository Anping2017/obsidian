# 神经递质与激素

## 🧪 化学信使系统概述

### 神经递质与激素的重要性
神经递质和激素是神经系统和内分泌系统的化学信使，负责细胞间的信息传递，是心理活动的化学基础。

### 化学信使的特点
- **特异性**：特定的受体结合
- **时效性**：作用时间有限
- **调节性**：可调节的释放
- **反馈性**：负反馈调节机制

## 🧬 神经递质系统

### 1. 胆碱能系统

#### 乙酰胆碱 (Acetylcholine, ACh)
**合成**：胆碱 + 乙酰辅酶A
**降解**：乙酰胆碱酯酶
**分布**：
- 神经肌肉接头
- 自主神经系统
- 中枢神经系统

**功能**：
- **运动控制**：控制肌肉收缩
- **记忆学习**：[[02-01-02-记忆系统]] - 记忆形成
- **注意觉醒**：[[02-01-01-注意与意识]] - 注意控制
- **自主神经**：调节内脏功能

**受体类型**：
- **烟碱受体**：快速兴奋
- **毒蕈碱受体**：慢速调节

**相关疾病**：
- **阿尔茨海默病**：胆碱能神经元死亡
- **重症肌无力**：神经肌肉接头障碍
- **帕金森病**：胆碱能系统失衡

### 2. 多巴胺系统

#### 多巴胺 (Dopamine, DA)
**合成**：酪氨酸 → 多巴 → 多巴胺
**降解**：单胺氧化酶，儿茶酚-O-甲基转移酶
**分布**：
- 黑质-纹状体通路
- 中脑-边缘通路
- 中脑-皮层通路

**功能**：
- **奖励动机**：[[03-03-01-工作动机]] - 奖励系统
- **运动控制**：运动程序控制
- **情绪调节**：情绪状态调节
- **认知功能**：工作记忆，注意

**受体类型**：
- **D1受体**：兴奋性受体
- **D2受体**：抑制性受体
- **D3受体**：边缘系统
- **D4受体**：前额叶皮层

**相关疾病**：
- **帕金森病**：黑质多巴胺神经元死亡
- **精神分裂症**：多巴胺系统过度活跃
- **成瘾**：多巴胺系统异常
- **抑郁症**：多巴胺系统功能低下

### 3. 去甲肾上腺素系统

#### 去甲肾上腺素 (Norepinephrine, NE)
**合成**：多巴胺 → 去甲肾上腺素
**降解**：单胺氧化酶，儿茶酚-O-甲基转移酶
**分布**：
- 蓝斑核
- 交感神经系统
- 中枢神经系统

**功能**：
- **觉醒注意**：[[02-01-01-注意与意识]] - 觉醒状态
- **应激反应**：[[03-01-07-心理健康维护]] - 应激反应
- **情绪调节**：情绪状态调节
- **记忆巩固**：记忆巩固过程

**受体类型**：
- **α1受体**：血管收缩
- **α2受体**：负反馈调节
- **β1受体**：心脏兴奋
- **β2受体**：支气管扩张

**相关疾病**：
- **抑郁症**：去甲肾上腺素系统功能低下
- **焦虑症**：去甲肾上腺素系统过度活跃
- **ADHD**：去甲肾上腺素系统异常
- **PTSD**：应激反应异常

### 4. 5-羟色胺系统

#### 5-羟色胺 (Serotonin, 5-HT)
**合成**：色氨酸 → 5-羟色胺
**降解**：单胺氧化酶
**分布**：
- 中缝核
- 胃肠道
- 血小板

**功能**：
- **情绪调节**：情绪状态调节
- **睡眠调节**：睡眠-觉醒周期
- **食欲控制**：食欲调节
- **疼痛调节**：疼痛感知调节

**受体类型**：
- **5-HT1受体**：抑制性受体
- **5-HT2受体**：兴奋性受体
- **5-HT3受体**：离子通道受体
- **5-HT4受体**：兴奋性受体

**相关疾病**：
- **抑郁症**：5-羟色胺系统功能低下
- **焦虑症**：5-羟色胺系统异常
- **强迫症**：5-羟色胺系统异常
- **失眠**：睡眠调节异常

### 5. 氨基酸类神经递质

#### 谷氨酸 (Glutamate)
**特点**：主要兴奋性神经递质
**功能**：
- **学习记忆**：[[02-01-02-记忆系统]] - 长时程增强
- **突触可塑性**：突触强度调节
- **神经发育**：神经发育过程
- **认知功能**：高级认知功能

**受体类型**：
- **NMDA受体**：学习记忆
- **AMPA受体**：快速兴奋
- **代谢型受体**：慢速调节

**相关疾病**：
- **癫痫**：过度兴奋
- **中风**：兴奋性毒性
- **阿尔茨海默病**：谷氨酸系统异常

#### GABA (γ-氨基丁酸)
**特点**：主要抑制性神经递质
**功能**：
- **抑制控制**：抑制过度兴奋
- **焦虑调节**：焦虑状态调节
- **睡眠调节**：睡眠促进
- **运动控制**：运动抑制

**受体类型**：
- **GABAA受体**：快速抑制
- **GABAB受体**：慢速抑制

**相关疾病**：
- **焦虑症**：GABA系统功能低下
- **癫痫**：GABA系统异常
- **失眠**：GABA系统异常

## 🔄 神经递质与激素的相互作用

### 1. 神经内分泌调节

#### 下丘脑-垂体-靶腺轴
**下丘脑-垂体-肾上腺轴**：
- **功能**：应激反应调节
- **过程**：下丘脑 → 垂体 → 肾上腺
- **激素**：CRH → ACTH → 皮质醇
- **意义**：[[03-01-07-心理健康维护]] - 应激管理

**下丘脑-垂体-甲状腺轴**：
- **功能**：代谢调节
- **过程**：下丘脑 → 垂体 → 甲状腺
- **激素**：TRH → TSH → 甲状腺激素
- **意义**：代谢功能调节

**下丘脑-垂体-性腺轴**：
- **功能**：性功能调节
- **过程**：下丘脑 → 垂体 → 性腺
- **激素**：GnRH → FSH/LH → 性激素
- **意义**：性功能调节

### 2. 神经递质-激素相互作用

#### 多巴胺-催乳素
- **关系**：多巴胺抑制催乳素
- **机制**：多巴胺 → 催乳素抑制
- **意义**：哺乳调节

#### 5-羟色胺-皮质醇
- **关系**：5-羟色胺调节皮质醇
- **机制**：5-羟色胺 → 下丘脑 → 皮质醇
- **意义**：应激反应调节

#### 去甲肾上腺素-肾上腺素
- **关系**：去甲肾上腺素合成肾上腺素
- **机制**：去甲肾上腺素 → 肾上腺素
- **意义**：应激反应
