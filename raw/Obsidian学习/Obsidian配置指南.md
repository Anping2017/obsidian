# Obsidian配置指南

## 📋 配置说明

### 配置目的
- **优化体验**：优化Obsidian使用体验
- **提高效率**：提高学习和工作效率
- **个性化设置**：个性化设置界面和功能
- **功能扩展**：扩展Obsidian功能

### 配置原则
- **简洁性**：界面简洁明了
- **功能性**：功能完整实用
- **个性化**：符合个人习惯
- **扩展性**：支持功能扩展

## ⚙️ 基础配置

### 界面设置
**主题选择**：
- 推荐主题：Obsidian、Minimal、Things
- 选择原则：简洁、清晰、护眼
- 设置方法：设置 → 外观 → 主题

**字体设置**：
- 推荐字体：思源黑体、微软雅黑、Arial
- 字体大小：14-16px
- 行高：1.5-1.8
- 设置方法：设置 → 外观 → 字体

**颜色设置**：
- 背景色：浅色或深色
- 文字色：对比度适中
- 链接色：突出显示
- 设置方法：设置 → 外观 → 颜色

### 编辑器设置
**编辑模式**：
- 实时预览：推荐开启
- 源码模式：根据需要
- 设置方法：设置 → 编辑器 → 编辑模式

**自动保存**：
- 自动保存：推荐开启
- 保存间隔：30秒
- 设置方法：设置 → 编辑器 → 自动保存

**拼写检查**：
- 拼写检查：推荐开启
- 语言设置：中文、英文
- 设置方法：设置 → 编辑器 → 拼写检查

## 🔧 功能配置

### 文件管理
**文件命名**：
- 命名规则：使用中文，避免特殊字符
- 文件结构：按主题分类
- 设置方法：设置 → 文件与链接 → 文件命名

**链接设置**：
- 内部链接：使用[[]]格式
- 外部链接：使用[]()格式
- 设置方法：设置 → 文件与链接 → 链接

**附件设置**：
- 附件位置：指定文件夹
- 附件格式：支持多种格式
- 设置方法：设置 → 文件与链接 → 附件

### 搜索功能
**搜索设置**：
- 搜索范围：全部文件
- 搜索选项：区分大小写
- 设置方法：设置 → 搜索 → 搜索选项

**快速搜索**：
- 快捷键：Ctrl+P
- 搜索内容：文件名、内容
- 设置方法：设置 → 快捷键 → 搜索

### 同步设置
**云同步**：
- 推荐服务：Obsidian Sync
- 同步内容：文件、设置、插件
- 设置方法：设置 → 同步 → 云同步

**本地同步**：
- 同步工具：Git、Dropbox、OneDrive
- 同步频率：实时或定时
- 设置方法：设置 → 同步 → 本地同步

## 🔌 插件配置

### 推荐插件
**核心插件**：
- 文件恢复：自动备份文件
- 工作区：保存工作状态
- 设置方法：设置 → 核心插件

**社区插件**：
- Dataview：数据视图
- Templater：模板系统
- Calendar：日历视图
- Mind Map：思维导图
- 设置方法：设置 → 社区插件

### 插件安装
**安装方法**：
1. 打开设置
2. 选择社区插件
3. 浏览插件
4. 安装插件
5. 启用插件

**插件管理**：
- 启用/禁用：根据需要
- 更新插件：定期更新
- 卸载插件：不需要时卸载
- 设置方法：设置 → 社区插件 → 管理

### 模板创建
**模板内容**：

## 🎨 个性化配置

### 快捷键设置
**常用快捷键**：
- 新建文件：Ctrl+N
- 打开文件：Ctrl+O
- 保存文件：Ctrl+S
- 搜索：Ctrl+P
- 设置：Ctrl+,

**自定义快捷键**：
- 设置方法：设置 → 快捷键
- 自定义原则：符合习惯
- 避免冲突：检查冲突

### 工作区设置
**工作区布局**：
- 文件树：左侧
- 编辑器：中间
- 预览：右侧
- 设置方法：设置 → 工作区

**工作区保存**：
- 保存布局：自动保存
- 恢复布局：启动时恢复
- 设置方法：设置 → 工作区 → 保存

## 📊 性能优化

### 性能设置
**文件数量**：
- 建议数量：1000-5000个文件
- 超过建议：考虑分库
- 设置方法：设置 → 性能

**插件数量**：
- 建议数量：10-20个插件
- 过多插件：影响性能
- 设置方法：设置 → 插件

**缓存设置**：
- 缓存大小：默认设置
- 清理缓存：定期清理
- 设置方法：设置 → 性能 → 缓存

### 备份设置
**自动备份**：
- 备份频率：每日
- 备份内容：文件、设置
- 设置方法：设置 → 备份

**手动备份**：
- 备份方法：复制文件夹
- 备份位置：外部存储
- 备份频率：重要更新前
