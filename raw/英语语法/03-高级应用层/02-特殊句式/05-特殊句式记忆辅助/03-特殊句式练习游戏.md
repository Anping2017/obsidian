# 特殊句式练习游戏

## 核心概念
特殊句式练习游戏通过趣味性的互动方式，帮助学习者在轻松愉快的氛围中掌握英语特殊句式的特点和用法。

## 游戏类型

### 1. 特殊句式识别游戏

#### 游戏名称: "句式侦探"
**游戏规则**: 
- 给出一个句子，要求识别特殊句式类型
- 答对得1分，答错扣1分
- 连续答对5个得额外奖励分

**游戏示例**:
```
句子: Here comes the bus.
答案: 倒装句
解释: 谓语comes在前，主语the bus在后，属于完全倒装
```

**难度等级**:
- **初级**: 简单句，常见特殊句式
- **中级**: 复合句，多种特殊句式
- **高级**: 复杂句，特殊特殊句式

#### 游戏名称: "句式连连看"
**游戏规则**:
- 给出两列句子，要求将相同句式的句子连接起来
- 时间限制3分钟
- 全部连接正确得满分

**游戏示例**:
```
左列: Here comes the bus.
右列: There goes the train.
答案: 连接（都是倒装句）
左列: It was Tom who broke the window.
右列: Here comes the bus.
答案: 不连接（句式不同）
```

### 2. 特殊句式转换游戏

#### 游戏名称: "句式变形记"
**游戏规则**:
- 给出一个句子，要求转换成其他特殊句式
- 每个转换得1分
- 转换越多得分越高

**游戏示例**:
```
原句: The bus comes here. (正常句)
转换: 
- Here comes the bus. (倒装句)
- It is here that the bus comes. (强调句)
- The bus comes here, and the train goes there. (省略句)
```

**转换规则**:
- **正常句→倒装句**: 主谓颠倒
- **正常句→强调句**: 使用It is...that结构
- **正常句→省略句**: 省略重复成分
- **正常句→独立主格**: 使用名词+分词结构

#### 游戏名称: "句式家族"
**游戏规则**:
- 给出一个句子，要求造出所有特殊句式
- 造出越多得分越高
- 时间限制5分钟

**游戏示例**:
```
原句: Tom broke the window.
家族: 
- Tom broke the window. (正常句)
- Here comes Tom. (倒装句)
- It was Tom who broke the window. (强调句)
- Tom broke the window, and Mary broke the door. (省略句)
- The window broken, Tom left. (独立主格)
```

### 3. 特殊句式填空游戏

#### 游戏名称: "句式填空大师"
**游戏规则**:
- 给出句子，挖空需要填的特殊句式
- 从选项中选择正确的句式
- 答对得1分，答错扣1分

**游戏示例**:
```
句子: ___ comes the bus.
选项: A. Here B. There C. Where D. When
答案: A. Here (倒装句)
解释: Here comes the bus是倒装句的典型结构
```

**填空类型**:
- **句式填空**: 选择正确的特殊句式
- **成分填空**: 选择正确的句子成分
- **连接词填空**: 选择正确的连接词

#### 游戏名称: "句式选择器"
**游戏规则**:
- 给出多个选项，要求选择正确的特殊句式
- 每个选项对应不同句式
- 选择正确得1分

**游戏示例**:
```
句子: ___ was Tom who broke the window.
选项: A. It B. That C. This D. There
答案: A. It (强调句)
解释: It was Tom who broke the window是强调句的典型结构
```

### 4. 特殊句式对比游戏

#### 游戏名称: "句式找不同"
**游戏规则**:
- 给出两个句子，找出句式不同的地方
- 找出越多得分越高
- 时间限制2分钟

**游戏示例**:
```
句子1: The bus comes here.
句子2: Here comes the bus.
不同: 正常句 vs 倒装句
```

#### 游戏名称: "句式配对"
**游戏规则**:
- 给出句式类别，要求找出对应的句子
- 配对正确得1分
- 全部配对正确得额外奖励

**游戏示例**:
```
句式类别: 倒装句
对应句子: Here comes the bus.
```

### 5. 特殊句式应用游戏

#### 游戏名称: "句式造句"
**游戏规则**:
- 给出句式要求，要求造出符合要求的句子
- 句子正确得1分
- 句子优美得额外奖励

**游戏示例**:
```
要求: 用倒装句造句
句子: Here comes the bus.
得分: 1分 (符合句式要求)
```

#### 游戏名称: "句式故事"
**游戏规则**:
- 给出句式序列，要求编出符合的故事
- 故事连贯得1分
- 故事有趣得额外奖励

**游戏示例**:
```
句式序列: 正常句 → 倒装句 → 强调句
故事: The bus comes here. Here comes the bus. It is here that the bus comes.
得分: 1分 (符合句式序列)
```

## 游戏评分系统

### 基础评分
- **答对1题**: 1分
- **答错1题**: -1分
- **连续答对5题**: +5分
- **时间奖励**: 提前完成+2分

### 等级评定
- **初级**: 0-20分
- **中级**: 21-40分
- **高级**: 41-60分
- **专家**: 61分以上

### 成就系统
- **句式新手**: 完成10题
- **句式达人**: 完成50题
- **句式大师**: 完成100题
- **句式专家**: 完成200题

## 游戏策略

### 策略1: 句式识别
1. **看结构特点**: 分析句子的结构特点
2. **看语法功能**: 分析句子的语法功能
3. **看语境**: 理解句子的语境

### 策略2: 句式转换
1. **掌握规律**: 熟记句式转换规律
2. **多练习**: 通过练习加深记忆
3. **举一反三**: 从一个句式扩展到其他句式

### 策略3: 句式应用
1. **理解功能**: 理解各句式的语法功能
2. **灵活运用**: 在实际中灵活运用
3. **创新表达**: 尝试创新表达方式

## 刻意练习

### 练习1: 基础识别
完成下列句式识别练习：
1. Here comes the bus.
2. It was Tom who broke the window.
3. I like apples and oranges.

### 练习2: 高级转换
完成下列句式转换练习：
1. 正常句 → 倒装句
2. 正常句 → 强调句
3. 正常句 → 省略句

### 练习3: 综合应用
完成下列综合应用练习：
1. 用给定句式造句
2. 找出句子中的句式错误
3. 改写句子改变句式
